Anleitungen auf Deutsch

VS Code und die Editoren, die darauf aufbauen (Cursor, Windsurf, VSCodium), öffnen Textdateien, Bilder und einige Medien. Für viele andere Formate brauchen Sie eine Erweiterung. Jede Anleitung nennt die Schritte und sagt, was kostenlos ist.

  • Eine .docx-Datei in VS Code öffnen. Word-, OpenDocument- und alte .doc-Dateien direkt in VS Code oder Cursor lesen, mit Gliederung, Suche, nachverfolgten Änderungen und Kommentaren. Kostenlos und offline.
  • Eine PowerPoint-Datei (.pptx) in VS Code ansehen. .pptx-, .ppsx- und alte .ppt-Dateien in VS Code oder Cursor ansehen, mit Miniaturansichten, Sprechernotizen, Suche und Vollbild-Präsentation. Kostenlos, ohne PowerPoint.
  • Eine Excel-Datei (.xlsx) in VS Code öffnen. .xlsx-, .xls- und .ods-Dateien in VS Code oder Cursor als Tabelle öffnen, mit Excel-Zahlenformaten, Filter, Sortierung, Statistik und SQL. Kostenlos, offline, ohne Excel.
  • PDFs im Dunkelmodus in VS Code lesen. PDFs in VS Code oder Cursor auf dunklen oder sepiafarbenen Seiten lesen. Text wird hell, Fotos behalten ihre echten Farben. Mit Suche, Gliederung und Markierungen. Kostenlos.
  • Binärdateien in VS Code als Hex ansehen und bearbeiten. Bytes jeder Datei in VS Code oder Cursor ansehen, suchen, bearbeiten und vergleichen, von 0 Byte bis zu einem 4-GB-Image. Mit Data Inspector und sicherem Speichern. Kostenlos und offline.
  • PDF-, Word-, PowerPoint- oder Excel-Datei in VS Code in Markdown umwandeln. Rechtsklick auf eine PDF-, DOCX-, PPTX-, XLSX-, CSV-, HTML- oder EPUB-Datei in VS Code, und das Markdown öffnet sich daneben. Kostenlos, offline, ohne Python.
  • XML in VS Code formatieren und XPath darauf ausführen. XML in VS Code formatieren oder minifizieren, wobei sich nur der Leerraum zwischen Tags ändert. Dazu XPath 1.0 mit den Namespaces der Datei und Copy XPath.
  • AWS-S3-, Cloudflare-R2- oder MinIO-Buckets in VS Code durchsuchen. S3-, R2-, MinIO-, B2- und Wasabi-Buckets in VS Code durchsuchen, Objekte schreibgeschützt öffnen, mit Fortsetzung hoch- und herunterladen, Ordner abgleichen.
  • Bash- oder Zsh-Skript in VS Code formatieren. Bash-, sh-, zsh-, bats- und mksh-Skripte in VS Code mit Shift+Alt+F oder beim Speichern formatieren. shfmt 3.14.1 ist eingebaut, liest .editorconfig, offline.
  • Zwei Excel- oder CSV-Dateien in VS Code vergleichen. Vergleichen Sie .xlsx, .xls, .ods oder CSV in VS Code Zelle für Zelle: geänderte Zellen, neue und entfernte Zeilen, Spalten, Blätter und Git HEAD. Kostenlos.
  • Audio in VS Code abspielen und LUFS messen. Audio Player spielt WAV, MP3, FLAC, Ogg und Opus in VS Code ab, mit Wellenform, Spektrogramm, A-B-Schleife und LUFS-Messung nach ITU-R BS.1770-4.
  • Tags in VS Code automatisch umbenennen. Tag Auto Rename & Close Tag Sync ändert beim Tippen den passenden Tag mit und schließt Tags, in HTML, JSX, Vue, Svelte, PHP und weiteren Sprachen.
  • Claude-Code- und Codex-Sitzungen in VS Code lesen. Agent Session Viewer zeigt Ihre Sitzungen aus Claude Code und Codex in VS Code. Lesen, durchsuchen und im Terminal fortsetzen, kostenlos und ohne Konto.
  • DXF-Zeichnungen in VS Code ansehen. DXF Viewer öffnet DXF von R12 bis AutoCAD 2018 in VS Code, mit Layouts, Layern, Textsuche, Messen und Export als PNG oder SVG, ganz ohne CAD-Programm.
  • SQLite-Datenbanken in VS Code bearbeiten. Mit SQLite DB Viewer öffnen Sie .db- und .sqlite-Dateien in VS Code, bearbeiten Zellen, importieren CSV-Dateien und speichern mit Sicherungskopie.
  • Binärdateien in VS Code ansehen. ELF Viewer & PE Viewer zeigt Header, Sektionen, Importe, Exporte und Sicherheitsflags von EXE, DLL, SO und Mach-O in VS Code, ohne readelf oder objdump.
  • Schriftdateien in VS Code prüfen. Font Viewer öffnet TTF, OTF, WOFF, WOFF2, TTC und OTC in VS Code. Testen Sie Text mit variablen Achsen, sehen Sie alle Glyphen und lesen Sie die Lizenz.
  • Graphviz-Vorschau in VS Code. Graphviz Viewer zeigt .dot- und .gv-Dateien in VS Code als Live-Vorschau. Graphviz 16.1 ist eingebaut, Sie müssen also nichts weiter installieren.
  • JAR- und Class-Dateien in VS Code ansehen. JAR Viewer zeigt Pakete, Klassen und Ressourcen einer JAR in VS Code, dazu Bytecode und mit CFR dekompilierten Java-Quelltext. Das Ansehen ist kostenlos.
  • Mermaid-Vorschau in VS Code. Mermaid Viewer zeigt .mmd-Dateien und mermaid-Blöcke in Markdown als Live-Vorschau in VS Code. Mermaid 12.3.0 ist eingebaut, offline und ohne Konto.
  • NetCDF und HDF5 in VS Code ansehen. Mit NetCDF Viewer & HDF5 Viewer öffnen Sie .nc- und .h5-Dateien ohne Python in VS Code und sehen Variablen, Attribute, Werte und Karten mit Küstenlinien.
  • NPY- und NPZ-Dateien in VS Code ansehen. Tensor Viewer öffnet .npy, .npz, PyTorch-Checkpoints, GGUF und Safetensors in VS Code, ohne Python, mit Form, Typ, Statistiken, Heatmap und Werten.
  • Netzwerkmitschnitte in VS Code analysieren. PCAP Viewer öffnet .pcap- und .pcapng-Dateien in VS Code, mit Paketliste, Protokollbaum, Display-Filtern und Follow Stream, ganz ohne Wireshark.
  • Videos mit Ton in VS Code abspielen. Video Preview with Sound spielt MP4 und MOV mit AAC-Ton in VS Code ab, ohne zusätzliche Installation. Mit Ihrem ffmpeg öffnen auch MKV, WebM und AVI.
  • C und C++ in VS Code mit einem Klick ausführen. Run C++ and C Code kompiliert .c- und .cpp-Dateien mit Ihrem gcc, g++, clang oder clang++ und startet das Programm im Terminal von VS Code.
  • 3D-Modelle (STL, OBJ, GLB) in VS Code ansehen. 3D Model Viewer öffnet STL, OBJ, GLB, glTF, PLY und 3MF direkt in VS Code. Sie drehen, zoomen und messen das Modell, ohne ein CAD-Programm zu starten.
  • TIFF-Dateien in VS Code ansehen. TIFF Viewer zeigt .tif- und .tiff-Dateien in VS Code an, auch mit 16 Bit, 32 Bit, Gleitkommawerten und GeoTIFF-Koordinaten.
  • XMind-Mindmaps in VS Code öffnen. XMind Viewer öffnet .xmind-Dateien aus XMind 8 und XMind 2020+ in VS Code, mit allen Blättern, Beziehungen, Notizen und Formeln, offline ohne Anmeldung.
  • ZIP- und TAR-Archive in VS Code durchsuchen. ZIP Viewer & Archive Explorer zeigt den Inhalt von ZIP-, JAR-, VSIX-, TAR- und GZ-Archiven in VS Code und entpackt nur die Dateien, die Sie brauchen.
