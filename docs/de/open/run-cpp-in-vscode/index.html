C und C++ in VS Code mit einem Klick ausführen

Installieren Sie Run C++ and C Code, öffnen Sie eine .c- oder .cpp-Datei und klicken Sie in der Titelleiste des Editors auf Run oder drücken Sie Strg+Alt+Enter (auf dem Mac Cmd+Alt+Enter). Die Erweiterung kompiliert mit dem Compiler, der bereits auf Ihrem Rechner installiert ist, und startet das Programm in einem Terminal, in dem scanf und cin funktionieren. Ausführen, der Bereich „Input & Tests“, der Stresstest und der Benchmark sind kostenlos. Zovo Pro (einmalig 19 USD) ergänzt eine Sanitizer-Prüfung, einen Vergleich von -O0, -O2 und -O3 und Testberichte, jeweils mit 3 kostenlosen Versuchen.

Schritte in VS Code

  1. Installieren Sie Run C++ and C Code aus dem Marketplace, oder drücken Sie Ctrl+P (Cmd+P unter macOS) und führen Sie ext install zovo.zovo-run-cpp aus.
  2. Öffnen Sie eine .c-, .cpp-, .cc- oder .cxx-Datei und klicken Sie auf Run oder drücken Sie Strg+Alt+Enter (auf dem Mac Cmd+Alt+Enter). Das Programm läuft im Terminal „Run: file.cpp“, wo Sie Eingaben eintippen. Am Ende sehen Sie Rückgabecode, Laufzeit und höchsten Speicherverbrauch.
  3. Fehler und Warnungen von gcc und clang erscheinen mit Datei, Zeile und Spalte im Bereich „Problems“. Das klappt auch, wenn der Pfad Leerzeichen, & oder Umlaute enthält, denn keine Shell verarbeitet Ihre Pfade.
  4. Wählen Sie im Menü „...“ der Titelleiste „Run with Input & Test Cases“. Im Bereich „Input & Tests“ fügen Sie Eingaben ein und sehen stdout, stderr, Rückgabecode, Laufzeit und Speicherverbrauch. Testfälle speichern Sie pro Datei und führen sie gemeinsam aus, mit Ergebnis je Test und zeilenweisem Vergleich der Ausgabe.
  5. Eine Zeile // run: -O2 -lm in den ersten 40 Zeilen setzt Compiler-Flags nur für diese Datei. Sie stehen hinter den Standard-Flags, deshalb setzt sich -O2 gegen -O0 durch. Mit // args: "Hello World" 3 übergeben Sie Programmargumente; Anführungszeichen halten Wörter mit Leerzeichen zusammen.
  6. Stop beendet eine Endlosschleife samt allen Prozessen, die das Programm gestartet hat. Bei einem Absturz nennt die Erweiterung das Signal und seine übliche Bedeutung. Zum Debuggen wählen Sie im Menü „...“ den Eintrag „Debug C/C++ File“.

In Cursor, Windsurf und VSCodium

Diese Editoren installieren Erweiterungen aus Open VSX. Öffnen Sie die Extensions-Ansicht (Ctrl+Shift+X), suchen Sie nach zovo.zovo-run-cpp und klicken Sie auf Install. Die Seite auf Open VSX ist zovo/zovo-run-cpp. Danach funktioniert alles wie in VS Code.

Was kostenlos ist

Kostenlos sind Kompilieren und Ausführen mit einem Klick, „Build Only (Compile, Don't Run)“, „Run Last Build (Don't Compile)“, „Build and Run All Files in This Folder“, das Debuggen, der Bereich „Input & Tests“ mit gespeicherten Testfällen, Flags und Argumente pro Datei, der Stresstest gegen eine Referenzlösung mit bis zu 10.000 Eingaben und der Benchmark mit 10 Durchläufen. Die Standard-Flags sind -std=c++20 -Wall -Wextra -g -O0 für C++ und -std=c17 -Wall -Wextra -g -O0 für C. Ist der Compiler zu alt für diese Standards, nimmt die Erweiterung den neuesten, den er kennt, und sagt das. Es gibt keine Netzwerkzugriffe, keine Telemetrie und kein Konto.

Was Zovo Pro hinzufügt

Der „Sanitizer Check“ baut eine Kopie Ihres Programms mit -fsanitize=address,undefined, führt sie mit der Eingabe aus dem Bereich „Input & Tests“ und mit jedem gespeicherten Testfall aus und trägt jeden Fund an der richtigen Zeile im Bereich „Problems“ ein. So finden Sie Speicherfehler und undefiniertes Verhalten, ohne Flags und Testläufe von Hand einzurichten. Außerdem gibt es „Compare -O0, -O2 and -O3“, das das Programm dreimal baut, jede Variante fünfmal ausführt und mittlere Laufzeit, Speicherverbrauch, Programmgröße und die Gleichheit der Ausgabe zeigt, sowie „Save a Test Report (JUnit XML and Markdown)“, das alle gespeicherten Testfälle ausführt und einen Bericht als JUnit XML und Markdown speichert.

So funktioniert Sanitizer Check

  1. Fügen Sie im Bereich „Input & Tests“ eine Eingabe ein oder speichern Sie Testfälle.
  2. Führen Sie in der Befehlspalette „Run C++: Sanitizer Check: AddressSanitizer and UBSan on the Input and Test Cases (Zovo Pro)“ aus, oder klicken Sie die Quelldatei im Explorer mit der rechten Maustaste an und wählen Sie „Zovo Pro: Sanitizer check“.
  3. Prüfen Sie die Funde im Bereich „Problems“. Ein Build-Fehler, Stop oder Abbrechen verbraucht keinen Versuch.

Sanitizer Check läuft 3 Mal kostenlos, danach braucht es eine Lizenz. Beim Öffnen einer Datei erscheint kein Pop-up, und es läuft kein Countdown.

Per Karte zahlen, einmalig USD 19

Zovo Pro kostet einmalig USD 19. Es ist kein Abo und schaltet die Pro-Werkzeuge in allen Zovo-Erweiterungen frei. Nach der Zahlung per Karte (Stripe) steht der Lizenzschlüssel auf der nächsten Seite. Führen Sie in VS Code "Enter Zovo Pro license key" aus der Command Palette aus und fügen Sie den Schlüssel ein. Der Schlüssel wird auf Ihrem Rechner geprüft, ohne Netzwerkzugriff.

Ein Team mit 5 Personen zahlt einmalig USD 59, ebenfalls per Karte. Alle Regeln und Pro-Werkzeuge stehen auf der Zovo-Pro-Seite (Englisch).

Was es nicht kann

  • Ein Compiler (gcc, g++, clang oder clang++) muss bereits installiert sein; die Erweiterung lädt nie selbst einen herunter.
  • Zum Debuggen brauchen Sie CodeLLDB oder die C/C++-Erweiterung von Microsoft.
  • Der Sanitizer Check braucht eine Sanitizer-Laufzeitbibliothek, also gcc oder clang unter macOS und Linux und clang aus LLVM unter Windows. Der gcc von MinGW bringt keine mit.
  • Läufe im Bereich „Input & Tests“ und Tests werden nach 10 Sekunden gestoppt (zovoRun.timeLimitSeconds); im Terminal gibt es kein Zeitlimit.

Fragen

Ist Run C++ and C Code kostenlos?

Ja. Ausführen, Debuggen, der Bereich „Input & Tests“, Stresstest und Benchmark sind kostenlos. Sanitizer Check, der Vergleich der Optimierungsstufen und der Testbericht sind Zovo-Pro-Werkzeuge mit je 3 kostenlosen Versuchen.

Mit welcher Tastenkombination starte ich das Programm?

Mit Strg+Alt+Enter, auf dem Mac mit Cmd+Alt+Enter. Solange ein Programm läuft, stoppt dieselbe Tastenkombination es.

Ändert die Erweiterung meine Einstellungen?

Nein, sie schreibt keine Einstellungsdateien. Nur wenn Sie Debug wählen, fügt sie einen einzigen Eintrag in launch.json hinzu.

Funktioniert das auch in Cursor?

Ja. Cursor installiert Erweiterungen aus Open VSX. Suchen Sie in der Erweiterungsansicht nach zovo.zovo-run-cpp.

Alle Funktionen und Einstellungen stehen auf der Seite von Run C++ and C Code (Englisch).
