Bash- oder Zsh-Skript in VS Code formatieren

Installieren Sie die kostenlose Erweiterung Shell Formatter for Bash & Zsh, öffnen Sie ein Shell-Skript und drücken Sie Shift+Alt+F (Shift+Option+F auf dem Mac). Die shfmt-3.14.1-Engine ist als WebAssembly in der Erweiterung enthalten, daher müssen Sie nichts herunterladen, und die Ausgabe ist Byte für Byte dieselbe wie bei shfmt auf der Kommandozeile. Format Document, Format Selection, Formatieren beim Speichern, die .editorconfig-Schlüssel und Syntaxfehler in Problems sind kostenlos und funktionieren offline. Zovo Pro (einmalig 19 USD) ergänzt drei Werkzeuge, Format All Shell Scripts in a Folder, Formatting Check with a Patch File und Minify a Script to a Copy, jeweils mit 3 kostenlosen Versuchen.

Schritte in VS Code

  1. Installieren Sie Shell Formatter for Bash & Zsh aus dem Marketplace, oder drücken Sie Strg+P (Cmd+P unter macOS) und führen Sie ext install zovo.zovo-shell-formatter aus.
  2. Öffnen Sie ein Shell-Skript und drücken Sie Shift+Alt+F (Shift+Option+F auf dem Mac). Wenn VS Code fragt, welcher Formatierer verwendet werden soll, wählen Sie Shell Formatter, oder führen Sie „Shell Formatter: Use as Default Formatter for Shell Scripts“ aus.
  3. Damit bei jedem Speichern formatiert wird, führen Sie „Shell Formatter: Turn On Format on Save for Shell Scripts“ aus.
  4. Der Dialekt kommt aus der ersten Zeile (#!/bin/bash, #!/bin/sh, #!/usr/bin/env zsh), dann aus dem Dateinamen (.bash, .zsh, .zshrc, .bats, .ksh), sonst gilt bash. Mit shellFormatter.dialect oder shell_variant in .editorconfig legen Sie ihn selbst fest.
  5. Klicken Sie in der Statusleiste auf shfmt 3.14.1, um das Menü zu öffnen: formatieren, als Standard festlegen, Formatieren beim Speichern, „Copy the matching shfmt command (for CI)“ und Einstellungen.
  6. Ist das Skript kein gültiges Shell-Skript, bleibt es unverändert, und das Problems-Panel zeigt Zeile und Spalte.

Was kostenlos ist und was Zovo Pro dazu gibt

Format Document, Format Selection, Formatieren beim Speichern, die Dialekterkennung, die .editorconfig-Schlüssel, das Menü in der Statusleiste, Copy the Matching shfmt Command (for CI) und Syntaxfehler in Problems sind kostenlos. Es gibt keine Anmeldung, keine Netzwerkanfrage und keine Telemetrie.

Format All Shell Scripts in a Folder prüft jedes Skript in einem Ordner und seinen Unterordnern, erkannt am Namen oder an einer #!-Zeile, die eine Shell nennt, und meldet, wie viele sich ändern würden. Danach formatiert es alle oder liefert einen Markdown-Bericht, mit derselben Engine, denselben Einstellungen und derselben .editorconfig wie Format Document. Ein Repository mit Dutzenden Skripten in verschiedenen Stilen erhält in einem Durchgang einen einheitlichen Stil, und Skripte, die danach nicht mehr dieselben Befehle ausführen würden, bleiben, wie sie sind.

Mit Format All Shell Scripts in a Folder (Zovo Pro)

  1. Klicken Sie im Explorer mit der rechten Maustaste auf einen Ordner und wählen Sie „Zovo Pro: Format All Shell Scripts in a Folder“, oder führen Sie „Shell Formatter: Format All Shell Scripts in a Folder (Pro)“ in der Command Palette oder im Menü der Statusleiste aus und wählen Sie den Ordner.
  2. Der Titel der nächsten Liste zeigt, wie viele Skripte sich ändern würden, etwa „N of M scripts would change“.
  3. Wählen Sie „Format N scripts“, um jede Datei zu formatieren und zu speichern (Rückgängig funktioniert pro Datei), oder „Show the report only“ für eine Markdown-Liste aller Skripte, ohne dass sich etwas ändert.
  4. Ein Versuch zählt nur, wenn Sie ein Ergebnis erhalten. Ein Ordner ohne Shell-Skripte oder mit lauter bereits formatierten Skripten verbraucht keinen.

Format All Shell Scripts in a Folder funktioniert 3-mal auf Ihrem Computer, bevor es nach einer Lizenz fragt. Beim Öffnen einer Datei gibt es kein Pop-up und keinen Countdown.

Schritte in Cursor, Windsurf oder VSCodium

  1. Öffnen Sie die Ansicht Extensions mit Strg+Umschalt+X (Cmd+Umschalt+X unter macOS).
  2. Suchen Sie nach zovo.zovo-shell-formatter und klicken Sie auf Install. Cursor, Windsurf und VSCodium installieren aus Open VSX, dort heißt die Erweiterung zovo/zovo-shell-formatter.
  3. Hat Ihr Editor keine Galerie, laden Sie die .vsix-Datei von der Open-VSX-Seite herunter und führen Sie „Extensions: Install from VSIX...“ aus.
  4. Danach funktioniert alles wie in VS Code.

Was Shell Formatter for Bash & Zsh öffnet

  • Bash-, POSIX-sh- (auch dash und ash), mksh- (auch ksh), bats- und zsh-Skripte.
  • Dieselbe Ausgabe wie shfmt 3.14.1 auf der Kommandozeile. 354 von 354 Läufen mit 178 echten Skripten aus GitHub-Projekten und Homebrew stimmten Byte für Byte überein.
  • Bevor eine Änderung angewendet wird, wird das formatierte Skript erneut geparst und muss dieselben Befehle ausführen wie das Original (Dateien bis 256 KB).
  • shfmt-Optionen als Einstellungen oder .editorconfig-Schlüssel: Einrückung, binäre Operatoren in der nächsten Zeile, Einrückung von switch case, Leerzeichen bei Umleitungen, Ausrichtung beibehalten, Funktionsklammern in der nächsten Zeile, Vereinfachen und Minifizieren.
  • Windows-Zeilenenden (CRLF) bleiben CRLF, und ein 2-MB-Skript wird in etwa 0,2 Sekunden formatiert.

Was es nicht kann

  • Dockerfiles, .env-Dateien sowie fish- und csh-Skripte werden nie angefasst.
  • Die zsh-Unterstützung in shfmt ist neu. Ein zsh-Skript, das shfmt nicht parsen kann, bleibt unverändert.
  • Dateien über 10 MB (Einstellung shellFormatter.maxFileMB) und Dateien mit Binärbytes, etwa selbstentpackende Installer, werden nicht formatiert.
  • shfmt läuft mit einem Zeitlimit (standardmäßig 10 Sekunden, Einstellung shellFormatter.timeoutSeconds). Wird es erreicht, bleibt die Datei unverändert.

Häufige Fragen

Ist es kostenlos?

Format Document, Format Selection, Formatieren beim Speichern und die .editorconfig-Unterstützung sind kostenlos. Die drei Pro-Werkzeuge Format All Shell Scripts in a Folder, Formatting Check with a Patch File und Minify a Script to a Copy haben jeweils 3 kostenlose Versuche. Danach brauchen sie Zovo Pro, einmalig 19 USD für alle Zovo-Erweiterungen.

Muss ich shfmt installieren?

Nein. shfmt 3.14.1 ist als WebAssembly in der Erweiterung enthalten, daher funktioniert sie offline, ohne dass etwas heruntergeladen wird.

Kann die Formatierung mein Skript beschädigen?

Ein Skript mit Syntaxfehler bleibt unverändert. Bevor eine Änderung angewendet wird, wird das formatierte Skript erneut geparst und muss dieselben Befehle ausführen wie das Original.

Funktioniert es in Cursor?

Ja. Cursor, Windsurf und VSCodium installieren die Erweiterung aus Open VSX, wo sie als zovo/zovo-shell-formatter veröffentlicht ist.
