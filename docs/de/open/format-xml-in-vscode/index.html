XML in VS Code formatieren und XPath darauf ausführen

Installieren Sie die kostenlose Erweiterung XML Formatter & XPath Tools, öffnen Sie eine XML-Datei und drücken Sie Shift+Alt+F (Shift+Option+F auf dem Mac). Nur der Leerraum zwischen Tags ändert sich. Text, CDATA, Kommentare, xml:space="preserve" und Attributwerte bleiben Byte für Byte erhalten, und eine Datei, die nicht wohlgeformt ist, wird nie verändert. Formatieren, Minify XML, XPath 1.0 mit den Namespace-Präfixen der Datei, Copy XPath und die Ansicht XML Tree sind kostenlos und funktionieren offline. Schritte in VS Code

  1. Installieren Sie XML Formatter & XPath Tools aus dem Marketplace, oder drücken Sie Strg+P (Cmd+P unter macOS) und führen Sie ext install zovo.zovo-xml-xpath-tools aus.
  2. Öffnen Sie eine .xml-Datei und drücken Sie Shift+Alt+F (Shift+Option+F auf dem Mac), oder führen Sie Format Document aus. Wenn Sie mehr als einen XML-Formatierer installiert haben, fragt VS Code, welcher verwendet werden soll. Format Selection funktioniert ebenfalls.
  3. Der Formatierer übernimmt Ihre Tabulatorgröße und Ihre Wahl zwischen Tabs und Leerzeichen und behält Zeilenenden, Byte Order Mark und den abschließenden Zeilenumbruch bei. Ist die Datei nicht wohlgeformt, ändert sich nichts, und Sie erhalten den Fehler mit Zeile und Spalte.
  4. Um die Datei stattdessen zu verkleinern, führen Sie „XML: Minify XML“ für die ganze Datei oder eine Auswahl aus. Kommentare bleiben erhalten, außer Sie aktivieren xmlXpathTools.minify.removeComments.
  5. Um einen XPath auszuführen, klicken Sie auf die Suchschaltfläche im Editortitel oder führen Sie „XML: Evaluate XPath…“ aus. Die Treffer erscheinen mit ihrer Zeile in XPath Results. Ein Klick auf einen Treffer markiert ihn im Editor.
  6. Klicken Sie auf den XPath in der Statusleiste, um den Pfad des Elements unter dem Cursor zu kopieren, mit Positionen, mit id- oder name-Attributen oder in einer portablen Form mit local-name().
  7. Bei einer Datei über 50 MB klicken Sie im Explorer mit der rechten Maustaste darauf und wählen „Format Large XML File on Disk…“. Der Befehl schreibt name.formatted.xml daneben oder ersetzt die Datei, nachdem Sie bestätigt haben.

Was kostenlos ist und was Zovo Pro dazu gibt

Format Document, Format Selection, Minify XML, XPath 1.0, Copy XPath, die Ansicht XML Tree, die Wohlgeformtheitsfehler in Problems und Format Large XML File on Disk sind kostenlos. Es gibt keine Anmeldung, und die Erweiterung enthält keinen Netzwerkcode.

Run XPath on Every XML File in a Folder führt einen XPath über jede Datei vom Typ .xml, .xsd, .csproj, .svg, .kml und ähnliche in einem Ordner aus, jeweils mit den eigenen Namespace-Präfixen der Datei. Die Ergebnisse öffnen sich als CSV (file, line, kind, name, value) für eine Tabellenkalkulation, als JSON für ein Skript oder als Markdown-Bericht für ein Review. So erhalten Sie denselben Wert aus vielen Dateien, etwa jede artifactId in einer Reihe von pom.xml-Dateien, ohne sie einzeln zu öffnen.

Mit Run XPath on Every XML File in a Folder (Zovo Pro)

  1. Klicken Sie im Explorer mit der rechten Maustaste auf einen Ordner und wählen Sie „Zovo Pro: Run XPath on Every XML File in a Folder“, oder führen Sie „XML: Run XPath on Every XML File in a Folder (Pro)“ in der Command Palette aus und wählen Sie den Ordner.
  2. Oder klicken Sie, nachdem Sie einen XPath in einer Datei ausgeführt haben, auf die letzte Zeile von XPath Results, „Run this XPath on every XML file in a folder“, um denselben Ausdruck auf einen Ordner anzuwenden.
  3. Geben Sie den XPath ein. Eine Benachrichtigung zeigt den Fortschritt mit einer Cancel-Schaltfläche.
  4. Wählen Sie „Open as CSV“, „Open as JSON“ oder „Open a Markdown report“. Die Ergebnisse öffnen sich in einem neuen Editor-Tab. Ein Versuch zählt nur, wenn Sie ein Ergebnis erhalten. Escape, ein Tippfehler im XPath oder ein Ordner ohne XML-Dateien verbraucht keinen.

Run XPath on Every XML File in a Folder funktioniert 3-mal auf Ihrem Computer, bevor es nach einer Lizenz fragt. Beim Öffnen einer Datei gibt es kein Pop-up und keinen Countdown.

Schritte in Cursor, Windsurf oder VSCodium

  1. Öffnen Sie die Ansicht Extensions mit Strg+Umschalt+X (Cmd+Umschalt+X unter macOS).
  2. Suchen Sie nach zovo.zovo-xml-xpath-tools und klicken Sie auf Install. Cursor, Windsurf und VSCodium installieren aus Open VSX, dort heißt die Erweiterung zovo/zovo-xml-xpath-tools.
  3. Hat Ihr Editor keine Galerie, laden Sie die .vsix-Datei von der Open-VSX-Seite herunter und führen Sie „Extensions: Install from VSIX...“ aus.
  4. Danach funktioniert alles wie in VS Code.

Was XML Formatter & XPath Tools öffnet

  • Dateien, die VS Code als XML öffnet. Die Erweiterung öffnet außerdem Dateien vom Typ .kml, .gpx, .rss, .atom, .wsdl, .dbk, .xlf, .xliff, .resx, .nuspec, .props, .targets und .xaml als XML.
  • Große Dateien. Formatieren, Baum und XPath laufen in einem Hintergrund-Thread. In den Tests der Erweiterung wurde eine 49-MB-Datei mit etwa 1 Million Elementen in 1,6 Sekunden formatiert.
  • Einfache Namen treffen auch einen Default-Namespace, daher funktioniert //dependency/artifactId in einer pom.xml. Für striktes XPath 1.0 aktivieren Sie xmlXpathTools.xpath.strictNamespaces.
  • Attribut-Layout wie geschrieben, in einer Zeile oder ein Attribut pro Zeile (Einstellung xmlXpathTools.format.attributes).
  • Die Ansicht XML Tree im Explorer folgt dem Cursor, und Problems listet Wohlgeformtheitsfehler mit Zeile und Spalte.

Was es nicht kann

  • Nur XPath 1.0. XPath 2.0 oder 3.1, XQuery und XSLT werden nicht unterstützt.
  • Die Erweiterung prüft, ob eine Datei wohlgeformt ist. Sie validiert nicht gegen ein XSD oder eine DTD.
  • Dateien über 50 MB lassen sich auf der Festplatte formatieren, aber VS Code übergibt sie nicht an Erweiterungen, deshalb laufen Baum und XPath nicht auf ihnen.
  • Der Befehl für die Festplatte liest UTF-8, UTF-16 mit Byte Order Mark und ISO-8859-1.
  • Ein Element mit Text darin, etwa <p>Some <b>bold</b> text</p>, bleibt so in seiner Zeile, wie es geschrieben ist. Nur Elemente, die Tags und keinen Text enthalten, erhalten neue Zeilenumbrüche.

Häufige Fragen

Ist es kostenlos?

Formatieren, Minify XML, XPath, Copy XPath, die Ansicht XML Tree und die Prüfung auf Wohlgeformtheit sind kostenlos. Die drei Pro-Werkzeuge Run XPath on Every XML File in a Folder, Format All XML Files in a Folder und Compare Two XML Files Ignoring Formatting haben jeweils 3 kostenlose Versuche. Danach brauchen sie Zovo Pro, einmalig 19 USD für alle Zovo-Erweiterungen.

Ändert das Formatieren meinen Text oder CDATA?

Nein. Nur der Leerraum zwischen Tags ändert sich, und zwar in Elementen, die Tags und keinen Text enthalten. Text, CDATA, Kommentare und Inhalt in xml:space="preserve" werden unverändert übernommen, und ein zweites Formatieren ändert nichts mehr.

Warum findet mein XPath in einer pom.xml nichts?

Die Datei hat einen Default-Namespace. In dieser Erweiterung treffen einfache Namen auch einen Default-Namespace, daher funktioniert //dependency. Für striktes XPath 1.0 aktivieren Sie xmlXpathTools.xpath.strictNamespaces.

Funktioniert es in Cursor?

Ja. Cursor, Windsurf und VSCodium installieren die Erweiterung aus Open VSX, wo sie als zovo/zovo-xml-xpath-tools veröffentlicht ist.
