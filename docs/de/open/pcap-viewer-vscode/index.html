Netzwerkmitschnitte in VS Code analysieren

Installieren Sie PCAP Viewer und klicken Sie auf eine .pcap- oder .pcapng-Datei. Die Erweiterung liest den Mitschnitt selbst, Wireshark, tshark oder sharkd brauchen Sie nicht. Paketliste, Protokollbaum, Hex-Ansicht, Display-Filter, Follow TCP/UDP Stream, Statistiken und der Export als pcap sind kostenlos. Zovo Pro (einmalig 19 USD) ergänzt den Export der Paketliste als CSV oder JSON, einen Bericht im Markdown-Format und eine Zusammenfassung ganzer Ordner, jeweils mit 3 kostenlosen Versuchen.

In VS Code installierenMarketplace-SeiteOpen VSX (Cursor, Windsurf, VSCodium)

Kostenlos, MIT-Lizenz. Extension ID zovo.zovo-pcap-viewer.

Schritte in VS Code

  1. Installieren Sie PCAP Viewer aus dem Marketplace, oder drücken Sie Ctrl+P (Cmd+P unter macOS) und führen Sie ext install zovo.zovo-pcap-viewer aus.
  2. Klicken Sie im Explorer auf eine .pcap-, .pcapng-, .pcap.gz- oder .pcapng.gz-Datei. Gepackte Mitschnitte werden im Arbeitsspeicher entpackt. Für .cap oder andere Dateinamen wählen Sie im Kontextmenü „Open in PCAP Viewer“.
  3. Wählen Sie ein Paket, um seinen Protokollbaum zu sehen. Ein Klick auf ein Feld hebt die zugehörigen Bytes in der Hex-Ansicht hervor, ein Klick auf ein Byte wählt das passende Feld.
  4. Geben Sie einen Display-Filter in der Syntax von Wireshark ein, etwa tcp.port == 443 oder ip.addr == 10.0.0.0/24. Ist der Ausdruck gültig, wird das Feld grün; häufig genutzte Filter speichern Sie über das Stern-Menü. Mit einem Rechtsklick auf ein Paket filtern Sie nach Quelle, Ziel, Verbindung oder Protokoll.
  5. Doppelklicken Sie auf ein Paket, um seinem TCP- oder UDP-Stream zu folgen. Die Daten erscheinen der Reihe nach, vom Client zum Server in Rot und vom Server zum Client in Blau, wahlweise als ASCII, UTF-8 oder Hexdump. Sie können sie kopieren oder als Datei speichern.
  6. Führen Sie in der Befehlspalette „PCAP Viewer: Statistics (Conversations, Endpoints, Protocols)“ aus, um Protokollhierarchie, Verbindungen und Endpunkte zu sehen; ein Klick auf eine Zeile setzt den passenden Filter. Mit Strg+G (auf dem Mac Cmd+G) springen Sie zu einer bestimmten Paketnummer.

In Cursor, Windsurf und VSCodium

Diese Editoren installieren Erweiterungen aus Open VSX. Öffnen Sie die Extensions-Ansicht (Ctrl+Shift+X), suchen Sie nach zovo.zovo-pcap-viewer und klicken Sie auf Install. Die Seite auf Open VSX ist zovo/zovo-pcap-viewer. Danach funktioniert alles wie in VS Code.

Was kostenlos ist

Kostenlos sind das Lesen von pcap und pcapng (auch als .gz), Paketliste, Protokollbaum und Hex-Ansicht, Display-Filter, Follow TCP/UDP Stream, Protokollhierarchie, Verbindungen und Endpunkte sowie der Export ausgewählter oder gefilterter Pakete als neue pcap-Datei. Dekodiert werden unter anderem Ethernet, VLAN, IPv4, IPv6, ICMP, TCP, UDP, DNS, DHCP, HTTP/1.x, TLS-Records mit SNI und ALPN sowie QUIC-Long-Header. Hostnamen stammen nur aus dem Mitschnitt selbst, nichts wird im Netz nachgeschlagen, und es gibt keine Telemetrie. Große Dateien werden in einem eigenen Thread gelesen; in den Release-Tests war ein 1-GB-Mitschnitt mit 1.438.965 Paketen in etwa 2 Sekunden aufgelistet.

Was Zovo Pro hinzufügt

„Capture Report, Markdown“ schreibt eine Markdown-Datei, die Sie direkt in ein Ticket einfügen können. Sie enthält eine Zusammenfassung, die Protokolle, die wichtigsten Endpunkte und Verbindungen, DNS-Anfragen mit Antworten, TLS-Servernamen, HTTP-Anfragen, Antwortcodes, User-Agents und DHCP-Hostnamen. Statt diese Angaben von Hand zusammenzusuchen, erhalten Sie sie in einem Schritt. Die anderen Pro-Werkzeuge sind „Export Packet List to CSV or JSON“, das die gefilterten Pakete als Tabelle für Excel, jq oder pandas speichert, und „Summarize a Folder of Captures to CSV“, das eine CSV-Zeile pro Mitschnitt eines Ordners schreibt.

So funktioniert Capture Report, Markdown

  1. Öffnen Sie den Mitschnitt und wählen Sie im Export-Menü der Werkzeugleiste den Capture Report, oder führen Sie in der Befehlspalette „PCAP Viewer: Capture Report, Markdown (Pro)...“ aus.
  2. Alternativ klicken Sie im Explorer mit der rechten Maustaste auf eine .pcap- oder .pcapng-Datei und wählen „Zovo Pro: Capture report“.
  3. Wählen Sie den Speicherort. Ein Versuch zählt erst, wenn die Datei geschrieben wurde; Escape oder ein Fehler verbrauchen keinen.

Capture Report, Markdown läuft 3 Mal kostenlos, danach braucht es eine Lizenz. Beim Öffnen einer Datei erscheint kein Pop-up, und es läuft kein Countdown.

Per Karte zahlen, einmalig USD 19

Zovo Pro kostet einmalig USD 19. Es ist kein Abo und schaltet die Pro-Werkzeuge in allen Zovo-Erweiterungen frei. Nach der Zahlung per Karte (Stripe) steht der Lizenzschlüssel auf der nächsten Seite. Führen Sie in VS Code "Enter Zovo Pro license key" aus der Command Palette aus und fügen Sie den Schlüssel ein. Der Schlüssel wird auf Ihrem Rechner geprüft, ohne Netzwerkzugriff.

Ein Team mit 5 Personen zahlt einmalig USD 59, ebenfalls per Karte. Alle Regeln und Pro-Werkzeuge stehen auf der Zovo-Pro-Seite (Englisch).

Was es nicht kann

  • TLS-Entschlüsselung, HTTP/2 und Live-Mitschnitte werden nicht unterstützt. 802.11 wird nur bis zum Header dekodiert, QUIC nur mit Long-Headern.
  • Gepackte .gz-Mitschnitte werden höchstens bis 512 MB entpackt (pcapViewer.maxGzipMB); darüber erscheint eine Meldung.
  • Dateien auf Remote- oder virtuellen Dateisystemen öffnen bis 256 MB (pcapViewer.maxRemoteMB).
  • .cap, .dmp und einfache .gz-Dateien öffnen nicht per Klick, sondern über „Open in PCAP Viewer“.

Fragen

Ist PCAP Viewer kostenlos?

Ja. Ansehen, Filtern, Follow Stream, die Statistiken und der Export als pcap sind kostenlos. Der Export als CSV oder JSON, der Markdown-Bericht und die Ordner-Zusammenfassung sind Zovo-Pro-Werkzeuge mit je 3 kostenlosen Versuchen.

Muss Wireshark installiert sein?

Nein. Die Erweiterung liest die Datei selbst, unter Windows, macOS und Linux. Wireshark, tshark oder sharkd werden nicht gebraucht.

Was passiert bei beschädigten Dateien?

Sie sehen alle Pakete vor der beschädigten Stelle und eine Meldung, was dort nicht stimmt, zum Beispiel ein abgeschnittenes Paket oder ein Block, der über das Dateiende hinausreicht.

Funktioniert das auch in Cursor?

Ja. Cursor installiert Erweiterungen aus Open VSX. Suchen Sie in der Erweiterungsansicht nach zovo.zovo-pcap-viewer.

Alle Funktionen und Einstellungen stehen auf der Seite von PCAP Viewer (Englisch).
