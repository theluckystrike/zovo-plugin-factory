Claude-Code- und Codex-Sitzungen in VS Code lesen

Mit Agent Session Viewer erscheinen Ihre lokalen Sitzungen aus Claude Code und Codex in einer eigenen Ansicht in VS Code, nach Projektordner sortiert. Lesen, die Suche über alle Sitzungen, das Fortsetzen im Terminal und der Markdown-Export einer einzelnen Sitzung sind kostenlos, ohne Konto und ohne Begrenzung des Verlaufs. Zovo Pro (einmalig 19 USD) ergänzt einen Nutzungs- und Kostenbericht, einen Export mit geschwärzten Geheimnissen und den Sammelexport nach Markdown, und jedes dieser Werkzeuge können Sie dreimal kostenlos ausprobieren.

In VS Code installierenMarketplace-SeiteOpen VSX (Cursor, Windsurf, VSCodium)

Kostenlos, MIT-Lizenz. Extension ID zovo.agent-session-viewer.

Schritte in VS Code

  1. Installieren Sie Agent Session Viewer aus dem Marketplace, oder drücken Sie Ctrl+P (Cmd+P unter macOS) und führen Sie ext install zovo.agent-session-viewer aus.
  2. Klicken Sie in der Aktivitätsleiste auf das Symbol „Agent Sessions“. Sitzungen aus Claude Code (~/.claude/projects) und Codex (~/.codex/sessions) stehen in einem gemeinsamen Baum, nach Projektordner gruppiert. Subagents hängen unter der Sitzung, die sie gestartet hat.
  3. Klicken Sie auf eine Sitzung, um sie zu öffnen. Der Kopfbereich zeigt Werkzeug, Modell, Git-Branch, Dauer, Zahl der Gesprächsrunden und die Token-Summen. Kosten erscheinen nur, wenn die Datei sie enthält: Claude Code schreibt sie, Codex nicht. Dateiänderungen sehen Sie als Diff.
  4. Mit „Search Sessions“ oben in der Ansicht durchsuchen Sie alle Sitzungen. Ein Treffer öffnet die Sitzung an der Fundstelle, und das Suchfeld der Sitzung zählt alle Treffer, auch in eingeklappten Ausgaben von Werkzeugaufrufen.
  5. Um weiterzuarbeiten, klicken Sie mit der rechten Maustaste auf die Sitzung und wählen „Resume in Terminal“. Im Projektordner öffnet sich ein Terminal und führt claude --resume oder codex resume mit der Sitzungs-ID aus.
  6. „Copy Resume Command“ kopiert nur den Befehl, standardmäßig mit einem vorangestellten cd (agentSessionViewer.resumeWithCd). Mit „Export to Markdown…“ speichern Sie eine einzelne Sitzung als Markdown-Datei.

In Cursor, Windsurf und VSCodium

Diese Editoren installieren Erweiterungen aus Open VSX. Öffnen Sie die Extensions-Ansicht (Ctrl+Shift+X), suchen Sie nach zovo.agent-session-viewer und klicken Sie auf Install. Die Seite auf Open VSX ist zovo/agent-session-viewer. Danach funktioniert alles wie in VS Code.

Was kostenlos ist

Kostenlos und ohne Begrenzung sind der Sitzungsbaum, das Lesen der Sitzungen, die Suche über alle Sitzungen, „Resume in Terminal“, „Copy Resume Command“, der Markdown-Export einer einzelnen Sitzung, die Rohansicht und „Reveal in File Manager“. Sie sehen Ihren ganzen Verlauf, nicht nur die letzten Tage. Die Erweiterung liest nur: Sie ändert, verschiebt und löscht keine Sitzungsdateien. Die kostenlosen Funktionen brauchen keine Anmeldung, senden keine Telemetrie und machen keine Netzwerkaufrufe.

Was Zovo Pro hinzufügt

Usage and Cost Report addiert die Token aller Sitzungen, eines Projekts oder eines Werkzeugs in einem Zeitraum, den Sie wählen, und schätzt die Kosten pro Projekt, Modell und Tag zu API-Listenpreisen. Heraus kommen ein Markdown-Bericht und eine CSV-Datei mit einer Zeile pro Tag, Projekt und Modell, die Sie direkt für eine Kundenabrechnung oder eine Tabellenkalkulation verwenden können. Die weiteren Pro-Werkzeuge sind Share-Safe Export, der eine Sitzung oder ein ganzes Projekt als HTML-Seite oder Markdown ausgibt und dabei API-Schlüssel, Token, Passwörter, .env-Werte, private Schlüssel, E-Mail-Adressen und Ihren Benutzerordner unkenntlich macht, und Bulk Export to Markdown, der alle Sitzungen eines Projekts, eines Werkzeugs oder eines Zeitraums als Markdown-Dateien mit einer index.md in einen neuen Ordner schreibt.

So funktioniert Usage and Cost Report

  1. Klicken Sie im Sitzungsbaum mit der rechten Maustaste auf einen Projektordner und wählen „Usage and Cost Report (Pro)…“, oder führen Sie in der Befehlspalette „Agent Sessions: Usage and Cost Report (Pro)…“ aus.
  2. Wählen Sie den Umfang und den Zeitraum. Die Erweiterung speichert einen Markdown-Bericht und eine CSV-Datei.

Usage and Cost Report läuft 3 Mal kostenlos, danach braucht es eine Lizenz. Beim Öffnen einer Datei erscheint kein Pop-up, und es läuft kein Countdown.

Per Karte zahlen, einmalig USD 19

Zovo Pro kostet einmalig USD 19. Es ist kein Abo und schaltet die Pro-Werkzeuge in allen Zovo-Erweiterungen frei. Nach der Zahlung per Karte (Stripe) steht der Lizenzschlüssel auf der nächsten Seite. Führen Sie in VS Code "Enter Zovo Pro license key" aus der Command Palette aus und fügen Sie den Schlüssel ein. Der Schlüssel wird auf Ihrem Rechner geprüft, ohne Netzwerkzugriff.

Ein Team mit 5 Personen zahlt einmalig USD 59, ebenfalls per Karte. Alle Regeln und Pro-Werkzeuge stehen auf der Zovo-Pro-Seite (Englisch).

Was es nicht kann

  • Gelesen werden nur Sitzungen aus Claude Code und Codex. Sitzungen aus Cursor, Copilot und Gemini CLI werden noch nicht unterstützt.
  • Zum Fortsetzen muss Claude Code beziehungsweise Codex installiert und im Terminal über den PATH erreichbar sein.
  • Die Suche findet reinen Text, keine regulären Ausdrücke, und hört nach 300 Treffern auf. Die Liste zeigt höchstens 2.000 Sitzungen (agentSessionViewer.maxSessions).
  • Die Kosten im Pro-Bericht sind eine Schätzung zu API-Listenpreisen. Wer Claude Pro oder Max oder einen ChatGPT-Tarif nutzt, zahlt nach Tarif.

Fragen

Ist die Erweiterung kostenlos?

Ja. Lesen, Suchen, Fortsetzen und der Export einer einzelnen Sitzung sind kostenlos, ohne Konto und ohne Begrenzung des Verlaufs. Nur Usage and Cost Report, Share-Safe Export und Bulk Export to Markdown gehören zu Zovo Pro. Jedes davon können Sie dreimal kostenlos ausprobieren, und ein Versuch zählt nur, wenn das Werkzeug seine Datei gespeichert hat.

Kann die Erweiterung Sitzungen löschen oder verändern?

Nein. Sie liest die Sitzungsdateien nur und hat keinen Befehl zum Löschen, Verschieben oder Umbenennen. Sie schreibt nur die Exporte, die Sie selbst anlegen.

Funktioniert die Erweiterung in Cursor?

Ja, sie lässt sich über Open VSX in Cursor installieren. Lesen kann sie aber nur Sitzungen aus Claude Code und Codex, nicht den Chatverlauf von Cursor selbst.

Gehört die Erweiterung zu Anthropic oder OpenAI?

Nein. Sie ist ein eigenständiges Projekt und mit Anthropic und OpenAI nicht verbunden.

Alle Funktionen und Einstellungen stehen auf der Seite von Agent Session Viewer (Englisch).
