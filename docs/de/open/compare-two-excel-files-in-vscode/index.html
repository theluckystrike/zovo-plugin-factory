Zwei Excel- oder CSV-Dateien in VS Code vergleichen

Installieren Sie die kostenlose Erweiterung Excel Compare & XLSX Diff und wählen Sie zwei Arbeitsmappen oder CSV-Dateien. Geänderte Zellen erscheinen gelb mit dem alten Wert durchgestrichen, hinzugefügte Zeilen grün und entfernte Zeilen rot. Die Zeilen werden aneinander ausgerichtet und die Spalten über ihre Kopfzeile zugeordnet, daher zählt eine eingefügte Zeile oder Spalte als eine Änderung. Vor einem Commit können Sie eine Arbeitsmappe auch mit ihrer Version in Git HEAD vergleichen. Das alles ist kostenlos und kommt ohne Netzwerkanfragen aus. Zovo Pro (einmalig 19 USD) ergänzt drei Werkzeuge, Export a diff report, Match rows by key columns und Compare two folders of workbooks, jeweils mit 3 kostenlosen Versuchen.

Schritte in VS Code

  1. Installieren Sie Excel Compare & XLSX Diff aus dem Marketplace, oder drücken Sie Strg+P (Cmd+P unter macOS) und führen Sie ext install zovo.zovo-excel-compare aus.
  2. Markieren Sie zwei Dateien im Explorer, klicken Sie mit der rechten Maustaste und wählen Sie Compare Selected Excel Files. Oder klicken Sie mit der rechten Maustaste auf eine Datei, wählen Sie Compare with... und dann die zweite Datei. Über die Command Palette führen Sie "Excel Compare: Compare Two Excel or CSV Files..." aus.
  3. Jede Kombination aus .xlsx, .xlsm, .xls, .ods, .csv und .tsv funktioniert, Sie können also eine .xlsx mit einer .csv vergleichen.
  4. Lesen Sie die Zusammenfassungszeile und dann den Tab jedes Blatts mit der Anzahl seiner Unterschiede. Ein Klick auf eine Zelle zeigt den vollständigen alten und neuen Wert, den Sie kopieren können.
  5. Mit N und P (oder Next und Previous) springen Sie blattübergreifend durch alle Änderungen. Wechseln Sie zwischen Values und Formulas, um entweder die angezeigten Werte oder die Formeln selbst zu vergleichen.
  6. Um vor einem Commit zu sehen, was Sie geändert haben, klicken Sie in einem Git-Repository mit der rechten Maustaste auf eine Arbeitsmappe und wählen Sie Compare with Git HEAD.

Der Vergleich zweier beliebiger Dateien, das Raster, Values und Formulas, Next und Previous, der CSV-Vergleich mit erkannter Kodierung und erkanntem Trennzeichen sowie Compare with Git HEAD sind kostenlos, ohne Anmeldung, ohne Netzwerkanfragen und ohne Telemetrie.

Wenn jemand anderes die Änderungen sehen muss, schreibt Export a diff report eine XLSX-Arbeitsmappe, in der die geänderten, hinzugefügten und entfernten Zellen farbig gefüllt sind, mit einem Summary-Blatt und einer Changes-Liste mit jedem alten und neuen Wert. Alternativ entsteht eine HTML-Seite oder eine CSV-Liste der Änderungen. Sie verschicken eine Datei statt Screenshots.

Schritte in Cursor, Windsurf oder VSCodium

  1. Öffnen Sie die Ansicht Extensions mit Strg+Umschalt+X (Cmd+Umschalt+X unter macOS).
  2. Suchen Sie nach zovo.zovo-excel-compare und klicken Sie auf Install. Cursor, Windsurf und VSCodium installieren aus Open VSX, dort heißt die Erweiterung zovo/zovo-excel-compare.
  3. Hat Ihr Editor keine Galerie, laden Sie die .vsix-Datei von der Open-VSX-Seite herunter und führen Sie „Extensions: Install from VSIX...“ aus.
  4. Danach funktioniert alles wie in VS Code.

Was Excel Compare & XLSX Diff öffnet

  • Blätter werden zuerst über den Namen, dann über die Position zugeordnet. Blätter, die es nur in einer Datei gibt, erscheinen als hinzugefügt oder entfernt.
  • CSV und TSV mit erkannter Kodierung (UTF-8 mit oder ohne BOM, UTF-16, Windows-Codepages) und erkanntem Trennzeichen (Komma, Semikolon, Tab oder Pipe), auch Felder in Anführungszeichen mit Zeilenumbrüchen.
  • Große Blätter: Das Raster zeichnet nur die sichtbaren Zeilen, daher scrollt ein Blatt mit 300.000 Zeilen wie ein kurzes.
  • Hinweise, wenn sich verbundene Zellen unterscheiden oder ein Limit ein Blatt gekürzt hat.
  • Die beiden anderen Pro-Werkzeuge: Match rows by key columns ordnet Zeilen über eine ID-Spalte zu, sodass sortierte oder umgestellte Blätter sauber verglichen und verschobene Zeilen markiert werden. Compare two folders of workbooks paart Dateien über den Namen und zeigt, welche gleich sind, welche sich unterscheiden und welche nur in einem Ordner liegen.

Was es nicht kann

  • Dateien bis 200 MB (Einstellung excelCompare.maxFileSizeMB), 300.000 Zeilen pro Blatt (excelCompare.maxRows), 1.000 Spalten und 200 Blätter. Ein Hinweis in der Ansicht zeigt, wenn ein Limit gegriffen hat.
  • Eine Arbeitsmappe, die sich auf mehr als 600 MB entpacken würde oder wie eine Zip-Bombe komprimiert ist, wird vor dem Entpacken abgelehnt.
  • Ohne das Pro-Werkzeug Match rows by key columns werden Zeilen über Inhalt und Position ausgerichtet, nicht über eine ID-Spalte.
  • Die Erweiterung vergleicht nur. Sie bearbeitet oder mergt die Dateien nicht.

Häufige Fragen

Ist es kostenlos?

Der Vergleich zweier Arbeitsmappen oder CSV-Dateien, Values und Formulas, Next und Previous sowie Compare with Git HEAD sind kostenlos. Die drei Pro-Werkzeuge, Export a diff report, Match rows by key columns und Compare two folders of workbooks, haben jeweils 3 kostenlose Versuche. Danach brauchen sie Zovo Pro, einmalig 19 USD für alle Zovo-Erweiterungen.

Kann VS Code zwei Excel-Dateien ohne Erweiterung vergleichen?

Nein. Eine .xlsx-Datei ist ein Zip-Archiv aus XML-Teilen, daher zeigt der eingebaute Diff sie als Binärdatei. Sie brauchen eine Erweiterung, die die Arbeitsmappe liest.

Markiert eine oben eingefügte Zeile alle Zeilen darunter als geändert?

Nein. Die Zeilen werden vor dem Vergleich aneinander ausgerichtet, daher erscheint eine eingefügte Zeile als eine hinzugefügte Zeile.

Kann ich sehen, was sich seit meinem letzten Commit in einer Arbeitsmappe geändert hat?

Ja. Klicken Sie in einem Git-Repository mit der rechten Maustaste auf die Datei und wählen Sie Compare with Git HEAD. Dafür wird Ihr lokales git verwendet.
