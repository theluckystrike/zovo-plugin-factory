JAR- und Class-Dateien in VS Code ansehen

Installieren Sie JAR Viewer & Java Decompiler und klicken Sie auf eine .jar-, .war-, .ear-, .aar- oder .class-Datei. Pakete, Klassen und Ressourcen erscheinen direkt in VS Code. Paketbaum, Übersicht, Bytecode und der mit CFR dekompilierte Quelltext sind kostenlos, für den Quelltext brauchen Sie allerdings eine Java-Laufzeit ab Version 8. Zovo Pro (einmalig 19 USD) ergänzt den Export aller dekompilierten Quellen, den Vergleich zweier JARs und die Suche in allen JARs eines Ordners, und jedes dieser Werkzeuge können Sie dreimal kostenlos ausprobieren.

In VS Code installierenMarketplace-SeiteOpen VSX (Cursor, Windsurf, VSCodium)

Kostenlos, MIT-Lizenz. Extension ID zovo.zovo-jar-viewer.

Schritte in VS Code

  1. Installieren Sie JAR Viewer & Java Decompiler aus dem Marketplace, oder drücken Sie Ctrl+P (Cmd+P unter macOS) und führen Sie ext install zovo.zovo-jar-viewer aus.
  2. Klicken Sie im Explorer auf die Datei. Pakete und Ressourcen erscheinen als Baum mit einem Filter, der eine Klasse auch unter 50.000 Einträgen schon beim Tippen findet. Innere Klassen sind abgeblendet.
  3. Die Übersicht zeigt Format, Größe, Zahl der Einträge, Klassen und Pakete, Main-Class, Created-By und ein Diagramm der Java-Versionen, für die die Klassen kompiliert wurden (52 ist Java 8, 61 ist Java 17, 65 ist Java 21).
  4. Wählen Sie eine Klasse, sehen Sie den dekompilierten Java-Quelltext einschließlich innerer Klassen. Sie können ihn kopieren oder in einem Editor-Tab öffnen. Java sucht die Erweiterung zuerst in jarViewer.javaPath, dann in JAVA_HOME und dann als java im PATH.
  5. Auch ohne Java funktionieren die übrigen Reiter: Bytecode im Stil von javap -c -p mit jedem Opcode, tableswitch und lookupswitch, Ausnahmetabellen und Zeilennummern, dazu Members mit Feldern und Methoden als Java-Deklarationen samt Deskriptoren und Zugriffsflags sowie der Konstantenpool mit Filter.
  6. Textressourcen wie Properties, XML, JSON oder SQL öffnen als Text, binäre Dateien mit einer Hex-Vorschau. Verschachtelte JARs, etwa in BOOT-INF/lib bei Spring Boot, öffnen Sie eine Ebene tief.

In Cursor, Windsurf und VSCodium

Diese Editoren installieren Erweiterungen aus Open VSX. Öffnen Sie die Extensions-Ansicht (Ctrl+Shift+X), suchen Sie nach zovo.zovo-jar-viewer und klicken Sie auf Install. Die Seite auf Open VSX ist zovo/zovo-jar-viewer. Danach funktioniert alles wie in VS Code.

Was kostenlos ist

Kostenlos und ohne Anmeldung sind Paketbaum, Übersicht, dekompilierter Quelltext, Bytecode, Members, Konstantenpool, Klasseninformationen, Ressourcen und verschachtelte JARs. Der Decompiler CFR 0.152 ist in der Erweiterung enthalten. Das Archiv wird in einem eigenen Hintergrund-Thread mit Zeit- und Speichergrenze gelesen, ZIP-Bomben werden abgewiesen, und die Erweiterung verändert das Archiv nie. Sie arbeitet ohne Netzwerkzugriff und ohne Telemetrie.

Was Zovo Pro hinzufügt

Export decompiled sources of a JAR dekompiliert eine ganze JAR und schreibt das Ergebnis als Ordner mit .java-Dateien, mit Fortschrittsanzeige und der Möglichkeit abzubrechen. Sie müssen also nicht jede Klasse einzeln öffnen und kopieren. Die weiteren Pro-Werkzeuge sind Compare two JARs, das hinzugefügte, entfernte und geänderte Klassen, geänderte Signaturen von Methoden und Feldern sowie geänderte Java-Versionen als Markdown-Bericht ausgibt, und Find a class, method or string in every JAR of a folder, das in allen JARs eines Ordners samt verschachtelter JARs nach Klassen, Methoden, Feldern oder Zeichenkettenkonstanten sucht, als reiner Text oder als /regex/.

So funktioniert Export decompiled sources of a JAR

  1. Klicken Sie im Explorer mit der rechten Maustaste auf die JAR-Datei und wählen „Zovo Pro: Export decompiled sources“, oder führen Sie in der Befehlspalette „JAR Viewer: Export decompiled sources of a JAR (Pro)“ aus.
  2. Wählen Sie den Zielordner. Der Fortschritt wird angezeigt, und Sie können jederzeit abbrechen. Für Java-Quelltext brauchen Sie eine Java-Laufzeit ab Version 8, ohne Java schreibt das Werkzeug nur Bytecode-Listings.

Export decompiled sources of a JAR läuft 3 Mal kostenlos, danach braucht es eine Lizenz. Beim Öffnen einer Datei erscheint kein Pop-up, und es läuft kein Countdown.

Per Karte zahlen, einmalig USD 19

Zovo Pro kostet einmalig USD 19. Es ist kein Abo und schaltet die Pro-Werkzeuge in allen Zovo-Erweiterungen frei. Nach der Zahlung per Karte (Stripe) steht der Lizenzschlüssel auf der nächsten Seite. Führen Sie in VS Code "Enter Zovo Pro license key" aus der Command Palette aus und fügen Sie den Schlüssel ein. Der Schlüssel wird auf Ihrem Rechner geprüft, ohne Netzwerkzugriff.

Ein Team mit 5 Personen zahlt einmalig USD 59, ebenfalls per Karte. Alle Regeln und Pro-Werkzeuge stehen auf der Zovo-Pro-Seite (Englisch).

Was es nicht kann

  • Für den dekompilierten Quelltext brauchen Sie eine Java-Laufzeit ab Version 8. Ohne Java zeigt der Quelltext-Reiter nur einen Hinweis, wie Sie das Dekompilieren einschalten.
  • Die Ausgabe von CFR kann vom ursprünglichen Quelltext abweichen, etwa bei Namen lokaler Variablen, manchen Generics und Lambdas.
  • APK- und DEX-Dateien werden nicht unterstützt, und verschachtelte JARs öffnen nur eine Ebene tief.
  • Die Erweiterung ist nur zum Ansehen da. JARs lassen sich nicht bearbeiten oder neu packen.

Fragen

Ist die Erweiterung kostenlos?

Ja. Ansehen und Dekompilieren sind kostenlos, ohne Begrenzung und ohne Anmeldung. Der Export aller Quellen, der Vergleich zweier JARs und die Suche in einem Ordner gehören zu Zovo Pro. Jedes dieser Werkzeuge können Sie dreimal kostenlos ausprobieren, und ein Versuch zählt nur, wenn das Werkzeug ein Ergebnis liefert.

Funktioniert das ohne Java?

Teilweise. Paketbaum, Übersicht, Bytecode, Members, Konstantenpool und Ressourcen funktionieren ohne Java. Nur für den dekompilierten Quelltext brauchen Sie eine Java-Laufzeit ab Version 8.

Funktioniert das auch in Cursor?

Ja. Die Erweiterung steht auch bei Open VSX bereit und lässt sich deshalb in Cursor, Windsurf und VSCodium installieren.

Alle Funktionen und Einstellungen stehen auf der Seite von JAR Viewer & Java Decompiler (Englisch).
