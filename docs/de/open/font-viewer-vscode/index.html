Schriftdateien in VS Code prüfen

Installieren Sie Font Viewer und klicken Sie im Explorer auf eine .ttf-, .otf-, .woff-, .woff2-, .ttc- oder .otc-Datei. Die Schrift öffnet sich in VS Code, nur zum Ansehen. Typentest, Glyphenübersicht, Zeichentabelle, Lizenzangaben und das Kopieren der @font-face-Regel sind kostenlos. Zovo Pro (einmalig 19 USD) ergänzt die Umwandlung in WOFF2, WOFF oder TTF und einen Bericht über alle Schriften eines Ordners, und jedes dieser Werkzeuge können Sie dreimal kostenlos ausprobieren.

In VS Code installierenMarketplace-SeiteOpen VSX (Cursor, Windsurf, VSCodium)

Kostenlos, MIT-Lizenz. Extension ID zovo.font-viewer-vscode.

Schritte in VS Code

  1. Installieren Sie Font Viewer aus dem Marketplace, oder drücken Sie Ctrl+P (Cmd+P unter macOS) und führen Sie ext install zovo.font-viewer-vscode aus.
  2. Klicken Sie im Explorer auf die Schriftdatei. Font Viewer ist für diese Dateien der Standardeditor und ändert die Schrift nie. Bei Sammlungen (.ttc, .otc) wählen Sie die gewünschte Schrift in der Liste im Kopfbereich.
  3. Im Reiter Type tester tippen Sie Ihren Beispieltext, stellen die Größe mit dem Regler zwischen 8 und 200 px ein und sehen eine Größenreihe von 12 bis 96 px. Variable Schriften haben für jede Achse einen eigenen Regler, und OpenType-Funktionen wie liga, kern, ss01 oder zero schalten Sie per Kontrollkästchen.
  4. Der Reiter Glyphs zeigt jede Glyphe, auch Ligaturen und Alternativformen, die keine Taste erzeugt. Suchen Sie nach Name, Zeichen, U+20AC oder Glyphen-ID, und kopieren Sie das Zeichen, den Codepunkt oder den Umriss als SVG.
  5. Der Reiter Characters zeigt die Abdeckung je Unicode-Block, etwa „Basic Latin 95/128“. Im Reiter Info lesen Sie Lizenz, Designer, Copyright, Einbettungsrechte und Metriken.
  6. „Copy CSS“ kopiert die @font-face-Regel zusammen mit passenden font-variation-settings und font-feature-settings. Ohne die Schrift zu öffnen, geht das im Explorer per Rechtsklick und „Copy CSS @font-face“.

In Cursor, Windsurf und VSCodium

Diese Editoren installieren Erweiterungen aus Open VSX. Öffnen Sie die Extensions-Ansicht (Ctrl+Shift+X), suchen Sie nach zovo.font-viewer-vscode und klicken Sie auf Install. Die Seite auf Open VSX ist zovo/font-viewer-vscode. Danach funktioniert alles wie in VS Code.

Was kostenlos ist

Kostenlos sind das Öffnen aller sechs Formate, der Typentest mit variablen Achsen und OpenType-Funktionen, die Glyphenübersicht mit Suche und SVG-Kopie, die Zeichentabelle mit Abdeckung je Unicode-Block, der Info-Reiter mit Lizenz und Einbettungsrechten und das Kopieren der @font-face-Regel. Auch CJK-Schriften mit 20.000 Glyphen öffnen schnell, weil die Glyphen seitenweise geladen werden. Speichern Sie eine neue Fassung der Schrift, lädt die offene Ansicht sie neu. Die Erweiterung arbeitet offline, ohne Netzwerkaufrufe und ohne Telemetrie.

Was Zovo Pro hinzufügt

Convert Font wandelt eine TTF- oder OTF-Datei in WOFF2 oder WOFF für Webseiten um, oder eine WOFF2-Datei zurück in eine installierbare TTF- oder OTF-Datei. Sie können eine einzelne Schrift oder einen ganzen Ordner umwandeln. Die neuen Dateien landen neben den Quellen, und aus einer TTC wird eine Datei pro Schnitt. Die Tabellendaten werden unverändert übernommen, Umrisse, Hinting, variable Achsen und OpenType-Funktionen bleiben also gleich. Eine WOFF2-Datei ist dabei etwa 45 Prozent so groß wie die TTF, bei JetBrains Mono (variabel) zum Beispiel 43.632 statt 96.940 Bytes. Das zweite Pro-Werkzeug, Font Folder Report, listet alle Schriften eines Ordners mit Familie, Schnitt, Gewicht, Achsen, Version, Glyphenzahl, Lizenz und Einbettungsrechten als CSV, als Markdown-Tabelle oder als fonts.css mit einer @font-face-Regel pro Schrift.

So funktioniert Convert Font to WOFF2, WOFF or TTF

  1. Öffnen Sie die Schrift und klicken Sie in der Editor-Titelleiste auf „Convert Font to WOFF2, WOFF or TTF… (Pro)“, oder klicken Sie im Explorer mit der rechten Maustaste auf eine Schrift oder einen Ordner und wählen denselben Eintrag.
  2. Wählen Sie das Zielformat. Die neuen Dateien werden neben den Quelldateien gespeichert.

Convert Font to WOFF2, WOFF or TTF läuft 3 Mal kostenlos, danach braucht es eine Lizenz. Beim Öffnen einer Datei erscheint kein Pop-up, und es läuft kein Countdown.

Per Karte zahlen, einmalig USD 19

Zovo Pro kostet einmalig USD 19. Es ist kein Abo und schaltet die Pro-Werkzeuge in allen Zovo-Erweiterungen frei. Nach der Zahlung per Karte (Stripe) steht der Lizenzschlüssel auf der nächsten Seite. Führen Sie in VS Code "Enter Zovo Pro license key" aus der Command Palette aus und fügen Sie den Schlüssel ein. Der Schlüssel wird auf Ihrem Rechner geprüft, ohne Netzwerkzugriff.

Ein Team mit 5 Personen zahlt einmalig USD 59, ebenfalls per Karte. Alle Regeln und Pro-Werkzeuge stehen auf der Zovo-Pro-Seite (Englisch).

Was es nicht kann

  • WOFF2-Sammlungen, SVG-Schriften, .dfont und Type-1-Schriften werden nicht unterstützt.
  • Dateien über 64 MB (fontViewer.maxFileMB) öffnen nicht, stattdessen erscheint eine Meldung.
  • Die Glyphenübersicht zeigt bei variablen Schriften die Standardinstanz. Farbschriften (COLR, SVG, sbix, CBDT) erscheinen im Typentest und in der Zeichentabelle farbig, in der Glyphenübersicht aber nur als Umriss.

Fragen

Ist Font Viewer kostenlos?

Ja. Das Ansehen von Schriften ist kostenlos. Convert Font und Font Folder Report gehören zu Zovo Pro. Jedes davon können Sie dreimal kostenlos ausprobieren, und ein Versuch zählt nur, wenn die Dateien geschrieben wurden.

Kann ich die Schrift damit bearbeiten?

Nein. Font Viewer öffnet Schriften nur zum Lesen und ändert die Datei nie. Die Pro-Umwandlung legt neue Dateien neben der Quelle an.

Funktioniert das auch in Cursor?

Ja. Die Erweiterung steht auch bei Open VSX bereit und lässt sich deshalb in Cursor, Windsurf und VSCodium installieren.

Alle Funktionen und Einstellungen stehen auf der Seite von Font Viewer (Englisch).
