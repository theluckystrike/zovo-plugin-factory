PDF-, Word-, PowerPoint- oder Excel-Datei in VS Code in Markdown umwandeln

Installieren Sie die kostenlose Erweiterung Convert to Markdown, klicken Sie im Explorer mit der rechten Maustaste auf eine PDF-, Word-, PowerPoint-, Excel-, CSV-, HTML-, EPUB-, ODT- oder RTF-Datei und wählen Sie Convert to Markdown. Das Markdown öffnet sich neben der Datei, mit Überschriften, Listen, Tabellen, Links und den Sprechernotizen der Folien, und nichts verlässt Ihren Computer. Convert to Markdown und Copy as Markdown sind für alle Formate kostenlos. Zovo Pro (einmalig 19 USD) ergänzt drei Werkzeuge, Convert a Folder to Markdown, Convert to Markdown with Images und LLM-ready Markdown Chunks, jeweils mit 3 kostenlosen Versuchen.

Schritte in VS Code

  1. Installieren Sie Convert to Markdown aus dem Marketplace, oder drücken Sie Strg+P (Cmd+P unter macOS) und führen Sie ext install zovo.zovo-convert-to-markdown aus.
  2. Klicken Sie im Explorer mit der rechten Maustaste auf eine Datei vom Typ .pdf, .docx, .pptx, .xlsx, .xls, .ods, .csv, .tsv, .html, .epub, .odt oder .rtf und wählen Sie Convert to Markdown. Sie können auch mit der rechten Maustaste auf den Tab einer geöffneten Datei klicken.
  3. Oder führen Sie „Convert to Markdown: Convert to Markdown“ in der Command Palette aus. Der Befehl wandelt die Datei im aktiven Tab um oder fragt nach einer Datei.
  4. Das Markdown öffnet sich neben der Datei als ungespeichertes Dokument. Bei großen Dateien sehen Sie den Fortschritt mit einer Cancel-Schaltfläche.
  5. Speichern Sie das Dokument. Der Name name.md neben der Quelldatei ist bereits eingetragen. Wenn jedes Mal sofort dort gespeichert werden soll, setzen Sie toMarkdown.output auf file.
  6. Um das Markdown an anderer Stelle einzufügen, klicken Sie mit der rechten Maustaste auf die Datei und wählen Sie Copy as Markdown. Wenn Sie im Explorer mehrere Dateien auswählen, werden sie nacheinander umgewandelt.
  7. Keine Datei zur Hand? Führen Sie „Convert to Markdown: Convert a sample file“ in der Command Palette aus, um ein mitgeliefertes Word-, PDF- oder PowerPoint-Beispiel umzuwandeln.

Was kostenlos ist und was Zovo Pro dazu gibt

Convert to Markdown und Copy as Markdown sind für alle Formate kostenlos, also für PDF, Word, PowerPoint, Excel, ODS, CSV, TSV, HTML, EPUB, ODT und RTF. Sie installieren nichts weiter, weder Python noch einen Server noch ein Kommandozeilenwerkzeug. Nichts verlässt Ihren Computer.

Convert a Folder to Markdown wandelt in einem Durchgang jede unterstützte Datei in einem Ordner und seinen Unterordnern in .md-Dateien um, entweder in einen neuen Ordner mit derselben Struktur oder neben jede Datei, mit Fortschrittsanzeige und Cancel. Sie entscheiden, ob vorhandene .md-Dateien übersprungen oder überschrieben werden, und _conversion-report.md führt jede Datei als umgewandelt, übersprungen oder fehlgeschlagen auf. Dateien mit gleichem Namen behalten ihren Typ im neuen Namen (report.pdf.md, report.docx.md), sodass keine verloren geht.

Mit Convert a Folder to Markdown (Zovo Pro)

  1. Klicken Sie im Explorer mit der rechten Maustaste auf einen Ordner und wählen Sie „Zovo Pro: Convert a Folder to Markdown“, oder führen Sie „Convert to Markdown: Convert a Folder to Markdown (Pro)“ in der Command Palette aus und wählen Sie den Ordner.
  2. Wählen Sie das Ziel der .md-Dateien: „Into a new folder“ (der Ordnername mit -markdown am Ende, mit denselben Unterordnern), „Next to each file“ oder „Pick another folder...“.
  3. Wenn schon .md-Dateien vorhanden sind, wählen Sie Skip oder Overwrite. Eine Benachrichtigung zeigt den Fortschritt mit einer Cancel-Schaltfläche.
  4. Am Ende öffnet sich _conversion-report.md. Der Bericht führt jede Datei als umgewandelt, übersprungen oder fehlgeschlagen auf, mit einem Link zu jeder neuen Markdown-Datei.

Convert a Folder to Markdown funktioniert 3-mal auf Ihrem Computer, bevor es nach einer Lizenz fragt. Beim Öffnen einer Datei gibt es kein Pop-up und keinen Countdown.

Schritte in Cursor, Windsurf oder VSCodium

  1. Öffnen Sie die Ansicht Extensions mit Strg+Umschalt+X (Cmd+Umschalt+X unter macOS).
  2. Suchen Sie nach zovo.zovo-convert-to-markdown und klicken Sie auf Install. Cursor, Windsurf und VSCodium installieren aus Open VSX, dort heißt die Erweiterung zovo/zovo-convert-to-markdown.
  3. Hat Ihr Editor keine Galerie, laden Sie die .vsix-Datei von der Open-VSX-Seite herunter und führen Sie „Extensions: Install from VSIX...“ aus.
  4. Danach funktioniert alles wie in VS Code.

Was Convert to Markdown öffnet

  • PDF mit Überschriften aus den Schriftgrößen, Absätzen mit zusammengefügten Zeilenumbrüchen und Worttrennungen, Listen, einfachen Tabellen und zweispaltigen Seiten, die Spalte für Spalte gelesen werden. Wiederkehrende Kopf- und Fußzeilen und Seitenzahlen werden entfernt.
  • Word (.docx, .docm, .dotx) mit Überschriften, Fett, Kursiv, Durchgestrichen, Links, verschachtelten Listen, Tabellen, Blockzitaten und Fußnoten.
  • PowerPoint (.pptx, .pptm, .ppsx, .potx) mit einem Abschnitt ## Slide n: title pro Folie, mit Aufzählungen und ihren Ebenen, Tabellen und den Sprechernotizen.
  • Excel und andere Tabellen (.xlsx, .xlsm, .xlsb, .xls, .ods) mit einem Abschnitt ## Sheet: name und einer Pipe-Tabelle pro Blatt. CSV und TSV werden zu einer Tabelle.
  • HTML (.html, .htm, .xhtml), wobei Codeblöcke ihre Sprache behalten und Skripte und Stile entfernt werden, sowie EPUB mit jedem Kapitel in Lesereihenfolge.

Was es nicht kann

  • Gescannte PDFs (Bilder von Seiten) enthalten keinen Text zum Umwandeln. Texterkennung (OCR) ist nicht enthalten.
  • PDF-Tabellen werden an den Abständen zwischen den Spalten erkannt. Tabellen ohne klare Abstände erscheinen als Absätze.
  • In der kostenlosen Umwandlung werden Bilder zu Platzhaltern wie *[Image: Map of the site]*. Diagramme, SmartArt und Videos in Folien werden benannt, nicht umgewandelt.
  • Alte Word-97-2003-Dateien und RTF liefern Text und Tabellen ohne Formatierung. Passwortgeschützte Dateien und alte PowerPoint-97-2003-Dateien erhalten eine Meldung statt einer Umwandlung.
  • Dateien über 200 MB werden nicht umgewandelt (Einstellung toMarkdown.maxFileSizeMB), und ein PDF stoppt nach 1.000 Seiten (Einstellung toMarkdown.pdfMaxPages).

Häufige Fragen

Ist es kostenlos?

Convert to Markdown und Copy as Markdown sind für alle Formate kostenlos. Die drei Pro-Werkzeuge Convert a Folder to Markdown, Convert to Markdown with Images und LLM-ready Markdown Chunks haben jeweils 3 kostenlose Versuche. Danach brauchen sie Zovo Pro, einmalig 19 USD für alle Zovo-Erweiterungen.

Lädt die Erweiterung meine Dateien hoch?

Nein. Die Konverter laufen auf Ihrem Computer in VS Code, ohne Netzwerkaufrufe und ohne Telemetrie.

Wandelt sie gescannte PDFs um?

Nein. Ein gescanntes PDF enthält Bilder von Seiten, keinen Text, und Convert to Markdown hat keine OCR.

Funktioniert es in Cursor?

Ja. Cursor, Windsurf und VSCodium installieren die Erweiterung aus Open VSX, wo sie als zovo/zovo-convert-to-markdown veröffentlicht ist.
