SQLite-Datenbanken in VS Code bearbeiten

Installieren Sie SQLite DB Viewer und klicken Sie auf eine .db- oder .sqlite-Datei. Sie öffnet schreibgeschützt; nach einem Klick auf „Enable editing“ ändern Sie Zellen und Zeilen, führen INSERT oder UPDATE aus oder importieren eine CSV-Datei. Öffnen, Lesen, Bearbeiten, Speichern mit Sicherungskopie und CSV-Import sind kostenlos. Zovo Pro (einmalig 19 USD) ergänzt den Vergleich zweier Datenbanken, ein ER-Diagramm und den Export aller Tabellen, jeweils mit 3 kostenlosen Versuchen.

In VS Code installierenMarketplace-SeiteOpen VSX (Cursor, Windsurf, VSCodium)

Kostenlos, MIT-Lizenz. Extension ID zovo.sqlite-table-viewer.

Schritte in VS Code

  1. Installieren Sie SQLite DB Viewer aus dem Marketplace, oder drücken Sie Ctrl+P (Cmd+P unter macOS) und führen Sie ext install zovo.sqlite-table-viewer aus.
  2. Klicken Sie im Explorer auf eine Datei mit der Endung .db, .sqlite, .sqlite3 oder .db3. Sie öffnet schreibgeschützt. Sortieren, Spaltenfilter, die Suche über alle Spalten und die Registerkarte Schema stehen sofort zur Verfügung.
  3. Klicken Sie auf „Enable editing“. Vorher meldet die Erweiterung, wenn ein anderes Programm die Datei geöffnet hat, wenn die -wal-Datei Transaktionen enthält, die noch nicht in der Hauptdatei stehen, oder wenn eine -journal-Datei einen laufenden Schreibvorgang anzeigt.
  4. Doppelklicken Sie auf eine Zelle (oder drücken Sie Enter oder F2), ändern Sie den Wert und bestätigen Sie mit Enter. Mit + Row, Duplicate und Delete bearbeiten Sie Zeilen, in der Registerkarte SQL führen Sie INSERT, UPDATE oder DELETE aus. Jede Änderung landet mit ihrem SQL in einer Liste ausstehender Änderungen und lässt sich mit Undo zurücknehmen.
  5. Speichern Sie mit Strg+S (auf dem Mac Cmd+S). Dabei werden Fremdschlüssel geprüft und PRAGMA quick_check ausgeführt; dann legt die Erweiterung eine Sicherungskopie wie name.db.20261109-143000.bak an, schreibt die neue Datenbank in eine temporäre Datei und ersetzt das Original durch Umbenennen. Hat sich die Datei seit dem Öffnen geändert, wird nicht gespeichert, und Ihre Änderungen bleiben erhalten.
  6. Um eine CSV- oder TSV-Datei in eine neue Datenbank zu laden, klicken Sie sie im Explorer mit der rechten Maustaste an und wählen „Import CSV into a new SQLite database…“. Trennzeichen, Kodierung, Kopfzeile und Spaltenzuordnung legen Sie selbst fest. Eine Million Zeilen sind in etwa 2 Sekunden importiert, mit Fortschrittsbalken und der Möglichkeit abzubrechen.

In Cursor, Windsurf und VSCodium

Diese Editoren installieren Erweiterungen aus Open VSX. Öffnen Sie die Extensions-Ansicht (Ctrl+Shift+X), suchen Sie nach zovo.sqlite-table-viewer und klicken Sie auf Install. Die Seite auf Open VSX ist zovo/sqlite-table-viewer. Danach funktioniert alles wie in VS Code.

Was kostenlos ist

Kostenlos bleiben Öffnen und Lesen, die Registerkarte SQL, das Bearbeiten von Zellen und Zeilen, Speichern mit Sicherungskopie, der Import von CSV und TSV mit Spaltenumwandlungen, die Tabellenwerkzeuge (Spalten hinzufügen, umbenennen oder löschen, Tabellen umbenennen, Suchen und Ersetzen in einer Spalte) und der Export der angezeigten Zeilen als CSV, JSON oder SQL-INSERT. Schreibt Ihre Anwendung nebenher im WAL-Modus in die Datenbank, liest die Erweiterung die abgeschlossenen Transaktionen aus der -wal-Datei und lädt die Ansicht einmal pro Sekunde neu, solange Sie nicht bearbeiten. SQLite läuft als WebAssembly mit, es muss nichts installiert werden, und es gibt keine Netzwerkzugriffe und keine Telemetrie.

Was Zovo Pro hinzufügt

„Compare SQLite Databases“ vergleicht Tabellen, Spalten, Indizes, Views, Trigger und Zeilen zweier SQLite-Dateien; Zeilen werden über den Primärschlüssel oder die rowid zugeordnet. Sie erhalten einen Markdown-Bericht und das Skript a-vs-b-sync.sql, das die zweite Datenbank an die erste angleicht. Das Skript wird nur im Editor geöffnet und nie für Sie ausgeführt. So sparen Sie sich den Abgleich von Hand, etwa zwischen einer Testkopie und dem Original. Dazu kommen „ER Diagram of a SQLite Database“, das name-er.svg, ein Mermaid-erDiagram und name-schema.md schreibt, und „Export All SQLite Tables to Excel or CSV“, das eine Excel-Arbeitsmappe mit einem Blatt pro Tabelle oder eine CSV-Datei pro Tabelle erzeugt.

So funktioniert Compare SQLite Databases

  1. Klicken Sie im Explorer mit der rechten Maustaste auf die erste Datenbankdatei und wählen Sie „Zovo Pro: Compare SQLite Databases“. Alternativ starten Sie das Werkzeug über die Schaltfläche DB tools im Editor oder über „Compare SQLite Databases (Pro)…“ in der Befehlspalette.
  2. Wählen Sie die zweite Datenbank.
  3. Prüfen Sie den Markdown-Bericht und das Skript a-vs-b-sync.sql. Beide Datenbanken werden dabei nur gelesen.

Compare SQLite Databases läuft 3 Mal kostenlos, danach braucht es eine Lizenz. Beim Öffnen einer Datei erscheint kein Pop-up, und es läuft kein Countdown.

Was es nicht kann

  • Die ganze Datenbank wird in den Arbeitsspeicher geladen. Dateien bis 512 MB lassen sich öffnen und bis 256 MB bearbeiten; größere Dateien öffnen nur schreibgeschützt.
  • Verschlüsselte Datenbanken (SQLCipher, SEE) lassen sich nicht öffnen.
  • Dateien auf Remote- oder virtuellen Dateisystemen öffnen nur schreibgeschützt.
  • Wenn Sie die Registerkarte mit ungespeicherten Änderungen schließen, gehen diese verloren.

Fragen

Ist SQLite DB Viewer kostenlos?

Ja. Öffnen, Bearbeiten, Speichern, CSV-Import und der Export der angezeigten Zeilen sind kostenlos, ohne Zeitlimit und ohne Lizenzhinweis. Der Datenbankvergleich, das ER-Diagramm und der Export aller Tabellen sind Zovo-Pro-Werkzeuge mit je 3 kostenlosen Versuchen.

Kann meine Anwendung die Datenbank gleichzeitig benutzen?

Ja. Die Datei wird in den Arbeitsspeicher gelesen und wieder geschlossen, sodass ein anderes Programm weiter hineinschreiben kann. Die Ansicht lädt neu, sobald sich die Datenbank oder ihre -wal-Datei ändert, außer während Sie bearbeiten.

Funktioniert das auch in Cursor?

Ja. Cursor installiert Erweiterungen aus Open VSX. Suchen Sie in der Erweiterungsansicht nach zovo.sqlite-table-viewer.

Alle Funktionen und Einstellungen stehen auf der Seite von SQLite DB Viewer (Englisch).
