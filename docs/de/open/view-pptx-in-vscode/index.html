Eine PowerPoint-Datei (.pptx) in VS Code ansehen

Mit der kostenlosen Erweiterung PPTX Viewer öffnen Sie .pptx-, .ppsx-, .potx- und alte .ppt-Dateien direkt in VS Code, mit Miniaturansichten, Sprechernotizen, Suche über alle Folien und einer Vollbild-Präsentation. PowerPoint oder LibreOffice brauchen Sie nicht, und nichts wird hochgeladen. Zovo Pro (einmalig 19 USD) exportiert die ganze Präsentation als PDF oder alle Folien als PNG.

Schritte in VS Code

  1. Installieren Sie PPTX Viewer aus dem Marketplace, oder drücken Sie Strg+P (Cmd+P unter macOS) und führen Sie ext install zovo.pptx-slide-viewer aus.
  2. Klicken Sie im Explorer auf eine .pptx-Datei. Links stehen die Miniaturansichten, und zu jeder Folie sehen Sie die Sprechernotizen.
  3. Durchsuchen Sie Titel, Aufzählungen, Tabellenzellen und Notizen der ganzen Präsentation und springen Sie zur passenden Folie.
  4. Klicken Sie auf Present, um eine Folie nach der anderen im Vollbild zu zeigen. Pfeiltasten oder ein Klick blättern weiter, Esc bringt den Editor zurück.
  5. Kopieren Sie eine Folie oder die ganze Präsentation als Markdown, oder eine einzelne Folie als PNG-Bild, etwa für einen Pull Request.

Was kostenlos ist und was Zovo Pro dazu gibt

Kostenlos sind Ansicht, Present, Sprechernotizen, Suche, Miniaturansichten und Gliederung, das Kopieren oder Speichern einer Folie als PNG und Copy as Markdown für eine Folie oder die ganze Präsentation. Die Ansicht lädt neu, wenn ein Skript oder ein KI-Agent die Datei speichert.

Wer eine Präsentation an jemanden ohne PowerPoint schickt, braucht meist ein PDF. Der Pro-Export speichert eine PDF-Seite pro Folie in Foliengröße, gezeichnet auf Ihrem Computer, ohne LibreOffice und ohne Upload. Die Seiten sind Bilder der Folien, der Text im PDF lässt sich also nicht markieren oder durchsuchen. Weitere Pro-Werkzeuge exportieren alle Folien als PNG, wandeln einen Ordner mit Präsentationen in Markdown um und verkleinern eine Präsentation mit großen Fotos (Compress Deck).

Mit Export Deck as PDF (Zovo Pro)

  1. Öffnen Sie die Präsentation im Viewer.
  2. Klicken Sie in der Werkzeugleiste auf Export, oder führen Sie in der Command Palette „PPTX Viewer Pro: Export Deck as PDF (Pro)...“ aus.
  3. Wählen Sie den Speicherort. Die Originaldatei bleibt unverändert.

Export Deck as PDF funktioniert 3-mal auf Ihrem Computer, bevor es nach einer Lizenz fragt. Beim Öffnen einer Datei gibt es kein Pop-up und keinen Countdown.

Schritte in Cursor, Windsurf oder VSCodium

  1. Öffnen Sie die Ansicht Extensions mit Strg+Umschalt+X (Cmd+Umschalt+X unter macOS).
  2. Suchen Sie nach zovo.pptx-slide-viewer und klicken Sie auf Install. Cursor, Windsurf und VSCodium installieren aus Open VSX, dort heißt die Erweiterung zovo/pptx-slide-viewer.
  3. Hat Ihr Editor keine Galerie, laden Sie die .vsix-Datei von der Open-VSX-Seite herunter und führen Sie „Extensions: Install from VSIX...“ aus.
  4. Danach funktioniert alles wie in VS Code.

Was es nicht kann

  • PPTX Viewer ist ein Viewer. Folien lassen sich nicht bearbeiten, und Present hat keine Referentenansicht und keinen Timer.
  • Alte .ppt-Dateien (PowerPoint 97 bis 2003) zeigen nur Text, ohne Bilder, Formen und Layout.
  • Fehlende Schriften werden durch ähnliche ersetzt, daher können Zeilenumbrüche leicht von PowerPoint abweichen.

Häufige Fragen

Brauche ich PowerPoint?

Nein. PPTX Viewer zeichnet die Folien selbst, direkt in VS Code.

Geht das auch über Remote SSH oder WSL?

Ja. Die Erweiterung liest Dateien über VS Code und funktioniert deshalb auch mit Remote SSH, WSL, Dev Containers und Codespaces.

Wird meine Datei hochgeladen?

Nein. Alles läuft auf Ihrem Computer.
