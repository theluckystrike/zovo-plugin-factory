Anleitungen auf Deutsch

Eine .docx-Datei in VS Code öffnen

VS Code zeigt eine .docx-Datei von sich aus nicht an. Mit der kostenlosen Erweiterung DOCX Viewer öffnen Sie .docx-, .odt- und alte .doc-Dateien als Vorschau in einem Editor-Tab, mit Gliederung, Suche, Tabellen, Bildern, nachverfolgten Änderungen und Kommentaren. Office oder LibreOffice brauchen Sie nicht, und die Datei verlässt Ihren Computer nicht. Zovo Pro (einmalig 19 USD) fügt Exporte hinzu, etwa den Vergleich zweier Fassungen als Word-Datei mit echten nachverfolgten Änderungen.

Schritte in VS Code

  1. Installieren Sie DOCX Viewer aus dem Marketplace, oder drücken Sie Strg+P (Cmd+P unter macOS) und führen Sie ext install zovo.docx-viewer-vscode aus.
  2. Klicken Sie im Explorer auf eine .docx-, .odt- oder .doc-Datei. Sie öffnet sich als schreibgeschützte Vorschau, die dem VS-Code-Theme folgt. Der Theme-Button schaltet auf weißes Papier um.
  3. Drücken Sie Strg+F (Cmd+F unter macOS), um zu suchen. Die Suche zeigt die Zahl der Treffer, und die Gliederung springt zu jeder Überschrift.
  4. Wechseln Sie in die Seitenansicht (Page view), wenn Sie Seitengröße, Ränder, Kopf- und Fußzeilen sehen wollen. Nachverfolgte Änderungen und Kommentare zeigt die Leseansicht (Reading view).
  5. Mit „DOCX Viewer: Copy as Markdown“ kopieren Sie das ganze Dokument als Markdown, mit Tabellen und Fußnoten.

Was kostenlos ist und was Zovo Pro dazu gibt

Kostenlos sind Lese- und Seitenansicht, Suche, Gliederung, nachverfolgte Änderungen und Kommentare, Copy as Markdown, der Markdown-Vergleich und die Redline zweier Fassungen auf dem Bildschirm, mit Änderungsliste und Nebeneinander-Ansicht.

Wer zwei Fassungen eines Vertrags oder einer Spezifikation vergleicht, will das Ergebnis oft in Word weitergeben. Die Redline auf dem Bildschirm ist kostenlos. Der Pro-Export schreibt daraus ein neues Word-Dokument auf Basis der neueren Fassung, in dem jeder Unterschied eine echte nachverfolgte Änderung ist. Word und LibreOffice können jede Änderung einzeln annehmen oder ablehnen. Weitere Pro-Werkzeuge sind der Export der Redline als HTML-Datei, die Änderungsliste als Excel-Arbeitsmappe und der Vergleich zweier Ordner.

Mit Export Redline as DOCX (Zovo Pro)

  1. Öffnen Sie die neuere Fassung, klicken Sie in der Werkzeugleiste auf Compare und wählen Sie „Compare with another document“ oder „Compare with Git HEAD“, dann Redline. Das ist kostenlos.
  2. Führen Sie in der Command Palette „DOCX Viewer Pro: Export Redline as DOCX with Tracked Changes (Pro)“ aus.
  3. Wählen Sie den Speicherort. Ihre beiden Dokumente bleiben unverändert.

Export Redline as DOCX funktioniert 3-mal auf Ihrem Computer, bevor es nach einer Lizenz fragt. Beim Öffnen einer Datei gibt es kein Pop-up und keinen Countdown.

Schritte in Cursor, Windsurf oder VSCodium

  1. Öffnen Sie die Ansicht Extensions mit Strg+Umschalt+X (Cmd+Umschalt+X unter macOS).
  2. Suchen Sie nach zovo.docx-viewer-vscode und klicken Sie auf Install. Cursor, Windsurf und VSCodium installieren aus Open VSX, dort heißt die Erweiterung zovo/docx-viewer-vscode.
  3. Hat Ihr Editor keine Galerie, laden Sie die .vsix-Datei von der Open-VSX-Seite herunter und führen Sie „Extensions: Install from VSIX...“ aus.
  4. Danach funktioniert alles wie in VS Code.

Was es nicht kann

  • DOCX Viewer ist ein Viewer. Sie können das Dokument nicht bearbeiten oder speichern.
  • Alte .doc-Dateien zeigen nur den Text.
  • SmartArt wird nicht angezeigt, und .rtf-Dateien öffnet die Erweiterung nicht.

Häufige Fragen

Brauche ich Microsoft Word oder LibreOffice?

Nein. DOCX Viewer liest die Datei selbst, direkt in VS Code oder Cursor.

Wird meine Datei hochgeladen?

Nein. Die Erweiterung liest die Datei auf Ihrem Computer und sendet nichts davon ins Netz.

Kann ich das Dokument bearbeiten?

Nein. DOCX Viewer ist ein Viewer. Zum Bearbeiten nehmen Sie Word, LibreOffice oder Word im Browser.

Funktioniert das in Cursor?

Ja. Cursor, Windsurf und VSCodium installieren die Erweiterung aus Open VSX. Die Schritte stehen weiter unten.
