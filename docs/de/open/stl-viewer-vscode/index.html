3D-Modelle (STL, OBJ, GLB) in VS Code ansehen

Installieren Sie 3D Model Viewer und klicken Sie im Explorer auf eine .stl-, .obj-, .glb-, .gltf-, .ply- oder .3mf-Datei. Das Modell öffnet sich als 3D-Ansicht direkt in VS Code. Ansehen, Messen, die Szenenstruktur, Animationen und Bildschirmfotos sind kostenlos. Zovo Pro (einmalig 19 USD) ergänzt eine Druckprüfung, eine Schnittansicht und einen Drehteller-Export als GIF, und jedes dieser Werkzeuge können Sie dreimal kostenlos ausprobieren.

In VS Code installierenMarketplace-SeiteOpen VSX (Cursor, Windsurf, VSCodium)

Kostenlos, MIT-Lizenz. Extension ID zovo.3d-model-viewer.

Schritte in VS Code

  1. Installieren Sie 3D Model Viewer aus dem Marketplace, oder drücken Sie Ctrl+P (Cmd+P unter macOS) und führen Sie ext install zovo.3d-model-viewer aus.
  2. Klicken Sie im Explorer auf die Modelldatei. Öffnet sich ein anderer Viewer, klicken Sie mit der rechten Maustaste auf die Datei und wählen „Open in 3D Model Viewer“, oder Sie nutzen „Reopen Editor With...“.
  3. Ziehen mit der Maus dreht das Modell, Ziehen mit der rechten Maustaste oder mit gedrückter Umschalttaste verschiebt es, und das Mausrad zoomt. Mit der Taste F passen Sie das ganze Modell ins Bild ein.
  4. Der Seitenbereich zeigt die Zahl der Eckpunkte, Dreiecke, Materialien und Texturen sowie die Größe in Modelleinheiten. In der Szenenstruktur (bis 3.000 Knoten) blenden Sie einzelne Knoten über ihr Kontrollkästchen aus.
  5. Drücken Sie M und klicken Sie zwei Punkte an. Sie sehen den Abstand mit seinen X-, Y- und Z-Anteilen. W schaltet das Drahtgitter ein und aus, B den Begrenzungsrahmen, G das Raster und N die Normalen (bei Modellen bis 250.000 Eckpunkten).
  6. Enthält eine GLB- oder glTF-Datei Animationen, wählen Sie einen Clip und starten oder pausieren ihn mit der Leertaste. Über „Screenshot“ in der Werkzeugleiste speichern Sie die Ansicht als PNG.

In Cursor, Windsurf und VSCodium

Diese Editoren installieren Erweiterungen aus Open VSX. Öffnen Sie die Extensions-Ansicht (Ctrl+Shift+X), suchen Sie nach zovo.3d-model-viewer und klicken Sie auf Install. Die Seite auf Open VSX ist zovo/3d-model-viewer. Danach funktioniert alles wie in VS Code.

Was kostenlos ist

Kostenlos ist das Öffnen von GLB und glTF 2.0 (auch mit externen .bin-Dateien und Texturen, PBR-Materialien, Skins, Morph Targets und Animationen), von STL im Binär- und ASCII-Format, von OBJ mit der über mtllib genannten .mtl-Datei aus demselben Ordner, von PLY als Netz oder Punktwolke und von 3MF. Messen, Szenenstruktur, Drahtgitter, Animationen und Bildschirmfotos gehören ebenfalls dazu. three.js ist eingebaut, Sie brauchen also kein weiteres Programm, und die Modelldatei selbst wird nie verändert.

Was Zovo Pro hinzufügt

Die Druckprüfung zeigt vor dem Slicen Größe, Volumen und Oberfläche des Modells und prüft, ob das Netz geschlossen ist. Sie meldet offene und nicht-mannigfaltige Kanten, falsch ausgerichtete Flächen, Dreiecke ohne Fläche und die Zahl getrennter Teile, und „Mark problems“ zeichnet die fehlerhaften Kanten direkt auf das Modell. Wählen Sie ein Material (PLA, PETG, ABS, ASA, TPU, Nylon, PC oder Harz), den Füllgrad, die Wandstärke, den Filamentdurchmesser und Ihren Preis pro Kilogramm, dann schätzt die Erweiterung Gewicht, Filamentlänge und Materialkosten. Den Bericht kopieren Sie oder speichern ihn als Markdown oder JSON. So finden Sie Fehler im Netz, bevor Sie Zeit und Material am Drucker verlieren. Außerdem gibt es Section View, das das Modell mit einer X-, Y- oder Z-Ebene schneidet, Fläche und Umfang des Schnitts misst und den Umriss als SVG speichert, und Turntable Export für ein 360-Grad-GIF oder 72 nummerierte PNG-Bilder.

So funktioniert Print Check

  1. Öffnen Sie das Modell und führen Sie in der Befehlspalette „3D Model Viewer: Print Check (Zovo Pro)“ aus, oder klicken Sie im Explorer mit der rechten Maustaste auf die Datei und wählen „Zovo Pro: Print check“.
  2. Klicken Sie im Seitenbereich auf „Run print check“ und stellen Sie Material, Füllgrad, Wandstärke, Filamentdurchmesser und Preis pro Kilogramm ein.
  3. Prüfen Sie das Ergebnis und kopieren Sie den Bericht oder speichern Sie ihn als Markdown oder JSON.

Print Check läuft 3 Mal kostenlos, danach braucht es eine Lizenz. Beim Öffnen einer Datei erscheint kein Pop-up, und es läuft kein Countdown.

Per Karte zahlen, einmalig USD 19

Zovo Pro kostet einmalig USD 19. Es ist kein Abo und schaltet die Pro-Werkzeuge in allen Zovo-Erweiterungen frei. Nach der Zahlung per Karte (Stripe) steht der Lizenzschlüssel auf der nächsten Seite. Führen Sie in VS Code "Enter Zovo Pro license key" aus der Command Palette aus und fügen Sie den Schlüssel ein. Der Schlüssel wird auf Ihrem Rechner geprüft, ohne Netzwerkzugriff.

Ein Team mit 5 Personen zahlt einmalig USD 59, ebenfalls per Karte. Alle Regeln und Pro-Werkzeuge stehen auf der Zovo-Pro-Seite (Englisch).

Was es nicht kann

  • FBX, DAE, USD, STEP, IGES und glTF 1.0 öffnet die Erweiterung nicht.
  • Mit Draco oder meshopt komprimierte glTF-Dateien und KTX2-Texturen werden nicht dekodiert. Eine Meldung nennt dann die fehlende Erweiterung.
  • Die Datei wird vollständig in den Arbeitsspeicher gelesen. Die Grenze liegt standardmäßig bei 1 GB (modelViewer.maxFileMB, höchstens 4096), größere Dateien werden nicht geöffnet.
  • STL, OBJ und PLY haben keine Einheit. Die Koordinaten werden so angezeigt, wie sie in der Datei stehen, und die Druckprüfung liest sie als Millimeter.

Fragen

Ist 3D Model Viewer kostenlos?

Ja. Ansehen, Messen, Szenenstruktur, Animationen und Bildschirmfotos sind kostenlos. Print Check, Section View und Turntable Export gehören zu Zovo Pro, und jedes dieser Werkzeuge können Sie dreimal kostenlos ausprobieren.

Verändert die Erweiterung meine Modelldatei?

Nein. Die Modelldatei wird nie geschrieben. Gespeichert werden nur Dateien, die Sie selbst speichern, zum Beispiel ein Bildschirmfoto oder mit Pro ein Prüfbericht.

Funktioniert das auch in Cursor?

Ja. Die Erweiterung steht auch bei Open VSX bereit und lässt sich deshalb in Cursor, Windsurf und VSCodium installieren.

Kann ich auch FBX- oder STEP-Dateien öffnen?

Nein. FBX, DAE, USD, STEP, IGES und glTF 1.0 werden nicht unterstützt.

Alle Funktionen und Einstellungen stehen auf der Seite von 3D Model Viewer (Englisch).
