Audio in VS Code abspielen und LUFS messen

Installieren Sie Audio Player & WAV Player, klicken Sie im Explorer auf eine WAV-, MP3-, FLAC-, Ogg- oder Opus-Datei und drücken Sie die Leertaste. Die Datei spielt direkt in VS Code. Wiedergabe, Wellenform, Spektrogramm, A-B-Schleife und der Lautheitsmesser sind kostenlos. Zovo Pro (einmalig 19 USD) ergänzt das Normalisieren auf -14, -16 oder -23 LUFS und einen Lautheitsbericht für ganze Ordner, und jedes dieser Werkzeuge können Sie dreimal kostenlos ausprobieren.

In VS Code installierenMarketplace-SeiteOpen VSX (Cursor, Windsurf, VSCodium)

Kostenlos, MIT-Lizenz. Extension ID zovo.audio-preview-vscode.

Schritte in VS Code

  1. Installieren Sie Audio Player & WAV Player aus dem Marketplace, oder drücken Sie Ctrl+P (Cmd+P unter macOS) und führen Sie ext install zovo.audio-preview-vscode aus.
  2. Klicken Sie im Explorer auf die Audiodatei und drücken Sie die Leertaste. Öffnet sich ein anderer Player, klicken Sie mit der rechten Maustaste auf die Datei und wählen „Open in Audio Preview“, oder Sie nutzen „Reopen Editor With...“.
  3. Jeder Kanal hat eine eigene Wellenform (bis zu 8 Kanäle), und ein Klick springt an diese Stelle. Ziehen Sie über die Wellenform, um einen Bereich als A-B-Schleife festzulegen. Mit [ und ] setzen Sie Anfang und Ende, L schaltet die Schleife ein und aus.
  4. Die Geschwindigkeit stellen Sie zwischen 0,25-fach und 2-fach ein, die Tonhöhe bleibt dabei gleich. Die Pfeiltasten nach links und rechts springen 5 Sekunden, mit gedrückter Umschalttaste 1 Sekunde.
  5. Der Bereich Loudness zeigt die integrierte Lautheit sowie Kurzzeit- und Momentanlautheit in LUFS nach ITU-R BS.1770-4, dazu pro Kanal Sample Peak, RMS, DC-Offset und übersteuerte Samples. „Copy stats“ kopiert alle Werte in die Zwischenablage.
  6. In den Bereichen File und Tags sehen Sie Formatdetails wie den LAME-Header einer MP3 oder die MD5-Prüfsumme einer FLAC-Datei sowie Tags aus ID3, RIFF INFO, Vorbis-Kommentaren und iTunes-Atomen.

In Cursor, Windsurf und VSCodium

Diese Editoren installieren Erweiterungen aus Open VSX. Öffnen Sie die Extensions-Ansicht (Ctrl+Shift+X), suchen Sie nach zovo.audio-preview-vscode und klicken Sie auf Install. Die Seite auf Open VSX ist zovo/audio-preview-vscode. Danach funktioniert alles wie in VS Code.

Was kostenlos ist

Kostenlos sind Wiedergabe, Wellenform, Spektrogramm (FFT mit 2048 Punkten auf einer logarithmischen Frequenzachse), A-B-Schleife und der Lautheitsmesser. Auf den Testdateien des Projekts liegen die LUFS-Werte höchstens 0,1 LU neben denen des ebur128-Filters von ffmpeg. Opus spielt die Erweiterung mit einem eingebauten libopus-Decoder ab, den VS Code selbst nicht hat. Große WAV-Dateien blockieren den Editor nicht: Kopfdaten und Tags erscheinen zuerst, die Samples werden danach in Blöcken von 2 MB gelesen. Die Datei selbst wird nie verändert, und die Erweiterung macht keine Netzwerkaufrufe.

Was Zovo Pro hinzufügt

Wählen Sie -14 LUFS (Spotify, YouTube), -16 LUFS (Apple Music, Podcasts), -23 LUFS (EBU R128) oder einen eigenen Zielwert. Die Erweiterung schreibt eine neue WAV-Datei wie mix-14LUFS.wav neben das Original, das unverändert bleibt. Würde der Sample Peak dabei über -1 dBFS steigen, wird die Verstärkung verringert, und die Meldung sagt Ihnen das. Die Bittiefe bleibt erhalten, nur 8-Bit-, A-law- und mu-law-Dateien werden zu 16 Bit. So bringen Sie eine Aufnahme auf den Pegel der Zielplattform, ohne ein Audioprogramm zu öffnen. Das zweite Pro-Werkzeug, Folder Loudness Report, schreibt für jede Audiodatei eines Ordners eine CSV-Zeile mit Format, Dauer, LUFS-Werten, Sample Peak, RMS, übersteuerten Samples und der Verstärkung, die für -14, -16 und -23 LUFS nötig ist. WAV liest die Erweiterung selbst, MP3, FLAC, Ogg, Opus und M4A misst sie dafür mit Ihrem eigenen ffmpeg.

So funktioniert Normalize Loudness to -14 / -16 / -23 LUFS

  1. Öffnen Sie die Audiodatei und wählen Sie im Menü der Editor-Titelleiste „Normalize Loudness to -14 / -16 / -23 LUFS (Pro)“, oder klicken Sie die Datei im Explorer mit der rechten Maustaste an und wählen denselben Eintrag.
  2. Wählen Sie den Zielwert. Die neue WAV-Datei wird neben dem Original gespeichert.

Normalize Loudness to -14 / -16 / -23 LUFS läuft 3 Mal kostenlos, danach braucht es eine Lizenz. Beim Öffnen einer Datei erscheint kein Pop-up, und es läuft kein Countdown.

Per Karte zahlen, einmalig USD 19

Zovo Pro kostet einmalig USD 19. Es ist kein Abo und schaltet die Pro-Werkzeuge in allen Zovo-Erweiterungen frei. Nach der Zahlung per Karte (Stripe) steht der Lizenzschlüssel auf der nächsten Seite. Führen Sie in VS Code "Enter Zovo Pro license key" aus der Command Palette aus und fügen Sie den Schlüssel ein. Der Schlüssel wird auf Ihrem Rechner geprüft, ohne Netzwerkzugriff.

Ein Team mit 5 Personen zahlt einmalig USD 59, ebenfalls per Karte. Alle Regeln und Pro-Werkzeuge stehen auf der Zovo-Pro-Seite (Englisch).

Was es nicht kann

  • Für .m4a und .aac brauchen Sie ein eigenes ffmpeg, weil VS Code keinen AAC-Decoder mitbringt. Ohne ffmpeg sehen Sie nur Codec, Dauer, Bitrate und Tags. ALAC und AC-3 brauchen ebenfalls ffmpeg, und ffmpeg ist nicht in der Erweiterung enthalten.
  • Gemessen wird der Sample Peak, kein überabgetasteter True Peak. Eine Lautheitsspanne (LRA) gibt es noch nicht.
  • WAV-Dateien über 2048 MB und komprimierte Dateien mit mehr als 600 MB dekodierten Daten (etwa 28 Minuten Stereo mit 44,1 kHz) werden nur abgespielt, nicht analysiert.
  • Die Erweiterung dient zum Prüfen, nicht zum Bearbeiten. Schneiden oder Kürzen ist nicht möglich.

Fragen

Ist die Erweiterung kostenlos?

Ja. Wiedergabe, Wellenform, Spektrogramm und Lautheitsmesser sind kostenlos. Normalize Loudness und Folder Loudness Report gehören zu Zovo Pro. Jedes davon können Sie dreimal kostenlos ausprobieren, und ein Versuch zählt nur, wenn das Werkzeug seine Datei geschrieben hat.

Warum spielt meine M4A-Datei nicht ab?

VS Code bringt keinen AAC-Decoder mit. Installieren Sie ffmpeg, dann erscheint die Schaltfläche „Decode with ffmpeg“, die eine WAV-Kopie anlegt. Diese Kopie wird nach einem Tag gelöscht. Den Pfad zu ffmpeg legen Sie mit audioPreview.ffmpegPath fest. In nicht vertrauenswürdigen Arbeitsbereichen wird diese Einstellung ignoriert.

Funktioniert das auch in Cursor?

Ja. Die Erweiterung steht auch bei Open VSX bereit und lässt sich deshalb in Cursor, Windsurf und VSCodium installieren.

Wird meine Audiodatei verändert?

Nein. Die Erweiterung schreibt nichts in die Datei zurück. Auch Normalize Loudness legt eine neue Datei an und lässt das Original unverändert.
