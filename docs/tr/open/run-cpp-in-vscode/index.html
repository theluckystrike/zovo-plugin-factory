VS Code'da adımlar

  1. Run C++ and C Code eklentisini Marketplace'ten kurun ya da Ctrl+P (macOS'ta Cmd+P) tuşlayıp ext install zovo.zovo-run-cpp komutunu çalıştırın.
  2. Bir derleyicinin kurulu olduğundan emin olun. "Run C++: Pick Compiler (gcc, g++, clang, clang++)" bulduklarını listeler. Hiç yoksa bir kurulum sayfası sisteminiz için resmi adımları gösterir (Xcode Command Line Tools, MSYS2 ya da WinLibs veya Linux paket yöneticiniz).
  3. Bir .cpp, .cc, .cxx ya da .c dosyası açın ve editör başlığındaki Run düğmesine tıklayın ya da Ctrl+Alt+Enter'a (Mac'te Cmd+Alt+Enter) basın.
  4. Program "Run: file.cpp" adlı bir terminalde çalışır. Girdiyi oraya yazın. Sonunda çıkış kodunu, çalışma süresini ve tepe bellek kullanımını görürsünüz. Program çalışırken Run düğmesi Stop'a dönüşür.
  5. Bayraklar ya da argümanlar için dosyanın ilk 40 satırına // run: -O2 -lm ve // args: "Hello World" 3 yazın. C++ için varsayılanlar -std=c++20 -Wall -Wextra -g -O0 şeklindedir.
  6. Kayıtlı girdiyle test etmek için "Run C++: Run with Input & Test Cases" komutunu çalıştırın. Girdiyi yapıştırın, Run with input'a basın, sonra Save as test case seçin. Run all tests, satır diff'iyle birlikte geçti ya da kaldı sonucunu gösterir.

Neler ücretsiz, Zovo Pro neler ekler

Run, Build Only, Run Last Build, Debug, klasör derlemeleri, Input & Tests paneli, stres testi ve benchmark ücretsizdir. Oturum açmak gerekmez, eklenti ağ çağrısı yapmaz ve telemetri içermez.

Testlerinizi geçen bir program yine de bir dizinin sonunun ötesini okuyabilir ya da bir int'i taşırabilir. Sanitizer check, AddressSanitizer ve UndefinedBehaviorSanitizer (-fsanitize=address,undefined) ile ikinci bir kopya derler, onu paneldeki girdiyle ve kayıtlı her test durumuyla çalıştırır. Her heap ya da stack taşmasını, use after free hatasını, işaretli tam sayı taşmasını ve diğer tanımsız davranışları kendi satırında Problems paneline koyar. Sanitizer bayraklarını elle ayarlamadan hatayı satırında bulursunuz.

Sanitizer check nasıl kullanılır (Zovo Pro)

  1. Input & Tests paneline girdi yazın ve varsa test durumlarını kaydedin. Kontrol paneldeki girdiyle ve kayıtlı her test durumuyla çalışır.
  2. Panelde "Stress test, benchmark and more" altındaki "Sanitizer check (Pro)" düğmesine tıklayın ya da Command Palette'ten "Run C++: Sanitizer Check: AddressSanitizer and UBSan on the Input and Test Cases (Zovo Pro)" komutunu çalıştırın.
  3. Satırına gitmek için Problems panelindeki bir bulguya tıklayın. Bir derleme hatası, Stop ya da Cancel deneme hakkı harcamaz.

Sanitizer check, lisans istemeden önce bilgisayarınızda 3 kez ücretsiz çalışır. Açılır pencere ya da geri sayım yoktur.

Cursor, Windsurf ya da VSCodium'da adımlar

  1. Ctrl+Shift+X (macOS'ta Cmd+Shift+X) ile Extensions görünümünü açın.
  2. zovo.zovo-run-cpp arayın ve Install'a tıklayın. Cursor, Windsurf ve VSCodium eklentileri Open VSX üzerinden kurar. Bu eklentinin oradaki adı zovo/zovo-run-cpp.
  3. Editörünüzde eklenti galerisi yoksa .vsix dosyasını Open VSX sayfasından indirin ve "Extensions: Install from VSIX..." komutunu çalıştırın.
  4. Sonrası VS Code ile aynıdır.

Run C++ and C Code neler yapar

  • gcc, g++, clang ve clang++ ile C ve C++ dosyaları (.c, .cpp, .cc, .cxx).
  • Windows'ta olağan klasörlerindeki MSYS2, WinLibs, MinGW, TDM-GCC ve LLVM ile g++-14 gibi Homebrew adları.
  • Boşluk, & ya da ASCII dışı harf içeren yollar, çünkü bunları hiçbir shell ayrıştırmaz.
  • Bir milyon satır yazdıran programlar. Panel ilk 2.000 satırı gösterir ve gerisini sayar.

Neleri yapmaz

  • Bilgisayarınızda bir derleyici gerektirir ve hiçbir zaman derleyici indirmez.
  • Input panelindeki çalıştırmalar ve test durumları 10 saniye sonra durur (zovoRun.timeLimitSeconds ayarı).
  • 32 MB'ı aşan çıktı saklanmaz, yalnızca sayılır (zovoRun.maxCapturedOutputMB ayarı).
  • Sanitizer kontrolü, sanitizer runtime'ı olan bir derleyici gerektirir. Windows'taki MinGW gcc'de bu yoktur, orada LLVM'in clang'ını kullanın. Kontrol bunu deneme hakkı harcamadan söyler.
  • Debug için CodeLLDB ya da C/C++ eklentisi kurulu olmalıdır.

Sık sorulan sorular

Ücretsiz mi?

Run, Build Only, Debug, klasör derlemeleri, Input & Tests paneli, stres testi ve benchmark ücretsizdir. Üç Pro aracı, Sanitizer check, Compare -O0, -O2 and -O3 ve Test report, 3'er kez ücretsiz denenebilir. Sonrasında Zovo Pro gerekir, tüm Zovo eklentileri için tek seferlik 19 USD.

Programım cin ile girdi okuyabilir mi?

Evet. Program gerçek bir terminalde çalışır, bu yüzden cin ve scanf yazdığınız şeyi bekler ve satır sonu olmayan istemler (prompt) önce görünür.

settings.json ya da tasks.json dosyamı değiştirir mi?

Hayır. Ayar dosyalarınıza hiçbir zaman yazmaz. Debug, yalnızca Debug'a bastığınızda .vscode/launch.json dosyasına tek bir kayıt ekler.

Cursor'da çalışır mı?

Evet. Eklenti Open VSX'te yer alır, bu yüzden Cursor, Windsurf ve VSCodium onu kurabilir.
