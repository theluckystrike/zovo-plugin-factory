VS Code'da XML'i biçimlendirin ve üzerinde XPath çalıştırın

Ücretsiz XML Formatter & XPath Tools eklentisini kurun, bir XML dosyası açın ve Shift+Alt+F (Mac'te Shift+Option+F) tuşlarına basın. Yalnızca etiketler arasındaki boşluklar değişir. Metin, CDATA, yorumlar, xml:space="preserve" ve öznitelik değerleri bayt bayt aynı kalır, iyi biçimli (well-formed) olmayan bir dosya hiç değiştirilmez. Biçimlendirme, Minify XML, dosyanın kendi ad alanı önekleriyle XPath 1.0, Copy XPath ve XML Tree görünümü ücretsizdir ve çevrimdışı çalışır. Zovo Pro (tek seferlik 19 USD) üç araç ekler, Run XPath on Every XML File in a Folder, Format All XML Files in a Folder ve Compare Two XML Files Ignoring Formatting. Her birinin 3 ücretsiz deneme hakkı vardır.

VS Code'da adımlar

  1. XML Formatter & XPath Tools eklentisini Marketplace'ten kurun ya da Ctrl+P (macOS'ta Cmd+P) tuşlayıp ext install zovo.zovo-xml-xpath-tools komutunu çalıştırın.
  2. Bir .xml dosyası açın ve Shift+Alt+F (Mac'te Shift+Option+F) tuşlarına basın ya da Format Document'ı çalıştırın. Birden fazla XML biçimlendiriciniz varsa VS Code hangisini kullanacağını sorar. Format Selection da çalışır.
  3. Biçimlendirici sekme boyutunuzu ve sekme ya da boşluk tercihinizi kullanır. Satır sonlarını, bayt sırası işaretini (BOM) ve dosya sonundaki satır sonunu korur. Dosya iyi biçimli değilse hiçbir şey değişmez ve hatayı satır ve sütunuyla görürsünüz.
  4. Dosyayı küçültmek için tüm dosyada ya da bir seçimde “XML: Minify XML” komutunu çalıştırın. xmlXpathTools.minify.removeComments ayarını açmadığınız sürece yorumlar kalır.
  5. Bir XPath çalıştırmak için editör başlığındaki arama düğmesine tıklayın ya da “XML: Evaluate XPath…” komutunu çalıştırın. Sonuçlar satırlarıyla birlikte XPath Results'ta listelenir. Bir sonuca tıklayınca editörde seçilir.
  6. İmlecin altındaki öğenin yolunu kopyalamak için durum çubuğundaki XPath'e tıklayın. Yolu konumlarla, id ya da name öznitelikleriyle veya taşınabilir bir local-name() biçiminde kopyalayabilirsiniz.
  7. 50 MB'tan büyük bir dosya için Explorer'da dosyaya sağ tıklayıp “Format Large XML File on Disk…” seçeneğini seçin. Komut dosyanın yanına name.formatted.xml yazar ya da onaylarsanız dosyanın kendisini değiştirir.

Neler ücretsiz, Zovo Pro neler ekler

Format Document, Format Selection, Minify XML, XPath 1.0, Copy XPath, XML Tree görünümü, Problems'taki iyi biçimlilik hataları ve Format Large XML File on Disk ücretsizdir. Oturum açma yoktur ve eklentide ağ kodu bulunmaz.

Run XPath on Every XML File in a Folder, bir klasör altındaki her .xml, .xsd, .csproj, .svg, .kml ve benzeri dosyada tek bir XPath'i, her dosyanın kendi ad alanı önekleriyle çalıştırır. Sonuçlar elektronik tablo için CSV (dosya, satır, tür, ad, değer), betik için JSON ya da inceleme için Markdown raporu olarak açılır. Bir dizi pom.xml dosyasındaki her artifactId gibi aynı değeri birçok dosyadan, dosyaları tek tek açmadan alırsınız.

Run XPath on Every XML File in a Folder nasıl kullanılır (Zovo Pro)

  1. Explorer'da bir klasöre sağ tıklayıp “Zovo Pro: Run XPath on Every XML File in a Folder” seçeneğini seçin ya da Command Palette'ten “XML: Run XPath on Every XML File in a Folder (Pro)” komutunu çalıştırıp klasörü seçin.
  2. Ya da bir dosyada XPath çalıştırdıktan sonra XPath Results'ın son satırına, “Run this XPath on every XML file in a folder” satırına tıklayarak aynı ifadeyi bir klasörde çalıştırın.
  3. XPath'i yazın. Bir bildirim ilerlemeyi Cancel düğmesiyle gösterir.
  4. “Open as CSV”, “Open as JSON” ya da “Open a Markdown report” seçeneğini seçin. Sonuçlar yeni bir editör sekmesinde açılır. Deneme hakkı yalnızca bir sonuç aldığınızda düşer. Escape, XPath'te bir yazım hatası ya da XML dosyası olmayan bir klasör hak harcamaz.

Run XPath on Every XML File in a Folder, lisans istemeden önce bilgisayarınızda 3 kez ücretsiz çalışır. Açılır pencere ya da geri sayım yoktur.

XML Formatter & XPath Tools neler yapar

  • VS Code'un XML olarak açtığı dosyalar. Eklenti ayrıca .kml, .gpx, .rss, .atom, .wsdl, .dbk, .xlf, .xliff, .resx, .nuspec, .props, .targets ve .xaml dosyalarını da XML olarak açar.
  • Büyük dosyalarda biçimlendirme, ağaç ve XPath arka plandaki bir iş parçacığında çalışır. Eklentinin testlerinde yaklaşık 1 milyon öğeli 49 MB'lık bir dosya 1,6 saniyede biçimlendirildi.
  • Öneksiz adlar varsayılan ad alanıyla da eşleşir, bu yüzden bir pom.xml içinde //dependency/artifactId çalışır. Katı XPath 1.0 için xmlXpathTools.xpath.strictNamespaces ayarını açın.
  • Öznitelikler yazıldığı gibi, tek satırda ya da her biri ayrı satırda kalabilir (xmlXpathTools.format.attributes ayarı).
  • Explorer'daki XML Tree görünümü imleci izler. Problems, iyi biçimlilik hatalarını satır ve sütunlarıyla listeler.

Neleri yapmaz

  • Yalnızca XPath 1.0 desteklenir. XPath 2.0 ya da 3.1, XQuery veya XSLT yoktur.
  • Eklenti dosyanın iyi biçimli olup olmadığını denetler. XSD ya da DTD'ye göre doğrulama yapmaz.
  • 50 MB'tan büyük dosyalar diskte biçimlendirilebilir, ancak VS Code bu dosyaları eklentilere vermez, bu yüzden ağaç ve XPath onlarda çalışmaz.
  • Diskteki komut UTF-8, bayt sırası işaretli UTF-16 ve ISO-8859-1 okur.
  • <p>Some <b>bold</b> text</p> gibi içinde metin olan bir öğe yazıldığı gibi kendi satırında kalır. Yeni satır sonları yalnızca metin içermeyen, sadece etiket içeren öğelere eklenir.

Sık sorulan sorular

Ücretsiz mi?

Biçimlendirme, Minify XML, XPath, Copy XPath, XML Tree görünümü ve iyi biçimlilik denetimleri ücretsizdir. Üç Pro aracı, Run XPath on Every XML File in a Folder, Format All XML Files in a Folder ve Compare Two XML Files Ignoring Formatting, 3'er kez ücretsiz denenebilir. Sonrasında Zovo Pro gerekir, tüm Zovo eklentileri için tek seferlik 19 USD.

Biçimlendirme metnimi veya CDATA'yı değiştirir mi?

Hayır. Yalnızca metin içermeyen, sadece etiket içeren öğelerde etiketler arasındaki boşluklar değişir. Metin, CDATA, yorumlar ve xml:space="preserve" içindeki içerik olduğu gibi kopyalanır. İkinci bir biçimlendirme hiçbir şeyi değiştirmez.

XPath'im bir pom.xml dosyasında neden hiçbir şey seçmiyor?

Dosyanın varsayılan bir ad alanı var. Bu eklentide öneksiz adlar varsayılan ad alanıyla da eşleşir, bu yüzden //dependency çalışır. Katı XPath 1.0 için xmlXpathTools.xpath.strictNamespaces ayarını açın.

Cursor'da çalışır mı?

Evet. Cursor, Windsurf ve VSCodium onu Open VSX'ten kurar. Eklenti orada zovo/zovo-xml-xpath-tools adıyla yayımlanmıştır.
