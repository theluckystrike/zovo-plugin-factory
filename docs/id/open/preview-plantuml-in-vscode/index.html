Pasang ekstensi gratis PlantUML Viewer & Preview, buka file .puml atau file Markdown dengan blok plantuml, lalu klik tombol preview. Diagram digambar di samping kode Anda saat Anda mengetik, oleh jar PlantUML yang ada di dalam ekstensi dan Java 11 atau lebih baru milik Anda, sehingga tidak ada yang dikirim ke server dan Graphviz tidak diperlukan. Pratinjau, zoom, tautan error, dan menyimpan satu diagram sebagai SVG atau PNG gratis. Zovo Pro (USD 19 sekali bayar) menambahkan tiga alat, Export All Diagrams in a Folder, Markdown Diagrams to Images, dan Compare with a Git Version, dan masing-masing bisa dicoba 3 kali gratis.

Langkah di VS Code

  1. Pasang PlantUML Viewer & Preview dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.zovo-plantuml-viewer.
  2. Pastikan Java 11 atau lebih baru sudah terpasang. Ekstensi mencarinya di pengaturan plantumlViewer.javaPath, lalu JAVA_HOME, lalu java di PATH, lalu folder JDK yang umum. Jika tidak ditemukan, pratinjau memberitahukannya dan menawarkan "Set the Java path". "PlantUML: Show Java and Layout Status" menampilkan apa yang ditemukan.
  3. Buka file .puml, .plantuml, .iuml, .pu, atau .wsd, atau file Markdown dengan blok ```plantuml, lalu klik tombol preview di kanan atas editor. Anda juga bisa menekan Alt+D di file PlantUML atau menjalankan "PlantUML: Open Preview to the Side".
  4. Mulai mengetik. Pratinjau digambar ulang sesaat setelah Anda berhenti (400 ms secara default, pengaturan plantumlViewer.renderDelay). Semua diagram di file tampil dalam satu pratinjau, dan diagram di bawah kursor diberi garis tepi.
  5. Zoom dengan tombol, dengan Ctrl atau Cmd dan roda mouse, atau dengan tombol + dan -. Klik Fit untuk menyesuaikan dengan lebar panel, dan seret diagram untuk bergeser di dalamnya. Diagram dengan error menampilkan pesan PlantUML dan tautan "Go to line".
  6. Klik SVG atau PNG di atas sebuah diagram untuk menyimpan diagram itu, atau Copy SVG untuk menyalinnya.

Yang gratis dan yang ditambahkan Zovo Pro

Pratinjau langsung file .puml, .plantuml, .iuml, .pu, dan .wsd serta blok plantuml di Markdown, zoom dan pan, error dengan tautan ke baris, menyimpan satu diagram sebagai SVG atau PNG, Copy SVG, warna sintaks, snippet (seq, classd, activity, mindmap, gantt, dan lainnya), folding, dan komentar gratis. Diagram digambar di komputer Anda dan tidak pernah dikirim ke server.

Saat diagram sebuah proyek harus masuk ke dokumentasi atau slide, Export All Diagrams in a Folder menulis setiap diagram dari setiap file PlantUML di sebuah folder beserta subfoldernya ke SVG, PNG, atau PDF dalam satu kali jalan, di samping setiap file atau semuanya dalam satu folder. Diagram dengan error dilewati dan dicantumkan dengan file, baris, dan pesannya, dan sisanya tetap ditulis. Anda tidak perlu membuka setiap file dan menyimpan setiap diagram secara manual.

Cara memakai Export All Diagrams in a Folder (Zovo Pro)

  1. Klik kanan sebuah folder di Explorer lalu pilih "Zovo Pro: Export all diagrams in a folder", klik "Export all diagrams in a folder" di baris Pro tools pada toolbar pratinjau, atau jalankan "PlantUML: Export All Diagrams in a Folder (Pro)" dari Command Palette dan pilih foldernya.
  2. Pilih SVG, PNG, atau PDF, lalu "Next to each PlantUML file" atau "All in one folder...".
  3. Setelah selesai, sebuah pesan menyebutkan berapa diagram yang diekspor. Klik "Show errors" untuk daftar diagram yang mengalami error, atau "Reveal" untuk melihat filenya.
  4. Percobaan hanya dihitung jika setidaknya satu gambar ditulis. Escape, Cancel, atau folder tanpa file PlantUML tidak memakai percobaan.

Export All Diagrams in a Folder bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.zovo-plantuml-viewer lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/zovo-plantuml-viewer.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan PlantUML Viewer & Preview

  • Diagram sequence, class, activity, component, state, use case, mind map, Gantt chart, dan blok @start... lain dari PlantUML bawaan (build MIT 1.2026.10).
  • Fence Markdown ```plantuml, ```puml, dan ```uml, dengan atau tanpa @startuml di dalamnya. Tombol preview tampil pada file Markdown yang memiliki setidaknya satu blok tersebut.
  • !include file dari folder diagram, folder workspace Anda, dan plantumlViewer.includePaths, serta standard library seperti !include <C4/C4_Container>, secara offline. Include C4, ikon AWS, dan icon-font yang ditulis sebagai alamat https://raw.githubusercontent.com/... dibaca dari salinan di dalam jar.
  • Diagram sequence, mind map, dan Gantt chart tidak memerlukan layout engine. Diagram class, component, state, dan use case memakai Graphviz jika dot terpasang (plantumlViewer.layout diatur ke auto), dan engine Smetana bawaan PlantUML jika tidak.
  • Diagram ditampilkan sebagai gambar, sehingga tautan atau teks di dalam diagram tidak bisa menjalankan kode di editor.

Yang tidak bisa dilakukan

  • Java 11 atau lebih baru harus terpasang. Ekstensi tidak mengunduh Java.
  • Include dari alamat web ditolak, kecuali alamat C4, ikon AWS, dan icon-font yang salinannya ada di dalam jar. Ikon AWS berasal dari set ikon AWS di dalam PlantUML (versi 20), sehingga ikon yang lebih baru menampilkan error yang menyebut namanya.
  • Build MIT PlantUML tidak punya Ditaa dan tidak punya renderer LaTeX untuk @startmath. Blok Ditaa menampilkan halaman "not supported" dari PlantUML.
  • Tanpa Graphviz, Smetana menata diagram class dan component sedikit berbeda, dan diagram class yang sangat besar bisa terlihat lebih rapat.
  • Diagram yang butuh lebih dari 30 detik (pengaturan plantumlViewer.renderTimeoutSeconds) dihentikan, dan gambar dipotong pada 8192 piksel per sisi (pengaturan plantumlViewer.maxImageSize).

Pertanyaan umum

Apakah gratis?

Pratinjau langsung, zoom dan pan, tautan error, menyimpan satu diagram sebagai SVG atau PNG, warna sintaks, dan snippet gratis. Tiga alat Pro, Export All Diagrams in a Folder, Markdown Diagrams to Images, dan Compare with a Git Version, masing-masing bisa dicoba 3 kali gratis. Setelah itu alat tersebut memerlukan Zovo Pro, USD 19 sekali bayar untuk semua ekstensi Zovo.

Apakah saya perlu Java atau Graphviz?

Java 11 atau lebih baru perlu, karena PlantUML adalah program Java. Graphviz tidak perlu. Tanpa Graphviz, diagram class dan component memakai layout engine Smetana bawaan PlantUML. Jika dot terpasang, dot yang dipakai.

Apakah diagram saya dikirim ke server?

Tidak. Jar PlantUML bawaan berjalan di komputer Anda dengan profil keamanan ALLOWLIST, dan include dari alamat web ditolak. Tidak ada server PlantUML yang dipakai.

Apakah bisa dipakai di Cursor?

Bisa. Cursor, Windsurf, dan VSCodium memasangnya dari Open VSX, tempat ekstensi ini diterbitkan sebagai zovo/zovo-plantuml-viewer.
