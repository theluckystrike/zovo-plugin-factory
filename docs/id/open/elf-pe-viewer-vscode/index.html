Melihat section dan import file ELF, EXE, atau DLL di VS Code

Pasang ELF Viewer & PE Viewer yang gratis lalu klik file .so, .exe, .dll, atau .dylib. Anda mendapatkan tab untuk header, section, segment, import, export, dan simbol dari file Linux ELF, Windows PE, dan Apple Mach-O, ditambah tampilan hex, tanpa readelf, objdump, atau dumpbin. Setiap tampilan file gratis dan baca-saja. Zovo Pro (USD 19 sekali bayar) menambahkan tiga alat, ekspor sebagai JSON atau header C, membandingkan dua biner, dan mencari nama di folder berisi biner, dengan 3 kali percobaan gratis masing-masing.

Langkah di VS Code

  1. Pasang ELF Viewer & PE Viewer dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.zovo-elf-pe-viewer.
  2. Klik file .exe, .dll, .sys, .so, .dylib, .elf, atau .ko di Explorer. File terbuka di viewer. Untuk file objek .o atau executable Linux atau macOS tanpa ekstensi, klik kanan file lalu pilih Open in ELF & PE Viewer.
  3. Tab Overview tampil pertama. Tab ini menampilkan arsitektur, jenis file, entry point, library yang ditautkan, flag keamanan seperti ASLR dan DEP, build ID, dan path PDB.
  4. Buka tab Sections atau Imports. Import ELF menampilkan library dan versi simbol dari setiap fungsi. File PE juga mendapat data directory, import delay-load, dan resource, dan file Mach-O mendapat load command.
  5. Ketik di kotak filter di atas tabel untuk menyaring baris, dan klik judul kolom untuk mengurutkan. Copy rows menyalin baris ke clipboard sebagai teks yang dipisahkan tab.
  6. Klik tautan bytes dari sebuah section atau segment untuk melihat byte-nya ditandai di tab Hex. Di tab Headers, Show every header field with its offset membuka pohon field.

Yang gratis dan yang ditambahkan Zovo Pro

Setiap tampilan file gratis, tanpa sign-in, termasuk overview, semua tabel, filter, urutkan dan salin, tampilan hex, dan pohon field. Ekstensi ini tidak pernah menulis ke file biner dan tidak melakukan panggilan jaringan.

Untuk mengetahui biner mana di folder build yang mengimpor sebuah fungsi atau menautkan sebuah library, alat ini membaca setiap file ELF, PE, dan Mach-O di folder itu dan mencantumkan setiap hasil beserta filenya. Teks biasa cocok dengan bagian mana pun dari sebuah nama, dan /regex/ juga bisa dipakai. Anda mendapat jawabannya dalam satu pencarian, tanpa membuka setiap biner atau menjalankan readelf atau dumpbin file demi file.

Cara memakai Find a symbol or import in a folder (Zovo Pro)

  1. Buka sebuah biner lalu klik Find in folder… di bagian atas viewer, atau jalankan “ELF & PE Viewer: Find a symbol or import in a folder (Pro)” dari Command Palette.
  2. Ketik nama seperti CreateFileW atau SSL_read, atau regex seperti /^_?pthread_/. Pencarian dilakukan di folder workspace, atau Anda diminta memilih folder.
  3. Dari viewer, hasilnya terbuka di tab Find dengan tombol Copy. Dari Command Palette, hasilnya tampil dalam daftar, dan satu klik membuka biner itu.
  4. Escape, atau pencarian tanpa hasil, tidak memakai percobaan gratis.

Find a symbol or import in a folder bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.zovo-elf-pe-viewer lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/zovo-elf-pe-viewer.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan ELF Viewer & PE Viewer

  • File ELF 32 dan 64-bit, little endian dan big endian, seperti .so, .o, .ko, .elf, .axf, dan executable Linux.
  • File PE32 dan PE32+ seperti .exe, .dll, .sys, .efi, dan .pyd, dengan import berdasarkan nama dan ordinal, export dengan forwarder, dan header runtime .NET.
  • Mach-O 32 dan 64-bit, serta universal binary. Pilih arsitekturnya, seperti arm64 atau x86_64, di bagian atas.
  • Tabel hingga 100.000 baris yang bisa difilter, diurutkan, dan disalin.

Yang tidak bisa dilakukan

  • Ekstensi ini baca-saja dan tidak punya disassembly.
  • Static library (.a), file class Java, WebAssembly, dan file DEX tidak dibaca.
  • Setiap tabel berhenti di 100.000 baris, dan pembacaan berhenti setelah 10 detik. Viewer memberi tahu jika hal itu terjadi.
  • File di file system remote atau virtual dibaca hingga 256 MB. Find in folder hanya mencari di folder lokal.
  • File .o dan file tanpa ekstensi tidak terbuka secara bawaan. Pakai Open in ELF & PE Viewer dari menu klik kanan.

Pertanyaan umum

Apakah ini gratis?

Setiap tampilan file gratis, tanpa sign-in. Tiga alat Pro, ekspor sebagai JSON atau header C, membandingkan dua biner, dan mencari nama di folder, masing-masing bisa dicoba 3 kali gratis. Setelah itu alat-alat ini memerlukan Zovo Pro, USD 19 sekali bayar untuk semua ekstensi Zovo.

Apakah saya perlu readelf, objdump, atau dumpbin?

Tidak. Ekstensi ini membaca file ELF, PE, dan Mach-O sendiri, tanpa program lain yang perlu dipasang.

Apakah bisa mengubah biner?

Tidak. Ekstensi ini hanya membaca file dan tidak pernah menulis ke dalamnya. Ekspor Pro menyimpan file JSON atau header baru di lokasi yang Anda pilih.

Apakah bisa dipakai di Cursor?

Bisa. README-nya menyebutkan bahwa ekstensi ini berjalan di Cursor, Windsurf, dan VSCodium, dan ekstensi ini ada di Open VSX, jadi editor-editor itu bisa memasangnya.
