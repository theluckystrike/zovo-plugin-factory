Membuka Excel atau CSV di VS Code dan menjalankan SQL

Pasang XLSX Viewer & Excel Viewer: file Excel (.xlsx, .xls, .ods) dan Parquet langsung terbuka sebagai tabel dengan sekali klik, sedangkan CSV dibuka lewat ikon tabel di kanan atas editor. Mengurutkan, memfilter, statistik kolom, query SQL pada baris di tabel, dan ekspor semuanya gratis. Zovo Pro (USD 19 sekali bayar) menambahkan alat seperti Combine Files and Sheets, JOIN dengan file lain, dan query atas seluruh isi file besar, dengan 3 kali percobaan gratis untuk setiap alat.

Pasang di VS CodeHalaman MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

Gratis, lisensi MIT. Extension ID zovo.table-viewer-vscode.

Langkah di VS Code

  1. Pasang Table Viewer dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.table-viewer-vscode.
  2. Klik file .xlsx, .xlsm, .xls, atau .ods di Explorer; file terbuka sebagai tabel. File .csv atau .tsv terbuka di editor teks: klik ikon tabel di kanan atas, atau pilih "Open in Table Viewer" dari menu klik kanan.
  3. Klik header kolom untuk mengurutkan, dan ketik di kotak di bawah header untuk memfilter, misalnya 5..9 untuk rentang atau !test untuk membuang baris yang memuat kata itu. Kotak pencarian di atas mencari di semua kolom sekaligus.
  4. Klik "Query" di toolbar, tulis SELECT dengan FROM this untuk file yang sedang terbuka, lalu tekan Ctrl+Enter (Cmd+Enter di Mac). GROUP BY, HAVING, CASE, subquery di FROM, dan sekitar 70 fungsi didukung.
  5. Sheet dari workbook yang sama bisa digabungkan secara gratis dengan JOIN berdasarkan nama sheet.
  6. Hasil query terbuka di grid yang sama. Anda bisa mengurutkan dan memfilternya lagi, atau menyimpannya sebagai CSV, TSV, JSON, atau JSON Lines.
  7. Jika script, notebook, atau git pull menulis ulang file, tabel dimuat ulang otomatis dan urutan serta filter Anda tetap dipertahankan.

Di Cursor, Windsurf, dan VSCodium

Editor ini memasang ekstensi dari Open VSX. Buka tampilan Extensions (Ctrl+Shift+X), cari zovo.table-viewer-vscode, lalu klik Install. Halamannya di Open VSX adalah zovo/table-viewer-vscode. Setelah itu cara pakainya sama seperti di VS Code.

Yang gratis

Membuka file CSV, TSV, Excel, dan Parquet, sheet, rumus, mengurutkan, memfilter, mencari, statistik kolom, filter SQL, query SQL pada baris di tabel, JOIN antar-sheet dalam workbook yang sama, perbandingan dengan Git HEAD atau file tabel lain, serta ekspor ke CSV, TSV, JSON, atau JSON Lines semuanya gratis. Tabel menampilkan hingga 1.000.000 baris. Tidak perlu akun, Python, atau database, dan semuanya berjalan offline.

Yang ditambahkan Zovo Pro

Combine Files and Sheets menggabungkan banyak file CSV, TSV, Excel, ODS, dan Parquet, satu folder, atau semua sheet dalam satu workbook menjadi satu file CSV, XLSX, atau Parquet. Kolom dicocokkan berdasarkan nama header, dan kolom source_file serta source_sheet menunjukkan asal setiap baris. Ini menghemat waktu menyalin dan menempel, misalnya untuk ekspor bulanan. Alat Pro lainnya adalah Split Table by Column Value, query atas seluruh isi file (seperti GROUP BY pada CSV berukuran beberapa GB), JOIN dengan file lain di workspace, menyimpan sebagai Parquet, dan batas bawaan yang lebih besar (5.000.000 baris, CSV 2 GB, Excel 200 MB).

Cara memakai Combine Files and Sheets

  1. Klik kanan folder, beberapa file tabel yang dipilih, atau sebuah workbook di Explorer, lalu pilih "Zovo Pro: Combine Files and Sheets".
  2. Anda juga bisa menjalankan "Combine Files and Sheets (Pro)..." dari Command Palette, atau mengklik Combine di toolbar.
  3. Simpan hasilnya sebagai file CSV, XLSX, atau Parquet.

Combine Files and Sheets bisa dipakai 3 kali gratis sebelum meminta lisensi. Tidak ada popup saat file dibuka dan tidak ada hitung mundur.

Bayar dengan kartu, USD 19 sekali

Zovo Pro seharga USD 19 sekali bayar. Bukan langganan, dan lisensinya membuka alat Pro di semua ekstensi Zovo. Setelah membayar dengan kartu (Stripe), kunci lisensi muncul di halaman berikutnya. Di VS Code, jalankan "Enter Zovo Pro license key" dari Command Palette lalu tempel kuncinya. Kunci diperiksa di komputer Anda, tanpa koneksi jaringan.

Lisensi untuk tim berisi 5 orang seharga USD 59 sekali bayar, juga bisa dengan kartu. Semua aturan dan alat Pro ada di halaman Zovo Pro (bahasa Inggris).

Yang tidak bisa dilakukan

  • File CSV dan TSV secara bawaan terbuka di editor teks; gunakan ikon tabel atau "Open in Table Viewer".
  • Table Viewer hanya untuk membaca: sel tidak bisa diedit dan file sumber tidak bisa disimpan.
  • Tanpa Pro, tabel memuat hingga 1.000.000 baris dan 512 MB pertama dari sebuah CSV. File .xls, .xlsb, dan .ods di atas 50 MB menampilkan pesan, bukan tabel.
  • Hanya satu SELECT yang berjalan dalam satu waktu; RIGHT JOIN, FULL JOIN, WITH, dan subquery di dalam ekspresi tidak didukung.

Pertanyaan

Apakah fitur SQL-nya gratis?

Ya. Query SQL pada baris di tabel, filter SQL, dan JOIN antar-sheet dalam workbook yang sama gratis. JOIN dengan file lain dan query atas seluruh isi file termasuk Zovo Pro dan bisa dicoba 3 kali secara gratis; setelah itu Zovo Pro seharga USD 19 sekali bayar untuk semua ekstensi Zovo.

Apakah bisa dipakai di Cursor?

Bisa. Ekstensi ini juga tersedia di Open VSX, jadi di Cursor Anda cukup memasangnya dari panel Extensions.

Mengapa file CSV saya terbuka sebagai teks?

File CSV sengaja dibuka di editor teks karena banyak orang mengeditnya sebagai teks. Klik ikon tabel di kanan atas editor, atau pilih "Open in Table Viewer" dari menu klik kanan.

Bisakah saya mengedit sel?

Tidak. Table Viewer tidak pernah mengubah atau menimpa file. Export dan penyimpanan hasil query hanya menulis file baru yang Anda pilih sendiri.

Semua fitur dan pengaturan ada di halaman Table Viewer (bahasa Inggris).
