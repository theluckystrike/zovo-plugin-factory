Memutar video MOV, MKV, WebM, dan MP4 dengan suara di VS Code

Pasang ekstensi gratis Video Preview with Sound lalu klik video di Explorer. File MP4, MOV, dan M4V dengan suara AAC diputar dengan suaranya tanpa memasang apa pun lagi, karena ekstensi ini membawa dekoder suaranya sendiri. MKV, WebM, AVI, dan video yang tidak bisa didekode VS Code, seperti Apple ProRes, memerlukan ffmpeg di komputer Anda. Pemutaran, suara, subtitle, dan konversi gratis, dan Zovo Pro (USD 19 sekali bayar) menambahkan Clip export, Frame export, dan contact sheet, dengan 3 kali percobaan gratis untuk setiap alat.

Langkah di VS Code

  1. Pasang Video Preview with Sound dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.video-preview-with-sound.
  2. Jika videonya berupa file MKV, WebM, AVI, WMV, FLV, MPG, OGV, atau M2TS, atau bersuara AC-3, E-AC-3, atau DTS, pasang ffmpeg lebih dulu. Jalankan winget install ffmpeg di Windows, sudo apt install ffmpeg di Linux, atau brew install ffmpeg di macOS. MP4, MOV, dan M4V dengan suara AAC tidak memerlukan apa pun lagi.
  3. Klik file .mp4, .m4v, .mov, .webm, .mkv, .avi, .wmv, .flv, .mpg, .mpeg, .ogv, atau .m2ts di Explorer, lalu tekan Spasi untuk memutarnya. Jika VS Code menanyakan editor mana yang dipakai, pilih “Video Preview with Sound”.
  4. Video diputar tanpa suara sampai chip menampilkan “Sound: on”. File MKV atau WebM disalin ke MP4 tanpa encode ulang. ProRes, AVI, WMV, dan video lain yang tidak bisa didekode VS Code dikonversi ke H.264 satu kali lalu disimpan di cache.
  5. Letakkan file .srt atau .vtt dengan nama yang sama di sebelah video, dan subtitle dimuat dengan sendirinya. Tekan C atau pakai menu CC untuk berganti trek atau mematikannya.
  6. Tekan , dan . untuk maju atau mundur satu frame, [ dan ] untuk mengubah kecepatan dari 0.1x sampai 4x, A dan B untuk mengatur loop, S untuk menyimpan frame saat ini sebagai PNG ukuran penuh, dan P untuk picture-in-picture.

Yang gratis dan yang ditambahkan Zovo Pro

Pemutaran dengan suara, dekoder AAC bawaan, pemutaran MKV dan WebM dengan ffmpeg, konversi video yang tidak bisa didekode VS Code, subtitle, picture-in-picture, langkah per frame, kecepatan, loop A-B, menyimpan frame saat ini sebagai PNG (S), panel metadata, dan melanjutkan dari posisi terakhir gratis.

Clip export menyimpan bagian A-B dari video, atau seluruh video, sebagai GIF atau MP4 untuk pull request, issue, atau dokumentasi. GIF dibuat di dalam pemutar tanpa alat lain: 480 px pada 10 fps, 640 px pada 15 fps, atau hingga 960 px pada 15 fps, paling lama 60 detik. MP4 dipotong oleh ffmpeg Anda sendiri, baik sebagai potongan tepat yang di-encode ulang ke H.264 dan AAC dan dimulai di frame A, maupun sebagai salinan cepat yang mempertahankan stream asli dan dimulai di keyframe sebelum A.

Cara memakai Clip export (Zovo Pro)

  1. Buka video di pemutar. Tekan A di awal dan B di akhir bagian yang Anda inginkan, atau jangan atur apa pun untuk memakai seluruh video.
  2. Tekan Clip (dengan lencana PRO) di pemutar, atau “Export a Clip as GIF or MP4” di baris Pro tools kecil di bawah kontrol. Anda juga bisa mengklik kanan video di Explorer dan memilih “Zovo Pro: Export a Clip as GIF or MP4”.
  3. Pilih “GIF, 480 px wide, 10 fps”, “GIF, 640 px wide, 15 fps”, “GIF, up to 960 px wide, 15 fps”, “MP4, exact cut”, atau “MP4, fast copy”, lalu tentukan lokasi penyimpanan.
  4. Esc menghentikan ekspor. Percobaan baru dihitung saat file tersimpan, jadi dialog yang dibatalkan atau ekspor yang dihentikan tidak memakai percobaan gratis.

Clip export bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.video-preview-with-sound lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/video-preview-with-sound.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan Video Preview with Sound

  • MP4, M4V, dan MOV dengan suara AAC (mono atau stereo), ALAC, MP3, atau PCM, tanpa pemasangan lain, di Windows, Linux, dan macOS.
  • MKV dan WebM, disalin ke MP4 oleh ffmpeg dan diputar dengan suara.
  • Suara AC-3, E-AC-3, DTS, Opus, atau AAC 5.1 di MP4, M4V, atau MOV, didekode oleh ffmpeg atau oleh afconvert bawaan macOS.
  • Video Apple ProRes, MPEG-4 Part 2, dan DNxHD, serta file AVI, WMV, FLV, MPG, MPEG, OGV, dan M2TS, dikonversi ke H.264 dengan ffmpeg.
  • Subtitle dari file .srt dan .vtt di sebelah video.

Yang tidak bisa dilakukan

  • Tanpa ffmpeg, MKV dan WebM tidak terbuka di sistem mana pun. Pemutar menampilkan “Install ffmpeg to open this file”. ffmpeg tidak disertakan dalam ekstensi.
  • afconvert di macOS tidak bisa mengonversi video dan tidak bisa membuka MKV atau WebM. Konversi selalu memerlukan ffmpeg Anda sendiri, dan file ProRes yang panjang bisa memakan waktu beberapa menit.
  • Dekoder bawaan memutar HE-AAC dari inti AAC-LC-nya dengan setengah sample rate. Pasang ffmpeg untuk HE-AAC penuh, AAC 5.1, AC-3, dan DTS.
  • File yang lebih besar dari 4096 MB tetap diputar, tetapi tanpa suara (pengaturan videoPreview.maxDecodeSizeMB).
  • Subtitle hanya diambil dari file .srt dan .vtt, paling besar 5 MB per file. Subtitle di dalam file video tidak dibaca. File .ts dan .mts tidak dibuka, karena nama itu dipakai untuk file TypeScript.

Pertanyaan umum

Mengapa VS Code memutar MP4 saya tanpa suara?

Chromium bawaan VS Code punya dekoder video H.264 tetapi tidak punya dekoder AAC, padahal sebagian besar file MP4 dan MOV memakai suara AAC. Ekstensi ini mendekode suaranya sendiri dan memutarnya selaras dengan gambar.

Apakah saya perlu ffmpeg?

Tidak untuk MP4, MOV, dan M4V dengan suara AAC, ALAC, MP3, atau PCM. ffmpeg diperlukan untuk MKV, WebM, AVI, WMV, FLV, MPG, OGV, dan M2TS, untuk ProRes dan video lain yang tidak bisa didekode VS Code, dan untuk klip MP4 dari Clip export. Suara AC-3, E-AC-3, dan DTS memerlukan ffmpeg, atau afconvert di macOS.

Apakah ini gratis?

Ya. Pemutaran, suara, subtitle, langkah per frame, menyimpan frame saat ini sebagai PNG, dan konversi gratis. Clip export, Frame export, dan contact sheet adalah alat Zovo Pro dengan 3 kali percobaan gratis masing-masing, lalu USD 19 sekali bayar untuk semua ekstensi Zovo.

Apakah bisa dipakai di Cursor?

Bisa. Ekstensi ini ada di Open VSX sebagai zovo/video-preview-with-sound, jadi Cursor, Windsurf, dan VSCodium bisa memasangnya.
