Membuka gambar DXF di VS Code

Pasang DXF Viewer yang gratis lalu klik file .dxf. Ekstensi ini membaca DXF ASCII dan biner dari R12 sampai AutoCAD 2018, dengan block, teks, dimension, hatch, dan sheet paper space, dan Anda bisa menyembunyikan layer, mencari teks, dan mengukur. File DWG tidak dibaca. File .dwg membuka halaman singkat berisi versinya dan cara menyimpan salinan DXF. Melihat gambar gratis, dan Zovo Pro (USD 19 sekali bayar) menambahkan tiga alat, Extract drawing data, Compare drawings, dan Folder inventory, dengan 3 kali percobaan gratis masing-masing.

Langkah di VS Code

  1. Pasang DXF Viewer dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.dxf-viewer.
  2. Klik file .dxf di Explorer. File terbuka di DXF Viewer. Panel samping mencantumkan layer, jenis entity, dan data gambar seperti versi, satuan, dan ukuran.
  3. Seret untuk menggeser, gulir untuk zoom di posisi penunjuk, dan tekan F atau klik dua kali agar gambar muat di layar. B berganti antara latar gelap dan putih.
  4. Jika gambar punya paper space, pilih layout di daftar Sheet. Tampilannya seperti hasil cetak, dengan title block dan viewport pada skalanya.
  5. Hilangkan centang sebuah layer di panel Layers untuk menyembunyikannya. Tekan Ctrl+F (Cmd+F di Mac) untuk mencari teks, MTEXT, atau atribut block, dan tekan M untuk mengukur jarak antara dua titik.
  6. Klik Export PNG atau Export SVG untuk menyimpan tampilan. Saat Anda menyimpan DXF lagi dari program CAD, tampilan yang terbuka dimuat ulang dengan zoom, sheet, dan layer yang sama.

Yang gratis dan yang ditambahkan Zovo Pro

Membuka file DXF, sheet, layer, pencarian teks, pengukuran, muat ulang langsung, dan ekspor PNG atau SVG gratis. Viewer ini tidak melakukan panggilan jaringan dan tidak pernah mengubah gambar.

Inventaris ini membaca setiap file .dxf di sebuah folder dan subfoldernya, lalu menyimpan satu baris CSV per gambar. Setiap baris berisi versi DXF, satuan, lebar dan tinggi, layer, entity, block, teks, dan field title block seperti TITLE, DWG_NO, REV, dan DATE. Saat Anda menerima satu folder gambar, Anda bisa melihat isinya dalam satu spreadsheet tanpa membuka file satu per satu.

Cara memakai Inventory of a Folder of Drawings to CSV (Zovo Pro)

  1. Klik kanan folder di Explorer lalu pilih “Inventory of a Folder of Drawings to CSV (Zovo Pro)”. Atau jalankan “DXF Viewer: Inventory of a Folder of Drawings to CSV (Zovo Pro)” dari Command Palette dan pilih foldernya.
  2. Notifikasi menampilkan progresnya dan bisa dibatalkan. Lalu tentukan lokasi penyimpanan CSV. Nama bawaannya berakhiran -dxf-inventory.csv.
  3. Percobaan baru dihitung saat file CSV tersimpan, jadi Cancel atau Escape tidak memakai percobaan. File yang tidak bisa dibaca dicantumkan di kolom Error.

Inventory of a Folder of Drawings to CSV bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.dxf-viewer lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/dxf-viewer.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan DXF Viewer

  • DXF ASCII dan biner, dari R12 sampai AutoCAD 2018.
  • Line, arc, circle, ellipse, polyline dengan bulge, spline, pattern hatch, TEXT, MTEXT, atribut block, nested block, dan dimension.
  • Layout paper space, dengan setiap viewport pada skala dan rotasinya sendiri, dan layer yang dibekukan di viewport itu tidak ditampilkan.
  • File besar, dibaca di worker thread. Gambar 24 MB dengan 600.000 garis dimuat dalam sekitar satu detik.

Yang tidak bisa dilakukan

  • File DWG tidak dibaca. Simpan dulu sebagai DXF.
  • Entity 3D digambar datar, sebagai tampak atas, dan 3DSOLID, REGION, serta BODY tidak digambar.
  • Teks memakai font sans-serif, bukan font SHX atau TrueType dari file, dan ketebalan garis (line weight) tidak dipakai.
  • Viewport digambar sebagai persegi panjang, dan gradien hatch tampil sebagai isi warna solid.
  • File di atas 500 MB tidak dibaca (pengaturan dxfViewer.maxFileMB, hingga 2048).

Pertanyaan umum

Apakah ini gratis?

Membuka file DXF, sheet, layer, pencarian teks, pengukuran, muat ulang langsung, dan ekspor PNG atau SVG gratis. Tiga alat Pro, Extract drawing data, Compare drawings, dan Folder inventory, masing-masing bisa dicoba 3 kali gratis. Setelah itu alat-alat ini memerlukan Zovo Pro, USD 19 sekali bayar untuk semua ekstensi Zovo.

Apakah bisa membuka file DWG?

Tidak. DWG adalah format tertutup. File .dwg membuka halaman singkat berisi versinya dan langkah-langkah menyimpan salinan DXF di AutoCAD, BricsCAD, LibreCAD, QCAD, atau ODA File Converter yang gratis.

Bisakah saya mengedit gambarnya?

Tidak. Viewer ini baca-saja. Satu-satunya file yang ditulisnya adalah hasil ekspor yang Anda pilih di dialog simpan, dan viewer ini menolak menimpa file gambar.

Apakah bisa dipakai di Cursor?

Bisa. DXF Viewer ada di Open VSX, jadi Cursor, Windsurf, dan VSCodium bisa memasangnya.
