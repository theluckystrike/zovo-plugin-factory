Upload file ke server lewat SFTP atau FTP dari VS Code

Pasang ekstensi gratis SFTP & FTP Sync and Upload lalu tulis .vscode/sftp.json dengan host, user, dan folder server. Setelah itu setiap file diunggah saat Anda menyimpannya, lewat SFTP, FTP, atau FTPS. Klik kanan file atau folder untuk upload, download, atau membandingkannya dengan salinan di server, dan buka file server di tab biasa dari tampilan Remote Files. Folder .vscode, file .env, dan private key Anda tidak pernah diunggah. Semua itu gratis, tanpa akun. Zovo Pro (USD 19 sekali bayar) menambahkan tiga alat, Sync Folder with Remote, Roll Back a Remote File, dan Server Profiles and Jump Host, dan masing-masing bisa dicoba 3 kali gratis.

Langkah di VS Code

  1. Pasang SFTP & FTP Sync and Upload dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.zovo-sftp.
  2. Jalankan "SFTP: Create sftp.json Config" dari Command Palette, atau klik Create sftp.json di tampilan SFTP Remote.
  3. Isi protocol (sftp, ftp, atau ftps), host, username, privateKeyPath (hapus jika ingin memakai password), dan remotePath, yaitu folder server yang sesuai dengan folder lokal Anda. Arahkan kursor ke key mana pun untuk melihat bantuannya.
  4. Atur "uploadOnSave": true. Mulai saat itu, setiap file yang Anda simpan akan diunggah. Password yang Anda ketik ditanyakan sekali dan disimpan di secret storage editor, tidak pernah di sftp.json.
  5. Klik kanan file atau folder mana pun di Explorer, atau sebuah tab, lalu pilih Upload, Download, atau Compare with Server Copy (Compare hanya untuk file).
  6. Buka tampilan Remote Files untuk menjelajahi server. Buka file di tab editor biasa lalu simpan kembali, unduh, salin path-nya, atau hapus. "SFTP: Show Transfer Log" menampilkan setiap koneksi dan transfer.

Yang gratis dan yang ditambahkan Zovo Pro

Upload saat menyimpan, Upload, Download, dan Compare with Server Copy, tampilan Remote Files, SFTP, FTP, dan FTPS, pemeriksaan host key, dan transfer log gratis, tanpa akun dan tanpa sign-in ke apa pun selain server Anda sendiri. Tanpa telemetri.

Saat server dan folder lokal Anda sudah tidak sama, Sync Folder with Remote membandingkan keduanya dan mencantumkan setiap perbedaan sebelum ada file yang dipindahkan: file yang hanya ada di sini, hanya ada di server, atau lebih baru di salah satu sisi. Anda memilih upload, download, delete, atau skip per file, membuka diff berdampingan, menyimpan dry run sebagai teks, lalu menerapkannya. Anda melihat dengan tepat apa yang akan berubah di server sebelum perubahan terjadi.

Cara memakai Sync Folder with Remote (Zovo Pro)

  1. Klik kanan sebuah folder di Explorer lalu pilih "Zovo Pro: Sync folder with remote (diff preview)", atau jalankan "SFTP: Sync Folder with Remote, Diff Preview (Pro)..." dari Command Palette. Tampilan Remote Files punya tombol yang sama di title bar-nya.
  2. Baca rencananya. Untuk setiap file pilih upload, download, delete, atau skip, dan buka diff dari file mana pun yang Anda ragukan.
  3. Terapkan rencananya. Percobaan hanya dihitung jika rencana sync ditampilkan. Escape atau Cancel tidak pernah memakai percobaan.

Sync Folder with Remote bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.zovo-sftp lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/zovo-sftp.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan SFTP & FTP Sync and Upload

  • SFTP dengan SSH key, key terenkripsi, SSH agent, atau password, FTP, serta FTPS dengan TLS explicit atau implicit.
  • .vscode, .git, file .env, private key, .npmrc, dan file rahasia lain tidak pernah diunggah. Tambahkan pola Anda sendiri di ignore, dengan gaya .gitignore.
  • Host key server diperiksa. Pin dengan hostFingerprint atau konfirmasi saat koneksi pertama. Host key yang berubah menghentikan koneksi.
  • Di folder yang belum Anda percayai (Restricted Mode), ekstensi tetap mati, sehingga proyek hasil unduhan tidak bisa mengirim file Anda ke mana pun.
  • Dua alat Pro lainnya. Roll Back a Remote File menyimpan 10 salinan server terakhir sebuah file di komputer Anda sebelum upload menimpanya, dan Server Profiles and Jump Host menaruh beberapa server (staging, production) dalam satu sftp.json serta terhubung lewat SSH jump host.

Yang tidak bisa dilakukan

  • Satu koneksi per server pada satu waktu, dan transfer FTP berjalan satu per satu.
  • Symbolic link di server diikuti untuk file, tetapi folder yang berupa link tidak ditelusuri oleh upload folder, download folder, atau sync.
  • Key dalam format PuTTY .ppk harus dikonversi ke OpenSSH terlebih dahulu (puttygen key.ppk -O private-openssh -o key).
  • Sync membandingkan ukuran dan waktu modifikasi, lalu isi byte dari file yang ukurannya sama, sampai 300 file atau 64 MB per kali jalan.
  • Salinan rollback disimpan untuk file sampai 5 MB secara default, dan hanya di komputer ini.

Pertanyaan umum

Apakah gratis?

Upload saat menyimpan, Upload, Download, Compare with Server Copy, tampilan Remote Files, dan transfer log gratis, lewat SFTP, FTP, dan FTPS. Tiga alat Pro, Sync Folder with Remote, Roll Back a Remote File, dan Server Profiles and Jump Host, masing-masing bisa dicoba 3 kali gratis. Setelah itu alat tersebut memerlukan Zovo Pro, USD 19 sekali bayar untuk semua ekstensi Zovo.

Apakah password saya disimpan di sftp.json?

Tidak. Password atau passphrase yang Anda ketik disimpan di secret storage editor. Jangan tulis password di sftp.json, dan Anda akan ditanya sekali.

Apakah file .env saya ikut diunggah?

Tidak. .vscode, .git, file .env, private key, dan .npmrc ada di daftar ignore default dan tidak pernah diunggah.

Apakah VS Code bisa upload lewat SFTP tanpa ekstensi?

Tidak. VS Code tidak punya upload SFTP atau FTP. Remote SSH mengedit file langsung di server. Untuk mengunggah proyek lokal, Anda memerlukan ekstensi, atau scp dan rsync di terminal.
