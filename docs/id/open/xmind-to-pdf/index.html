XMind ke PDF tanpa XMind, semua sheet dalam satu PDF

Pasang XMind Viewer & Mind Map Viewer (zovo.xmind-mind-map-viewer) lalu klik file .xmind. Setiap sheet terbuka sebagai tab, tanpa perlu XMind. Melihat, pencarian, serta ekspor PNG, SVG, dan Markdown gratis. PDF of every sheet adalah alat Zovo Pro yang menyimpan satu PDF dengan satu halaman per sheet, dalam warna cetak, dengan bookmark untuk setiap sheet. Alat ini bisa dicoba 3 kali gratis di komputer Anda, lalu Zovo Pro seharga USD 19 sekali bayar untuk semua ekstensi Zovo.

Langkah di VS Code

  1. Pasang XMind Viewer dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.xmind-mind-map-viewer.
  2. Klik file .xmind di Explorer. File dari XMind 2020 dan yang lebih baru, XMind Zen, dan XMind 8 bisa terbuka. Setiap sheet peta menjadi tab di bagian atas.
  3. Telusuri sheet-sheetnya. Setiap sheet terbuka dengan layout yang tersimpan di file. Seret untuk menggeser, pakai Ctrl atau Cmd + roda mouse untuk zoom, dan tekan F agar sheet muat di layar.
  4. Buka menu “Export…” di toolbar di atas peta lalu pilih “PDF, every sheet (Zovo Pro)”. Anda juga bisa menjalankan “XMind Viewer: Export every sheet as PDF (Zovo Pro)” dari Command Palette saat peta terbuka.
  5. Tentukan nama file di dialog simpan lalu klik “Export PDF”. Sebuah pesan menampilkan jumlah halaman yang disimpan, dengan tombol “Show in folder”. File peta Anda tidak pernah diubah.
  6. Untuk gambar gratis dari satu sheet, pilih “PNG picture” atau “SVG picture” di menu Export yang sama.

Yang gratis dan yang ditambahkan Zovo Pro

Membuka file .xmind, .mm, dan .opml gratis, termasuk setiap sheet, semua layout, collapse, level, pencarian, dan panel detail. Ekspor ke PNG (hingga 2x), SVG, sheet sebagai outline Markdown di clipboard, dan semua sheet sebagai satu file Markdown juga gratis.

PDF of every sheet menyimpan semua sheet peta sebagai satu file PDF, satu halaman per sheet, dalam warna cetak, dengan bookmark untuk setiap sheet. Anda mendapatkan seluruh peta dalam satu kali jalan, tanpa mengekspor setiap sheet sebagai gambar lalu menggabungkannya secara manual. Di XMind sendiri, ekspor PDF memerlukan XMind Pro, paket XMind berbayar.

Cara memakai PDF of every sheet (Zovo Pro)

  1. Saat peta terbuka, pilih “PDF, every sheet (Zovo Pro)” di menu “Export…”, klik “PDF of every sheet” di baris Zovo Pro kecil pada toolbar, atau jalankan “XMind Viewer: Export every sheet as PDF (Zovo Pro)” dari Command Palette.
  2. Dari Explorer, klik kanan file .xmind, .mm, atau .opml lalu pilih “Zovo Pro: PDF of every sheet”.
  3. Tentukan lokasi penyimpanan PDF lalu klik “Export PDF”. Percobaan baru dihitung saat file tersimpan, jadi Cancel tidak memakai percobaan.
  4. Setelah 3 percobaan gratis habis, alat ini menampilkan cara mendapatkan Zovo Pro.

PDF of every sheet bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.xmind-mind-map-viewer lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/xmind-mind-map-viewer.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan XMind Viewer

  • File .xmind dari XMind 2020 sampai 2026 dan XMind Zen (content.json), serta dari XMind 8, XMind 7, dan versi 3.x yang lebih lama (content.xml).
  • Setiap sheet sebagai tab, dengan relationship, boundary, summary, marker, label, catatan, gambar dari dalam file, dan persamaan LaTeX yang digambar dengan KaTeX.
  • File FreeMind dan Freeplane .mm serta outline .opml. PDF of every sheet juga berfungsi untuk file-file ini.
  • Judul berbahasa Tionghoa, Jepang, Korea, dan emoji, dengan judul panjang yang dipotong ke baris berikutnya.
  • Peta besar. Dalam pengujian README, file .xmind 30 MB dengan 10.111 topik dan 60 gambar terbuka dalam 0,65 detik.

Yang tidak bisa dilakukan

  • Baca-saja. Untuk mengubah peta, buka di XMind, Freeplane, atau editor peta pikiran lain.
  • Peta yang diberi kata sandi tidak bisa dibuka, karena XMind mengenkripsi isinya. Anda akan melihat pesan yang menjelaskan hal itu.
  • Sheet fishbone, timeline, matrix, dan brace digambar sebagai logic chart atau org chart. Posisi topik yang Anda seret secara manual di XMind tidak dipertahankan, dan gaya dari tema XMind (font, bentuk garis, bentuk topik) tidak disalin. Warna isi dan warna teks topik tetap disalin.
  • Setiap halaman PDF adalah gambar dari sheet, jadi teks di PDF tidak bisa dipilih atau dicari.
  • File yang lebih besar dari 1 GB (pengaturan xmindViewer.maxFileMB) menampilkan pesan, bukan terbuka.

Pertanyaan umum

Apakah ini gratis?

Melihat peta serta ekspor PNG, SVG, dan Markdown gratis. PDF of every sheet, ekspor CSV (Excel) dan OPML, serta Convert a folder adalah alat Zovo Pro. Setiap alat Pro bisa dicoba 3 kali gratis di komputer Anda, lalu Zovo Pro seharga USD 19 sekali bayar untuk semua ekstensi Zovo.

Apakah XMind harus terpasang?

Tidak. Ekstensi ini membaca file .xmind sendiri, berjalan offline, dan tidak membuat permintaan jaringan.

Bisakah saya mengubah satu folder penuh berisi peta ke PDF?

Tidak. Convert a folder menulis file Markdown, CSV, atau OPML. PDF dibuat satu peta setiap kali.

Apakah bisa dipakai di Cursor?

Bisa. Ekstensi ini juga ada di Open VSX, jadi bisa dipasang di Cursor, Windsurf, VSCodium, dan editor lain yang berbasis VS Code.
