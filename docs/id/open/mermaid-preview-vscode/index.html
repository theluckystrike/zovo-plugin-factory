Pratinjau diagram Mermaid di VS Code

VS Code tidak punya pratinjau Mermaid sendiri. Pasang Mermaid Viewer yang gratis, buka file .mmd atau .mermaid, lalu klik ikon pratinjau di kanan atas editor. Diagram mengikuti ketikan Anda. Di file Markdown, pratinjaunya mencantumkan setiap blok mermaid. Mermaid 12.3.0 sudah ada di dalam ekstensi, jadi pratinjau serta ekspor PNG atau SVG gratis dan berjalan offline tanpa sign-in. Zovo Pro (USD 19 sekali bayar) menambahkan ekspor PDF, ekspor semua diagram di workspace, dan ekspor saat menyimpan, masing-masing dengan 3 kali percobaan gratis.

Langkah di VS Code

  1. Pasang Mermaid Viewer dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.mermaid-viewer.
  2. Buka file .mmd atau .mermaid lalu klik ikon pratinjau di judul editor, atau tekan Ctrl+K V (Cmd+K V di macOS). Anda juga bisa menjalankan “Mermaid Viewer: Open Diagram Editor (Text + Live Preview)” dari Command Palette.
  3. Untuk file Markdown dengan blok ```mermaid, klik ikon pratinjau yang sama. Pratinjau mencantumkan setiap diagram, masing-masing dengan baris galat dan tombol ekspornya sendiri.
  4. Klik “Edit diagram” di atas sebuah blok di file Markdown untuk mengeditnya di samping pratinjau langsung. Simpan, dan teksnya kembali ke bloknya.
  5. Gulir untuk zoom di posisi penunjuk, dan seret untuk menggeser. Fit dan 100% ada di toolbar.
  6. Klik Export untuk Save PNG (1x, 2x, atau 4x, atau lebar atau tinggi yang tepat), Save SVG, Copy PNG, atau Copy SVG code.

Yang gratis dan yang ditambahkan Zovo Pro

Pratinjau langsung, editor diagram, Edit diagram untuk blok Markdown, pelengkapan kode, garis bawah galat, 15 templat, outline Mermaid Diagrams, serta ekspor dan salin PNG dan SVG gratis. Tidak ada akun, tidak ada sign-in, dan tidak ada AI.

Export All Diagrams in Workspace menulis setiap diagram dari setiap file .mmd, .mermaid, dan Markdown di folder ke SVG, PNG, atau keduanya, ke dalam mermaid-export/ dengan struktur folder yang sama seperti sumbernya. Diagram yang tidak bisa digambar dicantumkan di akhir. Anda tidak perlu membuka dan mengekspor setiap diagram secara manual saat dokumentasi berubah.

Cara memakai Export All Diagrams in Workspace (Zovo Pro)

  1. Buka folder di VS Code. Jalankan “Mermaid Viewer: Export All Diagrams in Workspace (SVG/PNG) (Pro)” dari Command Palette, atau klik “Export All Diagrams in Workspace” di baris “Pro tools” di bawah toolbar pratinjau.
  2. Pilih SVG, PNG, atau SVG dan PNG.
  3. Pakai folder bawaan mermaid-export (pengaturan mermaidViewer.exportFolder) atau pilih “Choose a folder…”. Percobaan baru dihitung saat file selesai ditulis, dan Escape tidak memakai percobaan.

Export All Diagrams in Workspace bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.mermaid-viewer lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/mermaid-viewer.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan Mermaid Viewer

  • Flowchart, sequence, class, state, ER, Gantt, pie, gitGraph, mindmap, timeline, sankey, XY chart, block, C4, architecture, dan jenis lain yang dikenal Mermaid 12.3.0.
  • Galat digarisbawahi di barisnya dan dicantumkan di panel Problems. Diagram terakhir yang benar tetap tampil, dan satu blok yang rusak di file Markdown tidak menyembunyikan blok lain.
  • Zoom dari 1 % hingga 3.200 % di posisi penunjuk, dengan geser dan cubit di trackpad.
  • Ekspor SVG dengan label teks biasa untuk wiki Azure DevOps dan GitHub.
  • Latar belakang dengan warna editor, putih, transparan, atau warna pilihan sendiri, yang juga dipakai untuk ekspor.

Yang tidak bisa dilakukan

  • Ekstensi ini tidak menambahkan diagram ke pratinjau Markdown bawaan VS Code. Ekstensi ini membuka panel pratinjaunya sendiri.
  • Rumus matematika di label mungkin tidak tampil dengan benar, karena font KaTeX tidak disertakan.
  • Paket ikon yang dimuat Mermaid dari internet tidak dimuat. Ikon bawaan tetap berfungsi.
  • Diagram di atas 500.000 karakter atau 2.000 tautan tidak digambar sampai Anda menaikkan batasnya (pengaturan mermaidViewer.maxTextSize dan mermaidViewer.maxEdges).
  • Penggambaran yang memakan waktu lebih dari 10 detik dihentikan (pengaturan mermaidViewer.renderTimeoutSeconds).

Pertanyaan umum

Apakah ini gratis?

Pratinjau, editor, pengeditan blok Markdown, serta ekspor PNG dan SVG gratis. Alat Pro (ekspor PDF, Export All Diagrams in Workspace, dan Export on Save) masing-masing bisa dicoba 3 kali gratis. Setelah itu alat-alat ini memerlukan Zovo Pro, USD 19 sekali bayar untuk semua ekstensi Zovo.

Mengapa blok mermaid saya tidak tampil di pratinjau Markdown VS Code?

Pratinjau Markdown bawaan VS Code tidak menggambar Mermaid. Mermaid Viewer membuka panel pratinjaunya sendiri untuk file Markdown, dengan zoom dan ekspor untuk setiap diagram.

Apakah perlu akun atau internet?

Tidak. Mermaid 12.3.0 sudah disertakan, tidak ada sign-in dan tidak ada AI, dan pratinjau memblokir setiap permintaan jaringan.

Apakah bisa dipakai di Cursor?

Bisa. Ekstensi ini ada di Open VSX sebagai zovo/mermaid-viewer, jadi Cursor, Windsurf, dan VSCodium bisa memasangnya.
