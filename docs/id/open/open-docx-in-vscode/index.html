Membuka file Word (.docx) di VS Code

Pasang DOCX Viewer, lalu klik file .docx di Explorer: file langsung terbuka sebagai pratinjau hanya-baca di tab VS Code, juga dalam tema gelap. Anda bisa mencari teks, melompat ke heading lewat outline, serta melihat tracked changes dan komentar, semuanya gratis dan tanpa Office. Zovo Pro (USD 19 sekali bayar) menambahkan alat ekspor seperti Export Redline as Word, dengan 3 kali percobaan gratis untuk setiap alat.

Pasang di VS CodeHalaman MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

Gratis, lisensi MIT. Extension ID zovo.docx-viewer-vscode.

Langkah di VS Code

  1. Pasang DOCX Viewer dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.docx-viewer-vscode.
  2. Klik file .docx, .dotx, .docm, .odt, atau .ott di Explorer. File terbuka sebagai pratinjau hanya-baca. File .doc dan .dot lama terbuka sebagai teks.
  3. Tekan Ctrl+F (Cmd+F di macOS) untuk mencari. Enter melompat ke hasil berikutnya, Shift+Enter ke hasil sebelumnya, dan Esc menghapus pencarian.
  4. Gunakan outline untuk melompat ke heading. Klik "Page view" di toolbar untuk melihat ukuran halaman, margin, header, dan footer; "Reading view" menampilkan teks seperti halaman web yang rapi.
  5. Jika dokumen berisi tracked changes atau komentar, sebuah bilah di bagian atas Reading view menghitungnya. Pilih Markup, Final, atau Original. Arahkan kursor ke sebuah perubahan untuk melihat siapa yang membuatnya dan kapan.
  6. Pilih "Copy as Markdown" untuk menyalin seluruh dokumen sebagai Markdown, misalnya untuk issue, wiki, atau chat.
  7. Untuk melihat apa yang berubah di antara dua versi, klik kanan file lalu pilih "Compare with Git HEAD" atau "Compare Documents (Redline)...".

Di Cursor, Windsurf, dan VSCodium

Editor ini memasang ekstensi dari Open VSX. Buka tampilan Extensions (Ctrl+Shift+X), cari zovo.docx-viewer-vscode, lalu klik Install. Halamannya di Open VSX adalah zovo/docx-viewer-vscode. Setelah itu cara pakainya sama seperti di VS Code.

Yang gratis

Reading view dan Page view, pencarian, outline, rumus matematika dan grafik, tracked changes dan komentar, Copy as Markdown, Open as Text, serta perbandingan dengan Git HEAD atau dokumen lain (sebagai redline di layar atau diff Markdown) semuanya gratis. Viewer memuat ulang file saat file berubah di disk, misalnya ketika script atau AI agent menyimpannya. Semuanya berjalan offline, tanpa akun dan tanpa telemetri.

Yang ditambahkan Zovo Pro

Export Redline as Word membandingkan dokumen ini dengan versi lain, lalu menulis file .docx baru berdasarkan versi yang lebih baru, dengan setiap perbedaan dicatat sebagai tracked change atas nama "Compare". Kedua dokumen asli tidak diubah. Ini menghemat banyak waktu ketika Anda harus membandingkan dua versi kontrak atau spesifikasi. Alat Pro lain di DOCX Viewer adalah Export Redline as PDF, Export Change List of a Comparison (daftar bernomor semua perubahan dalam Excel, CSV, dan Markdown), dan Compare Two Folders of Documents.

Cara memakai Export Redline as Word

  1. Klik kanan dokumen Word di Explorer lalu pilih "Zovo Pro: Export Redline as Word", atau jalankan "Export Redline as Word (Pro)..." dari Command Palette.
  2. Pilih versi lain dari dokumen tersebut.
  3. Tentukan lokasi file .docx baru, lalu simpan.

Export Redline as Word bisa dipakai 3 kali gratis sebelum meminta lisensi. Tidak ada popup saat file dibuka dan tidak ada hitung mundur.

Bayar dengan kartu, USD 19 sekali

Zovo Pro seharga USD 19 sekali bayar. Bukan langganan, dan lisensinya membuka alat Pro di semua ekstensi Zovo. Setelah membayar dengan kartu (Stripe), kunci lisensi muncul di halaman berikutnya. Di VS Code, jalankan "Enter Zovo Pro license key" dari Command Palette lalu tempel kuncinya. Kunci diperiksa di komputer Anda, tanpa koneksi jaringan.

Lisensi untuk tim berisi 5 orang seharga USD 59 sekali bayar, juga bisa dengan kartu. Semua aturan dan alat Pro ada di halaman Zovo Pro (bahasa Inggris).

Yang tidak bisa dilakukan

  • DOCX Viewer hanya penampil: tidak bisa mengedit atau menyimpan dokumen.
  • File .doc lama hanya menampilkan teks, tanpa format, gambar, atau tata letak. File .rtf tidak dibuka, kecuali jika namanya berakhiran .doc.
  • Page view tidak menampilkan tracked changes atau komentar, dan SmartArt tidak ditampilkan.
  • Redline hanya membandingkan teks utama dan tabel, dan ekspor ke Word memerlukan file Word sebagai versi yang lebih baru.

Pertanyaan

Apakah DOCX Viewer gratis?

Ya. Membaca, mencari, dan membandingkan di layar gratis dan akan tetap gratis. Empat alat ekspor dan perbandingan termasuk Zovo Pro. Masing-masing bisa dicoba 3 kali secara gratis; setelah itu Zovo Pro seharga USD 19 sekali bayar untuk semua ekstensi Zovo.

Apakah DOCX Viewer bisa dipakai di Cursor?

Bisa. Ekstensi ini juga tersedia di Open VSX, jadi di Cursor Anda cukup memasangnya dari panel Extensions.

Bisakah saya mengedit dokumen?

Tidak. DOCX Viewer hanya membuka file untuk dibaca dan tidak menerima atau menolak perubahan di dalam file. "Open in Default App" membuka file di Word, Pages, atau LibreOffice.

Apakah bisa dipakai di vscode.dev?

Bisa. Di vscode.dev dan github.dev Anda bisa membaca file .docx tanpa meng-clone repositori. "Compare with Git HEAD", "Open in Default App", dan redline tidak tersedia di sana.

Semua fitur dan pengaturan ada di halaman DOCX Viewer (bahasa Inggris).
