Format skrip bash atau zsh di VS Code

Pasang ekstensi gratis Shell Formatter for Bash & Zsh, buka sebuah shell script, lalu tekan Shift+Alt+F (Shift+Option+F di Mac). Engine shfmt 3.14.1 sudah ada di dalam ekstensi sebagai WebAssembly, jadi tidak ada yang perlu diunduh, dan hasilnya sama persis dengan baris perintah shfmt sampai ke byte-nya. Format Document, Format Selection, format saat menyimpan, key .editorconfig, dan error sintaks di Problems gratis dan bekerja offline. Zovo Pro (USD 19 sekali bayar) menambahkan tiga alat, Format All Shell Scripts in a Folder, Formatting Check with a Patch File, dan Minify a Script to a Copy, dan masing-masing bisa dicoba 3 kali gratis.

Langkah di VS Code

  1. Pasang Shell Formatter for Bash & Zsh dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.zovo-shell-formatter.
  2. Buka sebuah shell script lalu tekan Shift+Alt+F (Shift+Option+F di Mac). Jika VS Code menanyakan formatter yang dipakai, pilih Shell Formatter, atau jalankan "Shell Formatter: Use as Default Formatter for Shell Scripts".
  3. Untuk memformat setiap kali menyimpan, jalankan "Shell Formatter: Turn On Format on Save for Shell Scripts".
  4. Dialek diambil dari baris pertama (#!/bin/bash, #!/bin/sh, #!/usr/bin/env zsh), lalu dari nama file (.bash, .zsh, .zshrc, .bats, .ksh), jika tidak ada maka bash. Atur shellFormatter.dialect atau shell_variant di .editorconfig untuk memilihnya sendiri.
  5. Klik shfmt 3.14.1 di status bar untuk membuka menu: format, jadikan default, format saat menyimpan, "Copy the matching shfmt command (for CI)", dan pengaturan.
  6. Jika skripnya bukan shell yang valid, skrip tidak diubah dan panel Problems menampilkan baris dan kolomnya.

Yang gratis dan yang ditambahkan Zovo Pro

Format Document, Format Selection, format saat menyimpan, deteksi dialek, key .editorconfig, menu status bar, Copy the Matching shfmt Command (for CI), dan error sintaks di Problems gratis. Tanpa sign-in, tanpa permintaan jaringan, dan tanpa telemetri.

Format All Shell Scripts in a Folder memeriksa setiap skrip di sebuah folder beserta subfoldernya, yang dikenali dari nama atau dari baris #! yang menyebut sebuah shell, lalu memberi tahu berapa yang akan berubah. Setelah itu alat ini memformat semuanya atau memberikan laporan Markdown, dengan engine, pengaturan, dan .editorconfig yang sama dengan Format Document. Repositori dengan puluhan skrip bergaya berbeda mendapat satu gaya dalam satu kali jalan, dan skrip yang tidak akan menjalankan perintah yang sama dibiarkan apa adanya.

Cara memakai Format All Shell Scripts in a Folder (Zovo Pro)

  1. Klik kanan sebuah folder di Explorer lalu pilih "Zovo Pro: Format All Shell Scripts in a Folder", atau jalankan "Shell Formatter: Format All Shell Scripts in a Folder (Pro)" dari Command Palette atau dari menu status bar, lalu pilih foldernya.
  2. Judul daftar berikutnya menunjukkan berapa skrip yang akan berubah, misalnya "N of M scripts would change".
  3. Pilih "Format N scripts" untuk memformat dan menyimpan setiap file (Undo berlaku per file), atau "Show the report only" untuk daftar Markdown semua skrip tanpa ada yang diubah.
  4. Percobaan hanya dihitung jika Anda mendapat hasil. Folder tanpa shell script, atau dengan semua skrip yang sudah terformat, tidak memakai percobaan.

Format All Shell Scripts in a Folder bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.zovo-shell-formatter lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/zovo-shell-formatter.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan Shell Formatter for Bash & Zsh

  • Skrip Bash, POSIX sh (juga dash dan ash), mksh (juga ksh), bats, dan zsh.
  • Hasil yang sama dengan shfmt 3.14.1 di baris perintah: 354 dari 354 run pada 178 skrip nyata dari proyek GitHub dan Homebrew cocok sampai ke byte-nya.
  • Sebelum perubahan diterapkan, skrip yang sudah diformat di-parse lagi dan harus menjalankan perintah yang sama dengan aslinya (file sampai 256 KB).
  • Opsi shfmt sebagai pengaturan atau key .editorconfig: indent, operator biner di baris berikutnya, indent case di switch, spasi pada redirect, keep padding, kurung kurawal fungsi di baris berikutnya, simplify, dan minify.
  • Akhir baris Windows (CRLF) tetap CRLF, dan skrip 2 MB diformat dalam sekitar 0,2 detik.

Yang tidak bisa dilakukan

  • Ekstensi ini tidak pernah menyentuh Dockerfile, file .env, atau skrip fish dan csh.
  • Dukungan zsh di shfmt masih baru. Skrip zsh yang tidak bisa di-parse shfmt dibiarkan tidak berubah.
  • File di atas 10 MB (pengaturan shellFormatter.maxFileMB) dan file dengan byte biner, seperti installer yang mengekstrak dirinya sendiri, tidak diformat.
  • shfmt berjalan dengan batas waktu (10 detik secara default, pengaturan shellFormatter.timeoutSeconds). Jika batas itu tercapai, file tidak berubah.

Pertanyaan umum

Apakah gratis?

Format Document, Format Selection, format saat menyimpan, dan dukungan .editorconfig gratis. Tiga alat Pro, Format All Shell Scripts in a Folder, Formatting Check with a Patch File, dan Minify a Script to a Copy, masing-masing bisa dicoba 3 kali gratis. Setelah itu alat tersebut memerlukan Zovo Pro, USD 19 sekali bayar untuk semua ekstensi Zovo.

Apakah saya perlu memasang shfmt?

Tidak. shfmt 3.14.1 sudah ada di dalam ekstensi sebagai WebAssembly, jadi bekerja offline tanpa ada yang perlu diunduh.

Apakah skrip saya bisa rusak?

Skrip dengan error sintaks dibiarkan tidak berubah. Sebelum perubahan diterapkan, skrip yang sudah diformat di-parse lagi dan harus menjalankan perintah yang sama dengan aslinya.

Apakah bisa dipakai di Cursor?

Bisa. Cursor, Windsurf, dan VSCodium memasangnya dari Open VSX, tempat ekstensi ini diterbitkan sebagai zovo/zovo-shell-formatter.
