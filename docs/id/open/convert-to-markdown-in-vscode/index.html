Langkah di VS Code

  1. Pasang Convert to Markdown dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.zovo-convert-to-markdown.
  2. Di Explorer, klik kanan file .pdf, .docx, .pptx, .xlsx, .xls, .ods, .csv, .tsv, .html, .epub, .odt, atau .rtf, lalu pilih Convert to Markdown. Anda juga bisa mengklik kanan tab file yang sedang terbuka.
  3. Atau jalankan "Convert to Markdown: Convert to Markdown" dari Command Palette. Perintah ini mengonversi file di tab aktif, atau meminta Anda memilih file.
  4. Markdown terbuka di samping file sebagai dokumen yang belum disimpan. Untuk file besar, progres tampil dengan tombol Cancel.
  5. Tekan Save. Nama name.md di sebelah file sumber sudah terisi. Agar hasilnya selalu langsung disimpan di sana, atur toMarkdown.output ke file.
  6. Untuk menempelkan Markdown di tempat lain, klik kanan file lalu pilih Copy as Markdown. Pilih beberapa file di Explorer untuk mengonversinya satu per satu.
  7. Tidak punya file untuk dicoba? Jalankan "Convert to Markdown: Convert a sample file" dari Command Palette untuk mengonversi contoh Word, PDF, atau PowerPoint yang disertakan.

Yang gratis dan yang ditambahkan Zovo Pro

Convert to Markdown dan Copy as Markdown gratis untuk semua format: PDF, Word, PowerPoint, Excel, ODS, CSV, TSV, HTML, EPUB, ODT, dan RTF. Anda tidak perlu memasang apa pun lagi, tanpa Python, tanpa server, dan tanpa alat baris perintah. Tidak ada data yang meninggalkan komputer Anda.

Convert a Folder to Markdown mengonversi setiap file yang didukung di sebuah folder beserta subfoldernya menjadi file .md dalam satu kali jalan, ke folder baru dengan struktur yang sama atau di samping setiap file, dengan progres dan tombol Cancel. Anda memilih apakah file .md yang sudah ada dilewati atau ditimpa, dan _conversion-report.md mencantumkan setiap file sebagai berhasil dikonversi, dilewati, atau gagal. File dengan nama yang sama menyimpan jenisnya di nama baru (report.pdf.md, report.docx.md), sehingga tidak ada yang hilang.

Cara memakai Convert a Folder to Markdown (Zovo Pro)

  1. Klik kanan sebuah folder di Explorer lalu pilih "Zovo Pro: Convert a Folder to Markdown", atau jalankan "Convert to Markdown: Convert a Folder to Markdown (Pro)" dari Command Palette dan pilih foldernya.
  2. Pilih tujuan file .md: "Into a new folder" (nama folder ditambah -markdown, dengan subfolder yang sama), "Next to each file", atau "Pick another folder...".
  3. Jika ada file .md yang sudah ada, pilih Skip atau Overwrite. Sebuah notifikasi menampilkan progres dengan tombol Cancel.
  4. Di akhir, _conversion-report.md terbuka. File ini mencantumkan setiap file sebagai berhasil dikonversi, dilewati, atau gagal, dengan tautan ke setiap file Markdown baru.

Convert a Folder to Markdown bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.zovo-convert-to-markdown lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/zovo-convert-to-markdown.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan Convert to Markdown

  • PDF: heading dari ukuran huruf, paragraf dengan baris terputus dan kata bertanda hubung yang digabung kembali, daftar, tabel sederhana, dan halaman dua kolom yang dibaca per kolom. Header, footer, dan nomor halaman yang berulang dibuang.
  • Word (.docx, .docm, .dotx): heading, tebal, miring, coret, tautan, daftar bersarang, tabel, kutipan blok, dan catatan kaki.
  • PowerPoint (.pptx, .pptm, .ppsx, .potx): satu bagian ## Slide n: title per slide, dengan bullet beserta levelnya, tabel, dan catatan pembicara.
  • Excel dan spreadsheet lain (.xlsx, .xlsm, .xlsb, .xls, .ods): satu bagian ## Sheet: name dengan tabel pipe per sheet. CSV dan TSV menjadi satu tabel.
  • HTML (.html, .htm, .xhtml), dengan blok kode yang tetap menyimpan bahasanya serta script dan style yang dibuang, dan EPUB, dengan setiap bab sesuai urutan baca.

Yang tidak bisa dilakukan

  • PDF hasil pindai (gambar halaman) tidak berisi teks yang bisa dikonversi. Pengenalan teks (OCR) tidak disertakan.
  • Tabel PDF dikenali dari celah di antara kolom. Tabel tanpa celah yang jelas menjadi paragraf.
  • Pada konversi gratis, gambar menjadi placeholder seperti *[Image: Map of the site]*. Chart, SmartArt, dan video di slide hanya disebut namanya, tidak dikonversi.
  • File Word 97-2003 lama dan RTF menghasilkan teks dan tabel tanpa format. File yang dilindungi password dan file PowerPoint 97-2003 lama mendapat pesan, bukan hasil konversi.
  • File di atas 200 MB tidak dikonversi (pengaturan toMarkdown.maxFileSizeMB), dan konversi PDF berhenti setelah 1.000 halaman (pengaturan toMarkdown.pdfMaxPages).
