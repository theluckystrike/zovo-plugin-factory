Format HTML dan CSS di VS Code tanpa merusak blok pre atau tag inline

Pasang ekstensi gratis HTML Formatter & CSS Formatter lalu tekan Shift+Alt+F di file HTML, CSS, SCSS, atau LESS. Ekstensi ini juga memformat blok <style> dan <script> di dalam halaman, mengikuti .editorconfig Anda, membiarkan <pre>, <textarea>, dan tag inline seperti yang Anda tulis, dan tidak pernah mengubah urutan atribut. Ekstensi berjalan offline dengan js-beautify yang sudah dibundel, jadi tidak perlu Node, npm, atau file konfigurasi. Zovo Pro (USD 19 sekali bayar) menambahkan tiga alat, yaitu Format Folder with Diff Preview, Minify HTML and CSS, dan HTML Lint Report, dan masing-masing bisa dicoba gratis 3 kali.

Langkah di VS Code

  1. Pasang HTML Formatter & CSS Formatter dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.zovo-html-formatter.
  2. Buka file HTML, CSS, SCSS, atau LESS dan tekan Shift+Alt+F (Shift+Option+F di macOS). Jika VS Code menanyakan formatter mana yang dipakai, pilih HTML Formatter & CSS Formatter.
  3. Untuk menjadikannya formatter bawaan bagi keempat bahasa dalam satu langkah, jalankan "HTML Formatter: Use as Default Formatter for HTML, CSS, SCSS and LESS" dari Command Palette.
  4. Pilih beberapa baris lalu jalankan Format Selection untuk memformat baris itu saja.
  5. Untuk memformat setiap kali menyimpan, aktifkan zovoHtmlFormat.formatOnSave, atau pakai editor.formatOnSave milik VS Code sendiri setelah ekstensi ini menjadi formatter bawaan.
  6. Indentasi diambil dari editor, lalu dari .editorconfig (gaya dan ukuran indentasi, akhir baris, baris baru di akhir file, panjang baris maksimum), sehingga seluruh tim mendapat hasil yang sama.

Yang gratis dan yang ditambahkan Zovo Pro

Format Document, Format Selection, dan format saat menyimpan untuk HTML, CSS, SCSS, dan LESS, dengan dukungan .editorconfig, semuanya gratis, tanpa login, tanpa permintaan jaringan, dan tanpa telemetri.

Saat seluruh situs perlu satu gaya, Format Folder with Diff Preview memformat semua file HTML, CSS, SCSS, dan LESS dalam satu folder di memori, menampilkan file yang berubah dengan diff berdampingan untuk masing-masing file, dan hanya menulis file yang tetap Anda centang. Anda melihat setiap perubahan sebelum file ditulis.

Cara memakai Format Folder with Diff Preview (Zovo Pro)

  1. Klik kanan sebuah folder di Explorer dan pilih "Zovo Pro: Format folder with diff preview", atau jalankan "HTML Formatter: Format Folder with Diff Preview (Pro)" dari Command Palette.
  2. Periksa file yang berubah. Buka diff file mana pun dan hapus centang file yang ingin Anda biarkan apa adanya.
  3. Tulis file yang dicentang. Satu percobaan hanya dihitung jika alat memberikan hasil.

Format Folder with Diff Preview bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.zovo-html-formatter lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/zovo-html-formatter.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan HTML Formatter & CSS Formatter

  • CSS di dalam <style> dan JavaScript di dalam <script> pada HTML.
  • Tetap seperti yang ditulis: isi <pre> dan <textarea>, tag inline di barisnya, urutan atribut, baris kosong antar blok (paling banyak satu berturut-turut), gaya indentasi head dan body halaman, dan tag template seperti {{ }} dan {% %}.
  • Di SCSS dan LESS, map dan pemanggilan fungsi multi-baris tetap pada tata letaknya, dan komentar di akhir baris tetap di barisnya.
  • Dua alat Pro lainnya. Minify HTML and CSS menulis salinan .min.html dan .min.css dengan laporan byte dan byte gzip yang dihemat. HTML Lint Report menemukan gambar tanpa teks alt, field form tanpa label, id duplikat, level heading yang terlewat, dan masalah lain, dalam laporan Markdown dan panel Problems.

Yang tidak bisa dilakukan

  • File .js, .jsx, .ts, Vue, dan Svelte yang berdiri sendiri tidak diformat oleh ekstensi ini. Hanya JavaScript di dalam <script> yang diformat.
  • Baris tidak dipatahkan kecuali Anda mengatur panjang wrap, jadi baris yang sangat panjang tetap panjang.
  • SCSS dan LESS diproses oleh formatter CSS. Sintaks yang tidak umum seperti detached ruleset LESS bisa tetap memakai spasi aslinya.
  • Minify tidak memperpendek JavaScript dan tidak mengganti nama atau menggabungkan rule CSS.

Pertanyaan umum

Apakah gratis?

Format Document, Format Selection, dan format saat menyimpan untuk HTML, CSS, SCSS, dan LESS gratis. Tiga alat Pro, yaitu Format Folder with Diff Preview, Minify HTML and CSS, dan HTML Lint Report, masing-masing bisa dicoba gratis 3 kali. Setelah itu perlu Zovo Pro, USD 19 sekali bayar untuk semua ekstensi Zovo.

Apakah VS Code bisa memformat HTML tanpa ekstensi?

Bisa. VS Code punya formatter HTML dan CSS bawaan. Ekstensi ini membaca .editorconfig, menjaga indentasi head dan body milik halaman, menjaga tata letak map SCSS dan LESS, dan menambahkan alat Pro untuk folder, minify, dan lint.

Apakah blok pre saya akan berubah atau atribut diurutkan ulang?

Tidak. Isi pre dan textarea, tag inline, dan urutan atribut tetap seperti yang Anda tulis.

Apakah perlu Node atau npm?

Tidak. js-beautify 1.15.4 sudah dibundel di dalam ekstensi dan berjalan offline.
