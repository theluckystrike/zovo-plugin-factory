Langkah di VS Code

  1. Pasang 3D Model Viewer dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.3d-model-viewer.
  2. Klik file .stl, .obj, .ply, .3mf, .glb, atau .gltf di Explorer. Jika viewer lain yang terbuka, klik kanan file lalu pilih “Open in 3D Model Viewer”.
  3. Seret untuk memutar, seret dengan tombol kanan atau Shift-seret untuk menggeser, dan gulir untuk zoom. Tekan F agar seluruh model muat di tampilan.
  4. Baca panel untuk jumlah vertex, segitiga, material, tekstur, dan ukuran dalam satuan model. Tekan P untuk menampilkan atau menyembunyikan panel dan pohon scene.
  5. Tekan W untuk wireframe, N untuk vertex normal, dan B untuk bounding box. Atur Shading ke Smooth untuk menghilangkan tampilan bersegi pada file STL.
  6. Tekan M (Measure) lalu klik dua titik di permukaan. Garisnya menampilkan jarak, dan bilah status menambahkan komponen X, Y, dan Z. Esc menghentikannya.
  7. Klik Screenshot untuk menyimpan tampilan sebagai file PNG.

Yang gratis dan yang ditambahkan Zovo Pro

Membuka keenam format, orbit, geser dan zoom, panel statistik, pohon scene, Measure, wireframe, normal, bounding box, grid, sumbu, animasi glTF, dan screenshot PNG gratis. Ekstensi ini berjalan offline dan tidak melakukan panggilan jaringan.

Print check memberi ukuran, volume, dan luas permukaan model, lalu memeriksa apakah mesh kedap air (watertight): tepi terbuka, tepi non-manifold, face yang menghadap ke arah yang salah, segitiga dengan luas nol, dan jumlah bagian yang terpisah. Mark problems menggambar tepi yang bermasalah di model. Dengan material, infill, ketebalan dinding, diameter filamen, dan harga per kg, alat ini memperkirakan berat, panjang filamen, dan biaya material sebelum Anda membuka slicer.

Cara memakai Print check (Zovo Pro)

  1. Buka file STL di 3D Model Viewer.
  2. Tekan “Run print check” di panel samping, atau jalankan “3D Model Viewer: Print Check (Zovo Pro)” dari Command Palette. Anda juga bisa mengklik kanan file di Explorer dan memilih “Zovo Pro: Print check”.
  3. Jika mesh bermasalah, tekan “Mark problems” untuk melihat tepi terbuka berwarna merah dan tepi bermasalah lainnya berwarna magenta. Pilih material (PLA, PETG, ABS, ASA, TPU, nylon, PC, atau resin), infill, dan harga per kg Anda.
  4. Salin laporannya, atau simpan sebagai Markdown atau JSON. Satu percobaan gratis berlaku untuk satu tab file yang terbuka, jadi Anda bisa mengubah pengaturan dan menjalankannya lagi di tab itu.

Print check bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.3d-model-viewer lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/3d-model-viewer.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan 3D Model Viewer

  • STL, biner dan ASCII, dengan warna per face jika file memilikinya.
  • OBJ dengan file .mtl yang disebut oleh mtllib, jika file itu ada di sebelah model.
  • Mesh dan point cloud PLY, ASCII dan biner, dengan warna vertex.
  • Objek 3MF, build item, dan warna base material.
  • GLB dan glTF 2.0 dengan buffer .bin dan tekstur yang tertanam atau terpisah, material PBR, pohon node, skin, morph target, dan animasi.

Yang tidak bisa dilakukan

  • File FBX, DAE, USD, STEP, IGES, dan glTF 1.0 tidak terbuka.
  • glTF yang dikompresi dengan Draco dan meshopt serta tekstur KTX2 belum didekode. Pesan yang muncul menyebutkan ekstensi yang belum didukung.
  • Seluruh file dibaca ke memori. File di atas 1024 MB (pengaturan modelViewer.maxFileMB) menampilkan pesan dan tidak dibaca.
  • STL, OBJ, dan PLY tidak punya satuan, jadi ukuran dan jarak adalah koordinat mentah. glTF dalam meter dan 3MF dalam milimeter, kecuali file menyebutkan lain.
  • Print check dan Section view membaca mesh yang terlihat, hingga 3 juta segitiga, dan memerlukan mesh, bukan point cloud. Beratnya adalah perkiraan. Support, brim, serta lapisan atas dan bawah tidak dihitung.

Pertanyaan umum

Ukuran STL dalam satuan apa?

File STL tidak membawa satuan, jadi viewer menampilkan koordinat mentah. Print check membaca STL, OBJ, dan PLY sebagai milimeter, dan Anda bisa mengubah satuannya di panel Print check jika file Anda memakai satuan lain.

Apakah bisa membuka file OBJ dengan material?

Bisa, jika file .mtl yang disebut oleh mtllib ada di sebelah model. Tekstur dan file .bin hanya dimuat dari folder model dan folder workspace yang terbuka.

Apakah ini gratis?

Ya. Membuka model, mengukur, statistik, pohon scene, dan screenshot gratis. Print check, Section view, dan Turntable export adalah alat Zovo Pro dengan 3 kali percobaan gratis masing-masing, lalu USD 19 sekali bayar untuk semua ekstensi Zovo.

Apakah bisa dipakai offline?

Bisa. Ekstensi ini menggambar dengan three.js di dalam VS Code, tanpa telemetri dan tanpa panggilan jaringan. Satu-satunya pengecualian adalah panggilan ke GitHub saat Anda mengaktifkan Zovo Pro dengan GitHub Sponsors.
