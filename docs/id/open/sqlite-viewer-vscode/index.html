Membuka database SQLite di VS Code

Pasang SQLite Viewer & Editor yang gratis lalu klik file .db, .sqlite, atau .sqlite3. Setiap tabel terbuka sebagai grid dalam mode baca-saja, dengan tab Schema dan SQL hanya satu klik jauhnya. Ekstensi ini juga membaca baris yang sudah di-commit tetapi masih ada di file -wal. Melihat data, mengedit setelah Anda mengklik Enable editing, Save dengan cadangan, dan impor CSV gratis. Zovo Pro (USD 19 sekali bayar) menambahkan perbandingan database, diagram ER, dan ekspor semua tabel sekaligus, masing-masing dengan 3 kali percobaan gratis.

Langkah di VS Code

  1. Pasang SQLite DB Viewer dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.sqlite-table-viewer.
  2. Klik file .db, .sqlite, .sqlite3, .db3, .s3db, .sl3, .vscdb, atau .gpkg di Explorer. File terbuka sebagai tabel, dalam mode baca-saja.
  3. Pilih tabel atau view di sebelah kiri. Klik judul kolom untuk mengurutkan, ketik di bawah judul kolom untuk memfilter (misalnya 5..9 atau =word), atau cari di semua kolom sekaligus.
  4. Buka tab Schema untuk melihat kolom, key, foreign key, dan pernyataan CREATE, atau tab SQL untuk menjalankan satu pernyataan setiap kali. 20 pernyataan terakhir disimpan.
  5. Untuk mengubah data, klik Enable editing. Klik dua kali sebuah sel, ketik nilai baru, lalu tekan Enter. Setiap perubahan menunggu di daftar pending, lengkap dengan SQL-nya dan tombol Undo.
  6. Tekan Save (Ctrl+S, atau Cmd+S di macOS). Save memeriksa constraint, membuat salinan cadangan seperti name.db.20261109-143000.bak, lalu mengganti file dalam satu langkah.

Yang gratis dan yang ditambahkan Zovo Pro

Membuka dan membaca, tab SQL, mengedit sel dan baris, Save dengan cadangan, impor CSV dan TSV, alat tabel, dan ekspor baris yang sedang tampil gratis. Tidak ada akun dan tidak ada batas waktu uji coba.

Alat ini menulis setiap tabel database dalam satu kali jalan, sebagai satu workbook Excel (.xlsx) dengan satu sheet per tabel dan baris judul yang tebal dan dibekukan, atau sebagai folder berisi satu file CSV per tabel. Export versi gratis hanya menyimpan baris yang sedang tampil dari satu tabel, jadi dengan alat ini Anda tidak perlu mengekspor tabel satu per satu. Alat ini hanya membaca database dan tidak pernah menulis ke dalamnya.

Cara memakai Export All SQLite Tables to Excel or CSV (Zovo Pro)

  1. Saat database terbuka, klik tombol DB tools (dengan lencana PRO kecil) di toolbar editor, atau klik alatnya di baris “Pro tools” di bawah toolbar.
  2. Atau klik kanan file database di Explorer dan pilih “Zovo Pro: Export All Tables to Excel or CSV”, atau jalankan “Export All SQLite Tables to Excel or CSV (Pro)…” dari Command Palette.
  3. Pilih “Excel workbook (.xlsx)” atau “CSV files in a folder”, lalu tentukan lokasi penyimpanan. Percobaan baru dihitung saat file selesai ditulis, dan Escape tidak memakai percobaan.

Export All SQLite Tables to Excel or CSV bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.sqlite-table-viewer lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/sqlite-table-viewer.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan SQLite DB Viewer

  • Baris yang sudah di-commit tetapi masih ada di file -wal, dengan muat ulang langsung saat aplikasi Anda menulis (tombol Live mematikannya).
  • Sel JSON sebagai pohon, gambar sebagai gambar, dan BLOB float32 sebagai vektor di panel sel.
  • Salin sebagai CSV, TSV, JSON, atau pernyataan INSERT, serta Export baris yang tampil sebagai CSV, JSON, atau pernyataan SQL INSERT.
  • Impor CSV dan TSV ke tabel baru atau tabel yang sudah ada, dengan pratinjau, pemetaan kolom, progress bar, dan Cancel.
  • Database hingga 512 MB, dengan baris yang diambil satu halaman setiap kali.

Yang tidak bisa dilakukan

  • Seluruh database dimuat ke memori. File di atas 512 MB menampilkan pesan (pengaturan sqliteTableViewer.maxFileSizeMB).
  • Pengeditan dibatasi untuk file hingga 256 MB (pengaturan sqliteTableViewer.editMaxFileSizeMB). File yang lebih besar tetap baca-saja.
  • Database terenkripsi (SQLCipher, SEE) tidak bisa dibuka.
  • Pengeditan hanya bisa untuk file di komputer ini. File di file system remote atau virtual terbuka dalam mode baca-saja.
  • Perubahan yang belum disimpan hilang saat Anda menutup tab, dan file tetap seperti semula.

Pertanyaan umum

Apakah ini gratis?

Membuka, melihat, tab SQL, mengedit, Save, dan impor CSV gratis, tanpa akun. Tiga alat Pro (Compare SQLite Databases, ER Diagram, dan Export All Tables) masing-masing bisa dicoba 3 kali gratis. Setelah itu alat-alat ini memerlukan Zovo Pro, USD 19 sekali bayar untuk semua ekstensi Zovo.

Bisakah saya mengedit baris di VS Code?

Bisa. File terbuka dalam mode baca-saja, lalu Anda klik Enable editing untuk mengubah sel dan baris atau menjalankan INSERT dan UPDATE. Tidak ada yang ditulis sampai Anda menekan Save, yang lebih dulu membuat salinan cadangan.

Mengapa viewer lain menampilkan baris lama?

Dalam mode WAL, commit baru berada di file -wal sampai checkpoint menyalinnya ke file utama. Viewer yang hanya membaca file utama tidak melihatnya. Ekstensi ini membaca bagian file -wal yang sudah di-commit.

Apakah bisa dipakai di Cursor?

Bisa. Ekstensi ini ada di Open VSX sebagai zovo/sqlite-table-viewer, jadi Cursor, Windsurf, dan VSCodium bisa memasangnya.
