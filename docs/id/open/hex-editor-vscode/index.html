Melihat dan mengedit file biner di VS Code

Pasang Hex Viewer, klik kanan file di Explorer, lalu pilih "Open in Hex Viewer". Melihat, mencari, menimpa, menyisipkan, dan menghapus byte, data inspector, serta membandingkan dua file semuanya gratis, bahkan untuk file berukuran beberapa gigabyte. Zovo Pro (USD 19 sekali bayar) menambahkan alat seperti checksum, bookmark, dan peta entropi, dengan 3 kali percobaan gratis untuk setiap alat.

Pasang di VS CodeHalaman MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

Gratis, lisensi MIT. Extension ID zovo.zovo-hex-viewer.

Langkah di VS Code

  1. Pasang Hex Viewer dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.zovo-hex-viewer.
  2. Klik kanan file di Explorer lalu pilih "Open in Hex Viewer". File berakhiran .bin, .dat, .img, .rom, .dmp, atau .dump langsung terbuka dengan klik biasa.
  3. Tekan Ctrl+G (Cmd+G di macOS) untuk melompat ke offset dalam format heksadesimal atau desimal, atau secara relatif dengan +0x100 atau -16. Dengan Ctrl+F Anda bisa mencari byte hex dengan wildcard ??, teks biasa, atau teks UTF-16.
  4. Ketik dua digit hex untuk menimpa satu byte, atau tekan Insert untuk menyisipkan byte. Delete, cut, dan paste bekerja pada seleksi apa pun, Ctrl+Z membatalkan setiap langkah, dan Ctrl+S menyimpan.
  5. Pilih dua file di Explorer, klik kanan, lalu pilih "Compare in Hex Viewer". Tekan F7 untuk melompat ke perbedaan berikutnya dan Shift+F7 ke perbedaan sebelumnya.
  6. Data inspector di sebelah kanan membaca byte di posisi kursor sebagai integer, float, cap waktu, atau GUID. Lewat "Copy as..." di toolbar, seleksi bisa disalin sebagai hex, C array, Python bytes, atau base64.

Di Cursor, Windsurf, dan VSCodium

Editor ini memasang ekstensi dari Open VSX. Buka tampilan Extensions (Ctrl+Shift+X), cari zovo.zovo-hex-viewer, lalu klik Install. Halamannya di Open VSX adalah zovo/zovo-hex-viewer. Setelah itu cara pakainya sama seperti di VS Code.

Yang gratis

Semua fitur di atas gratis dan akan tetap gratis: melihat file, melompat ke offset, mencari, Copy as, data inspector, mengedit dengan sisip dan hapus, penyimpanan aman, undo, dan membandingkan dua file. Level teratas tampilan Structure, dengan 26 template bawaan, juga gratis. File lokal sebesar apa pun langsung terbuka karena hanya baris yang tampil di layar yang dibaca; dalam uji rilis, file 4 GB terbuka dalam 0,6 detik. Ekstensi ini bekerja offline tanpa akun.

Yang ditambahkan Zovo Pro

Checksums of File menghitung CRC-32, Adler-32, MD5, SHA-1, SHA-256, dan SHA-512 sebuah file dalam satu kali baca, juga untuk file 4 GB, dan "Checksums of Selection or File" bisa melakukannya untuk byte yang diseleksi saja. Jadi Anda tidak perlu membuka terminal atau program lain untuk memeriksa file unduhan atau image firmware. Alat Pro lain di Hex Viewer adalah field bertingkat di tampilan Structure, bookmark dengan catatan, ekspor laporan perbandingan, Find Bytes in Files, Entropy and Byte Histogram, dan Extract Strings.

Cara memakai Checksums of File

  1. Klik kanan satu file atau lebih di Explorer lalu pilih "Zovo Pro: Checksums of File".
  2. Atau, di file yang sedang terbuka, seleksi byte lalu klik "Checksums..." di bawah data inspector, atau jalankan "Checksums of Selection or File" dari Command Palette.
  3. Pilih salah satu nilai di daftar untuk menyalinnya.

Checksums of File bisa dipakai 3 kali gratis sebelum meminta lisensi. Tidak ada popup saat file dibuka dan tidak ada hitung mundur.

Bayar dengan kartu, USD 19 sekali

Zovo Pro seharga USD 19 sekali bayar. Bukan langganan, dan lisensinya membuka alat Pro di semua ekstensi Zovo. Setelah membayar dengan kartu (Stripe), kunci lisensi muncul di halaman berikutnya. Di VS Code, jalankan "Enter Zovo Pro license key" dari Command Palette lalu tempel kuncinya. Kunci diperiksa di komputer Anda, tanpa koneksi jaringan.

Lisensi untuk tim berisi 5 orang seharga USD 59 sekali bayar, juga bisa dengan kartu. Semua aturan dan alat Pro ada di halaman Zovo Pro (bahasa Inggris).

Yang tidak bisa dilakukan

  • Hanya .bin, .dat, .img, .rom, .dmp, dan .dump yang otomatis terbuka di Hex Viewer; file lain dibuka dengan "Open in Hex Viewer". File Intel .hex terbuka di editor teks.
  • File di sistem file remote atau virtual bisa dibuka hingga 256 MB (pengaturan hexViewer.maxRemoteMB). File lokal tidak dibatasi ukurannya.
  • Copy as bekerja hingga 32 MB dan paste hingga 16 MB.
  • Perbandingan membaca file sesuai yang tersimpan di disk, jadi perubahan yang belum disimpan tidak ikut dibandingkan.

Pertanyaan

Apakah Hex Viewer gratis?

Ya. Melihat, mengedit, dan membandingkan file gratis. Tujuh fitur Pro, seperti checksum dan bookmark, bisa dicoba 3 kali secara gratis; setelah itu Zovo Pro seharga USD 19 sekali bayar untuk semua ekstensi Zovo.

Apakah Hex Viewer bisa dipakai di Cursor?

Bisa. Ekstensi ini juga tersedia di Open VSX, jadi di Cursor Anda cukup memasangnya dari panel Extensions.

Bisakah saya menyisipkan byte, tidak hanya menimpa?

Bisa. Tekan Insert untuk beralih antara mode timpa dan sisip. Menyisipkan atau menghapus byte di file 4 GB berlangsung seketika, karena sampai disimpan hanya daftar perubahan yang dicatat.

Apakah penyimpanannya aman?

Ya. Jika ukuran file tidak berubah, hanya byte yang diubah yang ditulis. Jika ukurannya berubah, Hex Viewer lebih dulu memeriksa ruang disk yang tersisa lalu menulis salinan baru, sehingga disk penuh atau crash tidak meninggalkan file yang setengah tertulis.

Semua fitur dan pengaturan ada di halaman Hex Viewer (bahasa Inggris).
