Membuka file PCAP di VS Code

Pasang PCAP Viewer yang gratis lalu klik file .pcap atau .pcapng. Ekstensi ini menampilkan daftar paket, pohon protokol, panel hex yang terhubung ke pohon, display filter gaya Wireshark, follow stream, dan statistik. File dibaca sendiri dengan JavaScript, jadi Anda tidak memerlukan Wireshark, tshark, atau sharkd. Viewer-nya gratis, dan Zovo Pro (USD 19 sekali bayar) menambahkan ekspor daftar paket ke CSV atau JSON, laporan capture dalam Markdown, dan ringkasan folder, dengan 3 kali percobaan gratis untuk setiap alat.

Langkah di VS Code

  1. Pasang PCAP Viewer dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.zovo-pcap-viewer.
  2. Klik file .pcap, .pcapng, .pcap.gz, .pcapng.gz, atau .ntar. Untuk .cap, .dmp, atau nama lain, klik kanan file di Explorer lalu pilih “Open in PCAP Viewer”.
  3. Ketik display filter seperti tcp.port == 443 && ip.addr == 10.0.0.1 lalu tekan Enter. Kotaknya menjadi hijau jika filter valid, dan menjelaskan kesalahannya jika tidak valid.
  4. Klik sebuah field di pohon protokol untuk menyorot byte-nya di panel hex, atau klik sebuah byte untuk menemukan field-nya.
  5. Klik dua kali sebuah paket untuk mengikuti stream TCP atau UDP-nya, sebagai ASCII, UTF-8, atau hex dump. Salin atau simpan ke file.
  6. Klik Statistics untuk melihat hierarki protokol, percakapan (conversations), endpoint, dan nama-nama yang ditemukan di capture. Klik sebuah baris untuk memfilter berdasarkan baris itu.
  7. Buka menu Export untuk menyimpan paket yang dipilih, atau semua paket yang ditampilkan filter, sebagai file pcap baru.

Yang gratis dan yang ditambahkan Zovo Pro

Daftar paket, pohon protokol, panel hex yang terhubung, display filter, filter tersimpan, follow stream, statistik, dan ekspor paket sebagai file pcap baru gratis. Tidak perlu sign-in, dan semuanya berjalan offline.

Alat ini menulis paket yang ditampilkan filter ke file CSV atau JSON, satu baris per paket: nomor, waktu UTC, detik sejak awal, sumber, tujuan, port, protokol, panjang, filter stream, nama host dari capture, dan teks Info. CSV-nya bisa dibuka di Excel dengan teks yang mirip rumus sudah diamankan, dan JSON-nya bisa dipakai dengan jq dan pandas. Anda mendapatkan tabel untuk tiket atau skrip tanpa menyalin baris secara manual.

Cara memakai Export packet list to CSV or JSON (Zovo Pro)

  1. Buka capture dan ketik display filter jika Anda hanya ingin sebagian paket.
  2. Buka menu Export di toolbar lalu pilih “Packet list as CSV” atau “Packet list as JSON”, atau jalankan “PCAP Viewer: Export Packet List to CSV or JSON (Pro)...” dari Command Palette. Anda juga bisa mengklik kanan capture di Explorer dan memilih “Zovo Pro: Export packet list to CSV or JSON”.
  3. Tentukan lokasi penyimpanan file. Percobaan baru dihitung saat file selesai ditulis, jadi Escape atau galat tidak memakai apa pun.

Export packet list to CSV or JSON bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.zovo-pcap-viewer lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/zovo-pcap-viewer.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan PCAP Viewer

  • pcap (mikrodetik dan nanodetik, little-endian dan big-endian) dan pcapng, juga dalam bentuk .gz.
  • Ethernet, VLAN 802.1Q, Linux cooked capture (SLL dan SLL2), IPv4 dan IPv6 mentah, BSD loopback, header 802.11, dan radiotap.
  • ARP, IPv4, IPv6, ICMP, ICMPv6, TCP, UDP, DNS dan mDNS, DHCP, HTTP/1.x, record TLS dengan nama server (SNI) dan ALPN, serta long header QUIC.
  • Capture besar. Dalam pengujian rilis, capture 1 GB berisi 1.438.965 paket tercantum dalam sekitar 2 detik.
  • File yang rusak. Setiap paket sebelum bagian yang rusak tetap ditampilkan, dengan pesan yang menjelaskan apa yang salah dan di mana.

Yang tidak bisa dilakukan

  • Hanya protokol dalam daftar di atas yang didekode menjadi field. HTTP berarti HTTP/1.x, 802.11 hanya header-nya, dan QUIC hanya long header-nya.
  • Lalu lintas TLS tidak didekripsi. Yang ditampilkan adalah record TLS dengan nama server (SNI) dan ALPN.
  • Kotak filter menerima bagian umum dari sintaks display filter Wireshark, bukan seluruhnya.
  • Capture .gz berhenti dibongkar di 512 MB (pengaturan pcapViewer.maxGzipMB) dan memberi tahu hal itu.
  • File di file system remote atau virtual terbuka hingga 256 MB (pengaturan pcapViewer.maxRemoteMB).

Pertanyaan umum

Apakah Wireshark harus terpasang?

Tidak. PCAP Viewer membaca pcap dan pcapng dengan JavaScript di dalam VS Code, di Windows, macOS, dan Linux. Ekstensi ini tidak memakai Wireshark, tshark, atau sharkd.

Apakah membuka capture mengirim kueri DNS?

Tidak. Nama host hanya diambil dari jawaban DNS di dalam paket dan dari blok nama di file pcapng. Ekstensi ini tidak punya telemetri dan tidak membuat permintaan jaringan.

Apakah ini gratis?

Ya. Viewer, filter, follow stream, statistik, dan ekspor pcap gratis. Export packet list to CSV or JSON, Capture report, dan Folder summary adalah alat Zovo Pro dengan 3 kali percobaan gratis masing-masing, lalu USD 19 sekali bayar untuk semua ekstensi Zovo.

Apakah bisa dipakai di Cursor?

Bisa. Ekstensi ini berjalan di VS Code 1.90 dan yang lebih baru, serta di editor yang memasang ekstensi dari Open VSX, seperti Cursor, Windsurf, dan VSCodium.
