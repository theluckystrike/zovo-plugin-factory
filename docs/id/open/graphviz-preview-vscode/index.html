Pratinjau graf Graphviz DOT tanpa memasang Graphviz

Pasang Graphviz Viewer & DOT Viewer yang gratis, buka file .dot atau .gv, lalu klik ikon pratinjau. Graf digambar di samping editor dan digambar ulang saat Anda mengetik, dengan Graphviz 16.1 yang sudah ada di dalam ekstensi sebagai WebAssembly, jadi Anda tidak perlu memasang apa pun lagi. Pratinjau, enam engine layout, klik untuk melompat ke baris, dan ekspor SVG atau PNG gratis. Zovo Pro (USD 19 sekali bayar) menambahkan ekspor PDF vektor, ekspor semua graf di workspace, dan ekspor saat menyimpan, dengan 3 kali percobaan gratis masing-masing.

Langkah di VS Code

  1. Pasang Graphviz Viewer & DOT Viewer dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.zovo-graphviz-preview.
  2. Buka file .dot atau .gv. Klik ikon pratinjau di bilah judul editor, atau tekan Ctrl+K V (Cmd+K V di Mac). Graf terbuka di samping file.
  3. Edit file. Pratinjau digambar ulang 300 ms setelah Anda berhenti mengetik, tanpa perlu menyimpan. Galat sintaks digarisbawahi di barisnya dan dicantumkan di Problems, dan pratinjau tetap menampilkan gambar terakhir yang benar.
  4. Pilih dot, neato, fdp, sfdp, circo, atau twopi di toolbar. Dengan auto, atribut layout= dari graf yang dipakai, atau dot jika atribut itu tidak ada.
  5. Ketik di Find node untuk menyorot node yang nama atau labelnya cocok. Klik sebuah node, edge, atau cluster untuk menaruh kursor di barisnya di kode sumber.
  6. Klik SVG atau PNG untuk menyimpan graf. PNG disimpan pada 2x dengan latar putih, dalam warna Graphviz biasa.

Yang gratis dan yang ditambahkan Zovo Pro

Pratinjau langsung, keenam engine layout, galat di Problems, Find node, klik ke baris, geser dan zoom, ekspor SVG dan PNG dari graf yang terbuka, serta blok dot di pratinjau Markdown gratis. Tidak perlu sign-in, tidak ada panggilan jaringan, dan tidak ada telemetri.

Ekspor PDF menyimpan PDF vektor dari graf dengan teks yang tetap berupa teks, jadi tetap tajam di zoom berapa pun dan bisa dicari serta disalin. Pilih halaman seukuran graf seperti dot -Tpdf, atau halaman A4 atau Letter dengan halaman judul dan bookmark, dan file Markdown menghasilkan satu halaman per blok dot. Anda mendapatkan PDF untuk dokumen desain atau untuk dicetak tanpa memasang Graphviz.

Cara memakai Export to PDF (Vector, Title Page) (Zovo Pro)

  1. Buka pratinjau lalu klik PDF di toolbar (dengan tag PRO kecil), atau jalankan “Graphviz: Export to PDF (Vector, Title Page) (Pro)” dari Command Palette.
  2. Pilih “Graph-size pages”, “Title page and A4 pages”, “Title page and Letter pages”, atau “Graph-size pages with a title page”, lalu tentukan lokasi penyimpanan.
  3. Escape, Cancel, atau galat pada graf tidak memakai percobaan gratis.

Export to PDF (Vector, Title Page) bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.zovo-graphviz-preview lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/zovo-graphviz-preview.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan Graphviz Viewer & DOT Viewer

  • Graph dan digraph dengan cluster, subgraph, dan label HTML.
  • Blok berpagar dot, graphviz, dan gv di Markdown, digambar di pratinjau Markdown bawaan.
  • Tema gelap. Garis dan teks hitam bawaan mengikuti warna tema Anda, dan warna yang Anda atur di graf tetap seperti adanya.
  • Graf besar, di-layout di thread terpisah dengan batas waktu. sfdp biasanya jauh lebih cepat daripada dot untuk ribuan node.

Yang tidak bisa dilakukan

  • Graf di atas 4.096 KB tidak di-layout, dan layout yang memakan waktu lebih dari 15 detik dihentikan (graphvizPreview.maxSourceKB, graphvizPreview.renderTimeoutSeconds).
  • Atribut image= dan gambar di label HTML memang sengaja tidak digambar.
  • Hanya ada satu pratinjau per file, dan pratinjau tidak dipulihkan setelah restart. Problems hanya tampil selama pratinjau terbuka.
  • PDF memakai font PDF standar, jadi karakter di luar teks Eropa Barat, seperti label berbahasa Tionghoa atau beraksara Sirilik, tampil sebagai “?” di PDF. SVG dan PNG menampilkannya dengan benar.

Pertanyaan umum

Apakah ini gratis?

Pratinjau langsung, keenam engine, klik ke baris, serta ekspor SVG dan PNG gratis. Tiga alat Pro, ekspor PDF, Export All Graphs in Workspace, dan Export on Save, masing-masing bisa dicoba 3 kali gratis. Setelah itu alat-alat ini memerlukan Zovo Pro, USD 19 sekali bayar untuk semua ekstensi Zovo.

Apakah Graphviz harus dipasang?

Tidak. Graphviz 16.1 sudah ada di dalam ekstensi sebagai WebAssembly. Tidak ada yang dipasang di komputer Anda, dan semuanya berjalan offline.

Apakah blok dot di Markdown ikut digambar?

Ya. Blok berpagar dengan bahasa dot, graphviz, atau gv digambar di pratinjau Markdown VS Code.

Apakah bisa dipakai di Cursor?

Bisa. Ekstensi ini ada di Open VSX, jadi Cursor, Windsurf, dan VSCodium bisa memasangnya.
