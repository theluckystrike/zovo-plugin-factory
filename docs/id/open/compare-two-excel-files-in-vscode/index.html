Membandingkan dua file Excel atau CSV di VS Code

Pasang ekstensi gratis Excel Compare & XLSX Diff lalu pilih dua workbook atau file CSV. Sel yang berubah ditandai kuning dengan nilai lama dicoret, baris yang ditambahkan berwarna hijau, dan baris yang dihapus berwarna merah. Baris diselaraskan dan kolom dicocokkan berdasarkan header, sehingga satu baris atau kolom yang disisipkan tampil sebagai satu perubahan. Anda juga bisa membandingkan workbook dengan versi Git HEAD-nya sebelum commit. Semua itu gratis, tanpa permintaan jaringan. Zovo Pro (USD 19 sekali bayar) menambahkan tiga alat, yaitu Export a diff report, Match rows by key columns, dan Compare two folders of workbooks, dan masing-masing bisa dicoba gratis 3 kali.

Langkah di VS Code

  1. Pasang Excel Compare & XLSX Diff dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.zovo-excel-compare.
  2. Pilih dua file di Explorer, klik kanan, lalu pilih Compare Selected Excel Files. Atau klik kanan satu file, pilih Compare with... lalu pilih file lainnya. Dari Command Palette, Anda juga bisa menjalankan "Excel Compare: Compare Two Excel or CSV Files...".
  3. Kombinasi apa pun dari .xlsx, .xlsm, .xls, .ods, .csv, dan .tsv bisa dipakai, jadi Anda bisa membandingkan file .xlsx dengan file .csv.
  4. Baca baris ringkasan, lalu tab setiap sheet beserta jumlah perbedaannya. Klik sel untuk melihat nilai lama dan baru secara lengkap dan menyalinnya.
  5. Tekan N dan P (atau Next dan Previous) untuk berpindah ke setiap perubahan di semua sheet. Beralih antara Values dan Formulas untuk membandingkan nilai yang tampil di sel atau formulanya sendiri.
  6. Untuk melihat apa yang Anda ubah sebelum commit, klik kanan workbook di repository Git dan pilih Compare with Git HEAD.

Yang gratis dan yang ditambahkan Zovo Pro

Membandingkan dua file apa pun, grid, Values dan Formulas, perpindahan ke perubahan berikutnya dan sebelumnya, perbandingan CSV dengan deteksi encoding dan pemisah, serta Compare with Git HEAD gratis. Tidak perlu login, tanpa permintaan jaringan, dan tanpa telemetri.

Saat orang lain perlu melihat perubahannya, Export a diff report menulis workbook XLSX yang mewarnai sel yang berubah, ditambahkan, dan dihapus, lengkap dengan sheet Summary dan daftar Changes berisi setiap nilai lama dan baru. Alat ini juga bisa menulis satu halaman HTML atau daftar perubahan dalam CSV. Anda cukup mengirim satu file, bukan tangkapan layar.

Cara memakai Export a diff report (Zovo Pro)

  1. Bandingkan dua file seperti di atas, lalu klik Export report di toolbar perbandingan, atau jalankan "Excel Compare: Export a diff report (XLSX, HTML or CSV) (Pro)" dari Command Palette.
  2. Pilih XLSX, HTML, atau CSV.
  3. Pilih lokasi penyimpanan laporan. Satu percobaan hanya terpakai jika laporan berhasil ditulis.

Export a diff report bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.zovo-excel-compare lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/zovo-excel-compare.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan Excel Compare & XLSX Diff

  • Sheet dicocokkan berdasarkan nama, lalu posisi. Sheet yang hanya ada di satu file dicantumkan sebagai ditambahkan atau dihapus.
  • CSV dan TSV dengan encoding yang dideteksi otomatis (UTF-8 dengan atau tanpa BOM, UTF-16, Windows code page) dan pemisah yang dideteksi otomatis (koma, titik koma, tab, atau pipe), termasuk field berkutip yang berisi baris baru.
  • Sheet besar. Grid hanya menggambar baris yang terlihat di layar, sehingga sheet dengan 300.000 baris bisa digulir seperti sheet pendek.
  • Catatan jika merged cell berbeda atau jika sebuah batas memotong sheet.
  • Dua alat Pro lainnya. Match rows by key columns mencocokkan baris berdasarkan kolom ID, sehingga sheet yang diurutkan atau disusun ulang tetap dibandingkan dengan rapi dan baris yang berpindah ditandai. Compare two folders of workbooks memasangkan file berdasarkan nama dan menunjukkan mana yang sama, mana yang berbeda, dan mana yang hanya ada di satu folder.

Yang tidak bisa dilakukan

  • File hingga 200 MB (setting excelCompare.maxFileSizeMB), 300.000 baris per sheet (excelCompare.maxRows), 1.000 kolom, dan 200 sheet. Catatan muncul di tampilan jika sebuah batas berlaku.
  • Workbook yang akan membengkak lebih dari 600 MB saat dibuka, atau dikompresi seperti zip bomb, ditolak sebelum diekstrak.
  • Tanpa alat Pro Match rows by key columns, baris diselaraskan berdasarkan isi dan posisinya, bukan berdasarkan kolom ID.
  • Ekstensi ini hanya membandingkan, tidak mengedit atau menggabungkan file.

Pertanyaan umum

Apakah gratis?

Membandingkan dua workbook atau file CSV, Values dan Formulas, perubahan berikutnya dan sebelumnya, serta Compare with Git HEAD gratis. Tiga alat Pro, yaitu Export a diff report, Match rows by key columns, dan Compare two folders of workbooks, masing-masing punya 3 percobaan gratis. Setelah itu diperlukan Zovo Pro, USD 19 sekali bayar untuk semua ekstensi Zovo.

Apakah VS Code bisa membandingkan dua file Excel tanpa ekstensi?

Tidak. File .xlsx adalah zip berisi bagian-bagian XML, sehingga diff bawaan menampilkannya sebagai file biner. Anda memerlukan ekstensi yang bisa membaca workbook.

Apakah baris yang disisipkan di atas membuat semua baris di bawahnya ditandai berubah?

Tidak. Baris diselaraskan sebelum dibandingkan, sehingga baris yang disisipkan tampil sebagai satu baris yang ditambahkan.

Bisakah saya melihat apa yang berubah di workbook sejak commit terakhir?

Bisa. Klik kanan file di repository Git dan pilih Compare with Git HEAD. Perintah ini menjalankan git lokal Anda.
