Format dan periksa file konfigurasi nginx di VS Code

Pasang ekstensi gratis Nginx Config Formatter & Lint, buka konfigurasi nginx, lalu tekan Shift+Alt+F (Shift+Option+F di Mac). Formatter mem-parse hasilnya sendiri dan tidak mengubah apa pun jika file tidak akan terbaca sama, sehingga konfigurasi yang valid tetap valid. Warna sintaks, problems saat mengetik dengan quick fix, hover untuk sekitar 300 directive, completion, outline, dan ringkasan konfigurasi lintas file include gratis dan berjalan di komputer Anda. Langkah di VS Code

  1. Pasang Nginx Config Formatter & Lint dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.zovo-nginx-config.
  2. Buka konfigurasinya. File terbuka sebagai nginx jika bernama nginx.conf atau berakhiran .nginx atau .nginxconf, atau jika berupa file .conf di folder bernama nginx (seperti /etc/nginx/conf.d/default.conf) atau file di nginx/sites-available, nginx/sites-enabled, atau nginx/snippets. Untuk file lain, pilih "nginx" sebagai language mode.
  3. Tekan Shift+Alt+F (Shift+Option+F di Mac). Anda mendapat satu statement per baris dengan indentasi editor Anda, nilai log_format yang panjang tetap dengan baris barunya, dan paling banyak satu baris kosong berturut-turut dipertahankan (pengaturan nginxConfig.format.maxBlankLines).
  4. Problems tampil saat Anda mengetik: ; yang hilang, kurung kurawal yang belum ditutup atau berlebih, string yang belum ditutup, directive di blok yang salah, root atau listen ganda, dan dua server dengan nama yang sama di satu port. Tekan Ctrl+. (Cmd+. di Mac) untuk quick fix seperti "Add the missing ";"" atau proxy_set_heder yang diganti menjadi proxy_set_header.
  5. Arahkan kursor ke sebuah directive untuk melihat sintaks, nilai default, blok yang diizinkan, dan tautan ke dokumentasi nginx. Completion menawarkan directive yang diizinkan di blok saat ini, dan variabel setelah $.
  6. Klik ikon daftar di title bar editor, atau jalankan "Nginx: Show Config Overview", untuk melihat setiap server dengan port dan namanya serta setiap location dengan fungsinya, lintas file include. Klik file dan baris untuk membukanya.

Yang gratis dan yang ditambahkan Zovo Pro

Warna sintaks (blok Lua diwarnai sebagai Lua), Format Document, problems dengan quick fix, hover, completion, outline, dan ringkasan konfigurasi gratis. Semuanya berjalan di komputer Anda, tanpa permintaan jaringan.

Security Audit memeriksa konfigurasi beserta semua file include-nya dan mencantumkan setiap temuan dengan file, baris, alasan pentingnya, dan perbaikannya, diurutkan sebagai high, medium, dan low. Alat ini mencari TLS 1.0 dan 1.1, cipher yang lemah, server HTTPS tanpa HSTS dan security header lain, location yang add_header-nya sendiri diam-diam membuang header tersebut, path traversal off-by-slash pada alias, proxy_pass ke host yang diambil dari request, file .git dan .env yang ikut disajikan, daftar isi folder, dan request body tanpa batas. Anda menemukan kesalahan ini sebelum konfigurasi masuk ke production, tanpa membaca setiap file include secara manual.

Cara memakai Security Audit (Zovo Pro)

  1. Klik "Security audit" di baris Pro tools pada toolbar ringkasan konfigurasi, klik kanan file .conf atau .nginx di Explorer lalu pilih "Zovo Pro: Security audit", atau jalankan "Nginx: Security Audit (Pro)" dari Command Palette.
  2. Hasil audit terbuka di samping editor. Setiap temuan menampilkan file dan barisnya, alasannya, dan perbaikannya. Klik file dan baris untuk membukanya.
  3. Klik "Save report" untuk menyimpan temuan sebagai file Markdown.
  4. Percobaan hanya dihitung jika audit menampilkan hasilnya. Escape, atau file tanpa blok http atau server, tidak memakai percobaan.

Security Audit bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.zovo-nginx-config lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/zovo-nginx-config.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan Nginx Config Formatter & Lint

  • Directive OpenResty/Lua, headers-more, Brotli, Passenger, dan modul umum lain dikenali dan tidak pernah ditandai.
  • Blok Lua seperti content_by_lua_block diwarnai sebagai Lua.
  • Tampilan Outline mencantumkan server dengan nama dan port-nya, location, upstream, dan map.
  • Include relatif dibaca dari nginxConfig.prefix, folder file tersebut, folder induknya, atau /etc/nginx, sesuai urutan itu.
  • Perubahan yang belum disimpan di editor yang terbuka dipakai oleh ringkasan konfigurasi dan alat Pro.

Yang tidak bisa dilakukan

  • Formatter menaruh satu spasi di antara directive dan nilainya, sehingga perataan kolom seperti listen 80; tidak dipertahankan.
  • File dengan kurung kurawal atau string yang belum ditutup tidak diformat. File tetap tidak berubah dan status bar menyebutkan alasannya.
  • Pemeriksaan membaca file Anda dan tidak menjalankan nginx -t. File sertifikat yang hilang atau modul yang tidak dimuat hanya ditemukan oleh nginx sendiri.
  • Regex location diuji dengan regular expression JavaScript. Beberapa fitur yang hanya ada di PCRE (possessive quantifier, rekursi) tidak bisa diuji dan dilaporkan sebagai dilewati.

Apakah format bisa merusak konfigurasi saya?
