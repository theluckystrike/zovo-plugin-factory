Melihat pratinjau file font di VS Code

Pasang Font Viewer yang gratis lalu klik file .ttf, .otf, .woff, .woff2, atau .ttc. Ekstensi ini menampilkan teks contoh Anda sendiri dalam font itu, waterfall berbagai ukuran, grid glyph yang bisa dicari, serta lisensi dan hak embedding, tanpa memasang font di sistem Anda. Type tester, grid glyph, peta karakter, tab Info, dan Copy CSS @font-face gratis. Zovo Pro (USD 19 sekali bayar) menambahkan dua alat, Convert Font dan Font Folder Report, dan masing-masing bisa dicoba 3 kali gratis.

Langkah di VS Code

  1. Pasang Font Viewer dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.font-viewer-vscode.
  2. Klik file .ttf, .otf, .woff, .woff2, .ttc, atau .otc di Explorer. Font Viewer adalah editor bawaan untuk file-file ini, dan tidak pernah mengubah font.
  3. Di tab Type tester, ketik teks Anda sendiri, geser slider ukuran dari 8 sampai 200 px, dan baca waterfall dari 12 sampai 96 px. Geser slider sumbu font variabel, dan nyalakan atau matikan fitur OpenType seperti liga atau ss01.
  4. Di tab Glyphs, cari berdasarkan nama, karakter, U+20AC, atau id glyph. Klik sebuah glyph untuk melihatnya dalam ukuran besar dengan garis baseline, x-height, dan cap height, lalu salin karakternya, code point-nya, atau outline-nya sebagai SVG.
  5. Di tab Characters, baca cakupan setiap blok Unicode, seperti “Basic Latin 95/128”. Matikan “Only characters in the font” untuk melihat karakter yang tidak ada.
  6. Di tab Info, baca lisensi, desainer, hak cipta, dan hak embedding, lalu salin aturan @font-face yang siap pakai.

Yang gratis dan yang ditambahkan Zovo Pro

Membuka setiap font yang didukung, type tester, grid glyph, peta karakter, tab Info, dan Copy CSS @font-face gratis. Font Viewer berjalan offline, tanpa panggilan jaringan dan tanpa telemetri.

Font Folder Report mencantumkan setiap font di sebuah folder dengan family, style, weight, sumbu, versi, jumlah glyph, lisensi, URL lisensi, dan hak embedding. Daftarnya ditulis sebagai file CSV, tabel Markdown, atau satu fonts.css dengan aturan @font-face untuk setiap font (WOFF2 lebih dulu). Sebelum Anda menyertakan satu folder font di aplikasi atau situs web, Anda bisa melihat untuk apa setiap font boleh dipakai dalam satu file, tanpa membuka font satu per satu.

Cara memakai Font Folder Report (Zovo Pro)

  1. Klik kanan folder berisi font di Explorer lalu pilih “Font Folder Report: CSV, Markdown or @font-face CSS… (Pro)”, atau jalankan “Font Viewer: Font Folder Report: CSV, Markdown or @font-face CSS… (Pro)” dari Command Palette dan pilih foldernya.
  2. Pilih formatnya, yaitu CSV, tabel Markdown, atau aturan CSS @font-face.
  3. Simpan file. Nama bawaannya adalah fonts-report.csv, fonts-report.md, dan fonts.css, dan percobaan baru dihitung saat file selesai ditulis.

Font Folder Report bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.font-viewer-vscode lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/font-viewer-vscode.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan Font Viewer

  • Font TrueType .ttf dan OpenType .otf, termasuk font variabel.
  • Font web .woff dan .woff2. WOFF2 dibongkar oleh dekoder milik ekstensi sendiri.
  • Koleksi .ttc dan .otc, dengan daftar di header untuk memilih face.
  • Font CJK besar dengan 20.000 glyph, dimuat per halaman saat Anda menggulir.
  • Klik kanan font di Explorer lalu pilih Copy CSS @font-face tanpa membukanya.

Yang tidak bisa dilakukan

  • Koleksi WOFF2, font SVG, .dfont, dan font Type 1 tidak didukung.
  • Outline glyph menampilkan instance bawaan dari font variabel. Type tester, waterfall, dan peta karakter mengikuti slider sumbu.
  • Font berwarna digambar berwarna di type tester dan peta karakter, tetapi grid glyph menampilkan outline polosnya.
  • File di atas 64 MB menampilkan pesan, bukan terbuka (pengaturan fontViewer.maxFileMB).
  • Ekstensi ini baca-saja. Font tidak diedit dan tidak dipasang di sistem Anda.

Pertanyaan umum

Apakah ini gratis?

Melihat font, type tester, grid glyph, peta karakter, tab Info, dan Copy CSS @font-face gratis. Dua alat Pro, Convert Font dan Font Folder Report, masing-masing bisa dicoba 3 kali gratis. Setelah itu keduanya memerlukan Zovo Pro, USD 19 sekali bayar untuk semua ekstensi Zovo.

Apakah font harus dipasang dulu?

Tidak. Font dibaca dari file dan hanya ditampilkan di dalam tab Font Viewer. Daftar font sistem Anda tidak berubah.

Apakah bisa membuka WOFF2 dari folder build saya?

Bisa. WOFF2 dibongkar oleh dekoder milik ekstensi sendiri, dan tampilan yang terbuka dimuat ulang saat Anda menyimpan build font yang baru.

Apakah bisa dipakai di Cursor?

Bisa. Font Viewer ada di Open VSX sebagai zovo/font-viewer-vscode, jadi Cursor, Windsurf, dan VSCodium bisa memasangnya.
