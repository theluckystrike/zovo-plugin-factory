Mengganti nama tag HTML, JSX, dan Vue secara otomatis di VS Code

Pasang ekstensi gratis Auto Rename Tag & Close Tag Sync lalu ubah nama di tag pembuka atau tag penutup. Tag pasangannya ikut berubah saat Anda mengetik. Penggantian nama ini memakai linked editing milik VS Code sendiri (editor.linkedEditing). Ekstensi ini menyalakan pengaturan itu untuk bahasa-bahasanya dan menemukan tag pasangan di HTML, JSX, TSX, Vue, Svelte, Astro, PHP, Blade, Twig, XML, Markdown, dan lainnya, sehingga satu undo mengembalikan kedua tag. Rename, auto close, dan kotak tag pasangan gratis, dan Zovo Pro (USD 19 sekali bayar) menambahkan Rename Tag in All Files dan Check Unclosed Tags in All Files, dengan 3 kali percobaan gratis untuk setiap alat.

Langkah di VS Code

  1. Pasang Tag Auto Rename & Close Tag Sync dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.zovo-auto-rename-tag.
  2. Buka file HTML, JSX, TSX, Vue, Svelte, PHP, atau file template lain, lalu ubah nama di tag pembuka. Tag penutup ikut berubah saat Anda mengetik, begitu juga sebaliknya.
  3. Ketik > setelah tag pembuka, dan tag penutup muncul setelah kursor. Ketik </, dan nama elemen yang masih terbuka langsung terisi.
  4. Letakkan kursor di sebuah tag, dan kedua tag mendapat kotak dengan warna bracket tema Anda.
  5. Klik kanan di editor untuk “Go to Matching Tag” dan “Select Tag Content”. Untuk mengetik nama baru di sebuah kotak, jalankan “Tag Sync: Rename Tag Pair…” dari Command Palette.
  6. Klik item Tags di bilah status untuk melihat apa yang aktif untuk file ini, atau untuk mematikan ekstensi untuk satu bahasa. Jika tertulis “Tags: rename off”, klik item itu untuk menyalakan rename untuk bahasa tersebut.

Yang gratis dan yang ditambahkan Zovo Pro

Rename saat mengetik, auto close pada > dan </, kotak tag pasangan, Go to Matching Tag, Select Tag Content, Rename Tag Pair…, dan menu bilah status gratis. Tidak ada iklan, tidak perlu sign-in, dan semuanya berjalan offline.

Alat ini mengganti nama komponen atau elemen di setiap file bertag di workspace sekaligus, misalnya <Button> menjadi <UiButton> di setiap file .tsx, .vue, .html, dan template. Hanya nama tag yang berubah, tidak pernah teks, atribut, string, atau komentar. Anda melihat jumlahnya lebih dulu, “Preview first” membuka refactor preview VS Code, dan satu Undo mengembalikan semua file.

Cara memakai Rename Tag in All Files (Zovo Pro)

  1. Buka folder proyek di VS Code. Alat ini memerlukan folder yang terbuka.
  2. Jalankan “Tag Sync: Rename Tag in All Files… (Pro)” dari Command Palette, atau klik kanan file .html, .htm, .vue, .jsx, .tsx, atau .svelte di Explorer lalu pilih “Zovo Pro: Rename Tag in All Files”.
  3. Ketik tag yang akan diganti namanya persis seperti yang tertulis di file (misalnya Button), lalu nama barunya.
  4. Pilih “Rename”, atau “Preview first” untuk memeriksa perubahan di refactor preview. File yang tidak sedang terbuka ikut diubah tetapi tidak disimpan. File > Save All menyimpannya, dan Undo mengembalikannya.

Rename Tag in All Files bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.zovo-auto-rename-tag lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/zovo-auto-rename-tag.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan Tag Auto Rename & Close Tag Sync

  • Rename di HTML, JSX dan TSX, Vue, Svelte, Astro, PHP, Blade, Twig, Jinja, Nunjucks, Liquid, ERB, EJS, Handlebars, XML, SVG, dan Markdown.
  • Tag void seperti br, img, input, meta, dan hr tidak pernah dipasangkan atau ditutup.
  • Di .tsx, hanya JSX sungguhan yang dianggap tag. Perbandingan seperti a < b && c > d dan generic seperti useState<string>() dibiarkan, dan file .ts tidak disentuh.
  • Komentar, string, isi <script> dan <style>, serta blok {{ }}, {% %}, <?php ?>, dan <% %> dilewati.
  • File baru yang belum disimpan langsung berfungsi begitu bahasanya ditentukan.

Yang tidak bisa dilakukan

  • Di JSX dan TSX, TypeScript menutup tag sendiri, jadi ekstensi ini menyerahkan penutupan tag kepadanya. Tag penutup dari TypeScript menjadi langkah undo tersendiri.
  • Jika ekstensi Vue, Svelte, Astro, atau Red Hat XML terpasang, ekstensi itu yang menutup tag di bahasanya, dan ekstensi ini tidak ikut campur.
  • File di atas 1 MB atau 50.000 baris tidak mendapat rename, close, atau highlight langsung (pengaturan zovoTags.maxFileSizeKB dan zovoTags.maxFileLines). Bilah status memberi tahu hal itu, dan perintah-perintahnya tetap berfungsi.
  • Tag yang ditulis di dalam ekspresi {...} Svelte atau Astro tidak diganti namanya.
  • Jika ekstensi Auto Rename Tag atau Auto Close Tag yang lebih lama juga aktif, keduanya bisa mengedit tag yang sama. Pakai salah satu saja.

Pertanyaan umum

Apa bedanya dengan pengaturan editor.linkedEditing?

Ekstensi ini memakai editor.linkedEditing untuk rename. Ekstensi ini menyalakan pengaturan itu untuk setiap bahasa yang didukungnya dan menemukan tag pasangan di setiap bahasa itu, dari HTML dan Vue sampai PHP, Twig, XML, dan JSX. Ekstensi ini juga menutup tag, menggambar kotak di sekitar tag pasangan, dan menambahkan Go to Matching Tag serta Select Tag Content. Jika Anda sendiri mematikan editor.linkedEditing, bilah status menampilkan “Tags: rename off”, dan satu klik menyalakannya untuk bahasa itu.

Apakah undo tetap berfungsi?

Ya. Edit Anda dan perubahan pada tag pasangannya adalah satu langkah undo, karena rename memakai linked editing VS Code. Tag penutup dari auto close ikut masuk ke langkah undo > yang Anda ketik, kecuali di JSX dan TSX, tempat TypeScript yang menutup tag.

Apakah ini gratis?

Ya. Rename, auto close, kotak tag pasangan, dan perintah editor gratis. Rename Tag in All Files dan Check Unclosed Tags in All Files adalah alat Zovo Pro dengan 3 kali percobaan gratis masing-masing, lalu USD 19 sekali bayar untuk semua ekstensi Zovo.

Apakah bisa dipakai di Cursor?

Bisa. Cursor, Windsurf, dan VSCodium memasangnya dari Open VSX sebagai zovo/zovo-auto-rename-tag.
