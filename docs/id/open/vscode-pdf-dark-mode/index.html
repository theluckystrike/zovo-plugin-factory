Membaca PDF dalam mode gelap di VS Code

Pasang PDF Viewer & PDF Reader (Dark), lalu klik file .pdf: jika VS Code memakai tema gelap, halaman langsung tampil gelap, dan tombol bulan menyalakan atau mematikannya. Foto tetap mempertahankan warna aslinya. Membaca, mode sepia, pencarian, highlight, dan menyalin highlight sebagai Markdown semuanya gratis. Zovo Pro (USD 19 sekali bayar) menambahkan alat seperti pengelolaan halaman, penggabungan PDF, dan perbandingan PDF, dengan 3 kali percobaan gratis untuk setiap alat.

Pasang di VS CodeHalaman MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

Gratis, lisensi MIT. Extension ID zovo.pdf-viewer-dark.

Langkah di VS Code

  1. Pasang PDF Reader dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.pdf-viewer-dark.
  2. Klik file .pdf di Explorer. Jika VS Code memakai tema gelap, halaman langsung tampil gelap; tombol bulan atau "Toggle Dark Pages" menyalakan atau mematikannya untuk file ini.
  3. Ingin warna yang lebih hangat untuk membaca lama? Tombol kertas di sebelah tombol bulan, atau "Toggle Sepia Pages", menampilkan halaman sepia. Foto tetap berwarna asli di kedua mode.
  4. Tekan Ctrl+F (Cmd+F di macOS) untuk mencari, dan buka sidebar berisi outline serta thumbnail halaman dengan "Toggle Outline and Pages".
  5. Seleksi teks lalu pilih salah satu dari 4 warna, atau tekan H untuk kuning. Tab Highlights mencantumkan semua highlight Anda, dan satu klik membawa Anda kembali ke tempatnya.
  6. Dengan "Copy Highlights as Markdown" Anda menyalin daftar highlight beserta tautan ke setiap halaman, praktis untuk catatan.

Di Cursor, Windsurf, dan VSCodium

Editor ini memasang ekstensi dari Open VSX. Buka tampilan Extensions (Ctrl+Shift+X), cari zovo.pdf-viewer-dark, lalu klik Install. Halamannya di Open VSX adalah zovo/pdf-viewer-dark. Setelah itu cara pakainya sama seperti di VS Code.

Yang gratis

Halaman gelap dan sepia, pencarian, outline dan thumbnail halaman, highlight dalam 4 warna, Copy Highlights as Markdown, Go to Page, dan tautan Markdown yang membuka PDF di halaman tertentu semuanya gratis. Viewer memuat ulang PDF saat file berubah di disk, misalnya setelah build LaTeX atau Typst, dan tetap berada di halaman yang sama. Setiap PDF dibuka kembali di halaman dan tingkat zoom terakhir. Semuanya berjalan offline tanpa telemetri, dan highlight tidak ditulis ke dalam file PDF.

Yang ditambahkan Zovo Pro

Export Highlights of All PDFs to Markdown mengumpulkan highlight dari semua PDF Anda, atau hanya PDF di workspace ini, ke dalam satu file Markdown, dikelompokkan per file, lengkap dengan warna dan tautan ke setiap halaman. Setelah membaca banyak paper atau spesifikasi, semua catatan Anda ada di satu tempat tanpa perlu membuka file satu per satu. Alat Pro lainnya adalah alat halaman (mengambil, menghapus, atau memecah halaman ke PDF baru), Merge PDFs, dan Compare Two PDFs.

Cara memakai Export Highlights of All PDFs to Markdown

  1. Jalankan "Export Highlights of All PDFs to Markdown (Pro)..." dari Command Palette, atau klik tautan "All PDFs" di tab Highlights.
  2. Jika diminta, pilih antara semua PDF yang punya highlight atau hanya PDF di workspace ini.
  3. Tentukan lokasi file Markdown, lalu simpan.

Export Highlights of All PDFs to Markdown bisa dipakai 3 kali gratis sebelum meminta lisensi. Tidak ada popup saat file dibuka dan tidak ada hitung mundur.

Bayar dengan kartu, USD 19 sekali

Zovo Pro seharga USD 19 sekali bayar. Bukan langganan, dan lisensinya membuka alat Pro di semua ekstensi Zovo. Setelah membayar dengan kartu (Stripe), kunci lisensi muncul di halaman berikutnya. Di VS Code, jalankan "Enter Zovo Pro license key" dari Command Palette lalu tempel kuncinya. Kunci diperiksa di komputer Anda, tanpa koneksi jaringan.

Lisensi untuk tim berisi 5 orang seharga USD 59 sekali bayar, juga bisa dengan kartu. Semua aturan dan alat Pro ada di halaman Zovo Pro (bahasa Inggris).

Yang tidak bisa dilakukan

  • Viewer ini tidak bisa mengisi formulir, mengedit teks atau gambar di halaman, maupun mencetak.
  • Highlight tersimpan di VS Code pada komputer ini: tidak terlihat di aplikasi PDF lain dan tidak disinkronkan.
  • File besar dimuat seluruhnya ke memori; untuk file di atas 200 MB, viewer bertanya dulu sebelum membukanya.
  • Hanya .pdf yang didukung, bukan DjVu, XPS, atau EPUB.

Pertanyaan

Apakah PDF viewer ini gratis?

Ya. Membaca, halaman gelap dan sepia, pencarian, dan highlight gratis dan akan tetap gratis. Empat alat Pro, seperti Merge PDFs dan Compare Two PDFs, bisa dicoba 3 kali secara gratis; setelah itu Zovo Pro seharga USD 19 sekali bayar untuk semua ekstensi Zovo.

Apakah bisa dipakai di Cursor?

Bisa. Ekstensi ini juga tersedia di Open VSX, jadi di Cursor Anda cukup memasangnya dari panel Extensions.

Apakah grafik tetap berwarna?

Foto dan gambar raster lainnya tetap berwarna asli. Grafik vektor dibalik warnanya seperti teks.

Apakah Quick Open masih berfungsi saat PDF terbuka?

Ya. Viewer ini tidak mengambil alih Ctrl+P, jadi Quick Open dan Command Palette tetap bisa dipakai.

Semua fitur dan pengaturan ada di halaman PDF Reader (bahasa Inggris).
