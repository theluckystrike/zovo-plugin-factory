Lihat gambar dari path di kode Anda, di gutter dan saat hover

Pasang ekstensi gratis Image Preview & Image Hover lalu buka file yang menyebut sebuah gambar. Thumbnail tampil di gutter di samping barisnya, dan hover pada path menampilkan gambar, jenisnya, ukurannya dalam piksel, dan ukuran filenya. Ekstensi ini bekerja di import JavaScript dan TypeScript, JSX, CSS url(), Markdown, HTML src dan srcset, YAML, dan data URI, tanpa permintaan jaringan. Zovo Pro (USD 19 sekali bayar) menambahkan tiga alat, Find Unused Images, Find Broken Image References, dan Image Weight Report, dan masing-masing bisa dicoba 3 kali gratis.

Langkah di VS Code

  1. Pasang Image Preview & Image Hover dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.zovo-image-preview.
  2. Buka file yang menyebut sebuah gambar, misalnya import logo from './logo.png', CSS url(), atau HTML <img src>. Thumbnail tampil di gutter, satu per baris.
  3. Arahkan kursor ke path. Hover menampilkan gambar (diskalakan agar muat, tidak pernah diperbesar), jenisnya, lebar × tinggi dalam piksel, ukuran file, dan transparansi, dengan tautan untuk membuka file atau menampilkannya di Explorer.
  4. Jika sebuah path tidak ditemukan, hover memberitahukannya dan mencantumkan path yang sudah dicari. Tambahkan prefix Anda sendiri di imgPreview.aliases, misalnya { "@images": "src/assets/images" }, atau folder untuk path yang diawali / di imgPreview.publicFolders.
  5. Untuk menyembunyikan thumbnail di gutter, jalankan "Image Preview: Show or Hide Gutter Thumbnails" dari Command Palette.
  6. Tidak punya proyek untuk dicoba? Jalankan "Image Preview: Open the Sample Files" untuk membuka proyek demo kecil dengan semua jenis path.

Yang gratis dan yang ditambahkan Zovo Pro

Thumbnail di gutter, hover, resolusi path dengan alias, paths di tsconfig.json dan jsconfig.json, package monorepo, dan data URI gratis. Tanpa akun, tanpa permintaan jaringan, tanpa telemetri, dan bekerja offline.

Find Unused Images mencantumkan gambar di workspace (atau di satu folder) yang tidak disebut oleh file kode, style, Markdown, HTML, JSON, atau YAML mana pun, dari yang terbesar, dalam laporan Markdown beserta ukurannya. Setelah Anda konfirmasi, gambar dipindahkan ke folder _unused-images dengan struktur folder tetap sama, dan Edit > Undo memindahkannya kembali. Anda membersihkan gambar lama dari proyek tanpa memeriksa setiap nama secara manual.

Cara memakai Find Unused Images (Zovo Pro)

  1. Klik kanan sebuah folder di Explorer lalu pilih "Zovo Pro: Find unused images", atau jalankan "Image Preview: Find Unused Images (Pro)" dari Command Palette. Jika ada lebih dari satu folder workspace, pilih foldernya.
  2. Sebuah notifikasi menampilkan progres dengan tombol Cancel. Lalu laporan Markdown terbuka dengan setiap gambar yang tidak terpakai beserta ukurannya, dari yang terbesar.
  3. Klik "Move N to _unused-images" untuk memindahkannya, atau tutup pesan tersebut agar gambar tetap di tempatnya. Edit > Undo memindahkannya kembali.
  4. Percobaan hanya dihitung jika laporan terbuka. Escape tidak pernah memakai percobaan.

Find Unused Images bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.zovo-image-preview lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/zovo-image-preview.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan Image Preview & Image Hover

  • Thumbnail di gutter untuk file PNG, JPEG, GIF, WebP, AVIF, SVG, BMP, dan ICO, serta untuk URI data:image/.... File TIFF dan HEIC mendapat ukuran dan jenisnya dari header.
  • Path relatif terhadap file, /logo.png dari public/, static/, dan folder web root lain, @/ untuk src/, ~ untuk node_modules atau folder home Anda, serta paths di tsconfig.json atau jsconfig.json dengan extends.
  • Nama file dengan spasi, %20, ?v=2, atau #id. Nama biasa seperti beans.jpg di JSON dicocokkan dengan gambar terdekat yang bernama sama.
  • Monorepo: folder public/ dan tsconfig.json milik setiap package dipakai.
  • URL remote tampil sebagai tautan dan tidak pernah diunduh.

Yang tidak bisa dilakukan

  • Path yang dibentuk saat kode berjalan, seperti `icons/${name}.svg` atau penggabungan string, tidak bisa dipratinjau, dan bisa membuat sebuah gambar tampak tidak terpakai. Periksa daftar gambar yang tidak terpakai sebelum Anda memindahkan file.
  • Satu thumbnail per baris, yaitu gambar pertama di baris tersebut. Hover berfungsi untuk setiap path di baris itu.
  • Workspace remote dan virtual (SSH, WSL, Codespaces, vscode.dev) belum didukung di versi ini.
  • Alias Webpack, Vite, atau Next.js yang hanya ada di file konfigurasi JavaScript tidak dibaca. Tambahkan ke imgPreview.aliases atau ke paths di tsconfig.json.
  • Gambar di atas 20 MB diukur tetapi tidak digambar (pengaturan imgPreview.maxFileSizeMB). Image Weight Report menandai file yang berat tetapi tidak mengompresinya.

Pertanyaan umum

Apakah gratis?

Thumbnail di gutter, hover, dan resolusi path gratis. Tiga alat Pro, Find Unused Images, Find Broken Image References, dan Image Weight Report, masing-masing bisa dicoba 3 kali gratis. Setelah itu alat tersebut memerlukan Zovo Pro, USD 19 sekali bayar untuk semua ekstensi Zovo.

Mengapa path @/ atau alias saya tidak menampilkan gambar?

Alias tersebut mungkin hanya ada di file konfigurasi Webpack, Vite, atau Next.js, yang tidak dibaca. Tambahkan ke imgPreview.aliases atau ke paths di tsconfig.json.

Apakah bisa dipakai lewat Remote SSH atau WSL?

Belum di versi ini. Gambar untuk hover dibaca dari disk lokal.

Apakah bisa dipakai di Cursor?

Bisa. Cursor, Windsurf, dan VSCodium memasangnya dari Open VSX, tempat ekstensi ini diterbitkan sebagai zovo/zovo-image-preview.
