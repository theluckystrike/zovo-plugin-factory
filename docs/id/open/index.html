Panduan dalam bahasa Indonesia

VS Code dan editor turunannya (Cursor, Windsurf, VSCodium) bisa membuka teks, gambar, dan sebagian media. Untuk banyak format lain, Anda memerlukan ekstensi. Setiap panduan berisi langkah-langkahnya dan menjelaskan apa saja yang gratis.

  • Membuka file NumPy .npy dan .npz di VS Code. Buka array NumPy .npy dan .npz di VS Code dengan Tensor Viewer gratis: dtype, shape, statistik, heatmap, gambar, dan nilai-nilainya, tanpa Python.
  • Viewer NetCDF gratis yang berjalan di VS Code. Buka file NetCDF .nc di VS Code di Windows, macOS, atau Linux: header, variabel, peta dengan garis pantai, dan deret waktu. Juga HDF5 .h5 dan MATLAB 7.3 .mat.
  • Membuka database SQLite di VS Code. Buka file .db atau .sqlite di VS Code dengan SQLite Viewer & Editor gratis: tabel, skema, dan SQL, lalu edit sel dan baris dan simpan dengan cadangan.
  • Pratinjau diagram Mermaid di VS Code. Lihat pratinjau diagram Mermaid dari file .mmd dan blok Markdown di VS Code dengan Mermaid Viewer gratis. Pratinjau langsung, ekspor PNG dan SVG, offline.
  • Memutar video MOV, MKV, WebM, dan MP4 dengan suara di VS Code. Putar MP4, MOV, dan M4V bersuara AAC di VS Code tanpa memasang apa pun lagi. MKV, WebM, dan AVI juga bisa dengan ffmpeg Anda sendiri. Gratis, dengan subtitle.
  • Melihat file STL di VS Code. Buka file STL di VS Code dengan 3D Model Viewer gratis: putar, ukur jarak dua titik, wireframe, dan statistik model. Juga membuka OBJ, PLY, 3MF, GLB, dan glTF.
  • Membuka file PCAP di VS Code. Baca capture .pcap, .pcapng, dan .pcap.gz di VS Code dengan PCAP Viewer gratis: daftar paket, pohon protokol, panel hex, dan filter. Tanpa Wireshark.
  • Mengganti nama tag HTML, JSX, dan Vue secara otomatis di VS Code. Ubah nama tag HTML, JSX, atau Vue, dan tag pasangannya ikut berubah saat mengetik. Gratis, berbasis linked editing VS Code, dengan auto close dan satu undo.
  • Membaca dan melanjutkan riwayat Claude Code di VS Code. Baca, cari, dan lanjutkan sesi lama Claude Code dan Codex di VS Code. Subagent bersarang, edit sebagai diff, total token. Baca-saja dan offline.
  • Mengubah TIFF ke PNG tanpa kehilangan kualitas. Buka TIFF, BigTIFF, dan GeoTIFF di VS Code secara gratis, lalu simpan satu atau semua halaman sebagai PNG dengan nilai 8 dan 16-bit tetap tepat. Offline.
  • XMind ke PDF tanpa XMind, semua sheet dalam satu PDF. Buka peta pikiran .xmind di VS Code tanpa XMind dan simpan semua sheet ke satu PDF, satu halaman per sheet. Melihat gratis, PDF adalah alat Zovo Pro.
  • Melihat pratinjau file font di VS Code. Buka font .ttf, .otf, .woff, .woff2, dan .ttc di VS Code dengan Font Viewer gratis: uji teks, lihat semua glyph, dan baca lisensinya tanpa memasang font.
  • Memutar file audio di VS Code. Putar file WAV, MP3, FLAC, Ogg, dan Opus di VS Code dengan Audio Player gratis: waveform, spektrogram, loop A-B, kecepatan, dan loudness LUFS.
  • Membuka gambar DXF di VS Code. Lihat gambar .dxf di VS Code dengan DXF Viewer gratis: DXF ASCII dan biner, layer, sheet paper space, cari teks, ukur, serta ekspor PNG atau SVG.
  • Membuka file di dalam ZIP tanpa mengekstraknya. Telusuri ZIP, JAR, TAR, atau TAR.GZ di VS Code dan buka satu file di dalamnya di tab baca-saja, tanpa membongkar apa pun ke disk. Gratis dan offline.
  • Melihat section dan import file ELF, EXE, atau DLL di VS Code. Buka file .so, .exe, .dll, dan .dylib di VS Code dengan ELF Viewer & PE Viewer gratis: header, section, import, export, simbol, dan hex, baca-saja.
  • Pratinjau graf Graphviz DOT tanpa memasang Graphviz. Lihat pratinjau file .dot dan .gv di samping editor VS Code saat Anda mengetik, dengan Graphviz bawaan. Enam engine layout, klik ke baris, ekspor SVG dan PNG.
  • Menjalankan file C++ di VS Code dengan satu klik. Kompilasi dan jalankan file .cpp atau .c di VS Code dengan satu klik, memakai gcc, g++, atau clang Anda. Input di terminal, galat di Problems, test case.
  • Membuka JAR dan membaca source Java hasil dekompilasi di VS Code. Buka file .jar, .war, .ear, .aar, dan .class di VS Code: paket, MANIFEST.MF, bytecode, dan source Java hasil dekompilasi CFR. Gratis dan baca-saja.
  • Waktu cetak dan pemakaian filamen dari file G-code. Buka file .gcode di VS Code atau Cursor lalu lihat waktu cetak, panjang dan berat filamen, ukuran, dan kecepatan, di samping estimasi slicer. Gratis, offline.
  • Membandingkan dua file Excel atau CSV di VS Code. Bandingkan dua file .xlsx, .xls, .ods, atau CSV di VS Code per sel: sel berubah, baris ditambah dan dihapus, kolom dan sheet dicocokkan, serta Git HEAD. Gratis.
  • Cara mengonversi file PDF, Word, PowerPoint, atau Excel ke Markdown di VS Code. Klik kanan file PDF, DOCX, PPTX, XLSX, CSV, HTML, atau EPUB di VS Code, dan Markdown terbuka di sampingnya. Gratis, offline, tanpa Python, tanpa upload.
  • Format XML di VS Code dan jalankan XPath di file tersebut. Format atau minify XML di VS Code dengan hanya mengubah spasi di antara tag, jalankan XPath 1.0 dengan namespace milik file, dan salin XPath di posisi kursor.
  • Lihat gambar dari path di kode Anda, di gutter dan saat hover. Thumbnail di gutter dan hover dengan gambar, ukuran piksel, dan ukuran file untuk path gambar di JS, CSS, HTML, dan Markdown di VS Code. Gratis.
  • Edit file .env di VS Code tanpa menampilkan nilai rahasia Anda. Warnai file .env di VS Code, sembunyikan nilai rahasia sebagai titik sampai kursor ada di barisnya, perbaiki key ganda dan kutip yang salah. Gratis dan offline.
  • Format skrip bash atau zsh di VS Code. Format skrip bash, sh, zsh, bats, dan mksh di VS Code dengan Shift+Alt+F atau saat menyimpan. shfmt 3.14.1 bawaan, membaca .editorconfig, offline.
  • Jelajahi bucket AWS S3, Cloudflare R2, atau MinIO di VS Code. Jelajahi bucket S3, R2, MinIO, B2, dan Wasabi di VS Code. Buka objek read-only, upload dan download yang bisa dilanjutkan, sync folder setelah rencana dry-run.
  • Edit file .proto di VS Code dengan highlighting, format, dan go to definition. Highlight, format, dan periksa file .proto di VS Code: formatter yang menjaga komentar, go to definition, error bergaya protoc. Gratis, offline, tanpa protoc.
  • Format dan periksa file konfigurasi nginx di VS Code. Format nginx.conf di VS Code tanpa merusak file yang valid, lihat ; yang hilang atau directive salah tempat, dan hover untuk sekitar 300 directive.
  • Pratinjau diagram PlantUML di VS Code saat Anda mengetik. Pratinjau langsung PlantUML di VS Code untuk file .puml dan blok plantuml di Markdown, digambar di komputer Anda oleh jar bawaan. Perlu Java 11, tanpa Graphviz.
  • Upload file ke server lewat SFTP atau FTP dari VS Code. Atur .vscode/sftp.json, dan VS Code mengunggah setiap file saat disimpan, lewat SFTP, FTP, atau FTPS. Upload, download, bandingkan, edit file server. Gratis.
  • Format HTML dan CSS di VS Code tanpa merusak blok pre atau tag inline. Format HTML, CSS, SCSS, dan LESS di VS Code, termasuk blok style dan script serta .editorconfig. Pre, textarea, tag inline, dan urutan atribut tetap. Gratis.
  • Melihat dan mengedit file biner di VS Code. Lihat dan edit byte file apa pun di VS Code dengan Hex Viewer, termasuk file 4 GB. Ada pencarian, data inspector, dan perbandingan. Gratis dan offline.
  • Membuka file Word (.docx) di VS Code. Buka file .docx, .odt, dan .doc lama di VS Code sebagai pratinjau dengan mode gelap, outline, dan pencarian. Tanpa Office, offline, dan gratis.
  • Membuka Excel atau CSV di VS Code dan menjalankan SQL. Buka .xlsx, .xls, dan CSV di VS Code sebagai tabel yang bisa diurutkan dan difilter hingga 1.000.000 baris, lalu jalankan SQL. Tanpa Python, offline.
  • Membuka file Word dan PowerPoint di VS Code tanpa Office. Lihat file .docx, .odt, dan .pptx di VS Code atau Cursor tanpa Microsoft Office atau LibreOffice. Gratis, offline, dengan pencarian dan outline.
  • Membaca PDF dalam mode gelap di VS Code. Baca PDF di VS Code dengan halaman gelap atau sepia, foto tetap berwarna asli. Ada pencarian, outline, thumbnail, dan highlight. Gratis dan offline.
