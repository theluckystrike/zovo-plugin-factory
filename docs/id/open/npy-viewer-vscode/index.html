Membuka file NumPy .npy dan .npz di VS Code

Pasang ekstensi gratis Tensor Viewer (NPZ Viewer & NPY Viewer) lalu klik file .npy atau .npz. Setiap array tampil dengan nama, dtype, dan shape-nya. Satu klik menampilkan min, max, mean, std, jumlah NaN, grafik, histogram, dan nilai-nilainya, tanpa Python. Tampilan, gambar, tabel Values, serta Save as .npy atau CSV gratis. Zovo Pro (USD 19 sekali bayar) menambahkan dua alat, Compare two checkpoints dan Scan all tensors, dan masing-masing bisa dicoba 3 kali gratis.

Langkah di VS Code

  1. Pasang Tensor Viewer dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.tensor-viewer.
  2. Klik file .npy atau .npz di Explorer. Tabel mencantumkan setiap array dengan nama, tipe, shape, jumlah parameter, dan ukurannya.
  3. Klik satu array. Panel kanan menampilkan min, max, mean, std, serta jumlah NaN, Inf, dan nol, lalu heatmap untuk array 2D atau grafik garis untuk array 1D, dan sebuah histogram.
  4. Baca angkanya di tabel Values, 32 baris sekaligus. Untuk array dengan 3 dimensi atau lebih, ketik irisan seperti [5, :, :] di kolom Slice.
  5. Jika array berbentuk gambar, misalnya (H, W, 3) atau (N, 3, H, W), bagian Image menggambarnya. Pilih Layout, Frame, dan Range di sana. Matriks float menampilkan tombol “Show as image” sebagai gantinya.
  6. Klik “Save as .npy...” atau “Save as CSV...” untuk menulis array, atau irisannya, ke file baru.

Yang gratis dan yang ditambahkan Zovo Pro

Semua format, statistik, heatmap, grafik garis, histogram, gambar, tabel Values, irisan, raw array, serta Save as .npy atau CSV gratis. Python tidak diperlukan, dan viewer ini tidak melakukan panggilan jaringan.

Scan all tensors membaca setiap nilai dari setiap array di file, bukan sampel. Alat ini menandai NaN, Inf, array yang seluruhnya nol atau konstan, dan nilai float 10.000 atau lebih. Hasilnya berupa min, max, mean, std, dan norma L2 yang tepat untuk setiap array dalam satu laporan yang bisa difilter dan disimpan sebagai CSV, Markdown, atau JSON. Anda menemukan array yang rusak di file .npz besar tanpa mengklik satu per satu.

Cara memakai Scan all tensors (Zovo Pro)

  1. Buka file lalu klik tombol “Scan all tensors” di bagian atas viewer, atau klik kanan file di Explorer dan pilih “Zovo Pro: Scan Tensors for NaN, Inf and Zeros”.
  2. Bisa juga dengan menjalankan “NumPy Viewer Pro: Scan All Tensors for NaN, Inf and Zeros” dari Command Palette lalu memilih file.
  3. Notifikasi menampilkan progresnya, dan Cancel menghentikan pemindaian yang lama. Di laporan, pakai filter “Only tensors to check”, lalu simpan laporan sebagai CSV, Markdown, atau JSON.

Scan all tensors bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.tensor-viewer lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/tensor-viewer.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan Tensor Viewer

  • File .npy dengan header v1, v2, dan v3, urutan C dan Fortran, dengan urutan byte apa pun.
  • Arsip .npz dengan entri stored atau deflated, termasuk zip64.
  • bool, int8 sampai int64, uint8 sampai uint64, float16, float32, float64, dan bilangan kompleks (statistik dihitung dari magnitudonya).
  • Array berbentuk gambar, tumpukan, dan batch, digambar sebagai gambar, satu frame setiap kali.
  • Ekstensi yang sama juga membuka file .safetensors, .gguf, serta PyTorch .pt, .pth, dan .ckpt.

Yang tidak bisa dilakukan

  • Array objek hasil pickle dicantumkan tetapi ditolak, tidak pernah dijalankan. Array teks dan array terstruktur dicantumkan tanpa statistik.
  • Array dengan lebih dari 2.000.000 nilai diambil sampelnya untuk statistik dan grafik (pengaturan tensorViewer.sampleValues). Panel memberi tahu jika statistik berasal dari sampel.
  • Entri .npz yang terkompresi hanya dibaca dari awal. Nilai setelah 64 MB pertama tidak ditampilkan, dan entri di atas 512 MB tidak bisa disimpan.
  • Gambar digambar paling besar 512 piksel di sisi terpanjang. Array 2 kanal dan array berurutan Fortran tidak punya tampilan gambar.
  • Ekspor CSV berhenti di 20 juta nilai. Nilai int64 di atas 2^53 kehilangan digit terakhirnya di tabel dan di CSV.

Pertanyaan umum

Apakah ini gratis?

Membuka file .npy dan .npz, statistik, grafik, gambar, tabel Values, serta Save as .npy atau CSV gratis. Dua alat Pro, Compare two checkpoints dan Scan all tensors, masing-masing bisa dicoba 3 kali gratis. Setelah itu keduanya memerlukan Zovo Pro, USD 19 sekali bayar untuk semua ekstensi Zovo.

Apakah perlu Python?

Tidak. Tensor Viewer membaca file itu sendiri, jadi Python dan NumPy tidak perlu dipasang.

Apakah aman membuka file .npy dari internet?

Tidak ada isi file yang pernah dijalankan. Array objek, yang disimpan NumPy sebagai pickle, dicantumkan lalu ditolak, dan viewer ini tidak pernah mengubah file yang ditampilkannya.

Apakah bisa dipakai di Cursor?

Bisa. Tensor Viewer ada di Open VSX sebagai zovo/tensor-viewer, jadi Cursor, Windsurf, dan VSCodium bisa memasangnya.
