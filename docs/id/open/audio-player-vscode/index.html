Memutar file audio di VS Code

Pasang Audio Player & WAV Player yang gratis lalu klik file .wav, .mp3, .flac, .ogg, atau .opus. Ekstensi ini memutar file dengan waveform untuk setiap channel, spektrogram, loop A-B, kecepatan dari 0.25x sampai 2x dengan pitch tetap, dan angka loudness LUFS. Opus diputar dengan dekoder yang disertakan, dan file M4A serta AAC bisa diputar setelah satu klik jika Anda punya ffmpeg. Memutar dan memeriksa file gratis, dan Zovo Pro (USD 19 sekali bayar) menambahkan dua alat, Folder Loudness Report dan Normalize Loudness, dengan 3 kali percobaan gratis masing-masing.

Langkah di VS Code

  1. Pasang Audio Player & WAV Player dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.audio-preview-vscode.
  2. Klik file .wav, .mp3, .flac, .ogg, .opus, atau .m4a di Explorer. Jika pemutar lain yang terbuka, klik kanan file lalu pilih “Open in Audio Preview”.
  3. Tekan Spasi untuk memutar atau menjeda. Panah kiri dan kanan melompat 5 detik (1 detik dengan Shift). Klik waveform untuk pindah posisi.
  4. Seret di sepanjang waveform untuk me-loop bagian itu, atau tekan [ dan ] untuk menetapkan awal dan akhir loop di posisi playhead. L menyalakan atau mematikan loop.
  5. Pilih kecepatan dari 0.25x sampai 2x. Pitch-nya tetap sama.
  6. Baca header untuk codec, sample rate, channel, bit depth, durasi, dan bitrate, panel Loudness untuk LUFS, peak, dan RMS, serta panel Tags untuk judul, artis, album, dan tag lainnya.

Yang gratis dan yang ditambahkan Zovo Pro

Memutar setiap format yang didukung, waveform, spektrogram, loop A-B, kecepatan, panel Loudness, File, dan Tags, serta Copy stats gratis. Tidak ada yang ditulis kembali ke file audio, dan ekstensi ini tidak melakukan panggilan jaringan.

Folder Loudness Report menulis satu baris CSV untuk setiap file audio di sebuah folder, berisi format, durasi, sample rate, bit depth, judul dan artis, integrated LUFS, short-term dan momentary max, sample peak, RMS, sampel yang terpotong (clipped), dan gain yang dibutuhkan setiap file untuk mencapai -14, -16, dan -23 LUFS. Anda mengurutkan dan memeriksa satu folder rekaman di spreadsheet, tanpa membuka file satu per satu. File WAV dibaca oleh ekstensi itu sendiri, sedangkan baris MP3, FLAC, Ogg, Opus, dan M4A memerlukan ffmpeg Anda sendiri.

Cara memakai Folder Loudness Report (Zovo Pro)

  1. Klik kanan folder di Explorer lalu pilih “Folder Loudness Report (CSV, Pro)”, atau jalankan “Audio Preview: Folder Loudness Report (CSV, Pro)” dari Command Palette dan pilih foldernya. Di pemutar, alat ini juga ada di menu “...” pada judul editor.
  2. Pilih “This folder and its subfolders” atau “This folder only”, lalu tentukan lokasi penyimpanan loudness-report.csv.
  3. Notifikasi menampilkan progresnya dan bisa dibatalkan. Buka CSV-nya di spreadsheet. Percobaan baru dihitung saat file selesai ditulis.

Folder Loudness Report bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.audio-preview-vscode lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/audio-preview-vscode.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan Audio Player & WAV Player

  • WAV (PCM 8 sampai 32-bit, float, A-law, mu-law, RF64), dibaca per potongan 2 MB agar file besar tidak membekukan editor.
  • MP3, FLAC, dan Ogg Vorbis dengan dekoder yang sudah ada di VS Code.
  • Opus dalam .opus atau .ogg, dengan dekoder libopus yang disertakan (WebAssembly).
  • Hingga 8 channel, masing-masing di jalur waveform sendiri.
  • Tag dari ID3v1, ID3v2.2 sampai 2.4, RIFF INFO, Vorbis comment, dan atom iTunes.

Yang tidak bisa dilakukan

  • M4A dan AAC memerlukan ffmpeg Anda sendiri. Tanpa ffmpeg, Anda melihat codec, durasi, bitrate, tag, dan sebuah pesan.
  • ALAC, AC-3, dan codec lain yang tidak bisa didekode VS Code juga memerlukan tombol ffmpeg.
  • File terkompresi didekode utuh. Di atas 600 MB sampel hasil dekode (sekitar 28 menit stereo 44,1 kHz), file hanya diputar (pengaturan audioPreview.maxDecodedMB).
  • Peak yang ditampilkan adalah sample peak, bukan true peak dengan oversampling, dan tidak ada loudness range (LRA).
  • Ekstensi ini memutar dan memeriksa file. Ekstensi ini tidak memotong atau mengedit file.

Pertanyaan umum

Apakah ini gratis?

Memutar, waveform, spektrogram, loop, dan angka loudness gratis. Dua alat Pro, Folder Loudness Report dan Normalize Loudness, masing-masing bisa dicoba 3 kali gratis. Setelah itu keduanya memerlukan Zovo Pro, USD 19 sekali bayar untuk semua ekstensi Zovo.

Mengapa file .opus saya tidak bisa diputar di VS Code?

VS Code membawa Chromium tanpa dekoder Opus. Ekstensi ini membawa libopus yang dikompilasi ke WebAssembly, jadi Opus bisa diputar tanpa memasang apa pun lagi.

Mengapa M4A saya menampilkan pesan, bukan diputar?

VS Code juga tidak punya dekoder AAC. Jika ffmpeg terpasang, tombol Decode with ffmpeg membuat salinan WAV di folder penyimpanan ekstensi, lalu file bisa diputar. Tidak ada yang disertakan atau diunduh.

Apakah bisa dipakai di Cursor?

Bisa. Ekstensi ini ada di Open VSX sebagai zovo/audio-preview-vscode, jadi Cursor, Windsurf, dan VSCodium bisa memasangnya.
