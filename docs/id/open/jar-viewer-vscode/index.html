Membuka JAR dan membaca source Java hasil dekompilasi di VS Code

Pasang JAR Viewer & Java Decompiler yang gratis lalu klik file .jar, .war, .ear, .aar, atau .class. Ekstensi ini menampilkan paket, resource, MANIFEST.MF, dan versi Java setiap class, daftar bytecode bergaya javap -c -p yang tidak butuh Java, serta source Java yang didekompilasi oleh CFR 0.152 bawaan dengan runtime Java 8 atau lebih baru di komputer Anda. Semua tampilan dan dekompilasi class satu per satu gratis. Zovo Pro (USD 19 sekali bayar) menambahkan tiga alat, Export decompiled sources of a JAR, Compare two JARs, dan Find in every JAR of a folder, dengan 3 kali percobaan gratis masing-masing.

Langkah di VS Code

  1. Pasang JAR Viewer dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.zovo-jar-viewer.
  2. Klik file .jar, .war, .ear, .aar, atau .class di Explorer. File terbuka di JAR Viewer. Overview menampilkan format, jumlah entri, class, dan paket, Main-Class, Created by, MANIFEST.MF, serta grafik versi Java yang dipakai untuk mengompilasi class-class itu.
  3. Ketik sebagian nama di kotak filter di atas pohon paket. Class dan file langsung ditemukan sambil Anda mengetik. Inner class tampil redup di bawah class luarnya.
  4. Klik sebuah class. Tab Java source menampilkan hasil dekompilasinya dengan CFR 0.152, beserta inner class-nya. Copy menyalin source ke clipboard, dan Open in editor membukanya di tab editor biasa.
  5. Jika tab Java source menyebutkan bahwa source Java hasil dekompilasi memerlukan runtime Java, atur jarViewer.javaPath ke binary java atau folder JDK, atau atur JAVA_HOME. “JAR Viewer: Check the Java runtime used for decompiling” menunjukkan Java mana yang dipakai.
  6. Buka tab Bytecode untuk daftar bergaya javap -c -p dengan setiap opcode, tabel exception, dan nomor baris. Tab Members, Constant pool, dan Class info menampilkan deklarasi, entri constant pool, dan atribut class.
  7. Di JAR Spring Boot, WAR, atau AAR, klik JAR di dalam BOOT-INF/lib atau WEB-INF/lib, atau classes.jar milik AAR, lalu klik “Open nested archive”. Arsip itu terbuka satu tingkat ke dalam, dan tombol dengan nama file luar di bagian atas membawa Anda kembali.

Yang gratis dan yang ditambahkan Zovo Pro

Pohon paket, Overview, manifest, resource, source Java hasil dekompilasi, bytecode, members, constant pool, class info, dan JAR bersarang gratis, tanpa sign-in. CFR sudah disertakan di ekstensi dan berjalan dengan Java yang sudah ada di komputer Anda. Ekstensi ini tidak pernah mengubah arsip dan tidak melakukan panggilan jaringan.

Export decompiled sources of a JAR mendekompilasi setiap class dari sebuah JAR, WAR, EAR, atau AAR dengan CFR dan menulis file .java ke sebuah folder, dengan progress dan tombol Cancel. Tanpa runtime Java, alat ini menulis daftar bytecode sebagai gantinya. Anda mendapat seluruh library sebagai file source untuk dicari atau dibaca di editor, tanpa membuka class satu per satu.

Cara memakai Export decompiled sources of a JAR (Zovo Pro)

  1. Buka arsip lalu klik “Export sources…” di bagian atas viewer, atau “Export decompiled sources” di baris kecil Pro tools. Anda juga bisa klik kanan file di Explorer lalu pilih “Zovo Pro: Export decompiled sources”.
  2. Atau jalankan “JAR Viewer: Export decompiled sources of a JAR (Pro)” dari Command Palette. Jika tidak ada arsip yang terbuka, Anda diminta memilih file JAR, WAR, EAR, atau AAR.
  3. Pilih folder lalu klik “Export here”. Source masuk ke folder baru yang dinamai sesuai arsipnya dengan -src di akhir.
  4. Sebuah notifikasi menampilkan progress. Cancel menghentikan ekspor dan tidak memakai percobaan. Setelah selesai, viewer memberi tahu berapa file yang ditulis dan di mana.

Export decompiled sources of a JAR bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.zovo-jar-viewer lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/zovo-jar-viewer.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan JAR Viewer

  • Arsip JAR, WAR, EAR, dan AAR, serta file .class tunggal beserta inner class-nya dari folder yang sama.
  • Arsip hingga 200.000 entri, dan filter yang menemukan class atau file di antara 50.000 entri sambil Anda mengetik.
  • Generic signature, record, permitted subclass, nest host, dan anotasi di data class.
  • Resource teks seperti properties, XML, JSON, SQL, dan file services sebagai teks, serta pratinjau hex untuk file biner.
  • Arsip Spring Boot BOOT-INF/lib, WAR WEB-INF/lib, dan AAR classes.jar, satu tingkat ke dalam.

Yang tidak bisa dilakukan

  • Source hasil dekompilasi memerlukan Java 8 atau lebih baru di komputer Anda. Tanpa Java, bytecode dan semua tampilan lain tetap berfungsi.
  • Output CFR bisa berbeda dari source aslinya, misalnya pada nama variabel lokal, sebagian generic, dan lambda.
  • Setiap entri dibuka hingga 64 MB, file class hingga 16 MB, dan arsip bersarang hingga 128 MB. File di file system remote atau virtual dibaca hingga 256 MB.
  • Ekstensi ini baca-saja, jadi Anda tidak bisa mengedit atau mengompilasi ulang class. Arsip bersarang hanya terbuka satu tingkat ke dalam.
  • File APK dan DEX tidak dibaca.

Pertanyaan umum

Apakah ini gratis?

Ya. Semua tampilan dan dekompilasi class satu per satu gratis. Tiga alat Pro, Export decompiled sources of a JAR, Compare two JARs, dan Find in every JAR of a folder, masing-masing bisa dicoba 3 kali gratis, dan percobaan hanya dihitung saat alat memberikan hasil. Setelah itu alat-alat ini memerlukan Zovo Pro, USD 19 sekali bayar untuk semua ekstensi Zovo.

Mengapa tab Java source meminta Java?

CFR adalah program Java. Viewer mencari Java di jarViewer.javaPath, lalu JAVA_HOME, lalu java di PATH Anda. Runtime Java 8 atau yang lebih baru apa pun bisa dipakai.

Apakah bytecode bisa dibaca tanpa Java?

Bisa. Tab Bytecode, Members, Constant pool, dan Class info dibaca dengan JavaScript dan tidak memerlukan Java.

Apakah bisa dipakai di Cursor?

Bisa. Ekstensi ini ada di Open VSX sebagai zovo/zovo-jar-viewer, jadi Cursor, Windsurf, dan VSCodium bisa memasangnya.
