Jelajahi bucket AWS S3, Cloudflare R2, atau MinIO di VS Code

Pasang ekstensi gratis S3 Explorer lalu buka tampilan S3 Buckets di Activity Bar. Ekstensi ini bekerja dengan AWS S3 (profil dari ~/.aws, termasuk profil SSO), Cloudflare R2, MinIO, Backblaze B2, Wasabi, dan DigitalOcean Spaces. Menjelajah, membuka objek read-only, upload, download, copy, move, rename, delete, versions, tags, presigned URL, dan sync folder gratis, tanpa sign-in dan tanpa telemetri. Zovo Pro (USD 19 sekali bayar) menambahkan tiga alat, Copy to Another Connection, Size and Cost Report, dan Scheduled Sync, dan masing-masing bisa dicoba 3 kali gratis.

Langkah di VS Code

  1. Pasang S3 Explorer dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.zovo-s3-explorer.
  2. Buka tampilan S3 Explorer di Activity Bar lalu klik Add Connection. Pilih profil AWS dari ~/.aws, atau ketik access key, account ID dan token R2, atau endpoint URL MinIO atau layanan lain yang kompatibel dengan S3. Key yang Anda ketik disimpan di keychain OS.
  3. Buka sebuah koneksi untuk melihat bucket-nya. Key dimuat 1.000 sekaligus dengan baris "Load 1,000 more". Jika key Anda tidak boleh melihat daftar bucket, klik kanan koneksi lalu pilih Add Bucket by Name.
  4. Klik sebuah objek untuk membukanya read-only di tab atau di viewer yang sesuai. Untuk melihat metadata, tags, versions, dan presigned URL, klik kanan objek lalu pilih Show Details, Versions and Presigned URL.
  5. Untuk mengubah sebuah objek, klik kanan lalu pilih Edit and Upload. Anda mengedit salinannya, dan sebuah dialog menampilkan bucket, key, dan kedua ukuran sebelum objek diganti.
  6. Seret file atau folder dari Explorer ke sebuah bucket untuk mengunggahnya, atau klik kanan lalu pilih Download. File 16 MB atau lebih diunggah per bagian dengan progres dan Cancel, dan upload yang terhenti dilanjutkan dengan hanya mengirim bagian yang hilang.
  7. Untuk menjaga folder lokal dan sebuah prefix tetap sama, klik kanan bucket atau folder lalu pilih Sync Folder. Anda melihat rencana dry-run (baru, berubah, akan dihapus) sebelum ada yang berubah.

Yang gratis dan yang ditambahkan Zovo Pro

Menjelajah, membuka, Edit and Upload, upload, download, copy, move, rename, delete, versions, tags, presigned URL, dan sync folder gratis, tanpa sign-in, tanpa akun, dan tanpa telemetri. Ekstensi ini hanya terhubung ke endpoint penyimpanan yang Anda tambahkan.

Copy to Another Connection menyalin objek atau seluruh folder dari satu koneksi ke koneksi lain, misalnya dari AWS S3 ke Cloudflare R2 atau MinIO, dengan konfirmasi yang sama seperti setiap copy: key dicantumkan, dan key yang akan diganti disebutkan. Objek besar dikirim lewat multipart upload. Anda memindahkan data antar penyedia atau antar akun dari tree, tanpa script atau alat kedua.

Cara memakai Copy to Another Connection (Zovo Pro)

  1. Tambahkan koneksi kedua terlebih dahulu. Lalu klik kanan sebuah objek atau folder di tampilan S3 Buckets dan pilih "Copy to Another Connection... (Pro)", atau klik Copy to Another Connection di baris "Zovo Pro tools" di bagian bawah tampilan.
  2. Pilih koneksi tujuan, bucket, dan folder tujuan (kosongkan untuk level teratas).
  3. Baca daftar objek di konfirmasi lalu klik Copy, atau Copy and Replace jika sebagian key sudah ada. Sebuah notifikasi menampilkan progresnya.
  4. Percobaan hanya dihitung jika ada objek yang tersalin. Escape saat memilih, atau koneksi kedua yang belum ada, tidak memakai percobaan.

Copy to Another Connection bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.zovo-s3-explorer lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/zovo-s3-explorer.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan S3 Explorer

  • Profil AWS dengan access key, credential_process, role dengan source_profile, dan profil SSO setelah aws sso login. endpoint_url di sebuah profil dipakai.
  • MinIO dan layanan lain yang kompatibel dengan S3 dengan endpoint URL, region, URL path-style atau virtual-hosted, dan opsi untuk menerima sertifikat self-signed.
  • Metadata, content type, storage class, ETag, tags (edit dan simpan), versions (buka, unduh, pulihkan), dan presigned URL GET atau PUT dari 15 menit sampai 7 hari.
  • Bucket dengan jutaan key, 1.000 sekaligus, dengan pencarian dan filter berdasarkan prefix.
  • Download mempertahankan struktur folder dan tidak pernah menulis di luar folder yang Anda pilih. Key dengan segmen .., huruf drive, atau byte NUL dilewati dan dicantumkan.

Yang tidak bisa dilakukan

  • Ekstensi ini tidak pernah memakai profil AWS default atau AWS_PROFILE dengan sendirinya. Anda yang memilih profil untuk terhubung.
  • Objek teks di atas 10 MB bertanya dulu, lalu menampilkan 1 MB pertama. Objek biner di atas 200 MB bertanya sebelum diunduh.
  • Objek yang dibuka bersifat read-only. Hanya Edit and Upload yang menulis ke bucket, setelah konfirmasi.
  • Scheduled Sync hanya berjalan selama VS Code terbuka, setiap 5 sampai 60 menit, dan tidak pernah menghapus.
  • Request yang tidak mendapat jawaban berhenti setelah 30 detik (pengaturan s3Explorer.requestTimeoutSeconds).

Pertanyaan umum

Apakah gratis?

Menjelajah, membuka, upload, download, copy, move, rename, delete, versions, tags, presigned URL, dan sync folder gratis. Tiga alat Pro, Copy to Another Connection, Size and Cost Report, dan Scheduled Sync, masing-masing bisa dicoba 3 kali gratis. Setelah itu alat tersebut memerlukan Zovo Pro, USD 19 sekali bayar untuk semua ekstensi Zovo.

Di mana key saya disimpan?

Key yang Anda ketik masuk ke keychain OS melalui VS Code SecretStorage, tidak pernah ke file pengaturan. Profil AWS dibaca dari ~/.aws hanya saat Anda memilih salah satunya.

Apakah bisa dipakai dengan Cloudflare R2 dan MinIO?

Bisa. R2 memakai account ID Anda dan access key dari sebuah R2 API token. MinIO dan layanan lain yang kompatibel dengan S3 memakai endpoint URL, region, dan URL path-style atau virtual-hosted.

Apakah bisa dipakai di Cursor?

Bisa. Cursor, Windsurf, dan VSCodium memasangnya dari Open VSX, tempat ekstensi ini diterbitkan sebagai zovo/zovo-s3-explorer.
