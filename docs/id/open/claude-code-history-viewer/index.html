Membaca dan melanjutkan riwayat Claude Code di VS Code

Pasang Claude Code History & Codex History Viewer (Agent Session Viewer). Ekstensi ini mencantumkan sesi Claude Code Anda dari ~/.claude/projects dan sesi Codex dari ~/.codex/sessions dalam satu tampilan samping, membuka setiap sesi sebagai transkrip yang mudah dibaca, dan melanjutkannya di terminal dengan satu klik. Membaca, pencarian, resume, dan ekspor satu sesi ke Markdown gratis, tanpa akun. Zovo Pro (USD 19 sekali bayar) menambahkan laporan pemakaian dan biaya, ekspor yang aman dibagikan dengan rahasia disamarkan, dan ekspor massal ke Markdown, dan setiap alat Pro bisa dicoba 3 kali gratis.

Langkah di VS Code

  1. Pasang Agent Session Viewer dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.agent-session-viewer.
  2. Klik ikon Agent Sessions di Activity Bar. Tampilan Sessions mencantumkan sesi Claude Code dan Codex, dikelompokkan per folder proyek, dengan subagent di bawah sesi yang memulainya.
  3. Klik sebuah sesi untuk membacanya. Pemanggilan tool diciutkan, pemanggilan yang gagal diberi tanda merah, dan edit file tampil sebagai diff. Header menampilkan model, branch git, jumlah giliran, dan total token.
  4. Untuk menemukan sesi lama, klik ikon pencarian di bagian atas tampilan, atau jalankan “Agent Sessions: Search Sessions” dari Command Palette. Pilih sebuah hasil untuk membuka sesi tepat di bagian yang cocok.
  5. Klik ikon terminal di sebelah sesi (Resume in Terminal). Terminal terbuka di folder proyek dan menjalankan claude --resume <id> atau codex resume <id>.
  6. Untuk file sesi .jsonl di folder lain, klik kanan file itu, pilih Open With, lalu pilih Agent Session Viewer.

Yang gratis dan yang ditambahkan Zovo Pro

Fitur gratisnya mencakup pohon Sessions, membaca sesi, pencarian di semua sesi, Resume in Terminal, Copy Resume Command, ekspor satu sesi ke Markdown, tampilan mentah, dan Reveal in File Manager. Tidak ada batas riwayat dan tidak perlu sign-in.

Share-safe export menyimpan satu sesi, atau semua sesi dari satu proyek, sebagai satu halaman HTML mandiri atau satu file Markdown. API key, token, kata sandi di URL, nilai .env, private key, alamat email, dan folder home Anda diganti dengan [REDACTED ...], dan pesannya mencantumkan apa saja yang disembunyikan. Anda bisa mengirim sebuah sesi untuk pull request, audit, atau serah terima tanpa membersihkannya secara manual.

Cara memakai Share-safe export (Zovo Pro)

  1. Buka sesi, lalu klik tombol Share-safe export di toolbar sesi. Atau klik kanan sebuah sesi atau folder proyek di pohon Sessions dan pilih “Share-Safe Export, Secrets Redacted (Pro)…”.
  2. Saat sesi terbuka, Anda juga bisa menjalankan “Agent Sessions: Share-Safe Export, Secrets Redacted (Pro)…” dari Command Palette.
  3. Pilih formatnya, halaman HTML atau Markdown, dengan atau tanpa output tool. Lalu tentukan lokasi penyimpanan file.
  4. Baca hasil ekspornya sebelum Anda membagikannya. Percobaan baru dihitung saat file tersimpan, dan Escape atau Cancel tidak memakai percobaan.

Share-safe export bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.agent-session-viewer lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/agent-session-viewer.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan Agent Session Viewer

  • Sesi Claude Code di ~/.claude/projects (atau folder projects di dalam CLAUDE_CONFIG_DIR) dan sesi Codex di ~/.codex/sessions (atau folder sessions di dalam CODEX_HOME).
  • Subagent dari kedua tool, bersarang di bawah sesi yang memulainya.
  • Header berisi tool, model, folder proyek, branch git, durasi, jumlah giliran, total token, dan biaya jika file mencatatnya (Claude Code mencatatnya, Codex tidak).
  • Edit file sebagai diff (Edit, Write, dan apply_patch), serta thinking dan ringkasan reasoning Codex, dalam keadaan diciutkan.
  • Nama thread Codex dari session_index.jsonl, jadi thread yang sudah diganti namanya tetap memakai nama itu.

Yang tidak bisa dilakukan

  • Ekstensi ini hanya membaca Claude Code dan Codex. Sesi Cursor, Copilot, dan Gemini CLI belum didukung.
  • Ekstensi ini baca-saja. File sesi tidak pernah diubah, dipindahkan, atau dihapus, dan tidak ada perintah hapus.
  • Pencarian mencocokkan teks biasa, bukan regular expression, dan berhenti di 300 hasil.
  • Resume in Terminal memerlukan Claude Code atau Codex yang terpasang dan ada di PATH terminal.
  • File dibaca hingga 256 MB secara bawaan (agentSessionViewer.maxFileSizeMB). File yang lebih besar terbuka dengan bagian awalnya saja. Reasoning Codex yang tersimpan terenkripsi tidak bisa ditampilkan.

Pertanyaan umum

Di mana Claude Code menyimpan riwayat chat?

Di ~/.claude/projects, satu folder per proyek dan satu file .jsonl per sesi. Jika CLAUDE_CONFIG_DIR diatur, riwayatnya ada di bawah folder itu.

Apakah ini gratis?

Ya. Membaca, pencarian, resume, dan ekspor satu sesi ke Markdown gratis, tanpa batas riwayat. Tiga alat Pro (laporan pemakaian dan biaya, share-safe export, ekspor massal) masing-masing bisa dicoba 3 kali gratis, lalu Zovo Pro seharga USD 19 sekali bayar untuk semua ekstensi Zovo.

Bisakah saya menghapus sesi lama dari viewer?

Tidak. Ekstensi ini hanya membaca file sesi Anda dan tidak pernah mengubah, memindahkan, atau menghapusnya.

Apakah ini buatan Anthropic?

Bukan. Ekstensi ini tidak dibuat oleh Anthropic atau OpenAI dan tidak berafiliasi dengan keduanya. Ekstensi ini tidak melakukan panggilan jaringan dan tidak punya telemetri.
