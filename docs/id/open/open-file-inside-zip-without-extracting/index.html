Membuka file di dalam ZIP tanpa mengekstraknya

Pasang ZIP Viewer & Archive Explorer yang gratis lalu klik file .zip, .jar, .vsix, .tar, .tar.gz, atau .gz. Ekstensi ini mencantumkan folder dan file di dalamnya, dan klik dua kali membuka sebuah file di tab baca-saja biasa, dibaca langsung dari arsip, jadi tidak ada yang dibongkar. Menelusuri arsip, membuka entri, pencarian nama, dan ekstraksi gratis. Zovo Pro (USD 19 sekali bayar) menambahkan tiga alat, membandingkan dua arsip, mengekspor daftar entri, dan mencari file di semua arsip dalam satu folder, dengan 3 kali percobaan gratis masing-masing.

Langkah di VS Code

  1. Pasang ZIP Viewer & Archive Explorer dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.zip-archive-explorer.
  2. Klik file .zip, .jar, .vsix, .tar, .tar.gz, .tgz, atau .gz di Explorer. File terbuka sebagai daftar folder dan file dengan ukuran, ukuran terkompresi, rasio, dan tanggal. Untuk .war, .whl, .nupkg, .apk, atau .epub, klik kanan lalu pilih Open in Archive Explorer.
  3. Temukan filenya. Klik dua kali sebuah folder, pakai bilah path di bagian atas, atau tekan Backspace untuk naik satu tingkat. Atau ketik di kotak pencarian. * dan ? berfungsi sebagai wildcard, misalnya *.json.
  4. Klik dua kali file itu atau tekan Enter. File terbuka dalam mode baca-saja di tab biasa. Kode mendapat pewarnaan sintaks, gambar terbuka di pratinjau gambar, dan ZIP di dalam ZIP terbuka sebagai arsip lain.
  5. Bagian Archive Explorer di sidebar Explorer mencantumkan setiap arsip yang sudah Anda buka. Klik kanan sebuah entri di sana untuk Open to the Side, Extract..., atau Copy Path.
  6. Untuk mengubah file, pilih file itu lalu klik Extract.... Satu file melewati dialog simpan. Nama yang berisi .. atau path absolut tidak pernah ditulis, dan arsipnya sendiri tidak pernah diubah.

Yang gratis dan yang ditambahkan Zovo Pro

Menelusuri arsip, membuka entri di tab, pencarian nama, pohon di sidebar, Copy Path, dan ekstraksi gratis. Ekstensi ini berjalan offline, tanpa panggilan jaringan dan tanpa telemetri.

Saat Anda tahu nama filenya tetapi tidak tahu arsip build, cadangan, atau rilis mana yang menyimpannya, membuka arsip satu per satu terlalu lama. Find a file in all archives of a folder mencari di nama entri setiap file ZIP, JAR, WAR, VSIX, TAR, dan GZ di bawah sebuah folder, mencantumkan setiap hasil dengan arsip dan path-nya, lalu membuka yang Anda pilih di tab baca-saja. Alat ini tidak menulis file apa pun.

Cara memakai Find a file in all archives of a folder (Zovo Pro)

  1. Jalankan “Archive Explorer: Find a File in All Archives of a Folder... (Pro)” dari Command Palette lalu pilih folder yang akan dicari, atau klik kanan sebuah folder di Explorer dan pilih “Zovo Pro: Find a file in all archives of a folder”.
  2. Ketik nama file. * dan ? berfungsi sebagai wildcard, misalnya log4j*.jar atau *.properties.
  3. Pilih satu hasil dari daftar. File terbuka dalam mode baca-saja di tab, seperti entri lainnya. Percobaan baru dihitung jika ada setidaknya satu hasil.

Find a file in all archives of a folder bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.zip-archive-explorer lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/zip-archive-explorer.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan ZIP Viewer & Archive Explorer

  • ZIP, JAR, dan VSIX, dengan entri Stored dan Deflate, ZIP64, dan arsip self-extracting.
  • TAR (ustar, nama panjang GNU, dan header pax), TAR.GZ, TGZ, dan file GZ tunggal.
  • WAR, EAR, WHL, NUPKG, APK, AAR, XPI, dan EPUB melalui Open in Archive Explorer.
  • Arsip dengan hingga 200.000 entri, dibaca dari disk per bagian, jadi ZIP besar tidak dimuat utuh.

Yang tidak bisa dilakukan

  • Entri yang dikompresi dengan BZIP2, LZMA, Zstandard, atau Deflate64, serta entri terenkripsi, dicantumkan tetapi tidak dibuka.
  • File 7z, RAR, XZ, dan BZ2 tidak didukung.
  • Entri bersifat baca-saja. Ekstrak file untuk mengubahnya.
  • Entri di atas 512 MB tidak terbuka di tab tetapi tetap bisa diekstrak. File .tar.gz dibongkar di memori, hingga 2 GB secara bawaan.

Pertanyaan umum

Apakah ini gratis?

Menelusuri arsip, membuka entri, pencarian nama, pohon di sidebar, dan ekstraksi gratis. Tiga alat Pro, Compare two archives, Export the entry list, dan Find a file in all archives of a folder, masing-masing bisa dicoba 3 kali gratis. Setelah itu alat-alat ini memerlukan Zovo Pro, USD 19 sekali bayar untuk semua ekstensi Zovo.

Apakah file disalin ke folder sementara saat saya membukanya?

Tidak. Entri dibaca dari arsip ke tab baca-saja. Hanya Extract yang menulis file ke disk.

Bisakah saya mengedit file di dalam ZIP?

Tidak. Entri bersifat baca-saja dan arsip tidak pernah diubah. Ekstrak filenya, edit, lalu kemas ulang arsipnya dengan alat lain.

Apakah bisa dipakai di Cursor?

Bisa. ZIP Viewer & Archive Explorer ada di Open VSX, jadi Cursor, Windsurf, dan VSCodium bisa memasangnya.
