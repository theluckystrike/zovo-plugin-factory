Edit file .proto di VS Code dengan highlighting, format, dan go to definition

Pasang ekstensi gratis Protobuf & Proto3 Formatter lalu buka folder berisi file .proto. Ekstensi ini menambahkan highlighting, formatter yang menjaga setiap komentar, go to definition, find references, dan error dengan kata-kata protoc, untuk proto2, proto3, dan editions 2023 dan 2024. Ekstensi ini berjalan offline dengan parser sendiri, jadi tidak perlu protoc, language server, atau setup apa pun, dan semua itu gratis. Zovo Pro (USD 19 sekali bayar) menambahkan tiga alat, Check Breaking Changes Against Git, Generate API Docs, dan Decode a Binary Message, dan masing-masing bisa dicoba 3 kali gratis.

Langkah di VS Code

  1. Pasang Protobuf & Proto3 Formatter dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.zovo-protobuf.
  2. Buka folder berisi file .proto. Highlighting, outline, dan breadcrumbs langsung aktif.
  3. Tekan Shift+Alt+F (Shift+Option+F di macOS) untuk memformat, atau nyalakan editor.formatOnSave. Anda mendapat satu statement per baris, indentasi dari editor Anda, dan satu spasi di sekitar =. Komentar, kelompok baris kosong, dan baris baru Anda di statement panjang tetap di tempatnya.
  4. Tekan F12 pada sebuah type atau import untuk membuka definisinya, dan Shift+F12 untuk melihat daftar pemakaiannya. Ctrl atau Cmd klik sebuah import untuk membuka filenya. Arahkan kursor ke sebuah type untuk melihat field dan komentarnya.
  5. Error tampil di panel Problems dengan kata-kata protoc: nomor field ganda (dengan nomor bebas berikutnya), type yang tidak dikenal, type yang dipakai tanpa import-nya, nomor dan nama yang di-reserve, serta aturan proto3 dan editions. Import yang tidak dipakai tampil pudar.
  6. Jika import Anda berawal dari folder seperti proto/ atau third_party/, import ditemukan dengan menelusuri ke atas dari setiap file. Untuk root lain, tambahkan ke pengaturan zovoProto.importPaths, seperti yang Anda lakukan dengan protoc -I.

Yang gratis dan yang ditambahkan Zovo Pro

Highlighting (juga untuk blok kode proto di Markdown), Format Document, go to definition, find references, error bergaya protoc, outline, Go to Symbol in workspace, hover, dan completion, termasuk nomor field bebas berikutnya setelah =, gratis. Tanpa sign-in, tanpa permintaan jaringan, dan tanpa telemetri.

Sebelum Anda melakukan merge perubahan pada file .proto, Check Breaking Changes Against Git membandingkan file Anda dengan main (atau branch yang Anda atur) dan mencantumkan field yang dihapus, nomor, type, dan label yang berubah, field dan nilai enum yang diganti namanya, serta method yang dihapus atau diubah. Setiap temuan menyebutkan apakah perubahan itu merusak data biner, JSON, atau hanya kode yang di-generate, sehingga Anda melihat apa yang akan salah dibaca oleh client lama sebelum hal itu terjadi. Anda bisa menyimpan temuan sebagai file JSON untuk CI.

Cara memakai Check Breaking Changes Against Git (Zovo Pro)

  1. Klik kanan file .proto atau sebuah folder di Explorer lalu pilih "Zovo Pro: Check breaking changes against git", klik kanan di editor .proto lalu pilih "Check Breaking Changes Against Git (Pro)", atau jalankan "Protobuf: Check Breaking Changes Against Git (Pro)" dari Command Palette. Folder harus berada di repositori git, dan git harus terpasang.
  2. Pemeriksaan membandingkan setiap file .proto di repositori pada working tree Anda, termasuk perubahan yang belum disimpan, dengan merge base dari origin/main, main, origin/master, atau master (yang pertama ada), atau dari branch di pengaturan zovoProto.baseBranch. Laporan Markdown terbuka dengan temuan yang dikelompokkan per file.
  3. Klik "Save JSON for CI" di pesan yang muncul untuk menyimpan temuan sebagai proto-breaking.json.
  4. Percobaan hanya dihitung jika laporan terbuka. Folder di luar git atau base branch yang tidak ada tidak memakai percobaan.

Check Breaking Changes Against Git bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.zovo-protobuf lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/zovo-protobuf.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan Protobuf & Proto3 Formatter

  • proto2, proto3, dan editions (2023, 2024), serta blok kode proto di Markdown.
  • Aturan scope protobuf untuk go to definition dan find references lintas import: type bersarang, package, dan . di awal nama.
  • Nama bawaan untuk well-known types seperti google/protobuf/timestamp.proto.
  • Tidak ada tanda merah yang keliru. Jika sebuah import tidak ada di workspace Anda, baris import memberitahukannya dan type yang dibawanya tidak ditebak.
  • Completion untuk type, keyword, option, path import, dan nomor field bebas berikutnya setelah =.

Yang tidak bisa dilakukan

  • Nama custom option diperiksa import-nya, tetapi tidak terhadap type field dari extension-nya.
  • Pemeriksaan feature editions mencakup enum_type, label, packed, dan group. Aturan feature lain diserahkan ke protoc.
  • Formatter menjaga baris baru Anda di dalam statement panjang. Formatter tidak memotong baris panjang dan tidak menyejajarkan = dalam kolom.
  • Format memerlukan file yang bisa di-parse. Perbaiki dulu error di panel Problems.
  • Import lintas file memerlukan folder di disk. Di virtual workspace hanya highlighting, format, dan outline yang berfungsi.

Pertanyaan umum

Apakah gratis?

Highlighting, format, go to definition, find references, error bergaya protoc, hover, dan completion gratis. Tiga alat Pro, Check Breaking Changes Against Git, Generate API Docs, dan Decode a Binary Message, masing-masing bisa dicoba 3 kali gratis. Setelah itu alat tersebut memerlukan Zovo Pro, USD 19 sekali bayar untuk semua ekstensi Zovo.

Apakah saya perlu memasang protoc?

Tidak. Ekstensi ini punya parser sendiri dan berjalan offline. Pesan errornya memakai kata-kata yang sama dengan protoc.

Mengapa sebuah import menampilkan catatan, bukan tanda merah?

File yang di-import tidak ada di workspace Anda. Tambahkan folder root-nya ke zovoProto.importPaths, seperti protoc -I.

Apakah bisa dipakai di Cursor?

Bisa. Cursor, Windsurf, dan VSCodium memasangnya dari Open VSX, tempat ekstensi ini diterbitkan sebagai zovo/zovo-protobuf.
