Format XML di VS Code dan jalankan XPath di file tersebut

Pasang ekstensi gratis XML Formatter & XPath Tools, buka file XML, lalu tekan Shift+Alt+F (Shift+Option+F di Mac). Hanya spasi di antara tag yang berubah. Teks, CDATA, komentar, xml:space="preserve", dan nilai atribut tetap sama persis sampai ke byte-nya, dan file yang tidak well-formed tidak pernah diubah. Format, Minify XML, XPath 1.0 dengan prefix namespace milik file, Copy XPath, dan tampilan XML Tree gratis dan bekerja offline. Langkah di VS Code

  1. Pasang XML Formatter & XPath Tools dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.zovo-xml-xpath-tools.
  2. Buka file .xml lalu tekan Shift+Alt+F (Shift+Option+F di Mac), atau jalankan Format Document. Jika Anda punya lebih dari satu formatter XML, VS Code menanyakan mana yang dipakai. Format Selection juga bisa.
  3. Formatter memakai ukuran tab serta pilihan tab atau spasi Anda, dan mempertahankan akhir baris, byte order mark, dan baris baru terakhir. Jika file tidak well-formed, tidak ada yang berubah dan Anda mendapat error dengan baris dan kolomnya.
  4. Untuk membuat file lebih kecil, jalankan "XML: Minify XML" pada seluruh file atau pada pilihan teks. Komentar tetap ada kecuali Anda menyalakan xmlXpathTools.minify.removeComments.
  5. Untuk menjalankan XPath, klik tombol pencarian di judul editor atau jalankan "XML: Evaluate XPath…". Hasilnya tampil di XPath Results beserta barisnya. Klik salah satu untuk memilihnya di editor.
  6. Klik XPath di status bar untuk menyalin path elemen di bawah kursor: dengan posisi, dengan atribut id atau name, atau dalam bentuk portabel local-name().
  7. Untuk file di atas 50 MB, klik kanan file di Explorer lalu pilih "Format Large XML File on Disk…". Perintah ini menulis name.formatted.xml di sebelahnya, atau mengganti file setelah Anda mengonfirmasi.

Yang gratis dan yang ditambahkan Zovo Pro

Format Document, Format Selection, Minify XML, XPath 1.0, Copy XPath, tampilan XML Tree, error well-formedness di Problems, dan Format Large XML File on Disk gratis. Tidak perlu sign-in, dan ekstensi ini tidak punya kode jaringan.

Run XPath on Every XML File in a Folder menjalankan satu XPath pada setiap file .xml, .xsd, .csproj, .svg, .kml, dan file sejenis di dalam sebuah folder, masing-masing dengan prefix namespace miliknya sendiri. Hasilnya terbuka sebagai CSV (file, line, kind, name, value) untuk spreadsheet, sebagai JSON untuk script, atau sebagai laporan Markdown untuk review. Anda mendapatkan nilai yang sama dari banyak file, misalnya setiap artifactId di sekumpulan file pom.xml, tanpa membukanya satu per satu.

Cara memakai Run XPath on Every XML File in a Folder (Zovo Pro)

  1. Klik kanan sebuah folder di Explorer lalu pilih "Zovo Pro: Run XPath on Every XML File in a Folder", atau jalankan "XML: Run XPath on Every XML File in a Folder (Pro)" dari Command Palette dan pilih foldernya.
  2. Atau, setelah menjalankan XPath di satu file, klik baris terakhir XPath Results, "Run this XPath on every XML file in a folder", untuk menjalankan ekspresi yang sama pada sebuah folder.
  3. Ketik XPath-nya. Sebuah notifikasi menampilkan progres dengan tombol Cancel.
  4. Pilih "Open as CSV", "Open as JSON", atau "Open a Markdown report". Hasilnya terbuka di tab editor baru. Percobaan hanya dihitung jika Anda mendapat hasil. Escape, salah ketik di XPath, atau folder tanpa file XML tidak memakai percobaan.

Run XPath on Every XML File in a Folder bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.zovo-xml-xpath-tools lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/zovo-xml-xpath-tools.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan XML Formatter & XPath Tools

  • File yang dibuka VS Code sebagai XML. Ekstensi ini juga membuka file .kml, .gpx, .rss, .atom, .wsdl, .dbk, .xlf, .xliff, .resx, .nuspec, .props, .targets, dan .xaml sebagai XML.
  • File besar: format, tree, dan XPath berjalan di thread latar belakang. Dalam pengujian ekstensi, file 49 MB dengan sekitar 1 juta elemen diformat dalam 1,6 detik.
  • Nama biasa juga cocok dengan default namespace, sehingga //dependency/artifactId berfungsi di pom.xml. Nyalakan xmlXpathTools.xpath.strictNamespaces untuk XPath 1.0 yang ketat.
  • Tata letak atribut: tetap seperti ditulis, satu baris, atau satu atribut per baris (pengaturan xmlXpathTools.format.attributes).
  • Tampilan XML Tree di Explorer mengikuti kursor, dan Problems mencantumkan error well-formedness beserta baris dan kolomnya.

Yang tidak bisa dilakukan

  • Hanya XPath 1.0. Tidak ada XPath 2.0 atau 3.1, XQuery, atau XSLT.
  • Ekstensi ini memeriksa apakah file well-formed. Ekstensi ini tidak memvalidasi terhadap XSD atau DTD.
  • File di atas 50 MB bisa diformat di disk, tetapi VS Code tidak memberikannya ke ekstensi, sehingga tree dan XPath tidak berjalan pada file tersebut.
  • Perintah on-disk membaca UTF-8, UTF-16 dengan byte order mark, dan ISO-8859-1.
  • Elemen yang berisi teks, seperti <p>Some <b>bold</b> text</p>, tetap di barisnya seperti ditulis. Hanya elemen yang berisi tag tanpa teks yang mendapat baris baru.

Pertanyaan umum

Apakah gratis?

Format, Minify XML, XPath, Copy XPath, tampilan XML Tree, dan pemeriksaan well-formedness gratis. Tiga alat Pro, Run XPath on Every XML File in a Folder, Format All XML Files in a Folder, dan Compare Two XML Files Ignoring Formatting, masing-masing bisa dicoba 3 kali gratis. Setelah itu alat tersebut memerlukan Zovo Pro, USD 19 sekali bayar untuk semua ekstensi Zovo.

Apakah format mengubah teks atau CDATA saya?

Tidak. Hanya spasi di antara tag yang berubah, pada elemen yang berisi tag tanpa teks. Teks, CDATA, komentar, dan isi di dalam xml:space="preserve" disalin apa adanya, dan format kedua tidak mengubah apa pun.

Mengapa XPath saya tidak memilih apa pun di pom.xml?

File tersebut punya default namespace. Di ekstensi ini, nama biasa juga cocok dengan default namespace, sehingga //dependency berfungsi. Nyalakan xmlXpathTools.xpath.strictNamespaces untuk XPath 1.0 yang ketat.

Apakah bisa dipakai di Cursor?

Bisa. Cursor, Windsurf, dan VSCodium memasangnya dari Open VSX, tempat ekstensi ini diterbitkan sebagai zovo/zovo-xml-xpath-tools.
