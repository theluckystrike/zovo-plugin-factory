Viewer NetCDF gratis yang berjalan di VS Code

Pasang ekstensi gratis NetCDF Viewer & HDF5 Viewer di VS Code lalu klik file .nc. Anda mendapatkan header, pohon variabel, peta dengan garis pantai, slider waktu, dan deret waktu dari titik mana pun yang Anda klik, tanpa Python, NCL, atau pemasangan lain. Viewer yang sama membuka file HDF5 .h5 dan file MATLAB 7.3 .mat, dan semua ini gratis. Zovo Pro (USD 19 sekali bayar) menambahkan dua alat, Compare two files dan Export a subset, dan masing-masing bisa dicoba 3 kali gratis.

Langkah di VS Code

  1. Pasang NetCDF Viewer & HDF5 Viewer dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.hdf5-netcdf-explorer.
  2. Klik file .nc, .nc4, .netcdf, atau .cdf di Explorer. Ringkasannya menampilkan format, dimensi, atribut global, dan tabel semua variabel, mirip ncdump -h.
  3. Pilih variabel di pohon sebelah kiri. Irisan 2D digambar sebagai heatmap, dengan garis pantai jika baris dan kolomnya adalah lintang dan bujur.
  4. Geser slider waktu, atau tekan ▶ di sebelahnya untuk memutar sepanjang waktu. Klik satu titik di peta untuk menggambar deret waktunya.
  5. Buka tab Table untuk menelusuri nilai per halaman, 100 baris kali 30 kolom, dengan nilai koordinat sebagai judul kolom.
  6. Klik “Save PNG” untuk menyimpan plot, atau “Export slice…” untuk menyimpan irisan di layar sebagai CSV atau JSON. “Copy xarray code” memberi baris Python untuk irisan yang sama.
  7. Untuk file HDF5, klik file .h5. Untuk file MATLAB 7.3 .mat, klik kanan file lalu pilih “Open in HDF5 NetCDF Explorer”.

Yang gratis dan yang ditambahkan Zovo Pro

Semua format, pohon variabel, atribut, tabel, plot dan peta dengan garis pantai, Play, deret waktu per titik, Save PNG, dan Export slice gratis. Ekstensi ini tidak memerlukan Python dan tidak melakukan panggilan jaringan untuk fitur-fitur ini.

Export a subset bekerja seperti ncks -d atau .sel di xarray. Pilih variabel dan rentang untuk setiap dimensi, berdasarkan indeks (0:99) atau berdasarkan nilai (30..60, 2023-08-01..2023-08-31). Alat ini menyimpan file NetCDF dengan koordinat, atribut, dan baris history, atau CSV rapi dengan satu baris per titik. Anda mendapatkan file kecil untuk satu wilayah dan satu periode tanpa menulis skrip.

Cara memakai Export a subset (Zovo Pro)

  1. Buka file lalu klik tombol “Export subset…” di sebelah “Export slice…”, atau klik kanan file di Explorer dan pilih “Zovo Pro: Export a Subset of a Variable”.
  2. Bisa juga dengan menjalankan “NetCDF Viewer Pro: Export Subset of a Variable (NetCDF or CSV)...” dari Command Palette.
  3. Ketik rentang untuk setiap dimensi. Kotaknya menampilkan apa yang Anda pilih sambil Anda mengetik.
  4. Pilih NetCDF atau CSV lalu tentukan lokasi penyimpanan. Notifikasi menampilkan progresnya, dan Cancel menghentikan proses tanpa meninggalkan file yang setengah tertulis.

Export a subset bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.hdf5-netcdf-explorer lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/hdf5-netcdf-explorer.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan NetCDF Viewer & HDF5 Viewer

  • NetCDF-4 dan NetCDF-4 classic, NetCDF-3 classic dan 64-bit offset, serta CDF-5 (data 64-bit).
  • File HDF5 (.h5, .hdf5, .he5, .hdf) dengan kompresi deflate, shuffle, szip, LZF, Blosc, bitshuffle, LZ4, Zstd, bzip2, dan ZFP.
  • MATLAB 7.3 .mat dan file lain berbasis HDF5 seperti .jld2, .loom, dan .h5ad.
  • Dekode CF untuk scale_factor, add_offset, _FillValue, dan satuan waktu, termasuk kalender noleap, 360_day, dan all_leap.
  • File di mesin lain lewat Remote SSH, WSL, atau dev container.

Yang tidak bisa dilakukan

  • Zarr dan HDF4 tidak didukung. File MATLAB .mat yang disimpan dalam format v5 bukan HDF5 dan tidak terbuka. Simpan ulang dengan save(filename, '-v7.3').
  • Garis pantai hanya digambar pada grid lintang-bujur yang teratur. Grid curvilinear dengan lintang dan bujur 2D, serta grid terproyeksi dalam meter, tidak mendapat garis pantai.
  • Array yang lebih besar dari 512 x 512 diambil sampelnya untuk plot. Ekspor menulis paling banyak 1.000.000 nilai per file (pengaturan hdf5NetcdfExplorer.maxReadValues).
  • File system virtual, seperti repositori GitHub yang dibuka di vscode.dev, tidak didukung.
  • Dataset dengan filter HDF5 lain, seperti SZ atau JPEG, menampilkan pesan, bukan nilai.

Pertanyaan umum

Apakah ini gratis?

Melihat data gratis: semua format, peta, Play, deret waktu, Save PNG, dan Export slice. Dua alat Pro, Compare two files dan Export a subset, masing-masing bisa dicoba 3 kali gratis. Setelah itu keduanya memerlukan Zovo Pro, USD 19 sekali bayar untuk semua ekstensi Zovo.

Apakah ada viewer NetCDF untuk Windows?

Ada. Ekstensi ini berjalan di mana pun VS Code berjalan, termasuk Windows, macOS, dan Linux, dan tidak memerlukan Python.

Apakah bisa membuka file HDF5 dan MAT?

Bisa untuk file HDF5 .h5 dan file MATLAB 7.3 .mat. File MATLAB v5 .mat yang lebih lama bukan HDF5, jadi yang muncul adalah pesan.

Apakah bisa dipakai di Cursor?

Bisa. Ekstensi ini ada di Open VSX sebagai zovo/hdf5-netcdf-explorer, jadi Cursor, Windsurf, dan VSCodium bisa memasangnya.
