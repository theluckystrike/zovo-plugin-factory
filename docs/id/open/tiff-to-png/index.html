Mengubah TIFF ke PNG tanpa kehilangan kualitas

Pasang TIFF Viewer & TIF Viewer (16-bit, GeoTIFF). Ekstensi ini membuka file .tif dan .tiff di VS Code, termasuk file 16-bit, float, dan multi-halaman, dan Export PNG menyimpan halaman seperti yang tampil, secara gratis. Alat Zovo Pro Export pages menyimpan halaman ini atau semua halaman sebagai PNG resolusi penuh dengan nilai yang tersimpan, sehingga data 8 dan 16-bit mempertahankan nilai yang tepat. Export pages, Batch convert, dan Region stats masing-masing bisa dicoba 3 kali gratis, lalu Zovo Pro seharga USD 19 sekali bayar.

Langkah di VS Code

  1. Pasang TIFF Viewer dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.tiff-viewer.
  2. Klik file .tif atau .tiff di Explorer. File terbuka di TIFF Viewer. Jika viewer lain yang terbuka, klik kanan file lalu pilih “Open in TIFF Viewer”, atau pakai “Reopen Editor With...” dari menu judul editor.
  3. Gulir untuk zoom dan seret untuk menggeser. Bilah status menampilkan nilai tersimpan di bawah penunjuk.
  4. Untuk file multi-halaman, pilih halaman di strip halaman, atau tekan PageDown dan PageUp (atau J dan K).
  5. Untuk data 16-bit atau float, pakai kontrol Channel dan Contrast stretch (min ke max, 2 sampai 98 persen, atau rentang penuh tipe datanya). Tekan T untuk membuka panel tag, dengan bagian GeoTIFF jika file punya tag GeoTIFF.
  6. Klik Export PNG untuk menyimpan halaman saat ini seperti yang Anda lihat, dengan channel dan stretch yang Anda pilih. Ini gratis.

Yang gratis dan yang ditambahkan Zovo Pro

Fitur gratisnya mencakup semua halaman, channel dan contrast stretch, nilai piksel di bawah penunjuk, tag TIFF, koordinat GeoTIFF, dan Export PNG dari halaman seperti yang tampil. Melihat file berjalan offline dan tanpa sign-in.

Export pages menyimpan halaman ini atau semua halaman dari file multi-halaman sebagai PNG resolusi penuh. Dengan “stored values”, data 8 dan 16-bit mempertahankan nilai yang tepat dalam PNG 8 atau 16-bit. Data bertanda (signed), 32-bit, dan float dipetakan ke 16 bit sesuai rentang yang tampil, dan teks di PNG menjelaskan cara mendapatkan kembali nilainya. Halaman GeoTIFF juga mendapat world file .pgw dan footprint .geojson, sehingga PNG-nya jatuh di tempat yang benar di QGIS atau ArcGIS.

Cara memakai Export pages (Zovo Pro)

  1. Buka file TIFF lalu klik Export pages di toolbar viewer. Anda juga bisa menjalankan “TIFF Viewer: Export Pages to PNG (Pro)...” dari Command Palette saat file terbuka.
  2. Pilih “Page N with the stored values” (PNG 16-bit untuk data 16-bit) atau “Page N as shown” (8-bit). Di file multi-halaman, Anda juga bisa memilih “All N pages with the stored values” atau “All N pages as shown”.
  3. Tentukan nama file, atau foldernya jika semua halaman, lalu simpan. Percobaan baru dihitung saat PNG selesai ditulis, dan Escape tidak memakai percobaan.
  4. Untuk satu folder penuh berisi file TIFF, klik kanan folder itu lalu jalankan “TIFF Viewer: Batch Convert TIFF Folder to PNG (Pro)...” (juga alat Pro).

Export pages bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.tiff-viewer lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/tiff-viewer.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan TIFF Viewer

  • TIFF klasik dan BigTIFF, little-endian dan big-endian, strip dan tile, chunky dan planar.
  • Sampel integer unsigned dan signed 1 sampai 64-bit serta float 16, 32, dan 64-bit, dengan contrast stretch berbasis persentil.
  • Gray, RGB dan RGBA, palet, CMYK, dan YCbCr dalam JPEG, tanpa kompresi, LZW, Deflate, PackBits, JPEG, serta CCITT Group 3 dan 4.
  • File multi-halaman dengan strip halaman dan thumbnail untuk 300 halaman pertama.
  • Tag GeoTIFF, yaitu kode EPSG, ukuran piksel, batas (bounds), nilai nodata, dan koordinat peta di bawah penunjuk.

Yang tidak bisa dilakukan

  • Halaman yang dikompresi dengan ZSTD, LERC, WebP, dan JPEG 2000 dicantumkan dengan tag-nya tetapi tidak didekode.
  • File di atas 1 GB (pengaturan tiffViewer.maxFileMB, bawaan 1024) tidak didekode. File seperti itu menampilkan pesan dan tag dari setiap halaman.
  • Halaman yang sisinya lebih dari 6000 piksel atau totalnya lebih dari 24 juta piksel ditampilkan dengan setiap piksel ke-N. Pembacaan nilai di bawah penunjuk dan statistik tetap memakai resolusi penuh.
  • Halaman tile dengan kurang dari 8 bit per piksel dan YCbCr tanpa kompresi tidak didekode. Sub-image di SubIFD (sebagian piramida DNG dan OME-TIFF) dicantumkan di tag tetapi tidak ditampilkan sebagai halaman.
  • Viewer ini baca-saja dan tidak pernah menulis ke file TIFF. Map tile dan reproyeksi tidak termasuk.

Pertanyaan umum

Apakah mengubah TIFF ke PNG menurunkan kualitas?

PNG bersifat lossless. Kualitas hanya hilang jika data 16-bit diturunkan ke 8-bit. Di Export pages, pilih opsi stored values agar nilai 8 dan 16-bit tetap tepat.

Apakah ini gratis?

Melihat file TIFF dan Export PNG dari halaman seperti yang tampil gratis. Export pages, Batch convert, dan Region stats adalah alat Pro dengan 3 kali percobaan gratis masing-masing, lalu Zovo Pro seharga USD 19 sekali bayar untuk semua ekstensi Zovo.

Apakah gambar saya diunggah?

Tidak. Ekstensi ini tidak melakukan panggilan jaringan sendiri dan tidak punya telemetri. File dibaca dan ditulis di komputer Anda.

Apakah bisa dipakai di Cursor atau Windsurf?

Bisa. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan TIFF Viewer tersedia di sana.
