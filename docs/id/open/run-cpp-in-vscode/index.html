Menjalankan file C++ di VS Code dengan satu klik

Pasang ekstensi gratis Run C++ and C Code, buka file .cpp atau .c, lalu klik Run di judul editor, atau tekan Ctrl+Alt+Enter (Cmd+Alt+Enter di Mac). Ekstensi ini mengompilasi file dengan gcc, g++, clang, atau clang++ yang sudah ada di komputer Anda dan menjalankannya di terminal, tempat cin dan scanf berfungsi. Galat kompilasi masuk ke panel Problems di baris yang tepat, dan panel Input & Tests, stress test, serta benchmark gratis. Zovo Pro (USD 19 sekali bayar) menambahkan pemeriksaan sanitizer, perbandingan -O0, -O2, dan -O3, serta laporan tes, dengan 3 kali percobaan gratis masing-masing.

Langkah di VS Code

  1. Pasang Run C++ and C Code dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.zovo-run-cpp.
  2. Pastikan compiler sudah terpasang. “Run C++: Pick Compiler (gcc, g++, clang, clang++)” mencantumkan compiler yang ditemukan. Jika tidak ada, halaman penyiapan menampilkan langkah resmi untuk sistem Anda (Xcode Command Line Tools, MSYS2 atau WinLibs, atau package manager Linux Anda).
  3. Buka file .cpp, .cc, .cxx, atau .c lalu klik tombol Run di judul editor, atau tekan Ctrl+Alt+Enter (Cmd+Alt+Enter di Mac).
  4. Program berjalan di terminal bernama “Run: file.cpp”. Ketik input-nya di sana. Di akhir, Anda melihat exit code, waktu jalan, dan memori puncak. Selama program berjalan, tombol Run berubah menjadi Stop.
  5. Untuk flag atau argumen, tulis // run: -O2 -lm dan // args: "Hello World" 3 di 40 baris pertama file. Bawaan untuk C++ adalah -std=c++20 -Wall -Wextra -g -O0.
  6. Untuk menguji dengan input tersimpan, jalankan “Run C++: Run with Input & Test Cases”. Tempel input, tekan Run with input, lalu Save as test case. Run all tests menampilkan lulus atau gagal dengan diff per baris.

Yang gratis dan yang ditambahkan Zovo Pro

Run, Build Only, Run Last Build, Debug, build satu folder, panel Input & Tests, stress test, dan benchmark gratis. Tidak perlu sign-in, tidak ada panggilan jaringan, dan tidak ada telemetri.

Program yang lulus semua tes Anda tetap bisa membaca melewati akhir array atau membuat int overflow. Sanitizer check membuat build kedua dengan AddressSanitizer dan UndefinedBehaviorSanitizer (-fsanitize=address,undefined), menjalankannya dengan input di panel dan setiap test case tersimpan, lalu menaruh setiap heap atau stack overflow, use after free, signed overflow, atau undefined behavior lainnya di panel Problems pada barisnya. Anda menemukan bug di barisnya tanpa mengatur flag sanitizer secara manual.

Cara memakai Sanitizer check (Zovo Pro)

  1. Isi input di panel Input & Tests, dan simpan test case jika Anda punya. Pemeriksaan berjalan dengan input di panel dan dengan setiap test case tersimpan.
  2. Klik “Sanitizer check (Pro)” di panel, di bawah “Stress test, benchmark and more”, atau jalankan “Run C++: Sanitizer Check: AddressSanitizer and UBSan on the Input and Test Cases (Zovo Pro)” dari Command Palette.
  3. Klik sebuah temuan di panel Problems untuk melompat ke barisnya. Galat build, Stop, atau Cancel tidak memakai percobaan gratis.

Sanitizer check bisa dipakai 3 kali gratis di komputer Anda sebelum meminta lisensi. Tidak ada popup dan tidak ada hitung mundur.

Langkah di Cursor, Windsurf, atau VSCodium

  1. Buka tampilan Extensions dengan Ctrl+Shift+X (Cmd+Shift+X di macOS).
  2. Cari zovo.zovo-run-cpp lalu klik Install. Cursor, Windsurf, dan VSCodium memasang ekstensi dari Open VSX, dan di sana ekstensi ini bernama zovo/zovo-run-cpp.
  3. Jika editor Anda tidak punya galeri ekstensi, unduh file .vsix dari halaman Open VSX lalu jalankan "Extensions: Install from VSIX...".
  4. Setelah itu, semuanya berjalan sama seperti di VS Code.

Yang bisa dilakukan Run C++ and C Code

  • File C dan C++ (.c, .cpp, .cc, .cxx) dengan gcc, g++, clang, dan clang++.
  • MSYS2, WinLibs, MinGW, TDM-GCC, dan LLVM di folder Windows yang biasa, serta nama Homebrew seperti g++-14.
  • Path yang berisi spasi, &, atau huruf non-ASCII, karena tidak ada shell yang mem-parsing path tersebut.
  • Program yang mencetak sejuta baris. Panel menampilkan 2.000 baris pertama dan menghitung sisanya.

Yang tidak bisa dilakukan

  • Ekstensi ini memerlukan compiler di komputer Anda dan tidak pernah mengunduhnya.
  • Program yang dijalankan dari panel Input dan test case berhenti setelah 10 detik (pengaturan zovoRun.timeLimitSeconds).
  • Output setelah 32 MB hanya dihitung, tidak disimpan (pengaturan zovoRun.maxCapturedOutputMB).
  • Pemeriksaan sanitizer memerlukan compiler dengan runtime sanitizer. MinGW gcc di Windows tidak punya runtime itu, jadi pakai clang dari LLVM di sana. Pemeriksaan memberi tahu hal itu tanpa memakai percobaan.
  • Debug memerlukan CodeLLDB atau ekstensi C/C++ yang terpasang.

Pertanyaan umum

Apakah ini gratis?

Run, Build Only, Debug, build satu folder, panel Input & Tests, stress test, dan benchmark gratis. Tiga alat Pro, Sanitizer check, Compare -O0, -O2 and -O3, dan Test report, masing-masing bisa dicoba 3 kali gratis. Setelah itu alat-alat ini memerlukan Zovo Pro, USD 19 sekali bayar untuk semua ekstensi Zovo.

Apakah program saya bisa membaca input dengan cin?

Bisa. Program berjalan di terminal sungguhan, jadi cin dan scanf menunggu ketikan Anda, dan prompt tanpa baris baru tampil lebih dulu.

Apakah ekstensi ini mengubah settings.json atau tasks.json saya?

Tidak. Ekstensi ini tidak pernah menulis file pengaturan Anda. Debug menambahkan satu entri ke .vscode/launch.json, dan hanya saat Anda menekan Debug.

Apakah bisa dipakai di Cursor?

Bisa. Ekstensi ini ada di Open VSX, jadi Cursor, Windsurf, dan VSCodium bisa memasangnya.
