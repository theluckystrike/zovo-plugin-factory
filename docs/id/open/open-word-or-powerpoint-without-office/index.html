Membuka file Word dan PowerPoint di VS Code tanpa Office

Pasang DOCX Viewer untuk dokumen Word (.docx, .odt, dan file .doc lama sebagai teks) serta PPTX Viewer untuk presentasi (.pptx, .ppsx, .potx, dan file .ppt lama sebagai teks). Keduanya membuka file dengan sekali klik di tab VS Code, tanpa Office atau LibreOffice. Membaca, mencari, outline, melihat tracked changes, dan Copy as Markdown semuanya gratis. Zovo Pro (USD 19 sekali bayar) menambahkan alat seperti ekspor redline ke PDF di DOCX Viewer, dengan 3 kali percobaan gratis untuk setiap alat.

Pasang di VS CodeHalaman MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

Gratis, lisensi MIT. Extension ID zovo.docx-viewer-vscode.

Langkah di VS Code

  1. Pasang DOCX Viewer dari Marketplace, atau tekan Ctrl+P (Cmd+P di macOS) lalu jalankan ext install zovo.docx-viewer-vscode.
  2. Klik file .docx, .dotx, .docm, atau .odt di Explorer. File terbuka di DOCX Viewer sebagai pratinjau hanya-baca yang mengikuti tema VS Code; tombol tema mengubahnya menjadi kertas putih.
  3. Tekan Ctrl+F (Cmd+F di macOS) untuk mencari, dan gunakan outline untuk melompat ke heading. Klik "Page view" di toolbar untuk melihat halaman seperti tata letak di Word.
  4. Tracked changes dan komentar tampil di Reading view, dengan pilihan Markup, Final, dan Original. Tidak ada perubahan yang diterima atau ditolak di dalam file.
  5. Untuk presentasi, pasang juga PPTX Viewer. Klik file .pptx, .ppsx, atau .potx untuk melihat slide beserta thumbnail, catatan pembicara, dan pencarian di seluruh presentasi. File .ppt lama hanya terbuka sebagai teks.
  6. Di PPTX Viewer, klik "Present" untuk menampilkan slide satu per satu dalam layar penuh. Tekan Esc untuk kembali ke editor.
  7. Salin isi sebagai Markdown dengan "Copy as Markdown" di DOCX Viewer, atau dengan "Copy Slide Text as Markdown" dan "Copy All Slides as Markdown" di PPTX Viewer. Satu slide bisa disalin sebagai gambar dengan "Copy Slide as PNG Picture".

Di Cursor, Windsurf, dan VSCodium

Editor ini memasang ekstensi dari Open VSX. Buka tampilan Extensions (Ctrl+Shift+X), cari zovo.docx-viewer-vscode, lalu klik Install. Halamannya di Open VSX adalah zovo/docx-viewer-vscode. Setelah itu cara pakainya sama seperti di VS Code.

Yang gratis

Di DOCX Viewer, Reading view dan Page view, pencarian, outline, tracked changes dan komentar, perbandingan di layar (sebagai redline atau diff Markdown), dan Copy as Markdown semuanya gratis. Di PPTX Viewer, tampilan slide, thumbnail, catatan pembicara, pencarian, Present, menyalin atau menyimpan satu slide sebagai PNG, dan menyalin sebagai Markdown juga gratis. Kedua ekstensi bekerja offline tanpa akun, dan memuat ulang file begitu program lain menyimpannya, misalnya script atau AI agent.

Yang ditambahkan Zovo Pro

Export Redline as PDF membandingkan dua versi dokumen Word dan menyimpan hasilnya sebagai PDF bernomor halaman. Halaman pertama berisi ringkasan jumlah perubahan, lalu seluruh dokumen versi baru dengan teks tambahan berwarna hijau dan bergaris bawah, teks yang dihapus merah dan dicoret, teks yang dipindah biru, serta perubahan format berwarna kuning tua. Dengan begitu Anda bisa mengirim satu file yang menunjukkan semua perubahan kepada orang yang tidak punya Word. Alat Pro lain di DOCX Viewer adalah Export Redline as Word (file .docx baru dengan tracked changes), Export Change List of a Comparison (daftar bernomor semua perubahan dalam Excel, CSV, dan Markdown), dan Compare Two Folders of Documents. PPTX Viewer juga punya alat Pro sendiri dalam Zovo Pro yang sama, misalnya Export Deck as PDF dan Compare Two Decks.

Cara memakai Export Redline as PDF

  1. Buka dokumen di DOCX Viewer, atau klik kanan dokumen di Explorer lalu pilih "Zovo Pro: Export Redline as PDF".
  2. Anda juga bisa menjalankan "Export Redline as PDF (Pro)..." dari Command Palette.
  3. Pilih dokumen pembandingnya, lalu simpan PDF-nya.

Export Redline as PDF bisa dipakai 3 kali gratis sebelum meminta lisensi. Tidak ada popup saat file dibuka dan tidak ada hitung mundur.

Yang tidak bisa dilakukan

  • DOCX Viewer dan PPTX Viewer hanya penampil: keduanya tidak bisa mengedit atau menyimpan dokumen maupun slide.
  • File .doc dan .ppt lama hanya ditampilkan sebagai teks, tanpa format, gambar, atau tata letak.
  • File .rtf, .odp, dan Keynote tidak didukung. File RTF yang bernama .doc tetap terbuka sebagai teks.
  • Page view tidak menampilkan tracked changes atau komentar; keduanya terlihat di Reading view.

Pertanyaan

Apakah DOCX Viewer gratis?

Ya. Membaca, mencari, outline, tracked changes, perbandingan di layar, dan Copy as Markdown gratis dan akan tetap gratis. Hanya empat alat ekspor dan perbandingan yang termasuk Zovo Pro. Masing-masing bisa dicoba 3 kali secara gratis; setelah itu Zovo Pro seharga USD 19 sekali bayar untuk semua ekstensi Zovo.

Apakah bisa dipakai di Cursor?

Bisa. DOCX Viewer dan PPTX Viewer juga tersedia di Open VSX, jadi di Cursor Anda cukup memasangnya dari panel Extensions.

Apakah saya perlu Microsoft Office atau LibreOffice?

Tidak. Kedua ekstensi membaca file sendiri dan bekerja offline. Dokumen Anda tidak dikirim ke mana pun.

Bisakah presentasi PowerPoint disimpan sebagai PDF?

Bisa, dengan Export Deck as PDF di PPTX Viewer. Ini alat Zovo Pro dengan 3 kali percobaan gratis. Halaman PDF-nya berupa gambar slide, jadi teksnya tidak bisa dipilih atau dicari.

Semua fitur dan pengaturan ada di halaman DOCX Viewer (bahasa Inggris).
