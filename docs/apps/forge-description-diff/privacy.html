Privacy policy for Description Diff for Jira

What the app reads

When you open the "Description diff" tab on an issue, the app reads that issue's change history and the names and types of the fields in it from Jira, as you (Forge asUser). It can only read what your Jira account can read.

What the app shows

It shows versions of the Description and other text fields, and the display name of the person who made each change. Jira provides these names in the change history.

What the app stores

Nothing. The app has no storage scope, no cache, no database and no logs that contain issue text or names. If an unexpected error happens, the Forge log gets one line with the error type only (for example TypeError), without issue content.

What leaves Atlassian

Nothing. The app has no egress permissions and no remote back end. Everything runs on Atlassian's Forge platform.

What the app changes

Nothing. It has no scope that writes to Jira.

Personal data

Display names and account IDs are only processed in memory to show who made each change. Account IDs aren't sent to the browser. Because nothing is stored, there's no personal data to delete or report later.
