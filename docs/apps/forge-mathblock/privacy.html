Privacy

MathBlock for Confluence doesn't collect, store or send personal data.

  • It requests no Confluence API scopes and no storage, and declares no outside network addresses.
  • The LaTeX in each macro is stored by Confluence in the page, as a macro setting. The app's Forge function receives that text when the page is viewed or exported, draws it as SVG and returns it.
  • Drawn formulas, and the errors for formulas that can't be drawn, are kept in the function's memory, keyed by the site and the formula text, until the function instance is recycled. Nothing is written to disk or to a database.
  • The function receives Forge's standard request context (for example your account ID and the site's license state). The app reads the license state, the environment type (production or development), the macro type and the site ID. It uses the site ID only to keep each site's cached drawings apart in memory. It doesn't log or keep the rest.
  • If a formula can't be drawn because of an unexpected fault, the function logs a short error message without the formula.
