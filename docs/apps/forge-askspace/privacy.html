AskSpace privacy notice

What is stored. AskSpace stores the content that users enter:

  • question titles and details
  • answers and comments
  • topics and votes

Each record also holds the author's Atlassian account ID and the time it was created or changed.

Where it is stored. All data is kept in the app's Forge SQL database. That database is hosted by Atlassian for your Confluence site. Zovo runs no servers for this app and cannot read this data.

What leaves Atlassian. Nothing. The app calls your own Confluence site's REST API, as the current user, to check whether that user can see a space, page or blog post and whether they are an administrator. Once a week it calls Atlassian's personal data reporting API (see below). That API is part of Atlassian, not an outside service.

What is not stored. Names, email addresses and avatars are not stored. Confluence shows them from the account ID when a page is viewed.

Closed accounts (personal data reporting).

  • Once a week, AskSpace reports the account IDs it stores to Atlassian's personal data reporting API, 90 per request. A large site is covered over several weekly runs.
  • When Atlassian reports an account as closed, AskSpace removes that account's votes from every score and then deletes the votes. If the job is interrupted, the next weekly run finishes it. It also replaces the account ID on that person's questions, answers and comments with a placeholder, shown as "Former user". The text of those posts is kept, because other people's answers and discussion depend on it. Administrators can delete the posts.

Deletion.

  • Authors and administrators can delete posts in the app (see the README for who can delete what).
  • Uninstalling the app makes the data unavailable. After that, Atlassian's Forge data-retention rules apply.

Other stored values. The app stores a random encryption key for list cursors and the position of the weekly report, in the same database. Neither is personal data.
