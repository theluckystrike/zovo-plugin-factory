The model

  • Every Zovo extension stays free and complete. Opening and viewing a file is never paid.
  • Zovo Pro is an optional licence: USD 19 once, for life (USD 15 until 9 November, 11:56). It covers the Pro tools in every Zovo VS Code viewer, now and later. A team licence is 5 seats for USD 59 once.
  • No subscription, no ads, no popups. Each Pro tool runs 3 times for free on each computer. After that, one quick pick appears, and only when the user clicks a Pro tool.
  • If 10 or more licences sell in the first 60 days, new buyers move to USD 25. People who already paid keep Pro.

Rules that keep the ratings safe

  • Everything that has shipped free stays free in every later version. Pro is only new work: export, batch, cross-file and template tools.
  • The listing says it before the install: "Free, offline, no sign-in. Optional Zovo Pro (USD 19 once, all Zovo viewers) adds ...". The Marketplace label stays Free.
  • No startup message, no timer, no countdown, no window the user did not open. A setting hides Pro completely.
  • No network call, except the one the user starts when they choose to pay or enter a key.
  • A buyer enters the key once in each Zovo viewer. VS Code keeps secrets per extension.

Cold math USD a month, low / mid / high (E)

USD a month = installs a day x 30 x share still active x share of active users who buy x appeal of the Pro set x the price (USD 15 when this was computed; now USD 19) x share of buyers the payment rail reaches. Active share is 15, 25 or 40 percent (low, mid, high). Of those, 0.13, 0.32 or 0.75 percent buy, so 0.02 to 0.30 percent of all installs. That brackets SQLite Viewer PRO, the best public number we have (0.035 to 0.15 percent of installs). GitHub Sponsors alone reaches about 70 percent of buyers. In month 1, Pro is live for only part of the month.

Hex Viewer, mid case: 80 installs a day x 30 = 2,400 installs a month. 25 percent stay active = 600. 0.32 percent of them buy = 1.9 buyers. 1.9 x USD 15 x 0.7 rail reach = about USD 20 a month (at USD 19: about USD 25, E, if the share of buyers holds). How people pay

  1. The user opens a file in a free Zovo viewer. Nothing asks for money.
  2. The user clicks a Pro tool. The first 3 runs are free. The 4th click shows one quick pick with the ways to pay.
  3. GitHub Sponsors: the buyer pays the "$19 one time" Zovo Pro tier. Back in VS Code, the extension uses the built-in GitHub sign-in and makes one call to check the sponsorship. Then Pro is on.
  4. PayPal: the buyer sends USD 19 to https://www.paypal.com/paypalme/najzzz/19. The owner runs one command, which signs a ZOVO1 key, and emails it. The buyer pastes the key.
  5. Card (when Stripe is on): a stable link on license.zovo.one sends the buyer to a Stripe payment page. After payment, a small Cloudflare Worker checks the payment with Stripe and shows a signed key with an Open in VS Code button.
  6. The extension checks every key offline with a public key built into it and keeps the key in VS Code's secret store. Keys keep working even if the Worker goes away.

Owner steps, in minutes 227 minutes for all of them

Steps 1 to 4 take 15 minutes and need no new account. All steps with links are on the MONEY-HOUR page in the owner steps folder on the Desktop.

  1. GitHub Sponsors: nothing to do. The Zovo Pro tier ($19 one time) is published (FIXSPON); the notemods tiers stay unchanged. 0 min
    Get Zovo Pro opens that tier directly.
  2. Back up the 2 licence signing keys from the keychain to the password manager (commands in PAY1.md, section 5). 2 min
    If this Mac is lost, no new keys can be issued. Sold keys keep working.
  3. Apify: finish the ID check if Apify asks for anything more. 10 min
    9 paid Actors stay hidden until it passes. GATE5 sets the prices the same hour.
  4. Modrinth: create one token with the create and write scopes (MOD2.md, owner step 1). 3 min
    EXEC5 uploads the mods the same day.
  5. Only with a Stripe account in a supported country: stripe login, then go.sh test and go.sh live. 11 min
    Card checkout for buyers without GitHub.
  6. JetBrains: Trader details, bank and the sales form (jetbrains-paid.md). 40 min
    JetBrains bills for us. 3 freemium plugins are staged.
  7. Shopify: Partner account and a dev store (shopify.md). 45 min
    2 apps built, USD 0 hosting.
  8. Roblox: ID check and the Stripe form (roblox.md). 75 min
    2 plugins with a USD 4.99 Pro are built.
  9. Atlassian: Partner tabs and identity, by 6 December. 25 min
    Needed before any paid listing.
  10. Ask an accountant once about tax on Sponsors and PayPal income. 15 min
    GitHub Sponsors does not collect VAT for us.
  11. At 10 sales in 60 days: say yes to USD 25 for new buyers. 1 min
    Needs a new USD 25 Zovo tier and one line in sponsors.js. The general $25 one-time tier does not unlock Zovo Pro.

What we will not do

  • No paywall on viewing.
  • No subscription.
  • No startup popups or countdowns.
  • No launch price or strike-through tricks.
  • No Pro in products with no paid rival proving demand, until Hex Pro sells 3 licences.
