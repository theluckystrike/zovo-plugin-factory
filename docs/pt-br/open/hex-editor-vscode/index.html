Guias em português · Hex Viewer

Editor hexadecimal no VS Code

A extensão gratuita Hex Viewer mostra os bytes de qualquer arquivo no VS Code, de 0 byte a uma imagem de disco de 4 GB. Ela lê só as linhas que estão na tela, então um arquivo de 4 GB abriu em 0,6 s nos testes. Você vai para um offset, busca bytes com curinga ??, lê valores no data inspector, insere e apaga bytes com desfazer, e compara dois arquivos byte a byte.

Passo a passo no VS Code

  1. Instale a extensão Hex Viewer pelo Marketplace, ou pressione Ctrl+P (Cmd+P no macOS) e rode ext install zovo.zovo-hex-viewer.
  2. Clique com o botão direito em qualquer arquivo no Explorer e escolha "Open in Hex Viewer". Arquivos .bin, .dat, .img, .rom, .dmp e .dump já abrem no Hex Viewer com um clique.
  3. Ctrl+G (Cmd+G no macOS) vai para um offset: 0x1F40, +0x100, -16 ou end. Ctrl+F busca bytes como 50 4B 03 04, com ?? para qualquer byte, texto ou texto UTF-16.
  4. O data inspector à direita lê os bytes no cursor como inteiros de 8 a 64 bits, float, Unix time, GUID e outros. Clique em "Little-endian" para trocar a ordem dos bytes.
  5. Digite dois dígitos hex para sobrescrever um byte. Insert alterna para o modo de inserção, em que o arquivo cresce. Ctrl+Z desfaz e Ctrl+S salva.
  6. Para comparar dois arquivos, selecione os dois no Explorer e escolha "Compare in Hex Viewer". F7 vai para a próxima diferença.

O que é grátis e o que o Zovo Pro adiciona

Ver arquivos de qualquer tamanho, ir para offset, buscar, Copy as (hex, array C, bytes Python, base64), o data inspector, editar com inserção e remoção, desfazer, o salvamento seguro e a comparação de dois arquivos são gratuitos e continuam gratuitos.

Para conferir um download ou um firmware, Checksums of File calcula CRC-32, Adler-32, MD5, SHA-1, SHA-256 e SHA-512 do arquivo ou da seleção em uma só passada, também em um arquivo de 4 GB, sem precisar abrir o arquivo. O Zovo Pro também traz os campos aninhados dos binary templates (ELF, PE, PNG, ZIP e outros), bookmarks com notas, relatório de comparação, busca em vários arquivos e o mapa de entropia com histograma de bytes.

Com Checksums of File (Zovo Pro)

  1. Clique com o botão direito em um ou mais arquivos no Explorer e escolha Checksums of File. Com o arquivo aberto, use o botão "Checksums..." abaixo do data inspector para a seleção.
  2. Os valores aparecem em uma lista.
  3. Escolha um valor para copiá-lo.

Checksums of File funciona 3 vezes no seu computador antes de pedir uma licença, e uma tentativa só conta quando você recebe um resultado. Nada sobre o Pro aparece quando você abre um arquivo.

No Cursor, Windsurf ou VSCodium

Esses editores instalam extensões pelo Open VSX. Abra a visão Extensions (Ctrl+Shift+X, ou Cmd+Shift+X no macOS), procure zovo.zovo-hex-viewer e clique em Install. Depois disso, tudo funciona como no VS Code.

O que ela não faz

  • Copy as funciona até 32 MB, e colar até 16 MB.
  • Arquivos em sistemas de arquivos remotos ou virtuais abrem até 256 MB (setting hexViewer.maxRemoteMB).
  • Arquivos de texto e arquivos Intel .hex continuam abrindo no editor de texto.

Perguntas

A extensão é paga?

Não. Ver, editar e comparar é gratuito. Só os checksums, os campos aninhados dos templates, os bookmarks e as outras ferramentas Pro são Zovo Pro (USD 19 uma vez), com 3 usos grátis cada.

Salvar um arquivo grande é seguro?

Sim. Se o tamanho não muda, só os bytes alterados são gravados. Se muda, a extensão grava uma cópia nova e depois troca, então um disco cheio não deixa o arquivo pela metade.

Funciona offline?

Sim. Sem telemetria e sem chamadas de rede.
