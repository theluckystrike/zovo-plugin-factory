Um visualizador NetCDF grátis que roda no VS Code

Instale a extensão grátis NetCDF Viewer & HDF5 Viewer no VS Code e clique em um arquivo .nc. Você vê o cabeçalho, uma árvore de variáveis, um mapa com o contorno do litoral, um controle de tempo e a série temporal de qualquer ponto em que clicar, sem Python, NCL ou outra instalação. O mesmo visualizador abre arquivos HDF5 .h5 e arquivos MATLAB 7.3 .mat, e tudo isso é grátis. O Zovo Pro (19 USD, pagos uma vez) acrescenta duas ferramentas, Compare two files e Export a subset, e cada uma tem 3 usos grátis.

Passo a passo no VS Code

  1. Instale o NetCDF Viewer & HDF5 Viewer pelo Marketplace, ou aperte Ctrl+P (Cmd+P no macOS) e rode ext install zovo.hdf5-netcdf-explorer.
  2. Clique em um arquivo .nc, .nc4, .netcdf ou .cdf no Explorer. A visão geral mostra o formato, as dimensões, os atributos globais e uma tabela com todas as variáveis, parecida com a saída do ncdump -h.
  3. Escolha uma variável na árvore à esquerda. Um recorte 2-D é desenhado como heatmap, com o contorno do litoral quando as linhas e as colunas são latitude e longitude.
  4. Mova o controle de tempo, ou aperte ▶ ao lado dele para avançar no tempo. Clique em um ponto do mapa para ver a série temporal desse ponto.
  5. Abra a aba Table para percorrer os valores, 100 linhas por 30 colunas, com os valores das coordenadas como cabeçalhos.
  6. Clique em "Save PNG" para salvar o gráfico, ou em "Export slice…" para salvar o recorte da tela como CSV ou JSON. "Copy xarray code" gera a linha de Python para o mesmo recorte.
  7. Para um arquivo HDF5, clique no arquivo .h5. Para um arquivo MATLAB 7.3 .mat, clique nele com o botão direito e escolha "Open in HDF5 NetCDF Explorer".

O que é grátis e o que o Zovo Pro acrescenta

Todos os formatos, a árvore, os atributos, a tabela, os gráficos e mapas com litoral, o Play, a série temporal de um ponto, o Save PNG e o Export slice são grátis. Não precisa de Python, e esses recursos não fazem chamadas de rede.

O Export a subset funciona como o ncks -d ou o .sel do xarray. Você escolhe uma variável e um intervalo para cada dimensão, por índice (0:99) ou por valor (30..60, 2023-08-01..2023-08-31). Ele salva um arquivo NetCDF com as coordenadas, os atributos e uma linha history, ou um CSV organizado com uma linha por ponto. Você tem um arquivo pequeno de uma região e de um período sem escrever um script.

Como usar Export a subset (Zovo Pro)

  1. Abra o arquivo e clique no botão "Export subset…" ao lado de "Export slice…", ou clique com o botão direito no arquivo no Explorer e escolha "Zovo Pro: Export a Subset of a Variable".
  2. Você também pode rodar "NetCDF Viewer Pro: Export Subset of a Variable (NetCDF or CSV)..." pela Command Palette.
  3. Digite um intervalo para cada dimensão. A caixa mostra o que você selecionou enquanto você digita.
  4. Escolha NetCDF ou CSV e onde salvar. Uma notificação mostra o progresso, e Cancel interrompe sem deixar um arquivo gravado pela metade.

Export a subset funciona 3 vezes no seu computador antes de pedir uma licença. Não há janela pop-up nem contagem regressiva.

Passo a passo no Cursor, Windsurf ou VSCodium

  1. Abra a visão Extensions com Ctrl+Shift+X (Cmd+Shift+X no macOS).
  2. Busque zovo.hdf5-netcdf-explorer e clique em Install. Cursor, Windsurf e VSCodium instalam extensões do Open VSX, onde esta se chama zovo/hdf5-netcdf-explorer.
  3. Se o seu editor não tiver galeria, baixe o arquivo .vsix na página do Open VSX e rode "Extensions: Install from VSIX...".
  4. Depois disso, tudo funciona como no VS Code.

O que o NetCDF Viewer & HDF5 Viewer faz

  • NetCDF-4 e NetCDF-4 classic, NetCDF-3 classic e 64-bit offset, e CDF-5 (dados de 64 bits).
  • Arquivos HDF5 (.h5, .hdf5, .he5, .hdf) com compressão deflate, shuffle, szip, LZF, Blosc, bitshuffle, LZ4, Zstd, bzip2 e ZFP.
  • MATLAB 7.3 .mat e outros arquivos baseados em HDF5, como .jld2, .loom e .h5ad.
  • Decodificação CF de scale_factor, add_offset, _FillValue e unidades de tempo, inclusive os calendários noleap, 360_day e all_leap.
  • Arquivos em uma máquina remota via Remote SSH, WSL ou dev container.

O que ele não faz

  • Zarr e HDF4 não são suportados. Arquivos MATLAB .mat salvos no formato v5 não são HDF5 e não abrem. Salve esses arquivos de novo com save(filename, '-v7.3').
  • O contorno do litoral só aparece em grades regulares de latitude e longitude. Grades curvilíneas, com latitude e longitude 2-D, e grades projetadas em metros ficam sem litoral.
  • Arrays maiores que 512 x 512 são amostrados no gráfico. As exportações gravam no máximo 1.000.000 de valores por arquivo (configuração hdf5NetcdfExplorer.maxReadValues).
  • Sistemas de arquivos virtuais, como repositórios do GitHub abertos no vscode.dev, não são suportados.
  • Datasets com outros filtros HDF5, como SZ ou JPEG, mostram uma mensagem no lugar dos valores.

Perguntas frequentes

É grátis?

A visualização é grátis, com todos os formatos, mapas, Play, séries temporais, Save PNG e Export slice. As duas ferramentas Pro, Compare two files e Export a subset, têm 3 usos grátis cada. Depois disso elas precisam do Zovo Pro, 19 USD pagos uma vez para todas as extensões Zovo.

Existe visualizador NetCDF para Windows?

Sim. Esta extensão roda onde o VS Code roda, inclusive no Windows, no macOS e no Linux, e não precisa de Python.

Ele abre arquivos HDF5 e MAT?

Sim para arquivos HDF5 .h5 e arquivos MATLAB 7.3 .mat. Arquivos MATLAB v5 .mat, mais antigos, não são HDF5 e mostram uma mensagem.

Funciona no Cursor?

Sim. A extensão está no Open VSX como zovo/hdf5-netcdf-explorer, então Cursor, Windsurf e VSCodium podem instalá-la.
