Como converter um arquivo PDF, Word, PowerPoint ou Excel para Markdown no VS Code

Instale a extensão grátis Convert to Markdown, clique com o botão direito em um arquivo PDF, Word, PowerPoint, Excel, CSV, HTML, EPUB, ODT ou RTF no Explorer e escolha Convert to Markdown. O Markdown abre ao lado do arquivo, com títulos, listas, tabelas, links e as notas do apresentador dos slides, e nada sai do seu computador. Convert to Markdown e Copy as Markdown são grátis para todos os formatos. O Zovo Pro (19 USD, pagos uma vez só) acrescenta três ferramentas, Convert a Folder to Markdown, Convert to Markdown with Images e LLM-ready Markdown Chunks, e cada uma tem 3 usos grátis.

Passo a passo no VS Code

  1. Instale o Convert to Markdown pelo Marketplace, ou aperte Ctrl+P (Cmd+P no macOS) e rode ext install zovo.zovo-convert-to-markdown.
  2. No Explorer, clique com o botão direito em um arquivo .pdf, .docx, .pptx, .xlsx, .xls, .ods, .csv, .tsv, .html, .epub, .odt ou .rtf e escolha Convert to Markdown. Você também pode clicar com o botão direito na aba de um arquivo aberto.
  3. Ou rode "Convert to Markdown: Convert to Markdown" pela Command Palette. O comando converte o arquivo da aba ativa ou pede um arquivo.
  4. O Markdown abre ao lado do arquivo como um documento não salvo. Em arquivos grandes, aparece o progresso com um botão Cancel.
  5. Salve o documento. O nome name.md, ao lado do arquivo de origem, já vem preenchido. Para salvar direto nesse lugar toda vez, defina toMarkdown.output como file.
  6. Para colar o Markdown em outro lugar, clique com o botão direito no arquivo e escolha Copy as Markdown. Se você selecionar vários arquivos no Explorer, eles são convertidos um depois do outro.
  7. Não tem um arquivo à mão? Rode "Convert to Markdown: Convert a sample file" pela Command Palette para converter um exemplo de Word, PDF ou PowerPoint que vem com a extensão.

O que é grátis e o que o Zovo Pro acrescenta

Convert to Markdown e Copy as Markdown são grátis para todos os formatos: PDF, Word, PowerPoint, Excel, ODS, CSV, TSV, HTML, EPUB, ODT e RTF. Você não instala mais nada, nem Python, nem servidor, nem ferramenta de linha de comando. Nada sai do seu computador.

Convert a Folder to Markdown converte de uma vez cada arquivo suportado de uma pasta e de suas subpastas em arquivos .md, em uma nova pasta com a mesma estrutura ou ao lado de cada arquivo, com progresso e Cancel. Você escolhe se pula ou sobrescreve os arquivos .md que já existem, e o _conversion-report.md lista cada arquivo como convertido, pulado ou com falha. Arquivos com o mesmo nome mantêm o tipo no novo nome (report.pdf.md, report.docx.md), então nenhum se perde.

Como usar Convert a Folder to Markdown (Zovo Pro)

  1. Clique com o botão direito em uma pasta no Explorer e escolha "Zovo Pro: Convert a Folder to Markdown", ou rode "Convert to Markdown: Convert a Folder to Markdown (Pro)" pela Command Palette e escolha a pasta.
  2. Escolha para onde vão os arquivos .md: "Into a new folder" (o nome da pasta mais -markdown, com as mesmas subpastas), "Next to each file" ou "Pick another folder...".
  3. Se alguns arquivos .md já existirem, escolha Skip ou Overwrite. Uma notificação mostra o progresso com um botão Cancel.
  4. No final, o _conversion-report.md abre. Ele lista cada arquivo como convertido, pulado ou com falha, com um link para cada novo arquivo Markdown.

Passo a passo no Cursor, Windsurf ou VSCodium

  1. Abra a visão Extensions com Ctrl+Shift+X (Cmd+Shift+X no macOS).
  2. Busque zovo.zovo-convert-to-markdown e clique em Install. Cursor, Windsurf e VSCodium instalam extensões do Open VSX, onde esta se chama zovo/zovo-convert-to-markdown.
  3. Se o seu editor não tiver galeria, baixe o arquivo .vsix na página do Open VSX e rode "Extensions: Install from VSIX...".
  4. Depois disso, tudo funciona como no VS Code.

O que o Convert to Markdown faz

  • PDF, com títulos tirados dos tamanhos de fonte, parágrafos com as linhas quebradas e as palavras hifenizadas reunidas, listas, tabelas simples e páginas de duas colunas lidas coluna por coluna. Cabeçalhos, rodapés e números de página repetidos são descartados.
  • Word (.docx, .docm, .dotx), com títulos, negrito, itálico, tachado, links, listas aninhadas, tabelas, citações em bloco e notas de rodapé.
  • PowerPoint (.pptx, .pptm, .ppsx, .potx), com uma seção ## Slide n: title por slide, com os marcadores e seus níveis, as tabelas e as notas do apresentador.
  • Excel e outras planilhas (.xlsx, .xlsm, .xlsb, .xls, .ods), com uma seção ## Sheet: name e uma tabela com barras verticais por planilha. CSV e TSV viram uma única tabela.
  • HTML (.html, .htm, .xhtml), em que os blocos de código mantêm a linguagem e scripts e estilos são descartados, e EPUB, com cada capítulo na ordem de leitura.

O que ele não faz

  • PDFs digitalizados (imagens de páginas) não têm texto para converter. Reconhecimento de texto (OCR) não está incluído.
  • As tabelas de PDF são encontradas pelos espaços entre as colunas. Tabelas sem espaços claros saem como parágrafos.
  • Na conversão grátis, as imagens viram marcadores como *[Image: Map of the site]*. Gráficos, SmartArt e vídeos dos slides são nomeados, não convertidos.
  • Arquivos antigos do Word 97-2003 e RTF geram texto e tabelas sem formatação. Arquivos protegidos por senha e arquivos antigos do PowerPoint 97-2003 recebem uma mensagem em vez de uma conversão.
  • Arquivos acima de 200 MB não são convertidos (configuração toMarkdown.maxFileSizeMB), e um PDF para depois de 1.000 páginas (configuração toMarkdown.pdfMaxPages).

Perguntas frequentes

É grátis?

Convert to Markdown e Copy as Markdown são grátis para todos os formatos. As três ferramentas Pro, Convert a Folder to Markdown, Convert to Markdown with Images e LLM-ready Markdown Chunks, têm 3 usos grátis cada. Depois disso, elas precisam do Zovo Pro, 19 USD uma vez só para todas as extensões Zovo.

A extensão envia meus arquivos para algum lugar?

Não. Os conversores rodam no seu computador, dentro do VS Code, sem chamadas de rede e sem telemetria.

Ela converte PDFs digitalizados?

Não. Um PDF digitalizado contém imagens de páginas, não texto, e o Convert to Markdown não tem OCR.

Funciona no Cursor?

Sim. Cursor, Windsurf e VSCodium instalam a extensão pelo Open VSX, onde ela está publicada como zovo/zovo-convert-to-markdown.
