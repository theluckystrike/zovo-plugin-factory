Como enviar arquivos para um servidor por SFTP ou FTP no VS Code

Instale a extensão grátis SFTP & FTP Sync and Upload e crie um .vscode/sftp.json com o host, o usuário e a pasta do servidor. A partir daí, cada arquivo é enviado quando você salva, por SFTP, FTP ou FTPS. Clique com o botão direito em um arquivo ou pasta para enviar ou baixar, ou em um arquivo para compará-lo com a cópia do servidor. No painel Remote Files, os arquivos do servidor abrem em uma aba normal. Sua pasta .vscode, seus arquivos .env e suas chaves privadas nunca são enviados. Tudo isso é grátis, sem conta. O Zovo Pro (19 USD, pagos uma vez só) acrescenta três ferramentas, Sync Folder with Remote, Roll Back a Remote File e Server Profiles and Jump Host, e cada uma tem 3 usos grátis.

Passo a passo no VS Code

  1. Instale o SFTP & FTP Sync and Upload pelo Marketplace, ou aperte Ctrl+P (Cmd+P no macOS) e rode ext install zovo.zovo-sftp.
  2. Execute "SFTP: Create sftp.json Config" na Command Palette ou clique em Create sftp.json no painel SFTP Remote.
  3. Preencha protocol (sftp, ftp ou ftps), host, username, privateKeyPath (deixe de fora para usar senha) e remotePath, a pasta do servidor que corresponde à sua pasta local. Passe o mouse sobre qualquer chave para ver a ajuda.
  4. Defina "uploadOnSave": true. A partir de agora, cada arquivo que você salvar é enviado. A senha que você digitar é pedida uma vez e fica no armazenamento seguro do editor (secret storage), nunca no sftp.json.
  5. Clique com o botão direito em qualquer arquivo ou pasta no Explorer, ou em uma aba, e escolha Upload, Download ou Compare with Server Copy (Compare funciona só em arquivos).
  6. Abra o painel Remote Files para navegar pelo servidor. Abra um arquivo em uma aba normal do editor e salve para enviá-lo de volta, baixe, copie o caminho ou exclua. "SFTP: Show Transfer Log" mostra cada conexão e cada transferência.

O que é grátis e o que o Zovo Pro acrescenta

Envio ao salvar, Upload, Download e Compare with Server Copy, o painel Remote Files, SFTP, FTP e FTPS, a verificação da chave do host e o log de transferências são grátis, sem conta e sem login em nada além do seu próprio servidor. Sem telemetria.

Quando o servidor e a sua pasta local ficaram diferentes, o Sync Folder with Remote compara os dois e lista cada diferença antes de mover qualquer coisa: arquivos só aqui, só no servidor ou mais novos de um dos lados. Você escolhe enviar, baixar, excluir ou pular para cada arquivo, abre um diff lado a lado, salva a simulação como texto e depois aplica. Você vê exatamente o que vai mudar no servidor antes que mude.

Como usar Sync Folder with Remote (Zovo Pro)

  1. Clique com o botão direito em uma pasta no Explorer e escolha "Zovo Pro: Sync folder with remote (diff preview)", ou execute "SFTP: Sync Folder with Remote, Diff Preview (Pro)..." na Command Palette. A barra de título do painel Remote Files tem o mesmo botão.
  2. Leia o plano. Para cada arquivo, escolha enviar, baixar, excluir ou pular, e abra o diff de qualquer arquivo sobre o qual tiver dúvida.
  3. Aplique o plano. Um uso só é contado quando um plano de sincronização foi exibido. Escape ou Cancel nunca gasta um uso.

Sync Folder with Remote funciona 3 vezes no seu computador antes de pedir uma licença. Não há janela pop-up nem contagem regressiva.

Passo a passo no Cursor, Windsurf ou VSCodium

  1. Abra a visão Extensions com Ctrl+Shift+X (Cmd+Shift+X no macOS).
  2. Busque zovo.zovo-sftp e clique em Install. Cursor, Windsurf e VSCodium instalam extensões do Open VSX, onde esta se chama zovo/zovo-sftp.
  3. Se o seu editor não tiver galeria, baixe o arquivo .vsix na página do Open VSX e rode "Extensions: Install from VSIX...".
  4. Depois disso, tudo funciona como no VS Code.

O que o SFTP & FTP Sync and Upload faz

  • SFTP com chaves SSH, chaves criptografadas, agente SSH ou senha; FTP; FTPS com TLS explícito ou implícito.
  • .vscode, .git, arquivos .env, chaves privadas, .npmrc e outros arquivos secretos nunca são enviados. Adicione seus próprios padrões em ignore, no estilo do .gitignore.
  • A chave do host do servidor é verificada: fixe-a com hostFingerprint ou confirme na primeira conexão. Uma chave alterada interrompe a conexão.
  • Em uma pasta que você não marcou como confiável (Restricted Mode), a extensão fica desligada, então um projeto baixado não consegue enviar seus arquivos para lugar nenhum.
  • Há mais duas ferramentas Pro. O Roll Back a Remote File guarda no seu computador as 10 últimas cópias de um arquivo do servidor antes que um envio o sobrescreva. O Server Profiles and Jump Host coloca vários servidores (staging, produção) em um único sftp.json e conecta por um jump host SSH.

O que ele não faz

  • Uma conexão por servidor de cada vez, e as transferências FTP rodam uma após a outra.
  • Links simbólicos no servidor são seguidos para arquivos, mas pastas vinculadas não são percorridas em envios, downloads ou sincronização de pastas.
  • Chaves no formato PuTTY .ppk precisam ser convertidas para OpenSSH antes (puttygen key.ppk -O private-openssh -o key).
  • A sincronização compara tamanho e data de modificação e depois os bytes dos arquivos de mesmo tamanho, até 300 arquivos ou 64 MB por execução.
  • As cópias para reversão são mantidas, por padrão, para arquivos de até 5 MB, e só neste computador.

Perguntas frequentes

É grátis?

Envio ao salvar, Upload, Download, Compare with Server Copy, o painel Remote Files e o log de transferências são grátis, por SFTP, FTP e FTPS. As três ferramentas Pro, Sync Folder with Remote, Roll Back a Remote File e Server Profiles and Jump Host, têm 3 usos grátis cada. Depois disso, elas precisam do Zovo Pro, 19 USD pagos uma vez só para todas as extensões Zovo.

Minha senha fica salva no sftp.json?

Não. A senha ou frase secreta que você digita fica no armazenamento seguro do editor. Deixe password fora do sftp.json e ela será pedida uma vez.

A extensão vai enviar meu arquivo .env?

Não. .vscode, .git, arquivos .env, chaves privadas e .npmrc estão na lista de exclusão padrão e nunca são enviados.

O VS Code envia arquivos por SFTP sem extensão?

Não. O VS Code não tem envio por SFTP ou FTP. O Remote SSH edita os arquivos no próprio servidor; para enviar um projeto local, você precisa de uma extensão, ou de scp e rsync no terminal.
