Passo a passo no VS Code

  1. Instale o SQLite DB Viewer pelo Marketplace, ou aperte Ctrl+P (Cmd+P no macOS) e rode ext install zovo.sqlite-table-viewer.
  2. Clique em um arquivo .db, .sqlite, .sqlite3, .db3, .s3db, .sl3, .vscdb ou .gpkg no Explorer. Ele abre como tabela, somente leitura.
  3. Escolha uma tabela ou view à esquerda. Clique no cabeçalho de uma coluna para ordenar, digite embaixo de um cabeçalho para filtrar (por exemplo 5..9 ou =word) ou busque em todas as colunas de uma vez.
  4. Abra a aba Schema para ver colunas, chaves, chaves estrangeiras e os comandos CREATE, ou a aba SQL para rodar um comando por vez. Os últimos 20 comandos ficam guardados.
  5. Para alterar dados, clique em Enable editing. Dê um duplo clique em uma célula, digite o novo valor e aperte Enter. Cada alteração fica em uma lista de pendências, com o SQL e um Undo.
  6. Aperte Save (Ctrl+S, ou Cmd+S no macOS). O Save confere as restrições, faz uma cópia de backup como name.db.20261109-143000.bak e substitui o arquivo em uma única etapa.

Passo a passo no Cursor, Windsurf ou VSCodium

  1. Abra a visão Extensions com Ctrl+Shift+X (Cmd+Shift+X no macOS).
  2. Busque zovo.sqlite-table-viewer e clique em Install. Cursor, Windsurf e VSCodium instalam extensões do Open VSX, onde esta se chama zovo/sqlite-table-viewer.
  3. Se o seu editor não tiver galeria, baixe o arquivo .vsix na página do Open VSX e rode "Extensions: Install from VSIX...".
  4. Depois disso, tudo funciona como no VS Code.

O que o SQLite DB Viewer faz

  • Linhas confirmadas que ainda estão no arquivo -wal, com recarga ao vivo enquanto o seu app grava (o botão Live desliga isso).
  • Células JSON como árvore, imagens como figura e BLOBs float32 como vetores no painel da célula.
  • Cópia como CSV, TSV, JSON ou comandos INSERT, e exportação das linhas visíveis como CSV, JSON ou comandos SQL INSERT.
  • Importação de CSV e TSV para uma tabela nova ou existente, com prévia, mapeamento de colunas, barra de progresso e Cancel.
  • Bancos de até 512 MB, com as linhas buscadas uma página por vez.

O que ele não faz

  • O banco inteiro é carregado na memória. Arquivos acima de 512 MB mostram uma mensagem (configuração sqliteTableViewer.maxFileSizeMB).
  • A edição vale só para arquivos de até 256 MB (configuração sqliteTableViewer.editMaxFileSizeMB). Arquivos maiores ficam somente leitura.
  • Bancos criptografados (SQLCipher, SEE) não abrem.
  • A edição só funciona em arquivos deste computador. Arquivos em sistemas de arquivos remotos ou virtuais abrem somente leitura.
  • Alterações não salvas são descartadas quando você fecha a aba, e o arquivo continua como estava.

Perguntas frequentes

É grátis?

Abrir, visualizar, a aba SQL, editar, o Save e a importação de CSV são grátis, sem conta. As três ferramentas Pro (Compare SQLite Databases, ER Diagram e Export All Tables) têm 3 usos grátis cada. Depois disso elas precisam do Zovo Pro, 19 USD pagos uma vez para todas as extensões Zovo.

Dá para editar linhas no VS Code?

Sim. O arquivo abre somente leitura, e você clica em Enable editing para alterar células e linhas ou rodar INSERT e UPDATE. Nada é gravado até você apertar Save, que antes faz uma cópia de backup.

Por que outro visualizador mostra linhas antigas?

No modo WAL, os novos commits ficam no arquivo -wal até um checkpoint copiá-los para o arquivo principal. Um visualizador que lê só o arquivo principal não vê essas linhas. Este lê a parte já confirmada do arquivo -wal.

Funciona no Cursor?

Sim. A extensão está no Open VSX como zovo/sqlite-table-viewer, então Cursor, Windsurf e VSCodium podem instalá-la.
