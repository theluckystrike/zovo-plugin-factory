Como comparar dois arquivos Excel ou CSV no VS Code

Instale a extensão grátis Excel Compare & XLSX Diff e escolha duas pastas de trabalho ou arquivos CSV. As células alteradas aparecem em amarelo com o valor antigo riscado, as linhas adicionadas em verde e as removidas em vermelho. As linhas são alinhadas e as colunas pareadas pelo cabeçalho, então uma linha ou coluna inserida conta como uma única alteração, e você pode comparar uma planilha com a versão do Git HEAD antes do commit. Tudo isso é grátis, sem nenhuma requisição de rede. O Zovo Pro (19 USD, pagos uma vez só) acrescenta três ferramentas, Export a diff report, Match rows by key columns e Compare two folders of workbooks, e cada uma tem 3 usos grátis.

Passo a passo no VS Code

  1. Instale o Excel Compare & XLSX Diff pelo Marketplace, ou aperte Ctrl+P (Cmd+P no macOS) e rode ext install zovo.zovo-excel-compare.
  2. Selecione dois arquivos no Explorer, clique com o botão direito e escolha Compare Selected Excel Files. Ou clique com o botão direito em um arquivo, escolha Compare with... e selecione o outro. Pela Command Palette, execute "Excel Compare: Compare Two Excel or CSV Files...".
  3. Qualquer combinação de .xlsx, .xlsm, .xls, .ods, .csv e .tsv funciona, então você pode comparar um .xlsx com um .csv.
  4. Leia a linha de resumo e depois a guia de cada aba com o número de diferenças. Clique em uma célula para ver o valor antigo e o novo completos e copiá-los.
  5. Aperte N e P (ou Next e Previous) para passar por todas as alterações em todas as abas. Alterne entre Values e Formulas para comparar o que as células mostram ou as próprias fórmulas.
  6. Para ver o que você mudou antes de um commit, clique com o botão direito em uma planilha dentro de um repositório Git e escolha Compare with Git HEAD.

O que é grátis e o que o Zovo Pro acrescenta

Comparar quaisquer dois arquivos, a grade, Values e Formulas, a próxima alteração e a anterior, o diff de CSV com codificação e delimitador detectados e Compare with Git HEAD são grátis, sem login, sem requisições de rede e sem telemetria.

Quando outra pessoa precisa ver as alterações, o Export a diff report grava uma pasta de trabalho XLSX com as células alteradas, adicionadas e removidas preenchidas em cor, uma aba Summary e uma lista Changes com cada valor antigo e novo. Ele também pode gravar uma página HTML ou uma lista CSV das alterações. Você envia um arquivo em vez de capturas de tela.

Como usar Export a diff report (Zovo Pro)

  1. Compare dois arquivos como acima e clique em Export report na barra de ferramentas da comparação, ou execute "Excel Compare: Export a diff report (XLSX, HTML or CSV) (Pro)" pela Command Palette.
  2. Escolha XLSX, HTML ou CSV.
  3. Escolha onde salvar o relatório. Um uso só é gasto quando o relatório foi gravado.

Export a diff report funciona 3 vezes no seu computador antes de pedir uma licença. Não há janela pop-up nem contagem regressiva.

Passo a passo no Cursor, Windsurf ou VSCodium

  1. Abra a visão Extensions com Ctrl+Shift+X (Cmd+Shift+X no macOS).
  2. Busque zovo.zovo-excel-compare e clique em Install. Cursor, Windsurf e VSCodium instalam extensões do Open VSX, onde esta se chama zovo/zovo-excel-compare.
  3. Se o seu editor não tiver galeria, baixe o arquivo .vsix na página do Open VSX e rode "Extensions: Install from VSIX...".
  4. Depois disso, tudo funciona como no VS Code.

O que o Excel Compare & XLSX Diff faz

  • Abas pareadas pelo nome e depois pela posição. Abas que existem em só um arquivo aparecem como adicionadas ou removidas.
  • CSV e TSV com a codificação detectada (UTF-8 com ou sem BOM, UTF-16, páginas de código do Windows) e o delimitador detectado (vírgula, ponto e vírgula, tabulação ou pipe), inclusive campos entre aspas com quebras de linha.
  • Abas grandes: a grade desenha só as linhas visíveis na tela, então uma aba com 300.000 linhas rola como uma curta.
  • Avisos quando células mescladas são diferentes ou quando um limite cortou uma aba.
  • As outras duas ferramentas Pro: Match rows by key columns pareia as linhas por uma coluna de ID, para que abas ordenadas ou reordenadas sejam comparadas corretamente e as linhas movidas fiquem marcadas; Compare two folders of workbooks pareia os arquivos pelo nome e mostra quais são iguais, quais diferem e quais existem em só uma pasta.

O que ele não faz

  • Arquivos de até 200 MB (configuração excelCompare.maxFileSizeMB), 300.000 linhas por aba (excelCompare.maxRows), 1.000 colunas e 200 abas. Um aviso na visualização informa quando um limite foi aplicado.
  • Uma pasta de trabalho que passaria de 600 MB ao ser descompactada, ou que está compactada como uma zip bomb, é recusada antes de ser descompactada.
  • Sem a ferramenta Pro Match rows by key columns, as linhas são alinhadas pelo conteúdo e pela posição, não por uma coluna de ID.
  • A extensão só compara. Ela não edita nem mescla os arquivos.

Perguntas frequentes

É grátis?

Comparar duas pastas de trabalho ou arquivos CSV, Values e Formulas, a próxima alteração e a anterior e Compare with Git HEAD são grátis. As três ferramentas Pro, Export a diff report, Match rows by key columns e Compare two folders of workbooks, têm 3 usos grátis cada. Depois disso, elas precisam do Zovo Pro, 19 USD uma vez só para todas as extensões Zovo.

O VS Code compara dois arquivos Excel sem extensão?

Não. Um arquivo .xlsx é um zip de partes XML, então o diff nativo mostra o arquivo como binário. Você precisa de uma extensão que leia a pasta de trabalho.

Uma linha inserida no topo marca todas as linhas abaixo como alteradas?

Não. As linhas são alinhadas antes da comparação, então uma linha inserida aparece como uma única linha adicionada.

Dá para ver o que mudou em uma planilha desde o último commit?

Sim. Clique com o botão direito no arquivo dentro de um repositório Git e escolha Compare with Git HEAD. O comando usa o seu git local.
