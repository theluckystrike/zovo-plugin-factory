Leia e retome o seu histórico do Claude Code no VS Code

Instale o Claude Code History & Codex History Viewer (Agent Session Viewer). Ele lista as suas sessões do Claude Code de ~/.claude/projects e as do Codex de ~/.codex/sessions em uma única visão lateral, abre cada uma como uma transcrição fácil de ler e retoma a sessão em um terminal com um clique. Ler, buscar, retomar e exportar uma sessão para Markdown são grátis, sem conta. O Zovo Pro (19 USD, pagos uma vez) acrescenta um relatório de uso e custo, uma exportação segura para compartilhar, com os segredos ocultos, e a exportação em lote para Markdown, e cada ferramenta Pro tem 3 usos grátis.

Passo a passo no VS Code

  1. Instale o Agent Session Viewer pelo Marketplace, ou aperte Ctrl+P (Cmd+P no macOS) e rode ext install zovo.agent-session-viewer.
  2. Clique no ícone Agent Sessions na barra de atividades. A visão Sessions lista as sessões do Claude Code e do Codex agrupadas por pasta de projeto, com os subagentes abaixo da sessão que os iniciou.
  3. Clique em uma sessão para ler. As chamadas de ferramentas ficam recolhidas, as que falharam ganham uma marca vermelha, e as edições de arquivo aparecem como diff. O cabeçalho mostra o modelo, o branch do git, os turnos e os totais de tokens.
  4. Para achar uma sessão antiga, clique no ícone de busca no topo da visão, ou rode "Agent Sessions: Search Sessions" pela Command Palette. Escolha um resultado para abrir a sessão no ponto encontrado.
  5. Clique no ícone de terminal ao lado da sessão (Resume in Terminal). Um terminal abre na pasta do projeto e roda claude --resume <id> ou codex resume <id>.
  6. Para um arquivo de sessão .jsonl em outra pasta, clique nele com o botão direito, escolha Open With e depois Agent Session Viewer.

O que é grátis e o que o Zovo Pro acrescenta

São grátis a árvore Sessions, a leitura das sessões, a busca em todas as sessões, Resume in Terminal, Copy Resume Command, a exportação de uma sessão para Markdown, a visualização bruta (raw) e Reveal in File Manager. Não há limite de histórico nem login.

O Share-safe export salva uma sessão, ou todas as sessões de um projeto, como uma única página HTML independente ou um único arquivo Markdown. Chaves de API, tokens, senhas em URLs, valores de .env, chaves privadas, e-mails e a sua pasta pessoal são trocados por [REDACTED ...], e a mensagem lista o que foi ocultado. Você pode enviar uma sessão para um pull request, uma auditoria ou uma passagem de trabalho sem limpar o texto à mão.

Como usar Share-safe export (Zovo Pro)

  1. Abra a sessão e clique no botão Share-safe export na barra de ferramentas da sessão. Ou clique com o botão direito em uma sessão ou em uma pasta de projeto na árvore Sessions e escolha "Share-Safe Export, Secrets Redacted (Pro)…".
  2. Com uma sessão aberta, você também pode rodar "Agent Sessions: Share-Safe Export, Secrets Redacted (Pro)…" pela Command Palette.
  3. Escolha o formato, página HTML ou Markdown, com ou sem as saídas das ferramentas. Depois escolha onde salvar o arquivo.
  4. Leia a exportação antes de compartilhar. Um uso só conta quando o arquivo é salvo. Escape ou Cancel não gastam nada.

Share-safe export funciona 3 vezes no seu computador antes de pedir uma licença. Não há janela pop-up nem contagem regressiva.

Passo a passo no Cursor, Windsurf ou VSCodium

  1. Abra a visão Extensions com Ctrl+Shift+X (Cmd+Shift+X no macOS).
  2. Busque zovo.agent-session-viewer e clique em Install. Cursor, Windsurf e VSCodium instalam extensões do Open VSX, onde esta se chama zovo/agent-session-viewer.
  3. Se o seu editor não tiver galeria, baixe o arquivo .vsix na página do Open VSX e rode "Extensions: Install from VSIX...".
  4. Depois disso, tudo funciona como no VS Code.

O que o Agent Session Viewer faz

  • Sessões do Claude Code em ~/.claude/projects (ou $CLAUDE_CONFIG_DIR/projects) e sessões do Codex em ~/.codex/sessions (ou $CODEX_HOME/sessions).
  • Subagentes das duas ferramentas, aninhados abaixo da sessão que os iniciou.
  • Um cabeçalho com ferramenta, modelo, pasta do projeto, branch do git, duração, número de turnos, totais de tokens e o custo quando o arquivo registra esse dado (o Claude Code registra, o Codex não).
  • Edições de arquivo como diff (Edit, Write e apply_patch), e o thinking e os resumos de raciocínio do Codex, recolhidos.
  • Nomes de threads do Codex lidos de session_index.jsonl, então threads renomeadas mantêm o nome.

O que ele não faz

  • Ele lê só Claude Code e Codex. Sessões do Cursor, do Copilot e do Gemini CLI ainda não são suportadas.
  • Ele é somente leitura. Nunca altera, move nem apaga arquivos de sessão, e não tem comando para apagar.
  • A busca encontra texto simples, não expressões regulares, e para em 300 resultados.
  • O Resume in Terminal precisa do Claude Code ou do Codex instalado e no PATH do terminal.
  • Por padrão, os arquivos são lidos até 256 MB (agentSessionViewer.maxFileSizeMB). Arquivos maiores abrem só com a primeira parte. O raciocínio do Codex guardado de forma criptografada não pode ser mostrado.

Perguntas frequentes

Onde o Claude Code guarda o histórico de conversas?

Em ~/.claude/projects, com uma pasta por projeto e um arquivo .jsonl por sessão. Se CLAUDE_CONFIG_DIR estiver definida, o histórico fica dentro dessa pasta.

É grátis?

Sim. Ler, buscar, retomar e exportar uma sessão para Markdown são grátis, sem limite de histórico. As três ferramentas Pro (relatório de uso e custo, Share-safe export e exportação em lote) têm 3 usos grátis cada. Depois disso, o Zovo Pro custa 19 USD, pagos uma vez, para todas as extensões Zovo.

Dá para apagar sessões antigas pelo visualizador?

Não. Ele só lê os arquivos de sessão e nunca altera, move ou apaga esses arquivos.

É feito pela Anthropic?

Não. Ele não é feito pela Anthropic nem pela OpenAI e não tem vínculo com elas. Não faz chamadas de rede e não tem telemetria.
