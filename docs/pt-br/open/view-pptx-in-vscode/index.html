Guias em português · PPTX Viewer

Ver slides PowerPoint .pptx no VS Code

A extensão gratuita PPTX Viewer abre apresentações do PowerPoint direto no VS Code: .pptx, .ppsx, .potx, .pptm e os antigos .ppt, com miniaturas, notas do apresentador, busca e o botão Present. É útil para conferir um deck que um script, o python-pptx ou um agente de IA acabou de gerar: o slide recarrega quando o arquivo é salvo. Sem PowerPoint, sem LibreOffice e sem upload.

Gratuita, licença MIT. ID zovo.pptx-slide-viewer, versão 0.5.4. Requer VS Code 1.90.0 ou mais recente.

Passo a passo no VS Code

  1. Instale a extensão PPTX Viewer pelo Marketplace, ou pressione Ctrl+P (Cmd+P no macOS) e rode ext install zovo.pptx-slide-viewer.
  2. Clique em um arquivo .pptx, .ppsx, .potx, .pptm ou .ppt no Explorer. Os slides aparecem com miniaturas e as notas do apresentador embaixo.
  3. Pressione Ctrl+F (Cmd+F no macOS) para buscar em títulos, tópicos, tabelas e notas do deck inteiro. A aba Outline lista os slides com o termo, e Enter vai para o próximo.
  4. Clique em Present para mostrar um slide por vez em tela cheia, com as setas, a barra de espaço ou um clique. Esc traz o editor de volta.
  5. Copy: "PNG" copia o slide atual como imagem (cerca de 1920 pixels de largura) para colar em um pull request ou issue. Copy: "Markdown" copia o slide como Markdown, e "All" copia o deck inteiro.
  6. Deixe o deck aberto enquanto um script o gera de novo: a cada salvamento o slide se atualiza em cerca de um segundo, no mesmo slide.

O que é grátis e o que o Zovo Pro adiciona

Ver os slides, Present, notas do apresentador, busca, miniaturas e outline, copiar ou salvar um slide como PNG e Copy as Markdown são gratuitos.

Para mandar o deck a quem não tem PowerPoint, Export Deck as PDF salva um PDF com uma página por slide, no tamanho do slide. As páginas são imagens dos slides, então o texto do PDF não pode ser selecionado. O Zovo Pro também exporta todos os slides como PNG, converte uma pasta de decks em Markdown com as notas e salva uma cópia menor de um deck com fotos grandes (Compress Deck).

Com Export Deck as PDF (Zovo Pro)

  1. Com o deck aberto, clique em Export na barra de ferramentas e escolha o PDF, ou rode "Export Deck as PDF (Pro)..." pela Command Palette.
  2. Escolha onde salvar o PDF.
  3. O deck original não é alterado, e as imagens são geradas no seu computador.

Export Deck as PDF funciona 3 vezes no seu computador antes de pedir uma licença, e uma tentativa só conta quando você recebe um resultado. Nada sobre o Pro aparece quando você abre um arquivo.

No Cursor, Windsurf ou VSCodium

Esses editores instalam extensões pelo Open VSX. Abra a visão Extensions (Ctrl+Shift+X, ou Cmd+Shift+X no macOS), procure zovo.pptx-slide-viewer e clique em Install. Depois disso, tudo funciona como no VS Code.

O que ela não faz

  • É um visualizador. Não edita slides.
  • Arquivos .ppt antigos abrem só como texto: títulos, texto dos slides e notas, sem imagens nem layout.
  • Vídeo, áudio e objetos incorporados não são desenhados, e o slide avisa o que falta.
  • Fontes que não estão instaladas são trocadas por uma parecida, então a quebra de linha pode mudar um pouco.

Perguntas

A extensão é paga?

Não. Ver, apresentar, buscar e copiar slides é gratuito. Só as exportações, a compressão e a comparação de decks são Zovo Pro (USD 19 uma vez), com 3 usos grátis cada.

Funciona com Remote SSH, WSL ou Codespaces?

Sim. A extensão lê o arquivo pelo VS Code, então funciona também em Remote SSH, WSL, Dev Containers e Codespaces.

O arquivo é enviado para algum lugar?

Não. Tudo roda no seu computador, sem telemetria.
