Como formatar XML no VS Code e fazer consultas XPath

Instale a extensão grátis XML Formatter & XPath Tools, abra um arquivo XML e aperte Shift+Alt+F (Shift+Option+F no Mac). Só os espaços em branco entre as tags mudam. Texto, CDATA, comentários, xml:space="preserve" e valores de atributos ficam iguais byte a byte, e um arquivo malformado nunca é alterado. Formatação, Minify XML, XPath 1.0 com os prefixos de namespace do próprio arquivo, Copy XPath e a visão XML Tree são grátis e funcionam offline. O Zovo Pro (19 USD, pagos uma vez só) acrescenta três ferramentas, Run XPath on Every XML File in a Folder, Format All XML Files in a Folder e Compare Two XML Files Ignoring Formatting, e cada uma tem 3 usos grátis.

Passo a passo no VS Code

  1. Instale o XML Formatter & XPath Tools pelo Marketplace, ou aperte Ctrl+P (Cmd+P no macOS) e rode ext install zovo.zovo-xml-xpath-tools.
  2. Abra um arquivo .xml e aperte Shift+Alt+F (Shift+Option+F no Mac), ou rode Format Document. Se você tiver mais de um formatador de XML, o VS Code pergunta qual usar. Format Selection também funciona.
  3. O formatador usa o seu tamanho de tabulação e a sua escolha entre tabs ou espaços, e mantém as quebras de linha, a marca de ordem de bytes (BOM) e a nova linha final. Se o arquivo estiver malformado, nada muda e você vê o erro com linha e coluna.
  4. Para deixar o arquivo menor, rode "XML: Minify XML" no arquivo inteiro ou em uma seleção. Os comentários ficam, a menos que você ative xmlXpathTools.minify.removeComments.
  5. Para rodar um XPath, clique no botão de busca na barra de título do editor ou rode "XML: Evaluate XPath…". Os resultados aparecem em XPath Results com a linha de cada um. Clique em um resultado para selecioná-lo no editor.
  6. Clique no XPath na barra de status para copiar o caminho do elemento sob o cursor: com posições, com atributos id ou name, ou na forma portátil com local-name().
  7. Para um arquivo acima de 50 MB, clique nele com o botão direito no Explorer e escolha "Format Large XML File on Disk…". O comando grava name.formatted.xml ao lado, ou substitui o arquivo depois que você confirmar.

O que é grátis e o que o Zovo Pro acrescenta

Format Document, Format Selection, Minify XML, XPath 1.0, Copy XPath, a visão XML Tree, os erros de boa formação em Problems e Format Large XML File on Disk são grátis. Não há login, e a extensão não tem código de rede.

Run XPath on Every XML File in a Folder roda um XPath em cada arquivo .xml, .xsd, .csproj, .svg, .kml e semelhantes dentro de uma pasta, cada um com seus próprios prefixos de namespace. Os resultados abrem como CSV (file, line, kind, name, value) para uma planilha, como JSON para um script ou como relatório em Markdown para uma revisão. Você pega o mesmo valor de muitos arquivos, como cada artifactId de um conjunto de arquivos pom.xml, sem abrir um por um.

Como usar Run XPath on Every XML File in a Folder (Zovo Pro)

  1. Clique com o botão direito em uma pasta no Explorer e escolha "Zovo Pro: Run XPath on Every XML File in a Folder", ou rode "XML: Run XPath on Every XML File in a Folder (Pro)" pela Command Palette e escolha a pasta.
  2. Ou, depois de rodar um XPath em um arquivo, clique na última linha de XPath Results, "Run this XPath on every XML file in a folder", para rodar a mesma expressão em uma pasta.
  3. Digite o XPath. Uma notificação mostra o progresso com um botão Cancel.
  4. Escolha "Open as CSV", "Open as JSON" ou "Open a Markdown report". Os resultados abrem em uma nova aba do editor. Um uso só conta quando você recebe um resultado. Escape, um erro de digitação no XPath ou uma pasta sem arquivos XML não gastam nenhum.

Passo a passo no Cursor, Windsurf ou VSCodium

  1. Abra a visão Extensions com Ctrl+Shift+X (Cmd+Shift+X no macOS).
  2. Busque zovo.zovo-xml-xpath-tools e clique em Install. Cursor, Windsurf e VSCodium instalam extensões do Open VSX, onde esta se chama zovo/zovo-xml-xpath-tools.
  3. Se o seu editor não tiver galeria, baixe o arquivo .vsix na página do Open VSX e rode "Extensions: Install from VSIX...".
  4. Depois disso, tudo funciona como no VS Code.

O que o XML Formatter & XPath Tools faz

  • Arquivos que o VS Code abre como XML. A extensão também abre como XML os arquivos .kml, .gpx, .rss, .atom, .wsdl, .dbk, .xlf, .xliff, .resx, .nuspec, .props, .targets e .xaml.
  • Arquivos grandes. Formatação, árvore e XPath rodam em uma thread em segundo plano. Nos testes da extensão, um arquivo de 49 MB com cerca de 1 milhão de elementos foi formatado em 1,6 segundo.
  • Nomes simples também casam com um namespace padrão, então //dependency/artifactId funciona em um pom.xml. Ative xmlXpathTools.xpath.strictNamespaces para XPath 1.0 estrito.
  • Os atributos podem ficar como foram escritos, em uma linha só ou um por linha (configuração xmlXpathTools.format.attributes).
  • A visão XML Tree no Explorer acompanha o cursor, e Problems lista os erros de boa formação com linha e coluna.

O que ele não faz

  • Só XPath 1.0. Não há XPath 2.0 ou 3.1, XQuery nem XSLT.
  • A extensão verifica se o arquivo é bem formado. Ela não valida contra um XSD ou uma DTD.
  • Arquivos acima de 50 MB podem ser formatados no disco, mas o VS Code não os entrega às extensões, então a árvore e o XPath não rodam neles.
  • O comando no disco lê UTF-8, UTF-16 com marca de ordem de bytes e ISO-8859-1.
  • Um elemento com texto dentro, como <p>Some <b>bold</b> text</p>, fica na sua linha como foi escrito. Só elementos que têm tags e nenhum texto ganham novas quebras de linha.

Perguntas frequentes

É grátis?

Formatação, Minify XML, XPath, Copy XPath, a visão XML Tree e as verificações de boa formação são grátis. As três ferramentas Pro, Run XPath on Every XML File in a Folder, Format All XML Files in a Folder e Compare Two XML Files Ignoring Formatting, têm 3 usos grátis cada. Depois disso, elas precisam do Zovo Pro, 19 USD uma vez só para todas as extensões Zovo.

A formatação muda meu texto ou o CDATA?

Não. Só mudam os espaços em branco entre as tags, em elementos que têm tags e nenhum texto. Texto, CDATA, comentários e conteúdo dentro de xml:space="preserve" são copiados como estão, e uma segunda formatação não muda nada.

Por que meu XPath não seleciona nada em um pom.xml?

O arquivo tem um namespace padrão. Nesta extensão, nomes simples também casam com um namespace padrão, então //dependency funciona. Ative xmlXpathTools.xpath.strictNamespaces para XPath 1.0 estrito.

Funciona no Cursor?

Sim. Cursor, Windsurf e VSCodium instalam a extensão pelo Open VSX, onde ela está publicada como zovo/zovo-xml-xpath-tools.
