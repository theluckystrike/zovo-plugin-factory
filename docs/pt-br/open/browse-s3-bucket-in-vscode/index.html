Como navegar em buckets AWS S3, Cloudflare R2 ou MinIO no VS Code

Instale a extensão grátis S3 Explorer e abra a visualização S3 Buckets na Activity Bar. Ela funciona com AWS S3 (perfis de ~/.aws, inclusive perfis SSO), Cloudflare R2, MinIO, Backblaze B2, Wasabi e DigitalOcean Spaces. Navegar, abrir objetos só para leitura, upload, download, copiar, mover, renomear, excluir, versões, tags, URLs pré-assinadas e sincronização de pastas são grátis, sem login e sem telemetria. O Zovo Pro (19 USD, pagos uma vez só) acrescenta três ferramentas, Copy to Another Connection, o Size and Cost Report e o Scheduled Sync, e cada uma tem 3 usos grátis.

Passo a passo no VS Code

  1. Instale o S3 Explorer pelo Marketplace, ou aperte Ctrl+P (Cmd+P no macOS) e rode ext install zovo.zovo-s3-explorer.
  2. Abra a visualização do S3 Explorer na Activity Bar e clique em Add Connection. Escolha um perfil AWS de ~/.aws, ou digite uma access key, um account ID e um token do R2, ou a URL do endpoint do MinIO ou de outro serviço compatível com S3. As chaves que você digita vão para o chaveiro do sistema operacional.
  3. Expanda uma conexão para ver os buckets. As chaves carregam de 1.000 em 1.000, com uma linha "Load 1,000 more". Se a sua chave não tiver permissão para listar buckets, clique com o botão direito na conexão e escolha Add Bucket by Name.
  4. Clique em um objeto para abri-lo só para leitura em uma aba ou no visualizador correspondente. Para ver os metadados, as tags, as versões e uma URL pré-assinada, clique com o botão direito no objeto e escolha Show Details, Versions and Presigned URL.
  5. Para alterar um objeto, clique com o botão direito nele e escolha Edit and Upload. Você edita uma cópia, e um diálogo mostra o bucket, a chave e os dois tamanhos antes de o objeto ser substituído.
  6. Arraste arquivos ou pastas do Explorer para um bucket para enviá-los, ou clique com o botão direito e escolha Download. Arquivos de 16 MB ou mais são enviados em partes, com progresso e Cancel, e um upload interrompido é retomado enviando só as partes que faltam.
  7. Para manter uma pasta local e um prefixo iguais, clique com o botão direito no bucket ou na pasta e escolha Sync Folder. Você vê um plano de dry-run (novos, alterados, a excluir) antes de qualquer mudança.

O que é grátis e o que o Zovo Pro acrescenta

Navegar, abrir, Edit and Upload, upload, download, copiar, mover, renomear, excluir, versões, tags, URLs pré-assinadas e sincronização de pastas são grátis, sem login, sem conta e sem telemetria. A extensão só se conecta aos endpoints de armazenamento que você adiciona.

Copy to Another Connection copia objetos ou pastas inteiras de uma conexão para outra, por exemplo do AWS S3 para o Cloudflare R2 ou o MinIO, com a mesma confirmação de toda cópia: as chaves são listadas, e as chaves que seriam substituídas aparecem pelo nome. Objetos grandes passam por um upload multipart. Você move dados entre provedores ou contas direto pela árvore, sem script e sem uma segunda ferramenta.

Como usar Copy to Another Connection (Zovo Pro)

  1. Adicione a segunda conexão antes. Depois clique com o botão direito em um objeto ou em uma pasta na visualização S3 Buckets e escolha "Copy to Another Connection... (Pro)", ou clique em Copy to Another Connection na linha "Zovo Pro tools" no fim da visualização.
  2. Escolha a conexão de destino, o bucket e a pasta de destino (vazia para o nível mais alto).
  3. Leia a lista de objetos na confirmação e clique em Copy, ou em Copy and Replace quando algumas chaves já existirem. Uma notificação mostra o progresso.
  4. Um uso só conta quando objetos foram copiados. Escape em uma das escolhas, ou a falta de uma segunda conexão, não gasta nenhum.

Copy to Another Connection funciona 3 vezes no seu computador antes de pedir uma licença. Não há janela pop-up nem contagem regressiva.

Passo a passo no Cursor, Windsurf ou VSCodium

  1. Abra a visão Extensions com Ctrl+Shift+X (Cmd+Shift+X no macOS).
  2. Busque zovo.zovo-s3-explorer e clique em Install. Cursor, Windsurf e VSCodium instalam extensões do Open VSX, onde esta se chama zovo/zovo-s3-explorer.
  3. Se o seu editor não tiver galeria, baixe o arquivo .vsix na página do Open VSX e rode "Extensions: Install from VSIX...".
  4. Depois disso, tudo funciona como no VS Code.

O que o S3 Explorer faz

  • Perfis AWS com access keys, credential_process, roles com source_profile e perfis SSO depois de aws sso login. O endpoint_url de um perfil é respeitado.
  • MinIO e outros serviços compatíveis com S3 com URL de endpoint, região, URLs path-style ou virtual-hosted e uma opção para aceitar certificado autoassinado.
  • Metadados, tipo de conteúdo, classe de armazenamento, ETag, tags (editar e salvar), versões (abrir, baixar, restaurar) e URLs pré-assinadas GET ou PUT de 15 minutos a 7 dias.
  • Buckets com milhões de chaves, de 1.000 em 1.000, com busca e filtro por prefixo.
  • Os downloads mantêm a estrutura de pastas e nunca gravam fora da pasta escolhida. Chaves com segmentos .., letras de unidade ou bytes NUL são puladas e listadas.

O que ele não faz

  • A extensão nunca usa sozinha o perfil AWS default nem o AWS_PROFILE. Você escolhe o perfil da conexão.
  • Objetos de texto acima de 10 MB pedem confirmação e depois mostram o primeiro 1 MB. Objetos binários acima de 200 MB pedem confirmação antes do download.
  • Os objetos abertos são só para leitura. Só o Edit and Upload grava no bucket, depois de uma confirmação.
  • O Scheduled Sync só roda com o VS Code aberto, a cada 5 a 60 minutos, e nunca exclui nada.
  • Requisições sem resposta param depois de 30 segundos (configuração s3Explorer.requestTimeoutSeconds).

Perguntas frequentes

É grátis?

Navegar, abrir, upload, download, copiar, mover, renomear, excluir, versões, tags, URLs pré-assinadas e sincronização de pastas são grátis. As três ferramentas Pro, Copy to Another Connection, o Size and Cost Report e o Scheduled Sync, têm 3 usos grátis cada. Depois disso, elas precisam do Zovo Pro, 19 USD uma vez só para todas as extensões Zovo.

Onde ficam minhas chaves?

As chaves que você digita vão para o chaveiro do sistema operacional pelo SecretStorage do VS Code, nunca para arquivos de configuração. Os perfis AWS são lidos de ~/.aws só quando você escolhe um.

Funciona com Cloudflare R2 e MinIO?

Sim. O R2 usa o seu account ID e a access key de um token de API do R2. O MinIO e outros serviços compatíveis com S3 usam uma URL de endpoint, uma região e URLs path-style ou virtual-hosted.

Funciona no Cursor?

Sim. Cursor, Windsurf e VSCodium instalam a extensão pelo Open VSX, onde ela está publicada como zovo/zovo-s3-explorer.
