Formatar HTML e CSS no VS Code sem quebrar blocos pre ou tags inline

Instale a extensão grátis HTML Formatter & CSS Formatter e pressione Shift+Alt+F em um arquivo HTML, CSS, SCSS ou LESS. Ela também formata os blocos <style> e <script> dentro da página, segue o seu .editorconfig, mantém <pre>, <textarea> e as tags inline como você escreveu e nunca muda a ordem dos atributos. Ela roda offline com um js-beautify embutido, então não precisa de Node, npm nem arquivo de configuração. O Zovo Pro (19 USD, pagos uma vez só) acrescenta três ferramentas, Format Folder with Diff Preview, Minify HTML and CSS e HTML Lint Report, e cada uma tem 3 usos grátis.

Passo a passo no VS Code

  1. Instale o HTML Formatter & CSS Formatter pelo Marketplace, ou aperte Ctrl+P (Cmd+P no macOS) e rode ext install zovo.zovo-html-formatter.
  2. Abra um arquivo HTML, CSS, SCSS ou LESS e pressione Shift+Alt+F (Shift+Option+F no macOS). Se o VS Code perguntar qual formatador usar, escolha HTML Formatter & CSS Formatter.
  3. Para torná-lo o formatador padrão das quatro linguagens de uma vez, execute "HTML Formatter: Use as Default Formatter for HTML, CSS, SCSS and LESS" na Command Palette.
  4. Selecione algumas linhas e execute Format Selection para formatar só essas linhas.
  5. Para formatar sempre que salvar, ative zovoHtmlFormat.formatOnSave, ou use o editor.formatOnSave do próprio VS Code depois que a extensão for o formatador padrão.
  6. A indentação vem do editor e depois do .editorconfig (estilo e tamanho da indentação, fim de linha, nova linha final, comprimento máximo da linha), então toda a equipe tem o mesmo resultado.

O que é grátis e o que o Zovo Pro acrescenta

Format Document, Format Selection e formatar ao salvar para HTML, CSS, SCSS e LESS, com suporte a .editorconfig, são grátis, sem login, sem requisições de rede e sem telemetria.

Quando um site inteiro precisa seguir um só estilo, o Format Folder with Diff Preview formata em memória todos os arquivos HTML, CSS, SCSS e LESS de uma pasta, mostra os arquivos alterados com um diff lado a lado para cada um e grava só os arquivos que você deixar marcados. Você vê cada mudança antes de qualquer arquivo ser gravado.

Como usar Format Folder with Diff Preview (Zovo Pro)

  1. Clique com o botão direito em uma pasta no Explorer e escolha "Zovo Pro: Format folder with diff preview", ou execute "HTML Formatter: Format Folder with Diff Preview (Pro)" na Command Palette.
  2. Confira os arquivos alterados. Abra o diff de qualquer arquivo e desmarque os arquivos que você quer deixar como estão.
  3. Grave os arquivos marcados. Um uso só é contado quando a ferramenta entrega um resultado.

Passo a passo no Cursor, Windsurf ou VSCodium

  1. Abra a visão Extensions com Ctrl+Shift+X (Cmd+Shift+X no macOS).
  2. Busque zovo.zovo-html-formatter e clique em Install. Cursor, Windsurf e VSCodium instalam extensões do Open VSX, onde esta se chama zovo/zovo-html-formatter.
  3. Se o seu editor não tiver galeria, baixe o arquivo .vsix na página do Open VSX e rode "Extensions: Install from VSIX...".
  4. Depois disso, tudo funciona como no VS Code.

O que o HTML Formatter & CSS Formatter faz

  • O CSS em <style> e o JavaScript em <script> dentro do HTML.
  • Ficam como você escreveu: o conteúdo de <pre> e <textarea>, as tags inline na própria linha, a ordem dos atributos, as linhas em branco entre blocos (no máximo uma seguida), o estilo de indentação do head e do body da página e tags de template como {{ }} e {% %}.
  • Em SCSS e LESS, maps e chamadas de função em várias linhas mantêm o layout, e os comentários no fim da linha continuam na mesma linha.
  • As outras duas ferramentas Pro. Minify HTML and CSS grava cópias .min.html e .min.css com um relatório dos bytes e dos bytes gzip economizados. HTML Lint Report encontra imagens sem texto alt, campos de formulário sem label, ids duplicados, níveis de título pulados e outros problemas, em um relatório Markdown e no painel Problems.

O que ele não faz

  • Arquivos .js, .jsx, .ts, Vue e Svelte avulsos não são formatados por esta extensão. Só o JavaScript dentro de <script> é formatado.
  • As linhas não são quebradas a menos que você defina um comprimento de quebra, então uma linha muito longa continua longa.
  • SCSS e LESS passam pelo formatador de CSS. Sintaxes incomuns, como os detached rulesets do LESS, podem manter o espaçamento original.
  • O Minify não encurta JavaScript e não renomeia nem junta regras CSS.

Perguntas frequentes

É grátis?

Format Document, Format Selection e formatar ao salvar para HTML, CSS, SCSS e LESS são grátis. As três ferramentas Pro, Format Folder with Diff Preview, Minify HTML and CSS e HTML Lint Report, têm 3 usos grátis cada. Depois disso, elas precisam do Zovo Pro, 19 USD pagos uma vez só para todas as extensões Zovo.

O VS Code formata HTML sem extensão?

Sim. O VS Code tem um formatador de HTML e CSS embutido. Esta extensão lê o .editorconfig, mantém a indentação própria do head e do body da página, mantém o layout dos maps de SCSS e LESS e acrescenta as ferramentas Pro de pasta, minify e lint.

Ela vai mudar meus blocos pre ou reordenar atributos?

Não. O conteúdo de pre e textarea, as tags inline e a ordem dos atributos ficam como você escreveu.

Precisa de Node ou npm?

Não. O js-beautify 1.15.4 vem embutido na extensão e roda offline.
