Abrir um arquivo Word .docx no VS Code

O VS Code não tem visualizador de Word, então um .docx abre com o aviso de arquivo binário. Instale a extensão gratuita DOCX Viewer e clique no arquivo de novo: ele abre como pré-visualização somente leitura, no tema do editor, com outline, busca, tabelas, gráficos e equações. Não precisa de Office nem de LibreOffice, e nada é enviado para a internet.

Passo a passo no VS Code

  1. Instale a extensão DOCX Viewer pelo Marketplace, ou pressione Ctrl+P (Cmd+P no macOS) e rode ext install zovo.docx-viewer-vscode.
  2. Clique em um arquivo .docx, .dotx ou .docm no Explorer. Arquivos OpenDocument (.odt) e os antigos .doc do Word 97-2003 também abrem, os .doc só como texto.
  3. Pressione Ctrl+F (Cmd+F no macOS) para buscar. O contador mostra quantas ocorrências há, e o outline leva direto a qualquer título.
  4. O botão de tema alterna entre as cores do editor e o papel branco. "Page view" mostra as páginas como o Word as monta, com margens, cabeçalhos e rodapés, e "Reading view" volta ao texto corrido.
  5. Se o documento tem alterações controladas ou comentários, uma barra no topo conta quantos são. Markup, Final e Original mostram o texto com as marcas, aceito ou rejeitado, sem mudar o arquivo.
  6. Para ver o que mudou entre duas versões, clique com o botão direito no arquivo e escolha "Compare with Git HEAD" ou "Compare Documents (Redline)...". O redline na tela é gratuito.

O que é grátis e o que o Zovo Pro adiciona

Leitura, Page view, busca, outline, alterações controladas e comentários, Copy as Markdown e o redline de duas versões na tela são gratuitos, sem conta e sem limite de uso.

Quando alguém precisa revisar as mudanças no próprio Word, Export Redline as Word grava um novo .docx em que cada diferença entre as duas versões vira uma alteração controlada real, do autor "Compare". O Word e o LibreOffice aceitam ou rejeitam cada uma. O Zovo Pro também exporta o redline como um arquivo HTML, salva a lista de mudanças em Excel e compara duas pastas de documentos.

Com Export Redline as Word (Zovo Pro)

  1. Com o documento aberto, rode "Export Redline as Word (Pro)..." pela Command Palette, ou clique com o botão direito no arquivo no Explorer.
  2. Escolha a outra versão do documento.
  3. Escolha onde salvar. Os dois documentos originais não são alterados.

Export Redline as Word funciona 3 vezes no seu computador antes de pedir uma licença, e uma tentativa só conta quando você recebe um resultado. Nada sobre o Pro aparece quando você abre um arquivo.

No Cursor, Windsurf ou VSCodium

Esses editores instalam extensões pelo Open VSX. Abra a visão Extensions (Ctrl+Shift+X, ou Cmd+Shift+X no macOS), procure zovo.docx-viewer-vscode e clique em Install. Depois disso, tudo funciona como no VS Code.

O que ela não faz

  • É um visualizador. Não edita nem salva o documento.
  • Arquivos .doc antigos mostram só o texto, sem formatação nem imagens.
  • SmartArt não aparece, e arquivos protegidos por senha mostram um aviso no lugar do conteúdo.

Perguntas

Preciso do Microsoft Office?

Não. A extensão lê o arquivo sozinha, dentro do VS Code ou do Cursor, e funciona offline.

A extensão é paga?

Não. Ler, buscar e comparar na tela é gratuito. Só as exportações e a comparação de pastas são Zovo Pro (USD 19 uma vez), com 3 usos grátis cada.

Funciona no navegador?

Sim. No vscode.dev e no github.dev, clique em um .docx de um repositório do GitHub para ler sem clonar.
