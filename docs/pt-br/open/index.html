Abra seus arquivos no VS Code e no Cursor

O VS Code abre texto, imagens e alguns vídeos. Para Word, PowerPoint, Excel, PDF no modo escuro ou um arquivo binário, você precisa de uma extensão. Cada guia mostra o passo a passo no VS Code e no Cursor, o que é grátis e o que o Zovo Pro adiciona.

  • Abrir um arquivo Word .docx no VS Code
    O VS Code mostra um .docx como binário. Com a extensão gratuita DOCX Viewer, o arquivo Word abre como pré-visualização com busca, outline e modo escuro. Funciona no Cursor.
  • Ver slides PowerPoint .pptx no VS Code
    Abra .pptx, .ppsx, .potx e .ppt antigos no VS Code ou no Cursor, com miniaturas, notas do apresentador, busca e apresentação em tela cheia. Extensão gratuita, sem upload.
  • Abrir Excel e CSV no VS Code como tabela
    Veja .xlsx, .xls, .ods, CSV e Parquet no VS Code como tabela que ordena e filtra, até 1.000.000 de linhas, e rode SQL com GROUP BY. Extensão gratuita, sem Excel e sem Python.
  • Ler PDF no modo escuro no VS Code
    Leia PDFs no VS Code com páginas escuras ou sépia, e as fotos mantêm as cores reais. Busca, outline, miniaturas e destaques em Markdown. Extensão gratuita e offline.
  • Editor hexadecimal no VS Code
    Veja, edite e compare os bytes de qualquer arquivo no VS Code, até imagens de disco de 4 GB. Ir para offset, busca com curinga, data inspector. Extensão gratuita e offline.
  • Renomeie tags HTML, JSX e Vue automaticamente no VS Code
    Renomeie uma tag HTML, JSX ou Vue e a tag correspondente muda enquanto você digita. Extensão grátis baseada no linked editing do VS Code, com um único undo.
  • Como navegar em buckets AWS S3, Cloudflare R2 ou MinIO no VS Code
    Navegue em buckets S3, R2, MinIO, B2 e Wasabi no VS Code: abra objetos só para leitura, faça upload e download com retomada e sincronize pastas com dry-run.
  • Leia e retome o seu histórico do Claude Code no VS Code
    Leia, busque e retome sessões antigas do Claude Code e do Codex no VS Code. Subagentes aninhados, edições como diff, totais de tokens. Só leitura e offline.
  • Compare dois arquivos ZIP no VS Code
    Abra ZIP, JAR, TAR e GZ no VS Code de graça e liste os arquivos adicionados, removidos ou alterados entre dois pacotes em um relatório Markdown (Zovo Pro).
  • Como converter um arquivo PDF, Word, PowerPoint ou Excel para Markdown no VS Code
    Clique com o botão direito em um PDF, DOCX, PPTX, XLSX, CSV, HTML ou EPUB no VS Code e o Markdown abre ao lado. Grátis, offline, sem Python e sem upload.
  • DXF para CSV no VS Code: extraia atributos de bloco e textos
    Abra um desenho DXF no VS Code e salve atributos de bloco, contagem de blocos, textos ou layers em CSV para o Excel. Ver é grátis, o CSV é do Zovo Pro.
  • Como editar um arquivo .env no VS Code sem mostrar seus segredos
    Cores para arquivos .env no VS Code, valores secretos como pontos até o cursor chegar na linha, e correção de chaves duplicadas e aspas. Grátis e offline.
  • Formatar e verificar um arquivo de configuração do nginx no VS Code
    Formate o nginx.conf no VS Code sem quebrar um arquivo válido, veja um ; faltando ou uma diretiva fora do bloco certo e use o hover de cerca de 300 diretivas.
  • Como formatar um script bash ou zsh no VS Code
    Formate scripts bash, sh, zsh, bats e mksh no VS Code com Shift+Alt+F ou ao salvar. O shfmt 3.14.1 vem embutido, lê o .editorconfig e funciona offline.
  • Como formatar XML no VS Code e fazer consultas XPath
    Formate ou minifique XML no VS Code mudando só os espaços entre as tags, rode XPath 1.0 com os namespaces do próprio arquivo e copie o XPath do cursor.
  • Como ver a imagem de um caminho no seu código, na margem e no hover
    Veja uma miniatura na margem e um hover com a imagem, o tamanho em pixels e o tamanho do arquivo para caminhos em JS, CSS, HTML e Markdown no VS Code.
  • Veja o preview de diagramas Mermaid no VS Code
    Veja diagramas Mermaid de arquivos .mmd e de blocos no Markdown com o Mermaid Viewer grátis. Preview ao vivo, PNG e SVG, offline e sem login.
  • Um visualizador NetCDF grátis que roda no VS Code
    Abra arquivos NetCDF .nc no VS Code no Windows, macOS ou Linux: cabeçalho, variáveis, mapas com litoral e séries temporais. Também HDF5 e MATLAB 7.3.
  • Normalize o loudness do áudio para um alvo em LUFS
    Toque WAV, MP3, FLAC, Ogg e Opus no VS Code com um medidor LUFS grátis e grave um WAV novo em -14, -16 ou -23 LUFS. Offline, sem upload.
  • Abra arquivos .npy e .npz do NumPy no VS Code
    Abra arrays NumPy .npy e .npz no VS Code com o Tensor Viewer grátis: dtype, shape, estatísticas, heatmaps, imagens e valores, sem Python.
  • Abra um arquivo PCAP no VS Code
    Leia capturas .pcap, .pcapng e .pcap.gz no VS Code com o PCAP Viewer grátis: lista de pacotes, árvore de protocolos, painel hex e filtros. Sem Wireshark.
  • Assista vídeos MOV, MKV, WebM e MP4 com som no VS Code
    Assista MP4, MOV e M4V com som AAC no VS Code sem instalar mais nada. MKV, WebM e AVI também tocam, com o seu ffmpeg. Player grátis com legendas.
  • Visualizar um diagrama PlantUML no VS Code enquanto você digita
    Preview ao vivo de PlantUML no VS Code para arquivos .puml e blocos plantuml no Markdown, desenhado no seu computador. Precisa de Java 11, sem Graphviz.
  • Editar arquivos .proto no VS Code com destaque de sintaxe, formatação e ir para a definição
    Destaque, formate e verifique arquivos .proto no VS Code: formatador que mantém os comentários e erros no estilo do protoc. Grátis, offline, sem protoc.
  • Abra um banco de dados SQLite no VS Code
    Abra um arquivo .db ou .sqlite no VS Code com o SQLite Viewer & Editor grátis: tabelas, esquema e SQL. Edite células e linhas e salve com backup.
  • Abra arquivos STL no VS Code
    Abra arquivos STL no VS Code com o 3D Model Viewer grátis: gire, meça entre dois pontos, use wireframe e veja estatísticas. Também abre OBJ, PLY, 3MF e glTF.
  • Converta TIFF para PNG sem perder qualidade
    Abra TIFF, BigTIFF e GeoTIFF no VS Code de graça e salve uma página ou todas como PNG, com os valores de 8 e 16 bits exatos. Offline.
  • Converta TTF para WOFF2 no VS Code
    Veja fontes TTF, OTF, WOFF e WOFF2 no VS Code de graça e converta TTF ou OTF para WOFF2 ao lado do arquivo original. Offline, sem upload.
  • XMind para PDF sem o XMind: todas as folhas em um único PDF
    Abra um mapa mental .xmind no VS Code sem o XMind e salve todas as folhas em um PDF, uma página por folha. Ver é grátis, o PDF é uma ferramenta do Zovo Pro.
