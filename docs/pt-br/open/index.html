Abra seus arquivos no VS Code e no Cursor

O VS Code abre texto, imagens e alguns vídeos. Para Word, PowerPoint, Excel, PDF no modo escuro ou um arquivo binário, você precisa de uma extensão. Cada guia mostra o passo a passo no VS Code e no Cursor, o que é grátis e o que o Zovo Pro adiciona.

  • Abrir um arquivo Word .docx no VS Code
    O VS Code mostra um .docx como binário. Com a extensão gratuita DOCX Viewer, o arquivo Word abre como pré-visualização com busca, outline e modo escuro. Funciona no Cursor.
  • Ver slides PowerPoint .pptx no VS Code
    Abra .pptx, .ppsx, .potx e .ppt antigos no VS Code ou no Cursor, com miniaturas, notas do apresentador, busca e apresentação em tela cheia. Extensão gratuita, sem upload.
  • Abrir Excel e CSV no VS Code como tabela
    Veja .xlsx, .xls, .ods, CSV e Parquet no VS Code como tabela que ordena e filtra, até 1.000.000 de linhas, e rode SQL com GROUP BY. Extensão gratuita, sem Excel e sem Python.
  • Ler PDF no modo escuro no VS Code
    Leia PDFs no VS Code com páginas escuras ou sépia, e as fotos mantêm as cores reais. Busca, outline, miniaturas e destaques em Markdown. Extensão gratuita e offline.
  • Editor hexadecimal no VS Code
    Veja, edite e compare os bytes de qualquer arquivo no VS Code, até imagens de disco de 4 GB. Ir para offset, busca com curinga, data inspector. Extensão gratuita e offline.
