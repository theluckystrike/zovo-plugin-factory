Guias em português · Table Viewer

Abrir Excel e CSV no VS Code como tabela

O VS Code abre um .xlsx como binário e um CSV como texto puro. A extensão gratuita Table Viewer mostra planilhas Excel, CSV e Parquet como uma tabela que ordena, filtra e busca, até 1.000.000 de linhas, com os formatos de número do Excel e as fórmulas. O botão Query roda SQL com GROUP BY sobre o arquivo. Sem Excel, sem Python e sem enviar nada para a internet.

Passo a passo no VS Code

  1. Instale a extensão Table Viewer pelo Marketplace, ou pressione Ctrl+P (Cmd+P no macOS) e rode ext install zovo.table-viewer-vscode.
  2. Clique em um arquivo .xlsx, .xlsm, .xlsb, .xls, .ods ou .parquet no Explorer. Ele abre como tabela. Uma pasta de trabalho com várias planilhas mostra um seletor.
  3. Um .csv ou .tsv continua abrindo como texto. Clique no ícone de tabela no canto superior direito do editor, ou clique com o botão direito no arquivo e escolha "Open in Table Viewer".
  4. Clique no cabeçalho de uma coluna para ordenar. Digite na caixa abaixo do cabeçalho para filtrar: >10, 5..9 ou parte de um texto. A caixa de busca no topo procura em todas as colunas.
  5. Clique em Query, escreva um SELECT e pressione Ctrl+Enter (Cmd+Enter no macOS). FROM this é o arquivo aberto, e um JOIN com outra planilha da mesma pasta de trabalho é gratuito.
  6. Copy CSV, Copy JSON e Copy Markdown copiam a seleção. Export salva as linhas filtradas como CSV, TSV, JSON ou JSON Lines.

O que é grátis e o que o Zovo Pro adiciona

Abrir CSV, TSV, Excel e Parquet, as planilhas, as fórmulas, ordenar, filtrar, buscar, as estatísticas das colunas, o filtro SQL, consultas SQL sobre as linhas da tabela, JOIN entre planilhas do mesmo arquivo, a comparação com o Git e a exportação para CSV, TSV e JSON são gratuitos.

Quando os dados vêm em muitos arquivos, um por mês ou um por filial, Combine Files and Sheets junta vários CSV, TSV, Excel, ODS e Parquet, uma pasta inteira ou todas as planilhas de uma pasta de trabalho em um só arquivo CSV, XLSX ou Parquet. As colunas são casadas pelo nome do cabeçalho, e as colunas source_file e source_sheet dizem de onde veio cada linha. O Zovo Pro também roda consultas sobre o arquivo inteiro quando a tabela só tem as primeiras linhas (um GROUP BY em um CSV de vários GB), faz JOIN com outros arquivos e salva como Parquet.

Com Combine Files and Sheets (Zovo Pro)

  1. No Explorer, clique com o botão direito em uma pasta, em vários arquivos de tabela selecionados ou em uma pasta de trabalho e escolha Combine Files and Sheets. Também funciona pelo botão Combine na barra de ferramentas ou por "Excel Viewer Pro: Combine Files and Sheets (Pro)..." na Command Palette.
  2. Escolha o formato de saída (CSV, XLSX ou Parquet) e onde salvar.
  3. Arquivos que não podem ser lidos são pulados e listados no resumo. Os arquivos de origem não mudam.

Combine Files and Sheets funciona 3 vezes no seu computador antes de pedir uma licença, e uma tentativa só conta quando você recebe um resultado. Nada sobre o Pro aparece quando você abre um arquivo.

No Cursor, Windsurf ou VSCodium

Esses editores instalam extensões pelo Open VSX. Abra a visão Extensions (Ctrl+Shift+X, ou Cmd+Shift+X no macOS), procure zovo.table-viewer-vscode e clique em Install. Depois disso, tudo funciona como no VS Code.

O que ela não faz

  • A extensão só lê. Não edita nem salva a planilha.
  • Por padrão carrega até 1.000.000 de linhas por arquivo (setting tableViewer.maxRows).
  • Arquivos .xls, .xlsb e .ods acima de 50 MB não carregam.
  • Uma consulta sobre um CSV inteiro maior que a tabela, o JOIN com outros arquivos e salvar como Parquet são Zovo Pro, com 3 usos grátis cada.

Perguntas

Preciso do Excel ou do Python?

Não. A extensão é JavaScript que roda offline, sem kernel e sem conta.

O SQL é pago?

Não. Consultas sobre as linhas da tabela, o filtro SQL e o JOIN entre planilhas do mesmo arquivo são gratuitos. Ler um arquivo grande inteiro e o JOIN com outros arquivos são Zovo Pro, com 3 usos grátis.

A tabela atualiza quando o arquivo muda?

Sim. Quando um script ou um git pull grava o arquivo de novo, a tabela recarrega em cerca de meio segundo e mantém a ordenação e os filtros.
