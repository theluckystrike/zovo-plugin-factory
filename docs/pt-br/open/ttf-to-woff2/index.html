Converta TTF para WOFF2 no VS Code

Instale o Font Viewer (TTF, OTF and WOFF viewer). Ele abre fontes .ttf, .otf, .woff, .woff2, .ttc e .otc com um testador de texto, uma grade de glifos, um mapa de caracteres e uma aba Info com a licença, tudo de graça. A ferramenta Convert Font do Zovo Pro grava um WOFF2 (ou WOFF) ao lado de um TTF ou OTF, e também transforma um WOFF2 de volta em um TTF/OTF instalável. Convert Font e Font Folder Report têm 3 usos grátis cada, e depois o Zovo Pro custa 19 USD, pagos uma vez.

Passo a passo no VS Code

  1. Instale o Font Viewer pelo Marketplace, ou aperte Ctrl+P (Cmd+P no macOS) e rode ext install zovo.font-viewer-vscode.
  2. Clique em um arquivo .ttf ou .otf no Explorer. Ele abre no Font Viewer, que é somente leitura e nunca altera a fonte. Se abrir outro editor, clique com o botão direito no arquivo e escolha "Open in Font Viewer".
  3. Na aba Type tester, digite um texto de exemplo, arraste o controle de tamanho e mova os controles dos eixos variáveis. Ligue e desligue os recursos OpenType.
  4. Abra a aba Info para conferir a licença, o designer e os direitos de embedding antes de colocar a fonte em um site.
  5. Clique em Copy CSS no Type tester para pegar a regra @font-face, ou clique com o botão direito na fonte no Explorer e escolha "Copy CSS @font-face".
  6. Para gerar o arquivo WOFF2, rode o Convert Font (uma ferramenta do Zovo Pro, veja abaixo).

O que é grátis e o que o Zovo Pro acrescenta

São grátis abrir fontes TTF, OTF, WOFF, WOFF2, TTC e OTC, o Type tester com eixos variáveis e recursos OpenType, a grade de glifos, o mapa de caracteres, a aba Info com a licença e o Copy CSS @font-face.

O Convert Font transforma um TTF ou OTF em WOFF2 ou WOFF para usar em um site, ou um WOFF2 de volta em um TTF/OTF instalável. Ele aceita uma fonte ou uma pasta inteira, grava os arquivos novos ao lado dos originais e gera um arquivo por face no caso de um TTC. Os dados das tabelas são copiados como estão, então contornos, hinting, eixos variáveis e recursos não mudam.

Como usar Convert Font (Zovo Pro)

  1. Clique no botão Convert Font na barra de título da aba da fonte, ou clique com o botão direito em um arquivo de fonte ou em uma pasta no Explorer e escolha "Convert Font to WOFF2, WOFF or TTF… (Pro)".
  2. Pela Command Palette, rode "Font Viewer: Convert Font to WOFF2, WOFF or TTF… (Pro)" e escolha uma fonte ou uma pasta.
  3. Escolha WOFF2. O novo arquivo .woff2 é gravado ao lado do original, e o original continua como estava.
  4. Um uso só conta quando os arquivos são gravados.

Convert Font funciona 3 vezes no seu computador antes de pedir uma licença. Não há janela pop-up nem contagem regressiva.

Passo a passo no Cursor, Windsurf ou VSCodium

  1. Abra a visão Extensions com Ctrl+Shift+X (Cmd+Shift+X no macOS).
  2. Busque zovo.font-viewer-vscode e clique em Install. Cursor, Windsurf e VSCodium instalam extensões do Open VSX, onde esta se chama zovo/font-viewer-vscode.
  3. Se o seu editor não tiver galeria, baixe o arquivo .vsix na página do Open VSX e rode "Extensions: Install from VSIX...".
  4. Depois disso, tudo funciona como no VS Code.

O que o Font Viewer faz

  • TrueType .ttf, inclusive fontes variáveis, e OpenType .otf com contornos CFF.
  • Fontes WOFF .woff e WOFF2 .woff2.
  • Coleções .ttc e .otc, com a fonte escolhida em uma lista no cabeçalho.
  • Todos os glifos com nome e code point, busca por nome, caractere, U+20AC ou glyph id, e cópia do contorno como SVG.
  • Cobertura por bloco Unicode, a tabela name completa, métricas, eixos e as tags de recursos GSUB e GPOS.

O que ele não faz

  • Coleções WOFF2, fontes SVG, .dfont e fontes Type 1 não são suportadas.
  • Arquivos acima de 64 MB (configuração fontViewer.maxFileMB) mostram uma mensagem em vez de abrir.
  • Os contornos dos glifos mostram a instância padrão de uma fonte variável. O Type tester, a waterfall e o mapa de caracteres seguem os controles dos eixos.
  • Fontes coloridas aparecem em cores no Type tester e no mapa de caracteres, mas a grade de glifos mostra só os contornos. Fontes variáveis CFF2 são desenhadas com a própria fonte na grade de glifos, não a partir dos contornos.
  • O Convert Font copia os dados das tabelas como estão. Ferramentas que também reescrevem os dados dos glifos geram arquivos WOFF2 alguns por cento menores.

Perguntas frequentes

É grátis?

Ver fontes é grátis, com o Type tester, os glifos, o mapa de caracteres, a aba Info e o Copy CSS @font-face. Convert Font e Font Folder Report são ferramentas Pro com 3 usos grátis cada. Depois disso, o Zovo Pro custa 19 USD, pagos uma vez, para todas as extensões Zovo.

Quanto menor fica um WOFF2?

No teste do README, o WOFF2 ficou com cerca de 45 por cento do tamanho do TTF (JetBrains Mono variável, de 96.940 para 43.632 bytes).

A conversão altera a fonte?

Não. Os dados das tabelas são copiados como estão, então contornos, hinting, eixos variáveis e recursos continuam iguais. O arquivo original não é alterado.

Minhas fontes são enviadas para algum servidor?

Não. O Font Viewer funciona offline, não faz chamadas de rede e não envia telemetria.
