Editar arquivos .proto no VS Code com destaque de sintaxe, formatação e ir para a definição

Instale a extensão grátis Protobuf & Proto3 Formatter e abra uma pasta com arquivos .proto. Ela adiciona destaque de sintaxe, um formatador que mantém todos os comentários, ir para a definição, localizar referências e erros com a mesma redação do protoc, para proto2, proto3 e as editions 2023 e 2024. Ela funciona offline com o próprio parser, então não precisa de protoc, de servidor de linguagem nem de configuração, e tudo isso é grátis. O Zovo Pro (19 USD, pagos uma vez só) acrescenta três ferramentas, Check Breaking Changes Against Git, Generate API Docs e Decode a Binary Message, e cada uma tem 3 usos grátis.

Passo a passo no VS Code

  1. Instale o Protobuf & Proto3 Formatter pelo Marketplace, ou aperte Ctrl+P (Cmd+P no macOS) e rode ext install zovo.zovo-protobuf.
  2. Abra uma pasta com arquivos .proto. O destaque de sintaxe, a estrutura (outline) e a trilha de navegação (breadcrumbs) aparecem na hora.
  3. Pressione Shift+Alt+F (Shift+Option+F no macOS) para formatar, ou ative editor.formatOnSave. O resultado tem uma instrução por linha, a indentação do seu editor e um único espaço em volta de =. Comentários, grupos de linhas em branco e as suas quebras de linha em instruções longas ficam onde estavam.
  4. Pressione F12 em um tipo ou import para ir até a definição, e Shift+F12 para listar os usos. Ctrl+clique ou Cmd+clique em um import abre o arquivo. Passe o mouse sobre um tipo para ver os campos e o comentário dele.
  5. Os erros aparecem no painel Problems com a redação do protoc: números de campo duplicados (com o próximo número livre), tipos desconhecidos, tipos usados sem o import, números e nomes reservados e as regras de proto3 e das editions. Imports sem uso ficam esmaecidos.
  6. Se os seus imports começam em uma pasta como proto/ ou third_party/, eles são encontrados subindo a partir de cada arquivo. Para outras raízes, adicione-as à configuração zovoProto.importPaths, como você faria com protoc -I.

O que é grátis e o que o Zovo Pro acrescenta

O destaque de sintaxe (também em blocos de código proto no Markdown), Format Document, ir para a definição, localizar referências, os erros no estilo do protoc, a estrutura, Go to Symbol in workspace, o hover e o autocompletar, inclusive o próximo número de campo livre depois de =, são grátis. Não há login, nem requisição de rede, nem telemetria.

Antes de fazer merge de uma mudança em um arquivo .proto, o Check Breaking Changes Against Git compara os seus arquivos com a main (ou com a branch que você definiu) e lista campos removidos, números, tipos e labels alterados, campos e valores de enum renomeados e métodos removidos ou alterados. Cada resultado diz se quebra dados binários, JSON ou só o código gerado. Assim você vê o que os clientes antigos vão ler errado antes que isso aconteça. Você pode salvar os resultados em um arquivo JSON para a CI.

Como usar Check Breaking Changes Against Git (Zovo Pro)

  1. Clique com o botão direito em um arquivo .proto ou em uma pasta no Explorer e escolha "Zovo Pro: Check breaking changes against git", clique com o botão direito dentro de um editor .proto e escolha "Check Breaking Changes Against Git (Pro)", ou execute "Protobuf: Check Breaking Changes Against Git (Pro)" na Command Palette. A pasta precisa estar em um repositório git, e o git precisa estar instalado.
  2. A verificação compara todos os arquivos .proto do repositório na sua árvore de trabalho, incluindo edições não salvas, com a merge base de origin/main, main, origin/master ou master (a primeira que existir), ou da branch definida na configuração zovoProto.baseBranch. Um relatório em Markdown abre com os resultados agrupados por arquivo.
  3. Clique em "Save JSON for CI" na mensagem para guardar os resultados em proto-breaking.json.
  4. Um uso só conta quando o relatório abriu. Uma pasta fora do git ou a falta de uma branch base não gasta nenhum.

Check Breaking Changes Against Git funciona 3 vezes no seu computador antes de pedir uma licença. Não há janela pop-up nem contagem regressiva.

Passo a passo no Cursor, Windsurf ou VSCodium

  1. Abra a visão Extensions com Ctrl+Shift+X (Cmd+Shift+X no macOS).
  2. Busque zovo.zovo-protobuf e clique em Install. Cursor, Windsurf e VSCodium instalam extensões do Open VSX, onde esta se chama zovo/zovo-protobuf.
  3. Se o seu editor não tiver galeria, baixe o arquivo .vsix na página do Open VSX e rode "Extensions: Install from VSIX...".
  4. Depois disso, tudo funciona como no VS Code.

O que o Protobuf & Proto3 Formatter faz

  • proto2, proto3 e editions (2023, 2024), além de blocos de código proto no Markdown.
  • As regras de escopo do protobuf para ir para a definição e localizar referências entre imports: tipos aninhados, pacotes e um . inicial.
  • Nomes embutidos dos well-known types, como google/protobuf/timestamp.proto.
  • Sem marcas vermelhas falsas: quando um import não está no seu workspace, a linha do import avisa e os tipos que ele traria não são adivinhados.
  • Autocompletar de tipos, palavras-chave, opções, caminhos de import e do próximo número de campo livre depois de =.

O que ele não faz

  • Nomes de opções personalizadas são verificados quanto ao import, mas não em relação ao tipo de campo da extensão.
  • As verificações de features das editions cobrem enum_type, labels, packed e groups. As outras regras de features ficam para o protoc.
  • O formatador mantém as suas quebras de linha dentro de instruções longas. Ele não quebra linhas longas e não alinha os = em colunas.
  • A formatação precisa de um arquivo que passe no parser. Corrija antes o erro mostrado no painel Problems.
  • Imports entre arquivos precisam de pastas no disco. Em um workspace virtual, só o destaque de sintaxe, a formatação e a estrutura funcionam.

Perguntas frequentes

É grátis?

O destaque de sintaxe, a formatação, ir para a definição, localizar referências, os erros no estilo do protoc, o hover e o autocompletar são grátis. As três ferramentas Pro, Check Breaking Changes Against Git, Generate API Docs e Decode a Binary Message, têm 3 usos grátis cada. Depois disso, elas precisam do Zovo Pro, 19 USD uma vez só para todas as extensões Zovo.

Preciso instalar o protoc?

Não. A extensão tem o próprio parser e funciona offline. Os erros usam a mesma redação do protoc.

Por que um import mostra um aviso em vez de marcas vermelhas?

O arquivo importado não está no seu workspace. Adicione a pasta raiz dele a zovoProto.importPaths, como no protoc -I.

Funciona no Cursor?

Sim. Cursor, Windsurf e VSCodium instalam a extensão pelo Open VSX, onde ela está publicada como zovo/zovo-protobuf.
