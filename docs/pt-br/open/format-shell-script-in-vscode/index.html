Como formatar um script bash ou zsh no VS Code

Instale a extensão grátis Shell Formatter for Bash & Zsh, abra um script shell e pressione Shift+Alt+F (Shift+Option+F no Mac). O motor do shfmt 3.14.1 vem dentro da extensão em WebAssembly, então não há nada para baixar, e a saída é igual à do shfmt de linha de comando, byte a byte. Format Document, Format Selection, a formatação ao salvar, as chaves do .editorconfig e os erros de sintaxe em Problems são grátis e funcionam offline. O Zovo Pro (19 USD, pagos uma vez só) acrescenta três ferramentas, Format All Shell Scripts in a Folder, Formatting Check with a Patch File e Minify a Script to a Copy, e cada uma tem 3 usos grátis.

Passo a passo no VS Code

  1. Instale o Shell Formatter for Bash & Zsh pelo Marketplace, ou aperte Ctrl+P (Cmd+P no macOS) e rode ext install zovo.zovo-shell-formatter.
  2. Abra um script shell e pressione Shift+Alt+F (Shift+Option+F no Mac). Se o VS Code perguntar qual formatador usar, escolha Shell Formatter, ou rode "Shell Formatter: Use as Default Formatter for Shell Scripts".
  3. Para formatar sempre que salvar, rode "Shell Formatter: Turn On Format on Save for Shell Scripts".
  4. O dialeto vem da primeira linha (#!/bin/bash, #!/bin/sh, #!/usr/bin/env zsh), depois do nome do arquivo (.bash, .zsh, .zshrc, .bats, .ksh) e, se nada disso servir, é bash. Para escolher você mesmo, defina shellFormatter.dialect ou shell_variant no .editorconfig.
  5. Clique em shfmt 3.14.1 na barra de status para abrir o menu com formatar, definir como padrão, formatar ao salvar, "Copy the matching shfmt command (for CI)" e as configurações.
  6. Se o script não for shell válido, ele fica sem alteração e o painel Problems mostra a linha e a coluna.

O que é grátis e o que o Zovo Pro acrescenta

Format Document, Format Selection, a formatação ao salvar, a detecção do dialeto, as chaves do .editorconfig, o menu da barra de status, o Copy the Matching shfmt Command (for CI) e os erros de sintaxe em Problems são grátis. Não há login, requisição de rede nem telemetria.

Format All Shell Scripts in a Folder verifica cada script de uma pasta e das subpastas, encontrado pelo nome ou por uma linha #! que cita um shell, e diz quantos mudariam. Depois formata todos ou gera um relatório Markdown, com o mesmo motor, as mesmas configurações e o mesmo .editorconfig do Format Document. Um repositório com dezenas de scripts em estilos diferentes fica com um estilo só em uma execução, e os scripts que não rodariam os mesmos comandos ficam como estão.

Como usar Format All Shell Scripts in a Folder (Zovo Pro)

  1. Clique com o botão direito em uma pasta no Explorer e escolha "Zovo Pro: Format All Shell Scripts in a Folder", ou rode "Shell Formatter: Format All Shell Scripts in a Folder (Pro)" pela Command Palette ou pelo menu da barra de status e escolha a pasta.
  2. O título da lista seguinte mostra quantos scripts mudariam, como "N of M scripts would change".
  3. Escolha "Format N scripts" para formatar e salvar cada arquivo (o Undo funciona arquivo por arquivo), ou "Show the report only" para uma lista Markdown de todos os scripts sem alterar nada.
  4. Um uso só conta quando você recebe um resultado. Uma pasta sem scripts shell, ou com todos os scripts já formatados, não gasta nenhum.

Passo a passo no Cursor, Windsurf ou VSCodium

  1. Abra a visão Extensions com Ctrl+Shift+X (Cmd+Shift+X no macOS).
  2. Busque zovo.zovo-shell-formatter e clique em Install. Cursor, Windsurf e VSCodium instalam extensões do Open VSX, onde esta se chama zovo/zovo-shell-formatter.
  3. Se o seu editor não tiver galeria, baixe o arquivo .vsix na página do Open VSX e rode "Extensions: Install from VSIX...".
  4. Depois disso, tudo funciona como no VS Code.

O que o Shell Formatter for Bash & Zsh faz

  • Scripts bash, POSIX sh (também dash e ash), mksh (também ksh), bats e zsh.
  • A mesma saída do shfmt 3.14.1 na linha de comando. Em 178 scripts reais de projetos do GitHub e do Homebrew, 354 de 354 execuções bateram byte a byte.
  • Antes de uma mudança ser aplicada, o script formatado é analisado de novo e precisa rodar os mesmos comandos do original (arquivos de até 256 KB).
  • Opções do shfmt como configurações ou chaves do .editorconfig: indentação, operadores binários na linha seguinte, indentação dos case do switch, espaço nos redirecionamentos, manter o alinhamento, chaves de função na linha seguinte, simplificar e minificar.
  • Finais de linha do Windows (CRLF) continuam CRLF, e um script de 2 MB é formatado em cerca de 0,2 segundo.

O que ele não faz

  • A extensão nunca mexe em Dockerfiles, arquivos .env, scripts fish ou csh.
  • O suporte a zsh no shfmt é recente. Um script zsh que o shfmt não consegue analisar fica sem alteração.
  • Arquivos acima de 10 MB (configuração shellFormatter.maxFileMB) e arquivos com bytes binários, como instaladores autoextraíveis, não são formatados.
  • O shfmt roda com um limite de tempo (10 segundos por padrão, configuração shellFormatter.timeoutSeconds). Se o limite for atingido, o arquivo fica sem alteração.

Perguntas frequentes

É grátis?

Format Document, Format Selection, a formatação ao salvar e o suporte ao .editorconfig são grátis. As três ferramentas Pro, Format All Shell Scripts in a Folder, Formatting Check with a Patch File e Minify a Script to a Copy, têm 3 usos grátis cada. Depois disso, elas precisam do Zovo Pro, 19 USD uma vez só para todas as extensões Zovo.

Preciso instalar o shfmt?

Não. O shfmt 3.14.1 vem dentro da extensão em WebAssembly, então funciona offline sem nada para baixar.

A formatação pode quebrar meu script?

Um script com erro de sintaxe fica sem alteração. Antes de uma mudança ser aplicada, o script formatado é analisado de novo e precisa rodar os mesmos comandos do original.

Funciona no Cursor?

Sim. Cursor, Windsurf e VSCodium instalam a extensão pelo Open VSX, onde ela está publicada como zovo/zovo-shell-formatter.
