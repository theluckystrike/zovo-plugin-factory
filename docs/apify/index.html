Why these exist

Most of this data is public in a browser and awkward everywhere else. Google Trends rate-limits per IP, the Ad Transparency Center has no export, app store reviews come in two formats with different pagination, and YouTube transcripts live behind a panel that only handles one video. Each Actor does one of those jobs, keeps the schema flat, and charges only when a row is saved.

How to call them

Every Actor takes a JSON input and returns dataset items. You can run one from the Apify console, from curl, or with the Apify client for Python and Node. They also show up as MCP tools if you add the Apify MCP server to your client.

Prices are per saved result. They are $0.0015 per ad row, $0.0001 per review, $0.002 per Google Trends term, $0.001 per screenshot or PDF, $0.0025 per YouTube transcript, $0.002 per Google News article, $0.001 per web page, $0.001 per TikTok transcript, $0.002 per Medium or Substack article, $0.004 per job and $0.005 per website with contacts. Failed results are free.
