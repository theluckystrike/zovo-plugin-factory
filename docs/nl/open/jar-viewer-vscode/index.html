Handleidingen in het Nederlands

Een JAR openen en de gedecompileerde Java-broncode lezen in VS Code

Installeer de gratis JAR Viewer & Java Decompiler en klik op een .jar-, .war-, .ear-, .aar- of .class-bestand. Je ziet de packages, resources, MANIFEST.MF en de Java-versie van elke class, een bytecodelijst in de stijl van javap -c -p die geen Java nodig heeft, en Java-broncode die de meegeleverde CFR 0.152 decompileert met de Java-runtime (8 of nieuwer) op je computer. Elke weergave en het decompileren van één class tegelijk zijn gratis. Zovo Pro (eenmalig USD 19) voegt drie tools toe: Export decompiled sources of a JAR, Compare two JARs en Find in every JAR of a folder. Elke tool kun je 3 keer gratis proberen.

Stappen in VS Code

  1. Installeer JAR Viewer via de Marketplace, of druk op Ctrl+P (Cmd+P op macOS) en voer ext install zovo.zovo-jar-viewer uit.
  2. Klik in de Explorer op een .jar-, .war-, .ear-, .aar- of .class-bestand. Het opent in JAR Viewer. Overview toont het formaat, het aantal entries, classes en packages, Main-Class, Created by, de MANIFEST.MF en een grafiek van de Java-versies waarvoor de classes gecompileerd zijn.
  3. Typ een deel van een naam in het filtervak boven de packageboom. Classes en bestanden worden gevonden terwijl je typt. Inner classes staan gedimd onder hun buitenste class.
  4. Klik op een class. Het tabblad Java source toont die gedecompileerd met CFR 0.152, met de inner classes erbij. Copy zet de broncode op het klembord en Open in editor opent hem in een gewoon editortabblad.
  5. Meldt het tabblad Java source dat gedecompileerde Java-broncode een Java-runtime nodig heeft, stel dan jarViewer.javaPath in op een java-binary of een JDK-map, of stel JAVA_HOME in. "JAR Viewer: Check the Java runtime used for decompiling" laat zien welke Java gebruikt wordt.
  6. Open het tabblad Bytecode voor een lijst in de stijl van javap -c -p met elke opcode, de exception tables en de regelnummers. Members, Constant pool en Class info tonen de declaraties, de entries van de constant pool en de class-attributen.
  7. Klik in een Spring Boot-JAR, een WAR of een AAR op een JAR in BOOT-INF/lib of WEB-INF/lib, of op de classes.jar van de AAR, en klik dan op "Open nested archive". Het archief opent één niveau diep, en de knop met de naam van het buitenste bestand bovenaan brengt je terug.

Wat gratis is en wat Zovo Pro toevoegt

De packageboom, Overview, het manifest, resources, gedecompileerde Java-broncode, bytecode, members, constant pool, class info en geneste JAR's zijn gratis, zonder inloggen. CFR zit in de extensie en draait op de Java die al op je computer staat. De extensie verandert het archief nooit en doet geen netwerkverzoeken.

Export decompiled sources of a JAR decompileert elke class van een JAR, WAR, EAR of AAR met CFR en schrijft de .java-bestanden naar een map, met voortgang en een knop Cancel. Zonder Java-runtime schrijft de tool in plaats daarvan de bytecodelijsten. Je krijgt de hele library als bronbestanden om te doorzoeken of te lezen in je editor, in plaats van één class tegelijk te openen.

Export decompiled sources of a JAR gebruiken (Zovo Pro)

  1. Open het archief en klik bovenaan de viewer op "Export sources…", of op "Export decompiled sources" in de kleine rij Pro tools. Je kunt ook in de Explorer met rechts op het bestand klikken en "Zovo Pro: Export decompiled sources" kiezen.
  2. Of voer "JAR Viewer: Export decompiled sources of a JAR (Pro)" uit vanuit het Command Palette. Is er geen archief open, dan vraagt de tool je een JAR-, WAR-, EAR- of AAR-bestand te kiezen.
  3. Kies een map en klik op "Export here". De broncode komt in een nieuwe map met de naam van het archief en -src aan het eind.
  4. Een melding toont de voortgang. Cancel stopt de export en kost geen poging. Als het klaar is, meldt de viewer hoeveel bestanden er geschreven zijn en waar.

Export decompiled sources of a JAR werkt 3 keer gratis op je computer voordat om een licentie wordt gevraagd. Er is geen pop-up en geen aftelling.

Stappen in Cursor, Windsurf of VSCodium

  1. Open de Extensions-weergave met Ctrl+Shift+X (Cmd+Shift+X op macOS).
  2. Zoek zovo.zovo-jar-viewer en klik op Install. Cursor, Windsurf en VSCodium installeren extensies van Open VSX, waar deze extensie zovo/zovo-jar-viewer heet.
  3. Heeft je editor geen galerie, download dan het .vsix-bestand van de pagina op Open VSX en voer "Extensions: Install from VSIX..." uit.
  4. Daarna werkt alles zoals in VS Code.

Wat JAR Viewer doet

  • JAR-, WAR-, EAR- en AAR-archieven, en losse .class-bestanden met hun inner classes uit dezelfde map.
  • Archieven tot 200.000 entries, en een filter dat een class of bestand tussen 50.000 entries vindt terwijl je typt.
  • Generic signatures, records, permitted subclasses, nest hosts en annotaties in de classdata.
  • Tekstresources zoals properties-, XML-, JSON-, SQL- en services-bestanden als tekst, en een hex-voorbeeld voor binaire bestanden.
  • Spring Boot BOOT-INF/lib, WAR WEB-INF/lib en AAR classes.jar, één niveau diep.

Wat het niet doet

  • Gedecompileerde broncode heeft Java 8 of nieuwer op je computer nodig. Zonder Java werken de bytecode en alle andere weergaven gewoon.
  • De uitvoer van CFR kan afwijken van de originele broncode, bijvoorbeeld in de namen van lokale variabelen, sommige generics en lambda's.
  • Entries worden uitgepakt tot 64 MB per stuk, class-bestanden tot 16 MB en geneste archieven tot 128 MB. Bestanden op een extern of virtueel bestandssysteem worden tot 256 MB gelezen.
  • De extensie is alleen-lezen, dus je kunt een class niet bewerken of opnieuw compileren. Geneste archieven openen maar één niveau diep.
  • APK- en DEX-bestanden worden niet gelezen.

Veelgestelde vragen

Is het gratis?

Ja. Elke weergave en het decompileren van één class tegelijk zijn gratis. De drie Pro-tools, Export decompiled sources of a JAR, Compare two JARs en Find in every JAR of a folder, kun je elk 3 keer gratis gebruiken, en een poging telt alleen als de tool een resultaat geeft. Daarna heb je Zovo Pro nodig, eenmalig USD 19 voor alle Zovo-extensies.

Waarom vraagt het tabblad Java source om Java?

CFR is een Java-programma. De viewer zoekt Java in jarViewer.javaPath, dan in JAVA_HOME en dan java op je PATH. Elke Java-runtime vanaf versie 8 werkt.

Kan ik de bytecode lezen zonder Java?

Ja. De tabbladen Bytecode, Members, Constant pool en Class info worden in JavaScript gelezen en hebben geen Java nodig.

Werkt het in Cursor?

Ja. De extensie staat op Open VSX als zovo/zovo-jar-viewer, dus Cursor, Windsurf en VSCodium kunnen haar installeren.
