XML formatteren in VS Code en er XPath op uitvoeren

Installeer de gratis XML Formatter & XPath Tools, open een XML-bestand en druk op Shift+Alt+F (Shift+Option+F op een Mac). Alleen de witruimte tussen tags verandert. Tekst, CDATA, commentaar, xml:space="preserve" en attribuutwaarden blijven byte voor byte gelijk, en een bestand dat niet well-formed is, wordt nooit gewijzigd. Formatteren, Minify XML, XPath 1.0 met de namespaceprefixen van het bestand zelf, Copy XPath en de weergave XML Tree zijn gratis en werken offline. Zovo Pro (eenmalig 19 USD) voegt drie tools toe, Run XPath on Every XML File in a Folder, Format All XML Files in a Folder en Compare Two XML Files Ignoring Formatting, en elke tool heeft 3 gratis pogingen.

Stappen in VS Code

  1. Installeer XML Formatter & XPath Tools via de Marketplace, of druk op Ctrl+P (Cmd+P op macOS) en voer ext install zovo.zovo-xml-xpath-tools uit.
  2. Open een .xml-bestand en druk op Shift+Alt+F (Shift+Option+F op een Mac), of voer Format Document uit. Heb je meer dan één XML-formatter, dan vraagt VS Code welke je wilt gebruiken. Format Selection werkt ook.
  3. De formatter gebruikt je tabgrootte en je keuze voor tabs of spaties, en behoudt de regeleinden, de byte order mark en de laatste regelovergang. Is het bestand niet well-formed, dan verandert er niets en krijg je de fout met regel en kolom.
  4. Wil je het bestand juist klein maken, voer dan "XML: Minify XML" uit op het hele bestand of een selectie. Commentaar blijft staan, tenzij je xmlXpathTools.minify.removeComments aanzet.
  5. Wil je een XPath uitvoeren, klik dan op de zoekknop in de titel van de editor of voer "XML: Evaluate XPath…" uit. De resultaten staan in XPath Results met hun regel. Klik op een resultaat om het in de editor te selecteren.
  6. Klik op het XPath in de statusbalk om het pad van het element onder de cursor te kopiëren, met posities, met id- of name-attributen, of in een draagbare vorm met local-name().
  7. Is een bestand groter dan 50 MB, klik er dan met rechts op in de Explorer en kies "Format Large XML File on Disk…". Dat schrijft name.formatted.xml ernaast, of vervangt het bestand nadat je hebt bevestigd.

Wat gratis is en wat Zovo Pro toevoegt

Format Document, Format Selection, Minify XML, XPath 1.0, Copy XPath, de weergave XML Tree, de well-formedness-fouten in Problems en Format Large XML File on Disk zijn gratis. Je hoeft je niet aan te melden, en de extensie bevat geen netwerkcode.

Run XPath on Every XML File in a Folder voert één XPath uit op elk .xml-, .xsd-, .csproj-, .svg-, .kml- en vergelijkbaar bestand in een map en de submappen, elk met zijn eigen namespaceprefixen. De resultaten openen als CSV (file, line, kind, name, value) voor een spreadsheet, als JSON voor een script of als Markdown-rapport voor een review. Zo haal je dezelfde waarde uit veel bestanden, zoals elke artifactId uit een reeks pom.xml-bestanden, zonder ze een voor een te openen.

Run XPath on Every XML File in a Folder gebruiken (Zovo Pro)

  1. Klik in de Explorer met de rechtermuisknop op een map en kies "Zovo Pro: Run XPath on Every XML File in a Folder", of voer "XML: Run XPath on Every XML File in a Folder (Pro)" uit vanuit het Command Palette en kies de map.
  2. Of klik, nadat je een XPath in één bestand hebt uitgevoerd, op de laatste regel van XPath Results, "Run this XPath on every XML file in a folder", om dezelfde expressie op een map uit te voeren.
  3. Typ het XPath. Een melding toont de voortgang met een knop Cancel.
  4. Kies "Open as CSV", "Open as JSON" of "Open a Markdown report". De resultaten openen in een nieuw editortabblad. Een poging telt pas als je een resultaat krijgt. Escape, een typfout in het XPath of een map zonder XML-bestanden kost geen poging.

Run XPath on Every XML File in a Folder werkt 3 keer gratis op je computer voordat om een licentie wordt gevraagd. Er is geen pop-up en geen aftelling.

Stappen in Cursor, Windsurf of VSCodium

  1. Open de Extensions-weergave met Ctrl+Shift+X (Cmd+Shift+X op macOS).
  2. Zoek zovo.zovo-xml-xpath-tools en klik op Install. Cursor, Windsurf en VSCodium installeren extensies van Open VSX, waar deze extensie zovo/zovo-xml-xpath-tools heet.
  3. Heeft je editor geen galerie, download dan het .vsix-bestand van de pagina op Open VSX en voer "Extensions: Install from VSIX..." uit.
  4. Daarna werkt alles zoals in VS Code.

Wat XML Formatter & XPath Tools doet

  • Bestanden die VS Code als XML opent. De extensie opent ook .kml-, .gpx-, .rss-, .atom-, .wsdl-, .dbk-, .xlf-, .xliff-, .resx-, .nuspec-, .props-, .targets- en .xaml-bestanden als XML.
  • Grote bestanden, want formatteren, de boom en XPath draaien in een achtergrondthread. In de tests van de extensie werd een bestand van 49 MB met ongeveer 1 miljoen elementen in 1,6 seconden geformatteerd.
  • Gewone namen matchen ook een standaardnamespace, dus //dependency/artifactId werkt in een pom.xml. Zet xmlXpathTools.xpath.strictNamespaces aan voor strikt XPath 1.0.
  • Indeling van attributen zoals geschreven, op één regel of één attribuut per regel (instelling xmlXpathTools.format.attributes).
  • De weergave XML Tree in de Explorer volgt de cursor, en Problems toont well-formedness-fouten met regel en kolom.

Wat het niet doet

  • Alleen XPath 1.0. Er is geen XPath 2.0 of 3.1, XQuery of XSLT.
  • Het controleert of een bestand well-formed is. Het valideert niet tegen een XSD of DTD.
  • Bestanden boven 50 MB kun je op schijf formatteren, maar VS Code geeft ze niet aan extensies door, dus de boom en XPath werken er niet op.
  • De opdracht voor bestanden op schijf leest UTF-8, UTF-16 met een byte order mark en ISO-8859-1.
  • Een element met tekst erin, zoals <p>Some <b>bold</b> text</p>, blijft op zijn regel zoals het geschreven is. Alleen elementen met tags en zonder tekst krijgen nieuwe regeleinden.

Veelgestelde vragen

Is het gratis?

Formatteren, Minify XML, XPath, Copy XPath, de weergave XML Tree en de controles op well-formedness zijn gratis. De drie Pro-tools, Run XPath on Every XML File in a Folder, Format All XML Files in a Folder en Compare Two XML Files Ignoring Formatting, hebben elk 3 gratis pogingen. Daarna is Zovo Pro nodig, eenmalig 19 USD voor alle Zovo-extensies.

Verandert formatteren mijn tekst of CDATA?

Nee. Alleen de witruimte tussen tags verandert, in elementen met tags en zonder tekst. Tekst, CDATA, commentaar en inhoud binnen xml:space="preserve" worden ongewijzigd overgenomen, en een tweede keer formatteren verandert niets.

Waarom selecteert mijn XPath niets in een pom.xml?

Het bestand heeft een standaardnamespace. In deze extensie matchen gewone namen ook een standaardnamespace, dus //dependency werkt. Zet xmlXpathTools.xpath.strictNamespaces aan voor strikt XPath 1.0.

Werkt het in Cursor?

Ja. Cursor, Windsurf en VSCodium installeren het vanuit Open VSX, waar het is gepubliceerd als zovo/zovo-xml-xpath-tools.
