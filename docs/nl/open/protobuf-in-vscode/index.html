Handleidingen in het Nederlands

.proto-bestanden bewerken in VS Code met kleuring, formatteren en ga naar definitie

Installeer de gratis Protobuf & Proto3 Formatter en open een map met .proto-bestanden. Je krijgt syntaxkleuring, een formatter die elk commentaar behoudt, ga naar definitie, verwijzingen zoeken en fouten in de bewoording van protoc, voor proto2, proto3 en editions 2023 en 2024. Het werkt offline met een eigen parser, dus zonder protoc, zonder language server en zonder setup, en dat is allemaal gratis. Zovo Pro (eenmalig 19 USD) voegt drie tools toe, Check Breaking Changes Against Git, Generate API Docs en Decode a Binary Message, en elke tool heeft 3 gratis pogingen.

Stappen in VS Code

  1. Installeer Protobuf & Proto3 Formatter via de Marketplace, of druk op Ctrl+P (Cmd+P op macOS) en voer ext install zovo.zovo-protobuf uit.
  2. Open een map met .proto-bestanden. Kleuring, de outline en breadcrumbs werken meteen.
  3. Druk op Shift+Alt+F (Shift+Option+F op macOS) om te formatteren, of zet editor.formatOnSave aan. Je krijgt één statement per regel, de inspringing van je editor en enkele spaties rond =. Commentaar, groepen lege regels en je eigen regeleinden in lange statements blijven waar ze stonden.
  4. Druk op F12 op een type of een import om naar de definitie te gaan, en op Shift+F12 om de plekken te zien waar het gebruikt wordt. Ctrl- of Cmd-klik op een import opent het bestand. Houd de muis op een type om de velden en het commentaar te zien.
  5. Fouten verschijnen in het paneel Problems in de bewoording van protoc: dubbele veldnummers (met het volgende vrije nummer), onbekende types, types die zonder hun import worden gebruikt, gereserveerde nummers en namen, en de regels van proto3 en editions. Ongebruikte imports worden vaag weergegeven.
  6. Beginnen je imports bij een map zoals proto/ of third_party/, dan worden ze gevonden door vanaf elk bestand omhoog te zoeken. Andere roots voeg je toe aan de instelling zovoProto.importPaths, zoals je met protoc -I zou doen.

Wat gratis is en wat Zovo Pro toevoegt

Kleuring (ook voor proto-codeblokken in Markdown), Format Document, ga naar definitie, verwijzingen zoeken, fouten zoals protoc, de outline, Go to Symbol in workspace, hovers en aanvulling, inclusief het volgende vrije veldnummer na =, zijn gratis. Er is geen aanmelding, geen netwerkverzoek en geen telemetrie.

Voordat je een wijziging in een .proto-bestand merget, vergelijkt Check Breaking Changes Against Git je bestanden met main (of de branch die je instelt) en toont verwijderde velden, gewijzigde nummers, types en labels, hernoemde velden en enumwaarden, en verwijderde of gewijzigde methoden. Bij elke bevinding staat of die binaire data, JSON of alleen gegenereerde code breekt, zodat je ziet wat oude clients verkeerd gaan lezen voordat het gebeurt. Je kunt de bevindingen opslaan als JSON-bestand voor CI.

Check Breaking Changes Against Git gebruiken (Zovo Pro)

  1. Klik in de Explorer met de rechtermuisknop op een .proto-bestand of een map en kies "Zovo Pro: Check breaking changes against git", klik met rechts in een .proto-editor en kies "Check Breaking Changes Against Git (Pro)", of voer "Protobuf: Check Breaking Changes Against Git (Pro)" uit vanuit het Command Palette. De map moet in een git-repository staan, en git moet geïnstalleerd zijn.
  2. De controle vergelijkt elk .proto-bestand van de repository in je working tree, inclusief niet-opgeslagen wijzigingen, met de merge base van origin/main, main, origin/master of master (de eerste die bestaat), of van de branch in de instelling zovoProto.baseBranch. Er opent een Markdown-rapport met de bevindingen per bestand.
  3. Klik in de melding op "Save JSON for CI" om de bevindingen te bewaren als proto-breaking.json.
  4. Een poging telt pas als het rapport is geopend. Een map buiten git of een ontbrekende basisbranch kost geen poging.

Check Breaking Changes Against Git werkt 3 keer gratis op je computer voordat om een licentie wordt gevraagd. Er is geen pop-up en geen aftelling.

Stappen in Cursor, Windsurf of VSCodium

  1. Open de Extensions-weergave met Ctrl+Shift+X (Cmd+Shift+X op macOS).
  2. Zoek zovo.zovo-protobuf en klik op Install. Cursor, Windsurf en VSCodium installeren extensies van Open VSX, waar deze extensie zovo/zovo-protobuf heet.
  3. Heeft je editor geen galerie, download dan het .vsix-bestand van de pagina op Open VSX en voer "Extensions: Install from VSIX..." uit.
  4. Daarna werkt alles zoals in VS Code.

Wat Protobuf & Proto3 Formatter doet

  • proto2, proto3 en editions (2023, 2024), en proto-codeblokken in Markdown.
  • De scopingregels van protobuf voor ga naar definitie en verwijzingen zoeken over imports heen: geneste types, packages en een . aan het begin.
  • Ingebouwde namen voor de well-known types, zoals google/protobuf/timestamp.proto.
  • Geen onterechte rode markeringen. Als een import niet in je workspace staat, meldt de importregel dat en wordt er niet gegokt naar de types die hij zou opleveren.
  • Aanvulling voor types, trefwoorden, opties, importpaden en het volgende vrije veldnummer na =.

Wat het niet doet

  • Namen van eigen opties worden gecontroleerd op hun import, maar niet op het veldtype van de extensie.
  • De controles op features van editions gaan over enum_type, labels, packed en groups. Andere featureregels worden aan protoc overgelaten.
  • De formatter houdt je regeleinden binnen lange statements. Hij breekt lange regels niet af en lijnt = niet uit in kolommen.
  • Formatteren werkt alleen met een bestand dat te parsen is. Los eerst de fout in het paneel Problems op.
  • Imports tussen bestanden hebben mappen op schijf nodig. In een virtuele workspace werken alleen kleuring, formatteren en de outline.

Veelgestelde vragen

Is het gratis?

Kleuring, formatteren, ga naar definitie, verwijzingen zoeken, de fouten zoals protoc, hovers en aanvulling zijn gratis. De drie Pro-tools, Check Breaking Changes Against Git, Generate API Docs en Decode a Binary Message, hebben elk 3 gratis pogingen. Daarna is Zovo Pro nodig, eenmalig 19 USD voor alle Zovo-extensies.

Moet protoc geïnstalleerd zijn?

Nee. De extensie heeft een eigen parser en werkt offline. De fouten gebruiken dezelfde bewoording als protoc.

Waarom toont een import een opmerking in plaats van rode markeringen?

Het geïmporteerde bestand staat niet in je workspace. Voeg de rootmap toe aan zovoProto.importPaths, zoals bij protoc -I.

Werkt het in Cursor?

Ja. Cursor, Windsurf en VSCodium installeren het vanuit Open VSX, waar het is gepubliceerd als zovo/zovo-protobuf.
