Handleidingen in het Nederlands

VS Code en de editors die erop gebaseerd zijn (Cursor, Windsurf, VSCodium) openen tekst, afbeeldingen en een deel van de media. Voor veel andere formaten heb je een extensie nodig. Elke handleiding geeft de stappen en zegt wat gratis is.

  • NumPy-bestanden (.npy en .npz) bekijken in VS Code. Open NumPy-arrays in .npy en .npz in VS Code met de gratis Tensor Viewer: dtype, shape, statistieken, heatmaps, afbeeldingen en waarden, zonder Python.
  • Een gratis NetCDF-viewer in VS Code. Open NetCDF-bestanden (.nc) in VS Code op Windows, macOS of Linux: header, variabelen, kaarten met kustlijnen en tijdreeksen. Ook HDF5 en MATLAB 7.3.
  • Een SQLite-database openen in VS Code. Open een .db- of .sqlite-bestand in VS Code met de gratis SQLite Viewer & Editor: tabellen, schema en SQL. Bewerk cellen en rijen en sla op met een backup.
  • Mermaid-diagrammen bekijken in VS Code. Bekijk Mermaid-diagrammen uit .mmd-bestanden en Markdown-blokken in VS Code met de gratis Mermaid Viewer. Live preview, PNG- en SVG-export, offline.
  • MOV-, MKV-, WebM- en MP4-video's met geluid afspelen in VS Code. Speel MP4, MOV en M4V met AAC-geluid af in VS Code zonder extra installatie. MKV, WebM en AVI spelen ook, met je eigen ffmpeg. Gratis player met ondertitels.
  • STL-bestanden bekijken in VS Code. Open STL in VS Code met de gratis 3D Model Viewer: draaien, afstand tussen twee punten meten, wireframe en modelgegevens. Ook OBJ, PLY, 3MF, GLB en glTF.
  • Een PCAP-bestand openen in VS Code. Lees .pcap-, .pcapng- en .pcap.gz-captures in VS Code met de gratis PCAP Viewer: pakketlijst, protocolboom, hex-weergave en filters. Geen Wireshark nodig.
  • HTML-, JSX- en Vue-tags automatisch hernoemen in VS Code. Hernoem een HTML-, JSX- of Vue-tag en de bijbehorende tag verandert mee terwijl je typt. Gratis extensie met linked editing, auto close en één undo.
  • Je Claude Code-geschiedenis lezen en hervatten in VS Code. Lees, doorzoek en hervat oude Claude Code- en Codex-sessies in VS Code. Subagents ingesprongen, edits als diff, tokentotalen. Alleen-lezen en offline.
  • TIFF naar PNG omzetten zonder kwaliteitsverlies. Open TIFF-, BigTIFF- en GeoTIFF-bestanden gratis in VS Code en sla één of alle pagina's op als PNG, met exacte 8- en 16-bit-waarden. Offline.
  • XMind naar PDF zonder XMind: alle sheets in één PDF. Open een .xmind-mindmap in VS Code zonder XMind en sla alle sheets op in één PDF, één pagina per sheet. Bekijken is gratis, de PDF is een Zovo Pro-tool.
  • Een lettertypebestand bekijken in VS Code. Open .ttf-, .otf-, .woff-, .woff2- en .ttc-lettertypen in VS Code met de gratis Font Viewer: tekst testen, alle glyphs en de licentie, zonder installeren.
  • Audiobestanden afspelen in VS Code. Speel WAV-, MP3-, FLAC-, Ogg- en Opus-bestanden af in VS Code met de gratis Audio Player: waveform, spectrogram, A-B-loop, snelheid en luidheid in LUFS.
  • Een DXF-tekening openen in VS Code. Bekijk .dxf-tekeningen in VS Code met de gratis DXF Viewer: ASCII- en binaire DXF, lagen, paper space-sheets, tekst zoeken, meten en export naar PNG of SVG.
  • Een bestand in een ZIP openen zonder het uit te pakken. Blader door een ZIP, JAR, TAR of TAR.GZ in VS Code en open één bestand eruit in een alleen-lezen tabblad, zonder iets uit te pakken. Gratis en offline.
  • De secties en imports van een ELF-, EXE- of DLL-bestand bekijken in VS Code. Open .so-, .exe-, .dll- en .dylib-bestanden in VS Code met de gratis ELF Viewer & PE Viewer: headers, secties, imports, exports, symbolen en hex, alleen-lezen.
  • Een Graphviz DOT-graaf bekijken zonder Graphviz te installeren. Bekijk .dot- en .gv-bestanden naast de editor in VS Code terwijl je typt, met Graphviz ingebouwd. Zes layout-engines, klik naar de regel, SVG- en PNG-export.
  • Een C++-bestand uitvoeren in VS Code met één klik. Compileer en start het open .cpp- of .c-bestand in VS Code met één klik, met je eigen gcc, g++ of clang. Invoer in de terminal, fouten in Problems, testcases.
  • Een Parquet-viewer gebruiken in VS Code. Open .parquet-, .parq- en .pq-bestanden in VS Code als sorteerbaar raster met het schema, geneste kolommen en exacte decimalen. Gratis, zonder Python.
  • Een JAR openen en de gedecompileerde Java-broncode lezen in VS Code. Open .jar-, .war-, .ear-, .aar- en .class-bestanden in VS Code: packages, MANIFEST.MF, bytecode en Java-code gedecompileerd met CFR. Gratis en alleen-lezen.
  • Een PDF-, Word-, PowerPoint- of Excel-bestand omzetten naar Markdown in VS Code. Klik met rechts op een PDF, DOCX, PPTX, XLSX, CSV, HTML of EPUB in VS Code en de Markdown opent ernaast. Gratis, offline, zonder Python en zonder upload.
  • Een .env-bestand bewerken in VS Code zonder je geheimen te tonen. Kleur .env-bestanden in VS Code, toon geheime waarden als puntjes tot de cursor op de regel staat en herstel dubbele sleutels en quotes. Gratis en offline.
  • De afbeelding achter een pad in je code zien, in de gutter en bij hover. Een miniatuur in de gutter en een hover met afbeelding, pixelmaten en bestandsgrootte bij afbeeldingspaden in JS, CSS, HTML en Markdown in VS Code. Gratis.
  • .proto-bestanden bewerken in VS Code met kleuring, formatteren en ga naar definitie. Kleur, formatteer en controleer .proto-bestanden in VS Code: formatter die commentaar behoudt, ga naar definitie, fouten zoals protoc. Gratis, zonder protoc.
  • AWS S3-, Cloudflare R2- of MinIO-buckets bekijken in VS Code. Blader door S3-, R2-, MinIO-, B2- en Wasabi-buckets in VS Code: open objecten alleen-lezen, up- en download met hervatten en sync een map na een proefplan.
  • Een bash- of zsh-script formatteren in VS Code. Formatteer bash-, sh-, zsh-, bats- en mksh-scripts in VS Code met Shift+Alt+F of bij opslaan. shfmt 3.14.1 zit erin, leest .editorconfig en werkt offline.
  • XML formatteren in VS Code en er XPath op uitvoeren. Formatteer of verklein XML in VS Code waarbij alleen witruimte tussen tags verandert, voer XPath 1.0 uit met de namespaces van het bestand en kopieer het XPath.
  • Een binair bestand bekijken en bewerken in VS Code. Bekijk en bewerk de bytes van elk bestand in VS Code met Hex Viewer, ook bestanden van 4 GB. Met zoeken, data inspector en vergelijken. Gratis en offline.
  • Een Word-bestand (.docx) openen in VS Code. Open .docx-, .odt- en oude .doc-bestanden in VS Code als voorbeeld met donkere modus, outline en zoeken. Zonder Office, offline en gratis.
  • Excel of CSV openen in VS Code en bevragen met SQL. Open .xlsx, .xls en CSV in VS Code als sorteerbare, filterbare tabel tot 1.000.000 rijen en draai SQL-query's. Zonder Python of database, offline.
  • Word en PowerPoint openen in VS Code, zonder Office. Bekijk .docx-, .odt- en .pptx-bestanden in VS Code of Cursor zonder Microsoft Office of LibreOffice. Gratis, offline, met zoeken en een outline.
  • PDF's lezen in donkere modus in VS Code. Lees PDF's in VS Code op donkere of sepia pagina's waarop foto's hun kleuren houden. Met zoeken, outline, miniaturen en markeringen. Gratis en offline.
