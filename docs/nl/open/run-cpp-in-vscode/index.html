Handleidingen in het Nederlands

Een C++-bestand uitvoeren in VS Code met één klik

Installeer de gratis extensie Run C++ and C Code, open een .cpp- of .c-bestand en klik op Run in de titelbalk van de editor, of druk op Ctrl+Alt+Enter (Cmd+Alt+Enter op een Mac). De extensie compileert het bestand met de gcc, g++, clang of clang++ die al op je computer staat en voert het uit in de terminal, waar cin en scanf werken. Compilerfouten komen in het paneel Problems op de juiste regel, en het paneel Input & Tests, de stresstest en de benchmark zijn gratis. Zovo Pro (eenmalig USD 19) voegt een sanitizer-check, een vergelijking van -O0, -O2 en -O3 en een testrapport toe. Elke tool kun je 3 keer gratis proberen.

Stappen in VS Code

  1. Installeer Run C++ and C Code via de Marketplace, of druk op Ctrl+P (Cmd+P op macOS) en voer ext install zovo.zovo-run-cpp uit.
  2. Zorg dat er een compiler geïnstalleerd is. "Run C++: Pick Compiler (gcc, g++, clang, clang++)" toont wat de extensie vindt. Is er geen, dan toont een installatiepagina de officiële stappen voor je systeem (Xcode Command Line Tools, MSYS2 of WinLibs, of de pakketbeheerder van je Linux).
  3. Open een .cpp-, .cc-, .cxx- of .c-bestand en klik op de knop Run in de titelbalk van de editor, of druk op Ctrl+Alt+Enter (Cmd+Alt+Enter op een Mac).
  4. Het programma draait in een terminal met de naam "Run: file.cpp". Typ daar de invoer. Aan het eind zie je de exitcode, de looptijd en het piekgeheugen. Zolang het programma draait, wordt de knop Run een knop Stop.
  5. Voor flags of argumenten zet je // run: -O2 -lm en // args: "Hello World" 3 in de eerste 40 regels van het bestand. De standaardinstellingen voor C++ zijn -std=c++20 -Wall -Wextra -g -O0.
  6. Wil je testen met opgeslagen invoer, voer dan "Run C++: Run with Input & Test Cases" uit. Plak de invoer, druk op Run with input en daarna op Save as test case. Run all tests toont geslaagd of mislukt, met een diff per regel.

Wat gratis is en wat Zovo Pro toevoegt

Run, Build Only, Run Last Build, Debug, builds van een map, het paneel Input & Tests, de stresstest en de benchmark zijn gratis. Je hoeft niet in te loggen, er zijn geen netwerkverzoeken en geen telemetrie.

Een programma dat je tests haalt, kan nog steeds voorbij het eind van een array lezen of een int laten overlopen. Sanitizer check bouwt een tweede versie met AddressSanitizer en UndefinedBehaviorSanitizer (-fsanitize=address,undefined), voert die uit op de invoer uit het paneel en op elke opgeslagen testcase, en zet elke heap- of stack-overflow, use after free, signed overflow of ander undefined behavior in het paneel Problems op de juiste regel. Je vindt de bug op zijn regel, zonder sanitizer-flags met de hand in te stellen.

Sanitizer check gebruiken (Zovo Pro)

  1. Zet invoer in het paneel Input & Tests, en sla testcases op als je die hebt. De check draait op de invoer uit het paneel en op elke opgeslagen testcase.
  2. Klik op "Sanitizer check (Pro)" in het paneel onder "Stress test, benchmark and more", of voer "Run C++: Sanitizer Check: AddressSanitizer and UBSan on the Input and Test Cases (Zovo Pro)" uit vanuit het Command Palette.
  3. Klik op een melding in het paneel Problems om naar de regel te springen. Een buildfout, Stop of Cancel kost geen gratis poging.

Sanitizer check werkt 3 keer gratis op je computer voordat om een licentie wordt gevraagd. Er is geen pop-up en geen aftelling.

Stappen in Cursor, Windsurf of VSCodium

  1. Open de Extensions-weergave met Ctrl+Shift+X (Cmd+Shift+X op macOS).
  2. Zoek zovo.zovo-run-cpp en klik op Install. Cursor, Windsurf en VSCodium installeren extensies van Open VSX, waar deze extensie zovo/zovo-run-cpp heet.
  3. Heeft je editor geen galerie, download dan het .vsix-bestand van de pagina op Open VSX en voer "Extensions: Install from VSIX..." uit.
  4. Daarna werkt alles zoals in VS Code.

Wat Run C++ and C Code doet

  • C- en C++-bestanden (.c, .cpp, .cc, .cxx) met gcc, g++, clang en clang++.
  • MSYS2, WinLibs, MinGW, TDM-GCC en LLVM in hun gebruikelijke Windows-mappen, en Homebrew-namen zoals g++-14.
  • Paden met spaties, & of niet-ASCII-letters, omdat geen shell ze verwerkt.
  • Programma's die een miljoen regels printen. Het paneel toont de eerste 2.000 en telt de rest.

Wat het niet doet

  • De extensie heeft een compiler op je computer nodig en downloadt er nooit een.
  • Runs in het paneel Input en testcases stoppen na 10 seconden (instelling zovoRun.timeLimitSeconds).
  • Uitvoer na 32 MB wordt geteld, niet bewaard (instelling zovoRun.maxCapturedOutputMB).
  • De sanitizer-check heeft een compiler met de sanitizer-runtime nodig. MinGW gcc op Windows heeft die niet, dus gebruik daar clang van LLVM. De check meldt dat zonder een poging te gebruiken.
  • Debug heeft CodeLLDB of de extensie C/C++ nodig.

Veelgestelde vragen

Is het gratis?

Run, Build Only, Debug, builds van een map, het paneel Input & Tests, de stresstest en de benchmark zijn gratis. De drie Pro-tools, Sanitizer check, Compare -O0, -O2 and -O3 en Test report, kun je elk 3 keer gratis gebruiken. Daarna heb je Zovo Pro nodig, eenmalig USD 19 voor alle Zovo-extensies.

Kan mijn programma invoer lezen met cin?

Ja. Het draait in een echte terminal, dus cin en scanf wachten op wat je typt, en prompts zonder nieuwe regel verschijnen eerst.

Verandert het mijn settings.json of tasks.json?

Nee. De extensie schrijft nooit naar je instellingenbestanden. Debug voegt één entry toe aan .vscode/launch.json, en alleen als je op Debug drukt.

Werkt het in Cursor?

Ja. De extensie staat op Open VSX, dus Cursor, Windsurf en VSCodium kunnen hem installeren.
