Een lettertypebestand bekijken in VS Code

Installeer de gratis Font Viewer en klik op een .ttf-, .otf-, .woff-, .woff2- of .ttc-bestand. Je ziet je eigen voorbeeldtekst in het lettertype, een waterfall met groottes, een glyph-raster waarin je kunt zoeken, en de licentie en embedding-rechten, zonder het lettertype op je systeem te installeren. De type tester, het glyph-raster, de tekentabel, het tabblad Info en Copy CSS @font-face zijn gratis. Zovo Pro (eenmalig USD 19) voegt twee tools toe, Convert Font en Font Folder Report. Elke tool kun je 3 keer gratis proberen.

Stappen in VS Code

  1. Installeer Font Viewer via de Marketplace, of druk op Ctrl+P (Cmd+P op macOS) en voer ext install zovo.font-viewer-vscode uit.
  2. Klik in de Explorer op een .ttf-, .otf-, .woff-, .woff2-, .ttc- of .otc-bestand. Font Viewer is de standaardeditor voor deze bestanden en verandert het lettertype nooit.
  3. Typ op het tabblad Type tester je eigen tekst, sleep de grootteschuif van 8 tot 200 px en bekijk de waterfall van 12 tot 96 px. Verschuif de schuiven van een variabel lettertype en zet OpenType-features zoals liga of ss01 aan en uit.
  4. Zoek op het tabblad Glyphs op naam, teken, U+20AC of glyph-id. Klik op een glyph om hem groot te zien met de baseline, x-hoogte en kapitaalhoogte, en kopieer het teken, het codepunt of de omtrek als SVG.
  5. Lees op het tabblad Characters de dekking van elk Unicode-blok, zoals "Basic Latin 95/128". Zet "Only characters in the font" uit om te zien wat ontbreekt.
  6. Lees op het tabblad Info de licentie, de ontwerper, het copyright en de embedding-rechten, en kopieer een kant-en-klare @font-face-regel.

Wat gratis is en wat Zovo Pro toevoegt

Elk ondersteund lettertype openen, de type tester, het glyph-raster, de tekentabel, het tabblad Info en Copy CSS @font-face zijn gratis. Font Viewer werkt offline, zonder netwerkverzoeken en zonder telemetrie.

Font Folder Report zet elk lettertype in een map in een lijst met familie, stijl, gewicht, assen, versie, aantal glyphs, licentie, licentie-URL en embedding-rechten. De lijst wordt een CSV-bestand, een Markdown-tabel of één fonts.css met een @font-face-regel voor elk lettertype (WOFF2 eerst). Voordat je een map met lettertypen meelevert in een app of website, zie je in één bestand waarvoor je elk lettertype mag gebruiken, zonder ze een voor een te openen.

Font Folder Report gebruiken (Zovo Pro)

  1. Klik in de Explorer met rechts op een map met lettertypen en kies "Font Folder Report: CSV, Markdown or @font-face CSS… (Pro)", of voer "Font Viewer: Font Folder Report: CSV, Markdown or @font-face CSS… (Pro)" uit vanuit het Command Palette en kies de map.
  2. Kies het formaat: CSV, Markdown-tabel of CSS @font-face-regels.
  3. Sla het bestand op. De standaardnamen zijn fonts-report.csv, fonts-report.md en fonts.css, en een poging telt pas als het bestand geschreven is.

Font Folder Report werkt 3 keer gratis op je computer voordat om een licentie wordt gevraagd. Er is geen pop-up en geen aftelling.

Stappen in Cursor, Windsurf of VSCodium

  1. Open de Extensions-weergave met Ctrl+Shift+X (Cmd+Shift+X op macOS).
  2. Zoek zovo.font-viewer-vscode en klik op Install. Cursor, Windsurf en VSCodium installeren extensies van Open VSX, waar deze extensie zovo/font-viewer-vscode heet.
  3. Heeft je editor geen galerie, download dan het .vsix-bestand van de pagina op Open VSX en voer "Extensions: Install from VSIX..." uit.
  4. Daarna werkt alles zoals in VS Code.

Wat Font Viewer doet

  • TrueType- (.ttf) en OpenType-lettertypen (.otf), ook variabele lettertypen.
  • Weblettertypen in .woff en .woff2. WOFF2 wordt uitgepakt door de eigen decoder van de extensie.
  • Collecties in .ttc en .otc, met een lijst in de kop om het lettertype te kiezen.
  • Grote CJK-lettertypen met 20.000 glyphs, die per pagina laden terwijl je scrollt.
  • Klik in de Explorer met rechts op een lettertype en kies Copy CSS @font-face zonder het te openen.

Wat het niet doet

  • WOFF2-collecties, SVG-lettertypen, .dfont en Type 1-lettertypen worden niet ondersteund.
  • Glyph-omtrekken tonen de standaardinstantie van een variabel lettertype. De type tester, de waterfall en de tekentabel volgen de schuiven van de assen.
  • Kleurlettertypen worden in kleur getekend in de type tester en de tekentabel, maar het glyph-raster toont alleen hun gewone omtrekken.
  • Bestanden boven 64 MB tonen een melding in plaats van te openen (instelling fontViewer.maxFileMB).
  • De extensie is alleen-lezen. Ze bewerkt geen lettertypen en installeert ze niet op je systeem.

Veelgestelde vragen

Is het gratis?

Lettertypen bekijken, de type tester, het glyph-raster, de tekentabel, het tabblad Info en Copy CSS @font-face zijn gratis. De twee Pro-tools, Convert Font en Font Folder Report, kun je elk 3 keer gratis gebruiken. Daarna heb je Zovo Pro nodig, eenmalig USD 19 voor alle Zovo-extensies.

Moet ik het lettertype installeren?

Nee. Het lettertype wordt uit het bestand gelezen en alleen in het tabblad van Font Viewer getoond. De lijst met lettertypen op je systeem verandert niet.

Kan het een WOFF2 uit mijn buildmap openen?

Ja. WOFF2 wordt uitgepakt door de eigen decoder van de extensie, en de open weergave herlaadt als je een nieuwe build van het lettertype opslaat.

Werkt het in Cursor?

Ja. Font Viewer staat op Open VSX als zovo/font-viewer-vscode, dus Cursor, Windsurf en VSCodium kunnen de extensie installeren.
