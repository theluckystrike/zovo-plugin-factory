Як відтворити відео MOV, MKV, WebM і MP4 зі звуком у VS Code

Встановіть безкоштовне розширення Video Preview with Sound і клацніть відео в Explorer. Файли MP4, MOV і M4V зі звуком AAC відтворюються зі звуком без жодних додаткових встановлень, бо розширення має власний декодер звуку. Для MKV, WebM, AVI і відео, яке VS Code не декодує, як-от Apple ProRes, потрібен ffmpeg на вашому комп’ютері. Відтворення, звук, субтитри й конвертація безкоштовні, а Zovo Pro (19 USD один раз) додає Clip export, Frame export і contact sheet, з 3 безкоштовними запусками для кожного інструмента.

Як це зробити у VS Code

  1. Встановіть Video Preview with Sound з Marketplace або натисніть Ctrl+P (Cmd+P на macOS) і виконайте ext install zovo.video-preview-with-sound.
  2. Якщо відео має формат MKV, WebM, AVI, WMV, FLV, MPG, OGV або M2TS чи звук AC-3, E-AC-3 або DTS, спершу встановіть ffmpeg. Виконайте winget install ffmpeg у Windows, sudo apt install ffmpeg у Linux або brew install ffmpeg на macOS. MP4, MOV і M4V зі звуком AAC більше нічого не потребують.
  3. Клацніть файл .mp4, .m4v, .mov, .webm, .mkv, .avi, .wmv, .flv, .mpg, .mpeg, .ogv або .m2ts в Explorer і натисніть пробіл, щоб відтворити його. Якщо VS Code запитає, який редактор використати, виберіть «Video Preview with Sound».
  4. Відео грає без звуку, доки на мітці не з’явиться «Sound: on». MKV або WebM копіюється в MP4 без перекодування. ProRes, AVI, WMV та інше відео, яке VS Code не декодує, один раз конвертується в H.264 і зберігається в кеші.
  5. Покладіть файл .srt або .vtt з тією самою назвою поруч із відео, і субтитри завантажаться самі. Натисніть C або скористайтеся меню CC, щоб перемкнути доріжку чи вимкнути субтитри.
  6. Натискайте , і ., щоб перейти на один кадр, [ і ], щоб змінити швидкість від 0.1x до 4x, A і B, щоб задати петлю, S, щоб зберегти поточний кадр як PNG у повному розмірі, і P для режиму «картинка в картинці».

Що безкоштовно і що додає Zovo Pro

Відтворення зі звуком, вбудований декодер AAC, відтворення MKV і WebM з ffmpeg, конвертація відео, яке VS Code не декодує, субтитри, «картинка в картинці», покадровий перехід, швидкість, петля A-B, збереження поточного кадру як PNG (S), панель метаданих і продовження з місця зупинки безкоштовні.

Clip export зберігає частину відео між A і B або все відео як GIF чи MP4 для pull request, issue чи документації. GIF створюється всередині плеєра без інших інструментів: 480 px при 10 fps, 640 px при 15 fps або до 960 px при 15 fps, не довше 60 секунд. MP4 вирізає ваш власний ffmpeg. Точне вирізання перекодовує в H.264 і AAC і починається з кадру A, а швидке копіювання зберігає вихідні потоки й починається з ключового кадру перед A.

Як запустити Clip export (Zovo Pro)

  1. Відкрийте відео в плеєрі. Натисніть A на початку і B у кінці потрібної частини або нічого не задавайте, щоб узяти все відео.
  2. Натисніть Clip (з позначкою PRO) у плеєрі або «Export a Clip as GIF or MP4» у маленькому рядку Pro tools під елементами керування. Можна також клацнути відео правою кнопкою в Explorer і вибрати «Zovo Pro: Export a Clip as GIF or MP4».
  3. Виберіть «GIF, 480 px wide, 10 fps», «GIF, 640 px wide, 15 fps», «GIF, up to 960 px wide, 15 fps», «MP4, exact cut» або «MP4, fast copy», а потім місце для збереження.
  4. Esc зупиняє експорт. Запуск зараховується лише тоді, коли файл збережено, тож скасований діалог або зупинений експорт не витрачають безкоштовний запуск.

Clip export можна запустити на вашому комп’ютері 3 рази безкоштовно, після цього розширення попросить ліцензію. Жодних спливних вікон і жодного зворотного відліку.

Як встановити в Cursor, Windsurf або VSCodium

  1. Відкрийте панель Extensions клавішами Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Знайдіть zovo.video-preview-with-sound і натисніть Install. Cursor, Windsurf і VSCodium встановлюють розширення з Open VSX, де це розширення опубліковано як zovo/video-preview-with-sound.
  3. Якщо у вашому редакторі немає каталогу розширень, завантажте файл .vsix зі сторінки Open VSX і виконайте «Extensions: Install from VSIX...».
  4. Далі все працює так само, як у VS Code.

Що вміє Video Preview with Sound

  • MP4, M4V і MOV зі звуком AAC (моно або стерео), ALAC, MP3 чи PCM без інших встановлень, у Windows, Linux і macOS.
  • MKV і WebM, які ffmpeg копіює в MP4 і які відтворюються зі звуком.
  • Звук AC-3, E-AC-3, DTS, Opus або 5.1 AAC у MP4, M4V чи MOV, який декодує ffmpeg або afconvert, що входить до macOS.
  • Відео Apple ProRes, MPEG-4 Part 2 і DNxHD та файли AVI, WMV, FLV, MPG, MPEG, OGV і M2TS, які ffmpeg конвертує в H.264.
  • Субтитри з файлів .srt і .vtt поруч із відео.

Чого розширення не робить

  • Без ffmpeg MKV і WebM не відкриваються в жодній системі. Плеєр показує «Install ffmpeg to open this file». ffmpeg не входить до розширення.
  • afconvert у macOS не конвертує відео й не відкриває MKV чи WebM. Для конвертації завжди потрібен ваш власний ffmpeg, а довгий файл ProRes може конвертуватися кілька хвилин.
  • Вбудований декодер відтворює HE-AAC з його ядра AAC-LC з половинною частотою дискретизації. Для повного HE-AAC, 5.1 AAC, AC-3 і DTS встановіть ffmpeg.
  • Файли понад 4096 МБ відтворюються, але без звуку (налаштування videoPreview.maxDecodeSizeMB).
  • Субтитри беруться лише з файлів .srt і .vtt, не більше 5 МБ кожен. Субтитри всередині відеофайлу не читаються. Файли .ts і .mts не відкриваються, бо так називаються файли TypeScript.

Часті запитання

Чому VS Code відтворює мій MP4 без звуку?

Вбудований у VS Code Chromium має декодер відео H.264, але не має декодера AAC, а більшість файлів MP4 і MOV мають звук AAC. Це розширення саме декодує звук і відтворює його синхронно з картинкою.

Чи потрібен ffmpeg?

Не для MP4, MOV і M4V зі звуком AAC, ALAC, MP3 або PCM. ffmpeg потрібен для MKV, WebM, AVI, WMV, FLV, MPG, OGV і M2TS, для ProRes та іншого відео, яке VS Code не декодує, і для кліпів MP4 з Clip export. Для звуку AC-3, E-AC-3 і DTS потрібен ffmpeg або afconvert на macOS.

Це безкоштовно?

Так. Відтворення, звук, субтитри, покадровий перехід, збереження поточного кадру як PNG і конвертація безкоштовні. Clip export, Frame export і contact sheet є інструментами Zovo Pro з 3 безкоштовними запусками кожен, а далі 19 USD один раз для всіх розширень Zovo.

Чи працює це в Cursor?

Так. Розширення є на Open VSX як zovo/video-preview-with-sound, тож його можна встановити в Cursor, Windsurf і VSCodium.
