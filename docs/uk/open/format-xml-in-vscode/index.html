Як форматувати XML у VS Code і виконувати на ньому XPath

Встановіть безкоштовне розширення XML Formatter & XPath Tools, відкрийте файл XML і натисніть Shift+Alt+F (Shift+Option+F на Mac). Змінюються лише пробіли між тегами: текст, CDATA, коментарі, xml:space="preserve" і значення атрибутів лишаються байт у байт, а файл, який не є well-formed, ніколи не змінюється. Форматування, Minify XML, XPath 1.0 із префіксами просторів імен самого файлу, Copy XPath і подання XML Tree безкоштовні й працюють офлайн. Zovo Pro (19 USD один раз) додає три інструменти, Run XPath on Every XML File in a Folder, Format All XML Files in a Folder і Compare Two XML Files Ignoring Formatting, і кожен має 3 безкоштовні спроби.

Як це зробити у VS Code

  1. Встановіть XML Formatter & XPath Tools з Marketplace або натисніть Ctrl+P (Cmd+P на macOS) і виконайте ext install zovo.zovo-xml-xpath-tools.
  2. Відкрийте файл .xml і натисніть Shift+Alt+F (Shift+Option+F на Mac) або виконайте Format Document. Якщо у вас кілька форматерів XML, VS Code запитає, який використати. Format Selection теж працює.
  3. Форматер бере ваш розмір табуляції й вибір між табуляцією та пробілами, а також зберігає закінчення рядків, мітку порядку байтів (BOM) і останній символ нового рядка. Якщо файл не well-formed, нічого не змінюється, і ви бачите помилку з рядком і колонкою.
  4. Щоб натомість зменшити файл, виконайте "XML: Minify XML" для всього файлу або виділення. Коментарі лишаються, якщо не ввімкнути xmlXpathTools.minify.removeComments.
  5. Щоб виконати XPath, натисніть кнопку пошуку в заголовку редактора або виконайте "XML: Evaluate XPath…". Результати з їхнім рядком з'являються в XPath Results. Клацніть результат, щоб виділити його в редакторі.
  6. Клацніть XPath у рядку стану, щоб скопіювати шлях елемента під курсором: з позиціями, з атрибутами id або name чи в переносній формі local-name().
  7. Для файлу понад 50 МБ клацніть його правою кнопкою в Explorer і виберіть "Format Large XML File on Disk…". Команда записує name.formatted.xml поруч або замінює файл після вашого підтвердження.

Що безкоштовно і що додає Zovo Pro

Format Document, Format Selection, Minify XML, XPath 1.0, Copy XPath, подання XML Tree, помилки well-formedness у Problems і Format Large XML File on Disk безкоштовні. Входити в обліковий запис не потрібно, і в розширенні немає мережевого коду.

Run XPath on Every XML File in a Folder виконує один XPath для кожного файлу .xml, .xsd, .csproj, .svg, .kml та подібних у папці, кожного з його власними префіксами просторів імен. Результати відкриваються як CSV (файл, рядок, тип, ім'я, значення) для електронної таблиці, як JSON для скрипта або як звіт Markdown для перевірки. Ви отримуєте те саме значення з багатьох файлів, наприклад кожен artifactId у наборі файлів pom.xml, не відкриваючи їх по одному.

Як запустити Run XPath on Every XML File in a Folder (Zovo Pro)

  1. Клацніть правою кнопкою папку в Explorer і виберіть "Zovo Pro: Run XPath on Every XML File in a Folder" або виконайте "XML: Run XPath on Every XML File in a Folder (Pro)" з Command Palette і виберіть папку.
  2. Або, виконавши XPath в одному файлі, клацніть останній рядок XPath Results, "Run this XPath on every XML file in a folder", щоб виконати той самий вираз для папки.
  3. Введіть XPath. Сповіщення показує прогрес із кнопкою Cancel.
  4. Виберіть "Open as CSV", "Open as JSON" або "Open a Markdown report". Результати відкриваються в новій вкладці редактора. Спроба зараховується, лише коли ви отримали результат: Escape, помилка в XPath або папка без файлів XML спроби не витрачають.

Run XPath on Every XML File in a Folder можна запустити на вашому комп’ютері 3 рази безкоштовно, після цього розширення попросить ліцензію. Жодних спливних вікон і жодного зворотного відліку.

Як встановити в Cursor, Windsurf або VSCodium

  1. Відкрийте панель Extensions клавішами Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Знайдіть zovo.zovo-xml-xpath-tools і натисніть Install. Cursor, Windsurf і VSCodium встановлюють розширення з Open VSX, де це розширення опубліковано як zovo/zovo-xml-xpath-tools.
  3. Якщо у вашому редакторі немає каталогу розширень, завантажте файл .vsix зі сторінки Open VSX і виконайте «Extensions: Install from VSIX...».
  4. Далі все працює так само, як у VS Code.

Що вміє XML Formatter & XPath Tools

  • Файли, які VS Code відкриває як XML. Розширення також відкриває як XML файли .kml, .gpx, .rss, .atom, .wsdl, .dbk, .xlf, .xliff, .resx, .nuspec, .props, .targets і .xaml.
  • Великі файли: форматування, дерево і XPath працюють у фоновому потоці. У тестах розширення файл на 49 МБ із приблизно 1 мільйоном елементів відформатовано за 1,6 секунди.
  • Прості імена також збігаються з простором імен за замовчуванням, тому //dependency/artifactId працює в pom.xml. Для строгого XPath 1.0 увімкніть xmlXpathTools.xpath.strictNamespaces.
  • Розташування атрибутів: як написано, в один рядок або кожен атрибут в окремому рядку (налаштування xmlXpathTools.format.attributes).
  • Подання XML Tree в Explorer стежить за курсором, а Problems показує помилки well-formedness з рядком і колонкою.

Чого розширення не робить

  • Лише XPath 1.0. XPath 2.0 чи 3.1, XQuery і XSLT немає.
  • Розширення перевіряє, що файл well-formed. Перевірки за XSD або DTD немає.
  • Файли понад 50 МБ можна відформатувати на диску, але VS Code не передає їх розширенням, тому дерево і XPath для них не працюють.
  • Команда для форматування на диску читає UTF-8, UTF-16 з міткою порядку байтів (BOM) і ISO-8859-1.
  • Елемент із текстом, як-от <p>Some <b>bold</b> text</p>, лишається у своєму рядку як написано. Нові розриви рядків отримують лише елементи, що містять теги й не містять тексту.

Часті запитання

Це безкоштовно?

Форматування, Minify XML, XPath, Copy XPath, подання XML Tree і перевірка well-formedness безкоштовні. Три Pro-інструменти, Run XPath on Every XML File in a Folder, Format All XML Files in a Folder і Compare Two XML Files Ignoring Formatting, мають по 3 безкоштовні спроби. Після цього потрібен Zovo Pro, 19 USD один раз для всіх розширень Zovo.

Чи змінить форматування мій текст або CDATA?

Ні. Змінюються лише пробіли між тегами в елементах, що містять теги й не містять тексту. Текст, CDATA, коментарі та вміст усередині xml:space="preserve" копіюються як є, а повторне форматування нічого не змінює.

Чому мій XPath нічого не знаходить у pom.xml?

У файлі є простір імен за замовчуванням. У цьому розширенні прості імена також збігаються з ним, тому //dependency працює. Для строгого XPath 1.0 увімкніть xmlXpathTools.xpath.strictNamespaces.

Чи працює воно в Cursor?

Так. Cursor, Windsurf і VSCodium встановлюють його з Open VSX, де воно опубліковане як zovo/zovo-xml-xpath-tools.
