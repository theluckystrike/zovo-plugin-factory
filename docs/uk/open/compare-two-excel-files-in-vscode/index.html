Порівняння двох файлів Excel або CSV у VS Code

Встановіть безкоштовне розширення Excel Compare & XLSX Diff і виберіть дві книги або два CSV-файли. Змінені клітинки виділено жовтим, а старе значення перекреслено, додані рядки показано зеленим, видалені червоним. Рядки вирівнюються, а стовпці зіставляються за заголовком, тому один вставлений рядок чи стовпець видно як одну зміну. Перед комітом книгу можна порівняти з її версією в Git HEAD. Усе це безкоштовно і без мережевих запитів. Zovo Pro (19 USD один раз) додає три інструменти: Export a diff report, Match rows by key columns і Compare two folders of workbooks. Кожен має 3 безкоштовні спроби.

Як це зробити у VS Code

  1. Встановіть Excel Compare & XLSX Diff з Marketplace або натисніть Ctrl+P (Cmd+P на macOS) і виконайте ext install zovo.zovo-excel-compare.
  2. Виділіть два файли в Explorer, клацніть правою кнопкою і виберіть Compare Selected Excel Files. Або клацніть правою кнопкою один файл, виберіть Compare with... і вкажіть другий. З Command Palette можна виконати «Excel Compare: Compare Two Excel or CSV Files...».
  3. Підходить будь-яке поєднання .xlsx, .xlsm, .xls, .ods, .csv і .tsv, тож можна порівняти .xlsx із .csv.
  4. Прочитайте рядок підсумку, потім вкладки аркушів із кількістю відмінностей на кожній. Клацніть клітинку, щоб побачити повне старе й нове значення та скопіювати їх.
  5. Натискайте N і P (або Next і Previous), щоб переходити між усіма змінами на всіх аркушах. Перемикайтеся між Values і Formulas, щоб порівнювати те, що показують клітинки, або самі формули.
  6. Щоб побачити свої зміни до коміту, клацніть правою кнопкою книгу в Git-репозиторії й виберіть Compare with Git HEAD.

Що безкоштовно і що додає Zovo Pro

Порівняння будь-яких двох файлів, сітка, Values і Formulas, перехід до наступної й попередньої зміни, порівняння CSV із визначенням кодування й роздільника та Compare with Git HEAD безкоштовні. Входити в обліковий запис не потрібно, мережевих запитів і телеметрії немає.

Коли зміни треба показати іншій людині, Export a diff report створює книгу XLSX, де змінені, додані й видалені клітинки залито кольором, з аркушем Summary і списком Changes з усіма старими й новими значеннями. Також можна отримати одну HTML-сторінку або CSV-список змін. Ви надсилаєте один файл замість скриншотів.

Як запустити Export a diff report (Zovo Pro)

  1. Порівняйте два файли, як описано вище, потім натисніть Export report на панелі порівняння або виконайте «Excel Compare: Export a diff report (XLSX, HTML or CSV) (Pro)» з Command Palette.
  2. Виберіть XLSX, HTML або CSV.
  3. Вкажіть, куди зберегти звіт. Спроба витрачається, лише якщо звіт записано.

Export a diff report можна запустити на вашому комп’ютері 3 рази безкоштовно, після цього розширення попросить ліцензію. Жодних спливних вікон і жодного зворотного відліку.

Як встановити в Cursor, Windsurf або VSCodium

  1. Відкрийте панель Extensions клавішами Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Знайдіть zovo.zovo-excel-compare і натисніть Install. Cursor, Windsurf і VSCodium встановлюють розширення з Open VSX, де це розширення опубліковано як zovo/zovo-excel-compare.
  3. Якщо у вашому редакторі немає каталогу розширень, завантажте файл .vsix зі сторінки Open VSX і виконайте «Extensions: Install from VSIX...».
  4. Далі все працює так само, як у VS Code.

Що вміє Excel Compare & XLSX Diff

  • Аркуші зіставляються за назвою, потім за позицією. Аркуші, які є лише в одному файлі, позначаються як додані або видалені.
  • CSV і TSV з автоматичним визначенням кодування (UTF-8 з BOM і без, UTF-16, кодові сторінки Windows) і роздільника (кома, крапка з комою, табуляція або вертикальна риска), зокрема поля в лапках із розривами рядків.
  • Великі аркуші. Сітка малює лише видимі рядки, тому аркуш на 300 000 рядків гортається так само, як короткий.
  • Примітки, якщо об’єднані клітинки відрізняються або аркуш обрізано через ліміт.
  • Два інші інструменти Pro. Match rows by key columns зіставляє рядки за стовпцем ID, тому відсортовані чи переставлені аркуші порівнюються чисто, а переміщені рядки позначаються. Compare two folders of workbooks складає пари файлів за назвою й показує, які однакові, які відрізняються і які є лише в одній теці.

Чого розширення не робить

  • Файли до 200 МБ (параметр excelCompare.maxFileSizeMB), 300 000 рядків на аркуш (excelCompare.maxRows), 1000 стовпців і 200 аркушів. Якщо спрацював ліміт, у вікні порівняння з’являється примітка.
  • Книга, яка після розпакування зайняла б понад 600 МБ або стиснута як zip-бомба, відхиляється до розпакування.
  • Без інструмента Pro Match rows by key columns рядки вирівнюються за вмістом і позицією, а не за стовпцем ID.
  • Розширення лише порівнює файли, воно не редагує й не об’єднує їх.

Це безкоштовно?

Порівняння двох книг або CSV-файлів, Values і Formulas, перехід до наступної й попередньої зміни та Compare with Git HEAD безкоштовні. Три інструменти Pro, Export a diff report, Match rows by key columns і Compare two folders of workbooks, мають по 3 безкоштовні спроби. Далі потрібен Zovo Pro за 19 USD один раз, він відкриває всі розширення Zovo.

Чи може VS Code порівняти два файли Excel без розширення?

Ні. Файл .xlsx є zip-архівом із частинами XML, тому вбудований diff показує його як двійковий. Потрібне розширення, яке читає книгу.

Якщо вставити рядок на початку, усі рядки нижче буде позначено як змінені?

Ні. Рядки вирівнюються перед порівнянням, тому вставлений рядок видно як один доданий рядок.

Чи можна побачити, що змінилося в книзі після останнього коміту?

Так. Клацніть файл правою кнопкою в Git-репозиторії й виберіть Compare with Git HEAD. Використовується ваш локальний git.
