Як переглянути секції та імпорти файлу ELF, EXE чи DLL у VS Code

Встановіть безкоштовний ELF Viewer & PE Viewer і клацніть файл .so, .exe, .dll або .dylib. Ви отримаєте вкладки із заголовками, секціями, сегментами, імпортами, експортами й символами файлів Linux ELF, Windows PE та Apple Mach-O, а також hex-перегляд, без readelf, objdump чи dumpbin. Усі види файлу безкоштовні й працюють лише на читання. Zovo Pro (19 USD один раз) додає три інструменти, експорт у JSON або заголовок C, порівняння двох бінарних файлів і пошук назви в папці з бінарними файлами, з 3 безкоштовними запусками кожен.

Як це зробити у VS Code

  1. Встановіть ELF Viewer & PE Viewer з Marketplace або натисніть Ctrl+P (Cmd+P на macOS) і виконайте ext install zovo.zovo-elf-pe-viewer.
  2. Клацніть файл .exe, .dll, .sys, .so, .dylib, .elf або .ko в Explorer. Він відкриється в переглядачі. Для об’єктного файлу .o або виконуваного файлу Linux чи macOS без розширення клацніть файл правою кнопкою й виберіть Open in ELF & PE Viewer.
  3. Першою відкривається вкладка Overview. На ній видно архітектуру, тип файлу, точку входу, підключені бібліотеки, прапорці безпеки, як-от ASLR і DEP, build ID і шлях до PDB.
  4. Відкрийте вкладку Sections або Imports. Імпорти ELF показують бібліотеку та версію символу кожної функції. Для файлів PE є ще data directories, імпорти з відкладеним завантаженням (delay-load) і ресурси, а для Mach-O є load commands.
  5. Введіть текст у поле фільтра над таблицею, щоб звузити рядки, і клацніть заголовок стовпця, щоб відсортувати. Copy rows копіює рядки в буфер обміну як текст, розділений табуляцією.
  6. Клацніть посилання bytes секції чи сегмента, щоб побачити їхні байти, позначені на вкладці Hex. На вкладці Headers кнопка Show every header field with its offset відкриває дерево полів.

Що безкоштовно і що додає Zovo Pro

Усі види файлу безкоштовні й не потребують входу: огляд, усі таблиці, фільтр, сортування й копіювання, hex-перегляд і дерево полів. Розширення ніколи не записує в бінарний файл і не робить мережевих запитів.

Щоб дізнатися, які бінарні файли в папці збірки імпортують функцію чи підключають бібліотеку, цей інструмент читає кожен файл ELF, PE та Mach-O у папці й показує кожен збіг разом із файлом. Звичайний текст знаходить будь-яку частину назви, а також працює /regex/. Ви отримуєте відповідь одним пошуком і не відкриваєте кожен бінарний файл та не запускаєте readelf чи dumpbin для кожного файлу окремо.

Як запустити Find a symbol or import in a folder (Zovo Pro)

  1. Відкрийте бінарний файл і натисніть Find in folder… угорі переглядача або виконайте «ELF & PE Viewer: Find a symbol or import in a folder (Pro)» з Command Palette.
  2. Введіть назву, як-от CreateFileW або SSL_read, чи регулярний вираз, як-от /^_?pthread_/. Пошук іде в папці робочої області, або інструмент попросить вибрати папку.
  3. Якщо пошук запущено з переглядача, збіги відкриваються на вкладці Find з кнопкою Copy. Якщо з Command Palette, вони з’являються у списку, і клацання відкриває потрібний бінарний файл.
  4. Escape або пошук без збігів не витрачає безкоштовний запуск.

Find a symbol or import in a folder можна запустити на вашому комп’ютері 3 рази безкоштовно, після цього розширення попросить ліцензію. Жодних спливних вікон і жодного зворотного відліку.

Як встановити в Cursor, Windsurf або VSCodium

  1. Відкрийте панель Extensions клавішами Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Знайдіть zovo.zovo-elf-pe-viewer і натисніть Install. Cursor, Windsurf і VSCodium встановлюють розширення з Open VSX, де це розширення опубліковано як zovo/zovo-elf-pe-viewer.
  3. Якщо у вашому редакторі немає каталогу розширень, завантажте файл .vsix зі сторінки Open VSX і виконайте «Extensions: Install from VSIX...».
  4. Далі все працює так само, як у VS Code.

Що вміє ELF Viewer & PE Viewer

  • Файли ELF 32 і 64 біт, little-endian і big-endian, як-от .so, .o, .ko, .elf, .axf і виконувані файли Linux.
  • Файли PE32 і PE32+, як-от .exe, .dll, .sys, .efi і .pyd, з імпортами за назвою й за порядковим номером (ordinal), експортами з переадресацією (forwarders) і заголовком середовища .NET.
  • Mach-O 32 і 64 біт та універсальні бінарні файли. Архітектуру, як-от arm64 чи x86_64, вибирають угорі.
  • Таблиці до 100 000 рядків, які можна фільтрувати, сортувати й копіювати.

Чого розширення не робить

  • Розширення працює лише на читання й не має дизасемблера.
  • Статичні бібліотеки (.a), class-файли Java, WebAssembly і DEX не читаються.
  • Кожна таблиця обмежена 100 000 рядків, а читання зупиняється через 10 секунд. Переглядач повідомляє, коли це стається.
  • Файли на віддалених або віртуальних файлових системах читаються до 256 МБ. Find in folder шукає лише в локальних папках.
  • Файли .o і файли без розширення за замовчуванням не відкриваються. Скористайтеся Open in ELF & PE Viewer у контекстному меню.

Часті запитання

Це безкоштовно?

Усі види файлу безкоштовні, без входу. Три Pro-інструменти, експорт у JSON або заголовок C, порівняння двох бінарних файлів і пошук назви в папці, мають по 3 безкоштовні запуски. Після цього потрібен Zovo Pro, 19 USD один раз для всіх розширень Zovo.

Чи потрібні readelf, objdump або dumpbin?

Ні. Розширення саме читає файли ELF, PE і Mach-O, інші програми встановлювати не треба.

Чи може воно змінити бінарний файл?

Ні. Воно лише читає файл і ніколи в нього не записує. Pro-експорт зберігає новий файл JSON або заголовка там, де ви вкажете.

Чи працює це в Cursor?

Так. У README сказано, що розширення працює в Cursor, Windsurf і VSCodium, і воно є на Open VSX, тож ці редактори можуть його встановити.
