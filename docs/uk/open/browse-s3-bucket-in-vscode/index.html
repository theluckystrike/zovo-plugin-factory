Як переглядати бакети AWS S3, Cloudflare R2 або MinIO у VS Code

Встановіть безкоштовне розширення S3 Explorer і відкрийте його подання S3 Buckets на Activity Bar. Воно працює з AWS S3 (профілі з ~/.aws, зокрема профілі SSO), Cloudflare R2, MinIO, Backblaze B2, Wasabi і DigitalOcean Spaces. Перегляд, відкриття об'єктів лише для читання, вивантаження, завантаження, копіювання, переміщення, перейменування, видалення, версії, теги, presigned URL і синхронізація папки безкоштовні, без входу й без телеметрії. Zovo Pro (19 USD один раз) додає три інструменти, Copy to Another Connection, Size and Cost Report і Scheduled Sync, і кожен має 3 безкоштовні спроби.

Як це зробити у VS Code

  1. Встановіть S3 Explorer з Marketplace або натисніть Ctrl+P (Cmd+P на macOS) і виконайте ext install zovo.zovo-s3-explorer.
  2. Відкрийте подання S3 Explorer на Activity Bar і натисніть Add Connection. Виберіть профіль AWS з ~/.aws або введіть ключ доступу, ID облікового запису R2 і токен чи URL endpoint MinIO або іншого S3-сумісного сервісу. Ключі, які ви вводите, зберігаються в системному сховищі ключів (keychain).
  3. Розгорніть підключення, щоб побачити його бакети. Ключі об'єктів завантажуються по 1000 за раз із рядком "Load 1,000 more". Якщо ваш ключ не має права отримувати список бакетів, клацніть підключення правою кнопкою і виберіть Add Bucket by Name.
  4. Клацніть об'єкт, щоб відкрити його лише для читання у вкладці або у відповідному переглядачі. Щоб побачити його метадані, теги, версії й presigned URL, клацніть його правою кнопкою і виберіть Show Details, Versions and Presigned URL.
  5. Щоб змінити об'єкт, клацніть його правою кнопкою і виберіть Edit and Upload. Ви редагуєте копію, а перед заміною об'єкта діалог показує бакет, ключ і обидва розміри.
  6. Перетягніть файли або папки з Explorer на бакет, щоб вивантажити їх, або клацніть правою кнопкою і виберіть Download. Файли від 16 МБ вивантажуються частинами з прогресом і кнопкою Cancel, а перерване вивантаження продовжується лише з відсутніми частинами.
  7. Щоб локальна папка й префікс збігалися, клацніть правою кнопкою бакет або папку і виберіть Sync Folder. Перш ніж щось зміниться, ви бачите план dry-run (нові, змінені, до видалення).

Що безкоштовно і що додає Zovo Pro

Перегляд, відкриття, Edit and Upload, вивантаження, завантаження, копіювання, переміщення, перейменування, видалення, версії, теги, presigned URL і синхронізація папки безкоштовні, без входу, без облікового запису й без телеметрії. Розширення підключається лише до endpoint сховищ, які ви додали.

Copy to Another Connection копіює об'єкти або цілі папки з одного підключення в інше, наприклад з AWS S3 у Cloudflare R2 або MinIO, з тим самим підтвердженням, що й під час кожного копіювання: ключі перелічено, а ключі, які буде замінено, названо. Великі об'єкти передаються через multipart upload. Ви переносите дані між провайдерами або обліковими записами просто з дерева, без скрипта й без другого інструмента.

Як запустити Copy to Another Connection (Zovo Pro)

  1. Спершу додайте друге підключення. Потім клацніть правою кнопкою об'єкт або папку в поданні S3 Buckets і виберіть "Copy to Another Connection... (Pro)" або натисніть Copy to Another Connection у рядку "Zovo Pro tools" наприкінці подання.
  2. Виберіть цільове підключення, бакет і папку призначення (порожньо для верхнього рівня).
  3. Прочитайте список об'єктів у підтвердженні й натисніть Copy або Copy and Replace, якщо деякі ключі вже існують. Сповіщення показує прогрес.
  4. Спроба зараховується, лише коли об'єкти скопійовано. Escape під час вибору або відсутність другого підключення спроби не витрачають.

Copy to Another Connection можна запустити на вашому комп’ютері 3 рази безкоштовно, після цього розширення попросить ліцензію. Жодних спливних вікон і жодного зворотного відліку.

Як встановити в Cursor, Windsurf або VSCodium

  1. Відкрийте панель Extensions клавішами Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Знайдіть zovo.zovo-s3-explorer і натисніть Install. Cursor, Windsurf і VSCodium встановлюють розширення з Open VSX, де це розширення опубліковано як zovo/zovo-s3-explorer.
  3. Якщо у вашому редакторі немає каталогу розширень, завантажте файл .vsix зі сторінки Open VSX і виконайте «Extensions: Install from VSIX...».
  4. Далі все працює так само, як у VS Code.

Що вміє S3 Explorer

  • Профілі AWS із ключами доступу, credential_process, ролі із source_profile і профілі SSO після aws sso login. endpoint_url у профілі враховується.
  • MinIO та інші S3-сумісні сервіси з URL endpoint, регіоном, URL у стилі path-style або virtual-hosted і можливістю приймати самопідписаний сертифікат.
  • Метадані, тип вмісту, клас зберігання, ETag, теги (редагування й збереження), версії (відкриття, завантаження, відновлення) і presigned URL для GET або PUT від 15 хвилин до 7 днів.
  • Бакети з мільйонами ключів, по 1000 за раз, з пошуком і фільтром за префіксом.
  • Завантаження зберігають структуру папок і ніколи не записують за межі вибраної папки: ключі із сегментами .., літерами дисків або байтами NUL пропускаються й перелічуються.

Чого розширення не робить

  • Розширення ніколи саме не використовує профіль AWS default або AWS_PROFILE. Ви самі вибираєте профіль для підключення.
  • Текстові об'єкти понад 10 МБ спершу запитують підтвердження, а потім показують перший 1 МБ. Бінарні об'єкти понад 200 МБ запитують підтвердження перед завантаженням.
  • Відкриті об'єкти доступні лише для читання. У бакет записує лише Edit and Upload, після підтвердження.
  • Scheduled Sync працює лише тоді, коли VS Code відкрито, кожні 5-60 хвилин, і ніколи нічого не видаляє.
  • Запити без відповіді зупиняються через 30 секунд (налаштування s3Explorer.requestTimeoutSeconds).

Часті запитання

Це безкоштовно?

Перегляд, відкриття, вивантаження, завантаження, копіювання, переміщення, перейменування, видалення, версії, теги, presigned URL і синхронізація папки безкоштовні. Три Pro-інструменти, Copy to Another Connection, Size and Cost Report і Scheduled Sync, мають по 3 безкоштовні спроби. Після цього потрібен Zovo Pro, 19 USD один раз для всіх розширень Zovo.

Де зберігаються мої ключі?

Ключі, які ви вводите, потрапляють у системне сховище ключів через VS Code SecretStorage і ніколи не потрапляють у файли налаштувань. Профілі AWS зчитуються з ~/.aws, лише коли ви вибираєте один із них.

Чи працює воно з Cloudflare R2 і MinIO?

Так. Для R2 потрібні ID вашого облікового запису й ключ доступу токена R2 API. Для MinIO та інших S3-сумісних сервісів потрібні URL endpoint, регіон і URL у стилі path-style або virtual-hosted.

Чи працює воно в Cursor?

Так. Cursor, Windsurf і VSCodium встановлюють його з Open VSX, де воно опубліковане як zovo/zovo-s3-explorer.
