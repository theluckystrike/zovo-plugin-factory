Як читати й відновлювати історію Claude Code у VS Code

Встановіть Claude Code History & Codex History Viewer (Agent Session Viewer). Розширення показує ваші сесії Claude Code з ~/.claude/projects і сесії Codex з ~/.codex/sessions на одній бічній панелі, відкриває кожну як зручний для читання транскрипт і відновлює її в терміналі одним клацанням. Читання, пошук, відновлення та експорт однієї сесії в Markdown безкоштовні й не потребують облікового запису. Zovo Pro (19 USD один раз) додає звіт про використання й вартість, безпечний для поширення експорт із прихованими секретами та пакетний експорт у Markdown, і кожен Pro-інструмент має 3 безкоштовні запуски.

Як це зробити у VS Code

  1. Встановіть Agent Session Viewer з Marketplace або натисніть Ctrl+P (Cmd+P на macOS) і виконайте ext install zovo.agent-session-viewer.
  2. Клацніть значок Agent Sessions на панелі дій (activity bar). Панель Sessions показує сесії Claude Code і Codex, згруповані за папками проєктів, а субагенти вкладені під сесією, яка їх запустила.
  3. Клацніть сесію, щоб її прочитати. Виклики інструментів згорнуті, невдалі виклики позначені червоним, а правки файлів показано як diff. У заголовку видно модель, гілку git, кількість ходів і підсумки токенів.
  4. Щоб знайти стару сесію, клацніть значок пошуку вгорі панелі або виконайте «Agent Sessions: Search Sessions» з Command Palette. Виберіть результат, і сесія відкриється на місці збігу.
  5. Клацніть значок термінала біля сесії (Resume in Terminal). Термінал відкриється в папці проєкту й виконає claude --resume <id> або codex resume <id>.
  6. Якщо файл сесії .jsonl лежить в іншій папці, клацніть його правою кнопкою, виберіть Open With, а потім Agent Session Viewer.

Що безкоштовно і що додає Zovo Pro

Безкоштовні дерево Sessions, читання сесій, пошук по всіх сесіях, Resume in Terminal, Copy Resume Command, експорт однієї сесії в Markdown, сирий вигляд (raw view) і Reveal in File Manager. Обмеження на обсяг історії немає, і входити в обліковий запис не потрібно.

Share-safe export зберігає одну сесію або всі сесії проєкту як одну самодостатню HTML-сторінку чи один файл Markdown. Ключі API, токени, паролі в URL, значення з .env, приватні ключі, адреси email і шлях до вашої домашньої папки замінюються на [REDACTED ...], а повідомлення перелічує, що саме приховано. Ви можете надіслати сесію для pull request, аудиту чи передачі роботи, не вичищаючи її вручну.

Як запустити Share-safe export (Zovo Pro)

  1. Відкрийте сесію й натисніть кнопку Share-safe export на панелі інструментів сесії. Або клацніть правою кнопкою сесію чи папку проєкту в дереві Sessions і виберіть «Share-Safe Export, Secrets Redacted (Pro)…».
  2. Коли сесію відкрито, можна також виконати «Agent Sessions: Share-Safe Export, Secrets Redacted (Pro)…» з Command Palette.
  3. Виберіть формат, HTML-сторінку або Markdown, з виводом інструментів чи без нього. Потім виберіть, куди зберегти файл.
  4. Прочитайте експорт, перш ніж ним ділитися. Запуск зараховується лише тоді, коли файл збережено. Escape або Cancel нічого не коштують.

Share-safe export можна запустити на вашому комп’ютері 3 рази безкоштовно, після цього розширення попросить ліцензію. Жодних спливних вікон і жодного зворотного відліку.

Як встановити в Cursor, Windsurf або VSCodium

  1. Відкрийте панель Extensions клавішами Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Знайдіть zovo.agent-session-viewer і натисніть Install. Cursor, Windsurf і VSCodium встановлюють розширення з Open VSX, де це розширення опубліковано як zovo/agent-session-viewer.
  3. Якщо у вашому редакторі немає каталогу розширень, завантажте файл .vsix зі сторінки Open VSX і виконайте «Extensions: Install from VSIX...».
  4. Далі все працює так само, як у VS Code.

Що вміє Agent Session Viewer

  • Сесії Claude Code у ~/.claude/projects (або $CLAUDE_CONFIG_DIR/projects) і сесії Codex у ~/.codex/sessions (або $CODEX_HOME/sessions).
  • Субагенти обох інструментів, вкладені під сесією, яка їх запустила.
  • Заголовок з інструментом, моделлю, папкою проєкту, гілкою git, тривалістю, кількістю ходів, підсумками токенів і вартістю, якщо файл її записує (Claude Code записує, Codex ні).
  • Правки файлів як diff (Edit, Write і apply_patch), а також thinking і підсумки міркувань Codex у згорнутому вигляді.
  • Назви потоків Codex із session_index.jsonl, тож перейменовані потоки зберігають свої назви.

Чого розширення не робить

  • Розширення читає лише Claude Code і Codex. Сесії Cursor, Copilot і Gemini CLI поки не підтримуються.
  • Воно працює лише на читання. Розширення ніколи не змінює, не переміщує й не видаляє файли сесій і не має команди видалення.
  • Пошук знаходить звичайний текст, а не регулярні вирази, і зупиняється на 300 результатах.
  • Для Resume in Terminal потрібні встановлені Claude Code або Codex, доступні в PATH термінала.
  • За замовчуванням файли читаються до 256 МБ (agentSessionViewer.maxFileSizeMB), а більші файли відкриваються лише з першою частиною. Міркування Codex, збережені в зашифрованому вигляді, показати не можна.

Часті запитання

Де Claude Code зберігає історію чатів?

У ~/.claude/projects, по одній папці на проєкт і по одному файлу .jsonl на сесію. Якщо задано CLAUDE_CONFIG_DIR, історія лежить у цій папці.

Це безкоштовно?

Так. Читання, пошук, відновлення та експорт однієї сесії в Markdown безкоштовні, без обмеження історії. Три Pro-інструменти (звіт про використання й вартість, безпечний експорт і пакетний експорт) мають по 3 безкоштовні запуски, а далі Zovo Pro коштує 19 USD один раз для всіх розширень Zovo.

Чи можна видаляти старі сесії з переглядача?

Ні. Розширення лише читає файли сесій і ніколи їх не змінює, не переміщує й не видаляє.

Його створила Anthropic?

Ні. Розширення не створене Anthropic чи OpenAI і не пов’язане з ними. Воно не робить мережевих запитів і не має телеметрії.
