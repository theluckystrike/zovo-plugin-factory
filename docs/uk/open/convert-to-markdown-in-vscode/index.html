Як конвертувати файл PDF, Word, PowerPoint або Excel у Markdown у VS Code

Встановіть безкоштовне розширення Convert to Markdown, у Explorer клацніть правою кнопкою файл PDF, Word, PowerPoint, Excel, CSV, HTML, EPUB, ODT або RTF і виберіть Convert to Markdown. Markdown відкриється поруч із файлом, із заголовками, списками, таблицями, посиланнями та нотатками доповідача до слайдів, і жодні дані не залишають ваш комп'ютер. Convert to Markdown і Copy as Markdown безкоштовні для всіх форматів. Zovo Pro (19 USD один раз) додає три інструменти, Convert a Folder to Markdown, Convert to Markdown with Images і LLM-ready Markdown Chunks, і кожен має 3 безкоштовні спроби.

Як це зробити у VS Code

  1. Встановіть Convert to Markdown з Marketplace або натисніть Ctrl+P (Cmd+P на macOS) і виконайте ext install zovo.zovo-convert-to-markdown.
  2. У Explorer клацніть правою кнопкою файл .pdf, .docx, .pptx, .xlsx, .xls, .ods, .csv, .tsv, .html, .epub, .odt або .rtf і виберіть Convert to Markdown. Можна також клацнути правою кнопкою вкладку відкритого файлу.
  3. Або виконайте "Convert to Markdown: Convert to Markdown" з Command Palette. Команда конвертує файл в активній вкладці або просить вибрати файл.
  4. Markdown відкривається поруч із файлом як незбережений документ. Для великих файлів показано прогрес із кнопкою Cancel.
  5. Збережіть документ. Ім'я name.md поруч із вихідним файлом уже підставлено. Щоб щоразу одразу зберігати файл туди, задайте для toMarkdown.output значення file.
  6. Щоб вставити Markdown деінде, клацніть файл правою кнопкою і виберіть Copy as Markdown. Якщо виділити в Explorer кілька файлів, вони конвертуються один за одним.
  7. Немає файлу під рукою? Виконайте "Convert to Markdown: Convert a sample file" з Command Palette, щоб конвертувати вбудований приклад Word, PDF або PowerPoint.

Що безкоштовно і що додає Zovo Pro

Convert to Markdown і Copy as Markdown безкоштовні для всіх форматів: PDF, Word, PowerPoint, Excel, ODS, CSV, TSV, HTML, EPUB, ODT і RTF. Більше нічого встановлювати не потрібно, ні Python, ні сервер, ні утиліту командного рядка. Жодні дані не залишають ваш комп'ютер.

Convert a Folder to Markdown за один запуск конвертує всі підтримувані файли в папці та її підпапках у файли .md, у нову папку з тією самою структурою або поруч із кожним файлом, із прогресом і кнопкою Cancel. Ви вибираєте, пропускати чи перезаписувати наявні файли .md, а _conversion-report.md показує для кожного файлу, чи його сконвертовано, пропущено, чи конвертація не вдалася. Файли з однаковим ім'ям зберігають свій тип у новому імені (report.pdf.md, report.docx.md), тому жоден не губиться.

Як запустити Convert a Folder to Markdown (Zovo Pro)

  1. Клацніть правою кнопкою папку в Explorer і виберіть "Zovo Pro: Convert a Folder to Markdown" або виконайте "Convert to Markdown: Convert a Folder to Markdown (Pro)" з Command Palette і виберіть папку.
  2. Виберіть, куди зберегти файли .md: "Into a new folder" (ім'я папки із закінченням -markdown, з тими самими підпапками), "Next to each file" або "Pick another folder...".
  3. Якщо деякі файли .md уже існують, виберіть Skip або Overwrite. Сповіщення показує прогрес із кнопкою Cancel.
  4. Наприкінці відкривається _conversion-report.md. У ньому для кожного файлу вказано, чи його сконвертовано, пропущено, чи конвертація не вдалася, і є посилання на кожен новий файл Markdown.

Convert a Folder to Markdown можна запустити на вашому комп’ютері 3 рази безкоштовно, після цього розширення попросить ліцензію. Жодних спливних вікон і жодного зворотного відліку.

Як встановити в Cursor, Windsurf або VSCodium

  1. Відкрийте панель Extensions клавішами Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Знайдіть zovo.zovo-convert-to-markdown і натисніть Install. Cursor, Windsurf і VSCodium встановлюють розширення з Open VSX, де це розширення опубліковано як zovo/zovo-convert-to-markdown.
  3. Якщо у вашому редакторі немає каталогу розширень, завантажте файл .vsix зі сторінки Open VSX і виконайте «Extensions: Install from VSIX...».
  4. Далі все працює так само, як у VS Code.

Що вміє Convert to Markdown

  • PDF із заголовками за розміром шрифту, абзацами, у яких склеєно розірвані рядки й слова з переносами, списками, простими таблицями та двоколонковими сторінками, які читаються колонка за колонкою. Повторювані колонтитули й номери сторінок прибираються.
  • Word (.docx, .docm, .dotx) із заголовками, жирним шрифтом, курсивом, закресленим текстом, посиланнями, вкладеними списками, таблицями, цитатами та виносками.
  • PowerPoint (.pptx, .pptm, .ppsx, .potx) з розділом ## Slide n: title для кожного слайда, пунктами списків із їхніми рівнями, таблицями та нотатками доповідача.
  • Excel та інші таблиці (.xlsx, .xlsm, .xlsb, .xls, .ods) з розділом ## Sheet: name і pipe-таблицею для кожного аркуша. CSV і TSV стають однією таблицею.
  • HTML (.html, .htm, .xhtml), де блоки коду зберігають мову, а скрипти й стилі прибираються, і EPUB, де розділи йдуть у порядку читання.

Чого розширення не робить

  • У сканованих PDF (зображеннях сторінок) немає тексту для конвертації. Розпізнавання тексту (OCR) немає.
  • Таблиці в PDF визначаються за проміжками між колонками. Таблиці без чітких проміжків виводяться як абзаци.
  • Під час безкоштовної конвертації зображення стають заповнювачами на кшталт *[Image: Map of the site]*. Діаграми, SmartArt і відео на слайдах лише названо, а не сконвертовано.
  • Старі файли Word 97-2003 і RTF дають текст і таблиці без форматування. Для файлів, захищених паролем, і старих файлів PowerPoint 97-2003 замість конвертації показується повідомлення.
  • Файли понад 200 МБ не конвертуються (налаштування toMarkdown.maxFileSizeMB), а конвертація PDF зупиняється після 1000 сторінок (налаштування toMarkdown.pdfMaxPages).

Часті запитання

Це безкоштовно?

Convert to Markdown і Copy as Markdown безкоштовні для всіх форматів. Три Pro-інструменти, Convert a Folder to Markdown, Convert to Markdown with Images і LLM-ready Markdown Chunks, мають по 3 безкоштовні спроби. Після цього потрібен Zovo Pro, 19 USD один раз для всіх розширень Zovo.

Розширення вивантажує мої файли?

Ні. Конвертери працюють на вашому комп'ютері, всередині VS Code, без мережевих запитів і без телеметрії.

Чи конвертує воно скановані PDF?

Ні. Сканований PDF містить зображення сторінок, а не текст, а в Convert to Markdown немає OCR.

Чи працює воно в Cursor?

Так. Cursor, Windsurf і VSCodium встановлюють його з Open VSX, де воно опубліковане як zovo/zovo-convert-to-markdown.
