Як відтворити аудіофайли у VS Code

Встановіть безкоштовний Audio Player & WAV Player і клацніть файл .wav, .mp3, .flac, .ogg або .opus. Він відтворює файл і показує хвильову форму для кожного каналу, спектрограму, петлю A-B, швидкість від 0.25x до 2x без зміни висоти тону та значення гучності в LUFS. Opus відтворюється вбудованим декодером, а файли M4A і AAC грають після одного клацання, якщо у вас є ffmpeg. Відтворення й перевірка файлів безкоштовні, а Zovo Pro (19 USD один раз) додає два інструменти, Folder Loudness Report і Normalize Loudness, з 3 безкоштовними запусками кожен.

Як це зробити у VS Code

  1. Встановіть Audio Player & WAV Player з Marketplace або натисніть Ctrl+P (Cmd+P на macOS) і виконайте ext install zovo.audio-preview-vscode.
  2. Клацніть файл .wav, .mp3, .flac, .ogg, .opus або .m4a в Explorer. Якщо відкривається інший плеєр, клацніть файл правою кнопкою й виберіть «Open in Audio Preview».
  3. Пробіл запускає й призупиняє відтворення. Стрілки ліворуч і праворуч переходять на 5 секунд (із Shift на 1 секунду). Клацніть хвильову форму, щоб перейти до потрібного місця.
  4. Протягніть мишею по хвильовій формі, щоб зациклити цю частину, або натисніть [ і ], щоб поставити початок і кінець петлі в поточній позиції. Клавіша L вмикає й вимикає петлю.
  5. Виберіть швидкість від 0.25x до 2x. Висота тону не змінюється.
  6. У заголовку видно кодек, частоту дискретизації, канали, розрядність, тривалість і бітрейт. Панель Loudness показує LUFS, пік і RMS, а панель Tags показує назву, виконавця, альбом та інші теги.

Що безкоштовно і що додає Zovo Pro

Відтворення всіх підтримуваних форматів, хвильова форма, спектрограма, петля A-B, швидкість, панелі Loudness, File і Tags та Copy stats безкоштовні. Розширення нічого не записує назад в аудіофайл і не робить мережевих запитів.

Folder Loudness Report записує в CSV по рядку для кожного аудіофайлу в папці: формат, тривалість, частоту дискретизації, розрядність, назву й виконавця, інтегральну гучність у LUFS, максимуми short-term і momentary, пік семплів, RMS, кількість обрізаних семплів і підсилення, потрібне файлу, щоб досягти -14, -16 і -23 LUFS. Ви сортуєте й перевіряєте папку записів у таблиці й не відкриваєте кожен файл окремо. Файли WAV розширення читає саме, а для рядків MP3, FLAC, Ogg, Opus і M4A потрібен ваш власний ffmpeg.

Як запустити Folder Loudness Report (Zovo Pro)

  1. Клацніть правою кнопкою папку в Explorer і виберіть «Folder Loudness Report (CSV, Pro)» або виконайте «Audio Preview: Folder Loudness Report (CSV, Pro)» з Command Palette і виберіть папку. У плеєрі ця команда є також у меню «...» в заголовку редактора.
  2. Виберіть «This folder and its subfolders» або «This folder only», а потім місце, куди зберегти loudness-report.csv.
  3. Сповіщення показує хід роботи, і роботу можна скасувати. Відкрийте CSV у програмі для електронних таблиць. Запуск зараховується лише тоді, коли файл записано.

Folder Loudness Report можна запустити на вашому комп’ютері 3 рази безкоштовно, після цього розширення попросить ліцензію. Жодних спливних вікон і жодного зворотного відліку.

Як встановити в Cursor, Windsurf або VSCodium

  1. Відкрийте панель Extensions клавішами Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Знайдіть zovo.audio-preview-vscode і натисніть Install. Cursor, Windsurf і VSCodium встановлюють розширення з Open VSX, де це розширення опубліковано як zovo/audio-preview-vscode.
  3. Якщо у вашому редакторі немає каталогу розширень, завантажте файл .vsix зі сторінки Open VSX і виконайте «Extensions: Install from VSIX...».
  4. Далі все працює так само, як у VS Code.

Що вміє Audio Player & WAV Player

  • WAV (PCM від 8 до 32 біт, float, A-law, mu-law, RF64), який читається частинами по 2 МБ, тож великий файл не підвішує редактор.
  • MP3, FLAC і Ogg Vorbis через декодер, який уже є у VS Code.
  • Opus у файлах .opus або .ogg через вбудований декодер libopus (WebAssembly).
  • До 8 каналів, кожен на окремій доріжці хвильової форми.
  • Теги ID3v1 та ID3v2 версій від 2.2 до 2.4, RIFF INFO, коментарі Vorbis і атоми iTunes.

Чого розширення не робить

  • Для M4A і AAC потрібен ваш власний ffmpeg. Без нього ви бачите кодек, тривалість, бітрейт, теги й повідомлення.
  • ALAC, AC-3 та інші кодеки, які VS Code не декодує, теж потребують кнопки ffmpeg.
  • Стиснені файли декодуються повністю. Якщо декодовані семпли займають понад 600 МБ (приблизно 28 хвилин стерео 44,1 кГц), файл лише відтворюється (налаштування audioPreview.maxDecodedMB).
  • Пік тут вибірковий (sample peak), а не true peak з передискретизацією, і діапазону гучності (LRA) немає.
  • Розширення відтворює й перевіряє файли. Воно не вирізає й не редагує їх.

Часті запитання

Це безкоштовно?

Відтворення, хвильова форма, спектрограма, петля та значення гучності безкоштовні. Два Pro-інструменти, Folder Loudness Report і Normalize Loudness, мають по 3 безкоштовні запуски. Після цього потрібен Zovo Pro, 19 USD один раз для всіх розширень Zovo.

Чому мій файл .opus не відтворюється у VS Code?

VS Code постачається з Chromium без декодера Opus. Це розширення містить libopus, скомпільований у WebAssembly, тож Opus відтворюється без додаткових встановлень.

Чому M4A показує повідомлення замість відтворення?

У VS Code немає й декодера AAC. Якщо встановлено ffmpeg, кнопка Decode with ffmpeg створює копію у форматі WAV у папці сховища розширення, і файл відтворюється. Розширення не містить ffmpeg і нічого не завантажує.

Чи працює це в Cursor?

Так. Розширення є на Open VSX як zovo/audio-preview-vscode, тож його можна встановити в Cursor, Windsurf і VSCodium.
