Як запустити файл C++ у VS Code одним клацанням

Встановіть безкоштовне розширення Run C++ and C Code, відкрийте файл .cpp або .c і натисніть Run у заголовку редактора або Ctrl+Alt+Enter (Cmd+Alt+Enter на Mac). Воно компілює файл компілятором gcc, g++, clang або clang++, який уже є на вашому комп’ютері, і запускає програму в терміналі, де працюють cin і scanf. Помилки компілятора потрапляють на панель Problems у правильний рядок, а панель Input & Tests, стрес-тест і бенчмарк безкоштовні. Zovo Pro (19 USD один раз) додає перевірку санітайзерами, порівняння -O0, -O2 і -O3 та звіт про тести, з 3 безкоштовними запусками кожен.

Як це зробити у VS Code

  1. Встановіть Run C++ and C Code з Marketplace або натисніть Ctrl+P (Cmd+P на macOS) і виконайте ext install zovo.zovo-run-cpp.
  2. Переконайтеся, що компілятор встановлено. «Run C++: Pick Compiler (gcc, g++, clang, clang++)» показує, які компілятори знайдено. Якщо жодного немає, сторінка налаштування покаже офіційні кроки для вашої системи (Xcode Command Line Tools, MSYS2 або WinLibs чи менеджер пакетів вашого Linux).
  3. Відкрийте файл .cpp, .cc, .cxx або .c і натисніть кнопку Run у заголовку редактора або Ctrl+Alt+Enter (Cmd+Alt+Enter на Mac).
  4. Програма запускається в терміналі з назвою «Run: file.cpp». Вводьте дані для неї там. Наприкінці ви побачите код виходу, час роботи й пікову пам’ять. Поки програма працює, кнопка Run стає кнопкою Stop.
  5. Для прапорців чи аргументів додайте // run: -O2 -lm і // args: "Hello World" 3 у перші 40 рядків файлу. Для C++ за замовчуванням використовуються -std=c++20 -Wall -Wextra -g -O0.
  6. Щоб тестувати на збережених вхідних даних, виконайте «Run C++: Run with Input & Test Cases». Вставте вхідні дані, натисніть Run with input, а потім Save as test case. Run all tests показує, які тести пройдено, а які ні, з порівнянням по рядках (diff).

Що безкоштовно і що додає Zovo Pro

Run, Build Only, Run Last Build, Debug, збірка папки, панель Input & Tests, стрес-тест і бенчмарк безкоштовні. Розширення не потребує входу, не робить мережевих запитів і не має телеметрії.

Програма, яка проходить ваші тести, все одно може читати за межами масиву чи переповнювати int. Sanitizer check збирає другу копію з AddressSanitizer і UndefinedBehaviorSanitizer (-fsanitize=address,undefined), запускає її на вхідних даних панелі й на кожному збереженому тесті та показує на панелі Problems кожне переповнення купи чи стека, use after free, знакове переповнення чи іншу невизначену поведінку в її рядку. Ви знаходите помилку в її рядку й не налаштовуєте прапорці санітайзерів вручну.

Як запустити Sanitizer check (Zovo Pro)

  1. Введіть дані на панелі Input & Tests і збережіть тести, якщо вони у вас є. Перевірка запускається на вхідних даних панелі та на кожному збереженому тесті.
  2. Натисніть «Sanitizer check (Pro)» на панелі в розділі «Stress test, benchmark and more» або виконайте «Run C++: Sanitizer Check: AddressSanitizer and UBSan on the Input and Test Cases (Zovo Pro)» з Command Palette.

Як встановити в Cursor, Windsurf або VSCodium

  1. Відкрийте панель Extensions клавішами Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Знайдіть zovo.zovo-run-cpp і натисніть Install. Cursor, Windsurf і VSCodium встановлюють розширення з Open VSX, де це розширення опубліковано як zovo/zovo-run-cpp.
  3. Якщо у вашому редакторі немає каталогу розширень, завантажте файл .vsix зі сторінки Open VSX і виконайте «Extensions: Install from VSIX...».
  4. Далі все працює так само, як у VS Code.

Що вміє Run C++ and C Code

  • Файли C і C++ (.c, .cpp, .cc, .cxx) з gcc, g++, clang і clang++.
  • MSYS2, WinLibs, MinGW, TDM-GCC і LLVM у їхніх звичних папках Windows, а також назви Homebrew, як-от g++-14.
  • Шляхи з пробілами, & або не-ASCII літерами, бо жодна оболонка їх не розбирає.
  • Програми, які друкують мільйон рядків. Панель показує перші 2000 і рахує решту.

Чого розширення не робить

  • Розширенню потрібен компілятор на вашому комп’ютері, і воно ніколи його не завантажує.
  • Запуски на панелі Input і тести зупиняються через 10 секунд (налаштування zovoRun.timeLimitSeconds).
  • Вивід понад 32 МБ лише рахується, але не зберігається (налаштування zovoRun.maxCapturedOutputMB).
  • Для перевірки санітайзерами потрібен компілятор із runtime санітайзерів. У MinGW gcc у Windows його немає, тож там використовуйте clang з LLVM. Перевірка повідомить про це й не витратить запуск.
  • Для Debug потрібне встановлене розширення CodeLLDB або C/C++.

Часті запитання

Це безкоштовно?

Run, Build Only, Debug, збірка папки, панель Input & Tests, стрес-тест і бенчмарк безкоштовні. Три Pro-інструменти, Sanitizer check, Compare -O0, -O2 and -O3 і Test report, мають по 3 безкоштовні запуски. Після цього потрібен Zovo Pro, 19 USD один раз для всіх розширень Zovo.

Чи може моя програма читати введення через cin?

Так. Вона працює в справжньому терміналі, тож cin і scanf чекають на те, що ви введете, а запрошення без символу нового рядка показуються першими.

Чи змінює воно мої settings.json або tasks.json?

Ні. Розширення ніколи не записує ваші файли налаштувань. Debug додає один запис у .vscode/launch.json, і лише тоді, коли ви натискаєте Debug.

Чи працює це в Cursor?

Так. Розширення є на Open VSX, тож його можна встановити в Cursor, Windsurf і VSCodium.
