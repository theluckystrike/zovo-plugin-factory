Як відформатувати HTML і CSS у VS Code, не зламавши блоки pre та inline-теги

Встановіть безкоштовне розширення HTML Formatter & CSS Formatter і натисніть Shift+Alt+F у файлі HTML, CSS, SCSS або LESS. Воно також форматує блоки <style> і <script> усередині сторінки, дотримується вашого .editorconfig, залишає <pre>, <textarea> та inline-теги такими, як ви їх написали, і ніколи не змінює порядок атрибутів. Розширення працює офлайн із вбудованим js-beautify, тому Node, npm і файл конфігурації не потрібні. Zovo Pro (19 USD один раз) додає три інструменти: Format Folder with Diff Preview, Minify HTML and CSS і HTML Lint Report. Кожен має 3 безкоштовні спроби.

Як це зробити у VS Code

  1. Встановіть HTML Formatter & CSS Formatter з Marketplace або натисніть Ctrl+P (Cmd+P на macOS) і виконайте ext install zovo.zovo-html-formatter.
  2. Відкрийте файл HTML, CSS, SCSS або LESS і натисніть Shift+Alt+F (Shift+Option+F у macOS). Якщо VS Code запитає, який форматувальник використати, виберіть HTML Formatter & CSS Formatter.
  3. Щоб за один крок зробити його типовим форматувальником для всіх чотирьох мов, виконайте «HTML Formatter: Use as Default Formatter for HTML, CSS, SCSS and LESS» у Command Palette.
  4. Виділіть кілька рядків і виконайте Format Selection, щоб відформатувати лише їх.
  5. Щоб форматувати під час кожного збереження, увімкніть zovoHtmlFormat.formatOnSave або використовуйте власний editor.formatOnSave VS Code, коли розширення вже стало типовим форматувальником.
  6. Відступи беруться з редактора, потім із .editorconfig (стиль і розмір відступу, кінець рядка, порожній рядок у кінці файлу, максимальна довжина рядка), тому вся команда отримує однаковий результат.

Що безкоштовно і що додає Zovo Pro

Format Document, Format Selection і форматування під час збереження для HTML, CSS, SCSS і LESS з підтримкою .editorconfig безкоштовні, без входу в обліковий запис, без мережевих запитів і без телеметрії.

Коли весь сайт треба привести до одного стилю, Format Folder with Diff Preview форматує в пам’яті кожен файл HTML, CSS, SCSS і LESS у теці, показує змінені файли з diff поруч для кожного й записує лише ті файли, які ви залишили позначеними. Ви бачите кожну зміну, перш ніж файл буде записано.

Як запустити Format Folder with Diff Preview (Zovo Pro)

  1. Клацніть правою кнопкою на теці в Explorer і виберіть «Zovo Pro: Format folder with diff preview» або виконайте «HTML Formatter: Format Folder with Diff Preview (Pro)» у Command Palette.
  2. Перегляньте змінені файли. Відкрийте diff будь-якого файлу й зніміть позначку з файлів, які треба залишити як є.
  3. Запишіть позначені файли. Спроба зараховується, лише якщо інструмент дав результат.

Format Folder with Diff Preview можна запустити на вашому комп’ютері 3 рази безкоштовно, після цього розширення попросить ліцензію. Жодних спливних вікон і жодного зворотного відліку.

Як встановити в Cursor, Windsurf або VSCodium

  1. Відкрийте панель Extensions клавішами Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Знайдіть zovo.zovo-html-formatter і натисніть Install. Cursor, Windsurf і VSCodium встановлюють розширення з Open VSX, де це розширення опубліковано як zovo/zovo-html-formatter.
  3. Якщо у вашому редакторі немає каталогу розширень, завантажте файл .vsix зі сторінки Open VSX і виконайте «Extensions: Install from VSIX...».
  4. Далі все працює так само, як у VS Code.

Що вміє HTML Formatter & CSS Formatter

  • CSS у <style> і JavaScript у <script> усередині HTML.
  • Залишаються такими, як написано: вміст <pre> і <textarea>, inline-теги на своєму рядку, порядок атрибутів, порожні рядки між блоками (не більше одного поспіль), стиль відступів head і body сторінки та шаблонні теги на кшталт {{ }} і {% %}.
  • У SCSS і LESS багаторядкові map і виклики функцій зберігають своє розташування, а коментарі в кінці рядка залишаються на своєму рядку.
  • Ще два інструменти Pro. Minify HTML and CSS записує копії .min.html і .min.css зі звітом про заощаджені байти й байти після gzip. HTML Lint Report знаходить зображення без alt-тексту, поля форм без label, повторювані id, пропущені рівні заголовків та інші проблеми й показує їх у звіті Markdown і в панелі Problems.

Чого розширення не робить

  • Окремі файли .js, .jsx, .ts, Vue і Svelte це розширення не форматує. Форматується лише JavaScript усередині <script>.
  • Рядки не переносяться, доки ви не задасте довжину переносу, тож дуже довгий рядок так і лишається довгим.
  • SCSS і LESS обробляє форматувальник CSS. Незвичний синтаксис, наприклад detached rulesets у LESS, може зберегти початкові пробіли.
  • Мініфікація не скорочує JavaScript, не перейменовує й не об’єднує правила CSS.

Чи форматує VS Code HTML без розширення?

Так. У VS Code є вбудований форматувальник HTML і CSS. Це розширення читає .editorconfig, зберігає власні відступи head і body сторінки, зберігає розташування map у SCSS і LESS та додає інструменти Pro для тек, мініфікації й перевірки.
