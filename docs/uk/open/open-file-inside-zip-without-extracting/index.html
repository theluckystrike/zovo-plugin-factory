Як відкрити файл усередині ZIP без розпакування

Встановіть безкоштовний ZIP Viewer & Archive Explorer і клацніть файл .zip, .jar, .vsix, .tar, .tar.gz або .gz. Він показує папки й файли всередині, а подвійне клацання відкриває файл у звичайній вкладці лише для читання. Файл читається прямо з архіву, тож нічого не розпаковується. Перегляд, відкриття записів, пошук за назвою й витягування файлів безкоштовні. Zovo Pro (19 USD один раз) додає три інструменти, порівняння двох архівів, експорт списку записів і пошук файлу в усіх архівах папки, з 3 безкоштовними запусками кожен.

Як це зробити у VS Code

  1. Встановіть ZIP Viewer & Archive Explorer з Marketplace або натисніть Ctrl+P (Cmd+P на macOS) і виконайте ext install zovo.zip-archive-explorer.
  2. Клацніть файл .zip, .jar, .vsix, .tar, .tar.gz, .tgz або .gz в Explorer. Він відкривається як список папок і файлів з розміром, стисненим розміром, коефіцієнтом стиснення й датою. Для .war, .whl, .nupkg, .apk або .epub клацніть правою кнопкою й виберіть Open in Archive Explorer.
  3. Знайдіть файл. Двічі клацніть папку, скористайтеся рядком шляху вгорі або натисніть Backspace, щоб піднятися на рівень вище. Або введіть текст у поле пошуку. * і ? працюють як шаблони, наприклад *.json.
  4. Двічі клацніть файл або натисніть Enter. Він відкривається лише для читання у звичайній вкладці. Код отримує підсвічування синтаксису, зображення відкриваються в перегляді зображень, а ZIP усередині ZIP відкривається як ще один архів.
  5. Розділ Archive Explorer на бічній панелі Explorer показує всі архіви, які ви відкривали. Клацніть запис там правою кнопкою, щоб вибрати Open to the Side, Extract... або Copy Path.
  6. Щоб змінити файл, виберіть його й натисніть Extract... (один файл зберігається через діалог збереження). Назви з .. або абсолютним шляхом ніколи не записуються, а сам архів ніколи не змінюється.

Що безкоштовно і що додає Zovo Pro

Перегляд архівів, відкриття записів у вкладках, пошук за назвою, дерево на бічній панелі, Copy Path і витягування файлів безкоштовні. Розширення працює офлайн, без мережевих запитів і без телеметрії.

Коли ви знаєте назву файлу, але не знаєте, в якому архіві збірки, резервної копії чи релізу він лежить, відкривати кожен архів задовго. Find a file in all archives of a folder шукає за назвами записів у кожному файлі ZIP, JAR, WAR, VSIX, TAR і GZ у папці, показує кожен збіг з архівом і шляхом і відкриває вибраний у вкладці лише для читання. Інструмент не записує жодних файлів.

Як запустити Find a file in all archives of a folder (Zovo Pro)

  1. Виконайте «Archive Explorer: Find a File in All Archives of a Folder... (Pro)» з Command Palette і виберіть папку для пошуку або клацніть папку правою кнопкою в Explorer і виберіть «Zovo Pro: Find a file in all archives of a folder».
  2. Введіть назву файлу. * і ? працюють як шаблони, наприклад log4j*.jar або *.properties.
  3. Виберіть збіг у списку. Він відкриється лише для читання у вкладці, як будь-який запис. Запуск зараховується лише тоді, коли є хоча б один збіг.

Find a file in all archives of a folder можна запустити на вашому комп’ютері 3 рази безкоштовно, після цього розширення попросить ліцензію. Жодних спливних вікон і жодного зворотного відліку.

Як встановити в Cursor, Windsurf або VSCodium

  1. Відкрийте панель Extensions клавішами Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Знайдіть zovo.zip-archive-explorer і натисніть Install. Cursor, Windsurf і VSCodium встановлюють розширення з Open VSX, де це розширення опубліковано як zovo/zip-archive-explorer.
  3. Якщо у вашому редакторі немає каталогу розширень, завантажте файл .vsix зі сторінки Open VSX і виконайте «Extensions: Install from VSIX...».
  4. Далі все працює так само, як у VS Code.

Що вміє ZIP Viewer & Archive Explorer

  • ZIP, JAR і VSIX із записами Stored і Deflate, ZIP64 і саморозпакувальні архіви.
  • TAR (ustar, довгі назви GNU і заголовки pax), TAR.GZ, TGZ і окремі файли GZ.
  • WAR, EAR, WHL, NUPKG, APK, AAR, XPI і EPUB через Open in Archive Explorer.
  • Архіви до 200 000 записів, які читаються з диска частинами, тож великий ZIP не завантажується цілком.

Чого розширення не робить

  • Записи, стиснені BZIP2, LZMA, Zstandard або Deflate64, і зашифровані записи показано в списку, але вони не відкриваються.
  • Файли 7z, RAR, XZ і BZ2 не підтримуються.
  • Записи доступні лише для читання. Щоб змінити файл, витягніть його.
  • Записи понад 512 МБ не відкриваються у вкладці, але їх можна витягти. Файл .tar.gz розпаковується в пам’яті, за замовчуванням до 2 ГБ.

Часті запитання

Це безкоштовно?

Перегляд архівів, відкриття записів, пошук за назвою, дерево на бічній панелі й витягування файлів безкоштовні. Три Pro-інструменти, Compare two archives, Export the entry list і Find a file in all archives of a folder, мають по 3 безкоштовні запуски. Після цього потрібен Zovo Pro, 19 USD один раз для всіх розширень Zovo.

Чи копіюється файл у тимчасову папку, коли я його відкриваю?

Ні. Запис читається з архіву у вкладку лише для читання. Файли на диск записує тільки Extract.

Чи можна редагувати файл усередині ZIP?

Ні. Записи доступні лише для читання, і архів ніколи не змінюється. Витягніть файл, відредагуйте його й запакуйте архів знову іншим інструментом.

Чи працює це в Cursor?

Так. ZIP Viewer & Archive Explorer є на Open VSX, тож його можна встановити в Cursor, Windsurf і VSCodium.
