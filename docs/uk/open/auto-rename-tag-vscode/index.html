Автоматичне перейменування тегів HTML, JSX і Vue у VS Code

Встановіть безкоштовне розширення Auto Rename Tag & Close Tag Sync і змініть назву у відкривному або закривному тезі. Парний тег змінюється під час введення. Перейменування виконує вбудований у VS Code механізм linked editing (editor.linkedEditing). Розширення вмикає це налаштування для своїх мов і знаходить парний тег у HTML, JSX, TSX, Vue, Svelte, Astro, PHP, Blade, Twig, XML, Markdown та інших, тож одна дія скасування повертає обидва теги. Перейменування, автозакриття й рамка навколо парного тега безкоштовні, а Zovo Pro (19 USD один раз) додає Rename Tag in All Files і Check Unclosed Tags in All Files, з 3 безкоштовними запусками для кожного інструмента.

Як це зробити у VS Code

  1. Встановіть Tag Auto Rename & Close Tag Sync з Marketplace або натисніть Ctrl+P (Cmd+P на macOS) і виконайте ext install zovo.zovo-auto-rename-tag.
  2. Відкрийте файл HTML, JSX, TSX, Vue, Svelte, PHP або інший шаблон і змініть назву у відкривному тезі. Закривний тег змінюється під час введення, і навпаки.
  3. Наберіть > після відкривного тега, і закривний тег з’явиться після курсора. Наберіть </, і назва відкритого елемента допишеться сама.
  4. Поставте курсор на тег, і обидва теги отримають рамку в кольорах дужок вашої теми.
  5. Клацніть правою кнопкою в редакторі, щоб вибрати «Go to Matching Tag» або «Select Tag Content». Щоб ввести нову назву в полі, виконайте «Tag Sync: Rename Tag Pair…» з Command Palette.
  6. Клацніть елемент Tags у рядку стану, щоб побачити, що ввімкнено для цього файлу, або вимкнути розширення для однієї мови. Якщо там написано «Tags: rename off», клацніть його, щоб увімкнути перейменування для цієї мови.

Що безкоштовно і що додає Zovo Pro

Перейменування під час введення, автозакриття після > і </, рамка навколо парного тега, Go to Matching Tag, Select Tag Content, Rename Tag Pair… і меню в рядку стану безкоштовні. Розширення не показує реклами, не потребує входу й працює офлайн.

Інструмент перейменовує компонент чи елемент одразу в усіх файлах з тегами в робочій області, наприклад <Button> на <UiButton> в усіх файлах .tsx, .vue, .html і шаблонах. Змінюються лише назви тегів, ніколи текст, атрибути, рядки чи коментарі. Спершу ви бачите кількість змін, «Preview first» відкриває попередній перегляд рефакторингу VS Code, а одна дія Undo повертає всі файли.

Як запустити Rename Tag in All Files (Zovo Pro)

  1. Відкрийте папку проєкту у VS Code. Без відкритої папки інструмент не працює.
  2. Виконайте «Tag Sync: Rename Tag in All Files… (Pro)» з Command Palette або клацніть правою кнопкою файл .html, .htm, .vue, .jsx, .tsx чи .svelte в Explorer і виберіть «Zovo Pro: Rename Tag in All Files».
  3. Введіть тег, який треба перейменувати, так, як він записаний у файлах (наприклад, Button), а потім нову назву.
  4. Виберіть «Rename» або «Preview first», щоб перевірити зміни в попередньому перегляді рефакторингу. Файли, які не були відкриті, змінюються, але не зберігаються. File > Save All зберігає їх, а Undo повертає все назад.

Rename Tag in All Files можна запустити на вашому комп’ютері 3 рази безкоштовно, після цього розширення попросить ліцензію. Жодних спливних вікон і жодного зворотного відліку.

Як встановити в Cursor, Windsurf або VSCodium

  1. Відкрийте панель Extensions клавішами Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Знайдіть zovo.zovo-auto-rename-tag і натисніть Install. Cursor, Windsurf і VSCodium встановлюють розширення з Open VSX, де це розширення опубліковано як zovo/zovo-auto-rename-tag.
  3. Якщо у вашому редакторі немає каталогу розширень, завантажте файл .vsix зі сторінки Open VSX і виконайте «Extensions: Install from VSIX...».
  4. Далі все працює так само, як у VS Code.

Що вміє Tag Auto Rename & Close Tag Sync

  • Перейменування в HTML, JSX і TSX, Vue, Svelte, Astro, PHP, Blade, Twig, Jinja, Nunjucks, Liquid, ERB, EJS, Handlebars, XML, SVG і Markdown.
  • Порожні (void) теги, як-от br, img, input, meta і hr, ніколи не отримують пари й не закриваються.
  • У .tsx тегом вважається лише справжній JSX. Порівняння на зразок a < b && c > d і generics на зразок useState<string>() залишаються без змін, а файли .ts розширення не чіпає.
  • Коментарі, рядки, вміст <script> і <style> та блоки {{ }}, {% %}, <?php ?> і <% %> пропускаються.
  • Нові незбережені файли працюють, щойно для них вибрано мову.

Чого розширення не робить

  • У JSX і TSX теги закриває сам TypeScript, тому там розширення залишає закриття йому. Закривний тег від TypeScript є окремим кроком скасування.
  • Якщо встановлено розширення Vue, Svelte, Astro або Red Hat XML, теги в його мові закриває воно, а це розширення не втручається.
  • Файли понад 1 МБ або 50 000 рядків не отримують живого перейменування, закриття й підсвічування (налаштування zovoTags.maxFileSizeKB і zovoTags.maxFileLines). Рядок стану про це повідомляє, а команди працюють і далі.
  • Теги всередині виразів {...} у Svelte чи Astro не перейменовуються.
  • Якщо водночас увімкнено старіше розширення Auto Rename Tag чи Auto Close Tag, обидва можуть редагувати той самий тег. Залиште одне з них.

Часті запитання

Чим це відрізняється від налаштування editor.linkedEditing?

Розширення використовує editor.linkedEditing для перейменування. Воно вмикає це налаштування для кожної підтримуваної мови й знаходить у кожній із них парний тег, від HTML і Vue до PHP, Twig, XML і JSX. Крім того, воно закриває теги, малює рамку навколо парного тега й додає Go to Matching Tag і Select Tag Content. Якщо ви самі вимкнули editor.linkedEditing, рядок стану показує «Tags: rename off», і одне клацання вмикає його для цієї мови.

Чи працює скасування?

Так. Ваша правка й зміна парного тега скасовуються одним кроком, бо перейменування використовує linked editing VS Code. Закривний тег від автозакриття входить у той самий крок скасування, що й набраний вами >, окрім JSX і TSX, де теги закриває TypeScript.

Це безкоштовно?

Так. Перейменування, автозакриття, рамка навколо парного тега й команди редактора безкоштовні. Rename Tag in All Files і Check Unclosed Tags in All Files є інструментами Zovo Pro з 3 безкоштовними запусками кожен, а далі 19 USD один раз для всіх розширень Zovo.

Чи працює це в Cursor?
