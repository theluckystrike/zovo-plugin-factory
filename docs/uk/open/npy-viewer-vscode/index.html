Як переглянути файли NumPy .npy і .npz у VS Code

Встановіть безкоштовний Tensor Viewer (NPZ Viewer & NPY Viewer) і клацніть файл .npy або .npz. Кожен масив показано з назвою, dtype і формою, а клацання по ньому показує min, max, mean, std, кількість NaN, графік, гістограму й самі значення, без Python. Перегляд, зображення, таблиця Values і Save as .npy або CSV безкоштовні. Zovo Pro (19 USD один раз) додає два інструменти, Compare two checkpoints і Scan all tensors, і кожен має 3 безкоштовні запуски.

Як це зробити у VS Code

  1. Встановіть Tensor Viewer з Marketplace або натисніть Ctrl+P (Cmd+P на macOS) і виконайте ext install zovo.tensor-viewer.
  2. Клацніть файл .npy або .npz в Explorer. Таблиця показує кожен масив із назвою, типом, формою, кількістю параметрів і розміром.
  3. Клацніть масив. Права панель показує min, max, mean, std і кількість значень NaN, Inf і нулів, далі теплову карту для двовимірного масиву або лінійний графік для одновимірного, а також гістограму.
  4. Перегляньте числа в таблиці Values, по 32 рядки за раз. Для масивів із 3 і більше вимірами введіть зріз, як-от [5, :, :], у поле Slice.
  5. Якщо масив має форму зображення, як-от (H, W, 3) або (N, 3, H, W), розділ Image малює його. Там же виберіть Layout, Frame і Range. Для матриць із числами з рухомою комою замість цього є кнопка «Show as image».
  6. Натисніть «Save as .npy...» або «Save as CSV...», щоб записати масив або зріз у новий файл.

Що безкоштовно і що додає Zovo Pro

Усі формати, статистика, теплові карти, лінійні графіки, гістограми, зображення, таблиця Values, зрізи, сирі масиви (raw arrays) і Save as .npy або CSV безкоштовні. Python не потрібен, і переглядач не робить мережевих запитів.

Scan all tensors читає кожне значення кожного масиву у файлі, а не вибірку, і позначає NaN, Inf, масиви з самих нулів, сталі масиви та значення з рухомою комою від 10 000 і більше. Він показує точні min, max, mean, std і норму L2 кожного масиву в одному звіті, який можна відфільтрувати й зберегти як CSV, Markdown або JSON. Ви знаходите пошкоджений масив у великому .npz, не переглядаючи кожен по черзі.

  1. Відкрийте файл і натисніть кнопку «Scan all tensors» угорі переглядача або клацніть файл правою кнопкою в Explorer і виберіть «Zovo Pro: Scan Tensors for NaN, Inf and Zeros».

Як встановити в Cursor, Windsurf або VSCodium

  1. Відкрийте панель Extensions клавішами Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Знайдіть zovo.tensor-viewer і натисніть Install. Cursor, Windsurf і VSCodium встановлюють розширення з Open VSX, де це розширення опубліковано як zovo/tensor-viewer.
  3. Якщо у вашому редакторі немає каталогу розширень, завантажте файл .vsix зі сторінки Open VSX і виконайте «Extensions: Install from VSIX...».
  4. Далі все працює так само, як у VS Code.

Що вміє Tensor Viewer

  • Файли .npy із заголовком версій v1, v2 і v3, у порядку C і Fortran, з будь-яким порядком байтів.
  • Архіви .npz з нестисненими й стисненими (deflate) записами, зокрема zip64.
  • bool, від int8 до int64, від uint8 до uint64, float16, float32, float64 і комплексні числа (статистика за модулем).
  • Масиви у формі зображень, стеки й пакети (batches) малюються як зображення, по одному кадру.
  • Те саме розширення відкриває також файли .safetensors, .gguf і PyTorch .pt, .pth і .ckpt.

Чого розширення не робить

  • Масиви об’єктів, збережені через pickle, видно в списку, але переглядач відмовляється їх відкривати й ніколи їх не виконує. Текстові та структуровані масиви показано без статистики.
  • Для масивів понад 2 000 000 значень статистику й графіки рахують за вибіркою (налаштування tensorViewer.sampleValues). Панель повідомляє, коли статистика взята з вибірки.
  • Стиснені записи .npz читаються лише з початку. Значення після перших 64 МБ запису не показуються, а записи понад 512 МБ не можна зберегти.
  • Зображення малюються не більше ніж 512 пікселів за довшою стороною. Для двоканальних масивів і масивів у порядку Fortran вигляду зображення немає.
  • Експорт у CSV зупиняється на 20 мільйонах значень. Значення int64 понад 2^53 втрачають останні цифри в таблиці та в CSV.

Часті запитання

Це безкоштовно?

Відкриття файлів .npy і .npz, статистика, графіки, зображення, таблиця Values і Save as .npy або CSV безкоштовні. Два Pro-інструменти, Compare two checkpoints і Scan all tensors, мають по 3 безкоштовні запуски. Після цього потрібен Zovo Pro, 19 USD один раз для всіх розширень Zovo.

Чи потрібен Python?

Ні. Tensor Viewer сам читає файли, тож Python і NumPy встановлювати не треба.

Чи безпечно відкривати файл .npy з інтернету?

Ніщо з файлу ніколи не виконується. Масиви об’єктів, які NumPy зберігає як pickle, видно в списку, але переглядач відмовляється їх відкривати. Показаний файл переглядач ніколи не змінює.

Чи працює це в Cursor?

Так. Tensor Viewer є на Open VSX як zovo/tensor-viewer, тож його можна встановити в Cursor, Windsurf і VSCodium.
