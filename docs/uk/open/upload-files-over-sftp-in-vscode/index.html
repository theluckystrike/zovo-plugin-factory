Як завантажувати файли на сервер через SFTP або FTP з VS Code

Встановіть безкоштовне розширення SFTP & FTP Sync and Upload і створіть .vscode/sftp.json з хостом, користувачем і папкою на сервері. Після цього кожен файл завантажується на сервер, коли ви його зберігаєте, через SFTP, FTP або FTPS. Клацніть правою кнопкою файл або папку, щоб завантажити на сервер, завантажити із сервера або порівняти з копією на сервері, а файли сервера відкривайте у звичайній вкладці з подання Remote Files. Ваша папка .vscode, файли .env і приватні ключі ніколи не завантажуються на сервер. Усе це безкоштовно, без облікового запису. Zovo Pro (19 USD один раз) додає три інструменти, Sync Folder with Remote, Roll Back a Remote File і Server Profiles and Jump Host, і кожен має 3 безкоштовні спроби.

Як це зробити у VS Code

  1. Встановіть SFTP & FTP Sync and Upload з Marketplace або натисніть Ctrl+P (Cmd+P на macOS) і виконайте ext install zovo.zovo-sftp.
  2. Виконайте "SFTP: Create sftp.json Config" з Command Palette або натисніть Create sftp.json у поданні SFTP Remote.
  3. Заповніть protocol (sftp, ftp або ftps), host, username, privateKeyPath (пропустіть, щоб використовувати пароль) і remotePath, папку на сервері, що відповідає вашій локальній папці. Наведіть курсор на будь-який ключ, щоб побачити довідку.
  4. Задайте "uploadOnSave": true. Відтепер кожен збережений файл завантажується на сервер. Пароль, який ви вводите, запитується один раз і зберігається в секретному сховищі редактора, ніколи не в sftp.json.
  5. Клацніть правою кнопкою будь-який файл або папку в Explorer чи вкладку й виберіть Upload, Download або Compare with Server Copy (Compare працює для файлів).
  6. Відкрийте подання Remote Files, щоб переглядати сервер. Відкрийте файл у звичайній вкладці редактора й збережіть його назад, завантажте його, скопіюйте його шлях або видаліть його. "SFTP: Show Transfer Log" показує кожне з'єднання й кожну передачу.

Що безкоштовно і що додає Zovo Pro

Завантаження під час збереження, Upload, Download і Compare with Server Copy, подання Remote Files, SFTP, FTP і FTPS, перевірка ключа хоста й журнал передач безкоштовні, без облікового запису й без входу будь-куди, крім вашого власного сервера. Телеметрії немає.

Коли сервер і ваша локальна папка розійшлися, Sync Folder with Remote порівнює їх і перелічує кожну відмінність, перш ніж щось буде передано: файли лише тут, лише на сервері або новіші з одного боку. Для кожного файлу ви вибираєте завантаження на сервер, завантаження із сервера, видалення або пропуск, відкриваєте порівняння поруч, зберігаєте dry run як текст, а потім застосовуєте. Ви точно бачите, що зміниться на сервері, ще до того, як це зміниться.

Як запустити Sync Folder with Remote (Zovo Pro)

  1. Клацніть правою кнопкою папку в Explorer і виберіть "Zovo Pro: Sync folder with remote (diff preview)" або виконайте "SFTP: Sync Folder with Remote, Diff Preview (Pro)..." з Command Palette. Подання Remote Files має таку саму кнопку у своєму заголовку.
  2. Прочитайте план. Для кожного файлу виберіть завантаження на сервер, завантаження із сервера, видалення або пропуск і відкрийте порівняння для будь-якого файлу, в якому ви не впевнені.
  3. Застосуйте план. Спроба зараховується, лише коли було показано план синхронізації. Escape або Cancel ніколи не витрачають спробу.

Як встановити в Cursor, Windsurf або VSCodium

  1. Відкрийте панель Extensions клавішами Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Знайдіть zovo.zovo-sftp і натисніть Install. Cursor, Windsurf і VSCodium встановлюють розширення з Open VSX, де це розширення опубліковано як zovo/zovo-sftp.
  3. Якщо у вашому редакторі немає каталогу розширень, завантажте файл .vsix зі сторінки Open VSX і виконайте «Extensions: Install from VSIX...».
  4. Далі все працює так само, як у VS Code.

Що вміє SFTP & FTP Sync and Upload

  • SFTP із ключами SSH, зашифрованими ключами, агентом SSH або паролем, FTP, FTPS з явним або неявним TLS.
  • .vscode, .git, файли .env, приватні ключі, .npmrc та інші секретні файли ніколи не завантажуються на сервер. Власні шаблони додайте в ignore у стилі .gitignore.
  • Ключ хоста сервера перевіряється: закріпіть його через hostFingerprint або підтвердьте під час першого з'єднання. Змінений ключ зупиняє з'єднання.
  • У папці, якій ви не довіряєте (Restricted Mode), розширення вимкнене, тож завантажений проєкт не може нікуди надіслати ваші файли.
  • Інші два Pro-інструменти: Roll Back a Remote File зберігає на вашому комп'ютері 10 останніх серверних копій файлу, перш ніж завантаження їх перезапише, а Server Profiles and Jump Host вміщує кілька серверів (staging, production) в один sftp.json і з'єднується через проміжний хост SSH (jump host).

Чого розширення не робить

  • Одне з'єднання із сервером за раз, а передачі FTP виконуються одна за одною.
  • Символьні посилання на сервері працюють для файлів, але пов'язані папки не обходяться під час завантаження папок на сервер, із сервера або синхронізації.
  • Ключі у форматі PuTTY .ppk спершу треба конвертувати в OpenSSH (puttygen key.ppk -O private-openssh -o key).
  • Синхронізація порівнює розмір і час зміни, а потім байти файлів однакового розміру, до 300 файлів або 64 МБ за запуск.
  • Копії для відкату за замовчуванням зберігаються для файлів до 5 МБ і лише на цьому комп'ютері.

Це безкоштовно?

Після цього потрібен Zovo Pro, 19 USD один раз для всіх розширень Zovo.

Чи зберігається мій пароль у sftp.json?

Ні. Пароль або парольна фраза, які ви вводите, зберігаються в секретному сховищі редактора. Не вказуйте password у sftp.json, і його буде запитано один раз.

Чи завантажить воно мій файл .env на сервер?

Ні. .vscode, .git, файли .env, приватні ключі й .npmrc є в стандартному списку ігнорування й ніколи не завантажуються на сервер.

Чи може VS Code завантажувати файли через SFTP без розширення?

Ні. У VS Code немає завантаження через SFTP або FTP. Remote SSH редагує файли безпосередньо на сервері, а щоб завантажити локальний проєкт, потрібне розширення або scp і rsync у терміналі.
