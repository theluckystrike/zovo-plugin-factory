Посібники українською

VS Code і редактори на його основі (Cursor, Windsurf, VSCodium) відкривають текст, зображення та частину медіафайлів. Для багатьох інших форматів потрібне розширення. У кожному посібнику є кроки й сказано, що безкоштовно.

  • Як читати й відновлювати історію Claude Code у VS Code. Читайте, шукайте й відновлюйте старі сесії Claude Code і Codex у VS Code. Субагенти вкладені, правки як diff, підсумки токенів. Лише читання, офлайн.
  • Як відтворити аудіофайли у VS Code. Відтворюйте WAV, MP3, FLAC, Ogg і Opus у VS Code з безкоштовним Audio Player: хвильова форма, спектрограма, петля A-B, швидкість і гучність у LUFS.
  • Автоматичне перейменування тегів HTML, JSX і Vue у VS Code. Змініть назву тега HTML, JSX чи Vue, і парний тег зміниться під час введення. Безкоштовне розширення на основі linked editing, з автозакриттям і одним undo.
  • Як відкрити креслення DXF у VS Code. Переглядайте креслення .dxf у VS Code з безкоштовним DXF Viewer: ASCII і бінарний DXF, шари, аркуші paper space, пошук тексту, вимірювання, PNG і SVG.
  • Як переглянути секції та імпорти файлу ELF, EXE чи DLL у VS Code. Відкривайте файли .so, .exe, .dll і .dylib у VS Code з безкоштовним ELF Viewer & PE Viewer: заголовки, секції, імпорти, експорти, символи й hex.
  • Як переглянути файл шрифту у VS Code. Відкривайте шрифти .ttf, .otf, .woff, .woff2 і .ttc у VS Code з безкоштовним Font Viewer: свій текст, усі гліфи й ліцензія, без встановлення шрифту.
  • Як переглянути граф Graphviz DOT без встановлення Graphviz. Переглядайте файли .dot і .gv поруч із кодом у VS Code під час введення, Graphviz уже вбудовано. Шість рушіїв компонування, перехід до рядка, SVG і PNG.
  • Як переглянути діаграми Mermaid у VS Code. Переглядайте діаграми Mermaid у VS Code з файлів .mmd і блоків Markdown з безкоштовним Mermaid Viewer. Живий перегляд, експорт PNG і SVG, офлайн, без входу.
  • Безкоштовний переглядач NetCDF у VS Code. Відкривайте файли NetCDF .nc у VS Code на Windows, macOS чи Linux: заголовок, змінні, карти з береговими лініями, часові ряди. Також HDF5 і MATLAB 7.3.
  • Як переглянути файли NumPy .npy і .npz у VS Code. Відкривайте масиви NumPy .npy і .npz у VS Code з безкоштовним Tensor Viewer: dtype, форма, статистика, теплові карти, зображення й значення, без Python.
  • Як відкрити файл PCAP у VS Code. Читайте дампи .pcap, .pcapng і .pcap.gz у VS Code з безкоштовним PCAP Viewer: список пакетів, дерево протоколів, hex-панель і фільтри. Без Wireshark.
  • Як запустити файл C++ у VS Code одним клацанням. Компілюйте й запускайте відкритий файл .cpp або .c у VS Code одним клацанням вашим gcc, g++ чи clang. Введення в терміналі, помилки в Problems, тести.
  • Як відкрити базу даних SQLite у VS Code. Відкрийте файл .db або .sqlite у VS Code з безкоштовним SQLite Viewer & Editor: таблиці, схема й SQL, редагування клітинок і рядків, Save з резервною копією.
  • Як конвертувати TIFF у PNG без втрати якості. Відкривайте TIFF, BigTIFF і GeoTIFF у VS Code безкоштовно й зберігайте одну чи всі сторінки як PNG з точними 8- і 16-бітними значеннями. Офлайн.
  • Як відтворити відео MOV, MKV, WebM і MP4 зі звуком у VS Code. Відтворюйте MP4, MOV і M4V зі звуком AAC у VS Code без додаткових встановлень. MKV, WebM і AVI теж грають, з вашим ffmpeg. Безкоштовний плеєр із субтитрами.
  • XMind у PDF без XMind: усі аркуші в одному PDF. Відкрийте мапу .xmind у VS Code без XMind і збережіть усі аркуші в один PDF, по сторінці на аркуш. Перегляд безкоштовний, PDF є інструментом Zovo Pro.
  • Як відкрити файл усередині ZIP без розпакування. Переглядайте ZIP, JAR, TAR або TAR.GZ у VS Code й відкривайте файл з архіву у вкладці лише для читання, нічого не розпаковуючи на диск. Безкоштовно й офлайн.
  • Як відкрити JAR і прочитати декомпільований код Java у VS Code. Відкривайте .jar, .war, .ear, .aar і .class у VS Code: пакети, MANIFEST.MF, байткод і код Java, декомпільований CFR. Безкоштовно й лише для читання.
  • Як переглянути HAR-файл офлайн у VS Code. HAR-записи містять cookie й токени. Відкрийте їх офлайн у VS Code з таблицею запитів, waterfall і фільтрами та збережіть копію без секретів.
  • Як конвертувати файл PDF, Word, PowerPoint або Excel у Markdown у VS Code. Клацніть правою кнопкою PDF, DOCX, PPTX, XLSX, CSV, HTML або EPUB у VS Code, і поруч відкриється Markdown. Безкоштовно, офлайн, без Python і без вивантаження.
  • Як форматувати XML у VS Code і виконувати на ньому XPath. Форматуйте або мінімізуйте XML у VS Code, змінюючи лише пробіли між тегами, виконуйте XPath 1.0 із просторами імен файлу й копіюйте XPath під курсором.
  • Як побачити зображення за шляхом у коді, у гуттері й при наведенні. Мініатюра в гуттері й підказка із зображенням, розміром у пікселях і розміром файлу для шляхів до зображень у JS, CSS, HTML і Markdown у VS Code. Безкоштовно.
  • Як редагувати файл .env у VS Code, не показуючи секрети. Підсвічування .env у VS Code, секретні значення як крапки, доки курсор не на їхньому рядку, і виправлення дубльованих ключів та лапок. Безкоштовно й офлайн.
  • Як форматувати скрипт bash або zsh у VS Code. Форматуйте скрипти bash, sh, zsh, bats і mksh у VS Code через Shift+Alt+F або під час збереження. Вбудований shfmt 3.14.1 читає .editorconfig і працює офлайн.
  • Як переглядати бакети AWS S3, Cloudflare R2 або MinIO у VS Code. Бакети S3, R2, MinIO, B2 і Wasabi у VS Code: об'єкти лише для читання, вивантаження й завантаження з відновленням, синхронізація папки після dry-run.
  • Як редагувати файли .proto у VS Code з підсвічуванням, форматуванням і переходом до визначення. Підсвічування, форматування й перевірка .proto у VS Code: форматер зберігає коментарі, є перехід до визначення й помилки як у protoc. Безкоштовно, без protoc.
  • Як форматувати й перевіряти конфігурацію nginx у VS Code. Форматуйте nginx.conf у VS Code, не ламаючи коректний файл, бачте пропущену ; або директиву не на місці під час введення й підказки для приблизно 300 директив.
  • Як переглядати діаграму PlantUML у VS Code під час введення. Живий перегляд PlantUML у VS Code для .puml і блоків plantuml у Markdown, малює вбудований jar на вашому комп'ютері. Потрібна Java 11, Graphviz не потрібен.
