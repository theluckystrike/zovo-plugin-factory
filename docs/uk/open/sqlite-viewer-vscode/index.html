Як відкрити базу даних SQLite у VS Code

Встановіть безкоштовний SQLite Viewer & Editor і клацніть файл .db, .sqlite або .sqlite3. Кожна таблиця відкривається як сітка лише для читання, а вкладки Schema і SQL поруч. Розширення читає також зафіксовані рядки, які ще лежать у файлі -wal. Перегляд, редагування після натискання Enable editing, Save з резервною копією та імпорт CSV безкоштовні. Zovo Pro (19 USD один раз) додає порівняння баз даних, ER-діаграми та експорт усіх таблиць одразу, з 3 безкоштовними запусками кожен.

Як це зробити у VS Code

  1. Встановіть SQLite DB Viewer з Marketplace або натисніть Ctrl+P (Cmd+P на macOS) і виконайте ext install zovo.sqlite-table-viewer.
  2. Клацніть файл .db, .sqlite, .sqlite3, .db3, .s3db, .sl3, .vscdb або .gpkg в Explorer. Він відкривається як таблиця, лише для читання.
  3. Виберіть таблицю або представлення ліворуч. Клацніть заголовок стовпця, щоб відсортувати, введіть текст під заголовком, щоб відфільтрувати (наприклад, 5..9 або =word), або шукайте одразу в усіх стовпцях.
  4. Відкрийте вкладку Schema, щоб побачити стовпці, ключі, зовнішні ключі й інструкції CREATE, або вкладку SQL, щоб виконувати інструкції по одній. Останні 20 інструкцій зберігаються.
  5. Щоб змінити дані, натисніть Enable editing. Двічі клацніть клітинку, введіть нове значення й натисніть Enter. Кожна зміна чекає в списку незбережених змін зі своїм SQL і кнопкою Undo.
  6. Натисніть Save (Ctrl+S або Cmd+S на macOS). Save перевіряє обмеження, робить резервну копію, як-от name.db.20261109-143000.bak, і замінює файл за один крок.

Відкриття й читання, вкладка SQL, редагування клітинок і рядків, Save з резервною копією, імпорт CSV і TSV, інструменти таблиць і експорт рядків, які видно на екрані, безкоштовні. Немає облікового запису й немає таймера пробного періоду.

Цей інструмент записує всі таблиці бази за один запуск: одну книгу Excel (.xlsx) з окремим аркушем для кожної таблиці й жирним закріпленим рядком заголовків або папку з окремим файлом CSV для кожної таблиці. Безкоштовний Export зберігає лише видимі рядки однієї таблиці, тож із цим інструментом не треба експортувати таблиці по одній. Він лише читає базу й ніколи в неї не записує.

Як встановити в Cursor, Windsurf або VSCodium

  1. Відкрийте панель Extensions клавішами Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Знайдіть zovo.sqlite-table-viewer і натисніть Install. Cursor, Windsurf і VSCodium встановлюють розширення з Open VSX, де це розширення опубліковано як zovo/sqlite-table-viewer.
  3. Якщо у вашому редакторі немає каталогу розширень, завантажте файл .vsix зі сторінки Open VSX і виконайте «Extensions: Install from VSIX...».
  4. Далі все працює так само, як у VS Code.

Що вміє SQLite DB Viewer

  • Зафіксовані рядки, які ще лежать у файлі -wal, з живим перезавантаженням, поки ваш застосунок пише в базу (кнопка Live його вимикає).
  • Клітинки JSON у вигляді дерева, зображення як картинки, а BLOB з float32 як вектори на панелі клітинки.
  • Копіювання як CSV, TSV, JSON або інструкцій INSERT і Export видимих рядків як CSV, JSON або інструкцій SQL INSERT.
  • Імпорт CSV і TSV у нову або наявну таблицю з попереднім переглядом, зіставленням стовпців, індикатором прогресу й кнопкою Cancel.
  • Бази даних до 512 МБ, рядки завантажуються посторінково.

Чого розширення не робить

  • Уся база завантажується в пам’ять. Для файлів понад 512 МБ показується повідомлення (налаштування sqliteTableViewer.maxFileSizeMB).
  • Редагувати можна файли до 256 МБ (налаштування sqliteTableViewer.editMaxFileSizeMB). Більші файли лишаються лише для читання.
  • Зашифровані бази (SQLCipher, SEE) не відкриваються.
  • Редагування працює лише для файлів на цьому комп’ютері. Файли на віддалених або віртуальних файлових системах відкриваються лише для читання.
  • Незбережені зміни відкидаються, коли ви закриваєте вкладку, і файл лишається таким, як був.

Часті запитання

Це безкоштовно?

Відкриття, перегляд, вкладка SQL, редагування, Save та імпорт CSV безкоштовні й не потребують облікового запису. Три Pro-інструменти (Compare SQLite Databases, ER Diagram і Export All Tables) мають по 3 безкоштовні запуски. Після цього потрібен Zovo Pro, 19 USD один раз для всіх розширень Zovo.

Чи можна редагувати рядки у VS Code?

Так. Файл відкривається лише для читання, а щоб змінювати клітинки й рядки чи виконувати INSERT і UPDATE, натисніть Enable editing. Нічого не записується, доки ви не натиснете Save, а Save спершу робить резервну копію.

Чому інший переглядач показує старі рядки?

У режимі WAL нові коміти лежать у файлі -wal, доки checkpoint не перенесе їх в основний файл. Переглядач, який читає лише основний файл, їх не бачить. Цей переглядач читає зафіксовану частину файлу -wal.

Чи працює це в Cursor?

Так. Розширення є на Open VSX як zovo/sqlite-table-viewer, тож його можна встановити в Cursor, Windsurf і VSCodium.
