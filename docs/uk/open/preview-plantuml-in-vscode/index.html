Як переглядати діаграму PlantUML у VS Code під час введення

Встановіть безкоштовне розширення PlantUML Viewer & Preview, відкрийте файл .puml або файл Markdown із блоком plantuml і натисніть кнопку попереднього перегляду. Діаграма малюється поруч із вашим кодом під час введення за допомогою jar PlantUML, що постачається всередині розширення, і вашої власної Java 11 або новішої, тому нічого не надсилається на сервер і Graphviz не потрібен. Попередній перегляд, масштабування, посилання на помилки й збереження однієї діаграми як SVG або PNG безкоштовні. Zovo Pro (19 USD один раз) додає три інструменти, Export All Diagrams in a Folder, Markdown Diagrams to Images і Compare with a Git Version, і кожен має 3 безкоштовні спроби.

Як це зробити у VS Code

  1. Встановіть PlantUML Viewer & Preview з Marketplace або натисніть Ctrl+P (Cmd+P на macOS) і виконайте ext install zovo.zovo-plantuml-viewer.
  2. Переконайтеся, що встановлено Java 11 або новішу. Розширення шукає її в налаштуванні plantumlViewer.javaPath, потім у JAVA_HOME, потім java у PATH, а потім у звичних папках JDK. Якщо нічого не знайдено, попередній перегляд повідомляє про це й пропонує "Set the Java path". "PlantUML: Show Java and Layout Status" показує, що знайдено.
  3. Відкрийте файл .puml, .plantuml, .iuml, .pu або .wsd чи файл Markdown із блоком ```plantuml і натисніть кнопку попереднього перегляду вгорі праворуч у редакторі. Також можна натиснути Alt+D у файлі PlantUML або виконати "PlantUML: Open Preview to the Side".
  4. Пишіть. Попередній перегляд перемальовується невдовзі після того, як ви зупинилися (400 ms за замовчуванням, налаштування plantumlViewer.renderDelay). Усі діаграми файлу показано в одному перегляді, а діаграму під курсором обведено рамкою.
  5. Масштабуйте кнопками, Ctrl або Cmd з коліщатком миші чи клавішами + і -. Натисніть Fit, щоб вписати діаграму за шириною панелі, і перетягуйте діаграму, щоб пересуватися нею. Діаграма з помилкою показує повідомлення PlantUML і посилання "Go to line".
  6. Натисніть SVG або PNG над діаграмою, щоб зберегти саме цю діаграму, або Copy SVG, щоб скопіювати її.

Що безкоштовно і що додає Zovo Pro

Живий перегляд файлів .puml, .plantuml, .iuml, .pu і .wsd та блоків plantuml у Markdown, масштабування й переміщення, помилки з посиланням на рядок, збереження однієї діаграми як SVG або PNG, Copy SVG, кольори синтаксису, сніпети (seq, classd, activity, mindmap, gantt та інші), згортання й коментарі безкоштовні. Діаграми малюються на вашому комп'ютері й ніколи не надсилаються на сервер.

Коли діаграми проєкту мають потрапити в документацію або слайди, Export All Diagrams in a Folder за один запуск записує кожну діаграму кожного файлу PlantUML у папці та її підпапках у SVG, PNG або PDF, поруч із кожним файлом або все в одну папку. Діаграми з помилкою пропускаються й перелічуються з файлом, рядком і повідомленням, а решта записується. Вам не треба відкривати кожен файл і зберігати кожну діаграму вручну.

Як запустити Export All Diagrams in a Folder (Zovo Pro)

  1. Клацніть правою кнопкою папку в Explorer і виберіть "Zovo Pro: Export all diagrams in a folder", натисніть "Export all diagrams in a folder" у рядку Pro-інструментів на панелі попереднього перегляду або виконайте "PlantUML: Export All Diagrams in a Folder (Pro)" з Command Palette і виберіть папку.
  2. Виберіть SVG, PNG або PDF, потім "Next to each PlantUML file" або "All in one folder...".
  3. Коли все готово, повідомлення показує, скільки діаграм експортовано. Натисніть "Show errors", щоб побачити список діаграм із помилкою, або "Reveal", щоб побачити файли.
  4. Спроба зараховується, лише коли записано принаймні одне зображення. Escape, Cancel або папка без файлів PlantUML спроби не витрачають.

Як встановити в Cursor, Windsurf або VSCodium

  1. Відкрийте панель Extensions клавішами Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Знайдіть zovo.zovo-plantuml-viewer і натисніть Install. Cursor, Windsurf і VSCodium встановлюють розширення з Open VSX, де це розширення опубліковано як zovo/zovo-plantuml-viewer.
  3. Якщо у вашому редакторі немає каталогу розширень, завантажте файл .vsix зі сторінки Open VSX і виконайте «Extensions: Install from VSIX...».
  4. Далі все працює так само, як у VS Code.

Що вміє PlantUML Viewer & Preview

  • Діаграми послідовності, класів, активності, компонентів, станів, варіантів використання, ментальні карти, діаграми Ганта та інші блоки @start... вбудованого PlantUML (MIT-збірка 1.2026.10).
  • Блоки Markdown ```plantuml, ```puml і ```uml, з @startuml усередині або без. Кнопка попереднього перегляду з'являється у файлі Markdown, де є принаймні один такий блок.
  • !include файлів із папки діаграми, папок вашої робочої області й plantumlViewer.includePaths, а також стандартна бібліотека, як-от !include <C4/C4_Container>, офлайн. Include для C4, іконок AWS і шрифтів іконок, записані як адреси https://raw.githubusercontent.com/..., зчитуються з копії всередині jar.
  • Діаграмам послідовності, ментальним картам і діаграмам Ганта рушій розкладки не потрібен. Діаграми класів, компонентів, станів і варіантів використання використовують Graphviz, якщо встановлено dot (plantumlViewer.layout має значення auto), а якщо ні, то рушій Smetana, вбудований у PlantUML.
  • Діаграми показуються як зображення, тому посилання чи текст усередині діаграми не можуть запустити код у редакторі.

Чого розширення не робить

  • Має бути встановлено Java 11 або новішу. Розширення не завантажує Java.
  • Include з вебадрес відхиляються, крім адрес C4, іконок AWS і шрифтів іконок, копія яких є в jar. Іконки AWS беруться з набору іконок AWS усередині PlantUML (версія 20), тому для новішої іконки показується помилка з її назвою.
  • MIT-збірка PlantUML не має Ditaa і рендерера LaTeX для @startmath. Блок Ditaa показує сторінку PlantUML "not supported".
  • Без Graphviz рушій Smetana розкладає діаграми класів і компонентів трохи інакше, а дуже великі діаграми класів можуть виглядати щільнішими.
  • Діаграма, малювання якої триває понад 30 секунд (налаштування plantumlViewer.renderTimeoutSeconds), зупиняється, а зображення обрізаються до 8192 пікселів з кожного боку (налаштування plantumlViewer.maxImageSize).

Часті запитання

Це безкоштовно?

Живий перегляд, масштабування й переміщення, посилання на помилки, збереження однієї діаграми як SVG або PNG, кольори синтаксису й сніпети безкоштовні. Три Pro-інструменти, Export All Diagrams in a Folder, Markdown Diagrams to Images і Compare with a Git Version, мають по 3 безкоштовні спроби. Після цього потрібен Zovo Pro, 19 USD один раз для всіх розширень Zovo.

Чи потрібні Java або Graphviz?

Java 11 або новіша потрібна, бо PlantUML є програмою на Java. Graphviz не потрібен. Без нього діаграми класів і компонентів використовують рушій розкладки Smetana, вбудований у PlantUML. Якщо dot встановлено, використовується він.

Чи надсилається моя діаграма на сервер?

Ні. Вбудований jar PlantUML працює на вашому комп'ютері з профілем безпеки ALLOWLIST, а include з вебадрес відхиляються. Жоден сервер PlantUML не використовується.

Чи працює воно в Cursor?

Так. Cursor, Windsurf і VSCodium встановлюють його з Open VSX, де воно опубліковане як zovo/zovo-plantuml-viewer.
