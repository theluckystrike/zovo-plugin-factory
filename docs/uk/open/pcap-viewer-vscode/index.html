Як відкрити файл PCAP у VS Code

Встановіть безкоштовний PCAP Viewer і клацніть файл .pcap або .pcapng. Він показує список пакетів, дерево протоколів, hex-панель, пов’язану з деревом, фільтри відображення у стилі Wireshark, follow stream і статистику. Розширення саме читає файл на JavaScript, тож Wireshark, tshark чи sharkd не потрібні. Переглядач безкоштовний, а Zovo Pro (19 USD один раз) додає експорт списку пакетів у CSV або JSON, звіт про дамп у Markdown і зведення по папці, з 3 безкоштовними запусками для кожного інструмента.

Як це зробити у VS Code

  1. Встановіть PCAP Viewer з Marketplace або натисніть Ctrl+P (Cmd+P на macOS) і виконайте ext install zovo.zovo-pcap-viewer.
  2. Клацніть файл .pcap, .pcapng, .pcap.gz, .pcapng.gz або .ntar. Для .cap, .dmp чи інших назв клацніть файл правою кнопкою в Explorer і виберіть «Open in PCAP Viewer».
  3. Введіть фільтр відображення, як-от tcp.port == 443 && ip.addr == 10.0.0.1, і натисніть Enter. Поле стає зеленим, коли фільтр правильний, а якщо ні, пояснює, що не так.
  4. Клацніть поле в дереві протоколів, щоб підсвітити його байти в hex-панелі, або клацніть байт, щоб знайти його поле.
  5. Двічі клацніть пакет, щоб переглянути його потік TCP або UDP (follow stream) як ASCII, UTF-8 або hex-дамп. Потік можна скопіювати або зберегти у файл.
  6. Натисніть Statistics, щоб побачити ієрархію протоколів, розмови (conversations), кінцеві точки (endpoints) та імена, знайдені в дампі. Клацніть рядок, щоб відфільтрувати за ним.
  7. Відкрийте меню Export, щоб зберегти вибрані пакети або всі пакети, які показує фільтр, як новий файл pcap.

Що безкоштовно і що додає Zovo Pro

Список пакетів, дерево протоколів, пов’язана hex-панель, фільтри відображення, збережені фільтри, follow stream, статистика й експорт пакетів у новий файл pcap безкоштовні. Розширення не потребує входу й працює офлайн.

Інструмент записує пакети, які показує фільтр, у файл CSV або JSON, по рядку на пакет: номер, час UTC, секунди від початку, джерело, призначення, порти, протокол, довжина, фільтр потоку, імена хостів із дампу й текст Info. CSV відкривається в Excel, а текст, схожий на формули, знешкоджено. JSON працює з jq і pandas. Ви отримуєте таблицю для тікета чи скрипту й не копіюєте рядки вручну.

Як встановити в Cursor, Windsurf або VSCodium

  1. Відкрийте панель Extensions клавішами Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Знайдіть zovo.zovo-pcap-viewer і натисніть Install. Cursor, Windsurf і VSCodium встановлюють розширення з Open VSX, де це розширення опубліковано як zovo/zovo-pcap-viewer.
  3. Якщо у вашому редакторі немає каталогу розширень, завантажте файл .vsix зі сторінки Open VSX і виконайте «Extensions: Install from VSIX...».
  4. Далі все працює так само, як у VS Code.

Що вміє PCAP Viewer

  • pcap (мікросекундний і наносекундний, little-endian і big-endian) і pcapng, також у вигляді .gz.
  • Ethernet, 802.1Q VLAN, Linux cooked capture (SLL і SLL2), raw IPv4 і IPv6, BSD loopback, заголовки 802.11 і radiotap.
  • ARP, IPv4, IPv6, ICMP, ICMPv6, TCP, UDP, DNS і mDNS, DHCP, HTTP/1.x, записи TLS з іменем сервера (SNI) і ALPN, а також довгі заголовки QUIC.
  • Великі дампи. Під час перевірок релізу дамп на 1 ГБ із 1 438 965 пакетами з’явився в списку приблизно за 2 с.
  • Пошкоджені файли. Показано кожен пакет до місця пошкодження, а повідомлення пояснює, що не так і де.

Чого розширення не робить

  • У поля розбираються лише протоколи зі списку. HTTP означає HTTP/1.x, для 802.11 розбирається заголовок, а для QUIC довгий заголовок.
  • Трафік TLS не розшифровується. Видно записи TLS з іменем сервера (SNI) і ALPN.
  • Поле фільтра приймає поширену частину синтаксису фільтрів відображення Wireshark, а не весь синтаксис.
  • Розпакування дампу .gz зупиняється на 512 МБ (налаштування pcapViewer.maxGzipMB), і розширення про це повідомляє.
  • Файли на віддаленій або віртуальній файловій системі відкриваються до 256 МБ (налаштування pcapViewer.maxRemoteMB).

Часті запитання

Чи потрібно встановлювати Wireshark?

Ні. PCAP Viewer читає pcap і pcapng на JavaScript усередині VS Code, у Windows, macOS і Linux. Він не використовує Wireshark, tshark чи sharkd.

Чи надсилає відкриття дампу запити DNS?

Ні. Імена хостів беруться лише з відповідей DNS у пакетах і блоків імен у файлах pcapng. Розширення не має телеметрії й не робить мережевих запитів.

Це безкоштовно?

Так. Переглядач, фільтри, follow stream, статистика й експорт у pcap безкоштовні. Export packet list to CSV or JSON, Capture report і Folder summary є інструментами Zovo Pro з 3 безкоштовними запусками кожен, а далі 19 USD один раз для всіх розширень Zovo.

Чи працює це в Cursor?

Так. Розширення працює у VS Code 1.90 і новіших версіях та в редакторах, які встановлюють розширення з Open VSX, як-от Cursor, Windsurf і VSCodium.
