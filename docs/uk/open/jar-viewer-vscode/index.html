Як відкрити JAR і прочитати декомпільований код Java у VS Code

Встановіть безкоштовний JAR Viewer & Java Decompiler і клацніть файл .jar, .war, .ear, .aar або .class. Він показує пакети, ресурси, MANIFEST.MF і версію Java кожного класу, лістинг байткоду в стилі javap -c -p, якому не потрібна Java, і код Java, декомпільований вбудованим CFR 0.152 за допомогою Java 8 або новішої на вашому комп’ютері. Усі перегляди й декомпіляція одного класу за раз безкоштовні. Zovo Pro (19 USD один раз) додає три інструменти, експорт декомпільованого коду JAR, порівняння двох JAR і пошук у кожному JAR папки, з 3 безкоштовними запусками кожен.

Як це зробити у VS Code

  1. Встановіть JAR Viewer з Marketplace або натисніть Ctrl+P (Cmd+P на macOS) і виконайте ext install zovo.zovo-jar-viewer.
  2. Клацніть файл .jar, .war, .ear, .aar або .class в Explorer. Він відкриється в JAR Viewer. Overview показує формат, кількість записів, класів і пакетів, Main-Class, Created by, MANIFEST.MF і діаграму версій Java, під які скомпільовано класи.
  3. Введіть частину назви в поле фільтра над деревом пакетів. Воно знаходить класи й файли під час введення. Внутрішні класи показано приглушеними під їхнім зовнішнім класом.
  4. Клацніть клас. Вкладка Java source показує його декомпільованим CFR 0.152 разом із внутрішніми класами. Copy копіює код у буфер обміну, а Open in editor відкриває його у звичайній вкладці редактора.
  5. Якщо вкладка Java source пише, що для декомпільованого коду Java потрібне середовище Java, вкажіть у jarViewer.javaPath файл java або папку JDK чи задайте JAVA_HOME. Команда «JAR Viewer: Check the Java runtime used for decompiling» показує, яку Java використано.
  6. Відкрийте вкладку Bytecode, щоб побачити лістинг у стилі javap -c -p з кожним опкодом, таблицями винятків і номерами рядків. Members, Constant pool і Class info показують оголошення, записи пулу констант і атрибути класу.
  7. У JAR для Spring Boot, WAR або AAR клацніть JAR у BOOT-INF/lib чи WEB-INF/lib або classes.jar з AAR, а потім «Open nested archive». Архів відкриється на один рівень углиб, а кнопка з назвою зовнішнього файлу вгорі повертає назад.

Що безкоштовно і що додає Zovo Pro

Дерево пакетів, Overview, маніфест, ресурси, декомпільований код Java, байткод, Members, Constant pool, Class info і вкладені JAR безкоштовні, без входу в обліковий запис. CFR постачається з розширенням і працює на Java, яка вже є на вашому комп’ютері. Розширення ніколи не змінює архів і не робить мережевих запитів.

Export decompiled sources of a JAR декомпілює кожен клас JAR, WAR, EAR або AAR за допомогою CFR і записує файли .java у папку, показуючи прогрес і кнопку Cancel. Без середовища Java інструмент записує натомість лістинги байткоду. Ви отримуєте всю бібліотеку як файли з кодом, у яких можна шукати й читати їх у редакторі, замість відкривати класи по одному.

Як запустити Export decompiled sources of a JAR (Zovo Pro)

  1. Відкрийте архів і натисніть «Export sources…» угорі переглядача або «Export decompiled sources» у невеликому рядку Pro tools. Також можна клацнути файл правою кнопкою в Explorer і вибрати «Zovo Pro: Export decompiled sources».
  2. Або виконайте «JAR Viewer: Export decompiled sources of a JAR (Pro)» з Command Palette. Якщо жоден архів не відкрито, команда попросить вибрати файл JAR, WAR, EAR або AAR.
  3. Виберіть папку й натисніть «Export here». Код з’явиться в новій папці з назвою архіву та -src у кінці.
  4. Сповіщення показує прогрес. Cancel зупиняє експорт і не витрачає запуск. Коли все готово, переглядач показує, скільки файлів записано і куди.

Export decompiled sources of a JAR можна запустити на вашому комп’ютері 3 рази безкоштовно, після цього розширення попросить ліцензію. Жодних спливних вікон і жодного зворотного відліку.

Як встановити в Cursor, Windsurf або VSCodium

  1. Відкрийте панель Extensions клавішами Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Знайдіть zovo.zovo-jar-viewer і натисніть Install. Cursor, Windsurf і VSCodium встановлюють розширення з Open VSX, де це розширення опубліковано як zovo/zovo-jar-viewer.
  3. Якщо у вашому редакторі немає каталогу розширень, завантажте файл .vsix зі сторінки Open VSX і виконайте «Extensions: Install from VSIX...».
  4. Далі все працює так само, як у VS Code.

Що вміє JAR Viewer

  • Архіви JAR, WAR, EAR і AAR, а також окремі файли .class з їхніми внутрішніми класами з тієї самої папки.
  • Архіви до 200 000 записів і фільтр, який знаходить клас або файл серед 50 000 записів під час введення.
  • Generic-сигнатури, records, permitted subclasses, nest hosts та анотації в даних класу.
  • Текстові ресурси, як-от properties, XML, JSON, SQL і файли services, показано як текст, а бінарні файли мають hex-перегляд.
  • Архіви Spring Boot BOOT-INF/lib, WAR WEB-INF/lib і AAR classes.jar на один рівень углиб.

Чого розширення не робить

  • Для декомпільованого коду потрібна Java 8 або новіша на вашому комп’ютері. Без неї байткод і всі інші перегляди працюють.
  • Результат CFR може відрізнятися від оригінального коду, наприклад у назвах локальних змінних, деяких generics і лямбдах.
  • Записи розпаковуються до 64 МБ кожен, class-файли до 16 МБ, вкладені архіви до 128 МБ. Файли на віддалених або віртуальних файлових системах читаються до 256 МБ.
  • Розширення працює лише для читання, тож клас не можна редагувати чи перекомпілювати. Вкладені архіви відкриваються лише на один рівень углиб.
  • Файли APK і DEX не читаються.

Після цього потрібен Zovo Pro, 19 USD один раз для всіх розширень Zovo.

Чому вкладка Java source просить Java?

CFR є програмою на Java. Переглядач шукає Java в jarViewer.javaPath, потім у JAVA_HOME, а потім java у вашому PATH. Підходить будь-яке середовище Java 8 або новіше.

Чи можна читати байткод без Java?

Так. Вкладки Bytecode, Members, Constant pool і Class info читаються на JavaScript і не потребують Java.

Чи працює це в Cursor?

Так. Розширення є на Open VSX як zovo/zovo-jar-viewer, тож його можна встановити в Cursor, Windsurf і VSCodium.
