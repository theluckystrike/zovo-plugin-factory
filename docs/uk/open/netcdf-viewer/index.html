Безкоштовний переглядач NetCDF у VS Code

Встановіть у VS Code безкоштовне розширення NetCDF Viewer & HDF5 Viewer і клацніть файл .nc. Ви побачите заголовок, дерево змінних, карту з береговими лініями, повзунок часу й часовий ряд будь-якої точки, на яку клацнете, і для цього не потрібні Python, NCL чи інше налаштування. Той самий переглядач відкриває файли HDF5 .h5 і MATLAB 7.3 .mat, і все це безкоштовно. Zovo Pro (19 USD один раз) додає два інструменти, Compare two files і Export a subset, і кожен має 3 безкоштовні запуски.

Як це зробити у VS Code

  1. Встановіть NetCDF Viewer & HDF5 Viewer з Marketplace або натисніть Ctrl+P (Cmd+P на macOS) і виконайте ext install zovo.hdf5-netcdf-explorer.
  2. Клацніть файл .nc, .nc4, .netcdf або .cdf в Explorer. Огляд показує формат, виміри, глобальні атрибути й таблицю всіх змінних, приблизно як ncdump -h.
  3. Виберіть змінну в дереві ліворуч. Двовимірний зріз малюється як теплова карта, з береговими лініями, якщо рядки й стовпці відповідають широті й довготі.
  4. Пересуньте повзунок часу або натисніть ▶ поруч із ним, щоб програти зміни в часі. Клацніть точку на карті, щоб побудувати її часовий ряд.
  5. Відкрийте вкладку Table, щоб гортати значення сторінками по 100 рядків і 30 стовпців, зі значеннями координат як заголовками.
  6. Натисніть «Save PNG», щоб зберегти графік, або «Export slice…», щоб зберегти зріз на екрані як CSV чи JSON. «Copy xarray code» дає рядок Python для того самого зрізу.
  7. Для файлу HDF5 клацніть файл .h5. Файл MATLAB 7.3 .mat клацніть правою кнопкою й виберіть «Open in HDF5 NetCDF Explorer».

Що безкоштовно і що додає Zovo Pro

Усі формати, дерево, атрибути, таблиця, графіки й карти з береговими лініями, Play, часові ряди точок, Save PNG і Export slice безкоштовні. Для цих функцій не потрібен Python, і розширення не робить для них мережевих запитів.

Export a subset працює як ncks -d або .sel у xarray. Виберіть змінну й діапазон для кожного виміру, за індексом (0:99) або за значенням (30..60, 2023-08-01..2023-08-31). Інструмент зберігає файл NetCDF з координатами, атрибутами й рядком history або охайний CSV з одним рядком на точку. Ви отримуєте невеликий файл для одного регіону й періоду без написання скрипту.

Як запустити Export a subset (Zovo Pro)

  1. Відкрийте файл і натисніть кнопку «Export subset…» поруч з «Export slice…» або клацніть файл правою кнопкою в Explorer і виберіть «Zovo Pro: Export a Subset of a Variable».
  2. Або виконайте «NetCDF Viewer Pro: Export Subset of a Variable (NetCDF or CSV)...» з Command Palette.
  3. Введіть діапазон для кожного виміру. Поле показує, що ви вибрали, уже під час введення.
  4. Виберіть NetCDF або CSV і місце для збереження. Сповіщення показує хід роботи, а Cancel зупиняє її й не залишає недописаного файлу.

Export a subset можна запустити на вашому комп’ютері 3 рази безкоштовно, після цього розширення попросить ліцензію. Жодних спливних вікон і жодного зворотного відліку.

Як встановити в Cursor, Windsurf або VSCodium

  1. Відкрийте панель Extensions клавішами Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Знайдіть zovo.hdf5-netcdf-explorer і натисніть Install. Cursor, Windsurf і VSCodium встановлюють розширення з Open VSX, де це розширення опубліковано як zovo/hdf5-netcdf-explorer.
  3. Якщо у вашому редакторі немає каталогу розширень, завантажте файл .vsix зі сторінки Open VSX і виконайте «Extensions: Install from VSIX...».
  4. Далі все працює так само, як у VS Code.

Що вміє NetCDF Viewer & HDF5 Viewer

  • NetCDF-4 і NetCDF-4 classic, NetCDF-3 classic і 64-bit offset, а також CDF-5 (64-бітні дані).
  • Файли HDF5 (.h5, .hdf5, .he5, .hdf) зі стисненням deflate, shuffle, szip, LZF, Blosc, bitshuffle, LZ4, Zstd, bzip2 і ZFP.
  • MATLAB 7.3 .mat та інші файли на основі HDF5, як-от .jld2, .loom і .h5ad.
  • CF-декодування scale_factor, add_offset, _FillValue і одиниць часу, зокрема з календарями noleap, 360_day і all_leap.
  • Файли на віддаленій машині через Remote SSH, WSL або dev container.

Чого розширення не робить

  • Zarr і HDF4 не підтримуються. Файли MATLAB .mat, збережені у форматі v5, не є HDF5 і не відкриваються. Збережіть їх знову командою save(filename, '-v7.3').
  • Берегові лінії малюються лише на регулярних сітках широти й довготи. Криволінійні сітки з двовимірними широтою й довготою та проєкційні сітки в метрах берегових ліній не мають.
  • Для графіка масиви понад 512 x 512 беруться вибірково. Експорт записує не більше 1 000 000 значень у файл (налаштування hdf5NetcdfExplorer.maxReadValues).
  • Віртуальні файлові системи, як-от репозиторії GitHub, відкриті у vscode.dev, не підтримуються.
  • Набори даних з іншими фільтрами HDF5, як-от SZ чи JPEG, показують повідомлення замість значень.

Часті запитання

Це безкоштовно?

Перегляд безкоштовний: усі формати, карти, Play, часові ряди, Save PNG і Export slice. Два Pro-інструменти, Compare two files і Export a subset, мають по 3 безкоштовні запуски. Після цього потрібен Zovo Pro, 19 USD один раз для всіх розширень Zovo.

Чи є переглядач NetCDF для Windows?

Так. Це розширення працює всюди, де працює VS Code, зокрема у Windows, macOS і Linux, і не потребує Python.

Чи відкриває він файли HDF5 і MAT?

Так, файли HDF5 .h5 і MATLAB 7.3 .mat. Старіші файли MATLAB v5 .mat не є HDF5, і для них показується повідомлення.

Чи працює це в Cursor?

Так. Розширення є на Open VSX як zovo/hdf5-netcdf-explorer, тож його можна встановити в Cursor, Windsurf і VSCodium.
