Як переглянути файл шрифту у VS Code

Встановіть безкоштовний Font Viewer і клацніть файл .ttf, .otf, .woff, .woff2 або .ttc. Він показує ваш власний текст цим шрифтом, каскад розмірів (waterfall), сітку гліфів із пошуком, а також ліцензію й права на вбудовування, і шрифт не треба встановлювати в систему. Type tester, сітка гліфів, карта символів, вкладка Info та Copy CSS @font-face безкоштовні. Як це зробити у VS Code

  1. Встановіть Font Viewer з Marketplace або натисніть Ctrl+P (Cmd+P на macOS) і виконайте ext install zovo.font-viewer-vscode.
  2. Клацніть файл .ttf, .otf, .woff, .woff2, .ttc або .otc в Explorer. Font Viewer є стандартним редактором для цих файлів і ніколи не змінює шрифт.
  3. На вкладці Type tester введіть свій текст, пересуньте повзунок розміру від 8 до 200 px і перегляньте каскад розмірів від 12 до 96 px. Для варіативного шрифту рухайте повзунки осей і вмикайте чи вимикайте можливості OpenType, як-от liga або ss01.
  4. На вкладці Glyphs шукайте за назвою, символом, кодом U+20AC або номером гліфа. Клацніть гліф, щоб побачити його великим із базовою лінією, висотою x і висотою великих літер, і скопіюйте символ, його кодову точку або контур як SVG.
  5. На вкладці Characters перегляньте покриття кожного блоку Unicode, наприклад «Basic Latin 95/128». Вимкніть «Only characters in the font», щоб побачити, яких символів бракує.
  6. На вкладці Info прочитайте ліцензію, ім’я дизайнера, авторські права й права на вбудовування та скопіюйте готове правило @font-face.

Що безкоштовно і що додає Zovo Pro

Font Folder Report перелічує всі шрифти в папці з родиною, накресленням, вагою, осями, версією, кількістю гліфів, ліцензією, URL ліцензії та правами на вбудовування. Він записує список як файл CSV, таблицю Markdown або один fonts.css з правилом @font-face для кожного шрифту (WOFF2 першим). Перш ніж додати папку шрифтів у застосунок чи на сайт, ви бачите в одному файлі, як можна використовувати кожен шрифт, і не відкриваєте їх по одному.

Як запустити Font Folder Report (Zovo Pro)

  1. Клацніть правою кнопкою папку зі шрифтами в Explorer і виберіть «Font Folder Report: CSV, Markdown or @font-face CSS… (Pro)» або виконайте «Font Viewer: Font Folder Report: CSV, Markdown or @font-face CSS… (Pro)» з Command Palette і виберіть папку.
  2. Виберіть формат: CSV, таблиця Markdown або правила CSS @font-face.
  3. Збережіть файл. Стандартні назви файлів fonts-report.csv, fonts-report.md і fonts.css, а запуск зараховується лише тоді, коли файл записано.

Як встановити в Cursor, Windsurf або VSCodium

  1. Відкрийте панель Extensions клавішами Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Знайдіть zovo.font-viewer-vscode і натисніть Install. Cursor, Windsurf і VSCodium встановлюють розширення з Open VSX, де це розширення опубліковано як zovo/font-viewer-vscode.
  3. Якщо у вашому редакторі немає каталогу розширень, завантажте файл .vsix зі сторінки Open VSX і виконайте «Extensions: Install from VSIX...».
  4. Далі все працює так само, як у VS Code.

Що вміє Font Viewer

  • Шрифти TrueType .ttf і OpenType .otf, зокрема варіативні.
  • Вебшрифти .woff і .woff2. WOFF2 розпаковує власний декодер розширення.
  • Колекції .ttc і .otc зі списком у заголовку, де можна вибрати накреслення.
  • Великі шрифти CJK на 20 000 гліфів, які завантажуються сторінками під час прокручування.
  • Клацніть шрифт правою кнопкою в Explorer і виберіть Copy CSS @font-face, не відкриваючи його.

Чого розширення не робить

  • Колекції WOFF2, шрифти SVG, .dfont і шрифти Type 1 не підтримуються.
  • Контури гліфів показують стандартний екземпляр (default instance) варіативного шрифту. Type tester, каскад розмірів і карта символів враховують повзунки осей.
  • Кольорові шрифти показано в кольорі в Type tester і на карті символів, але сітка гліфів показує їхні прості контури.
  • Файли понад 64 МБ показують повідомлення замість відкриття (налаштування fontViewer.maxFileMB).
  • Розширення працює лише на читання. Воно не редагує шрифти й не встановлює їх у систему.

Часті запитання

Це безкоштовно?

Перегляд шрифтів, Type tester, сітка гліфів, карта символів, вкладка Info та Copy CSS @font-face безкоштовні. Два Pro-інструменти, Convert Font і Font Folder Report, мають по 3 безкоштовні запуски. Після цього потрібен Zovo Pro, 19 USD один раз для всіх розширень Zovo.

Чи треба встановлювати шрифт?

Ні. Шрифт читається з файлу й показується лише на вкладці Font Viewer. Список системних шрифтів не змінюється.

Чи відкриє він WOFF2 з моєї папки збірки?

Так. WOFF2 розпаковує власний декодер розширення, а відкритий вид перезавантажується, коли ви зберігаєте нову збірку шрифту.

Чи працює це в Cursor?

Так. Font Viewer є на Open VSX як zovo/font-viewer-vscode, тож його можна встановити в Cursor, Windsurf і VSCodium.
