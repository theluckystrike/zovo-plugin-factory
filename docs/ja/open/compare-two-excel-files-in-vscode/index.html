VS Code で 2 つの Excel または CSV ファイルを比較する

無料の Excel Compare & XLSX Diff をインストールし、2 つのブックまたは CSV ファイルを選びます。変更されたセルは黄色で古い値に取り消し線が付き、追加された行は緑、削除された行は赤で表示されます。行は位置合わせされ、列はヘッダーで対応付けられるため、行や列を 1 つ挿入しても 1 つの変更として表示されます。コミット前にブックを Git HEAD のバージョンと比較することもできます。これらはすべて無料で、ネットワーク通信もありません。Zovo Pro(USD 19 の買い切り)では Export a diff report、Match rows by key columns、Compare two folders of workbooks の 3 つのツールが加わり、それぞれ 3 回まで無料で試せます。

VS Code での手順

  1. Marketplace から Excel Compare & XLSX Diff をインストールします。または Ctrl+P（macOS では Cmd+P）を押して ext install zovo.zovo-excel-compare を実行します。
  2. Explorer で 2 つのファイルを選択し、右クリックして Compare Selected Excel Files を選びます。または 1 つのファイルを右クリックして Compare with... を選び、もう一方のファイルを指定します。Command Palette からは "Excel Compare: Compare Two Excel or CSV Files..." を実行します。
  3. .xlsx、.xlsm、.xls、.ods、.csv、.tsv はどの組み合わせでも比較できるので、.xlsx と .csv を比べることもできます。
  4. まずサマリー行を読み、次に各シートのタブで差分の数を確認します。セルをクリックすると古い値と新しい値の全体が表示され、コピーできます。
  5. N と P(または Next と Previous)を押すと、シートをまたいですべての変更を順に移動できます。Values と Formulas を切り替えると、セルに表示される値を比べるか、数式そのものを比べるかを選べます。
  6. コミット前に何を変えたかを見るには、Git リポジトリ内のブックを右クリックして Compare with Git HEAD を選びます。

無料でできることと Zovo Pro で増えること

任意の 2 ファイルの比較、グリッド表示、Values と Formulas、前後の変更への移動、文字コードと区切り文字を自動判定する CSV 差分、Compare with Git HEAD は無料です。サインインは不要で、ネットワーク通信もテレメトリーもありません。

変更内容をほかの人に見せる必要があるとき、Export a diff report は変更・追加・削除されたセルを色で塗った XLSX ブックを書き出します。Summary シートと、古い値と新しい値をすべて並べた Changes リストも含まれます。HTML ページ 1 枚や、変更点の CSV リストとして書き出すこともできます。スクリーンショットの代わりにファイルを 1 つ送るだけで済みます。

Export a diff report（Zovo Pro）の手順

  1. 上の手順で 2 つのファイルを比較し、比較画面のツールバーで Export report をクリックします。または Command Palette から "Excel Compare: Export a diff report (XLSX, HTML or CSV) (Pro)" を実行します。
  2. XLSX、HTML、CSV のいずれかを選びます。
  3. レポートの保存先を選びます。試用回数が減るのは、レポートが書き出されたときだけです。

Export a diff report は、ライセンスを求める前にお使いのコンピューターで 3 回まで使えます。ファイルを開いたときにポップアップやカウントダウンは出ません。

Cursor、Windsurf、VSCodium での手順

  1. Ctrl+Shift+X（macOS では Cmd+Shift+X）で Extensions ビューを開きます。
  2. zovo.zovo-excel-compare を検索して Install をクリックします。Cursor、Windsurf、VSCodium は Open VSX から拡張機能をインストールします。Open VSX での名前は zovo/zovo-excel-compare です。
  3. エディターに拡張機能のギャラリーがない場合は、Open VSX のページから .vsix をダウンロードし、「Extensions: Install from VSIX...」を実行します。
  4. あとは VS Code と同じように使えます。

Excel Compare & XLSX Diff で開けるもの

  • シートはまず名前で、次に位置で対応付けられます。片方のファイルにしかないシートは追加または削除として一覧に出ます。
  • CSV と TSV の文字コード(BOM 付き・なしの UTF-8、UTF-16、Windows のコードページ)と区切り文字(カンマ、セミコロン、タブ、パイプ)を自動判定します。改行を含む引用符付きフィールドにも対応します。
  • 大きなシート: グリッドは画面に見えている行だけを描画するので、300,000 行のシートも短いシートと同じようにスクロールできます。
  • 結合セルが異なる場合や、制限によってシートが途中で切られた場合は注記が出ます。
  • ほかの 2 つの Pro ツール: Match rows by key columns は ID 列で行を対応付けるので、並べ替えたシートもきれいに比較でき、移動した行に印が付きます。Compare two folders of workbooks はファイルを名前でペアにし、同じもの、異なるもの、片方のフォルダーにしかないものを表示します。

できないこと

  • ファイルは 200 MB まで(設定 excelCompare.maxFileSizeMB)、シートあたり 300,000 行まで(excelCompare.maxRows)、1,000 列、200 シートまでです。制限が適用されたときはビューに注記が出ます。
  • 展開すると 600 MB を超えるブックや、zip 爆弾のように圧縮されたブックは、展開する前に拒否されます。
  • Pro ツールの Match rows by key columns を使わない場合、行は ID 列ではなく内容と位置で揃えられます。
  • 比較専用です。ファイルの編集やマージはできません。

よくある質問

無料ですか?

2 つのブックや CSV ファイルの比較、Values と Formulas、前後の変更への移動、Compare with Git HEAD は無料です。3 つの Pro ツール、Export a diff report、Match rows by key columns、Compare two folders of workbooks はそれぞれ 3 回まで無料で試せます。その後は Zovo Pro が必要で、USD 19 の買い切りですべての Zovo 拡張機能に使えます。

拡張機能なしで VS Code で 2 つの Excel ファイルを比較できますか?

できません。.xlsx ファイルは XML パーツをまとめた zip なので、標準の差分表示ではバイナリとして扱われます。ブックを読み取れる拡張機能が必要です。

先頭に行を 1 つ挿入すると、その下の行がすべて変更扱いになりますか?

なりません。比較の前に行の位置合わせを行うので、挿入した行は追加された 1 行として表示されます。

前回のコミットからブックの何が変わったかを確認できますか?

できます。Git リポジトリ内のファイルを右クリックして Compare with Git HEAD を選びます。ローカルの git を使って実行されます。
