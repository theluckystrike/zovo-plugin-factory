DXF 図面を VS Code で表示する

DXF Viewer を入れて .dxf ファイルをクリックすると、CAD ソフトなしで図面が VS Code に表示されます。表示、シートの切り替え、レイヤー、文字検索、計測、ライブリロード、PNG と SVG の書き出しは無料です。Zovo Pro(USD 19 の買い切り)では 2 つの図面の比較、ブロック属性などの CSV 抽出、フォルダ内の図面一覧の作成が加わり、それぞれ 3 回まで無料で試せます。

VS Code にインストールMarketplace のページOpen VSX (Cursor、Windsurf、VSCodium)

無料、MIT ライセンス。 Extension ID zovo.dxf-viewer.

VS Code での手順

  1. Marketplace から DXF Viewer をインストールします。Ctrl+P (macOS では Cmd+P) を押して ext install zovo.dxf-viewer を実行しても入ります。
  2. エクスプローラーで .dxf ファイルをクリックします。R12 から AutoCAD 2018 までの ASCII とバイナリの DXF が開き、ブロック、入れ子の挿入、文字、寸法も描かれます。
  3. ペーパースペースのレイアウトがある図面では、Sheet リストでシートを選びます。タイトルブロックとビューポートが印刷時と同じ縮尺で表示され、ビューポートごとにフリーズされたレイヤーは表示されません。
  4. ドラッグか矢印キーでパン、スクロールでズームし、F キーかダブルクリックで全体を表示します。レイヤーパネルではレイヤーごとに表示と非表示を切り替えられ、B キーで背景を暗色と白に切り替えます。
  5. Ctrl+F(Mac は Cmd+F)で TEXT、MTEXT、ブロック属性の文字を検索します。Measure(ボタンか M キー)では 2 点間の距離、ΔX、ΔY、角度を測れ、端点や中心にスナップします。
  6. PNG(画面の 2 倍の解像度)や SVG(表示中のレイヤーをパスと文字で保存)に書き出せます。CAD ソフトで DXF を保存し直すと、ズーム、シート、レイヤーの状態を保ったまま表示が更新されます。

Cursor、Windsurf、VSCodium の場合

これらのエディターは Open VSX から拡張機能を入れます。Extensions ビュー (Ctrl+Shift+X) で zovo.dxf-viewer を検索して Install を押してください。Open VSX のページは zovo/dxf-viewer です。あとは VS Code と同じ手順で使えます。

無料でできること

DXF ファイルの表示、シート、レイヤー、文字検索、計測、ライブリロード、PNG と SVG の書き出しは無料で、今後も無料のままです。CAD ソフトや外部ツールは不要で、オフラインで動きます。図面を書き換えることはなく、ネットワーク通信やテレメトリもありません。

Zovo Pro で追加されるもの

Compare Two Drawings は図面の 2 つの版を比べてレポートを開きます。変わったレイヤーやブロック数に加え、追加、削除、変更された図形を古い値と新しい値付きで一覧にするので、REV A から REV B に変わった属性、移動したドア、書き換えた文字を目で探す必要がありません。ほかに、ブロック属性、ブロック数、文字、レイヤー一覧を Excel 用の CSV に書き出す Extract Block Attributes, Text or Layers to CSV と、フォルダ内のすべての .dxf を 1 図面 1 行の CSV にまとめる Inventory of a Folder of Drawings to CSV があります。

Compare Two Drawings の使い方

  1. エクスプローラーで 2 つの .dxf ファイルを選び、右クリックして「Zovo Pro: Compare drawings」を選びます。
  2. または、コマンドパレットで「DXF Viewer: Compare Two Drawings (Zovo Pro)」を実行し、比べる版を選びます。
  3. 変更点をまとめたレポートが開きます。

Compare Two Drawings はライセンスなしで 3 回まで使えます。ファイルを開いたときにポップアップが出たり、残り日数が表示されたりすることはありません。

できないこと

  • DWG ファイルは表示できません。.dwg を開くと DWG のバージョンと DXF への変換方法を示すページが出るので、AutoCAD、DWG TrueView、LibreCAD、ODA File Converter などで DXF に変換してください。
  • 3D の図形は平面として描かれ、3DSOLID、REGION、BODY は描かれません。
  • SHX と TrueType のフォントはサンセリフ体に置き換えられ、線の太さは反映されません。
  • 500 MB を超えるファイルは読み込まれません(dxfViewer.maxFileMB、最大 2048)。

よくある質問

無料で使えますか?

はい。図面の表示、シート、レイヤー、検索、計測、PNG と SVG の書き出しは無料です。図面の比較、CSV 抽出、フォルダ一覧の 3 つが Zovo Pro のツールで、それぞれ 3 回まで無料で試せます。CSV を保存したかレポートが開いたときだけ 1 回と数え、キャンセルでは減りません。

Cursor でも使えますか?

はい。Cursor は Open VSX から拡張機能をインストールします。拡張機能ビューで zovo.dxf-viewer を検索してインストールしてください。

DWG ファイルも開けますか?

いいえ。.dwg は案内ページが開くだけで、図面は表示されません。CAD ソフトや ODA File Converter で DXF に変換してから開いてください。

図面を編集できますか?

いいえ、表示専用です。図面が変更されることはなく、書き込むのは自分で選んだ書き出しファイルだけです。

すべての機能と設定は DXF Viewer のページ (英語) にあります。
