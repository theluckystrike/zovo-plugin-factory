PCAP と PCAPNG を VS Code で開いて解析する

PCAP Viewer を入れて .pcap や .pcapng をクリックすると、Wireshark も tshark もなしでパケット一覧、プロトコルツリー、Hex ペインが VS Code に表示されます。ディスプレイフィルタ、TCP/UDP ストリームの追跡、統計、pcap ファイルとしての書き出しは無料です。Zovo Pro(USD 19 の買い切り)ではチケットに貼れる Markdown のキャプチャレポート、パケット一覧の CSV/JSON 書き出し、フォルダ内のキャプチャの集計が加わり、それぞれ 3 回まで無料で試せます。

VS Code にインストールMarketplace のページOpen VSX (Cursor、Windsurf、VSCodium)

無料、MIT ライセンス。 Extension ID zovo.zovo-pcap-viewer.

VS Code での手順

  1. Marketplace から PCAP Viewer をインストールします。Ctrl+P (macOS では Cmd+P) を押して ext install zovo.zovo-pcap-viewer を実行しても入ります。
  2. .pcap、.pcapng、.pcap.gz、.pcapng.gz ファイルをクリックします。.cap など別の名前のファイルは、右クリックして「Open in PCAP Viewer」を選びます。
  3. パケットを選ぶとプロトコルツリーが表示されます。フィールドをクリックすると Hex ペインの該当バイトが強調され、バイトをクリックするとそのフィールドが選ばれます。
  4. フィルタ欄に tcp.port == 443 && ip.addr == 10.0.0.1 のような Wireshark 形式のディスプレイフィルタを入力して Enter を押します。正しい式なら欄が緑になり、よく使うフィルタは星のメニューに保存できます。
  5. パケットをダブルクリックすると、その TCP または UDP ストリームの中身が、クライアントからサーバーは赤、サーバーからクライアントは青で表示されます。ASCII、UTF-8、Hex ダンプを切り替え、コピーや保存もできます。
  6. コマンドパレットの「PCAP Viewer: Statistics (Conversations, Endpoints, Protocols)」でプロトコル階層、会話、エンドポイントを確認し、行をクリックしてフィルタをかけます。Ctrl+G(Mac は Cmd+G)で指定した番号のパケットに移動できます。

Cursor、Windsurf、VSCodium の場合

これらのエディターは Open VSX から拡張機能を入れます。Extensions ビュー (Ctrl+Shift+X) で zovo.zovo-pcap-viewer を検索して Install を押してください。Open VSX のページは zovo/zovo-pcap-viewer です。あとは VS Code と同じ手順で使えます。

無料でできること

パケット一覧、プロトコルツリー、双方向に連動する Hex ペイン、ディスプレイフィルタ、TCP/UDP ストリームの追跡、統計、選択またはフィルタ済みのパケットの pcap ファイルへの書き出しは無料です。pcap と pcapng(gzip 圧縮を含む)を読み、ARP、IPv4、IPv6、TCP、UDP、DNS、DHCP、HTTP/1.x、TLS の SNI と ALPN などを解析します。すべて JavaScript で処理するので Windows、macOS、Linux で外部ツールなしに動き、ホスト名はキャプチャ内の情報だけから表示され、ネットワークで問い合わせることはありません。テレメトリもありません。

Zovo Pro で追加されるもの

Capture Report は、チケットにそのまま貼れる Markdown ファイルを作ります。概要、プロトコル、上位のエンドポイントと会話(ストリームフィルタ付き)、DNS クエリと応答、TLS のサーバー名、HTTP リクエストとレスポンスコード、User-Agent、DHCP のホスト名が 1 つにまとまるので、画面を見ながら手で書き写す必要がありません。ほかに、フィルタで表示中のパケットを 1 行ずつ CSV か JSON に書き出す Export Packet List to CSV or JSON と、フォルダ内のキャプチャを 1 ファイル 1 行の CSV にまとめる Summarize a Folder of Captures to CSV があります。

Capture Report, Markdown の使い方

  1. キャプチャを開き、ツールバーの Export メニューからキャプチャレポートを選ぶか、コマンドパレットで「PCAP Viewer: Capture Report, Markdown (Pro)...」を実行します。
  2. 保存先を選んで「Save report」をクリックすると、Markdown ファイルが保存されます。

Capture Report, Markdown はライセンスなしで 3 回まで使えます。ファイルを開いたときにポップアップが出たり、残り日数が表示されたりすることはありません。

できないこと

  • TLS の復号、HTTP/2 の解析、ライブキャプチャには対応していません。HTTP は HTTP/1.x、QUIC はロングヘッダー、802.11 はヘッダーまでの解析です。
  • .gz のキャプチャは 512 MB まで展開し、そこで止まったことを表示します(pcapViewer.maxGzipMB)。
  • リモートや仮想ファイルシステム上のファイルは 256 MB まで開けます。ローカルのファイルはサイズに関係なく開けます。
  • .cap、.dmp、拡張子が .gz だけのファイルはクリックしても自動では開かないので、「Open in PCAP Viewer」を使います。

よくある質問

Wireshark のインストールは必要ですか?

いいえ。Wireshark、tshark、sharkd は不要で、拡張機能が JavaScript でファイルを読みます。

無料で使えますか?

はい。表示、フィルタ、ストリームの追跡、統計、pcap への書き出しは無料です。CSV/JSON への書き出し、キャプチャレポート、フォルダの集計が Zovo Pro のツールで、それぞれ 3 回まで無料で試せます。試用はファイルが書き出されたときだけ数え、Escape やエラーでは減りません。

Cursor でも使えますか?

はい。Cursor、Windsurf、VSCodium などの Open VSX 対応エディターで動きます。Cursor の拡張機能ビューで zovo.zovo-pcap-viewer を検索してインストールしてください。

大きなキャプチャも開けますか?

はい。ファイルは別スレッドで 4 MB ずつ読まれ、作者の確認では 1 GB、約 144 万パケットのキャプチャが約 2 秒で一覧表示されました。

すべての機能と設定は PCAP Viewer のページ (英語) にあります。
