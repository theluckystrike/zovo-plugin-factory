Claude Code と Codex の履歴を VS Code で読む

Agent Session Viewer を入れると、アクティビティバーの「Agent Sessions」に Claude Code と Codex のセッションがプロジェクトフォルダごとに並び、クリックするだけで読めます。閲覧、全セッションの検索、ターミナルでの再開、1 セッションの Markdown 書き出しは無料で、履歴の件数にも制限はありません。Zovo Pro(USD 19 の買い切り)を使うと、利用量とコストのレポート、秘密情報を伏せた書き出し、Markdown への一括書き出しが加わり、それぞれ 3 回まで無料で試せます。

VS Code にインストールMarketplace のページOpen VSX (Cursor、Windsurf、VSCodium)

無料、MIT ライセンス。 Extension ID zovo.agent-session-viewer.

VS Code での手順

  1. Marketplace から Agent Session Viewer をインストールします。Ctrl+P (macOS では Cmd+P) を押して ext install zovo.agent-session-viewer を実行しても入ります。
  2. アクティビティバーの「Agent Sessions」アイコンをクリックします。Claude Code(~/.claude/projects)と Codex(~/.codex/sessions)のセッションが 1 つのツリーにまとまり、サブエージェントは開始元のセッションの下に入ります。
  3. セッションをクリックして開きます。ヘッダーにはモデル、Git ブランチ、所要時間、ターン数、トークン数が表示され、ファイルの編集は diff で表示されます。コストはファイルに記録されている場合だけ表示されます(Claude Code は記録し、Codex は記録しません)。
  4. ビュー上部の検索アイコンで全セッションを検索します。結果を選ぶとセッションが一致箇所で開き、折りたたまれたツールの出力の中の一致も数えられます。
  5. 続きから作業するときは、セッションの横のターミナルアイコンをクリックします。プロジェクトフォルダでターミナルが開き、claude --resume または codex resume がセッション ID 付きで実行されます。
  6. コマンドだけ必要な場合は、右クリックメニューの「Copy Resume Command」を使います。先頭に cd を付けるかどうかは agentSessionViewer.resumeWithCd で切り替えられます。

Cursor、Windsurf、VSCodium の場合

これらのエディターは Open VSX から拡張機能を入れます。Extensions ビュー (Ctrl+Shift+X) で zovo.agent-session-viewer を検索して Install を押してください。Open VSX のページは zovo/agent-session-viewer です。あとは VS Code と同じ手順で使えます。

無料でできること

セッションツリー、セッションの閲覧、全セッションの検索、ターミナルでの再開、再開コマンドのコピー、1 セッションの Markdown 書き出し、生データの表示、ファイルマネージャーでの表示は無料で、件数の制限もありません。セッションファイルを変更、移動、削除することはなく、テレメトリ、ネットワーク通信、サインインもありません。

Zovo Pro で追加されるもの

Usage and Cost Report は、全セッション、1 つのプロジェクト、または 1 つのツールについて、指定した期間のトークン数を合計し、プロジェクト、モデル、日ごとのコストを API の定価で見積もります。結果は Markdown のレポートと、日・プロジェクト・モデルごとに 1 行の CSV で保存されるので、クライアントへの請求や表計算にそのまま使えます。ほかに、API キー、トークン、.env の値、メールアドレスなどを伏せ字にして HTML か Markdown で書き出す Share-Safe Export と、プロジェクトや期間ごとにセッションをまとめて Markdown ファイルにする Bulk Export to Markdown があります。

Usage and Cost Report の使い方

  1. Sessions ビューの「...」メニュー、またはツリーのプロジェクトフォルダの右クリックメニューから「Usage and Cost Report (Pro)…」を選びます。コマンドパレットの「Agent Sessions: Usage and Cost Report (Pro)…」からも始められます。
  2. 集計する範囲と期間を選ぶと、Markdown のレポートと CSV ファイルが保存されます。

Usage and Cost Report はライセンスなしで 3 回まで使えます。ファイルを開いたときにポップアップが出たり、残り日数が表示されたりすることはありません。

カードで支払う (USD 19、買い切り)

Zovo Pro は USD 19 の買い切りです。サブスクリプションではなく、すべての Zovo 拡張機能の Pro ツールが使えるようになります。カード (Stripe) で支払うと、次のページにライセンスキーが表示されます。VS Code のコマンドパレットで "Enter Zovo Pro license key" を実行し、キーを貼り付けてください。キーはネットワークを使わずに手元のパソコンで確認されます。

5 人までのチーム向けは USD 59 の買い切りで、カードで支払えます。ルールと Pro ツールの一覧は Zovo Pro のページ (英語) にあります。

できないこと

  • 読めるのは Claude Code と Codex のセッションだけです。Cursor、Copilot、Gemini CLI のセッションにはまだ対応していません。
  • 再開するには、Claude Code または Codex がインストールされ、ターミナルの PATH から使える必要があります。
  • 検索は正規表現ではなく通常のテキスト検索で、結果は 300 件で止まります。一覧に出るセッションは最大 2,000 件です(agentSessionViewer.maxSessions)。
  • Pro のレポートのコストは API の定価による見積もりです。Claude の Pro / Max プランや ChatGPT のプランはプラン単位で請求されます。

よくある質問

無料でどこまで使えますか?

閲覧、検索、再開、1 セッションの Markdown 書き出しは無料で、履歴の上限もありません。利用量とコストのレポート、秘密情報を伏せた書き出し、一括書き出しの 3 つが Zovo Pro のツールで、それぞれ 3 回まで無料で試せます。試用はツールがファイルを保存したときだけ数え、Escape やキャンセルでは減りません。

Cursor で使えますか?

Cursor は Open VSX から拡張機能をインストールするので、拡張機能ビューで zovo.agent-session-viewer を検索して入れられます。ただし、読めるのは Claude Code と Codex のセッションで、Cursor 自体のチャット履歴には対応していません。

セッションファイルが書き換えられることはありますか?

ありません。読み取り専用で、削除、移動、名前変更のコマンドもありません。書き込むのは、自分で選んだ書き出しファイルと Zovo Pro の状態を保存する ~/.zovo/pro.json だけです。

Anthropic や OpenAI の公式ツールですか?

いいえ。Anthropic とも OpenAI とも関係のない拡張機能です。

すべての機能と設定は Agent Session Viewer のページ (英語) にあります。
