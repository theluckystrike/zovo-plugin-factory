NetCDF と HDF5 のファイルを VS Code で見る

NetCDF Viewer & HDF5 Viewer を入れて .nc や .h5 をクリックすると、Python も NCL もなしで変数、メタデータ、値が VS Code に表示されます。表、折れ線グラフ、ヒートマップ、海岸線付きの地図、地点の時系列、PNG の保存、スライスの書き出しは無料です。Zovo Pro(USD 19 の買い切り)では 2 つのファイルの比較と、範囲を指定した変数の書き出しが加わり、それぞれ 3 回まで無料で試せます。

VS Code にインストールMarketplace のページOpen VSX (Cursor、Windsurf、VSCodium)

無料、MIT ライセンス。 Extension ID zovo.hdf5-netcdf-explorer.

VS Code での手順

  1. Marketplace から NetCDF Viewer & HDF5 Viewer をインストールします。Ctrl+P (macOS では Cmd+P) を押して ext install zovo.hdf5-netcdf-explorer を実行しても入ります。
  2. エクスプローラーで .nc、.nc4、.h5、.hdf5、.he5 などのファイルをクリックします。ncdump -h と同じように、形式、次元、グローバル属性、変数の一覧が表示されます。
  3. 左のツリーで変数を選びます。型、次元名付きの shape、チャンク、圧縮フィルタ、属性が表示され、scale_factor、add_offset、_FillValue と CF の時間単位はデコードされた値で表示されます。
  4. 行と列にする 2 つの次元を選び、ほかの次元はスライダーで動かします。1 次元は折れ線グラフ、2 次元はカラーバー付きのヒートマップになり、緯度経度のグリッドなら海岸線付きの地図として描かれます。スライダーの横の ▶ で時間を順に再生できます。
  5. 3 次元以上の変数では、ヒートマップのセルをクリックするとその地点の時系列が描かれます。PNG として保存するか、CSV としてコピーできます。
  6. 「Save PNG」でタイトル、単位、スライダーの位置、カラーバー付きの図を保存し、「Export slice…」で表示中のスライスを CSV か JSON に書き出します。

Cursor、Windsurf、VSCodium の場合

これらのエディターは Open VSX から拡張機能を入れます。Extensions ビュー (Ctrl+Shift+X) で zovo.hdf5-netcdf-explorer を検索して Install を押してください。Open VSX のページは zovo/hdf5-netcdf-explorer です。あとは VS Code と同じ手順で使えます。

無料でできること

NetCDF-4、NetCDF-3(classic と 64-bit offset)、CDF-5、HDF5 と HDF5 ベースの形式、MATLAB 7.3 の .mat の表示、ツリー、属性、表、グラフ、海岸線付きの地図、再生、時系列、統計、Save PNG、Export slice、xarray や h5py の読み込みコードのコピーは無料です。deflate や szip に加え、LZF、Blosc、Zstd などのプラグインフィルタで圧縮された HDF5 も Python なしで読めます。大きなファイルはバックグラウンドでスライスごとに読まれ、ファイルが変わると自動で再読み込みします。テレメトリはありません。

Zovo Pro で追加されるもの

Compare Two NetCDF or HDF5 Files は、nccmp のように 2 つのファイルを比べます。片方にしかない変数や、shape、型、属性の違いを一覧にし、両方にある数値変数は CF デコード後のすべての値を比べて、変数ごとに最大と平均の絶対差、RMSE、異なる値の数、欠損値や NaN の不一致、最大差の位置を出します。NetCDF-4 と NetCDF-3 のように形式が違っても比べられ、レポートは CSV、Markdown、JSON で保存できます。もう 1 つの Pro ツール Export Subset of a Variable は、ncks -d や xarray の .sel のように次元ごとの範囲を指定して、変数の一部を NetCDF か CSV に書き出します。

Compare Two NetCDF or HDF5 Files の使い方

  1. ファイルを開き、ビューア上部の「Compare with…」ボタンをクリックして比較相手のファイルを選びます。
  2. または、エクスプローラーで 2 つのファイルを選んで右クリックし、「Zovo Pro: Compare Two NetCDF or HDF5 Files」を選びます。
  3. 必要なら hdf5NetcdfExplorer.compareTolerance で許容誤差を設定します。レポートを絞り込み、CSV、Markdown、JSON のいずれかで保存します。

Compare Two NetCDF or HDF5 Files はライセンスなしで 3 回まで使えます。ファイルを開いたときにポップアップが出たり、残り日数が表示されたりすることはありません。

できないこと

  • .mat は MATLAB 7.3(HDF5 形式)だけに対応し、クリックしても自動では開きません。右クリックして「Open in HDF5 NetCDF Explorer」を選びます。v5 などの古い .mat は開けず、save(filename, '-v7.3') で保存し直すよう案内が出ます。
  • Zarr、HDF4、NASA CDF には対応していません。
  • Remote SSH、WSL、Dev Containers では使えますが、vscode.dev の GitHub リポジトリのような仮想ファイルシステムには対応していません。
  • 曲線格子(2 次元の緯度経度)や投影座標のグリッドには海岸線が描かれません。

よくある質問

無料で使えますか?

はい。表示、グラフ、地図、時系列、PNG の保存、スライスの書き出しは無料で、0.6.0 より前からある機能は今後も無料です。2 つのファイルの比較と変数の一部の書き出しが Zovo Pro のツールで、それぞれ 3 回まで無料で試せます。

Cursor でも使えますか?

はい。Cursor は Open VSX から拡張機能をインストールします。拡張機能ビューで zovo.hdf5-netcdf-explorer を検索してインストールしてください。

MATLAB の .mat ファイルは開けますか?

MATLAB 7.3 で保存した .mat(中身は HDF5)なら、右クリックの「Open in HDF5 NetCDF Explorer」で開けます。v5 などの古い形式は開けないので、MATLAB で save(filename, '-v7.3') として保存し直してください。

Python は必要ですか?

いいえ。Python も NCL も不要で、設定も要りません。

すべての機能と設定は NetCDF Viewer & HDF5 Viewer のページ (英語) にあります。
