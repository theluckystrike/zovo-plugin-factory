VS Code で動画を音付きで再生する

Video Preview with Sound を入れると、VS Code の標準プレイヤーでは音が出ない AAC 音声の MP4・MOV も、追加のインストールなしで音付きで再生できます。MKV、WebM、AVI などは、自分でインストールした ffmpeg があれば開けます。再生、字幕、コマ送り、A-B ループ、フレームの PNG 保存は無料です。Zovo Pro(USD 19、買い切り)では GIF / MP4 クリップの書き出し、フレームの一括書き出し、コンタクトシートが加わり、それぞれ 3 回まで無料で試せます。

VS Code にインストールMarketplace のページOpen VSX (Cursor、Windsurf、VSCodium)

無料、MIT ライセンス。 Extension ID zovo.video-preview-with-sound.

VS Code での手順

  1. Marketplace から Video Preview with Sound をインストールします。Ctrl+P (macOS では Cmd+P) を押して ext install zovo.video-preview-with-sound を実行しても入ります。
  2. エクスプローラーで動画ファイルをクリックし、Space で再生します。.mp4 を開くときにどのエディターを使うか聞かれたら、「Video Preview with Sound」を選びます。
  3. MP4・MOV の AAC 音声は、内蔵のデコーダー(Symphonia を WebAssembly にしたもの)が Windows、macOS、Linux のどれでも処理します。MKV、WebM、AVI を開くときや、Apple ProRes のように VS Code が再生できない映像を H.264 に変換するときは、先に ffmpeg をインストールしておきます(brew install ffmpeg、winget install ffmpeg、sudo apt install ffmpeg など)。
  4. 動画と同じフォルダにある .srt や .vtt の字幕は自動で読み込まれます。C キーか CC メニューで切り替えられます。
  5. , と . で 1 コマずつ戻る・進む、[ と ] で速度を変える(0.1 倍から 4 倍)、A と B でループ区間を決める、P でピクチャーインピクチャーにする、といった操作ができます。S キーを押すと、今のフレームを原寸の PNG で保存できます。
  6. I キーでメタデータパネルを開くと、コーデック、サイズ、フレームレート、ビットレート、サンプルレート、チャンネル数などを確認できます。止めた位置と再生速度は、次にその動画を開いたときに引き継がれます。

Cursor、Windsurf、VSCodium の場合

これらのエディターは Open VSX から拡張機能を入れます。Extensions ビュー (Ctrl+Shift+X) で zovo.video-preview-with-sound を検索して Install を押してください。Open VSX のページは zovo/video-preview-with-sound です。あとは VS Code と同じ手順で使えます。

無料でできること

再生、音声のデコード、ffmpeg を使った変換、字幕、コマ送り、速度の変更、A-B ループ、ピクチャーインピクチャー、フレームの PNG 保存、メタデータパネル、再生位置の記憶はすべて無料です。動画ファイルに書き込むことはなく、テレメトリーもありません。

Zovo Pro で追加されるもの

A と B で決めた区間(決めていなければ動画全体)を GIF または MP4 として保存します。GIF はプレイヤーの中で作られ、480 px・10 fps、640 px・15 fps、最大 960 px・15 fps から選べます(長さは最大 60 秒)。プルリクエストや issue、ドキュメントに貼る短い動画を、別のツールを使わずに作れます。MP4 は手元の ffmpeg で切り出し、A のフレームから H.264 / AAC で再エンコードする exact と、A の直前のキーフレームから元のストリームのまま切り出す fast copy を選べます。ほかに、フレームをまとめて PNG で保存する Export Frames as PNG と、16・30・48 コマを 1 枚の画像に並べる Contact Sheet of the Video があります。

Export a Clip as GIF or MP4 の使い方

  1. 動画を開き、必要なら A と B で書き出す区間を決めます。
  2. プレイヤーの Clip ボタンを押すか、エクスプローラーで動画を右クリックして「Zovo Pro: Export a Clip as GIF or MP4」を選びます。
  3. GIF か MP4 を選び、サイズなどを指定して保存します。書き出しは Esc で止められます。

Export a Clip as GIF or MP4 はライセンスなしで 3 回まで使えます。ファイルを開いたときにポップアップが出たり、残り日数が表示されたりすることはありません。

できないこと

  • MKV、WebM、AVI、AC-3 音声の再生と、すべての変換には ffmpeg が必要です。ffmpeg は同梱されていないため、ない場合は MKV と WebM を開けません。
  • 字幕は動画の外にある .srt / .vtt だけに対応しています。動画に埋め込まれた字幕は読み込みません。
  • .ts と .mts は TypeScript のファイル名と重なるため、この拡張機能では開きません。
  • 音声は最初にデコードされるので、それが終わるまでは無音で再生されます。4096 MB(videoPreview.maxDecodeSizeMB)を超えるファイルは音なしで再生されます。

よくある質問

無料で使えますか?

はい。再生、音声、字幕、変換は無料です。GIF / MP4 のクリップ書き出し、フレームの一括書き出し、コンタクトシートは Zovo Pro のツールで、それぞれ 3 回まで無料で試せます。試用回数はファイルを保存したときだけ減り、キャンセルや中止では減りません。

ffmpeg は必要ですか?

AAC、ALAC、MP3、PCM 音声の MP4 / MOV なら不要です。MKV、WebM、AVI、AC-3 音声、映像の変換、Pro ツールでの MP4 クリップの書き出しには、自分でインストールした ffmpeg が必要です。GIF、フレームの書き出し、コンタクトシートは ffmpeg なしで使えます。

Cursor でも使えますか?

はい。Open VSX からインストールできるので、Cursor、Windsurf、VSCodium でも使えます。

すべての機能と設定は Video Preview with Sound のページ (英語) にあります。
