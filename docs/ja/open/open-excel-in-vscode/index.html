VS Code で Excel ファイル（.xlsx）を開く方法

VS Code は .xlsx ファイルをそのままでは表として開けません。無料の拡張機能 Table Viewer は、.xlsx、.xlsm、.xlsb、.xls、.ods に加えて CSV と Parquet も、並べ替えとフィルターができる表として最大 1,000,000 行まで表示します。ブックの数値書式もそのまま使えます。Excel も Python も不要です。Zovo Pro（19 USD の買い切り）では、多数のファイルやブックの全シートを 1 つのファイルにまとめる機能などが使えます。

VS Code での手順

  1. Marketplace から Table Viewer をインストールします。または Ctrl+P（macOS では Cmd+P）を押して ext install zovo.table-viewer-vscode を実行します。
  2. エクスプローラーで .xlsx ファイルをクリックします。表として開き、ツールバーに行数と列数が表示されます。
  3. 列見出しをクリックすると並べ替えます。各見出しの下の入力欄でフィルターでき、たとえば >10 や 5..9 が使えます。上部の検索欄はすべての列を検索します。
  4. 「Excel formats」スイッチで、数値、パーセント、日付を Excel と同じ書式で表示します。セルをダブルクリックすると、値の全体がセルパネルに表示されます。
  5. 集計するときは Query をクリックし、GROUP BY などを使った SELECT を書いて Ctrl+Enter（Mac では Cmd+Enter）を押します。Stats では各列の件数、空の値、最小値、最大値、平均が見られます。

無料でできることと Zovo Pro で増えること

CSV、TSV、Excel、Parquet ファイルを開くこと、シート、フィルター、並べ替え、検索、列の統計、SQL フィルター、表の行に対する SQL クエリー、Git HEAD との比較、CSV、TSV、JSON、JSON Lines へのエクスポートは無料です。

12 個に分かれた月次レポートや、支店ごとにシートが分かれたブックを、Combine Files and Sheets で 1 つの CSV、XLSX、Parquet ファイルにまとめられます。列は見出しの名前で対応づけられ、source_file と source_sheet の列で各行の出どころがわかります。ほかの Pro ツールには、表に先頭の行しか読み込まれていないときのファイル全体へのクエリー、ほかのファイルとの JOIN、Parquet での保存があります。

Combine Files and Sheets（Zovo Pro）の手順

  1. ツールバーの Combine をクリックするか、Command Palette で「Excel Viewer Pro: Combine Files and Sheets (Pro)...」を実行します。エクスプローラーでフォルダー、選択した複数のファイル、またはブックを右クリックしても始められます。
  2. まとめる対象と、CSV、XLSX、Parquet のどれで保存するかを選びます。
  3. 保存先を選びます。元のファイルは変更されません。

Combine Files and Sheets は、ライセンスを求める前にお使いのコンピューターで 3 回まで使えます。ファイルを開いたときにポップアップやカウントダウンは出ません。

Cursor、Windsurf、VSCodium での手順

  1. Ctrl+Shift+X（macOS では Cmd+Shift+X）で Extensions ビューを開きます。
  2. zovo.table-viewer-vscode を検索して Install をクリックします。Cursor、Windsurf、VSCodium は Open VSX から拡張機能をインストールします。Open VSX での名前は zovo/table-viewer-vscode です。
  3. エディターに拡張機能のギャラリーがない場合は、Open VSX のページから .vsix をダウンロードし、「Extensions: Install from VSIX...」を実行します。
  4. あとは VS Code と同じように使えます。

できないこと

  • Table Viewer は読み取り専用です。セルの編集はできず、Export は選んだ新しいファイルだけに書き込みます。
  • .xls、.xlsb、.ods と小さな .xlsx はファイル全体を読み込み、上限は 50 MB です（設定 tableViewer.maxExcelSizeMB）。
  • 表に読み込むのは最大 1,000,000 行です（設定 tableViewer.maxRows）。それより多い場合はお知らせが出ます。

よくある質問

Excel は必要ですか？

いいえ。Table Viewer がファイルを直接読み込みます。Excel、Python、データベースは不要です。

セルを書き換えられますか？

いいえ。Table Viewer はビューアーです。編集には Excel、LibreOffice Calc、または表計算エディターを使ってください。

ファイルはアップロードされますか？

いいえ。オフラインで動き、サインインも不要です。
