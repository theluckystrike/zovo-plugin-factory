VS Code で bash や zsh のスクリプトを整形する

無料の Shell Formatter for Bash & Zsh をインストールし、シェルスクリプトを開いて Shift+Alt+F(Mac では Shift+Option+F)を押します。shfmt 3.14.1 のエンジンが WebAssembly として拡張機能に同梱されているので、ダウンロードするものはなく、出力は shfmt のコマンドラインとバイト単位で同じです。Format Document、Format Selection、保存時の整形、.editorconfig のキー、Problems に表示される構文エラーは無料で、オフラインで動作します。Zovo Pro(USD 19 の買い切り)では Format All Shell Scripts in a Folder、Formatting Check with a Patch File、Minify a Script to a Copy の 3 つのツールが加わり、それぞれ 3 回まで無料で試せます。

VS Code での手順

  1. Marketplace から Shell Formatter for Bash & Zsh をインストールします。または Ctrl+P（macOS では Cmd+P）を押して ext install zovo.zovo-shell-formatter を実行します。
  2. シェルスクリプトを開き、Shift+Alt+F(Mac では Shift+Option+F)を押します。VS Code がどのフォーマッターを使うか尋ねたら Shell Formatter を選ぶか、「Shell Formatter: Use as Default Formatter for Shell Scripts」を実行します。
  3. 保存のたびに整形するには、「Shell Formatter: Turn On Format on Save for Shell Scripts」を実行します。
  4. 方言(dialect)はまず 1 行目(#!/bin/bash、#!/bin/sh、#!/usr/bin/env zsh)から、次にファイル名(.bash、.zsh、.zshrc、.bats、.ksh)から決まり、どちらもなければ bash になります。自分で選ぶには、shellFormatter.dialect か .editorconfig の shell_variant を設定します。
  5. ステータスバーの shfmt 3.14.1 をクリックするとメニューが開きます。整形、既定のフォーマッターに設定、保存時に整形、「Copy the matching shfmt command (for CI)」、設定が並びます。
  6. スクリプトがシェルとして正しくない場合、ファイルは変更されず、Problems パネルに行と列が表示されます。

無料でできることと Zovo Pro で増えること

Format Document、Format Selection、保存時の整形、方言の判定、.editorconfig のキー、ステータスバーのメニュー、Copy the Matching shfmt Command (for CI)、Problems に表示される構文エラーは無料です。サインイン、ネットワーク通信、テレメトリーはありません。

Format All Shell Scripts in a Folder は、フォルダーとそのサブフォルダーにあるスクリプトをすべて調べ、何本が変わるかを示します。スクリプトは名前か、シェルを指定する #! 行で見つけます。そのうえで、Format Document と同じエンジン、設定、.editorconfig を使ってすべて整形するか、Markdown のレポートを出します。スタイルがばらばらのスクリプトが数十本あるリポジトリも 1 回の実行でスタイルがそろい、同じコマンドを実行しなくなるスクリプトはそのまま残ります。

Format All Shell Scripts in a Folder（Zovo Pro）の手順

  1. Explorer でフォルダーを右クリックして「Zovo Pro: Format All Shell Scripts in a Folder」を選ぶか、Command Palette またはステータスバーのメニューから「Shell Formatter: Format All Shell Scripts in a Folder (Pro)」を実行してフォルダーを選びます。
  2. 次のリストのタイトルに、変わるスクリプトの数が「N of M scripts would change」のように表示されます。
  3. 「Format N scripts」を選ぶと、各ファイルを整形して保存します(元に戻す操作はファイルごとに使えます)。「Show the report only」を選ぶと、何も変更せずに、すべてのスクリプトを並べた Markdown の一覧が開きます。
  4. 試用回数が減るのは、結果が出たときだけです。シェルスクリプトがないフォルダーや、すべてのスクリプトが整形済みのフォルダーでは減りません。

Format All Shell Scripts in a Folder は、ライセンスを求める前にお使いのコンピューターで 3 回まで使えます。ファイルを開いたときにポップアップやカウントダウンは出ません。

Cursor、Windsurf、VSCodium での手順

  1. Ctrl+Shift+X（macOS では Cmd+Shift+X）で Extensions ビューを開きます。
  2. zovo.zovo-shell-formatter を検索して Install をクリックします。Cursor、Windsurf、VSCodium は Open VSX から拡張機能をインストールします。Open VSX での名前は zovo/zovo-shell-formatter です。
  3. エディターに拡張機能のギャラリーがない場合は、Open VSX のページから .vsix をダウンロードし、「Extensions: Install from VSIX...」を実行します。
  4. あとは VS Code と同じように使えます。

Shell Formatter for Bash & Zsh で開けるもの

  • Bash、POSIX sh(dash と ash も)、mksh(ksh も)、bats、zsh のスクリプト。
  • shfmt 3.14.1 のコマンドラインと同じ出力。GitHub のプロジェクトと Homebrew の実際のスクリプト 178 本で、354 回中 354 回の実行がバイト単位で一致しました。
  • 変更を適用する前に、整形後のスクリプトをもう一度解析し、元と同じコマンドを実行することを確かめます(256 KB までのファイル)。
  • shfmt のオプションを設定または .editorconfig のキーで指定できます。インデント、二項演算子を次の行に置く、switch の case のインデント、リダイレクトの空白、パディングの維持、関数の波かっこを次の行に置く、simplify、minify です。
  • Windows の改行(CRLF)は CRLF のまま残り、2 MB のスクリプトは約 0.2 秒で整形できます。

できないこと

  • Dockerfile、.env ファイル、fish や csh のスクリプトには一切触れません。
  • shfmt の zsh 対応はまだ新しいものです。shfmt が解析できない zsh スクリプトは変更されません。
  • 10 MB を超えるファイル(設定 shellFormatter.maxFileMB)と、自己展開型のインストーラーのようにバイナリのバイトを含むファイルは整形されません。
  • shfmt は制限時間付きで実行されます(既定は 10 秒、設定 shellFormatter.timeoutSeconds)。制限に達すると、ファイルは変更されません。

よくある質問

無料で使えますか?

Format Document、Format Selection、保存時の整形、.editorconfig への対応は無料です。3 つの Pro ツール、Format All Shell Scripts in a Folder、Formatting Check with a Patch File、Minify a Script to a Copy は、それぞれ 3 回まで無料で試せます。その後は Zovo Pro が必要です。USD 19 の買い切りで、すべての Zovo 拡張機能に使えます。

shfmt をインストールする必要はありますか?

いいえ。shfmt 3.14.1 は WebAssembly として拡張機能に同梱されているので、何もダウンロードせずにオフラインで動作します。

スクリプトが壊れることはありませんか?

構文エラーのあるスクリプトは変更されません。変更を適用する前に、整形後のスクリプトをもう一度解析し、元と同じコマンドを実行することを確かめます。

Cursor でも使えますか?

はい。Cursor、Windsurf、VSCodium は Open VSX からインストールできます。Open VSX では zovo/zovo-shell-formatter として公開されています。
