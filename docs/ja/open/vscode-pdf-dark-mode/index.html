VS Code で PDF をダークモードで読む

PDF のダークモードの多くはページ全体を反転するので、写真の青空がオレンジ色になってしまいます。無料の拡張機能 PDF Reader は、ページを反転したあと、各画像の元のピクセルを上から描き直します。文字と背景は暗くなり、写真は本来の色のままです。セピアのページ、検索、目次、ページのサムネイル、ハイライトも使えます。Zovo Pro（19 USD の買い切り）では、ページ操作ツール、PDF の結合、すべての PDF のハイライトの書き出しが使えます。

VS Code での手順

  1. Marketplace から PDF Reader をインストールします。または Ctrl+P（macOS では Cmd+P）を押して ext install zovo.pdf-viewer-dark を実行します。
  2. エクスプローラーで .pdf ファイルをクリックします。VS Code がダークテーマならページは暗く、ライトテーマなら印刷したときと同じ見た目で表示されます。
  3. ツールバーの月のボタンか「PDF: Toggle Dark Pages」で、開いているファイルのダーク表示を切り替えます。「PDF: Toggle Sepia Pages」で温かみのあるセピアのページになります。
  4. テーマに関係なくダーク表示を固定したいときは、pdfViewer.darkMode を on または off にします。
  5. 文字を選択して H を押すとハイライトできます。Highlights タブに、すべてのハイライトがページ番号つきで並びます。

無料でできることと Zovo Pro で増えること

閲覧、ダークとセピアのページ、検索、目次とサムネイル、ハイライト、Copy as Markdown、ページへのリンクは無料です。

論文や仕様書をたくさん読むなら、ハイライトした箇所を 1 か所にまとめたくなります。Pro のエクスポートは、ハイライトしたすべての PDF（またはこのワークスペースの PDF だけ）のハイライトを 1 つの Markdown ファイルに書き出します。ファイルごとにまとめられ、色と各ページへのリンクがつきます。ほかの Pro ツールには、2 つの PDF の比較、ページの抽出・削除・分割による新しい PDF の作成、PDF の結合があります。

Export Highlights of All PDFs（Zovo Pro）の手順

  1. PDF の中で残しておきたい箇所をハイライトします。
  2. Command Palette で「PDF: Export Highlights of All PDFs to Markdown (Pro)...」を実行するか、Highlights タブの「All PDFs」をクリックします。
  3. Markdown ファイルの保存先を選びます。PDF 自体は変更されません。

Export Highlights of All PDFs は、ライセンスを求める前にお使いのコンピューターで 3 回まで使えます。ファイルを開いたときにポップアップやカウントダウンは出ません。

Cursor、Windsurf、VSCodium での手順

  1. Ctrl+Shift+X（macOS では Cmd+Shift+X）で Extensions ビューを開きます。
  2. zovo.pdf-viewer-dark を検索して Install をクリックします。Cursor、Windsurf、VSCodium は Open VSX から拡張機能をインストールします。Open VSX での名前は zovo/pdf-viewer-dark です。
  3. エディターに拡張機能のギャラリーがない場合は、Open VSX のページから .vsix をダウンロードし、「Extensions: Install from VSIX...」を実行します。
  4. あとは VS Code と同じように使えます。

できないこと

  • 線で描かれたグラフなどのベクター図形は、文字と同じように反転します。色が保たれるのは埋め込み画像だけです。
  • ハイライトはこのコンピューターの VS Code に保存され、PDF ファイルには書き込まれません。ほかの PDF アプリでは見えません。
  • フォームの入力、ページの編集、印刷はできません。

よくある質問

ダークモードで写真の色がおかしくなりませんか？

なりません。ページを反転したあと、埋め込み画像を元のピクセルで描き直すので、色はそのままです。

PDF ファイルは変更されますか？

いいえ。ダーク表示もハイライトもファイルを変更しません。

Ctrl+P を奪いませんか？

いいえ。Quick Open はそのまま使え、PDF 用のキーは PDF のタブがアクティブなときだけ有効です。
