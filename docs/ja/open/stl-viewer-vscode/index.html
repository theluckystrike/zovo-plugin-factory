VS Code で STL / OBJ / GLB を表示する

3D Model Viewer を入れると、.stl、.obj、.glb、.gltf、.ply、.3mf をクリックするだけで、VS Code の中に 3D で表示できます。表示、計測、シーンツリー、アニメーションの再生、スクリーンショットは無料です。Zovo Pro(USD 19、買い切り)では 3D プリント前のチェック、断面表示、ターンテーブルの書き出しが加わり、それぞれ 3 回まで無料で試せます。

VS Code にインストールMarketplace のページOpen VSX (Cursor、Windsurf、VSCodium)

無料、MIT ライセンス。 Extension ID zovo.3d-model-viewer.

VS Code での手順

  1. Marketplace から 3D Model Viewer をインストールします。Ctrl+P (macOS では Cmd+P) を押して ext install zovo.3d-model-viewer を実行しても入ります。
  2. エクスプローラーでモデルファイルをクリックします。別のビューアーで開いた場合は、右クリックして「Open in 3D Model Viewer」を選ぶか、「Reopen Editor With...」を使います。
  3. ドラッグで回転、右ドラッグまたは Shift + ドラッグで移動、スクロールでズームします。F キーでモデル全体を画面に合わせます。
  4. パネルで頂点、三角形、マテリアル、テクスチャの数と、モデル単位でのサイズを確認します。シーンツリー(最大 3,000 ノード)のチェックボックスで、ノードごとに表示を切り替えられます。
  5. M キーで計測モードにして 2 点をクリックすると、X、Y、Z の成分付きで距離が表示されます。W でワイヤーフレーム、N で法線、B でバウンディングボックス、G でグリッドを切り替えられます。
  6. glTF / GLB にアニメーションがあれば、クリップを選んで Space で再生と一時停止を切り替えます。ツールバーの Screenshot で PNG を保存できます。

Cursor、Windsurf、VSCodium の場合

これらのエディターは Open VSX から拡張機能を入れます。Extensions ビュー (Ctrl+Shift+X) で zovo.3d-model-viewer を検索して Install を押してください。Open VSX のページは zovo/3d-model-viewer です。あとは VS Code と同じ手順で使えます。

無料でできること

GLB と glTF 2.0(外部の .bin やテクスチャ、PBR マテリアル、アニメーションを含む)、バイナリと ASCII の STL、mtllib で指定された .mtl 付きの OBJ、メッシュと点群の PLY、3MF の表示はすべて無料です。計測、シーンツリー、表示の切り替え、スクリーンショットも無料で、three.js を内蔵しているため外部ツールは不要です。

Zovo Pro で追加されるもの

スライスする前にサイズ、体積、表面積を出し、メッシュが閉じているかどうか(開いた辺、非多様体の辺、向きが逆の面、面積ゼロの三角形、分かれたパーツの数)を調べます。「Mark problems」を押すと問題のある辺がモデル上に描かれ、PLA、PETG、ABS、ASA、TPU、ナイロン、PC、レジンから材料を選ぶと、重さ、フィラメントの長さ、材料費の目安が出ます。結果はコピーするか、Markdown / JSON で保存できます。ほかに、X、Y、Z の平面でモデルを切って断面の面積や周長を表示し、輪郭を SVG で保存できる Section View と、360 度回転する GIF または 72 枚の連番 PNG を書き出す Turntable Export があります。

Print Check の使い方

  1. モデルを開き、コマンドパレットで「3D Model Viewer: Print Check (Zovo Pro)」を実行するか、エクスプローラーでモデルを右クリックして「Zovo Pro: Print check」を選びます。
  2. サイドパネルの「Run print check」を押し、材料、インフィル、壁の厚さ、フィラメント径、1 kg あたりの価格を指定します。
  3. 結果を確認し、必要ならコピーするか、Markdown / JSON で保存します。

Print Check はライセンスなしで 3 回まで使えます。ファイルを開いたときにポップアップが出たり、残り日数が表示されたりすることはありません。

できないこと

  • FBX、DAE、USD、STEP、IGES、glTF 1.0 は開けません。
  • Draco や meshopt で圧縮された glTF と KTX2 テクスチャはデコードされず、メッセージが表示されます。
  • ファイル全体をメモリに読み込みます。既定の上限は 1 GB(modelViewer.maxFileMB、最大 4096)で、それを超えるファイルは読み込まれません。
  • STL、OBJ、PLY には単位がないため、座標の値がそのまま使われます。

よくある質問

無料で使えますか?

はい。モデルの表示、計測、シーンツリーは無料です。プリントチェック、断面表示、ターンテーブルの書き出しは Zovo Pro のツールで、それぞれ 3 回まで無料で試せます。

モデルファイルが書き換えられることはありますか?

ありません。モデルファイルには書き込まず、保存されるのはスクリーンショットや Pro ツールのレポートなど、自分で保存を選んだファイルだけです。

Cursor でも使えますか?

はい。Open VSX からインストールできるので、Cursor、Windsurf、VSCodium でも使えます。

すべての機能と設定は 3D Model Viewer のページ (英語) にあります。
