VS Code で C / C++ をワンクリックで実行する

Run C++ and C Code を入れると、エディタータイトルの Run ボタン(または Ctrl+Alt+Enter、Mac では Cmd+Alt+Enter)で、C / C++ のファイルをコンパイルしてそのまま実行できます。コンパイラは、パソコンにすでにある gcc、g++、clang、clang++ を使います。実行、入力とテストケースのパネル、ストレステスト、ベンチマークは無料です。Zovo Pro(USD 19、買い切り)ではサニタイザーチェック、-O0 / -O2 / -O3 の比較、テストレポートの保存が加わり、それぞれ 3 回まで無料で試せます。

VS Code にインストールMarketplace のページOpen VSX (Cursor、Windsurf、VSCodium)

無料、MIT ライセンス。 Extension ID zovo.zovo-run-cpp.

VS Code での手順

  1. Marketplace から Run C++ and C Code をインストールします。Ctrl+P (macOS では Cmd+P) を押して ext install zovo.zovo-run-cpp を実行しても入ります。
  2. .c または .cpp(.cc、.cxx も可)のファイルを開き、エディタータイトルの Run ボタンを押すか、Ctrl+Alt+Enter(Mac は Cmd+Alt+Enter)を押します。プログラムは「Run: file.cpp」という名前のターミナルで動くので、scanf や cin への入力をそのまま打てます。終わると終了コード、実行時間、ピークメモリが表示されます。
  3. コンパイルエラーと警告は、ファイル、行、列付きで Problems パネルに出ます。パスにスペースや &、ASCII 以外の文字が含まれていても、エラーの行に正しく移動できます。
  4. 「...」メニューの「Run with Input & Test Cases」を選ぶと Input & Tests パネルが開きます。入力を貼り付けて実行すると stdout、stderr、終了コード、実行時間、ピークメモリが表示され、テストケースとして保存しておけば、すべてまとめて実行して合否と行ごとの差分を確認できます。
  5. ファイルの先頭 40 行以内に // run: -O2 -lm と書くとそのファイル用のコンパイルフラグを、// args: "Hello World" 3 と書くとプログラムの引数を指定できます。
  6. 無限ループは Stop ボタン(実行中は同じキー)で止まり、プログラムが起動した子プロセスもまとめて終了します。クラッシュしたときは、シグナルとその一般的な意味が表示されます。
  7. 「...」メニューの「Debug C/C++ File」を選ぶと、CodeLLDB または Microsoft の C/C++ 拡張機能を使ってデバッグを始められます。

Cursor、Windsurf、VSCodium の場合

これらのエディターは Open VSX から拡張機能を入れます。Extensions ビュー (Ctrl+Shift+X) で zovo.zovo-run-cpp を検索して Install を押してください。Open VSX のページは zovo/zovo-run-cpp です。あとは VS Code と同じ手順で使えます。

無料でできること

ワンクリックでのコンパイルと実行、Problems パネルへのエラー表示、Input & Tests パネルとテストケース、ファイルごとのフラグと引数、デバッグの開始、フォルダ内の全ファイルのビルド、参照解と比べるストレステスト(最大 10,000 入力)、10 回実行するベンチマークはすべて無料です。ネットワーク通信やテレメトリーはなく、アカウントも不要です。

Zovo Pro で追加されるもの

AddressSanitizer と UndefinedBehaviorSanitizer(-fsanitize=address,undefined)を付けた別のビルドを作り、パネルの入力と保存済みのすべてのテストケースで実行します。ヒープやスタックのオーバーフロー、解放後の使用、符号付き整数のオーバーフローなどが見つかると、起きた行に Problems として表示されるので、フラグを自分で付けてビルドし直す必要がありません。ほかに、3 つの最適化レベルでビルドして実行時間、ピークメモリ、プログラムのサイズ、出力が同じかどうかを比べる Compare -O0, -O2 and -O3 と、JUnit XML と Markdown のレポートを保存する Save a Test Report (JUnit XML and Markdown) があります。

Sanitizer Check の使い方

  1. Input & Tests パネルに入力を入れるか、テストケースを保存しておきます。
  2. コマンドパレットで「Run C++: Sanitizer Check: AddressSanitizer and UBSan on the Input and Test Cases (Zovo Pro)」を実行するか、エクスプローラーでソースファイルを右クリックして「Zovo Pro: Sanitizer check」を選びます。
  3. 見つかった問題を Problems パネルで確認し、該当する行に移動します。

Sanitizer Check はライセンスなしで 3 回まで使えます。ファイルを開いたときにポップアップが出たり、残り日数が表示されたりすることはありません。

できないこと

  • コンパイラは同梱されておらず、ダウンロードもされません。gcc、g++、clang、clang++ のどれかを先にインストールしておく必要があります。
  • デバッグには CodeLLDB または Microsoft の C/C++ 拡張機能が必要です。
  • サニタイザーチェックにはサニタイザーのランタイムが必要です。macOS と Linux では gcc か clang、Windows では LLVM の clang を使います。MinGW の gcc にはランタイムがありません。
  • Input & Tests パネルとテストでの実行は 10 秒で打ち切られます(zovoRun.timeLimitSeconds)。ターミナルでの実行に時間制限はありません。

よくある質問

無料で使えますか?

はい。実行、Input & Tests パネル、テストケース、ストレステスト、ベンチマークは無料です。サニタイザーチェック、最適化レベルの比較、テストレポートは Zovo Pro のツールで、それぞれ 3 回まで無料で試せます。ビルドエラー、Stop、キャンセルでは試用回数は減りません。

コンパイラも一緒にインストールされますか?

いいえ。パソコンにある gcc、g++、clang、clang++ を PATH から探して使います。Windows では MSYS2、MinGW、WinLibs、TDM-GCC、Chocolatey、Scoop、LLVM のフォルダも探します。見つかったコンパイラは「Pick Compiler (gcc, g++, clang, clang++)」で確認できます。

Cursor でも使えますか?

はい。Open VSX からインストールできるので、Cursor、Windsurf、VSCodium でも使えます。

すべての機能と設定は Run C++ and C Code のページ (英語) にあります。
