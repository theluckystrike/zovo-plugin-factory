XMind ファイルを VS Code で開く

XMind Viewer を入れると、.xmind ファイルをクリックするだけで、XMind がなくても VS Code でマインドマップを表示できます。XMind 2020〜2026 と XMind Zen、XMind 8 以前の形式に対応し、表示、検索、PNG・SVG・Markdown への書き出しは無料です。Zovo Pro(USD 19、買い切り)では全シートの PDF 書き出し、CSV(Excel)/ OPML への書き出し、フォルダの一括変換が加わり、それぞれ 3 回まで無料で試せます。

VS Code にインストールMarketplace のページOpen VSX (Cursor、Windsurf、VSCodium)

無料、MIT ライセンス。 Extension ID zovo.xmind-mind-map-viewer.

VS Code での手順

  1. Marketplace から XMind Viewer をインストールします。Ctrl+P (macOS では Cmd+P) を押して ext install zovo.xmind-mind-map-viewer を実行しても入ります。
  2. エクスプローラーで .xmind ファイルをクリックします。FreeMind / Freeplane の .mm と .opml も同じように開けます。
  3. シートごとにタブが表示されます。ラベル付きの関係線、タイトル付きの境界、サマリー、マーカー、ラベル、ノート、ファイル内の画像、KaTeX で描かれる LaTeX の数式も表示されます。
  4. ドラッグで移動し、Ctrl / Cmd + ホイール(またはピンチ)でポインターの位置を中心にズームします。F で全体を表示し、0 で 100% に戻ります。
  5. 枝の端の丸をクリックするか、トピックをダブルクリックするか、Space で枝を折りたたみます。折りたたんだ枝には隠れているトピックの数が表示され、XMind で折りたたまれていた枝は折りたたまれたまま開きます。Levels で 1〜4 階層目までに絞ることもできます。
  6. Ctrl / Cmd + F で、タイトル、ノート、ラベル、数式を検索します。折りたたまれた枝の中も検索されます。
  7. PNG(最大 2 倍)、SVG、シートの Markdown アウトライン(クリップボード)、全シートをまとめた Markdown ファイルに書き出せます。

Cursor、Windsurf、VSCodium の場合

これらのエディターは Open VSX から拡張機能を入れます。Extensions ビュー (Ctrl+Shift+X) で zovo.xmind-mind-map-viewer を検索して Install を押してください。Open VSX のページは zovo/xmind-mind-map-viewer です。あとは VS Code と同じ手順で使えます。

無料でできること

表示、レイアウトの切り替え(map、logic chart の右・左、tree、org chart の下・上)、検索、詳細パネル、PNG・SVG・Markdown への書き出しはすべて無料です。オフラインで動作し、サインインやネットワーク通信はありません。日本語や絵文字のタイトルも VS Code のフォントで表示されます。

Zovo Pro で追加されるもの

すべてのシートを 1 つの PDF にまとめます。1 シートが 1 ページになり、印刷向けの色で、シートごとのしおりも付きます。シートを 1 枚ずつ画像にして資料に並べる手間がかかりません。ほかに、全シートの全トピックを表(シート、階層、パス、ノート、ラベル、マーカー、リンク)または OPML のアウトラインとして書き出す Export the map as CSV (Excel) or OPML と、フォルダとサブフォルダ内の .xmind、.mm、.opml をまとめて Markdown、CSV、OPML に変換する Convert a folder of mind maps to Markdown, CSV or OPML があります。

Export every sheet as PDF の使い方

  1. マップを開いて Export メニューから PDF を選ぶか、コマンドパレットで「XMind Viewer: Export every sheet as PDF (Zovo Pro)」を実行します。エクスプローラーでファイルを右クリックして「Zovo Pro: PDF of every sheet」を選んでも同じです。
  2. 保存先を選ぶと、全シートを含む PDF が保存されます。

Export every sheet as PDF はライセンスなしで 3 回まで使えます。ファイルを開いたときにポップアップが出たり、残り日数が表示されたりすることはありません。

できないこと

  • 表示専用です。マップを変更するには、XMind や Freeplane などのエディターを使ってください。
  • パスワードで保護されたマップは開けません。
  • フィッシュボーン、タイムライン、マトリックス、ブレースのシートは logic chart か org chart として描かれます。XMind で手で動かしたトピックの位置は保持されません。
  • XMind のテーマのフォント、線の形、トピックの形は再現されません。塗りと文字の色は反映されます。

よくある質問

無料で使えますか?

はい。表示、検索、PNG・SVG・Markdown への書き出しは無料です。PDF、CSV(Excel)/ OPML への書き出しとフォルダの一括変換は Zovo Pro のツールで、それぞれ 3 回まで無料で試せます。試用回数はファイルを保存したときだけ減ります。

XMind 8 の古いファイルも開けますか?

はい。content.xml 形式の XMind 8 と XMind 7、さらに古い 3.x のファイルも開けます。content.json 形式の XMind 2020〜2026 と XMind Zen にも対応しています。

Cursor でも使えますか?

はい。Open VSX からインストールできるので、Cursor、Windsurf、VSCodium でも使えます。

すべての機能と設定は XMind Viewer のページ (英語) にあります。
