pickle ファイル(.pkl)を Python なしで開く

Pickle Viewer & PKL Viewer を入れると、.pkl や .pickle ファイルを Python なしで VS Code で開けます。ファイルは何もインポートせず何も呼び出さないリーダーでデコードされるので、悪意のある pickle でもコードは実行されません。ツリー、NumPy 配列、pandas の表、オペコード一覧、安全チェックは無料です。Zovo Pro(USD 19、買い切り)では JSON / CSV への全行エクスポートと、フォルダ内の危険な pickle をまとめて調べるスキャンが加わり、それぞれ 3 回まで無料で試せます。

VS Code にインストールMarketplace のページOpen VSX (Cursor、Windsurf、VSCodium)

無料、MIT ライセンス。 Extension ID zovo.zovo-pickle-viewer.

VS Code での手順

  1. Marketplace から Pickle Viewer & PKL Viewer をインストールします。Ctrl+P (macOS では Cmd+P) を押して ext install zovo.zovo-pickle-viewer を実行しても入ります。
  2. エクスプローラーで .pkl または .pickle ファイルをクリックします。.p ファイルは Progress ABL のソースコードと拡張子が同じため自動では開かないので、右クリックして「Open in PKL Viewer」を選びます。
  3. Tree タブで、デコードされたオブジェクトを型、長さ、値と一緒に確認します。dict のキーの型、tuple、bytes、set、datetime、大きな整数は Python の型のまま表示されます。復元できないクラスは module.Class という名前のプレースホルダーになり、ファイルに保存されている属性を確認できます。
  4. Arrays タブでは、dtype が通常の数値型の NumPy 配列について、shape、dtype、min、max、mean、NaN の数、先頭の値のグリッドを確認できます。2 次元以上の配列はヒートマップでも表示されます。
  5. Tables タブでは、pandas の DataFrame が列の dtype とインデックス付きの表で表示されます。
  6. Safety タブで、Python で読み込んだときにインポートまたは呼び出される名前の一覧を確認します。os.system、subprocess.Popen、builtins.eval などは Risky と表示され、危険なファイルでは赤いバナーが出て、最初からこのタブが開きます。Opcodes タブには pickletools.dis に近い形式のオペコード一覧があります。

Cursor、Windsurf、VSCodium の場合

これらのエディターは Open VSX から拡張機能を入れます。Extensions ビュー (Ctrl+Shift+X) で zovo.zovo-pickle-viewer を検索して Install を押してください。Open VSX のページは zovo/zovo-pickle-viewer です。あとは VS Code と同じ手順で使えます。

無料でできること

Tree、Arrays、Tables、Opcodes、Safety の各タブはすべて無料です。Python は不要で、オフラインで動作し、ネットワーク通信やテレメトリーはありません。デコードはワーカースレッドで行われるため、大きなファイルを開いても VS Code の操作は止まりません。

Zovo Pro で追加されるもの

フォルダ内の .pkl、.pickle、.p、.joblib、.dill ファイルと、PyTorch の .pt、.pth、.ckpt、.bin チェックポイントに含まれる pickle をまとめて調べ、Markdown のレポートを 1 つ保存します。危険なファイルが先頭に並び、Python がインポートまたは呼び出す名前とそのバイトオフセットが記載されるので、ダウンロードしたモデルファイルを 1 つずつ開いて確かめる必要がありません。調べる間もファイルは読み込まれず、実行もされません。もう 1 つの Pro ツール Export Pickle to JSON or CSV は、オブジェクト全体を JSON に、または pandas の DataFrame と 1 次元・2 次元の NumPy 配列を全行の CSV に保存します。

Scan a Folder for Unsafe Pickles and PyTorch Files の使い方

  1. エクスプローラーでフォルダを右クリックし、「Zovo Pro: Scan a folder for unsafe pickles」を選びます。コマンドパレットで「PKL Viewer: Scan a Folder for Unsafe Pickles and PyTorch Files (Zovo Pro)」を実行しても同じです。
  2. 保存された Markdown レポートを開き、先頭に並んだ危険なファイルと、それぞれの名前が現れるバイトオフセットを確認します。

Scan a Folder for Unsafe Pickles and PyTorch Files はライセンスなしで 3 回まで使えます。ファイルを開いたときにポップアップが出たり、残り日数が表示されたりすることはありません。

できないこと

  • 512 MB を超えるファイルはメッセージが表示され、読み込まれません。上限は設定 pickleViewer.maxFileMB で最大 2048 MB まで変更できます。
  • 圧縮された配列を含む joblib ファイル、PyTorch の .pt zip アーカイブ、.npy ファイルは、ここでいう pickle ではないため開けません。
  • Safety タブの一覧に問題がなくても、ファイルが安全だという保証にはなりません。Python で読み込むのは信頼できる pickle だけにしてください。
  • 大きなコンテナは最初の 1,000 項目、ツリーは 50,000 ノード、表は最初の 1,000 行まで表示されます。オペコードの集計と安全チェックは常にファイル全体が対象です。

よくある質問

無料で使えますか?

はい。pickle を開いて Tree、Arrays、Tables、Opcodes、Safety の各タブで中身を確認する機能はすべて無料です。JSON / CSV エクスポートとフォルダのスキャンは Zovo Pro のツールで、それぞれ 3 回まで無料で試せます。試用回数はツールがファイルを保存したときだけ減ります。

Cursor でも使えますか?

はい。Open VSX からインストールできるので、Cursor、Windsurf、VSCodium でも使えます。

開いただけで pickle のコードが実行されることはありませんか?

ありません。ファイルは何もインポートせず何も呼び出さないリーダーでデコードされます。Python も使わないので、悪意のある pickle を開いてもパソコンには影響しません。

PyTorch のモデルファイルは開けますか?

PyTorch の .pt zip アーカイブはビューアーでは開けません。Pro ツールの Scan a Folder for Unsafe Pickles and PyTorch Files を使うと、.pt、.pth、.ckpt、.bin に含まれる pickle の安全チェックができます。

すべての機能と設定は Pickle Viewer & PKL Viewer のページ (英語) にあります。
