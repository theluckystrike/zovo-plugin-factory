VS Code で XML を整形し、XPath を実行する

無料の XML Formatter & XPath Tools をインストールし、XML ファイルを開いて Shift+Alt+F(Mac では Shift+Option+F)を押します。変わるのはタグ間の空白だけです。テキスト、CDATA、コメント、xml:space="preserve"、属性値は 1 バイトも変わらず、整形式でないファイルは一切変更されません。整形、Minify XML、ファイル自身の名前空間プレフィックスを使う XPath 1.0、Copy XPath、XML Tree ビューは無料で、オフラインで動きます。Zovo Pro(USD 19 の買い切り)では Run XPath on Every XML File in a Folder、Format All XML Files in a Folder、Compare Two XML Files Ignoring Formatting の 3 つのツールが加わり、それぞれ 3 回まで無料で試せます。

VS Code での手順

  1. Marketplace から XML Formatter & XPath Tools をインストールします。または Ctrl+P（macOS では Cmd+P）を押して ext install zovo.zovo-xml-xpath-tools を実行します。
  2. .xml ファイルを開いて Shift+Alt+F(Mac では Shift+Option+F)を押すか、Format Document を実行します。XML のフォーマッターが複数ある場合は、どれを使うか VS Code が尋ねます。Format Selection も使えます。
  3. フォーマッターはタブのサイズと、タブかスペースかの設定に従い、改行コード、BOM(バイトオーダーマーク)、末尾の改行を保ちます。ファイルが整形式でない場合は何も変更せず、エラーを行と列付きで表示します。
  4. ファイルを小さくしたい場合は、ファイル全体または選択範囲に対して「XML: Minify XML」を実行します。xmlXpathTools.minify.removeComments をオンにしない限り、コメントは残ります。
  5. XPath を実行するには、エディターのタイトルにある検索ボタンをクリックするか、「XML: Evaluate XPath…」を実行します。結果は行番号付きで XPath Results に並びます。結果をクリックすると、エディターでその箇所が選択されます。
  6. ステータスバーの XPath をクリックすると、カーソル位置の要素のパスをコピーできます。位置付き、id 属性や name 属性付き、local-name() を使うポータブルな形式から選べます。
  7. 50 MB を超えるファイルは、Explorer で右クリックして「Format Large XML File on Disk…」を選びます。隣に name.formatted.xml を書き出すか、確認のうえで元のファイルを置き換えます。

無料でできることと Zovo Pro で増えること

Format Document、Format Selection、Minify XML、XPath 1.0、Copy XPath、XML Tree ビュー、Problems に出る整形式エラー、Format Large XML File on Disk は無料です。サインインは不要で、拡張機能にネットワーク処理のコードはありません。

Run XPath on Every XML File in a Folder は、フォルダー内の .xml、.xsd、.csproj、.svg、.kml などのファイルすべてに 1 つの XPath を実行します。名前空間プレフィックスは、ファイルごとに自身のものが使われます。結果は表計算ソフト向けの CSV(file、line、kind、name、value)、スクリプト向けの JSON、レビュー向けの Markdown レポートで開けます。複数の pom.xml にあるすべての artifactId のように、多くのファイルから同じ値を 1 つずつ開かずに取り出せます。

Run XPath on Every XML File in a Folder（Zovo Pro）の手順

  1. Explorer でフォルダーを右クリックして「Zovo Pro: Run XPath on Every XML File in a Folder」を選ぶか、Command Palette から「XML: Run XPath on Every XML File in a Folder (Pro)」を実行してフォルダーを選びます。
  2. 1 つのファイルで XPath を実行した後なら、XPath Results の最後の行「Run this XPath on every XML file in a folder」をクリックして、同じ式をフォルダーに実行することもできます。
  3. XPath を入力します。通知に進行状況と Cancel ボタンが表示されます。
  4. 「Open as CSV」、「Open as JSON」、「Open a Markdown report」のいずれかを選びます。結果は新しいエディタータブで開きます。試用回数が減るのは結果が出たときだけです。Escape を押したとき、XPath の入力ミス、XML ファイルのないフォルダーでは回数は減りません。

Run XPath on Every XML File in a Folder は、ライセンスを求める前にお使いのコンピューターで 3 回まで使えます。ファイルを開いたときにポップアップやカウントダウンは出ません。

Cursor、Windsurf、VSCodium での手順

  1. Ctrl+Shift+X（macOS では Cmd+Shift+X）で Extensions ビューを開きます。
  2. zovo.zovo-xml-xpath-tools を検索して Install をクリックします。Cursor、Windsurf、VSCodium は Open VSX から拡張機能をインストールします。Open VSX での名前は zovo/zovo-xml-xpath-tools です。
  3. エディターに拡張機能のギャラリーがない場合は、Open VSX のページから .vsix をダウンロードし、「Extensions: Install from VSIX...」を実行します。
  4. あとは VS Code と同じように使えます。

XML Formatter & XPath Tools で開けるもの

  • VS Code が XML として開くファイル。さらにこの拡張機能は、.kml、.gpx、.rss、.atom、.wsdl、.dbk、.xlf、.xliff、.resx、.nuspec、.props、.targets、.xaml のファイルも XML として開きます。
  • 大きなファイル。整形、ツリー、XPath はバックグラウンドのスレッドで動きます。拡張機能のテストでは、約 100 万個の要素を含む 49 MB のファイルが 1.6 秒で整形されました。
  • プレフィックスのない名前はデフォルト名前空間にも一致するので、pom.xml で //dependency/artifactId がそのまま使えます。厳密な XPath 1.0 にするには、xmlXpathTools.xpath.strictNamespaces をオンにします。
  • 属性のレイアウトは、書いたまま、1 行にまとめる、1 行に 1 属性、から選べます(設定 xmlXpathTools.format.attributes)。
  • Explorer の XML Tree ビューはカーソルに追従し、Problems には整形式エラーが行と列付きで表示されます。

できないこと

  • XPath 1.0 のみです。XPath 2.0 や 3.1、XQuery、XSLT には対応していません。
  • ファイルが整形式かどうかは確認しますが、XSD や DTD による検証はしません。
  • 50 MB を超えるファイルはディスク上で整形できますが、VS Code が拡張機能に渡さないため、ツリーと XPath は使えません。
  • ディスク上で整形するコマンドが読めるのは、UTF-8、BOM 付きの UTF-16、ISO-8859-1 です。
  • <p>Some <b>bold</b> text</p> のようにテキストを含む要素は、書いたままの行に残ります。改行が加わるのは、タグだけを含みテキストを含まない要素です。

よくある質問

無料で使えますか?

整形、Minify XML、XPath、Copy XPath、XML Tree ビュー、整形式のチェックは無料です。3 つの Pro ツール、Run XPath on Every XML File in a Folder、Format All XML Files in a Folder、Compare Two XML Files Ignoring Formatting は、それぞれ 3 回まで無料で試せます。その後は Zovo Pro が必要です。USD 19 の買い切りで、すべての Zovo 拡張機能に使えます。

整形でテキストや CDATA が変わりますか?

いいえ。変わるのはタグ間の空白だけで、それもタグだけを含みテキストを含まない要素の中に限られます。テキスト、CDATA、コメント、xml:space="preserve" の中身はそのままコピーされ、2 回目の整形では何も変わりません。

pom.xml で XPath が何も選択しないのはなぜですか?

そのファイルにはデフォルト名前空間があります。この拡張機能では、プレフィックスのない名前がデフォルト名前空間にも一致するので、//dependency が使えます。厳密な XPath 1.0 にするには、xmlXpathTools.xpath.strictNamespaces をオンにします。

Cursor でも使えますか?

はい。Cursor、Windsurf、VSCodium は Open VSX からインストールできます。Open VSX では zovo/zovo-xml-xpath-tools として公開されています。
