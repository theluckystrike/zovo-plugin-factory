VS Code で SQLite データベースを編集する

SQLite DB Viewer を入れると、.db や .sqlite ファイルが VS Code で読み取り専用で開き、「Enable editing」を押すとセルや行の編集、SQL の実行、CSV のインポートができます。表示、編集、バックアップ付きの保存、CSV / TSV のインポートは無料です。Zovo Pro(USD 19、買い切り)では 2 つのデータベースの比較、ER 図の作成、全テーブルの一括エクスポートが加わり、それぞれ 3 回まで無料で試せます。

VS Code にインストールMarketplace のページOpen VSX (Cursor、Windsurf、VSCodium)

無料、MIT ライセンス。 Extension ID zovo.sqlite-table-viewer.

VS Code での手順

  1. Marketplace から SQLite DB Viewer をインストールします。Ctrl+P (macOS では Cmd+P) を押して ext install zovo.sqlite-table-viewer を実行しても入ります。
  2. エクスプローラーで .db、.sqlite、.sqlite3 などのファイルをクリックします。最初は読み取り専用で開き、並べ替え、列ごとのフィルター、全列の検索、Schema タブで中身を確認できます。
  3. 「Enable editing」をクリックして編集を有効にします。別のプログラムがファイルを開いているときや、-wal ファイルにメインファイルへまだ反映されていないトランザクションがあるときは、その前に知らせてくれます。
  4. セルをダブルクリック(または Enter、F2)して値を変え、+ Row、Duplicate、Delete で行を操作します。SQL タブでは INSERT、UPDATE、DELETE などを実行できます。変更はすべて SQL 付きの保留リストに入り、Undo で取り消せます。
  5. Ctrl+S(Mac は Cmd+S)で保存します。保存時には外部キーと PRAGMA quick_check が確認され、name.db.20261109-143000.bak のようなバックアップを作ってから、一時ファイルに書き込んで元のファイルと置き換えます。開いた後でディスク上のファイルが変わっていた場合は保存が中止され、変更は残ります。
  6. CSV や TSV は、新しいデータベースにも既存のテーブルにも取り込めます。新しいデータベースを作る場合は、エクスプローラーで CSV ファイルを右クリックして「Import CSV into a new SQLite database…」を選びます。区切り文字、文字コード、ヘッダー行、列の対応を指定でき、100 万行を約 2 秒で取り込めます。

Cursor、Windsurf、VSCodium の場合

これらのエディターは Open VSX から拡張機能を入れます。Extensions ビュー (Ctrl+Shift+X) で zovo.sqlite-table-viewer を検索して Install を押してください。Open VSX のページは zovo/sqlite-table-viewer です。あとは VS Code と同じ手順で使えます。

無料でできること

開く、読む、SQL タブ、セルと行の編集、バックアップ付きの保存、列の変換付きの CSV / TSV インポート、列の追加・名前変更・削除などのテーブル操作、表示中の行の CSV・JSON・SQL INSERT へのエクスポートはすべて無料です。SQLite は WebAssembly で動くので別途インストールは不要で、ネットワーク通信とテレメトリーはありません。

Zovo Pro で追加されるもの

2 つの SQLite ファイルのテーブル、列、インデックス、ビュー、トリガー、行(主キーまたは rowid で対応付け)を比べ、差分をまとめた Markdown のレポートと、2 つ目のデータベースを 1 つ目に合わせる a-vs-b-sync.sql を作ります。スクリプトはエディターで開かれるだけで、勝手に実行されることはありません。どこが違うのかを表ごとに手で探す必要がなくなります。ほかに、SVG と Mermaid の ER 図と Markdown のスキーマ文書を作る ER Diagram of a SQLite Database と、全テーブルを 1 つの Excel ブックまたはテーブルごとの CSV に書き出す Export All SQLite Tables to Excel or CSV があります。どのツールもデータベースを読むだけで、書き込むことはありません。

Compare SQLite Databases の使い方

  1. エクスプローラーで 1 つ目のデータベースファイルを右クリックし、「Zovo Pro: Compare SQLite Databases」を選びます。コマンドパレットの「Compare SQLite Databases (Pro)…」や、エディターの DB tools ボタンからも始められます。
  2. 比べるもう 1 つのデータベースを選びます。
  3. 保存された Markdown レポートと a-vs-b-sync.sql を確認します。

Compare SQLite Databases はライセンスなしで 3 回まで使えます。ファイルを開いたときにポップアップが出たり、残り日数が表示されたりすることはありません。

できないこと

  • データベース全体をメモリに読み込むため、開けるのは 512 MB まで、編集できるのは 256 MB までです。それより大きいファイルは読み取り専用で開きます。
  • SQLCipher や SEE で暗号化されたデータベースは開けません。
  • 編集できるのはローカルのファイルだけです。リモートや仮想ファイルシステム上のファイルは読み取り専用で開きます。
  • 未保存の変更があるままタブを閉じると、その変更は失われます。

よくある質問

無料で使えますか?

はい。表示、編集、保存、CSV のインポートは無料で、アカウントも不要です。データベースの比較、ER 図、全テーブルのエクスポートは Zovo Pro のツールで、それぞれ 3 回まで無料で試せます。Esc やエラーでは試用回数は減りません。

アプリが使っているデータベースを開いても大丈夫ですか?

ファイルはメモリに読み込まれた後すぐに閉じられるので、ほかのプログラムは開いている間も書き込みを続けられます。-wal ファイルのコミット済みトランザクションも読み込み、1 秒ごとに変更を確認して再読み込みします。編集中は再読み込みせず、通知だけを表示します。

Cursor でも使えますか?

はい。Open VSX からインストールできるので、Cursor、Windsurf、VSCodium でも使えます。

すべての機能と設定は SQLite DB Viewer のページ (英語) にあります。
