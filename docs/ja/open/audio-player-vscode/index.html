VS Code で音声ファイルを再生・解析する

Audio Player & WAV Player を入れると、.wav、.mp3、.flac、.ogg、.opus をクリックするだけで VS Code の中で再生でき、波形、スペクトログラム、ラウドネスメーターも表示されます。.m4a と .aac の再生には、自分でインストールした ffmpeg が必要です。再生、波形、スペクトログラム、ラウドネスメーターは無料です。Zovo Pro(USD 19、買い切り)ではラウドネスのノーマライズとフォルダのラウドネスレポートが加わり、それぞれ 3 回まで無料で試せます。

VS Code にインストールMarketplace のページOpen VSX (Cursor、Windsurf、VSCodium)

無料、MIT ライセンス。 Extension ID zovo.audio-preview-vscode.

VS Code での手順

  1. Marketplace から Audio Player & WAV Player をインストールします。Ctrl+P (macOS では Cmd+P) を押して ext install zovo.audio-preview-vscode を実行しても入ります。
  2. エクスプローラーで音声ファイルをクリックし、Space で再生します。別のプレイヤーで開いた場合は、右クリックして「Open in Audio Preview」を選ぶか、「Reopen Editor With...」を使います。
  3. 波形はチャンネルごと(最大 8 チャンネル)に表示され、クリックするとその位置に移動します。波形の上をドラッグすると A-B ループの区間になり、[ と ] で開始と終了の位置を、L でループのオンとオフを切り替えられます。
  4. 再生速度は、音程を保ったまま 0.25 倍から 2 倍まで変えられます。左右の矢印キーで 5 秒(Shift を押しながらなら 1 秒)移動します。
  5. ラウドネスメーターで、ITU-R BS.1770-4 に基づく integrated、short-term、momentary の LUFS を確認します。チャンネルごとのサンプルピーク、RMS、DC オフセット、クリップしたサンプルの数も表示され、「Copy stats」でまとめてコピーできます。
  6. File パネルと Tags パネルで、コーデック、サンプルレート、ビット深度や、ID3、Vorbis コメントなどのタグを確認します。

Cursor、Windsurf、VSCodium の場合

これらのエディターは Open VSX から拡張機能を入れます。Extensions ビュー (Ctrl+Shift+X) で zovo.audio-preview-vscode を検索して Install を押してください。Open VSX のページは zovo/audio-preview-vscode です。あとは VS Code と同じ手順で使えます。

無料でできること

再生、波形、2048 ポイントの FFT によるスペクトログラム、ラウドネスメーター、ファイル情報とタグの表示はすべて無料です。VS Code 自体は Opus を再生できませんが、この拡張機能は WebAssembly 版の libopus(85 KB)を同梱しています。大きな WAV は 2 MB ずつ読み込まれ、173 MB・10 分・24 ビットの WAV の解析は約 1.3 秒で終わりました。ネットワーク通信とテレメトリーはなく、ファイルに書き込むこともありません。

Zovo Pro で追加されるもの

-14 LUFS(Spotify、YouTube)、-16 LUFS(Apple Music、ポッドキャスト)、-23 LUFS(EBU R128)、または任意の目標値を選ぶと、mix-14LUFS.wav のような新しい WAV ファイルを元のファイルの隣に書き出します。元のファイルは変更されません。ゲインを上げるとサンプルピークが -1 dBFS を超える場合はゲインを抑え、そのことをメッセージで知らせます。ビット深度は保たれます(8 ビット、A-law、μ-law のファイルは 16 ビットになります)。配信先に合わせた音量調整を、別の音声ソフトを開かずに済ませられます。もう 1 つの Pro ツール Folder Loudness Report は、フォルダ内の音声ファイルごとに LUFS、ピーク、各目標値までに必要なゲインなどを 1 行ずつ CSV にまとめます。

Normalize Loudness to -14 / -16 / -23 LUFS の使い方

  1. 音声ファイルを開いてエディタータイトルのメニューから「Normalize Loudness to -14 / -16 / -23 LUFS (Pro)」を選ぶか、エクスプローラーでファイルを右クリックして同じ項目を選びます。
  2. 目標のラウドネスを選びます。元のファイルの隣に新しい WAV ファイルが保存されます。

Normalize Loudness to -14 / -16 / -23 LUFS はライセンスなしで 3 回まで使えます。ファイルを開いたときにポップアップが出たり、残り日数が表示されたりすることはありません。

できないこと

  • .m4a と .aac の再生には ffmpeg が必要です。VS Code の Chromium には AAC のデコーダーがないためです。ALAC や AC-3 も同じです。ffmpeg は同梱されていません。
  • ピークはサンプルピークで、オーバーサンプリングしたトゥルーピークではありません。ラウドネスレンジ(LRA)の計測はまだありません。
  • 2048 MB を超える WAV と、デコード後に 600 MB を超える圧縮ファイルは、再生だけで解析はされません。
  • 確認用のプレイヤーなので、トリミングなどの編集はできません。

よくある質問

無料で使えますか?

はい。再生、波形、スペクトログラム、ラウドネスメーターは無料です。ラウドネスのノーマライズとフォルダのラウドネスレポートは Zovo Pro のツールで、それぞれ 3 回まで無料で試せます。試用回数はファイルが書き出されたときだけ減ります。

M4A ファイルは再生できますか?

ffmpeg がインストールされていれば、「Decode with ffmpeg」で WAV のコピーを作って再生します(コピーは 1 日後に削除されます)。ffmpeg がない場合は、コーデック、長さ、ビットレート、タグと、その旨のメッセージが表示されます。

Cursor でも使えますか?

はい。Open VSX からインストールできるので、Cursor、Windsurf、VSCodium でも使えます。

すべての機能と設定は Audio Player & WAV Player のページ (英語) にあります。
