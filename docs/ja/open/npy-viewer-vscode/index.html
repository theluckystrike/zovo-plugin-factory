NumPy の .npy と .npz を VS Code で開く

Tensor Viewer を入れて .npy か .npz をクリックすると、Python なしで配列の名前、dtype、shape が一覧になり、配列を選ぶと統計、グラフ、値が表示されます。PyTorch、GGUF、Safetensors の表示も含め、閲覧と .npy や CSV への保存は無料です。Zovo Pro(USD 19 の買い切り)では 2 つのファイルのテンソルを全値で比べるツールと、NaN や Inf を全値から探すスキャンが加わり、それぞれ 3 回まで無料で試せます。

VS Code にインストールMarketplace のページOpen VSX (Cursor、Windsurf、VSCodium)

無料、MIT ライセンス。 Extension ID zovo.tensor-viewer.

VS Code での手順

  1. Marketplace から Tensor Viewer をインストールします。Ctrl+P (macOS では Cmd+P) を押して ext install zovo.tensor-viewer を実行しても入ります。
  2. エクスプローラーで .npy か .npz ファイルをクリックします。各配列の名前、型、shape、要素数、サイズが表で表示され、フィルタと列の並べ替えが使えます。
  3. 配列をクリックすると、min、max、mean、std と NaN、+Inf、-Inf、ゼロの数が表示され、2 次元ならヒートマップ、1 次元なら折れ線グラフ、さらにヒストグラムが描かれます。
  4. 値の表は 32 行ずつページを送り、[5, :, :] のようなスライスを指定できます。「Copy values」でタブ区切りテキストとしてコピーできます。
  5. (H, W) や (H, W, 3) のような画像の形をした配列は画像として表示されます。表示中のテンソルやスライスは「Save as .npy...」や「Save as CSV...」で新しいファイルに保存できます。
  6. 同じビューアで PyTorch の .pt、.pth、.ckpt、.gguf、.safetensors も開けます。PyTorch の pickle は実行せずにデータとして読まれ、読み込むと os.system や eval を実行するようなファイルには赤い警告が出ます。

Cursor、Windsurf、VSCodium の場合

これらのエディターは Open VSX から拡張機能を入れます。Extensions ビュー (Ctrl+Shift+X) で zovo.tensor-viewer を検索して Install を押してください。Open VSX のページは zovo/tensor-viewer です。あとは VS Code と同じ手順で使えます。

無料でできること

テンソルの一覧、統計、ヒストグラム、ヒートマップ、画像表示、値の表、スライス、生のバイナリ配列の表示、.npy と CSV への保存は無料で、0.6.0 より前からある機能は今後も無料です。ヘッダーだけを読み、テンソルはオフセットで 1 つずつ読むので、大きなファイルもすぐに開きます。ファイルが変わると自動で再読み込みします。表示中のファイルを書き換えることはなく、テレメトリもありません。

Zovo Pro で追加されるもの

Compare Two Tensor Files は 2 つのファイルのすべてのテンソルの全値を読み、テンソルごとに最大と平均の絶対差、RMSE、相対 L2 誤差、コサイン類似度、異なる値の数、最大差の位置を出します。片方にしかないテンソルや shape と型の変化も一覧になり、.safetensors と .pt、.gguf と .npz のように形式が違っても比べられるので、変換や学習の前後でどこが変わったかをすぐに確かめられます。もう 1 つの Pro ツール Scan All Tensors for NaN, Inf and Zeros は、サンプリングせずに全値を読み、NaN、Inf、すべてゼロのテンソル、定数のテンソル、10,000 以上の値を見つけます。どちらもレポートを CSV、Markdown、JSON で保存できます。

Compare Two Tensor Files (Checkpoint Diff) の使い方

  1. エクスプローラーで 2 つのファイルを選んで右クリックし、「Zovo Pro: Compare Two Checkpoints」を選びます。ビューアの「Compare with...」ボタンや、コマンドパレットの「NumPy Viewer Pro: Compare Two Tensor Files (Checkpoint Diff)」からも始められます。
  2. レポートを「Only tensors that differ」で絞り込み、CSV、Markdown、JSON のいずれかで保存します。

Compare Two Tensor Files (Checkpoint Diff) はライセンスなしで 3 回まで使えます。ファイルを開いたときにポップアップが出たり、残り日数が表示されたりすることはありません。

できないこと

  • pickle で保存されたオブジェクト配列(allow_pickle=True で保存したもの)は一覧に出ますが、中身は開けません。テキスト配列と構造化配列は統計なしで一覧に出ます。
  • 大きなテンソルの統計とグラフは最大 2,000,000 個の値から計算されます(tensorViewer.sampleValues)。正確な値かサンプルかはパネルに表示されます。
  • 圧縮された .npz では、画像と値は各エントリーの先頭 64 MB からだけ読み込みます。
  • ヒートマップは最大 256 x 256 セル、CSV の書き出しは 2,000 万値までです。

よくある質問

Python や NumPy のインストールは必要ですか?

いいえ。Python なしで .npy と .npz を開けます。

無料で使えますか?

はい。表示、統計、グラフ、値の表、.npy と CSV への保存は無料です。チェックポイントの比較と全テンソルのスキャンが Zovo Pro のツールで、それぞれ 3 回まで無料で試せます。

Cursor でも使えますか?

はい。Cursor は Open VSX から拡張機能をインストールします。拡張機能ビューで zovo.tensor-viewer を検索してインストールしてください。

allow_pickle=True で保存したファイルは開けますか?

pickle で保存されたオブジェクト配列は、安全のため一覧に表示するだけで中身は開きません。数値の配列は通常どおり表示されます。

すべての機能と設定は Tensor Viewer のページ (英語) にあります。
