AWS S3、Cloudflare R2、MinIO のバケットを VS Code で閲覧する

無料の S3 Explorer をインストールし、Activity Bar にある S3 Buckets ビューを開きます。AWS S3(~/.aws のプロファイル、SSO プロファイルにも対応)、Cloudflare R2、MinIO、Backblaze B2、Wasabi、DigitalOcean Spaces で使えます。閲覧、オブジェクトを読み取り専用で開く操作、アップロード、ダウンロード、コピー、移動、名前の変更、削除、バージョン、タグ、署名付き URL(presigned URL)、フォルダー同期は無料で、サインインもテレメトリーもありません。Zovo Pro(USD 19 の買い切り)では Copy to Another Connection、Size and Cost Report、Scheduled Sync の 3 つのツールが加わり、それぞれ 3 回まで無料で試せます。

VS Code での手順

  1. Marketplace から S3 Explorer をインストールします。または Ctrl+P（macOS では Cmd+P）を押して ext install zovo.zovo-s3-explorer を実行します。
  2. Activity Bar の S3 Explorer ビューを開き、Add Connection をクリックします。~/.aws の AWS プロファイルを選ぶか、アクセスキー、R2 のアカウント ID とトークン、または MinIO などの S3 互換サービスのエンドポイント URL を入力します。入力したキーは OS のキーチェーンに保存されます。
  3. 接続を展開すると、バケットが表示されます。キーは 1,000 件ずつ読み込まれ、「Load 1,000 more」の行で続きを読み込みます。キーにバケット一覧の権限がない場合は、接続を右クリックして Add Bucket by Name を選びます。
  4. オブジェクトをクリックすると、読み取り専用でタブまたは対応するビューアーに開きます。メタデータ、タグ、バージョン、署名付き URL を見るには、オブジェクトを右クリックして Show Details, Versions and Presigned URL を選びます。
  5. オブジェクトを変更するには、右クリックして Edit and Upload を選びます。編集するのはコピーで、オブジェクトを置き換える前に、バケット、キー、両方のサイズを示すダイアログが表示されます。
  6. Explorer からファイルやフォルダーをバケットにドラッグするとアップロードでき、右クリックして Download を選ぶとダウンロードできます。16 MB 以上のファイルは進行状況と Cancel 付きで分割してアップロードされ、止まったアップロードは足りない部分だけを送って再開します。
  7. ローカルのフォルダーとプレフィックスを同じ内容に保つには、バケットまたはフォルダーを右クリックして Sync Folder を選びます。何かが変わる前に、ドライランの計画(新規、変更、削除予定)が表示されます。

無料でできることと Zovo Pro で増えること

閲覧、オブジェクトを開く操作、Edit and Upload、アップロード、ダウンロード、コピー、移動、名前の変更、削除、バージョン、タグ、署名付き URL、フォルダー同期は無料です。サインイン、アカウント、テレメトリーはありません。接続するのは、追加したストレージのエンドポイントだけです。

Copy to Another Connection は、オブジェクトやフォルダー全体をある接続から別の接続へ、たとえば AWS S3 から Cloudflare R2 や MinIO へコピーします。確認はほかのコピーと同じで、キーが一覧表示され、置き換えられるキーは名前が示されます。大きなオブジェクトはマルチパートアップロードで送られます。スクリプトや別のツールを使わずに、ツリーからプロバイダー間やアカウント間でデータを移せます。

Copy to Another Connection（Zovo Pro）の手順

  1. 先に 2 つ目の接続を追加します。次に S3 Buckets ビューでオブジェクトかフォルダーを右クリックして「Copy to Another Connection... (Pro)」を選ぶか、ビューの末尾にある「Zovo Pro tools」の行で Copy to Another Connection をクリックします。
  2. コピー先の接続、バケット、保存先のフォルダー(最上位なら空欄)を選びます。
  3. 確認に表示されるオブジェクトの一覧を読み、Copy をクリックします。すでにあるキーが含まれる場合は Copy and Replace をクリックします。通知に進行状況が表示されます。
  4. 試用回数が減るのは、オブジェクトがコピーされたときだけです。選択の途中で Escape を押した場合や、2 つ目の接続がない場合は減りません。

Copy to Another Connection は、ライセンスを求める前にお使いのコンピューターで 3 回まで使えます。ファイルを開いたときにポップアップやカウントダウンは出ません。

Cursor、Windsurf、VSCodium での手順

  1. Ctrl+Shift+X（macOS では Cmd+Shift+X）で Extensions ビューを開きます。
  2. zovo.zovo-s3-explorer を検索して Install をクリックします。Cursor、Windsurf、VSCodium は Open VSX から拡張機能をインストールします。Open VSX での名前は zovo/zovo-s3-explorer です。
  3. エディターに拡張機能のギャラリーがない場合は、Open VSX のページから .vsix をダウンロードし、「Extensions: Install from VSIX...」を実行します。
  4. あとは VS Code と同じように使えます。

S3 Explorer で開けるもの

  • アクセスキー、credential_process、source_profile を使うロールの AWS プロファイルと、aws sso login 後の SSO プロファイル。プロファイルの endpoint_url にも従います。
  • エンドポイント URL、リージョン、パス形式または仮想ホスト形式の URL を指定する MinIO などの S3 互換サービス。自己署名証明書を受け入れるオプションもあります。
  • メタデータ、コンテンツタイプ、ストレージクラス、ETag、タグ(編集して保存)、バージョン(開く、ダウンロード、復元)、15 分から 7 日の GET または PUT の署名付き URL。
  • 数百万のキーがあるバケット。1,000 件ずつ読み込み、プレフィックスで検索と絞り込みができます。
  • ダウンロードはフォルダー構成を保ち、選んだフォルダーの外には書き込みません。.. セグメント、ドライブ文字、NUL バイトを含むキーはスキップされ、一覧に表示されます。

できないこと

  • AWS の default プロファイルや AWS_PROFILE を勝手に使うことはありません。接続に使うプロファイルは自分で選びます。
  • 10 MB を超えるテキストのオブジェクトは、確認のあとに最初の 1 MB を表示します。200 MB を超えるバイナリのオブジェクトは、ダウンロードの前に確認します。
  • 開いたオブジェクトは読み取り専用です。バケットに書き込むのは Edit and Upload だけで、確認のあとに行われます。
  • Scheduled Sync は VS Code が開いている間だけ、5 分から 60 分ごとに実行され、削除は一切行いません。
  • 応答のないリクエストは 30 秒で止まります(設定 s3Explorer.requestTimeoutSeconds)。

よくある質問

無料で使えますか?

閲覧、オブジェクトを開く操作、アップロード、ダウンロード、コピー、移動、名前の変更、削除、バージョン、タグ、署名付き URL、フォルダー同期は無料です。3 つの Pro ツール、Copy to Another Connection、Size and Cost Report、Scheduled Sync は、それぞれ 3 回まで無料で試せます。その後は Zovo Pro が必要です。USD 19 の買い切りで、すべての Zovo 拡張機能に使えます。

キーはどこに保存されますか?

入力したキーは VS Code の SecretStorage を通じて OS のキーチェーンに保存され、設定ファイルには書き込まれません。AWS プロファイルは、選んだときにだけ ~/.aws から読み込まれます。

Cloudflare R2 や MinIO でも使えますか?

はい。R2 ではアカウント ID と R2 API トークンのアクセスキーを使います。MinIO などの S3 互換サービスでは、エンドポイント URL、リージョン、パス形式または仮想ホスト形式の URL を指定します。

Cursor でも使えますか?

はい。Cursor、Windsurf、VSCodium は Open VSX からインストールできます。Open VSX では zovo/zovo-s3-explorer として公開されています。
