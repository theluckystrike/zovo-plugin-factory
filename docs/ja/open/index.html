日本語のガイド

VS Code とそれをベースにしたエディター（Cursor、Windsurf、VSCodium）は、テキストファイル、画像、一部のメディアを開けます。それ以外の多くの形式には拡張機能が必要です。各ガイドで手順と、無料でできることを説明します。

  • VS Code で .docx ファイルを開く方法。Word、OpenDocument、古い .doc ファイルを VS Code や Cursor で読めます。見出しのアウトライン、検索、変更履歴、コメントに対応。無料でオフライン。
  • VS Code で PowerPoint ファイル（.pptx）を表示する方法。.pptx、.ppsx、古い .ppt ファイルを VS Code や Cursor で表示できます。サムネイル、発表者ノート、検索、全画面のスライドショーに対応。無料で、PowerPoint は不要です。
  • VS Code で Excel ファイル（.xlsx）を開く方法。.xlsx、.xls、.ods ファイルを VS Code や Cursor で表として開けます。Excel の数値書式、フィルター、並べ替え、統計、SQL に対応。無料、オフライン、Excel は不要です。
  • VS Code で PDF をダークモードで読む。VS Code や Cursor で PDF をダークまたはセピアのページで読めます。文字は明るくなり、写真は本来の色のまま。検索、目次、ハイライトに対応。無料です。
  • VS Code でバイナリファイルを 16 進数で表示・編集する。VS Code や Cursor で、0 バイトから 4 GB のイメージまで、あらゆるファイルのバイトを表示、検索、編集、比較できます。Data Inspector と安全な保存つき。無料でオフライン。

ほかのガイドは英語で読めます。
