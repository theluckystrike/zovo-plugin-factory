日本語のガイド

VS Code とそれをベースにしたエディター（Cursor、Windsurf、VSCodium）は、テキストファイル、画像、一部のメディアを開けます。それ以外の多くの形式には拡張機能が必要です。各ガイドで手順と、無料でできることを説明します。

  • VS Code で .docx ファイルを開く方法。Word、OpenDocument、古い .doc ファイルを VS Code や Cursor で読めます。見出しのアウトライン、検索、変更履歴、コメントに対応。無料でオフライン。
  • VS Code で PowerPoint ファイル（.pptx）を表示する方法。.pptx、.ppsx、古い .ppt ファイルを VS Code や Cursor で表示できます。サムネイル、発表者ノート、検索、全画面のスライドショーに対応。無料で、PowerPoint は不要です。
  • VS Code で Excel ファイル（.xlsx）を開く方法。.xlsx、.xls、.ods ファイルを VS Code や Cursor で表として開けます。Excel の数値書式、フィルター、並べ替え、統計、SQL に対応。無料、オフライン、Excel は不要です。
  • VS Code で PDF をダークモードで読む。VS Code や Cursor で PDF をダークまたはセピアのページで読めます。文字は明るくなり、写真は本来の色のまま。検索、目次、ハイライトに対応。無料です。
  • VS Code でバイナリファイルを 16 進数で表示・編集する。VS Code や Cursor で、0 バイトから 4 GB のイメージまで、あらゆるファイルのバイトを表示、検索、編集、比較できます。Data Inspector と安全な保存つき。無料でオフライン。
  • VS Code で音声ファイルを再生・解析する。Audio Player & WAV Player を使うと、WAV、MP3、FLAC、Ogg、Opus を VS Code の中で再生し、波形、スペクトログラム、LUFS のラウドネスを確認できます。
  • HTML・JSX・Vue のタグを対で自動リネームする。開始タグを書き換えると閉じタグも同時に変わり、> を入力すると閉じタグが入ります。VS Code の linked editing を使うので、1 回の Undo で元に戻せます。
  • Claude Code と Codex の履歴を VS Code で読む。Agent Session Viewer なら、Claude Code と Codex のセッションを VS Code で一覧・検索し、ターミナルで再開できます。読み取り専用で、オフラインで動きます。
  • DXF 図面を VS Code で表示する。DXF Viewer なら CAD ソフトなしで .dxf の図面を VS Code に表示できます。R12 から AutoCAD 2018 までの DXF、シート、レイヤー、計測、PNG と SVG の書き出しに対応しています。
  • VS Code で SQLite データベースを編集する。SQLite DB Viewer を使うと、.db や .sqlite を VS Code で開き、Enable editing でセルや行を編集できます。保存時にはバックアップが作られ、CSV のインポートも無料です。
  • EXE・DLL・ELF を VS Code で解析する。ELF Viewer & PE Viewer なら .exe、.dll、.so、.dylib を VS Code で開き、ヘッダー、セクション、インポート、エクスポート、シンボルを確認できます。外部ツールは不要です。
  • VS Code でフォントファイルをプレビューする。Font Viewer を使うと、TTF、OTF、WOFF、WOFF2、TTC を VS Code で開き、文字の見え方、グリフ、収録文字、ライセンスを確認できます。フォントは変更されません。
  • Graphviz の DOT を VS Code でプレビューする。Graphviz Viewer なら Graphviz をインストールせずに .dot と .gv を VS Code でライブプレビューできます。エラー表示、ノード検索、SVG と PNG の書き出しも無料です。
  • JAR と .class を VS Code で見る・逆コンパイルする。JAR Viewer & Java Decompiler なら .jar、.war、.aar、.class を VS Code で開き、パッケージ、バイトコード、CFR による逆コンパイル結果を確認できます。
  • Mermaid 図を VS Code で編集・プレビューする。Mermaid Viewer なら .mmd と .mermaid、Markdown 内の mermaid ブロックを VS Code でライブプレビューしながら編集できます。Mermaid 12.3.0 同梱でオフラインでも動きます。
  • NetCDF と HDF5 のファイルを VS Code で見る。NetCDF Viewer & HDF5 Viewer なら Python なしで .nc と .h5 を VS Code で開き、変数、属性、値、海岸線付きの地図を確認できます。MATLAB 7.3 の .mat も開けます。
  • NumPy の .npy と .npz を VS Code で開く。Tensor Viewer なら Python なしで .npy と .npz を VS Code で開き、配列の名前、dtype、shape、統計、ヒートマップ、値を確認できます。PyTorch や GGUF にも対応しています。
  • PCAP と PCAPNG を VS Code で開いて解析する。PCAP Viewer なら Wireshark なしで .pcap と .pcapng を VS Code で開き、パケット一覧、プロトコルツリー、Hex、ディスプレイフィルタ、ストリームの追跡を使えます。
  • pickle ファイル(.pkl)を Python なしで開く。Pickle Viewer & PKL Viewer を使うと、.pkl や .pickle を Python なしで VS Code で開けます。コードは実行されず、ツリー、NumPy 配列、pandas の表、危険な呼び出しの一覧を確認できます。
  • VS Code で動画を音付きで再生する。Video Preview with Sound を使うと、VS Code の標準プレイヤーでは音が出ない AAC 音声の MP4・MOV も音付きで再生できます。MKV や WebM は ffmpeg があれば開けます。
  • VS Code で C / C++ をワンクリックで実行する。Run C++ and C Code を使うと、手元の gcc、g++、clang で C / C++ のファイルをワンクリックでコンパイルして実行できます。入力とテストケースのパネルも無料です。
  • VS Code で STL / OBJ / GLB を表示する。3D Model Viewer を使うと、STL、OBJ、GLB、glTF、PLY、3MF の 3D モデルを VS Code の中で回転・拡大して確認できます。2 点間の距離の計測やシーンツリーも無料です。
  • VS Code で 16 ビット TIFF / GeoTIFF を開く。TIFF Viewer を使うと、16 ビットや浮動小数点の TIFF、GeoTIFF を VS Code で開けます。コントラストは自動で調整され、ピクセルの保存値や地図座標も確認できます。
  • XMind ファイルを VS Code で開く。XMind Viewer を使うと、.xmind ファイルを XMind なしで VS Code に表示できます。XMind 8 と XMind 2020 以降の形式、FreeMind の .mm、OPML にも対応しています。
  • ZIP や TAR を解凍せずに VS Code で開く。ZIP Viewer & Archive Explorer を使うと、ZIP、JAR、VSIX、TAR、TAR.GZ を解凍せずに VS Code で開き、中のファイルを確認したり、必要なものだけ取り出したりできます。

ほかのガイドは英語で読めます。
