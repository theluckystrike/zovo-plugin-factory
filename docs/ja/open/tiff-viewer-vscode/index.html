VS Code で 16 ビット TIFF / GeoTIFF を開く

TIFF Viewer を入れると、.tif や .tiff をクリックするだけで、16 ビット、32 ビット、浮動小数点の画像も真っ黒にならずに表示されます。全ページの表示、コントラストの調整、ピクセル値、タグ、GeoTIFF の座標、表示中のページの PNG 書き出しは無料です。Zovo Pro(USD 19、買い切り)では全ページの PNG 書き出し、範囲の統計、フォルダの一括変換が加わり、それぞれ 3 回まで無料で試せます。

VS Code にインストールMarketplace のページOpen VSX (Cursor、Windsurf、VSCodium)

無料、MIT ライセンス。 Extension ID zovo.tiff-viewer.

VS Code での手順

  1. Marketplace から TIFF Viewer をインストールします。Ctrl+P (macOS では Cmd+P) を押して ext install zovo.tiff-viewer を実行しても入ります。
  2. エクスプローラーで .tif または .tiff ファイルをクリックします。.gtiff、.btf、.tf8 は、右クリックして「Open in TIFF Viewer」を選びます。
  3. 8 ビット以外の画像は、0.5〜99.5 パーセンタイルのストレッチをかけた状態で開きます。min から max、2〜98 パーセンタイル、型の全範囲にも切り替えられます。
  4. ポインターを画像に合わせると、表示色ではなく、その位置に保存されている値がステータスバーに出ます。Values セクションでは min、max、mean、nodata と NaN の数、小さなヒストグラムを確認でき、T キーでタグのパネルを開けます。
  5. 複数ページのファイルでは、サムネイル付きのページ一覧から選ぶか、PageDown / PageUp(または J / K)でページを移動します。View メニューで RGB 合成と各チャンネルの表示を切り替えられます。
  6. GeoTIFF では CRS / EPSG、ピクセルサイズ、範囲、nodata 値が表示され、ポインターの位置の地図座標も出ます。nodata と NaN のピクセルは透明になり、統計から除外されます。
  7. 表示中のページは、選んだチャンネルとストレッチのまま Export PNG で書き出せます。

Cursor、Windsurf、VSCodium の場合

これらのエディターは Open VSX から拡張機能を入れます。Extensions ビュー (Ctrl+Shift+X) で zovo.tiff-viewer を検索して Install を押してください。Open VSX のページは zovo/tiff-viewer です。あとは VS Code と同じ手順で使えます。

無料でできること

全ページ、チャンネル、ストレッチ、ピクセル値、タグ、GeoTIFF の座標、表示中のページの PNG 書き出しはすべて無料です。classic TIFF と BigTIFF、ストリップとタイル、1〜64 ビットの整数と 16・32・64 ビットの浮動小数点、LZW、Deflate、PackBits、JPEG などの圧縮に対応しています。ピクセルはバックグラウンドのワーカーでデコードされ、オフラインで動作します。

Zovo Pro で追加されるもの

画像上で四角形をドラッグすると、その範囲のピクセル数、min、max、mean、標準偏差、1・5・25・50・75・95・99 パーセンタイル、保存値のヒストグラムが表示されます。nodata と NaN は除外したうえで数が示され、GeoTIFF では範囲の四隅の地図座標も出ます。Save CSV でチャンネルごとに 1 行の CSV(32 ビンのヒストグラム付き)を保存できるので、数値を手で書き写す必要がありません。ほかに、ページを原寸の PNG で書き出す Export Pages to PNG(GeoTIFF では .pgw と .geojson も出力)と、フォルダ内の TIFF をまとめて PNG に変換する Batch Convert TIFF Folder to PNG があります。

Region Statistics の使い方

  1. TIFF を開き、コマンドパレットで「TIFF Viewer: Region Statistics (Pro)」を実行するか、エクスプローラーでファイルを右クリックして「Zovo Pro: Region statistics」を選びます。
  2. 画像上で、調べたい範囲を四角形でドラッグします。
  3. パネルの数値を確認し、必要なら Save CSV で保存します。

Region Statistics はライセンスなしで 3 回まで使えます。ファイルを開いたときにポップアップが出たり、残り日数が表示されたりすることはありません。

できないこと

  • ZSTD、LERC、WebP、JPEG 2000 で圧縮されたページは表示されず、タグと注記だけが出ます。
  • SubIFD のサブ画像(一部の DNG や OME-TIFF のピラミッド)はタグには出ますが、ページとしては表示されません。
  • ファイルはメモリに読み込まれます。既定の上限は 1 GB(tiffViewer.maxFileMB、最大 4096)で、それを超えるファイルはピクセルを表示せず、各ページのタグだけを表示します。
  • 地図タイルの表示や投影の変換はできません。

よくある質問

無料で使えますか?

はい。表示、コントラストの調整、ピクセル値、タグ、GeoTIFF の情報、表示中のページの PNG 書き出しは無料です。全ページの書き出し、範囲の統計、フォルダの一括変換は Zovo Pro のツールで、それぞれ 3 回まで無料で試せます。

TIFF ファイルが変更されることはありますか?

ありません。書き込まれるのは、Export PNG と Pro ツールで保存したファイルだけです。

Cursor でも使えますか?

はい。Open VSX からインストールできるので、Cursor、Windsurf、VSCodium でも使えます。

すべての機能と設定は TIFF Viewer のページ (英語) にあります。
