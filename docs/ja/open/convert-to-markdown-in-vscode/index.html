PDF、Word、PowerPoint、Excel のファイルを VS Code で Markdown に変換する

無料の Convert to Markdown 拡張機能をインストールし、Explorer で PDF、Word、PowerPoint、Excel、CSV、HTML、EPUB、ODT、RTF のファイルを右クリックして Convert to Markdown を選びます。見出し、リスト、表、リンク、スライドのスピーカーノートを含む Markdown がファイルの隣に開き、データがパソコンの外に出ることはありません。Convert to Markdown と Copy as Markdown はすべての形式で無料です。Zovo Pro(USD 19 の買い切り)では Convert a Folder to Markdown、Convert to Markdown with Images、LLM-ready Markdown Chunks の 3 つのツールが加わり、それぞれ 3 回まで無料で試せます。

無料、MIT ライセンス。拡張機能 ID zovo.zovo-convert-to-markdown、バージョン 0.1.1。

このガイドは English、Deutsch、Español でも読めます。

VS Code での手順

  1. Marketplace から Convert to Markdown をインストールします。または Ctrl+P（macOS では Cmd+P）を押して ext install zovo.zovo-convert-to-markdown を実行します。
  2. Explorer で .pdf、.docx、.pptx、.xlsx、.xls、.ods、.csv、.tsv、.html、.epub、.odt、.rtf のいずれかのファイルを右クリックし、Convert to Markdown を選びます。開いているファイルのタブを右クリックしても使えます。
  3. Command Palette から「Convert to Markdown: Convert to Markdown」を実行する方法もあります。アクティブなタブのファイルを変換し、開いていない場合はファイルを尋ねます。
  4. Markdown は未保存のドキュメントとしてファイルの隣に開きます。大きなファイルでは、Cancel ボタン付きで進行状況が表示されます。
  5. 保存を押します。元のファイルと同じ場所の name.md という名前があらかじめ入っています。毎回すぐにそこへ保存したい場合は、toMarkdown.output を file に設定します。
  6. Markdown を別の場所に貼り付けたいときは、ファイルを右クリックして Copy as Markdown を選びます。Explorer で複数のファイルを選ぶと、1 つずつ順に変換します。
  7. 手元にファイルがない場合は、Command Palette から「Convert to Markdown: Convert a sample file」を実行すると、同梱の Word、PDF、PowerPoint のサンプルを変換できます。

無料でできることと Zovo Pro で増えること

Convert to Markdown と Copy as Markdown は、PDF、Word、PowerPoint、Excel、ODS、CSV、TSV、HTML、EPUB、ODT、RTF のすべての形式で無料です。Python、サーバー、コマンドラインツールなど、ほかに何もインストールする必要はありません。データがパソコンの外に出ることもありません。

Convert a Folder to Markdown は、フォルダーとそのサブフォルダーにある対応ファイルをすべて、1 回の実行で .md ファイルに変換します。出力先は同じ構成の新しいフォルダーか各ファイルの隣で、進行状況と Cancel も表示されます。既存の .md ファイルをスキップするか上書きするかを選べ、_conversion-report.md に各ファイルの結果(変換、スキップ、失敗)が記録されます。同じ名前のファイルは新しい名前に元の形式が残るので(report.pdf.md、report.docx.md)、どれも失われません。

Convert a Folder to Markdown（Zovo Pro）の手順

  1. Explorer でフォルダーを右クリックして「Zovo Pro: Convert a Folder to Markdown」を選ぶか、Command Palette から「Convert to Markdown: Convert a Folder to Markdown (Pro)」を実行してフォルダーを選びます。
  2. .md ファイルの出力先を選びます。「Into a new folder」(フォルダー名の末尾に -markdown を付け、同じサブフォルダー構成にします)、「Next to each file」、「Pick another folder...」のいずれかです。
  3. .md ファイルがすでにある場合は、Skip か Overwrite を選びます。通知に進行状況と Cancel ボタンが表示されます。
  4. 最後に _conversion-report.md が開きます。各ファイルが変換、スキップ、失敗のどれになったかと、新しい Markdown ファイルへのリンクが並びます。

Convert a Folder to Markdown は、ライセンスを求める前にお使いのコンピューターで 3 回まで使えます。ファイルを開いたときにポップアップやカウントダウンは出ません。

Cursor、Windsurf、VSCodium での手順

  1. Ctrl+Shift+X（macOS では Cmd+Shift+X）で Extensions ビューを開きます。
  2. zovo.zovo-convert-to-markdown を検索して Install をクリックします。Cursor、Windsurf、VSCodium は Open VSX から拡張機能をインストールします。Open VSX での名前は zovo/zovo-convert-to-markdown です。
  3. エディターに拡張機能のギャラリーがない場合は、Open VSX のページから .vsix をダウンロードし、「Extensions: Install from VSIX...」を実行します。
  4. あとは VS Code と同じように使えます。

Convert to Markdown で開けるもの

  • PDF では、フォントサイズから見出しを作り、途中で折り返した行とハイフンで分かれた単語をつないで段落にし、リストと単純な表も変換します。2 段組のページは段ごとに読みます。繰り返し出るヘッダー、フッター、ページ番号は取り除きます。
  • Word(.docx、.docm、.dotx)では、見出し、太字、斜体、取り消し線、リンク、入れ子のリスト、表、引用ブロック、脚注を変換します。
  • PowerPoint(.pptx、.pptm、.ppsx、.potx)では、スライドごとに ## Slide n: title のセクションを作り、箇条書きとそのレベル、表、スピーカーノートを入れます。
  • Excel などのスプレッドシート(.xlsx、.xlsm、.xlsb、.xls、.ods)では、シートごとに ## Sheet: name のセクションとパイプ区切りの表を作ります。CSV と TSV は 1 つの表になります。
  • HTML(.html、.htm、.xhtml)ではコードブロックの言語を残し、スクリプトとスタイルを取り除きます。EPUB は各章を読む順に変換します。

できないこと

  • スキャンした PDF(ページの画像)には、変換できるテキストがありません。文字認識(OCR)は含まれていません。
  • PDF の表は、列と列の間の空きから見つけます。空きがはっきりしない表は段落として出力されます。
  • 無料の変換では、画像は *[Image: Map of the site]* のようなプレースホルダーになります。スライド内のグラフ、SmartArt、動画は名前だけが入り、変換はされません。
  • 古い Word 97-2003 のファイルと RTF は、書式のないテキストと表になります。パスワード付きのファイルと古い PowerPoint 97-2003 のファイルは変換されず、メッセージが表示されます。
  • 200 MB を超えるファイルは変換されず(設定 toMarkdown.maxFileSizeMB)、PDF は 1,000 ページで止まります(設定 toMarkdown.pdfMaxPages)。

よくある質問

無料で使えますか?

Convert to Markdown と Copy as Markdown はすべての形式で無料です。3 つの Pro ツール、Convert a Folder to Markdown、Convert to Markdown with Images、LLM-ready Markdown Chunks は、それぞれ 3 回まで無料で試せます。その後は Zovo Pro が必要です。USD 19 の買い切りで、すべての Zovo 拡張機能に使えます。

ファイルはアップロードされますか?

いいえ。変換はお使いのパソコン上の VS Code 内で行われ、ネットワーク通信もテレメトリーもありません。

スキャンした PDF は変換できますか?

いいえ。スキャンした PDF に入っているのはテキストではなくページの画像で、Convert to Markdown には OCR がありません。

Cursor でも使えますか?

はい。Cursor、Windsurf、VSCodium は Open VSX からインストールできます。Open VSX では zovo/zovo-convert-to-markdown として公開されています。
