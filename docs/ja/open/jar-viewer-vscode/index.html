JAR と .class を VS Code で見る・逆コンパイルする

JAR Viewer & Java Decompiler を入れて .jar、.war、.ear、.aar、.class をクリックすると、パッケージとリソースのツリー、マニフェスト、バイトコード、同梱の CFR 0.152 で逆コンパイルした Java ソースが表示されます。閲覧と逆コンパイルは無料ですが、ソースの表示には Java 8 以上のランタイムが必要です。Zovo Pro(USD 19 の買い切り)では JAR 全体のソースの書き出し、2 つの JAR の比較、フォルダ内の全 JAR の検索が加わり、それぞれ 3 回まで無料で試せます。

VS Code にインストールMarketplace のページOpen VSX (Cursor、Windsurf、VSCodium)

無料、MIT ライセンス。 Extension ID zovo.zovo-jar-viewer.

VS Code での手順

  1. Marketplace から JAR Viewer & Java Decompiler をインストールします。Ctrl+P (macOS では Cmd+P) を押して ext install zovo.zovo-jar-viewer を実行しても入ります。
  2. エクスプローラーでファイルをクリックします。パッケージとリソースがツリーで表示され、フィルタ欄に入力すると 50,000 エントリーの中からでもクラスやファイルを絞り込めます。インナークラスは薄い色で表示されます。
  3. Overview では形式、サイズ、エントリー数、Main-Class、Created-By、multi-release かどうか、クラスの Java バージョンのグラフ(52 は Java 8、61 は Java 17、65 は Java 21)を確認できます。
  4. クラスを選ぶと、インナークラスを含めて逆コンパイルされた Java ソースが表示されます。コピーしたり、エディターのタブで開いたりできます。Java は jarViewer.javaPath、JAVA_HOME、PATH 上の java の順に探されます。
  5. Java がない環境でも、javap -c -p 形式のバイトコード、メンバー、定数プール、クラス情報は表示できます。リソースのテキストファイルはテキストとして、バイナリは Hex プレビューで開きます。
  6. Spring Boot の BOOT-INF/lib、WAR の WEB-INF/lib、AAR の classes.jar のような入れ子の JAR も 1 階層まで開けます。

Cursor、Windsurf、VSCodium の場合

これらのエディターは Open VSX から拡張機能を入れます。Extensions ビュー (Ctrl+Shift+X) で zovo.zovo-jar-viewer を検索して Install を押してください。Open VSX のページは zovo/zovo-jar-viewer です。あとは VS Code と同じ手順で使えます。

無料でできること

パッケージ、クラス、リソース、マニフェスト、Java バージョン、バイトコード、逆コンパイルしたソース、入れ子の JAR の閲覧はすべて無料で、上限もサインインもありません。アーカイブは時間とメモリの上限付きの別スレッドで読まれ、zip 爆弾は拒否されます。アーカイブを書き換えることはなく、ネットワーク通信やテレメトリもありません。

Zovo Pro で追加されるもの

Export decompiled sources of a JAR は、JAR 全体を逆コンパイルして .java ファイルのフォルダとして書き出します。進捗が表示され、途中でキャンセルもできるので、クラスを 1 つずつ開いてコピーする必要がありません。ほかに、追加、削除、変更されたクラス、メソッドとフィールドのシグネチャ、Java バージョンの変化を Markdown のレポートにする Compare two JARs と、フォルダ内のすべての JAR(入れ子の JAR を含む)からクラス、メソッド、フィールド、文字列定数をテキストか /regex/ で探す Find a class, method or string in every JAR of a folder があります。

Export decompiled sources of a JAR の使い方

  1. エクスプローラーで JAR を右クリックして「Zovo Pro: Export decompiled sources」を選ぶか、コマンドパレットで「JAR Viewer: Export decompiled sources of a JAR (Pro)」を実行します。
  2. 書き出し先のフォルダを選び、「Export here」をクリックします。逆コンパイルには Java 8 以上のランタイムが必要です。

Export decompiled sources of a JAR はライセンスなしで 3 回まで使えます。ファイルを開いたときにポップアップが出たり、残り日数が表示されたりすることはありません。

できないこと

  • 逆コンパイルしたソースの表示と書き出しには Java 8 以上のランタイムが必要です。
  • CFR の出力は元のソースと異なる場合があります(ローカル変数名、一部のジェネリクスやラムダなど)。
  • APK と DEX ファイルには対応していません。入れ子の JAR は 1 階層までです。
  • JAR の編集や再パックはできません。

よくある質問

無料で使えますか?

はい。閲覧と逆コンパイルはすべて無料で、上限もサインインもありません。ソースの一括書き出し、JAR の比較、フォルダ内の検索の 3 つが Zovo Pro のツールで、それぞれ 3 回まで無料で試せます。試用は結果が出たときだけ数えます。

Cursor でも使えますか?

はい。Cursor、Windsurf、VSCodium で動きます。Cursor は Open VSX から拡張機能をインストールするので、拡張機能ビューで zovo.zovo-jar-viewer を検索してください。

Java がインストールされていなくても使えますか?

ツリー、Overview、バイトコード、定数プールなどは Java なしで表示できます。逆コンパイルしたソースだけは Java 8 以上が必要で、Java がない場合はソースのタブに有効にする方法が表示されます。

Fernflower など別のデコンパイラーは選べますか?

いいえ。同梱されているのは CFR 0.152 だけです。

すべての機能と設定は JAR Viewer & Java Decompiler のページ (英語) にあります。
