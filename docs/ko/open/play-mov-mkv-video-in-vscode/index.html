VS Code에서 MOV, MKV, WebM, MP4 동영상을 소리까지 재생하기

무료 확장 Video Preview with Sound를 설치하고 Explorer에서 동영상을 클릭합니다. AAC 소리가 있는 MP4, MOV, M4V 파일은 확장에 소리 디코더가 들어 있어서 다른 설치 없이 소리와 함께 재생됩니다. MKV, WebM, AVI와 Apple ProRes처럼 VS Code가 디코딩하지 못하는 영상은 컴퓨터에 ffmpeg가 있어야 합니다. 재생, 소리, 자막, 변환은 무료이고, Zovo Pro(USD 19, 한 번 결제)는 Clip export, Frame export, 콘택트 시트를 더하며, 도구마다 3번 무료로 써 볼 수 있습니다.

VS Code에서 하는 방법

  1. Marketplace에서 Video Preview with Sound 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.video-preview-with-sound를 실행합니다.
  2. 동영상이 MKV, WebM, AVI, WMV, FLV, MPG, OGV, M2TS 파일이거나 소리가 AC-3, E-AC-3, DTS이면 먼저 ffmpeg를 설치합니다. Windows에서는 winget install ffmpeg, Linux에서는 sudo apt install ffmpeg, macOS에서는 brew install ffmpeg를 실행합니다. AAC 소리가 있는 MP4, MOV, M4V는 더 설치할 것이 없습니다.
  3. Explorer에서 .mp4, .m4v, .mov, .webm, .mkv, .avi, .wmv, .flv, .mpg, .mpeg, .ogv, .m2ts 파일을 클릭하고 Space를 눌러 재생합니다. 어떤 에디터로 열지 물으면 "Video Preview with Sound"를 고릅니다.
  4. 칩에 "Sound: on"이 나올 때까지는 소리 없이 재생됩니다. MKV나 WebM은 다시 인코딩하지 않고 MP4로 옮겨 담습니다. ProRes, AVI, WMV처럼 VS Code가 디코딩하지 못하는 영상은 한 번 H.264로 변환해 캐시에 보관합니다.
  5. 동영상 옆에 같은 이름의 .srt나 .vtt 파일을 두면 자막이 저절로 불러와집니다. C를 누르거나 CC 메뉴에서 트랙을 바꾸거나 자막을 끕니다.
  6. ,와 .로 한 프레임씩 이동하고, [와 ]로 속도를 0.1x에서 4x까지 바꿉니다. A와 B로 반복 구간을 정하고, S로 현재 프레임을 원본 크기 PNG로 저장하고, P로 PIP(화면 속 화면)를 켭니다.

무료 기능과 Zovo Pro가 더하는 기능

소리와 함께 재생, 내장 AAC 디코더, ffmpeg를 쓴 MKV와 WebM 재생, VS Code가 디코딩하지 못하는 영상 변환, 자막, PIP, 프레임 단위 이동, 속도 조절, A-B 반복, 현재 프레임 PNG 저장(S), 메타데이터 패널, 이어 보기는 무료입니다.

Clip export는 동영상의 A-B 구간이나 동영상 전체를 풀 리퀘스트, 이슈, 문서에 넣을 GIF나 MP4로 저장합니다. GIF는 다른 도구 없이 플레이어 안에서 만들며, 480 px 10 fps, 640 px 15 fps, 최대 960 px 15 fps 중에서 고르고 길이는 최대 60초입니다. MP4는 직접 설치한 ffmpeg로 자릅니다. H.264와 AAC로 다시 인코딩해 A 프레임에서 정확히 시작하는 방식과, 원본 스트림을 그대로 두고 A 앞의 키프레임에서 시작하는 빠른 복사 방식이 있습니다.

Clip export 사용하기 (Zovo Pro)

  1. 플레이어에서 동영상을 엽니다. 원하는 구간의 시작에서 A, 끝에서 B를 누릅니다. 아무것도 정하지 않으면 동영상 전체를 씁니다.
  2. 플레이어의 Clip(PRO 배지가 있음)을 누르거나, 컨트롤 아래 작은 Pro tools 줄에서 "Export a Clip as GIF or MP4"를 누릅니다. Explorer에서 동영상을 마우스 오른쪽 버튼으로 클릭하고 "Zovo Pro: Export a Clip as GIF or MP4"를 골라도 됩니다.

  4. Esc를 누르면 내보내기가 멈춥니다. 횟수는 파일이 저장됐을 때만 줄어들기 때문에, 대화 상자를 취소하거나 내보내기를 멈추면 무료 횟수가 줄지 않습니다.

Video Preview with Sound의 기능

  • AAC(모노, 스테레오), ALAC, MP3, PCM 소리가 있는 MP4, M4V, MOV. Windows, Linux, macOS에서 다른 설치 없이 재생됩니다.
  • MKV와 WebM. ffmpeg가 MP4로 옮겨 담아 소리와 함께 재생합니다.
  • MP4, M4V, MOV 안의 AC-3, E-AC-3, DTS, Opus, 5.1 AAC 소리. ffmpeg나 macOS에 들어 있는 afconvert로 디코딩합니다.
  • Apple ProRes, MPEG-4 Part 2, DNxHD 영상과 AVI, WMV, FLV, MPG, MPEG, OGV, M2TS 파일. ffmpeg로 H.264로 변환합니다.
  • 동영상 옆에 있는 .srt, .vtt 파일의 자막.

할 수 없는 것

  • ffmpeg가 없으면 어떤 시스템에서도 MKV와 WebM이 열리지 않습니다. 플레이어에 "Install ffmpeg to open this file"이 나옵니다. ffmpeg는 확장에 들어 있지 않습니다.
  • macOS의 afconvert는 영상을 변환하지 못하고 MKV나 WebM을 열지 못합니다. 변환에는 항상 직접 설치한 ffmpeg가 필요하고, 긴 ProRes 파일은 몇 분 걸릴 수 있습니다.
  • 내장 디코더는 HE-AAC를 AAC-LC 코어로 절반 샘플 레이트에서 재생합니다. 완전한 HE-AAC, 5.1 AAC, AC-3, DTS가 필요하면 ffmpeg를 설치하세요.
  • 4096 MB보다 큰 파일도 재생은 되지만 소리가 나지 않습니다(설정 videoPreview.maxDecodeSizeMB).
  • 자막은 .srt와 .vtt 파일에서만, 파일당 최대 5 MB까지 읽습니다. 동영상 파일 안에 든 자막은 읽지 않습니다. .ts와 .mts 파일은 TypeScript 파일 이름이라서 열지 않습니다.

자주 묻는 질문

VS Code에서 MP4를 재생하면 왜 소리가 안 나나요?

VS Code에 내장된 Chromium에는 H.264 영상 디코더는 있지만 AAC 디코더가 없고, 대부분의 MP4, MOV 파일은 AAC 소리를 씁니다. 이 확장은 소리를 직접 디코딩해 화면과 맞춰 재생합니다.

ffmpeg가 필요한가요?

AAC, ALAC, MP3, PCM 소리가 있는 MP4, MOV, M4V에는 필요 없습니다. MKV, WebM, AVI, WMV, FLV, MPG, OGV, M2TS와 ProRes처럼 VS Code가 디코딩하지 못하는 영상, Clip export의 MP4 클립에는 ffmpeg가 필요합니다. AC-3, E-AC-3, DTS 소리에는 ffmpeg가 필요하고, macOS에서는 afconvert로도 됩니다.

무료인가요?

네. 재생, 소리, 자막, 프레임 단위 이동, 현재 프레임 PNG 저장, 변환은 무료입니다. Clip export, Frame export, 콘택트 시트는 Zovo Pro 도구로 각각 3번 무료로 써 볼 수 있고, 그다음에는 모든 Zovo 확장에 쓰는 라이선스를 USD 19에 한 번 구매합니다.

Cursor에서도 되나요?
