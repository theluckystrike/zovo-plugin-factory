VS Code에서 Excel 또는 CSV 파일 두 개 비교하기

무료 확장 Excel Compare & XLSX Diff를 설치하고 통합 문서나 CSV 파일 두 개를 고릅니다. 바뀐 셀은 노란색으로 표시되고 이전 값에는 취소선이 그어지며, 추가된 행은 초록색, 삭제된 행은 빨간색으로 표시됩니다. 행을 먼저 맞추고 열은 머리글로 맞추므로 행이나 열을 하나 끼워 넣어도 변경 하나로 표시됩니다. 커밋하기 전에 통합 문서를 Git HEAD 버전과 비교할 수도 있습니다. 이 기능은 모두 무료이며 네트워크 요청을 보내지 않습니다. Zovo Pro(USD 19 한 번)는 Export a diff report, Match rows by key columns, Compare two folders of workbooks의 세 가지 도구를 더하며, 각 도구는 3번 무료로 쓸 수 있습니다.

VS Code에서 하는 방법

  1. Marketplace에서 Excel Compare & XLSX Diff 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.zovo-excel-compare를 실행합니다.
  2. Explorer에서 파일 두 개를 선택하고 마우스 오른쪽 버튼으로 클릭한 뒤 Compare Selected Excel Files를 고릅니다. 또는 파일 하나를 마우스 오른쪽 버튼으로 클릭하고 Compare with...를 고른 다음 다른 파일을 선택합니다. Command Palette에서 "Excel Compare: Compare Two Excel or CSV Files..."를 실행해도 됩니다.
  3. .xlsx, .xlsm, .xls, .ods, .csv, .tsv를 어떤 조합으로든 비교할 수 있으므로 .xlsx 파일과 .csv 파일도 비교됩니다.
  4. 먼저 요약 줄을 읽고, 시트마다 차이 개수가 표시된 탭을 확인합니다. 셀을 클릭하면 이전 값과 새 값 전체가 보이고 복사할 수 있습니다.
  5. N과 P(또는 Next와 Previous)를 눌러 모든 시트의 변경 사항을 차례로 이동합니다. Values와 Formulas를 전환하면 셀에 보이는 값을 비교하거나 수식 자체를 비교할 수 있습니다.
  6. 커밋 전에 바꾼 내용을 보려면 Git 저장소 안의 통합 문서를 마우스 오른쪽 버튼으로 클릭하고 Compare with Git HEAD를 고릅니다.

무료 기능과 Zovo Pro가 더하는 기능

두 파일 비교, 그리드, Values와 Formulas, 다음 및 이전 변경으로 이동, 인코딩과 구분자를 자동으로 감지하는 CSV 비교, Compare with Git HEAD는 무료입니다. 로그인, 네트워크 요청, 원격 측정이 없습니다.

변경 내용을 다른 사람에게 보여 줘야 할 때 Export a diff report는 바뀐 셀, 추가된 셀, 삭제된 셀을 색으로 채우고 Summary 시트와 모든 이전 값과 새 값을 담은 Changes 목록이 들어 있는 XLSX 통합 문서를 만듭니다. HTML 페이지 하나나 변경 사항의 CSV 목록으로도 만들 수 있습니다. 스크린샷 대신 파일 하나만 보내면 됩니다.

Export a diff report 사용하기 (Zovo Pro)

  1. 위와 같이 두 파일을 비교한 다음 비교 도구 모음에서 Export report를 클릭하거나, Command Palette에서 "Excel Compare: Export a diff report (XLSX, HTML or CSV) (Pro)"를 실행합니다.
  2. XLSX, HTML, CSV 중 하나를 고릅니다.
  3. 보고서를 저장할 위치를 고릅니다. 보고서가 실제로 저장되었을 때만 시도 횟수가 차감됩니다.

Export a diff report 기능은 라이선스를 묻기 전에 내 컴퓨터에서 3번 무료로 쓸 수 있습니다. 팝업도 없고 카운트다운도 없습니다.

Cursor, Windsurf, VSCodium에서

  1. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 엽니다.
  2. zovo.zovo-excel-compare를 검색하고 Install을 누릅니다. Cursor, Windsurf, VSCodium은 Open VSX에서 확장을 설치하며, 이 확장은 그곳에서 zovo/zovo-excel-compare라는 이름으로 올라가 있습니다.
  3. 에디터에 확장 갤러리가 없으면 Open VSX 페이지에서 .vsix 파일을 내려받고 "Extensions: Install from VSIX..."를 실행합니다.
  4. 그다음은 VS Code에서와 똑같이 동작합니다.

Excel Compare & XLSX Diff의 기능

  • 시트는 이름으로, 그다음 위치로 맞춥니다. 한쪽 파일에만 있는 시트는 추가 또는 삭제로 표시됩니다.
  • CSV와 TSV는 인코딩(BOM이 있거나 없는 UTF-8, UTF-16, Windows 코드 페이지)과 구분자(쉼표, 세미콜론, 탭, 파이프)를 자동으로 감지하며, 줄바꿈이 들어간 따옴표 필드도 처리합니다.
  • 큰 시트도 그리드가 화면에 보이는 행만 그리므로 300,000행짜리 시트도 짧은 시트처럼 스크롤됩니다.
  • 병합된 셀이 다르거나 제한 때문에 시트가 잘리면 메모가 표시됩니다.
  • 나머지 Pro 도구 두 가지도 있습니다. Match rows by key columns는 ID 열로 행을 맞춰 정렬하거나 순서를 바꾼 시트도 깔끔하게 비교하고 이동한 행을 표시합니다. Compare two folders of workbooks는 파일을 이름으로 짝지어 어떤 파일이 같고, 어떤 파일이 다르고, 어떤 파일이 한쪽 폴더에만 있는지 보여 줍니다.

할 수 없는 것

  • 파일은 200 MB까지(설정 excelCompare.maxFileSizeMB), 시트당 300,000행(excelCompare.maxRows), 열 1,000개, 시트 200개까지 비교합니다. 제한이 적용되면 뷰에 메모가 표시됩니다.
  • 압축을 풀었을 때 600 MB를 넘거나 zip bomb처럼 압축된 통합 문서는 압축을 풀기 전에 거부됩니다.
  • Pro 도구 Match rows by key columns 없이는 행을 ID 열이 아니라 내용과 위치로 맞춥니다.
  • 비교만 하며 파일을 편집하거나 병합하지는 않습니다.

자주 묻는 질문

무료인가요?

통합 문서나 CSV 파일 두 개 비교, Values와 Formulas, 다음 및 이전 변경으로 이동, Compare with Git HEAD는 무료입니다. 세 가지 Pro 도구 Export a diff report, Match rows by key columns, Compare two folders of workbooks는 각각 3번 무료로 쓸 수 있습니다. 그 뒤에는 모든 Zovo 확장에 적용되는 Zovo Pro(USD 19 한 번)가 필요합니다.

확장 없이 VS Code에서 Excel 파일 두 개를 비교할 수 있나요?

아니요. .xlsx 파일은 XML 파트를 묶은 zip 파일이라 기본 diff에서는 바이너리로 표시됩니다. 통합 문서를 읽는 확장이 필요합니다.

맨 위에 행을 하나 끼워 넣으면 아래 행이 모두 바뀐 것으로 표시되나요?

아니요. 비교하기 전에 행을 맞추므로 끼워 넣은 행은 추가된 행 하나로 표시됩니다.

마지막 커밋 이후 통합 문서에서 바뀐 내용을 볼 수 있나요?

예. Git 저장소 안의 파일을 마우스 오른쪽 버튼으로 클릭하고 Compare with Git HEAD를 고릅니다. 로컬 git을 실행합니다.
