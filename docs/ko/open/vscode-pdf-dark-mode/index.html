한국어 가이드 · PDF Reader

VS Code에서 PDF를 다크 모드로 읽기

대부분의 PDF 다크 모드는 페이지 전체를 반전해서, 사진 속 파란 하늘이 주황색이 됩니다. 무료 PDF Reader 확장은 페이지를 반전한 뒤 각 이미지의 원래 픽셀을 다시 그려 넣습니다. 그래서 글자와 배경은 어두워지고 사진은 원래 색을 유지합니다. 페이지는 VS Code 테마를 따르고, 달 버튼으로 언제든 바꿀 수 있습니다. 모두 오프라인으로 동작하며 텔레메트리가 없습니다.

VS Code에 설치Marketplace 페이지Open VSX (Cursor, Windsurf, VSCodium)

무료, MIT 라이선스. 확장 ID zovo.pdf-viewer-dark, 버전 0.3.5. VS Code 1.90.0 이상이 필요합니다.

VS Code에서 하는 방법

  1. Marketplace에서 PDF Reader 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.pdf-viewer-dark를 실행합니다.
  2. 탐색기에서 .pdf 파일을 클릭합니다. VS Code가 어두운 테마면 페이지가 처음부터 어둡게 열립니다.
  3. 툴바의 달 버튼(또는 Command Palette의 "PDF: Toggle Dark Pages")으로 이 파일의 어두운 페이지를 켜고 끕니다. 설정 pdfViewer.darkMode를 on이나 off로 바꾸면 테마를 따르지 않습니다.
  4. 달 옆의 종이 버튼은 오래 읽기 편한 세피아 페이지를 보여줍니다. pdfViewer.lightPages를 sepia로 두면 모든 PDF에 적용됩니다.
  5. Ctrl+F(macOS에서는 Cmd+F)로 검색합니다. 사이드바에 PDF 개요와 페이지 썸네일이 있습니다.
  6. 텍스트를 선택하고 4가지 색 중 하나를 고르거나 H를 누릅니다. Highlights 탭에 하이라이트가 나열되고, "Copy as Markdown"은 페이지마다 링크가 달린 목록을 복사합니다.

무료 기능과 Zovo Pro

읽기, 어두운 페이지와 세피아 페이지, 검색, 개요, 썸네일, 하이라이트, Copy as Markdown, 페이지 링크는 무료입니다.

논문이나 명세서를 많이 읽는 사람은 하이라이트를 한곳에 모으고 싶어 합니다. Export Highlights of All PDFs는 하이라이트한 모든 PDF(또는 이 워크스페이스의 PDF만)의 하이라이트를 파일별로 묶어, 색과 페이지 링크와 함께 Markdown 파일 하나로 씁니다. Zovo Pro는 페이지를 새 PDF로 추출, 삭제, 분할하기, PDF 합치기, 두 PDF 비교하기도 더합니다.

Export Highlights of All PDFs 사용하기 (Zovo Pro)

  1. Command Palette에서 "PDF: Export Highlights of All PDFs to Markdown (Pro)..."를 실행하거나, Highlights 탭의 "All PDFs" 링크를 누릅니다.
  2. 모든 PDF로 할지, 이 워크스페이스의 PDF만으로 할지 고릅니다.
  3. .md 파일을 저장할 위치를 고릅니다. PDF는 바뀌지 않습니다.

Export Highlights of All PDFs 기능은 라이선스를 묻기 전에 내 컴퓨터에서 3번 쓸 수 있고, 결과를 얻었을 때만 1번으로 셉니다. 파일을 열 때 Pro 안내는 나오지 않습니다.

Cursor, Windsurf, VSCodium에서

이 편집기들은 Open VSX에서 확장을 설치합니다. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 열고 zovo.pdf-viewer-dark를 검색한 뒤 Install을 누릅니다. 그다음은 VS Code와 같습니다.

할 수 없는 것

  • 벡터 선으로 그린 차트는 글자처럼 반전됩니다. 그림으로 저장된 차트는 원래 색을 유지합니다.
  • 하이라이트는 이 컴퓨터의 VS Code에 저장되며 PDF 안에는 쓰이지 않습니다.
  • 양식 채우기, PDF 편집, 인쇄는 하지 않습니다.
  • 200 MB가 넘는 파일은 열기 전에 물어봅니다.

자주 묻는 질문

PDF 파일이 바뀌나요?

아니요. 다크 모드와 하이라이트는 화면과 VS Code 안에만 있습니다. 파일은 바뀌지 않습니다.

LaTeX 빌드 후 자동으로 다시 읽나요?

네. 디스크의 파일이 바뀌면 다시 읽고, 같은 페이지와 같은 배율에 머뭅니다.

Ctrl+P는 그대로 쓸 수 있나요?

네. 확장이 Ctrl+P(macOS에서는 Cmd+P)를 쓰지 않으므로 PDF가 열려 있어도 Quick Open이 됩니다.

영어판 가이드에는 다른 방법과 비슷한 확장까지 더 자세히 나와 있습니다.
