한국어 가이드

VS Code에서 Claude Code 대화 기록을 읽고 이어 하기

Claude Code History & Codex History Viewer(Agent Session Viewer)를 설치합니다. ~/.claude/projects의 Claude Code 세션과 ~/.codex/sessions의 Codex 세션을 사이드 뷰 하나에 나열하고, 각 세션을 읽기 쉬운 대화 기록으로 열며, 클릭 한 번으로 터미널에서 세션을 이어 갑니다. 읽기, 검색, 이어 하기, 세션 하나를 Markdown으로 내보내기는 계정 없이 무료입니다. Zovo Pro(USD 19, 한 번 결제)는 사용량과 비용 보고서, 비밀 정보를 가리는 공유용 내보내기, Markdown 일괄 내보내기를 더하며, Pro 도구마다 3번 무료로 써 볼 수 있습니다.

VS Code에서 하는 방법

  1. Marketplace에서 Agent Session Viewer 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.agent-session-viewer를 실행합니다.
  2. 액티비티 바에서 Agent Sessions 아이콘을 클릭합니다. Sessions 뷰에 Claude Code와 Codex 세션이 프로젝트 폴더별로 나오고, 서브에이전트는 그것을 시작한 세션 아래에 나옵니다.
  3. 세션을 클릭해 읽습니다. 도구 호출은 접혀 있고, 실패한 호출에는 빨간 표시가 붙으며, 파일 편집은 diff로 보입니다. 머리글에는 모델, git 브랜치, 턴 수, 토큰 합계가 나옵니다.
  4. 예전 세션을 찾으려면 뷰 위쪽의 검색 아이콘을 누르거나 Command Palette에서 "Agent Sessions: Search Sessions"를 실행합니다. 결과를 고르면 일치하는 위치에서 세션이 열립니다.
  5. 세션 옆의 터미널 아이콘(Resume in Terminal)을 누릅니다. 프로젝트 폴더에서 터미널이 열리고 claude --resume <id> 또는 codex resume <id>가 실행됩니다.
  6. 다른 폴더에 있는 .jsonl 세션 파일은 마우스 오른쪽 버튼으로 클릭하고 Open With를 고른 뒤 Agent Session Viewer를 선택합니다.

무료 기능과 Zovo Pro가 더하는 기능

Sessions 트리, 세션 읽기, 여러 세션에 걸친 검색, Resume in Terminal, Copy Resume Command, 세션 하나를 Markdown으로 내보내기, raw 보기, Reveal in File Manager는 무료입니다. 기록 개수 제한이 없고 로그인도 필요 없습니다.

Share-safe export는 세션 하나 또는 한 프로젝트의 모든 세션을 그 자체로 열리는 HTML 페이지 하나나 Markdown 파일 하나로 저장합니다. API 키, 토큰, URL 안의 비밀번호, .env 값, 개인 키, 이메일, 홈 폴더 경로를 [REDACTED ...]로 바꾸고, 무엇을 가렸는지 메시지로 알려 줍니다. 풀 리퀘스트, 감사, 인수인계에 세션을 보낼 때 손으로 정리하지 않아도 됩니다.

Share-safe export 사용하기 (Zovo Pro)

  1. 세션을 연 다음 세션 도구 모음의 Share-safe export 버튼을 누릅니다. 또는 Sessions 트리에서 세션이나 프로젝트 폴더를 마우스 오른쪽 버튼으로 클릭하고 "Share-Safe Export, Secrets Redacted (Pro)…"를 고릅니다.
  2. 세션을 연 상태에서 Command Palette의 "Agent Sessions: Share-Safe Export, Secrets Redacted (Pro)…"를 실행해도 됩니다.
  3. 형식을 고릅니다. HTML 페이지나 Markdown 중에서, 도구 출력을 넣을지 뺄지 정합니다. 그다음 저장할 곳을 정합니다.
  4. 공유하기 전에 내보낸 파일을 읽어 보세요. 횟수는 파일이 저장됐을 때만 줄어들고, Escape나 Cancel로 취소하면 줄지 않습니다.

Share-safe export 기능은 라이선스를 묻기 전에 내 컴퓨터에서 3번 무료로 쓸 수 있습니다. 팝업도 없고 카운트다운도 없습니다.

Cursor, Windsurf, VSCodium에서

  1. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 엽니다.
  2. zovo.agent-session-viewer를 검색하고 Install을 누릅니다. Cursor, Windsurf, VSCodium은 Open VSX에서 확장을 설치하며, 이 확장은 그곳에서 zovo/agent-session-viewer라는 이름으로 올라가 있습니다.
  3. 에디터에 확장 갤러리가 없으면 Open VSX 페이지에서 .vsix 파일을 내려받고 "Extensions: Install from VSIX..."를 실행합니다.
  4. 그다음은 VS Code에서와 똑같이 동작합니다.

Agent Session Viewer의 기능

  • ~/.claude/projects(또는 $CLAUDE_CONFIG_DIR/projects)의 Claude Code 세션과 ~/.codex/sessions(또는 $CODEX_HOME/sessions)의 Codex 세션.
  • 두 도구의 서브에이전트. 그것을 시작한 세션 아래에 중첩해서 보여 줍니다.
  • 도구, 모델, 프로젝트 폴더, git 브랜치, 소요 시간, 턴 수, 토큰 합계가 있는 머리글. 파일에 비용이 기록되어 있으면 비용도 나옵니다(Claude Code는 기록하고 Codex는 기록하지 않습니다).
  • diff로 보이는 파일 편집(Edit, Write, apply_patch)과 접혀 있는 thinking, Codex reasoning 요약.
  • session_index.jsonl에서 가져온 Codex 스레드 이름. 이름을 바꾼 스레드도 그 이름으로 나옵니다.

할 수 없는 것

  • Claude Code와 Codex만 읽습니다. Cursor, Copilot, Gemini CLI 세션은 아직 지원하지 않습니다.
  • 읽기 전용입니다. 세션 파일을 바꾸거나 옮기거나 지우지 않으며, 삭제 명령도 없습니다.
  • 검색은 정규식이 아닌 일반 텍스트로 찾고, 결과 300개에서 멈춥니다.
  • Resume in Terminal을 쓰려면 Claude Code나 Codex가 설치되어 터미널의 PATH에 있어야 합니다.
  • 파일은 기본적으로 256 MB까지 읽습니다(agentSessionViewer.maxFileSizeMB). 더 큰 파일은 앞부분만 열립니다. 암호화되어 저장된 Codex reasoning은 보여 줄 수 없습니다.

자주 묻는 질문

Claude Code는 대화 기록을 어디에 저장하나요?

~/.claude/projects에 프로젝트마다 폴더 하나, 세션마다 .jsonl 파일 하나로 저장합니다. CLAUDE_CONFIG_DIR가 설정되어 있으면 그 폴더 아래에 저장합니다.

무료인가요?

네. 읽기, 검색, 이어 하기, 세션 하나를 Markdown으로 내보내기는 기록 개수 제한 없이 무료입니다. 세 Pro 도구(사용량과 비용 보고서, 공유용 내보내기, 일괄 내보내기)는 각각 3번 무료로 써 볼 수 있고, 그다음에는 모든 Zovo 확장에 쓰는 Zovo Pro 라이선스를 USD 19에 한 번 구매합니다.

뷰어에서 오래된 세션을 지울 수 있나요?

아니요. 세션 파일을 읽기만 하고, 바꾸거나 옮기거나 지우지 않습니다.

Anthropic이 만든 확장인가요?

아니요. Anthropic이나 OpenAI가 만들지 않았고 두 회사와 관계도 없습니다. 네트워크를 쓰지 않고 텔레메트리도 없습니다.
