무료 확장 XML Formatter & XPath Tools를 설치하고 XML 파일을 연 뒤 Shift+Alt+F(Mac에서는 Shift+Option+F)를 누릅니다. 태그 사이의 공백만 바뀝니다. 텍스트, CDATA, 주석, xml:space="preserve", 속성 값은 바이트 단위까지 그대로이며, 올바른 형식(well-formed)이 아닌 파일은 절대 바뀌지 않습니다. 포맷, Minify XML, 파일 자체의 네임스페이스 접두사를 쓰는 XPath 1.0, Copy XPath, XML Tree 보기는 무료이고 오프라인으로 동작합니다. Zovo Pro(USD 19 한 번)는 Run XPath on Every XML File in a Folder, Format All XML Files in a Folder, Compare Two XML Files Ignoring Formatting의 세 가지 도구를 더하며, 각 도구는 3번 무료로 쓸 수 있습니다.

VS Code에서 하는 방법

  1. Marketplace에서 XML Formatter & XPath Tools 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.zovo-xml-xpath-tools를 실행합니다.
  2. .xml 파일을 열고 Shift+Alt+F(Mac에서는 Shift+Option+F)를 누르거나 Format Document를 실행합니다. XML 포매터가 여러 개 있으면 VS Code가 어느 것을 쓸지 묻습니다. Format Selection도 쓸 수 있습니다.
  3. 포매터는 설정된 탭 크기와 탭 또는 공백 선택을 따르고, 줄 끝 문자, 바이트 순서 표시(BOM), 마지막 줄바꿈을 유지합니다. 파일이 올바른 형식이 아니면 아무것도 바뀌지 않고, 오류가 줄과 열 번호와 함께 표시됩니다.
  4. 반대로 파일을 작게 만들려면 파일 전체나 선택 영역에서 "XML: Minify XML"을 실행합니다. xmlXpathTools.minify.removeComments를 켜지 않으면 주석은 남습니다.
  5. XPath를 실행하려면 편집기 제목 표시줄의 검색 버튼을 클릭하거나 "XML: Evaluate XPath…"를 실행합니다. 결과는 XPath Results에 줄 번호와 함께 나옵니다. 결과를 클릭하면 편집기에서 해당 부분이 선택됩니다.
  6. 상태 표시줄의 XPath를 클릭하면 커서 아래 요소의 경로를 복사합니다. 위치 번호를 넣은 형식, id 또는 name 속성을 쓴 형식, 이식 가능한 local-name() 형식 중에서 고를 수 있습니다.
  7. 50 MB가 넘는 파일은 Explorer에서 마우스 오른쪽 버튼으로 클릭하고 "Format Large XML File on Disk…"를 고릅니다. 옆에 name.formatted.xml을 쓰거나, 확인을 받은 뒤 원본 파일을 바꿉니다.

무료 기능과 Zovo Pro가 더하는 기능

Format Document, Format Selection, Minify XML, XPath 1.0, Copy XPath, XML Tree 보기, Problems의 형식 오류 표시, Format Large XML File on Disk는 무료입니다. 로그인할 필요가 없고, 확장에는 네트워크 코드가 없습니다.

Run XPath on Every XML File in a Folder는 폴더 아래의 모든 .xml, .xsd, .csproj, .svg, .kml 같은 파일에 XPath 하나를 실행하며, 파일마다 그 파일의 네임스페이스 접두사를 씁니다. 결과는 스프레드시트용 CSV(file, line, kind, name, value), 스크립트용 JSON, 검토용 Markdown 보고서로 열 수 있습니다. 여러 pom.xml 파일의 모든 artifactId처럼 많은 파일에서 같은 값을 하나씩 열지 않고 얻을 수 있습니다.

Run XPath on Every XML File in a Folder 사용하기 (Zovo Pro)

  1. Explorer에서 폴더를 마우스 오른쪽 버튼으로 클릭하고 "Zovo Pro: Run XPath on Every XML File in a Folder"를 고르거나, Command Palette에서 "XML: Run XPath on Every XML File in a Folder (Pro)"를 실행하고 폴더를 고릅니다.
  2. 또는 한 파일에서 XPath를 실행한 뒤 XPath Results의 마지막 줄 "Run this XPath on every XML file in a folder"를 클릭해 같은 식을 폴더에 실행합니다.
  3. XPath를 입력합니다. 알림에 진행 상황과 Cancel 버튼이 표시됩니다.
  4. "Open as CSV", "Open as JSON", "Open a Markdown report" 중 하나를 고릅니다. 결과는 새 편집기 탭에 열립니다. 무료 사용은 결과가 나왔을 때만 1번으로 셉니다. Escape, XPath 오타, XML 파일이 없는 폴더는 횟수를 쓰지 않습니다.

Cursor, Windsurf, VSCodium에서

  1. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 엽니다.
  2. zovo.zovo-xml-xpath-tools를 검색하고 Install을 누릅니다. Cursor, Windsurf, VSCodium은 Open VSX에서 확장을 설치하며, 이 확장은 그곳에서 zovo/zovo-xml-xpath-tools라는 이름으로 올라가 있습니다.

XML Formatter & XPath Tools의 기능

  • VS Code가 XML로 여는 파일. 이 확장은 .kml, .gpx, .rss, .atom, .wsdl, .dbk, .xlf, .xliff, .resx, .nuspec, .props, .targets, .xaml 파일도 XML로 엽니다.
  • 큰 파일. 포맷, 트리, XPath는 백그라운드 스레드에서 실행됩니다. 확장의 테스트에서 요소가 약 백만 개인 49 MB 파일을 1.6초 만에 포맷했습니다.
  • 단순한 이름도 기본 네임스페이스와 일치하므로 pom.xml에서 //dependency/artifactId가 동작합니다. 엄격한 XPath 1.0을 원하면 xmlXpathTools.xpath.strictNamespaces를 켭니다.
  • 속성 배치는 쓴 그대로, 한 줄, 한 줄에 속성 하나 중에서 고릅니다(설정 xmlXpathTools.format.attributes).
  • Explorer의 XML Tree 보기는 커서를 따라가고, Problems에는 형식 오류가 줄과 열 번호와 함께 나옵니다.

할 수 없는 것

  • XPath 1.0만 지원합니다. XPath 2.0이나 3.1, XQuery, XSLT는 지원하지 않습니다.
  • 파일이 올바른 형식인지만 확인합니다. XSD나 DTD로 유효성 검사를 하지 않습니다.
  • 50 MB가 넘는 파일은 디스크에서 포맷할 수 있지만, VS Code가 이런 파일을 확장에 넘겨주지 않아 트리와 XPath는 동작하지 않습니다.
  • 디스크 포맷 명령은 UTF-8, 바이트 순서 표시가 있는 UTF-16, ISO-8859-1을 읽습니다.
  • <p>Some <b>bold</b> text</p>처럼 안에 텍스트가 있는 요소는 쓴 그대로 한 줄에 남습니다. 텍스트 없이 태그만 담은 요소에만 새 줄바꿈이 들어갑니다.

자주 묻는 질문

무료인가요?

포맷, Minify XML, XPath, Copy XPath, XML Tree 보기, 형식 검사는 무료입니다. 세 가지 Pro 도구 Run XPath on Every XML File in a Folder, Format All XML Files in a Folder, Compare Two XML Files Ignoring Formatting은 각각 3번 무료로 쓸 수 있습니다. 그 뒤에는 Zovo Pro가 필요하며, USD 19 한 번으로 모든 Zovo 확장에 적용됩니다.

포맷하면 텍스트나 CDATA가 바뀌나요?

아니요. 텍스트 없이 태그만 담은 요소에서 태그 사이의 공백만 바뀝니다. 텍스트, CDATA, 주석, xml:space="preserve" 안의 내용은 그대로 복사되며, 다시 포맷해도 바뀌는 것이 없습니다.

pom.xml에서 XPath가 아무것도 선택하지 않는 이유는 무엇인가요?

이 파일에는 기본 네임스페이스가 있습니다. 이 확장에서는 단순한 이름도 기본 네임스페이스와 일치하므로 //dependency가 동작합니다. 엄격한 XPath 1.0을 원하면 xmlXpathTools.xpath.strictNamespaces를 켭니다.

Cursor에서도 되나요?

네. Cursor, Windsurf, VSCodium은 Open VSX에서 설치하며, 그곳에는 zovo/zovo-xml-xpath-tools로 게시되어 있습니다.
