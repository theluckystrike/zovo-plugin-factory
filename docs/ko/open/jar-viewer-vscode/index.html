VS Code에서 JAR를 열고 디컴파일된 Java 소스 읽기

무료 확장 JAR Viewer & Java Decompiler를 설치하고 .jar, .war, .ear, .aar, .class 파일을 클릭합니다. 패키지, 리소스, MANIFEST.MF와 클래스마다 Java 버전이 나오고, Java 없이 보는 javap -c -p 형식의 바이트코드 목록과, 내장된 CFR 0.152가 컴퓨터에 있는 Java 8 이상 런타임으로 디컴파일한 Java 소스도 볼 수 있습니다. 모든 보기 기능과 클래스를 하나씩 디컴파일하는 기능은 무료입니다. Zovo Pro(USD 19, 한 번 결제)는 Export decompiled sources of a JAR, Compare two JARs, Find in every JAR of a folder 세 도구를 더하며, 도구마다 3번 무료로 써 볼 수 있습니다.

VS Code에서 하는 방법

  1. Marketplace에서 JAR Viewer 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.zovo-jar-viewer를 실행합니다.
  2. Explorer에서 .jar, .war, .ear, .aar, .class 파일을 클릭하면 JAR Viewer로 열립니다. Overview에는 형식, 항목 수, 클래스 수, 패키지 수, Main-Class, Created by, MANIFEST.MF, 그리고 클래스가 어떤 Java 버전용으로 컴파일됐는지 보여 주는 차트가 나옵니다.
  3. 패키지 트리 위의 필터 상자에 이름 일부를 입력합니다. 입력하는 동안 클래스와 파일을 찾아 줍니다. 내부 클래스는 바깥 클래스 아래에 흐리게 표시됩니다.
  4. 클래스를 클릭합니다. Java source 탭이 CFR 0.152로 디컴파일한 소스를 내부 클래스와 함께 보여 줍니다. Copy는 소스를 클립보드에 넣고, Open in editor는 일반 에디터 탭에서 엽니다.
  5. Java source 탭에 디컴파일된 Java 소스를 보려면 Java 런타임이 필요하다는 안내가 나오면, jarViewer.javaPath를 java 실행 파일이나 JDK 폴더로 설정하거나 JAVA_HOME을 설정합니다. "JAR Viewer: Check the Java runtime used for decompiling"을 실행하면 어떤 Java를 쓰는지 알 수 있습니다.
  6. Bytecode 탭을 열면 모든 opcode, 예외 테이블, 줄 번호가 담긴 javap -c -p 형식 목록이 나옵니다. Members, Constant pool, Class info 탭은 선언, 상수 풀 항목, 클래스 속성을 보여 줍니다.
  7. Spring Boot JAR, WAR, AAR에서는 BOOT-INF/lib나 WEB-INF/lib 안의 JAR, 또는 AAR의 classes.jar를 클릭한 다음 "Open nested archive"를 누릅니다. 한 단계 깊이까지 열리며, 위쪽에 있는 바깥 파일 이름 버튼을 누르면 돌아갑니다.

무료 기능과 Zovo Pro가 더하는 기능

패키지 트리, Overview, 매니페스트, 리소스, 디컴파일된 Java 소스, 바이트코드, 멤버, 상수 풀, 클래스 정보, 중첩 JAR는 로그인 없이 무료입니다. CFR은 확장에 들어 있고 컴퓨터에 이미 있는 Java로 실행됩니다. 확장은 아카이브를 바꾸지 않고 네트워크를 쓰지 않습니다.

Export decompiled sources of a JAR는 JAR, WAR, EAR, AAR의 모든 클래스를 CFR로 디컴파일해 .java 파일로 폴더에 씁니다. 진행 상황과 Cancel 버튼이 나옵니다. Java 런타임이 없으면 대신 바이트코드 목록을 씁니다. 클래스를 하나씩 여는 대신 라이브러리 전체를 소스 파일로 받아 에디터에서 검색하거나 읽을 수 있습니다.

Export decompiled sources of a JAR 사용하기 (Zovo Pro)

  1. 아카이브를 열고 뷰어 위쪽의 "Export sources…"를 누르거나, 작은 Pro tools 줄의 "Export decompiled sources"를 누릅니다. Explorer에서 파일을 마우스 오른쪽 버튼으로 클릭하고 "Zovo Pro: Export decompiled sources"를 골라도 됩니다.
  2. 또는 Command Palette에서 "JAR Viewer: Export decompiled sources of a JAR (Pro)"를 실행합니다. 열린 아카이브가 없으면 JAR, WAR, EAR, AAR 파일을 고르라고 합니다.
  3. 폴더를 고르고 "Export here"를 누릅니다. 소스는 아카이브 이름 끝에 -src가 붙은 새 폴더에 들어갑니다.
  4. 알림에 진행 상황이 나옵니다. Cancel을 누르면 내보내기가 멈추고 무료 횟수가 줄지 않습니다. 끝나면 뷰어가 몇 개의 파일을 어디에 썼는지 알려 줍니다.

Export decompiled sources of a JAR 기능은 라이선스를 묻기 전에 내 컴퓨터에서 3번 무료로 쓸 수 있습니다. 팝업도 없고 카운트다운도 없습니다.

Cursor, Windsurf, VSCodium에서

  1. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 엽니다.
  2. zovo.zovo-jar-viewer를 검색하고 Install을 누릅니다. Cursor, Windsurf, VSCodium은 Open VSX에서 확장을 설치하며, 이 확장은 그곳에서 zovo/zovo-jar-viewer라는 이름으로 올라가 있습니다.
  3. 에디터에 확장 갤러리가 없으면 Open VSX 페이지에서 .vsix 파일을 내려받고 "Extensions: Install from VSIX..."를 실행합니다.
  4. 그다음은 VS Code에서와 똑같이 동작합니다.

JAR Viewer의 기능

  • JAR, WAR, EAR, AAR 아카이브, 그리고 같은 폴더의 내부 클래스를 포함한 단독 .class 파일.
  • 항목이 200,000개까지인 아카이브. 필터는 50,000개 항목 중에서 입력하는 동안 클래스나 파일을 찾습니다.
  • 클래스 데이터의 제네릭 시그니처, record, permitted subclass, nest host, 애너테이션.
  • properties, XML, JSON, SQL, services 파일 같은 텍스트 리소스는 텍스트로, 바이너리 파일은 hex 미리 보기로 보여 줍니다.
  • Spring Boot BOOT-INF/lib, WAR WEB-INF/lib, AAR classes.jar 아카이브를 한 단계 깊이까지 엽니다.

할 수 없는 것

  • 디컴파일된 소스를 보려면 컴퓨터에 Java 8 이상이 있어야 합니다. Java가 없어도 바이트코드와 다른 모든 보기는 동작합니다.
  • CFR 출력은 원래 소스와 다를 수 있습니다. 지역 변수 이름, 일부 제네릭, 람다가 그 예입니다.
  • 항목은 하나에 64 MB, 클래스 파일은 16 MB, 중첩 아카이브는 128 MB까지 풉니다. 원격 파일 시스템이나 가상 파일 시스템의 파일은 256 MB까지 읽습니다.
  • 읽기 전용이라 클래스를 편집하거나 다시 컴파일할 수 없습니다. 중첩 아카이브는 한 단계 깊이까지만 열립니다.
  • APK와 DEX 파일은 읽지 않습니다.

자주 묻는 질문

무료인가요?

네. 모든 보기 기능과 클래스를 하나씩 디컴파일하는 기능은 무료입니다. 세 Pro 도구(Export decompiled sources of a JAR, Compare two JARs, Find in every JAR of a folder)는 각각 3번 무료로 써 볼 수 있고, 도구가 결과를 냈을 때만 한 번으로 셉니다. 그다음에는 Zovo Pro가 필요하며, 모든 Zovo 확장에 쓰는 라이선스를 USD 19에 한 번 구매합니다.

Java source 탭은 왜 Java를 요구하나요?

CFR은 Java 프로그램입니다. 뷰어는 jarViewer.javaPath, JAVA_HOME, PATH의 java 순서로 Java를 찾습니다. Java 8 이상 런타임이면 무엇이든 됩니다.

Java 없이 바이트코드를 볼 수 있나요?

네. Bytecode, Members, Constant pool, Class info 탭은 JavaScript로 읽으므로 Java가 필요 없습니다.

Cursor에서도 되나요?

네. Open VSX에 zovo/zovo-jar-viewer로 올라가 있어 Cursor, Windsurf, VSCodium에서 설치할 수 있습니다.
