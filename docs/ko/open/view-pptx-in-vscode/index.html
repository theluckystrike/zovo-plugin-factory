한국어 가이드 · PPTX Viewer

VS Code에서 PowerPoint .pptx 슬라이드 보기

무료 PPTX Viewer 확장은 PowerPoint 발표 자료를 VS Code에서 바로 엽니다. .pptx, .ppsx, .potx, .pptm, 구형 .ppt를 썸네일, 발표자 노트, 검색, Present 버튼과 함께 보여줍니다. 스크립트, python-pptx, AI 에이전트가 방금 만든 발표 자료를 확인할 때 특히 편합니다. 파일이 저장될 때마다 슬라이드가 다시 읽힙니다. PowerPoint, LibreOffice, 업로드 모두 필요 없습니다.

VS Code에 설치Marketplace 페이지Open VSX (Cursor, Windsurf, VSCodium)

무료, MIT 라이선스. 확장 ID zovo.pptx-slide-viewer, 버전 0.5.5. VS Code 1.90.0 이상이 필요합니다.

VS Code에서 하는 방법

  1. Marketplace에서 PPTX Viewer 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.pptx-slide-viewer를 실행합니다.
  2. 탐색기에서 .pptx, .ppsx, .potx, .pptm, .ppt 파일을 클릭합니다. 슬라이드와 썸네일이 나오고, 아래에 발표자 노트가 보입니다.
  3. Ctrl+F(macOS에서는 Cmd+F)로 발표 자료 전체의 제목, 글머리 기호, 표, 노트를 검색합니다. Outline 탭에 해당 슬라이드가 나열되고, Enter로 다음 슬라이드로 갑니다.
  4. Present를 누르면 한 번에 한 장씩 전체 화면으로 보여줍니다. 화살표 키, 스페이스바, 클릭으로 넘기고 Esc로 편집기에 돌아옵니다.
  5. Copy: "PNG"는 현재 슬라이드를 약 1920픽셀 너비의 그림으로 복사해 pull request나 이슈에 붙일 수 있게 합니다. Copy: "Markdown"은 슬라이드를 Markdown으로, "All"은 발표 자료 전체를 복사합니다.
  6. 스크립트가 발표 자료를 다시 만드는 동안 파일을 열어 두세요. 저장될 때마다 약 1초 안에 슬라이드가 갱신되고 보던 슬라이드에 머뭅니다.

무료 기능과 Zovo Pro

슬라이드 보기, Present, 발표자 노트, 검색, 썸네일과 개요, 슬라이드 한 장을 PNG로 복사하거나 저장하기, Copy as Markdown은 무료입니다.

PowerPoint가 없는 사람에게 발표 자료를 보내야 할 때, Export Deck as PDF는 슬라이드 한 장을 한 쪽으로, 슬라이드 크기 그대로 PDF에 저장합니다. 각 쪽은 슬라이드 그림이라서 PDF 안의 텍스트는 선택할 수 없습니다. Zovo Pro는 모든 슬라이드를 PNG로 내보내기, 폴더 안의 발표 자료를 노트와 함께 Markdown으로 바꾸기, 사진이 많은 발표 자료의 작은 사본 저장하기(Compress Deck)도 더합니다.

Export Deck as PDF 사용하기 (Zovo Pro)

  1. 발표 자료를 연 상태에서 툴바의 Export를 누르고 PDF를 고르거나, Command Palette에서 "Export Deck as PDF (Pro)..."를 실행합니다.
  2. PDF를 저장할 위치를 고릅니다.
  3. 원래 발표 자료는 바뀌지 않고, 그림은 내 컴퓨터에서 만들어집니다.

Export Deck as PDF 기능은 라이선스를 묻기 전에 내 컴퓨터에서 3번 쓸 수 있고, 결과를 얻었을 때만 1번으로 셉니다. 파일을 열 때 Pro 안내는 나오지 않습니다.

Zovo Pro는 USD 19를 한 번만 내면 됩니다. 구독이 아니며, 이 확장뿐 아니라 모든 Zovo 확장의 Pro 도구가 켜집니다. 카드(Stripe)로 결제하면 다음 페이지에 라이선스 키가 표시됩니다. VS Code의 Command Palette에서 "Zovo Pro: Enter Zovo Pro license key"를 실행하고 키를 붙여 넣으세요. 키는 네트워크 연결 없이 내 컴퓨터에서 확인됩니다. GitHub Sponsors로 결제할 때는 "$19 one time" 등급을 고른 뒤, 같은 GitHub 계정으로 "Zovo Pro: I already paid: unlock with GitHub Sponsors"를 실행하세요. PayPal로 결제할 때는 메모에 "Zovo Pro"라고 적어 USD 19를 보내면 하루 안에 이메일로 키를 받습니다.

5명 팀 라이선스는 USD 59 한 번이며, 카드 또는 PayPal로 결제할 수 있습니다. 모든 규칙과 Pro 도구는 Zovo Pro 페이지(영어)에 있습니다.

Cursor, Windsurf, VSCodium에서

이 편집기들은 Open VSX에서 확장을 설치합니다. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 열고 zovo.pptx-slide-viewer를 검색한 뒤 Install을 누릅니다. 그다음은 VS Code와 같습니다.

할 수 없는 것

  • 뷰어입니다. 슬라이드를 편집하지 않습니다.
  • 구형 .ppt는 텍스트로만 열립니다. 제목, 슬라이드 텍스트, 노트가 보이고 그림과 레이아웃은 없습니다.
  • 동영상, 오디오, 포함된 개체는 그려지지 않으며, 슬라이드에 무엇이 빠졌는지 표시됩니다.
  • 컴퓨터에 없는 글꼴은 비슷한 글꼴로 바뀌므로 줄바꿈이 PowerPoint와 조금 다를 수 있습니다.

자주 묻는 질문

확장이 유료인가요?

아니요. 보기, 발표, 검색, 슬라이드 복사는 무료입니다. 내보내기, 압축, 발표 자료 비교만 Zovo Pro(USD 19 한 번)이며, 각각 3번은 무료로 쓸 수 있습니다.

Remote SSH, WSL, Codespaces에서도 되나요?

네. 확장이 VS Code를 통해 파일을 읽으므로 Remote SSH, WSL, Dev Containers, Codespaces에서도 동작합니다.

파일이 어딘가로 전송되나요?

아니요. 모든 처리가 내 컴퓨터에서 이루어지고 텔레메트리도 없습니다.
