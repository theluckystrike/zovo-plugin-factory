VS Code와 Cursor에서 파일 열기

VS Code는 텍스트, 이미지, 일부 동영상을 엽니다. Word, PowerPoint, Excel, 다크 모드 PDF, 바이너리 파일을 보려면 확장이 필요합니다. 각 가이드는 VS Code와 Cursor에서 하는 방법, 무료 기능, Zovo Pro가 더하는 기능을 설명합니다.

  • VS Code에서 .docx Word 파일 열기
    VS Code는 .docx를 바이너리 파일로 보여줍니다. 무료 DOCX Viewer 확장을 설치하면 Word 문서가 검색, 개요, 다크 모드가 있는 미리보기로 열립니다. Cursor에서도 됩니다.
  • VS Code에서 PowerPoint .pptx 슬라이드 보기
    VS Code나 Cursor에서 .pptx, .ppsx, .potx, 구형 .ppt를 열고 썸네일, 발표자 노트, 검색, 전체 화면 발표를 씁니다. 무료 확장이며 파일을 업로드하지 않습니다.
  • VS Code에서 Excel과 CSV를 표로 열기
    VS Code에서 .xlsx, .xls, .ods, CSV, Parquet을 정렬과 필터가 되는 표로 보고(최대 1,000,000행), GROUP BY가 되는 SQL을 실행합니다. 무료 확장이며 Excel과 Python이 필요 없습니다.
  • VS Code에서 PDF를 다크 모드로 읽기
    VS Code에서 어두운 페이지나 세피아 페이지로 PDF를 읽고, 사진은 원래 색을 유지합니다. 검색, 개요, 썸네일, Markdown으로 복사되는 하이라이트. 무료 오프라인 확장입니다.
  • VS Code의 헥스 에디터
    VS Code에서 어떤 파일이든 바이트를 보고, 편집하고, 비교합니다. 4 GB 디스크 이미지까지 됩니다. 오프셋 이동, 와일드카드 검색, 데이터 인스펙터. 무료 오프라인 확장입니다.
