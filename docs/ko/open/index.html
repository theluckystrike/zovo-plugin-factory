VS Code와 Cursor에서 파일 열기

VS Code는 텍스트, 이미지, 일부 동영상을 엽니다. Word, PowerPoint, Excel, 다크 모드 PDF, 바이너리 파일을 보려면 확장이 필요합니다. 각 가이드는 VS Code와 Cursor에서 하는 방법, 무료 기능, Zovo Pro가 더하는 기능을 설명합니다.

  • VS Code에서 .docx Word 파일 열기
    VS Code는 .docx를 바이너리 파일로 보여줍니다. 무료 DOCX Viewer 확장을 설치하면 Word 문서가 검색, 개요, 다크 모드가 있는 미리보기로 열립니다. Cursor에서도 됩니다.
  • VS Code에서 PowerPoint .pptx 슬라이드 보기
    VS Code나 Cursor에서 .pptx, .ppsx, .potx, 구형 .ppt를 열고 썸네일, 발표자 노트, 검색, 전체 화면 발표를 씁니다. 무료 확장이며 파일을 업로드하지 않습니다.
  • VS Code에서 Excel과 CSV를 표로 열기
    VS Code에서 .xlsx, .xls, .ods, CSV, Parquet을 정렬과 필터가 되는 표로 보고(최대 1,000,000행), GROUP BY가 되는 SQL을 실행합니다. 무료 확장이며 Excel과 Python이 필요 없습니다.
  • VS Code에서 PDF를 다크 모드로 읽기
    VS Code에서 어두운 페이지나 세피아 페이지로 PDF를 읽고, 사진은 원래 색을 유지합니다. 검색, 개요, 썸네일, Markdown으로 복사되는 하이라이트. 무료 오프라인 확장입니다.
  • VS Code의 헥스 에디터
    VS Code에서 어떤 파일이든 바이트를 보고, 편집하고, 비교합니다. 4 GB 디스크 이미지까지 됩니다. 오프셋 이동, 와일드카드 검색, 데이터 인스펙터. 무료 오프라인 확장입니다.
  • VS Code에서 오디오 파일 재생하기
    무료 Audio Player로 VS Code에서 WAV, MP3, FLAC, Ogg, Opus 파일을 재생합니다. 파형, 스펙트로그램, A-B 반복, 재생 속도, LUFS 라우드니스를 봅니다.
  • VS Code에서 HTML, JSX, Vue 태그 이름을 자동으로 함께 바꾸기
    HTML, JSX, Vue 태그 이름을 바꾸면 짝이 되는 태그도 입력하는 대로 바뀝니다. VS Code linked editing 기반의 무료 확장으로, 태그 자동 닫기와 한 번에 되돌리기도 됩니다.
  • VS Code에서 AWS S3, Cloudflare R2, MinIO 버킷을 탐색하는 방법
    VS Code에서 S3, R2, MinIO, B2, Wasabi 버킷을 탐색합니다. 객체를 읽기 전용으로 열고, 이어 받기가 되는 업로드와 다운로드, 드라이런 계획 뒤 폴더 동기화.
  • VS Code에서 Claude Code 대화 기록을 읽고 이어 하기
    VS Code에서 지난 Claude Code, Codex 세션을 읽고, 검색하고, 이어서 실행합니다. 서브에이전트는 중첩 표시, 편집은 diff, 토큰 합계까지. 읽기 전용, 오프라인.
  • VS Code에서 PDF, Word, PowerPoint, Excel 파일을 Markdown으로 변환하는 방법
    VS Code에서 PDF, DOCX, PPTX, XLSX, CSV, HTML, EPUB 파일을 마우스 오른쪽 버튼으로 클릭하면 옆에 Markdown이 열립니다. 무료이고 오프라인이며 Python도 업로드도 필요 없습니다.
  • VS Code에서 DXF 도면 열기
    무료 DXF Viewer로 VS Code에서 .dxf 도면을 봅니다. ASCII와 바이너리 DXF, 레이어, 페이퍼 공간 시트, 텍스트 찾기, 측정, PNG와 SVG 내보내기.
  • VS Code에서 비밀 값을 화면에 보이지 않고 .env 파일을 편집하는 방법
    VS Code에서 .env 파일에 색을 입히고, 커서가 그 줄에 올 때까지 비밀 값을 점으로 가리며, 중복 키와 잘못된 따옴표를 고칩니다. 무료이고 오프라인입니다.
  • VS Code에서 ELF, EXE, DLL 파일의 섹션과 임포트 보기
    무료 ELF Viewer & PE Viewer로 VS Code에서 .so, .exe, .dll, .dylib 파일을 엽니다. 헤더, 섹션, 임포트, 익스포트, 심볼, hex를 읽기 전용으로 봅니다.
  • VS Code에서 폰트 파일 미리보기
    무료 Font Viewer로 VS Code에서 .ttf, .otf, .woff, .woff2, .ttc 폰트를 엽니다. 설치하지 않고 문장을 입력해 보고, 모든 글리프와 라이선스를 확인합니다.
  • VS Code에서 nginx 설정 파일을 포맷하고 검사하는 방법
    VS Code에서 올바른 파일을 깨뜨리지 않고 nginx.conf를 포맷합니다. 빠진 ;와 잘못된 블록의 지시어를 입력 중에 표시하고, 약 300개 지시어에 호버 도움말을 제공합니다.
  • VS Code에서 bash 또는 zsh 스크립트를 포맷하는 방법
    VS Code에서 Shift+Alt+F 또는 저장할 때 bash, sh, zsh, bats, mksh 스크립트를 포맷합니다. shfmt 3.14.1 내장, .editorconfig 지원, 오프라인 동작.
  • VS Code에서 XML을 포맷하고 XPath로 조회하기
    VS Code에서 태그 사이 공백만 바꿔 XML을 포맷하거나 압축하고, 파일의 네임스페이스로 XPath 1.0을 실행하며, 커서 위치의 XPath를 복사합니다.
  • Graphviz를 설치하지 않고 DOT 그래프 미리보기
    Graphviz가 내장된 확장으로 VS Code에서 .dot, .gv 파일을 입력하는 대로 에디터 옆에 미리 봅니다. 레이아웃 엔진 여섯 개, 클릭하면 줄 이동, SVG와 PNG 내보내기.
  • VS Code에서 코드 속 이미지 경로의 이미지를 거터와 호버로 보기
    VS Code에서 JS, CSS, HTML, Markdown의 이미지 경로 옆 거터에 썸네일이 보이고, 마우스를 올리면 이미지와 픽셀 크기, 파일 크기가 나옵니다. 무료입니다.
  • VS Code에서 JAR를 열고 디컴파일된 Java 소스 읽기
    VS Code에서 .jar, .war, .ear, .aar, .class 파일을 엽니다. 패키지, MANIFEST.MF, 바이트코드, CFR로 디컴파일한 Java 소스를 무료로, 읽기 전용으로 봅니다.
  • VS Code에서 Mermaid 다이어그램 미리보기
    무료 Mermaid Viewer로 VS Code에서 .mmd 파일과 Markdown 블록의 Mermaid 다이어그램을 미리 봅니다. 실시간 미리보기, PNG와 SVG 내보내기, 로그인 없이 오프라인.
  • VS Code에서 쓰는 무료 NetCDF 뷰어
    Windows, macOS, Linux의 VS Code에서 NetCDF .nc 파일을 엽니다. 헤더, 변수, 해안선이 그려진 지도, 시계열을 봅니다. HDF5 .h5와 MATLAB 7.3 .mat도 열립니다.
  • VS Code에서 NumPy .npy, .npz 파일 보기
    무료 Tensor Viewer로 VS Code에서 .npy, .npz NumPy 배열을 엽니다. dtype, shape, 통계, 히트맵, 이미지, 값까지 Python 없이 볼 수 있습니다.
  • 압축을 풀지 않고 ZIP 안의 파일 열기
    VS Code에서 ZIP, JAR, TAR, TAR.GZ 안을 둘러보고, 디스크에 풀지 않고 파일 하나를 읽기 전용 탭으로 엽니다. 무료이고 오프라인에서 동작합니다.
  • VS Code에서 PCAP 파일 열기
    무료 PCAP Viewer로 VS Code에서 .pcap, .pcapng, .pcap.gz 캡처를 읽습니다. 패킷 목록, 프로토콜 트리, hex 창, 필터를 Wireshark 없이 씁니다.
  • VS Code에서 MOV, MKV, WebM, MP4 동영상을 소리까지 재생하기
    VS Code에서 AAC 소리가 있는 MP4, MOV, M4V를 다른 설치 없이 소리와 함께 재생합니다. MKV, WebM, AVI는 직접 설치한 ffmpeg로 재생합니다. 자막도 되는 무료 플레이어.
  • VS Code에서 입력하면서 PlantUML 다이어그램 미리보기
    VS Code에서 .puml 파일과 Markdown의 plantuml 블록을 실시간으로 미리 봅니다. 내장 jar가 내 컴퓨터에서 그립니다. Java 11 필요, Graphviz 불필요.
  • VS Code에서 구문 강조, 포맷, 정의로 이동으로 .proto 파일 편집하기
    VS Code에서 .proto 파일을 강조, 포맷, 검사합니다. 주석을 모두 지키는 포맷터와 protoc과 같은 문구의 오류를 제공합니다. 무료, 오프라인, protoc 불필요.
  • VS Code에서 EPUB 책 읽기
    VS Code 탭에서 .epub 파일을 페이지 단위나 스크롤로 읽습니다. 목차, 책 전체 검색, 각주 팝업, 세피아와 다크 테마를 지원하며 무료로 오프라인에서 씁니다.
  • VS Code에서 C++ 파일을 클릭 한 번으로 실행하기
    VS Code에서 열린 .cpp나 .c 파일을 내 컴퓨터의 gcc, g++, clang으로 클릭 한 번에 컴파일하고 실행합니다. 터미널 입력, Problems의 오류, 테스트 케이스.
  • VS Code에서 SQLite 데이터베이스 열기
    무료 SQLite Viewer & Editor로 VS Code에서 .db, .sqlite 파일을 엽니다. 테이블, 스키마, SQL을 보고, 셀과 행을 고친 뒤 백업을 만들며 저장합니다.
  • VS Code에서 STL 파일 보기
    무료 3D Model Viewer로 VS Code에서 STL 파일을 엽니다. 회전, 두 점 사이 거리 측정, 와이어프레임, 모델 통계를 봅니다. OBJ, PLY, 3MF, GLB, glTF도 열립니다.
  • 화질 손실 없이 TIFF를 PNG로 변환하기
    VS Code에서 TIFF, BigTIFF, GeoTIFF 파일을 무료로 열고, 한 페이지나 모든 페이지를 PNG로 저장합니다. 8비트와 16비트 값은 그대로 유지됩니다. 오프라인.
  • XMind 없이 XMind를 PDF로: 모든 시트를 PDF 하나로
    XMind 없이 VS Code에서 .xmind 마인드맵을 열고 모든 시트를 시트당 한 페이지로 PDF 하나에 저장합니다. 보기는 무료이고, PDF는 Zovo Pro 도구입니다.
