VS Code에서 PCAP 파일 열기

무료 확장 PCAP Viewer를 설치하고 .pcap이나 .pcapng 파일을 클릭합니다. 패킷 목록, 프로토콜 트리, 트리와 연결된 hex 창, Wireshark 방식의 표시 필터, 스트림 따라가기(follow stream), 통계가 나옵니다. 파일을 JavaScript로 직접 읽으므로 Wireshark, tshark, sharkd가 필요 없습니다. 뷰어는 무료이고, Zovo Pro(USD 19, 한 번 결제)는 패킷 목록 CSV/JSON 내보내기, Markdown 캡처 보고서, 폴더 요약을 더하며, 도구마다 3번 무료로 써 볼 수 있습니다.

VS Code에서 하는 방법

  1. Marketplace에서 PCAP Viewer 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.zovo-pcap-viewer를 실행합니다.
  2. .pcap, .pcapng, .pcap.gz, .pcapng.gz, .ntar 파일을 클릭합니다. .cap, .dmp 같은 다른 이름은 Explorer에서 파일을 마우스 오른쪽 버튼으로 클릭하고 "Open in PCAP Viewer"를 고릅니다.
  3. tcp.port == 443 && ip.addr == 10.0.0.1 같은 표시 필터를 입력하고 Enter를 누릅니다. 필터가 맞으면 상자가 초록색이 되고, 틀리면 무엇이 잘못됐는지 알려 줍니다.
  4. 프로토콜 트리에서 필드를 클릭하면 hex 창에서 해당 바이트가 강조됩니다. 바이트를 클릭하면 그 바이트가 속한 필드를 찾아 줍니다.
  5. 패킷을 더블클릭하면 그 TCP 또는 UDP 스트림을 ASCII, UTF-8, hex 덤프로 따라갑니다. 내용을 복사하거나 파일로 저장할 수 있습니다.
  6. Statistics를 누르면 프로토콜 계층, 대화(conversations), 엔드포인트, 캡처에서 찾은 이름이 나옵니다. 행을 클릭하면 그 값으로 필터가 걸립니다.
  7. Export 메뉴를 열어 선택한 패킷이나 필터에 보이는 모든 패킷을 새 pcap 파일로 저장합니다.

무료 기능과 Zovo Pro가 더하는 기능

패킷 목록, 프로토콜 트리, 연결된 hex 창, 표시 필터, 저장한 필터, 스트림 따라가기, 통계, 패킷을 새 pcap 파일로 내보내기는 무료입니다. 로그인이 필요 없고 오프라인에서 동작합니다.

필터에 보이는 패킷을 한 패킷당 한 행으로 CSV나 JSON 파일에 씁니다. 번호, UTC 시각, 시작 후 경과 초, 출발지, 목적지, 포트, 프로토콜, 길이, 스트림 필터, 캡처에서 찾은 호스트 이름, Info 텍스트가 들어갑니다. CSV는 수식처럼 보이는 텍스트를 안전하게 바꿔 두어 Excel에서 바로 열 수 있고, JSON은 jq와 pandas에서 쓸 수 있습니다. 행을 손으로 복사하지 않고도 티켓이나 스크립트에 넣을 표를 얻습니다.

Cursor, Windsurf, VSCodium에서

  1. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 엽니다.
  2. zovo.zovo-pcap-viewer를 검색하고 Install을 누릅니다. Cursor, Windsurf, VSCodium은 Open VSX에서 확장을 설치하며, 이 확장은 그곳에서 zovo/zovo-pcap-viewer라는 이름으로 올라가 있습니다.
  3. 에디터에 확장 갤러리가 없으면 Open VSX 페이지에서 .vsix 파일을 내려받고 "Extensions: Install from VSIX..."를 실행합니다.
  4. 그다음은 VS Code에서와 똑같이 동작합니다.

PCAP Viewer의 기능

  • pcap(마이크로초, 나노초, 리틀 엔디언과 빅 엔디언)과 pcapng. .gz로 압축된 파일도 읽습니다.
  • Ethernet, 802.1Q VLAN, Linux cooked capture(SLL, SLL2), raw IPv4와 IPv6, BSD loopback, 802.11 헤더와 radiotap.
  • ARP, IPv4, IPv6, ICMP, ICMPv6, TCP, UDP, DNS와 mDNS, DHCP, HTTP/1.x, 서버 이름(SNI)과 ALPN이 있는 TLS 레코드, QUIC long header.
  • 큰 캡처. 릴리스 점검에서 패킷 1,438,965개가 든 1 GB 캡처의 목록이 약 2초 만에 나왔습니다.
  • 손상된 파일. 손상된 곳 앞의 패킷은 모두 보여 주고, 무엇이 어디서 잘못됐는지 메시지로 알려 줍니다.

할 수 없는 것

  • 목록에 있는 프로토콜만 필드로 풀어 보여 줍니다. HTTP는 HTTP/1.x, 802.11은 헤더, QUIC은 long header까지입니다.
  • TLS 트래픽은 복호화하지 않습니다. 서버 이름(SNI)과 ALPN이 있는 TLS 레코드를 보여 줍니다.
  • 필터 상자는 Wireshark 표시 필터 문법 중 자주 쓰는 부분만 받고, 전체 문법을 받지는 않습니다.
  • .gz 캡처는 512 MB에서 압축 풀기를 멈추고 그렇게 알려 줍니다(설정 pcapViewer.maxGzipMB).
  • 원격 파일 시스템이나 가상 파일 시스템의 파일은 256 MB까지 엽니다(설정 pcapViewer.maxRemoteMB).

자주 묻는 질문

Wireshark를 설치해야 하나요?

아니요. PCAP Viewer는 Windows, macOS, Linux의 VS Code 안에서 JavaScript로 pcap과 pcapng를 읽습니다. Wireshark, tshark, sharkd를 쓰지 않습니다.

캡처를 열면 DNS 질의가 나가나요?

아니요. 호스트 이름은 패킷 안의 DNS 응답과 pcapng 파일의 이름 블록에서만 가져옵니다. 이 확장은 텔레메트리가 없고 네트워크 요청을 보내지 않습니다.

무료인가요?

네. 뷰어, 필터, 스트림 따라가기, 통계, pcap 내보내기는 무료입니다. Export packet list to CSV or JSON, Capture report, Folder summary는 Zovo Pro 도구로 각각 3번 무료로 써 볼 수 있고, 그다음에는 모든 Zovo 확장에 쓰는 라이선스를 USD 19에 한 번 구매합니다.

Cursor에서도 되나요?

네. VS Code 1.90 이상과 Cursor, Windsurf, VSCodium처럼 Open VSX에서 확장을 설치하는 에디터에서 동작합니다.
