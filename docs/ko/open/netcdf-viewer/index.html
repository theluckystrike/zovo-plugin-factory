VS Code에서 쓰는 무료 NetCDF 뷰어

VS Code에 무료 확장 NetCDF Viewer & HDF5 Viewer를 설치하고 .nc 파일을 클릭합니다. 헤더, 변수 트리, 해안선이 그려진 지도, 시간 슬라이더, 클릭한 지점의 시계열을 Python, NCL, 다른 설치 없이 볼 수 있습니다. 같은 뷰어로 HDF5 .h5 파일과 MATLAB 7.3 .mat 파일도 열 수 있고, 이 기능은 모두 무료입니다. Zovo Pro(USD 19, 한 번 결제)는 Compare two files와 Export a subset 두 도구를 더하며, 도구마다 3번 무료로 써 볼 수 있습니다.

VS Code에서 하는 방법

  1. Marketplace에서 NetCDF Viewer & HDF5 Viewer 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.hdf5-netcdf-explorer를 실행합니다.
  2. Explorer에서 .nc, .nc4, .netcdf, .cdf 파일을 클릭합니다. 개요 화면에 형식, 차원, 전역 속성, 모든 변수의 표가 ncdump -h와 비슷하게 나옵니다.
  3. 왼쪽 트리에서 변수를 고릅니다. 2차원 슬라이스가 히트맵으로 그려지고, 행과 열이 위도와 경도이면 해안선도 함께 그려집니다.
  4. 시간 슬라이더를 움직이거나, 옆의 ▶를 눌러 시간 순서대로 재생합니다. 지도에서 한 지점을 클릭하면 그 지점의 시계열이 그려집니다.
  5. Table 탭을 열면 값을 100행 x 30열씩 넘겨 볼 수 있고, 머리글에는 좌표 값이 나옵니다.
  6. "Save PNG"를 눌러 그래프를 저장하거나, "Export slice…"를 눌러 화면의 슬라이스를 CSV나 JSON으로 저장합니다. "Copy xarray code"는 같은 슬라이스를 읽는 Python 코드 한 줄을 줍니다.
  7. HDF5 파일은 .h5 파일을 클릭하면 열립니다. MATLAB 7.3 .mat 파일은 마우스 오른쪽 버튼으로 클릭하고 "Open in HDF5 NetCDF Explorer"를 고릅니다.

무료 기능과 Zovo Pro가 더하는 기능

모든 형식, 트리, 속성, 표, 그래프, 해안선이 그려진 지도, 재생, 지점별 시계열, Save PNG, Export slice는 무료입니다. Python이 필요 없고, 이 기능들은 네트워크를 쓰지 않습니다.

Export a subset은 ncks -d나 xarray .sel처럼 동작합니다. 변수를 고르고 차원마다 범위를 인덱스(0:99)나 값(30..60, 2023-08-01..2023-08-31)으로 지정합니다. 결과는 좌표, 속성, history 줄이 들어간 NetCDF 파일이나, 한 지점이 한 행인 깔끔한 CSV로 저장됩니다. 스크립트를 쓰지 않고도 한 지역, 한 기간만 담은 작은 파일을 얻을 수 있습니다.

Export a subset 사용하기 (Zovo Pro)

  1. 파일을 열고 "Export slice…" 옆의 "Export subset…" 버튼을 누릅니다. 또는 Explorer에서 파일을 마우스 오른쪽 버튼으로 클릭하고 "Zovo Pro: Export a Subset of a Variable"을 고릅니다.
  2. Command Palette에서 "NetCDF Viewer Pro: Export Subset of a Variable (NetCDF or CSV)..."를 실행해도 됩니다.
  3. 차원마다 범위를 입력합니다. 입력하는 동안 상자에 선택한 범위가 나옵니다.
  4. NetCDF나 CSV를 고르고 저장할 곳을 정합니다. 진행 상황은 알림에 나오고, Cancel로 멈추면 반쯤 쓴 파일은 남지 않습니다.

Export a subset 기능은 라이선스를 묻기 전에 내 컴퓨터에서 3번 무료로 쓸 수 있습니다. 팝업도 없고 카운트다운도 없습니다.

Cursor, Windsurf, VSCodium에서

  1. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 엽니다.
  2. zovo.hdf5-netcdf-explorer를 검색하고 Install을 누릅니다. Cursor, Windsurf, VSCodium은 Open VSX에서 확장을 설치하며, 이 확장은 그곳에서 zovo/hdf5-netcdf-explorer라는 이름으로 올라가 있습니다.
  3. 에디터에 확장 갤러리가 없으면 Open VSX 페이지에서 .vsix 파일을 내려받고 "Extensions: Install from VSIX..."를 실행합니다.
  4. 그다음은 VS Code에서와 똑같이 동작합니다.

NetCDF Viewer & HDF5 Viewer의 기능

  • NetCDF-4, NetCDF-4 classic, NetCDF-3 classic과 64-bit offset, CDF-5(64비트 데이터).
  • deflate, shuffle, szip, LZF, Blosc, bitshuffle, LZ4, Zstd, bzip2, ZFP 압축을 쓴 HDF5 파일(.h5, .hdf5, .he5, .hdf).
  • MATLAB 7.3 .mat와 .jld2, .loom, .h5ad 같은 HDF5 기반 파일.
  • scale_factor, add_offset, _FillValue, 시간 단위의 CF 디코딩. noleap, 360_day, all_leap 달력도 지원합니다.
  • Remote SSH, WSL, dev container로 연결한 원격 컴퓨터의 파일.

할 수 없는 것

  • Zarr와 HDF4는 지원하지 않습니다. v5 형식으로 저장한 MATLAB .mat 파일은 HDF5가 아니라서 열리지 않습니다. save(filename, '-v7.3')으로 다시 저장하세요.
  • 해안선은 규칙적인 위도-경도 격자에만 그려집니다. 위도와 경도가 2차원인 곡선 격자와 미터 단위의 투영 격자에는 해안선이 없습니다.
  • 512 x 512보다 큰 배열은 그래프를 샘플로 그립니다. 내보내기는 파일 하나에 값을 최대 1,000,000개까지 씁니다(설정 hdf5NetcdfExplorer.maxReadValues).
  • vscode.dev에서 연 GitHub 저장소 같은 가상 파일 시스템은 지원하지 않습니다.
  • SZ나 JPEG 같은 다른 HDF5 필터를 쓴 데이터셋은 값 대신 메시지가 나옵니다.

자주 묻는 질문

무료인가요?

보기 기능은 무료입니다. 모든 형식, 지도, 재생, 시계열, Save PNG, Export slice가 여기에 들어갑니다. 두 Pro 도구 Compare two files와 Export a subset은 각각 3번 무료로 써 볼 수 있습니다. 그다음에는 Zovo Pro가 필요하며, 모든 Zovo 확장에 쓰는 라이선스를 USD 19에 한 번 구매합니다.

Windows용 NetCDF 뷰어가 있나요?

네. 이 확장은 Windows, macOS, Linux 등 VS Code가 돌아가는 곳이면 어디서나 동작하고, Python이 필요 없습니다.

HDF5 파일과 MAT 파일도 열 수 있나요?

HDF5 .h5 파일과 MATLAB 7.3 .mat 파일은 열 수 있습니다. 예전 MATLAB v5 .mat 파일은 HDF5가 아니므로 대신 메시지가 나옵니다.

Cursor에서도 되나요?

네. Open VSX에 zovo/hdf5-netcdf-explorer로 올라가 있어 Cursor, Windsurf, VSCodium에서 설치할 수 있습니다.
