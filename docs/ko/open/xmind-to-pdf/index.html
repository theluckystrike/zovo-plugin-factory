XMind 없이 XMind를 PDF로: 모든 시트를 PDF 하나로

XMind Viewer & Mind Map Viewer(zovo.xmind-mind-map-viewer)를 설치하고 .xmind 파일을 클릭하면, XMind 없이 모든 시트가 탭으로 열립니다. 보기, 검색, PNG, SVG, Markdown 내보내기는 무료입니다. PDF of every sheet는 Zovo Pro 도구로, 시트당 한 페이지에 인쇄용 색을 쓰고 시트마다 북마크를 단 PDF 하나를 저장합니다. 내 컴퓨터에서 3번 무료로 써 볼 수 있고, 그다음에는 모든 Zovo 확장에 쓰는 Zovo Pro 라이선스를 USD 19에 한 번 구매합니다.

VS Code에서 하는 방법

  1. Marketplace에서 XMind Viewer 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.xmind-mind-map-viewer를 실행합니다.
  2. Explorer에서 .xmind 파일을 클릭합니다. XMind 2020 이후 버전, XMind Zen, XMind 8 파일이 열립니다. 맵의 시트마다 위쪽에 탭이 하나씩 생깁니다.
  3. 시트를 차례로 봅니다. 각 시트는 파일에 저장된 레이아웃으로 열립니다. 끌면 이동하고, Ctrl 또는 Cmd를 누른 채 휠을 돌리면 확대, 축소되며, F를 누르면 시트가 화면에 맞춰집니다.
  4. 맵 위 도구 모음의 "Export…" 메뉴를 열고 "PDF, every sheet (Zovo Pro)"를 고릅니다. 맵이 열려 있을 때 Command Palette에서 "XMind Viewer: Export every sheet as PDF (Zovo Pro)"를 실행해도 됩니다.
  5. 저장 대화 상자에서 파일 이름을 정하고 "Export PDF"를 누릅니다. 저장된 페이지 수와 "Show in folder" 버튼이 있는 메시지가 나옵니다. 맵 파일은 바뀌지 않습니다.
  6. 시트 하나를 그림으로 무료로 저장하려면 같은 Export 메뉴에서 "PNG picture"나 "SVG picture"를 고릅니다.

무료 기능과 Zovo Pro가 더하는 기능

.xmind, .mm, .opml 파일 열기는 무료입니다. 모든 시트, 모든 레이아웃, 접기, 단계 보기, 검색, 세부 정보 패널이 들어갑니다. PNG(최대 2x), SVG 내보내기, 시트를 Markdown 개요로 클립보드에 복사하기, 모든 시트를 Markdown 파일 하나로 내보내기도 무료입니다.

PDF of every sheet는 맵의 모든 시트를 시트당 한 페이지, 인쇄용 색, 시트마다 북마크가 있는 PDF 파일 하나로 저장합니다. 시트를 하나씩 그림으로 내보내 손으로 합치지 않고도 한 번에 맵 전체를 얻습니다. XMind 자체에서는 PDF 내보내기에 유료 요금제인 XMind Pro가 필요합니다.

PDF of every sheet 사용하기 (Zovo Pro)

  1. 맵을 연 상태에서 "Export…" 메뉴의 "PDF, every sheet (Zovo Pro)"를 고르거나, 도구 모음의 작은 Zovo Pro 줄에서 "PDF of every sheet"를 누르거나, Command Palette에서 "XMind Viewer: Export every sheet as PDF (Zovo Pro)"를 실행합니다.
  2. Explorer에서 .xmind, .mm, .opml 파일을 마우스 오른쪽 버튼으로 클릭하고 "Zovo Pro: PDF of every sheet"를 골라도 됩니다.
  3. PDF를 저장할 곳을 정하고 "Export PDF"를 누릅니다. 횟수는 파일이 저장됐을 때만 줄어들기 때문에 Cancel로 취소하면 줄지 않습니다.
  4. 무료 3번을 다 쓰면 도구가 Zovo Pro를 얻는 방법을 보여 줍니다.

PDF of every sheet 기능은 라이선스를 묻기 전에 내 컴퓨터에서 3번 무료로 쓸 수 있습니다. 팝업도 없고 카운트다운도 없습니다.

Cursor, Windsurf, VSCodium에서

  1. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 엽니다.
  2. zovo.xmind-mind-map-viewer를 검색하고 Install을 누릅니다. Cursor, Windsurf, VSCodium은 Open VSX에서 확장을 설치하며, 이 확장은 그곳에서 zovo/xmind-mind-map-viewer라는 이름으로 올라가 있습니다.
  3. 에디터에 확장 갤러리가 없으면 Open VSX 페이지에서 .vsix 파일을 내려받고 "Extensions: Install from VSIX..."를 실행합니다.
  4. 그다음은 VS Code에서와 똑같이 동작합니다.

XMind Viewer의 기능

  • XMind 2020~2026과 XMind Zen의 .xmind 파일(content.json), XMind 8, XMind 7, 예전 3.x 버전의 파일(content.xml).
  • 모든 시트를 탭으로 보여 줍니다. 관계선, 경계, 요약, 마커, 라벨, 노트, 파일 안의 그림, KaTeX로 그린 LaTeX 수식도 나옵니다.
  • FreeMind와 Freeplane의 .mm 파일, .opml 개요. 이 파일에서도 PDF of every sheet를 쓸 수 있습니다.
  • 한국어, 중국어, 일본어, 이모지 제목. 긴 제목은 줄바꿈됩니다.
  • 큰 맵. README 테스트에서 주제 10,111개와 그림 60개가 든 30 MB .xmind 파일이 0.65초 만에 열렸습니다.

할 수 없는 것

  • 읽기 전용입니다. 맵을 고치려면 XMind, Freeplane 같은 마인드맵 편집기에서 여세요.
  • 비밀번호가 걸린 맵은 XMind가 내용을 암호화하기 때문에 열 수 없습니다. 그렇다는 메시지가 나옵니다.
  • Fishbone, timeline, matrix, brace 시트는 로직 차트나 조직도로 그려집니다. XMind에서 손으로 옮긴 주제 위치는 유지되지 않고, XMind 테마의 스타일(글꼴, 선 모양, 주제 모양)도 옮겨지지 않습니다. 주제의 채우기 색과 글자 색은 옮겨집니다.
  • PDF의 각 페이지는 시트를 찍은 그림이라서 PDF 안의 글자를 선택하거나 검색할 수 없습니다.
  • 1 GB보다 큰 파일(설정 xmindViewer.maxFileMB)은 열리지 않고 메시지가 나옵니다.

자주 묻는 질문

무료인가요?

맵 보기와 PNG, SVG, Markdown 내보내기는 무료입니다. PDF of every sheet, CSV(Excel)와 OPML 내보내기, Convert a folder는 Zovo Pro 도구입니다. Pro 도구는 각각 내 컴퓨터에서 3번 무료로 써 볼 수 있고, 그다음에는 모든 Zovo 확장에 쓰는 Zovo Pro 라이선스를 USD 19에 한 번 구매합니다.

XMind를 설치해야 하나요?

아니요. 확장이 .xmind 파일을 직접 읽고, 오프라인에서 동작하며 네트워크 요청을 보내지 않습니다.

폴더 안의 맵을 한꺼번에 PDF로 바꿀 수 있나요?

아니요. Convert a folder는 Markdown, CSV, OPML 파일을 씁니다. PDF는 맵 하나씩 만듭니다.

Cursor에서도 되나요?

네. 이 확장은 Open VSX에도 올라가 있어서 Cursor, Windsurf, VSCodium 같은 VS Code 기반 에디터에 설치됩니다.
