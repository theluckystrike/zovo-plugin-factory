VS Code에서 DXF 도면 열기

무료 확장 DXF Viewer를 설치하고 .dxf 파일을 클릭합니다. R12부터 AutoCAD 2018까지의 ASCII와 바이너리 DXF를 블록, 텍스트, 치수, 해치, 페이퍼 공간 시트와 함께 읽고, 레이어를 숨기거나 텍스트를 찾거나 거리를 잴 수 있습니다. DWG 파일은 읽지 않습니다. .dwg를 열면 버전과 DXF 사본을 저장하는 방법이 적힌 짧은 페이지가 나옵니다. 보기는 무료이고, Zovo Pro(USD 19, 한 번 결제)는 Extract drawing data, Compare drawings, Folder inventory 세 도구를 더하며, 도구마다 3번 무료로 써 볼 수 있습니다.

VS Code에서 하는 방법

  1. Marketplace에서 DXF Viewer 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.dxf-viewer를 실행합니다.
  2. Explorer에서 .dxf 파일을 클릭하면 DXF Viewer로 열립니다. 옆 패널에 레이어, 엔티티 종류, 버전, 단위, 크기 같은 도면 정보가 나옵니다.
  3. 끌면 이동하고, 스크롤하면 포인터 위치를 기준으로 확대, 축소됩니다. F를 누르거나 더블클릭하면 도면이 화면에 맞춰집니다. B는 어두운 배경과 흰 배경을 바꿉니다.
  4. 도면에 페이퍼 공간이 있으면 Sheet 목록에서 레이아웃을 고릅니다. 표제란과 뷰포트가 축척대로 놓인, 출력될 때와 같은 모습이 나옵니다.
  5. Layers 패널에서 레이어의 체크를 풀면 그 레이어가 숨겨집니다. Ctrl+F(Mac에서는 Cmd+F)로 텍스트, MTEXT, 블록 속성을 찾고, M을 눌러 두 점 사이를 잽니다.
  6. Export PNG나 Export SVG를 눌러 화면을 저장합니다. CAD 프로그램에서 DXF를 다시 저장하면, 열린 화면이 같은 확대 배율, 시트, 레이어로 다시 불러와집니다.

무료 기능과 Zovo Pro가 더하는 기능

DXF 파일 열기, 시트, 레이어, 텍스트 찾기, 측정, 자동 다시 불러오기, PNG와 SVG 내보내기는 무료입니다. 뷰어는 네트워크를 쓰지 않고 도면을 바꾸지 않습니다.

이 도구는 폴더와 하위 폴더의 모든 .dxf 파일을 읽고 도면마다 CSV 한 행을 저장합니다. 각 행에는 DXF 버전, 단위, 너비와 높이, 레이어, 엔티티, 블록, 텍스트, 그리고 TITLE, DWG_NO, REV, DATE 같은 표제란 항목이 들어갑니다. 도면 폴더를 받았을 때 파일을 하나씩 열지 않고 스프레드시트 하나로 무엇이 들었는지 파악합니다.

Inventory of a Folder of Drawings to CSV 사용하기 (Zovo Pro)

  1. Explorer에서 폴더를 마우스 오른쪽 버튼으로 클릭하고 "Inventory of a Folder of Drawings to CSV (Zovo Pro)"를 고릅니다. 또는 Command Palette에서 "DXF Viewer: Inventory of a Folder of Drawings to CSV (Zovo Pro)"를 실행하고 폴더를 고릅니다.
  2. 진행 상황은 알림에 나오고 취소할 수 있습니다. 그다음 CSV를 저장할 곳을 정합니다. 기본 이름은 -dxf-inventory.csv로 끝납니다.
  3. 횟수는 CSV 파일이 저장됐을 때만 줄어들기 때문에 Cancel이나 Escape로 취소하면 줄지 않습니다. 읽지 못한 파일은 Error 열에 나옵니다.

Inventory of a Folder of Drawings to CSV 기능은 라이선스를 묻기 전에 내 컴퓨터에서 3번 무료로 쓸 수 있습니다. 팝업도 없고 카운트다운도 없습니다.

Cursor, Windsurf, VSCodium에서

  1. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 엽니다.
  2. zovo.dxf-viewer를 검색하고 Install을 누릅니다. Cursor, Windsurf, VSCodium은 Open VSX에서 확장을 설치하며, 이 확장은 그곳에서 zovo/dxf-viewer라는 이름으로 올라가 있습니다.
  3. 에디터에 확장 갤러리가 없으면 Open VSX 페이지에서 .vsix 파일을 내려받고 "Extensions: Install from VSIX..."를 실행합니다.
  4. 그다음은 VS Code에서와 똑같이 동작합니다.

DXF Viewer의 기능

  • R12부터 AutoCAD 2018까지의 ASCII와 바이너리 DXF.
  • 선, 호, 원, 타원, bulge가 있는 폴리선, 스플라인, 패턴 해치, TEXT, MTEXT, 블록 속성, 중첩 블록, 치수.
  • 페이퍼 공간 레이아웃. 뷰포트마다 고유한 축척과 회전을 쓰고, 뷰포트에서 동결한 레이어는 빼고 그립니다.
  • 큰 파일은 워커 스레드에서 읽습니다. 선 600,000개가 든 24 MB 도면이 약 1초 만에 열립니다.

할 수 없는 것

  • DWG 파일은 읽지 않습니다. 먼저 DXF로 저장하세요.
  • 3D 엔티티는 위에서 본 평면으로 그리고, 3DSOLID, REGION, BODY는 그리지 않습니다.
  • 텍스트는 파일의 SHX나 TrueType 글꼴이 아닌 산세리프 글꼴로 보이고, 선 굵기는 쓰지 않습니다.
  • 뷰포트는 사각형으로 그리고, 그라데이션 해치는 단색 채우기로 보입니다.
  • 500 MB가 넘는 파일은 읽지 않습니다(설정 dxfViewer.maxFileMB, 최대 2048).

자주 묻는 질문

무료인가요?

DXF 파일 열기, 시트, 레이어, 텍스트 찾기, 측정, 자동 다시 불러오기, PNG와 SVG 내보내기는 무료입니다. 세 Pro 도구 Extract drawing data, Compare drawings, Folder inventory는 각각 3번 무료로 써 볼 수 있습니다. 그다음에는 Zovo Pro가 필요하며, 모든 Zovo 확장에 쓰는 라이선스를 USD 19에 한 번 구매합니다.

DWG 파일도 열 수 있나요?

아니요. DWG는 비공개 형식입니다. .dwg 파일을 열면 버전과 함께 AutoCAD, BricsCAD, LibreCAD, QCAD, 무료 ODA File Converter에서 DXF 사본을 저장하는 방법이 적힌 짧은 페이지가 나옵니다.

도면을 편집할 수 있나요?

아니요. 뷰어는 읽기 전용입니다. 저장 대화 상자에서 고른 내보내기 파일만 쓰고, 도면 파일을 덮어쓰는 것은 거부합니다.

Cursor에서도 되나요?

네. DXF Viewer는 Open VSX에 올라가 있어 Cursor, Windsurf, VSCodium에서 설치할 수 있습니다.
