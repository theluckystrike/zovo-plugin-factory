VS Code에서 EPUB 책 읽기

무료 확장 EPUB Reader를 설치하고 .epub 파일을 클릭합니다. 책이 VS Code 탭에서 마지막으로 읽던 페이지로 열리고, 페이지 단위나 스크롤로 읽을 수 있습니다. 목차, 책 전체 검색, 각주 팝업, VS Code·라이트·세피아·다크 테마를 쓸 수 있습니다. 읽기는 무료이고 오프라인에서 됩니다. Zovo Pro(USD 19, 한 번 결제)는 Export Book to Markdown or Text와 Check EPUB 두 도구를 더하며, 도구마다 3번 무료로 써 볼 수 있습니다.

VS Code에서 하는 방법

  1. Marketplace에서 EPUB Reader 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.zovo-epub-reader를 실행합니다.
  2. Explorer에서 .epub 파일을 클릭합니다. 책이 탭에서 지난번에 멈춘 페이지로 열립니다. 다른 에디터가 열리면 파일을 마우스 오른쪽 버튼으로 클릭하고 "Open in EPUB Reader"를 고릅니다.
  3. 왼쪽, 오른쪽 화살표 키, Page Up과 Page Down, Space, 마우스 휠, 또는 페이지의 오른쪽이나 왼쪽 가장자리 클릭으로 페이지를 넘깁니다. 에디터가 넓으면 페이지가 두 단으로 보입니다.
  4. 도구 모음 왼쪽 끝의 Contents 버튼을 누르고 장을 고릅니다. EPUB 3 nav 목차와 EPUB 2 NCX 목차를 모두 읽고, 그 안의 부와 절도 보여 줍니다.
  5. "Search in book"에 검색어를 입력하고(Ctrl+F, Mac에서는 Cmd+F로 바로 갈 수 있음) Enter를 누릅니다. 일치하는 곳마다 장과 함께 목록에 나오고 본문에서 강조됩니다. Enter는 다음 결과로, Shift+Enter는 이전 결과로 갑니다.
  6. 각주 번호를 클릭하면 각주가 팝업으로 열립니다. Escape로 닫습니다.
  7. 도구 모음에서 Paged와 Scrolled를 바꾸고, VS Code, Light, Sepia, Dark 테마 중 하나를 고르고, A−와 A+로 글자 크기를 조절합니다. 고른 설정은 모든 책에 그대로 유지됩니다. Info를 누르면 표지, 저자, 언어, ISBN이 보입니다.

무료 기능과 Zovo Pro가 더하는 기능

읽기, 목차, 검색, 각주 팝업, 테마, 글자 크기, 책 정보, 그리고 현재 장을 이미지와 함께 .md 파일로 저장하는 Markdown 버튼은 무료입니다. 확장은 네트워크 요청을 하지 않고, 책 안의 스크립트는 절대 실행되지 않습니다.

Export Book to Markdown or Text는 모든 장을 한 번에 씁니다. Markdown 파일 하나, 장마다 Markdown 파일 하나(01 - Title.md, 02 - ...), 또는 일반 텍스트 파일 하나로 저장합니다. 이미지는 Markdown 옆 폴더에 들어가고, 기존 파일은 절대 덮어쓰지 않습니다. 가지고 있는 책의 텍스트를 메모, 인용, 직접 만든 도구에 쓰려고 장을 하나씩 저장하지 않아도 됩니다.

Export Book to Markdown or Text 사용하기 (Zovo Pro)

  1. 책을 연 상태에서 탭의 ... 메뉴에서 "Export Book to Markdown or Text (Pro)"를 고르거나, Explorer에서 .epub 파일을 마우스 오른쪽 버튼으로 클릭하고 같은 항목을 고릅니다.
  2. Command Palette에서 "EPUB Reader: Export Book to Markdown or Text (Pro)"를 실행해도 됩니다. 열려 있는 책을 쓰고, 없으면 EPUB 파일을 고르라고 합니다.
  3. "Markdown, one file", "Markdown, one file per chapter", "Plain text" 중 하나를 고릅니다. 파일 하나로 저장하면 저장할 곳을 고릅니다. 장마다 파일을 만들면 책 옆에 <book name> (Markdown)이라는 새 폴더가 생기고 그 안에 저장됩니다.
  4. 횟수는 파일이 실제로 써졌을 때만 줄어들고, Cancel이나 Escape로 취소하면 줄지 않습니다.

Export Book to Markdown or Text 기능은 라이선스를 묻기 전에 내 컴퓨터에서 3번 무료로 쓸 수 있습니다. 팝업도 없고 카운트다운도 없습니다.

Cursor, Windsurf, VSCodium에서

  1. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 엽니다.
  2. zovo.zovo-epub-reader를 검색하고 Install을 누릅니다. Cursor, Windsurf, VSCodium은 Open VSX에서 확장을 설치하며, 이 확장은 그곳에서 zovo/zovo-epub-reader라는 이름으로 올라가 있습니다.
  3. 에디터에 확장 갤러리가 없으면 Open VSX 페이지에서 .vsix 파일을 내려받고 "Extensions: Install from VSIX..."를 실행합니다.
  4. 그다음은 VS Code에서와 똑같이 동작합니다.

EPUB Reader의 기능

  • EPUB 2와 EPUB 3 책. EPUB 3 nav 목차나 EPUB 2 NCX 목차를 읽습니다.
  • 각주와 미주를 팝업으로 보여 줍니다. 각주가 별도 노트 파일에 있어도 됩니다.
  • 큰 책. 디스크에서는 여는 부분만 읽으며, 400개 장으로 된 테스트 책이 약 1초 만에 열렸습니다.
  • 표지, 제목, 저자, 언어, ISBN, 출판사, 날짜, EPUB 버전을 담은 책 정보.
  • 인터넷에서 받은 어떤 책이든 열 수 있습니다. 스크립트, 이벤트 핸들러, 폼, 프레임, 인라인 스타일, 원격 이미지는 페이지를 보여 주기 전에 제거합니다.

할 수 없는 것

  • DRM으로 보호된 책은 열 수 없습니다. 깨진 글자 대신 알기 쉬운 메시지가 나옵니다.
  • 책 자체의 스타일 시트와 내장 폰트는 쓰지 않습니다.
  • 만화나 그림책 같은 고정 레이아웃 책은 흐르는 페이지로 보이므로 원래 페이지 디자인이 사라집니다.
  • 오디오, 동영상, 인라인 SVG 그림은 보이지 않습니다. 이미지로 들어간 SVG 표지나 그림은 보입니다.
  • 검색은 장 단위로 하므로 두 장에 걸친 구절은 찾지 못합니다. 200 MB가 넘는 책은 읽지 않습니다(설정 epubReader.maxFileMB).

자주 묻는 질문

Kindle 책이나 DRM 책도 열 수 있나요?

아니요. DRM으로 보호된 책은 깨진 글자 대신 알기 쉬운 메시지가 나옵니다. .epub 파일만 열리므로 AZW, MOBI 같은 Kindle 형식은 읽지 못합니다.

읽던 곳을 기억하나요?

네. 책마다 마지막으로 본 페이지에서 열립니다. 위치는 이 컴퓨터의 VS Code 로컬 저장소에만 남습니다.

무료인가요?

읽기, 검색, 각주, 테마, 책 정보, 장 하나를 Markdown으로 내보내기는 무료입니다. 두 Pro 도구 Export Book to Markdown or Text와 Check EPUB는 각각 3번 무료로 써 볼 수 있습니다. 그다음에는 Zovo Pro가 필요하며, 모든 Zovo 확장에 쓰는 라이선스를 USD 19에 한 번 구매합니다.

Cursor에서도 되나요?

네. EPUB Reader는 Open VSX에 zovo/zovo-epub-reader로 올라가 있어 Cursor, Windsurf, VSCodium에서 설치할 수 있습니다.
