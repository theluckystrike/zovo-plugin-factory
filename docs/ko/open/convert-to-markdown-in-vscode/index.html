VS Code에서 PDF, Word, PowerPoint, Excel 파일을 Markdown으로 변환하는 방법

무료 확장 Convert to Markdown을 설치하고, Explorer에서 PDF, Word, PowerPoint, Excel, CSV, HTML, EPUB, ODT, RTF 파일을 마우스 오른쪽 버튼으로 클릭한 뒤 Convert to Markdown을 고릅니다. 파일 옆에 Markdown이 열리며 제목, 목록, 표, 링크와 슬라이드의 발표자 노트가 들어 있고, 어떤 데이터도 컴퓨터 밖으로 나가지 않습니다. Convert to Markdown과 Copy as Markdown은 모든 형식에서 무료입니다. Zovo Pro(USD 19 한 번)는 Convert a Folder to Markdown, Convert to Markdown with Images, LLM-ready Markdown Chunks의 세 가지 도구를 더하며, 각 도구는 3번 무료로 쓸 수 있습니다.

VS Code에서 하는 방법

  1. Marketplace에서 Convert to Markdown 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.zovo-convert-to-markdown를 실행합니다.
  2. Explorer에서 .pdf, .docx, .pptx, .xlsx, .xls, .ods, .csv, .tsv, .html, .epub, .odt, .rtf 파일을 마우스 오른쪽 버튼으로 클릭하고 Convert to Markdown을 고릅니다. 열려 있는 파일의 탭을 마우스 오른쪽 버튼으로 클릭해도 됩니다.
  3. 또는 Command Palette에서 "Convert to Markdown: Convert to Markdown"을 실행합니다. 활성 탭의 파일을 변환하고, 열린 파일이 없으면 파일을 고르라고 묻습니다.
  4. Markdown은 파일 옆에 저장되지 않은 문서로 열립니다. 큰 파일은 진행 상황과 Cancel 버튼이 표시됩니다.
  5. 문서를 저장합니다. 원본 파일 옆의 name.md라는 이름이 미리 채워져 있습니다. 매번 바로 그 위치에 저장하려면 toMarkdown.output을 file로 설정합니다.
  6. Markdown을 다른 곳에 붙여 넣으려면 파일을 마우스 오른쪽 버튼으로 클릭하고 Copy as Markdown을 고릅니다. Explorer에서 여러 파일을 선택하면 하나씩 차례로 변환합니다.
  7. 변환할 파일이 없다면 Command Palette에서 "Convert to Markdown: Convert a sample file"을 실행해 함께 제공되는 Word, PDF, PowerPoint 샘플을 변환해 봅니다.

무료 기능과 Zovo Pro가 더하는 기능

Convert to Markdown과 Copy as Markdown은 PDF, Word, PowerPoint, Excel, ODS, CSV, TSV, HTML, EPUB, ODT, RTF의 모든 형식에서 무료입니다. Python, 서버, 명령줄 도구 등 다른 것은 설치할 필요가 없습니다. 어떤 데이터도 컴퓨터 밖으로 나가지 않습니다.

Convert a Folder to Markdown은 폴더와 하위 폴더에 있는 지원 파일을 한 번에 모두 .md 파일로 변환합니다. 결과는 같은 구조의 새 폴더에 넣거나 각 파일 옆에 두며, 진행 상황과 Cancel 버튼이 표시됩니다. 이미 있는 .md 파일은 건너뛸지 덮어쓸지 고를 수 있고, _conversion-report.md에는 파일마다 변환, 건너뜀, 실패 여부가 정리됩니다. 이름이 같은 파일은 새 이름에 원래 형식이 남으므로(report.pdf.md, report.docx.md) 어느 것도 사라지지 않습니다.

Convert a Folder to Markdown 사용하기 (Zovo Pro)

  1. Explorer에서 폴더를 마우스 오른쪽 버튼으로 클릭하고 "Zovo Pro: Convert a Folder to Markdown"을 고르거나, Command Palette에서 "Convert to Markdown: Convert a Folder to Markdown (Pro)"를 실행하고 폴더를 고릅니다.
  2. .md 파일을 둘 위치를 "Into a new folder"(폴더 이름 뒤에 -markdown을 붙인 새 폴더, 하위 폴더 구조는 같음), "Next to each file", "Pick another folder..." 중에서 고릅니다.
  3. .md 파일이 이미 있으면 Skip 또는 Overwrite를 고릅니다. 알림에 진행 상황과 Cancel 버튼이 표시됩니다.
  4. 끝나면 _conversion-report.md가 열립니다. 파일마다 변환, 건너뜀, 실패 여부와 새 Markdown 파일의 링크가 나옵니다.

Convert a Folder to Markdown 기능은 라이선스를 묻기 전에 내 컴퓨터에서 3번 무료로 쓸 수 있습니다. 팝업도 없고 카운트다운도 없습니다.

  1. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 엽니다.
  2. zovo.zovo-convert-to-markdown를 검색하고 Install을 누릅니다. Cursor, Windsurf, VSCodium은 Open VSX에서 확장을 설치하며, 이 확장은 그곳에서 zovo/zovo-convert-to-markdown라는 이름으로 올라가 있습니다.

Convert to Markdown의 기능

  • PDF는 글꼴 크기로 제목을 찾고, 끊어진 줄과 하이픈으로 나뉜 단어를 이어 문단으로 만들며, 목록, 간단한 표, 두 단 페이지(단 순서대로 읽음)를 처리합니다. 반복되는 머리글, 바닥글, 페이지 번호는 뺍니다.
  • Word(.docx, .docm, .dotx)는 제목, 굵게, 기울임꼴, 취소선, 링크, 중첩 목록, 표, 인용 블록, 각주를 변환합니다.
  • PowerPoint(.pptx, .pptm, .ppsx, .potx)는 슬라이드마다 ## Slide n: title 섹션을 만들고 글머리 기호와 수준, 표, 발표자 노트를 넣습니다.
  • Excel 등 스프레드시트(.xlsx, .xlsm, .xlsb, .xls, .ods)는 시트마다 ## Sheet: name 섹션과 파이프 표를 만듭니다. CSV와 TSV는 표 하나가 됩니다.
  • HTML(.html, .htm, .xhtml)은 코드 블록의 언어를 유지하고 스크립트와 스타일을 뺍니다. EPUB은 각 장을 읽는 순서대로 변환합니다.

할 수 없는 것

  • 스캔한 PDF(페이지 이미지)에는 변환할 텍스트가 없습니다. 문자 인식(OCR)은 포함되어 있지 않습니다.
  • PDF의 표는 열 사이의 빈 공간으로 찾습니다. 빈 공간이 뚜렷하지 않은 표는 문단으로 나옵니다.
  • 무료 변환에서 이미지는 *[Image: Map of the site]* 같은 자리 표시자가 됩니다. 슬라이드의 차트, SmartArt, 동영상은 이름만 적고 변환하지 않습니다.
  • 오래된 Word 97-2003 파일과 RTF는 서식 없이 텍스트와 표만 나옵니다. 암호로 보호된 파일과 오래된 PowerPoint 97-2003 파일은 변환 대신 안내 메시지가 나옵니다.
  • 200 MB가 넘는 파일은 변환하지 않으며(설정 toMarkdown.maxFileSizeMB), PDF는 1,000페이지에서 변환을 멈춥니다(설정 toMarkdown.pdfMaxPages).

자주 묻는 질문

무료인가요?

Convert to Markdown과 Copy as Markdown은 모든 형식에서 무료입니다. 세 가지 Pro 도구 Convert a Folder to Markdown, Convert to Markdown with Images, LLM-ready Markdown Chunks는 각각 3번 무료로 쓸 수 있습니다. 그 뒤에는 Zovo Pro가 필요하며, USD 19 한 번으로 모든 Zovo 확장에 적용됩니다.

파일이 업로드되나요?

아니요. 변환기는 VS Code 안에서 내 컴퓨터로 실행되며, 네트워크 호출도 원격 측정도 없습니다.

스캔한 PDF도 변환하나요?

아니요. 스캔한 PDF에는 텍스트가 아니라 페이지 이미지가 들어 있고, Convert to Markdown에는 OCR이 없습니다.

Cursor에서도 되나요?

네. Cursor, Windsurf, VSCodium은 Open VSX에서 설치하며, 그곳에는 zovo/zovo-convert-to-markdown으로 게시되어 있습니다.
