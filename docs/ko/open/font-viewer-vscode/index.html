VS Code에서 폰트 파일 미리보기

무료 확장 Font Viewer를 설치하고 .ttf, .otf, .woff, .woff2, .ttc 파일을 클릭합니다. 직접 입력한 문장을 그 폰트로 보여 주고, 크기별 미리보기(waterfall), 검색할 수 있는 글리프 표, 라이선스와 임베딩 권한을 보여 줍니다. 시스템에 폰트를 설치하지 않아도 됩니다. Type tester, 글리프 표, 문자표, Info 탭, Copy CSS @font-face는 무료입니다. Zovo Pro(USD 19, 한 번 결제)는 Convert Font와 Font Folder Report 두 도구를 더하며, 도구마다 3번 무료로 써 볼 수 있습니다.

VS Code에서 하는 방법

  1. Marketplace에서 Font Viewer 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.font-viewer-vscode를 실행합니다.
  2. Explorer에서 .ttf, .otf, .woff, .woff2, .ttc, .otc 파일을 클릭합니다. 이 파일들의 기본 에디터는 Font Viewer이고, 폰트를 바꾸지 않습니다.
  3. Type tester 탭에서 원하는 문장을 입력하고, 크기 슬라이더를 8에서 200 px까지 움직이고, 12에서 96 px까지의 waterfall을 봅니다. 가변 폰트는 축 슬라이더를 움직이고, liga나 ss01 같은 OpenType 기능을 켜고 끕니다.
  4. Glyphs 탭에서 이름, 글자, U+20AC, 글리프 id로 검색합니다. 글리프를 클릭하면 기준선, x-height, cap height와 함께 크게 보이고, 글자, 코드 포인트, SVG 윤곽선을 복사할 수 있습니다.
  5. Characters 탭에서 "Basic Latin 95/128"처럼 유니코드 블록마다 지원 범위를 봅니다. "Only characters in the font"를 끄면 빠진 글자도 보입니다.
  6. Info 탭에서 라이선스, 디자이너, 저작권, 임베딩 권한을 읽고, 바로 쓸 수 있는 @font-face 규칙을 복사합니다.

무료 기능과 Zovo Pro가 더하는 기능

지원하는 모든 폰트 열기, Type tester, 글리프 표, 문자표, Info 탭, Copy CSS @font-face는 무료입니다. Font Viewer는 오프라인에서 동작하고, 네트워크를 쓰지 않으며 텔레메트리도 없습니다.

Font Folder Report는 폴더 안 모든 폰트를 패밀리, 스타일, 굵기, 축, 버전, 글리프 수, 라이선스, 라이선스 URL, 임베딩 권한과 함께 나열합니다. 목록은 CSV 파일, Markdown 표, 또는 폰트마다 @font-face 규칙이 하나씩 든 fonts.css 하나(WOFF2 우선)로 씁니다. 폰트 폴더를 앱이나 웹사이트에 넣기 전에, 폰트를 하나씩 열지 않고 파일 하나로 각 폰트를 어디에 쓸 수 있는지 확인합니다.

Font Folder Report 사용하기 (Zovo Pro)

  1. Explorer에서 폰트 폴더를 마우스 오른쪽 버튼으로 클릭하고 "Font Folder Report: CSV, Markdown or @font-face CSS… (Pro)"를 고르거나, Command Palette에서 "Font Viewer: Font Folder Report: CSV, Markdown or @font-face CSS… (Pro)"를 실행하고 폴더를 고릅니다.
  2. 형식을 고릅니다. CSV, Markdown 표, CSS @font-face 규칙 중 하나입니다.
  3. 파일을 저장합니다. 기본 이름은 fonts-report.csv, fonts-report.md, fonts.css이고, 횟수는 파일이 실제로 써졌을 때만 줄어듭니다.

Font Folder Report 기능은 라이선스를 묻기 전에 내 컴퓨터에서 3번 무료로 쓸 수 있습니다. 팝업도 없고 카운트다운도 없습니다.

Cursor, Windsurf, VSCodium에서

  1. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 엽니다.
  2. zovo.font-viewer-vscode를 검색하고 Install을 누릅니다. Cursor, Windsurf, VSCodium은 Open VSX에서 확장을 설치하며, 이 확장은 그곳에서 zovo/font-viewer-vscode라는 이름으로 올라가 있습니다.
  3. 에디터에 확장 갤러리가 없으면 Open VSX 페이지에서 .vsix 파일을 내려받고 "Extensions: Install from VSIX..."를 실행합니다.
  4. 그다음은 VS Code에서와 똑같이 동작합니다.

Font Viewer의 기능

  • TrueType .ttf와 OpenType .otf 폰트. 가변 폰트도 됩니다.
  • .woff와 .woff2 웹 폰트. WOFF2는 확장에 들어 있는 디코더로 풉니다.
  • .ttc, .otc 컬렉션. 머리글의 목록에서 폰트를 고릅니다.
  • 글리프가 20,000개인 큰 CJK 폰트. 스크롤하는 대로 페이지 단위로 불러옵니다.
  • Explorer에서 폰트를 마우스 오른쪽 버튼으로 클릭하고 Copy CSS @font-face를 고르면 열지 않고도 규칙을 복사합니다.

할 수 없는 것

  • WOFF2 컬렉션, SVG 폰트, .dfont, Type 1 폰트는 지원하지 않습니다.
  • 글리프 윤곽선은 가변 폰트의 기본 인스턴스로 보입니다. Type tester, waterfall, 문자표는 축 슬라이더를 따라갑니다.
  • 컬러 폰트는 Type tester와 문자표에서 컬러로 그려지지만, 글리프 표에는 단색 윤곽선으로 나옵니다.
  • 64 MB가 넘는 파일은 열리지 않고 메시지가 나옵니다(설정 fontViewer.maxFileMB).
  • 읽기 전용입니다. 폰트를 편집하거나 시스템에 설치하지 않습니다.

자주 묻는 질문

무료인가요?

폰트 보기, Type tester, 글리프 표, 문자표, Info 탭, Copy CSS @font-face는 무료입니다. 두 Pro 도구 Convert Font와 Font Folder Report는 각각 3번 무료로 써 볼 수 있습니다. 그다음에는 Zovo Pro가 필요하며, 모든 Zovo 확장에 쓰는 라이선스를 USD 19에 한 번 구매합니다.

폰트를 설치해야 하나요?

아니요. 폰트는 파일에서 읽어 Font Viewer 탭 안에서만 보여 줍니다. 시스템 폰트 목록은 바뀌지 않습니다.

빌드 폴더의 WOFF2도 열 수 있나요?

네. WOFF2는 확장에 들어 있는 디코더로 풀고, 폰트를 새로 빌드해 저장하면 열린 화면이 다시 불러옵니다.

Cursor에서도 되나요?

네. Font Viewer는 Open VSX에 zovo/font-viewer-vscode로 올라가 있어 Cursor, Windsurf, VSCodium에서 설치할 수 있습니다.
