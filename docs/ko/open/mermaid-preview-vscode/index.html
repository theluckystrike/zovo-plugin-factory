VS Code에서 Mermaid 다이어그램 미리보기

VS Code에는 자체 Mermaid 미리보기가 없습니다. 무료 Mermaid Viewer를 설치하고 .mmd나 .mermaid 파일을 연 뒤 에디터 오른쪽 위의 미리보기 아이콘을 누르면, 입력하는 대로 다이어그램이 바뀝니다. Markdown 파일에서는 미리보기에 모든 mermaid 블록이 나옵니다. Mermaid 12.3.0이 확장 안에 들어 있어서 미리보기와 PNG, SVG 내보내기는 무료이고, 로그인 없이 오프라인에서 동작합니다. Zovo Pro(USD 19, 한 번 결제)는 PDF 내보내기, 워크스페이스의 모든 다이어그램 내보내기, 저장할 때 내보내기를 더하며, 도구마다 3번 무료로 써 볼 수 있습니다.

VS Code에서 하는 방법

  1. Marketplace에서 Mermaid Viewer 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.mermaid-viewer를 실행합니다.
  2. .mmd나 .mermaid 파일을 열고 에디터 제목 줄의 미리보기 아이콘을 누르거나 Ctrl+K V(macOS에서는 Cmd+K V)를 누릅니다. Command Palette에서 "Mermaid Viewer: Open Diagram Editor (Text + Live Preview)"를 실행해도 됩니다.
  3. ```mermaid 블록이 있는 Markdown 파일에서는 같은 미리보기 아이콘을 누릅니다. 미리보기에 모든 다이어그램이 나오고, 다이어그램마다 오류 줄과 내보내기 버튼이 따로 있습니다.
  4. Markdown 파일에서 블록 위의 "Edit diagram"을 누르면 실시간 미리보기 옆에서 그 블록을 고칠 수 있습니다. 저장하면 텍스트가 원래 블록으로 돌아갑니다.
  5. 스크롤하면 포인터 위치를 기준으로 확대, 축소되고, 끌면 화면이 이동합니다. 도구 모음에 Fit과 100%가 있습니다.
  6. Export를 누르고 Save PNG(1x, 2x, 4x 또는 정확한 너비나 높이), Save SVG, Copy PNG, Copy SVG code 중에서 고릅니다.

무료 기능과 Zovo Pro가 더하는 기능

실시간 미리보기, 다이어그램 에디터, Markdown 블록의 Edit diagram, 자동 완성, 오류 밑줄, 템플릿 15개, Mermaid Diagrams 개요, PNG와 SVG 내보내기와 복사는 무료입니다. 계정, 로그인, AI가 없습니다.

Export All Diagrams in Workspace는 폴더 안 모든 .mmd, .mermaid, Markdown 파일의 다이어그램을 SVG, PNG 또는 둘 다로 mermaid-export/에 씁니다. 폴더 구조는 원본과 같게 만듭니다. 그릴 수 없는 다이어그램은 마지막에 목록으로 나옵니다. 문서가 바뀔 때마다 다이어그램을 하나씩 열어 손으로 내보내지 않아도 됩니다.

Export All Diagrams in Workspace 사용하기 (Zovo Pro)

  1. VS Code에서 폴더를 엽니다. Command Palette에서 "Mermaid Viewer: Export All Diagrams in Workspace (SVG/PNG) (Pro)"를 실행하거나, 미리보기 도구 모음 아래 "Pro tools" 줄에서 "Export All Diagrams in Workspace"를 누릅니다.
  2. SVG, PNG, 또는 SVG and PNG를 고릅니다.
  3. 기본 폴더 mermaid-export(설정 mermaidViewer.exportFolder)를 그대로 쓰거나 "Choose a folder…"를 고릅니다. 횟수는 파일이 실제로 써졌을 때만 줄어들고, Escape로 취소하면 줄지 않습니다.

Export All Diagrams in Workspace 기능은 라이선스를 묻기 전에 내 컴퓨터에서 3번 무료로 쓸 수 있습니다. 팝업도 없고 카운트다운도 없습니다.

Cursor, Windsurf, VSCodium에서

  1. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 엽니다.
  2. zovo.mermaid-viewer를 검색하고 Install을 누릅니다. Cursor, Windsurf, VSCodium은 Open VSX에서 확장을 설치하며, 이 확장은 그곳에서 zovo/mermaid-viewer라는 이름으로 올라가 있습니다.
  3. 에디터에 확장 갤러리가 없으면 Open VSX 페이지에서 .vsix 파일을 내려받고 "Extensions: Install from VSIX..."를 실행합니다.
  4. 그다음은 VS Code에서와 똑같이 동작합니다.

Mermaid Viewer의 기능

  • Flowchart, sequence, class, state, ER, Gantt, pie, gitGraph, mindmap, timeline, sankey, XY chart, block, C4, architecture 등 Mermaid 12.3.0이 아는 모든 종류.
  • 오류는 해당 줄에 밑줄로 표시되고 Problems 패널에도 나옵니다. 마지막으로 제대로 그려진 다이어그램이 화면에 남고, Markdown 파일에서 블록 하나가 깨져도 다른 블록은 그대로 보입니다.
  • 포인터 위치 기준 1 %에서 3,200 %까지 확대. 트랙패드로 이동과 핀치 확대도 됩니다.
  • Azure DevOps와 GitHub 위키용으로 라벨을 일반 텍스트로 쓰는 SVG 내보내기.
  • 배경은 에디터 색, 흰색, 투명, 직접 고른 색 중에서 정할 수 있고, 내보낼 때도 같은 배경이 쓰입니다.

할 수 없는 것

  • VS Code 자체 Markdown 미리보기에 다이어그램을 넣지는 않습니다. 별도의 미리보기 패널을 엽니다.
  • KaTeX 글꼴이 들어 있지 않아서 라벨 안의 수식($$...$$)이 제대로 보이지 않을 수 있습니다.
  • Mermaid가 인터넷에서 불러오는 아이콘 팩은 불러오지 않습니다. 내장 아이콘은 됩니다.
  • 500,000자 또는 링크 2,000개가 넘는 다이어그램은 한도를 올리기 전까지 그리지 않습니다(설정 mermaidViewer.maxTextSize, mermaidViewer.maxEdges).
  • 그리는 데 10초가 넘게 걸리면 중단합니다(설정 mermaidViewer.renderTimeoutSeconds).

자주 묻는 질문

무료인가요?

미리보기, 에디터, Markdown 블록 편집, PNG와 SVG 내보내기는 무료입니다. Pro 도구(PDF 내보내기, Export All Diagrams in Workspace, Export on Save)는 각각 3번 무료로 써 볼 수 있습니다. 그다음에는 Zovo Pro가 필요하며, 모든 Zovo 확장에 쓰는 라이선스를 USD 19에 한 번 구매합니다.

VS Code Markdown 미리보기에 mermaid 블록이 왜 안 그려지나요?

VS Code에 내장된 Markdown 미리보기는 Mermaid를 그리지 않습니다. Mermaid Viewer는 Markdown 파일용 미리보기 패널을 따로 열고, 다이어그램마다 확대와 내보내기 기능을 줍니다.

계정이나 인터넷 연결이 필요한가요?

아니요. Mermaid 12.3.0이 확장에 들어 있고, 로그인과 AI가 없으며, 미리보기는 모든 네트워크 요청을 막습니다.

Cursor에서도 되나요?

네. Open VSX에 zovo/mermaid-viewer로 올라가 있어 Cursor, Windsurf, VSCodium에서 설치할 수 있습니다.
