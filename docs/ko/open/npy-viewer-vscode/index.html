VS Code에서 NumPy .npy, .npz 파일 보기

무료 확장 Tensor Viewer(NPZ Viewer & NPY Viewer)를 설치하고 .npy 또는 .npz 파일을 클릭합니다. 배열마다 이름, dtype, shape가 목록으로 나오고, 배열을 클릭하면 Python 없이 min, max, 평균, 표준편차, NaN 개수, 차트, 히스토그램, 값을 볼 수 있습니다. 보기, 이미지, Values 표, .npy나 CSV로 저장하기는 무료입니다. Zovo Pro(USD 19, 한 번 결제)는 Compare two checkpoints와 Scan all tensors 두 도구를 더하며, 도구마다 3번 무료로 써 볼 수 있습니다.

VS Code에서 하는 방법

  1. Marketplace에서 Tensor Viewer 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.tensor-viewer를 실행합니다.
  2. Explorer에서 .npy 또는 .npz 파일을 클릭합니다. 표에 모든 배열이 이름, 타입, shape, 파라미터 수, 크기와 함께 나옵니다.
  3. 배열을 클릭합니다. 오른쪽 패널에 min, max, 평균, 표준편차와 NaN, Inf, 0의 개수가 나옵니다. 그 아래에 2차원 배열은 히트맵, 1차원 배열은 선 그래프가 나오고, 히스토그램도 나옵니다.
  4. Values 표에서 숫자를 32행씩 읽습니다. 3차원 이상인 배열은 Slice 칸에 [5, :, :] 같은 슬라이스를 입력합니다.
  5. 배열이 (H, W, 3)이나 (N, 3, H, W)처럼 이미지 모양이면 Image 섹션에 그림으로 그려집니다. 여기서 Layout, Frame, Range를 고릅니다. 실수(float) 행렬에는 대신 "Show as image" 버튼이 나옵니다.
  6. "Save as .npy..." 또는 "Save as CSV..."를 눌러 배열이나 슬라이스를 새 파일로 저장합니다.

무료 기능과 Zovo Pro가 더하는 기능

모든 형식, 통계, 히트맵, 선 그래프, 히스토그램, 이미지, Values 표, 슬라이스, raw 배열, .npy나 CSV로 저장하기는 무료입니다. Python이 필요 없고, 뷰어는 네트워크를 쓰지 않습니다.

Scan all tensors는 샘플이 아니라 파일 안 모든 배열의 모든 값을 읽습니다. NaN, Inf, 전부 0이거나 값이 일정한 배열, 10,000 이상인 실수 값을 찾아 표시합니다. 배열마다 정확한 min, max, 평균, 표준편차, L2 norm을 보고서 하나로 보여 주며, 보고서는 필터할 수 있고 CSV, Markdown, JSON으로 저장할 수 있습니다. 큰 .npz에서 배열을 하나씩 클릭하지 않아도 문제가 있는 배열을 찾을 수 있습니다.

Cursor, Windsurf, VSCodium에서

  1. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 엽니다.
  2. zovo.tensor-viewer를 검색하고 Install을 누릅니다. Cursor, Windsurf, VSCodium은 Open VSX에서 확장을 설치하며, 이 확장은 그곳에서 zovo/tensor-viewer라는 이름으로 올라가 있습니다.
  3. 에디터에 확장 갤러리가 없으면 Open VSX 페이지에서 .vsix 파일을 내려받고 "Extensions: Install from VSIX..."를 실행합니다.
  4. 그다음은 VS Code에서와 똑같이 동작합니다.

Tensor Viewer의 기능

  • 헤더 v1, v2, v3의 .npy 파일. C 순서와 Fortran 순서, 두 가지 바이트 순서를 모두 읽습니다.
  • 항목이 stored 또는 deflate로 저장된 .npz 아카이브(zip64 포함).
  • bool, int8~int64, uint8~uint64, float16, float32, float64, 복소수(통계는 크기 기준).
  • 이미지 모양의 배열, 스택, 배치를 한 프레임씩 그림으로 그립니다.
  • 같은 확장으로 .safetensors, .gguf, PyTorch .pt, .pth, .ckpt 파일도 열 수 있습니다.

할 수 없는 것

  • pickle로 저장된 객체 배열은 목록에만 나오고 열리지 않으며, 실행되지도 않습니다. 텍스트 배열과 구조화 배열은 통계 없이 목록에만 나옵니다.
  • 값이 2,000,000개를 넘는 배열은 통계와 그래프를 샘플로 계산합니다(설정 tensorViewer.sampleValues). 통계가 샘플에서 나온 것이면 패널에 그렇게 표시됩니다.
  • 압축된 .npz 항목은 앞부분부터만 읽습니다. 처음 64 MB 뒤의 값은 보이지 않고, 512 MB가 넘는 항목은 저장할 수 없습니다.
  • 이미지는 긴 변 기준 최대 512픽셀로 그립니다. 2채널 배열과 Fortran 순서 배열에는 이미지 보기가 없습니다.
  • CSV 내보내기는 값 2천만 개에서 멈춥니다. 2^53보다 큰 int64 값은 표와 CSV에서 마지막 자릿수가 정확하지 않습니다.

자주 묻는 질문

무료인가요?

.npy, .npz 파일 열기, 통계, 그래프, 이미지, Values 표, .npy나 CSV로 저장하기는 무료입니다. 두 Pro 도구 Compare two checkpoints와 Scan all tensors는 각각 3번 무료로 써 볼 수 있습니다. 그다음에는 Zovo Pro가 필요하며, 모든 Zovo 확장에 쓰는 라이선스를 USD 19에 한 번 구매합니다.

Python이 필요한가요?

아니요. Tensor Viewer가 파일을 직접 읽으므로 Python과 NumPy를 설치하지 않아도 됩니다.

인터넷에서 받은 .npy 파일을 열어도 안전한가요?

파일 안의 어떤 것도 실행되지 않습니다. NumPy가 pickle로 저장하는 객체 배열은 목록에만 나오고 열리지 않으며, 뷰어는 보여 주는 파일을 바꾸지 않습니다.

Cursor에서도 되나요?

네. Tensor Viewer는 Open VSX에 zovo/tensor-viewer로 올라가 있어 Cursor, Windsurf, VSCodium에서 설치할 수 있습니다.
