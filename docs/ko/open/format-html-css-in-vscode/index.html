VS Code에서 하는 방법

  1. Marketplace에서 HTML Formatter & CSS Formatter 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.zovo-html-formatter를 실행합니다.
  2. HTML, CSS, SCSS, LESS 파일을 열고 Shift+Alt+F(macOS에서는 Shift+Option+F)를 누릅니다. 어떤 포매터를 쓸지 VS Code가 물으면 HTML Formatter & CSS Formatter를 고릅니다.
  3. 네 가지 언어 모두의 기본 포매터로 한 번에 지정하려면 Command Palette에서 "HTML Formatter: Use as Default Formatter for HTML, CSS, SCSS and LESS"를 실행합니다.
  4. 몇 줄을 선택하고 Format Selection을 실행하면 선택한 줄만 포맷합니다.
  5. 저장할 때마다 포맷하려면 zovoHtmlFormat.formatOnSave를 켜거나, 이 확장이 기본 포매터가 된 뒤 VS Code 자체의 editor.formatOnSave를 사용합니다.
  6. 들여쓰기는 먼저 편집기 설정에서, 그다음 .editorconfig(들여쓰기 스타일과 크기, 줄 끝, 마지막 줄바꿈, 최대 줄 길이)에서 가져오므로 팀 전체가 같은 결과를 얻습니다.

무료 기능과 Zovo Pro가 더하는 기능

HTML, CSS, SCSS, LESS의 Format Document, Format Selection, 저장 시 포맷과 .editorconfig 지원은 무료입니다. 로그인, 네트워크 요청, 원격 측정이 없습니다.

사이트 전체를 하나의 스타일로 맞춰야 할 때 Format Folder with Diff Preview는 폴더의 모든 HTML, CSS, SCSS, LESS 파일을 메모리에서 포맷하고, 바뀐 파일마다 나란히 보는 diff를 보여 주며, 체크를 남겨 둔 파일만 저장합니다. 파일이 저장되기 전에 모든 변경 내용을 볼 수 있습니다.

Cursor, Windsurf, VSCodium에서

  1. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 엽니다.
  2. zovo.zovo-html-formatter를 검색하고 Install을 누릅니다. Cursor, Windsurf, VSCodium은 Open VSX에서 확장을 설치하며, 이 확장은 그곳에서 zovo/zovo-html-formatter라는 이름으로 올라가 있습니다.

  4. 그다음은 VS Code에서와 똑같이 동작합니다.

HTML Formatter & CSS Formatter의 기능

  • HTML 안의 <style> CSS와 <script> JavaScript.
  • 작성한 그대로 유지되는 것: <pre>와 <textarea>의 내용, 같은 줄에 있는 인라인 태그, 속성 순서, 블록 사이의 빈 줄(연속으로는 최대 한 줄), 페이지의 head와 body 들여쓰기 스타일, {{ }}와 {% %} 같은 템플릿 태그.
  • SCSS와 LESS에서 여러 줄로 쓴 map과 함수 호출은 레이아웃을 유지하고, 줄 끝 주석은 그 줄에 남습니다.
  • 나머지 Pro 도구 두 가지도 있습니다. Minify HTML and CSS는 .min.html과 .min.css 사본을 만들고 줄어든 바이트와 gzip 바이트를 보고합니다. HTML Lint Report는 alt 텍스트가 없는 이미지, label이 없는 폼 필드, 중복 id, 건너뛴 제목 단계 같은 문제를 찾아 Markdown 보고서와 Problems 패널에 보여 줍니다.

할 수 없는 것

  • 단독 .js, .jsx, .ts, Vue, Svelte 파일은 이 확장이 포맷하지 않습니다. <script> 안의 JavaScript만 포맷합니다.
  • 줄 바꿈 길이를 설정하지 않으면 줄을 나누지 않으므로 아주 긴 줄은 그대로 깁니다.
  • SCSS와 LESS는 CSS 포매터로 처리합니다. LESS detached ruleset 같은 특이한 문법은 원래 간격이 남을 수 있습니다.
  • Minify는 JavaScript를 줄이지 않으며, CSS 규칙의 이름을 바꾸거나 합치지 않습니다.

자주 묻는 질문

무료인가요?

HTML, CSS, SCSS, LESS의 Format Document, Format Selection, 저장 시 포맷은 무료입니다. 세 가지 Pro 도구 Format Folder with Diff Preview, Minify HTML and CSS, HTML Lint Report는 각각 3번 무료로 쓸 수 있습니다. 그 뒤에는 모든 Zovo 확장에 적용되는 Zovo Pro(USD 19 한 번)가 필요합니다.

확장 없이도 VS Code에서 HTML을 포맷할 수 있나요?

예. VS Code에는 HTML과 CSS 포매터가 기본으로 들어 있습니다. 이 확장은 .editorconfig를 읽고, 페이지 고유의 head와 body 들여쓰기를 유지하고, SCSS와 LESS map의 레이아웃을 유지하며, 폴더, minify, lint용 Pro 도구를 더합니다.

pre 블록을 바꾸거나 속성 순서를 바꾸나요?

아니요. pre와 textarea의 내용, 인라인 태그, 속성 순서는 작성한 그대로 유지됩니다.

Node나 npm이 필요한가요?

아니요. js-beautify 1.15.4가 확장에 들어 있어 오프라인으로 실행됩니다.
