VS Code에서 입력하면서 PlantUML 다이어그램 미리보기

무료 확장 PlantUML Viewer & Preview를 설치하고 .puml 파일이나 plantuml 블록이 있는 Markdown 파일을 연 다음 미리보기 버튼을 클릭합니다. 다이어그램은 입력하는 동안 코드 옆에 그려집니다. 확장에 들어 있는 PlantUML jar와 내 컴퓨터의 Java 11 이상이 그리므로 서버로 보내는 것이 없고 Graphviz도 필요 없습니다. 미리보기, 확대/축소, 오류 링크, 다이어그램 하나를 SVG나 PNG로 저장하는 기능은 무료입니다. Zovo Pro(USD 19 한 번)는 Export All Diagrams in a Folder, Markdown Diagrams to Images, Compare with a Git Version의 세 가지 도구를 더하며, 각 도구는 3번 무료로 쓸 수 있습니다.

VS Code에서 하는 방법

  1. Marketplace에서 PlantUML Viewer & Preview 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.zovo-plantuml-viewer를 실행합니다.
  2. Java 11 이상이 설치되어 있는지 확인합니다. 확장은 plantumlViewer.javaPath 설정, JAVA_HOME, PATH의 java, 일반적인 JDK 폴더 순서로 찾습니다. 찾지 못하면 미리보기에 그 사실이 표시되고 "Set the Java path" 버튼이 나옵니다. "PlantUML: Show Java and Layout Status"를 실행하면 무엇을 찾았는지 볼 수 있습니다.
  3. .puml, .plantuml, .iuml, .pu, .wsd 파일이나 ```plantuml 블록이 있는 Markdown 파일을 열고 편집기 오른쪽 위의 미리보기 버튼을 클릭합니다. PlantUML 파일에서 Alt+D를 누르거나 "PlantUML: Open Preview to the Side"를 실행해도 됩니다.
  4. 입력합니다. 입력을 멈추고 잠시 뒤 미리보기가 다시 그려집니다(기본 400 ms, plantumlViewer.renderDelay 설정). 파일의 모든 다이어그램이 미리보기 하나에 표시되고, 커서가 있는 다이어그램에는 테두리가 표시됩니다.
  5. 버튼, Ctrl 또는 Cmd를 누른 채 마우스 휠, + 키와 - 키로 확대/축소합니다. Fit을 클릭하면 패널 너비에 맞춰지고, 다이어그램을 끌어서 이동할 수 있습니다. 오류가 있는 다이어그램에는 PlantUML 메시지와 "Go to line" 링크가 표시됩니다.
  6. 다이어그램 위의 SVG 또는 PNG를 클릭하면 그 다이어그램 하나가 저장되고, Copy SVG를 클릭하면 복사됩니다.

무료 기능과 Zovo Pro가 더하는 기능

.puml, .plantuml, .iuml, .pu, .wsd 파일과 Markdown의 plantuml 블록 실시간 미리보기, 확대/축소와 이동, 줄 링크가 있는 오류 표시, 다이어그램 하나를 SVG 또는 PNG로 저장, Copy SVG, 구문 색상, 스니펫(seq, classd, activity, mindmap, gantt 등), 접기와 주석은 무료입니다. 다이어그램은 내 컴퓨터에서 그려지며 서버로 보내지지 않습니다.

프로젝트의 다이어그램을 문서나 슬라이드에 넣어야 할 때 Export All Diagrams in a Folder는 폴더와 하위 폴더에 있는 모든 PlantUML 파일의 모든 다이어그램을 한 번에 SVG, PNG 또는 PDF로 씁니다. 결과는 각 파일 옆에 두거나 한 폴더에 모을 수 있습니다. 오류가 있는 다이어그램은 건너뛰고 파일, 줄, 메시지와 함께 목록으로 보여 주며, 나머지는 그대로 씁니다. 파일을 하나씩 열어 다이어그램을 직접 저장할 필요가 없습니다.

Export All Diagrams in a Folder 사용하기 (Zovo Pro)

  1. Explorer에서 폴더를 마우스 오른쪽 버튼으로 클릭하고 "Zovo Pro: Export all diagrams in a folder"를 고르거나, 미리보기 도구 모음의 Pro tools 줄에서 "Export all diagrams in a folder"를 클릭하거나, Command Palette에서 "PlantUML: Export All Diagrams in a Folder (Pro)"를 실행하고 폴더를 고릅니다.
  2. SVG, PNG, PDF 중 하나를 고른 다음 "Next to each PlantUML file" 또는 "All in one folder..."를 고릅니다.
  3. 끝나면 메시지가 몇 개의 다이어그램을 내보냈는지 알려 줍니다. 오류가 난 다이어그램 목록은 "Show errors"를 클릭해 보고, 파일은 "Reveal"을 클릭해 확인합니다.
  4. 이미지가 하나 이상 써졌을 때만 무료 시도 1번이 차감됩니다. Esc, Cancel, PlantUML 파일이 없는 폴더는 시도를 쓰지 않습니다.

Export All Diagrams in a Folder 기능은 라이선스를 묻기 전에 내 컴퓨터에서 3번 무료로 쓸 수 있습니다. 팝업도 없고 카운트다운도 없습니다.

Cursor, Windsurf, VSCodium에서

  1. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 엽니다.
  2. zovo.zovo-plantuml-viewer를 검색하고 Install을 누릅니다. Cursor, Windsurf, VSCodium은 Open VSX에서 확장을 설치하며, 이 확장은 그곳에서 zovo/zovo-plantuml-viewer라는 이름으로 올라가 있습니다.
  3. 에디터에 확장 갤러리가 없으면 Open VSX 페이지에서 .vsix 파일을 내려받고 "Extensions: Install from VSIX..."를 실행합니다.
  4. 그다음은 VS Code에서와 똑같이 동작합니다.

PlantUML Viewer & Preview의 기능

  • 내장 PlantUML(MIT 빌드 1.2026.10)의 시퀀스, 클래스, 액티비티, 컴포넌트, 상태, 유스케이스 다이어그램, 마인드맵, 간트 차트와 그 밖의 @start... 블록.
  • Markdown의 ```plantuml, ```puml, ```uml 블록(안에 @startuml이 있어도 되고 없어도 됨). 이런 블록이 하나 이상 있는 Markdown 파일에 미리보기 버튼이 나타납니다.
  • 다이어그램 폴더, 작업 영역 폴더, plantumlViewer.includePaths에 있는 파일의 !include와 !include <C4/C4_Container> 같은 표준 라이브러리를 오프라인으로 처리합니다. https://raw.githubusercontent.com/... 주소로 쓴 C4, AWS 아이콘, 아이콘 폰트 include는 jar 안의 사본에서 읽습니다.
  • 시퀀스 다이어그램, 마인드맵, 간트 차트에는 레이아웃 엔진이 필요 없습니다. 클래스, 컴포넌트, 상태, 유스케이스 다이어그램은 dot이 설치되어 있으면 Graphviz를(plantumlViewer.layout이 auto일 때), 없으면 PlantUML에 내장된 Smetana 엔진을 씁니다.
  • 다이어그램은 이미지로 표시되므로 다이어그램 안의 링크나 텍스트가 편집기에서 코드를 실행할 수 없습니다.

할 수 없는 것

  • Java 11 이상이 설치되어 있어야 합니다. 확장은 Java를 내려받지 않습니다.
  • 웹 주소에서 가져오는 include는 거부됩니다. 단, jar에 사본이 있는 C4, AWS 아이콘, 아이콘 폰트 주소는 예외입니다. AWS 아이콘은 PlantUML에 들어 있는 AWS 아이콘 세트(버전 20)에서 가져오므로, 그보다 새 아이콘은 그 이름을 알려 주는 오류로 표시됩니다.
  • PlantUML MIT 빌드에는 Ditaa와 @startmath용 LaTeX 렌더러가 없습니다. Ditaa 블록에는 PlantUML의 "not supported" 페이지가 표시됩니다.
  • Graphviz가 없으면 Smetana가 클래스와 컴포넌트 다이어그램을 조금 다르게 배치하며, 아주 큰 클래스 다이어그램은 더 빽빽해 보일 수 있습니다.
  • 30초보다 오래 걸리는 다이어그램은 중지되고(plantumlViewer.renderTimeoutSeconds 설정), 이미지는 한 변이 8192픽셀을 넘으면 잘립니다(plantumlViewer.maxImageSize 설정).

자주 묻는 질문

무료인가요?

실시간 미리보기, 확대/축소와 이동, 오류 링크, 다이어그램 하나를 SVG 또는 PNG로 저장, 구문 색상과 스니펫은 무료입니다. 세 가지 Pro 도구 Export All Diagrams in a Folder, Markdown Diagrams to Images, Compare with a Git Version은 각각 3번 무료로 쓸 수 있습니다. 그 뒤에는 Zovo Pro가 필요하며, USD 19 한 번으로 모든 Zovo 확장에 적용됩니다.

Java나 Graphviz가 필요한가요?

Java 11 이상은 필요합니다. PlantUML이 Java 프로그램이기 때문입니다. Graphviz는 필요 없습니다. Graphviz가 없으면 클래스와 컴포넌트 다이어그램은 PlantUML에 내장된 Smetana 레이아웃 엔진을 씁니다. dot이 설치되어 있으면 그것을 씁니다.

다이어그램이 서버로 전송되나요?

아니요. 내장 PlantUML jar가 ALLOWLIST 보안 프로필로 내 컴퓨터에서 실행되며, 웹 주소에서 가져오는 include는 거부됩니다. PlantUML 서버는 쓰지 않습니다.

Cursor에서도 되나요?

네. Cursor, Windsurf, VSCodium은 Open VSX에서 설치하며, 이 확장은 그곳에 zovo/zovo-plantuml-viewer로 게시되어 있습니다.
