화질 손실 없이 TIFF를 PNG로 변환하기

TIFF Viewer & TIF Viewer (16-bit, GeoTIFF)를 설치합니다. VS Code에서 16비트, float, 여러 페이지 파일을 포함한 .tif, .tiff 파일을 열고, Export PNG로 화면에 보이는 그대로 페이지를 무료로 저장합니다. Zovo Pro 도구 Export pages는 현재 페이지나 모든 페이지를 저장된 값 그대로 원본 해상도 PNG로 저장하므로, 8비트와 16비트 데이터의 값이 정확히 유지됩니다. Export pages, Batch convert, Region stats는 각각 3번 무료로 써 볼 수 있고, 그다음에는 Zovo Pro를 USD 19에 한 번 구매합니다.

VS Code에서 하는 방법

  1. Marketplace에서 TIFF Viewer 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.tiff-viewer를 실행합니다.
  2. Explorer에서 .tif나 .tiff 파일을 클릭하면 TIFF Viewer로 열립니다. 다른 뷰어가 열리면 파일을 마우스 오른쪽 버튼으로 클릭하고 "Open in TIFF Viewer"를 고르거나, 에디터 제목 메뉴의 "Reopen Editor With..."를 씁니다.
  3. 스크롤하면 확대, 축소되고 끌면 이동합니다. 상태 표시줄에 포인터 아래 픽셀의 저장된 값이 나옵니다.
  4. 여러 페이지 파일은 페이지 띠에서 페이지를 고르거나 PageDown, PageUp(또는 J, K)을 누릅니다.
  5. 16비트나 float 데이터는 Channel과 Contrast stretch(min에서 max, 2~98 퍼센트, 타입 전체 범위)로 조절합니다. T를 누르면 태그 패널이 열리고, 파일에 GeoTIFF 태그가 있으면 GeoTIFF 섹션도 나옵니다.
  6. Export PNG를 누르면 고른 채널과 스트레치를 적용해 화면에 보이는 그대로 현재 페이지를 저장합니다. 이 기능은 무료입니다.

무료 기능과 Zovo Pro가 더하는 기능

모든 페이지, 채널과 대비 스트레치, 포인터 아래 픽셀 값, TIFF 태그, GeoTIFF 좌표, 화면에 보이는 페이지의 Export PNG는 무료입니다. 보기 기능은 로그인 없이 오프라인에서 동작합니다.

Export pages는 현재 페이지나 여러 페이지 파일의 모든 페이지를 원본 해상도 PNG로 저장합니다. "stored values"를 고르면 8비트와 16비트 데이터는 8비트 또는 16비트 PNG에 값이 정확히 유지됩니다. 부호 있는 정수, 32비트, float 데이터는 화면에 보이는 범위에 맞춰 16비트로 옮기고, 원래 값을 되찾는 방법을 PNG 텍스트에 적어 둡니다. GeoTIFF 페이지는 .pgw 월드 파일과 .geojson 범위 파일도 함께 저장하므로, PNG가 QGIS나 ArcGIS에서 제자리에 놓입니다.

Export pages 사용하기 (Zovo Pro)

  1. TIFF를 열고 뷰어 도구 모음의 Export pages를 누릅니다. 파일이 열려 있을 때 Command Palette에서 "TIFF Viewer: Export Pages to PNG (Pro)..."를 실행해도 됩니다.
  2. "Page N with the stored values"(16비트 데이터는 16비트 PNG) 또는 "Page N as shown"(8비트)을 고릅니다. 여러 페이지 파일에서는 "All N pages with the stored values"나 "All N pages as shown"도 고를 수 있습니다.
  3. 파일 이름을 정하고(모든 페이지라면 폴더를 정하고) 저장합니다. 횟수는 PNG가 실제로 써졌을 때만 줄어들고, Escape로 취소하면 줄지 않습니다.
  4. TIFF가 든 폴더 전체는 폴더를 마우스 오른쪽 버튼으로 클릭하고 "TIFF Viewer: Batch Convert TIFF Folder to PNG (Pro)..."를 실행합니다(이것도 Pro 도구입니다).

Export pages 기능은 라이선스를 묻기 전에 내 컴퓨터에서 3번 무료로 쓸 수 있습니다. 팝업도 없고 카운트다운도 없습니다.

Cursor, Windsurf, VSCodium에서

  1. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 엽니다.
  2. zovo.tiff-viewer를 검색하고 Install을 누릅니다. Cursor, Windsurf, VSCodium은 Open VSX에서 확장을 설치하며, 이 확장은 그곳에서 zovo/tiff-viewer라는 이름으로 올라가 있습니다.
  3. 에디터에 확장 갤러리가 없으면 Open VSX 페이지에서 .vsix 파일을 내려받고 "Extensions: Install from VSIX..."를 실행합니다.
  4. 그다음은 VS Code에서와 똑같이 동작합니다.

TIFF Viewer의 기능

  • 일반 TIFF와 BigTIFF. 리틀 엔디언과 빅 엔디언, strip과 tile, chunky와 planar를 모두 읽습니다.
  • 1~64비트 부호 없는 정수와 부호 있는 정수, 16, 32, 64비트 float 샘플. 퍼센타일 대비 스트레치를 씁니다.
  • 회색조, RGB와 RGBA, 팔레트, CMYK, JPEG 안의 YCbCr. 무압축, LZW, Deflate, PackBits, JPEG, CCITT Group 3과 4 압축.
  • 여러 페이지 파일. 페이지 띠가 있고, 처음 300페이지는 썸네일로 보여 줍니다.
  • GeoTIFF 태그. EPSG 코드, 픽셀 크기, 범위, nodata 값, 포인터 아래 지점의 지도 좌표가 나옵니다.

할 수 없는 것

  • ZSTD, LERC, WebP, JPEG 2000으로 압축된 페이지는 태그와 함께 목록에 나오지만 디코딩하지 않습니다.
  • 1 GB가 넘는 파일(설정 tiffViewer.maxFileMB, 기본값 1024)은 디코딩하지 않고, 메시지와 모든 페이지의 태그만 보여 줍니다.
  • 한 변이 6000픽셀을 넘거나 2천4백만 픽셀을 넘는 페이지는 N번째 픽셀마다 하나씩 골라 보여 줍니다. 포인터 값 표시와 통계는 그래도 원본 해상도를 씁니다.
  • 픽셀당 8비트 미만인 tile 페이지와 무압축 YCbCr은 디코딩하지 않습니다. SubIFD 안의 하위 이미지(일부 DNG, OME-TIFF 피라미드)는 태그 목록에는 나오지만 페이지로 보이지 않습니다.
  • 뷰어는 읽기 전용이라 TIFF 파일에 쓰지 않습니다. 지도 타일과 재투영 기능은 없습니다.

자주 묻는 질문

TIFF를 PNG로 바꾸면 화질이 떨어지나요?

PNG는 무손실 형식입니다. 16비트 데이터를 8비트로 줄일 때만 화질이 떨어집니다. Export pages에서 stored values 옵션을 고르면 8비트와 16비트 값이 정확히 유지됩니다.

무료인가요?

TIFF 파일 보기와 화면에 보이는 페이지의 Export PNG는 무료입니다. Export pages, Batch convert, Region stats는 Pro 도구로 각각 3번 무료로 써 볼 수 있고, 그다음에는 모든 Zovo 확장에 쓰는 Zovo Pro 라이선스를 USD 19에 한 번 구매합니다.

이미지가 업로드되나요?

아니요. 확장이 스스로 네트워크를 쓰지 않고 텔레메트리도 없습니다. 파일은 내 컴퓨터에서 읽고 씁니다.

Cursor나 Windsurf에서도 되나요?

네. Cursor, Windsurf, VSCodium은 Open VSX에서 확장을 설치하고, TIFF Viewer는 Open VSX에 올라가 있습니다.
