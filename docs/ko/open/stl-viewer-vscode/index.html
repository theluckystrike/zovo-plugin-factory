VS Code에서 하는 방법

  1. Marketplace에서 3D Model Viewer 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.3d-model-viewer를 실행합니다.
  2. Explorer에서 .stl, .obj, .ply, .3mf, .glb, .gltf 파일을 클릭합니다. 다른 뷰어가 열리면 파일을 마우스 오른쪽 버튼으로 클릭하고 "Open in 3D Model Viewer"를 고릅니다.
  3. 끌면 회전하고, 오른쪽 버튼으로 끌거나 Shift를 누른 채 끌면 이동하고, 스크롤하면 확대, 축소됩니다. F를 누르면 모델 전체가 화면에 맞춰집니다.
  4. 패널에서 정점, 삼각형, 재질, 텍스처 수와 모델 단위 크기를 확인합니다. P를 누르면 패널과 씬 트리를 보이거나 숨깁니다.
  5. W는 와이어프레임, N은 정점 노멀, B는 바운딩 박스입니다. Shading을 Smooth로 바꾸면 STL 파일의 각진 면이 매끄럽게 보입니다.
  6. M(Measure)을 누르고 표면에서 두 점을 클릭합니다. 선에 거리가 나오고, 상태 표시줄에 X, Y, Z 성분이 더해집니다. Esc로 끝냅니다.
  7. Screenshot을 눌러 현재 화면을 PNG 파일로 저장합니다.

무료 기능과 Zovo Pro가 더하는 기능

여섯 가지 형식 열기, 회전, 이동, 확대, 통계 패널, 씬 트리, Measure, 와이어프레임, 노멀, 바운딩 박스, 그리드, 축, glTF 애니메이션, PNG 스크린샷은 무료입니다. 오프라인에서 동작하고 네트워크를 쓰지 않습니다.

Print check는 모델의 크기, 부피, 표면적을 보여 주고 메시가 닫혀 있는지(watertight) 검사합니다. 열린 모서리, non-manifold 모서리, 방향이 뒤집힌 면, 넓이가 0인 삼각형, 분리된 부품 수를 확인합니다. Mark problems를 누르면 문제가 있는 모서리가 모델 위에 그려집니다. 재질, 내부 채움(infill), 벽 두께, 필라멘트 지름, kg당 가격을 넣으면 슬라이서를 열기 전에 무게, 필라멘트 길이, 재료비를 어림합니다.

Print check 사용하기 (Zovo Pro)

  1. 3D Model Viewer에서 STL 파일을 엽니다.
  2. 옆 패널에서 "Run print check"를 누르거나, Command Palette에서 "3D Model Viewer: Print Check (Zovo Pro)"를 실행합니다. Explorer에서 파일을 마우스 오른쪽 버튼으로 클릭하고 "Zovo Pro: Print check"를 골라도 됩니다.
  3. 메시에 문제가 있으면 "Mark problems"를 눌러 열린 모서리는 빨간색, 다른 문제 모서리는 자홍색으로 봅니다. 재질(PLA, PETG, ABS, ASA, TPU, 나일론, PC, 레진), 내부 채움, kg당 가격을 고릅니다.
  4. 보고서를 복사하거나 Markdown, JSON으로 저장합니다. 무료 1회는 열린 파일 탭 하나에 해당하므로, 같은 탭에서는 설정을 바꿔 다시 실행할 수 있습니다.

Print check 기능은 라이선스를 묻기 전에 내 컴퓨터에서 3번 무료로 쓸 수 있습니다. 팝업도 없고 카운트다운도 없습니다.

Cursor, Windsurf, VSCodium에서

  1. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 엽니다.
  2. zovo.3d-model-viewer를 검색하고 Install을 누릅니다. Cursor, Windsurf, VSCodium은 Open VSX에서 확장을 설치하며, 이 확장은 그곳에서 zovo/3d-model-viewer라는 이름으로 올라가 있습니다.
  3. 에디터에 확장 갤러리가 없으면 Open VSX 페이지에서 .vsix 파일을 내려받고 "Extensions: Install from VSIX..."를 실행합니다.
  4. 그다음은 VS Code에서와 똑같이 동작합니다.

3D Model Viewer의 기능

  • 바이너리와 ASCII STL. 파일에 면별 색이 있으면 그 색도 보여 줍니다.
  • OBJ. mtllib가 가리키는 .mtl 파일이 모델 옆에 있으면 함께 읽습니다.
  • PLY 메시와 포인트 클라우드(ASCII, 바이너리), 정점 색 포함.
  • 3MF 오브젝트, 빌드 아이템, 기본 재질 색.
  • GLB와 glTF 2.0. 내장 또는 외부 .bin 버퍼와 텍스처, PBR 재질, 노드 트리, 스킨, 모프 타깃, 애니메이션을 지원합니다.

할 수 없는 것

  • FBX, DAE, USD, STEP, IGES, glTF 1.0 파일은 열리지 않습니다.
  • Draco, meshopt로 압축된 glTF와 KTX2 텍스처는 아직 디코딩하지 않습니다. 어떤 확장이 빠졌는지 메시지로 알려 줍니다.
  • 파일 전체를 메모리로 읽습니다. 1024 MB가 넘는 파일(설정 modelViewer.maxFileMB)은 메시지가 나오고 읽지 않습니다.
  • STL, OBJ, PLY에는 단위가 없어서 크기와 거리는 좌표 값 그대로입니다. glTF는 미터, 3MF는 밀리미터로 봅니다(파일에 다르게 적혀 있지 않은 경우).
  • Print check와 Section view는 보이는 메시를 삼각형 3백만 개까지 읽고, 포인트 클라우드가 아닌 메시가 필요합니다. 무게는 어림값입니다. 서포트, 브림, 위아래 레이어는 계산에 들어가지 않습니다.

자주 묻는 질문

STL 측정값은 어떤 단위인가요?

STL 파일에는 단위가 없어서 뷰어는 좌표 값을 그대로 보여 줍니다. Print check는 STL, OBJ, PLY를 밀리미터로 읽으며, 파일이 다른 단위를 쓰면 Print check 패널에서 단위를 바꿀 수 있습니다.

재질이 있는 OBJ 파일도 열 수 있나요?

네. mtllib가 가리키는 .mtl 파일이 모델 옆에 있으면 됩니다. 텍스처와 .bin 파일은 모델 폴더와 열린 워크스페이스 폴더에서만 불러옵니다.

무료인가요?

네. 모델 열기, 측정, 통계, 씬 트리, 스크린샷은 무료입니다. Print check, Section view, Turntable export는 Zovo Pro 도구로 각각 3번 무료로 써 볼 수 있고, 그다음에는 모든 Zovo 확장에 쓰는 라이선스를 USD 19에 한 번 구매합니다.

오프라인에서도 되나요?

네. VS Code 안에서 three.js로 그리고, 텔레메트리가 없으며 네트워크를 쓰지 않습니다. 예외는 GitHub Sponsors로 Zovo Pro를 켤 때 GitHub에 한 번 연결하는 것뿐입니다.
