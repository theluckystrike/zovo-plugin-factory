VS Code에서 bash 또는 zsh 스크립트를 포맷하는 방법

무료 확장 Shell Formatter for Bash & Zsh를 설치하고 셸 스크립트를 연 뒤 Shift+Alt+F(Mac에서는 Shift+Option+F)를 누릅니다. shfmt 3.14.1 엔진이 WebAssembly로 확장 안에 들어 있어 따로 내려받을 것이 없고, 결과는 shfmt 명령줄과 바이트 단위로 같습니다. Format Document, Format Selection, 저장 시 포맷, .editorconfig 키, Problems의 구문 오류 표시는 무료이며 오프라인에서 동작합니다. Zovo Pro(USD 19 한 번)는 Format All Shell Scripts in a Folder, Formatting Check with a Patch File, Minify a Script to a Copy의 세 가지 도구를 더하며, 각 도구는 3번 무료로 쓸 수 있습니다.

VS Code에서 하는 방법

  1. Marketplace에서 Shell Formatter for Bash & Zsh 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.zovo-shell-formatter를 실행합니다.
  2. 셸 스크립트를 열고 Shift+Alt+F(Mac에서는 Shift+Option+F)를 누릅니다. VS Code가 어떤 포맷터를 쓸지 물으면 Shell Formatter를 고르거나 "Shell Formatter: Use as Default Formatter for Shell Scripts"를 실행합니다.
  3. 저장할 때마다 포맷하려면 "Shell Formatter: Turn On Format on Save for Shell Scripts"를 실행합니다.
  4. 방언은 먼저 첫 줄(#!/bin/bash, #!/bin/sh, #!/usr/bin/env zsh)로, 그다음 파일 이름(.bash, .zsh, .zshrc, .bats, .ksh)으로 정하며, 둘 다 해당하지 않으면 bash로 봅니다. 직접 정하려면 shellFormatter.dialect를 설정하거나 .editorconfig에 shell_variant를 씁니다.
  5. 상태 표시줄의 shfmt 3.14.1을 클릭하면 메뉴가 열립니다. 포맷, 기본 포맷터로 설정, 저장 시 포맷, "Copy the matching shfmt command (for CI)", 설정이 있습니다.
  6. 스크립트가 올바른 셸 문법이 아니면 그대로 두고, Problems 패널에 줄과 열을 표시합니다.

무료 기능과 Zovo Pro가 더하는 기능

Format Document, Format Selection, 저장 시 포맷, 방언 감지, .editorconfig 키, 상태 표시줄 메뉴, Copy the Matching shfmt Command (for CI), Problems의 구문 오류 표시는 무료입니다. 로그인, 네트워크 요청, 원격 측정이 없습니다.

Format All Shell Scripts in a Folder는 폴더와 하위 폴더에서 이름이나 셸을 지정한 #! 줄로 찾은 모든 스크립트를 검사하고, 몇 개가 바뀔지 알려 줍니다. 그다음 Format Document와 같은 엔진, 설정, .editorconfig로 모두 포맷하거나 Markdown 보고서만 보여 줍니다. 스타일이 제각각인 스크립트 수십 개가 있는 저장소도 한 번 실행으로 스타일이 하나로 맞춰지며, 포맷 후 같은 명령을 실행하지 않게 될 스크립트는 그대로 둡니다.

Format All Shell Scripts in a Folder 사용하기 (Zovo Pro)

  1. Explorer에서 폴더를 마우스 오른쪽 버튼으로 클릭하고 "Zovo Pro: Format All Shell Scripts in a Folder"를 고르거나, Command Palette 또는 상태 표시줄 메뉴에서 "Shell Formatter: Format All Shell Scripts in a Folder (Pro)"를 실행하고 폴더를 고릅니다.
  2. 다음 목록의 제목에 "N of M scripts would change"처럼 바뀔 스크립트 수가 나옵니다.
  3. "Format N scripts"를 고르면 각 파일을 포맷하고 저장합니다(실행 취소는 파일마다 됩니다). "Show the report only"를 고르면 아무것도 바꾸지 않고 모든 스크립트를 나열한 Markdown 목록을 보여 줍니다.
  4. 결과가 나왔을 때만 시도 횟수가 차감됩니다. 셸 스크립트가 없는 폴더나 모든 스크립트가 이미 포맷된 폴더에서는 차감되지 않습니다.

Format All Shell Scripts in a Folder 기능은 라이선스를 묻기 전에 내 컴퓨터에서 3번 무료로 쓸 수 있습니다. 팝업도 없고 카운트다운도 없습니다.

Cursor, Windsurf, VSCodium에서

  1. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 엽니다.
  2. zovo.zovo-shell-formatter를 검색하고 Install을 누릅니다. Cursor, Windsurf, VSCodium은 Open VSX에서 확장을 설치하며, 이 확장은 그곳에서 zovo/zovo-shell-formatter라는 이름으로 올라가 있습니다.
  3. 에디터에 확장 갤러리가 없으면 Open VSX 페이지에서 .vsix 파일을 내려받고 "Extensions: Install from VSIX..."를 실행합니다.
  4. 그다음은 VS Code에서와 똑같이 동작합니다.

Shell Formatter for Bash & Zsh의 기능

  • Bash, POSIX sh(dash와 ash 포함), mksh(ksh 포함), bats, zsh 스크립트.
  • 명령줄의 shfmt 3.14.1과 같은 결과. GitHub 프로젝트와 Homebrew의 실제 스크립트 178개로 354번 실행해 354번 모두 바이트 단위로 일치했습니다.
  • 변경을 적용하기 전에 포맷한 스크립트를 다시 파싱하며, 원본과 같은 명령을 실행해야 합니다(256 KB 이하 파일).
  • 설정이나 .editorconfig 키로 shfmt 옵션을 지정합니다. 들여쓰기, 이항 연산자를 다음 줄에, switch case 들여쓰기, 리디렉션 뒤 공백, 정렬 여백 유지, 함수 중괄호를 다음 줄에, 단순화, 압축(minify)이 있습니다.
  • Windows 줄 끝(CRLF)은 CRLF로 유지되며, 2 MB 스크립트는 약 0.2초 만에 포맷됩니다.

할 수 없는 것

  • Dockerfile, .env 파일, fish, csh 스크립트는 건드리지 않습니다.
  • shfmt의 zsh 지원은 새로 추가되었습니다. shfmt가 파싱하지 못하는 zsh 스크립트는 그대로 둡니다.
  • 10 MB가 넘는 파일(설정 shellFormatter.maxFileMB)과 자동 압축 해제 설치 프로그램처럼 바이너리 바이트가 들어 있는 파일은 포맷하지 않습니다.
  • shfmt는 시간 제한(기본 10초, 설정 shellFormatter.timeoutSeconds) 안에서 실행됩니다. 제한에 걸리면 파일은 그대로 남습니다.

자주 묻는 질문

무료인가요?

Format Document, Format Selection, 저장 시 포맷, .editorconfig 지원은 무료입니다. 세 가지 Pro 도구 Format All Shell Scripts in a Folder, Formatting Check with a Patch File, Minify a Script to a Copy는 각각 3번 무료로 쓸 수 있습니다. 그 뒤에는 Zovo Pro가 필요하며, USD 19 한 번으로 모든 Zovo 확장에 적용됩니다.

shfmt를 설치해야 하나요?

아니요. shfmt 3.14.1이 WebAssembly로 확장 안에 들어 있어 내려받을 것 없이 오프라인에서 동작합니다.

스크립트가 망가지지는 않나요?

구문 오류가 있는 스크립트는 그대로 둡니다. 변경을 적용하기 전에 포맷한 스크립트를 다시 파싱하며, 원본과 같은 명령을 실행해야 합니다.

Cursor에서도 되나요?

네. Cursor, Windsurf, VSCodium은 Open VSX에서 설치하며, 그곳에는 zovo/zovo-shell-formatter로 게시되어 있습니다.
