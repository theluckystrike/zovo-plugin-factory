Graphviz를 설치하지 않고 DOT 그래프 미리보기

무료 확장 Graphviz Viewer & DOT Viewer를 설치하고 .dot이나 .gv 파일을 연 뒤 미리보기 아이콘을 누릅니다. 그래프가 에디터 옆에 그려지고 입력하는 대로 다시 그려집니다. Graphviz 16.1이 WebAssembly로 확장 안에 들어 있어서 다른 것을 설치할 필요가 없습니다. 미리보기, 레이아웃 엔진 여섯 개, 클릭해서 해당 줄로 이동, SVG와 PNG 내보내기는 무료입니다. Zovo Pro(USD 19, 한 번 결제)는 벡터 PDF 내보내기, 워크스페이스의 모든 그래프 내보내기, 저장할 때 내보내기를 더하며, 도구마다 3번 무료로 써 볼 수 있습니다.

VS Code에서 하는 방법

  1. Marketplace에서 Graphviz Viewer & DOT Viewer 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.zovo-graphviz-preview를 실행합니다.
  2. .dot이나 .gv 파일을 엽니다. 에디터 제목 줄의 미리보기 아이콘을 누르거나 Ctrl+K V(Mac에서는 Cmd+K V)를 누르면 파일 옆에 그래프가 열립니다.
  3. 파일을 고칩니다. 입력을 멈추고 300 ms가 지나면 저장하지 않아도 미리보기가 다시 그려집니다. 문법 오류는 해당 줄에 밑줄이 그어지고 Problems에 나오며, 미리보기는 마지막으로 제대로 그려진 그래프를 유지합니다.
  4. 도구 모음에서 dot, neato, fdp, sfdp, circo, twopi 중 하나를 고릅니다. auto로 두면 그래프의 layout= 속성을 쓰고, 속성이 없으면 dot을 씁니다.
  5. Find node에 입력하면 이름이나 라벨이 일치하는 노드가 강조됩니다. 노드, 엣지, 클러스터를 클릭하면 소스에서 해당 줄로 커서가 갑니다.
  6. SVG나 PNG를 눌러 그래프를 저장합니다. PNG는 흰 배경에 보통 Graphviz 색으로 2x 크기로 저장됩니다.

무료 기능과 Zovo Pro가 더하는 기능

실시간 미리보기, 레이아웃 엔진 여섯 개 모두, Problems의 오류 표시, Find node, 클릭해서 줄 이동, 이동과 확대, 열린 그래프의 SVG와 PNG 내보내기, Markdown 미리보기 안의 dot 블록은 무료입니다. 로그인이 필요 없고, 네트워크를 쓰지 않으며 텔레메트리도 없습니다.

PDF 내보내기는 글자가 텍스트로 남는 벡터 PDF를 저장하므로, 아무리 확대해도 선명하고 글자를 검색하고 복사할 수 있습니다. dot -Tpdf처럼 그래프 크기에 맞춘 페이지나, 표지와 북마크가 있는 A4 또는 Letter 페이지를 고를 수 있고, Markdown 파일은 dot 블록마다 한 페이지가 됩니다. Graphviz를 설치하지 않고도 설계 문서나 인쇄용 PDF를 얻습니다.

Export to PDF (Vector, Title Page) 사용하기 (Zovo Pro)

  1. 미리보기를 열고 도구 모음의 PDF(작은 PRO 표시가 있음)를 누르거나, Command Palette에서 "Graphviz: Export to PDF (Vector, Title Page) (Pro)"를 실행합니다.
  2. "Graph-size pages", "Title page and A4 pages", "Title page and Letter pages", "Graph-size pages with a title page" 중에서 고르고 저장할 곳을 정합니다.
  3. Escape, Cancel, 그래프 오류로 끝나면 무료 횟수가 줄지 않습니다.

Export to PDF (Vector, Title Page) 기능은 라이선스를 묻기 전에 내 컴퓨터에서 3번 무료로 쓸 수 있습니다. 팝업도 없고 카운트다운도 없습니다.

Cursor, Windsurf, VSCodium에서

  1. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 엽니다.
  2. zovo.zovo-graphviz-preview를 검색하고 Install을 누릅니다. Cursor, Windsurf, VSCodium은 Open VSX에서 확장을 설치하며, 이 확장은 그곳에서 zovo/zovo-graphviz-preview라는 이름으로 올라가 있습니다.
  3. 에디터에 확장 갤러리가 없으면 Open VSX 페이지에서 .vsix 파일을 내려받고 "Extensions: Install from VSIX..."를 실행합니다.
  4. 그다음은 VS Code에서와 똑같이 동작합니다.

Graphviz Viewer & DOT Viewer의 기능

  • 클러스터, 서브그래프, HTML 라벨이 있는 graph와 digraph.
  • Markdown 안의 dot, graphviz, gv 펜스 블록. VS Code에 내장된 Markdown 미리보기에 그려집니다.
  • 어두운 테마. 기본 검은 선과 글자는 테마 색을 따르고, 그래프에 직접 지정한 색은 그대로 둡니다.
  • 큰 그래프. 시간 제한이 있는 별도 스레드에서 레이아웃을 계산합니다. 노드가 수천 개이면 보통 sfdp가 dot보다 훨씬 빠릅니다.

할 수 없는 것

  • 4,096 KB가 넘는 그래프는 레이아웃을 계산하지 않고, 15초가 넘게 걸리는 레이아웃은 중단합니다(graphvizPreview.maxSourceKB, graphvizPreview.renderTimeoutSeconds).
  • image= 속성과 HTML 라벨 안의 그림은 설계상 그리지 않습니다.
  • 미리보기는 파일마다 하나이고, 재시작 후에는 복원되지 않습니다. Problems 표시는 미리보기가 열려 있을 때만 나옵니다.
  • PDF는 표준 PDF 글꼴을 쓰므로, 한국어, 중국어, 키릴 문자처럼 서유럽 문자가 아닌 라벨은 PDF에서 "?"로 보입니다. SVG와 PNG에서는 제대로 보입니다.

자주 묻는 질문

무료인가요?

실시간 미리보기, 엔진 여섯 개, 클릭해서 줄 이동, SVG와 PNG 내보내기는 무료입니다. 세 Pro 도구 PDF 내보내기, Export All Graphs in Workspace, Export on Save는 각각 3번 무료로 써 볼 수 있습니다. 그다음에는 Zovo Pro가 필요하며, 모든 Zovo 확장에 쓰는 라이선스를 USD 19에 한 번 구매합니다.

Graphviz를 설치해야 하나요?

아니요. Graphviz 16.1이 WebAssembly로 확장 안에 들어 있습니다. 컴퓨터에 따로 설치되는 것은 없고, 오프라인에서 동작합니다.

Markdown 안의 dot 블록도 그려 주나요?

네. 언어가 dot, graphviz, gv인 펜스 블록은 VS Code Markdown 미리보기에 그려집니다.

Cursor에서도 되나요?

네. 이 확장은 Open VSX에 올라가 있어 Cursor, Windsurf, VSCodium에서 설치할 수 있습니다.
