VS Code에서 AWS S3, Cloudflare R2, MinIO 버킷을 탐색하는 방법

무료 확장 S3 Explorer를 설치하고 작업 막대(Activity Bar)에서 S3 Buckets 뷰를 엽니다. AWS S3(~/.aws의 프로필, SSO 프로필 포함), Cloudflare R2, MinIO, Backblaze B2, Wasabi, DigitalOcean Spaces에서 동작합니다. 탐색, 객체를 읽기 전용으로 열기, 업로드, 다운로드, 복사, 이동, 이름 바꾸기, 삭제, 버전, 태그, 미리 서명된 URL, 폴더 동기화는 무료이며 로그인과 원격 측정이 없습니다. Zovo Pro(USD 19 한 번)는 Copy to Another Connection, Size and Cost Report, Scheduled Sync의 세 가지 도구를 더하며, 각 도구는 3번 무료로 쓸 수 있습니다.

VS Code에서 하는 방법

  1. Marketplace에서 S3 Explorer 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.zovo-s3-explorer를 실행합니다.
  2. 작업 막대에서 S3 Explorer 뷰를 열고 Add Connection을 클릭합니다. ~/.aws의 AWS 프로필을 고르거나, 액세스 키, R2 계정 ID와 토큰, 또는 MinIO 등 S3 호환 서비스의 엔드포인트 URL을 입력합니다. 입력한 키는 OS 키체인에 저장됩니다.
  3. 연결을 펼쳐 버킷을 봅니다. 키는 한 번에 1,000개씩 불러오며 "Load 1,000 more" 행이 있습니다. 키에 버킷 목록 권한이 없으면 연결을 마우스 오른쪽 버튼으로 클릭하고 Add Bucket by Name을 고릅니다.
  4. 객체를 클릭하면 탭이나 해당 뷰어에서 읽기 전용으로 열립니다. 메타데이터, 태그, 버전, 미리 서명된 URL을 보려면 객체를 마우스 오른쪽 버튼으로 클릭하고 Show Details, Versions and Presigned URL을 고릅니다.
  5. 객체를 바꾸려면 마우스 오른쪽 버튼으로 클릭하고 Edit and Upload를 고릅니다. 복사본을 편집하며, 객체를 바꾸기 전에 버킷, 키, 두 크기를 보여 주는 대화 상자가 나옵니다.
  6. Explorer에서 파일이나 폴더를 버킷으로 끌어다 놓아 업로드하거나, 마우스 오른쪽 버튼으로 클릭하고 Download를 고릅니다. 16 MB 이상 파일은 진행 상황과 Cancel 버튼이 표시되며 여러 부분으로 나눠 올라가고, 중단된 업로드는 빠진 부분만 올려 이어 갑니다.
  7. 로컬 폴더와 프리픽스를 같게 유지하려면 버킷이나 폴더를 마우스 오른쪽 버튼으로 클릭하고 Sync Folder를 고릅니다. 무언가 바뀌기 전에 드라이런 계획(새 항목, 변경된 항목, 삭제할 항목)을 먼저 보여 줍니다.

무료 기능과 Zovo Pro가 더하는 기능

탐색, 열기, Edit and Upload, 업로드, 다운로드, 복사, 이동, 이름 바꾸기, 삭제, 버전, 태그, 미리 서명된 URL, 폴더 동기화는 무료이며 로그인, 계정, 원격 측정이 없습니다. 직접 추가한 스토리지 엔드포인트에만 연결합니다.

Copy to Another Connection은 객체나 폴더 전체를 한 연결에서 다른 연결로 복사합니다. 예를 들어 AWS S3에서 Cloudflare R2나 MinIO로 복사합니다. 확인 절차는 다른 복사와 같아서 키 목록이 나오고 덮어쓸 키는 이름으로 표시됩니다. 큰 객체는 멀티파트 업로드로 보냅니다. 스크립트나 다른 도구 없이 트리에서 바로 공급자나 계정 사이로 데이터를 옮길 수 있습니다.

Copy to Another Connection 사용하기 (Zovo Pro)

  1. 먼저 두 번째 연결을 추가합니다. 그다음 S3 Buckets 뷰에서 객체나 폴더를 마우스 오른쪽 버튼으로 클릭하고 "Copy to Another Connection... (Pro)"를 고르거나, 뷰 끝의 "Zovo Pro tools" 행에서 Copy to Another Connection을 클릭합니다.
  2. 대상 연결, 버킷, 대상 폴더(최상위는 비워 둠)를 고릅니다.
  3. 확인 창에서 객체 목록을 읽고 Copy를 클릭합니다. 이미 있는 키가 있으면 Copy and Replace를 클릭합니다. 알림에 진행 상황이 표시됩니다.
  4. 객체가 복사되었을 때만 시도 횟수가 차감됩니다. 선택 중에 Escape를 누르거나 두 번째 연결이 없으면 차감되지 않습니다.

Copy to Another Connection 기능은 라이선스를 묻기 전에 내 컴퓨터에서 3번 무료로 쓸 수 있습니다. 팝업도 없고 카운트다운도 없습니다.

Cursor, Windsurf, VSCodium에서

  1. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 엽니다.
  2. zovo.zovo-s3-explorer를 검색하고 Install을 누릅니다. Cursor, Windsurf, VSCodium은 Open VSX에서 확장을 설치하며, 이 확장은 그곳에서 zovo/zovo-s3-explorer라는 이름으로 올라가 있습니다.
  3. 에디터에 확장 갤러리가 없으면 Open VSX 페이지에서 .vsix 파일을 내려받고 "Extensions: Install from VSIX..."를 실행합니다.
  4. 그다음은 VS Code에서와 똑같이 동작합니다.

S3 Explorer의 기능

  • 액세스 키가 있는 AWS 프로필, credential_process, source_profile을 쓰는 역할, aws sso login 후의 SSO 프로필. 프로필의 endpoint_url도 따릅니다.
  • 엔드포인트 URL, 리전, 경로 방식 또는 가상 호스트 방식 URL을 쓰는 MinIO와 기타 S3 호환 서비스. 자체 서명 인증서를 허용하는 옵션도 있습니다.
  • 메타데이터, 콘텐츠 유형, 스토리지 클래스, ETag, 태그(편집 후 저장), 버전(열기, 다운로드, 복원), 15분에서 7일까지 유효한 미리 서명된 GET 또는 PUT URL.
  • 키가 수백만 개인 버킷도 1,000개씩 불러오며, 프리픽스로 찾고 거를 수 있습니다.
  • 다운로드는 폴더 구조를 유지하고 고른 폴더 밖에는 절대 쓰지 않습니다. .. 세그먼트, 드라이브 문자, NUL 바이트가 있는 키는 건너뛰고 목록으로 보여 줍니다.

할 수 없는 것

  • AWS default 프로필이나 AWS_PROFILE을 스스로 쓰지 않습니다. 연결할 프로필은 직접 고릅니다.
  • 10 MB가 넘는 텍스트 객체는 먼저 묻고 처음 1 MB만 보여 줍니다. 200 MB가 넘는 바이너리 객체는 내려받기 전에 묻습니다.
  • 연 객체는 읽기 전용입니다. Edit and Upload만 확인을 거쳐 버킷에 씁니다.
  • Scheduled Sync는 VS Code가 열려 있는 동안에만 5분에서 60분 간격으로 실행되며, 아무것도 삭제하지 않습니다.
  • 응답이 없는 요청은 30초 뒤에 멈춥니다(설정 s3Explorer.requestTimeoutSeconds).

자주 묻는 질문

무료인가요?

탐색, 열기, 업로드, 다운로드, 복사, 이동, 이름 바꾸기, 삭제, 버전, 태그, 미리 서명된 URL, 폴더 동기화는 무료입니다. 세 가지 Pro 도구 Copy to Another Connection, Size and Cost Report, Scheduled Sync는 각각 3번 무료로 쓸 수 있습니다. 그 뒤에는 Zovo Pro가 필요하며, USD 19 한 번으로 모든 Zovo 확장에 적용됩니다.

키는 어디에 저장되나요?

입력한 키는 VS Code SecretStorage를 통해 OS 키체인에 저장되며 설정 파일에는 절대 들어가지 않습니다. AWS 프로필은 직접 고를 때만 ~/.aws에서 읽습니다.

Cloudflare R2와 MinIO에서도 되나요?

네. R2는 계정 ID와 R2 API 토큰의 액세스 키를 씁니다. MinIO와 기타 S3 호환 서비스는 엔드포인트 URL, 리전, 경로 방식 또는 가상 호스트 방식 URL을 씁니다.

Cursor에서도 되나요?

네. Cursor, Windsurf, VSCodium은 Open VSX에서 설치하며, 그곳에는 zovo/zovo-s3-explorer로 게시되어 있습니다.
