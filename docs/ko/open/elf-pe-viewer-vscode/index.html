VS Code에서 ELF, EXE, DLL 파일의 섹션과 임포트 보기

무료 확장 ELF Viewer & PE Viewer를 설치하고 .so, .exe, .dll, .dylib 파일을 클릭합니다. Linux ELF, Windows PE, Apple Mach-O 파일의 헤더, 섹션, 세그먼트, 임포트, 익스포트, 심볼 탭과 hex 보기가 나오며, readelf, objdump, dumpbin이 필요 없습니다. 파일 보기 기능은 모두 무료이고 읽기 전용입니다. Zovo Pro(USD 19, 한 번 결제)는 JSON이나 C 헤더로 내보내기, 두 바이너리 비교, 바이너리 폴더에서 이름 찾기 세 도구를 더하며, 도구마다 3번 무료로 써 볼 수 있습니다.

VS Code에서 하는 방법

  1. Marketplace에서 ELF Viewer & PE Viewer 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.zovo-elf-pe-viewer를 실행합니다.
  2. Explorer에서 .exe, .dll, .sys, .so, .dylib, .elf, .ko 파일을 클릭하면 뷰어로 열립니다. .o 오브젝트 파일이나 확장자가 없는 Linux, macOS 실행 파일은 마우스 오른쪽 버튼으로 클릭하고 Open in ELF & PE Viewer를 고릅니다.
  3. 먼저 Overview 탭이 나옵니다. 아키텍처, 파일 종류, 엔트리 포인트, 링크된 라이브러리, ASLR과 DEP 같은 보안 플래그, 빌드 ID, PDB 경로를 보여 줍니다.
  4. Sections 탭이나 Imports 탭을 엽니다. ELF 임포트는 함수마다 라이브러리와 심볼 버전이 나옵니다. PE 파일에는 데이터 디렉터리, 지연 로드 임포트, 리소스가 더 있고, Mach-O 파일에는 로드 커맨드가 있습니다.
  5. 표 위의 필터 상자에 입력하면 행이 좁혀지고, 열 머리글을 클릭하면 정렬됩니다. Copy rows는 행을 탭으로 구분한 텍스트로 클립보드에 넣습니다.
  6. 섹션이나 세그먼트의 bytes 링크를 누르면 Hex 탭에서 해당 바이트가 표시됩니다. Headers 탭의 Show every header field with its offset은 필드 트리를 엽니다.

무료 기능과 Zovo Pro가 더하는 기능

파일 보기 기능은 로그인 없이 모두 무료입니다. 개요, 모든 표, 필터, 정렬, 복사, hex 보기, 필드 트리가 여기에 들어갑니다. 확장은 바이너리에 쓰지 않고 네트워크를 쓰지 않습니다.

빌드 폴더에서 어떤 바이너리가 특정 함수를 임포트하거나 특정 라이브러리를 링크하는지 알고 싶을 때, 이 도구는 폴더 안 모든 ELF, PE, Mach-O 파일을 읽고 일치하는 항목을 파일과 함께 나열합니다. 일반 텍스트는 이름의 어느 부분과도 일치하고, /regex/도 쓸 수 있습니다. 바이너리를 하나씩 열거나 파일마다 readelf나 dumpbin을 돌리지 않고 검색 한 번으로 답을 얻습니다.

Find a symbol or import in a folder 사용하기 (Zovo Pro)

  1. 바이너리를 열고 뷰어 위쪽의 Find in folder…를 누르거나, Command Palette에서 "ELF & PE Viewer: Find a symbol or import in a folder (Pro)"를 실행합니다.
  2. CreateFileW나 SSL_read 같은 이름, 또는 /^_?pthread_/ 같은 정규식을 입력합니다. 워크스페이스 폴더를 검색하거나, 폴더를 물어봅니다.
  3. 뷰어에서 실행하면 결과가 Copy 버튼이 있는 Find 탭에 열립니다. Command Palette에서 실행하면 목록으로 나오고, 클릭하면 그 바이너리가 열립니다.
  4. Escape를 누르거나 일치하는 항목이 없으면 무료 횟수가 줄지 않습니다.

Find a symbol or import in a folder 기능은 라이선스를 묻기 전에 내 컴퓨터에서 3번 무료로 쓸 수 있습니다. 팝업도 없고 카운트다운도 없습니다.

Cursor, Windsurf, VSCodium에서

  1. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 엽니다.
  2. zovo.zovo-elf-pe-viewer를 검색하고 Install을 누릅니다. Cursor, Windsurf, VSCodium은 Open VSX에서 확장을 설치하며, 이 확장은 그곳에서 zovo/zovo-elf-pe-viewer라는 이름으로 올라가 있습니다.
  3. 에디터에 확장 갤러리가 없으면 Open VSX 페이지에서 .vsix 파일을 내려받고 "Extensions: Install from VSIX..."를 실행합니다.
  4. 그다음은 VS Code에서와 똑같이 동작합니다.

ELF Viewer & PE Viewer의 기능

  • 32비트와 64비트, 리틀 엔디언과 빅 엔디언 ELF 파일. .so, .o, .ko, .elf, .axf, Linux 실행 파일 등.
  • .exe, .dll, .sys, .efi, .pyd 같은 PE32, PE32+ 파일. 이름과 서수(ordinal) 임포트, 포워더가 있는 익스포트, .NET 런타임 헤더도 보여 줍니다.
  • 32비트와 64비트 Mach-O, 유니버설 바이너리. 위쪽에서 arm64나 x86_64 같은 아키텍처를 고릅니다.
  • 행이 100,000개까지인 표. 필터, 정렬, 복사가 됩니다.

할 수 없는 것

  • 읽기 전용이고 디스어셈블 기능은 없습니다.
  • 정적 라이브러리(.a), Java 클래스 파일, WebAssembly, DEX 파일은 읽지 않습니다.
  • 표는 표마다 100,000행에서 멈추고, 읽기는 10초가 지나면 멈춥니다. 그럴 때는 뷰어가 알려 줍니다.
  • 원격 파일 시스템이나 가상 파일 시스템의 파일은 256 MB까지 읽습니다. Find in folder는 로컬 폴더만 검색합니다.
  • .o 파일과 확장자가 없는 파일은 기본으로 열리지 않습니다. 마우스 오른쪽 버튼 메뉴의 Open in ELF & PE Viewer를 쓰세요.

자주 묻는 질문

무료인가요?

파일 보기 기능은 로그인 없이 모두 무료입니다. 세 Pro 도구(JSON이나 C 헤더로 내보내기, 두 바이너리 비교, 폴더에서 이름 찾기)는 각각 3번 무료로 써 볼 수 있습니다. 그다음에는 Zovo Pro가 필요하며, 모든 Zovo 확장에 쓰는 라이선스를 USD 19에 한 번 구매합니다.

readelf, objdump, dumpbin이 필요한가요?

아니요. 확장이 ELF, PE, Mach-O 파일을 직접 읽으므로 다른 프로그램을 설치하지 않아도 됩니다.

바이너리가 바뀌나요?

아니요. 파일을 읽기만 하고 쓰지 않습니다. Pro 내보내기는 직접 고른 곳에 새 JSON 파일이나 헤더 파일을 저장합니다.

Cursor에서도 되나요?

네. README에 Cursor, Windsurf, VSCodium에서 동작한다고 나와 있고, Open VSX에 올라가 있어 이 에디터들에서 설치할 수 있습니다.
