VS Code에서 HTML, JSX, Vue 태그 이름을 자동으로 함께 바꾸기

무료 확장 Auto Rename Tag & Close Tag Sync를 설치하고 여는 태그나 닫는 태그의 이름을 바꿉니다. 입력하는 대로 짝이 되는 태그도 바뀝니다. 이름 바꾸기는 VS Code 자체의 linked editing(editor.linkedEditing) 기능입니다. 확장이 지원하는 언어에서 이 설정을 켜고, HTML, JSX, TSX, Vue, Svelte, Astro, PHP, Blade, Twig, XML, Markdown 등에서 짝이 되는 태그를 찾아 주므로, 되돌리기 한 번이면 두 태그가 함께 돌아옵니다. 이름 바꾸기, 자동 닫기, 짝 태그 상자 표시는 무료이고, Zovo Pro(USD 19, 한 번 결제)는 Rename Tag in All Files와 Check Unclosed Tags in All Files를 더하며, 도구마다 3번 무료로 써 볼 수 있습니다.

VS Code에서 하는 방법

  1. Marketplace에서 Tag Auto Rename & Close Tag Sync 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.zovo-auto-rename-tag를 실행합니다.
  2. HTML, JSX, TSX, Vue, Svelte, PHP나 다른 템플릿 파일을 열고 여는 태그의 이름을 바꿉니다. 닫는 태그가 입력하는 대로 바뀌고, 반대 방향도 됩니다.
  3. 여는 태그 뒤에 >를 입력하면 커서 뒤에 닫는 태그가 생깁니다. </를 입력하면 열려 있는 요소의 이름이 채워집니다.
  4. 태그에 커서를 두면 두 태그에 테마의 괄호 색으로 상자가 그려집니다.
  5. 에디터에서 마우스 오른쪽 버튼을 클릭하면 "Go to Matching Tag"와 "Select Tag Content"가 있습니다. 상자에 새 이름을 입력하려면 Command Palette에서 "Tag Sync: Rename Tag Pair…"를 실행합니다.
  6. 상태 표시줄의 Tags 항목을 클릭하면 이 파일에서 무엇이 켜져 있는지 보거나, 한 언어에서 확장을 끌 수 있습니다. "Tags: rename off"라고 나오면 클릭해서 그 언어의 이름 바꾸기를 켭니다.

무료 기능과 Zovo Pro가 더하는 기능

입력하는 대로 이름 바꾸기, >와 </에서 자동 닫기, 짝 태그 상자, Go to Matching Tag, Select Tag Content, Rename Tag Pair…, 상태 표시줄 메뉴는 무료입니다. 광고가 없고 로그인이 필요 없으며 오프라인에서 동작합니다.

워크스페이스의 모든 태그 파일에서 컴포넌트나 요소 이름을 한 번에 바꿉니다. 예를 들어 모든 .tsx, .vue, .html, 템플릿 파일에서 <Button>을 <UiButton>으로 바꿉니다. 태그 이름만 바뀌고 텍스트, 속성, 문자열, 주석은 바뀌지 않습니다. 먼저 바꿀 개수가 나오고, "Preview first"를 고르면 VS Code의 리팩터링 미리보기가 열리며, Undo 한 번으로 모든 파일이 돌아옵니다.

Rename Tag in All Files 사용하기 (Zovo Pro)

  1. VS Code에서 프로젝트 폴더를 엽니다. 이 도구는 열린 폴더가 있어야 합니다.
  2. Command Palette에서 "Tag Sync: Rename Tag in All Files… (Pro)"를 실행하거나, Explorer에서 .html, .htm, .vue, .jsx, .tsx, .svelte 파일을 마우스 오른쪽 버튼으로 클릭하고 "Zovo Pro: Rename Tag in All Files"를 고릅니다.
  3. 바꿀 태그를 파일에 적힌 그대로 입력하고(예: Button), 이어서 새 이름을 입력합니다.
  4. "Rename"을 고르거나, 리팩터링 미리보기에서 변경을 확인하려면 "Preview first"를 고릅니다. 열려 있지 않던 파일은 바뀌지만 저장되지는 않습니다. File > Save All로 저장하고, Undo로 되돌립니다.

Cursor, Windsurf, VSCodium에서

  1. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 엽니다.
  2. zovo.zovo-auto-rename-tag를 검색하고 Install을 누릅니다. Cursor, Windsurf, VSCodium은 Open VSX에서 확장을 설치하며, 이 확장은 그곳에서 zovo/zovo-auto-rename-tag라는 이름으로 올라가 있습니다.
  3. 에디터에 확장 갤러리가 없으면 Open VSX 페이지에서 .vsix 파일을 내려받고 "Extensions: Install from VSIX..."를 실행합니다.
  4. 그다음은 VS Code에서와 똑같이 동작합니다.

Tag Auto Rename & Close Tag Sync의 기능

  • HTML, JSX와 TSX, Vue, Svelte, Astro, PHP, Blade, Twig, Jinja, Nunjucks, Liquid, ERB, EJS, Handlebars, XML, SVG, Markdown에서 이름 바꾸기.
  • br, img, input, meta, hr 같은 void 태그는 짝을 짓거나 닫지 않습니다.
  • .tsx에서는 실제 JSX만 태그로 봅니다. a < b && c > d 같은 비교와 useState<string>() 같은 제네릭은 건드리지 않고, .ts 파일도 건드리지 않습니다.
  • 주석, 문자열, <script>와 <style> 본문, {{ }}, {% %}, <?php ?>, <% %> 블록은 건너뜁니다.
  • 저장하지 않은 새 파일도 언어가 정해지면 바로 동작합니다.

할 수 없는 것

  • JSX와 TSX에서는 TypeScript가 태그를 직접 닫기 때문에 이 확장은 닫기를 TypeScript에 맡깁니다. TypeScript가 넣은 닫는 태그는 따로 되돌리기 단계가 됩니다.
  • Vue, Svelte, Astro, Red Hat XML 확장이 설치되어 있으면 그 언어에서는 해당 확장이 태그를 닫고 이 확장은 나서지 않습니다.
  • 1 MB 또는 50,000줄이 넘는 파일에서는 실시간 이름 바꾸기, 닫기, 강조가 꺼집니다(설정 zovoTags.maxFileSizeKB, zovoTags.maxFileLines). 상태 표시줄에 그렇게 나오고, 명령은 계속 쓸 수 있습니다.
  • Svelte나 Astro의 {...} 식 안에 쓴 태그는 이름이 바뀌지 않습니다.
  • 예전 Auto Rename Tag나 Auto Close Tag 확장도 켜져 있으면 두 확장이 같은 태그를 고칠 수 있습니다. 하나만 남기세요.

자주 묻는 질문

editor.linkedEditing 설정과 무엇이 다른가요?

이 확장은 이름 바꾸기에 editor.linkedEditing을 씁니다. 지원하는 언어마다 이 설정을 켜고, HTML과 Vue부터 PHP, Twig, XML, JSX까지 각 언어에서 짝이 되는 태그를 찾습니다. 여기에 태그 닫기, 짝 태그 상자, Go to Matching Tag, Select Tag Content를 더합니다. editor.linkedEditing을 직접 꺼 두었다면 상태 표시줄에 "Tags: rename off"가 나오고, 클릭하면 그 언어에서 다시 켜집니다.

되돌리기는 그대로 되나요?

네. 이름 바꾸기가 VS Code의 linked editing을 쓰기 때문에, 직접 고친 내용과 짝 태그의 변경이 되돌리기 한 단계로 묶입니다. 자동 닫기로 생긴 닫는 태그는 입력한 >와 같은 되돌리기 단계에 들어갑니다. 다만 TypeScript가 태그를 닫는 JSX와 TSX는 예외입니다.

무료인가요?

네. 이름 바꾸기, 자동 닫기, 짝 태그 상자, 에디터 명령은 무료입니다. Rename Tag in All Files와 Check Unclosed Tags in All Files는 Zovo Pro 도구로 각각 3번 무료로 써 볼 수 있고, 그다음에는 모든 Zovo 확장에 쓰는 라이선스를 USD 19에 한 번 구매합니다.

Cursor에서도 되나요?

네. Cursor, Windsurf, VSCodium은 Open VSX에서 zovo/zovo-auto-rename-tag로 설치합니다.
