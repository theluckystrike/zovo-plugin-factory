VS Code에서 SQLite 데이터베이스 열기

무료 확장 SQLite Viewer & Editor를 설치하고 .db, .sqlite, .sqlite3 파일을 클릭합니다. 각 테이블이 읽기 전용 표로 열리고, Schema 탭과 SQL 탭은 클릭 한 번이면 됩니다. 아직 -wal 파일에 있는 커밋된 행도 읽습니다. 보기, Enable editing을 누른 뒤의 편집, 백업을 만드는 Save, CSV 가져오기는 무료입니다. Zovo Pro(USD 19, 한 번 결제)는 데이터베이스 비교, ER 다이어그램, 모든 테이블 한 번에 내보내기를 더하며, 도구마다 3번 무료로 써 볼 수 있습니다.

VS Code에서 하는 방법

  1. Marketplace에서 SQLite DB Viewer 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.sqlite-table-viewer를 실행합니다.
  2. Explorer에서 .db, .sqlite, .sqlite3, .db3, .s3db, .sl3, .vscdb, .gpkg 파일을 클릭합니다. 읽기 전용 표로 열립니다.
  3. 왼쪽에서 테이블이나 뷰를 고릅니다. 열 머리글을 클릭하면 정렬되고, 머리글 아래에 입력하면 필터가 걸립니다(예: 5..9, =word). 모든 열을 한 번에 검색할 수도 있습니다.
  4. Schema 탭에서 열, 키, 외래 키, CREATE 문을 보고, SQL 탭에서 문장을 하나씩 실행합니다. 최근 20개 문장이 기록됩니다.
  5. 데이터를 바꾸려면 Enable editing을 누릅니다. 셀을 더블클릭하고 새 값을 입력한 뒤 Enter를 누릅니다. 각 변경은 SQL, Undo와 함께 대기 목록에 쌓입니다.
  6. Save(Ctrl+S, macOS에서는 Cmd+S)를 누릅니다. Save는 제약 조건을 확인하고 name.db.20261109-143000.bak 같은 백업 사본을 만든 다음 파일을 한 번에 교체합니다.

무료 기능과 Zovo Pro가 더하는 기능

열기와 읽기, SQL 탭, 셀과 행 편집, 백업을 만드는 Save, CSV와 TSV 가져오기, 표 도구, 화면에 보이는 행 내보내기는 무료입니다. 계정이 필요 없고 체험 기간 타이머도 없습니다.

이 도구는 데이터베이스의 모든 테이블을 한 번에 씁니다. 테이블마다 시트가 하나씩 있고 머리글 행이 굵게 고정된 Excel 통합 문서(.xlsx) 하나, 또는 테이블마다 CSV 파일이 하나씩 든 폴더로 저장합니다. 무료 Export는 한 테이블에서 화면에 보이는 행만 저장하므로, 이 도구를 쓰면 테이블을 하나씩 내보내지 않아도 됩니다. 데이터베이스는 읽기만 하고 쓰지 않습니다.

  1. 데이터베이스를 연 상태에서 에디터 도구 모음의 DB tools 버튼(작은 PRO 배지가 있음)을 누르거나, 도구 모음 아래 "Pro tools" 줄에서 이 도구를 누릅니다.
  2. Explorer에서 데이터베이스 파일을 마우스 오른쪽 버튼으로 클릭하고 "Zovo Pro: Export All Tables to Excel or CSV"를 고르거나, Command Palette에서 "Export All SQLite Tables to Excel or CSV (Pro)…"를 실행해도 됩니다.
  3. "Excel workbook (.xlsx)" 또는 "CSV files in a folder"를 고르고 저장할 곳을 정합니다. 횟수는 파일이 실제로 써졌을 때만 줄어들고, Escape로 취소하면 줄지 않습니다.

Export All SQLite Tables to Excel or CSV 기능은 라이선스를 묻기 전에 내 컴퓨터에서 3번 무료로 쓸 수 있습니다. 팝업도 없고 카운트다운도 없습니다.

Cursor, Windsurf, VSCodium에서

  1. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 엽니다.
  2. zovo.sqlite-table-viewer를 검색하고 Install을 누릅니다. Cursor, Windsurf, VSCodium은 Open VSX에서 확장을 설치하며, 이 확장은 그곳에서 zovo/sqlite-table-viewer라는 이름으로 올라가 있습니다.
  3. 에디터에 확장 갤러리가 없으면 Open VSX 페이지에서 .vsix 파일을 내려받고 "Extensions: Install from VSIX..."를 실행합니다.
  4. 그다음은 VS Code에서와 똑같이 동작합니다.

SQLite DB Viewer의 기능

  • 아직 -wal 파일에 있는 커밋된 행. 앱이 쓰는 동안 실시간으로 다시 읽습니다(Live 버튼으로 끌 수 있음).
  • 셀 패널에서 JSON 셀은 트리로, 이미지는 그림으로, float32 BLOB은 벡터로 보입니다.
  • CSV, TSV, JSON, INSERT 문으로 복사. 화면에 보이는 행은 CSV, JSON, SQL INSERT 문으로 내보낼 수 있습니다.
  • 새 테이블이나 기존 테이블로 CSV, TSV 가져오기. 미리보기, 열 매핑, 진행률 표시, Cancel이 있습니다.
  • 512 MB까지의 데이터베이스. 행은 한 페이지씩 가져옵니다.

할 수 없는 것

  • 데이터베이스 전체를 메모리에 올립니다. 512 MB가 넘는 파일은 메시지가 나옵니다(설정 sqliteTableViewer.maxFileSizeMB).
  • 편집은 256 MB 이하 파일에서만 됩니다(설정 sqliteTableViewer.editMaxFileSizeMB). 더 큰 파일은 읽기 전용으로 남습니다.
  • 암호화된 데이터베이스(SQLCipher, SEE)는 열 수 없습니다.
  • 편집은 이 컴퓨터에 있는 파일에서만 됩니다. 원격 파일 시스템이나 가상 파일 시스템의 파일은 읽기 전용으로 열립니다.
  • 저장하지 않은 변경은 탭을 닫으면 사라지고, 파일은 그대로 남습니다.

자주 묻는 질문

무료인가요?

열기, 보기, SQL 탭, 편집, Save, CSV 가져오기는 계정 없이 무료로 쓸 수 있습니다. 세 Pro 도구(Compare SQLite Databases, ER Diagram, Export All Tables)는 각각 3번 무료로 써 볼 수 있습니다. 그다음에는 Zovo Pro가 필요하며, 모든 Zovo 확장에 쓰는 라이선스를 USD 19에 한 번 구매합니다.

VS Code에서 행을 편집할 수 있나요?

네. 파일은 읽기 전용으로 열리고, Enable editing을 누르면 셀과 행을 고치거나 INSERT, UPDATE를 실행할 수 있습니다. Save를 누르기 전에는 아무것도 쓰지 않으며, Save는 먼저 백업 사본을 만듭니다.

다른 뷰어에서는 왜 예전 행이 보이나요?

WAL 모드에서는 새 커밋이 체크포인트가 본 파일로 옮길 때까지 -wal 파일에 남아 있습니다. 본 파일만 읽는 뷰어는 이 행을 놓칩니다. 이 확장은 -wal 파일의 커밋된 부분도 읽습니다.

Cursor에서도 되나요?

네. Open VSX에 zovo/sqlite-table-viewer로 올라가 있어 Cursor, Windsurf, VSCodium에서 설치할 수 있습니다.
