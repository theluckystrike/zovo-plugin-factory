한국어 가이드 · Hex Viewer

VS Code의 헥스 에디터

무료 Hex Viewer 확장은 VS Code에서 빈 파일부터 4 GB 디스크 이미지까지 어떤 파일이든 바이트를 보여줍니다. 화면에 보이는 행만 읽기 때문에 테스트에서 4 GB 파일이 0.6초 만에 열렸습니다. 오프셋으로 이동하고, ?? 와일드카드로 바이트를 찾고, 데이터 인스펙터에서 값을 읽고, 바이트를 삽입하고 지우고 되돌리고, 두 파일을 바이트 단위로 비교할 수 있습니다.

VS Code에서 하는 방법

  1. Marketplace에서 Hex Viewer 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.zovo-hex-viewer를 실행합니다.
  2. 탐색기에서 파일을 마우스 오른쪽 버튼으로 클릭하고 "Open in Hex Viewer"를 고릅니다. .bin, .dat, .img, .rom, .dmp, .dump 파일은 클릭만 해도 Hex Viewer로 열립니다.
  3. Ctrl+G(macOS에서는 Cmd+G)로 0x1F40, +0x100, -16, end 같은 오프셋으로 이동합니다. Ctrl+F는 50 4B 03 04 같은 바이트를 찾고, ??는 아무 바이트나 뜻합니다. 텍스트와 UTF-16 텍스트도 찾을 수 있습니다.
  4. 오른쪽 데이터 인스펙터는 커서 위치의 바이트를 8~64비트 정수, 부동소수점, Unix 시간, GUID 등으로 읽습니다. "Little-endian"을 눌러 바이트 순서를 바꿉니다.
  5. 16진수 두 자리를 입력하면 바이트를 덮어씁니다. Insert 키로 삽입 모드로 바꾸면 파일이 길어집니다. Ctrl+Z로 되돌리고 Ctrl+S로 저장합니다.
  6. 두 파일을 비교하려면 탐색기에서 둘 다 선택하고 "Compare in Hex Viewer"를 고릅니다. F7로 다음 차이로 갑니다.

무료 기능과 Zovo Pro

어떤 크기의 파일이든 보기, 오프셋 이동, 검색, Copy as(16진수, C 배열, Python bytes, base64), 데이터 인스펙터, 삽입과 삭제가 되는 편집, 되돌리기, 안전한 저장, 두 파일 비교는 무료이며 앞으로도 무료입니다.

다운로드한 파일이나 펌웨어를 확인할 때, Checksums of File은 파일이나 선택 영역의 CRC-32, Adler-32, MD5, SHA-1, SHA-256, SHA-512를 한 번 읽어 계산합니다. 4 GB 파일도 되고, 파일을 열지 않아도 됩니다. Zovo Pro는 바이너리 템플릿의 중첩 필드(ELF, PE, PNG, ZIP 등), 메모가 달린 북마크, 비교 보고서, 여러 파일에서 찾기, 엔트로피 맵과 바이트 히스토그램도 더합니다.

Checksums of File 사용하기 (Zovo Pro)

  1. 탐색기에서 파일 하나 또는 여러 개를 마우스 오른쪽 버튼으로 클릭하고 Checksums of File을 고릅니다. 파일을 연 상태에서는 데이터 인스펙터 아래의 "Checksums..." 버튼이 선택 영역의 값을 계산합니다.
  2. 값이 목록으로 나옵니다.
  3. 값을 고르면 복사됩니다.

Checksums of File 기능은 라이선스를 묻기 전에 내 컴퓨터에서 3번 쓸 수 있고, 결과를 얻었을 때만 1번으로 셉니다. 파일을 열 때 Pro 안내는 나오지 않습니다.

Cursor, Windsurf, VSCodium에서

이 편집기들은 Open VSX에서 확장을 설치합니다. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 열고 zovo.zovo-hex-viewer를 검색한 뒤 Install을 누릅니다. 그다음은 VS Code와 같습니다.

할 수 없는 것

  • Copy as는 32 MB까지, 붙여넣기는 16 MB까지 됩니다.
  • 원격 또는 가상 파일 시스템의 파일은 256 MB까지 열립니다(설정 hexViewer.maxRemoteMB).
  • 텍스트 파일과 Intel .hex 파일은 그대로 텍스트 편집기에서 열립니다.

자주 묻는 질문

확장이 유료인가요?

아니요. 보기, 편집, 비교는 무료입니다. 체크섬, 템플릿의 중첩 필드, 북마크와 그 밖의 Pro 도구는 Zovo Pro(USD 19 한 번)이며, 각각 3번은 무료로 쓸 수 있습니다.

큰 파일을 저장해도 안전한가요?

네. 크기가 같으면 바뀐 바이트만 씁니다. 크기가 바뀌면 새 사본을 쓴 뒤 바꿔 넣으므로, 디스크가 가득 차도 반쯤 쓰인 파일이 남지 않습니다.

오프라인에서 되나요?

네. 텔레메트리도 네트워크 호출도 없습니다.
