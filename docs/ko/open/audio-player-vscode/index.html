VS Code에서 오디오 파일 재생하기

무료 확장 Audio Player & WAV Player를 설치하고 .wav, .mp3, .flac, .ogg, .opus 파일을 클릭합니다. 채널별 파형, 스펙트로그램, A-B 반복, 음높이를 유지하는 0.25x~2x 재생 속도, LUFS 라우드니스 수치와 함께 파일을 재생합니다. Opus는 확장에 들어 있는 디코더로 재생하고, M4A와 AAC 파일은 ffmpeg가 있으면 클릭 한 번 뒤에 재생됩니다. 재생과 파일 확인은 무료이고, Zovo Pro(USD 19, 한 번 결제)는 Folder Loudness Report와 Normalize Loudness 두 도구를 더하며, 도구마다 3번 무료로 써 볼 수 있습니다.

VS Code에서 하는 방법

  1. Marketplace에서 Audio Player & WAV Player 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.audio-preview-vscode를 실행합니다.
  2. Explorer에서 .wav, .mp3, .flac, .ogg, .opus, .m4a 파일을 클릭합니다. 다른 플레이어가 열리면 파일을 마우스 오른쪽 버튼으로 클릭하고 "Open in Audio Preview"를 고릅니다.
  3. Space로 재생하거나 멈춥니다. 왼쪽, 오른쪽 화살표는 5초씩(Shift를 누르면 1초씩) 이동합니다. 파형을 클릭하면 그 위치로 갑니다.
  4. 파형 위를 끌면 그 구간이 반복됩니다. 재생 위치에서 [와 ]를 눌러 반복 시작과 끝을 정할 수도 있습니다. L로 반복을 켜고 끕니다.
  5. 재생 속도를 0.25x에서 2x 사이로 고릅니다. 음높이는 그대로입니다.
  6. 머리글에서 코덱, 샘플 레이트, 채널, 비트 깊이, 길이, 비트레이트를 읽고, Loudness 패널에서 LUFS, 피크, RMS를, Tags 패널에서 제목, 아티스트, 앨범과 다른 태그를 읽습니다.

무료 기능과 Zovo Pro가 더하는 기능

지원하는 모든 형식의 재생, 파형, 스펙트로그램, A-B 반복, 재생 속도, Loudness, File, Tags 패널, Copy stats는 무료입니다. 오디오 파일에는 아무것도 다시 쓰지 않고, 확장은 네트워크를 쓰지 않습니다.

Folder Loudness Report는 폴더 안 모든 오디오 파일을 한 파일당 CSV 한 행으로 씁니다. 형식, 길이, 샘플 레이트, 비트 깊이, 제목과 아티스트, integrated LUFS, short-term과 momentary 최댓값, 샘플 피크, RMS, 클리핑된 샘플 수, -14, -16, -23 LUFS에 맞추는 데 필요한 게인이 들어갑니다. 파일을 하나씩 열지 않고 스프레드시트에서 녹음 폴더를 정렬하고 확인할 수 있습니다. WAV 파일은 확장이 직접 읽고, MP3, FLAC, Ogg, Opus, M4A 행에는 직접 설치한 ffmpeg가 필요합니다.

Folder Loudness Report 사용하기 (Zovo Pro)

  1. Explorer에서 폴더를 마우스 오른쪽 버튼으로 클릭하고 "Folder Loudness Report (CSV, Pro)"를 고르거나, Command Palette에서 "Audio Preview: Folder Loudness Report (CSV, Pro)"를 실행하고 폴더를 고릅니다. 플레이어에서는 에디터 제목 줄의 "..." 메뉴에도 있습니다.
  2. "This folder and its subfolders" 또는 "This folder only"를 고르고, loudness-report.csv를 저장할 곳을 정합니다.
  3. 진행 상황은 알림에 나오고 취소할 수 있습니다. CSV를 스프레드시트에서 엽니다. 횟수는 파일이 실제로 써졌을 때만 줄어듭니다.

Folder Loudness Report 기능은 라이선스를 묻기 전에 내 컴퓨터에서 3번 무료로 쓸 수 있습니다. 팝업도 없고 카운트다운도 없습니다.

Cursor, Windsurf, VSCodium에서

  1. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 엽니다.
  2. zovo.audio-preview-vscode를 검색하고 Install을 누릅니다. Cursor, Windsurf, VSCodium은 Open VSX에서 확장을 설치하며, 이 확장은 그곳에서 zovo/audio-preview-vscode라는 이름으로 올라가 있습니다.
  3. 에디터에 확장 갤러리가 없으면 Open VSX 페이지에서 .vsix 파일을 내려받고 "Extensions: Install from VSIX..."를 실행합니다.
  4. 그다음은 VS Code에서와 똑같이 동작합니다.

Audio Player & WAV Player의 기능

  • WAV(PCM 8~32비트, float, A-law, mu-law, RF64). 2 MB 단위로 읽어서 큰 파일도 에디터를 멈추지 않습니다.
  • VS Code에 이미 있는 디코더로 MP3, FLAC, Ogg Vorbis.
  • 확장에 들어 있는 libopus 디코더(WebAssembly)로 .opus나 .ogg 안의 Opus.
  • 최대 8채널. 채널마다 파형 줄이 따로 있습니다.
  • ID3v1, ID3v2.2~2.4, RIFF INFO, Vorbis comment, iTunes atom 태그.

할 수 없는 것

  • M4A와 AAC에는 직접 설치한 ffmpeg가 필요합니다. ffmpeg가 없으면 코덱, 길이, 비트레이트, 태그와 함께 메시지가 나옵니다.
  • ALAC, AC-3처럼 VS Code가 디코딩하지 못하는 다른 코덱도 ffmpeg 버튼이 필요합니다.
  • 압축 파일은 통째로 디코딩합니다. 디코딩한 샘플이 600 MB(44.1 kHz 스테레오로 약 28분)를 넘으면 재생만 됩니다(설정 audioPreview.maxDecodedMB).
  • 피크는 오버샘플링한 true peak가 아니라 샘플 피크이고, 라우드니스 범위(LRA)는 없습니다.
  • 파일을 재생하고 확인하는 도구입니다. 자르거나 편집하지 않습니다.

자주 묻는 질문

무료인가요?

재생, 파형, 스펙트로그램, 반복, 라우드니스 수치는 무료입니다. 두 Pro 도구 Folder Loudness Report와 Normalize Loudness는 각각 3번 무료로 써 볼 수 있습니다. 그다음에는 Zovo Pro가 필요하며, 모든 Zovo 확장에 쓰는 라이선스를 USD 19에 한 번 구매합니다.

VS Code에서 .opus 파일이 왜 재생되지 않나요?

VS Code에 들어 있는 Chromium에는 Opus 디코더가 없습니다. 이 확장은 WebAssembly로 컴파일한 libopus를 담고 있어서, 다른 설치 없이 Opus를 재생합니다.

M4A 파일은 왜 재생되지 않고 메시지가 나오나요?

VS Code에는 AAC 디코더도 없습니다. ffmpeg가 설치되어 있으면 Decode with ffmpeg 버튼이 확장의 저장 폴더에 WAV 사본을 만들고 파일이 재생됩니다. 확장에 들어 있거나 내려받는 것은 없습니다.

Cursor에서도 되나요?

네. 이 확장은 Open VSX에 zovo/audio-preview-vscode로 올라가 있어 Cursor, Windsurf, VSCodium에서 설치할 수 있습니다.
