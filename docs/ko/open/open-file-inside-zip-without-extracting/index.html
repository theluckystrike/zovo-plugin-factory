압축을 풀지 않고 ZIP 안의 파일 열기

무료 확장 ZIP Viewer & Archive Explorer를 설치하고 .zip, .jar, .vsix, .tar, .tar.gz, .gz 파일을 클릭합니다. 안에 든 폴더와 파일이 목록으로 나오고, 파일을 더블클릭하면 아카이브에서 바로 읽어 일반 읽기 전용 탭으로 열리므로 아무것도 풀지 않습니다. 둘러보기, 항목 열기, 이름 검색, 압축 풀기는 무료입니다. Zovo Pro(USD 19, 한 번 결제)는 두 아카이브 비교, 항목 목록 내보내기, 폴더 안 모든 아카이브에서 파일 찾기 세 도구를 더하며, 도구마다 3번 무료로 써 볼 수 있습니다.

VS Code에서 하는 방법

  1. Marketplace에서 ZIP Viewer & Archive Explorer 확장을 설치하거나, Ctrl+P(macOS에서는 Cmd+P)를 누르고 ext install zovo.zip-archive-explorer를 실행합니다.
  2. Explorer에서 .zip, .jar, .vsix, .tar, .tar.gz, .tgz, .gz 파일을 클릭합니다. 폴더와 파일이 크기, 압축 크기, 압축률, 날짜와 함께 목록으로 열립니다. .war, .whl, .nupkg, .apk, .epub는 마우스 오른쪽 버튼으로 클릭하고 Open in Archive Explorer를 고릅니다.
  3. 파일을 찾습니다. 폴더를 더블클릭하거나, 위쪽 경로 표시줄을 쓰거나, Backspace로 상위 폴더로 갑니다. 검색 상자에 입력해도 됩니다. *와 ?는 와일드카드로 쓰입니다(예: *.json).
  4. 파일을 더블클릭하거나 Enter를 누르면 일반 탭에 읽기 전용으로 열립니다. 코드는 구문 색이 입혀지고, 이미지는 이미지 미리보기로 열리며, ZIP 안의 ZIP은 또 하나의 아카이브로 열립니다.
  5. Explorer 사이드바의 Archive Explorer 섹션에 연 아카이브가 모두 나옵니다. 여기서 항목을 마우스 오른쪽 버튼으로 클릭하면 Open to the Side, Extract..., Copy Path가 있습니다.
  6. 파일을 고치려면 파일을 선택하고 Extract...를 누릅니다. 파일 하나는 저장 대화 상자로 저장합니다. ..이나 절대 경로가 들어간 이름은 쓰지 않으며, 아카이브 자체는 바뀌지 않습니다.

무료 기능과 Zovo Pro가 더하는 기능

아카이브 둘러보기, 항목을 탭으로 열기, 이름 검색, 사이드바 트리, Copy Path, 압축 풀기는 무료입니다. 확장은 오프라인에서 동작하고, 네트워크를 쓰지 않으며 텔레메트리도 없습니다.

파일 이름은 아는데 어느 빌드, 백업, 릴리스 아카이브에 들었는지 모를 때 아카이브를 하나씩 열면 시간이 오래 걸립니다. Find a file in all archives of a folder는 폴더 아래 모든 ZIP, JAR, WAR, VSIX, TAR, GZ 파일의 항목 이름을 검색해 일치하는 항목을 아카이브, 경로와 함께 나열하고, 고른 항목을 읽기 전용 탭으로 엽니다. 파일은 하나도 쓰지 않습니다.

Find a file in all archives of a folder 사용하기 (Zovo Pro)

  1. Command Palette에서 "Archive Explorer: Find a File in All Archives of a Folder... (Pro)"를 실행하고 검색할 폴더를 고르거나, Explorer에서 폴더를 마우스 오른쪽 버튼으로 클릭하고 "Zovo Pro: Find a file in all archives of a folder"를 고릅니다.
  2. 파일 이름을 입력합니다. *와 ?는 와일드카드로 쓰입니다(예: log4j*.jar, *.properties).
  3. 목록에서 일치하는 항목을 고르면 다른 항목처럼 탭에 읽기 전용으로 열립니다. 횟수는 일치하는 항목이 하나 이상 있을 때만 줄어듭니다.

Find a file in all archives of a folder 기능은 라이선스를 묻기 전에 내 컴퓨터에서 3번 무료로 쓸 수 있습니다. 팝업도 없고 카운트다운도 없습니다.

Cursor, Windsurf, VSCodium에서

  1. Ctrl+Shift+X(macOS에서는 Cmd+Shift+X)로 Extensions 보기를 엽니다.
  2. zovo.zip-archive-explorer를 검색하고 Install을 누릅니다. Cursor, Windsurf, VSCodium은 Open VSX에서 확장을 설치하며, 이 확장은 그곳에서 zovo/zip-archive-explorer라는 이름으로 올라가 있습니다.
  3. 에디터에 확장 갤러리가 없으면 Open VSX 페이지에서 .vsix 파일을 내려받고 "Extensions: Install from VSIX..."를 실행합니다.
  4. 그다음은 VS Code에서와 똑같이 동작합니다.

ZIP Viewer & Archive Explorer의 기능

  • ZIP, JAR, VSIX. Stored와 Deflate 항목, ZIP64, 자동 압축 풀림(self-extracting) 아카이브.
  • TAR(ustar, GNU 긴 이름, pax 헤더), TAR.GZ, TGZ, 단일 GZ 파일.
  • Open in Archive Explorer로 여는 WAR, EAR, WHL, NUPKG, APK, AAR, XPI, EPUB.
  • 항목이 200,000개까지인 아카이브. 디스크에서 필요한 범위만 읽으므로 큰 ZIP도 통째로 불러오지 않습니다.

할 수 없는 것

  • BZIP2, LZMA, Zstandard, Deflate64로 압축된 항목과 암호화된 항목은 목록에는 나오지만 열리지 않습니다.
  • 7z, RAR, XZ, BZ2 파일은 지원하지 않습니다.
  • 항목은 읽기 전용입니다. 고치려면 파일을 풀어서 고치세요.
  • 512 MB가 넘는 항목은 탭으로 열리지 않지만 압축을 풀 수는 있습니다. .tar.gz는 메모리에서 풀며, 기본 한도는 2 GB입니다.

자주 묻는 질문

무료인가요?

아카이브 둘러보기, 항목 열기, 이름 검색, 사이드바 트리, 압축 풀기는 무료입니다. 세 Pro 도구 Compare two archives, Export the entry list, Find a file in all archives of a folder는 각각 3번 무료로 써 볼 수 있습니다. 그다음에는 Zovo Pro가 필요하며, 모든 Zovo 확장에 쓰는 라이선스를 USD 19에 한 번 구매합니다.

파일을 열 때 임시 폴더로 복사되나요?

아니요. 항목은 아카이브에서 읽기 전용 탭으로 바로 읽어 옵니다. 디스크에 파일을 쓰는 것은 Extract뿐입니다.

ZIP 안의 파일을 편집할 수 있나요?

아니요. 항목은 읽기 전용이고 아카이브는 바뀌지 않습니다. 파일을 풀어서 고친 다음 다른 도구로 아카이브를 다시 만드세요.

Cursor에서도 되나요?

네. ZIP Viewer & Archive Explorer는 Open VSX에 올라가 있어 Cursor, Windsurf, VSCodium에서 설치할 수 있습니다.
