Questions

How does the dark mode work?

Each page is drawn, then its colors are turned around so the paper is dark and the text is light. Photos and charts are found on the page and drawn again in their true colors, so a picture never looks like a film negative. The moon button in the viewer switches dark pages off and on, and the paper button gives warm sepia pages.

Is my PDF uploaded anywhere?

No. The page reads the file inside this tab and pdf.js draws it here. The page itself cannot make a network request (connect-src none); the viewer frame can only load its own files from this site, such as fonts and character maps. Open the Network tab of your browser tools and you will see no request that carries your PDF.

Can I search, jump and highlight?

Yes. Find searches the whole PDF and shows the number of matches. The sidebar has the outline (bookmarks) and page thumbnails. Select text and pick a color to highlight it; Copy as Markdown copies all highlights with their page numbers.

Which PDFs does it open?

Any PDF up to 1 GB, including scanned PDFs, PDFs with forms and password-protected PDFs (it asks for the password). Large files open at once, because only the pages on screen are drawn.

Is a PDF with scripts or links safe to open?

PDF scripts never run, and pdf.js runs with eval turned off. Links in the PDF open in a new tab only when you click them, and only web and mail links. A broken or hostile file can at worst show an error.

Does it work offline?

Yes. After the first visit the page keeps a copy of its own files, pdf.js included, so it opens PDFs with no connection.
