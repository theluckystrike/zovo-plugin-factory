    Questions

    Is my mind map uploaded anywhere?

    No. The page reads the file inside this tab. Its Content Security Policy sets connect-src to none, so the page cannot send your map anywhere. A small unzip library (fflate) loads once from cdn.jsdelivr.net at a pinned version, its hash is checked before it runs, and your file is never sent there. Pictures in the map are shown from the file itself.

    Which XMind versions does it open?

    XMind 2020 to 2026 and XMind Zen files, which keep the map in content.json, and XMind 8, XMind 7 and older 3.x files, which keep it in content.xml. FreeMind and Freeplane .mm files and OPML outlines open too. A map saved with a password says so; it cannot be read without XMind.

    Does it show every sheet?

    Yes. A file with 3 sheets shows 3 tabs. Each sheet shows as a map you can drag and zoom, and as an outline with every topic, its notes, labels, markers, links and pictures. Floating topics, summaries and the counts of relationships and boundaries are listed too.

    Can I copy the map as text?

    Yes. Copy as Markdown puts the sheet on the clipboard as a Markdown outline, with labels and notes, ready for an issue, a README or notes.

    Is a hostile or broken file safe to open?

    The reader checks every ZIP entry: entries with unsafe names are refused and named, entries that unpack to more than their limit are stopped, and a damaged map shows a clear message. Titles and notes are written as plain text, never as HTML, and links in the map are shown, not opened.

    Does it work offline?

    Yes. After the first visit the page keeps a copy of its own files and of the pinned unzip library, so it opens maps with no connection.

    What is free and what is Zovo Pro?
