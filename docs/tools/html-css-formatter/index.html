Questions
Is my file uploaded anywhere?
No. The page reads the file inside this tab. Its Content Security Policy sets connect-src to none, so it cannot send your code anywhere, and it loads no library from another site: the formatter is part of the page. Open the Network tab of your browser tools and you will see no request when a file opens.
What does it change?
Indentation, one tag or one CSS declaration per line, spaces around properties and combinators, and runs of blank lines (two line breaks in a row are kept by default). It does not reorder attributes or CSS rules, and the contents of pre and textarea stay exactly as written.
Does it format the CSS and JavaScript inside an HTML page?
Yes. The CSS in style blocks and the JavaScript in script blocks are formatted with the same engine. Standalone .js, .ts, Vue and Svelte files are not formatted by this page or by the extension.
How is the indentation chosen?
Detect from the file looks at the indentation the file already uses, as VS Code does when it opens a file. You can pick 2 spaces, 4 spaces or tabs instead. If you pick a .editorconfig file together with the file, its indent_style, indent_size, end_of_line, insert_final_newline and max_line_length win.
Will formatting break my SCSS or LESS?
Maps and function calls written over several lines keep their layout, and a comment at the end of a line stays on that line. Unusual syntax such as LESS detached rulesets can keep its original spacing.
Does it work offline?
Yes. After the first visit the page keeps a copy of its own files, so it formats with no connection.
