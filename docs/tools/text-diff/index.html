Questions

Are my files uploaded anywhere?

No. The page reads both files inside this tab and compares them there. Its Content Security Policy sets connect-src to none, so the page cannot send your text anywhere. The diff code (jsdiff) loads from cdn.jsdelivr.net at a pinned version, and your browser checks the hash of every file before running it. Your files are never sent there.

How do I compare two files?

Choose both files at once in the file dialog, or drop them on the page together. The older file goes on the left; Swap sides turns it around. You can also open one file, then the other with Open file above the right box, or paste text into either box. The diff updates as you type.

What do the colors mean?

Red lines with a minus sign were removed from the original, green lines with a plus sign were added in the changed text. A changed line shows its old and new version next to each other, with the words that changed marked inside the line. Unchanged lines around each change stay visible, and longer unchanged runs fold into a button that shows them.

Can it ignore whitespace, case or line endings?

Yes. Ignore whitespace treats lines as equal when they differ only in spaces and tabs, Ignore case when they differ only in upper and lower case, and Ignore line endings (on by default) when one file uses CRLF and the other LF. The page says when the line endings differ, and when a file has no newline at the end.

What is in the .patch file?

A unified diff with 3 lines of context around each change, the format of diff -u and git diff. It is made in your browser from the lines you see and goes to your downloads. You can apply it with patch or git apply.

How big can the files be?

Up to 50 MB and a million lines a side. Lines that are the same at the start and the end are skipped before the diff, and the lining up runs in small steps so the tab stays responsive. If two texts differ in too many places to line up within 6 seconds, the page shows the changed middle part as removed and added lines and says so. The view draws the first 20,000 rows; the .patch has every change.

Can it compare Word, Excel, PDF or binary files?

No, this page compares plain text and tells you when a file is binary, Word, Excel or PDF. The free Folder Compare extension for VS Code opens Word files as Markdown, Excel and CSV files as rows and PDF files as text side by side, and shows other files as hex lines around every range of bytes that differs.
