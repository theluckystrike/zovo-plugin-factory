Questions
Is my file uploaded anywhere?
No. The page reads the file inside this tab. Its Content Security Policy sets connect-src to none, so the page cannot send your data anywhere. Apache Arrow JS and the ZSTD decoder load once from cdn.jsdelivr.net at pinned versions, their hashes are checked before they run, and your file is never sent there.
Which files does it open?
Avro object container files (.avro) with the null, deflate, snappy and zstandard codecs, Arrow IPC files (.arrow, .ipc) in file or stream format, and Feather V2 files (.feather) from pandas and pyarrow, uncompressed or with LZ4 or ZSTD. Feather V1, the format from before 2020, gets a short note on how to save it again.
What does it show?
The format, row count, codec or record batches, every column with its type, the nulls and the min and max of number columns, the file metadata (for example the pandas metadata that pyarrow writes), the raw Avro schema, and the first 1,000 rows. Click a column title to sort them.
Are big numbers and dates shown right?
Yes. 64-bit integers above 2^53 stay exact, decimals keep their scale, Avro dates and timestamps (millis, micros and nanos, local or UTC) and Arrow dates and timestamps show as ISO dates, and structs, lists and maps show as JSON.
How big a file can it open?
The page reads the whole file into the tab, so files up to 1.5 GB work on a normal computer. The row count covers the whole file. The free VS Code extension reads only the batch or block you scroll to, so files of any size open there.
Does it work offline?
Yes. After the first visit the page keeps a copy of its own files and of the two pinned libraries, so it opens files with no connection.
