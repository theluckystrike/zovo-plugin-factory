Questions

Is my Word file uploaded anywhere?

No. The page reads the file inside this tab and draws the pages with JavaScript. Its Content Security Policy sets connect-src to none, so the page cannot send your document anywhere. Open the Network tab of your browser tools and you will see no request when a file opens.

Which files does it open?

Word .docx files, including .docm and .dotx, and OpenDocument .odt files, up to 200 MB. Old binary .doc files need the VS Code extension.

Does it keep the layout?

It draws pages with their margins, headers, footers, footnotes, tables, lists and pictures, using docx-preview. Fonts that are not on your computer show in a close match, so line breaks can differ a little from Word. Old EMF and WMF drawings show as empty boxes here; the VS Code extension draws them.

Is a file with macros or links safe to open?

Macros never run. The page removes scripts, frames and embedded objects from the drawn document, rewrites links so that javascript links do nothing, and its policy allows only its own scripts. A file that unpacks to more than 500 MB or 10,000 parts is refused.

Can I read in dark mode?

Yes. The Theme button at the top switches the page and the viewer to dark, and it remembers your choice on this device. The pages of the document stay white like paper, so colors and pictures look the way the author made them.

Does it work offline?

Yes. After the first visit the page keeps a copy of its own files, so it opens Word files with no connection.
