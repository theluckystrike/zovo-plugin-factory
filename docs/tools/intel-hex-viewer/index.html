Questions

Is my firmware uploaded anywhere?

No. The page reads the file inside this tab with JavaScript. Its Content Security Policy sets connect-src to none, so the page cannot send your image anywhere. Open the Network tab of your browser tools and you will see no request when a file opens.

Which records does it read?

Intel HEX types 00 (data), 01 (end of file), 02 and 04 (segment and linear address), 03 and 05 (start address). S-records S0 (header text), S1, S2 and S3 (data with 16, 24 and 32-bit addresses), S5 and S6 (record count), and S7, S8 and S9 (start address). Lowercase hex digits and Windows or Unix line ends both work.

What does it check?

The checksum of every record, that the byte count matches the length, the start code and hex digits, known record types, the end record, the S5 or S6 count against the data records, text after the end record, and bytes written twice, with a note on whether the values differ. Each problem has its line number.

How do I read the memory map?

Records that touch are joined into segments. The bar shows the data in blue and the gaps blank, with long gaps drawn shorter so small blocks stay visible. The table lists the start, end and size of each segment and the gap before it. Click a segment to see its bytes.

What does the data inspector show?

Click a byte in the hex view to read it, and the bytes after it, as unsigned and signed 8, 16, 32 and 64-bit numbers in little and big endian, as a 32-bit float and as ASCII. Gaps show as two dashes in the hex view, and Go to address takes hex like 0x08000000.

Can it convert or compare images?

Not this page. Converting to Intel HEX, S19 or a flat binary, comparing two images and a CRC over a range are Zovo Pro tools in the free Intel HEX Viewer & S-Record Viewer extension for VS Code, with 3 free tries each.

Does it work offline?

Yes. After the first visit the page keeps a copy of its own files, so it opens firmware files with no connection.
