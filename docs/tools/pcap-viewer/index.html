Questions
Is my capture uploaded anywhere?
No. The page reads the file inside this tab. Its Content Security Policy sets connect-src to none, so the page cannot send your capture anywhere, and it loads no library. Host names come only from the capture itself (DNS answers in its packets and pcapng name blocks); nothing is looked up on the network, so opening a capture never sends a DNS query.
Which protocols does it decode?
Ethernet, 802.1Q VLAN, ARP, IPv4, IPv6 with extension headers, ICMP, ICMPv6, TCP with options, UDP, DNS and mDNS, DHCP, HTTP/1.x, TLS records with the Client Hello server name (SNI) and ALPN, and QUIC long headers. Click a layer to light up its bytes, or click a byte to find its field.
Which display filters work?
The common part of the Wireshark display filter syntax: protocols such as tcp, dns, http or tls, addresses (ip.addr == 10.0.0.1, ip.addr == 10.0.0.0/24, ipv6.addr), ports (tcp.port == 443, udp.port in {53 5353}), text (dns.qry.name contains "example", http.host matches "^api"), tls.sni, http.request.method, frame.len > 1000, tcp.flags.syn == 1 and tcp.stream == 3, joined with &&, || and not, with brackets. The box turns green when the filter is valid.
How do I follow a TCP stream?
Double-click a packet, or select it and press Follow stream. The data of that TCP or UDP connection shows in order, client to server in red and server to client in blue, with retransmitted bytes shown once. Statistics lists the protocol hierarchy, conversations and endpoints; click a row to filter on it.
How big a capture can it open?
Up to 2 GB in the tab, and only the rows on screen are decoded, so scrolling stays fast. A .gz capture stops unpacking at 512 MB and says so, which also stops a gzip bomb. A damaged file shows every packet before the damage and says what is wrong and where.
Does it work offline?
Yes. After the first visit the page keeps a copy of its own files, so it opens captures with no connection.
