Questions

Is my code uploaded anywhere?

No. The code stays in this tab. The page colors it and draws the picture with JavaScript, and its Content Security Policy sets connect-src to none, so it cannot send your code anywhere. The coloring library (highlight.js) loads from cdn.jsdelivr.net at a pinned version, and your browser checks its hash before running it. Your code is never sent there.

How do I make a code screenshot?

Paste code into the box, or open a source file. Pick the colors, frame, background and padding, then press Copy PNG to put the picture on your clipboard, or Save PNG or Save SVG to download it. Click a line in the picture to highlight it, Shift+click for a range, and double-click a word to mark it.

Which languages are colored?

The common languages of highlight.js: JavaScript, TypeScript, Python, Java, Kotlin, C, C++, C#, Objective-C, Go, Rust, Swift, Ruby, PHP, Perl, Lua, R, SQL, GraphQL, Bash and shell sessions, JSON, YAML, TOML and INI, HTML and XML, CSS, SCSS, Less, Markdown, Makefile, Diff, Visual Basic .NET and WebAssembly text. The language is picked from the file name or detected from the code, and you can choose it in the list. Other code shows in one color.

PNG or SVG?

PNG is a picture at 1x, 2x, 3x or 4x, good for chats, issues and slides. SVG keeps the code as text, so it is sharp at any size and the text can be selected; a computer without the font shows the next one in the list. A PNG wider or taller than 16,384 pixels is made at a smaller scale, and the page says which.

Can I use my own editor theme and font?

This page has eight color sets, including Dark Modern and Light Modern, and uses the monospace font of your computer. The free Code Screenshot extension for VS Code draws the picture with your own editor theme, token colors, font, ligatures and bracket colors.

Are there limits?

Files up to 5 MB. The picture shows up to 1,000 lines, and lines longer than 1,000 characters are cut with a mark; the page says when that happens. Copying a PNG needs a browser that allows images on the clipboard; if yours does not, use Save PNG.

Is code with HTML or scripts safe to paste?

Yes. The picture is built from text nodes, so code such as a script tag is drawn as text and never runs. Nothing you paste is run.
