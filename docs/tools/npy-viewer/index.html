Questions

Is my file uploaded anywhere?

No. The page reads the file inside this tab with the File API. Its Content Security Policy sets connect-src to none, so the page cannot send your arrays anywhere. One small library (fflate, to unpack compressed .npz files) loads from cdn.jsdelivr.net at a pinned version, and your browser checks its hash before running it. Your file is never sent there.

Which files does it open?

Files written by np.save (.npy format 1.0, 2.0 and 3.0) and by np.savez and np.savez_compressed (.npz, stored or deflated, including ZIP64). Types: bool, int and uint of 8 to 64 bits, float16, float32 and float64, complex64 and complex128, datetime64 and timedelta64, unicode and byte strings, little or big endian, C or Fortran order.

How big an array can it show?

The page has no file size limit of its own. It reads the headers first, then up to 64 MB of the array you click. For a bigger array, the stats, the chart and the first rows cover its first 64 MB, and the page says so. The free NumPy Viewer for VS Code reads every value.

What do the charts show?

The line chart shows the values in file order; when there are more values than pixels, the line is the mean of each pixel column and a light band shows its min and max. The histogram counts values in 40 equal bins. For 2-D and bigger arrays the heatmap shows the last two axes, and a slice box steps through the leading axes, so a stack of images shows one image at a time. Values below and above 0 get a blue and red scale with gray at 0.

Is a .npy file with Python objects safe to open?

Yes. Arrays of Python objects (dtype O) are stored as a pickle, which can run code when numpy loads it with allow_pickle=True. The page never runs a pickle: it lists such an array and says why it shows no values. The header is read as text and never run, and every value is written as plain text, never as HTML.

Does it work offline?

Yes. After the first visit the page keeps a copy of its own files and of the pinned library, so it opens arrays with no connection.
