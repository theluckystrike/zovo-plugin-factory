    Questions
    Is my PDF uploaded anywhere?
    No. The page reads the PDF inside this tab, and pdf.js parses it in a worker that comes from this site. The page's Content Security Policy sets connect-src to none, so it cannot send your file anywhere, and it loads no library from another site. Open the Network tab of your browser tools and you will see no request when you convert a file.
    How does it find headings?
    From the font sizes. The size used for most of the text is the body size, and lines set clearly larger become headings, with up to four levels: the largest size is #, the next ##, and so on. A heading list on the left jumps to each one in the Markdown.
    Does it keep tables?
    Simple ones. When two or more lines in a row split into the same number of columns by wide gaps, they become a Markdown pipe table. Tables without clear gaps between columns come out as paragraphs.
    What happens to headers, footers and page numbers?
    Text that repeats near the top or bottom edge on most pages, such as a running title, and lone page numbers are dropped, so they do not break up the paragraphs. Two-column pages are read left column first.
    Can it convert a scanned PDF?
    No. A scanned PDF holds pictures of pages, not text, and text recognition (OCR) is not part of this tool or the extension. The page tells you when a PDF has little or no text.
    Is this the same converter as the VS Code extension?
    Yes. The page runs the PDF converter of the Convert to Markdown extension with the same pdf.js build, so a PDF gives the same Markdown here and in VS Code. The extension also converts Word, PowerPoint, Excel, CSV, HTML, EPUB, ODT and RTF files.
