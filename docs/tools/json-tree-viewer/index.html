Questions

Is my JSON uploaded anywhere?

No. The page reads the file inside this tab with JavaScript. Its Content Security Policy sets connect-src to none, so the page cannot send your data anywhere. Open the Network tab of your browser tools and you will see no request when a file opens.

How big a file can it open?

Files up to 300 MB. The tree is built only for the parts you open, so a large file shows its first level as soon as it is read. In our test a 74 MB file opened in under a second. Expand all stops at a few thousand nodes so the tab stays quick; use search to reach a value deep in a big file.

Does it keep big numbers exact?

Yes. A 64-bit id such as 18446744073709551615 is shown digit for digit, where JSON.parse would round it, and the page notes how many numbers it kept. This uses the JSON source text access of current Chrome, Edge and Firefox; other browsers say when they cannot.

Can it read JSON with comments?

Yes. JSONC files such as VS Code settings, with // and /* */ comments and trailing commas, open after the comments are skipped, and the page says how many it skipped. JSON Lines files, one value per line, open as an array. For a file that is not valid JSON, the page shows the line and column of the error.

What is the table view?

Click an array of objects, such as the rows of an API response, to see it as a table below the tree: one row per item and one column per key, up to 60 columns. Click a column name to sort it.

What does it do with strings that hold JSON?

A string value that is itself JSON, as in many logs, queues and HAR files, opens as a nested tree under its key, so you can read the payload without copying it out.

Is a hostile file safe to open?

Keys and values are shown as plain text, never as HTML, and nothing from the file runs. Paths are built as text, never as code. Very deep nesting is walked without recursion, so it cannot crash the tab.

Does it work offline?

Yes. After the first visit the page keeps a copy of its own files, so it opens JSON files with no connection.
