Questions

Is my Parquet file uploaded anywhere?

No. The page reads the file inside this tab, and only the parts it needs: the footer with the schema, then the column chunks that hold the first rows. Its Content Security Policy sets connect-src to none, so the page cannot send your data anywhere. The Parquet reader (hyparquet) loads from cdn.jsdelivr.net at a pinned version, and your browser checks the hash of every file before running it. Your file is never sent there.

Which files does it open?

Apache Parquet files of any size from pandas, pyarrow, Spark, DuckDB, Polars and other writers, with snappy, gzip, zstd, brotli, lz4 or no compression, and data page v1 or v2. Files compressed with LZO and encrypted files are not read; the page says so.

Why only the first 1,000 rows?

The page is for a quick look: what the columns are and what the data looks like. It reads only the row groups that hold the first 1,000 rows, so a file of many GB opens about as fast as a small one. The free XLSX Viewer & Excel Viewer extension for VS Code opens up to 1,000,000 rows with filter, sort and SQL.

What does the schema show?

Every column and nested field as a tree, with its physical type, its logical type (such as STRING, TIMESTAMP with its unit, DECIMAL with precision and scale, LIST or MAP) and whether it is required, optional or repeated. Above it: the row count, row groups, compression, encodings, the writer and the keys of the key-value metadata, where pandas and Spark keep their own schema.

How are values shown?

Timestamps as ISO 8601 in UTC, INT64 values exactly with no rounding, nested lists, maps and structs as JSON, and binary values as hex. Empty values show as null. Every value is written as plain text, never as HTML. Click a column name to sort the rows on the page.

Can I save the rows?

Yes. Save rows as CSV writes the rows on the page, in the order you sorted them, to a CSV file. It is made in your browser and goes to your downloads.

Does it work offline?

Yes. After the first visit the page keeps a copy of its own files and of the pinned Parquet reader, so it opens files with no connection.
