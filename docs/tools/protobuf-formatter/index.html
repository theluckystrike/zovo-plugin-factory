Questions
Is my file uploaded anywhere?
No. The page reads your .proto files inside this tab. Its Content Security Policy sets connect-src to none, so it cannot send them anywhere, and it loads no library from another site. Open the Network tab of your browser tools and you will see no request when a file opens.
What does the formatter change?
Only spaces, line breaks and indentation: one statement per line, the indentation you pick, { on the same line, single spaces around =, no spaces inside brackets, and at most one blank line where the file had blank lines. Every comment stays in its place. Long statements keep your own line breaks, and = is not aligned in columns. Changed lines are marked.
Why is my file not formatted?
The formatter only touches a file that parses, so a broken file is never made worse. The page names the line of the first syntax error. Fix it, open the file again, and it formats.
Which errors does it find?
The ones protoc reports, with its wording: syntax errors, duplicate field numbers (with the next free number), reserved numbers and names, numbers out of range, unknown types and types used without their import, proto3 rules (first enum value 0, no required, no defaults), editions rules, enum aliases, map keys, oneof labels and extension ranges. Unused imports are listed too.
Why does it say an import was not found?
Pick the imported file together with the one that uses it, or pick the folder that holds them all. Until then the page does not guess about the types that import would bring, so you see no false errors. The well-known google/protobuf types are built in.
Does it work offline?
Yes. After the first visit the page keeps a copy of its own files, so it formats and checks .proto files with no connection.
