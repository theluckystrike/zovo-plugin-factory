Questions

Is my diagram uploaded anywhere?

No. Mermaid draws the diagram inside this tab. The Content Security Policy of the page sets connect-src to none, and the preview frame can only load its own files from this site. Your code is kept in this browser only (local storage), so it is still there when you come back.

Is this the official Mermaid Live Editor?

No. The official Mermaid Live Editor is mermaid.live, made by the Mermaid team. This is a separate free editor made by Zovo with the same open source Mermaid library (version 12.3), and the same preview as the Mermaid Viewer extension for VS Code. It needs no account and works offline.

Which diagrams can I draw?

The diagram types of Mermaid 12.3, among them flowchart, sequence, class, state, entity relationship, Gantt, pie, mind map, timeline, git graph, C4, Sankey, XY chart, block and architecture diagrams. The Example menu has a working start for each of those 15.

How do I save the diagram as PNG or SVG?

Click Export in the preview. Save PNG at 1x, 2x or 4x or an exact width, Save SVG, or copy either one. Text labels for wikis draws labels as SVG text, for Azure DevOps and other tools that drop HTML labels. Save .mmd saves the code itself.

How does Copy link work?

It packs your code (compressed) into the part of the link after the # sign. Browsers never send that part to a server, so the link works without any server storing your diagram. Anyone who opens the link sees the code in their own browser.

Can I open Markdown files with mermaid blocks?

Yes. Open a .md file and every ```mermaid block is drawn, with a list to switch between them. The preview has zoom, pan, fit and light or dark themes, and an error shows the line it is on.
