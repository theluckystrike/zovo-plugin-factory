Questions

Is my file uploaded anywhere?

No. The page reads the file with the File API inside this tab. Its Content Security Policy sets connect-src to none, so the page cannot send a request with your data even by mistake. You can check it yourself in the Network tab of your browser tools: opening a file adds no request.

How big a file can it open?

There is no size limit of its own. The page reads only the rows on screen, in 64 KB blocks, so a 50 MB file opens as fast as a small one. Find scans the whole file in 4 MB steps in a background worker and shows its progress.

Which formats does the structure view know?

PNG, JPEG, GIF, BMP, ICO, TIFF, WebP, WAV, FLAC, MP4, ZIP, gzip, TAR, PDF, SQLite, ELF, PE (EXE and DLL), Mach-O, Java class, PCAP, UF2, device tree blobs, uImage, Android boot.img, WebAssembly and DEX. The format is found from the first bytes, not the file name. Click a field to select its bytes.

Can I edit the bytes?

This page only views. The free Hex Viewer extension for VS Code and Cursor edits, inserts and deletes bytes, with undo, and saves large files without loading them whole.

Does it work offline?

Yes. After the first visit the page keeps a copy of its own files, so it opens and works with no connection.

Is a hostile or broken file safe to open?

The page writes file content as plain text, never as HTML, and its policy allows only its own scripts. Templates are data read with limits on fields, depth and time, and they run in a separate worker that stops after 10 seconds.
