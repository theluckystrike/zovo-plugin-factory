Questions

Is my schema uploaded anywhere?

No. The page reads the file inside this tab and draws the diagram with JavaScript. Its Content Security Policy sets connect-src to none, so the page cannot send your schema anywhere. Open the Network tab of your browser tools and you will see no request when a file opens.

Which DBML does it read?

Tables with schema names, aliases, header colors and notes; columns with types and settings (pk, increment, not null, unique, default, note and inline ref); indexes, including composite and primary key indexes; enums; Ref lines and Ref blocks with >, <, - and <>, composite refs and options such as delete: cascade; TableGroups with colors; sticky notes; and the Project block.

Can it draw an ER diagram from SQL?

Yes. Open a .sql file with CREATE TABLE statements from PostgreSQL, MySQL, SQL Server or SQLite. The page reads columns, primary keys, unique keys, REFERENCES on a column, FOREIGN KEY constraints, ALTER TABLE ... ADD FOREIGN KEY, CREATE INDEX and Postgres CREATE TYPE ... AS ENUM. Views, functions and triggers are skipped.

How is the diagram laid out?

Tables that other tables point to sit on the left, and the tables that point to them sit to their right, so a ref usually runs left to right. Tables of the same TableGroup stay together inside a shaded box. Each ref shows 1 or * at its ends. Click a table to light up its refs and see its columns, indexes and refs below the diagram, and use Find to jump to a table or column.

What do the checks find?

Refs to a table or column that is not defined, tables and columns defined twice, TableGroups that name a missing table, refs between columns of different types, and tables with no primary key. Each one names its line.

Can I export the diagram or the SQL?

Not from this page. The free DBML Viewer & ER Diagram extension for VS Code has Copy SVG. Exporting CREATE TABLE scripts, a high-resolution PNG, SVG or PDF and a schema diff with migration SQL are Zovo Pro tools there, with 3 free tries each.

Does it work offline?

Yes. After the first visit the page keeps a copy of its own files, so it draws diagrams with no connection.
