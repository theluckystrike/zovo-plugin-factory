    Questions

    Is my diagram uploaded anywhere?

    No. The page reads the file inside this tab. Its Content Security Policy sets connect-src to none, so it cannot send your text to a PlantUML server or anywhere else, and it loads no library from another site. Open the Network tab of your browser tools and you will see no request when a file opens.

    Does it draw the diagram like PlantUML?

    No. PlantUML is a Java program, and this page does not run it. It draws a simple sketch of sequence diagrams (participants, messages and alt, loop or else rows) and lists the elements and links of every other diagram. The free PlantUML Viewer extension draws the real diagram on your computer with the bundled PlantUML jar.

    How does it find the diagrams?

    With the PlantUML Viewer extension's own code: every @startX to @endX block of a .puml file, a file with no @start line as one diagram, and plantuml, puml and uml code blocks in Markdown, with or without @startuml inside.

    What do the checks find?

    A diagram with no @end line, a second @startuml before the first one is closed, an @enduml with no @start above it, a plantuml code block that is never closed, an include or theme line that points to a web address, a Ditaa or math block, an empty diagram, and participants used in a message but not declared.

    Why is an include from a web address flagged?

    The extension refuses includes from web addresses and reads only local files and the standard library inside the PlantUML jar. C4, AWS icon and icon-font includes written as raw.githubusercontent.com addresses are read from that built-in copy, so the page does not flag those.

    Can I take one diagram out of a Markdown file?

    Yes. Pick it in the list, then use Save as .puml or Copy diagram text. A code block without @startuml is saved with @startuml and @enduml added.
