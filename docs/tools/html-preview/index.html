    Questions
    Is my HTML file uploaded anywhere?
    No. The page reads your files inside this tab. Its Content Security Policy sets connect-src to none, so it cannot send them anywhere. Open the Network tab of your browser tools and you will see no request when a page opens.
    Why do my CSS and images not show?
    A browser page can only read the files you give it. Open the whole folder (drop it, or use Add the page's folder), or add the CSS, image and font files with Add CSS and image files. Linked stylesheets, @import, CSS url(), img, srcset, picture, video posters and local frames are then read from your files. The Linked files tab lists every reference and whether it was found.
    Does it load fonts, scripts or images from the web?
    No. Web addresses such as a Google Fonts or CDN link are listed, with their hosts, and never loaded, so the preview makes no request to any site. The preview frame has its own Content Security Policy with no web sources at all, on top of the policy of this page.
    Do scripts run?
    No. The page is shown in a sandboxed frame with scripts off, so you see it as it looks without JavaScript, and nothing in the file can run in your browser. Forms are not sent and links stay inside the preview. The free VS Code extension runs scripts in a sandboxed frame and shows a console.
    What does the Structure tab show?
    The title, language, charset, viewport, meta description with its length, canonical link, Open Graph tags and doctype, the heading outline from h1 to h6, and counts of links, images and images without alt text, scripts, stylesheets, forms, frames and repeated ids. The Source tab shows the file with line numbers.
    Can I check phone and tablet widths?
    Yes. The Width list sets 1440, 1024, 768, 375 or 320 pixels, so you can see how the page reflows and whether the viewport meta tag is set.
    Does it work offline?
    Yes. After the first visit the page keeps a copy of its own files, so it works with no connection.
