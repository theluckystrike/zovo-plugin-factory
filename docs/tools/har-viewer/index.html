Questions

Is my HAR file uploaded anywhere?

No. The page reads the file inside this tab. Its Content Security Policy sets connect-src to none, so the page cannot send your capture anywhere, and it loads no library. A HAR often holds cookies and tokens, so this matters: open the Network tab of your browser tools and you will see no request when a file opens.

How do I save a HAR file?

In Chrome, Edge or Firefox open DevTools, go to the Network tab, reload the page and choose Save all as HAR (the download arrow in Chrome). Safari calls it Export HAR. Then drop the file here.

What does the waterfall show?

One bar per request on a shared timeline that starts with the first request. The bar is split into blocked, DNS, connect, TLS, send, waiting and download, from the timings in the file. Click a row and the Timing tab gives the numbers.

What counts as failed or slow?

Failed means a status of 400 or more, or no response at all (cancelled or refused). Slow means the request took more than 1 second. The summary counts both, and the status list filters to them.

Does it warn about secrets?

Yes. When the capture holds Authorization or API key headers, cookie headers, or tokens in URLs or bodies, a banner says how many. The page never changes your file. The free VS Code extension writes a redacted copy with those values replaced.

Does it work offline?

Yes. After the first visit the page keeps a copy of its own files, so it opens HAR files with no connection.
