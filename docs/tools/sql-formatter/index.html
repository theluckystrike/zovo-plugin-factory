Questions

Is my SQL uploaded anywhere?

No. The page reads the file or the text you paste inside this tab and formats it in a background worker of the page. Its Content Security Policy sets connect-src to none, so the page cannot send your SQL anywhere. Open the Network tab of your browser tools and you will see no request when you format.

Can it break my SQL?

It is built not to. Strings, quoted names and $$ bodies are set aside before formatting and put back after it, and then the result is compared with your SQL token by token. If anything other than whitespace or keyword case would change, the page shows your text unchanged and names the line. Format the rest then formats every statement it can read and keeps the others exactly as written.

Which dialects does it know?

Standard SQL, PostgreSQL, MySQL, MariaDB, T-SQL (SQL Server), Oracle PL/SQL, SQLite, BigQuery, Snowflake, Amazon Redshift, Spark SQL, Hive, IBM Db2, Db2 for i, DuckDB, Trino, Couchbase N1QL, SingleStore, TiDB and ClickHouse. Auto picks one from the file name and from hints in the text, such as $$ bodies, DELIMITER lines, GO lines or PRAGMA.

What happens to DELIMITER, GO and psql lines?

They are kept byte for byte. MySQL DELIMITER sections, T-SQL GO batches, the Oracle / line and SQL*Plus commands, psql backslash commands and COPY ... FROM stdin rows are left as they are, and each statement between them is formatted on its own.

Does it indent stored procedures?

Yes. Procedures, functions, triggers and PL/SQL packages are indented by block, with BEGIN and END, IF and ELSE, loops, DECLARE and EXCEPTION. Turn off Indent procedures by block to format them as plain statements.

What does the statement list show?

Every statement with its first line, its kind (such as SELECT, INSERT, CREATE TABLE or CREATE FUNCTION) and the tables it names after FROM, JOIN, INTO, UPDATE and TABLE, plus whether it was formatted. Click a row to jump to its line in your SQL.

Does it work offline?

Yes. After the first visit the page keeps a copy of its own files, so it formats SQL with no connection.
