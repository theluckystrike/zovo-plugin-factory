Questions

Is my map file uploaded anywhere?

No. The page reads the file inside this tab, in 4 MB steps in a background worker. Its Content Security Policy sets connect-src to none, so the page cannot send your map anywhere. Open the Network tab of your browser tools and you will see no request when a map opens.

Which linkers does it read?

GNU ld (gcc, arm-none-eabi-gcc, ESP-IDF, Zephyr, the Raspberry Pi Pico SDK, STM32CubeIDE, avr-gcc, RISC-V), LLVM lld (clang and Rust embedded), IAR ILINK 7.x and 8.x, and Arm Compiler armlink 5 and 6 from Keil. The format is found from the first lines of the file. A .js.map source map is recognized and refused.

Do the numbers match the linker?

For GNU ld maps the region totals equal what ld prints with its print-memory-usage option. Discarded input sections get their own tab and are never counted in a region. GNU ld maps list global symbols without sizes, so a size marked ~ runs from the symbol to the next one in the same input section.

My lld or Rust map shows no memory regions. Why?

lld maps do not list the MEMORY block. Click Add a linker script and pick the memory.x or .ld file of the build: the page reads its MEMORY block and draws the region bars. You can also drop both files at once.

How do I make my linker write a map?

With gcc or clang add -Wl,-Map=firmware.map to the link step (add the cref option too for the list of files that use each symbol). With CMake use target_link_options(app PRIVATE -Wl,-Map=firmware.map). IAR and Keil have a map option in the linker settings. ESP-IDF, Zephyr, the Pico SDK and PlatformIO already write one into the build folder.

How big a map can it open?

There is no size limit of its own. The map is read in slices and parsed line by line in a worker, and the table shows 500 rows at a time with Show more rows, so a map of many MB with a million symbols does not freeze the tab.

Does it work offline?

Yes. After the first visit the page keeps a copy of its own files, so it opens maps with no connection.
