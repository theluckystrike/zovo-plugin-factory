    Questions

    Is my text uploaded anywhere?

    No. The page tests the pattern inside this tab, and a file you load is read with the File API. Its Content Security Policy sets connect-src to none, so the page cannot send your text anywhere. Open the Network tab of your browser tools and you will see no request while you test.

    Which regex flavor does it use?

    JavaScript, the engine built into your browser, with the flags d, g, i, m, s, u, v and y, named groups, lookbehind and Unicode property escapes. Python, Java, .NET, Go and PCRE differ in places, for example in lookbehind and possessive quantifiers. The Regex Preview & Regex Tester extension for VS Code lists those differences for the flavor you pick.

    How do the groups and replace work?

    Each match is a row, and each group in ( ) is a column, numbered in the order its ( appears. Named groups (?<name>...) show their name too, and a dash marks a group that did not take part in that match. In the replace box, $1 or $<name> puts a group back and $& the whole match, as in String.replace.

    What if my pattern hangs?

    The pattern runs in a background worker. If it takes more than 2 seconds, the page stops it and says so, so the tab never freezes. That is often a sign of catastrophic backtracking, such as (a+)+ on a long line with no match.

    How much text can I test?

    Files up to 20 MB. Matches are counted in the whole text, the table lists the first 5,000, and the highlight view shows the first 400,000 characters.

    Does it work offline?

    Yes. After the first visit the page keeps a copy of its own files, so it works with no connection.
