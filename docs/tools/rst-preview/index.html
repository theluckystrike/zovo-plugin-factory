      Questions

      Is my file uploaded anywhere?

      No. The page reads the file inside this tab and renders it with JavaScript. Its Content Security Policy sets connect-src to none, so the page cannot send your text anywhere. Open the Network tab of your browser tools and you will see no request when a file opens.

      What does the preview render?

      Section titles with any underline and overline style, paragraphs and inline markup, bullet, numbered (1, a, i, I), definition, field and option lists, literal blocks after ::, grid tables with row and column spans, simple tables, csv-table and list-table, admonitions such as note and warning, footnotes, citations, substitutions, line blocks, the contents directive and code blocks with :caption:, :linenos: and :emphasize-lines:.

      Which problems does it find?

      A title underline or overline that is too short, a title level that skips a level, a link to a target name that is not defined, an undefined substitution, a grid or simple table whose borders do not line up, and a directive type it does not know. Each one is listed with its line number; click it to jump there in the preview or in the source view.

      Does it work with Sphinx files?

      Yes, for reading. toctree entries show as a list, autodoc directives such as automodule show as labelled boxes, Python object descriptions show their signature, and roles such as :ref:, :doc: and :py:func: show as links or code. Text that Sphinx makes from your Python code is not there, because no Python runs.

      Why are pictures and math shown as boxes?

      The page reads only the file you open, never other files on your computer, so a picture or an include is a labelled box with its path. Math is shown as its LaTeX source. The free VS Code extension shows local pictures and includes from your workspace and draws math with KaTeX.

      Can I save the result?

      Save as HTML writes one HTML file of the rendered page, with its styles inside and no scripts, that opens in any browser. It is made in this tab and goes to your downloads.

      Is a hostile file safe to open?

      All file text is escaped before it is shown, links can only point to http, https, mailto or an anchor on the page, raw HTML blocks are shown as text and never run, and the page loads nothing from the network.
