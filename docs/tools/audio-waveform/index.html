Questions

Is my audio uploaded anywhere?

No. The page reads the file inside this tab. Its Content Security Policy sets connect-src to none, so the page cannot send your audio anywhere, and it loads no library. The player plays the file from your own computer. Open the Network tab of your browser tools and you will see no request when a file opens.

How is the loudness measured?

With ITU-R BS.1770-4: K-weighting, 400 ms blocks every 100 ms, an absolute gate at -70 LUFS and a relative gate 10 LU below. The page shows integrated loudness, the highest short-term (3 s) and momentary (400 ms) values and the loudness range. On the extension's test files it gives the same numbers as ffmpeg's ebur128 filter.

What else does it show?

Codec, sample rate, channels, bit depth, duration and bitrate, the sample peak, RMS, DC offset and clipped samples of each channel, a waveform per channel, a spectrogram on a log frequency scale, and the tags from ID3v1 and v2, RIFF INFO, FLAC and Ogg comments, plus the FLAC MD5 and the Opus pre-skip.

How do I loop a part?

Drag across the waveform and that part plays in a loop. Click the waveform to seek and clear the loop. Space plays and pauses, the arrow keys jump 5 seconds (1 with Shift), and Speed plays from 0.25x to 2x with the pitch kept.

Which files does it open?

WAV files are read by the page itself: PCM from 8 to 32-bit, 32 and 64-bit float, A-law, mu-law, extensible and RF64. MP3, FLAC, Ogg Vorbis, Opus and M4A are decoded by your browser, so they play and get a loudness reading in any current Chrome, Edge, Firefox or Safari.

How big a file can it open?

The waveform and loudness need all the samples in memory, so the page reads WAV files up to 600 MB of samples and packed files up to 150 MB. A bigger file still plays and shows its header. The free VS Code extension reads big WAV files in chunks.
