Questions

Is my file uploaded anywhere?

No. The page reads the file inside this tab and draws the map on a canvas. There is no basemap and no tile server, so it loads nothing for the map at all. Its Content Security Policy sets connect-src to none, so the page cannot send your data anywhere. Open the Network tab of your browser tools and you will see no request when a file opens.

Why is there no street map behind my data?

A street basemap would mean loading tiles from a server while your file is open, and that server would see which area you look at. This page draws your features on a plain background with a latitude and longitude grid and a scale bar instead. The VS Code extension ships an offline basemap of countries and lakes.

Which files does it open?

GeoJSON (FeatureCollection, Feature, bare geometries and newline-delimited GeoJSON), TopoJSON with one layer per object, KML with folders, styles, MultiGeometry and gx:Track, GPX tracks, routes and waypoints, WKT with one geometry per line (EWKT SRID prefixes are read), and CSV or TSV with lat and lon, latitude and longitude or y and x columns, or a WKT column. Shapefiles and KMZ need the VS Code extension.

What about coordinates in metres?

Web Mercator metres (EPSG:3857) are found from the GeoJSON crs member, an EWKT SRID or the size of the numbers, and are shown as longitude and latitude. Other projected coordinates are drawn as flat x and y with no grid. The VS Code extension reprojects them from a .prj file or an EPSG code.

What does a GPX file show?

Each track, route and waypoint on the map, and for the tracks: distance, duration, moving time (time spent faster than 1 km/h), moving speed, elevation gain and loss, the lowest and highest point, and an elevation profile. Distance is measured on the globe between the track points.

How do I find one feature?

Click it on the map, or type in the filter box above the table. The filter searches every property value, and Zoom to rows fits the map to the matches. Click a row to zoom to that feature and see all its properties. Copy GeoJSON puts one feature on the clipboard.

Is a hostile file safe to open?

Property values and names are written as plain text, never as HTML. KML and GPX are read with the DOCTYPE removed first, so an entity bomb cannot expand, and KML network links, icons and overlay pictures are never loaded; the page says how many there were. Broken coordinates are left out and counted.
