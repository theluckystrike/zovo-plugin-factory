Questions

Is my spec uploaded anywhere?

No. The page reads the file inside this tab. Its Content Security Policy sets connect-src to none, so the page cannot send your spec anywhere. The YAML reader (js-yaml) loads once from cdn.jsdelivr.net at a pinned version, and its hash is checked before it runs; your file is never sent there. The page makes no request when a spec opens.

Which specs does it read?

OpenAPI 3.0 and 3.1 and Swagger 2.0, in YAML or JSON, with webhooks, callbacks, security schemes, servers and tags. YAML anchors and aliases work. A file with no openapi or swagger field, such as AsyncAPI, gets a clear message.

What does it show for an operation?

The method and path, summary, description, operationId, tags, security and deprecation, then every parameter with where it goes, whether it is required and its type, the request body for each media type, and each response with its schema as a table of properties. $ref to schemas, parameters and responses inside the file are resolved, and circular schemas stop at the repeat.

What does the lint check?

That info has a title and version, servers are listed, every operation has a unique operationId, a summary or description and a success response, path parameters match the path template, every $ref inside the file points to something, and component schemas are used. It is a short readable check, not a full ruleset; the Swagger Editor & OpenAPI extension for VS Code lints as you type, with quick fixes.

Can I try the API from here?

No. This page never sends a request, so it cannot call your API. The free Swagger Editor & OpenAPI extension has a Swagger UI preview with Try it out, which sends a request only when you click Send.

Is a hostile spec safe to open?

Descriptions are shown as plain text, never as HTML or Markdown, and nothing in the spec runs. js-yaml builds plain data only. Only http and https links are clickable. Shared YAML aliases, such as a billion laughs file, are walked once, so they cannot freeze the tab, and refs to other files or URLs are never fetched.

Does it work offline?

Yes. After the first visit the page keeps a copy of its own files and of the pinned YAML reader, so it opens specs with no connection.
