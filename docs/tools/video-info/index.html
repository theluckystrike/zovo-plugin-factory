Questions
Is my video uploaded anywhere?
No. The page reads the file inside this tab. Its Content Security Policy sets connect-src to none, so the page cannot send your video anywhere, and it loads no library. The player plays the file from your own computer. Open the Network tab of your browser tools and you will see no request when a file opens.
What does it show?
The container and its brands, duration, file size and overall bitrate, and for each track the codec with its profile (such as H.264 High @ L4 or AAC-LC), resolution, frame rate, frame count and keyframes, sample rate, channels, bitrate, language and name. It also lists metadata stored in the file, such as the encoder, the creation date and, for phone videos, the camera model and location.
How big a video can it read?
Any size. The page jumps from box to box with File.slice and reads only the header parts, never the picture and sound data. A video whose moov header sits at the end, as many cameras write it, is read just as fast, and the page tells you where the header is.
Why does a video play here but not in VS Code?
Your browser has the AAC sound decoder and VS Code does not, so an MP4 can play here with sound and play silent in VS Code. The free Video Preview with Sound extension carries its own decoder, so the sound plays there too.
Why does a file show its facts but not play?
The facts come from the file itself, so they work for every codec. Playback uses the codecs of your browser, so ProRes, MPEG-4 Part 2 and most AVI files do not play in a browser. The VS Code extension converts them with your ffmpeg.
Can I save a frame?
Yes. Pause, step with the Frame buttons and press Save frame as PNG. The PNG has the full size of the video and its name holds the time. Frame steps use the frame rate of the file, so they match frame numbers in most videos.
