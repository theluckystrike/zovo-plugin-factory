Questions

Is my drawing uploaded anywhere?

No. The page reads the file inside this tab, and the DXF reader of the DXF Viewer extension parses it in a background worker of the page. The Content Security Policy sets connect-src to none, and the worker has no network functions. Open the Network tab of your browser tools and you will see no request when a drawing opens.

Which DXF files does it open?

ASCII and binary DXF files from AutoCAD R12 up to the current versions, from AutoCAD, LibreCAD, QCAD, FreeCAD, Inkscape, laser and CNC tools, up to 500 MB. Lines, polylines, arcs, circles, ellipses, splines, text, MTEXT, dimensions, hatches, blocks and inserts are drawn.

Can it open DWG files?

No. DWG is a closed binary format, and there is no open reader for it under a free license. Save or export the drawing as DXF in your CAD program (Save As, then a DXF type), or turn a folder of DWG files into DXF with the free ODA File Converter, then open the .dxf here.

Can I measure and find text?

Yes. Measure gives the distance and angle between two points, with snapping to ends and centres. Find text searches all text and MTEXT in the drawing and steps through the matches. Layers can be switched on and off, and paper space sheets have their own tabs.

Can I save the drawing as an image?

Yes. Export PNG and Export SVG save the current view, with the layers you have on, to your downloads. The DXF file itself is never changed.

Does it work offline?

Yes. After the first visit the page keeps a copy of its own files, so it opens drawings with no connection.
