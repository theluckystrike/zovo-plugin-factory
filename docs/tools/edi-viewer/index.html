Questions

Is my EDI file uploaded anywhere?

No. The page reads the file inside this tab with JavaScript. Its Content Security Policy sets connect-src to none, so the page cannot send your orders or invoices anywhere. Open the Network tab of your browser tools and you will see no request when a file opens.

Which EDI files does it read?

ANSI X12 files that start with ISA, such as 850 orders, 810 invoices, 856 ship notices, 837 and 835 health care claims and payments and 997 acknowledgments, and UN/EDIFACT files that start with UNA or UNB, such as ORDERS, INVOIC, DESADV and PRICAT. The separators come from the ISA segment or the UNA segment, and EDIFACT release characters such as ?+ are handled.

What do the element names and meanings cover?

Names for the envelope segments and for about 90 common segments of X12 005010 and EDIFACT D.96A to D.01B, and the meaning of frequent codes such as N101 BY (buying party), DTM 137 (document date) or QTY 21 (ordered quantity). Elements the page does not know still show their position, such as BEG03 or NAD02-1, and their value.

What does it check?

That ISA13 matches IEA02, GS06 matches GE02 and ST02 matches SE02 (UNB, UNG and UNH with their trailers for EDIFACT), that the counts in IEA01, GE01, SE01 and the EDIFACT trailers are right, that every header has its trailer, that segments sit inside an envelope, and that the mandatory elements the page knows are filled in. Each problem names its segment number and line.

How are loops shown?

A segment that starts a loop, such as N1, PO1, HL or NM1 in X12, or NAD and LIN in EDIFACT, holds the segments after it until the next loop or the summary. The grouping is a simple view of the structure, not a check against an implementation guide.

Is a broken file safe to open?

Text from the file is shown as plain text, never as HTML, and nothing in the file runs. A file cut short or with a missing trailer opens anyway, and the checks say what is missing.

Does it work offline?

Yes. After the first visit the page keeps a copy of its own files, so it opens EDI files with no connection.
