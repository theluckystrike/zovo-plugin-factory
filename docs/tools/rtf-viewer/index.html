    Questions

    Is my RTF file uploaded anywhere?

    No. The page reads the file inside this tab and turns it into a page with JavaScript, in a background worker. Its Content Security Policy sets connect-src to none, so the page cannot send your document anywhere. Open the Network tab of your browser tools and you will see no request when a file opens.

    Which RTF files does it open?

    Files from Word, WordPad, TextEdit, LibreOffice, R and SAS, up to 200 MB. It reads code pages and font charsets, Unicode, and Japanese, Chinese, Korean, Cyrillic and Greek text. Tables keep merged cells, borders, shading and header rows, so clinical tables (TFLs) with spanning headers look right.

    Are pictures shown?

    Yes. PNG, JPEG, BMP, EMF and WMF pictures stored in the file are drawn. Mac PICT and other kinds show as a labelled box, never a blank page. Pictures come only from the bytes inside the file; the page loads nothing else.

    Is a file with links or embedded objects safe to open?

    Embedded objects (OLE packages) are never opened or extracted; each shows as a box. Links work only for web and mail addresses, and only when you click them. The text of the file is shown as text, never run, and the page allows only its own scripts.

    Can I search and read in the dark?

    Press Ctrl+F or Cmd+F, or use the Find box, then Enter and Shift+Enter to move between matches. The outline lists the headings. Paper can follow the page theme, or stay light or dark; on dark paper, dark text is lightened so it stays readable.

    Does it work offline?

    Yes. After the first visit the page keeps a copy of its own files, so it opens RTF files with no connection.
