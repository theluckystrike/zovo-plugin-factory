Questions

Is my G-code uploaded anywhere?

No. The page reads the file inside this tab. Its Content Security Policy sets connect-src to none, so the page cannot send your file anywhere, and it loads no library. Open the Network tab of your browser tools and you will see no request when a file opens.

What does it show?

A top or front view of the toolpath with a layer slider. Layers below the current one are shown dimmed, or pick One layer. Colors follow the slicer's feature comments (outer wall, inner wall, infill, skin, skirt, support), the speed, the layer or the tool. Click a move and the page shows its line number and the line itself.

How is the print time worked out?

From the feed rate and length of every move, plus G4 dwells. Acceleration is not modelled, so a real print usually takes a little longer. When the slicer wrote its own estimate (Cura TIME, PrusaSlicer, OrcaSlicer or Bambu Studio), the page shows it next to its own.

How is the filament weight worked out?

From the E axis, absolute or relative, with G92 E0 resets, for the filament diameter and density in the boxes under the stats. PLA is 1.24 g/cm³, PETG 1.27 and ABS 1.04.

Does it read CNC programs?

Yes. A file with no extrusion opens in CNC mode: G0 rapids, G1 cuts, G2 and G3 arcs with I and J or R, plunges, inches (G20), relative moves (G91), G92 and G28. The slider steps through Z passes, and the stats give the cycle time, cut and rapid lengths, tools and spindle speed.

How big a file can it open?

Up to 500 MB. The moves are kept in compact arrays and drawn one color at a time, so a file with a million moves still opens in a few seconds. The VS Code extension reads big files in a worker in 4 MB chunks.
