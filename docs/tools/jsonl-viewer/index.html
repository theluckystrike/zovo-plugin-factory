Questions
Is my file uploaded anywhere?
No. The page reads the file inside this tab. Its Content Security Policy sets connect-src to none, so the page cannot send your data anywhere, and it loads no library. Training data and logs often hold private text, so you can check it: open the Network tab of your browser tools and you will see no request when a file opens.
What is a JSONL file?
JSON Lines, also called NDJSON: one JSON value per line, usually an object. Logs, dataset exports, eval results and fine-tuning files for OpenAI, Gemini and other models use it. Each line stands alone, so one bad line does not break the rest.
How are the columns made?
One column per top-level key, from the first 1,000 records. Each title shows the type (string, int, float, bool, object, array or mixed) and how many of those records fill that key. Nested values show as JSON in the cell. Click a row to see the whole record.
What about lines that are not valid JSON?
They stay in the table in red with their line number and the parser message, and the rest of the file opens. The facts at the top count them, and Only bad lines shows just those.
Can it read chat and fine-tuning files?
Yes. A record with messages (OpenAI), conversations (ShareGPT), contents (Gemini) or prompt and completion opens as a chat above its JSON, with tool calls shown in their own box.
How big a file can it open?
The page reads the whole file into the tab, so files of a few hundred MB work on a normal computer. A .jsonl.gz file is unpacked up to 512 MB. For files of many GB, the free VS Code extension streams them and keeps only the lines on screen in memory.
