Questions

Is my e-mail uploaded anywhere?

No. The page reads the file inside this tab with the EML Viewer extension's own mail reader. The page CSP sets connect-src to none, and the viewer frame cannot reach any server. Open the Network tab of your browser tools and you will see no request when a mail opens.

Why are the pictures in the mail not shown?

Pictures that a mail loads from the web are blocked on this page. Loading them would tell the sender that you opened the mail, and when and where. Pictures sent inside the mail (inline attachments) are shown. The VS Code extension can show remote pictures after you click.

Is a mail with scripts or a phishing link safe to open?

The message HTML goes through an allow-list cleaner and is shown in a sandboxed frame where no script can run. Links open only after you click them, in a new tab, and only web and mail links. Attachments are never opened, only saved when you click Save.

What can I see besides the message?

All headers, the raw source, the route the mail took from server to server with the time of each hop, and the SPF, DKIM and DMARC results that the receiving server wrote, as badges. That helps to spot a forged sender.

Can it open a whole mailbox?

Yes. An .mbox file (from Thunderbird, Apple Mail export or Google Takeout) opens as a list of messages with search and sort, up to 500 MB here. Click a message to read it.

Can I open Outlook .msg files?

Not yet. Save the mail as .eml in your mail program first (in Outlook on the web, Download; in Outlook, drag the mail to a folder), then open the .eml here.
