Questions

Is my CSV file uploaded anywhere?

No. The page reads the file inside this tab and draws the table with JavaScript. Its Content Security Policy sets connect-src to none, so the page cannot send your data anywhere. Open the Network tab of your browser tools and you will see no request when a file opens.

How big a CSV can it open?

Files up to 200 MB, and up to 1,000,000 rows or 20,000,000 cells. The grid draws only the rows on screen, so a file of 500,000 rows scrolls as fast as a small one. In our test a 44 MB CSV of 540,000 rows opened in under a second. The page says when it shows only part of a file.

Does it find the separator and encoding?

Yes. It reads the first lines to pick the separator (comma, semicolon, tab or pipe), whether the first row is a header, and the text encoding, so files from European Excel with semicolons and a byte order mark open right.

Can I sort and search?

Click a column name to sort by it, click again to reverse. Press Ctrl+F or Cmd+F to find text in the whole table and step through the matches.

Is a CSV with formulas or HTML safe to open?

Yes. Cells are shown as plain text, never as HTML, and nothing in a cell runs, so a cell that starts with = is shown as text and not run as a formula.

Does it work offline?

Yes. After the first visit the page keeps a copy of its own files, so it opens CSV files with no connection.
