    Questions

    Is my VCD file uploaded anywhere?

    No. The page reads the file inside this tab. Its Content Security Policy sets connect-src to none, so the page cannot send your design anywhere, and it loads no library. Open the Network tab of your browser tools and you will see no request when a file opens.

    How do I make a VCD file?

    In a Verilog testbench add $dumpfile("wave.vcd"); $dumpvars(0, tb); and run it with Icarus Verilog (iverilog and vvp). Verilator writes one with its trace option, GHDL with its vcd option, and Vivado, ModelSim and Questa have a VCD dump command too.

    Which signals show first?

    The first 64 signals of the file. Tick more in the list on the left, press + next to a scope to add all of its signals, or Show all. The search box matches every word, so axi data finds tb.dut.s_axi.wdata. Only the rows on screen are drawn, so many signals stay fast.

    How do I move and measure?

    Drag the waves or use Shift and the wheel to move in time, Ctrl or Cmd and the wheel to zoom at the mouse, and F to fit the whole run. Click to place the cursor: the Value column shows every signal at that time. Press A and B to set two markers, and the line under the waves shows B - A in the best time unit.

    How are x and z values shown?

    Undefined values are red and high-impedance values yellow, in the waves and in the Value column. In hex, a digit is x or z when all its 4 bits are, and X or Z when only some are. VHDL values U, W, L, H and - from GHDL show as they are. Short vectors are extended to their width the way the VCD standard says.

    How big a file can it open?

    The page reads the whole file into the tab, so dumps of a few hundred MB work on a normal computer, up to 1.5 GB. The VS Code extension reads files of many GB without loading them whole.
