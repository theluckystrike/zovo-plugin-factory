Questions
Is my file uploaded anywhere?
No. The page reads your XML inside this tab. Its Content Security Policy sets connect-src to none, so it cannot send the file anywhere, and it loads no library from another site. Open the Network tab of your browser tools and you will see no request when a file opens or an XPath runs.
Which XPath does it run?
XPath 1.0, with the same code as the extension. Prefixes come from the file, so //soap:Body works in a SOAP envelope. A plain name also matches an element in a default namespace, so //dependency/artifactId works in a pom.xml. Turn on Strict namespaces for plain XPath 1.0 rules. XPath 2.0 and 3.1, XQuery and XSLT are not supported.
Why does my XPath say a prefix is not declared?
The page binds only the prefixes that the file declares, and the message lists them. Use one of those, or write the step as *[local-name()='name'], which works with no prefix at all.
What does Format change?
Only the whitespace between tags, in elements that hold tags and no text. Text, CDATA, comments, xml:space="preserve" content and attribute values stay byte for byte, and a second format changes nothing. A file that is not well formed is not changed; the page shows the error with its line and column.
What are the three Copy XPath styles?
With positions, such as /project/dependencies/dependency[2]/artifactId. With id or name attributes, such as /manifest/application/activity[@android:name='.Main']. Portable, with local-name() steps that work in any XPath 1.0 tool without namespace bindings. Each one selects that one element.
Is it safe to open an XML file with entities?
Yes. Entities are never expanded and a DTD is never loaded. An entity bomb is counted, not expanded, and an external entity such as file:///etc/passwd is not read.
