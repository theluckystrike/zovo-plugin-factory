Questions

Is my graph uploaded anywhere?

No. Graphviz runs inside this tab as WebAssembly, in a background worker of the page that has no network functions. The page CSP sets connect-src to none. Your code is kept in this browser only (local storage), so it is still there when you come back.

Is it the real Graphviz?

Yes. The layout comes from Graphviz itself, compiled to WebAssembly by the viz.js project (version 3.31), so the result matches the dot command line tool. All six layouts are there: dot, neato, fdp, sfdp, circo and twopi. A layout= attribute in the file wins over the menu.

What happens with an error?

The preview keeps the last good graph, marks it as old, and lists the error with its line number. Click Go to line to jump there in the code. Warnings show without stopping the layout.

How do I save the graph?

Export SVG and Export PNG in the preview save the graph to your downloads; the PNG is drawn at the size you pick. Save .dot saves the code. Copy link packs the code after the # of the address, a part browsers never send to a server.

How big a graph can it lay out?

Graphs up to 4 MB of DOT code. A layout that runs longer than 15 seconds is stopped, and the page stays usable. For thousands of nodes, the sfdp layout is the fastest.

Does it work offline?

Yes. After the first visit the page keeps a copy of its own files, Graphviz included, so it works with no connection.
