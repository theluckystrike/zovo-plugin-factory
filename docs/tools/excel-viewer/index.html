Questions

Is my spreadsheet uploaded anywhere?

No. The page reads the file inside this tab and draws the table with JavaScript. Its Content Security Policy sets connect-src to none, so the page cannot send your data anywhere. Open the Network tab of your browser tools and you will see no request when a file opens.

Which files does it open?

Excel .xlsx, .xlsm, .xlsb and old .xls files, OpenDocument .ods, CSV and TSV text files, and Apache Parquet files, up to 200 MB. The format is found from the first bytes, so a CSV saved as .txt still opens as a table.

How many rows can it show?

Up to 200,000 rows a sheet for Excel files, 1,000,000 rows or 20,000,000 cells for CSV, and the first 100,000 rows of a Parquet file. The grid draws only the rows on screen, so scrolling stays fast. The page says when it shows only part of a file.

Does it run formulas or macros?

No. It shows the value Excel saved with each cell, so formulas never run here, and macros in .xlsm files are never run. Cell text is shown as plain text, never as HTML.

How does it read a CSV file?

It finds the separator (comma, semicolon, tab or pipe), the header row and the text encoding for you. Click a column name to sort by it, and press Ctrl+F or Cmd+F to find text in the table.

Does it work offline?

Yes. After the first visit the page keeps a copy of its own files, so it opens spreadsheets with no connection.
