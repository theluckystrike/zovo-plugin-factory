Questions

Is my DBC file uploaded anywhere?

No. The page reads the file inside this tab with JavaScript. Its Content Security Policy sets connect-src to none, so the page cannot send your file anywhere. Open the Network tab of your browser tools and you will see no request when a file opens.

What does it read from a DBC file?

Messages with standard and extended 29-bit ids, and signals with start bit, length, Intel or Motorola byte order, sign, factor, offset, range, unit and receivers. It also reads multiplexed signals (M and m1, m2 and so on), value tables and labels, comments (also comments that span lines), attributes with GenMsgCycleTime shown as the cycle time, float and double signals, and CAN FD frames up to 64 bytes. Signal groups and environment variables are counted but not shown.

How do I read the bit layout?

Each row is one byte of the frame, with bit 7 on the left. Intel signals run up from their start bit. Motorola signals start at their most significant bit and run down to bit 0 of that byte, then on from bit 7 of the next byte. A bar on the left edge of a cell marks the most significant bit of a signal, and a red outline marks bits that two signals share. For a multiplexed message, pick the multiplexer value to see its signals.

Can it decode a frame?

Yes. Pick a message and type the data bytes in hex. The page shows each raw value, the physical value (raw times factor plus offset) with its unit, the value-table label, and a note when the value is outside the signal range. For a multiplexed message it reads the multiplexer from your bytes first, and float signals are read as IEEE 754.

What do the checks find?

Signals that share bits (unless they belong to different multiplexer values), signals that run past the frame, message ids and signal names used twice, a minimum above the maximum, float signals with the wrong length, comments or value labels for messages that do not exist, and multiplexed signals with no multiplexer. Each one comes with its line number.

Can it open BLF, ASC or candump logs?

Not this page. The free DBC Viewer & CAN Log Viewer extension for VS Code opens Vector .blf and .asc logs, PCAN .trc files and candump .log files and decodes every frame with your DBC.

Is a broken or hostile file safe to open?

Text from the file is shown as plain text, never as HTML, and nothing in the file runs. Lines that do not parse are listed with their line number, and the rest of the file still opens.

Does it work offline?

Yes. After the first visit the page keeps a copy of its own files, so it opens DBC files with no connection.
