Questions

Is my font uploaded anywhere?

No. The page reads the file inside this tab. Its Content Security Policy sets connect-src to none, so the page cannot send your font anywhere. Three small libraries load once from cdn.jsdelivr.net at pinned versions, their hashes are checked before they run, and your font is never sent there. The type tester loads the font from its own bytes, not from a URL.

Which fonts does it open?

TrueType (.ttf), OpenType with CFF or CFF2 outlines (.otf), WOFF and WOFF2 web fonts, and font collections (.ttc), where you pick the font. Variable fonts get a slider for each axis, such as weight or width, and their named instances are listed.

Where do I see the license?

In the Names list: the copyright, license description, license URL, designer and vendor are name records 0, 13, 14, 9 and 8. The Font facts also show the embedding rights from the OS/2 table, such as Installable, Editable, Preview and print or Restricted.

How do I find a glyph?

Type a character, a code point such as U+20AC, a glyph name part such as acute or uni20AC, or a glyph id such as #12 in the box above the grid. Glyphs are drawn from their outlines, so ligatures and alternates that no key types show too. Click a glyph to see it large with its name, characters and advance width.

What does the coverage list show?

The Unicode blocks the font covers, with counts such as Basic Latin 95 of 128, so you can see at a glance whether a font has the accents, Cyrillic, Greek or symbols you need.

Does it work offline?

Yes. After the first visit the page keeps a copy of its own files and of the pinned libraries, so it opens fonts with no connection.
