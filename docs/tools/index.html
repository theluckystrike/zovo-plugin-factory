Free browser tools

Each tool opens your file inside the browser tab. Nothing is uploaded, and the tools keep working offline once loaded.

Hex Viewer Online

Free hex viewer online. Drop any file to see its bytes as hex and text, with a data inspector, find, go to offset and a structure view for ZIP, PNG, ELF, PE and 22 more formats. The file never leaves your browser.

DOCX Viewer Online

Free DOCX viewer online. Drop a Word .docx or .odt file to read it as pages, with find, zoom, print and a dark mode. The file never leaves your browser and nothing is uploaded.

The same viewers run inside VS Code and Cursor. See all Zovo extensions.
