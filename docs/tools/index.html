Free browser tools

Each tool opens your file inside the browser tab. Nothing is uploaded, and the tools keep working offline once loaded.

Hex Viewer Online

Free hex viewer online. Drop any file to see its bytes as hex and text, with a data inspector, find, go to offset and a structure view for ZIP, PNG, ELF, PE and 22 more formats. The file never leaves your browser.

DOCX Viewer Online

Free DOCX viewer online. Drop a Word .docx or .odt file to read it as pages, with find, zoom, print and a dark mode. The file never leaves your browser and nothing is uploaded.

Excel Viewer Online

Free Excel viewer online. Drop an .xlsx, .xls, .ods, .csv or .parquet file to see it as a sortable table with sheet tabs and find. The file never leaves your browser and nothing is uploaded.

CSV Viewer Online

Free CSV viewer online. Drop a .csv or .tsv file, even one of 1,000,000 rows, to see it as a sortable table with find. The separator and encoding are found for you, and the file never leaves your browser.

PPTX Viewer Online

Free PPTX viewer online. Drop a PowerPoint .pptx, .ppsx or .potx file to see its slides, with zoom, find, print and a dark mode. The file never leaves your browser and nothing is uploaded.

SQLite Viewer Online

Free SQLite viewer online. Drop a .db, .sqlite or .sqlite3 file to browse its tables, filter and sort rows, see the schema and run SQL queries. The database never leaves your browser.

PDF Dark Mode Viewer

Free PDF dark mode viewer. Drop a PDF to read it with dark pages that keep photos in their true colors, or sepia pages, with search, outline, thumbnails and highlights. The file never leaves your browser.

DXF Viewer Online

Free DXF viewer online. Drop a .dxf file to see the drawing with layers, paper space sheets, hatches, measure, find text and PNG or SVG export. ASCII and binary DXF. The file never leaves your browser.

SVG to PNG Converter

Free SVG to PNG converter. Drop one or many SVG files, pick 1x to 8x or a width in pixels and a transparent or solid background, and download each PNG or all of them as a ZIP. Nothing is uploaded.

EPUB Reader Online

Free EPUB reader online. Drop an .epub ebook to read it paged or scrolled, with the table of contents, search, footnote popups and light, sepia or dark themes. The book never leaves your browser.

Mermaid Editor Online

Free Mermaid editor online with a live preview. Write flowcharts, sequence, class, ER, Gantt, mind map, C4 and other Mermaid diagrams, then save PNG or SVG. Your code stays in this browser; share links carry it after the #.

STL Viewer Online

Free STL viewer online. Drop an STL, OBJ, PLY, GLB, glTF or 3MF file to turn, zoom and measure the 3D model, with wireframe, normals, the scene tree, animations and a PNG screenshot. Nothing is uploaded.

Graphviz Online

Free Graphviz online editor. Type DOT code and see the graph laid out live with dot, neato, fdp, sfdp, circo or twopi, with error lines, zoom and SVG or PNG export. Your graph stays in this browser.

DICOM Viewer Online

Free DICOM viewer online. Open a DICOM file, a whole CT or MRI series or a NIfTI volume to scroll slices, set window and level, see axial, coronal and sagittal views and every DICOM tag. Nothing is uploaded.

EML Viewer Online

Free EML viewer online. Drop an .eml, .emlx or .mbox file to read the mail as it was sent, with attachments, headers, the route and SPF, DKIM and DMARC results. Remote pictures stay blocked, and nothing is uploaded.

NPY and NPZ Viewer Online

Free NPY and NPZ viewer online. Drop a NumPy .npy or .npz file to see the shape, dtype, stats and first rows of each array, with a line chart, histogram or heatmap. No Python, and the file never leaves your browser.

Parquet Viewer Online

Free Parquet viewer online. Drop a .parquet file to see its schema, row groups, compression and first 1,000 rows as a table you can sort. Snappy, gzip, zstd, brotli and lz4. The file never leaves your browser.

HDF5 and NetCDF Viewer Online

Free HDF5 and NetCDF viewer online. Drop an .h5, .hdf5 or .nc file to browse its groups, datasets and attributes, see the first values and plot a line or heatmap. No Python, and the file never leaves your browser.

TIFF Viewer Online

Free TIFF viewer online. Drop a .tif or .tiff file to see every page, 16-bit and float images with auto contrast, pixel values, GeoTIFF coordinates and all tags. The file never leaves your browser.

DBC Viewer Online

Free DBC viewer online. Open a CAN .dbc file to see every message and signal, the bit layout of each frame, value tables and attributes, check it for overlapping bits and decode a frame. The file never leaves your browser.

Regex Tester Online

Free regex tester online. Type a regular expression and see every match highlighted in your text, a table with one column per group, a replace preview and a plain-words explanation. Load a log file; it never leaves your browser.

SARIF Viewer Online

Free SARIF viewer online. Open a .sarif log from CodeQL, Semgrep, ESLint, Bandit, Trivy or Gitleaks to see the results grouped by rule or file, with filters, code flow steps, rule help and CWE links. The log never leaves your browser.

Intel HEX Viewer Online

Free Intel HEX and S-record viewer online. Open a .hex, .ihex, .s19 or .srec firmware image to see its memory map, gaps and overlaps, a hex view by address and a data inspector, with every record checked. The file never leaves your browser.

EDI Viewer Online

Free EDI viewer online. Open an X12 or EDIFACT file (850, 810, 856, 837, ORDERS, INVOIC, DESADV) to read it as a tree with element names and code meanings, and check its control numbers and counts. The file never leaves your browser.
