Questions

Are my files uploaded anywhere?

No. The page reads both files inside this tab and compares them in a background worker of the same tab. Its Content Security Policy sets connect-src to none, and the reader is part of the page, so nothing is sent anywhere. Open the Network tab of your browser tools and you will see no request when you compare two files.

How are rows and columns matched?

Rows are lined up, not compared line by line, so a row inserted near the top does not mark every row below it as changed. A removed and an added row next to each other that share most cells count as one changed row. Columns are matched by their header row, and sheets by name, then by position.

What do the colours mean?

A changed cell is yellow, with the old value struck through next to the new one. Added rows and columns are green, removed ones red. Each sheet tab shows its number of differences. Click a cell to see its full old and new value.

Can I compare formulas?

Yes. Values compares what the cells show; Formulas compares the formulas themselves, and a cell without a formula by its value.

Can I compare an Excel file with a CSV file?

Yes. Any mix works, for example an .xlsx against a .csv. A CSV file compares like a workbook with one sheet. Its encoding (UTF-8, UTF-16 or a Windows code page) and its delimiter (comma, semicolon, tab or pipe) are detected.

How big can the files be?

Up to 100 MB each, 300,000 rows per sheet, 1,000 columns and 200 sheets. A note says when a limit cut a sheet. A workbook that would inflate like a zip bomb is refused before it is unpacked. Password protected workbooks cannot be read; save a copy without the password.
