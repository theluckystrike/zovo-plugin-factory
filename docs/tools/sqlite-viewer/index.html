Questions

Is my database uploaded anywhere?

No. The page reads the file inside this tab, and SQLite itself (compiled to WebAssembly) runs in a background worker of the page. The Content Security Policy sets connect-src to none, and the worker has no network functions at all. Open the Network tab of your browser tools and you will see no request when a database opens.

Which files does it open?

SQLite 3 databases up to 500 MB, whatever their name: .db, .sqlite, .sqlite3, .db3, and app files such as browser history or a phone backup. Pick the -wal file together with the database to see changes that are not checkpointed yet. Encrypted (SQLCipher) databases need their key and a desktop tool.

Can I run my own SQL?

Yes. The SQL tab runs reading statements (SELECT, WITH, VALUES, EXPLAIN and reading PRAGMA), one at a time, with a history of the last 30. Results show in the same grid, with sorting, filters and copy. The database is opened read-only, and it is a copy in memory anyway, so your file never changes. A query that runs for a long time can be stopped.

Can I edit the database?

This page is read-only. The free SQLite Editor extension for VS Code and Cursor edits cells and rows, stages every change with Undo, and saves with a backup.

Can I export the data?

Yes. Copy as CSV, TSV, JSON or SQL INSERT from the toolbar, or Export the rows in view (filtered and sorted) as a CSV, JSON or SQL file. Images stored in BLOB cells show as pictures, and any BLOB can be saved as a file.

Is a hostile database safe to open?

Cell values are written as plain text, never as HTML, and the page allows only its own scripts. The database runs in a worker inside a separate frame, so a broken or crafted file can at worst stop the worker; a Stop button replaces it.
