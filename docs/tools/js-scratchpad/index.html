Questions
Where does my code run?
In a Web Worker inside this browser tab, started fresh for each run. The worker has no access to the page, and the page's Content Security Policy sets connect-src to none, which the worker inherits: fetch, XMLHttpRequest and WebSocket fail there, and the page removes them as well. Nothing you type is sent anywhere. Open the Network tab of your browser tools to check: a run adds no request.
When does the code run?
Only when you press Run or Ctrl+Enter (Cmd+Enter on a Mac), or while you type if you tick Run while I type. Opening a file only loads it into the editor, so a file you did not write never runs by itself.
What happens with an endless loop?
The run is stopped at the time limit (5 seconds unless you pick 2 or 10) and the page says so. A loop that runs a million times keeps the first 100 values of each line and counts the rest, so the page stays fast.
What do the values on each line show?
The value of each expression statement and each new variable, such as total = 42. A line inside a loop shows each value it took, joined with a dot. console.log, info, warn, error, table and dir show on the line that called them, a promise shows its result once it settles, and an error shows on the line that threw. Click a line to see all of its values below the editor.
Does TypeScript work?
Yes, with no setup. Pick TypeScript (a .ts file picks it for you). Types, interfaces, generics, satisfies, enums and parameter properties work: the types are removed and every line keeps its number. Types are not checked. A namespace with values does not run here.
Can I use import, require or Node.js modules?
No. A browser has no Node.js and no node_modules, so import lines are flagged and require throws an error on its line. document and the DOM are not there either, because the code runs in a worker. The free JavaScript Playground extension for VS Code runs your file with Node.js, where imports and require resolve from your project.
Is my code saved?
The page keeps the code you type in this browser's local storage, so it is still here when you come back. It is not sent anywhere. Save file downloads it to your computer, and Copy code with values copies it as Markdown with the values as comments.
