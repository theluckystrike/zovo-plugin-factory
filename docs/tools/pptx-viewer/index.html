Questions

Is my deck uploaded anywhere?

No. The page reads the file inside this tab and draws the slides with JavaScript. Its Content Security Policy sets connect-src to none, so the page cannot send your slides anywhere. Open the Network tab of your browser tools and you will see no request when a deck opens.

Which files does it open?

PowerPoint .pptx, .ppsx, .potx and .pptm decks up to 200 MB. Old .ppt files from PowerPoint 97-2003 need the VS Code extension, which shows their text and speaker notes.

Do slides look the same as in PowerPoint?

Most decks draw well: text, pictures, shapes, tables and charts. Some SmartArt, effects and fonts that are not on your computer can look a little different, because the slides are drawn by pptx-preview and not by PowerPoint. The PPTX support is marked beta for that reason.

Is a deck with macros or links safe to open?

Macros and embedded objects never run. The page allows only its own scripts, and a deck that unpacks to more than 500 MB or holds more than 10,000 parts is refused before it is opened.

Can I present from here?

Use the page and zoom buttons to step through the slides, and Print to make a handout or a PDF with your browser. The free VS Code extension has a full-screen slideshow with the arrow keys.

Does it work offline?

Yes. After the first visit the page keeps a copy of its own files, so it opens decks with no connection.
