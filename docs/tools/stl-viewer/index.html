Questions

Is my model uploaded anywhere?

No. The page reads the file inside this tab and three.js draws it here. The page CSP sets connect-src to none, and the viewer frame may only read the files you picked, from memory. Open the Network tab of your browser tools and you will see no request when a model opens.

Which files does it open?

STL in binary and ASCII form, OBJ (with its MTL materials), PLY meshes and point clouds, GLB and glTF 2.0 (with embedded or separate buffers and textures) and 3MF, up to 1 GB. Draco, meshopt and KTX2 compressed glTF files are named in a clear message.

My glTF or OBJ shows no textures. What do I do?

A .gltf file often points to a .bin file and texture pictures, and an OBJ to an .mtl file. Pick all of them at once (or drop them together), and the viewer finds each one by its name. A GLB has everything inside, so one file is enough.

Can I measure the model?

Yes. Click Measure, then two points on the surface, to get the distance in the model units. The panel shows the size of the bounding box, the triangle and vertex counts and the scene tree. Y up or Z up can be switched for files from CAD and slicers.

Can I save a picture of the model?

Yes. Screenshot saves the current view as a PNG to your downloads, with the background you picked. The model file itself is never changed.

Does it work offline?

Yes. After the first visit the page keeps a copy of its own files, so it opens models with no connection.
