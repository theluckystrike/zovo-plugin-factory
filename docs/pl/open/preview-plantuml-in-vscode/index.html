Podgląd diagramu PlantUML w VS Code w trakcie pisania

Zainstaluj darmowe rozszerzenie PlantUML Viewer & Preview, otwórz plik .puml albo plik Markdown z blokiem plantuml i kliknij przycisk podglądu. Diagram jest rysowany obok kodu w trakcie pisania przez jar PlantUML dołączony do rozszerzenia i Twoją Javę w wersji 11 lub nowszej, więc nic nie trafia na serwer, a Graphviz nie jest potrzebny. Podgląd, powiększanie, linki do błędów i zapis pojedynczego diagramu jako SVG lub PNG są darmowe. Zovo Pro (19 USD jednorazowo) dodaje trzy narzędzia, Export All Diagrams in a Folder, Markdown Diagrams to Images i Compare with a Git Version, a każde z nich ma 3 darmowe próby.

Kroki w VS Code

  1. Zainstaluj PlantUML Viewer & Preview z Marketplace albo naciśnij Ctrl+P (Cmd+P w macOS) i uruchom ext install zovo.zovo-plantuml-viewer.
  2. Upewnij się, że masz zainstalowaną Javę w wersji 11 lub nowszej. Rozszerzenie szuka jej w ustawieniu plantumlViewer.javaPath, potem w JAVA_HOME, potem jako java w PATH, a na końcu w typowych folderach JDK. Jeśli jej nie znajdzie, podgląd o tym informuje i proponuje „Set the Java path”. Polecenie „PlantUML: Show Java and Layout Status” pokazuje, co zostało znalezione.
  3. Otwórz plik .puml, .plantuml, .iuml, .pu lub .wsd albo plik Markdown z blokiem ```plantuml i kliknij przycisk podglądu w prawym górnym rogu edytora. Możesz też nacisnąć Alt+D w pliku PlantUML lub uruchomić „PlantUML: Open Preview to the Side”.
  4. Pisz. Podgląd odświeża się chwilę po tym, jak przestaniesz pisać (domyślnie po 400 ms, ustawienie plantumlViewer.renderDelay). Wszystkie diagramy z pliku są widoczne w jednym podglądzie, a ten pod kursorem ma obramowanie.
  5. Powiększaj przyciskami, kółkiem myszy z wciśniętym Ctrl lub Cmd albo klawiszami + i -. Przycisk Fit dopasowuje diagram do szerokości panelu, a przeciąganie diagramu pozwala się po nim przesuwać. Diagram z błędem pokazuje komunikat PlantUML i link „Go to line”.
  6. Kliknij SVG lub PNG nad diagramem, aby zapisać ten jeden diagram, albo Copy SVG, aby go skopiować.

Co jest za darmo, a co dodaje Zovo Pro

Podgląd na żywo plików .puml, .plantuml, .iuml, .pu i .wsd oraz bloków plantuml w Markdownie, powiększanie i przesuwanie, błędy z linkiem do wiersza, zapis jednego diagramu jako SVG lub PNG, Copy SVG, kolorowanie składni, snippety (seq, classd, activity, mindmap, gantt i inne), zwijanie kodu i komentarze są darmowe. Diagramy są rysowane na Twoim komputerze i nigdy nie trafiają na serwer.

Gdy diagramy z projektu mają trafić do dokumentacji lub na slajdy, Export All Diagrams in a Folder w jednym przebiegu zapisuje każdy diagram z każdego pliku PlantUML w folderze i jego podfolderach jako SVG, PNG lub PDF, obok każdego pliku albo wszystkie w jednym folderze. Diagramy z błędami są pomijane i wypisywane z plikiem, wierszem i komunikatem, a pozostałe zostają zapisane. Nie trzeba otwierać każdego pliku i zapisywać każdego diagramu ręcznie.

Narzędzie Export All Diagrams in a Folder (Zovo Pro)

  1. Kliknij prawym przyciskiem folder w widoku Explorer i wybierz „Zovo Pro: Export all diagrams in a folder”, kliknij „Export all diagrams in a folder” w wierszu Pro tools na pasku narzędzi podglądu albo uruchom „PlantUML: Export All Diagrams in a Folder (Pro)” z Command Palette i wybierz folder.
  2. Wybierz SVG, PNG lub PDF, a potem „Next to each PlantUML file” albo „All in one folder...”.
  3. Na końcu komunikat podaje, ile diagramów wyeksportowano. Kliknij „Show errors”, aby zobaczyć listę diagramów z błędami, albo „Reveal”, aby zobaczyć pliki.
  4. Próba liczy się tylko wtedy, gdy zapisano co najmniej jeden obraz. Escape, Cancel albo folder bez plików PlantUML nie zużywają próby.

Export All Diagrams in a Folder działa 3 razy na twoim komputerze, zanim poprosi o licencję. Przy otwieraniu pliku nie ma wyskakujących okienek ani odliczania.

Kroki w Cursor, Windsurf lub VSCodium

  1. Otwórz widok Extensions skrótem Ctrl+Shift+X (Cmd+Shift+X w macOS).
  2. Wyszukaj zovo.zovo-plantuml-viewer i kliknij Install. Cursor, Windsurf i VSCodium instalują rozszerzenia z Open VSX, gdzie to rozszerzenie ma nazwę zovo/zovo-plantuml-viewer.
  3. Jeśli edytor nie ma galerii rozszerzeń, pobierz plik .vsix ze strony Open VSX i uruchom „Extensions: Install from VSIX...”.
  4. Dalej wszystko działa tak samo jak w VS Code.

Co otwiera PlantUML Viewer & Preview

  • Diagramy sekwencji, klas, aktywności, komponentów, stanów i przypadków użycia, mapy myśli, wykresy Gantta i inne bloki @start... dołączonego PlantUML (build MIT 1.2026.10).
  • Bloki Markdown ```plantuml, ```puml i ```uml, z @startuml w środku lub bez. Przycisk podglądu pojawia się w pliku Markdown, który ma co najmniej jeden taki blok.
  • !include plików z folderu diagramu, z folderów obszaru roboczego i z plantumlViewer.includePaths oraz biblioteka standardowa, np. !include <C4/C4_Container>, offline. Include’y C4, ikon AWS i icon fontów zapisane jako adresy https://raw.githubusercontent.com/... są czytane z kopii w jarze.
  • Diagramy sekwencji, mapy myśli i wykresy Gantta nie potrzebują silnika układu. Diagramy klas, komponentów, stanów i przypadków użycia używają Graphviz, gdy dot jest zainstalowany (plantumlViewer.layout ustawione na auto), a w przeciwnym razie silnika Smetana wbudowanego w PlantUML.
  • Diagramy są wyświetlane jako obrazy, więc link ani tekst w diagramie nie może uruchomić kodu w edytorze.

Czego nie robi

  • Musi być zainstalowana Java w wersji 11 lub nowszej. Rozszerzenie nie pobiera Javy.
  • Include’y z adresów internetowych są odrzucane, z wyjątkiem adresów C4, ikon AWS i icon fontów, których kopię ma jar. Ikony AWS pochodzą z zestawu ikon AWS wbudowanego w PlantUML (wersja 20), więc nowsza ikona pokazuje błąd z jej nazwą.
  • Build MIT PlantUML nie ma Ditaa ani renderera LaTeX dla @startmath. Blok Ditaa pokazuje stronę „not supported” z PlantUML.
  • Bez Graphviz Smetana układa diagramy klas i komponentów nieco inaczej, a bardzo duże diagramy klas mogą wyglądać ciaśniej.
  • Diagram, którego rysowanie trwa dłużej niż 30 sekund (ustawienie plantumlViewer.renderTimeoutSeconds), zostaje zatrzymany, a obrazy są przycinane do 8192 pikseli na bok (ustawienie plantumlViewer.maxImageSize).

Pytania

Czy to jest darmowe?

Podgląd na żywo, powiększanie i przesuwanie, linki do błędów, zapis jednego diagramu jako SVG lub PNG, kolorowanie składni i snippety są darmowe. Trzy narzędzia Pro, Export All Diagrams in a Folder, Markdown Diagrams to Images i Compare with a Git Version, mają po 3 darmowe próby. Potem wymagają Zovo Pro, 19 USD jednorazowo za wszystkie rozszerzenia Zovo.

Czy potrzebna jest Java albo Graphviz?

Java 11 lub nowsza tak, bo PlantUML to program w Javie. Graphviz nie. Bez niego diagramy klas i komponentów używają silnika układu Smetana wbudowanego w PlantUML. Jeśli dot jest zainstalowany, zostanie użyty.

Czy mój diagram jest wysyłany na serwer?

Nie. Dołączony jar PlantUML działa na Twoim komputerze z profilem bezpieczeństwa ALLOWLIST, a include’y z adresów internetowych są odrzucane. Żaden serwer PlantUML nie jest używany.

Czy działa w Cursorze?

Tak. Cursor, Windsurf i VSCodium instalują je z Open VSX, gdzie jest opublikowane jako zovo/zovo-plantuml-viewer.
