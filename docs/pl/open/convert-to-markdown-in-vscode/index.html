Jak przekonwertować plik PDF, Word, PowerPoint lub Excel do Markdown w VS Code

Zainstaluj darmowe rozszerzenie Convert to Markdown, kliknij prawym przyciskiem w widoku Explorer plik PDF, Word, PowerPoint, Excel, CSV, HTML, EPUB, ODT lub RTF i wybierz Convert to Markdown. Markdown otworzy się obok pliku, z nagłówkami, listami, tabelami, linkami i notatkami prelegenta ze slajdów, a żadne dane nie opuszczają komputera. Convert to Markdown i Copy as Markdown są darmowe dla wszystkich formatów. Zovo Pro (19 USD jednorazowo) dodaje trzy narzędzia, Convert a Folder to Markdown, Convert to Markdown with Images i LLM-ready Markdown Chunks, a każde z nich ma 3 darmowe próby.

Kroki w VS Code

  1. Zainstaluj Convert to Markdown z Marketplace albo naciśnij Ctrl+P (Cmd+P w macOS) i uruchom ext install zovo.zovo-convert-to-markdown.
  2. W widoku Explorer kliknij prawym przyciskiem plik .pdf, .docx, .pptx, .xlsx, .xls, .ods, .csv, .tsv, .html, .epub, .odt lub .rtf i wybierz Convert to Markdown. Można też kliknąć prawym przyciskiem kartę otwartego pliku.
  3. Można też uruchomić z Command Palette polecenie „Convert to Markdown: Convert to Markdown”. Konwertuje ono plik z aktywnej karty albo prosi o wskazanie pliku.
  4. Markdown otwiera się obok pliku jako niezapisany dokument. Przy dużych plikach widać postęp i przycisk Cancel.
  5. Zapisz dokument. Nazwa name.md obok pliku źródłowego jest już wpisana. Aby za każdym razem od razu zapisywać plik w tym miejscu, ustaw toMarkdown.output na file.
  6. Aby wkleić Markdown w inne miejsce, kliknij plik prawym przyciskiem i wybierz Copy as Markdown. Po zaznaczeniu kilku plików w widoku Explorer zostaną one przekonwertowane jeden po drugim.
  7. Brak pliku pod ręką? Uruchom z Command Palette polecenie „Convert to Markdown: Convert a sample file”, aby przekonwertować dołączony przykładowy plik Word, PDF lub PowerPoint.

Co jest za darmo, a co dodaje Zovo Pro

Convert to Markdown i Copy as Markdown są darmowe dla wszystkich formatów, czyli PDF, Word, PowerPoint, Excel, ODS, CSV, TSV, HTML, EPUB, ODT i RTF. Nie trzeba instalować nic więcej, ani Pythona, ani serwera, ani narzędzia wiersza poleceń. Żadne dane nie opuszczają komputera.

Convert a Folder to Markdown w jednym przebiegu konwertuje każdy obsługiwany plik z folderu i jego podfolderów do plików .md, do nowego folderu o tej samej strukturze albo obok każdego pliku, z widocznym postępem i przyciskiem Cancel. Istniejące pliki .md można pominąć albo nadpisać, a _conversion-report.md podaje dla każdego pliku, czy został przekonwertowany, pominięty, czy konwersja się nie udała. Pliki o tej samej nazwie zachowują swój typ w nowej nazwie (report.pdf.md, report.docx.md), więc żaden nie ginie.

Narzędzie Convert a Folder to Markdown (Zovo Pro)

  1. Kliknij prawym przyciskiem folder w widoku Explorer i wybierz „Zovo Pro: Convert a Folder to Markdown” albo uruchom z Command Palette polecenie „Convert to Markdown: Convert a Folder to Markdown (Pro)” i wybierz folder.
  2. Wybierz, gdzie trafią pliki .md: „Into a new folder” (nazwa folderu z dopiskiem -markdown, z tymi samymi podfolderami), „Next to each file” albo „Pick another folder...”.
  3. Jeśli niektóre pliki .md już istnieją, wybierz Skip albo Overwrite. Powiadomienie pokazuje postęp z przyciskiem Cancel.
  4. Na końcu otwiera się _conversion-report.md. Raport podaje dla każdego pliku, czy został przekonwertowany, pominięty, czy konwersja się nie udała, z linkiem do każdego nowego pliku Markdown.

Convert a Folder to Markdown działa 3 razy na twoim komputerze, zanim poprosi o licencję. Przy otwieraniu pliku nie ma wyskakujących okienek ani odliczania.

Kroki w Cursor, Windsurf lub VSCodium

  1. Otwórz widok Extensions skrótem Ctrl+Shift+X (Cmd+Shift+X w macOS).
  2. Wyszukaj zovo.zovo-convert-to-markdown i kliknij Install. Cursor, Windsurf i VSCodium instalują rozszerzenia z Open VSX, gdzie to rozszerzenie ma nazwę zovo/zovo-convert-to-markdown.
  3. Jeśli edytor nie ma galerii rozszerzeń, pobierz plik .vsix ze strony Open VSX i uruchom „Extensions: Install from VSIX...”.
  4. Dalej wszystko działa tak samo jak w VS Code.

Co otwiera Convert to Markdown

  • PDF z nagłówkami rozpoznanymi po rozmiarach czcionki, akapitami ze scalonymi przełamanymi wierszami i dzielonymi wyrazami, listami, prostymi tabelami i stronami dwukolumnowymi czytanymi kolumna po kolumnie. Powtarzające się nagłówki i stopki stron oraz numery stron są pomijane.
  • Word (.docx, .docm, .dotx) z nagłówkami, pogrubieniem, kursywą, przekreśleniem, linkami, zagnieżdżonymi listami, tabelami, cytatami blokowymi i przypisami.
  • PowerPoint (.pptx, .pptm, .ppsx, .potx) z jedną sekcją ## Slide n: title na slajd, z punktami i ich poziomami, tabelami i notatkami prelegenta.
  • Excel i inne arkusze (.xlsx, .xlsm, .xlsb, .xls, .ods) z jedną sekcją ## Sheet: name i tabelą z kreskami pionowymi na każdy arkusz. CSV i TSV dają jedną tabelę.
  • HTML (.html, .htm, .xhtml), w którym bloki kodu zachowują swój język, a skrypty i style są usuwane, oraz EPUB, z rozdziałami w kolejności czytania.

Czego nie robi

  • Zeskanowane pliki PDF (obrazy stron) nie zawierają tekstu do konwersji. Rozpoznawanie tekstu (OCR) nie jest dostępne.
  • Tabele w PDF są wykrywane po odstępach między kolumnami. Tabele bez wyraźnych odstępów trafiają do wyniku jako akapity.
  • W darmowej konwersji obrazy zamieniają się w znaczniki, takie jak *[Image: Map of the site]*. Wykresy, SmartArt i wideo na slajdach są tylko nazywane, a nie konwertowane.
  • Stare pliki Word 97-2003 i RTF dają tekst i tabele bez formatowania. Pliki chronione hasłem i stare pliki PowerPoint 97-2003 dostają komunikat zamiast konwersji.
  • Pliki większe niż 200 MB nie są konwertowane (ustawienie toMarkdown.maxFileSizeMB), a konwersja PDF kończy się po 1000 stronach (ustawienie toMarkdown.pdfMaxPages).

Pytania

Czy to jest darmowe?

Convert to Markdown i Copy as Markdown są darmowe dla wszystkich formatów. Trzy narzędzia Pro, Convert a Folder to Markdown, Convert to Markdown with Images i LLM-ready Markdown Chunks, mają po 3 darmowe próby. Potem wymagają Zovo Pro, 19 USD jednorazowo za wszystkie rozszerzenia Zovo.

Czy pliki są gdzieś wysyłane?

Nie. Konwertery działają na komputerze, wewnątrz VS Code, bez połączeń sieciowych i bez telemetrii.

Czy rozszerzenie konwertuje zeskanowane pliki PDF?

Nie. Zeskanowany PDF zawiera obrazy stron, a nie tekst, a Convert to Markdown nie ma OCR.

Czy działa w Cursor?

Tak. Cursor, Windsurf i VSCodium instalują je z Open VSX, gdzie jest opublikowane jako zovo/zovo-convert-to-markdown.
