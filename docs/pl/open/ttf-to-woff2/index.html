Konwersja TTF do WOFF2 w VS Code

Zainstaluj Font Viewer (TTF, OTF and WOFF viewer). Rozszerzenie otwiera fonty .ttf, .otf, .woff, .woff2, .ttc i .otc z testerem tekstu, siatką glifów, mapą znaków i zakładką Info z licencją, wszystko za darmo. Narzędzie Zovo Pro Convert Font zapisuje plik WOFF2 (albo WOFF) obok pliku TTF lub OTF i potrafi też zamienić WOFF2 z powrotem na instalowalny TTF/OTF. Convert Font i Font Folder Report możesz uruchomić po 3 razy za darmo, potem Zovo Pro kosztuje 19 USD jednorazowo.

Kroki w VS Code

  1. Zainstaluj Font Viewer z Marketplace albo naciśnij Ctrl+P (Cmd+P w macOS) i uruchom ext install zovo.font-viewer-vscode.
  2. Kliknij plik .ttf albo .otf w widoku Explorer. Otworzy się w Font Viewer, który działa tylko do odczytu i nigdy nie zmienia fontu. Jeśli otworzy się inny edytor, kliknij plik prawym przyciskiem i wybierz „Open in Font Viewer”.
  3. W zakładce Type tester wpisz przykładowy tekst, przeciągnij suwak rozmiaru i przesuń suwaki osi zmiennych. Włączaj i wyłączaj funkcje OpenType.
  4. Otwórz zakładkę Info, żeby sprawdzić licencję, projektanta i prawa do osadzania, zanim umieścisz font na stronie internetowej.
  5. Kliknij Copy CSS w zakładce Type tester, żeby dostać regułę @font-face, albo kliknij font prawym przyciskiem w widoku Explorer i wybierz „Copy CSS @font-face”.
  6. Plik WOFF2 utworzysz narzędziem Convert Font (narzędzie Zovo Pro opisane niżej).

Co jest za darmo, a co dodaje Zovo Pro

Za darmo są otwieranie fontów TTF, OTF, WOFF, WOFF2, TTC i OTC, tester tekstu z osiami zmiennymi i funkcjami OpenType, siatka glifów, mapa znaków, zakładka Info z licencją i Copy CSS @font-face.

Convert Font zamienia TTF albo OTF na WOFF2 lub WOFF dla strony internetowej albo WOFF2 z powrotem na instalowalny TTF/OTF. Działa na jednym foncie albo na całym folderze, zapisuje nowe pliki obok źródłowych, a z pliku TTC robi osobny plik dla każdego kroju. Dane tabel są kopiowane bez zmian, więc kontury, hinting, osie zmienne i funkcje OpenType pozostają takie same.

Narzędzie Convert Font (Zovo Pro)

  1. Kliknij przycisk Convert Font na pasku tytułu karty fontu albo kliknij prawym przyciskiem plik fontu lub folder w widoku Explorer i wybierz „Convert Font to WOFF2, WOFF or TTF… (Pro)”.
  2. Możesz też uruchomić z Command Palette polecenie „Font Viewer: Convert Font to WOFF2, WOFF or TTF… (Pro)” i wybrać font albo folder.
  3. Wybierz WOFF2. Nowy plik .woff2 zostanie zapisany obok źródłowego, a plik źródłowy się nie zmieni.
  4. Próba liczy się dopiero wtedy, gdy pliki zostaną zapisane.

Convert Font działa 3 razy na twoim komputerze, zanim poprosi o licencję. Przy otwieraniu pliku nie ma wyskakujących okienek ani odliczania.

Kroki w Cursor, Windsurf lub VSCodium

  1. Otwórz widok Extensions skrótem Ctrl+Shift+X (Cmd+Shift+X w macOS).
  2. Wyszukaj zovo.font-viewer-vscode i kliknij Install. Cursor, Windsurf i VSCodium instalują rozszerzenia z Open VSX, gdzie to rozszerzenie ma nazwę zovo/font-viewer-vscode.
  3. Jeśli edytor nie ma galerii rozszerzeń, pobierz plik .vsix ze strony Open VSX i uruchom „Extensions: Install from VSIX...”.
  4. Dalej wszystko działa tak samo jak w VS Code.

Co otwiera Font Viewer

  • TrueType .ttf, także fonty zmienne, i OpenType .otf z konturami CFF.
  • Fonty WOFF .woff i WOFF2 .woff2.
  • Kolekcje .ttc i .otc. Font wybierasz z listy w nagłówku.
  • Każdy glif z nazwą i punktem kodowym, wyszukiwanie po nazwie, znaku, U+20AC albo id glifu oraz kopiowanie konturu jako SVG.
  • Pokrycie bloków Unicode, pełna tabela nazw, metryki, osie oraz tagi funkcji GSUB i GPOS.

Czego nie robi

  • Kolekcje WOFF2, fonty SVG, .dfont i fonty Type 1 nie są obsługiwane.
  • Pliki większe niż 64 MB (ustawienie fontViewer.maxFileMB) pokazują komunikat zamiast się otworzyć.
  • Kontury glifów pokazują domyślną instancję fontu zmiennego. Tester tekstu, waterfall i mapa znaków podążają za suwakami osi.
  • Fonty kolorowe są rysowane w kolorze w testerze tekstu i mapie znaków, ale siatka glifów pokazuje zwykłe kontury. Fonty zmienne CFF2 są w siatce glifów rysowane samym fontem, a nie z konturów.
  • Convert Font kopiuje dane tabel bez zmian. Narzędzia, które przepisują też dane glifów, dają pliki WOFF2 mniejsze o kilka procent.

Pytania

Czy to jest za darmo?

Podgląd fontów jest za darmo, czyli tester tekstu, glify, mapa znaków, zakładka Info i Copy CSS @font-face. Convert Font i Font Folder Report to narzędzia Pro, które możesz uruchomić po 3 razy za darmo. Potem Zovo Pro kosztuje 19 USD jednorazowo za wszystkie rozszerzenia Zovo.

O ile mniejszy jest plik WOFF2?

W teście z README plik WOFF2 miał około 45 procent rozmiaru TTF (JetBrains Mono variable, z 96 940 do 43 632 bajtów).

Czy konwersja zmienia font?

Nie. Dane tabel są kopiowane bez zmian, więc kontury, hinting, osie zmienne i funkcje OpenType pozostają takie same. Plik źródłowy się nie zmienia.

Czy moje fonty są gdzieś wysyłane?

Nie. Font Viewer działa offline, nie łączy się z siecią i nie wysyła telemetrii.
