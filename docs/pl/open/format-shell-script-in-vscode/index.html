Jak sformatować skrypt bash lub zsh w VS Code

Zainstaluj darmowe rozszerzenie Shell Formatter for Bash & Zsh, otwórz skrypt powłoki i naciśnij Shift+Alt+F (Shift+Option+F na Macu). Silnik shfmt 3.14.1 jest dołączony do rozszerzenia jako WebAssembly, więc nic nie trzeba pobierać, a wynik jest bajt w bajt taki sam jak z shfmt w wierszu poleceń. Format Document, Format Selection, formatowanie przy zapisie, klucze .editorconfig i błędy składni w Problems są darmowe i działają offline. Zovo Pro (19 USD jednorazowo) dodaje trzy narzędzia, Format All Shell Scripts in a Folder, Formatting Check with a Patch File i Minify a Script to a Copy, a każde z nich ma 3 darmowe próby.

Kroki w VS Code

  1. Zainstaluj Shell Formatter for Bash & Zsh z Marketplace albo naciśnij Ctrl+P (Cmd+P w macOS) i uruchom ext install zovo.zovo-shell-formatter.
  2. Otwórz skrypt powłoki i naciśnij Shift+Alt+F (Shift+Option+F na Macu). Jeśli VS Code zapyta, którego formatera użyć, wybierz Shell Formatter albo uruchom polecenie „Shell Formatter: Use as Default Formatter for Shell Scripts”.
  3. Aby formatować przy każdym zapisie, uruchom polecenie „Shell Formatter: Turn On Format on Save for Shell Scripts”.
  4. Dialekt wynika z pierwszej linii (#!/bin/bash, #!/bin/sh, #!/usr/bin/env zsh), potem z nazwy pliku (.bash, .zsh, .zshrc, .bats, .ksh), a w pozostałych przypadkach jest to bash. Aby wybrać go samodzielnie, ustaw shellFormatter.dialect lub shell_variant w .editorconfig.
  5. Kliknij shfmt 3.14.1 na pasku stanu, aby otworzyć menu z formatowaniem, ustawieniem jako domyślny, formatowaniem przy zapisie, pozycją „Copy the matching shfmt command (for CI)” i ustawieniami.
  6. Jeśli skrypt nie jest poprawnym kodem powłoki, pozostaje bez zmian, a panel Problems pokazuje linię i kolumnę błędu.

Co jest za darmo, a co dodaje Zovo Pro

Format Document, Format Selection, formatowanie przy zapisie, wykrywanie dialektu, klucze .editorconfig, menu na pasku stanu, Copy the Matching shfmt Command (for CI) i błędy składni w Problems są darmowe. Nie ma logowania, żądań sieciowych ani telemetrii.

Format All Shell Scripts in a Folder sprawdza każdy skrypt w folderze i jego podfolderach, rozpoznany po nazwie lub po linii #! wskazującej powłokę, i podaje, ile z nich by się zmieniło. Potem formatuje wszystkie albo tworzy raport Markdown, z tym samym silnikiem, ustawieniami i .editorconfig co Format Document. Repozytorium z dziesiątkami skryptów w różnych stylach dostaje jeden styl w jednym przebiegu, a skrypty, które po formatowaniu nie wykonywałyby tych samych poleceń, zostają bez zmian.

Narzędzie Format All Shell Scripts in a Folder (Zovo Pro)

  1. Kliknij prawym przyciskiem folder w widoku Explorer i wybierz „Zovo Pro: Format All Shell Scripts in a Folder” albo uruchom polecenie „Shell Formatter: Format All Shell Scripts in a Folder (Pro)” z Command Palette lub z menu na pasku stanu i wybierz folder.
  2. Tytuł następnej listy podaje, ile skryptów by się zmieniło, np. „N of M scripts would change”.
  3. Wybierz „Format N scripts”, aby sformatować i zapisać każdy plik (Undo działa dla każdego pliku osobno), albo „Show the report only”, aby dostać listę Markdown wszystkich skryptów bez żadnych zmian.
  4. Próba liczy się tylko wtedy, gdy powstał wynik. Folder bez skryptów powłoki albo z samymi sformatowanymi już skryptami nie zużywa próby.

Format All Shell Scripts in a Folder działa 3 razy na twoim komputerze, zanim poprosi o licencję. Przy otwieraniu pliku nie ma wyskakujących okienek ani odliczania.

Kroki w Cursor, Windsurf lub VSCodium

  1. Otwórz widok Extensions skrótem Ctrl+Shift+X (Cmd+Shift+X w macOS).
  2. Wyszukaj zovo.zovo-shell-formatter i kliknij Install. Cursor, Windsurf i VSCodium instalują rozszerzenia z Open VSX, gdzie to rozszerzenie ma nazwę zovo/zovo-shell-formatter.
  3. Jeśli edytor nie ma galerii rozszerzeń, pobierz plik .vsix ze strony Open VSX i uruchom „Extensions: Install from VSIX...”.
  4. Dalej wszystko działa tak samo jak w VS Code.

Co otwiera Shell Formatter for Bash & Zsh

  • Skrypty Bash, POSIX sh (także dash i ash), mksh (także ksh), bats i zsh.
  • Ten sam wynik co shfmt 3.14.1 w wierszu poleceń. 354 z 354 uruchomień na 178 prawdziwych skryptach z projektów na GitHubie i z Homebrew dało wynik identyczny bajt w bajt.
  • Przed zastosowaniem zmiany sformatowany skrypt jest parsowany ponownie i musi wykonywać te same polecenia co oryginał (pliki do 256 KB).
  • Opcje shfmt jako ustawienia lub klucze .editorconfig, czyli wcięcie, operatory binarne w następnej linii, wcięcie case w switch, spacje przy przekierowaniach, zachowanie wyrównania, nawiasy funkcji w następnej linii, upraszczanie i minifikacja.
  • Windowsowe końce linii (CRLF) pozostają CRLF, a skrypt 2 MB formatuje się w około 0,2 sekundy.

Czego nie robi

  • Rozszerzenie nigdy nie zmienia plików Dockerfile, plików .env ani skryptów fish i csh.
  • Obsługa zsh w shfmt jest nowa. Skrypt zsh, którego shfmt nie potrafi sparsować, pozostaje bez zmian.
  • Pliki większe niż 10 MB (ustawienie shellFormatter.maxFileMB) i pliki z bajtami binarnymi, np. samorozpakowujące się instalatory, nie są formatowane.
  • shfmt działa z limitem czasu (domyślnie 10 sekund, ustawienie shellFormatter.timeoutSeconds). Po jego przekroczeniu plik pozostaje bez zmian.

Pytania

Czy to jest darmowe?

Format Document, Format Selection, formatowanie przy zapisie i obsługa .editorconfig są darmowe. Trzy narzędzia Pro, Format All Shell Scripts in a Folder, Formatting Check with a Patch File i Minify a Script to a Copy, mają po 3 darmowe próby. Potem wymagają Zovo Pro, 19 USD jednorazowo za wszystkie rozszerzenia Zovo.

Czy trzeba instalować shfmt?

Nie. shfmt 3.14.1 jest dołączony do rozszerzenia jako WebAssembly, więc działa offline i nic nie trzeba pobierać.

Czy formatowanie może zepsuć skrypt?

Skrypt z błędem składni pozostaje bez zmian. Przed zastosowaniem zmiany sformatowany skrypt jest parsowany ponownie i musi wykonywać te same polecenia co oryginał.

Czy działa w Cursor?

Tak. Cursor, Windsurf i VSCodium instalują je z Open VSX, gdzie jest opublikowane jako zovo/zovo-shell-formatter.
