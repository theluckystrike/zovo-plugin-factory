Formatowanie HTML i CSS w VS Code bez psucia bloków pre i tagów inline

Zainstaluj darmowe rozszerzenie HTML Formatter & CSS Formatter i naciśnij Shift+Alt+F w pliku HTML, CSS, SCSS lub LESS. Rozszerzenie formatuje też bloki <style> i <script> na stronie, stosuje się do pliku .editorconfig, zostawia <pre>, <textarea> i tagi inline w takiej postaci, w jakiej zostały napisane, i nigdy nie zmienia kolejności atrybutów. Działa offline z wbudowanym js-beautify, więc nie potrzeba Node, npm ani pliku konfiguracyjnego. Zovo Pro (19 USD jednorazowo) dodaje trzy narzędzia, Format Folder with Diff Preview, Minify HTML and CSS i HTML Lint Report, a każde z nich ma 3 darmowe próby.

Kroki w VS Code

  1. Zainstaluj HTML Formatter & CSS Formatter z Marketplace albo naciśnij Ctrl+P (Cmd+P w macOS) i uruchom ext install zovo.zovo-html-formatter.
  2. Otwórz plik HTML, CSS, SCSS lub LESS i naciśnij Shift+Alt+F (Shift+Option+F w macOS). Jeśli VS Code zapyta, którego formatera użyć, wybierz HTML Formatter & CSS Formatter.
  3. Aby jednym krokiem ustawić go jako domyślny formater dla wszystkich czterech języków, uruchom „HTML Formatter: Use as Default Formatter for HTML, CSS, SCSS and LESS” z Command Palette.
  4. Zaznacz kilka linii i uruchom Format Selection, aby sformatować tylko je.
  5. Aby formatować przy każdym zapisie, włącz zovoHtmlFormat.formatOnSave albo użyj ustawienia editor.formatOnSave z VS Code, gdy rozszerzenie jest już domyślnym formaterem.
  6. Wcięcia są brane z edytora, a potem z .editorconfig (styl i rozmiar wcięcia, koniec linii, końcowy znak nowej linii, maksymalna długość linii), więc cały zespół dostaje ten sam wynik.

Co jest za darmo, a co dodaje Zovo Pro

Format Document, Format Selection i formatowanie przy zapisie dla HTML, CSS, SCSS i LESS, z obsługą .editorconfig, są darmowe, bez logowania, bez żądań sieciowych i bez telemetrii.

Gdy cała witryna ma mieć jeden styl, Format Folder with Diff Preview formatuje w pamięci każdy plik HTML, CSS, SCSS i LESS w folderze, pokazuje zmienione pliki z diffem obok siebie dla każdego z nich i zapisuje tylko pliki, które zostaną zaznaczone. Każdą zmianę widać, zanim plik zostanie zapisany.

Narzędzie Format Folder with Diff Preview (Zovo Pro)

  1. Kliknij prawym przyciskiem folder w Explorer i wybierz „Zovo Pro: Format folder with diff preview” albo uruchom „HTML Formatter: Format Folder with Diff Preview (Pro)” z Command Palette.
  2. Przejrzyj zmienione pliki. Otwórz diff dowolnego pliku i odznacz pliki, które mają zostać bez zmian.
  3. Zapisz zaznaczone pliki. Próba liczy się tylko wtedy, gdy narzędzie da wynik.

Format Folder with Diff Preview działa 3 razy na twoim komputerze, zanim poprosi o licencję. Przy otwieraniu pliku nie ma wyskakujących okienek ani odliczania.

Kroki w Cursor, Windsurf lub VSCodium

  1. Otwórz widok Extensions skrótem Ctrl+Shift+X (Cmd+Shift+X w macOS).
  2. Wyszukaj zovo.zovo-html-formatter i kliknij Install. Cursor, Windsurf i VSCodium instalują rozszerzenia z Open VSX, gdzie to rozszerzenie ma nazwę zovo/zovo-html-formatter.
  3. Jeśli edytor nie ma galerii rozszerzeń, pobierz plik .vsix ze strony Open VSX i uruchom „Extensions: Install from VSIX...”.
  4. Dalej wszystko działa tak samo jak w VS Code.

Co otwiera HTML Formatter & CSS Formatter

  • CSS w <style> i JavaScript w <script> wewnątrz HTML.
  • Bez zmian zostają: zawartość <pre> i <textarea>, tagi inline w swojej linii, kolejność atrybutów, puste linie między blokami (najwyżej jedna z rzędu), styl wcięć head i body strony oraz tagi szablonów, takie jak {{ }} i {% %}.
  • W SCSS i LESS wieloliniowe mapy i wywołania funkcji zachowują układ, a komentarze na końcu linii zostają w swojej linii.
  • Pozostałe dwa narzędzia Pro. Minify HTML and CSS zapisuje kopie .min.html i .min.css z raportem zaoszczędzonych bajtów i bajtów po gzip. HTML Lint Report wykrywa obrazy bez tekstu alt, pola formularza bez etykiety, powtórzone id, pominięte poziomy nagłówków i inne problemy, w raporcie Markdown i w panelu Problems.

Czego nie robi

  • Osobne pliki .js, .jsx, .ts, Vue i Svelte nie są formatowane przez to rozszerzenie. Formatowany jest tylko JavaScript wewnątrz <script>.
  • Linie nie są zawijane, dopóki nie ustawi się długości zawijania, więc bardzo długa linia zostaje długa.
  • SCSS i LESS przechodzą przez formater CSS. Nietypowa składnia, na przykład detached rulesets w LESS, może zachować oryginalne odstępy.
  • Minifikacja nie skraca JavaScriptu i nie zmienia nazw ani nie łączy reguł CSS.

Pytania

Czy to jest darmowe?

Format Document, Format Selection i formatowanie przy zapisie dla HTML, CSS, SCSS i LESS są darmowe. Trzy narzędzia Pro, Format Folder with Diff Preview, Minify HTML and CSS i HTML Lint Report, mają po 3 darmowe próby. Potem potrzebny jest Zovo Pro, 19 USD jednorazowo za wszystkie rozszerzenia Zovo.

Czy VS Code formatuje HTML bez rozszerzenia?

Tak. VS Code ma wbudowany formater HTML i CSS. To rozszerzenie czyta .editorconfig, zachowuje własny styl wcięć head i body strony, zachowuje układ map w SCSS i LESS oraz dodaje narzędzia Pro do folderów, minifikacji i lintowania.

Czy zmieni moje bloki pre albo kolejność atrybutów?

Nie. Zawartość pre i textarea, tagi inline i kolejność atrybutów zostają takie, jak zostały napisane.

Czy potrzebny jest Node albo npm?

Nie. js-beautify 1.15.4 jest wbudowany w rozszerzenie i działa offline.
