Jak otworzyć plik Excel (.xlsx) w VS Code

VS Code sam nie otwiera pliku .xlsx jako tabeli. Darmowe rozszerzenie Table Viewer pokazuje .xlsx, .xlsm, .xlsb, .xls i .ods, a także CSV i Parquet, jako tabelę z sortowaniem i filtrami, do 1 000 000 wierszy, z formatami liczb ze skoroszytu. Nie potrzebuje Excela ani Pythona. Zovo Pro (19 USD jednorazowo) dodaje między innymi łączenie wielu plików albo wszystkich arkuszy skoroszytu w jeden plik.

Kroki w VS Code

  1. Zainstaluj Table Viewer z Marketplace albo naciśnij Ctrl+P (Cmd+P w macOS) i uruchom ext install zovo.table-viewer-vscode.
  2. Kliknij plik .xlsx w Eksploratorze. Otworzy się jako tabela, a pasek narzędzi pokaże liczbę wierszy i kolumn.
  3. Kliknij nagłówek kolumny, aby sortować. W polu pod nagłówkiem filtrujesz, na przykład >10 albo 5..9. Pole wyszukiwania u góry szuka we wszystkich kolumnach.
  4. Przełącznik „Excel formats” pokazuje liczby, procenty i daty tak jak w Excelu. Dwuklik na komórce otwiera panel z całą wartością.
  5. Do analiz kliknij Query, wpisz SELECT, na przykład z GROUP BY, i naciśnij Ctrl+Enter (Cmd+Enter na Macu). Stats pokazuje liczbę, puste wartości, minimum, maksimum i średnią każdej kolumny.

Co jest za darmo, a co dodaje Zovo Pro

Za darmo są otwieranie plików CSV, TSV, Excel i Parquet, arkusze, filtry, sortowanie, wyszukiwanie, statystyki kolumn, filtr SQL, zapytania SQL na wierszach tabeli, porównanie z Git HEAD oraz eksport do CSV, TSV, JSON i JSON Lines.

Combine Files and Sheets łączy raporty miesięczne z dwunastu plików albo skoroszyt z jednym arkuszem na oddział w jeden plik CSV, XLSX lub Parquet. Kolumny są dopasowywane po nazwie w nagłówku, a kolumny source_file i source_sheet mówią, skąd pochodzi każdy wiersz. Inne narzędzia Pro to zapytania na całym pliku, gdy tabela pokazuje tylko pierwsze wiersze, JOIN z innymi plikami i zapis do Parquet.

Narzędzie Combine Files and Sheets (Zovo Pro)

  1. Kliknij Combine na pasku narzędzi albo uruchom z Command Palette „Excel Viewer Pro: Combine Files and Sheets (Pro)...”. W Eksploratorze działa też prawy klik na folderze, kilku zaznaczonych plikach albo skoroszycie.
  2. Wybierz, co połączyć, i format CSV, XLSX albo Parquet.
  3. Wybierz, gdzie zapisać wynik. Pliki źródłowe się nie zmieniają.

Combine Files and Sheets działa 3 razy na twoim komputerze, zanim poprosi o licencję. Przy otwieraniu pliku nie ma wyskakujących okienek ani odliczania.

Kroki w Cursor, Windsurf lub VSCodium

  1. Otwórz widok Extensions skrótem Ctrl+Shift+X (Cmd+Shift+X w macOS).
  2. Wyszukaj zovo.table-viewer-vscode i kliknij Install. Cursor, Windsurf i VSCodium instalują rozszerzenia z Open VSX, gdzie to rozszerzenie ma nazwę zovo/table-viewer-vscode.
  3. Jeśli edytor nie ma galerii rozszerzeń, pobierz plik .vsix ze strony Open VSX i uruchom „Extensions: Install from VSIX...”.
  4. Dalej wszystko działa tak samo jak w VS Code.

Czego nie robi

  • Table Viewer tylko wyświetla dane. Nie edytuje komórek, a Export zapisuje tylko nowy plik, który wybierzesz.
  • Pliki .xls, .xlsb, .ods i małe .xlsx są wczytywane w całości, do 50 MB (ustawienie tableViewer.maxExcelSizeMB).
  • Tabela wczytuje do 1 000 000 wierszy (ustawienie tableViewer.maxRows). Gdy plik ma ich więcej, pojawia się komunikat.

Pytania

Czy potrzebuję Excela?

Nie. Table Viewer sam czyta plik, bez Excela, Pythona i bazy danych.

Czy mogę zmieniać komórki?

Nie. Table Viewer tylko wyświetla dane. Do edycji użyj Excela, LibreOffice Calc albo edytora arkuszy.

Czy plik jest gdzieś wysyłany?

Nie. Rozszerzenie działa offline, bez logowania.
