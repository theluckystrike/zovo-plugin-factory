Jak przeglądać buckety AWS S3, Cloudflare R2 lub MinIO w VS Code

Zainstaluj darmowe rozszerzenie S3 Explorer i otwórz jego widok S3 Buckets na pasku aktywności (Activity Bar). Działa z AWS S3 (profile z ~/.aws, także profile SSO), Cloudflare R2, MinIO, Backblaze B2, Wasabi i DigitalOcean Spaces. Przeglądanie, otwieranie obiektów tylko do odczytu, wysyłanie, pobieranie, kopiowanie, przenoszenie, zmiana nazwy, usuwanie, wersje, tagi, presigned URL i synchronizacja folderów są darmowe, bez logowania i bez telemetrii. Zovo Pro (19 USD jednorazowo) dodaje trzy narzędzia, Copy to Another Connection, Size and Cost Report i Scheduled Sync, a każde z nich ma 3 darmowe próby.

Kroki w VS Code

  1. Zainstaluj S3 Explorer z Marketplace albo naciśnij Ctrl+P (Cmd+P w macOS) i uruchom ext install zovo.zovo-s3-explorer.
  2. Otwórz widok S3 Explorer na pasku aktywności i kliknij Add Connection. Wybierz profil AWS z ~/.aws albo wpisz klucz dostępu, identyfikator konta R2 i token albo adres URL punktu końcowego MinIO lub innej usługi zgodnej z S3. Wpisane klucze trafiają do pęku kluczy systemu operacyjnego.
  3. Rozwiń połączenie, aby zobaczyć jego buckety. Klucze obiektów ładują się po 1000, z wierszem „Load 1,000 more”. Jeśli klucz dostępu nie pozwala na wyświetlenie listy bucketów, kliknij połączenie prawym przyciskiem i wybierz Add Bucket by Name.
  4. Kliknij obiekt, aby otworzyć go tylko do odczytu w karcie lub w pasującej przeglądarce. Aby zobaczyć jego metadane, tagi, wersje i presigned URL, kliknij go prawym przyciskiem i wybierz Show Details, Versions and Presigned URL.
  5. Aby zmienić obiekt, kliknij go prawym przyciskiem i wybierz Edit and Upload. Edytuje się kopię, a przed zastąpieniem obiektu okno dialogowe pokazuje bucket, klucz i oba rozmiary.
  6. Przeciągnij pliki lub foldery z widoku Explorer na bucket, aby je wysłać, albo kliknij prawym przyciskiem i wybierz Download. Pliki od 16 MB wzwyż są wysyłane w częściach, z postępem i przyciskiem Cancel, a przerwane wysyłanie jest wznawiane tylko z brakującymi częściami.
  7. Aby folder lokalny i prefiks miały tę samą zawartość, kliknij prawym przyciskiem bucket lub folder i wybierz Sync Folder. Przed jakąkolwiek zmianą widać plan próbny (dry-run) z pozycjami nowymi, zmienionymi i do usunięcia.

Co jest za darmo, a co dodaje Zovo Pro

Przeglądanie, otwieranie, Edit and Upload, wysyłanie, pobieranie, kopiowanie, przenoszenie, zmiana nazwy, usuwanie, wersje, tagi, presigned URL i synchronizacja folderów są darmowe, bez logowania, bez konta i bez telemetrii. Rozszerzenie łączy się tylko z dodanymi punktami końcowymi magazynu.

Copy to Another Connection kopiuje obiekty lub całe foldery z jednego połączenia do drugiego, np. z AWS S3 do Cloudflare R2 lub MinIO, z takim samym potwierdzeniem jak przy każdym kopiowaniu, czyli z listą kluczy i nazwami kluczy, które zostałyby zastąpione. Duże obiekty są przesyłane metodą multipart upload. Dane między dostawcami lub kontami przenosi się prosto z drzewa, bez skryptu i bez drugiego narzędzia.

Narzędzie Copy to Another Connection (Zovo Pro)

  1. Najpierw dodaj drugie połączenie. Potem kliknij prawym przyciskiem obiekt lub folder w widoku S3 Buckets i wybierz „Copy to Another Connection... (Pro)” albo kliknij Copy to Another Connection w wierszu „Zovo Pro tools” na końcu widoku.
  2. Wybierz połączenie docelowe, bucket i folder docelowy (pusty oznacza najwyższy poziom).
  3. Przeczytaj listę obiektów w potwierdzeniu i kliknij Copy albo Copy and Replace, jeśli niektóre klucze już istnieją. Powiadomienie pokazuje postęp.
  4. Próba liczy się tylko wtedy, gdy obiekty zostały skopiowane. Escape przy wyborze albo brak drugiego połączenia nie zużywa próby.

Copy to Another Connection działa 3 razy na twoim komputerze, zanim poprosi o licencję. Przy otwieraniu pliku nie ma wyskakujących okienek ani odliczania.

Kroki w Cursor, Windsurf lub VSCodium

  1. Otwórz widok Extensions skrótem Ctrl+Shift+X (Cmd+Shift+X w macOS).
  2. Wyszukaj zovo.zovo-s3-explorer i kliknij Install. Cursor, Windsurf i VSCodium instalują rozszerzenia z Open VSX, gdzie to rozszerzenie ma nazwę zovo/zovo-s3-explorer.
  3. Jeśli edytor nie ma galerii rozszerzeń, pobierz plik .vsix ze strony Open VSX i uruchom „Extensions: Install from VSIX...”.
  4. Dalej wszystko działa tak samo jak w VS Code.

Co otwiera S3 Explorer

  • Profile AWS z kluczami dostępu, credential_process, role z source_profile i profile SSO po aws sso login. Ustawienie endpoint_url w profilu jest uwzględniane.
  • MinIO i inne usługi zgodne z S3 z adresem URL punktu końcowego, regionem, adresami path-style lub virtual-hosted i opcją akceptowania certyfikatu z podpisem własnym.
  • Metadane, typ zawartości, klasa magazynu, ETag, tagi (edycja i zapis), wersje (otwieranie, pobieranie, przywracanie) oraz presigned URL dla GET lub PUT ważne od 15 minut do 7 dni.
  • Buckety z milionami kluczy, ładowanych po 1000, z wyszukiwaniem i filtrowaniem po prefiksie.
  • Pobieranie zachowuje strukturę folderów i nigdy nie zapisuje poza wybranym folderem. Klucze z segmentami .., literami dysków lub bajtami NUL są pomijane i wypisywane.

Czego nie robi

  • Rozszerzenie nigdy samo nie używa profilu AWS default ani AWS_PROFILE. Profil do połączenia wybiera się samodzielnie.
  • Obiekty tekstowe większe niż 10 MB najpierw wymagają potwierdzenia, a potem pokazują pierwszy 1 MB. Obiekty binarne większe niż 200 MB wymagają potwierdzenia przed pobraniem.
  • Otwarte obiekty są tylko do odczytu. Do bucketu zapisuje wyłącznie Edit and Upload, po potwierdzeniu.
  • Scheduled Sync działa tylko przy otwartym VS Code, co 5 do 60 minut, i nigdy niczego nie usuwa.
  • Żądania bez odpowiedzi są przerywane po 30 sekundach (ustawienie s3Explorer.requestTimeoutSeconds).

Pytania

Czy to jest darmowe?

Przeglądanie, otwieranie, wysyłanie, pobieranie, kopiowanie, przenoszenie, zmiana nazwy, usuwanie, wersje, tagi, presigned URL i synchronizacja folderów są darmowe. Trzy narzędzia Pro, Copy to Another Connection, Size and Cost Report i Scheduled Sync, mają po 3 darmowe próby. Potem wymagają Zovo Pro, 19 USD jednorazowo za wszystkie rozszerzenia Zovo.

Gdzie są przechowywane klucze?

Wpisane klucze trafiają do pęku kluczy systemu operacyjnego przez VS Code SecretStorage, nigdy do plików ustawień. Profile AWS są odczytywane z ~/.aws dopiero po wybraniu jednego z nich.

Czy działa z Cloudflare R2 i MinIO?

Tak. R2 wymaga identyfikatora konta i klucza dostępu tokenu API R2. MinIO i inne usługi zgodne z S3 wymagają adresu URL punktu końcowego, regionu i wyboru adresów path-style lub virtual-hosted.

Czy działa w Cursor?

Tak. Cursor, Windsurf i VSCodium instalują je z Open VSX, gdzie jest opublikowane jako zovo/zovo-s3-explorer.
