Poradniki po polsku

VS Code i edytory na nim oparte (Cursor, Windsurf, VSCodium) otwierają pliki tekstowe, obrazy i część multimediów. Do wielu innych formatów potrzebne jest rozszerzenie. Każdy poradnik podaje kroki i mówi, co jest za darmo.

  • Jak otworzyć plik .docx w VS Code. Czytaj pliki Word, OpenDocument i stare .doc w VS Code lub Cursor, ze spisem nagłówków, wyszukiwaniem, śledzonymi zmianami i komentarzami. Za darmo i offline.
  • Jak otworzyć plik PowerPoint (.pptx) w VS Code. Oglądaj pliki .pptx, .ppsx i stare .ppt w VS Code lub Cursor, z miniaturami, notatkami prelegenta, wyszukiwaniem i pokazem na pełnym ekranie. Za darmo, bez PowerPointa.
  • Jak otworzyć plik Excel (.xlsx) w VS Code. Otwieraj pliki .xlsx, .xls i .ods w VS Code lub Cursor jako tabelę, z formatami liczb z Excela, filtrem, sortowaniem, statystykami i SQL. Za darmo, offline, bez Excela.
  • Czytanie PDF w trybie ciemnym w VS Code. Czytaj PDF w VS Code lub Cursor na ciemnych albo sepiowych stronach. Tekst robi się jasny, a zdjęcia zachowują prawdziwe kolory. Z wyszukiwaniem, spisem treści i zakreśleniami. Za darmo.
  • Podgląd i edycja plików binarnych w VS Code. Oglądaj, przeszukuj, edytuj i porównuj bajty dowolnego pliku w VS Code lub Cursor, od 0 bajtów do obrazu 4 GB. Z Data Inspector i bezpiecznym zapisem. Za darmo i offline.
  • Jak otworzyć pliki .npy i .npz z NumPy w VS Code. Otwórz tablice NumPy z plików .npy i .npz w VS Code z darmowym Tensor Viewer: dtype, kształt, statystyki, mapy cieplne, obrazy i wartości, bez Pythona.
  • Darmowa przeglądarka plików NetCDF w VS Code. Otwórz pliki .nc NetCDF w VS Code w Windows, macOS lub Linuksie: nagłówek, zmienne, mapy z liniami brzegowymi i serie czasowe. Także HDF5 .h5 i MATLAB 7.3 .mat.
  • Jak otworzyć bazę SQLite w VS Code. Otwórz plik .db lub .sqlite w VS Code z darmowym SQLite Viewer & Editor: tabele, schemat i SQL, a potem zmień komórki i wiersze i zapisz z kopią zapasową.
  • Podgląd diagramów Mermaid w VS Code. Podgląd diagramów Mermaid z plików .mmd i bloków w Markdown w VS Code z darmowym Mermaid Viewer. Podgląd na żywo, eksport PNG i SVG, offline, bez logowania.
  • Odtwarzanie wideo MOV, MKV, WebM i MP4 z dźwiękiem w VS Code. Odtwarzaj w VS Code pliki MP4, MOV i M4V z dźwiękiem AAC bez dodatkowych instalacji. MKV, WebM i AVI zagrają z twoim ffmpeg. Darmowy odtwarzacz z napisami.
  • Jak otworzyć plik PCAP w VS Code. Czytaj zrzuty .pcap, .pcapng i .pcap.gz w VS Code z darmowym PCAP Viewer: lista pakietów, drzewo protokołów, widok hex i filtry. Bez instalowania Wiresharka.
  • Automatyczna zmiana nazw tagów HTML, JSX i Vue w VS Code. Zmień nazwę tagu HTML, JSX lub Vue, a pasujący tag zmieni się, gdy piszesz. Darmowe rozszerzenie oparte na linked editing w VS Code, z domykaniem i jednym Undo.
  • Czytaj i wznawiaj historię Claude Code w VS Code. Czytaj, przeszukuj i wznawiaj stare sesje Claude Code i Codex w VS Code. Subagenci pod sesją, edycje jako diffy, sumy tokenów. Tylko do odczytu i offline.
  • Jak zamienić TIFF na PNG bez utraty jakości. Otwieraj pliki TIFF, BigTIFF i GeoTIFF w VS Code za darmo, a potem zapisz jedną albo wszystkie strony jako PNG z dokładnymi wartościami 8 i 16 bitów. Offline.
  • Konwersja TTF do WOFF2 w VS Code. Podglądaj fonty TTF, OTF, WOFF i WOFF2 w VS Code za darmo, a potem zamień TTF albo OTF na WOFF2 obok pliku źródłowego. Offline, bez wysyłania plików.
  • Normalizacja głośności audio do docelowego poziomu LUFS. Odtwarzaj WAV, MP3, FLAC, Ogg i Opus w VS Code z darmowym miernikiem LUFS, a potem zapisz nowy WAV na -14, -16 lub -23 LUFS. Offline, bez wysyłania plików.
  • XMind do PDF bez XMind: wszystkie arkusze w jednym pliku PDF. Otwórz mapę myśli .xmind w VS Code bez XMind i zapisz wszystkie arkusze w jednym PDF, strona na arkusz. Podgląd jest za darmo, PDF to narzędzie Zovo Pro.
  • DXF do CSV w VS Code: wyciągnij atrybuty bloków i tekst. Otwórz rysunek DXF w VS Code i zapisz atrybuty bloków, liczby bloków, tekst albo warstwy jako CSV do Excela. Podgląd jest za darmo, eksport CSV to Zovo Pro.
  • Jak porównać dwa pliki ZIP w VS Code. Otwieraj pliki ZIP, JAR, TAR i GZ w VS Code za darmo, a potem zobacz pliki dodane, usunięte i zmienione między dwoma archiwami w raporcie Markdown (Zovo Pro).
  • Jak przekonwertować plik PDF, Word, PowerPoint lub Excel do Markdown w VS Code. Kliknij prawym przyciskiem plik PDF, DOCX, PPTX, XLSX, CSV, HTML lub EPUB w VS Code, a Markdown otworzy się obok. Za darmo, offline, bez Pythona i wysyłania.
  • Formatowanie XML w VS Code i zapytania XPath. Formatuj i minifikuj XML w VS Code, zmieniając tylko białe znaki między tagami, uruchamiaj XPath 1.0 z przestrzeniami nazw pliku i kopiuj XPath spod kursora.
  • Jak edytować plik .env w VS Code bez pokazywania sekretów na ekranie. Kolory w plikach .env w VS Code, sekrety ukryte jako kropki, dopóki kursor nie jest w ich linii, i poprawki duplikatów kluczy i cudzysłowów. Za darmo, offline.
  • Jak zobaczyć obraz ze ścieżki w kodzie, na marginesie i po najechaniu myszą. Miniatura na marginesie i podgląd obrazu z rozmiarem w pikselach i rozmiarem pliku dla ścieżek w JS, CSS, HTML i Markdown w VS Code. Za darmo.
  • Jak przeglądać buckety AWS S3, Cloudflare R2 lub MinIO w VS Code. Buckety S3, R2, MinIO, B2 i Wasabi w VS Code. Obiekty tylko do odczytu, wysyłanie ze wznawianiem, pobieranie i synchronizacja folderu po planie dry-run.
  • Jak sformatować skrypt bash lub zsh w VS Code. Formatowanie skryptów bash, sh, zsh, bats i mksh w VS Code skrótem Shift+Alt+F lub przy zapisie. Wbudowany shfmt 3.14.1 czyta .editorconfig i działa offline.
  • Edycja plików .proto w VS Code z kolorowaniem składni, formatowaniem i przejściem do definicji. Kolorowanie, formatowanie i sprawdzanie plików .proto w VS Code: formatter zachowuje komentarze, błędy w brzmieniu protoc. Darmowe, offline, bez protoc.
  • Formatowanie i sprawdzanie pliku konfiguracyjnego nginx w VS Code. Formatowanie nginx.conf w VS Code bez psucia poprawnego pliku. Brakujący ; i dyrektywy w złym bloku widać od razu, a podpowiedzi obejmują około 300 dyrektyw.
  • Podgląd diagramu PlantUML w VS Code w trakcie pisania. Podgląd PlantUML na żywo w VS Code dla plików .puml i bloków plantuml w Markdownie, rysowany na Twoim komputerze. Wymaga Javy 11, bez Graphviz.
