Jak porównać dwa pliki Excel lub CSV w VS Code

Zainstaluj darmowe rozszerzenie Excel Compare & XLSX Diff i wybierz dwa skoroszyty lub pliki CSV. Zmienione komórki są żółte, a stara wartość jest przekreślona, dodane wiersze są zielone, a usunięte czerwone. Wiersze są do siebie dopasowywane, a kolumny łączone po nagłówku, więc jeden wstawiony wiersz lub kolumna to jedna zmiana. Przed commitem można też porównać skoroszyt z jego wersją w Git HEAD. Wszystko to jest darmowe i działa bez żądań sieciowych. Zovo Pro (19 USD jednorazowo) dodaje trzy narzędzia, Export a diff report, Match rows by key columns i Compare two folders of workbooks, a każde z nich ma 3 darmowe próby.

Kroki w VS Code

  1. Zainstaluj Excel Compare & XLSX Diff z Marketplace albo naciśnij Ctrl+P (Cmd+P w macOS) i uruchom ext install zovo.zovo-excel-compare.
  2. Zaznacz dwa pliki w widoku Explorer, kliknij prawym przyciskiem i wybierz Compare Selected Excel Files. Możesz też kliknąć prawym przyciskiem jeden plik, wybrać Compare with... i wskazać drugi. Z Command Palette uruchom "Excel Compare: Compare Two Excel or CSV Files...".
  3. Działa dowolne połączenie .xlsx, .xlsm, .xls, .ods, .csv i .tsv, więc można porównać .xlsx z .csv.
  4. Przeczytaj linię podsumowania, a potem kartę każdego arkusza z liczbą różnic. Kliknij komórkę, aby zobaczyć jej pełną starą i nową wartość i je skopiować.
  5. Naciskaj N i P (albo Next i Previous), aby przechodzić przez wszystkie zmiany we wszystkich arkuszach. Przełączaj Values i Formulas, aby porównać to, co pokazują komórki, albo same formuły.
  6. Aby przed commitem sprawdzić, co zostało zmienione, kliknij prawym przyciskiem skoroszyt w repozytorium Git i wybierz Compare with Git HEAD.

Co jest za darmo, a co dodaje Zovo Pro

Porównanie dowolnych dwóch plików, siatka, Values i Formulas, przechodzenie do następnej i poprzedniej zmiany, porównanie CSV z wykrytym kodowaniem i separatorem oraz Compare with Git HEAD są darmowe, bez logowania, bez żądań sieciowych i bez telemetrii.

Gdy zmiany musi zobaczyć ktoś inny, Export a diff report zapisuje skoroszyt XLSX, w którym zmienione, dodane i usunięte komórki są wypełnione kolorem, z arkuszem Summary i listą Changes z każdą starą i nową wartością. Może też zapisać jedną stronę HTML albo listę zmian w CSV. Wysyłasz jeden plik zamiast zrzutów ekranu.

Narzędzie Export a diff report (Zovo Pro)

  1. Porównaj dwa pliki jak wyżej, a potem kliknij Export report na pasku narzędzi porównania albo uruchom "Excel Compare: Export a diff report (XLSX, HTML or CSV) (Pro)" z Command Palette.
  2. Wybierz XLSX, HTML lub CSV.
  3. Wybierz miejsce zapisu raportu. Próba jest zużywana tylko wtedy, gdy raport został zapisany.

Export a diff report działa 3 razy na twoim komputerze, zanim poprosi o licencję. Przy otwieraniu pliku nie ma wyskakujących okienek ani odliczania.

Kroki w Cursor, Windsurf lub VSCodium

  1. Otwórz widok Extensions skrótem Ctrl+Shift+X (Cmd+Shift+X w macOS).
  2. Wyszukaj zovo.zovo-excel-compare i kliknij Install. Cursor, Windsurf i VSCodium instalują rozszerzenia z Open VSX, gdzie to rozszerzenie ma nazwę zovo/zovo-excel-compare.
  3. Jeśli edytor nie ma galerii rozszerzeń, pobierz plik .vsix ze strony Open VSX i uruchom „Extensions: Install from VSIX...”.
  4. Dalej wszystko działa tak samo jak w VS Code.

Co otwiera Excel Compare & XLSX Diff

  • Arkusze dopasowywane po nazwie, a potem po pozycji. Arkusze, które są tylko w jednym pliku, są pokazywane jako dodane lub usunięte.
  • CSV i TSV z wykrytym kodowaniem (UTF-8 z BOM lub bez, UTF-16, strony kodowe Windows) i wykrytym separatorem (przecinek, średnik, tabulator lub pionowa kreska), także z polami w cudzysłowach zawierającymi znaki nowej linii.
  • Duże arkusze: siatka rysuje tylko wiersze widoczne na ekranie, więc arkusz z 300 000 wierszy przewija się jak krótki.
  • Uwagi, gdy różnią się scalone komórki albo gdy limit obciął arkusz.
  • Dwa pozostałe narzędzia Pro: Match rows by key columns dopasowuje wiersze po kolumnie ID, więc posortowane lub przestawione arkusze porównują się poprawnie, a przeniesione wiersze są oznaczane; Compare two folders of workbooks łączy pliki w pary po nazwie i pokazuje, które są takie same, które się różnią, a które są tylko w jednym folderze.

Czego nie robi

  • Pliki do 200 MB (ustawienie excelCompare.maxFileSizeMB), 300 000 wierszy na arkusz (excelCompare.maxRows), 1000 kolumn i 200 arkuszy. Uwaga w widoku informuje, kiedy zadziałał limit.
  • Skoroszyt, który po rozpakowaniu zająłby ponad 600 MB albo jest skompresowany jak zip bomb, jest odrzucany przed rozpakowaniem.
  • Bez narzędzia Pro Match rows by key columns wiersze są dopasowywane po treści i pozycji, a nie po kolumnie ID.
  • Rozszerzenie tylko porównuje. Nie edytuje i nie scala plików.

Pytania

Czy to jest darmowe?

Porównanie dwóch skoroszytów lub plików CSV, Values i Formulas, przechodzenie do następnej i poprzedniej zmiany oraz Compare with Git HEAD są darmowe. Trzy narzędzia Pro, Export a diff report, Match rows by key columns i Compare two folders of workbooks, mają po 3 darmowe próby. Potem wymagają Zovo Pro, 19 USD jednorazowo za wszystkie rozszerzenia Zovo.

Czy VS Code porówna dwa pliki Excel bez rozszerzenia?

Nie. Plik .xlsx to archiwum zip z częściami XML, więc wbudowany diff pokazuje go jako plik binarny. Potrzebne jest rozszerzenie, które czyta skoroszyt.

Czy wiersz wstawiony na górze oznacza wszystkie wiersze poniżej jako zmienione?

Nie. Wiersze są dopasowywane przed porównaniem, więc wstawiony wiersz pojawia się jako jeden dodany wiersz.

Czy można zobaczyć, co zmieniło się w skoroszycie od ostatniego commita?

Tak. Kliknij prawym przyciskiem plik w repozytorium Git i wybierz Compare with Git HEAD. Polecenie używa lokalnego gita.
