Formatowanie XML w VS Code i zapytania XPath

Zainstaluj darmowe rozszerzenie XML Formatter & XPath Tools, otwórz plik XML i naciśnij Shift+Alt+F (Shift+Option+F na Macu). Zmieniają się tylko białe znaki między tagami. Tekst, CDATA, komentarze, xml:space="preserve" i wartości atrybutów pozostają identyczne co do bajtu, a plik, który nie jest poprawnie sformułowany, nigdy nie jest zmieniany. Formatowanie, Minify XML, XPath 1.0 z prefiksami przestrzeni nazw zadeklarowanymi w pliku, Copy XPath i widok XML Tree są darmowe i działają offline. Zovo Pro (19 USD jednorazowo) dodaje trzy narzędzia, Run XPath on Every XML File in a Folder, Format All XML Files in a Folder i Compare Two XML Files Ignoring Formatting, a każde z nich ma 3 darmowe próby.

Kroki w VS Code

  1. Zainstaluj XML Formatter & XPath Tools z Marketplace albo naciśnij Ctrl+P (Cmd+P w macOS) i uruchom ext install zovo.zovo-xml-xpath-tools.
  2. Otwórz plik .xml i naciśnij Shift+Alt+F (Shift+Option+F na Macu) albo uruchom Format Document. Jeśli zainstalowanych jest kilka formaterów XML, VS Code zapyta, którego użyć. Działa też Format Selection.
  3. Formater stosuje ustawiony rozmiar tabulacji oraz tabulatory lub spacje i zachowuje znaki końca wiersza, znacznik kolejności bajtów (BOM) i końcowy znak nowego wiersza. Jeśli plik nie jest poprawnie sformułowany, nic się nie zmienia, a błąd jest pokazywany z numerem wiersza i kolumny.
  4. Aby zamiast tego zmniejszyć plik, uruchom „XML: Minify XML” na całym pliku lub na zaznaczeniu. Komentarze zostają, chyba że włączysz xmlXpathTools.minify.removeComments.
  5. Aby uruchomić XPath, kliknij przycisk wyszukiwania na pasku tytułu edytora albo uruchom „XML: Evaluate XPath…”. Wyniki pojawiają się w XPath Results z numerem wiersza. Kliknięcie wyniku zaznacza go w edytorze.
  6. Kliknij XPath na pasku stanu, aby skopiować ścieżkę elementu pod kursorem: z pozycjami, z atrybutami id lub name albo w przenośnej formie z local-name().
  7. Plik większy niż 50 MB kliknij prawym przyciskiem w widoku Explorer i wybierz „Format Large XML File on Disk…”. Polecenie zapisuje obok plik name.formatted.xml albo, po potwierdzeniu, zastępuje oryginalny plik.

Co jest za darmo, a co dodaje Zovo Pro

Format Document, Format Selection, Minify XML, XPath 1.0, Copy XPath, widok XML Tree, błędy składni XML w panelu Problems i Format Large XML File on Disk są darmowe. Nie trzeba się logować, a rozszerzenie nie zawiera kodu sieciowego.

Run XPath on Every XML File in a Folder uruchamia jedno wyrażenie XPath na każdym pliku .xml, .xsd, .csproj, .svg, .kml i podobnym w folderze, w każdym z jego własnymi prefiksami przestrzeni nazw. Wyniki otwierają się jako CSV (file, line, kind, name, value) do arkusza kalkulacyjnego, jako JSON do skryptu albo jako raport Markdown do przeglądu. Tę samą wartość z wielu plików, na przykład każdy artifactId z zestawu plików pom.xml, dostaje się bez otwierania ich po kolei.

Narzędzie Run XPath on Every XML File in a Folder (Zovo Pro)

  1. Kliknij prawym przyciskiem folder w widoku Explorer i wybierz „Zovo Pro: Run XPath on Every XML File in a Folder” albo uruchom z Command Palette „XML: Run XPath on Every XML File in a Folder (Pro)” i wybierz folder.
  2. Albo, po uruchomieniu XPath w jednym pliku, kliknij ostatni wiersz w XPath Results, „Run this XPath on every XML file in a folder”, aby uruchomić to samo wyrażenie na folderze.
  3. Wpisz XPath. Powiadomienie pokazuje postęp z przyciskiem Cancel.
  4. Wybierz „Open as CSV”, „Open as JSON” albo „Open a Markdown report”. Wyniki otwierają się w nowej karcie edytora. Próba liczy się tylko wtedy, gdy powstanie wynik. Escape, literówka w XPath albo folder bez plików XML nie zużywają próby.

Run XPath on Every XML File in a Folder działa 3 razy na twoim komputerze, zanim poprosi o licencję. Przy otwieraniu pliku nie ma wyskakujących okienek ani odliczania.

Kroki w Cursor, Windsurf lub VSCodium

  1. Otwórz widok Extensions skrótem Ctrl+Shift+X (Cmd+Shift+X w macOS).
  2. Wyszukaj zovo.zovo-xml-xpath-tools i kliknij Install. Cursor, Windsurf i VSCodium instalują rozszerzenia z Open VSX, gdzie to rozszerzenie ma nazwę zovo/zovo-xml-xpath-tools.
  3. Jeśli edytor nie ma galerii rozszerzeń, pobierz plik .vsix ze strony Open VSX i uruchom „Extensions: Install from VSIX...”.
  4. Dalej wszystko działa tak samo jak w VS Code.

Co otwiera XML Formatter & XPath Tools

  • Pliki, które VS Code otwiera jako XML. Rozszerzenie otwiera jako XML również pliki .kml, .gpx, .rss, .atom, .wsdl, .dbk, .xlf, .xliff, .resx, .nuspec, .props, .targets i .xaml.
  • Duże pliki. Formatowanie, drzewo i XPath działają w wątku w tle. W testach rozszerzenia plik 49 MB z około 1 milionem elementów został sformatowany w 1,6 sekundy.
  • Proste nazwy pasują też do domyślnej przestrzeni nazw, więc //dependency/artifactId działa w pom.xml. Dla ścisłego XPath 1.0 włącz xmlXpathTools.xpath.strictNamespaces.
  • Atrybuty mogą zostać tak, jak są zapisane, trafić do jednego wiersza albo stanąć po jednym w wierszu (ustawienie xmlXpathTools.format.attributes).
  • Widok XML Tree w panelu Explorer podąża za kursorem, a Problems pokazuje błędy składni XML z numerem wiersza i kolumny.

Czego nie robi

  • Tylko XPath 1.0. Nie ma XPath 2.0 ani 3.1, XQuery ani XSLT.
  • Rozszerzenie sprawdza, czy plik jest poprawnie sformułowany. Nie waliduje go względem XSD ani DTD.
  • Pliki większe niż 50 MB można sformatować na dysku, ale VS Code nie przekazuje ich rozszerzeniom, więc drzewo i XPath na nich nie działają.
  • Polecenie formatowania na dysku czyta UTF-8, UTF-16 ze znacznikiem kolejności bajtów i ISO-8859-1.
  • Element z tekstem w środku, taki jak <p>Some <b>bold</b> text</p>, zostaje w swoim wierszu tak, jak został zapisany. Nowe podziały wierszy dostają tylko elementy, które zawierają tagi i nie zawierają tekstu.

Pytania

Czy to jest darmowe?

Formatowanie, Minify XML, XPath, Copy XPath, widok XML Tree i sprawdzanie poprawności składni są darmowe. Trzy narzędzia Pro, Run XPath on Every XML File in a Folder, Format All XML Files in a Folder i Compare Two XML Files Ignoring Formatting, mają po 3 darmowe próby. Potem wymagają Zovo Pro, 19 USD jednorazowo za wszystkie rozszerzenia Zovo.

Czy formatowanie zmienia tekst albo CDATA?

Nie. Zmieniają się tylko białe znaki między tagami, w elementach, które zawierają tagi i nie zawierają tekstu. Tekst, CDATA, komentarze i zawartość w xml:space="preserve" są kopiowane bez zmian, a drugie formatowanie niczego nie zmienia.

Dlaczego XPath nic nie znajduje w pom.xml?

Plik ma domyślną przestrzeń nazw. W tym rozszerzeniu proste nazwy pasują też do domyślnej przestrzeni nazw, więc //dependency działa. Dla ścisłego XPath 1.0 włącz xmlXpathTools.xpath.strictNamespaces.

Czy działa w Cursor?

Tak. Cursor, Windsurf i VSCodium instalują je z Open VSX, gdzie jest opublikowane jako zovo/zovo-xml-xpath-tools.
