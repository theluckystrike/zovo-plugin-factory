Editar bases de datos SQLite en VS Code

Instala SQLite DB Viewer y haz clic en un archivo .db o .sqlite: se abre como una tabla en modo de solo lectura. Pulsa “Enable editing” para cambiar celdas y filas, ejecutar INSERT o UPDATE o importar un CSV; al guardar, se comprueban las restricciones, se hace una copia de seguridad y se reemplaza el archivo de una vez. Todo eso es gratis. Zovo Pro (USD 19 una sola vez) añade la comparación de dos bases de datos con un script de sincronización, un diagrama ER y la exportación de todas las tablas, con 3 usos gratis de cada herramienta.

Instalar en VS CodePágina del MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

Gratis, licencia MIT. Extension ID zovo.sqlite-table-viewer.

Pasos en VS Code

  1. Instala SQLite DB Viewer desde el Marketplace, o pulsa Ctrl+P (Cmd+P en macOS) y ejecuta ext install zovo.sqlite-table-viewer.
  2. Haz clic en un archivo .db, .sqlite, .sqlite3, .db3, .s3db, .sl3, .vscdb o .gpkg en el Explorador. Se abre como tabla, en modo de solo lectura. Puedes ordenar, filtrar columnas, buscar en todas las columnas y ver el esquema en la pestaña Schema.
  3. Pulsa “Enable editing”. Antes de empezar, la extensión te avisa si otro programa tiene el archivo abierto, si el archivo -wal contiene transacciones que aún no están en el archivo principal o si un -journal indica una escritura en curso.
  4. Haz doble clic en una celda (o pulsa Enter, F2 o empieza a escribir), cambia el valor y confirma con Enter. Para textos largos, JSON o BLOB, la barra espaciadora abre el panel de la celda. Con + Row, Duplicate y Delete rows añades, copias o borras filas.
  5. En la pestaña SQL puedes ejecutar INSERT, UPDATE, DELETE, REPLACE, CREATE, DROP y ALTER. Cada cambio queda en una lista de pendientes con su SQL y su Undo; “Show SQL” muestra todas las sentencias y “Discard all” las descarta.
  6. Pulsa Save (Ctrl+S o Cmd+S). Se comprueban las claves foráneas con PRAGMA foreign_key_check, se ejecuta PRAGMA quick_check, se crea una copia como name.db.20261109-143000.bak y la base nueva se escribe en un archivo temporal que reemplaza al original.
  7. Para crear una base de datos a partir de un CSV, haz clic derecho en el archivo .csv y elige “Import CSV into a new SQLite database…”.

En Cursor, Windsurf y VSCodium

Estos editores instalan extensiones desde Open VSX. Abre la vista Extensions (Ctrl+Shift+X), busca zovo.sqlite-table-viewer y pulsa Install. Su página en Open VSX es zovo/sqlite-table-viewer. Después se usa igual que en VS Code.

Qué es gratis

Es gratis abrir y leer la base, usar la pestaña SQL, editar celdas y filas, guardar con copia de seguridad, importar CSV y TSV (en una tabla nueva o existente, con vista previa, delimitador, codificación, fila de cabecera, mapeo y transformaciones de columnas), las herramientas de tabla (añadir, renombrar y borrar columnas, renombrar tablas, buscar y reemplazar en una columna) y exportar las filas visibles como CSV, JSON o SQL INSERT. Los valores se guardan como pide la columna: 42 en una columna INTEGER se guarda como número, 007 se queda como texto y un entero de 64 bits conserva todos sus dígitos. Si falla una restricción CHECK, NOT NULL, UNIQUE o de clave foránea, solo se rechaza ese cambio y se te dice cuál era. En la prueba del autor, un CSV de un millón de filas se importó en unos 2 segundos. SQLite funciona como WebAssembly dentro de VS Code, sin instalar nada, sin peticiones de red y sin telemetría.

Qué añade Zovo Pro

“Compare SQLite Databases” compara las tablas, columnas, índices, vistas, triggers y filas de dos archivos SQLite, emparejando las filas por clave primaria (o rowid). Genera un informe en Markdown con los recuentos y las primeras diferencias de cada tabla, y a-vs-b-sync.sql, un script que hace que la segunda base coincida con la primera. El script se abre en un editor y nunca se ejecuta por ti, y las dos bases solo se leen. Te evita comparar tabla por tabla con consultas escritas a mano. Las otras herramientas Pro son “ER Diagram of a SQLite Database”, que genera un diagrama SVG, un erDiagram de Mermaid y un documento con el esquema, y “Export All SQLite Tables to Excel or CSV”, que guarda todas las tablas en un libro de Excel o en un CSV por tabla.

Cómo se usa Compare SQLite Databases

  1. Haz clic derecho en la primera base de datos en el Explorador y elige “Zovo Pro: Compare SQLite Databases”. También puedes empezar desde el botón DB tools del editor o con “Compare SQLite Databases (Pro)…” en la paleta de comandos.
  2. Elige la segunda base de datos.
  3. Revisa el informe en Markdown y el script a-vs-b-sync.sql, y decide tú si lo ejecutas.

Compare SQLite Databases funciona 3 veces gratis antes de pedir una licencia. Al abrir un archivo no aparece ninguna ventana emergente ni cuenta atrás.

Lo que no hace

  • La base se carga entera en memoria: se abren archivos de hasta 512 MB y se editan los de hasta 256 MB. Los archivos de entre 256 y 512 MB se abren solo para lectura.
  • No abre bases de datos cifradas (SQLCipher, SEE).
  • Solo se editan archivos locales; los de espacios de trabajo remotos o virtuales se abren en solo lectura.
  • Si cierras la pestaña con cambios sin guardar, esos cambios se pierden.

Preguntas

¿Es gratis?

Sí. Abrir, editar, guardar con copia de seguridad, importar CSV y la pestaña SQL son gratis, sin periodo de prueba ni avisos de licencia. Solo la comparación de bases, el diagrama ER y la exportación de todas las tablas son herramientas de Zovo Pro, con 3 usos gratis cada una.

¿Funciona en Cursor?

Sí. Cursor instala las extensiones desde Open VSX. Busca zovo.sqlite-table-viewer en la vista de extensiones.

¿Puede dañar mi base de datos?

La base se abre en solo lectura y nada se escribe hasta que pulsas “Enable editing” y luego Save. Save se niega si el archivo cambió en el disco desde que lo abriste, hace antes una copia de seguridad y reemplaza el archivo de una vez, así que si algo falla queda el archivo antiguo o el nuevo, nunca una mezcla de los dos.

¿Necesito instalar sqlite3?

No. SQLite va incluido como WebAssembly. La herramienta sqlite3 solo se usa, si está instalada, para “Checkpoint and reload”.

Todas las funciones y ajustes están en la página de SQLite DB Viewer (en inglés).
