Formatear XML en VS Code y ejecutar XPath sobre él

Instala la extensión gratuita XML Formatter & XPath Tools, abre un archivo XML y pulsa Shift+Alt+F (Shift+Option+F en Mac). Solo cambian los espacios en blanco entre etiquetas. El texto, CDATA, los comentarios, xml:space="preserve" y los valores de los atributos se conservan byte a byte, y un archivo que no está bien formado nunca se modifica. El formateo, Minify XML, XPath 1.0 con los prefijos de namespace del propio archivo, Copy XPath y la vista XML Tree son gratis y funcionan sin conexión. Zovo Pro (USD 19 una sola vez) añade tres herramientas, Run XPath on Every XML File in a Folder, Format All XML Files in a Folder y Compare Two XML Files Ignoring Formatting, y cada una tiene 3 usos gratis.

Pasos en VS Code

  1. Instala XML Formatter & XPath Tools desde el Marketplace, o pulsa Ctrl+P (Cmd+P en macOS) y ejecuta ext install zovo.zovo-xml-xpath-tools.
  2. Abre un archivo .xml y pulsa Shift+Alt+F (Shift+Option+F en Mac), o ejecuta Format Document. Si tienes más de un formateador de XML, VS Code te pregunta cuál usar. Format Selection también funciona.
  3. El formateador usa tu tamaño de tabulación y tu elección de tabuladores o espacios, y conserva los finales de línea, la marca de orden de bytes (BOM) y el salto de línea final. Si el archivo no está bien formado, no cambia nada y ves el error con su línea y columna.
  4. Para reducir el archivo, ejecuta “XML: Minify XML” sobre todo el archivo o sobre una selección. Los comentarios se mantienen salvo que actives xmlXpathTools.minify.removeComments.
  5. Para ejecutar un XPath, haz clic en el botón de búsqueda del título del editor o ejecuta “XML: Evaluate XPath…”. Los resultados aparecen en XPath Results con su línea. Haz clic en uno para seleccionarlo en el editor.
  6. Haz clic en el XPath de la barra de estado para copiar la ruta del elemento bajo el cursor, con posiciones, con atributos id o name, o en una forma portable con local-name().
  7. Para un archivo de más de 50 MB, haz clic derecho en él en el Explorer y elige “Format Large XML File on Disk…”. El comando escribe name.formatted.xml a su lado o reemplaza el archivo cuando lo confirmas.

Qué es gratis y qué añade Zovo Pro

Format Document, Format Selection, Minify XML, XPath 1.0, Copy XPath, la vista XML Tree, los errores de buen formato en Problems y Format Large XML File on Disk son gratis. No hace falta iniciar sesión y la extensión no tiene código de red.

Run XPath on Every XML File in a Folder ejecuta un XPath sobre cada archivo .xml, .xsd, .csproj, .svg, .kml y similares de una carpeta, cada uno con sus propios prefijos de namespace. Los resultados se abren como CSV (file, line, kind, name, value) para una hoja de cálculo, como JSON para un script o como informe Markdown para una revisión. Obtienes el mismo valor de muchos archivos, como cada artifactId de un conjunto de archivos pom.xml, sin abrirlos uno por uno.

Qué abre XML Formatter & XPath Tools

  • Los archivos que VS Code abre como XML. La extensión también abre como XML los archivos .kml, .gpx, .rss, .atom, .wsdl, .dbk, .xlf, .xliff, .resx, .nuspec, .props, .targets y .xaml.
  • Archivos grandes. El formateo, el árbol y XPath se ejecutan en un hilo en segundo plano. En las pruebas de la extensión, un archivo de 49 MB con alrededor de 1 millón de elementos se formateó en 1,6 segundos.
  • Los nombres simples también coinciden con un namespace por defecto, así que //dependency/artifactId funciona en un pom.xml. Activa xmlXpathTools.xpath.strictNamespaces para un XPath 1.0 estricto.
  • Disposición de los atributos tal como están escritos, en una sola línea o un atributo por línea (ajuste xmlXpathTools.format.attributes).
  • La vista XML Tree del Explorer sigue al cursor, y Problems lista los errores de buen formato con su línea y columna.

Qué no hace

  • Solo XPath 1.0. No hay XPath 2.0 ni 3.1, XQuery ni XSLT.
  • Comprueba que un archivo esté bien formado. No lo valida contra un XSD ni una DTD.
  • Los archivos de más de 50 MB se pueden formatear en disco, pero VS Code no se los pasa a las extensiones, así que el árbol y XPath no funcionan con ellos.
  • El comando en disco lee UTF-8, UTF-16 con marca de orden de bytes e ISO-8859-1.
  • Un elemento con texto, como <p>Some <b>bold</b> text</p>, se queda en su línea tal como está escrito. Solo los elementos que contienen etiquetas y no texto reciben saltos de línea nuevos.

Preguntas frecuentes

¿Es gratis?

El formateo, Minify XML, XPath, Copy XPath, la vista XML Tree y la comprobación de buen formato son gratis. Las tres herramientas Pro, Run XPath on Every XML File in a Folder, Format All XML Files in a Folder y Compare Two XML Files Ignoring Formatting, tienen 3 usos gratis cada una. Después necesitan Zovo Pro, USD 19 una sola vez para todas las extensiones de Zovo.

¿El formateo cambia mi texto o el CDATA?

No. Solo cambian los espacios en blanco entre etiquetas, en los elementos que contienen etiquetas y no texto. El texto, CDATA, los comentarios y el contenido dentro de xml:space="preserve" se copian tal cual, y un segundo formateo no cambia nada.

¿Por qué mi XPath no selecciona nada en un pom.xml?

El archivo tiene un namespace por defecto. En esta extensión los nombres simples también coinciden con un namespace por defecto, así que //dependency funciona. Activa xmlXpathTools.xpath.strictNamespaces para un XPath 1.0 estricto.

¿Funciona en Cursor?

Sí. Cursor, Windsurf y VSCodium la instalan desde Open VSX, donde está publicada como zovo/zovo-xml-xpath-tools.
