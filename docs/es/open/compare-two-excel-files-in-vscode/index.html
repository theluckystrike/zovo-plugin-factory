Cómo comparar dos archivos de Excel o CSV en VS Code

Instala la extensión gratuita Excel Compare & XLSX Diff y elige dos libros o archivos CSV. Las celdas cambiadas se ven en amarillo con el valor antiguo tachado, las filas añadidas en verde y las eliminadas en rojo. Las filas se alinean y las columnas se emparejan por su encabezado, así que una fila o columna insertada cuenta como un solo cambio, y puedes comparar un libro con su versión de Git HEAD antes de hacer commit. Todo eso es gratis y sin peticiones de red. Zovo Pro (USD 19 una sola vez) añade tres herramientas, Export a diff report, Match rows by key columns y Compare two folders of workbooks, y cada una tiene 3 usos gratis.

Pasos en VS Code

  1. Instala Excel Compare & XLSX Diff desde el Marketplace, o pulsa Ctrl+P (Cmd+P en macOS) y ejecuta ext install zovo.zovo-excel-compare.
  2. Selecciona dos archivos en el Explorer, haz clic derecho y elige Compare Selected Excel Files. O haz clic derecho en un archivo, elige Compare with... y selecciona el otro. Desde la Command Palette, ejecuta "Excel Compare: Compare Two Excel or CSV Files...".
  3. Funciona cualquier combinación de .xlsx, .xlsm, .xls, .ods, .csv y .tsv, así que puedes comparar un .xlsx con un .csv.
  4. Lee la línea de resumen y luego la pestaña de cada hoja con su número de diferencias. Haz clic en una celda para ver su valor antiguo y nuevo completos y copiarlos.
  5. Pulsa N y P (o Next y Previous) para recorrer todos los cambios de todas las hojas. Cambia entre Values y Formulas para comparar lo que muestran las celdas o las propias fórmulas.
  6. Para ver lo que cambiaste antes de un commit, haz clic derecho en un libro dentro de un repositorio Git y elige Compare with Git HEAD.

Qué es gratis y qué añade Zovo Pro

Comparar dos archivos cualesquiera, la cuadrícula, Values y Formulas, el cambio siguiente y anterior, el diff de CSV con codificación y delimitador detectados y Compare with Git HEAD son gratis, sin iniciar sesión, sin peticiones de red y sin telemetría.

Cuando otra persona tiene que ver los cambios, Export a diff report escribe un libro XLSX con las celdas cambiadas, añadidas y eliminadas rellenas de color, una hoja Summary y una lista Changes con cada valor antiguo y nuevo. También puede escribir una página HTML o una lista CSV de los cambios. Envías un solo archivo en lugar de capturas de pantalla.

  3. Elige dónde guardar el informe. Solo se gasta un uso cuando el informe se ha escrito.

Pasos en Cursor, Windsurf o VSCodium

  1. Abre la vista Extensions con Ctrl+Shift+X (Cmd+Shift+X en macOS).
  2. Busca zovo.zovo-excel-compare y haz clic en Install. Cursor, Windsurf y VSCodium instalan extensiones desde Open VSX, donde esta se llama zovo/zovo-excel-compare.
  3. Si tu editor no tiene galería de extensiones, descarga el .vsix desde la página de Open VSX y ejecuta "Extensions: Install from VSIX...".
  4. Después funciona igual que en VS Code.

Qué abre Excel Compare & XLSX Diff

  • Hojas emparejadas por nombre y luego por posición. Las hojas que solo existen en un archivo aparecen como añadidas o eliminadas.
  • CSV y TSV con la codificación detectada (UTF-8 con o sin BOM, UTF-16, páginas de códigos de Windows) y el delimitador detectado (coma, punto y coma, tabulación o barra vertical), incluidos campos entre comillas con saltos de línea.
  • Hojas grandes: la cuadrícula dibuja solo las filas visibles, así que una hoja de 300.000 filas se desplaza como una corta.
  • Avisos cuando las celdas combinadas difieren o cuando un límite recortó una hoja.
  • Las otras dos herramientas Pro: Match rows by key columns empareja las filas por una columna de ID, de modo que las hojas ordenadas o reordenadas se comparan bien y las filas movidas quedan marcadas; Compare two folders of workbooks empareja los archivos por nombre y muestra cuáles son iguales, cuáles difieren y cuáles solo están en una carpeta.

Qué no hace

  • Archivos de hasta 200 MB (ajuste excelCompare.maxFileSizeMB), 300.000 filas por hoja (excelCompare.maxRows), 1.000 columnas y 200 hojas. Un aviso en la vista indica cuándo se aplicó un límite.
  • Un libro que se inflaría a más de 600 MB, o que está comprimido como una zip bomb, se rechaza antes de descomprimirlo.
  • Sin la herramienta Pro Match rows by key columns, las filas se alinean por su contenido y posición, no por una columna de ID.
  • Solo compara. No edita ni fusiona los archivos.

Preguntas frecuentes

¿Es gratis?

Comparar dos libros o archivos CSV, Values y Formulas, el cambio siguiente y anterior y Compare with Git HEAD son gratis. Las tres herramientas Pro, Export a diff report, Match rows by key columns y Compare two folders of workbooks, tienen 3 usos gratis cada una. Después necesitan Zovo Pro, USD 19 una sola vez para todas las extensiones de Zovo.

¿Puede VS Code comparar dos archivos de Excel sin una extensión?

No. Un archivo .xlsx es un zip de partes XML, así que el diff integrado lo muestra como binario. Necesitas una extensión que lea el libro.

¿Una fila insertada arriba marca como cambiadas todas las filas de debajo?

No. Las filas se alinean antes de compararse, así que una fila insertada aparece como una sola fila añadida.

¿Puedo ver qué cambió en un libro desde mi último commit?

Sí. Haz clic derecho en el archivo dentro de un repositorio Git y elige Compare with Git HEAD. Usa tu git local.
