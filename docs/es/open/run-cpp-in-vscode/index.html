Ejecutar C y C++ con un clic en VS Code

Instala Run C++ and C Code, abre un archivo .c o .cpp y pulsa Run (o Ctrl+Alt+Enter, Cmd+Alt+Enter en Mac). La extensión compila con el gcc, g++, clang o clang++ que ya tienes y ejecuta el programa en la terminal, donde scanf y cin funcionan. Ejecutar, el panel Input & Tests, la prueba de estrés y el benchmark son gratis. Zovo Pro (USD 19 una sola vez) añade una comprobación con sanitizers, una comparación de -O0, -O2 y -O3 y un informe de pruebas, con 3 usos gratis de cada herramienta.

Pasos en VS Code

  1. Instala Run C++ and C Code desde el Marketplace, o pulsa Ctrl+P (Cmd+P en macOS) y ejecuta ext install zovo.zovo-run-cpp.
  2. Abre un archivo .c, .cpp, .cc o .cxx. Pulsa el botón Run arriba a la derecha, usa Ctrl+Alt+Enter (Cmd+Alt+Enter en Mac) o haz clic derecho y elige “Run C/C++ File”.
  3. El programa se ejecuta en una terminal llamada “Run: file.cpp”. Escribe ahí la entrada; al terminar verás el código de salida, el tiempo de ejecución y la memoria máxima. Mientras corre, Run se convierte en Stop, que termina el programa y todos los procesos que haya iniciado.
  4. Los errores y avisos de gcc y clang aparecen en el panel Problems con archivo, línea y columna. Los errores del enlazador, como undefined reference to sqrt, incluyen una pista para resolverlos.
  5. Para probar con entradas fijas, abre “Run with Input & Test Cases” desde el menú “...” del editor o desde la pestaña Run C++ del panel inferior. Pega la entrada y pulsa “Run with input”. “Save as test case” guarda esa entrada con la salida esperada, y “Run all tests” muestra si cada caso pasa o falla, con las diferencias línea a línea.
  6. Para usar flags o argumentos en un solo archivo, escribe al principio // run: -O2 -lm util.c y // args: "Hello World" 3.

En Cursor, Windsurf y VSCodium

Estos editores instalan extensiones desde Open VSX. Abre la vista Extensions (Ctrl+Shift+X), busca zovo.zovo-run-cpp y pulsa Install. Su página en Open VSX es zovo/zovo-run-cpp. Después se usa igual que en VS Code.

Qué es gratis

Es gratis compilar y ejecutar con un clic, el panel Input & Tests con casos de prueba guardados en .zovo-run/tests/, los flags y argumentos por archivo, “Build Only (Compile, Don't Run)”, “Build and Run All Files in This Folder”, “Debug C/C++ File”, la prueba de estrés contra una solución de referencia (hasta 10.000 entradas) y el benchmark de 10 ejecuciones. Los flags por defecto son -std=c++20 -Wall -Wextra -g -O0 para C++ y -std=c17 -Wall -Wextra -g -O0 para C, y los programas en C se enlazan con -lm. Las rutas con espacios, &, ü o 你好 funcionan porque ningún shell interpreta tus rutas. Si un programa falla, ves la señal y lo que suele significar. No hay red, telemetría ni cuenta.

Qué añade Zovo Pro

“Sanitizer Check” compila una segunda copia del programa con AddressSanitizer y UndefinedBehaviorSanitizer (-fsanitize=address,undefined), la ejecuta con la entrada del panel y con cada caso de prueba guardado, y muestra en Problems, en la línea donde ocurrió, cada desbordamiento de heap o de pila, uso después de liberar, desbordamiento de enteros con signo u otro comportamiento indefinido. Así no tienes que preparar a mano una compilación con sanitizers ni revisar caso por caso. Las otras herramientas Pro son “Compare -O0, -O2 and -O3”, que compila tres veces y compara tiempo, memoria, tamaño y salida, y “Save a Test Report (JUnit XML and Markdown)”, que ejecuta todos los casos guardados y escribe un archivo JUnit XML y un informe en Markdown.

Cómo se usa Sanitizer Check

  1. Pega una entrada en el panel Input & Tests o guarda algunos casos de prueba.
  2. Ejecuta “Run C++: Sanitizer Check: AddressSanitizer and UBSan on the Input and Test Cases (Zovo Pro)” desde la paleta de comandos, o haz clic derecho en el archivo fuente en el Explorador y elige “Zovo Pro: Sanitizer check”.
  3. Revisa los hallazgos en el panel Problems. Un error de compilación, Stop o Cancel no gastan ningún uso.

Sanitizer Check funciona 3 veces gratis antes de pedir una licencia. Al abrir un archivo no aparece ninguna ventana emergente ni cuenta atrás.

Lo que no hace

  • Necesitas un compilador ya instalado (gcc, g++, clang o clang++). La extensión nunca lo descarga; si no encuentra ninguno, muestra los pasos oficiales para tu sistema.
  • “Debug C/C++ File” necesita CodeLLDB o la extensión C/C++ de Microsoft.
  • Las ejecuciones del panel Input & Tests y los casos de prueba tienen un límite de 10 segundos (zovoRun.timeLimitSeconds); las ejecuciones en la terminal no tienen límite.
  • Sanitizer Check necesita un compilador con el runtime de sanitizers: gcc o clang en macOS y Linux, o clang de LLVM en Windows. MinGW gcc no lo incluye.

Preguntas

¿Es gratis?

Sí. Ejecutar, depurar, el panel Input & Tests, la prueba de estrés y el benchmark son gratis. Solo Sanitizer Check, la comparación de -O0, -O2 y -O3 y el informe de pruebas son herramientas de Zovo Pro, con 3 usos gratis cada una.

¿Funciona en Cursor?

Sí. Cursor instala las extensiones desde Open VSX. Busca zovo.zovo-run-cpp en la vista de extensiones.

¿Instala el compilador por mí?

No. Usa el gcc, g++, clang o clang++ de tu equipo. En Windows también lo busca en las carpetas de MSYS2, MinGW, WinLibs, TDM-GCC, Chocolatey, Scoop y LLVM. “Run C++: Pick Compiler” muestra los que encontró, con sus versiones.

¿Puedo cambiar el atajo de teclado?

Sí. En Keyboard Shortcuts, busca “Run C++: Run C/C++ File” y asígnale otra combinación.

Todas las funciones y ajustes están en la página de Run C++ and C Code (en inglés).
