Guías en español

VS Code y los editores basados en él (Cursor, Windsurf, VSCodium) abren archivos de texto, imágenes y algunos medios. Para muchos otros formatos necesitas una extensión. Cada guía da los pasos y dice qué es gratis.

  • Cómo abrir un archivo .docx en VS Code. Lee archivos de Word, OpenDocument y .doc antiguos en VS Code o Cursor, con esquema de títulos, búsqueda, control de cambios y comentarios. Gratis y sin conexión.
  • Cómo ver un archivo de PowerPoint (.pptx) en VS Code. Abre archivos .pptx, .ppsx y .ppt antiguos en VS Code o Cursor, con miniaturas, notas del orador, búsqueda y presentación a pantalla completa. Gratis, sin PowerPoint.
  • Cómo abrir un archivo de Excel (.xlsx) en VS Code. Abre archivos .xlsx, .xls y .ods en VS Code o Cursor como tabla, con los formatos de número de Excel, filtros, orden, estadísticas y SQL. Gratis, sin conexión y sin Excel.
  • Leer un PDF en modo oscuro en VS Code. Lee PDF en VS Code o Cursor con páginas oscuras o sepia. El texto se aclara y las fotos mantienen sus colores reales. Con búsqueda, índice y resaltados. Gratis.
  • Ver y editar archivos binarios en VS Code en hexadecimal. Mira, busca, edita y compara los bytes de cualquier archivo en VS Code o Cursor, desde 0 bytes hasta una imagen de 4 GB. Con Data Inspector y guardado seguro. Gratis y sin conexión.
  • Convertir un archivo PDF, Word, PowerPoint o Excel a Markdown en VS Code. Haz clic derecho en un PDF, DOCX, PPTX, XLSX, CSV, HTML o EPUB en VS Code y obtén el Markdown al lado. Gratis, sin conexión, sin Python y sin subir nada.
  • Formatear XML en VS Code y ejecutar XPath sobre él. Formatea o minifica XML en VS Code cambiando solo los espacios entre etiquetas, ejecuta XPath 1.0 con los namespaces del archivo y copia el XPath del cursor.
  • Explorar buckets de AWS S3, Cloudflare R2 o MinIO en VS Code. Explora buckets de S3, R2, MinIO, B2 y Wasabi en VS Code, abre objetos en solo lectura, sube y descarga con reanudación y sincroniza tras ver un plan.
  • Formatear un script bash o zsh en VS Code. Formatea scripts bash, sh, zsh, bats y mksh en VS Code con Shift+Alt+F o al guardar. Incluye shfmt 3.14.1, lee .editorconfig y funciona sin conexión.
  • Cómo comparar dos archivos de Excel o CSV en VS Code. Compara archivos .xlsx, .xls, .ods o CSV en VS Code celda por celda: celdas cambiadas, filas añadidas y eliminadas, columnas, hojas y Git HEAD. Gratis.
  • Escuchar audio en VS Code y medir LUFS. Audio Player reproduce WAV, MP3, FLAC, Ogg y Opus en VS Code con forma de onda, espectrograma, bucle A-B y medición LUFS según ITU-R BS.1770-4.
  • Renombrar y cerrar etiquetas en VS Code. Cambia el nombre de una etiqueta HTML, JSX o Vue y su pareja cambia a la vez en VS Code. También cierra etiquetas y resalta la pareja.
  • Historial de Claude Code y Codex en VS Code. Lee, busca y reanuda tus sesiones de Claude Code y Codex desde un árbol en VS Code, con diffs, tokens y subagentes. Nunca modifica tus sesiones.
  • Ver archivos DXF en VS Code. DXF Viewer abre planos DXF 2D en VS Code: hojas de paper space, capas, búsqueda de texto, medición y exportación a PNG o SVG, sin programa CAD.
  • Editar bases de datos SQLite en VS Code. Abre archivos .db y .sqlite en VS Code, edita celdas y filas, ejecuta SQL e importa CSV. Al guardar se comprueban las restricciones y se crea una copia.
  • Ver binarios ELF, PE y Mach-O en VS Code. ELF Viewer & PE Viewer muestra cabeceras, secciones, imports, exports y símbolos de archivos EXE, DLL, SO y Mach-O en VS Code, con vista hexadecimal.
  • Previsualizar fuentes en VS Code. Font Viewer abre fuentes TTF, OTF, WOFF, WOFF2 y TTC en VS Code con probador de texto, ejes variables, funciones OpenType, glifos, cobertura y licencia.
  • Graphviz DOT en VS Code con vista previa en vivo. Graphviz Viewer muestra tus archivos .dot y .gv en VS Code mientras escribes, sin instalar Graphviz, con errores en Problemas y exportación a SVG o PNG.
  • Ver archivos JAR y decompilar Java en VS Code. JAR Viewer abre JAR, WAR, EAR, AAR y .class en VS Code: árbol de paquetes, versiones de Java, bytecode y código fuente decompilado con CFR.
  • Ver JSON como árbol en VS Code. JSON Tree Viewer muestra archivos JSON grandes como árbol en VS Code, con búsqueda, rutas JSONPath, tabla ordenable y números grandes exactos.
  • Vista previa de Mermaid en VS Code. Mermaid Viewer dibuja tus diagramas Mermaid en VS Code mientras escribes, también en bloques de Markdown, sin cuenta ni conexión, y exporta a PNG o SVG.
  • Ver archivos NetCDF y HDF5 en VS Code. Abre archivos .nc y .h5 en VS Code sin Python: variables, atributos CF, tablas de valores, mapas de calor y mapas con costas.
  • Ver tensores de NumPy, PyTorch y GGUF en VS Code. Abre .npy, .npz, .pt, .pth, .safetensors y .gguf en VS Code sin Python: nombre, tipo y forma de cada tensor, estadísticas, mapa de calor y valores.
  • Analizar capturas PCAP y PCAPNG en VS Code. Abre capturas .pcap y .pcapng en VS Code sin Wireshark: paquetes, árbol de protocolos, vista hexadecimal, filtros y seguimiento de flujos TCP.
  • Reproducir vídeos con sonido en VS Code. VS Code no decodifica el audio AAC y los MP4 suenan mudos. Video Preview with Sound reproduce MP4 y MOV con sonido, y MKV y WebM con ffmpeg.
  • Ejecutar C y C++ con un clic en VS Code. Compila y ejecuta archivos .c y .cpp en VS Code con un clic, con el gcc, g++ o clang que ya tienes. Entrada con scanf y cin, errores en Problems y pruebas.
  • Ver modelos 3D STL, OBJ y GLB en VS Code. Abre modelos .stl, .obj, .glb, .gltf, .ply y .3mf en VS Code: gíralos, mide distancias, revisa la malla y reproduce animaciones con 3D Model Viewer.
  • Ver imágenes TIFF y GeoTIFF en VS Code. Abre archivos .tif y .tiff en VS Code, también de 16 y 32 bits, flotantes, multipágina y GeoTIFF. Lee el valor de cada píxel y sus coordenadas de mapa.
  • Ver mapas mentales de XMind en VS Code. Abre archivos .xmind de XMind 8 y XMind 2020+, mapas .mm de FreeMind y Freeplane y esquemas .opml en VS Code, con todas las hojas, búsqueda y exportación.
  • Explorar archivos ZIP, JAR y TAR en VS Code. Mira dentro de archivos .zip, .jar, .vsix, .tar y .tgz en VS Code sin descomprimirlos, abre cualquier entrada en una pestaña y extrae solo lo que quieras.
