Convertir un archivo PDF, Word, PowerPoint o Excel a Markdown en VS Code

Instala la extensión gratuita Convert to Markdown, haz clic derecho en un archivo PDF, Word, PowerPoint, Excel, CSV, HTML, EPUB, ODT o RTF en el Explorer y elige Convert to Markdown. El Markdown se abre junto al archivo con sus encabezados, listas, tablas, enlaces y las notas del orador de las diapositivas, y nada sale de tu ordenador. Convert to Markdown y Copy as Markdown son gratis para todos los formatos. Zovo Pro (USD 19 una sola vez) añade tres herramientas, Convert a Folder to Markdown, Convert to Markdown with Images y LLM-ready Markdown Chunks, y cada una tiene 3 usos gratis.

Pasos en VS Code

  1. Instala Convert to Markdown desde el Marketplace, o pulsa Ctrl+P (Cmd+P en macOS) y ejecuta ext install zovo.zovo-convert-to-markdown.
  2. En el Explorer, haz clic derecho en un archivo .pdf, .docx, .pptx, .xlsx, .xls, .ods, .csv, .tsv, .html, .epub, .odt o .rtf y elige Convert to Markdown. También puedes hacer clic derecho en la pestaña de un archivo abierto.
  3. O ejecuta “Convert to Markdown: Convert to Markdown” desde la Command Palette. Convierte el archivo de la pestaña activa o te pide uno.
  4. El Markdown se abre junto al archivo como documento sin guardar. Con archivos grandes verás el progreso con un botón Cancel.
  5. Pulsa Guardar. El nombre name.md junto al archivo original ya viene puesto. Para guardarlo ahí directamente cada vez, pon toMarkdown.output en file.
  6. Para pegar el Markdown en otro sitio, haz clic derecho en el archivo y elige Copy as Markdown. Si seleccionas varios archivos en el Explorer, se convierten uno tras otro.
  7. ¿No tienes un archivo a mano? Ejecuta “Convert to Markdown: Convert a sample file” desde la Command Palette para convertir una muestra incluida de Word, PDF o PowerPoint.

Qué es gratis y qué añade Zovo Pro

Convert to Markdown y Copy as Markdown son gratis para todos los formatos: PDF, Word, PowerPoint, Excel, ODS, CSV, TSV, HTML, EPUB, ODT y RTF. No tienes que instalar nada más, ni Python, ni un servidor, ni una herramienta de línea de comandos. Nada sale de tu ordenador.

Convert a Folder to Markdown convierte en una sola pasada cada archivo admitido de una carpeta y sus subcarpetas en archivos .md, en una carpeta nueva con la misma estructura o junto a cada archivo, con progreso y Cancel. Tú decides si se omiten o se sobrescriben los archivos .md que ya existen, y _conversion-report.md marca cada archivo como convertido, omitido o fallido. Los archivos con el mismo nombre conservan su tipo en el nombre nuevo (report.pdf.md, report.docx.md), así que no se pierde ninguno.

Con Convert a Folder to Markdown (Zovo Pro)

  1. Haz clic derecho en una carpeta en el Explorer y elige “Zovo Pro: Convert a Folder to Markdown”, o ejecuta “Convert to Markdown: Convert a Folder to Markdown (Pro)” desde la Command Palette y elige la carpeta.
  2. Elige dónde van los archivos .md: “Into a new folder” (el nombre de la carpeta más -markdown, con las mismas subcarpetas), “Next to each file” o “Pick another folder...”.
  3. Si ya existen algunos archivos .md, elige Skip u Overwrite. Una notificación muestra el progreso con un botón Cancel.
  4. Al final se abre _conversion-report.md. Marca cada archivo como convertido, omitido o fallido, con un enlace a cada archivo Markdown nuevo.

Pasos en Cursor, Windsurf o VSCodium

  1. Abre la vista Extensions con Ctrl+Shift+X (Cmd+Shift+X en macOS).
  2. Busca zovo.zovo-convert-to-markdown y haz clic en Install. Cursor, Windsurf y VSCodium instalan extensiones desde Open VSX, donde esta se llama zovo/zovo-convert-to-markdown.
  3. Si tu editor no tiene galería de extensiones, descarga el .vsix desde la página de Open VSX y ejecuta "Extensions: Install from VSIX...".
  4. Después funciona igual que en VS Code.

Qué abre Convert to Markdown

  • PDF, con encabezados según el tamaño de la fuente, párrafos con las líneas partidas y las palabras con guion unidas, listas, tablas sencillas y páginas a dos columnas leídas columna por columna. Se quitan los encabezados y pies de página repetidos y los números de página.
  • Word (.docx, .docm, .dotx), con encabezados, negrita, cursiva, tachado, enlaces, listas anidadas, tablas, citas en bloque y notas al pie.
  • PowerPoint (.pptx, .pptm, .ppsx, .potx), con una sección ## Slide n: title por diapositiva, con las viñetas y sus niveles, las tablas y las notas del orador.
  • Excel y otras hojas de cálculo (.xlsx, .xlsm, .xlsb, .xls, .ods), con una sección ## Sheet: name y una tabla con barras verticales por hoja. CSV y TSV se convierten en una sola tabla.
  • HTML (.html, .htm, .xhtml), donde los bloques de código conservan su lenguaje y se quitan los scripts y estilos, y EPUB, con cada capítulo en orden de lectura.

Qué no hace

  • Los PDF escaneados (imágenes de páginas) no tienen texto que convertir. El reconocimiento de texto (OCR) no está incluido.
  • Las tablas de un PDF se detectan por los huecos entre columnas. Las tablas sin huecos claros salen como párrafos.
  • En la conversión gratuita, las imágenes se convierten en marcadores como *[Image: Map of the site]*. Los gráficos, SmartArt y vídeos de las diapositivas se nombran, no se convierten.
  • Los archivos antiguos de Word 97-2003 y RTF dan texto y tablas sin formato. Los archivos protegidos con contraseña y los PowerPoint 97-2003 antiguos reciben un mensaje en lugar de una conversión.
  • Los archivos de más de 200 MB no se convierten (ajuste toMarkdown.maxFileSizeMB) y un PDF se detiene tras 1.000 páginas (ajuste toMarkdown.pdfMaxPages).

Preguntas frecuentes

¿Es gratis?

Convert to Markdown y Copy as Markdown son gratis para todos los formatos. Las tres herramientas Pro, Convert a Folder to Markdown, Convert to Markdown with Images y LLM-ready Markdown Chunks, tienen 3 usos gratis cada una. Después necesitan Zovo Pro, USD 19 una sola vez para todas las extensiones de Zovo.

¿Sube mis archivos?

No. Los conversores se ejecutan en tu ordenador, dentro de VS Code, sin llamadas de red y sin telemetría.

¿Convierte PDF escaneados?

No. Un PDF escaneado contiene imágenes de páginas, no texto, y Convert to Markdown no tiene OCR.

¿Funciona en Cursor?

Sí. Cursor, Windsurf y VSCodium la instalan desde Open VSX, donde está publicada como zovo/zovo-convert-to-markdown.
