Explorar buckets de AWS S3, Cloudflare R2 o MinIO en VS Code

Instala la extensión gratuita S3 Explorer y abre su vista S3 Buckets en la Activity Bar. Funciona con AWS S3 (perfiles de ~/.aws, también perfiles SSO), Cloudflare R2, MinIO, Backblaze B2, Wasabi y DigitalOcean Spaces. Explorar, abrir objetos en solo lectura, subir, descargar, copiar, mover, renombrar, borrar, las versiones, los tags, las URL prefirmadas y la sincronización de carpetas son gratis, sin inicio de sesión y sin telemetría. Zovo Pro (USD 19 una sola vez) añade tres herramientas, Copy to Another Connection, el Size and Cost Report y Scheduled Sync, y cada una tiene 3 usos gratis.

Pasos en VS Code

  1. Instala S3 Explorer desde el Marketplace, o pulsa Ctrl+P (Cmd+P en macOS) y ejecuta ext install zovo.zovo-s3-explorer.
  2. Abre la vista S3 Explorer en la Activity Bar y haz clic en Add Connection. Elige un perfil de AWS de ~/.aws, o escribe una access key, un account ID y un token de R2, o la URL del endpoint de MinIO o de otro servicio compatible con S3. Las claves que escribes se guardan en el llavero del sistema operativo.
  3. Expande una conexión para ver sus buckets. Las keys se cargan de 1.000 en 1.000 con una fila "Load 1,000 more". Si tu clave no tiene permiso para listar buckets, haz clic derecho en la conexión y elige Add Bucket by Name.
  4. Haz clic en un objeto para abrirlo en solo lectura en una pestaña o en el visor que corresponda. Para ver sus metadatos, tags, versiones y una URL prefirmada, haz clic derecho en él y elige Show Details, Versions and Presigned URL.
  5. Para cambiar un objeto, haz clic derecho en él y elige Edit and Upload. Editas una copia, y un diálogo muestra el bucket, la key y los dos tamaños antes de reemplazar el objeto.
  6. Arrastra archivos o carpetas del Explorer a un bucket para subirlos, o haz clic derecho y elige Download. Los archivos de 16 MB o más se suben por partes con progreso y Cancel, y una subida interrumpida se reanuda enviando solo las partes que faltan.
  7. Para mantener iguales una carpeta local y un prefijo, haz clic derecho en el bucket o en la carpeta y elige Sync Folder. Verás un plan de simulación (nuevos, modificados, por borrar) antes de que cambie nada.

Qué es gratis y qué añade Zovo Pro

Explorar, abrir, Edit and Upload, subir, descargar, copiar, mover, renombrar, borrar, las versiones, los tags, las URL prefirmadas y la sincronización de carpetas son gratis, sin inicio de sesión, sin cuenta y sin telemetría. Solo se conecta a los endpoints de almacenamiento que añades.

Copy to Another Connection copia objetos o carpetas enteras de una conexión a otra, por ejemplo de AWS S3 a Cloudflare R2 o MinIO, con la misma confirmación que cualquier copia: se listan las keys y se nombran las que se reemplazarían. Los objetos grandes pasan por una subida multiparte. Así mueves datos entre proveedores o cuentas desde el árbol, sin un script ni otra herramienta.

Con Copy to Another Connection (Zovo Pro)

  1. Añade antes la segunda conexión. Después haz clic derecho en un objeto o una carpeta de la vista S3 Buckets y elige "Copy to Another Connection... (Pro)", o haz clic en Copy to Another Connection en la fila "Zovo Pro tools" al final de la vista.
  2. Elige la conexión de destino, el bucket y la carpeta de destino (vacía para el nivel superior).
  3. Revisa la lista de objetos en la confirmación y haz clic en Copy, o en Copy and Replace si algunas keys ya existen. Una notificación muestra el progreso.
  4. Un uso solo cuenta cuando se copiaron objetos. Pulsar Escape en una selección, o no tener una segunda conexión, no gasta ninguno.

Copy to Another Connection funciona 3 veces en tu equipo antes de pedir una licencia. Al abrir un archivo no hay ventanas emergentes ni cuentas atrás.

Pasos en Cursor, Windsurf o VSCodium

  1. Abre la vista Extensions con Ctrl+Shift+X (Cmd+Shift+X en macOS).
  2. Busca zovo.zovo-s3-explorer y haz clic en Install. Cursor, Windsurf y VSCodium instalan extensiones desde Open VSX, donde esta se llama zovo/zovo-s3-explorer.
  3. Si tu editor no tiene galería de extensiones, descarga el .vsix desde la página de Open VSX y ejecuta "Extensions: Install from VSIX...".
  4. Después funciona igual que en VS Code.

Qué abre S3 Explorer

  • Perfiles de AWS con access keys, credential_process, roles con source_profile y perfiles SSO después de aws sso login. Se respeta endpoint_url en un perfil.
  • MinIO y otros servicios compatibles con S3 con una URL de endpoint, una región, URL de estilo path o virtual-hosted y una opción para aceptar un certificado autofirmado.
  • Metadatos, content type, storage class, ETag, tags (editar y guardar), versiones (abrir, descargar, restaurar) y URL prefirmadas GET o PUT de 15 minutos a 7 días.
  • Buckets con millones de keys, de 1.000 en 1.000, con búsqueda y filtro por prefijo.
  • Las descargas conservan la estructura de carpetas y nunca escriben fuera de la carpeta que elegiste. Las keys con segmentos .., letras de unidad o bytes NUL se omiten y se listan.

Qué no hace

  • Nunca usa por su cuenta el perfil default de AWS ni AWS_PROFILE. Tú eliges el perfil con el que te conectas.
  • Los objetos de texto de más de 10 MB preguntan primero y luego muestran el primer 1 MB. Los objetos binarios de más de 200 MB preguntan antes de descargarse.
  • Los objetos abiertos son de solo lectura. Solo Edit and Upload escribe en el bucket, después de una confirmación.
  • Scheduled Sync solo funciona con VS Code abierto, cada 5 a 60 minutos, y nunca borra.
  • Las peticiones sin respuesta se detienen a los 30 segundos (ajuste s3Explorer.requestTimeoutSeconds).

Preguntas frecuentes

¿Es gratis?

Explorar, abrir, subir, descargar, copiar, mover, renombrar, borrar, las versiones, los tags, las URL prefirmadas y la sincronización de carpetas son gratis. Las tres herramientas Pro, Copy to Another Connection, el Size and Cost Report y Scheduled Sync, tienen 3 usos gratis cada una. Después necesitan Zovo Pro, USD 19 una sola vez para todas las extensiones de Zovo.

¿Dónde se guardan mis claves?

Las claves que escribes van al llavero del sistema operativo a través de VS Code SecretStorage, nunca a archivos de configuración. Los perfiles de AWS se leen de ~/.aws solo cuando eliges uno.

¿Funciona con Cloudflare R2 y MinIO?

Sí. R2 usa tu account ID y la access key de un token de API de R2. MinIO y otros servicios compatibles con S3 usan una URL de endpoint, una región y URL de estilo path o virtual-hosted.

¿Funciona en Cursor?

Sí. Cursor, Windsurf y VSCodium la instalan desde Open VSX, donde está publicada como zovo/zovo-s3-explorer.
