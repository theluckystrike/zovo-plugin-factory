Cómo abrir un archivo de Excel (.xlsx) en VS Code

VS Code no abre un .xlsx como tabla por sí solo. La extensión gratuita Table Viewer muestra .xlsx, .xlsm, .xlsb, .xls y .ods, además de CSV y Parquet, como una tabla que se puede ordenar y filtrar, de hasta 1.000.000 de filas y con los formatos de número del libro. No necesita Excel ni Python. Zovo Pro (19 USD en un solo pago) añade, entre otras cosas, unir muchos archivos o todas las hojas de un libro en un solo archivo.

Pasos en VS Code

  1. Instala Table Viewer desde el Marketplace, o pulsa Ctrl+P (Cmd+P en macOS) y ejecuta ext install zovo.table-viewer-vscode.
  2. Haz clic en un archivo .xlsx en el Explorador. Se abre como tabla, y la barra de herramientas muestra el número de filas y columnas.
  3. Haz clic en el encabezado de una columna para ordenar. En la casilla bajo cada encabezado filtras, por ejemplo con >10 o 5..9. La búsqueda de arriba mira en todas las columnas.
  4. El interruptor "Excel formats" muestra números, porcentajes y fechas como en Excel. Un doble clic en una celda abre el panel con el valor completo.
  5. Para análisis, haz clic en Query, escribe un SELECT, por ejemplo con GROUP BY, y pulsa Ctrl+Enter (Cmd+Enter en Mac). Stats muestra el recuento, los vacíos, el mínimo, el máximo y la media de cada columna.

Qué es gratis y qué añade Zovo Pro

Son gratis abrir archivos CSV, TSV, Excel y Parquet, las hojas, los filtros, el orden, la búsqueda, las estadísticas de columna, el filtro SQL, las consultas SQL sobre las filas de la tabla, la comparación con Git HEAD y la exportación a CSV, TSV, JSON y JSON Lines.

Combine Files and Sheets une en un solo archivo CSV, XLSX o Parquet los informes mensuales repartidos en doce archivos, o un libro con una hoja por sucursal. Las columnas se emparejan por el nombre del encabezado, y las columnas source_file y source_sheet indican de dónde viene cada fila. Otras herramientas Pro son las consultas sobre el archivo completo cuando la tabla muestra solo las primeras filas, JOIN con otros archivos y guardar como Parquet.

Con Combine Files and Sheets (Zovo Pro)

  1. Haz clic en Combine en la barra de herramientas, o ejecuta "Excel Viewer Pro: Combine Files and Sheets (Pro)..." desde la Command Palette. En el Explorador también puedes hacer clic derecho en una carpeta, en varios archivos seleccionados o en un libro.
  2. Elige qué unir y el formato CSV, XLSX o Parquet.
  3. Elige dónde guardar el resultado. Los archivos de origen no cambian.

Pasos en Cursor, Windsurf o VSCodium

  1. Abre la vista Extensions con Ctrl+Shift+X (Cmd+Shift+X en macOS).
  2. Busca zovo.table-viewer-vscode y haz clic en Install. Cursor, Windsurf y VSCodium instalan extensiones desde Open VSX, donde esta se llama zovo/table-viewer-vscode.
  3. Si tu editor no tiene galería de extensiones, descarga el .vsix desde la página de Open VSX y ejecuta "Extensions: Install from VSIX...".
  4. Después funciona igual que en VS Code.

Qué no hace

  • Table Viewer es de solo lectura. No edita celdas, y Export solo escribe el archivo nuevo que elijas.
  • Los archivos .xls, .xlsb, .ods y los .xlsx pequeños se leen enteros, hasta 50 MB (ajuste tableViewer.maxExcelSizeMB).
  • La tabla carga hasta 1.000.000 de filas (ajuste tableViewer.maxRows). Si el archivo tiene más, aparece un aviso.

Preguntas frecuentes

¿Necesito Excel?

No. Table Viewer lee el archivo por sí mismo, sin Excel, Python ni base de datos.

¿Puedo cambiar celdas?

No. Table Viewer es un visor. Para editar, usa Excel, LibreOffice Calc o un editor de hojas de cálculo.

¿Se sube mi archivo a algún sitio?

No. La extensión funciona sin conexión y sin cuenta.
