Historial de Claude Code y Codex en VS Code

Instala Agent Session Viewer y haz clic en el icono Agent Sessions de la barra de actividad: tus sesiones de Claude Code y Codex aparecen en un árbol, agrupadas por proyecto, y puedes leerlas, buscarlas y reanudarlas en una terminal. Leer, buscar, reanudar y exportar una sesión a Markdown es gratis y sin límite de historial. Zovo Pro (USD 19, un solo pago) añade un informe de uso y coste, una exportación con secretos ocultos y la exportación masiva a Markdown, y puedes probar cada herramienta 3 veces gratis.

Instalar en VS CodePágina del MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

Gratis, licencia MIT. Extension ID zovo.agent-session-viewer.

Pasos en VS Code

  1. Instala Agent Session Viewer desde el Marketplace, o pulsa Ctrl+P (Cmd+P en macOS) y ejecuta ext install zovo.agent-session-viewer.
  2. Haz clic en el icono Agent Sessions de la barra de actividad. Las sesiones de Claude Code (~/.claude/projects) y de Codex (~/.codex/sessions) aparecen en un mismo árbol, agrupadas por carpeta de proyecto, con los subagentes debajo de la sesión que los lanzó.
  3. Haz clic en una sesión para abrirla. La cabecera muestra la herramienta, el modelo, la rama de git, la duración, el número de turnos y los totales de tokens. El coste solo aparece cuando el archivo lo registra: Claude Code lo guarda y Codex no. Las ediciones de archivos se muestran como diffs y las llamadas a herramientas aparecen plegadas.
  4. Para buscar en todas las sesiones, usa “Search Sessions” en la parte superior de la vista. Al elegir un resultado, la sesión se abre en ese punto. Dentro de una sesión, el cuadro de búsqueda también encuentra texto en las partes plegadas; Enter va a la siguiente coincidencia y Shift+Enter a la anterior.
  5. Para seguir trabajando, haz clic derecho en la sesión y elige “Resume in Terminal”, o usa el icono de terminal junto a ella. Se abre una terminal en la carpeta del proyecto con claude --resume o codex resume y el ID de la sesión.
  6. “Copy Resume Command” copia ese mismo comando, por defecto precedido de un cd a la carpeta del proyecto (agentSessionViewer.resumeWithCd). Con “Export to Markdown…” guardas una sesión como archivo .md.

En Cursor, Windsurf y VSCodium

Estos editores instalan extensiones desde Open VSX. Abre la vista Extensions (Ctrl+Shift+X), busca zovo.agent-session-viewer y pulsa Install. Su página en Open VSX es zovo/agent-session-viewer. Después se usa igual que en VS Code.

Qué es gratis

Son gratis y sin límite el árbol de sesiones, la lectura de sesiones, la búsqueda en todas ellas, “Resume in Terminal”, “Copy Resume Command”, la exportación de una sesión a Markdown, la vista de texto sin formato y “Reveal in File Manager”. Antes de exportar, la extensión te recuerda que una transcripción puede contener secretos y te ofrece exportar sin las salidas de las herramientas. Para abrir un archivo .jsonl que te hayan pasado, haz clic derecho, elige “Open With...” y luego Agent Session Viewer; la extensión comprueba los primeros 20 registros y te avisa si no es una sesión. La extensión solo lee tus archivos de sesión y nunca los modifica, mueve ni borra. No hay telemetría, llamadas de red ni inicio de sesión.

Qué añade Zovo Pro

Usage and Cost Report suma los tokens de todas las sesiones, de un proyecto o de una herramienta en el rango de fechas que elijas, y estima el coste por proyecto, modelo y día con los precios de lista de la API. Guarda un informe en Markdown y un CSV con una fila por día, proyecto y modelo, listo para facturar a un cliente o para una hoja de cálculo. Un mensaje copiado en una sesión reanudada cuenta una sola vez, y los subagentes cuentan con la sesión que los lanzó. Las otras herramientas Pro son Share-Safe Export, que guarda una sesión o todo un proyecto como página HTML o Markdown con claves de API, tokens, valores de .env, correos y tu carpeta personal sustituidos por [REDACTED ...], y Bulk Export to Markdown, que guarda todas las sesiones de un proyecto, de una herramienta o de todos los proyectos en un rango de fechas como archivos Markdown con un index.md.

Cómo se usa Usage and Cost Report

  1. En el árbol de sesiones, haz clic derecho en una carpeta de proyecto y elige “Usage and Cost Report (Pro)…”, o ábrelo desde el menú ... de la vista Sessions.
  2. Si lo abriste desde el menú ..., elige todas las sesiones o un proyecto. Después elige el periodo, por ejemplo “Last 7 days” o “Last month”, o escribe un rango propio como 2026-11-01..2026-11-07 con “Custom range…”.
  3. La extensión suma los tokens y guarda el informe en Markdown y el archivo CSV.

Usage and Cost Report funciona 3 veces gratis antes de pedir una licencia. Al abrir un archivo no aparece ninguna ventana emergente ni cuenta atrás.

Lo que no hace

  • Solo lee sesiones de Claude Code y Codex. Las de Cursor, Copilot y Gemini CLI todavía no son compatibles.
  • Para reanudar una sesión, Claude Code o Codex debe estar instalado y accesible desde el PATH de la terminal.
  • La búsqueda es de texto simple, sin expresiones regulares, y se detiene en 300 resultados. El árbol muestra como máximo 2000 sesiones (agentSessionViewer.maxSessions).
  • El coste del informe Pro es una estimación con precios de lista de la API. Si usas un plan Claude Pro o Max, o un plan de ChatGPT, pagas según tu plan.

Preguntas

¿La extensión es gratis?

Sí. Leer, buscar, reanudar y exportar una sesión a Markdown es gratis y sin límite de historial. Usage and Cost Report, Share-Safe Export y Bulk Export to Markdown forman parte de Zovo Pro (USD 19, un solo pago). Puedes probar cada una 3 veces gratis, y un intento solo cuenta cuando la herramienta ha guardado su archivo; cancelar no gasta ninguno.

¿Funciona en Cursor?

Sí, la extensión se instala en Cursor desde Open VSX. Eso sí, lee las sesiones de Claude Code y Codex, no el historial del chat de Cursor.

¿Puede borrar o cambiar mis sesiones?

No. La extensión solo lee los archivos de sesión y no tiene ningún comando para borrarlos, moverlos ni renombrarlos. Las herramientas Pro solo escriben los archivos nuevos que eliges, nunca dentro de las carpetas de sesiones.

¿Está relacionada con Anthropic u OpenAI?

No. Es una extensión independiente que lee los archivos que Claude Code y Codex guardan en tu equipo.

Todas las funciones y ajustes están en la página de Agent Session Viewer (en inglés).
