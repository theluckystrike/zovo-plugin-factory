Ver y editar archivos binarios en VS Code en hexadecimal

VS Code no muestra archivos binarios. Con la extensión gratuita Hex Viewer puedes ver, buscar, editar y comparar los bytes de cualquier archivo, desde uno vacío hasta una imagen de disco de 4 GB. Un Data Inspector lee la selección como entero, número de coma flotante o marca de tiempo, y al guardar nunca queda un archivo a medio escribir. Zovo Pro (19 USD en un solo pago) añade herramientas para analizar formatos de archivo, como un mapa de entropía con histograma de bytes.

Pasos en VS Code

  1. Instala Hex Viewer desde el Marketplace, o pulsa Ctrl+P (Cmd+P en macOS) y ejecuta ext install zovo.zovo-hex-viewer.
  2. Haz clic derecho en un archivo en el Explorador y elige "Open in Hex Viewer". Los archivos .bin, .dat, .img, .rom, .dmp o .dump se abren directamente en Hex Viewer.
  3. Ctrl+G (Cmd+G) salta a un offset como 0x1F40, +0x100 o end. Ctrl+F busca bytes hex como 50 4B 03 04, con ?? para cualquier byte, y también texto o UTF-16.
  4. Escribe dígitos hex en la columna hex para sobrescribir bytes. También puedes insertar y borrar, Ctrl+Z deshace y Ctrl+S guarda.
  5. Selecciona dos archivos en el Explorador y elige "Compare in Hex Viewer". F7 va a la siguiente diferencia.

Qué es gratis y qué añade Zovo Pro

Son gratis ver archivos de cualquier tamaño, Go to Offset, la búsqueda, Copy as, el Data Inspector, editar con inserción y borrado, el guardado seguro, deshacer y la comparación de dos archivos.

Cuando desmontas un firmware o un formato desconocido, quieres saber dónde hay relleno, texto o código, y dónde empiezan los datos comprimidos o cifrados. El mapa de entropía lee el archivo entero en bloques de 4 MB, también con 4 GB, y muestra la entropía de cada bloque de 0 a 8 bits por byte, con un histograma de bytes y un informe en Markdown y CSV. Otras herramientas Pro son los campos anidados de las plantillas binarias, los marcadores con notas, un informe de comparación y la búsqueda de bytes en muchos archivos.

Con Entropy and Byte Histogram (Zovo Pro)

  1. Abre el archivo en Hex Viewer.
  2. Abre la pestaña Entropy en el panel lateral, o ejecuta "Hex Viewer Pro: Entropy and Byte Histogram (Pro)..." desde la Command Palette.

Pasos en Cursor, Windsurf o VSCodium

  1. Abre la vista Extensions con Ctrl+Shift+X (Cmd+Shift+X en macOS).
  2. Busca zovo.zovo-hex-viewer y haz clic en Install. Cursor, Windsurf y VSCodium instalan extensiones desde Open VSX, donde esta se llama zovo/zovo-hex-viewer.
  3. Si tu editor no tiene galería de extensiones, descarga el .vsix desde la página de Open VSX y ejecuta "Extensions: Install from VSIX...".
  4. Después funciona igual que en VS Code.

Qué no hace

  • Los archivos de texto como .txt, .ts y los .hex de Intel siguen abriéndose en el editor de texto. Para ellos usa "Open in Hex Viewer".
  • Copy as funciona hasta 32 MB, y pegar, hasta 16 MB.

Preguntas frecuentes

¿Puedo cambiar bytes?

Sí. Sobrescribir, insertar y borrar es gratis, con deshacer. Si el tamaño no cambia, al guardar solo se escriben los bytes modificados.

¿Qué tamaño de archivo admite?

Se ha probado con archivos de 4 GB. Solo se leen las filas visibles, así que incluso una imagen grande se abre rápido.

¿La extensión se conecta a la red?

No. Funciona sin conexión y no envía telemetría.
