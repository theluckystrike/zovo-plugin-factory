Formatear un script bash o zsh en VS Code

Instala la extensión gratuita Shell Formatter for Bash & Zsh, abre un script de shell y pulsa Shift+Alt+F (Shift+Option+F en Mac). El motor shfmt 3.14.1 viene dentro de la extensión como WebAssembly, así que no hay nada que descargar, y el resultado es idéntico byte a byte al de shfmt en la línea de comandos. Format Document, Format Selection, el formateo al guardar, las claves de .editorconfig y los errores de sintaxis en Problems son gratis y funcionan sin conexión. Zovo Pro (USD 19 una sola vez) añade tres herramientas, Format All Shell Scripts in a Folder, Formatting Check with a Patch File y Minify a Script to a Copy, y cada una tiene 3 usos gratis.

Pasos en VS Code

  1. Instala Shell Formatter for Bash & Zsh desde el Marketplace, o pulsa Ctrl+P (Cmd+P en macOS) y ejecuta ext install zovo.zovo-shell-formatter.
  2. Abre un script de shell y pulsa Shift+Alt+F (Shift+Option+F en Mac). Si VS Code te pregunta qué formateador usar, elige Shell Formatter, o ejecuta "Shell Formatter: Use as Default Formatter for Shell Scripts".
  3. Para formatear cada vez que guardas, ejecuta "Shell Formatter: Turn On Format on Save for Shell Scripts".
  4. El dialecto sale de la primera línea (#!/bin/bash, #!/bin/sh, #!/usr/bin/env zsh), si no del nombre del archivo (.bash, .zsh, .zshrc, .bats, .ksh), y si no se usa bash. Para elegirlo tú, define shellFormatter.dialect o shell_variant en .editorconfig.
  5. Haz clic en shfmt 3.14.1 en la barra de estado para abrir el menú, con formatear, establecer como predeterminado, formatear al guardar, "Copy the matching shfmt command (for CI)" y los ajustes.
  6. Si el script no es shell válido, queda sin cambios y el panel Problems muestra la línea y la columna.

Qué es gratis y qué añade Zovo Pro

Format Document, Format Selection, el formateo al guardar, la detección del dialecto, las claves de .editorconfig, el menú de la barra de estado, Copy the Matching shfmt Command (for CI) y los errores de sintaxis en Problems son gratis. No hay inicio de sesión, ni peticiones de red, ni telemetría.

Format All Shell Scripts in a Folder revisa cada script de una carpeta y sus subcarpetas, encontrado por su nombre o por una línea #! que nombra un shell, y te dice cuántos cambiarían. Después los formatea todos o te da un informe en Markdown, con el mismo motor, los mismos ajustes y el mismo .editorconfig que Format Document. Un repositorio con decenas de scripts en estilos distintos queda con un solo estilo en una pasada, y los scripts que no ejecutarían los mismos comandos se dejan como están.

Con Format All Shell Scripts in a Folder (Zovo Pro)

  1. Haz clic derecho en una carpeta en el Explorer y elige "Zovo Pro: Format All Shell Scripts in a Folder", o ejecuta "Shell Formatter: Format All Shell Scripts in a Folder (Pro)" desde la Command Palette o el menú de la barra de estado y elige la carpeta.
  2. El título de la lista siguiente muestra cuántos scripts cambiarían, por ejemplo "N of M scripts would change".
  3. Elige "Format N scripts" para formatear y guardar cada archivo (Deshacer funciona por archivo), o "Show the report only" para obtener una lista en Markdown de todos los scripts sin cambiar nada.
  4. Un uso solo cuenta cuando obtienes un resultado. Una carpeta sin scripts de shell, o con todos los scripts ya formateados, no gasta ninguno.

Format All Shell Scripts in a Folder funciona 3 veces en tu equipo antes de pedir una licencia. Al abrir un archivo no hay ventanas emergentes ni cuentas atrás.

Pasos en Cursor, Windsurf o VSCodium

  1. Abre la vista Extensions con Ctrl+Shift+X (Cmd+Shift+X en macOS).
  2. Busca zovo.zovo-shell-formatter y haz clic en Install. Cursor, Windsurf y VSCodium instalan extensiones desde Open VSX, donde esta se llama zovo/zovo-shell-formatter.
  3. Si tu editor no tiene galería de extensiones, descarga el .vsix desde la página de Open VSX y ejecuta "Extensions: Install from VSIX...".
  4. Después funciona igual que en VS Code.

Qué abre Shell Formatter for Bash & Zsh

  • Scripts de bash, POSIX sh (también dash y ash), mksh (también ksh), bats y zsh.
  • El mismo resultado que shfmt 3.14.1 en la línea de comandos. 354 de 354 ejecuciones sobre 178 scripts reales de proyectos de GitHub y de Homebrew coincidieron byte a byte.
  • Antes de aplicar un cambio, el script formateado se analiza de nuevo y debe ejecutar los mismos comandos que el original (archivos de hasta 256 KB).
  • Opciones de shfmt como ajustes o claves de .editorconfig, como sangría, operadores binarios en la línea siguiente, sangría de case en switch, espacios en redirecciones, conservar el relleno, llaves de función en la línea siguiente, simplificar y minificar.
  • Los finales de línea de Windows (CRLF) se quedan en CRLF, y un script de 2 MB se formatea en unos 0,2 segundos.

Qué no hace

  • Nunca toca Dockerfiles, archivos .env ni scripts fish o csh.
  • El soporte de zsh en shfmt es nuevo. Un script zsh que shfmt no puede analizar queda sin cambios.
  • Los archivos de más de 10 MB (ajuste shellFormatter.maxFileMB) y los archivos con bytes binarios, como los instaladores autoextraíbles, no se formatean.
  • shfmt se ejecuta con un límite de tiempo (10 segundos por defecto, ajuste shellFormatter.timeoutSeconds). Si se alcanza, el archivo queda sin cambios.

Preguntas frecuentes

¿Es gratis?

Format Document, Format Selection, el formateo al guardar y el soporte de .editorconfig son gratis. Las tres herramientas Pro, Format All Shell Scripts in a Folder, Formatting Check with a Patch File y Minify a Script to a Copy, tienen 3 usos gratis cada una. Después necesitan Zovo Pro, USD 19 una sola vez para todas las extensiones de Zovo.

¿Tengo que instalar shfmt?

No. shfmt 3.14.1 viene dentro de la extensión como WebAssembly, así que funciona sin conexión y no hay nada que descargar.

¿Puede romper mi script?

Un script con un error de sintaxis queda sin cambios. Antes de aplicar un cambio, el script formateado se analiza de nuevo y debe ejecutar los mismos comandos que el original.

¿Funciona en Cursor?

Sí. Cursor, Windsurf y VSCodium la instalan desde Open VSX, donde está publicada como zovo/zovo-shell-formatter.
