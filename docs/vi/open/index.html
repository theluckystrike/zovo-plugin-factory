Hướng dẫn bằng tiếng Việt

VS Code và các trình soạn thảo dựa trên nó (Cursor, Windsurf, VSCodium) mở được văn bản, hình ảnh và một số tệp đa phương tiện. Với nhiều định dạng khác, bạn cần một tiện ích. Mỗi hướng dẫn nêu các bước và cho biết phần nào miễn phí.

  • Xem tệp STL trong VS Code. Mở tệp STL trong VS Code bằng 3D Model Viewer miễn phí: xoay, đo giữa hai điểm, khung dây và thông số mô hình. Mở được cả OBJ, PLY, 3MF, GLB và glTF.
  • Đọc và tiếp tục lịch sử Claude Code trong VS Code. Đọc, tìm kiếm và tiếp tục các session Claude Code và Codex cũ trong VS Code. Subagent lồng bên dưới, chỉnh sửa dạng diff, tổng token. Chỉ đọc, offline.
  • Phát tệp âm thanh trong VS Code. Phát tệp WAV, MP3, FLAC, Ogg và Opus trong VS Code với Audio Player miễn phí: dạng sóng, phổ tần, vòng lặp A-B, tốc độ và độ lớn LUFS.
  • Tự động đổi tên thẻ HTML, JSX và Vue trong VS Code. Đổi tên một thẻ HTML, JSX hoặc Vue và thẻ tương ứng đổi theo ngay khi gõ. Tiện ích miễn phí dựa trên linked editing của VS Code, có tự đóng thẻ và một lần undo.
  • Mở bản vẽ DXF trong VS Code. Xem bản vẽ .dxf trong VS Code với DXF Viewer miễn phí: DXF ASCII và binary, lớp, sheet paper space, tìm chữ, đo và xuất PNG hoặc SVG.
  • Xem section và import của tệp ELF, EXE hoặc DLL trong VS Code. Mở tệp .so, .exe, .dll và .dylib trong VS Code với ELF Viewer & PE Viewer miễn phí: header, section, import, export, symbol và hex, chỉ đọc.
  • Xem trước tệp font trong VS Code. Mở font .ttf, .otf, .woff, .woff2 và .ttc trong VS Code với Font Viewer miễn phí: thử chữ, xem mọi glyph và đọc giấy phép, không cần cài font.
  • Xem trước đồ thị Graphviz DOT mà không cần cài Graphviz. Xem trước tệp .dot và .gv cạnh editor trong VS Code ngay khi gõ, Graphviz có sẵn bên trong. Sáu engine bố cục, bấm để tới dòng, xuất SVG và PNG.
  • Xem trước sơ đồ Mermaid trong VS Code. Xem trước sơ đồ Mermaid trong VS Code từ tệp .mmd và khối Markdown với Mermaid Viewer miễn phí. Xem trực tiếp, xuất PNG và SVG, offline, không cần đăng nhập.
  • Trình xem NetCDF miễn phí chạy trong VS Code. Mở tệp NetCDF .nc trong VS Code trên Windows, macOS hoặc Linux: header, biến, bản đồ có đường bờ biển, chuỗi thời gian. Mở cả HDF5 .h5 và MATLAB 7.3 .mat.
  • Xem tệp NumPy .npy và .npz trong VS Code. Mở mảng NumPy .npy và .npz trong VS Code với Tensor Viewer miễn phí: dtype, shape, thống kê, heatmap, hình ảnh và giá trị, không cần Python.
  • Mở tệp PCAP trong VS Code. Đọc bản bắt gói .pcap, .pcapng và .pcap.gz trong VS Code với PCAP Viewer miễn phí: danh sách gói, cây giao thức, khung hex và bộ lọc. Không cần Wireshark.
  • Chạy tệp C++ trong VS Code chỉ với một cú bấm. Biên dịch và chạy tệp .cpp hoặc .c đang mở trong VS Code bằng một cú bấm, dùng gcc, g++ hoặc clang có sẵn. Nhập liệu trong terminal, lỗi trong Problems.
  • Mở cơ sở dữ liệu SQLite trong VS Code. Mở tệp .db hoặc .sqlite trong VS Code với SQLite Viewer & Editor miễn phí: bảng, schema và SQL, rồi sửa ô, sửa hàng và lưu kèm bản sao lưu.
  • Chuyển TIFF sang PNG mà không mất chất lượng. Mở tệp TIFF, BigTIFF và GeoTIFF miễn phí trong VS Code, rồi lưu một trang hoặc mọi trang thành PNG, giữ đúng giá trị 8 và 16-bit. Chạy offline.
  • Phát video MOV, MKV, WebM và MP4 có tiếng trong VS Code. Phát MP4, MOV và M4V có tiếng AAC trong VS Code mà không cần cài thêm gì. MKV, WebM và AVI cũng phát được khi có ffmpeg. Trình phát miễn phí, có phụ đề.
  • Chuyển XMind sang PDF không cần XMind: mọi sheet trong một PDF. Mở sơ đồ tư duy .xmind trong VS Code không cần XMind và lưu mọi sheet vào một PDF, mỗi sheet một trang. Phần xem miễn phí, PDF là công cụ Zovo Pro.
  • Mở tệp bên trong ZIP mà không cần giải nén. Duyệt ZIP, JAR, TAR hoặc TAR.GZ trong VS Code và mở một tệp bên trong ở tab chỉ đọc, không giải nén gì ra ổ đĩa. Miễn phí và chạy offline.
  • Mở JAR và đọc mã nguồn Java đã dịch ngược trong VS Code. Mở tệp .jar, .war, .ear, .aar và .class trong VS Code: package, MANIFEST.MF, bytecode và mã nguồn Java dịch ngược bằng CFR. Miễn phí và chỉ đọc.
  • Hex editor cho file nhị phân trong VS Code. Mở file nhị phân ở dạng hex trong VS Code, sửa, chèn và xóa byte, tìm theo hex hoặc văn bản và so sánh hai file, kể cả file nhiều GB.
  • Mở file Word .docx trong VS Code. Mở file .docx, .odt và .doc ngay trong VS Code mà không cần Word, với chế độ tối, outline, tìm kiếm, tracked changes và so sánh hai phiên bản.
  • Mở Excel và CSV trong VS Code và chạy SQL trên dữ liệu. Mở file .xlsx, .xls, .csv và Parquet thành bảng có thể sắp xếp, lọc trong VS Code, tới 1.000.000 dòng, và chạy SQL với GROUP BY ngay trên file.
  • Mở file Word và PowerPoint trong VS Code mà không cần Office. Xem file .docx, .odt và .pptx trong VS Code mà không cần cài Office, với outline, tìm kiếm, tracked changes, ghi chú thuyết trình và chế độ trình chiếu.
  • Đọc PDF ở chế độ tối trong VS Code. Mở PDF trong VS Code với trang tối hoặc màu sepia, ảnh vẫn giữ màu thật, kèm tìm kiếm, outline, hình thu nhỏ và highlight 4 màu.

Các hướng dẫn khác có bằng tiếng Anh.
