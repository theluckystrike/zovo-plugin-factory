Format HTML và CSS trong VS Code mà không làm hỏng khối pre hay thẻ inline

Cài extension miễn phí HTML Formatter & CSS Formatter rồi nhấn Shift+Alt+F trong file HTML, CSS, SCSS hoặc LESS. Extension cũng format các khối <style> và <script> trong trang, tuân theo .editorconfig của bạn, giữ <pre>, <textarea> và các thẻ inline đúng như bạn viết, và không bao giờ đổi thứ tự thuộc tính. Extension chạy offline với js-beautify đóng gói sẵn, nên không cần Node, npm hay file cấu hình. Zovo Pro (19 USD một lần) thêm ba công cụ Format Folder with Diff Preview, Minify HTML and CSS và HTML Lint Report, mỗi công cụ có 3 lần dùng thử miễn phí.

Các bước trong VS Code

  1. Cài HTML Formatter & CSS Formatter từ Marketplace, hoặc nhấn Ctrl+P (Cmd+P trên macOS) rồi chạy ext install zovo.zovo-html-formatter.
  2. Mở file HTML, CSS, SCSS hoặc LESS và nhấn Shift+Alt+F (Shift+Option+F trên macOS). Nếu VS Code hỏi dùng formatter nào, chọn HTML Formatter & CSS Formatter.
  3. Để đặt extension làm formatter mặc định cho cả bốn ngôn ngữ trong một bước, chạy "HTML Formatter: Use as Default Formatter for HTML, CSS, SCSS and LESS" từ Command Palette.
  4. Chọn vài dòng rồi chạy Format Selection để chỉ format các dòng đó.
  5. Để format mỗi lần lưu, bật zovoHtmlFormat.formatOnSave, hoặc dùng editor.formatOnSave của chính VS Code sau khi extension đã là formatter mặc định.
  6. Thụt lề lấy từ trình soạn thảo, sau đó từ .editorconfig (kiểu và độ rộng thụt lề, ký tự cuối dòng, dòng mới cuối file, độ dài dòng tối đa), nên cả nhóm nhận được cùng một kết quả.

Những gì miễn phí và Zovo Pro thêm gì

Format Document, Format Selection và format khi lưu cho HTML, CSS, SCSS và LESS, có hỗ trợ .editorconfig, đều miễn phí, không cần đăng nhập, không có request mạng và không có telemetry.

Khi cả một website cần theo cùng một style, Format Folder with Diff Preview format trong bộ nhớ mọi file HTML, CSS, SCSS và LESS của một thư mục, hiện các file thay đổi kèm diff hai bên cho từng file, và chỉ ghi những file bạn giữ dấu chọn. Bạn thấy mọi thay đổi trước khi file nào được ghi.

Cách dùng Format Folder with Diff Preview (Zovo Pro)

  1. Nhấp chuột phải vào một thư mục trong Explorer và chọn "Zovo Pro: Format folder with diff preview", hoặc chạy "HTML Formatter: Format Folder with Diff Preview (Pro)" từ Command Palette.
  2. Xem qua các file thay đổi. Mở diff của bất kỳ file nào và bỏ chọn những file bạn muốn giữ nguyên.
  3. Ghi các file đã chọn. Một lần dùng thử chỉ bị tính khi công cụ trả về kết quả.

Format Folder with Diff Preview chạy được 3 lần miễn phí trên máy của bạn trước khi yêu cầu giấy phép. Không có cửa sổ bật lên và không có đếm ngược.

Các bước trong Cursor, Windsurf hoặc VSCodium

  1. Mở khung Extensions bằng Ctrl+Shift+X (Cmd+Shift+X trên macOS).
  2. Tìm zovo.zovo-html-formatter rồi bấm Install. Cursor, Windsurf và VSCodium cài tiện ích từ Open VSX, nơi tiện ích này có tên zovo/zovo-html-formatter.
  3. Nếu trình soạn thảo của bạn không có kho tiện ích, hãy tải tệp .vsix từ trang Open VSX rồi chạy "Extensions: Install from VSIX...".
  4. Sau đó mọi thứ hoạt động giống như trong VS Code.

HTML Formatter & CSS Formatter làm được gì

  • CSS trong <style> và JavaScript trong <script> bên trong HTML.
  • Giữ nguyên như đã viết: nội dung của <pre> và <textarea>, thẻ inline trên dòng của nó, thứ tự thuộc tính, dòng trống giữa các khối (tối đa một dòng liên tiếp), kiểu thụt lề head và body của trang, và template tag như {{ }} và {% %}.
  • Trong SCSS và LESS, map và lời gọi hàm nhiều dòng giữ nguyên bố cục, comment cuối dòng vẫn nằm trên dòng của nó.
  • Hai công cụ Pro còn lại. Minify HTML and CSS ghi bản sao .min.html và .min.css kèm báo cáo số byte và byte gzip tiết kiệm được. HTML Lint Report tìm ảnh thiếu alt text, trường form thiếu label, id trùng, cấp heading bị bỏ qua và các lỗi khác, đưa vào báo cáo Markdown và bảng Problems.

Những gì không làm được

  • File .js, .jsx, .ts, Vue và Svelte riêng lẻ không được extension này format. Chỉ JavaScript bên trong <script> được format.
  • Dòng không được ngắt trừ khi bạn đặt độ dài wrap, nên một dòng rất dài vẫn giữ nguyên.
  • SCSS và LESS đi qua formatter CSS. Cú pháp ít gặp như detached ruleset của LESS có thể giữ khoảng trắng ban đầu.
  • Minify không rút gọn JavaScript và không đổi tên hay gộp rule CSS.

Câu hỏi thường gặp

Extension có miễn phí không?

Format Document, Format Selection và format khi lưu cho HTML, CSS, SCSS và LESS đều miễn phí. Ba công cụ Pro Format Folder with Diff Preview, Minify HTML and CSS và HTML Lint Report mỗi công cụ có 3 lần dùng thử miễn phí. Sau đó cần Zovo Pro, 19 USD một lần cho mọi extension của Zovo.

VS Code có format HTML mà không cần extension không?

Có. VS Code có sẵn formatter HTML và CSS. Extension này đọc .editorconfig, giữ kiểu thụt lề head và body riêng của trang, giữ bố cục map trong SCSS và LESS, và thêm các công cụ Pro cho thư mục, minify và lint.

Extension có làm thay đổi khối pre hay sắp xếp lại thuộc tính không?

Không. Nội dung của pre và textarea, thẻ inline và thứ tự thuộc tính giữ đúng như bạn viết.

Có cần Node hay npm không?

Không. js-beautify 1.15.4 được đóng gói sẵn trong extension và chạy offline.
