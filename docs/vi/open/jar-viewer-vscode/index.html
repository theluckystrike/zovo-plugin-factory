Các bước trong VS Code

  1. Cài JAR Viewer từ Marketplace, hoặc nhấn Ctrl+P (Cmd+P trên macOS) rồi chạy ext install zovo.zovo-jar-viewer.
  2. Bấm vào tệp .jar, .war, .ear, .aar hoặc .class trong Explorer. Tệp mở trong JAR Viewer. Overview hiển thị định dạng, số mục, số class và package, Main-Class, Created by, MANIFEST.MF và biểu đồ các phiên bản Java mà các class được biên dịch cho.
  3. Gõ một phần tên vào ô lọc phía trên cây package. Ô lọc tìm class và tệp ngay khi bạn gõ. Inner class hiện mờ bên dưới class bên ngoài của nó.
  4. Bấm vào một class. Tab Java source hiển thị class đã dịch ngược bằng CFR 0.152, kèm các inner class. Copy chép mã nguồn vào clipboard, còn Open in editor mở nó trong một tab editor thường.
  5. Nếu tab Java source báo rằng mã nguồn Java dịch ngược cần Java runtime, hãy đặt jarViewer.javaPath trỏ tới tệp java hoặc một thư mục JDK, hoặc đặt JAVA_HOME. "JAR Viewer: Check the Java runtime used for decompiling" cho biết Java nào đang được dùng.
  6. Mở tab Bytecode để xem danh sách kiểu javap -c -p với mọi opcode, các bảng exception và số dòng. Members, Constant pool và Class info hiển thị các khai báo, các mục trong constant pool và các attribute của class.
  7. Trong một JAR Spring Boot, WAR hoặc AAR, bấm vào một JAR trong BOOT-INF/lib hoặc WEB-INF/lib, hoặc classes.jar của AAR, rồi bấm "Open nested archive". Tệp mở sâu thêm một cấp, và nút mang tên tệp bên ngoài ở trên cùng đưa bạn quay lại.

Những gì miễn phí và Zovo Pro thêm gì

Cây package, Overview, manifest, tài nguyên, mã nguồn Java dịch ngược, bytecode, Members, Constant pool, Class info và JAR lồng nhau đều miễn phí, không cần đăng nhập. CFR đi kèm tiện ích và chạy bằng Java đã có trên máy bạn. Tiện ích không bao giờ sửa tệp nén và không gọi mạng.

Export decompiled sources of a JAR dịch ngược mọi class trong một JAR, WAR, EAR hoặc AAR bằng CFR và ghi các tệp .java vào một thư mục, có hiển thị tiến độ và nút Cancel. Nếu không có Java runtime, công cụ ghi các danh sách bytecode thay vào đó. Bạn có cả thư viện dưới dạng tệp mã nguồn để tìm kiếm hoặc đọc trong editor, thay vì mở từng class một.

Cách dùng Export decompiled sources of a JAR (Zovo Pro)

  1. Mở tệp nén rồi bấm "Export sources…" ở đầu trình xem, hoặc "Export decompiled sources" trong hàng Pro tools nhỏ. Bạn cũng có thể nhấp chuột phải vào tệp trong Explorer và chọn "Zovo Pro: Export decompiled sources".
  2. Hoặc chạy "JAR Viewer: Export decompiled sources of a JAR (Pro)" từ Command Palette. Khi chưa mở tệp nén nào, lệnh sẽ yêu cầu bạn chọn một tệp JAR, WAR, EAR hoặc AAR.
  3. Chọn một thư mục rồi bấm "Export here". Mã nguồn được ghi vào một thư mục mới mang tên tệp nén, có thêm -src ở cuối.
  4. Một thông báo hiển thị tiến độ. Cancel dừng việc xuất và không tính lượt dùng thử. Khi xong, trình xem cho biết đã ghi bao nhiêu tệp và ghi vào đâu.

Export decompiled sources of a JAR chạy được 3 lần miễn phí trên máy của bạn trước khi yêu cầu giấy phép. Không có cửa sổ bật lên và không có đếm ngược.

Các bước trong Cursor, Windsurf hoặc VSCodium

  1. Mở khung Extensions bằng Ctrl+Shift+X (Cmd+Shift+X trên macOS).
  2. Tìm zovo.zovo-jar-viewer rồi bấm Install. Cursor, Windsurf và VSCodium cài tiện ích từ Open VSX, nơi tiện ích này có tên zovo/zovo-jar-viewer.
  3. Nếu trình soạn thảo của bạn không có kho tiện ích, hãy tải tệp .vsix từ trang Open VSX rồi chạy "Extensions: Install from VSIX...".
  4. Sau đó mọi thứ hoạt động giống như trong VS Code.

JAR Viewer làm được gì

  • Tệp nén JAR, WAR, EAR và AAR, và tệp .class riêng lẻ cùng các inner class nằm trong cùng thư mục.
  • Tệp nén có tới 200.000 mục, và ô lọc tìm một class hoặc tệp trong 50.000 mục ngay khi bạn gõ.
  • Generic signature, record, permitted subclass, nest host và annotation trong dữ liệu class.
  • Tài nguyên văn bản như properties, XML, JSON, SQL và tệp services hiển thị dạng văn bản, còn tệp nhị phân có bản xem trước hex.
  • Tệp nén trong BOOT-INF/lib của Spring Boot, WEB-INF/lib của WAR và classes.jar của AAR, sâu một cấp.

Những gì không làm được

  • Mã nguồn dịch ngược cần Java 8 trở lên trên máy bạn. Không có Java thì bytecode và mọi chế độ xem khác vẫn hoạt động.
  • Kết quả của CFR có thể khác mã nguồn gốc, ví dụ ở tên biến cục bộ, một số generics và lambda.
  • Mỗi mục được giải nén tối đa 64 MB, tệp class tối đa 16 MB và tệp nén lồng nhau tối đa 128 MB. Tệp trên hệ thống tệp từ xa hoặc ảo được đọc tối đa 256 MB.
  • Tiện ích chỉ đọc, nên bạn không thể sửa hoặc biên dịch lại một class. Tệp nén lồng nhau chỉ mở được sâu một cấp.
  • Không đọc tệp APK và DEX.

Câu hỏi thường gặp

Có miễn phí không?

Có. Mọi chế độ xem và việc dịch ngược từng class một đều miễn phí. Ba công cụ Pro, Export decompiled sources of a JAR, Compare two JARs và Find in every JAR of a folder, mỗi công cụ có 3 lượt dùng thử miễn phí, và một lượt chỉ bị tính khi công cụ cho bạn kết quả. Sau đó cần Zovo Pro, 19 USD một lần cho mọi tiện ích Zovo.

Vì sao tab Java source yêu cầu Java?

CFR là một chương trình Java. Trình xem tìm Java trong jarViewer.javaPath, rồi JAVA_HOME, rồi java trên PATH của bạn. Mọi Java runtime từ bản 8 trở lên đều dùng được.

Có đọc được bytecode khi không có Java không?

Có. Các tab Bytecode, Members, Constant pool và Class info được đọc bằng JavaScript và không cần Java.

Có dùng được trong Cursor không?

Có. Tiện ích có trên Open VSX với tên zovo/zovo-jar-viewer, nên Cursor, Windsurf và VSCodium cài được.
