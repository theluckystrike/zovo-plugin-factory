Upload tệp lên server qua SFTP hoặc FTP từ VS Code

Cài tiện ích miễn phí SFTP & FTP Sync and Upload và viết một tệp .vscode/sftp.json với host, user và thư mục trên server. Từ đó mỗi tệp được upload khi bạn lưu, qua SFTP, FTP hoặc FTPS. Nhấp chuột phải vào tệp hoặc thư mục để upload, download hoặc so sánh với bản trên server, và mở tệp trên server trong một tab bình thường từ view Remote Files. Thư mục .vscode, tệp .env và private key của bạn không bao giờ được upload. Tất cả đều miễn phí, không cần tài khoản. Zovo Pro (19 USD, trả một lần) thêm ba công cụ Sync Folder with Remote, Roll Back a Remote File và Server Profiles and Jump Host, mỗi công cụ có 3 lượt dùng thử miễn phí.

Các bước trong VS Code

  1. Cài SFTP & FTP Sync and Upload từ Marketplace, hoặc nhấn Ctrl+P (Cmd+P trên macOS) rồi chạy ext install zovo.zovo-sftp.
  2. Chạy "SFTP: Create sftp.json Config" từ Command Palette, hoặc bấm Create sftp.json trong view SFTP Remote.
  3. Điền protocol (sftp, ftp hoặc ftps), host, username, privateKeyPath (bỏ trống để dùng mật khẩu) và remotePath, thư mục trên server tương ứng với thư mục cục bộ của bạn. Rê chuột lên bất kỳ key nào để xem hướng dẫn.
  4. Đặt "uploadOnSave": true. Từ giờ, mỗi tệp bạn lưu sẽ được upload. Mật khẩu bạn nhập chỉ được hỏi một lần và được giữ trong secret storage của trình soạn thảo, không bao giờ nằm trong sftp.json.
  5. Nhấp chuột phải vào bất kỳ tệp hoặc thư mục nào trong Explorer, hoặc vào một tab, và chọn Upload, Download hoặc Compare with Server Copy (Compare chỉ dùng cho tệp).
  6. Mở view Remote Files để duyệt server. Mở một tệp trong tab trình soạn thảo bình thường rồi lưu ngược lên, tải nó về, sao chép đường dẫn hoặc xóa nó. "SFTP: Show Transfer Log" hiện mọi kết nối và lần truyền tệp.

Những gì miễn phí và Zovo Pro thêm gì

Upload khi lưu, Upload, Download và Compare with Server Copy, view Remote Files, SFTP, FTP và FTPS, kiểm tra host key và transfer log đều miễn phí, không cần tài khoản và không phải đăng nhập vào đâu ngoài server của chính bạn. Không có telemetry.

Khi server và thư mục cục bộ đã lệch nhau, Sync Folder with Remote so sánh hai bên và liệt kê mọi khác biệt trước khi có gì được chuyển: tệp chỉ có ở máy, chỉ có trên server, hoặc mới hơn ở một bên. Bạn chọn upload, download, xóa hoặc bỏ qua cho từng tệp, mở diff hai bên cạnh nhau, lưu bản chạy thử (dry run) thành văn bản, rồi mới áp dụng. Bạn thấy chính xác điều gì sẽ thay đổi trên server trước khi nó thay đổi.

Cách dùng Sync Folder with Remote (Zovo Pro)

  1. Nhấp chuột phải vào một thư mục trong Explorer và chọn "Zovo Pro: Sync folder with remote (diff preview)", hoặc chạy "SFTP: Sync Folder with Remote, Diff Preview (Pro)..." từ Command Palette. View Remote Files cũng có nút này trên thanh tiêu đề.
  2. Đọc bản kế hoạch. Với mỗi tệp, chọn upload, download, xóa hoặc bỏ qua, và mở diff của bất kỳ tệp nào bạn chưa chắc chắn.
  3. Áp dụng bản kế hoạch. Chỉ tính một lượt dùng thử khi bản kế hoạch đồng bộ đã hiện. Nhấn Escape hoặc Cancel thì không bao giờ tốn lượt.

Các bước trong Cursor, Windsurf hoặc VSCodium

  1. Mở khung Extensions bằng Ctrl+Shift+X (Cmd+Shift+X trên macOS).
  2. Tìm zovo.zovo-sftp rồi bấm Install. Cursor, Windsurf và VSCodium cài tiện ích từ Open VSX, nơi tiện ích này có tên zovo/zovo-sftp.
  3. Nếu trình soạn thảo của bạn không có kho tiện ích, hãy tải tệp .vsix từ trang Open VSX rồi chạy "Extensions: Install from VSIX...".
  4. Sau đó mọi thứ hoạt động giống như trong VS Code.

SFTP & FTP Sync and Upload làm được gì

  • SFTP với SSH key, key đã mã hóa, SSH agent hoặc mật khẩu; FTP; FTPS với TLS explicit hoặc implicit.
  • .vscode, .git, tệp .env, private key, .npmrc và các tệp bí mật khác không bao giờ được upload. Thêm mẫu của riêng bạn vào ignore, theo kiểu .gitignore.
  • Host key của server được kiểm tra: ghim nó bằng hostFingerprint hoặc xác nhận ở lần kết nối đầu tiên. Host key bị đổi sẽ dừng kết nối.
  • Trong thư mục bạn chưa tin cậy (Restricted Mode), tiện ích không hoạt động, nên một dự án tải về không thể gửi tệp của bạn đi đâu.
  • Hai công cụ Pro còn lại: Roll Back a Remote File giữ 10 bản server gần nhất của một tệp trên máy bạn trước khi một lần upload ghi đè nó, và Server Profiles and Jump Host đặt nhiều server (staging, production) trong một sftp.json và kết nối qua một SSH jump host.

Những gì không làm được

  • Mỗi server chỉ có một kết nối tại một thời điểm, và các lần truyền FTP chạy lần lượt từng cái.
  • Symbolic link trên server được đi theo với tệp, nhưng thư mục là link thì không được duyệt khi upload, download hay đồng bộ cả thư mục.
  • Key ở định dạng PuTTY .ppk phải được chuyển sang OpenSSH trước (puttygen key.ppk -O private-openssh -o key).
  • Đồng bộ so sánh kích thước và thời gian sửa đổi, rồi so từng byte của các tệp cùng kích thước, tối đa 300 tệp hoặc 64 MB mỗi lần chạy.
  • Bản sao để rollback mặc định chỉ được giữ cho tệp tới 5 MB, và chỉ trên máy này.

Câu hỏi thường gặp

Có miễn phí không?

Upload khi lưu, Upload, Download, Compare with Server Copy, view Remote Files và transfer log đều miễn phí, qua SFTP, FTP và FTPS. Ba công cụ Pro, Sync Folder with Remote, Roll Back a Remote File và Server Profiles and Jump Host, mỗi công cụ có 3 lượt dùng thử miễn phí. Sau đó cần Zovo Pro, 19 USD trả một lần cho mọi tiện ích Zovo.

Mật khẩu của tôi có được lưu trong sftp.json không?

Không. Mật khẩu hoặc passphrase bạn nhập được giữ trong secret storage của trình soạn thảo. Bỏ password ra khỏi sftp.json và bạn sẽ được hỏi một lần.

Tiện ích có upload tệp .env của tôi không?

Không. .vscode, .git, tệp .env, private key và .npmrc nằm trong danh sách bỏ qua mặc định và không bao giờ được upload.

VS Code có upload qua SFTP được mà không cần tiện ích không?

Không. VS Code không có tính năng upload qua SFTP hay FTP. Remote SSH sửa tệp ngay trên server; để upload một dự án cục bộ, bạn cần một tiện ích, hoặc scp và rsync trong terminal.
