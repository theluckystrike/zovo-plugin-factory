Mở file Word .docx trong VS Code

Cài DOCX Viewer rồi nhấp vào file .docx trong Explorer: tài liệu mở thành bản xem chỉ đọc ngay trong VS Code, theo giao diện sáng hoặc tối của VS Code, không cần Microsoft Word. Outline, tìm kiếm, tracked changes, bình luận, so sánh hai phiên bản trên màn hình và Copy as Markdown đều miễn phí. Zovo Pro (USD 19 một lần) bổ sung các công cụ như xuất bản redline thành file Word có tracked changes thật, và mỗi công cụ có 3 lần dùng thử miễn phí.

Cài vào VS CodeTrang MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

Miễn phí, giấy phép MIT. Extension ID zovo.docx-viewer-vscode.

Các bước trong VS Code

  1. Cài DOCX Viewer từ Marketplace, hoặc nhấn Ctrl+P (Cmd+P trên macOS) rồi chạy ext install zovo.docx-viewer-vscode.
  2. Nhấp vào file .docx, .dotx, .docm hoặc .odt trong Explorer. Tài liệu mở ở chế độ chỉ đọc, giữ tiêu đề, danh sách, bảng, hình ảnh, biểu đồ và công thức. Nút Theme chuyển sang nền giấy trắng nếu bạn không muốn đọc trên nền tối.
  3. Bấm vào một đề mục trong outline để nhảy tới phần đó. Nhấn Ctrl+F (Cmd+F trên macOS) để tìm chữ, Enter để tới kết quả tiếp theo và Shift+Enter để quay lại kết quả trước.
  4. Chuyển sang Page view khi cần xem khổ giấy, lề, header, footer và phông chữ như bản in. Dùng Ctrl+= và Ctrl+- để phóng to, thu nhỏ.
  5. Nếu tài liệu có tracked changes hoặc bình luận, thanh ở đầu Reading view cho biết số lượng. Chọn Markup để xem từng thay đổi theo màu của từng người, Final để xem bản như khi mọi thay đổi đã được chấp nhận, hoặc Original để xem bản gốc.
  6. Để xem khác biệt giữa hai phiên bản, nhấp chuột phải vào file và chọn “Compare with Git HEAD” hoặc “Compare with Another Document...”. Kết quả hiện thành redline hoặc Markdown diff ngay trong VS Code.
  7. Dùng “Copy as Markdown” hoặc “Open as Text” để lấy nội dung tài liệu và dán vào wiki, issue hay ghi chú.

Trong Cursor, Windsurf và VSCodium

Các trình soạn thảo này cài tiện ích từ Open VSX. Mở khung Extensions (Ctrl+Shift+X), tìm zovo.docx-viewer-vscode rồi bấm Install. Trang trên Open VSX là zovo/docx-viewer-vscode. Sau đó dùng giống như trong VS Code.

Những gì miễn phí

Toàn bộ phần xem đều miễn phí: Reading view và Page view, outline, tìm kiếm, công thức và biểu đồ, tracked changes và bình luận, so sánh với Git HEAD hoặc với một tài liệu khác (redline trên màn hình hoặc Markdown diff), Copy as Markdown và Open as Text. Tài liệu tự tải lại khi một chương trình khác lưu file, nên bản do script hay AI agent tạo ra luôn là bản mới nhất. Tiện ích chạy offline, không cần đăng nhập và không có telemetry.

Zovo Pro thêm gì

“Export Redline as Word” so sánh tài liệu đang mở với một phiên bản khác và ghi ra một file .docx mới dựa trên bản mới hơn, trong đó mỗi khác biệt là một tracked change thật của Word, gồm chữ thêm, chữ xóa, đoạn di chuyển, hàng bảng và thay đổi định dạng. Người nhận mở file trong Word và chấp nhận hoặc từ chối từng thay đổi, không ai phải tự dò hai bản để tìm chỗ khác. Các công cụ Pro khác là Export Redline as PDF (bản redline có đánh số trang và trang tóm tắt), Export Change List of a Comparison (danh sách thay đổi dạng Excel, CSV và Markdown) và Compare Two Folders of Documents (so sánh các tài liệu cùng tên trong hai thư mục).

Cách dùng Export Redline as Word

  1. Mở tài liệu trong DOCX Viewer rồi chạy “DOCX Viewer Pro: Export Redline as Word (Pro)...” từ Command Palette, hoặc nhấp chuột phải vào file trong Explorer và chọn “Zovo Pro: Export Redline as Word”.
  2. Chọn tài liệu còn lại để so sánh và nơi lưu file .docx mới. Bản mới hơn phải là file Word.
  3. Sau khi lưu, DOCX Viewer tự kiểm tra file vừa ghi và báo kết quả. Lượt dùng thử chỉ được tính khi file đã được ghi, nên đóng hộp thoại chọn file sẽ không mất lượt.

Export Redline as Word chạy miễn phí 3 lần trước khi yêu cầu giấy phép. Không có cửa sổ bật lên khi mở tệp và không có đếm ngược.

Những gì không làm được

  • DOCX Viewer chỉ để xem. Nó không chỉnh sửa, không lưu tài liệu và không chấp nhận hay từ chối tracked changes trong file.
  • File .doc đời cũ chỉ hiện phần chữ, không có định dạng, hình ảnh hay bố cục. Đuôi .rtf, .wps và .pages không được hỗ trợ.
  • File lớn hơn 100 MB sẽ hỏi trước khi mở. Page view không hiện tracked changes và bình luận, và SmartArt không được hiển thị.
  • Redline và so sánh thư mục cần VS Code bản desktop. Trong vscode.dev và github.dev, lệnh so sánh mở Markdown diff.

Câu hỏi

DOCX Viewer có miễn phí không?

Có. Đọc tài liệu, tìm kiếm, xem tracked changes và so sánh hai phiên bản trên màn hình đều miễn phí. Bốn công cụ xuất và so sánh thư mục thuộc Zovo Pro, trả USD 19 một lần cho mọi tiện ích Zovo, và mỗi công cụ cho dùng thử miễn phí 3 lần.

Có dùng được trong Cursor không?

Có. DOCX Viewer có trên Open VSX, nên bạn cài được trong Cursor (cũng như Windsurf và VSCodium) từ khung Extensions, giống như trong VS Code.

Có mở được file .doc đời cũ không?

Có, nhưng chỉ phần chữ, gồm đoạn văn, bảng đơn giản, header, footer, chú thích và bình luận. Định dạng, hình ảnh và bố cục không được hiển thị; nút “Open in Default App” mở file bằng ứng dụng mặc định trên máy.

DOCX Viewer có chạy trong vscode.dev không?

Có, DOCX Viewer chạy được trong vscode.dev và github.dev. Tuy vậy “Compare with Git HEAD”, “Open in Default App”, redline và so sánh thư mục chỉ có trong VS Code bản desktop.

Mọi tính năng và cài đặt có trên trang DOCX Viewer (tiếng Anh).
