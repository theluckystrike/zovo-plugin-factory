Đọc PDF ở chế độ tối trong VS Code

Cài PDF Reader rồi nhấp vào file .pdf: khi VS Code dùng giao diện tối, trang PDF hiện trên nền tối, còn nút hình mặt trăng bật hoặc tắt trang tối cho file đang mở. Trang tối, trang sepia, tìm kiếm, outline, hình thu nhỏ, highlight và Copy as Markdown đều miễn phí. Zovo Pro (USD 19 một lần) bổ sung các công cụ như gom highlight của mọi file PDF vào một file Markdown, mỗi công cụ có 3 lần dùng thử miễn phí.

Cài vào VS CodeTrang MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

Miễn phí, giấy phép MIT. Extension ID zovo.pdf-viewer-dark.

Các bước trong VS Code

  1. Cài PDF Reader từ Marketplace, hoặc nhấn Ctrl+P (Cmd+P trên macOS) rồi chạy ext install zovo.pdf-viewer-dark.
  2. Nhấp vào một file .pdf trong Explorer. Với giao diện tối của VS Code, trang PDF hiện trên nền tối; bấm nút hình mặt trăng (hoặc chạy “PDF: Toggle Dark Pages”) để bật hoặc tắt trang tối cho file đang mở.
  3. Bấm nút hình trang giấy cạnh nút mặt trăng để chuyển sang trang sepia, dịu mắt hơn khi đọc lâu. Ảnh chụp giữ nguyên màu trên cả trang tối lẫn trang sepia.
  4. Nhấn Ctrl+F (Cmd+F trên macOS) để tìm và Enter để tới kết quả tiếp theo. Chạy “PDF: Toggle Outline and Pages” để mở thanh bên với outline và hình thu nhỏ các trang.
  5. Bôi đen một đoạn chữ rồi chọn một trong 4 màu, hoặc nhấn H để tô màu vàng. Tab Highlights liệt kê mọi highlight kèm số trang; bấm vào một mục để nhảy tới đó.
  6. Dùng “Copy as Markdown” (hoặc “PDF: Copy Highlights as Markdown” trong Command Palette) để sao chép danh sách highlight kèm liên kết tới từng trang, rồi dán vào ghi chú.

Trong Cursor, Windsurf và VSCodium

Các trình soạn thảo này cài tiện ích từ Open VSX. Mở khung Extensions (Ctrl+Shift+X), tìm zovo.pdf-viewer-dark rồi bấm Install. Trang trên Open VSX là zovo/pdf-viewer-dark. Sau đó dùng giống như trong VS Code.

Những gì miễn phí

Trang tối và trang sepia, tìm kiếm, outline, hình thu nhỏ, highlight, Copy as Markdown, “Go to Page...” và liên kết tới từng trang đều miễn phí. PDF tự tải lại khi file thay đổi trên đĩa, chẳng hạn sau khi build LaTeX hoặc Typst, mà vẫn giữ trang và mức zoom, và mỗi file mở lại đúng trang bạn đọc lần trước. Tiện ích chạy offline, không có telemetry và không chạy JavaScript trong PDF.

Zovo Pro thêm gì

“Export Highlights of All PDFs to Markdown” gom highlight của mọi file PDF bạn đã đánh dấu (hoặc chỉ các file trong workspace hiện tại) vào một file Markdown, nhóm theo từng file, kèm màu và liên kết tới từng trang. Bạn không phải mở lại từng PDF để chép ghi chú khi viết báo cáo hay tổng hợp tài liệu. Các công cụ Pro khác là Page Tools (trích, xóa, sắp xếp lại và tách trang thành PDF mới), Merge PDFs và Compare Two PDFs.

Cách dùng Export Highlights of All PDFs to Markdown

  1. Chạy “PDF: Export Highlights of All PDFs to Markdown (Pro)...” từ Command Palette, hoặc bấm liên kết “All PDFs” trong tab Highlights.
  2. Chọn lấy highlight của mọi PDF hay chỉ các PDF trong workspace này, rồi chọn nơi lưu file Markdown.

Export Highlights of All PDFs to Markdown chạy miễn phí 3 lần trước khi yêu cầu giấy phép. Không có cửa sổ bật lên khi mở tệp và không có đếm ngược.

Những gì không làm được

  • Highlight chỉ được lưu trong VS Code trên máy này, không ghi vào file PDF, nên ứng dụng PDF khác không thấy và chúng không đồng bộ sang máy khác.
  • Trên trang tối, biểu đồ dạng vector bị đảo màu giống chữ; chỉ ảnh dạng raster giữ nguyên màu.
  • Tiện ích không điền form, không sửa chữ hay ảnh trên trang và không in.
  • File được tải toàn bộ vào bộ nhớ, và tiện ích hỏi trước khi mở file lớn hơn 200 MB.

Câu hỏi

PDF Reader có miễn phí không?

Có. Đọc PDF trên trang tối hoặc sepia, tìm kiếm, outline, hình thu nhỏ và highlight đều miễn phí. Bốn công cụ Pro (page tools, gộp PDF, xuất highlight của mọi PDF và so sánh hai PDF) thuộc Zovo Pro, trả USD 19 một lần cho mọi tiện ích Zovo, và mỗi công cụ có 3 lần dùng thử miễn phí.

Có dùng được trong Cursor không?

Có. PDF Reader có trên Open VSX, nên bạn cài được trong Cursor (cũng như Windsurf và VSCodium) từ khung Extensions, giống như trong VS Code.

Làm sao để PDF luôn hiện trang tối, kể cả khi VS Code dùng giao diện sáng?

Đặt setting pdfViewer.darkMode thành on. Giá trị mặc định auto cho trang đi theo giao diện của VS Code, còn off luôn hiện trang như bản in.

Highlight có làm thay đổi file PDF không?

Không. Highlight được lưu trong VS Code cho từng file và hiện lại khi bạn mở PDF lần sau; file PDF gốc không bị sửa.

Mọi tính năng và cài đặt có trên trang PDF Reader (tiếng Anh).
