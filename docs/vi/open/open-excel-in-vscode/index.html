Mở Excel và CSV trong VS Code và chạy SQL trên dữ liệu

Cài Table Viewer rồi nhấp vào file .xlsx, .xls, .ods hoặc .parquet để mở thành bảng; với file .csv hoặc .tsv, bấm biểu tượng bảng ở góc trên bên phải editor hoặc chọn “Open in Table Viewer”. Sắp xếp, lọc, thống kê cột, xuất file và truy vấn SQL trên các dòng đang có trong bảng đều miễn phí. Zovo Pro (USD 19 một lần) bổ sung truy vấn toàn bộ file CSV nhiều GB, JOIN với file khác, lưu thành Parquet, gộp và tách file, mỗi công cụ có 3 lần dùng thử miễn phí.

Cài vào VS CodeTrang MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

Miễn phí, giấy phép MIT. Extension ID zovo.table-viewer-vscode.

Các bước trong VS Code

  1. Cài Table Viewer từ Marketplace, hoặc nhấn Ctrl+P (Cmd+P trên macOS) rồi chạy ext install zovo.table-viewer-vscode.
  2. Nhấp vào file .xlsx, .xls, .ods hoặc .parquet để mở thành bảng. File .csv và .tsv vẫn mở trong trình soạn thảo văn bản; bấm biểu tượng bảng ở góc trên bên phải, hoặc nhấp chuột phải vào file và chọn “Open in Table Viewer”.
  3. Bấm vào tiêu đề cột để sắp xếp. Gõ vào ô dưới tiêu đề để lọc cột đó, ví dụ >10 hoặc 5..9 với cột số; ô tìm kiếm ở trên cùng tìm trong mọi cột.
  4. Bấm “Query” trên thanh công cụ, viết một câu SELECT với FROM this (file đang mở), rồi nhấn Ctrl+Enter (Cmd+Enter trên Mac). WHERE, GROUP BY, HAVING, ORDER BY, CASE và khoảng 70 hàm xử lý chữ, số và ngày tháng đều dùng được.
  5. Với workbook có nhiều sheet, bạn JOIN sheet khác theo tên, ví dụ JOIN "Customer List" c ON .... Trong lúc truy vấn chạy, bảng hiện tiến độ và nút Cancel.
  6. Kết quả mở trong cùng lưới bảng, nơi bạn sắp xếp, lọc và lưu thành CSV, TSV, JSON hoặc JSON Lines. Bấm “Back to file” để quay lại dữ liệu gốc.

Trong Cursor, Windsurf và VSCodium

Các trình soạn thảo này cài tiện ích từ Open VSX. Mở khung Extensions (Ctrl+Shift+X), tìm zovo.table-viewer-vscode rồi bấm Install. Trang trên Open VSX là zovo/table-viewer-vscode. Sau đó dùng giống như trong VS Code.

Những gì miễn phí

Bảng tới 1.000.000 dòng, sắp xếp, lọc, ô tìm kiếm, bộ lọc SQL WHERE, thống kê cột, Copy CSV, Copy JSON, Copy Markdown và xuất thành CSV, TSV, JSON hoặc JSON Lines đều miễn phí. Truy vấn SQL trên các dòng đang có trong bảng, JOIN giữa các sheet của cùng một workbook, so sánh với Git HEAD và tự tải lại khi file thay đổi cũng miễn phí. Tiện ích không cần Python hay cơ sở dữ liệu, chạy offline và không có telemetry.

Zovo Pro thêm gì

“Combine Files and Sheets” gộp nhiều file CSV, TSV, Excel, ODS và Parquet, cả một thư mục, hoặc mọi sheet của một workbook thành một file CSV, XLSX hoặc Parquet duy nhất. Cột được ghép theo tên tiêu đề, và hai cột source_file, source_sheet cho biết mỗi dòng đến từ đâu, nên bạn không phải chép tay từng file vào một bảng. Các công cụ Pro khác là truy vấn toàn bộ file lớn (GROUP BY trên CSV nhiều GB), JOIN với file CSV, Excel hoặc Parquet khác trong workspace, lưu kết quả thành Parquet và Split Table by Column Value. Zovo Pro cũng nâng giới hạn mặc định lên 5.000.000 dòng, CSV 2 GB và Excel 200 MB.

Cách dùng Combine Files and Sheets

  1. Nhấp chuột phải vào một thư mục, vài file bảng đã chọn hoặc một workbook trong Explorer và chọn “Zovo Pro: Combine Files and Sheets”, hoặc chạy “Excel Viewer Pro: Combine Files and Sheets (Pro)...” từ Command Palette.
  2. Chọn định dạng đầu ra (CSV, XLSX hoặc Parquet) và nơi lưu file. File nào không đọc được sẽ bị bỏ qua và được liệt kê trong bản tóm tắt.

Combine Files and Sheets chạy miễn phí 3 lần trước khi yêu cầu giấy phép. Không có cửa sổ bật lên khi mở tệp và không có đếm ngược.

Những gì không làm được

  • Table Viewer chỉ để xem. Nó không sửa ô và không lưu lại file gốc; Export và Save result chỉ ghi ra file mới mà bạn chọn.
  • Bản miễn phí hiện tối đa 1.000.000 dòng và đọc 512 MB đầu tiên của file CSV hoặc TSV. File .xls, .xlsb và .ods lớn hơn 50 MB hiện thông báo thay vì mở.
  • Mỗi lần chỉ chạy một câu SELECT; không hỗ trợ RIGHT JOIN, FULL JOIN, WITH hay truy vấn con bên trong biểu thức.
  • File .json, .jsonl, .numbers và .arrow không được hỗ trợ.

Câu hỏi

Table Viewer có miễn phí không?

Có. Xem bảng, sắp xếp, lọc, thống kê cột, xuất file và SQL trên các dòng đang có trong bảng đều miễn phí. Truy vấn toàn bộ file lớn, JOIN với file khác, lưu thành Parquet, gộp file và tách bảng thuộc Zovo Pro, trả USD 19 một lần cho mọi tiện ích Zovo, và mỗi công cụ có 3 lần dùng thử miễn phí.

Có dùng được trong Cursor không?

Có. Table Viewer có trên Open VSX, nên bạn cài được trong Cursor (cũng như Windsurf và VSCodium) từ khung Extensions, giống như trong VS Code.

Tại sao file CSV vẫn mở dưới dạng văn bản?

Table Viewer không thay trình soạn thảo văn bản cho file CSV và TSV, nên chúng vẫn mở dạng văn bản khi bạn nhấp vào. Bấm biểu tượng bảng ở góc trên bên phải editor, hoặc nhấp chuột phải vào file và chọn “Open in Table Viewer”.

Có chạy SQL trên file CSV vài GB được không?

Được, với Zovo Pro. Khi file vượt quá giới hạn của bảng, truy vấn đọc toàn bộ file theo kiểu stream, nên GROUP BY trên CSV nhiều GB vẫn chạy mà không làm treo VS Code. Truy vấn trên các dòng đã có trong bảng thì miễn phí.

Mọi tính năng và cài đặt có trên trang Table Viewer (tiếng Anh).
