Các bước trong VS Code

  1. Cài Run C++ and C Code từ Marketplace, hoặc nhấn Ctrl+P (Cmd+P trên macOS) rồi chạy ext install zovo.zovo-run-cpp.
  2. Kiểm tra rằng máy đã có trình biên dịch. "Run C++: Pick Compiler (gcc, g++, clang, clang++)" liệt kê những gì tiện ích tìm thấy. Nếu không có, một trang cài đặt hiện các bước chính thức cho hệ điều hành của bạn (Xcode Command Line Tools, MSYS2 hoặc WinLibs, hoặc trình quản lý gói của Linux).
  3. Mở tệp .cpp, .cc, .cxx hoặc .c rồi bấm nút Run trên thanh tiêu đề editor, hoặc nhấn Ctrl+Alt+Enter (Cmd+Alt+Enter trên Mac).
  4. Chương trình chạy trong một terminal tên "Run: file.cpp". Gõ dữ liệu đầu vào ở đó. Khi kết thúc, bạn thấy mã thoát (exit code), thời gian chạy và bộ nhớ đỉnh. Trong lúc chạy, nút Run chuyển thành Stop.
  5. Để thêm cờ biên dịch hoặc tham số, đặt // run: -O2 -lm và // args: "Hello World" 3 trong 40 dòng đầu của tệp. Cờ mặc định cho C++ là -std=c++20 -Wall -Wextra -g -O0.
  6. Để test với dữ liệu đầu vào đã lưu, chạy "Run C++: Run with Input & Test Cases". Dán dữ liệu vào, nhấn Run with input, rồi Save as test case. Run all tests hiện đạt hay không đạt (pass/fail) kèm diff từng dòng.

Những gì miễn phí và Zovo Pro thêm gì

Run, Build Only, Run Last Build, Debug, build cả thư mục, bảng Input & Tests, stress test và benchmark đều miễn phí. Không cần đăng nhập, không gọi mạng và không có telemetry.

Một chương trình qua hết test vẫn có thể đọc quá cuối mảng hoặc làm tràn số int. Sanitizer check build thêm một bản với AddressSanitizer và UndefinedBehaviorSanitizer (-fsanitize=address,undefined), chạy bản đó với dữ liệu trong bảng và mọi test case đã lưu, rồi đưa từng lỗi tràn heap hoặc stack, use after free, tràn số có dấu hay hành vi không xác định khác vào bảng Problems ở đúng dòng. Bạn tìm ra lỗi tại dòng của nó mà không phải tự thiết lập cờ sanitizer.

Cách dùng Sanitizer check (Zovo Pro)

  1. Nhập dữ liệu vào bảng Input & Tests, và lưu test case nếu có. Công cụ chạy với dữ liệu trong bảng và với mọi test case đã lưu.
  2. Bấm "Sanitizer check (Pro)" trong bảng, ở mục "Stress test, benchmark and more", hoặc chạy "Run C++: Sanitizer Check: AddressSanitizer and UBSan on the Input and Test Cases (Zovo Pro)" từ Command Palette.
  3. Bấm vào một kết quả trong bảng Problems để nhảy tới dòng của nó. Lỗi build, Stop hoặc Cancel không tốn lượt dùng thử nào.

Sanitizer check chạy được 3 lần miễn phí trên máy của bạn trước khi yêu cầu giấy phép. Không có cửa sổ bật lên và không có đếm ngược.

Các bước trong Cursor, Windsurf hoặc VSCodium

  1. Mở khung Extensions bằng Ctrl+Shift+X (Cmd+Shift+X trên macOS).
  2. Tìm zovo.zovo-run-cpp rồi bấm Install. Cursor, Windsurf và VSCodium cài tiện ích từ Open VSX, nơi tiện ích này có tên zovo/zovo-run-cpp.
  3. Nếu trình soạn thảo của bạn không có kho tiện ích, hãy tải tệp .vsix từ trang Open VSX rồi chạy "Extensions: Install from VSIX...".
  4. Sau đó mọi thứ hoạt động giống như trong VS Code.

Run C++ and C Code làm được gì

  • Tệp C và C++ (.c, .cpp, .cc, .cxx) với gcc, g++, clang và clang++.
  • MSYS2, WinLibs, MinGW, TDM-GCC và LLVM trong các thư mục thường gặp trên Windows, và tên kiểu Homebrew như g++-14.
  • Đường dẫn có dấu cách, & hoặc chữ không phải ASCII, vì không có shell nào phân tích chúng.
  • Chương trình in ra một triệu dòng. Bảng hiện 2.000 dòng đầu và đếm phần còn lại.

Những gì không làm được

  • Tiện ích cần trình biên dịch trên máy và không bao giờ tự tải về.
  • Các lần chạy trong bảng Input và test case dừng sau 10 giây (cài đặt zovoRun.timeLimitSeconds).
  • Output vượt 32 MB chỉ được đếm, không được giữ lại (cài đặt zovoRun.maxCapturedOutputMB).
  • Sanitizer check cần trình biên dịch có sanitizer runtime. MinGW gcc trên Windows không có, nên ở đó hãy dùng clang của LLVM. Công cụ báo điều này mà không tốn lượt dùng thử.
  • Debug cần cài CodeLLDB hoặc tiện ích C/C++.

Câu hỏi thường gặp

Có miễn phí không?

Run, Build Only, Debug, build cả thư mục, bảng Input & Tests, stress test và benchmark đều miễn phí. Ba công cụ Pro, Sanitizer check, Compare -O0, -O2 and -O3 và Test report, mỗi công cụ có 3 lượt dùng thử miễn phí. Sau đó cần Zovo Pro, 19 USD một lần cho mọi tiện ích Zovo.

Chương trình có đọc dữ liệu bằng cin được không?

Được. Chương trình chạy trong terminal thật, nên cin và scanf chờ những gì bạn gõ, và lời nhắc không có ký tự xuống dòng vẫn hiện trước.

Tiện ích có sửa settings.json hay tasks.json không?

Không. Nó không bao giờ ghi vào các tệp cài đặt của bạn. Debug thêm một mục vào .vscode/launch.json, và chỉ khi bạn nhấn Debug.

Có dùng được trong Cursor không?

Có. Tiện ích có trên Open VSX, nên Cursor, Windsurf và VSCodium cài được.
