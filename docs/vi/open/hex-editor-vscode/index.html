Hex editor cho file nhị phân trong VS Code

Cài Hex Viewer rồi nhấp chuột phải vào bất kỳ file nào và chọn “Open in Hex Viewer”; file .bin, .dat, .img, .rom, .dmp và .dump mở thẳng ở dạng hex khi bạn nhấp vào. Xem, tìm kiếm, nhảy tới offset, data inspector, sửa, chèn, xóa byte và so sánh hai file đều miễn phí, với file cục bộ ở bất kỳ kích thước nào. Zovo Pro (USD 19 một lần) bổ sung các công cụ như checksum, bản đồ entropy và trích xuất chuỗi, mỗi công cụ có 3 lần dùng thử miễn phí.

Cài vào VS CodeTrang MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

Miễn phí, giấy phép MIT. Extension ID zovo.zovo-hex-viewer.

Các bước trong VS Code

  1. Cài Hex Viewer từ Marketplace, hoặc nhấn Ctrl+P (Cmd+P trên macOS) rồi chạy ext install zovo.zovo-hex-viewer.
  2. Nhấp chuột phải vào một file trong Explorer và chọn “Open in Hex Viewer”. File .bin, .dat, .img, .rom, .dmp và .dump mở thẳng trong Hex Viewer khi bạn nhấp vào.
  3. Nhấn Ctrl+G (Cmd+G trên macOS) để nhảy tới một offset theo hệ hex hoặc thập phân, hoặc nhảy tương đối như +0x100 hay -16. Nhấn Ctrl+F để tìm chuỗi byte hex có ký tự đại diện ??, văn bản thường hoặc văn bản UTF-16.
  4. Gõ hai chữ số hex để ghi đè một byte, hoặc nhấn Insert để chuyển sang chế độ chèn. Xóa, cắt và dán hoạt động trên vùng chọn; Ctrl+Z để hoàn tác và Ctrl+S để lưu.
  5. Chọn vài byte để data inspector đọc chúng thành số nguyên, số thực, thời gian Unix hoặc GUID, với nút đổi thứ tự byte. Nút “Copy as...” sao chép vùng chọn dưới dạng hex, mảng C, Python bytes hoặc base64.
  6. Chọn hai file trong Explorer, nhấp chuột phải và chọn “Compare in Hex Viewer”. Nhấn F7 để tới chỗ khác nhau tiếp theo và Shift+F7 để quay lại.

Trong Cursor, Windsurf và VSCodium

Các trình soạn thảo này cài tiện ích từ Open VSX. Mở khung Extensions (Ctrl+Shift+X), tìm zovo.zovo-hex-viewer rồi bấm Install. Trang trên Open VSX là zovo/zovo-hex-viewer. Sau đó dùng giống như trong VS Code.

Những gì miễn phí

Mọi tính năng ở trên đều miễn phí: xem file cục bộ ở bất kỳ kích thước nào, nhảy tới offset, tìm kiếm, Copy as, data inspector, sửa, chèn và xóa byte, lưu an toàn, hoàn tác và so sánh hai file. Cấp đầu tiên của Structure view với 26 template có sẵn cũng miễn phí. Hex Viewer chỉ đọc những dòng đang hiện trên màn hình, nên file 4 GB vẫn mở nhanh. Tiện ích chạy offline, không cần đăng nhập và không có telemetry.

Zovo Pro thêm gì

“Checksums of Selection or File” tính CRC-32, Adler-32, MD5, SHA-1, SHA-256 và SHA-512 của vùng chọn hoặc của cả file chỉ trong một lần đọc, nên file 4 GB vẫn chạy được. Bạn chọn một giá trị để sao chép, không cần mở terminal hay dùng công cụ khác để kiểm tra một bản firmware hay một đoạn dữ liệu. Các công cụ Pro khác là các trường lồng nhau trong Structure view, bookmark có ghi chú, xuất báo cáo so sánh, Find Bytes in Files, Entropy and Byte Histogram và Extract Strings.

Cách dùng Checksums of Selection or File

  1. Mở file trong Hex Viewer. Nếu chỉ cần checksum của một đoạn, hãy chọn các byte đó.
  2. Bấm nút “Checksums...” bên dưới data inspector, hoặc chạy “Hex Viewer Pro: Checksums of Selection or File” từ Command Palette. Với file chưa mở, nhấp chuột phải vào file trong Explorer và chọn “Zovo Pro: Checksums of File”.
  3. Chọn giá trị cần sao chép. Lượt dùng thử được tính khi các giá trị hiện ra.

Checksums of Selection or File chạy miễn phí 3 lần trước khi yêu cầu giấy phép. Không có cửa sổ bật lên khi mở tệp và không có đếm ngược.

Những gì không làm được

  • File trên remote hoặc hệ thống file ảo chỉ mở được tới 256 MB theo mặc định (setting hexViewer.maxRemoteMB); file cục bộ không giới hạn kích thước.
  • “Copy as...” sao chép tối đa 32 MB, còn dán tối đa 16 MB.
  • Chỉ 6 đuôi file mở mặc định trong Hex Viewer. File Intel .hex và các file văn bản như .txt vẫn mở trong trình soạn thảo văn bản.
  • So sánh đọc hai file như đã lưu trên đĩa.

Câu hỏi

Hex Viewer có miễn phí không?

Có. Xem, tìm kiếm, sửa, chèn và xóa byte, data inspector và so sánh hai file đều miễn phí và sẽ tiếp tục miễn phí. Bảy công cụ Pro, như checksum và trích xuất chuỗi, thuộc Zovo Pro (USD 19 một lần cho mọi tiện ích Zovo), và mỗi công cụ có 3 lần dùng thử miễn phí.

Có dùng được trong Cursor không?

Có. Hex Viewer có trên Open VSX, nên bạn cài được trong Cursor (cũng như Windsurf và VSCodium) từ khung Extensions, giống như trong VS Code.

Hex Viewer có mở được file rất lớn không?

Có. Với file cục bộ, Hex Viewer chỉ đọc những dòng đang hiện theo từng khối 64 KB, nên file 4 GB mở được ngay. Chèn hoặc xóa byte trong file lớn cũng không phải chờ, vì thay đổi chỉ được ghi vào file khi bạn lưu.

Làm sao để chỉ xem mà không sợ sửa nhầm?

Đặt setting hexViewer.readOnly thành true để tắt chỉnh sửa. File chỉ đọc trên đĩa cũng chỉ được mở để xem.

Mọi tính năng và cài đặt có trên trang Hex Viewer (tiếng Anh).
