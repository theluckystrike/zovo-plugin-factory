Định dạng XML trong VS Code và chạy XPath trên tệp

Cài tiện ích miễn phí XML Formatter & XPath Tools, mở một tệp XML và nhấn Shift+Alt+F (Shift+Option+F trên Mac). Chỉ khoảng trắng giữa các thẻ thay đổi: văn bản, CDATA, chú thích, xml:space="preserve" và giá trị thuộc tính giữ nguyên từng byte, và một tệp không đúng cú pháp (not well formed) không bao giờ bị sửa. Định dạng, Minify XML, XPath 1.0 với các tiền tố namespace của chính tệp, Copy XPath và view XML Tree đều miễn phí và chạy offline. Zovo Pro (19 USD, trả một lần) thêm ba công cụ Run XPath on Every XML File in a Folder, Format All XML Files in a Folder và Compare Two XML Files Ignoring Formatting, mỗi công cụ có 3 lượt dùng thử miễn phí.

Các bước trong VS Code

  1. Cài XML Formatter & XPath Tools từ Marketplace, hoặc nhấn Ctrl+P (Cmd+P trên macOS) rồi chạy ext install zovo.zovo-xml-xpath-tools.
  2. Mở một tệp .xml và nhấn Shift+Alt+F (Shift+Option+F trên Mac), hoặc chạy Format Document. Nếu bạn có nhiều hơn một bộ định dạng XML, VS Code sẽ hỏi dùng bộ nào. Format Selection cũng dùng được.
  3. Bộ định dạng dùng kích thước tab và kiểu tab hay dấu cách của bạn, đồng thời giữ kiểu xuống dòng, byte order mark và dòng trống cuối tệp. Nếu tệp không đúng cú pháp, không có gì thay đổi và bạn nhận được lỗi kèm dòng và cột.
  4. Để thu gọn tệp, chạy "XML: Minify XML" trên cả tệp hoặc trên vùng chọn. Chú thích được giữ lại, trừ khi bạn bật xmlXpathTools.minify.removeComments.
  5. Để chạy XPath, bấm nút tìm kiếm trên thanh tiêu đề trình soạn thảo hoặc chạy "XML: Evaluate XPath…". Kết quả được liệt kê trong XPath Results kèm số dòng. Bấm vào một kết quả để chọn nó trong trình soạn thảo.
  6. Bấm vào XPath trên thanh trạng thái để sao chép đường dẫn của phần tử dưới con trỏ: kèm vị trí, kèm thuộc tính id hoặc name, hoặc ở dạng local-name() dùng được ở mọi nơi.
  7. Với tệp trên 50 MB, nhấp chuột phải vào tệp trong Explorer và chọn "Format Large XML File on Disk…". Lệnh này ghi name.formatted.xml bên cạnh, hoặc thay thế tệp sau khi bạn xác nhận.

Những gì miễn phí và Zovo Pro thêm gì

Format Document, Format Selection, Minify XML, XPath 1.0, Copy XPath, view XML Tree, lỗi cú pháp trong Problems và Format Large XML File on Disk đều miễn phí. Không cần đăng nhập, và tiện ích không có mã gọi mạng.

Run XPath on Every XML File in a Folder chạy một biểu thức XPath trên mọi tệp .xml, .xsd, .csproj, .svg, .kml và các tệp tương tự trong một thư mục, mỗi tệp với các tiền tố namespace của riêng nó. Kết quả mở ra dưới dạng CSV (file, line, kind, name, value) cho bảng tính, JSON cho script, hoặc báo cáo Markdown để xem lại. Bạn lấy cùng một giá trị từ nhiều tệp, ví dụ mọi artifactId trong một loạt tệp pom.xml, mà không phải mở từng tệp.

Cách dùng Run XPath on Every XML File in a Folder (Zovo Pro)

  1. Nhấp chuột phải vào một thư mục trong Explorer và chọn "Zovo Pro: Run XPath on Every XML File in a Folder", hoặc chạy "XML: Run XPath on Every XML File in a Folder (Pro)" từ Command Palette rồi chọn thư mục.
  2. Hoặc, sau khi chạy XPath trong một tệp, bấm dòng cuối của XPath Results, "Run this XPath on every XML file in a folder", để chạy cùng biểu thức đó trên một thư mục.
  3. Nhập XPath. Một thông báo hiện tiến trình kèm nút Cancel.
  4. Chọn "Open as CSV", "Open as JSON" hoặc "Open a Markdown report". Kết quả mở trong một tab mới. Chỉ tính một lượt dùng thử khi bạn nhận được kết quả: nhấn Escape, gõ sai XPath hoặc chọn thư mục không có tệp XML thì không tốn lượt nào.

Run XPath on Every XML File in a Folder chạy được 3 lần miễn phí trên máy của bạn trước khi yêu cầu giấy phép. Không có cửa sổ bật lên và không có đếm ngược.

Các bước trong Cursor, Windsurf hoặc VSCodium

  1. Mở khung Extensions bằng Ctrl+Shift+X (Cmd+Shift+X trên macOS).
  2. Tìm zovo.zovo-xml-xpath-tools rồi bấm Install. Cursor, Windsurf và VSCodium cài tiện ích từ Open VSX, nơi tiện ích này có tên zovo/zovo-xml-xpath-tools.
  3. Nếu trình soạn thảo của bạn không có kho tiện ích, hãy tải tệp .vsix từ trang Open VSX rồi chạy "Extensions: Install from VSIX...".
  4. Sau đó mọi thứ hoạt động giống như trong VS Code.

XML Formatter & XPath Tools làm được gì

  • Các tệp VS Code mở dưới dạng XML. Tiện ích còn mở các tệp .kml, .gpx, .rss, .atom, .wsdl, .dbk, .xlf, .xliff, .resx, .nuspec, .props, .targets và .xaml dưới dạng XML.
  • Tệp lớn: định dạng, cây và XPath chạy trong một luồng nền. Trong bộ kiểm thử của tiện ích, một tệp 49 MB với khoảng 1 triệu phần tử được định dạng trong 1,6 giây.
  • Tên không có tiền tố cũng khớp với namespace mặc định, nên //dependency/artifactId chạy được trong pom.xml. Bật xmlXpathTools.xpath.strictNamespaces để dùng XPath 1.0 nghiêm ngặt.
  • Cách xếp thuộc tính: giữ như đã viết, trên một dòng, hoặc mỗi thuộc tính một dòng (cài đặt xmlXpathTools.format.attributes).
  • View XML Tree trong Explorer đi theo con trỏ, và Problems liệt kê lỗi cú pháp kèm dòng và cột.

Những gì không làm được

  • Chỉ có XPath 1.0. Không có XPath 2.0 hay 3.1, XQuery hoặc XSLT.
  • Tiện ích kiểm tra tệp có đúng cú pháp XML hay không. Nó không kiểm tra theo XSD hay DTD.
  • Tệp trên 50 MB định dạng được trên đĩa, nhưng VS Code không chuyển các tệp này cho tiện ích, nên cây và XPath không chạy trên chúng.
  • Lệnh định dạng trên đĩa đọc UTF-8, UTF-16 có byte order mark và ISO-8859-1.
  • Phần tử có chứa văn bản, như <p>Some <b>bold</b> text</p>, giữ nguyên trên dòng như đã viết. Chỉ phần tử chứa thẻ mà không chứa văn bản mới được xuống dòng.

Câu hỏi thường gặp

Có miễn phí không?

Định dạng, Minify XML, XPath, Copy XPath, view XML Tree và kiểm tra cú pháp đều miễn phí. Ba công cụ Pro, Run XPath on Every XML File in a Folder, Format All XML Files in a Folder và Compare Two XML Files Ignoring Formatting, mỗi công cụ có 3 lượt dùng thử miễn phí. Sau đó cần Zovo Pro, 19 USD trả một lần cho mọi tiện ích Zovo.

Định dạng có làm đổi văn bản hay CDATA của tôi không?

Không. Chỉ khoảng trắng giữa các thẻ thay đổi, trong những phần tử chứa thẻ mà không chứa văn bản. Văn bản, CDATA, chú thích và nội dung bên trong xml:space="preserve" được giữ nguyên, và định dạng lần thứ hai không thay đổi gì.

Vì sao XPath của tôi không chọn được gì trong pom.xml?

Tệp có namespace mặc định. Trong tiện ích này, tên không có tiền tố cũng khớp với namespace mặc định, nên //dependency chạy được. Bật xmlXpathTools.xpath.strictNamespaces để dùng XPath 1.0 nghiêm ngặt.

Có dùng được trong Cursor không?

Có. Cursor, Windsurf và VSCodium cài tiện ích từ Open VSX, nơi nó được phát hành với tên zovo/zovo-xml-xpath-tools.
