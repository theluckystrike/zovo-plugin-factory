Định dạng script bash hoặc zsh trong VS Code

Cài tiện ích miễn phí Shell Formatter for Bash & Zsh, mở một shell script và nhấn Shift+Alt+F (Shift+Option+F trên Mac). Engine shfmt 3.14.1 có sẵn bên trong tiện ích dưới dạng WebAssembly, nên không phải tải gì về, và kết quả giống hệt dòng lệnh shfmt đến từng byte. Format Document, Format Selection, định dạng khi lưu, các khóa .editorconfig và lỗi cú pháp trong Problems đều miễn phí và chạy offline. Zovo Pro (19 USD, trả một lần) thêm ba công cụ Format All Shell Scripts in a Folder, Formatting Check with a Patch File và Minify a Script to a Copy, mỗi công cụ có 3 lượt dùng thử miễn phí.

Các bước trong VS Code

  1. Cài Shell Formatter for Bash & Zsh từ Marketplace, hoặc nhấn Ctrl+P (Cmd+P trên macOS) rồi chạy ext install zovo.zovo-shell-formatter.
  2. Mở một shell script và nhấn Shift+Alt+F (Shift+Option+F trên Mac). Nếu VS Code hỏi dùng bộ định dạng nào, chọn Shell Formatter, hoặc chạy "Shell Formatter: Use as Default Formatter for Shell Scripts".
  3. Để định dạng mỗi lần lưu, chạy "Shell Formatter: Turn On Format on Save for Shell Scripts".
  4. Dialect được lấy từ dòng đầu tiên (#!/bin/bash, #!/bin/sh, #!/usr/bin/env zsh), sau đó từ tên tệp (.bash, .zsh, .zshrc, .bats, .ksh), nếu không thì là bash. Đặt shellFormatter.dialect hoặc shell_variant trong .editorconfig để tự chọn.
  5. Bấm shfmt 3.14.1 trên thanh trạng thái để mở menu: định dạng, đặt làm mặc định, định dạng khi lưu, "Copy the matching shfmt command (for CI)" và cài đặt.
  6. Nếu script không phải shell hợp lệ, tệp giữ nguyên và panel Problems hiện dòng và cột của lỗi.

Những gì miễn phí và Zovo Pro thêm gì

Format Document, Format Selection, định dạng khi lưu, nhận diện dialect, các khóa .editorconfig, menu trên thanh trạng thái, Copy the Matching shfmt Command (for CI) và lỗi cú pháp trong Problems đều miễn phí. Không cần đăng nhập, không có yêu cầu mạng và không có telemetry.

Format All Shell Scripts in a Folder kiểm tra mọi script trong một thư mục và các thư mục con, tìm theo tên tệp hoặc theo dòng #! có ghi tên một shell, và cho biết bao nhiêu script sẽ thay đổi. Sau đó công cụ định dạng tất cả hoặc đưa ra một báo cáo Markdown, với cùng engine, cài đặt và .editorconfig như Format Document. Một repository có hàng chục script viết theo nhiều kiểu khác nhau sẽ có cùng một kiểu sau một lần chạy, còn script nào sau khi định dạng không chạy cùng các lệnh thì được giữ nguyên.

Cách dùng Format All Shell Scripts in a Folder (Zovo Pro)

  1. Nhấp chuột phải vào một thư mục trong Explorer và chọn "Zovo Pro: Format All Shell Scripts in a Folder", hoặc chạy "Shell Formatter: Format All Shell Scripts in a Folder (Pro)" từ Command Palette hay từ menu trên thanh trạng thái rồi chọn thư mục.
  2. Tiêu đề của danh sách tiếp theo cho biết bao nhiêu script sẽ thay đổi, ví dụ "N of M scripts would change".
  3. Chọn "Format N scripts" để định dạng và lưu từng tệp (Undo hoạt động theo từng tệp), hoặc "Show the report only" để có danh sách Markdown của mọi script mà không thay đổi gì.
  4. Chỉ tính một lượt dùng thử khi bạn nhận được kết quả. Thư mục không có shell script nào, hoặc mọi script đã được định dạng, thì không tốn lượt.

Format All Shell Scripts in a Folder chạy được 3 lần miễn phí trên máy của bạn trước khi yêu cầu giấy phép. Không có cửa sổ bật lên và không có đếm ngược.

Các bước trong Cursor, Windsurf hoặc VSCodium

  1. Mở khung Extensions bằng Ctrl+Shift+X (Cmd+Shift+X trên macOS).
  2. Tìm zovo.zovo-shell-formatter rồi bấm Install. Cursor, Windsurf và VSCodium cài tiện ích từ Open VSX, nơi tiện ích này có tên zovo/zovo-shell-formatter.
  3. Nếu trình soạn thảo của bạn không có kho tiện ích, hãy tải tệp .vsix từ trang Open VSX rồi chạy "Extensions: Install from VSIX...".
  4. Sau đó mọi thứ hoạt động giống như trong VS Code.

Shell Formatter for Bash & Zsh làm được gì

  • Script bash, POSIX sh (cả dash và ash), mksh (cả ksh), bats và zsh.
  • Kết quả giống shfmt 3.14.1 trên dòng lệnh: 354 trên 354 lần chạy với 178 script thật từ các dự án GitHub và Homebrew khớp đến từng byte.
  • Trước khi áp dụng thay đổi, script đã định dạng được phân tích lại và phải chạy cùng các lệnh như bản gốc (tệp tới 256 KB).
  • Các tùy chọn shfmt dưới dạng cài đặt hoặc khóa .editorconfig: thụt lề, toán tử nhị phân ở dòng sau, thụt lề case trong switch, dấu cách quanh chuyển hướng, giữ khoảng đệm, dấu ngoặc nhọn của hàm ở dòng sau, simplify và minify.
  • Kiểu xuống dòng Windows (CRLF) vẫn là CRLF, và một script 2 MB được định dạng trong khoảng 0,2 giây.

Những gì không làm được

  • Tiện ích không bao giờ đụng tới Dockerfile, tệp .env, script fish hay csh.
  • Hỗ trợ zsh trong shfmt còn mới. Script zsh mà shfmt không phân tích được sẽ được giữ nguyên.
  • Tệp trên 10 MB (cài đặt shellFormatter.maxFileMB) và tệp chứa byte nhị phân, như trình cài đặt tự giải nén, không được định dạng.
  • shfmt chạy với giới hạn thời gian (mặc định 10 giây, cài đặt shellFormatter.timeoutSeconds). Nếu hết giờ, tệp giữ nguyên.

Tôi có cần cài shfmt không?

Không. shfmt 3.14.1 có sẵn bên trong tiện ích dưới dạng WebAssembly, nên chạy offline mà không phải tải gì về.

Tiện ích có làm hỏng script của tôi không?

Script có lỗi cú pháp được giữ nguyên. Trước khi áp dụng thay đổi, script đã định dạng được phân tích lại và phải chạy cùng các lệnh như bản gốc.

Có dùng được trong Cursor không?
