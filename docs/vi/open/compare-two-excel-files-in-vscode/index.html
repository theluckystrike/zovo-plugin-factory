So sánh hai file Excel hoặc CSV trong VS Code

Cài extension miễn phí Excel Compare & XLSX Diff rồi chọn hai workbook hoặc hai file CSV. Ô thay đổi hiện màu vàng và giá trị cũ bị gạch ngang, dòng được thêm có màu xanh lá, dòng bị xóa có màu đỏ. Các dòng được căn khớp với nhau và cột được khớp theo tiêu đề, nên một dòng hoặc một cột chèn thêm chỉ hiện là một thay đổi. Bạn cũng có thể so sánh một workbook với phiên bản Git HEAD của nó trước khi commit. Tất cả đều miễn phí và không gửi request mạng nào. Zovo Pro (19 USD một lần) thêm ba công cụ Export a diff report, Match rows by key columns và Compare two folders of workbooks, mỗi công cụ có 3 lần dùng thử miễn phí.

Các bước trong VS Code

  1. Cài Excel Compare & XLSX Diff từ Marketplace, hoặc nhấn Ctrl+P (Cmd+P trên macOS) rồi chạy ext install zovo.zovo-excel-compare.
  2. Chọn hai file trong Explorer, nhấp chuột phải và chọn Compare Selected Excel Files. Hoặc nhấp chuột phải vào một file, chọn Compare with... rồi chọn file còn lại. Trong Command Palette, bạn cũng có thể chạy "Excel Compare: Compare Two Excel or CSV Files...".
  3. Có thể kết hợp tùy ý .xlsx, .xlsm, .xls, .ods, .csv và .tsv, nên bạn so sánh được một file .xlsx với một file .csv.
  4. Đọc dòng tóm tắt, rồi xem tab của từng sheet cùng số khác biệt của sheet đó. Nhấp vào một ô để xem đầy đủ giá trị cũ và mới và sao chép chúng.
  5. Nhấn N và P (hoặc Next và Previous) để đi qua mọi thay đổi trên tất cả các sheet. Chuyển giữa Values và Formulas để so sánh giá trị ô đang hiển thị hoặc chính công thức.
  6. Để xem bạn đã sửa gì trước khi commit, nhấp chuột phải vào workbook trong một repository Git và chọn Compare with Git HEAD.

Những gì miễn phí và Zovo Pro thêm gì

So sánh hai file bất kỳ, lưới dữ liệu, Values và Formulas, chuyển đến thay đổi kế tiếp và trước đó, so sánh CSV có tự phát hiện encoding và dấu phân cách, và Compare with Git HEAD đều miễn phí. Không cần đăng nhập, không có request mạng và không có telemetry.

Khi cần cho người khác xem các thay đổi, Export a diff report ghi ra một workbook XLSX, trong đó các ô thay đổi, được thêm và bị xóa được tô màu, kèm một sheet Summary và danh sách Changes có mọi giá trị cũ và mới. Công cụ này cũng có thể ghi ra một trang HTML hoặc một danh sách thay đổi dạng CSV. Bạn chỉ cần gửi một file thay vì nhiều ảnh chụp màn hình.

Cách dùng Export a diff report (Zovo Pro)

  1. So sánh hai file như trên, rồi nhấp Export report trên thanh công cụ so sánh, hoặc chạy "Excel Compare: Export a diff report (XLSX, HTML or CSV) (Pro)" từ Command Palette.
  2. Chọn XLSX, HTML hoặc CSV.
  3. Chọn nơi lưu báo cáo. Một lượt dùng thử chỉ bị tính khi báo cáo đã được ghi.

Export a diff report chạy được 3 lần miễn phí trên máy của bạn trước khi yêu cầu giấy phép. Không có cửa sổ bật lên và không có đếm ngược.

Các bước trong Cursor, Windsurf hoặc VSCodium

  1. Mở khung Extensions bằng Ctrl+Shift+X (Cmd+Shift+X trên macOS).
  2. Tìm zovo.zovo-excel-compare rồi bấm Install. Cursor, Windsurf và VSCodium cài tiện ích từ Open VSX, nơi tiện ích này có tên zovo/zovo-excel-compare.
  3. Nếu trình soạn thảo của bạn không có kho tiện ích, hãy tải tệp .vsix từ trang Open VSX rồi chạy "Extensions: Install from VSIX...".
  4. Sau đó mọi thứ hoạt động giống như trong VS Code.

Excel Compare & XLSX Diff làm được gì

  • Sheet được khớp theo tên, rồi theo vị trí. Sheet chỉ có trong một file được liệt kê là được thêm hoặc bị xóa.
  • CSV và TSV với encoding được tự phát hiện (UTF-8 có hoặc không có BOM, UTF-16, Windows code page) và dấu phân cách được tự phát hiện (dấu phẩy, dấu chấm phẩy, tab hoặc dấu gạch đứng), kể cả trường trong dấu ngoặc kép có xuống dòng.
  • Sheet lớn. Lưới chỉ vẽ các dòng đang hiện trên màn hình, nên một sheet 300.000 dòng cuộn mượt như sheet ngắn.
  • Ghi chú khi merged cell khác nhau hoặc khi một giới hạn cắt bớt sheet.
  • Hai công cụ Pro còn lại. Match rows by key columns khớp dòng theo một cột ID, nên sheet đã sắp xếp hoặc đổi thứ tự vẫn so sánh gọn gàng và dòng bị dời chỗ được đánh dấu. Compare two folders of workbooks ghép file theo tên và cho biết file nào giống nhau, file nào khác nhau và file nào chỉ có ở một thư mục.

Những gì không làm được

  • File tối đa 200 MB (setting excelCompare.maxFileSizeMB), 300.000 dòng mỗi sheet (excelCompare.maxRows), 1.000 cột và 200 sheet. Khi một giới hạn được áp dụng, view sẽ có ghi chú.
  • Workbook phình ra hơn 600 MB khi giải nén, hoặc được nén kiểu zip bomb, bị từ chối trước khi giải nén.
  • Nếu không có công cụ Pro Match rows by key columns, dòng được căn khớp theo nội dung và vị trí, không theo cột ID.
  • Extension chỉ so sánh, không sửa hay gộp file.

Câu hỏi thường gặp

Có miễn phí không?

So sánh hai workbook hoặc file CSV, Values và Formulas, chuyển đến thay đổi kế tiếp và trước đó, và Compare with Git HEAD đều miễn phí. Mỗi công cụ Pro trong ba công cụ Export a diff report, Match rows by key columns và Compare two folders of workbooks có 3 lần dùng thử miễn phí. Sau đó cần Zovo Pro, 19 USD một lần cho tất cả extension Zovo.

VS Code có so sánh được hai file Excel mà không cần extension không?

Không. File .xlsx là một file zip chứa các phần XML, nên diff có sẵn hiển thị nó như file nhị phân. Bạn cần một extension đọc được workbook.

Chèn một dòng ở đầu có làm mọi dòng bên dưới bị đánh dấu là thay đổi không?

Không. Các dòng được căn khớp trước khi so sánh, nên dòng chèn thêm chỉ hiện là một dòng được thêm.

Tôi có xem được workbook đã thay đổi gì từ lần commit gần nhất không?

Có. Nhấp chuột phải vào file trong repository Git và chọn Compare with Git HEAD. Lệnh này chạy git cục bộ của bạn.
