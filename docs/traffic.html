Channels that bring the most targeted visitors

  • 1. Free channels bring few paying users. All 6 Apify actions together give about 7.4 paying users for 3 owner hours (ESTIMATE). At about $0.25 each in month 1, that is about $2 a month. They are worth doing for first users, reviews and bug reports, not for money.
  • 2. The best paying-user channel is one post in the Apify & Crawlee Discord (23,978 members, FETCHED). The next three are the r/webscraping monthly thread (105,406 subs), a dev.to TubeText tutorial and an r/PPC how-to for Ads Transparency. Drafts are in out/I6D-drafts/.
  • 3. MCP registries and awesome lists bring almost nothing. Of 24 Actors created in 2026 and listed in the MCP Registry or awesome-remote-mcp-servers, 20 have 4 or fewer users ever (FETCHED). Most big awesome lists have stopped merging (0 or 1 of the last 30 closed PRs merged).

  • 5. Context Drift is free, so its channels score 0 paying users. For installs, Show HN is best (about 57 installs for 2 h, ESTIMATE). Cursor channels wait for Open VSX, because the extension is not there yet (FETCHED 404).

Collector

  • 1. The new collector `factory/sprint/metrics/collect.py` covers 16 products across Apify, VS Code, Open VSX, GitHub and Atlassian. One run took 3 min 25 s, appended one line to `history.jsonl` and logged 0 errors. Every token check came back 0.
  • 2. The biggest finding is that the default Apify Store API search shows 0 of our 5 public Actors. They appear only when `includeUnrunnableActors=true` is set. The API spec says this filter hides Actors from developers without KYC. Ours are LIMITED_PERMISSIONS, so the missing owner verification is the likely cause (INFERENCE).
  • 3. No store gives us revenue through an API today. Apify earnings live only in the Console (Insights). VS Code and Open VSX have no payments. Atlassian V3 reporting answers 404 until a Marketplace listing exists.
  • 4. We can measure some traffic now. The VS Code search rank of Context Drift is 1 for "claude.md", 6 for "agents.md" and 4 for "context drift". With the filter off, Apify ranks are 245 to 1,022. GitHub repo views are 0 in 14 days.
  • 5. Page views need owner credentials. VS Code needs an Azure DevOps sign-in (PATs retire 2026-12-01). GitHub Pages has no traffic API.
