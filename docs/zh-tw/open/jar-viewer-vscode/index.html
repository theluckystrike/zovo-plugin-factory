在 VS Code 開啟 JAR，閱讀反編譯後的 Java 原始碼

安裝免費的 JAR Viewer & Java Decompiler，點選 .jar、.war、.ear、.aar 或 .class 檔案。它會顯示套件、資源、MANIFEST.MF 和每個類別的 Java 版本，提供不需要 Java 的 javap -c -p 風格位元組碼清單，並用內建的 CFR 0.152 搭配你電腦上 Java 8 以上的執行環境，把類別反編譯成 Java 原始碼。所有檢視和一次反編譯一個類別都免費。Zovo Pro（一次付清 19 美元）另外提供三項工具，包括匯出 JAR 的反編譯原始碼、比對兩個 JAR，以及在資料夾的每個 JAR 中搜尋，每項各有 3 次免費試用。

在 VS Code 中的步驟

  1. 從 Marketplace 安裝 JAR Viewer，或按 Ctrl+P（macOS 上按 Cmd+P）後執行 ext install zovo.zovo-jar-viewer。
  2. 在 Explorer 點選 .jar、.war、.ear、.aar 或 .class 檔案，它會在 JAR Viewer 中開啟。Overview 會顯示格式、項目數、類別數和套件數、Main-Class、Created by、MANIFEST.MF，以及各類別編譯目標 Java 版本的圖表。
  3. 在套件樹上方的篩選框輸入部分名稱，輸入時就會找出類別和檔案。內部類別會以淡色顯示在外部類別底下。
  4. 點選一個類別。Java source 分頁會顯示以 CFR 0.152 反編譯的原始碼，包含它的內部類別。Copy 會把原始碼複製到剪貼簿，Open in editor 則會在一般的編輯器分頁中開啟。
  5. 如果 Java source 分頁顯示反編譯 Java 原始碼需要 Java 執行環境，請把 jarViewer.javaPath 設為 java 執行檔或 JDK 資料夾，或設定 JAVA_HOME。「JAR Viewer: Check the Java runtime used for decompiling」會顯示目前使用哪個 Java。
  6. 開啟 Bytecode 分頁，可以看到 javap -c -p 風格的清單，包含每個 opcode、例外表和行號。Members、Constant pool 和 Class info 分頁會顯示宣告、常數池項目和類別屬性。
  7. 在 Spring Boot JAR、WAR 或 AAR 中，點選 BOOT-INF/lib 或 WEB-INF/lib 裡的 JAR，或 AAR 的 classes.jar，再按「Open nested archive」。它會往下開啟一層，頂端顯示外層檔名的按鈕可以帶你返回。

哪些功能免費，Zovo Pro 又多了什麼

套件樹、Overview、manifest、資源、反編譯的 Java 原始碼、位元組碼、Members、Constant pool、Class info 和巢狀 JAR 都免費，不需登入。CFR 隨擴充功能一起提供，使用你電腦上已安裝的 Java 執行。擴充功能絕不修改壓縮檔，也不會連線到網路。

Export decompiled sources of a JAR 會用 CFR 反編譯 JAR、WAR、EAR 或 AAR 中的每個類別，把 .java 檔案寫入資料夾，過程中顯示進度並提供 Cancel 按鈕。沒有 Java 執行環境時，它會改為寫出位元組碼清單。你會得到整個函式庫的原始碼檔案，可以在編輯器中搜尋或閱讀，不必一次開啟一個類別。

使用 Export decompiled sources of a JAR（Zovo Pro）

  1. 開啟壓縮檔，按檢視器頂端的「Export sources…」，或小型 Pro tools 列中的「Export decompiled sources」。也可以在 Explorer 對檔案按右鍵，選擇「Zovo Pro: Export decompiled sources」。
  2. 或從 Command Palette 執行「JAR Viewer: Export decompiled sources of a JAR (Pro)」。沒有開啟壓縮檔時，它會請你選擇 JAR、WAR、EAR 或 AAR 檔案。
  3. 選擇資料夾並按「Export here」。原始碼會寫入一個以壓縮檔命名、結尾加上 -src 的新資料夾。
  4. 通知會顯示進度。Cancel 會停止匯出，且不算一次試用。完成後，檢視器會顯示寫入了多少個檔案，以及寫在哪裡。

在 Cursor、Windsurf 或 VSCodium 中的步驟

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）開啟 Extensions 檢視。
  2. 搜尋 zovo.zovo-jar-viewer 並按 Install。Cursor、Windsurf 和 VSCodium 從 Open VSX 安裝擴充功能，這個擴充功能在那裡的名稱是 zovo/zovo-jar-viewer。
  3. 如果編輯器沒有擴充功能市集，請在 Open VSX 頁面下載 .vsix 檔案，再執行「Extensions: Install from VSIX...」。
  4. 之後的用法和在 VS Code 中一樣。

JAR Viewer 能做什麼

  • JAR、WAR、EAR 和 AAR 壓縮檔，以及單一 .class 檔案和同一資料夾中的內部類別。
  • 最多 200,000 個項目的壓縮檔，篩選框可在 50,000 個項目中邊打字邊找出類別或檔案。
  • 類別資料中的泛型簽章、record、permitted subclass、nest host 和 annotation。
  • properties、XML、JSON、SQL 和 services 等文字資源以文字顯示，二進位檔案則以十六進位預覽。
  • Spring Boot 的 BOOT-INF/lib、WAR 的 WEB-INF/lib 和 AAR 的 classes.jar，可往下開啟一層。

它做不到的事

  • 反編譯原始碼需要電腦上有 Java 8 以上。沒有 Java 時，位元組碼和其他所有檢視仍可使用。
  • CFR 的輸出可能與原始程式碼不同，例如區域變數名稱、部分泛型和 lambda。
  • 每個項目最多解壓 64 MB，類別檔最多 16 MB，巢狀壓縮檔最多 128 MB。遠端或虛擬檔案系統上的檔案最多讀取 256 MB。
  • 它是唯讀的，無法編輯或重新編譯類別。巢狀壓縮檔只能往下開啟一層。
  • 不會讀取 APK 和 DEX 檔案。

常見問題

免費嗎？

是的。所有檢視和一次反編譯一個類別都免費。三項 Pro 工具 Export decompiled sources of a JAR、Compare two JARs 和 Find in every JAR of a folder 各有 3 次免費試用，而且只有在工具產生結果時才算一次。之後需要 Zovo Pro，一次付清 19 美元，可用於所有 Zovo 擴充功能。

為什麼 Java source 分頁需要 Java？

CFR 是 Java 程式。檢視器會依序在 jarViewer.javaPath、JAVA_HOME 和 PATH 上的 java 尋找 Java。任何 Java 8 以上的執行環境都可以。

沒有 Java 也能看位元組碼嗎？

可以。Bytecode、Members、Constant pool 和 Class info 分頁是用 JavaScript 讀取，不需要 Java。

可以在 Cursor 使用嗎？

可以。它在 Open VSX 上的名稱是 zovo/zovo-jar-viewer，所以 Cursor、Windsurf 和 VSCodium 都能安裝。
