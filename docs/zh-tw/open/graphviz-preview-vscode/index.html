不安裝 Graphviz 也能預覽 DOT 圖形

安裝免費的 Graphviz Viewer & DOT Viewer，開啟 .dot 或 .gv 檔案，按預覽圖示。圖形會畫在編輯器旁，並隨著你的輸入重繪。Graphviz 16.1 以 WebAssembly 形式內建在擴充功能中，所以不必安裝其他東西。預覽、六種版面配置引擎、點選跳到對應行，以及 SVG 或 PNG 匯出都免費。Zovo Pro（一次付清 19 美元）另外提供向量 PDF 匯出、匯出工作區中的所有圖形，以及儲存時匯出，每項各有 3 次免費試用。

在 VS Code 中的步驟

  1. 從 Marketplace 安裝 Graphviz Viewer & DOT Viewer，或按 Ctrl+P（macOS 上按 Cmd+P）後執行 ext install zovo.zovo-graphviz-preview。
  2. 開啟 .dot 或 .gv 檔案。按編輯器標題列的預覽圖示，或按 Ctrl+K V（Mac 上按 Cmd+K V），圖形會在檔案旁開啟。
  3. 編輯檔案。停止輸入 300 毫秒後預覽就會重繪，不必存檔。語法錯誤會在所在行加上底線並列在 Problems 中，預覽則保留上一張正確的圖。
  4. 在工具列選擇 dot、neato、fdp、sfdp、circo 或 twopi。選 auto 時會使用圖形的 layout= 屬性，沒有設定時使用 dot。
  5. 在 Find node 輸入文字，名稱或標籤符合的節點會亮起。按一下節點、邊或叢集，游標就會移到原始碼中它所在的那一行。
  6. 按 SVG 或 PNG 儲存圖形。PNG 以 2x 解析度、白色背景和一般的 Graphviz 配色儲存。

哪些功能免費，Zovo Pro 又多了什麼

即時預覽、全部六種版面配置引擎、Problems 中的錯誤、Find node、點選跳到對應行、平移和縮放、目前圖形的 SVG 和 PNG 匯出，以及 Markdown 預覽中的 dot 區塊都免費。不需要登入，不會連線到網路，也沒有遙測。

PDF 匯出會存成向量 PDF，文字保持為文字，所以任何縮放比例都清晰，也能搜尋和複製。可以選擇像 dot -Tpdf 一樣以圖形大小為頁面，或選擇 A4 或 Letter 頁面並加上標題頁和書籤；Markdown 檔案則是每個 dot 區塊一頁。不必安裝 Graphviz，就能得到放進設計文件或列印用的 PDF。

使用 Export to PDF (Vector, Title Page)（Zovo Pro）

  1. 開啟預覽，按工具列上的 PDF（有小小的 PRO 標記），或從 Command Palette 執行「Graphviz: Export to PDF (Vector, Title Page) (Pro)」。
  2. 選擇「Graph-size pages」、「Title page and A4 pages」、「Title page and Letter pages」或「Graph-size pages with a title page」，再選擇儲存位置。
  3. 按 Escape、Cancel 或圖形有錯誤時，都不會用掉免費試用。

在 Cursor、Windsurf 或 VSCodium 中的步驟

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）開啟 Extensions 檢視。
  2. 搜尋 zovo.zovo-graphviz-preview 並按 Install。Cursor、Windsurf 和 VSCodium 從 Open VSX 安裝擴充功能，這個擴充功能在那裡的名稱是 zovo/zovo-graphviz-preview。
  3. 如果編輯器沒有擴充功能市集，請在 Open VSX 頁面下載 .vsix 檔案，再執行「Extensions: Install from VSIX...」。
  4. 之後的用法和在 VS Code 中一樣。

Graphviz Viewer & DOT Viewer 能做什麼

  • 含叢集、子圖和 HTML 標籤的 graph 和 digraph。
  • Markdown 中以 dot、graphviz 和 gv 標示的程式碼區塊，會畫在內建的 Markdown 預覽中。
  • 深色佈景主題。預設的黑色線條和文字會改用佈景主題的顏色，圖形中自行設定的顏色則維持不變。
  • 大型圖形在獨立的執行緒中排版，並有時間限制。節點有數千個時，sfdp 通常比 dot 快很多。

它做不到的事

  • 超過 4,096 KB 的圖形不會排版，排版超過 15 秒會停止（graphvizPreview.maxSourceKB、graphvizPreview.renderTimeoutSeconds）。
  • image= 屬性和 HTML 標籤中的圖片刻意不繪製。
  • 每個檔案只有一個預覽，重新啟動後預覽不會還原。Problems 只在預覽開啟時顯示。
  • PDF 使用標準 PDF 字型，所以西歐文字以外的字元（例如中文或西里爾字母標籤）在 PDF 中會顯示為「?」。SVG 和 PNG 則能正常顯示。

常見問題

免費嗎？

即時預覽、六種引擎、點選跳到對應行，以及 SVG 和 PNG 匯出都免費。三項 Pro 工具 PDF 匯出、Export All Graphs in Workspace 和 Export on Save 各有 3 次免費試用，之後需要 Zovo Pro，一次付清 19 美元，可用於所有 Zovo 擴充功能。

需要安裝 Graphviz 嗎？

不需要。Graphviz 16.1 以 WebAssembly 形式內建在擴充功能中。電腦上不必安裝其他東西，也可以離線使用。

可以繪製 Markdown 中的 dot 區塊嗎？

可以。語言標示為 dot、graphviz 或 gv 的程式碼區塊，會在 VS Code 的 Markdown 預覽中畫出來。

可以在 Cursor 使用嗎？

可以。擴充功能在 Open VSX 上，所以 Cursor、Windsurf 和 VSCodium 都能安裝。
