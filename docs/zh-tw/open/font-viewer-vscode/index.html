在 VS Code 預覽字型檔案

安裝免費的 Font Viewer，點選 .ttf、.otf、.woff、.woff2 或 .ttc 檔案。它會用這個字型顯示你自己的範例文字、各種大小的瀑布預覽、可搜尋的字形格，以及授權和嵌入權限，不必把字型安裝到系統中。Type tester、字形格、字元對照表、Info 分頁和 Copy CSS @font-face 都免費。Zovo Pro（一次付清 19 美元）另外提供兩項工具 Convert Font 和 Font Folder Report，每項各有 3 次免費試用。

在 VS Code 中的步驟

  1. 從 Marketplace 安裝 Font Viewer，或按 Ctrl+P（macOS 上按 Cmd+P）後執行 ext install zovo.font-viewer-vscode。
  2. 在 Explorer 點選 .ttf、.otf、.woff、.woff2、.ttc 或 .otc 檔案。Font Viewer 是這些檔案的預設編輯器，而且從不修改字型。
  3. 在 Type tester 分頁輸入你自己的文字，把大小滑桿從 8 拖到 200 px，並查看 12 到 96 px 的瀑布預覽。可變字型可以移動軸滑桿，也能開關 liga 或 ss01 等 OpenType 功能。
  4. 在 Glyphs 分頁依名稱、字元、U+20AC 或 glyph id 搜尋。按一下字形可放大顯示，並看到基線、x 字高和大寫字高，還能複製字元、碼位或 SVG 外框。
  5. 在 Characters 分頁查看每個 Unicode 區塊的涵蓋率，例如「Basic Latin 95/128」。關閉「Only characters in the font」即可看到缺少哪些字元。
  6. 在 Info 分頁查看授權、設計者、版權和嵌入權限，並複製現成的 @font-face 規則。

哪些功能免費，Zovo Pro 又多了什麼

開啟所有支援的字型、Type tester、字形格、字元對照表、Info 分頁和 Copy CSS @font-face 都免費。Font Viewer 可離線使用，不會連線到網路，也沒有遙測。

Font Folder Report 會列出資料夾中的每個字型，包括字族、樣式、字重、軸、版本、字形數量、授權、授權網址和嵌入權限。清單可以寫成 CSV 檔案、Markdown 表格，或一個 fonts.css，其中每個字型一條 @font-face 規則（WOFF2 優先）。在把一整個資料夾的字型放進 App 或網站之前，用一個檔案就能看到每個字型的使用限制，不必逐一開啟。

使用 Font Folder Report（Zovo Pro）

  1. 在 Explorer 對字型資料夾按右鍵，選擇「Font Folder Report: CSV, Markdown or @font-face CSS… (Pro)」，或從 Command Palette 執行「Font Viewer: Font Folder Report: CSV, Markdown or @font-face CSS… (Pro)」，再選擇資料夾。
  2. 選擇格式，可以是 CSV、Markdown 表格或 CSS @font-face 規則。
  3. 儲存檔案。預設檔名是 fonts-report.csv、fonts-report.md 和 fonts.css，只有檔案寫入後才算一次試用。

Font Folder Report 在你的電腦上可以免費使用 3 次，之後才需要授權。不會跳出彈出視窗，也沒有倒數計時。

在 Cursor、Windsurf 或 VSCodium 中的步驟

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）開啟 Extensions 檢視。
  2. 搜尋 zovo.font-viewer-vscode 並按 Install。Cursor、Windsurf 和 VSCodium 從 Open VSX 安裝擴充功能，這個擴充功能在那裡的名稱是 zovo/font-viewer-vscode。
  3. 如果編輯器沒有擴充功能市集，請在 Open VSX 頁面下載 .vsix 檔案，再執行「Extensions: Install from VSIX...」。
  4. 之後的用法和在 VS Code 中一樣。

Font Viewer 能做什麼

  • TrueType .ttf 和 OpenType .otf 字型，也包括可變字型。
  • .woff 和 .woff2 網頁字型。WOFF2 由擴充功能自己的解碼器解壓。
  • .ttc 和 .otc 字型集，可在頁首的清單中選擇字面。
  • 有 20,000 個字形的大型 CJK 字型，捲動時分頁載入。
  • 在 Explorer 對字型按右鍵，選 Copy CSS @font-face，不必開啟檔案。

它做不到的事

  • 不支援 WOFF2 字型集、SVG 字型、.dfont 和 Type 1 字型。
  • 字形外框顯示的是可變字型的預設實例。Type tester、瀑布預覽和字元對照表會跟著軸滑桿改變。
  • 彩色字型在 Type tester 和字元對照表中以彩色繪製，但字形格只顯示一般外框。
  • 超過 64 MB 的檔案會顯示訊息，不會開啟（設定 fontViewer.maxFileMB）。
  • 它是唯讀的，不會編輯字型，也不會把字型安裝到系統中。

常見問題

免費嗎？

檢視字型、Type tester、字形格、字元對照表、Info 分頁和 Copy CSS @font-face 都免費。兩項 Pro 工具 Convert Font 和 Font Folder Report 各有 3 次免費試用，之後需要 Zovo Pro，一次付清 19 美元，可用於所有 Zovo 擴充功能。

需要安裝字型嗎？

不需要。字型從檔案讀取，只在 Font Viewer 分頁中顯示。系統的字型清單不會改變。

可以開啟建置資料夾中的 WOFF2 嗎？

可以。WOFF2 由擴充功能自己的解碼器解壓，儲存新建置的字型時，開啟中的檢視會重新載入。

可以在 Cursor 使用嗎？

可以。Font Viewer 在 Open VSX 上的名稱是 zovo/font-viewer-vscode，所以 Cursor、Windsurf 和 VSCodium 都能安裝。
