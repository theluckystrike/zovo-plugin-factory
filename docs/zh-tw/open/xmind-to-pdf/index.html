不用 XMind 也能轉成 PDF，所有工作表合成一個檔案

安裝 XMind Viewer & Mind Map Viewer（zovo.xmind-mind-map-viewer），點選 .xmind 檔案，每個工作表都會以分頁開啟，不需要 XMind。檢視、搜尋，以及 PNG、SVG 和 Markdown 匯出都免費。PDF of every sheet 是 Zovo Pro 工具，會把心智圖存成一個 PDF，每個工作表一頁，使用列印配色，並為每個工作表加上書籤。它在你的電腦上有 3 次免費試用，之後 Zovo Pro 一次付清 19 美元，可用於所有 Zovo 擴充功能。

在 VS Code 中的步驟

  1. 從 Marketplace 安裝 XMind Viewer，或按 Ctrl+P（macOS 上按 Cmd+P）後執行 ext install zovo.xmind-mind-map-viewer。
  2. 在 Explorer 點選 .xmind 檔案。XMind 2020 以後、XMind Zen 和 XMind 8 的檔案都能開啟。心智圖的每個工作表都是上方的一個分頁。
  3. 瀏覽各個工作表。每個工作表都以檔案中儲存的版面開啟。拖曳可移動，Ctrl 或 Cmd 加滾輪可縮放，按 F 讓工作表符合畫面。
  4. 開啟心智圖上方工具列的「Export…」選單，選擇「PDF, every sheet (Zovo Pro)」。心智圖開啟時，也可以從 Command Palette 執行「XMind Viewer: Export every sheet as PDF (Zovo Pro)」。
  5. 在儲存對話框中選擇檔名，按「Export PDF」。訊息會顯示存了幾頁，並附上「Show in folder」按鈕。你的心智圖檔案不會被修改。
  6. 如果只要單一工作表的免費圖片，請在同一個 Export 選單中選「PNG picture」或「SVG picture」。

哪些功能免費，Zovo Pro 又多了什麼

開啟 .xmind、.mm 和 .opml 檔案免費，包括所有工作表、所有版面、摺疊、層級、搜尋和詳細資料面板。匯出 PNG（最高 2x）、SVG、把工作表以 Markdown 大綱複製到剪貼簿，以及把所有工作表存成一個 Markdown 檔案，也都免費。

PDF of every sheet 會把心智圖的所有工作表存成一個 PDF 檔案，每個工作表一頁，使用列印配色，並為每個工作表加上書籤。一次就能得到整份心智圖，不必把每個工作表匯出成圖片再手動合併。在 XMind 本身，PDF 匯出需要 XMind Pro，也就是 XMind 的付費方案。

使用 PDF of every sheet（Zovo Pro）

  1. 心智圖開啟時，在「Export…」選單中選「PDF, every sheet (Zovo Pro)」，按工具列小小的 Zovo Pro 列中的「PDF of every sheet」，或從 Command Palette 執行「XMind Viewer: Export every sheet as PDF (Zovo Pro)」。
  2. 也可以在 Explorer 對 .xmind、.mm 或 .opml 檔案按右鍵，選擇「Zovo Pro: PDF of every sheet」。
  3. 選擇 PDF 的儲存位置，按「Export PDF」。只有檔案存檔後才算一次試用，所以按 Cancel 不會用掉。
  4. 3 次免費試用用完後，工具會顯示取得 Zovo Pro 的方式。

在 Cursor、Windsurf 或 VSCodium 中的步驟

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）開啟 Extensions 檢視。
  2. 搜尋 zovo.xmind-mind-map-viewer 並按 Install。Cursor、Windsurf 和 VSCodium 從 Open VSX 安裝擴充功能，這個擴充功能在那裡的名稱是 zovo/xmind-mind-map-viewer。
  3. 如果編輯器沒有擴充功能市集，請在 Open VSX 頁面下載 .vsix 檔案，再執行「Extensions: Install from VSIX...」。
  4. 之後的用法和在 VS Code 中一樣。

XMind Viewer 能做什麼

  • XMind 2020 到 2026 和 XMind Zen 的 .xmind 檔案（content.json），以及 XMind 8、XMind 7 和更舊的 3.x 版本（content.xml）。
  • 每個工作表一個分頁，包含關聯線、外框、摘要、標記、標籤、備註、檔案內的圖片，以及用 KaTeX 繪製的 LaTeX 公式。
  • FreeMind 和 Freeplane 的 .mm 檔案，以及 .opml 大綱。PDF of every sheet 也適用這些檔案。
  • 中文、日文、韓文和 emoji 標題，長標題會自動換行。
  • 大型心智圖。在 README 的測試中，一個含 10,111 個主題和 60 張圖片的 30 MB .xmind 檔案在 0.65 秒內開啟。

它做不到的事

  • 它是唯讀的。要修改心智圖，請用 XMind、Freeplane 或其他心智圖編輯器開啟。
  • 有密碼的心智圖無法開啟，因為 XMind 會加密其內容。你會看到說明原因的訊息。
  • 魚骨圖、時間軸、矩陣和括號圖工作表會畫成邏輯圖或組織圖。在 XMind 中手動拖曳的主題位置不會保留，XMind 佈景主題的樣式（字型、線條形狀、主題形狀）也不會複製，但主題的填色和文字顏色會保留。
  • 每頁 PDF 都是工作表的圖片，所以 PDF 中的文字無法選取或搜尋。
  • 大於 1 GB 的檔案（設定 xmindViewer.maxFileMB）會顯示訊息，不會開啟。

常見問題

免費嗎？

檢視心智圖以及 PNG、SVG 和 Markdown 匯出都免費。PDF of every sheet、CSV (Excel) 和 OPML 匯出，以及 Convert a folder 是 Zovo Pro 工具。每項 Pro 工具在你的電腦上各有 3 次免費試用，之後 Zovo Pro 一次付清 19 美元，可用於所有 Zovo 擴充功能。

需要安裝 XMind 嗎？

不需要。擴充功能自己讀取 .xmind 檔案，可離線使用，也不會發出網路請求。

可以把整個資料夾的心智圖轉成 PDF 嗎？

不行。Convert a folder 會輸出 Markdown、CSV 或 OPML 檔案。PDF 一次只能處理一份心智圖。

可以在 Cursor 使用嗎？

可以。這個擴充功能也發布在 Open VSX，所以能安裝在 Cursor、Windsurf、VSCodium 和其他以 VS Code 為基礎的編輯器中。
