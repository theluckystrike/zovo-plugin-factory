在 VS Code 預覽 Mermaid 圖表

VS Code 本身沒有 Mermaid 預覽。安裝免費的 Mermaid Viewer，開啟 .mmd 或 .mermaid 檔案，按編輯器右上角的預覽圖示，圖表就會跟著你的輸入更新。在 Markdown 檔案上，預覽會列出每個 mermaid 區塊。Mermaid 12.3.0 內建在擴充功能中，所以預覽和 PNG、SVG 匯出都免費，可離線使用，也不需要登入。Zovo Pro（一次付清 19 美元）另外提供 PDF 匯出、匯出工作區中的所有圖表，以及儲存時匯出，每項各有 3 次免費試用。

在 VS Code 中的步驟

  1. 從 Marketplace 安裝 Mermaid Viewer，或按 Ctrl+P（macOS 上按 Cmd+P）後執行 ext install zovo.mermaid-viewer。
  2. 開啟 .mmd 或 .mermaid 檔案，按編輯器標題列的預覽圖示，或按 Ctrl+K V（macOS 上按 Cmd+K V）。也可以從 Command Palette 執行「Mermaid Viewer: Open Diagram Editor (Text + Live Preview)」。
  3. 含有 ```mermaid 區塊的 Markdown 檔案，同樣按預覽圖示。預覽會列出每張圖表，各有自己的錯誤訊息行和匯出按鈕。
  4. 在 Markdown 檔案中，按區塊上方的「Edit diagram」，就能在即時預覽旁編輯該區塊。儲存後，文字會寫回原本的區塊。
  5. 捲動滑鼠滾輪會以指標位置為中心縮放，拖曳可平移。Fit 和 100% 在工具列上。
  6. 按 Export 可選擇 Save PNG（1x、2x 或 4x，或指定確切的寬度或高度）、Save SVG、Copy PNG 或 Copy SVG code。

哪些功能免費，Zovo Pro 又多了什麼

即時預覽、圖表編輯器、Markdown 區塊的 Edit diagram、自動完成、錯誤底線、15 個範本、Mermaid Diagrams 大綱，以及 PNG 和 SVG 的匯出與複製都免費。不需要帳號、不需要登入，也沒有 AI。

Export All Diagrams in Workspace 會把資料夾中每個 .mmd、.mermaid 和 Markdown 檔案裡的每張圖表匯出成 SVG、PNG 或兩者，存到 mermaid-export/，資料夾結構和原始檔案相同。無法繪製的圖表會在最後列出。文件更新時，不必再逐一開啟每張圖表手動匯出。

使用 Export All Diagrams in Workspace（Zovo Pro）

  1. 在 VS Code 開啟資料夾。從 Command Palette 執行「Mermaid Viewer: Export All Diagrams in Workspace (SVG/PNG) (Pro)」，或按預覽工具列下方「Pro tools」列中的「Export All Diagrams in Workspace」。
  2. 選擇 SVG、PNG 或 SVG 和 PNG。
  3. 保留預設資料夾 mermaid-export（設定 mermaidViewer.exportFolder），或選「Choose a folder…」。只有檔案寫入後才算一次試用，按 Escape 不會用掉。

在 Cursor、Windsurf 或 VSCodium 中的步驟

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）開啟 Extensions 檢視。
  2. 搜尋 zovo.mermaid-viewer 並按 Install。Cursor、Windsurf 和 VSCodium 從 Open VSX 安裝擴充功能，這個擴充功能在那裡的名稱是 zovo/mermaid-viewer。
  3. 如果編輯器沒有擴充功能市集，請在 Open VSX 頁面下載 .vsix 檔案，再執行「Extensions: Install from VSIX...」。
  4. 之後的用法和在 VS Code 中一樣。

Mermaid Viewer 能做什麼

  • 流程圖、循序圖、類別圖、狀態圖、ER 圖、甘特圖、圓餅圖、gitGraph、mindmap、timeline、sankey、XY chart、block、C4、architecture，以及 Mermaid 12.3.0 支援的其他類型。
  • 錯誤會在所在行加上底線，並列在 Problems 面板中。畫面會保留上一張正確的圖表，Markdown 檔案中有一個區塊出錯也不會影響其他區塊。
  • 以指標為中心從 1 % 縮放到 3,200 %，支援觸控板平移和雙指縮放。
  • SVG 匯出可使用純文字標籤，方便用在 Azure DevOps 和 GitHub wiki。
  • 背景可設為編輯器顏色、白色、透明或自訂顏色，匯出時也會套用。

它做不到的事

  • 它不會在 VS Code 內建的 Markdown 預覽中加入圖表，而是開啟自己的預覽面板。
  • 標籤中的數學式（$$...$$）可能顯示不正確，因為沒有內建 KaTeX 字型。
  • Mermaid 從網路載入的圖示套件不會載入。內建圖示可以使用。
  • 超過 500,000 個字元或 2,000 條連結的圖表，要先提高上限才會繪製（設定 mermaidViewer.maxTextSize 和 mermaidViewer.maxEdges）。
  • 繪製超過 10 秒會停止（設定 mermaidViewer.renderTimeoutSeconds）。

常見問題

免費嗎？

預覽、編輯器、Markdown 區塊編輯，以及 PNG 和 SVG 匯出都免費。Pro 工具（PDF 匯出、Export All Diagrams in Workspace 和 Export on Save）各有 3 次免費試用，之後需要 Zovo Pro，一次付清 19 美元，可用於所有 Zovo 擴充功能。

為什麼 VS Code 的 Markdown 預覽沒有顯示我的 mermaid 區塊？

VS Code 內建的 Markdown 預覽不會繪製 Mermaid。Mermaid Viewer 會為 Markdown 檔案開啟自己的預覽面板，每張圖表都能縮放和匯出。

需要帳號或網路嗎？

不需要。Mermaid 12.3.0 已內建，不需要登入，也沒有 AI，預覽會擋下所有網路請求。

可以在 Cursor 使用嗎？

可以。它在 Open VSX 上的名稱是 zovo/mermaid-viewer，所以 Cursor、Windsurf 和 VSCodium 都能安裝。
