在 VS Code 播放有聲音的 MOV、MKV、WebM 和 MP4 影片

安裝免費的 Video Preview with Sound 擴充功能，在 Explorer 點選影片。使用 AAC 聲音的 MP4、MOV 和 M4V 檔案可以直接有聲播放，不必另外安裝任何東西，因為擴充功能內建了自己的音訊解碼器。MKV、WebM、AVI 以及 VS Code 無法解碼的影片（例如 Apple ProRes）需要電腦上裝有 ffmpeg。播放、聲音、字幕和轉檔都免費，Zovo Pro（一次付清 19 美元）另外提供 Clip export、Frame export 和 contact sheet，每項工具各有 3 次免費試用。

在 VS Code 中的步驟

  1. 從 Marketplace 安裝 Video Preview with Sound，或按 Ctrl+P（macOS 上按 Cmd+P）後執行 ext install zovo.video-preview-with-sound。
  2. 如果影片是 MKV、WebM、AVI、WMV、FLV、MPG、OGV 或 M2TS 檔案，或聲音是 AC-3、E-AC-3 或 DTS，請先安裝 ffmpeg。Windows 執行 winget install ffmpeg，Linux 執行 sudo apt install ffmpeg，macOS 執行 brew install ffmpeg。使用 AAC 聲音的 MP4、MOV 和 M4V 不需要其他東西。
  3. 在 Explorer 點選 .mp4、.m4v、.mov、.webm、.mkv、.avi、.wmv、.flv、.mpg、.mpeg、.ogv 或 .m2ts 檔案，按空白鍵播放。如果 VS Code 詢問要用哪個編輯器，請選「Video Preview with Sound」。
  4. 在小標籤顯示「Sound: on」之前，影片會靜音播放。MKV 或 WebM 會直接複製進 MP4，不重新編碼。ProRes、AVI、WMV 和其他 VS Code 無法解碼的影片，會轉成 H.264 一次並保存在快取中。
  5. 在影片旁放一個同名的 .srt 或 .vtt 檔案，字幕就會自動載入。按 C 或使用 CC 選單切換字幕軌或關閉字幕。
  6. 按 , 和 . 逐格移動，按 [ 和 ] 在 0.1x 到 4x 之間調整速度，按 A 和 B 設定循環區段，按 S 把目前畫面存成原尺寸 PNG，按 P 開啟子母畫面。

哪些功能免費，Zovo Pro 又多了什麼

有聲播放、內建的 AAC 解碼器、搭配 ffmpeg 播放 MKV 和 WebM、轉換 VS Code 無法解碼的影片、字幕、子母畫面、逐格移動、變速、A-B 循環、把目前畫面存成 PNG（S）、中繼資料面板和續播都免費。

Clip export 會把影片的 A-B 區段或整部影片存成 GIF 或 MP4，用在 pull request、issue 或文件中。GIF 在播放器內產生，不需要其他工具，可選 480 px 10 fps、640 px 15 fps，或最寬 960 px 15 fps，最長 60 秒。MP4 由你自己的 ffmpeg 剪輯，可選精確剪輯（重新編碼為 H.264 和 AAC，從 A 點那一格開始），或快速複製（保留原始串流，從 A 點之前的關鍵影格開始）。

使用 Clip export（Zovo Pro）

  1. 在播放器開啟影片。在要擷取的區段開頭按 A、結尾按 B；不設定的話就使用整部影片。
  2. 按播放器中的 Clip（有 PRO 標記），或控制列下方小小的 Pro tools 列中的「Export a Clip as GIF or MP4」。也可以在 Explorer 對影片按右鍵，選擇「Zovo Pro: Export a Clip as GIF or MP4」。
  3. 選擇「GIF, 480 px wide, 10 fps」、「GIF, 640 px wide, 15 fps」、「GIF, up to 960 px wide, 15 fps」、「MP4, exact cut」或「MP4, fast copy」，再選擇儲存位置。
  4. 按 Esc 可停止匯出。只有檔案存檔後才算一次試用，所以取消對話框或停止匯出都不會用掉免費試用。

在 Cursor、Windsurf 或 VSCodium 中的步驟

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）開啟 Extensions 檢視。
  2. 搜尋 zovo.video-preview-with-sound 並按 Install。Cursor、Windsurf 和 VSCodium 從 Open VSX 安裝擴充功能，這個擴充功能在那裡的名稱是 zovo/video-preview-with-sound。
  3. 如果編輯器沒有擴充功能市集，請在 Open VSX 頁面下載 .vsix 檔案，再執行「Extensions: Install from VSIX...」。
  4. 之後的用法和在 VS Code 中一樣。

Video Preview with Sound 能做什麼

  • 使用 AAC（單聲道或立體聲）、ALAC、MP3 或 PCM 聲音的 MP4、M4V 和 MOV，不必另外安裝，Windows、Linux 和 macOS 都能用。
  • MKV 和 WebM 由 ffmpeg 複製進 MP4，有聲播放。
  • MP4、M4V 或 MOV 中的 AC-3、E-AC-3、DTS、Opus 或 5.1 AAC 聲音，由 ffmpeg 或 macOS 內建的 afconvert 解碼。
  • Apple ProRes、MPEG-4 Part 2 和 DNxHD 影片，以及 AVI、WMV、FLV、MPG、MPEG、OGV 和 M2TS 檔案，用 ffmpeg 轉成 H.264。
  • 影片旁 .srt 和 .vtt 檔案中的字幕。

它做不到的事

  • 沒有 ffmpeg 時，MKV 和 WebM 在任何系統上都無法開啟，播放器會顯示「Install ffmpeg to open this file」。擴充功能沒有內附 ffmpeg。
  • macOS 的 afconvert 無法轉換影片，也無法開啟 MKV 或 WebM。轉檔一定需要你自己的 ffmpeg，較長的 ProRes 檔案可能要花好幾分鐘。
  • 內建解碼器播放 HE-AAC 時只使用其中的 AAC-LC 核心，取樣率只有一半。完整的 HE-AAC、5.1 AAC、AC-3 和 DTS 請安裝 ffmpeg。
  • 大於 4096 MB 的檔案仍可播放，但沒有聲音（設定 videoPreview.maxDecodeSizeMB）。
  • 字幕只來自 .srt 和 .vtt 檔案，每個最多 5 MB。影片檔內嵌的字幕不會讀取。.ts 和 .mts 檔案不會開啟，因為這些副檔名是 TypeScript 檔案。

常見問題

為什麼 VS Code 播放 MP4 沒有聲音？

VS Code 內建的 Chromium 有 H.264 影片解碼器，但沒有 AAC 解碼器，而大多數 MP4 和 MOV 檔案使用 AAC 聲音。這個擴充功能自己解碼聲音，並和畫面同步播放。

需要 ffmpeg 嗎？

使用 AAC、ALAC、MP3 或 PCM 聲音的 MP4、MOV 和 M4V 不需要。MKV、WebM、AVI、WMV、FLV、MPG、OGV 和 M2TS，ProRes 和其他 VS Code 無法解碼的影片，以及 Clip export 輸出的 MP4 片段，都需要 ffmpeg。AC-3、E-AC-3 和 DTS 聲音需要 ffmpeg，或 macOS 上的 afconvert。

免費嗎？

是的。播放、聲音、字幕、逐格移動、把目前畫面存成 PNG 和轉檔都免費。Clip export、Frame export 和 contact sheet 是 Zovo Pro 工具，每項各有 3 次免費試用，之後一次付清 19 美元，可用於所有 Zovo 擴充功能。

可以在 Cursor 使用嗎？

可以。它在 Open VSX 上的名稱是 zovo/video-preview-with-sound，所以 Cursor、Windsurf 和 VSCodium 都能安裝。
