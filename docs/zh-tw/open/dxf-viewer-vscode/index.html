在 VS Code 開啟 DXF 圖面

安裝免費的 DXF Viewer，點選 .dxf 檔案。它能讀取 R12 到 AutoCAD 2018 的 ASCII 和二進位 DXF，包括圖塊、文字、標註、剖面線和圖紙空間配置，你可以隱藏圖層、搜尋文字和量測距離。它不讀取 DWG 檔案，點選 .dwg 會開啟一個簡短頁面，顯示版本和另存 DXF 副本的方法。檢視免費，Zovo Pro（一次付清 19 美元）另外提供三項工具 Extract drawing data、Compare drawings 和 Folder inventory，每項各有 3 次免費試用。

在 VS Code 中的步驟

  1. 從 Marketplace 安裝 DXF Viewer，或按 Ctrl+P（macOS 上按 Cmd+P）後執行 ext install zovo.dxf-viewer。
  2. 在 Explorer 點選 .dxf 檔案，它會在 DXF Viewer 中開啟。側邊面板會列出圖層、圖元類型，以及版本、單位和尺寸等圖面資訊。
  3. 拖曳可平移，捲動滾輪會以指標位置為中心縮放，按 F 或雙擊讓圖面符合畫面。按 B 在深色和白色背景之間切換。
  4. 如果圖面有圖紙空間，請在 Sheet 清單中選擇配置。它會以列印時的樣子顯示，包括標題欄和依比例顯示的視埠。
  5. 在 Layers 面板取消勾選圖層即可隱藏。按 Ctrl+F（Mac 上按 Cmd+F）搜尋文字、MTEXT 或圖塊屬性，按 M 量測兩點之間的距離。
  6. 按 Export PNG 或 Export SVG 儲存畫面。在 CAD 程式中重新儲存 DXF 後，開啟中的檢視會重新載入，並保留相同的縮放、圖紙和圖層。

哪些功能免費，Zovo Pro 又多了什麼

開啟 DXF 檔案、圖紙、圖層、文字搜尋、量測、自動重新載入，以及 PNG 或 SVG 匯出都免費。檢視器不會連線到網路，也不會修改圖面。

這項工具會讀取資料夾及其子資料夾中的每個 .dxf 檔案，每張圖面存成 CSV 的一列。每一列包含 DXF 版本、單位、寬度和高度、圖層、圖元、圖塊、文字，以及 TITLE、DWG_NO、REV 和 DATE 等標題欄欄位。拿到一整個資料夾的圖面時，在一個試算表中就能看到內容，不必逐一開啟。

使用 Inventory of a Folder of Drawings to CSV（Zovo Pro）

  1. 在 Explorer 對資料夾按右鍵，選擇「Inventory of a Folder of Drawings to CSV (Zovo Pro)」。或從 Command Palette 執行「DXF Viewer: Inventory of a Folder of Drawings to CSV (Zovo Pro)」，再選擇資料夾。
  2. 通知會顯示進度，可以取消。接著選擇 CSV 的儲存位置，預設檔名以 -dxf-inventory.csv 結尾。
  3. 只有 CSV 檔案存檔後才算一次試用，所以按 Cancel 或 Escape 不會用掉。無法讀取的檔案會列在 Error 欄中。

在 Cursor、Windsurf 或 VSCodium 中的步驟

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）開啟 Extensions 檢視。
  2. 搜尋 zovo.dxf-viewer 並按 Install。Cursor、Windsurf 和 VSCodium 從 Open VSX 安裝擴充功能，這個擴充功能在那裡的名稱是 zovo/dxf-viewer。
  3. 如果編輯器沒有擴充功能市集，請在 Open VSX 頁面下載 .vsix 檔案，再執行「Extensions: Install from VSIX...」。
  4. 之後的用法和在 VS Code 中一樣。

DXF Viewer 能做什麼

  • R12 到 AutoCAD 2018 的 ASCII 和二進位 DXF。
  • 直線、圓弧、圓、橢圓、含凸度（bulge）的聚合線、雲形線、圖樣剖面線、TEXT、MTEXT、圖塊屬性、巢狀圖塊和標註。
  • 圖紙空間配置，每個視埠依自己的比例和旋轉角度顯示，並排除該視埠凍結的圖層。
  • 大型檔案在 worker 執行緒中讀取。一個含 600,000 條直線的 24 MB 圖面大約一秒就能載入。

它做不到的事

  • 不讀取 DWG 檔案，請先另存為 DXF。
  • 3D 圖元會壓平成上視圖，3DSOLID、REGION 和 BODY 不會繪製。
  • 文字使用無襯線字型，而不是檔案中的 SHX 或 TrueType 字型，也不套用線寬。
  • 視埠以矩形繪製，漸層剖面線顯示為實心填色。
  • 超過 500 MB 的檔案不會讀取（設定 dxfViewer.maxFileMB，最大可設為 2048）。

常見問題

免費嗎？

開啟 DXF 檔案、圖紙、圖層、文字搜尋、量測、自動重新載入，以及 PNG 或 SVG 匯出都免費。三項 Pro 工具 Extract drawing data、Compare drawings 和 Folder inventory 各有 3 次免費試用，之後需要 Zovo Pro，一次付清 19 美元，可用於所有 Zovo 擴充功能。

可以開啟 DWG 檔案嗎？

不行。DWG 是封閉格式。點選 .dwg 檔案會開啟一個簡短頁面，顯示版本，以及在 AutoCAD、BricsCAD、LibreCAD、QCAD 或免費的 ODA File Converter 中另存 DXF 副本的步驟。

可以編輯圖面嗎？

不行。檢視器是唯讀的。它只會寫入你在儲存對話框中選擇的匯出檔，而且不會覆寫圖面。

可以在 Cursor 使用嗎？

可以。DXF Viewer 在 Open VSX 上，所以 Cursor、Windsurf 和 VSCodium 都能安裝。
