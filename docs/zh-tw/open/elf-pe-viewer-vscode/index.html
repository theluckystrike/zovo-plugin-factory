在 VS Code 查看 ELF、EXE 或 DLL 檔案的區段和匯入

安裝免費的 ELF Viewer & PE Viewer，點選 .so、.exe、.dll 或 .dylib 檔案。你會看到 Linux ELF、Windows PE 和 Apple Mach-O 檔案的標頭、區段、segment、匯入、匯出和符號分頁，還有十六進位檢視，不需要 readelf、objdump 或 dumpbin。檔案的所有檢視都免費且唯讀。Zovo Pro（一次付清 19 美元）另外提供三項工具，包括匯出成 JSON 或 C 標頭檔、比對兩個二進位檔，以及在一個資料夾的二進位檔中搜尋名稱，每項各有 3 次免費試用。

在 VS Code 中的步驟

  1. 從 Marketplace 安裝 ELF Viewer & PE Viewer，或按 Ctrl+P（macOS 上按 Cmd+P）後執行 ext install zovo.zovo-elf-pe-viewer。
  2. 在 Explorer 點選 .exe、.dll、.sys、.so、.dylib、.elf 或 .ko 檔案，它會在檢視器中開啟。.o 目的檔或沒有副檔名的 Linux 或 macOS 執行檔，請按右鍵選擇「Open in ELF & PE Viewer」。
  3. Overview 分頁會先出現，顯示架構、檔案類型、進入點、連結的函式庫、ASLR 和 DEP 等安全旗標、build ID 和 PDB 路徑。
  4. 開啟 Sections 或 Imports 分頁。ELF 匯入會顯示每個函式所屬的函式庫和符號版本。PE 檔案另外有資料目錄、延遲載入匯入和資源，Mach-O 檔案則有 load command。
  5. 在表格上方的篩選框輸入文字可縮小範圍，按欄位標題可排序。Copy rows 會把這些列以 Tab 分隔的文字放到剪貼簿。
  6. 按區段或 segment 的 bytes 連結，可在 Hex 分頁中看到標示出來的位元組。在 Headers 分頁中，「Show every header field with its offset」會開啟欄位樹。

哪些功能免費，Zovo Pro 又多了什麼

檔案的所有檢視都免費，不需要登入，包括總覽、所有表格、篩選、排序和複製、十六進位檢視和欄位樹。擴充功能從不寫入二進位檔，也不會連線到網路。

想知道建置資料夾中哪些二進位檔匯入了某個函式或連結了某個函式庫時，這項工具會讀取資料夾中每個 ELF、PE 和 Mach-O 檔案，列出每個符合項目和所在檔案。純文字會比對名稱的任何部分，也可以使用 /regex/。一次搜尋就能得到答案，不必逐一開啟二進位檔，或對每個檔案執行 readelf 或 dumpbin。

使用 Find a symbol or import in a folder（Zovo Pro）

  1. 開啟二進位檔，按檢視器上方的「Find in folder…」，或從 Command Palette 執行「ELF & PE Viewer: Find a symbol or import in a folder (Pro)」。
  2. 輸入名稱，例如 CreateFileW 或 SSL_read，或輸入規則運算式，例如 /^_?pthread_/。它會搜尋工作區資料夾，或請你選擇資料夾。
  3. 從檢視器執行時，符合項目會在 Find 分頁中開啟，並有 Copy 按鈕。從 Command Palette 執行時，結果會顯示在清單中，按一下就會開啟該二進位檔。
  4. 按 Escape，或搜尋沒有符合項目時，都不會用掉免費試用。

Find a symbol or import in a folder 在你的電腦上可以免費使用 3 次，之後才需要授權。不會跳出彈出視窗，也沒有倒數計時。

在 Cursor、Windsurf 或 VSCodium 中的步驟

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）開啟 Extensions 檢視。
  2. 搜尋 zovo.zovo-elf-pe-viewer 並按 Install。Cursor、Windsurf 和 VSCodium 從 Open VSX 安裝擴充功能，這個擴充功能在那裡的名稱是 zovo/zovo-elf-pe-viewer。
  3. 如果編輯器沒有擴充功能市集，請在 Open VSX 頁面下載 .vsix 檔案，再執行「Extensions: Install from VSIX...」。
  4. 之後的用法和在 VS Code 中一樣。

ELF Viewer & PE Viewer 能做什麼

  • 32 和 64 位元、little-endian 和 big-endian 的 ELF 檔案，例如 .so、.o、.ko、.elf、.axf 和 Linux 執行檔。
  • PE32 和 PE32+ 檔案，例如 .exe、.dll、.sys、.efi 和 .pyd，包括以名稱和序數匯入、含轉送（forwarder）的匯出，以及 .NET 執行階段標頭。
  • 32 和 64 位元的 Mach-O，以及 universal binary。在上方選擇架構，例如 arm64 或 x86_64。
  • 最多 100,000 列的表格，可以篩選、排序和複製。

它做不到的事

  • 它是唯讀的，沒有反組譯功能。
  • 不讀取靜態函式庫（.a）、Java class 檔案、WebAssembly 和 DEX 檔案。
  • 每個表格最多 100,000 列，讀取超過 10 秒會停止。發生時檢視器會說明。
  • 遠端或虛擬檔案系統上的檔案最多讀取 256 MB。Find in folder 只搜尋本機資料夾。
  • .o 檔案和沒有副檔名的檔案預設不會在檢視器中開啟，請在右鍵選單使用「Open in ELF & PE Viewer」。

常見問題

免費嗎？

檔案的所有檢視都免費，不需要登入。三項 Pro 工具（匯出成 JSON 或 C 標頭檔、比對兩個二進位檔、在資料夾中搜尋名稱）各有 3 次免費試用，之後需要 Zovo Pro，一次付清 19 美元，可用於所有 Zovo 擴充功能。

需要 readelf、objdump 或 dumpbin 嗎？

不需要。擴充功能自己讀取 ELF、PE 和 Mach-O 檔案，不必安裝其他程式。

它會修改二進位檔嗎？

不會。它只讀取檔案，從不寫入。Pro 匯出會在你選擇的位置另存新的 JSON 或標頭檔。

可以在 Cursor 使用嗎？

可以。README 說它可以在 Cursor、Windsurf 和 VSCodium 中使用，而且它在 Open VSX 上，所以這些編輯器都能安裝。
