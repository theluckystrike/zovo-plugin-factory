在 VS Code 開啟 SQLite 資料庫

安裝免費的 SQLite Viewer & Editor，點選 .db、.sqlite 或 .sqlite3 檔案。每個資料表會以唯讀的表格開啟，Schema 和 SQL 分頁點一下就到，而且還會讀取仍在 -wal 檔案中、已經提交的資料列。檢視、按下 Enable editing 後的編輯、附備份的 Save 和 CSV 匯入都免費。Zovo Pro（一次付清 19 美元）另外提供資料庫比對、ER 圖和一次匯出所有資料表，每項各有 3 次免費試用。

在 VS Code 中的步驟

  1. 從 Marketplace 安裝 SQLite DB Viewer，或按 Ctrl+P（macOS 上按 Cmd+P）後執行 ext install zovo.sqlite-table-viewer。
  2. 在 Explorer 點選 .db、.sqlite、.sqlite3、.db3、.s3db、.sl3、.vscdb 或 .gpkg 檔案。它會以唯讀表格開啟。
  3. 在左側選一個資料表或檢視表。按欄位標題排序，在標題下方輸入文字篩選（例如 5..9 或 =word），也可以一次搜尋所有欄位。
  4. 開啟 Schema 分頁查看欄位、索引鍵、外部索引鍵和 CREATE 陳述式，或在 SQL 分頁一次執行一個陳述式。最近 20 個陳述式會保留下來。
  5. 要修改資料時，按 Enable editing。雙擊儲存格，輸入新值後按 Enter。每項變更都會先放在待處理清單中，附有對應的 SQL 和 Undo。
  6. 按 Save（Ctrl+S，macOS 上按 Cmd+S）。Save 會檢查條件約束，建立備份檔（例如 name.db.20261109-143000.bak），再一次取代原檔案。

在 Cursor、Windsurf 或 VSCodium 中的步驟

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）開啟 Extensions 檢視。
  2. 搜尋 zovo.sqlite-table-viewer 並按 Install。Cursor、Windsurf 和 VSCodium 從 Open VSX 安裝擴充功能，這個擴充功能在那裡的名稱是 zovo/sqlite-table-viewer。
  3. 如果編輯器沒有擴充功能市集，請在 Open VSX 頁面下載 .vsix 檔案，再執行「Extensions: Install from VSIX...」。
  4. 之後的用法和在 VS Code 中一樣。

SQLite DB Viewer 能做什麼

  • 仍在 -wal 檔案中的已提交資料列，應用程式寫入時會即時重新載入（按 Live 按鈕可關閉）。
  • 在儲存格面板中，JSON 儲存格以樹狀顯示，圖片顯示為圖片，float32 BLOB 顯示為向量。
  • 複製為 CSV、TSV、JSON 或 INSERT 陳述式，並可將目前顯示的資料列匯出成 CSV、JSON 或 SQL INSERT 陳述式。
  • 將 CSV 和 TSV 匯入新的或現有的資料表，有預覽、欄位對應、進度列和 Cancel。
  • 最大 512 MB 的資料庫，資料列一次讀取一頁。

它做不到的事

  • 整個資料庫會載入記憶體。超過 512 MB 的檔案會顯示訊息（設定 sqliteTableViewer.maxFileSizeMB）。
  • 只能編輯 256 MB 以內的檔案（設定 sqliteTableViewer.editMaxFileSizeMB），較大的檔案維持唯讀。
  • 無法開啟加密的資料庫（SQLCipher、SEE）。
  • 只有這台電腦上的檔案可以編輯。遠端或虛擬檔案系統上的檔案以唯讀開啟。
  • 關閉分頁時，未儲存的變更會被捨棄，檔案維持原樣。

常見問題

免費嗎？

開啟、檢視、SQL 分頁、編輯、Save 和 CSV 匯入都免費，不需要帳號。三項 Pro 工具（Compare SQLite Databases、ER Diagram 和 Export All Tables）各有 3 次免費試用，之後需要 Zovo Pro，一次付清 19 美元，可用於所有 Zovo 擴充功能。

可以在 VS Code 裡編輯資料列嗎？

可以。檔案會以唯讀開啟，按 Enable editing 後就能修改儲存格和資料列，或執行 INSERT 和 UPDATE。按下 Save 之前不會寫入任何內容，Save 也會先建立備份。

為什麼其他檢視器顯示的是舊資料？

在 WAL 模式下，新的 commit 會留在 -wal 檔案中，直到檢查點（checkpoint）把它們複製到主檔案。只讀主檔案的檢視器會漏掉這些資料列，這個擴充功能則會讀取 -wal 檔案中已提交的部分。

可以在 Cursor 使用嗎？

可以。它在 Open VSX 上的名稱是 zovo/sqlite-table-viewer，所以 Cursor、Windsurf 和 VSCodium 都能安裝。
