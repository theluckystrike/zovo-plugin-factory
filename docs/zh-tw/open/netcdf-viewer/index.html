在 VS Code 中執行的免費 NetCDF 檢視器

在 VS Code 安裝免費的 NetCDF Viewer & HDF5 Viewer 擴充功能，點選 .nc 檔案。你會看到標頭、變數樹、含海岸線的地圖、時間滑桿，以及點選任一點後的時間序列，不需要 Python、NCL 或任何設定。同一個檢視器也能開啟 HDF5 .h5 檔案和 MATLAB 7.3 .mat 檔案，這些全部免費。Zovo Pro（一次付清 19 美元）另外提供兩項工具 Compare two files 和 Export a subset，每項各有 3 次免費試用。

在 VS Code 中安裝Marketplace 頁面Open VSX (Cursor, Windsurf, VSCodium)

免費，MIT 授權。擴充功能 ID zovo.hdf5-netcdf-explorer，版本 0.6.3。

在 VS Code 中的步驟

  1. 從 Marketplace 安裝 NetCDF Viewer & HDF5 Viewer，或按 Ctrl+P（macOS 上按 Cmd+P）後執行 ext install zovo.hdf5-netcdf-explorer。
  2. 在 Explorer 點選 .nc、.nc4、.netcdf 或 .cdf 檔案。總覽會顯示格式、維度、全域屬性和所有變數的表格，很像 ncdump -h 的輸出。
  3. 在左側的樹狀清單選一個變數。2-D 切片會畫成熱度圖，列和欄是緯度和經度時，還會畫上海岸線。
  4. 移動時間滑桿，或按旁邊的 ▶ 依時間播放。點選地圖上的一點，就會畫出該點的時間序列。
  5. 開啟 Table 分頁逐頁瀏覽數值，每頁 100 列、30 欄，欄列標題是座標值。
  6. 按「Save PNG」儲存圖表，或按「Export slice…」把畫面上的切片存成 CSV 或 JSON。「Copy xarray code」會提供取得同一個切片的那一行 Python 程式碼。
  7. HDF5 檔案直接點選 .h5 檔案即可。MATLAB 7.3 .mat 檔案請按右鍵，選擇「Open in HDF5 NetCDF Explorer」。

哪些功能免費，Zovo Pro 又多了什麼

所有格式、變數樹、屬性、表格、含海岸線的圖表和地圖、播放、點選取得時間序列、Save PNG 和 Export slice 都免費。不需要 Python，這些功能也不會連線到網路。

Export a subset 的用法類似 ncks -d 或 xarray 的 .sel。選一個變數，為每個維度設定範圍，可以用索引（0:99）或數值（30..60、2023-08-01..2023-08-31）。它會存成含座標、屬性和一行 history 的 NetCDF 檔案，或每個點一列的整齊 CSV。不必寫腳本，就能得到只含一個區域和時段的小檔案。

使用 Export a subset（Zovo Pro）

  1. 開啟檔案，按「Export slice…」旁邊的「Export subset…」按鈕，或在 Explorer 對檔案按右鍵，選擇「Zovo Pro: Export a Subset of a Variable」。
  2. 也可以從 Command Palette 執行「NetCDF Viewer Pro: Export Subset of a Variable (NetCDF or CSV)...」。
  3. 為每個維度輸入範圍。輸入時，方塊中會即時顯示目前選取的內容。
  4. 選擇 NetCDF 或 CSV，再選擇儲存位置。通知會顯示進度，按 Cancel 停止時不會留下寫到一半的檔案。

Export a subset 在你的電腦上可以免費使用 3 次，之後才需要授權。不會跳出彈出視窗，也沒有倒數計時。

在 Cursor、Windsurf 或 VSCodium 中的步驟

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）開啟 Extensions 檢視。
  2. 搜尋 zovo.hdf5-netcdf-explorer 並按 Install。Cursor、Windsurf 和 VSCodium 從 Open VSX 安裝擴充功能，這個擴充功能在那裡的名稱是 zovo/hdf5-netcdf-explorer。
  3. 如果編輯器沒有擴充功能市集，請在 Open VSX 頁面下載 .vsix 檔案，再執行「Extensions: Install from VSIX...」。
  4. 之後的用法和在 VS Code 中一樣。

NetCDF Viewer & HDF5 Viewer 能做什麼

  • NetCDF-4 和 NetCDF-4 classic、NetCDF-3 classic 和 64-bit offset，以及 CDF-5（64 位元資料）。
  • HDF5 檔案（.h5、.hdf5、.he5、.hdf），支援 deflate、shuffle、szip、LZF、Blosc、bitshuffle、LZ4、Zstd、bzip2 和 ZFP 壓縮。
  • MATLAB 7.3 .mat 以及其他以 HDF5 為基礎的檔案，例如 .jld2、.loom 和 .h5ad。
  • 依 CF 慣例解碼 scale_factor、add_offset、_FillValue 和時間單位，包括 noleap、360_day 和 all_leap 曆法。
  • 透過 Remote SSH、WSL 或 dev container 開啟遠端機器上的檔案。

它做不到的事

  • 不支援 Zarr 和 HDF4。以 v5 格式儲存的 MATLAB .mat 檔案不是 HDF5，無法開啟，請用 save(filename, '-v7.3') 重新儲存。
  • 只有規則的經緯度網格會畫出海岸線。使用 2-D 經緯度的曲線網格，以及以公尺為單位的投影網格，都不會有海岸線。
  • 大於 512 x 512 的陣列在繪圖時會抽樣。每個匯出檔最多寫入 1,000,000 個值（設定 hdf5NetcdfExplorer.maxReadValues）。
  • 不支援虛擬檔案系統，例如在 vscode.dev 開啟的 GitHub 儲存庫。
  • 使用其他 HDF5 篩選器（例如 SZ 或 JPEG）的資料集，會顯示訊息而不是數值。

常見問題

免費嗎？

所有格式、地圖、播放、時間序列、Save PNG 和 Export slice 等檢視功能都免費。兩項 Pro 工具 Compare two files 和 Export a subset 各有 3 次免費試用，之後需要 Zovo Pro，一次付清 19 美元，可用於所有 Zovo 擴充功能。

有 Windows 版的 NetCDF 檢視器嗎？

有。這個擴充功能在任何能執行 VS Code 的系統上都能用，包括 Windows、macOS 和 Linux，而且不需要 Python。

可以開啟 HDF5 和 MAT 檔案嗎？

HDF5 .h5 檔案和 MATLAB 7.3 .mat 檔案可以。舊的 MATLAB v5 .mat 檔案不是 HDF5，會顯示訊息。

可以在 Cursor 使用嗎？

可以。它在 Open VSX 上的名稱是 zovo/hdf5-netcdf-explorer，所以 Cursor、Windsurf 和 VSCodium 都能安裝。
