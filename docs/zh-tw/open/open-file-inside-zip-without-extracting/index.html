不解壓縮就開啟 ZIP 裡的檔案

安裝免費的 ZIP Viewer & Archive Explorer，點選 .zip、.jar、.vsix、.tar、.tar.gz 或 .gz 檔案。它會列出壓縮檔中的資料夾和檔案，雙擊即可在一般的唯讀分頁中開啟檔案，內容直接從壓縮檔讀取，不會解壓縮任何東西。瀏覽、開啟項目、名稱搜尋和解壓縮都免費。Zovo Pro（一次付清 19 美元）另外提供三項工具，包括比對兩個壓縮檔、匯出項目清單，以及在資料夾的所有壓縮檔中尋找檔案，每項各有 3 次免費試用。

在 VS Code 中的步驟

  1. 從 Marketplace 安裝 ZIP Viewer & Archive Explorer，或按 Ctrl+P（macOS 上按 Cmd+P）後執行 ext install zovo.zip-archive-explorer。
  2. 在 Explorer 點選 .zip、.jar、.vsix、.tar、.tar.gz、.tgz 或 .gz 檔案。它會開成資料夾和檔案的清單，顯示大小、壓縮後大小、壓縮率和日期。.war、.whl、.nupkg、.apk 或 .epub 請按右鍵選擇「Open in Archive Explorer」。
  3. 找到檔案。雙擊資料夾進入，使用上方的路徑列，或按 Backspace 回上一層。也可以在搜尋框輸入名稱，* 和 ? 可當萬用字元，例如 *.json。
  4. 雙擊檔案或按 Enter，它會在一般分頁中以唯讀開啟。程式碼有語法上色，圖片在圖片預覽中開啟，ZIP 裡的 ZIP 會開成另一個壓縮檔。
  5. Explorer 側邊欄的 Archive Explorer 區段會列出你開啟過的每個壓縮檔。在那裡對項目按右鍵，可以使用 Open to the Side、Extract... 或 Copy Path。
  6. 要修改檔案，請選取它並按 Extract...。單一檔案會經過儲存對話框。含有 .. 或絕對路徑的名稱永遠不會寫入，壓縮檔本身也不會被修改。

哪些功能免費，Zovo Pro 又多了什麼

瀏覽壓縮檔、在分頁中開啟項目、名稱搜尋、側邊欄樹狀檢視、Copy Path 和解壓縮都免費。擴充功能可離線使用，不會連線到網路，也沒有遙測。

知道檔名卻不知道在哪個建置、備份或發行版壓縮檔裡時，逐一開啟每個壓縮檔太花時間。Find a file in all archives of a folder 會搜尋資料夾底下每個 ZIP、JAR、WAR、VSIX、TAR 和 GZ 檔案的項目名稱，列出每個符合項目及其所在的壓縮檔和路徑，並在唯讀分頁中開啟你選的那個。它不會寫入任何檔案。

使用 Find a file in all archives of a folder（Zovo Pro）

  1. 從 Command Palette 執行「Archive Explorer: Find a File in All Archives of a Folder... (Pro)」並選擇要搜尋的資料夾，或在 Explorer 對資料夾按右鍵，選擇「Zovo Pro: Find a file in all archives of a folder」。
  2. 輸入檔名。* 和 ? 可當萬用字元，例如 log4j*.jar 或 *.properties。
  3. 從清單中選擇一個符合項目。它會和其他項目一樣以唯讀分頁開啟。至少有一個符合項目時才算一次試用。

在 Cursor、Windsurf 或 VSCodium 中的步驟

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）開啟 Extensions 檢視。
  2. 搜尋 zovo.zip-archive-explorer 並按 Install。Cursor、Windsurf 和 VSCodium 從 Open VSX 安裝擴充功能，這個擴充功能在那裡的名稱是 zovo/zip-archive-explorer。
  3. 如果編輯器沒有擴充功能市集，請在 Open VSX 頁面下載 .vsix 檔案，再執行「Extensions: Install from VSIX...」。
  4. 之後的用法和在 VS Code 中一樣。

ZIP Viewer & Archive Explorer 能做什麼

  • ZIP、JAR 和 VSIX，支援 Stored 和 Deflate 項目、ZIP64 和自解壓縮檔。
  • TAR（ustar、GNU 長檔名和 pax 標頭）、TAR.GZ、TGZ 和單一 GZ 檔案。
  • 透過 Open in Archive Explorer 開啟 WAR、EAR、WHL、NUPKG、APK、AAR、XPI 和 EPUB。
  • 最多 200,000 個項目的壓縮檔，以範圍讀取的方式從磁碟讀取，所以大型 ZIP 不會整個載入。

它做不到的事

  • 以 BZIP2、LZMA、Zstandard 或 Deflate64 壓縮的項目，以及加密的項目，會列出但無法開啟。
  • 不支援 7z、RAR、XZ 和 BZ2 檔案。
  • 項目是唯讀的。要修改檔案，請先解壓縮。
  • 超過 512 MB 的項目無法在分頁中開啟，但仍可解壓縮。.tar.gz 會在記憶體中解壓，預設最多 2 GB。

常見問題

免費嗎？

瀏覽壓縮檔、開啟項目、名稱搜尋、側邊欄樹狀檢視和解壓縮都免費。三項 Pro 工具 Compare two archives、Export the entry list 和 Find a file in all archives of a folder 各有 3 次免費試用，之後需要 Zovo Pro，一次付清 19 美元，可用於所有 Zovo 擴充功能。

開啟檔案時會複製到暫存資料夾嗎？

不會。項目會從壓縮檔讀進唯讀分頁。只有 Extract 會把檔案寫到磁碟。

可以編輯 ZIP 裡的檔案嗎？

不行。項目是唯讀的，壓縮檔也不會被修改。請解壓縮檔案、編輯，再用其他工具重新打包。

可以在 Cursor 使用嗎？

可以。ZIP Viewer & Archive Explorer 在 Open VSX 上，所以 Cursor、Windsurf 和 VSCodium 都能安裝。
