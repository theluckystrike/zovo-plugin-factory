在 VS Code 閱讀並恢復 Claude Code 對話紀錄

安裝 Claude Code History & Codex History Viewer (Agent Session Viewer)。它會在同一個側邊檢視中列出 ~/.claude/projects 裡的 Claude Code 工作階段和 ~/.codex/sessions 裡的 Codex 工作階段，把每一個都開成易讀的對話紀錄，按一下就能在終端機中恢復。閱讀、搜尋、恢復，以及把單一工作階段匯出成 Markdown 都免費，不需要帳號。Zovo Pro（一次付清 19 美元）另外提供用量與費用報告、遮蔽機密資訊的安全分享匯出，以及批次匯出成 Markdown，每項 Pro 工具各有 3 次免費試用。

在 VS Code 中的步驟

  1. 從 Marketplace 安裝 Agent Session Viewer，或按 Ctrl+P（macOS 上按 Cmd+P）後執行 ext install zovo.agent-session-viewer。
  2. 按活動列上的 Agent Sessions 圖示。Sessions 檢視會依專案資料夾分組列出 Claude Code 和 Codex 工作階段，子代理則列在啟動它的工作階段底下。
  3. 按一下工作階段即可閱讀。工具呼叫會摺疊起來，失敗的呼叫有紅色標記，檔案編輯以 diff 顯示。頁首顯示模型、git 分支、輪次和 token 總數。
  4. 要找舊的工作階段，按檢視上方的搜尋圖示，或從 Command Palette 執行「Agent Sessions: Search Sessions」。選擇一個結果，就會在符合處開啟該工作階段。
  5. 按工作階段旁的終端機圖示（Resume in Terminal）。終端機會在專案資料夾中開啟，並執行 claude --resume <id> 或 codex resume <id>。
  6. 如果 .jsonl 工作階段檔案在其他資料夾，請對它按右鍵，選擇 Open With，再選 Agent Session Viewer。

使用 Share-safe export（Zovo Pro）

在 Cursor、Windsurf 或 VSCodium 中的步驟

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）開啟 Extensions 檢視。
  2. 搜尋 zovo.agent-session-viewer 並按 Install。Cursor、Windsurf 和 VSCodium 從 Open VSX 安裝擴充功能，這個擴充功能在那裡的名稱是 zovo/agent-session-viewer。
  3. 如果編輯器沒有擴充功能市集，請在 Open VSX 頁面下載 .vsix 檔案，再執行「Extensions: Install from VSIX...」。
  4. 之後的用法和在 VS Code 中一樣。

Agent Session Viewer 能做什麼

  • ~/.claude/projects（或 $CLAUDE_CONFIG_DIR/projects）中的 Claude Code 工作階段，以及 ~/.codex/sessions（或 $CODEX_HOME/sessions）中的 Codex 工作階段。
  • 兩種工具的子代理，巢狀列在啟動它的工作階段底下。
  • 頁首顯示工具、模型、專案資料夾、git 分支、時長、輪次、token 總數，檔案有記錄時也顯示費用（Claude Code 會寫入，Codex 不會）。
  • 檔案編輯以 diff 顯示（Edit、Write 和 apply_patch），思考內容和 Codex 推理摘要會摺疊起來。
  • 從 session_index.jsonl 讀取 Codex 對話串名稱，所以重新命名過的對話串會保留名稱。

它做不到的事

  • 只讀取 Claude Code 和 Codex。目前不支援 Cursor、Copilot 和 Gemini CLI 的工作階段。
  • 它是唯讀的，從不修改、移動或刪除工作階段檔案，也沒有刪除指令。
  • 搜尋比對純文字，不支援規則運算式，最多 300 個結果。
  • Resume in Terminal 需要安裝 Claude Code 或 Codex，並且要在終端機的 PATH 中。
  • 預設最多讀取 256 MB 的檔案（agentSessionViewer.maxFileSizeMB），更大的檔案只開啟前面的部分。以加密方式儲存的 Codex 推理內容無法顯示。

常見問題

Claude Code 把對話紀錄存在哪裡？

在 ~/.claude/projects，每個專案一個資料夾，每個工作階段一個 .jsonl 檔案。如果設定了 CLAUDE_CONFIG_DIR，則改存在該資料夾底下。

免費嗎？

是的。閱讀、搜尋、恢復，以及把單一工作階段匯出成 Markdown 都免費，紀錄數量沒有上限。三項 Pro 工具（用量與費用報告、Share-safe export、批次匯出）各有 3 次免費試用，之後 Zovo Pro 一次付清 19 美元，可用於所有 Zovo 擴充功能。

可以從檢視器刪除舊的工作階段嗎？

不行。它只讀取你的工作階段檔案，從不修改、移動或刪除。

這是 Anthropic 做的嗎？

不是。它不是由 Anthropic 或 OpenAI 製作，也和它們沒有關係。它不會連線到網路，也沒有遙測。
