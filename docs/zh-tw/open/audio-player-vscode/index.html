在 VS Code 播放音訊檔案

安裝免費的 Audio Player & WAV Player，點選 .wav、.mp3、.flac、.ogg 或 .opus 檔案。它會播放檔案，並顯示每個聲道的波形、頻譜圖、A-B 循環、0.25x 到 2x 且音高不變的變速，以及 LUFS 響度數值。Opus 由內建的解碼器播放，M4A 和 AAC 檔案則在你有 ffmpeg 時按一下即可播放。播放和檢查檔案都免費，Zovo Pro（一次付清 19 美元）另外提供兩項工具 Folder Loudness Report 和 Normalize Loudness，每項各有 3 次免費試用。

在 VS Code 中的步驟

  1. 從 Marketplace 安裝 Audio Player & WAV Player，或按 Ctrl+P（macOS 上按 Cmd+P）後執行 ext install zovo.audio-preview-vscode。
  2. 在 Explorer 點選 .wav、.mp3、.flac、.ogg、.opus 或 .m4a 檔案。如果開啟的是其他播放器，請對檔案按右鍵，選擇「Open in Audio Preview」。
  3. 按空白鍵播放或暫停。左右方向鍵跳 5 秒（按住 Shift 則是 1 秒）。按一下波形可跳到該位置。
  4. 在波形上拖曳可循環播放該段，或按 [ 和 ] 在播放位置設定循環的起點和終點。按 L 開關循環。
  5. 選擇 0.25x 到 2x 的速度，音高保持不變。
  6. 在頁首查看編碼格式、取樣率、聲道、位元深度、長度和位元率，在 Loudness 面板查看 LUFS、峰值和 RMS，在 Tags 面板查看標題、演出者、專輯和其他標籤。

哪些功能免費，Zovo Pro 又多了什麼

播放所有支援的格式、波形、頻譜圖、A-B 循環、變速、Loudness、File 和 Tags 面板以及 Copy stats 都免費。它不會寫回音訊檔案，擴充功能也不會連線到網路。

Folder Loudness Report 會為資料夾中的每個音訊檔案寫一列 CSV，包含格式、長度、取樣率、位元深度、標題和演出者、整合 LUFS、短期和瞬時最大值、樣本峰值、RMS、削波樣本數，以及每個檔案要達到 -14、-16 和 -23 LUFS 所需的增益。在試算表中就能排序和檢查整個資料夾的錄音，不必逐一開啟。WAV 檔案由擴充功能自己讀取，MP3、FLAC、Ogg、Opus 和 M4A 的資料列則需要你自己的 ffmpeg。

使用 Folder Loudness Report（Zovo Pro）

  1. 在 Explorer 對資料夾按右鍵，選擇「Folder Loudness Report (CSV, Pro)」，或從 Command Palette 執行「Audio Preview: Folder Loudness Report (CSV, Pro)」，再選擇資料夾。在播放器中，它也在編輯器標題的「...」選單裡。
  2. 選擇「This folder and its subfolders」或「This folder only」，再選擇 loudness-report.csv 的儲存位置。
  3. 通知會顯示進度，可以取消。用試算表開啟 CSV。只有檔案寫入後才算一次試用。

在 Cursor、Windsurf 或 VSCodium 中的步驟

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）開啟 Extensions 檢視。
  2. 搜尋 zovo.audio-preview-vscode 並按 Install。Cursor、Windsurf 和 VSCodium 從 Open VSX 安裝擴充功能，這個擴充功能在那裡的名稱是 zovo/audio-preview-vscode。
  3. 如果編輯器沒有擴充功能市集，請在 Open VSX 頁面下載 .vsix 檔案，再執行「Extensions: Install from VSIX...」。
  4. 之後的用法和在 VS Code 中一樣。

Audio Player & WAV Player 能做什麼

  • WAV（PCM 8 到 32 位元、浮點數、A-law、mu-law、RF64），以 2 MB 為單位分段讀取，大檔案不會讓編輯器卡住。
  • MP3、FLAC 和 Ogg Vorbis，使用 VS Code 本來就有的解碼器。
  • .opus 或 .ogg 中的 Opus，使用內建的 libopus 解碼器（WebAssembly）。
  • 最多 8 個聲道，每個聲道有自己的波形軌。
  • ID3v1、ID3v2.2 到 2.4、RIFF INFO、Vorbis comment 和 iTunes atom 中的標籤。

它做不到的事

  • M4A 和 AAC 需要你自己的 ffmpeg。沒有 ffmpeg 時，你會看到編碼格式、長度、位元率和標籤，以及一則訊息。
  • ALAC、AC-3 和其他 VS Code 無法解碼的格式，也需要用 ffmpeg 按鈕。
  • 壓縮檔案會整個解碼。解碼後的樣本超過 600 MB（44.1 kHz 立體聲約 28 分鐘）時只能播放（設定 audioPreview.maxDecodedMB）。
  • 峰值是樣本峰值，不是超取樣的真實峰值（true peak），也沒有響度範圍（LRA）。
  • 它只播放和檢查檔案，不會剪輯或編輯檔案。

常見問題

免費嗎？

播放、波形、頻譜圖、循環和響度數值都免費。兩項 Pro 工具 Folder Loudness Report 和 Normalize Loudness 各有 3 次免費試用，之後需要 Zovo Pro，一次付清 19 美元，可用於所有 Zovo 擴充功能。

為什麼我的 .opus 檔案在 VS Code 中無法播放？

VS Code 內附的 Chromium 沒有 Opus 解碼器。這個擴充功能帶有編譯成 WebAssembly 的 libopus，所以 Opus 不必另外安裝任何東西就能播放。

為什麼我的 M4A 只顯示訊息而不播放？

VS Code 也沒有 AAC 解碼器。安裝 ffmpeg 後，按「Decode with ffmpeg」按鈕會在擴充功能的儲存資料夾中產生一份 WAV 副本，檔案就能播放。擴充功能不會內附或下載 ffmpeg。

可以在 Cursor 使用嗎？

可以。它在 Open VSX 上的名稱是 zovo/audio-preview-vscode，所以 Cursor、Windsurf 和 VSCodium 都能安裝。
