在 VS Code 開啟 PCAP 檔案

安裝免費的 PCAP Viewer，點選 .pcap 或 .pcapng 檔案。它會顯示封包清單、協定樹、與協定樹連動的十六進位窗格、Wireshark 風格的顯示篩選器、追蹤串流和統計資料。它以 JavaScript 自行讀取檔案，所以不需要 Wireshark、tshark 或 sharkd。檢視器免費，Zovo Pro（一次付清 19 美元）另外提供封包清單匯出成 CSV 或 JSON、Markdown 擷取報告和資料夾摘要，每項工具各有 3 次免費試用。

在 VS Code 中的步驟

  1. 從 Marketplace 安裝 PCAP Viewer，或按 Ctrl+P（macOS 上按 Cmd+P）後執行 ext install zovo.zovo-pcap-viewer。
  2. 點選 .pcap、.pcapng、.pcap.gz、.pcapng.gz 或 .ntar 檔案。.cap、.dmp 或其他檔名，請在 Explorer 對檔案按右鍵，選擇「Open in PCAP Viewer」。
  3. 輸入顯示篩選器，例如 tcp.port == 443 && ip.addr == 10.0.0.1，然後按 Enter。篩選器有效時輸入框會變成綠色，無效時會說明哪裡有錯。
  4. 按一下協定樹中的欄位，十六進位窗格中對應的位元組就會亮起；按一下位元組也能找到它所屬的欄位。
  5. 雙擊封包即可追蹤它的 TCP 或 UDP 串流，以 ASCII、UTF-8 或十六進位傾印顯示，可以複製，也可以存成檔案。
  6. 按 Statistics 查看協定階層、對話、端點，以及擷取檔中找到的名稱。按一下某一列就會以它篩選。
  7. 開啟 Export 選單，把選取的封包，或篩選器顯示的所有封包，存成新的 pcap 檔案。

它把篩選器顯示的封包寫成 CSV 或 JSON 檔案，每個封包一列，包括編號、UTC 時間、從開始算起的秒數、來源、目的地、連接埠、協定、長度、串流篩選器、擷取檔中的主機名稱和 Info 文字。CSV 在 Excel 中開啟時，看起來像公式的文字會經過安全處理，JSON 則可搭配 jq 和 pandas 使用。不必手動複製每一列，就能得到可以放進工單或腳本的表格。

在 Cursor、Windsurf 或 VSCodium 中的步驟

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）開啟 Extensions 檢視。
  2. 搜尋 zovo.zovo-pcap-viewer 並按 Install。Cursor、Windsurf 和 VSCodium 從 Open VSX 安裝擴充功能，這個擴充功能在那裡的名稱是 zovo/zovo-pcap-viewer。
  3. 如果編輯器沒有擴充功能市集，請在 Open VSX 頁面下載 .vsix 檔案，再執行「Extensions: Install from VSIX...」。
  4. 之後的用法和在 VS Code 中一樣。

PCAP Viewer 能做什麼

  • pcap（微秒和奈秒，little-endian 和 big-endian）和 pcapng，也支援 .gz 壓縮檔。
  • Ethernet、802.1Q VLAN、Linux cooked capture（SLL 和 SLL2）、raw IPv4 和 IPv6、BSD loopback、802.11 標頭和 radiotap。
  • ARP、IPv4、IPv6、ICMP、ICMPv6、TCP、UDP、DNS 和 mDNS、DHCP、HTTP/1.x、含伺服器名稱（SNI）和 ALPN 的 TLS 記錄，以及 QUIC long header。
  • 大型擷取檔。在發布前的檢查中，一個含 1,438,965 個封包的 1 GB 擷取檔約 2 秒就列出。
  • 損壞的檔案。損壞處之前的每個封包都會顯示，並有訊息說明哪裡出錯、在什麼位置。

它做不到的事

  • 只有清單中的協定會解碼成欄位。HTTP 只到 HTTP/1.x，802.11 只有標頭，QUIC 只有 long header。
  • 不會解密 TLS 流量，只顯示含伺服器名稱（SNI）和 ALPN 的 TLS 記錄。
  • 篩選框接受 Wireshark 顯示篩選器語法中常用的部分，而不是全部。
  • .gz 擷取檔解壓到 512 MB 就會停止（設定 pcapViewer.maxGzipMB），並顯示訊息。
  • 遠端或虛擬檔案系統上的檔案最多開啟 256 MB（設定 pcapViewer.maxRemoteMB）。

常見問題

需要安裝 Wireshark 嗎？

不需要。PCAP Viewer 在 VS Code 中用 JavaScript 讀取 pcap 和 pcapng，Windows、macOS 和 Linux 都能用。它不使用 Wireshark、tshark 或 sharkd。

開啟擷取檔會發出 DNS 查詢嗎？

不會。主機名稱只來自封包中的 DNS 回應和 pcapng 檔案的名稱區塊。擴充功能沒有遙測，也不發出網路請求。

免費嗎？

是的。檢視器、篩選器、追蹤串流、統計資料和 pcap 匯出都免費。Export packet list to CSV or JSON、Capture report 和 Folder summary 是 Zovo Pro 工具，每項各有 3 次免費試用，之後一次付清 19 美元，可用於所有 Zovo 擴充功能。

可以在 Cursor 使用嗎？

可以。它支援 VS Code 1.90 以上版本，以及從 Open VSX 安裝擴充功能的編輯器，例如 Cursor、Windsurf 和 VSCodium。
