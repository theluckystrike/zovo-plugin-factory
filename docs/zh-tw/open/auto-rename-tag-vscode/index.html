在 VS Code 自動重新命名 HTML、JSX 和 Vue 標籤

安裝免費的 Auto Rename Tag & Close Tag Sync 擴充功能，修改開始或結束標籤的名稱，對應的標籤就會在你輸入時一起改變。重新命名使用的是 VS Code 本身的 linked editing（editor.linkedEditing）。擴充功能會為它支援的語言開啟這個設定，並在 HTML、JSX、TSX、Vue、Svelte、Astro、PHP、Blade、Twig、XML、Markdown 等語言中找出對應的標籤，所以一次復原就能讓兩個標籤都還原。重新命名、自動閉合和對應標籤外框都免費，Zovo Pro（一次付清 19 美元）另外提供 Rename Tag in All Files 和 Check Unclosed Tags in All Files，每項工具各有 3 次免費試用。

在 VS Code 中的步驟

  1. 從 Marketplace 安裝 Tag Auto Rename & Close Tag Sync，或按 Ctrl+P（macOS 上按 Cmd+P）後執行 ext install zovo.zovo-auto-rename-tag。
  2. 開啟 HTML、JSX、TSX、Vue、Svelte、PHP 或其他範本檔案，修改開始標籤的名稱。結束標籤會在你輸入時跟著改，反過來也一樣。
  3. 在開始標籤後輸入 >，結束標籤會出現在游標後方。輸入 </，目前開啟中的元素名稱會自動補上。
  4. 游標停在標籤上時，兩個標籤都會以佈景主題的括號顏色加上外框。
  5. 在編輯器中按右鍵可使用「Go to Matching Tag」和「Select Tag Content」。要在輸入框中輸入新名稱，請從 Command Palette 執行「Tag Sync: Rename Tag Pair…」。
  6. 按狀態列上的 Tags 項目，可以查看這個檔案啟用了哪些功能，或為某個語言關閉擴充功能。如果顯示「Tags: rename off」，按一下即可為該語言開啟重新命名。

哪些功能免費，Zovo Pro 又多了什麼

輸入時重新命名、輸入 > 和 </ 時自動閉合、對應標籤外框、Go to Matching Tag、Select Tag Content、Rename Tag Pair… 和狀態列選單都免費。沒有廣告，不需要登入，可離線使用。

它會一次在工作區所有含標籤的檔案中重新命名元件或元素，例如在每個 .tsx、.vue、.html 和範本檔案中，把 <Button> 改成 <UiButton>。只會修改標籤名稱，不會動到文字、屬性、字串或註解。你會先看到數量，「Preview first」會開啟 VS Code 的重構預覽，一次 Undo 就能還原所有檔案。

使用 Rename Tag in All Files（Zovo Pro）

  1. 在 VS Code 開啟專案資料夾。這項工具需要開啟的資料夾。
  2. 從 Command Palette 執行「Tag Sync: Rename Tag in All Files… (Pro)」，或在 Explorer 對 .html、.htm、.vue、.jsx、.tsx 或 .svelte 檔案按右鍵，選擇「Zovo Pro: Rename Tag in All Files」。
  3. 輸入要重新命名的標籤，寫法要和檔案中相同（例如 Button），再輸入新名稱。
  4. 選「Rename」，或選「Preview first」在重構預覽中檢查變更。原本沒有開啟的檔案會被修改但不會儲存，用 File > Save All 保留變更，用 Undo 還原。

在 Cursor、Windsurf 或 VSCodium 中的步驟

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）開啟 Extensions 檢視。
  2. 搜尋 zovo.zovo-auto-rename-tag 並按 Install。Cursor、Windsurf 和 VSCodium 從 Open VSX 安裝擴充功能，這個擴充功能在那裡的名稱是 zovo/zovo-auto-rename-tag。
  3. 如果編輯器沒有擴充功能市集，請在 Open VSX 頁面下載 .vsix 檔案，再執行「Extensions: Install from VSIX...」。
  4. 之後的用法和在 VS Code 中一樣。

Tag Auto Rename & Close Tag Sync 能做什麼

  • 在 HTML、JSX 和 TSX、Vue、Svelte、Astro、PHP、Blade、Twig、Jinja、Nunjucks、Liquid、ERB、EJS、Handlebars、XML、SVG 和 Markdown 中重新命名。
  • br、img、input、meta 和 hr 等空元素永遠不會被配對或閉合。
  • 在 .tsx 中只有真正的 JSX 才算標籤。a < b && c > d 這類比較和 useState<string>() 這類泛型不會被動到，.ts 檔案也不會處理。
  • 註解、字串、<script> 和 <style> 的內容，以及 {{ }}、{% %}、<?php ?> 和 <% %> 區塊都會略過。
  • 新的未儲存檔案只要設定了語言就能使用。

它做不到的事

  • 在 JSX 和 TSX 中，TypeScript 會自己閉合標籤，所以這個擴充功能在那裡把閉合交給 TypeScript。TypeScript 產生的結束標籤是獨立的一個復原步驟。
  • 安裝了 Vue、Svelte、Astro 或 Red Hat XML 擴充功能時，由該擴充功能在它的語言中閉合標籤，這個擴充功能不介入。
  • 超過 1 MB 或 50,000 行的檔案沒有即時重新命名、閉合和醒目提示（設定 zovoTags.maxFileSizeKB 和 zovoTags.maxFileLines）。狀態列會顯示原因，指令仍然可以使用。
  • 寫在 Svelte 或 Astro {...} 運算式中的標籤不會重新命名。
  • 如果同時啟用了較舊的 Auto Rename Tag 或 Auto Close Tag 擴充功能，兩者可能會修改同一個標籤。請只保留其中一個。

常見問題

這和 editor.linkedEditing 設定有什麼不同？

擴充功能用 editor.linkedEditing 做重新命名。它會為每個支援的語言開啟這個設定，並在每個語言中找出對應的標籤，從 HTML、Vue 到 PHP、Twig、XML 和 JSX。它也會閉合標籤、為對應的標籤加上外框，並提供 Go to Matching Tag 和 Select Tag Content。如果你自己關閉了 editor.linkedEditing，狀態列會顯示「Tags: rename off」，按一下就能為該語言開啟。

復原還能正常運作嗎？

可以。你的編輯和對應標籤的變更是同一個復原步驟，因為重新命名使用 VS Code 的 linked editing。自動閉合產生的結束標籤會併入你輸入 > 的那個復原步驟，但 JSX 和 TSX 例外，那裡由 TypeScript 閉合標籤。

免費嗎？

是的。重新命名、自動閉合、對應標籤外框和編輯器指令都免費。Rename Tag in All Files 和 Check Unclosed Tags in All Files 是 Zovo Pro 工具，每項各有 3 次免費試用，之後一次付清 19 美元，可用於所有 Zovo 擴充功能。

可以在 Cursor 使用嗎？

可以。Cursor、Windsurf 和 VSCodium 從 Open VSX 安裝它，名稱是 zovo/zovo-auto-rename-tag。
