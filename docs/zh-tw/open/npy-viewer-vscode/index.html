在 VS Code 檢視 .npy 和 .npz NumPy 檔案

安裝免費的 Tensor Viewer (NPZ Viewer & NPY Viewer)，在 Explorer 點選 .npy 或 .npz 檔案。每個陣列都會列出名稱、dtype 和 shape，點一下就會顯示 min、max、mean、std、NaN 數量、圖表、直方圖和數值，完全不需要 Python。檢視、影像、Values 表格以及 Save as .npy 或 CSV 都免費。Zovo Pro（一次付清 19 美元）另外提供兩項工具 Compare two checkpoints 和 Scan all tensors，每項各有 3 次免費試用。

在 VS Code 中的步驟

  1. 從 Marketplace 安裝 Tensor Viewer，或按 Ctrl+P（macOS 上按 Cmd+P）後執行 ext install zovo.tensor-viewer。
  2. 在 Explorer 點選 .npy 或 .npz 檔案。表格會列出每個陣列的名稱、型別、shape、參數數量和大小。
  3. 點選一個陣列。右側面板會顯示 min、max、mean、std 以及 NaN、Inf 和零的數量，接著是 2-D 陣列的熱度圖或 1-D 陣列的折線圖，再加上直方圖。
  4. 在 Values 表格查看數值，一次顯示 32 列。3 維以上的陣列，可以在 Slice 欄位輸入切片，例如 [5, :, :]。
  5. 如果陣列的形狀像影像，例如 (H, W, 3) 或 (N, 3, H, W)，Image 區塊會把它畫成圖片，並可在那裡選擇 Layout、Frame 和 Range。浮點數矩陣則會改為顯示「Show as image」按鈕。
  6. 按「Save as .npy...」或「Save as CSV...」，把陣列或切片寫入新檔案。

哪些功能免費，Zovo Pro 又多了什麼

所有格式、統計值、熱度圖、折線圖、直方圖、影像、Values 表格、切片、原始陣列（raw arrays）以及 Save as .npy 或 CSV 都免費。不需要 Python，檢視器也不會連線到網路。

Scan all tensors 會讀取檔案中每個陣列的每一個值，而不是抽樣，並標出 NaN、Inf、全為零或為常數的陣列，以及 10,000 以上的浮點數值。它在同一份報告中列出每個陣列精確的 min、max、mean、std 和 L2 norm，報告可以篩選，也能存成 CSV、Markdown 或 JSON。要在大型 .npz 裡找出有問題的陣列，不必逐一點開。

在 Cursor、Windsurf 或 VSCodium 中的步驟

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）開啟 Extensions 檢視。
  2. 搜尋 zovo.tensor-viewer 並按 Install。Cursor、Windsurf 和 VSCodium 從 Open VSX 安裝擴充功能，這個擴充功能在那裡的名稱是 zovo/tensor-viewer。
  3. 如果編輯器沒有擴充功能市集，請在 Open VSX 頁面下載 .vsix 檔案，再執行「Extensions: Install from VSIX...」。
  4. 之後的用法和在 VS Code 中一樣。

Tensor Viewer 能做什麼

  • .npy 檔案，標頭 v1、v2 和 v3，C 和 Fortran 順序，兩種位元組順序都支援。
  • .npz 封存檔，未壓縮（stored）或 deflate 壓縮的項目都支援，包括 zip64。
  • bool、int8 到 int64、uint8 到 uint64、float16、float32、float64 和複數（統計值以絕對值計算）。
  • 形狀像影像的陣列、堆疊和批次會畫成圖片，一次顯示一格。
  • 同一個擴充功能也能開啟 .safetensors、.gguf 以及 PyTorch 的 .pt、.pth 和 .ckpt 檔案。

它做不到的事

  • 以 pickle 儲存的物件陣列會列出但拒絕開啟，絕不執行。文字陣列和結構化陣列只列出，沒有統計值。
  • 超過 2,000,000 個值的陣列，統計值和圖表以抽樣計算（設定 tensorViewer.sampleValues）。統計值來自抽樣時，面板會註明。
  • 壓縮的 .npz 項目只從開頭讀取，前 64 MB 之後的值不會顯示，超過 512 MB 的項目無法另存。
  • 圖片長邊最多 512 像素。2 通道和 Fortran 順序的陣列沒有圖片檢視。
  • CSV 匯出最多兩千萬個值。超過 2^53 的 int64 值在表格和 CSV 中會失去最後幾位數。

常見問題

免費嗎？

開啟 .npy 和 .npz 檔案、統計值、圖表、影像、Values 表格以及 Save as .npy 或 CSV 都免費。兩項 Pro 工具 Compare two checkpoints 和 Scan all tensors 各有 3 次免費試用，之後需要 Zovo Pro，一次付清 19 美元，可用於所有 Zovo 擴充功能。

需要 Python 嗎？

不需要。Tensor Viewer 自己讀取檔案，所以不必安裝 Python 或 NumPy。

開啟從網路下載的 .npy 檔案安全嗎？

檔案裡的任何內容都不會被執行。NumPy 以 pickle 儲存的物件陣列會列出但拒絕開啟，檢視器也不會修改它顯示的檔案。

可以在 Cursor 使用嗎？

可以。Tensor Viewer 在 Open VSX 上的名稱是 zovo/tensor-viewer，所以 Cursor、Windsurf 和 VSCodium 都能安裝。
