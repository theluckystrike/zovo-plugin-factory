在 VS Code 中的步驟

  1. 從 Marketplace 安裝 TIFF Viewer，或按 Ctrl+P（macOS 上按 Cmd+P）後執行 ext install zovo.tiff-viewer。
  2. 在 Explorer 點選 .tif 或 .tiff 檔案，它會在 TIFF Viewer 中開啟。如果開啟的是其他檢視器，請對檔案按右鍵，選擇「Open in TIFF Viewer」，或從編輯器標題選單使用「Reopen Editor With...」。
  3. 捲動滾輪縮放，拖曳平移。狀態列會顯示指標下方像素的儲存值。
  4. 多頁檔案可以在頁面列中選擇頁面，或按 PageDown 和 PageUp（或 J 和 K）。
  5. 16 位元或浮點數資料，可以使用 Channel 和 Contrast stretch 控制項（min 到 max、2 到 98 百分位，或型別的完整範圍）。按 T 開啟標籤面板，檔案有 GeoTIFF 標籤時會多一個 GeoTIFF 區段。
  6. 按 Export PNG 把目前頁面依畫面所見存檔，包含你選的通道和對比拉伸。這項功能免費。

哪些功能免費，Zovo Pro 又多了什麼

每一頁、通道和對比拉伸、指標下的像素值、TIFF 標籤、GeoTIFF 座標，以及依畫面所見的 Export PNG 都免費。檢視可離線使用，不需要登入。

Export pages 會把這一頁，或多頁檔案的所有頁面，存成全解析度 PNG。選擇「stored values」時，8 位元和 16 位元資料會以 8 或 16 位元 PNG 保留確切數值；有號、32 位元和浮點數資料則依顯示範圍對應到 16 位元，PNG 的文字資訊會說明如何還原數值。GeoTIFF 頁面還會產生 .pgw world file 和 .geojson 範圍檔，讓 PNG 在 QGIS 或 ArcGIS 中落在正確位置。

使用 Export pages（Zovo Pro）

  1. 開啟 TIFF，按檢視器工具列上的 Export pages。檔案開啟時，也可以從 Command Palette 執行「TIFF Viewer: Export Pages to PNG (Pro)...」。
  2. 選擇「Page N with the stored values」（16 位元資料輸出 16 位元 PNG）或「Page N as shown」（8 位元）。多頁檔案還可以選「All N pages with the stored values」或「All N pages as shown」。
  3. 選擇檔名，若是所有頁面則選擇資料夾，然後儲存。只有 PNG 寫入後才算一次試用，按 Escape 不會用掉。
  4. 要轉換整個資料夾的 TIFF，請對資料夾按右鍵，執行「TIFF Viewer: Batch Convert TIFF Folder to PNG (Pro)...」（這也是 Pro 工具）。

Export pages 在你的電腦上可以免費使用 3 次，之後才需要授權。不會跳出彈出視窗，也沒有倒數計時。

在 Cursor、Windsurf 或 VSCodium 中的步驟

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）開啟 Extensions 檢視。
  2. 搜尋 zovo.tiff-viewer 並按 Install。Cursor、Windsurf 和 VSCodium 從 Open VSX 安裝擴充功能，這個擴充功能在那裡的名稱是 zovo/tiff-viewer。
  3. 如果編輯器沒有擴充功能市集，請在 Open VSX 頁面下載 .vsix 檔案，再執行「Extensions: Install from VSIX...」。
  4. 之後的用法和在 VS Code 中一樣。

TIFF Viewer 能做什麼

  • 傳統 TIFF 和 BigTIFF，little-endian 和 big-endian，strip 和 tile，chunky 和 planar。
  • 1 到 64 位元的無號和有號整數，以及 16、32 和 64 位元浮點數樣本，搭配百分位對比拉伸。
  • 灰階、RGB 和 RGBA、調色盤、CMYK 和 JPEG 中的 YCbCr；無壓縮、LZW、Deflate、PackBits、JPEG 以及 CCITT Group 3 和 4。
  • 多頁檔案有頁面列，前 300 頁有縮圖。
  • 讀取 GeoTIFF 標籤中的 EPSG 代碼、像素大小、範圍和 nodata 值，並顯示指標下的地圖座標。

它做不到的事

  • 以 ZSTD、LERC、WebP 和 JPEG 2000 壓縮的頁面會列出標籤，但不會解碼。
  • 超過 1 GB 的檔案（設定 tiffViewer.maxFileMB，預設 1024）不會解碼，只顯示訊息和每一頁的標籤。
  • 單邊超過 6000 像素或總數超過兩千四百萬像素的頁面，會每隔 N 個像素取一個來顯示；指標讀值和統計仍使用全解析度。
  • 每像素少於 8 位元的 tile 頁面，以及未壓縮的 YCbCr，不會解碼。SubIFD 中的子影像（部分 DNG 和 OME-TIFF 金字塔）會列在標籤中，但不會當成頁面顯示。
  • 檢視器是唯讀的，從不寫入 TIFF 檔案。不提供地圖圖磚和重新投影。

常見問題

TIFF 轉 PNG 會失真嗎？

PNG 是無失真格式。只有把 16 位元資料降為 8 位元時才會損失品質。在 Export pages 中選擇 stored values 選項，就能完整保留 8 位元和 16 位元數值。

免費嗎？

檢視 TIFF 檔案和依畫面所見的 Export PNG 都免費。Export pages、Batch convert 和 Region stats 是 Pro 工具，各有 3 次免費試用，之後 Zovo Pro 一次付清 19 美元，可用於所有 Zovo 擴充功能。

我的影像會被上傳嗎？

不會。擴充功能本身不會連線到網路，也沒有遙測。檔案都在你的電腦上讀取和寫入。

可以在 Cursor 或 Windsurf 使用嗎？

可以。Cursor、Windsurf 和 VSCodium 從 Open VSX 安裝擴充功能，TIFF Viewer 也發布在那裡。
