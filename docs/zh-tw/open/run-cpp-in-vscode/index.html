在 VS Code 一鍵執行 C++ 檔案

安裝免費的 Run C++ and C Code 擴充功能，開啟 .cpp 或 .c 檔案，按編輯器標題列的 Run，或按 Ctrl+Alt+Enter（Mac 上按 Cmd+Alt+Enter）。它會用你電腦上已安裝的 gcc、g++、clang 或 clang++ 編譯檔案，並在終端機中執行，cin 和 scanf 都能正常使用。編譯錯誤會列在 Problems 面板的正確行號，Input & Tests 面板、壓力測試和效能測試都免費。Zovo Pro（一次付清 19 美元）另外提供 sanitizer 檢查、-O0、-O2 和 -O3 的比較，以及測試報告，每項各有 3 次免費試用。

在 VS Code 中的步驟

  1. 從 Marketplace 安裝 Run C++ and C Code，或按 Ctrl+P（macOS 上按 Cmd+P）後執行 ext install zovo.zovo-run-cpp。
  2. 確認已安裝編譯器。「Run C++: Pick Compiler (gcc, g++, clang, clang++)」會列出它找到的編譯器。如果沒有，設定頁面會顯示適用你系統的官方步驟（Xcode Command Line Tools、MSYS2 或 WinLibs，或 Linux 的套件管理員）。
  3. 開啟 .cpp、.cc、.cxx 或 .c 檔案，按編輯器標題列的 Run 按鈕，或按 Ctrl+Alt+Enter（Mac 上按 Cmd+Alt+Enter）。
  4. 程式會在名為「Run: file.cpp」的終端機中執行，在那裡輸入資料即可。結束時會顯示結束代碼、執行時間和最高記憶體用量。執行期間，Run 按鈕會變成 Stop。
  5. 要加旗標或引數，在檔案的前 40 行寫上 // run: -O2 -lm 和 // args: "Hello World" 3。C++ 的預設值是 -std=c++20 -Wall -Wextra -g -O0。
  6. 要用儲存的輸入測試，請執行「Run C++: Run with Input & Test Cases」。貼上輸入，按 Run with input，再按 Save as test case。Run all tests 會顯示通過或失敗，並附上逐行差異。

哪些功能免費，Zovo Pro 又多了什麼

Run、Build Only、Run Last Build、Debug、資料夾建置、Input & Tests 面板、壓力測試和效能測試都免費。不需要登入，不會連線到網路，也沒有遙測。

通過測試的程式，仍可能讀到陣列結尾之外，或發生 int 溢位。Sanitizer check 會用 AddressSanitizer 和 UndefinedBehaviorSanitizer（-fsanitize=address,undefined）另外建置一份，以面板中的輸入和每個儲存的測試案例執行，並把每個堆積或堆疊溢位、釋放後使用、有號整數溢位和其他未定義行為，列在 Problems 面板的對應行。不必手動設定 sanitizer 旗標，就能找到錯誤所在的那一行。

使用 Sanitizer check（Zovo Pro）

  1. 在 Input & Tests 面板輸入資料，如果有測試案例也先儲存。檢查會以面板中的輸入和每個儲存的測試案例執行。
  2. 按面板中「Stress test, benchmark and more」底下的「Sanitizer check (Pro)」，或從 Command Palette 執行「Run C++: Sanitizer Check: AddressSanitizer and UBSan on the Input and Test Cases (Zovo Pro)」。
  3. 按 Problems 面板中的項目即可跳到對應行。建置錯誤、按 Stop 或 Cancel 都不會用掉免費試用。

Sanitizer check 在你的電腦上可以免費使用 3 次，之後才需要授權。不會跳出彈出視窗，也沒有倒數計時。

在 Cursor、Windsurf 或 VSCodium 中的步驟

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）開啟 Extensions 檢視。
  2. 搜尋 zovo.zovo-run-cpp 並按 Install。Cursor、Windsurf 和 VSCodium 從 Open VSX 安裝擴充功能，這個擴充功能在那裡的名稱是 zovo/zovo-run-cpp。
  3. 如果編輯器沒有擴充功能市集，請在 Open VSX 頁面下載 .vsix 檔案，再執行「Extensions: Install from VSIX...」。
  4. 之後的用法和在 VS Code 中一樣。

Run C++ and C Code 能做什麼

  • C 和 C++ 檔案（.c、.cpp、.cc、.cxx），使用 gcc、g++、clang 和 clang++。
  • 安裝在 Windows 常見資料夾中的 MSYS2、WinLibs、MinGW、TDM-GCC 和 LLVM，以及 Homebrew 的名稱，例如 g++-14。
  • 含空格、& 或非 ASCII 字元的路徑，因為不經過 shell 解析。
  • 輸出上百萬行的程式。面板顯示前 2,000 行，並計算其餘的行數。

它做不到的事

  • 它需要你電腦上的編譯器，從不下載編譯器。
  • 在 Input 面板和測試案例中的執行，10 秒後會停止（設定 zovoRun.timeLimitSeconds）。
  • 超過 32 MB 的輸出只計數，不保留（設定 zovoRun.maxCapturedOutputMB）。
  • Sanitizer check 需要附有 sanitizer 執行階段的編譯器。Windows 上的 MinGW gcc 沒有，所以請改用 LLVM 的 clang；檢查會說明這點，而且不會用掉試用次數。
  • Debug 需要安裝 CodeLLDB 或 C/C++ 擴充功能。

常見問題

免費嗎？

Run、Build Only、Debug、資料夾建置、Input & Tests 面板、壓力測試和效能測試都免費。三項 Pro 工具 Sanitizer check、Compare -O0, -O2 and -O3 和 Test report 各有 3 次免費試用，之後需要 Zovo Pro，一次付清 19 美元，可用於所有 Zovo 擴充功能。

程式可以用 cin 讀取輸入嗎？

可以。程式在真正的終端機中執行，所以 cin 和 scanf 會等待你輸入，沒有換行的提示文字也會先顯示。

它會修改我的 settings.json 或 tasks.json 嗎？

不會。它從不寫入你的設定檔。只有在你按下 Debug 時，才會在 .vscode/launch.json 加入一筆設定。

可以在 Cursor 使用嗎？

可以。擴充功能在 Open VSX 上，所以 Cursor、Windsurf 和 VSCodium 都能安裝。
