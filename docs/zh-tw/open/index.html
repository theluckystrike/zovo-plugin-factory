繁體中文指南

VS Code 和以它為基礎的編輯器（Cursor、Windsurf、VSCodium）可以開啟文字、圖片和部分影音檔案。其他許多格式需要安裝擴充功能。每篇指南都列出步驟，並說明哪些功能免費。

  • 在 VS Code 檢視 .npy 和 .npz NumPy 檔案. 用免費的 Tensor Viewer 在 VS Code 開啟 .npy 和 .npz NumPy 陣列，查看 dtype、shape、統計值、熱度圖、影像和數值，不需要 Python。
  • 在 VS Code 中執行的免費 NetCDF 檢視器. 在 Windows、macOS 或 Linux 的 VS Code 開啟 .nc NetCDF 檔案，查看標頭、變數、含海岸線的地圖和時間序列。也能開啟 HDF5 .h5 和 MATLAB 7.3 .mat。
  • 在 VS Code 開啟 SQLite 資料庫. 用免費的 SQLite Viewer & Editor 在 VS Code 開啟 .db 或 .sqlite 檔案，查看資料表、結構描述和 SQL，還能編輯儲存格和資料列，儲存時自動備份。
  • 在 VS Code 預覽 Mermaid 圖表. 用免費的 Mermaid Viewer 在 VS Code 預覽 .mmd 檔案和 Markdown 中的 Mermaid 圖表。即時預覽、PNG 和 SVG 匯出，可離線使用，不需要登入。
  • 在 VS Code 播放有聲音的 MOV、MKV、WebM 和 MP4 影片. 在 VS Code 播放使用 AAC 聲音的 MP4、MOV 和 M4V，不必另外安裝。MKV、WebM 和 AVI 搭配你自己的 ffmpeg 也能播放。免費播放器，支援字幕。
  • 在 VS Code 檢視 STL 檔案. 用免費的 3D Model Viewer 在 VS Code 開啟 STL 檔案，可環繞檢視、量測兩點距離、顯示線框和模型統計。也能開啟 OBJ、PLY、3MF、GLB 和 glTF。
  • 把 TIFF 轉成 PNG，畫質不流失. 在 VS Code 免費開啟 TIFF、BigTIFF 和 GeoTIFF 檔案，再把單頁或所有頁面存成 PNG，8 位元和 16 位元數值完全保留。可離線使用。
  • 不用 XMind 也能轉成 PDF，所有工作表合成一個檔案. 在 VS Code 開啟 .xmind 心智圖，不需要 XMind，再把所有工作表存成一個 PDF，每個工作表一頁。檢視免費，PDF 是 Zovo Pro 工具。
  • 在 VS Code 閱讀並恢復 Claude Code 對話紀錄. 在 VS Code 閱讀、搜尋並恢復舊的 Claude Code 和 Codex 工作階段。子代理巢狀顯示，檔案編輯以 diff 呈現，附 token 統計。唯讀，可離線使用。
  • 在 VS Code 開啟 PCAP 檔案. 用免費的 PCAP Viewer 在 VS Code 讀取 .pcap、.pcapng 和 .pcap.gz 擷取檔，有封包清單、協定樹、十六進位窗格和篩選器，不需要 Wireshark。
  • 在 VS Code 自動重新命名 HTML、JSX 和 Vue 標籤. 修改 HTML、JSX 或 Vue 標籤名稱時，對應的標籤會跟著改。這個免費擴充功能以 VS Code 的 linked editing 為基礎，支援自動閉合，一次復原就能還原。
  • 在 VS Code 開啟 DXF 圖面. 用免費的 DXF Viewer 在 VS Code 檢視 .dxf 圖面，支援 ASCII 和二進位 DXF、圖層、圖紙空間配置、文字搜尋、量測，以及 PNG 或 SVG 匯出。
  • 在 VS Code 查看 ELF、EXE 或 DLL 檔案的區段和匯入. 用免費的 ELF Viewer & PE Viewer 在 VS Code 開啟 .so、.exe、.dll 和 .dylib 檔案，查看標頭、區段、匯入、匯出、符號和十六進位內容，唯讀。
  • 在 VS Code 預覽字型檔案. 用免費的 Font Viewer 在 VS Code 開啟 .ttf、.otf、.woff、.woff2 和 .ttc 字型，可以測試文字、查看每個字形、閱讀授權，不必安裝字型。
  • 在 VS Code 播放音訊檔案. 用免費的 Audio Player 在 VS Code 播放 WAV、MP3、FLAC、Ogg 和 Opus 檔案，有波形、頻譜圖、A-B 循環、變速和 LUFS 響度。
  • 不解壓縮就開啟 ZIP 裡的檔案. 在 VS Code 瀏覽 ZIP、JAR、TAR 或 TAR.GZ，並以唯讀分頁開啟其中一個檔案，不會解壓到磁碟。免費，可離線使用。
  • 不安裝 Graphviz 也能預覽 DOT 圖形. 在 VS Code 編輯器旁即時預覽 .dot 和 .gv 檔案，Graphviz 已內建。六種版面配置引擎、點選跳到原始碼行，以及 SVG 和 PNG 匯出。
  • 在 VS Code 一鍵執行 C++ 檔案. 在 VS Code 一鍵編譯並執行開啟中的 .cpp 或 .c 檔案，使用你自己的 gcc、g++ 或 clang。在終端機輸入資料，錯誤列在 Problems，支援測試案例。
  • 在 VS Code 閱讀 EPUB 電子書. 在 VS Code 分頁開啟 .epub，可以逐頁翻閱或捲動閱讀，有目錄、全書搜尋、註腳彈出視窗，以及褐色（Sepia）或深色主題。免費，可離線使用。
  • 在 VS Code 開啟 JAR，閱讀反編譯後的 Java 原始碼. 在 VS Code 開啟 .jar、.war、.ear、.aar 和 .class 檔案，查看套件、MANIFEST.MF、位元組碼，以及用 CFR 反編譯的 Java 原始碼。免費且唯讀。
