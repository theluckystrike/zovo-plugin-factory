在 VS Code 檢視 STL 檔案

安裝免費的 3D Model Viewer，在 Explorer 點選 .stl 檔案。拖曳可環繞檢視，按右鍵拖曳或 Shift 加拖曳可平移，捲動滾輪可縮放，按 M 可量測兩點之間的距離。同一個擴充功能也能開啟 OBJ、PLY、3MF、GLB 和 glTF，開啟、量測和場景樹都免費。Zovo Pro（一次付清 19 美元）另外提供 Print check、Section view 和 Turntable export，每項工具各有 3 次免費試用。

在 VS Code 中的步驟

  1. 從 Marketplace 安裝 3D Model Viewer，或按 Ctrl+P（macOS 上按 Cmd+P）後執行 ext install zovo.3d-model-viewer。
  2. 在 Explorer 點選 .stl、.obj、.ply、.3mf、.glb 或 .gltf 檔案。如果開啟的是其他檢視器，請對檔案按右鍵，選擇「Open in 3D Model Viewer」。
  3. 拖曳可環繞檢視，按右鍵拖曳或 Shift 加拖曳可平移，捲動滾輪可縮放。按 F 讓整個模型符合畫面。
  4. 面板會顯示頂點、三角形、材質、貼圖，以及以模型單位表示的尺寸。按 P 顯示或隱藏面板和場景樹。
  5. 按 W 切換線框，按 N 顯示頂點法線，按 B 顯示邊界框。把 Shading 設為 Smooth，可以去掉 STL 檔案的多面稜角外觀。
  6. 按 M（Measure），在表面上點兩個點。線上會顯示距離，狀態列會加上 X、Y、Z 三個分量。按 Esc 結束。
  7. 按 Screenshot 把目前的畫面存成 PNG 檔案。

哪些功能免費，Zovo Pro 又多了什麼

開啟全部六種格式、環繞、平移和縮放、統計面板、場景樹、Measure、線框、法線、邊界框、格線、座標軸、glTF 動畫和 PNG 螢幕截圖都免費。可離線使用，不會連線到網路。

Print check 會算出模型的尺寸、體積和表面積，並檢查網格是否封閉（watertight），包括開放邊、非流形邊、方向相反的面、面積為零的三角形，以及分離的零件數量。Mark problems 會在模型上畫出有問題的邊。輸入材料、填充率、壁厚、線材直徑和每公斤價格後，它會在你開啟切片軟體之前估算重量、線材長度和材料成本。

使用 Print check（Zovo Pro）

  1. 在 3D Model Viewer 開啟 STL 檔案。
  2. 按側邊面板的「Run print check」，或從 Command Palette 執行「3D Model Viewer: Print Check (Zovo Pro)」。也可以在 Explorer 對檔案按右鍵，選擇「Zovo Pro: Print check」。
  3. 如果網格有問題，按「Mark problems」，開放邊會以紅色顯示，其他有問題的邊以洋紅色顯示。選擇材料（PLA、PETG、ABS、ASA、TPU、尼龍、PC 或樹脂）、填充率和你的每公斤價格。
  4. 複製報告，或存成 Markdown 或 JSON。一次免費試用涵蓋一個開啟中的檔案分頁，所以在同一個分頁中可以改設定再執行。

在 Cursor、Windsurf 或 VSCodium 中的步驟

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）開啟 Extensions 檢視。
  2. 搜尋 zovo.3d-model-viewer 並按 Install。Cursor、Windsurf 和 VSCodium 從 Open VSX 安裝擴充功能，這個擴充功能在那裡的名稱是 zovo/3d-model-viewer。
  3. 如果編輯器沒有擴充功能市集，請在 Open VSX 頁面下載 .vsix 檔案，再執行「Extensions: Install from VSIX...」。
  4. 之後的用法和在 VS Code 中一樣。

3D Model Viewer 能做什麼

  • STL，二進位和 ASCII 都支援，檔案有每個面的顏色時也會顯示。
  • OBJ，以及 mtllib 指定、放在模型旁邊的 .mtl 檔案。
  • PLY 網格和點雲，ASCII 和二進位，含頂點顏色。
  • 3MF 物件、組建項目和基本材質顏色。
  • GLB 和 glTF 2.0，包括內嵌或外部的 .bin 緩衝區和貼圖、PBR 材質、節點樹、skin、morph target 和動畫。

它做不到的事

  • FBX、DAE、USD (Universal Scene Description)、STEP、IGES 和 glTF 1.0 檔案無法開啟。
  • 尚未支援以 Draco 和 meshopt 壓縮的 glTF，以及 KTX2 貼圖。訊息會指出缺少的 glTF extension。
  • 整個檔案會讀進記憶體。超過 1024 MB 的檔案（設定 modelViewer.maxFileMB）會顯示訊息，不會讀取。
  • STL、OBJ 和 PLY 沒有單位，所以尺寸和距離都是原始座標值。glTF 以公尺為單位，3MF 以公釐為單位，除非檔案另有指定。
  • Print check 和 Section view 讀取可見的網格，最多三百萬個三角形，而且需要網格，不能是點雲。重量是估計值，支撐、裙邊（brim）以及頂層和底層都不計入。

常見問題

STL 的量測單位是什麼？

STL 檔案沒有單位，所以檢視器顯示的是原始座標值。Print check 會把 STL、OBJ 和 PLY 當成公釐，如果檔案用的是其他單位，可以在它的面板中修改。

可以開啟有材質的 OBJ 檔案嗎？

可以，只要 mtllib 指定的 .mtl 檔案放在模型旁邊。貼圖和 .bin 檔案只會從模型所在的資料夾和開啟中的工作區資料夾載入。

免費嗎？

是的。開啟模型、量測、統計、場景樹和螢幕截圖都免費。Print check、Section view 和 Turntable export 是 Zovo Pro 工具，每項各有 3 次免費試用，之後一次付清 19 美元，可用於所有 Zovo 擴充功能。

可以離線使用嗎？

可以。它在 VS Code 中用 three.js 繪圖，沒有遙測，也不會連線到網路。唯一的例外是用 GitHub Sponsors 啟用 Zovo Pro 時，會連線到 GitHub。
