Guide in italiano · DOCX Viewer

Aprire un file Word .docx in VS Code

VS Code non ha un visualizzatore Word: un .docx si apre con l'avviso che il file è binario. Installa l'estensione gratuita DOCX Viewer e fai di nuovo clic sul file. Si apre in anteprima di sola lettura, con i colori del tuo tema, la struttura del documento, la ricerca, le tabelle, i grafici e le equazioni. Non servono Office né LibreOffice, e il file non viene caricato da nessuna parte.

I passaggi in VS Code

  1. Installa l'estensione DOCX Viewer dal Marketplace, oppure premi Ctrl+P (Cmd+P su macOS) ed esegui ext install zovo.docx-viewer-vscode.
  2. Fai clic su un file .docx, .dotx o .docm nell'Explorer. Si aprono anche i file OpenDocument (.odt) e i vecchi .doc di Word 97-2003, questi ultimi solo come testo.
  3. Premi Ctrl+F (Cmd+F su macOS) per cercare. Il contatore mostra quante corrispondenze ci sono, e la struttura porta subito a qualsiasi titolo.
  4. Il pulsante del tema passa dai colori dell'editor alla carta bianca. "Page view" mostra le pagine come le impagina Word, con margini, intestazioni e piè di pagina, e "Reading view" torna al testo continuo.
  5. Se il documento ha revisioni o commenti, una barra in alto li conta. Markup, Final e Original mostrano il testo con i segni, accettato o rifiutato, senza toccare il file.
  6. Per vedere cosa è cambiato tra due versioni, fai clic destro sul file e scegli "Compare with Git HEAD" o "Compare Documents (Redline)...". Il confronto a schermo è gratuito.

Cosa è gratis e cosa aggiunge Zovo Pro

Lettura, Page view, ricerca, struttura, revisioni e commenti, Copy as Markdown e il confronto a schermo di due versioni sono gratuiti, senza account.

Quando qualcuno deve rivedere le modifiche in Word, Export Redline as Word salva un nuovo .docx in cui ogni differenza tra le due versioni diventa una vera revisione, con autore "Compare". Word e LibreOffice possono accettarle o rifiutarle una per una. Zovo Pro esporta anche il confronto in un unico file HTML, salva l'elenco delle modifiche in una cartella di lavoro Excel e confronta due cartelle di documenti.

Con Export Redline as Word (Zovo Pro)

  1. Con il documento aperto, esegui "Export Redline as Word (Pro)..." dalla Command Palette, oppure fai clic destro sul file nell'Explorer.
  2. Scegli l'altra versione del documento.
  3. Scegli dove salvare. I due documenti originali non vengono modificati.

Export Redline as Word funziona 3 volte sul tuo computer prima di chiedere una licenza, e un tentativo conta solo quando ottieni un risultato. Quando apri un file non compare niente che riguardi Pro.

In Cursor, Windsurf o VSCodium

Questi editor installano le estensioni da Open VSX. Apri la vista Extensions (Ctrl+Shift+X, o Cmd+Shift+X su macOS), cerca zovo.docx-viewer-vscode e fai clic su Install. Poi funziona come in VS Code.

Cosa non fa

  • È un visualizzatore. Non modifica e non salva il documento.
  • I vecchi file .doc mostrano solo il testo, senza formattazione né immagini.
  • Gli SmartArt non vengono mostrati, e un file protetto da password mostra un messaggio al posto del contenuto.

Domande

Serve Microsoft Office?

No. L'estensione legge il file da sola, dentro VS Code o Cursor, e funziona offline.

L'estensione è a pagamento?

No. Leggere, cercare e confrontare a schermo è gratuito. Solo le esportazioni e il confronto di cartelle fanno parte di Zovo Pro (USD 19 una volta), con 3 utilizzi gratuiti ciascuno.

Funziona nel browser?

Sì. In vscode.dev e github.dev fai clic su un .docx di un repository GitHub per leggerlo senza clonarlo.
