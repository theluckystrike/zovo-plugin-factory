Passaggi in VS Code

  1. Installa Dotenv & .env File Editor dal Marketplace, oppure premi Ctrl+P (Cmd+P su macOS) ed esegui ext install zovo.zovo-dotenv.
  2. Apri un file .env (anche .env.local, .env.production, *.env o .flaskenv). Chiavi, export, valori, valori su più righe e riferimenti ${NAME} si colorano.
  3. I valori che sembrano segreti appaiono come puntini finché il cursore non è sulla loro riga. Per mostrarli tutti, fai clic sul pulsante a forma di occhio nel titolo dell'editor o esegui "Dotenv: Show or Hide Secret Values". I modelli come .env.example non vengono mai nascosti.
  4. I problemi compaiono nel pannello Problems: una chiave impostata due volte, spazi attorno a =, una virgoletta mai chiusa, una riga senza =, un nome non valido, spazi a fine riga o un ${NAME} che nessuna riga imposta. Premi Ctrl+. (Cmd+. su Mac) su un problema per applicare la correzione.
  5. Esegui Format Document per togliere gli spazi attorno a = e gli spazi a fine riga. Commenti, ordine e virgolette restano come sono.
  6. Per copiare un valore senza mostrarlo, esegui "Dotenv: Copy the Value on This Line". Copia il valore senza virgolette e caratteri di escape, anche mentre è nascosto.
  7. Nel codice, passa il mouse su process.env.DB_HOST, os.getenv("X"), System.getenv("X") e simili per vedere quale file .env lo imposta, e premi F12 per aprire quella riga.

Cosa fa Dotenv & .env File Editor

  • File .env, .env.* (come .env.local e .env.production), *.env e .flaskenv.
  • Quali valori vengono nascosti: i nomi con PASSWORD, TOKEN, SECRET, API_KEY, DSN, DATABASE_URL e simili, oppure tutti i valori, oppure nessuno (impostazione envFile.maskValues).
  • Hover e vai alla definizione nel codice per process.env e import.meta.env (JavaScript, TypeScript), os.environ e os.getenv (Python), os.Getenv (Go), ENV (Ruby), System.getenv (Java), env() (PHP) e altri.
  • Completamento delle chiavi dopo process.env..
  • I valori nascosti restano nascosti anche nell'outline, negli hover e nei completamenti, a meno che tu non lo disattivi (impostazione envFile.hoverShowsSecrets).

Cosa non fa

  • I valori sono nascosti solo sullo schermo. Il testo resta nel file, nei risultati di ricerca e nella forma della minimap, e copia e incolla copiano il valore reale.
  • .envrc (direnv) è uno script di shell e viene lasciato alle estensioni per la shell.
  • Il report sul codice vede nomi scritti per esteso come process.env.API_KEY. I nomi costruiti durante l'esecuzione non vengono trovati.
  • I problemi seguono le regole del pacchetto dotenv. Alcuni strumenti (Docker Compose v1, systemd) sono più severi, ed è proprio questo che segnalano gli avvisi.

Domande frequenti

È gratuito?

Colori, valori nascosti, problemi con correzioni rapide, formattazione e hover nel codice sono gratuiti. I tre strumenti Pro, Compare .env with .env.example, Find Keys Missing in Code or .env e Convert .env to JSON, YAML, Kubernetes, hanno 3 tentativi gratuiti ciascuno. Dopo richiedono Zovo Pro, 19 USD una tantum per tutte le estensioni Zovo.

Modifica il mio file .env per nascondere i valori?

No. Cambia solo la visualizzazione, il file non viene mai modificato. Copia e incolla copiano comunque il valore reale.

Perché la mia chiave risulta impostata due volte?

La stessa chiave compare su due righe. Il pacchetto dotenv tiene il primo valore, mentre le shell e Docker Compose tengono l'ultimo. La correzione rapida rimuove la seconda riga.

Funziona in Cursor?

Sì. Cursor, Windsurf e VSCodium lo installano da Open VSX, dove è pubblicato come zovo/zovo-dotenv.
