Convertire un file PDF, Word, PowerPoint o Excel in Markdown in VS Code

Installa l'estensione gratuita Convert to Markdown, fai clic destro su un file PDF, Word, PowerPoint, Excel, CSV, HTML, EPUB, ODT o RTF nell'Explorer e scegli Convert to Markdown. Il Markdown si apre accanto al file con intestazioni, elenchi, tabelle, link e note del relatore delle slide, e nulla lascia il tuo computer. Convert to Markdown e Copy as Markdown sono gratuiti per ogni formato. Zovo Pro (19 USD una tantum) aggiunge tre strumenti, Convert a Folder to Markdown, Convert to Markdown with Images e LLM-ready Markdown Chunks, e ognuno ha 3 tentativi gratuiti.

Passaggi in VS Code

  1. Installa Convert to Markdown dal Marketplace, oppure premi Ctrl+P (Cmd+P su macOS) ed esegui ext install zovo.zovo-convert-to-markdown.
  2. Nell'Explorer fai clic destro su un file .pdf, .docx, .pptx, .xlsx, .xls, .ods, .csv, .tsv, .html, .epub, .odt o .rtf e scegli Convert to Markdown. Puoi anche fare clic destro sulla scheda di un file aperto.
  3. In alternativa esegui "Convert to Markdown: Convert to Markdown" dalla Command Palette. Converte il file della scheda attiva, oppure ne chiede uno.
  4. Il Markdown si apre accanto al file come documento non salvato. Per i file grandi compare l'avanzamento con un pulsante Cancel.
  5. Salva il documento. Il nome name.md accanto al file di origine è già compilato. Per salvarlo subito lì ogni volta, imposta toMarkdown.output su file.
  6. Per incollare il Markdown altrove, fai clic destro sul file e scegli Copy as Markdown. Seleziona più file nell'Explorer per convertirli uno dopo l'altro.
  7. Non hai un file a portata di mano? Esegui "Convert to Markdown: Convert a sample file" dalla Command Palette per convertire un esempio Word, PDF o PowerPoint incluso nell'estensione.

Cosa è gratis e cosa aggiunge Zovo Pro

Convert to Markdown e Copy as Markdown sono gratuiti per ogni formato: PDF, Word, PowerPoint, Excel, ODS, CSV, TSV, HTML, EPUB, ODT e RTF. Non devi installare nient'altro, né Python, né un server, né uno strumento da riga di comando. Nulla lascia il tuo computer.

Convert a Folder to Markdown converte in file .md, in un'unica esecuzione, ogni file supportato di una cartella e delle sue sottocartelle, in una nuova cartella con la stessa struttura oppure accanto a ogni file, con avanzamento e Cancel. Scegli se saltare o sovrascrivere i file .md che esistono già, e _conversion-report.md indica per ogni file se è stato convertito, saltato o non riuscito. I file con lo stesso nome mantengono il tipo nel nuovo nome (report.pdf.md, report.docx.md), così nessuno va perso.

Usare Convert a Folder to Markdown (Zovo Pro)

  1. Fai clic destro su una cartella nell'Explorer e scegli "Zovo Pro: Convert a Folder to Markdown", oppure esegui "Convert to Markdown: Convert a Folder to Markdown (Pro)" dalla Command Palette e scegli la cartella.
  2. Scegli dove vanno i file .md: "Into a new folder" (il nome della cartella più -markdown, con le stesse sottocartelle), "Next to each file" o "Pick another folder...".
  3. Se alcuni file .md esistono già, scegli Skip o Overwrite. Una notifica mostra l'avanzamento con un pulsante Cancel.
  4. Alla fine si apre _conversion-report.md. Indica per ogni file se è stato convertito, saltato o non riuscito, con un link a ogni nuovo file Markdown.

Passaggi in Cursor, Windsurf o VSCodium

  1. Apri la vista Extensions con Ctrl+Maiusc+X (Cmd+Maiusc+X su macOS).
  2. Cerca zovo.zovo-convert-to-markdown e fai clic su Install. Cursor, Windsurf e VSCodium installano le estensioni da Open VSX, dove questa si chiama zovo/zovo-convert-to-markdown.
  3. Se il tuo editor non ha una galleria, scarica il file .vsix dalla pagina di Open VSX ed esegui "Extensions: Install from VSIX...".
  4. Da lì in poi funziona tutto come in VS Code.

Cosa fa Convert to Markdown

  • PDF, con intestazioni ricavate dalla dimensione dei caratteri, paragrafi con le righe spezzate e le parole sillabate riunite, elenchi, tabelle semplici e pagine a due colonne lette colonna per colonna. Intestazioni e piè di pagina ricorrenti e numeri di pagina vengono rimossi.
  • Word (.docx, .docm, .dotx), con intestazioni, grassetto, corsivo, barrato, link, elenchi nidificati, tabelle, citazioni e note a piè di pagina.
  • PowerPoint (.pptx, .pptm, .ppsx, .potx), con una sezione ## Slide n: title per ogni slide, gli elenchi puntati con i loro livelli, le tabelle e le note del relatore.
  • Excel e altri fogli di calcolo (.xlsx, .xlsm, .xlsb, .xls, .ods), con una sezione ## Sheet: name e una tabella con pipe per ogni foglio. CSV e TSV diventano una sola tabella.
  • HTML (.html, .htm, .xhtml), dove i blocchi di codice mantengono il linguaggio e script e stili vengono rimossi, ed EPUB, con ogni capitolo in ordine di lettura.

Cosa non fa

  • I PDF scansionati (immagini delle pagine) non contengono testo da convertire. Il riconoscimento del testo (OCR) non è incluso.
  • Le tabelle dei PDF vengono individuate dagli spazi tra le colonne. Le tabelle senza spazi chiari diventano paragrafi.
  • Nella conversione gratuita le immagini diventano segnaposto come *[Image: Map of the site]*. Grafici, SmartArt e video nelle slide vengono nominati, non convertiti.
  • I vecchi file Word 97-2003 e i file RTF danno testo e tabelle senza formattazione. I file protetti da password e i vecchi file PowerPoint 97-2003 ricevono un messaggio invece di una conversione.
  • I file oltre 200 MB non vengono convertiti (impostazione toMarkdown.maxFileSizeMB), e un PDF si ferma dopo 1.000 pagine (impostazione toMarkdown.pdfMaxPages).

Domande frequenti

È gratuito?

Convert to Markdown e Copy as Markdown sono gratuiti per ogni formato. I tre strumenti Pro, Convert a Folder to Markdown, Convert to Markdown with Images e LLM-ready Markdown Chunks, hanno 3 tentativi gratuiti ciascuno. Dopo richiedono Zovo Pro, 19 USD una tantum per tutte le estensioni Zovo.

Carica i miei file su internet?

No. I convertitori girano sul tuo computer, dentro VS Code, senza chiamate di rete e senza telemetria.

Converte i PDF scansionati?

No. Un PDF scansionato contiene immagini delle pagine, non testo, e Convert to Markdown non ha l'OCR.

Funziona in Cursor?

Sì. Cursor, Windsurf e VSCodium lo installano da Open VSX, dove è pubblicato come zovo/zovo-convert-to-markdown.
