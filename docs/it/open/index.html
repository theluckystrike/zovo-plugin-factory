Aprire i file in VS Code e Cursor

VS Code apre testo, immagini e alcuni video. Per Word, PowerPoint, Excel, i PDF in modalità scura o un file binario serve un'estensione. Ogni guida spiega i passaggi in VS Code e in Cursor, cosa è gratis e cosa aggiunge Zovo Pro.

  • Aprire un file Word .docx in VS Code
    VS Code mostra un .docx come file binario. Con l'estensione gratuita DOCX Viewer il documento Word si apre in anteprima con ricerca, struttura e modalità scura. Funziona anche in Cursor.
  • Vedere le diapositive PowerPoint .pptx in VS Code
    Apri .pptx, .ppsx, .potx e i vecchi .ppt in VS Code o Cursor, con miniature, note del relatore, ricerca e presentazione a schermo intero. Estensione gratuita, senza caricare il file online.
  • Aprire Excel e CSV in VS Code come tabella
    Vedi .xlsx, .xls, .ods, CSV e Parquet in VS Code come tabella da ordinare e filtrare, fino a 1.000.000 di righe, ed esegui SQL con GROUP BY. Estensione gratuita, senza Excel né Python.
  • Leggere i PDF in modalità scura in VS Code
    Leggi i PDF in VS Code su pagine scure o seppia, e le foto mantengono i colori veri. Ricerca, struttura, miniature ed evidenziazioni in Markdown. Estensione gratuita e offline.
  • Editor esadecimale in VS Code
    Vedi, modifica e confronta i byte di qualsiasi file in VS Code, fino a immagini disco di 4 GB. Vai a un offset, ricerca con caratteri jolly, data inspector. Estensione gratuita e offline.
  • Rinominare in automatico i tag HTML, JSX e Vue in VS Code
    Rinomina un tag HTML, JSX o Vue e il tag corrispondente cambia mentre scrivi. Estensione gratuita basata sul linked editing di VS Code, con un solo undo.
  • Sfogliare i bucket AWS S3, Cloudflare R2 o MinIO in VS Code
    Sfoglia bucket S3, R2, MinIO, B2 e Wasabi in VS Code: apri oggetti in sola lettura, upload e download con ripresa, sync di una cartella dopo un piano di prova.
  • Leggere e riprendere la cronologia di Claude Code in VS Code
    Leggi, cerca e riprendi le vecchie sessioni di Claude Code e Codex in VS Code. Subagent annidati, modifiche come diff, totali dei token. Sola lettura, offline.
  • Confrontare due file ZIP in VS Code
    Apri file ZIP, JAR, TAR e GZ in VS Code gratis, poi elenca i file aggiunti, rimossi o modificati tra due archivi in un report Markdown (Zovo Pro).
  • Convertire un file PDF, Word, PowerPoint o Excel in Markdown in VS Code
    Clic destro su un file PDF, DOCX, PPTX, XLSX, CSV, HTML o EPUB in VS Code e il Markdown si apre accanto. Gratis, offline, senza Python e senza upload.
  • Da DXF a CSV in VS Code: estrarre attributi dei blocchi e testi
    Apri un disegno DXF in VS Code e salva attributi e conteggi dei blocchi, testi o layer in un CSV per Excel. Visualizzare è gratis, l’export CSV è Zovo Pro.
  • Modificare un file .env in VS Code senza mostrare i tuoi segreti
    Colora i file .env in VS Code, mostra i valori segreti come puntini finché il cursore non è sulla riga e corregge chiavi doppie e virgolette. Gratis e offline.
  • Formattare uno script bash o zsh in VS Code
    Formatta script bash, sh, zsh, bats e mksh in VS Code con Shift+Alt+F o al salvataggio. shfmt 3.14.1 è integrato, legge .editorconfig e funziona offline.
  • Formattare XML in VS Code ed eseguire XPath
    Formatta o minimizza XML in VS Code cambiando solo gli spazi tra i tag, esegui XPath 1.0 con i namespace del file e copia l'XPath sotto il cursore.
  • Vedere l'immagine dietro un percorso nel codice, nel gutter e al passaggio del mouse
    Miniatura nel gutter e hover con immagine, dimensioni in pixel e peso del file per i percorsi di immagini in JS, CSS, HTML e Markdown in VS Code. Gratis.
  • Anteprima dei diagrammi Mermaid in VS Code
    Visualizza diagrammi Mermaid in VS Code da file .mmd e blocchi Markdown con Mermaid Viewer, gratis. Anteprima live, export PNG e SVG, offline, senza login.
  • Un visualizzatore NetCDF gratuito che funziona in VS Code
    Apri file NetCDF .nc in VS Code su Windows, macOS o Linux: header, variabili, mappe con le coste e serie temporali. Anche HDF5 .h5 e MATLAB 7.3 .mat.
  • Normalizzare il loudness audio a un valore LUFS
    Ascolta WAV, MP3, FLAC, Ogg e Opus in VS Code con un misuratore LUFS gratuito, poi scrivi un nuovo WAV a -14, -16 o -23 LUFS. Offline, senza upload.
  • Aprire file NumPy .npy e .npz in VS Code
    Apri array NumPy .npy e .npz in VS Code con Tensor Viewer, gratis: dtype, shape, statistiche, heatmap, immagini e valori, senza Python.
  • Aprire un file PCAP in VS Code
    Leggi catture .pcap, .pcapng e .pcap.gz in VS Code con PCAP Viewer, gratis: elenco dei pacchetti, albero dei protocolli, pannello hex e filtri. Senza Wireshark.
  • Riprodurre video MOV, MKV, WebM e MP4 con l’audio in VS Code
    Riproduci MP4, MOV e M4V con audio AAC in VS Code senza installare altro. MKV, WebM e AVI funzionano con il tuo ffmpeg. Player gratuito con sottotitoli.
  • Modificare i file .proto in VS Code con evidenziazione, formattazione e vai alla definizione
    Evidenzia, formatta e controlla i file .proto in VS Code: formatter che tiene i commenti, vai alla definizione, errori come protoc. Gratis e senza protoc.
  • Aprire un database SQLite in VS Code
    Apri un file .db o .sqlite in VS Code con SQLite Viewer & Editor, gratis: tabelle, schema e SQL, poi modifica celle e righe e salva con un backup.
  • Aprire file STL in VS Code
    Apri file STL in VS Code con 3D Model Viewer, gratis: rotazione, misura tra due punti, wireframe e statistiche. Apre anche OBJ, PLY, 3MF, GLB e glTF.
  • Convertire TIFF in PNG senza perdere qualità
    Apri file TIFF, BigTIFF e GeoTIFF in VS Code gratis, poi salva una pagina o tutte le pagine come PNG mantenendo esatti i valori a 8 e 16 bit. Offline.
  • Convertire TTF in WOFF2 in VS Code
    Visualizza font TTF, OTF, WOFF e WOFF2 in VS Code gratis, poi converti TTF o OTF in WOFF2 accanto al file sorgente. Offline, senza upload.
  • Da XMind a PDF senza XMind: tutti i fogli in un solo PDF
    Apri una mappa mentale .xmind in VS Code senza XMind e salva tutti i fogli in un PDF, una pagina per foglio. La visualizzazione è gratis, il PDF è Zovo Pro.
