Guide in italiano · Hex Viewer

Editor esadecimale in VS Code

L'estensione gratuita Hex Viewer mostra i byte di qualsiasi file in VS Code, da un file vuoto a un'immagine disco di 4 GB. Legge solo le righe sullo schermo: nei test un file di 4 GB si è aperto in 0,6 s. Puoi andare a un offset, cercare byte con il jolly ??, leggere valori nel data inspector, inserire e cancellare byte con annulla, e confrontare due file byte per byte.

I passaggi in VS Code

  1. Installa l'estensione Hex Viewer dal Marketplace, oppure premi Ctrl+P (Cmd+P su macOS) ed esegui ext install zovo.zovo-hex-viewer.
  2. Fai clic destro su un file nell'Explorer e scegli "Open in Hex Viewer". I file .bin, .dat, .img, .rom, .dmp e .dump si aprono in Hex Viewer con un semplice clic.
  3. Ctrl+G (Cmd+G su macOS) va a un offset: 0x1F40, +0x100, -16 o end. Ctrl+F cerca byte come 50 4B 03 04, con ?? per un byte qualsiasi, testo o testo UTF-16.
  4. Il data inspector a destra legge i byte sotto il cursore come interi da 8 a 64 bit, float, ora Unix, GUID e altro. Fai clic su "Little-endian" per cambiare l'ordine dei byte.
  5. Scrivi due cifre esadecimali per sovrascrivere un byte. Insert passa alla modalità di inserimento, in cui il file cresce. Ctrl+Z annulla e Ctrl+S salva.
  6. Per confrontare due file, selezionali nell'Explorer e scegli "Compare in Hex Viewer". F7 va alla differenza successiva.

Cosa è gratis e cosa aggiunge Zovo Pro

Vedere file di qualsiasi dimensione, andare a un offset, cercare, Copy as (hex, array C, bytes Python, base64), il data inspector, la modifica con inserimento e cancellazione, annulla, il salvataggio sicuro e il confronto di due file sono gratuiti e lo restano.

Per controllare un download o un firmware, Checksums of File calcola CRC-32, Adler-32, MD5, SHA-1, SHA-256 e SHA-512 del file o della selezione in un solo passaggio, anche su un file di 4 GB, senza bisogno di aprirlo. Zovo Pro aggiunge anche i campi annidati dei binary template (ELF, PE, PNG, ZIP e altri), segnalibri con note, un report di confronto, la ricerca in più file e la mappa dell'entropia con l'istogramma dei byte.

Con Checksums of File (Zovo Pro)

  1. Fai clic destro su uno o più file nell'Explorer e scegli Checksums of File. Con il file aperto, il pulsante "Checksums..." sotto il data inspector calcola quelli della selezione.
  2. I valori compaiono in un elenco.
  3. Scegli un valore per copiarlo.

Checksums of File funziona 3 volte sul tuo computer prima di chiedere una licenza, e un tentativo conta solo quando ottieni un risultato. Quando apri un file non compare niente che riguardi Pro.

In Cursor, Windsurf o VSCodium

Questi editor installano le estensioni da Open VSX. Apri la vista Extensions (Ctrl+Shift+X, o Cmd+Shift+X su macOS), cerca zovo.zovo-hex-viewer e fai clic su Install. Poi funziona come in VS Code.

Cosa non fa

  • Copy as funziona fino a 32 MB, e incolla fino a 16 MB.
  • I file su file system remoti o virtuali si aprono fino a 256 MB (impostazione hexViewer.maxRemoteMB).
  • I file di testo e i file Intel .hex si aprono ancora nell'editor di testo.

Domande

L'estensione è a pagamento?

No. Vedere, modificare e confrontare è gratuito. Le checksum, i campi annidati dei template, i segnalibri e gli altri strumenti Pro fanno parte di Zovo Pro (USD 19 una volta), con 3 utilizzi gratuiti ciascuno.

Salvare un file grande è sicuro?

Sì. Se la dimensione non cambia, vengono scritti solo i byte modificati. Altrimenti l'estensione scrive una copia nuova e poi la mette al posto della vecchia, così un disco pieno non lascia un file scritto a metà.

Funziona offline?

Sì. Niente telemetria, niente chiamate di rete.
