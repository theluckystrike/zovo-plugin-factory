Leggere e riprendere la cronologia di Claude Code in VS Code

Installa Claude Code History & Codex History Viewer (Agent Session Viewer). Elenca in un’unica vista laterale le tue sessioni di Claude Code da ~/.claude/projects e quelle di Codex da ~/.codex/sessions, apre ognuna come una trascrizione leggibile e la riprende in un terminale con un clic. Lettura, ricerca, ripresa ed export di una sessione in Markdown sono gratis, senza account. Zovo Pro (19 USD, una volta sola) aggiunge un report di utilizzo e costi, un export da condividere con i segreti oscurati e l’export in blocco in Markdown, e ogni strumento Pro si può provare gratis 3 volte.

Passaggi in VS Code

  1. Installa Agent Session Viewer dal Marketplace, oppure premi Ctrl+P (Cmd+P su macOS) ed esegui ext install zovo.agent-session-viewer.
  2. Fai clic sull’icona Agent Sessions nella barra delle attività. La vista Sessions elenca le sessioni di Claude Code e Codex, raggruppate per cartella di progetto, con i subagent sotto la sessione che li ha avviati.
  3. Fai clic su una sessione per leggerla. Le chiamate agli strumenti sono chiuse, quelle fallite hanno un segno rosso e le modifiche ai file compaiono come diff. L’intestazione mostra modello, branch git, turni e totali dei token.
  4. Per trovare una vecchia sessione, fai clic sull’icona di ricerca in cima alla vista, oppure esegui "Agent Sessions: Search Sessions" dalla Command Palette. Scegli un risultato per aprire la sessione nel punto trovato.
  5. Fai clic sull’icona del terminale accanto alla sessione (Resume in Terminal). Si apre un terminale nella cartella del progetto che esegue claude --resume <id> o codex resume <id>.
  6. Per un file di sessione .jsonl in un’altra cartella, fai clic destro sul file, scegli Open With e poi Agent Session Viewer.

Cosa è gratis e cosa aggiunge Zovo Pro

Sono gratis l’albero Sessions, la lettura delle sessioni, la ricerca in tutte le sessioni, Resume in Terminal, Copy Resume Command, l’export di una sessione in Markdown, la vista raw e Reveal in File Manager. Non c’è un limite alla cronologia e non serve il login.

Share-safe export salva una sessione, o tutte le sessioni di un progetto, come un’unica pagina HTML autonoma o un unico file Markdown. Chiavi API, token, password negli URL, valori di .env, chiavi private, indirizzi email e la tua cartella home vengono sostituiti con [REDACTED ...], e il messaggio elenca cosa è stato nascosto. Puoi inviare una sessione per una pull request, un audit o un passaggio di consegne senza ripulirla a mano.

Usare Share-safe export (Zovo Pro)

  1. Apri la sessione e fai clic sul pulsante Share-safe export nella barra della sessione. In alternativa fai clic destro su una sessione o su una cartella di progetto nell’albero Sessions e scegli "Share-Safe Export, Secrets Redacted (Pro)…".
  2. Con una sessione aperta puoi anche eseguire "Agent Sessions: Share-Safe Export, Secrets Redacted (Pro)…" dalla Command Palette.
  3. Scegli il formato, pagina HTML o Markdown, con o senza gli output degli strumenti. Poi indica dove salvare il file.
  4. Rileggi l’export prima di condividerlo. Una prova viene contata solo quando il file viene salvato. Esc o Cancel non consumano nulla.

Share-safe export funziona 3 volte sul tuo computer prima di chiedere una licenza. Non ci sono finestre a comparsa né conti alla rovescia.

Passaggi in Cursor, Windsurf o VSCodium

  1. Apri la vista Extensions con Ctrl+Maiusc+X (Cmd+Maiusc+X su macOS).
  2. Cerca zovo.agent-session-viewer e fai clic su Install. Cursor, Windsurf e VSCodium installano le estensioni da Open VSX, dove questa si chiama zovo/agent-session-viewer.
  3. Se il tuo editor non ha una galleria, scarica il file .vsix dalla pagina di Open VSX ed esegui "Extensions: Install from VSIX...".
  4. Da lì in poi funziona tutto come in VS Code.

Cosa fa Agent Session Viewer

  • Sessioni di Claude Code in ~/.claude/projects (o $CLAUDE_CONFIG_DIR/projects) e sessioni di Codex in ~/.codex/sessions (o $CODEX_HOME/sessions).
  • I subagent di entrambi gli strumenti, annidati sotto la sessione che li ha avviati.
  • Un’intestazione con strumento, modello, cartella del progetto, branch git, durata, numero di turni, totali dei token e costo, quando il file lo registra (Claude Code lo scrive, Codex no).
  • Modifiche ai file come diff (Edit, Write e apply_patch), thinking e riepiloghi del reasoning di Codex, chiusi.
  • I nomi dei thread di Codex da session_index.jsonl, quindi i thread rinominati mantengono il loro nome.

Cosa non fa

  • Legge solo Claude Code e Codex. Le sessioni di Cursor, Copilot e Gemini CLI non sono ancora supportate.
  • È in sola lettura. Non modifica, sposta o cancella mai i file di sessione, e non ha un comando per eliminarli.
  • La ricerca trova testo semplice, non espressioni regolari, e si ferma a 300 risultati.
  • Resume in Terminal richiede Claude Code o Codex installati e nel PATH del terminale.
  • Per impostazione predefinita i file vengono letti fino a 256 MB (agentSessionViewer.maxFileSizeMB), e quelli più grandi si aprono con la loro prima parte. Il reasoning di Codex salvato cifrato non può essere mostrato.

Domande frequenti

Dove salva Claude Code la cronologia delle chat?

In ~/.claude/projects, con una cartella per progetto e un file .jsonl per sessione. Se è impostata CLAUDE_CONFIG_DIR, si trova invece sotto quella cartella.

È gratis?

Sì. Lettura, ricerca, ripresa ed export di una sessione in Markdown sono gratis, e non c’è un limite alla cronologia. I tre strumenti Pro (report di utilizzo e costi, Share-safe export, export in blocco) si possono provare gratis 3 volte ciascuno. Dopo serve Zovo Pro, 19 USD una volta sola per tutte le estensioni Zovo.

Posso cancellare le vecchie sessioni dal visualizzatore?

No. Legge soltanto i tuoi file di sessione e non li modifica, sposta o cancella mai.

È fatto da Anthropic?

No. Non è realizzato da Anthropic o OpenAI né affiliato a loro. Non fa chiamate di rete e non ha telemetria.
