Da XMind a PDF senza XMind: tutti i fogli in un solo PDF

Installa XMind Viewer & Mind Map Viewer (zovo.xmind-mind-map-viewer) e fai clic sul file .xmind. Ogni foglio si apre in una scheda, senza bisogno di XMind. Visualizzazione, ricerca ed export in PNG, SVG e Markdown sono gratis. PDF of every sheet è uno strumento Zovo Pro che salva un unico PDF con una pagina per foglio, nei colori di stampa, con un segnalibro per ogni foglio. Si può provare gratis 3 volte sul tuo computer, poi Zovo Pro costa 19 USD una volta sola per tutte le estensioni Zovo.

Passaggi in VS Code

  1. Installa XMind Viewer dal Marketplace, oppure premi Ctrl+P (Cmd+P su macOS) ed esegui ext install zovo.xmind-mind-map-viewer.
  2. Fai clic sul file .xmind nell’Explorer. Si aprono i file di XMind 2020 e successivi, XMind Zen e XMind 8. Ogni foglio della mappa è una scheda in alto.
  3. Sfoglia i fogli. Ognuno si apre nel layout salvato nel file. Trascina per spostarti, usa Ctrl o Cmd + rotella per lo zoom e premi F per adattare il foglio alla finestra.
  4. Apri il menu "Export…" nella barra sopra la mappa e scegli "PDF, every sheet (Zovo Pro)". Con la mappa aperta puoi anche eseguire "XMind Viewer: Export every sheet as PDF (Zovo Pro)" dalla Command Palette.
  5. Scegli il nome del file nella finestra di salvataggio e fai clic su "Export PDF". Un messaggio indica quante pagine sono state salvate, con un pulsante "Show in folder". Il file della mappa non viene mai modificato.
  6. Per un’immagine gratuita di un foglio, scegli "PNG picture" o "SVG picture" nello stesso menu Export.

Cosa è gratis e cosa aggiunge Zovo Pro

Aprire file .xmind, .mm e .opml è gratis, con tutti i fogli, tutti i layout, la chiusura dei rami, i livelli, la ricerca e il pannello dei dettagli. Sono gratis anche l’export in PNG (fino a 2x) e SVG, il foglio come struttura Markdown negli appunti e tutti i fogli in un unico file Markdown.

PDF of every sheet salva tutti i fogli della mappa in un unico file PDF, una pagina per foglio, nei colori di stampa, con un segnalibro per ogni foglio. Ottieni l’intera mappa in un solo passaggio, invece di esportare ogni foglio come immagine e unire le immagini a mano. In XMind stesso l’export PDF richiede XMind Pro, un piano a pagamento di XMind.

Usare PDF of every sheet (Zovo Pro)

  1. Con la mappa aperta, scegli "PDF, every sheet (Zovo Pro)" nel menu "Export…", fai clic su "PDF of every sheet" nella piccola riga Zovo Pro della barra degli strumenti, oppure esegui "XMind Viewer: Export every sheet as PDF (Zovo Pro)" dalla Command Palette.
  2. Dall’Explorer, fai clic destro su un file .xmind, .mm o .opml e scegli "Zovo Pro: PDF of every sheet".
  3. Scegli dove salvare il PDF e fai clic su "Export PDF". Una prova viene contata solo quando un file viene salvato, quindi Cancel non consuma nulla.
  4. Dopo le 3 prove gratuite, lo strumento mostra i modi per ottenere Zovo Pro.

PDF of every sheet funziona 3 volte sul tuo computer prima di chiedere una licenza. Non ci sono finestre a comparsa né conti alla rovescia.

Passaggi in Cursor, Windsurf o VSCodium

  1. Apri la vista Extensions con Ctrl+Maiusc+X (Cmd+Maiusc+X su macOS).
  2. Cerca zovo.xmind-mind-map-viewer e fai clic su Install. Cursor, Windsurf e VSCodium installano le estensioni da Open VSX, dove questa si chiama zovo/xmind-mind-map-viewer.
  3. Se il tuo editor non ha una galleria, scarica il file .vsix dalla pagina di Open VSX ed esegui "Extensions: Install from VSIX...".
  4. Da lì in poi funziona tutto come in VS Code.

Cosa fa XMind Viewer

  • File .xmind di XMind dalla versione 2020 alla 2026 e di XMind Zen (content.json), e di XMind 8, XMind 7 e delle vecchie versioni 3.x (content.xml).
  • Ogni foglio come scheda, con relazioni, boundary, summary, marker, etichette, note, immagini contenute nel file ed equazioni LaTeX disegnate con KaTeX.
  • File .mm di FreeMind e Freeplane e strutture .opml. PDF of every sheet funziona anche con questi file.
  • Titoli in cinese, giapponese, coreano e con emoji, con i titoli lunghi che vanno a capo.
  • Mappe grandi. Nel test del README un file .xmind da 30 MB con 10.111 topic e 60 immagini si è aperto in 0,65 secondi.

Cosa non fa

  • È in sola lettura. Per modificare una mappa, aprila in XMind, Freeplane o un altro editor di mappe mentali.
  • Le mappe protette da password non si aprono, perché XMind ne cifra il contenuto. Compare un messaggio che lo spiega.
  • I fogli fishbone, timeline, matrix e brace vengono disegnati come diagrammi logici o org chart. Le posizioni dei topic trascinate a mano in XMind non vengono mantenute, e gli stili dei temi XMind (font, forme delle linee, forme dei topic) non vengono copiati. I colori di riempimento e del testo dei topic invece sì.
  • Ogni pagina del PDF è un’immagine del foglio, quindi il testo del PDF non si può selezionare né cercare.
  • I file più grandi di 1 GB (impostazione xmindViewer.maxFileMB) mostrano un messaggio invece di aprirsi.

Domande frequenti

È gratis?

La visualizzazione delle mappe e l’export in PNG, SVG e Markdown sono gratis. PDF of every sheet, l’export CSV (Excel) e OPML e Convert a folder sono strumenti Zovo Pro. Ogni strumento Pro si può provare gratis 3 volte sul tuo computer, poi Zovo Pro costa 19 USD una volta sola per tutte le estensioni Zovo.

Devo avere XMind installato?

No. L’estensione legge da sola il file .xmind, funziona offline e non fa richieste di rete.

Posso convertire in PDF un’intera cartella di mappe?

No. Convert a folder scrive file Markdown, CSV o OPML. Il PDF si crea una mappa alla volta.

Funziona in Cursor?

Sì. L’estensione è anche su Open VSX, quindi si installa in Cursor, Windsurf, VSCodium e altri editor basati su VS Code.
