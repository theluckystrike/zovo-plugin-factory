Formattare XML in VS Code ed eseguire XPath

Installa l'estensione gratuita XML Formatter & XPath Tools, apri un file XML e premi Shift+Alt+F (Shift+Option+F su Mac). Cambiano solo gli spazi tra i tag. Testo, CDATA, commenti, xml:space="preserve" e valori degli attributi restano identici byte per byte, e un file non ben formato non viene mai modificato. Formattazione, Minify XML, XPath 1.0 con i prefissi di namespace del file, Copy XPath e la vista XML Tree sono gratuiti e funzionano offline. Zovo Pro (19 USD una tantum) aggiunge tre strumenti, Run XPath on Every XML File in a Folder, Format All XML Files in a Folder e Compare Two XML Files Ignoring Formatting, e ognuno ha 3 tentativi gratuiti.

Passaggi in VS Code

  1. Installa XML Formatter & XPath Tools dal Marketplace, oppure premi Ctrl+P (Cmd+P su macOS) ed esegui ext install zovo.zovo-xml-xpath-tools.
  2. Apri un file .xml e premi Shift+Alt+F (Shift+Option+F su Mac), oppure esegui Format Document. Se hai più di un formatter XML, VS Code chiede quale usare. Funziona anche Format Selection.
  3. Il formatter usa la tua dimensione di tabulazione e la tua scelta tra tabulazioni e spazi, e mantiene i fine riga, il byte order mark e il ritorno a capo finale. Se il file non è ben formato, non cambia nulla e ricevi l'errore con riga e colonna.
  4. Per rendere invece il file più piccolo, esegui "XML: Minify XML" sull'intero file o su una selezione. I commenti restano, a meno che tu non attivi xmlXpathTools.minify.removeComments.
  5. Per eseguire un XPath, fai clic sul pulsante di ricerca nel titolo dell'editor o esegui "XML: Evaluate XPath…". I risultati compaiono in XPath Results con la loro riga. Fai clic su un risultato per selezionarlo nell'editor.
  6. Fai clic sull'XPath nella barra di stato per copiare il percorso dell'elemento sotto il cursore, con le posizioni, con gli attributi id o name o in una forma portabile con local-name().
  7. Per un file oltre 50 MB, fai clic destro sul file nell'Explorer e scegli "Format Large XML File on Disk…". Scrive name.formatted.xml accanto al file, oppure sostituisce il file dopo la tua conferma.

Cosa è gratis e cosa aggiunge Zovo Pro

Format Document, Format Selection, Minify XML, XPath 1.0, Copy XPath, la vista XML Tree, gli errori di buona formazione in Problems e Format Large XML File on Disk sono gratuiti. Non serve un login, e l'estensione non contiene codice di rete.

Run XPath on Every XML File in a Folder esegue un XPath su ogni file .xml, .xsd, .csproj, .svg, .kml e simili in una cartella e nelle sue sottocartelle, ciascuno con i propri prefissi di namespace. I risultati si aprono come CSV (file, line, kind, name, value) per un foglio di calcolo, come JSON per uno script o come report Markdown per una revisione. Ottieni lo stesso valore da molti file, come ogni artifactId in un insieme di file pom.xml, senza aprirli uno per uno.

Usare Run XPath on Every XML File in a Folder (Zovo Pro)

  1. Fai clic destro su una cartella nell'Explorer e scegli "Zovo Pro: Run XPath on Every XML File in a Folder", oppure esegui "XML: Run XPath on Every XML File in a Folder (Pro)" dalla Command Palette e scegli la cartella.
  2. In alternativa, dopo aver eseguito un XPath in un file, fai clic sull'ultima riga di XPath Results, "Run this XPath on every XML file in a folder", per eseguire la stessa espressione su una cartella.
  3. Scrivi l'XPath. Una notifica mostra l'avanzamento con un pulsante Cancel.
  4. Scegli "Open as CSV", "Open as JSON" o "Open a Markdown report". I risultati si aprono in una nuova scheda dell'editor. Un tentativo conta solo quando ottieni un risultato. Escape, un errore di battitura nell'XPath o una cartella senza file XML non ne consumano.

Passaggi in Cursor, Windsurf o VSCodium

  1. Apri la vista Extensions con Ctrl+Maiusc+X (Cmd+Maiusc+X su macOS).
  2. Cerca zovo.zovo-xml-xpath-tools e fai clic su Install. Cursor, Windsurf e VSCodium installano le estensioni da Open VSX, dove questa si chiama zovo/zovo-xml-xpath-tools.
  3. Se il tuo editor non ha una galleria, scarica il file .vsix dalla pagina di Open VSX ed esegui "Extensions: Install from VSIX...".
  4. Da lì in poi funziona tutto come in VS Code.

Cosa fa XML Formatter & XPath Tools

  • I file che VS Code apre come XML. L'estensione apre come XML anche i file .kml, .gpx, .rss, .atom, .wsdl, .dbk, .xlf, .xliff, .resx, .nuspec, .props, .targets e .xaml.
  • File grandi, perché formattazione, albero e XPath girano in un thread in background. Nei test dell'estensione un file da 49 MB con circa 1 milione di elementi è stato formattato in 1,6 secondi.
  • I nomi semplici trovano anche un namespace predefinito, quindi //dependency/artifactId funziona in un pom.xml. Per XPath 1.0 rigoroso attiva xmlXpathTools.xpath.strictNamespaces.
  • Disposizione degli attributi come scritti, su una sola riga o uno per riga (impostazione xmlXpathTools.format.attributes).
  • La vista XML Tree nell'Explorer segue il cursore, e Problems elenca gli errori di buona formazione con riga e colonna.

Cosa non fa

  • Solo XPath 1.0. Non ci sono XPath 2.0 o 3.1, XQuery o XSLT.
  • Controlla che un file sia ben formato. Non lo convalida rispetto a un XSD o a una DTD.
  • I file oltre 50 MB si possono formattare su disco, ma VS Code non li passa alle estensioni, quindi albero e XPath non funzionano su di essi.
  • Il comando su disco legge UTF-8, UTF-16 con byte order mark e ISO-8859-1.
  • Un elemento che contiene testo, come <p>Some <b>bold</b> text</p>, resta sulla sua riga così com'è scritto. Solo gli elementi che contengono tag e nessun testo ricevono nuovi a capo.

Domande frequenti

È gratuito?

Formattazione, Minify XML, XPath, Copy XPath, la vista XML Tree e il controllo di buona formazione sono gratuiti. I tre strumenti Pro, Run XPath on Every XML File in a Folder, Format All XML Files in a Folder e Compare Two XML Files Ignoring Formatting, hanno 3 tentativi gratuiti ciascuno. Dopo richiedono Zovo Pro, 19 USD una tantum per tutte le estensioni Zovo.

La formattazione cambia il mio testo o le sezioni CDATA?

No. Cambiano solo gli spazi tra i tag, negli elementi che contengono tag e nessun testo. Testo, CDATA, commenti e contenuto dentro xml:space="preserve" vengono copiati così come sono, e una seconda formattazione non cambia nulla.

Perché il mio XPath non seleziona nulla in un pom.xml?

Il file ha un namespace predefinito. In questa estensione i nomi semplici trovano anche un namespace predefinito, quindi //dependency funziona. Per XPath 1.0 rigoroso attiva xmlXpathTools.xpath.strictNamespaces.

Funziona in Cursor?

Sì. Cursor, Windsurf e VSCodium lo installano da Open VSX, dove è pubblicato come zovo/zovo-xml-xpath-tools.
