Normalizzare il loudness audio a un valore LUFS

Installa Audio Player & WAV Player (Audio Preview & Loudness Meter). Riproduce file WAV, MP3, FLAC, Ogg e Opus in VS Code con forma d’onda, spettrogramma e un misuratore di loudness gratuito (LUFS integrated, short-term e momentary, ITU-R BS.1770-4). Lo strumento Zovo Pro Normalize Loudness scrive accanto all’originale un nuovo WAV a -14, -16, -23 LUFS o a un valore scelto da te. Normalize Loudness e Folder Loudness Report si possono provare gratis 3 volte ciascuno, poi Zovo Pro costa 19 USD una volta sola.

Passaggi in VS Code

  1. Installa Audio Player & WAV Player dal Marketplace, oppure premi Ctrl+P (Cmd+P su macOS) ed esegui ext install zovo.audio-preview-vscode.
  2. Fai clic su un file .wav, .mp3, .flac, .ogg o .opus nell’Explorer. Si apre in Audio Preview. Se si apre un altro visualizzatore, fai clic destro sul file e scegli "Open in Audio Preview".
  3. Premi Spazio per riprodurre. Trascina sulla forma d’onda per ripetere in loop una parte, oppure imposta il loop con [ e ].
  4. Leggi il pannello Loudness, con LUFS integrated, short-term max e momentary max, sample peak, RMS e campioni in clipping per canale. Copy stats li copia negli appunti.
  5. Per cambiare il loudness, esegui Normalize Loudness (uno strumento Zovo Pro, vedi sotto).

Cosa è gratis e cosa aggiunge Zovo Pro

Sono gratis la riproduzione, la velocità da 0.25x a 2x con l’intonazione invariata, il loop A-B, la forma d’onda, lo spettrogramma, il misuratore di loudness, i pannelli File e Tags e Copy stats.

Normalize Loudness scrive accanto all’originale un nuovo file WAV, come mix-14LUFS.wav, a -14 LUFS (Spotify, YouTube), -16 (Apple Music, podcast), -23 (EBU R128) o a un valore scelto da te. L’originale non viene mai modificato. Se il guadagno porterebbe il sample peak sopra -1 dBFS, il guadagno viene ridotto e il messaggio lo dice, quindi non ti serve un secondo strumento per controllare il picco.

Usare Normalize Loudness (Zovo Pro)

  1. Apri il file audio ed esegui Normalize Loudness dalla barra del titolo dell’editor, oppure fai clic destro sul file nell’Explorer. Dalla Command Palette esegui "Audio Preview: Normalize Loudness to -14 / -16 / -23 LUFS (Pro)".
  2. Scegli -14 LUFS, -16 LUFS, -23 LUFS o "Other target..." (un numero da -40 a -5).
  3. Il nuovo WAV viene scritto accanto all’originale, e un messaggio mostra il loudness prima e dopo, il guadagno e il picco. Una prova viene contata solo quando il file viene scritto.

Normalize Loudness funziona 3 volte sul tuo computer prima di chiedere una licenza. Non ci sono finestre a comparsa né conti alla rovescia.

Passaggi in Cursor, Windsurf o VSCodium

  1. Apri la vista Extensions con Ctrl+Maiusc+X (Cmd+Maiusc+X su macOS).
  2. Cerca zovo.audio-preview-vscode e fai clic su Install. Cursor, Windsurf e VSCodium installano le estensioni da Open VSX, dove questa si chiama zovo/audio-preview-vscode.
  3. Se il tuo editor non ha una galleria, scarica il file .vsix dalla pagina di Open VSX ed esegui "Extensions: Install from VSIX...".
  4. Da lì in poi funziona tutto come in VS Code.

Cosa fa Audio Player & WAV Player

  • WAV (.wav, .wave) PCM da 8 a 32 bit, float a 32 e 64 bit, A-law, mu-law e RF64, letto a blocchi.
  • FLAC, MP3, Ogg Vorbis (.ogg, .oga) e Opus (.opus, con un decoder WebAssembly incluso).
  • LUFS integrated, short-term e momentary, sample peak, RMS, offset DC e campioni in clipping per canale.
  • Fino a 8 tracce di forma d’onda e uno spettrogramma su asse di frequenza logaritmico.
  • Tag da ID3v1, ID3v2, RIFF INFO, commenti Vorbis e atomi iTunes.

Cosa non fa

  • Normalize Loudness legge file WAV. Per MP3, FLAC, Ogg, Opus o M4A serve il tuo ffmpeg (impostazione audioPreview.ffmpegPath) in un workspace attendibile, e il risultato è un WAV a 16 bit.
  • Il risultato è sempre un file WAV, non MP3 o FLAC.
  • Il picco è un sample peak, non un true peak con sovracampionamento, e non c’è ancora il loudness range (LRA).
  • I file .m4a e .aac mostrano solo intestazione e tag se non hai ffmpeg. L’estensione non include né scarica nulla.
  • I file compressi vengono decodificati per intero. Oltre 600 MB di campioni decodificati (audioPreview.maxDecodedMB) si possono solo ascoltare.

Domande frequenti

È gratis?

Riproduzione audio, forma d’onda, spettrogramma e misuratore di loudness sono gratis. Normalize Loudness e Folder Loudness Report sono strumenti Pro con 3 prove gratuite ciascuno. Dopo serve Zovo Pro, 19 USD una volta sola per tutte le estensioni Zovo.

Modifica il mio file originale?

No. Normalize Loudness scrive un nuovo WAV accanto all’originale, che non viene mai modificato.

Quanto è preciso il misuratore LUFS?

Segue ITU-R BS.1770-4 e sui file di test dell’estensione ha dato gli stessi valori del filtro ebur128 di ffmpeg entro 0,1 LU.

Posso normalizzare un MP3?

Solo se ffmpeg è installato e viene trovato tramite audioPreview.ffmpegPath. Il risultato è un WAV a 16 bit, non un MP3.
