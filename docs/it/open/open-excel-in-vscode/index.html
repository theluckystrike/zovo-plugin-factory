Guide in italiano · Table Viewer

Aprire Excel e CSV in VS Code come tabella

VS Code apre un .xlsx come file binario e un CSV come testo semplice. L'estensione gratuita Table Viewer mostra cartelle di lavoro Excel, CSV e file Parquet come una tabella da ordinare, filtrare e cercare, fino a 1.000.000 di righe, con i formati numerici di Excel e le formule. Il pulsante Query esegue SQL con GROUP BY sul file. Senza Excel, senza Python e senza far passare i dati in rete.

I passaggi in VS Code

  1. Installa l'estensione Table Viewer dal Marketplace, oppure premi Ctrl+P (Cmd+P su macOS) ed esegui ext install zovo.table-viewer-vscode.
  2. Fai clic su un file .xlsx, .xlsm, .xlsb, .xls, .ods o .parquet nell'Explorer. Si apre come tabella. Una cartella di lavoro con più fogli mostra un selettore.
  3. Un .csv o un .tsv si apre ancora come testo. Fai clic sull'icona della tabella in alto a destra nell'editor, oppure fai clic destro sul file e scegli "Open in Table Viewer".
  4. Fai clic sull'intestazione di una colonna per ordinare. Scrivi nella casella sotto l'intestazione per filtrare: >10, 5..9 o una parte di testo. La ricerca in alto guarda in tutte le colonne.
  5. Fai clic su Query, scrivi una SELECT e premi Ctrl+Invio (Cmd+Invio su macOS). FROM this è il file aperto, e una JOIN con un altro foglio della stessa cartella di lavoro è gratuita.
  6. Copy CSV, Copy JSON e Copy Markdown copiano la selezione. Export salva le righe filtrate in CSV, TSV, JSON o JSON Lines.

Cosa è gratis e cosa aggiunge Zovo Pro

Aprire CSV, TSV, Excel e Parquet, i fogli, le formule, ordinare, filtrare, cercare, le statistiche delle colonne, il filtro SQL, le query SQL sulle righe della tabella, la JOIN tra fogli dello stesso file, il confronto con Git e l'esportazione in CSV, TSV e JSON sono gratuiti.

Quando i dati arrivano in tanti file, uno al mese o uno per filiale, Combine Files and Sheets unisce più CSV, TSV, Excel, ODS e Parquet, un'intera cartella o tutti i fogli di una cartella di lavoro in un solo file CSV, XLSX o Parquet. Le colonne vengono abbinate per nome dell'intestazione, e le colonne source_file e source_sheet dicono da dove viene ogni riga. Zovo Pro esegue anche le query sull'intero file quando la tabella ne contiene solo l'inizio (un GROUP BY su un CSV di diversi GB), fa JOIN con altri file e salva in Parquet.

Con Combine Files and Sheets (Zovo Pro)

  1. Nell'Explorer fai clic destro su una cartella, su più file di tabella selezionati o su una cartella di lavoro e scegli Combine Files and Sheets. Il pulsante Combine nella barra e "Excel Viewer Pro: Combine Files and Sheets (Pro)..." nella Command Palette fanno lo stesso.
  2. Scegli il formato di uscita (CSV, XLSX o Parquet) e dove salvarlo.
  3. I file che non si possono leggere vengono saltati ed elencati nel riepilogo. I file di origine non cambiano.

Combine Files and Sheets funziona 3 volte sul tuo computer prima di chiedere una licenza, e un tentativo conta solo quando ottieni un risultato. Quando apri un file non compare niente che riguardi Pro.

In Cursor, Windsurf o VSCodium

Questi editor installano le estensioni da Open VSX. Apri la vista Extensions (Ctrl+Shift+X, o Cmd+Shift+X su macOS), cerca zovo.table-viewer-vscode e fai clic su Install. Poi funziona come in VS Code.

Cosa non fa

  • L'estensione legge e basta. Non modifica e non salva la cartella di lavoro.
  • Di norma carica fino a 1.000.000 di righe per file (impostazione tableViewer.maxRows).
  • I file .xls, .xlsb e .ods oltre 50 MB non vengono caricati.
  • Una query su un intero CSV più grande della tabella, la JOIN con altri file e il salvataggio in Parquet fanno parte di Zovo Pro, con 3 utilizzi gratuiti ciascuno.

Domande

Servono Excel o Python?

No. L'estensione è JavaScript che funziona offline, senza kernel Python e senza account.

L'SQL è a pagamento?

No. Le query sulle righe della tabella, il filtro SQL e la JOIN tra fogli dello stesso file sono gratuiti. Leggere un intero file grande e fare JOIN con altri file fanno parte di Zovo Pro, con 3 utilizzi gratuiti.

La tabella si aggiorna quando il file cambia?

Sì. Quando uno script o un git pull riscrive il file, la tabella si ricarica in circa mezzo secondo e mantiene ordinamento e filtri.
