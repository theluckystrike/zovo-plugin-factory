Formattare uno script bash o zsh in VS Code

Installa l'estensione gratuita Shell Formatter for Bash & Zsh, apri uno script di shell e premi Shift+Alt+F (Shift+Option+F su Mac). Il motore shfmt 3.14.1 è incluso nell'estensione come WebAssembly, quindi non c'è nulla da scaricare, e il risultato è identico byte per byte a quello di shfmt da riga di comando. Format Document, Format Selection, la formattazione al salvataggio, le chiavi di .editorconfig e gli errori di sintassi in Problems sono gratuiti e funzionano offline. Zovo Pro (19 USD una tantum) aggiunge tre strumenti, Format All Shell Scripts in a Folder, Formatting Check with a Patch File e Minify a Script to a Copy, e ognuno ha 3 tentativi gratuiti.

Passaggi in VS Code

  1. Installa Shell Formatter for Bash & Zsh dal Marketplace, oppure premi Ctrl+P (Cmd+P su macOS) ed esegui ext install zovo.zovo-shell-formatter.
  2. Apri uno script di shell e premi Shift+Alt+F (Shift+Option+F su Mac). Se VS Code chiede quale formatter usare, scegli Shell Formatter, oppure esegui "Shell Formatter: Use as Default Formatter for Shell Scripts".
  3. Per formattare a ogni salvataggio, esegui "Shell Formatter: Turn On Format on Save for Shell Scripts".
  4. Il dialetto viene dalla prima riga (#!/bin/bash, #!/bin/sh, #!/usr/bin/env zsh), poi dal nome del file (.bash, .zsh, .zshrc, .bats, .ksh), altrimenti è bash. Per sceglierlo tu, imposta shellFormatter.dialect o shell_variant in .editorconfig.
  5. Fai clic su shfmt 3.14.1 nella barra di stato per aprire il menu, con formattazione, formatter predefinito, formattazione al salvataggio, "Copy the matching shfmt command (for CI)" e impostazioni.
  6. Se lo script non è shell valido, resta invariato e il pannello Problems mostra riga e colonna dell'errore.

Cosa è gratis e cosa aggiunge Zovo Pro

Format Document, Format Selection, la formattazione al salvataggio, il riconoscimento del dialetto, le chiavi di .editorconfig, il menu nella barra di stato, Copy the Matching shfmt Command (for CI) e gli errori di sintassi in Problems sono gratuiti. Non serve un login, e non ci sono richieste di rete né telemetria.

Format All Shell Scripts in a Folder controlla ogni script di una cartella e delle sue sottocartelle, riconosciuto dal nome o da una riga #! che indica una shell, e dice quanti cambierebbero. Poi li formatta tutti o produce un report Markdown, con lo stesso motore, le stesse impostazioni e lo stesso .editorconfig di Format Document. Un repository con decine di script in stili diversi passa a un unico stile in un'unica esecuzione, e gli script che non eseguirebbero più gli stessi comandi restano come sono.

Usare Format All Shell Scripts in a Folder (Zovo Pro)

  1. Fai clic destro su una cartella nell'Explorer e scegli "Zovo Pro: Format All Shell Scripts in a Folder", oppure esegui "Shell Formatter: Format All Shell Scripts in a Folder (Pro)" dalla Command Palette o dal menu della barra di stato e scegli la cartella.
  2. Il titolo dell'elenco successivo indica quanti script cambierebbero, per esempio "N of M scripts would change".
  3. Scegli "Format N scripts" per formattare e salvare ogni file (Undo funziona per singolo file), oppure "Show the report only" per un elenco Markdown di tutti gli script senza modificare nulla.
  4. Un tentativo conta solo quando ottieni un risultato. Una cartella senza script di shell, o con tutti gli script già formattati, non ne consuma.

Format All Shell Scripts in a Folder funziona 3 volte sul tuo computer prima di chiedere una licenza. Non ci sono finestre a comparsa né conti alla rovescia.

Passaggi in Cursor, Windsurf o VSCodium

  1. Apri la vista Extensions con Ctrl+Maiusc+X (Cmd+Maiusc+X su macOS).
  2. Cerca zovo.zovo-shell-formatter e fai clic su Install. Cursor, Windsurf e VSCodium installano le estensioni da Open VSX, dove questa si chiama zovo/zovo-shell-formatter.
  3. Se il tuo editor non ha una galleria, scarica il file .vsix dalla pagina di Open VSX ed esegui "Extensions: Install from VSIX...".
  4. Da lì in poi funziona tutto come in VS Code.

Cosa fa Shell Formatter for Bash & Zsh

  • Script bash, POSIX sh (anche dash e ash), mksh (anche ksh), bats e zsh.
  • Lo stesso risultato di shfmt 3.14.1 da riga di comando. In 354 esecuzioni su 354, su 178 script reali di progetti GitHub e di Homebrew, l'output è risultato identico byte per byte.
  • Prima di applicare una modifica, lo script formattato viene analizzato di nuovo e deve eseguire gli stessi comandi dell'originale (file fino a 256 KB).
  • Le opzioni di shfmt come impostazioni o chiavi di .editorconfig: indentazione, operatori binari all'inizio della riga successiva, indentazione dei case negli switch, spazi nei redirect, mantenimento del padding, graffe delle funzioni sulla riga successiva, simplify e minify.
  • I fine riga Windows (CRLF) restano CRLF, e uno script da 2 MB si formatta in circa 0,2 secondi.

Cosa non fa

  • Non tocca mai Dockerfile, file .env, script fish o csh.
  • Il supporto di zsh in shfmt è recente. Uno script zsh che shfmt non riesce ad analizzare resta invariato.
  • I file oltre 10 MB (impostazione shellFormatter.maxFileMB) e i file con byte binari, come gli installer autoestraenti, non vengono formattati.
  • shfmt gira con un limite di tempo (10 secondi di default, impostazione shellFormatter.timeoutSeconds). Se viene raggiunto, il file resta invariato.

Domande frequenti

È gratuito?

Format Document, Format Selection, la formattazione al salvataggio e il supporto di .editorconfig sono gratuiti. I tre strumenti Pro, Format All Shell Scripts in a Folder, Formatting Check with a Patch File e Minify a Script to a Copy, hanno 3 tentativi gratuiti ciascuno. Dopo richiedono Zovo Pro, 19 USD una tantum per tutte le estensioni Zovo.

Devo installare shfmt?

No. shfmt 3.14.1 è incluso nell'estensione come WebAssembly, quindi funziona offline senza scaricare nulla.

Può rovinare il mio script?

Uno script con un errore di sintassi resta invariato. Prima di applicare una modifica, lo script formattato viene analizzato di nuovo e deve eseguire gli stessi comandi dell'originale.

Funziona in Cursor?

Sì. Cursor, Windsurf e VSCodium lo installano da Open VSX, dove è pubblicato come zovo/zovo-shell-formatter.
