Convertire TTF in WOFF2 in VS Code

Installa Font Viewer (visualizzatore TTF, OTF e WOFF). Apre i font .ttf, .otf, .woff, .woff2, .ttc e .otc con un type tester, una griglia dei glifi, una mappa dei caratteri e una scheda Info con la licenza, tutto gratis. Lo strumento Zovo Pro Convert Font scrive un WOFF2 (o WOFF) accanto a un TTF o OTF, e può riportare un WOFF2 a un TTF/OTF installabile. Convert Font e Font Folder Report si possono provare gratis 3 volte ciascuno, poi Zovo Pro costa 19 USD una volta sola.

Passaggi in VS Code

  1. Installa Font Viewer dal Marketplace, oppure premi Ctrl+P (Cmd+P su macOS) ed esegui ext install zovo.font-viewer-vscode.
  2. Fai clic su un file .ttf o .otf nell’Explorer. Si apre in Font Viewer, che è in sola lettura e non modifica mai il font. Se si apre un altro editor, fai clic destro sul file e scegli "Open in Font Viewer".
  3. Nella scheda Type tester scrivi un testo di prova, trascina lo slider della dimensione e muovi gli slider degli assi variabili. Attiva e disattiva le feature OpenType.
  4. Apri la scheda Info per controllare licenza, designer e diritti di embedding prima di usare il font su un sito web.
  5. Fai clic su Copy CSS nel Type tester per ottenere la regola @font-face, oppure fai clic destro sul font nell’Explorer e scegli "Copy CSS @font-face".
  6. Per creare il file WOFF2, esegui Convert Font (uno strumento Zovo Pro, vedi sotto).

Cosa è gratis e cosa aggiunge Zovo Pro

Sono gratis l’apertura dei font TTF, OTF, WOFF, WOFF2, TTC e OTC, il type tester con assi variabili e feature OpenType, la griglia dei glifi, la mappa dei caratteri, la scheda Info con la licenza e Copy CSS @font-face.

Convert Font trasforma un TTF o un OTF in WOFF2 o WOFF per un sito web, oppure un WOFF2 di nuovo in un TTF/OTF installabile. Lavora su un font o su un’intera cartella, scrive i nuovi file accanto ai sorgenti e per un TTC crea un file per ogni font della collezione. I dati delle tabelle vengono copiati così come sono, quindi contorni, hinting, assi variabili e feature non cambiano.

Usare Convert Font (Zovo Pro)

  1. Fai clic sul pulsante Convert Font nella barra del titolo della scheda del font, oppure fai clic destro su un file di font o su una cartella nell’Explorer e scegli "Convert Font to WOFF2, WOFF or TTF… (Pro)".
  2. Dalla Command Palette esegui "Font Viewer: Convert Font to WOFF2, WOFF or TTF… (Pro)" e scegli un font o una cartella.
  3. Scegli WOFF2. Il nuovo file .woff2 viene scritto accanto al sorgente, che resta com’è.
  4. Una prova viene contata solo quando i file sono stati scritti.

Convert Font funziona 3 volte sul tuo computer prima di chiedere una licenza. Non ci sono finestre a comparsa né conti alla rovescia.

Passaggi in Cursor, Windsurf o VSCodium

  1. Apri la vista Extensions con Ctrl+Maiusc+X (Cmd+Maiusc+X su macOS).
  2. Cerca zovo.font-viewer-vscode e fai clic su Install. Cursor, Windsurf e VSCodium installano le estensioni da Open VSX, dove questa si chiama zovo/font-viewer-vscode.
  3. Se il tuo editor non ha una galleria, scarica il file .vsix dalla pagina di Open VSX ed esegui "Extensions: Install from VSIX...".
  4. Da lì in poi funziona tutto come in VS Code.

Cosa fa Font Viewer

  • TrueType .ttf, anche variabili, e OpenType .otf con contorni CFF.
  • Font WOFF .woff e WOFF2 .woff2.
  • Collezioni .ttc e .otc, dove scegli il font da un elenco nell’intestazione.
  • Ogni glifo con nome e code point, ricerca per nome, carattere, U+20AC o glyph id, e copia del contorno come SVG.
  • Copertura per blocco Unicode, tabella dei nomi completa, metriche, assi e tag delle feature GSUB e GPOS.

Cosa non fa

  • Collezioni WOFF2, font SVG, .dfont e font Type 1 non sono supportati.
  • I file oltre 64 MB (impostazione fontViewer.maxFileMB) mostrano un messaggio invece di aprirsi.
  • I contorni dei glifi mostrano l’istanza predefinita di un font variabile. Type tester, waterfall e mappa dei caratteri seguono gli slider degli assi.
  • I font a colori sono disegnati a colori nel type tester e nella mappa dei caratteri, ma la griglia dei glifi mostra contorni semplici. Nella griglia dei glifi i font variabili CFF2 sono disegnati con il font, non dai contorni.
  • Convert Font copia i dati delle tabelle così come sono. Gli strumenti che riscrivono anche i dati dei glifi producono file WOFF2 più piccoli di qualche punto percentuale.

Domande frequenti

È gratis?

La visualizzazione dei font è gratis, con type tester, glifi, mappa dei caratteri, scheda Info e Copy CSS @font-face. Convert Font e Font Folder Report sono strumenti Pro con 3 prove gratuite ciascuno. Dopo serve Zovo Pro, 19 USD una volta sola per tutte le estensioni Zovo.

Quanto è più piccolo un WOFF2?

Nel test del README un WOFF2 era circa il 45 percento della dimensione del TTF (JetBrains Mono variabile, da 96.940 a 43.632 byte).

La conversione modifica il font?

No. I dati delle tabelle vengono copiati così come sono, quindi contorni, hinting, assi variabili e feature restano uguali. Il file sorgente non viene modificato.

I miei font vengono caricati online?

No. Font Viewer funziona offline, non fa chiamate di rete e non invia telemetria.
