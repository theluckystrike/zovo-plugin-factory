Sfogliare i bucket AWS S3, Cloudflare R2 o MinIO in VS Code

Installa l'estensione gratuita S3 Explorer e apri la sua vista S3 Buckets nella Activity Bar. Funziona con AWS S3 (profili da ~/.aws, anche profili SSO), Cloudflare R2, MinIO, Backblaze B2, Wasabi e DigitalOcean Spaces. Navigazione, apertura degli oggetti in sola lettura, upload, download, copia, spostamento, rinomina, eliminazione, versioni, tag, presigned URL e sincronizzazione delle cartelle sono gratuiti, senza login e senza telemetria. Zovo Pro (19 USD una tantum) aggiunge tre strumenti, Copy to Another Connection, Size and Cost Report e Scheduled Sync, e ognuno ha 3 tentativi gratuiti.

Passaggi in VS Code

  1. Installa S3 Explorer dal Marketplace, oppure premi Ctrl+P (Cmd+P su macOS) ed esegui ext install zovo.zovo-s3-explorer.
  2. Apri la vista S3 Explorer nella Activity Bar e fai clic su Add Connection. Scegli un profilo AWS da ~/.aws, oppure inserisci una access key, un account ID e un token R2, o l'URL dell'endpoint di MinIO o di un altro servizio compatibile con S3. Le chiavi che inserisci vanno nel portachiavi del sistema operativo.
  3. Espandi una connessione per vedere i suoi bucket. Le chiavi si caricano 1.000 alla volta, con una riga "Load 1,000 more". Se la tua chiave non può elencare i bucket, fai clic destro sulla connessione e scegli Add Bucket by Name.
  4. Fai clic su un oggetto per aprirlo in sola lettura in una scheda o nel visualizzatore adatto. Per vederne metadati, tag, versioni e un presigned URL, fai clic destro sull'oggetto e scegli Show Details, Versions and Presigned URL.
  5. Per modificare un oggetto, fai clic destro e scegli Edit and Upload. Modifichi una copia, e prima che l'oggetto venga sostituito una finestra di dialogo mostra il bucket, la chiave ed entrambe le dimensioni.
  6. Trascina file o cartelle dall'Explorer su un bucket per caricarli, oppure fai clic destro e scegli Download. I file da 16 MB in su vengono caricati in parti con avanzamento e Cancel, e un upload interrotto riprende inviando solo le parti mancanti.
  7. Per mantenere uguali una cartella locale e un prefisso, fai clic destro sul bucket o sulla cartella e scegli Sync Folder. Prima che cambi qualcosa vedi un piano di prova (dry-run) con i file nuovi, modificati e da eliminare.

Cosa è gratis e cosa aggiunge Zovo Pro

Navigazione, apertura, Edit and Upload, upload, download, copia, spostamento, rinomina, eliminazione, versioni, tag, presigned URL e sincronizzazione delle cartelle sono gratuiti, senza login, senza account e senza telemetria. L'estensione si collega solo agli endpoint di storage che aggiungi.

Copy to Another Connection copia oggetti o intere cartelle da una connessione a un'altra, per esempio da AWS S3 a Cloudflare R2 o MinIO, con la stessa conferma di ogni copia: le chiavi vengono elencate e quelle che verrebbero sostituite sono indicate per nome. Gli oggetti grandi passano per un upload multipart. Sposti i dati tra provider o account direttamente dall'albero, senza uno script o un secondo strumento.

Usare Copy to Another Connection (Zovo Pro)

  1. Aggiungi prima la seconda connessione. Poi fai clic destro su un oggetto o una cartella nella vista S3 Buckets e scegli "Copy to Another Connection... (Pro)", oppure fai clic su Copy to Another Connection nella riga "Zovo Pro tools" in fondo alla vista.
  2. Scegli la connessione di destinazione, il bucket e la cartella di destinazione (vuota per il livello principale).
  3. Leggi l'elenco degli oggetti nella conferma e fai clic su Copy, oppure su Copy and Replace se alcune chiavi esistono già. Una notifica mostra l'avanzamento.
  4. Un tentativo conta solo quando sono stati copiati degli oggetti. Escape durante una scelta, o la mancanza di una seconda connessione, non ne consumano.

Copy to Another Connection funziona 3 volte sul tuo computer prima di chiedere una licenza. Non ci sono finestre a comparsa né conti alla rovescia.

Passaggi in Cursor, Windsurf o VSCodium

  1. Apri la vista Extensions con Ctrl+Maiusc+X (Cmd+Maiusc+X su macOS).
  2. Cerca zovo.zovo-s3-explorer e fai clic su Install. Cursor, Windsurf e VSCodium installano le estensioni da Open VSX, dove questa si chiama zovo/zovo-s3-explorer.
  3. Se il tuo editor non ha una galleria, scarica il file .vsix dalla pagina di Open VSX ed esegui "Extensions: Install from VSIX...".
  4. Da lì in poi funziona tutto come in VS Code.

Cosa fa S3 Explorer

  • Profili AWS con access key, credential_process, ruoli con source_profile e profili SSO dopo aws sso login. Il valore endpoint_url di un profilo viene rispettato.
  • MinIO e altri servizi compatibili con S3 con un URL dell'endpoint, una region, URL path-style o virtual-hosted, e un'opzione per accettare un certificato autofirmato.
  • Metadati, content type, storage class, ETag, tag (da modificare e salvare), versioni (da aprire, scaricare, ripristinare) e presigned URL GET o PUT da 15 minuti a 7 giorni.
  • Bucket con milioni di chiavi, caricate 1.000 alla volta, con ricerca e filtro per prefisso.
  • I download mantengono la struttura delle cartelle e non scrivono mai fuori dalla cartella scelta. Le chiavi con segmenti .., lettere di unità o byte NUL vengono saltate ed elencate.

Cosa non fa

  • Non usa mai da solo il profilo AWS default o AWS_PROFILE. Sei tu a scegliere il profilo con cui collegarti.
  • Per gli oggetti di testo oltre 10 MB chiede prima conferma, poi mostra il primo MB. Per gli oggetti binari oltre 200 MB chiede conferma prima del download.
  • Gli oggetti aperti sono di sola lettura. Solo Edit and Upload scrive nel bucket, dopo una conferma.
  • Scheduled Sync funziona solo mentre VS Code è aperto, ogni 5-60 minuti, e non elimina mai nulla.
  • Le richieste senza risposta si fermano dopo 30 secondi (impostazione s3Explorer.requestTimeoutSeconds).

Domande frequenti

È gratuito?

Navigazione, apertura, upload, download, copia, spostamento, rinomina, eliminazione, versioni, tag, presigned URL e sincronizzazione delle cartelle sono gratuiti. I tre strumenti Pro, Copy to Another Connection, Size and Cost Report e Scheduled Sync, hanno 3 tentativi gratuiti ciascuno. Dopo richiedono Zovo Pro, 19 USD una tantum per tutte le estensioni Zovo.

Dove vengono salvate le mie chiavi?

Le chiavi che inserisci vanno nel portachiavi del sistema operativo tramite VS Code SecretStorage, mai nei file di impostazioni. I profili AWS vengono letti da ~/.aws solo quando ne scegli uno.

Funziona con Cloudflare R2 e MinIO?

Sì. R2 richiede il tuo account ID e la access key di un token API R2. MinIO e gli altri servizi compatibili con S3 richiedono un URL dell'endpoint, una region e URL path-style o virtual-hosted.

Funziona in Cursor?

Sì. Cursor, Windsurf e VSCodium lo installano da Open VSX, dove è pubblicato come zovo/zovo-s3-explorer.
