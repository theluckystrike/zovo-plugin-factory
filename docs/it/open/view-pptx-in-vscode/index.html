Guide in italiano · PPTX Viewer

Vedere le diapositive PowerPoint .pptx in VS Code

L'estensione gratuita PPTX Viewer apre le presentazioni PowerPoint direttamente in VS Code: .pptx, .ppsx, .potx, .pptm e i vecchi .ppt, con miniature, note del relatore, ricerca e il pulsante Present. È comoda per controllare una presentazione appena generata da uno script, da python-pptx o da un agente AI: la diapositiva si ricarica a ogni salvataggio del file. Senza PowerPoint, senza LibreOffice e senza caricare nulla online.

Gratuita, licenza MIT. ID zovo.pptx-slide-viewer, versione 0.5.4. Richiede VS Code 1.90.0 o successivo.

I passaggi in VS Code

  1. Installa l'estensione PPTX Viewer dal Marketplace, oppure premi Ctrl+P (Cmd+P su macOS) ed esegui ext install zovo.pptx-slide-viewer.
  2. Fai clic su un file .pptx, .ppsx, .potx, .pptm o .ppt nell'Explorer. Le diapositive compaiono con le miniature e, sotto, le note del relatore.
  3. Premi Ctrl+F (Cmd+F su macOS) per cercare in titoli, elenchi, tabelle e note di tutta la presentazione. La scheda Outline elenca le diapositive trovate, e Invio passa alla successiva.
  4. Fai clic su Present per mostrare una diapositiva alla volta a schermo intero. Le frecce, la barra spaziatrice o un clic vanno avanti, Esc riporta all'editor.
  5. Copy: "PNG" copia la diapositiva come immagine (circa 1920 pixel di larghezza) da incollare in una pull request o in una issue. Copy: "Markdown" copia la diapositiva in Markdown, e "All" l'intera presentazione.
  6. Lascia aperta la presentazione mentre uno script la rigenera: a ogni salvataggio la diapositiva si aggiorna in circa un secondo, restando sulla stessa pagina.

Cosa è gratis e cosa aggiunge Zovo Pro

Vedere le diapositive, Present, le note del relatore, la ricerca, le miniature e la struttura, copiare o salvare una diapositiva come PNG e Copy as Markdown sono gratuiti.

Per mandare la presentazione a chi non ha PowerPoint, Export Deck as PDF salva un PDF con una pagina per diapositiva, nel formato della diapositiva. Le pagine sono immagini delle diapositive, quindi il testo del PDF non si può selezionare. Zovo Pro esporta anche tutte le diapositive come PNG, converte una cartella di presentazioni in Markdown con le note e salva una copia più leggera di una presentazione piena di foto (Compress Deck).

Con Export Deck as PDF (Zovo Pro)

  1. Con la presentazione aperta, fai clic su Export nella barra e scegli il PDF, oppure esegui "Export Deck as PDF (Pro)..." dalla Command Palette.
  2. Scegli dove salvare il PDF.
  3. La presentazione originale non cambia, e le immagini vengono create sul tuo computer.

Export Deck as PDF funziona 3 volte sul tuo computer prima di chiedere una licenza, e un tentativo conta solo quando ottieni un risultato. Quando apri un file non compare niente che riguardi Pro.

In Cursor, Windsurf o VSCodium

Questi editor installano le estensioni da Open VSX. Apri la vista Extensions (Ctrl+Shift+X, o Cmd+Shift+X su macOS), cerca zovo.pptx-slide-viewer e fai clic su Install. Poi funziona come in VS Code.

Cosa non fa

  • È un visualizzatore. Non modifica le diapositive.
  • I vecchi .ppt si aprono solo come testo: titoli, testo delle diapositive e note, senza immagini né layout.
  • Video, audio e oggetti incorporati non vengono disegnati, e la diapositiva segnala cosa manca.
  • Un carattere non installato sul computer viene sostituito con uno simile, quindi gli a capo possono cambiare un po'.

Domande

L'estensione è a pagamento?

No. Vedere, presentare, cercare e copiare le diapositive è gratuito. Solo le esportazioni, la compressione e il confronto di presentazioni fanno parte di Zovo Pro (USD 19 una volta), con 3 utilizzi gratuiti ciascuno.

Funziona con Remote SSH, WSL o Codespaces?

Sì. L'estensione legge il file tramite VS Code, quindi funziona anche con Remote SSH, WSL, Dev Containers e Codespaces.

Il file viene inviato da qualche parte?

No. Tutto avviene sul tuo computer, senza telemetria.
