Da DXF a CSV in VS Code: estrarre attributi dei blocchi e testi

Installa DXF Viewer & File Preview for 2D CAD Drawings (zovo.dxf-viewer) e fai clic sul file .dxf per vedere fogli, layer e testi. Visualizzazione, layer, ricerca nel testo, misura ed export PNG o SVG sono gratis. Extract drawing data è uno strumento Zovo Pro che salva un CSV con gli attributi dei blocchi (una riga per inserimento, una colonna per tag), i conteggi dei blocchi, tutti i testi con layer e posizione, oppure l’elenco dei layer. Si può provare gratis 3 volte sul tuo computer, poi Zovo Pro costa 19 USD una volta sola per tutte le estensioni Zovo.

Passaggi in VS Code

  1. Installa DXF Viewer dal Marketplace, oppure premi Ctrl+P (Cmd+P su macOS) ed esegui ext install zovo.dxf-viewer.
  2. Fai clic sul file .dxf nell’Explorer. Il pannello laterale elenca i layer con colore e numero di entità, una tabella dei tipi di entità (nel model space e dentro i blocchi) e i dati del disegno, compreso il numero di blocchi.
  3. Premi Ctrl+F (Cmd+F su Mac) e scrivi un numero di tag o il valore di un attributo per controllare che il dato sia nel disegno. Invio passa al risultato successivo.
  4. Esegui "DXF Viewer: Extract Block Attributes, Text or Layers to CSV (Zovo Pro)" dalla Command Palette o dal menu ... del disegno aperto. Puoi anche fare clic destro sul file .dxf nell’Explorer e scegliere "Zovo Pro: Extract drawing data to CSV".
  5. Nell’elenco "What should the CSV file hold?" scegli Block attributes, Block counts, All text o Layers.
  6. Scegli il nome del file nella finestra di salvataggio. Un messaggio indica quante righe sono state salvate. Apri il CSV in Excel o Google Sheets.

Cosa è gratis e cosa aggiunge Zovo Pro

Aprire file DXF è gratis e resta gratis, con i fogli del paper space, i layer, la ricerca nel testo, la misura, il ricaricamento automatico e l’export PNG o SVG. Anche il pannello laterale con layer, tipi di entità e dati del disegno è gratis.

Extract drawing data salva i dati del disegno che altrimenti copieresti a mano in un foglio di calcolo. Possono essere gli attributi dei blocchi, con una riga per inserimento e una colonna per tag (come un abaco delle porte o delle apparecchiature), i conteggi dei blocchi come distinta materiali, tutti i testi con layer e posizione, oppure l’elenco dei layer. Funziona su un disegno o su tutti i file .dxf di una cartella e delle sue sottocartelle, e con più disegni il CSV ha una colonna File. Legge solo i file sul tuo computer e non scrive mai in un disegno.

Usare Extract drawing data (Zovo Pro)

  1. Per un disegno, apri il file .dxf ed esegui "DXF Viewer: Extract Block Attributes, Text or Layers to CSV (Zovo Pro)" dalla Command Palette, oppure fai clic su "Extract drawing data to CSV" nella piccola riga Zovo Pro in cima al visualizzatore.
  2. Per una cartella, fai clic destro sulla cartella nell’Explorer e scegli "Extract Block Attributes, Text or Layers to CSV (Zovo Pro)". Vengono letti tutti i file .dxf della cartella e delle sottocartelle.
  3. Scegli cosa deve contenere il CSV e salva il file. Una prova viene contata solo quando il CSV è stato salvato, quindi Cancel o Esc non consumano nulla.
  4. Dopo le 3 prove gratuite, lo strumento mostra i modi per ottenere Zovo Pro.

Passaggi in Cursor, Windsurf o VSCodium

  1. Apri la vista Extensions con Ctrl+Maiusc+X (Cmd+Maiusc+X su macOS).
  2. Cerca zovo.dxf-viewer e fai clic su Install. Cursor, Windsurf e VSCodium installano le estensioni da Open VSX, dove questa si chiama zovo/dxf-viewer.
  3. Se il tuo editor non ha una galleria, scarica il file .vsix dalla pagina di Open VSX ed esegui "Extensions: Install from VSIX...".
  4. Da lì in poi funziona tutto come in VS Code.

Cosa fa DXF Viewer

  • Attributi dei blocchi, con una riga per inserimento con Block, Layer, X, Y, Rotation, Space e Handle, poi una colonna per ogni tag di attributo.
  • Conteggi dei blocchi, cioè quante volte è inserito ogni blocco, nel model space e nel paper space, con i suoi layer e tag di attributo.
  • Tutti i testi, cioè TEXT, MTEXT, attributi e valori delle quote, con tipo, layer, X, Y, altezza, blocco e tag.
  • Layer, con numero di entità, colore (ACI), stato acceso o spento e stato congelato.
  • DXF ASCII e binari, dai file R12 ad AutoCAD 2018, con blocchi e inserimenti annidati.

Cosa non fa

  • DWG non è supportato. Quando fai clic su un file .dwg, l’estensione mostra una pagina con la versione DWG e le istruzioni per salvare una copia DXF. Il convertitore gratuito ODA File Converter converte un’intera cartella di file DWG in una volta.
  • Il CSV contiene attributi dei blocchi, conteggi dei blocchi, testi o layer. Non è un elenco delle coordinate di ogni linea e polilinea.
  • I file oltre 500 MB non vengono letti (impostazione dxfViewer.maxFileMB, fino a 2048).
  • Un’estrazione su una cartella legge al massimo 5.000 disegni e salta le cartelle node_modules, .git, .svn e .hg.
  • Il visualizzatore è in sola lettura. La finestra di salvataggio rifiuta i nomi che finiscono in .dxf o .dwg, quindi un disegno non viene mai sovrascritto.

Domande frequenti

È gratis?

Visualizzazione dei file DXF, layer, fogli, ricerca nel testo, misura ed export PNG o SVG sono gratis. Extract drawing data, Compare drawings e Folder inventory sono strumenti Zovo Pro. Ogni strumento Pro si può provare gratis 3 volte sul tuo computer, poi Zovo Pro costa 19 USD una volta sola per tutte le estensioni Zovo.

Posso estrarre gli attributi da un file DWG?

Non direttamente, perché DWG non è supportato. Salva una copia DXF dal tuo programma CAD, oppure converti i file DWG con il convertitore gratuito ODA File Converter, poi apri il DXF.

Excel mostra correttamente accenti e formule?

Il CSV inizia con un BOM UTF-8, quindi Excel legge correttamente le lettere accentate e i testi non latini. Una cella che inizia con =, +, - o @ riceve un apostrofo iniziale, così Excel non la esegue come formula.

Funziona in Cursor?

Sì. È pubblicata su Open VSX come zovo/dxf-viewer, quindi si installa in Cursor, Windsurf e VSCodium.
