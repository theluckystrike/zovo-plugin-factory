Aprire file NumPy .npy e .npz in VS Code

Installa Tensor Viewer (NPZ Viewer & NPY Viewer), che è gratuito, e fai clic su un file .npy o .npz. Ogni array compare con nome, dtype e shape, e con un clic vedi minimo, massimo, media, deviazione standard, il numero di NaN, un grafico, un istogramma e i valori, senza Python. La visualizzazione, le immagini, la tabella Values e Save as .npy o CSV sono gratis. Zovo Pro (19 USD, una volta sola) aggiunge due strumenti, Compare two checkpoints e Scan all tensors, e ognuno si può provare gratis 3 volte.

Passaggi in VS Code

  1. Installa Tensor Viewer dal Marketplace, oppure premi Ctrl+P (Cmd+P su macOS) ed esegui ext install zovo.tensor-viewer.
  2. Fai clic su un file .npy o .npz nell’Explorer. La tabella elenca ogni array con nome, tipo, shape, numero di parametri e dimensione.
  3. Fai clic su un array. Il pannello a destra mostra minimo, massimo, media, deviazione standard e il numero di NaN, Inf e zeri, poi una heatmap per gli array 2-D o un grafico a linee per quelli 1-D, e un istogramma.
  4. Leggi i numeri nella tabella Values, 32 righe alla volta. Per gli array con 3 o più dimensioni, scrivi una fetta come [5, :, :] nel campo Slice.
  5. Se l’array ha la forma di un’immagine, come (H, W, 3) o (N, 3, H, W), la sezione Image lo disegna. Lì scegli Layout, Frame e Range. Per le matrici float compare invece il pulsante "Show as image".
  6. Fai clic su "Save as .npy..." o "Save as CSV..." per scrivere l’array, o la fetta, in un nuovo file.

Cosa è gratis e cosa aggiunge Zovo Pro

Tutti i formati, le statistiche, le heatmap, i grafici a linee, gli istogrammi, le immagini, la tabella Values, le fette, gli array raw e Save as .npy o CSV sono gratis. Non serve Python e il visualizzatore non fa chiamate di rete.

Scan all tensors legge tutti i valori di tutti gli array del file, non un campione, e segnala gli array con NaN, Inf, solo zeri o costanti e i valori float da 10.000 in su. Mostra minimo, massimo, media, deviazione standard e norma L2 esatti di ogni array in un unico report, che puoi filtrare e salvare come CSV, Markdown o JSON. Così trovi l’array difettoso in un .npz grande senza aprirli uno per uno.

Usare Scan all tensors (Zovo Pro)

  1. Apri il file e fai clic sul pulsante "Scan all tensors" in cima al visualizzatore, oppure fai clic destro sul file nell’Explorer e scegli "Zovo Pro: Scan Tensors for NaN, Inf and Zeros".
  2. In alternativa esegui "NumPy Viewer Pro: Scan All Tensors for NaN, Inf and Zeros" dalla Command Palette e scegli il file.
  3. Una notifica mostra l’avanzamento e Cancel ferma un’analisi lunga. Nel report usa il filtro "Only tensors to check", poi salva il report come CSV, Markdown o JSON.

Scan all tensors funziona 3 volte sul tuo computer prima di chiedere una licenza. Non ci sono finestre a comparsa né conti alla rovescia.

Passaggi in Cursor, Windsurf o VSCodium

  1. Apri la vista Extensions con Ctrl+Maiusc+X (Cmd+Maiusc+X su macOS).
  2. Cerca zovo.tensor-viewer e fai clic su Install. Cursor, Windsurf e VSCodium installano le estensioni da Open VSX, dove questa si chiama zovo/tensor-viewer.
  3. Se il tuo editor non ha una galleria, scarica il file .vsix dalla pagina di Open VSX ed esegui "Extensions: Install from VSIX...".
  4. Da lì in poi funziona tutto come in VS Code.

Cosa fa Tensor Viewer

  • File .npy con header v1, v2 e v3, in ordine C e Fortran, con entrambi gli ordini dei byte.
  • Archivi .npz con voci non compresse o compresse con deflate, anche zip64.
  • bool, da int8 a int64, da uint8 a uint64, float16, float32, float64 e numeri complessi (statistiche sul modulo).
  • Array con forma da immagine, pile e batch disegnati come immagini, un frame alla volta.
  • La stessa estensione apre anche file .safetensors, .gguf e file PyTorch .pt, .pth e .ckpt.

Cosa non fa

  • Gli array di oggetti salvati come pickle vengono elencati e rifiutati, mai eseguiti. Gli array di testo e quelli strutturati vengono elencati senza statistiche.
  • Per gli array con più di 2.000.000 di valori, statistiche e grafici si basano su un campione (impostazione tensorViewer.sampleValues). Il pannello indica quando le statistiche vengono da un campione.
  • Le voci compresse di un .npz vengono lette solo dall’inizio. I valori oltre i primi 64 MB non compaiono e le voci oltre 512 MB non si possono salvare.
  • Le immagini hanno al massimo 512 pixel sul lato lungo. Gli array a 2 canali e quelli in ordine Fortran non hanno la vista immagine.
  • L’esportazione CSV si ferma a 20 milioni di valori. I valori int64 oltre 2^53 perdono le ultime cifre nella tabella e nel CSV.

Domande frequenti

È gratis?

Aprire file .npy e .npz, le statistiche, i grafici, le immagini, la tabella Values e Save as .npy o CSV sono gratis. I due strumenti Pro, Compare two checkpoints e Scan all tensors, si possono provare gratis 3 volte ciascuno. Dopo serve Zovo Pro, 19 USD una volta sola per tutte le estensioni Zovo.

Serve Python?

No. Tensor Viewer legge i file da solo, quindi non devi installare Python né NumPy.

È sicuro aprire un file .npy scaricato da internet?

Nessun contenuto del file viene mai eseguito. Gli array di oggetti, che NumPy salva come pickle, vengono elencati e rifiutati, e il visualizzatore non modifica mai il file che mostra.

Funziona in Cursor?

Sì. Tensor Viewer è su Open VSX come zovo/tensor-viewer, quindi Cursor, Windsurf e VSCodium possono installarlo.
