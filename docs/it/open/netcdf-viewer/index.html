Un visualizzatore NetCDF gratuito che funziona in VS Code

Installa in VS Code l’estensione gratuita NetCDF Viewer & HDF5 Viewer e fai clic su un file .nc. Vedi l’header, l’albero delle variabili, una mappa con le linee di costa, uno slider del tempo e la serie temporale di qualsiasi punto su cui fai clic, senza Python, NCL o altre installazioni. Lo stesso visualizzatore apre i file HDF5 .h5 e i file MATLAB 7.3 .mat, e tutto questo è gratis. Zovo Pro (19 USD, una volta sola) aggiunge due strumenti, Compare two files ed Export a subset, e ognuno si può provare gratis 3 volte.

Passaggi in VS Code

  1. Installa NetCDF Viewer & HDF5 Viewer dal Marketplace, oppure premi Ctrl+P (Cmd+P su macOS) ed esegui ext install zovo.hdf5-netcdf-explorer.
  2. Fai clic su un file .nc, .nc4, .netcdf o .cdf nell’Explorer. La panoramica mostra il formato, le dimensioni, gli attributi globali e una tabella di tutte le variabili, come ncdump -h.
  3. Scegli una variabile nell’albero a sinistra. Una fetta 2-D viene disegnata come heatmap, con le linee di costa quando righe e colonne sono latitudine e longitudine.
  4. Sposta lo slider del tempo, oppure premi ▶ accanto allo slider per far scorrere il tempo. Fai clic su un punto della mappa per tracciarne la serie temporale.
  5. Apri la scheda Table per sfogliare i valori, 100 righe per 30 colonne, con i valori delle coordinate come intestazioni.
  6. Fai clic su "Save PNG" per salvare il grafico, oppure su "Export slice…" per salvare la fetta a schermo come CSV o JSON. "Copy xarray code" ti dà la riga Python per la stessa fetta.
  7. Per un file HDF5, fai clic sul file .h5. Per un file MATLAB 7.3 .mat, fai clic destro sul file e scegli "Open in HDF5 NetCDF Explorer".

Cosa è gratis e cosa aggiunge Zovo Pro

Tutti i formati, l’albero, gli attributi, la tabella, i grafici e le mappe con le coste, Play, la serie temporale di un punto, Save PNG ed Export slice sono gratis. Non serve Python e queste funzioni non fanno chiamate di rete.

Export a subset funziona come ncks -d o .sel di xarray. Scegli una variabile e un intervallo per ogni dimensione, per indice (0:99) o per valore (30..60, 2023-08-01..2023-08-31). Salva un file NetCDF con le coordinate, gli attributi e una riga history, oppure un CSV in formato tidy con una riga per punto. Ottieni un file piccolo per una regione e un periodo senza scrivere uno script.

Usare Export a subset (Zovo Pro)

  1. Apri il file e fai clic sul pulsante "Export subset…" accanto a "Export slice…", oppure fai clic destro sul file nell’Explorer e scegli "Zovo Pro: Export a Subset of a Variable".
  2. In alternativa esegui "NetCDF Viewer Pro: Export Subset of a Variable (NetCDF or CSV)..." dalla Command Palette.
  3. Scrivi un intervallo per ogni dimensione. Mentre scrivi, la casella mostra cosa hai selezionato.
  4. Scegli NetCDF o CSV e indica dove salvare. Una notifica mostra l’avanzamento, e Cancel si ferma senza lasciare un file scritto a metà.

Export a subset funziona 3 volte sul tuo computer prima di chiedere una licenza. Non ci sono finestre a comparsa né conti alla rovescia.

Passaggi in Cursor, Windsurf o VSCodium

  1. Apri la vista Extensions con Ctrl+Maiusc+X (Cmd+Maiusc+X su macOS).
  2. Cerca zovo.hdf5-netcdf-explorer e fai clic su Install. Cursor, Windsurf e VSCodium installano le estensioni da Open VSX, dove questa si chiama zovo/hdf5-netcdf-explorer.
  3. Se il tuo editor non ha una galleria, scarica il file .vsix dalla pagina di Open VSX ed esegui "Extensions: Install from VSIX...".
  4. Da lì in poi funziona tutto come in VS Code.

Cosa fa NetCDF Viewer & HDF5 Viewer

  • NetCDF-4 e NetCDF-4 classic, NetCDF-3 classic e 64-bit offset, e CDF-5 (dati a 64 bit).
  • File HDF5 (.h5, .hdf5, .he5, .hdf) compressi con deflate, shuffle, szip, LZF, Blosc, bitshuffle, LZ4, Zstd, bzip2 e ZFP.
  • File MATLAB 7.3 .mat e altri file basati su HDF5 come .jld2, .loom e .h5ad.
  • Decodifica CF di scale_factor, add_offset, _FillValue e delle unità di tempo, compresi i calendari noleap, 360_day e all_leap.
  • File su una macchina remota tramite Remote SSH, WSL o un dev container.

Cosa non fa

  • Zarr e HDF4 non sono supportati. I file MATLAB .mat salvati nel formato v5 non sono HDF5 e non si aprono. Salvali di nuovo con save(filename, '-v7.3').
  • Le linee di costa compaiono solo sulle griglie regolari latitudine-longitudine. Le griglie curvilinee con latitudine e longitudine 2-D e le griglie proiettate in metri non le hanno.
  • Gli array più grandi di 512 x 512 vengono campionati per il grafico. Le esportazioni scrivono al massimo 1.000.000 di valori per file (impostazione hdf5NetcdfExplorer.maxReadValues).
  • I file system virtuali, come i repository GitHub aperti in vscode.dev, non sono supportati.
  • I dataset con altri filtri HDF5, come SZ o JPEG, mostrano un messaggio al posto dei valori.

Domande frequenti

È gratis?

La visualizzazione è gratis, con tutti i formati, le mappe, Play, le serie temporali, Save PNG ed Export slice. I due strumenti Pro, Compare two files ed Export a subset, si possono provare gratis 3 volte ciascuno. Dopo serve Zovo Pro, 19 USD una volta sola per tutte le estensioni Zovo.

Esiste un visualizzatore NetCDF per Windows?

Sì. Questa estensione funziona ovunque funzioni VS Code, quindi su Windows, macOS e Linux, e non richiede Python.

Apre anche file HDF5 e MAT?

Sì, i file HDF5 .h5 e i file MATLAB 7.3 .mat. I vecchi file MATLAB v5 .mat non sono HDF5 e al loro posto compare un messaggio.

Funziona in Cursor?

Sì. È su Open VSX come zovo/hdf5-netcdf-explorer, quindi Cursor, Windsurf e VSCodium possono installarla.
