Se sektioner och imports i en ELF-, EXE- eller DLL-fil i VS Code

Installera det kostnadsfria tillägget ELF Viewer & PE Viewer och klicka på en .so-, .exe-, .dll- eller .dylib-fil. Steg i VS Code

  1. Installera ELF Viewer & PE Viewer från Marketplace, eller tryck Ctrl+P (Cmd+P på macOS) och kör ext install zovo.zovo-elf-pe-viewer.
  2. Klicka på en .exe-, .dll-, .sys-, .so-, .dylib-, .elf- eller .ko-fil i Explorer. Den öppnas i visaren. För en objektfil (.o) eller en körbar fil för Linux eller macOS utan filändelse högerklickar du på filen och väljer Open in ELF & PE Viewer.
  3. Fliken Overview visas först. Den visar arkitektur, filtyp, entry point, länkade bibliotek, säkerhetsflaggor som ASLR och DEP, build ID och PDB-sökvägen.
  4. Öppna fliken Sections eller Imports. Imports i ELF visar biblioteket och symbolversionen för varje funktion. PE-filer får också data directories, delay-load imports och resurser, och Mach-O-filer får load commands.
  5. Skriv i filterrutan ovanför en tabell för att begränsa raderna, och klicka på en kolumnrubrik för att sortera. Copy rows lägger raderna i urklipp som tabbseparerad text.
  6. Klicka på länken bytes för en sektion eller ett segment för att se dess bytes markerade i fliken Hex. I fliken Headers öppnar Show every header field with its offset fältträdet.

Vad som är gratis och vad Zovo Pro lägger till

Alla vyer av en fil är gratis och kräver ingen inloggning, med översikten, alla tabeller, filtrering, sortering och kopiering, hexvyn och fältträdet. Tillägget skriver aldrig till binärfilen och gör inga nätverksanrop.

Vill du veta vilka binärer i en byggmapp som importerar en funktion eller länkar ett bibliotek läser det här verktyget varje ELF-, PE- och Mach-O-fil i mappen och listar varje träff med sin fil. Vanlig text matchar valfri del av ett namn, och en /regex/ fungerar också. Du får svaret i en enda sökning i stället för att öppna varje binär eller köra readelf eller dumpbin fil för fil.

Använd Find a symbol or import in a folder (Zovo Pro)

  1. Öppna en binär och klicka på Find in folder… överst i visaren, eller kör ”ELF & PE Viewer: Find a symbol or import in a folder (Pro)” från Command Palette.
  2. Skriv ett namn som CreateFileW eller SSL_read, eller ett reguljärt uttryck som /^_?pthread_/. Verktyget söker i arbetsytans mapp eller frågar efter en mapp.
  3. Från visaren öppnas träffarna i en Find-flik med en Copy-knapp. Från Command Palette visas de i en lista, och ett klick öppnar binären.
  4. Escape, eller en sökning utan träff, använder inget gratis försök.

Find a symbol or import in a folder fungerar 3 gånger gratis på din dator innan en licens behövs. Det finns ingen popup och ingen nedräkning.

Steg i Cursor, Windsurf eller VSCodium

  1. Öppna vyn Extensions med Ctrl+Shift+X (Cmd+Shift+X på macOS).
  2. Sök efter zovo.zovo-elf-pe-viewer och klicka på Install. Cursor, Windsurf och VSCodium installerar tillägg från Open VSX, där det här tillägget heter zovo/zovo-elf-pe-viewer.
  3. Om din editor inte har något tilläggsgalleri laddar du ner .vsix-filen från sidan på Open VSX och kör ”Extensions: Install from VSIX...”.
  4. Sedan fungerar allt som i VS Code.

Vad ELF Viewer & PE Viewer gör

  • ELF-filer i 32 och 64 bitar, little och big endian, till exempel .so, .o, .ko, .elf, .axf och körbara filer för Linux.
  • PE32- och PE32+-filer som .exe, .dll, .sys, .efi och .pyd, med imports efter namn och ordinal, exports med forwarders och .NET runtime-headern.
  • Mach-O i 32 och 64 bitar, och universella binärer. Välj arkitektur, till exempel arm64 eller x86_64, överst.
  • Tabeller med upp till 100 000 rader som kan filtreras, sorteras och kopieras.

Vad det inte gör

  • Det är skrivskyddat och har ingen disassembly.
  • Statiska bibliotek (.a), Java class-filer, WebAssembly och DEX-filer läses inte.
  • Tabeller stannar vid 100 000 rader vardera, och läsningen stoppas efter 10 sekunder. Visaren säger till när det händer.
  • Filer på fjärr- eller virtuella filsystem läses upp till 256 MB. Find in folder söker bara i lokala mappar.
  • .o-filer och filer utan filändelse öppnas inte som standard. Använd Open in ELF & PE Viewer i högerklicksmenyn.

Vanliga frågor

Är det gratis?

Alla vyer av en fil är gratis, utan inloggning. De tre Pro-verktygen, export som JSON eller C-header, jämförelse av två binärer och sökning efter ett namn i en mapp, har 3 gratis försök vardera. Därefter behöver de Zovo Pro, 19 USD en gång för alla Zovo-tillägg.

Behöver jag readelf, objdump eller dumpbin?

Nej. Tillägget läser ELF-, PE- och Mach-O-filer själv, utan att något annat program är installerat.

Kan det ändra binärfilen?

Nej. Det läser bara filen och skriver aldrig till den. Pro-exporten sparar en ny JSON- eller header-fil där du väljer.

Fungerar det i Cursor?

Ja. Enligt README fungerar det i Cursor, Windsurf och VSCodium, och det finns på Open VSX, så de här editorerna kan installera det.
