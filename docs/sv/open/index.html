Guider på svenska

VS Code och editorerna som bygger på det (Cursor, Windsurf, VSCodium) öppnar text, bilder och en del media. För många andra format behöver du ett tillägg. Varje guide visar stegen och säger vad som är gratis.

  • Visa NumPy-filer i .npy och .npz i VS Code. Öppna NumPy-arrayer i .npy och .npz i VS Code med gratistillägget Tensor Viewer. Du ser dtype, shape, statistik, heatmaps, bilder och värden, utan Python.
  • En gratis NetCDF-visare i VS Code. Öppna NetCDF-filer (.nc) i VS Code på Windows, macOS eller Linux. Header, variabler, kartor med kustlinjer och tidsserier. Även HDF5 .h5 och MATLAB 7.3 .mat.
  • Öppna en SQLite-databas i VS Code. Öppna en .db- eller .sqlite-fil i VS Code med gratistillägget SQLite Viewer & Editor. Tabeller, schema och SQL, redigera celler och rader och spara med backup.
  • Förhandsgranska Mermaid-diagram i VS Code. Förhandsgranska Mermaid-diagram från .mmd-filer och Markdown-block i VS Code med gratistillägget Mermaid Viewer. Live, export till PNG och SVG, offline.
  • Spela MOV-, MKV-, WebM- och MP4-video med ljud i VS Code. Spela MP4, MOV och M4V med AAC-ljud i VS Code utan annan installation. MKV, WebM och AVI spelas också, med din egen ffmpeg. Gratis spelare med undertexter.
  • Visa STL-filer i VS Code. Öppna STL-filer i VS Code med gratistillägget 3D Model Viewer. Rotera, mät mellan två punkter, wireframe och statistik. Även OBJ, PLY, 3MF, GLB och glTF.
  • Öppna en PCAP-fil i VS Code. Läs .pcap-, .pcapng- och .pcap.gz-filer i VS Code med gratistillägget PCAP Viewer. Paketlista, protokollträd, hexpanel och filter, utan Wireshark.
  • Byt namn på HTML-, JSX- och Vue-taggar automatiskt i VS Code. Byt namn på en HTML-, JSX- eller Vue-tagg så ändras den matchande taggen medan du skriver. Gratis, byggt på linked editing, med auto close och ett ångra-steg.
  • Läs och återuppta din Claude Code-historik i VS Code. Läs, sök i och återuppta gamla sessioner från Claude Code och Codex i VS Code. Subagenter i träd, ändringar som diffar, tokensummor. Skrivskyddat och offline.
  • Konvertera TIFF till PNG utan att förlora kvalitet. Öppna TIFF-, BigTIFF- och GeoTIFF-filer gratis i VS Code och spara en sida eller alla sidor som PNG, med exakta 8- och 16-bitarsvärden. Offline.
  • XMind till PDF utan XMind: alla ark i en enda PDF. Öppna en .xmind-mindmap i VS Code utan XMind och spara alla ark i en PDF, en sida per ark. Visningen är gratis, och PDF-exporten är ett Zovo Pro-verktyg.
  • Spela ljudfiler i VS Code. Spela WAV, MP3, FLAC, Ogg och Opus i VS Code med gratistillägget Audio Player. Vågform, spektrogram, A-B-loop, hastighet och loudness i LUFS.
  • Öppna en DXF-ritning i VS Code. Visa .dxf-filer i VS Code med gratistillägget DXF Viewer. ASCII- och binär DXF, lager, ark i paper space, textsökning, mätning och export till PNG eller SVG.
  • Se sektioner och imports i en ELF-, EXE- eller DLL-fil i VS Code. Öppna .so-, .exe-, .dll- och .dylib-filer i VS Code med gratistillägget ELF Viewer & PE Viewer. Headers, sektioner, imports, exports, symboler och hex.
  • Förhandsgranska en typsnittsfil i VS Code. Öppna .ttf, .otf, .woff, .woff2 och .ttc i VS Code med gratistillägget Font Viewer. Testa text, se alla glyfer och läs licensen, utan att installera typsnittet.
  • Förhandsgranska en Graphviz DOT-graf utan att installera Graphviz. Förhandsgranska .dot- och .gv-filer bredvid editorn i VS Code medan du skriver, med Graphviz inbyggt. Sex layoutmotorer, klick till rad, SVG- och PNG-export.
  • Kör en C++-fil i VS Code med ett klick. Kompilera och kör den öppna .cpp- eller .c-filen i VS Code med ett klick, med din egen gcc, g++ eller clang. Indata i terminalen, fel i Problems, testfall.
  • Öppna en fil i en ZIP utan att packa upp den. Bläddra i en ZIP, JAR, TAR eller TAR.GZ i VS Code och öppna en fil därifrån i en skrivskyddad flik, utan att något packas upp på disken. Gratis och offline.
  • Öppna en JAR och läs dekompilerad Java-källkod i VS Code. Öppna .jar, .war, .ear, .aar och .class i VS Code: paket, MANIFEST.MF, bytecode och Java-källkod dekompilerad med CFR. Gratis och skrivskyddat.
