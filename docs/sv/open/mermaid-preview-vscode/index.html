Förhandsgranska Mermaid-diagram i VS Code

VS Code har ingen egen förhandsvisning av Mermaid. Installera det kostnadsfria tillägget Mermaid Viewer, öppna en .mmd- eller .mermaid-fil och klicka på förhandsvisningsikonen uppe till höger i editorn, så följer diagrammet med när du skriver. I en Markdown-fil listar förhandsvisningen alla mermaid-block. Mermaid 12.3.0 följer med i tillägget, så förhandsvisningen och exporten till PNG eller SVG är gratis och fungerar offline utan inloggning. Zovo Pro (19 USD, betalas en gång) lägger till PDF-export, export av alla diagram i arbetsytan och export när du sparar, med 3 gratis försök för varje verktyg.

Steg i VS Code

  1. Installera Mermaid Viewer från Marketplace, eller tryck Ctrl+P (Cmd+P på macOS) och kör ext install zovo.mermaid-viewer.
  2. Öppna en .mmd- eller .mermaid-fil och klicka på förhandsvisningsikonen i editorns titelrad, eller tryck Ctrl+K V (Cmd+K V på macOS). Du kan också köra ”Mermaid Viewer: Open Diagram Editor (Text + Live Preview)” från Command Palette.
  3. För en Markdown-fil med ```mermaid-block klickar du på samma förhandsvisningsikon. Förhandsvisningen listar alla diagram, vart och ett med sin egen felrad och sina egna exportknappar.
  4. Klicka på ”Edit diagram” ovanför ett block i Markdown-filen för att redigera det bredvid en liveförhandsvisning. När du sparar går texten tillbaka in i sitt block.
  5. Scrolla för att zooma vid pekaren och dra för att panorera. Fit och 100% finns i verktygsfältet.
  6. Klicka på Export för Save PNG (1x, 2x eller 4x, eller en exakt bredd eller höjd), Save SVG, Copy PNG eller Copy SVG code.

Vad som är gratis och vad Zovo Pro lägger till

Liveförhandsvisningen, diagrameditorn, Edit diagram för Markdown-block, komplettering, felmarkeringar, de 15 mallarna, översikten Mermaid Diagrams och export och kopiering som PNG och SVG är gratis. Det finns inget konto, ingen inloggning och ingen AI.

Export All Diagrams in Workspace skriver varje diagram i varje .mmd-, .mermaid- och Markdown-fil i mappen till SVG, PNG eller båda, i mermaid-export/ med samma mappar som källfilerna. Diagram som inte kan ritas listas på slutet. Du behöver inte öppna och exportera varje diagram för hand när dokumentationen ändras.

Använd Export All Diagrams in Workspace (Zovo Pro)

  1. Öppna mappen i VS Code. Kör ”Mermaid Viewer: Export All Diagrams in Workspace (SVG/PNG) (Pro)” från Command Palette, eller klicka på ”Export All Diagrams in Workspace” i raden ”Pro tools” under förhandsvisningens verktygsfält.
  2. Välj SVG, PNG eller SVG och PNG.
  3. Behåll standardmappen mermaid-export (inställningen mermaidViewer.exportFolder) eller välj ”Choose a folder…”. Ett försök räknas bara när filerna har skrivits, och Escape sparar försöket.

Export All Diagrams in Workspace fungerar 3 gånger gratis på din dator innan en licens behövs. Det finns ingen popup och ingen nedräkning.

Steg i Cursor, Windsurf eller VSCodium

  1. Öppna vyn Extensions med Ctrl+Shift+X (Cmd+Shift+X på macOS).
  2. Sök efter zovo.mermaid-viewer och klicka på Install. Cursor, Windsurf och VSCodium installerar tillägg från Open VSX, där det här tillägget heter zovo/mermaid-viewer.
  3. Om din editor inte har något tilläggsgalleri laddar du ner .vsix-filen från sidan på Open VSX och kör ”Extensions: Install from VSIX...”.
  4. Sedan fungerar allt som i VS Code.

Vad Mermaid Viewer gör

  • Flödesscheman, sekvens-, klass-, tillstånds- och ER-diagram, Gantt, cirkeldiagram, gitGraph, mindmap, timeline, sankey, XY chart, block, C4, architecture och de andra typer som Mermaid 12.3.0 känner till.
  • Fel stryks under på sin rad och listas i panelen Problems. Det senaste fungerande diagrammet stannar kvar, och ett trasigt block i en Markdown-fil döljer inte de andra.
  • Zoom från 1 % till 3 200 % vid pekaren, med panorering och nypzoom på styrplattan.
  • SVG-export med vanliga textetiketter för wikis i Azure DevOps och GitHub.
  • Bakgrund i editorns färg, vit, transparent eller en egen färg, som också används vid export.

Vad det inte gör

  • Det lägger inte till diagram i VS Codes egen Markdown-förhandsvisning. Det öppnar en egen förhandsvisningspanel.
  • Matematik i etiketter ($$...$$) kan se fel ut, eftersom KaTeX-typsnitten inte följer med.
  • Ikonpaket som Mermaid laddar från internet laddas inte. Inbyggda ikoner fungerar.
  • Diagram över 500 000 tecken eller 2 000 länkar ritas inte förrän du höjer gränsen (inställningarna mermaidViewer.maxTextSize och mermaidViewer.maxEdges).
  • En ritning som tar längre tid än 10 sekunder stoppas (inställningen mermaidViewer.renderTimeoutSeconds).

Vanliga frågor

Är det gratis?

Förhandsvisningen, editorn, redigering av Markdown-block och export till PNG och SVG är gratis. Pro-verktygen (PDF-export, Export All Diagrams in Workspace och Export on Save) har 3 gratis försök vardera. Därefter behöver de Zovo Pro, 19 USD en gång för alla Zovo-tillägg.

Varför visar VS Code inte mitt mermaid-block i Markdown-förhandsvisningen?

VS Codes inbyggda Markdown-förhandsvisning ritar inte Mermaid. Mermaid Viewer öppnar en egen förhandsvisningspanel för Markdown-filen, med zoom och export för varje diagram.

Behöver jag ett konto eller internet?

Nej. Mermaid 12.3.0 följer med i tillägget, det finns ingen inloggning och ingen AI, och förhandsvisningen blockerar alla nätverksanrop.

Fungerar det i Cursor?

Ja. Tillägget finns på Open VSX som zovo/mermaid-viewer, så Cursor, Windsurf och VSCodium kan installera det.
