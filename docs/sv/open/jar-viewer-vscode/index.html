Öppna en JAR och läs dekompilerad Java-källkod i VS Code

Installera det kostnadsfria tillägget JAR Viewer & Java Decompiler och klicka på en .jar-, .war-, .ear-, .aar- eller .class-fil. Det visar paketen, resurserna, MANIFEST.MF och Java-versionen för varje klass, en bytecode-listning i stil med javap -c -p som inte behöver Java, och Java-källkod som den medföljande CFR 0.152 dekompilerar med hjälp av Java 8 eller nyare på din dator. Alla vyer och dekompilering av en klass i taget är gratis. Zovo Pro (19 USD, betalas en gång) lägger till tre verktyg, export av de dekompilerade källfilerna för en JAR, jämförelse av två JAR-filer och sökning i alla JAR-filer i en mapp, och vart och ett har 3 gratis försök.

Steg i VS Code

  1. Installera JAR Viewer från Marketplace, eller tryck Ctrl+P (Cmd+P på macOS) och kör ext install zovo.zovo-jar-viewer.
  2. Klicka på en .jar-, .war-, .ear-, .aar- eller .class-fil i Explorer. Den öppnas i JAR Viewer. Overview visar formatet, antalet poster, klasser och paket, Main-Class, Created by, MANIFEST.MF och ett diagram över de Java-versioner som klasserna kompilerades för.
  3. Skriv en del av ett namn i filterrutan ovanför paketträdet. Den hittar klasser och filer medan du skriver. Inre klasser ligger nedtonade under sin yttre klass.
  4. Klicka på en klass. Fliken Java source visar den dekompilerad med CFR 0.152, tillsammans med dess inre klasser. Copy lägger källkoden i urklipp, och Open in editor öppnar den i en vanlig redigeringsflik.
  5. Om fliken Java source säger att dekompilerad Java-källkod behöver en Java-runtime anger du en java-binär eller en JDK-mapp i jarViewer.javaPath, eller sätter JAVA_HOME. ”JAR Viewer: Check the Java runtime used for decompiling” visar vilken Java som används.
  6. Öppna fliken Bytecode för en listning i stil med javap -c -p med varje opcode, undantagstabellerna och radnumren. Members, Constant pool och Class info visar deklarationerna, posterna i konstantpoolen och klassens attribut.
  7. I en Spring Boot-JAR, en WAR eller en AAR klickar du på en JAR i BOOT-INF/lib eller WEB-INF/lib, eller på AAR-filens classes.jar, och sedan på ”Open nested archive”. Den öppnas en nivå ner, och knappen med det yttre filnamnet överst tar dig tillbaka.

Vad som är gratis och vad Zovo Pro lägger till

Paketträdet, Overview, manifestet, resurserna, dekompilerad Java-källkod, bytecode, Members, Constant pool, Class info och kapslade JAR-filer är gratis, utan inloggning. CFR följer med tillägget och körs med den Java som redan finns på din dator. Tillägget ändrar aldrig arkivet och gör inga nätverksanrop.

Export decompiled sources of a JAR dekompilerar varje klass i en JAR, WAR, EAR eller AAR med CFR och skriver .java-filerna till en mapp, med förlopp och en Cancel-knapp. Utan Java-runtime skriver det bytecode-listningarna i stället. Du får hela biblioteket som källfiler att söka i eller läsa i din editor, i stället för att öppna en klass i taget.

Använd Export decompiled sources of a JAR (Zovo Pro)

  1. Öppna arkivet och klicka på ”Export sources…” överst i visaren, eller på ”Export decompiled sources” i den lilla raden Pro tools. Du kan också högerklicka på filen i Explorer och välja ”Zovo Pro: Export decompiled sources”.
  2. Eller kör ”JAR Viewer: Export decompiled sources of a JAR (Pro)” från Command Palette. Om inget arkiv är öppet ber kommandot dig välja en JAR-, WAR-, EAR- eller AAR-fil.
  3. Välj en mapp och klicka på ”Export here”. Källfilerna hamnar i en ny mapp som har arkivets namn med -src i slutet.
  4. En notis visar förloppet. Cancel stoppar exporten och använder inget försök. När exporten är klar visar visaren hur många filer den skrev och var.

Export decompiled sources of a JAR fungerar 3 gånger gratis på din dator innan en licens behövs. Det finns ingen popup och ingen nedräkning.

Steg i Cursor, Windsurf eller VSCodium

  1. Öppna vyn Extensions med Ctrl+Shift+X (Cmd+Shift+X på macOS).
  2. Sök efter zovo.zovo-jar-viewer och klicka på Install. Cursor, Windsurf och VSCodium installerar tillägg från Open VSX, där det här tillägget heter zovo/zovo-jar-viewer.
  3. Om din editor inte har något tilläggsgalleri laddar du ner .vsix-filen från sidan på Open VSX och kör ”Extensions: Install from VSIX...”.
  4. Sedan fungerar allt som i VS Code.

Vad JAR Viewer gör

  • JAR-, WAR-, EAR- och AAR-arkiv, och enskilda .class-filer med sina inre klasser från samma mapp.
  • Arkiv med upp till 200 000 poster, och ett filter som hittar en klass eller fil bland 50 000 poster medan du skriver.
  • Generiska signaturer, records, permitted subclasses, nest hosts och annoteringar i klassdata.
  • Textresurser som properties-, XML-, JSON-, SQL- och services-filer visas som text, och binärfiler får en hex-förhandsvisning.
  • Arkiv i Spring Boot BOOT-INF/lib, WAR WEB-INF/lib och AAR classes.jar, en nivå ner.

Vad det inte gör

  • Dekompilerad källkod kräver Java 8 eller nyare på din dator. Utan Java fungerar bytecode och alla andra vyer ändå.
  • CFR:s utdata kan skilja sig från den ursprungliga källkoden, till exempel i namn på lokala variabler, vissa generics och lambdauttryck.
  • Poster packas upp till 64 MB styck, klassfiler till 16 MB och kapslade arkiv till 128 MB. Filer på fjärr- eller virtuella filsystem läses upp till 256 MB.
  • Tillägget är skrivskyddat, så du kan inte redigera eller kompilera om en klass. Kapslade arkiv öppnas bara en nivå ner.
  • APK- och DEX-filer läses inte.

Vanliga frågor

Är det gratis?

Ja. Alla vyer och dekompilering av en klass i taget är gratis. De tre Pro-verktygen, Export decompiled sources of a JAR, Compare two JARs och Find in every JAR of a folder, har 3 gratis försök vardera, och ett försök räknas bara när verktyget ger dig ett resultat. Därefter behöver de Zovo Pro, 19 USD en gång för alla Zovo-tillägg.

Varför ber fliken Java source om Java?

CFR är ett Java-program. Visaren letar efter Java i jarViewer.javaPath, sedan i JAVA_HOME och sist efter java i din PATH. Alla Java-runtimes från version 8 och nyare fungerar.

Kan jag läsa bytecode utan Java?

Ja. Flikarna Bytecode, Members, Constant pool och Class info läses i JavaScript och behöver ingen Java.

Fungerar det i Cursor?

Ja. Det finns på Open VSX som zovo/zovo-jar-viewer, så Cursor, Windsurf och VSCodium kan installera det.
