Steg i VS Code

  1. Installera 3D Model Viewer från Marketplace, eller tryck Ctrl+P (Cmd+P på macOS) och kör ext install zovo.3d-model-viewer.
  2. Klicka på en .stl-, .obj-, .ply-, .3mf-, .glb- eller .gltf-fil i Explorer. Om en annan visare öppnas högerklickar du på filen och väljer ”Open in 3D Model Viewer”.
  3. Dra för att rotera, högerdra eller Shift-dra för att panorera och scrolla för att zooma. Tryck F för att få in hela modellen i vyn.
  4. Läs av panelen för vertices, trianglar, material, texturer och storleken i modellenheter. Tryck P för att visa eller dölja panelen och scenträdet.
  5. Tryck W för wireframe, N för vertexnormaler och B för bounding box. Ställ Shading på Smooth för att ta bort det kantiga utseendet hos STL-filer.
  6. Tryck M (Measure) och klicka på två punkter på ytan. Linjen visar avståndet, och statusfältet lägger till X-, Y- och Z-delarna. Esc avslutar.
  7. Klicka på Screenshot för att spara vyn som en PNG-fil.

Vad som är gratis och vad Zovo Pro lägger till

Att öppna alla sex formaten, rotera, panorera och zooma, statistikpanelen, scenträdet, Measure, wireframe, normaler, bounding box, rutnät, axlar, glTF-animationer och PNG-skärmbilder är gratis. Det fungerar offline och gör inga nätverksanrop.

Print check ger modellens storlek, volym och ytarea och kontrollerar om meshen är vattentät. Verktyget visar öppna kanter, icke-manifold-kanter, ytor som pekar åt fel håll, trianglar med noll yta och antalet separata delar. Mark problems ritar ut de felaktiga kanterna på modellen. Med material, infill, väggtjocklek, filamentdiameter och pris per kg uppskattar verktyget vikten, filamentlängden och materialkostnaden innan du öppnar din slicer.

Använd Print check (Zovo Pro)

  1. Öppna STL-filen i 3D Model Viewer.
  2. Tryck på ”Run print check” i sidopanelen, eller kör ”3D Model Viewer: Print Check (Zovo Pro)” från Command Palette. Du kan också högerklicka på filen i Explorer och välja ”Zovo Pro: Print check”.
  3. Om meshen har problem trycker du på ”Mark problems” för att se öppna kanter i rött och andra felaktiga kanter i magenta. Välj material (PLA, PETG, ABS, ASA, TPU, nylon, PC eller resin), infill och ditt pris per kg.
  4. Kopiera rapporten, eller spara den som Markdown eller JSON. Ett gratis försök gäller en öppen flik, så du kan ändra inställningarna och köra igen i samma flik.

Print check fungerar 3 gånger gratis på din dator innan en licens behövs. Det finns ingen popup och ingen nedräkning.

Steg i Cursor, Windsurf eller VSCodium

  1. Öppna vyn Extensions med Ctrl+Shift+X (Cmd+Shift+X på macOS).
  2. Sök efter zovo.3d-model-viewer och klicka på Install. Cursor, Windsurf och VSCodium installerar tillägg från Open VSX, där det här tillägget heter zovo/3d-model-viewer.
  3. Om din editor inte har något tilläggsgalleri laddar du ner .vsix-filen från sidan på Open VSX och kör ”Extensions: Install from VSIX...”.
  4. Sedan fungerar allt som i VS Code.

Vad 3D Model Viewer gör

  • STL, binär och ASCII, med färger per yta när filen har dem.
  • OBJ med .mtl-filen som anges av mtllib, när den ligger bredvid modellen.
  • PLY-mesher och punktmoln, ASCII och binära, med vertexfärger.
  • 3MF-objekt, build items och färger från basmaterial.
  • GLB och glTF 2.0 med inbäddade eller externa .bin-buffertar och texturer, PBR-material, nodträd, skins, morph targets och animationer.

Vad det inte gör

  • FBX, DAE, USD, STEP, IGES och glTF 1.0 öppnas inte.
  • glTF som är komprimerad med Draco eller meshopt och KTX2-texturer avkodas inte än. Ett meddelande anger vilken extension som saknas.
  • Hela filen läses in i minnet. Filer över 1024 MB (inställningen modelViewer.maxFileMB) visar ett meddelande och läses inte.
  • STL, OBJ och PLY har ingen enhet, så storlekar och avstånd är råa koordinater. glTF är i meter och 3MF i millimeter om inte filen anger något annat.
  • Print check och Section view läser de synliga mesherna, upp till 3 miljoner trianglar, och kräver en mesh, inte ett punktmoln. Vikten är en uppskattning. Support, brim och topp- och bottenlager räknas inte.

Vanliga frågor

Vilken enhet har mått i STL?

STL-filer har ingen enhet, så visaren visar råa koordinater. Print check läser STL, OBJ och PLY som millimeter, och du kan byta enhet i dess panel om filen använder en annan.

Kan den öppna OBJ-filer med material?

Ja, när .mtl-filen som anges av mtllib ligger bredvid modellen. Texturer och .bin-filer laddas bara från modellens mapp och de öppna mapparna i arbetsytan.

Är det gratis?

Ja. Att öppna modeller, mäta, statistiken, scenträdet och skärmbilder är gratis. Print check, Section view och Turntable export är Zovo Pro-verktyg med 3 gratis försök vardera, därefter 19 USD en gång för alla Zovo-tillägg.

Fungerar det offline?

Ja. Det ritar med three.js inne i VS Code, har ingen telemetri och gör inga nätverksanrop. Det enda undantaget är ett anrop till GitHub när du aktiverar Zovo Pro med GitHub Sponsors.
