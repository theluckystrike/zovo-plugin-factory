Installera det kostnadsfria tillägget SQLite Viewer & Editor och klicka på .db-, .sqlite- eller .sqlite3-filen. Varje tabell öppnas skrivskyddad som ett rutnät, med flikarna Schema och SQL ett klick bort. Tillägget läser också committade rader som fortfarande ligger i -wal-filen. Visning, redigering när du har klickat på Enable editing, Save med säkerhetskopia och CSV-import är gratis. Zovo Pro (19 USD, betalas en gång) lägger till jämförelse av databaser, ER-diagram och export av alla tabeller på en gång, med 3 gratis försök för varje verktyg.

Steg i VS Code

  1. Installera SQLite DB Viewer från Marketplace, eller tryck Ctrl+P (Cmd+P på macOS) och kör ext install zovo.sqlite-table-viewer.
  2. Klicka på en .db-, .sqlite-, .sqlite3-, .db3-, .s3db-, .sl3-, .vscdb- eller .gpkg-fil i Explorer. Den öppnas skrivskyddad som en tabell.
  3. Välj en tabell eller vy till vänster. Klicka på en kolumnrubrik för att sortera, skriv under en rubrik för att filtrera (till exempel 5..9 eller =word), eller sök i alla kolumner på en gång.
  4. Öppna fliken Schema för kolumner, nycklar, främmande nycklar och CREATE-satserna, eller fliken SQL för att köra en sats i taget. De senaste 20 satserna sparas.
  5. Klicka på Enable editing för att ändra data. Dubbelklicka på en cell, skriv det nya värdet och tryck Enter. Varje ändring väntar i en lista med sin SQL och Undo.
  6. Tryck på Save (Ctrl+S, eller Cmd+S på macOS). Save kontrollerar villkoren (constraints), gör en säkerhetskopia som name.db.20261109-143000.bak och ersätter filen i ett enda steg.

Vad som är gratis och vad Zovo Pro lägger till

Att öppna och läsa, fliken SQL, redigering av celler och rader, Save med säkerhetskopia, import av CSV och TSV, tabellverktygen och export av raderna som visas är gratis. Det finns inget konto och ingen provperiod som räknar ner.

Verktyget skriver alla tabeller i databasen i en enda körning, antingen som en Excel-arbetsbok (.xlsx) med ett blad per tabell och en fet, låst rubrikrad, eller som en mapp med en CSV-fil per tabell. Den kostnadsfria exporten sparar bara de rader som visas i en tabell, så du slipper exportera tabellerna en och en. Verktyget läser bara databasen och skriver aldrig till den.

Använd Export All SQLite Tables to Excel or CSV (Zovo Pro)

  1. Med databasen öppen klickar du på knappen DB tools (den har ett litet PRO-märke) i editorns verktygsfält, eller på verktyget i raden ”Pro tools” under verktygsfältet.
  2. Du kan också högerklicka på databasfilen i Explorer och välja ”Zovo Pro: Export All Tables to Excel or CSV”, eller köra ”Export All SQLite Tables to Excel or CSV (Pro)…” från Command Palette.
  3. Välj ”Excel workbook (.xlsx)” eller ”CSV files in a folder” och sedan var filerna ska sparas. Ett försök räknas bara när filerna har skrivits, och Escape kostar ingenting.

Export All SQLite Tables to Excel or CSV fungerar 3 gånger gratis på din dator innan en licens behövs. Det finns ingen popup och ingen nedräkning.

Steg i Cursor, Windsurf eller VSCodium

  1. Öppna vyn Extensions med Ctrl+Shift+X (Cmd+Shift+X på macOS).
  2. Sök efter zovo.sqlite-table-viewer och klicka på Install. Cursor, Windsurf och VSCodium installerar tillägg från Open VSX, där det här tillägget heter zovo/sqlite-table-viewer.
  3. Om din editor inte har något tilläggsgalleri laddar du ner .vsix-filen från sidan på Open VSX och kör ”Extensions: Install from VSIX...”.
  4. Sedan fungerar allt som i VS Code.

Vad SQLite DB Viewer gör

  • Committade rader som fortfarande ligger i -wal-filen, med automatisk omladdning medan ditt program skriver (knappen Live stänger av den).
  • JSON-celler som träd, bilder som bilder och float32-BLOB:ar som vektorer i cellpanelen.
  • Copy som CSV, TSV, JSON eller INSERT-satser, och Export av raderna som visas som CSV, JSON eller SQL INSERT-satser.
  • Import av CSV och TSV till en ny eller befintlig tabell, med förhandsgranskning, kolumnmappning, förloppsindikator och Cancel.
  • Databaser upp till 512 MB, där raderna hämtas en sida i taget.

Vad det inte gör

  • Hela databasen läses in i minnet. Filer över 512 MB visar ett meddelande (inställningen sqliteTableViewer.maxFileSizeMB).
  • Redigering fungerar bara för filer upp till 256 MB (inställningen sqliteTableViewer.editMaxFileSizeMB). Större filer förblir skrivskyddade.
  • Krypterade databaser (SQLCipher, SEE) kan inte öppnas.
  • Redigering fungerar bara för filer på den här datorn. Filer på fjärr- eller virtuella filsystem öppnas skrivskyddade.
  • Ändringar som inte har sparats försvinner när du stänger fliken, och filen förblir som den var.

Vanliga frågor

Är det gratis?

Att öppna, visa, fliken SQL, redigering, Save och CSV-import är gratis, utan konto. De tre Pro-verktygen (Compare SQLite Databases, ER Diagram och Export All Tables) har 3 gratis försök vardera. Därefter behöver de Zovo Pro, 19 USD en gång för alla Zovo-tillägg.

Kan jag redigera rader i VS Code?

Ja. Filen öppnas skrivskyddad, och du klickar på Enable editing för att ändra celler och rader eller köra INSERT och UPDATE. Inget skrivs förrän du trycker på Save, som först gör en säkerhetskopia.

Varför visar en annan visare gamla rader?

I WAL-läge ligger nya commits i -wal-filen tills en checkpoint kopierar in dem i huvudfilen. En visare som bara läser huvudfilen missar dem. Den här läser den committade delen av -wal-filen.

Fungerar det i Cursor?

Ja. Tillägget finns på Open VSX som zovo/sqlite-table-viewer, så Cursor, Windsurf och VSCodium kan installera det.
