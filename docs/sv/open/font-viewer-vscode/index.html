Förhandsgranska en typsnittsfil i VS Code

Installera det kostnadsfria tillägget Font Viewer och klicka på en .ttf-, .otf-, .woff-, .woff2- eller .ttc-fil. Det visar din egen exempeltext i typsnittet, ett vattenfall av storlekar, ett rutnät med glyfer som du kan söka i och licensen och inbäddningsrättigheterna, utan att typsnittet installeras i systemet. Type tester, glyfrutnätet, teckenkartan, fliken Info och Copy CSS @font-face är gratis. Steg i VS Code

  1. Installera Font Viewer från Marketplace, eller tryck Ctrl+P (Cmd+P på macOS) och kör ext install zovo.font-viewer-vscode.
  2. Klicka på en .ttf-, .otf-, .woff-, .woff2-, .ttc- eller .otc-fil i Explorer. Font Viewer är standardeditor för de här filerna, och den ändrar aldrig typsnittet.
  3. Skriv din egen text på fliken Type tester, dra storleksreglaget från 8 till 200 px och läs vattenfallet från 12 till 96 px. Flytta reglagen för ett variabelt typsnitt och slå på och av OpenType-funktioner som liga eller ss01.
  4. Sök på fliken Glyphs efter namn, tecken, U+20AC eller glyf-id. Klicka på en glyf för att se den stor med baslinje, x-höjd och versalhöjd, och kopiera tecknet, dess kodpunkt eller dess kontur som SVG.
  5. Läs täckningen för varje Unicode-block på fliken Characters, till exempel ”Basic Latin 95/128”. Stäng av ”Only characters in the font” för att se vad som saknas.
  6. Läs licens, formgivare, upphovsrätt och inbäddningsrättigheter på fliken Info, och kopiera en färdig @font-face-regel.

Vad som är gratis och vad Zovo Pro lägger till

Att öppna alla typsnitt som stöds, Type tester, glyfrutnätet, teckenkartan, fliken Info och Copy CSS @font-face är gratis. Font Viewer fungerar offline, utan nätverksanrop och utan telemetri.

Font Folder Report listar varje typsnitt i en mapp med familj, stil, vikt, axlar, version, antal glyfer, licens, licens-URL och inbäddningsrättigheter. Listan skrivs som en CSV-fil, en Markdown-tabell eller en fonts.css med en @font-face-regel för varje typsnitt (WOFF2 först). Innan du skickar med en mapp med typsnitt i en app eller på en webbplats ser du i en enda fil vad varje typsnitt får användas till, i stället för att öppna varje typsnitt.

Använd Font Folder Report (Zovo Pro)

  1. Högerklicka på en mapp med typsnitt i Explorer och välj ”Font Folder Report: CSV, Markdown or @font-face CSS… (Pro)”, eller kör ”Font Viewer: Font Folder Report: CSV, Markdown or @font-face CSS… (Pro)” från Command Palette och välj mappen.
  2. Välj format, CSV, Markdown-tabell eller CSS-regler med @font-face.
  3. Spara filen. Standardnamnen är fonts-report.csv, fonts-report.md och fonts.css, och ett försök räknas bara när filen har skrivits.

Font Folder Report fungerar 3 gånger gratis på din dator innan en licens behövs. Det finns ingen popup och ingen nedräkning.

Steg i Cursor, Windsurf eller VSCodium

  1. Öppna vyn Extensions med Ctrl+Shift+X (Cmd+Shift+X på macOS).
  2. Sök efter zovo.font-viewer-vscode och klicka på Install. Cursor, Windsurf och VSCodium installerar tillägg från Open VSX, där det här tillägget heter zovo/font-viewer-vscode.
  3. Om din editor inte har något tilläggsgalleri laddar du ner .vsix-filen från sidan på Open VSX och kör ”Extensions: Install from VSIX...”.
  4. Sedan fungerar allt som i VS Code.

Vad Font Viewer gör

  • TrueType (.ttf) och OpenType (.otf), även variabla typsnitt.
  • Webbtypsnitt i .woff och .woff2. WOFF2 packas upp av tilläggets egen avkodare.
  • Samlingar i .ttc och .otc, med en lista i rubriken där du väljer typsnitt.
  • Stora CJK-typsnitt med 20 000 glyfer, som laddas sida för sida medan du scrollar.
  • Högerklicka på ett typsnitt i Explorer och välj Copy CSS @font-face utan att öppna det.

Vad det inte gör

  • WOFF2-samlingar, SVG-typsnitt, .dfont och Type 1-typsnitt stöds inte.
  • Glyfkonturerna visar standardinstansen av ett variabelt typsnitt. Type tester, vattenfallet och teckenkartan följer axelreglagen.
  • Färgtypsnitt ritas i färg i Type tester och i teckenkartan, men glyfrutnätet visar deras enkla konturer.
  • Filer över 64 MB visar ett meddelande i stället för att öppnas (inställningen fontViewer.maxFileMB).
  • Det är skrivskyddat. Det redigerar inte typsnitt och installerar dem inte i systemet.

Vanliga frågor

Är det gratis?

Visning av typsnitt, Type tester, glyfrutnätet, teckenkartan, fliken Info och Copy CSS @font-face är gratis. De två Pro-verktygen, Convert Font och Font Folder Report, har 3 gratis försök vardera. Därefter behöver de Zovo Pro, 19 USD en gång för alla Zovo-tillägg.

Måste jag installera typsnittet?

Nej. Typsnittet läses från filen och visas bara i fliken Font Viewer. Systemets lista över typsnitt ändras inte.

Kan den öppna en WOFF2 från min build-mapp?

Ja. WOFF2 packas upp av tilläggets egen avkodare, och den öppna vyn laddas om när du sparar ett nytt bygge av typsnittet.

Fungerar det i Cursor?

Ja. Font Viewer finns på Open VSX som zovo/font-viewer-vscode, så Cursor, Windsurf och VSCodium kan installera det.
