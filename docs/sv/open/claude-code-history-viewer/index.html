Läs och återuppta din Claude Code-historik i VS Code

Installera Claude Code History & Codex History Viewer (Agent Session Viewer). Tillägget listar dina Claude Code-sessioner från ~/.claude/projects och dina Codex-sessioner från ~/.codex/sessions i en sidovy, öppnar varje session som ett läsbart transkript och återupptar den i en terminal med ett klick. Läsning, sökning, återupptagning och export av en session till Markdown är gratis, utan konto. Zovo Pro (19 USD, betalas en gång) lägger till en rapport över användning och kostnad, en export som går att dela där hemligheter är bortredigerade, och export av många sessioner till Markdown på en gång. Varje Pro-verktyg har 3 gratis försök.

Steg i VS Code

  1. Installera Agent Session Viewer från Marketplace, eller tryck Ctrl+P (Cmd+P på macOS) och kör ext install zovo.agent-session-viewer.
  2. Klicka på ikonen Agent Sessions i aktivitetsfältet. Vyn Sessions listar sessioner från Claude Code och Codex, grupperade per projektmapp, med subagenter under sessionen som startade dem.
  3. Klicka på en session för att läsa den. Verktygsanrop är ihopfällda, misslyckade anrop får en röd markering och filändringar visas som diffar. Rubriken visar modell, git-branch, antal turer och tokensummor.
  4. Klicka på sökikonen överst i vyn för att hitta en gammal session, eller kör ”Agent Sessions: Search Sessions” från Command Palette. Välj en träff så öppnas sessionen vid träffen.
  5. Klicka på terminalikonen bredvid sessionen (Resume in Terminal). En terminal öppnas i projektmappen och kör claude --resume <id> eller codex resume <id>.
  6. För en sessionsfil i .jsonl i en annan mapp högerklickar du på filen, väljer Open With och sedan Agent Session Viewer.

Vad som är gratis och vad Zovo Pro lägger till

Trädet Sessions, att läsa sessioner, sökning i alla sessioner, Resume in Terminal, Copy Resume Command, export av en session till Markdown, råvyn och Reveal in File Manager är gratis. Det finns ingen gräns för historiken och ingen inloggning.

Share-safe export sparar en session, eller alla sessioner i ett projekt, som en fristående HTML-sida eller en Markdown-fil. API-nycklar, tokens, lösenord i URL:er, värden från .env, privata nycklar, e-postadresser och din hemmapp byts ut mot [REDACTED ...], och meddelandet listar vad som doldes. Du kan skicka en session till en pull request, en granskning eller en överlämning utan att rensa den för hand.

Använd Share-safe export (Zovo Pro)

  1. Öppna sessionen och klicka på knappen Share-safe export i sessionens verktygsfält. Du kan också högerklicka på en session eller en projektmapp i trädet Sessions och välja ”Share-Safe Export, Secrets Redacted (Pro)…”.
  2. När en session är öppen kan du också köra ”Agent Sessions: Share-Safe Export, Secrets Redacted (Pro)…” från Command Palette.
  3. Välj format, HTML-sida eller Markdown, med eller utan verktygsutdata. Välj sedan var filen ska sparas.
  4. Läs exporten innan du delar den. Ett försök räknas bara när filen sparas, och Escape eller Cancel kostar ingenting.

Share-safe export fungerar 3 gånger gratis på din dator innan en licens behövs. Det finns ingen popup och ingen nedräkning.

Steg i Cursor, Windsurf eller VSCodium

  1. Öppna vyn Extensions med Ctrl+Shift+X (Cmd+Shift+X på macOS).
  2. Sök efter zovo.agent-session-viewer och klicka på Install. Cursor, Windsurf och VSCodium installerar tillägg från Open VSX, där det här tillägget heter zovo/agent-session-viewer.
  3. Om din editor inte har något tilläggsgalleri laddar du ner .vsix-filen från sidan på Open VSX och kör ”Extensions: Install from VSIX...”.
  4. Sedan fungerar allt som i VS Code.

Vad Agent Session Viewer gör

  • Claude Code-sessioner i ~/.claude/projects (eller $CLAUDE_CONFIG_DIR/projects) och Codex-sessioner i ~/.codex/sessions (eller $CODEX_HOME/sessions).
  • Subagenter från båda verktygen, under sessionen som startade dem.
  • En rubrik med verktyg, modell, projektmapp, git-branch, längd, antal turer, tokensummor och kostnaden när filen har den (Claude Code skriver den, Codex gör det inte).
  • Filändringar som diffar (Edit, Write och apply_patch), och thinking och sammanfattningar av reasoning i Codex, ihopfällda.
  • Trådnamn i Codex från session_index.jsonl, så trådar som har bytt namn behåller sina namn.

Vad det inte gör

  • Det läser bara Claude Code och Codex. Sessioner från Cursor, Copilot och Gemini CLI stöds inte än.
  • Det är skrivskyddat. Det ändrar, flyttar eller raderar aldrig sessionsfiler, och det har inget kommando för att radera.
  • Sökningen matchar vanlig text, inte reguljära uttryck, och stannar vid 300 träffar.
  • Resume in Terminal kräver att Claude Code eller Codex är installerat och finns i terminalens PATH.
  • Filer läses som standard upp till 256 MB (agentSessionViewer.maxFileSizeMB), och större filer öppnas med sin första del. Reasoning från Codex som lagras krypterat kan inte visas.

Vanliga frågor

Var sparar Claude Code chatthistoriken?

I ~/.claude/projects, med en mapp per projekt och en .jsonl-fil per session. Om CLAUDE_CONFIG_DIR är satt ligger den under den mappen i stället.

Är det gratis?

Ja. Läsning, sökning, återupptagning och export av en session till Markdown är gratis, utan gräns för historiken. De tre Pro-verktygen (rapport över användning och kostnad, share-safe export och export av många sessioner) har 3 gratis försök vardera. Därefter kostar Zovo Pro 19 USD en gång för alla Zovo-tillägg.

Kan jag radera gamla sessioner i visaren?

Nej. Den läser bara dina sessionsfiler och ändrar, flyttar eller raderar dem aldrig.

Är det gjort av Anthropic?

Nej. Det är inte gjort av eller knutet till Anthropic eller OpenAI. Det gör inga nätverksanrop och har ingen telemetri.
