Spela MOV-, MKV-, WebM- och MP4-video med ljud i VS Code

Installera det kostnadsfria tillägget Video Preview with Sound och klicka på videon i Explorer. MP4-, MOV- och M4V-filer med AAC-ljud spelas med ljud utan någon annan installation, eftersom tillägget har en egen ljudavkodare. MKV, WebM, AVI och video som VS Code inte kan avkoda, till exempel Apple ProRes, kräver ffmpeg på datorn. Uppspelning, ljud, undertexter och konvertering är gratis, och Zovo Pro (19 USD, betalas en gång) lägger till Clip export, Frame export och ett kontaktark, med 3 gratis försök för varje verktyg.

Steg i VS Code

  1. Installera Video Preview with Sound från Marketplace, eller tryck Ctrl+P (Cmd+P på macOS) och kör ext install zovo.video-preview-with-sound.
  2. Om videon är en MKV-, WebM-, AVI-, WMV-, FLV-, MPG-, OGV- eller M2TS-fil, eller har ljud i AC-3, E-AC-3 eller DTS, installerar du ffmpeg först. Kör winget install ffmpeg på Windows, sudo apt install ffmpeg på Linux eller brew install ffmpeg på macOS. MP4, MOV och M4V med AAC-ljud behöver inget mer.
  3. Klicka på en .mp4-, .m4v-, .mov-, .webm-, .mkv-, .avi-, .wmv-, .flv-, .mpg-, .mpeg-, .ogv- eller .m2ts-fil i Explorer och tryck på mellanslag för att spela den. Om VS Code frågar vilken editor som ska användas väljer du ”Video Preview with Sound”.
  4. Videon spelas utan ljud tills etiketten visar ”Sound: on”. En MKV eller WebM kopieras till MP4 utan omkodning. ProRes, AVI, WMV och annan video som VS Code inte kan avkoda konverteras till H.264 en gång och sparas i cachen.
  5. Lägg en .srt- eller .vtt-fil med samma namn bredvid videon, så laddas undertexterna automatiskt. Tryck C eller använd CC-menyn för att byta spår eller stänga av dem.
  6. Tryck , och . för att stega en bildruta, [ och ] för att ändra hastigheten från 0,1x till 4x, A och B för att sätta en loop, S för att spara den aktuella bildrutan som PNG i full storlek och P för bild-i-bild.

Vad som är gratis och vad Zovo Pro lägger till

Uppspelning med ljud, den inbyggda AAC-avkodaren, uppspelning av MKV och WebM med ffmpeg, konvertering av video som VS Code inte kan avkoda, undertexter, bild-i-bild, stegning bildruta för bildruta, hastighet, A-B-loopen, att spara aktuell bildruta som PNG (S), metadatapanelen och att fortsätta där du slutade är gratis.

Clip export sparar A-B-delen av en video, eller hela videon, som GIF eller MP4 till en pull request, ett ärende eller dokumentation. GIF-filen skapas i spelaren utan något annat verktyg, med 480 px i 10 fps, 640 px i 15 fps eller upp till 960 px i 15 fps, och högst 60 sekunder. MP4-filen klipps av din egen ffmpeg, antingen som ett exakt klipp som kodas om till H.264 och AAC och börjar på A-bildrutan, eller som en snabb kopia som behåller de ursprungliga strömmarna och börjar på nyckelbildrutan före A.

Använd Clip export (Zovo Pro)

  1. Öppna videon i spelaren. Tryck A i början och B i slutet av den del du vill ha, eller sätt ingenting för att använda hela videon.
  2. Tryck på Clip (med ett PRO-märke) i spelaren, eller på ”Export a Clip as GIF or MP4” i den lilla raden Pro tools under kontrollerna. Du kan också högerklicka på videon i Explorer och välja ”Zovo Pro: Export a Clip as GIF or MP4”.
  3. Välj ”GIF, 480 px wide, 10 fps”, ”GIF, 640 px wide, 15 fps”, ”GIF, up to 960 px wide, 15 fps”, ”MP4, exact cut” eller ”MP4, fast copy”, och välj sedan var filen ska sparas.
  4. Esc stoppar exporten. Ett försök räknas bara när en fil sparas, så en avbruten dialog eller en stoppad export använder inget gratis försök.

Clip export fungerar 3 gånger gratis på din dator innan en licens behövs. Det finns ingen popup och ingen nedräkning.

Steg i Cursor, Windsurf eller VSCodium

  1. Öppna vyn Extensions med Ctrl+Shift+X (Cmd+Shift+X på macOS).
  2. Sök efter zovo.video-preview-with-sound och klicka på Install. Cursor, Windsurf och VSCodium installerar tillägg från Open VSX, där det här tillägget heter zovo/video-preview-with-sound.
  3. Om din editor inte har något tilläggsgalleri laddar du ner .vsix-filen från sidan på Open VSX och kör ”Extensions: Install from VSIX...”.
  4. Sedan fungerar allt som i VS Code.

Vad Video Preview with Sound gör

  • MP4, M4V och MOV med AAC-ljud (mono eller stereo), ALAC, MP3 eller PCM, utan någon annan installation, på Windows, Linux och macOS.
  • MKV och WebM, som ffmpeg kopierar till MP4 och som sedan spelas med ljud.
  • Ljud i AC-3, E-AC-3, DTS, Opus eller 5.1 AAC i MP4, M4V eller MOV, avkodat av ffmpeg eller av afconvert som följer med macOS.
  • Video i Apple ProRes, MPEG-4 Part 2 och DNxHD, och AVI-, WMV-, FLV-, MPG-, MPEG-, OGV- och M2TS-filer, konverterade till H.264 med ffmpeg.
  • Undertexter från .srt- och .vtt-filer bredvid videon.

Vad det inte gör

  • Utan ffmpeg öppnas inte MKV och WebM, på något system. Spelaren säger ”Install ffmpeg to open this file”. ffmpeg följer inte med tillägget.
  • afconvert i macOS kan inte konvertera video och kan inte öppna MKV eller WebM. Konvertering kräver alltid din egen ffmpeg, och en lång ProRes-fil kan ta flera minuter.
  • Den inbyggda avkodaren spelar HE-AAC från dess AAC-LC-kärna med halva samplingsfrekvensen. Installera ffmpeg för full HE-AAC, 5.1 AAC, AC-3 och DTS.
  • Filer större än 4096 MB spelas ändå, men utan ljud (inställningen videoPreview.maxDecodeSizeMB).
  • Undertexter kommer bara från .srt- och .vtt-filer, högst 5 MB vardera. Undertexter inuti videofilen läses inte. .ts- och .mts-filer öppnas inte, eftersom de filnamnen används för TypeScript.

Vanliga frågor

Varför spelar VS Code min MP4 utan ljud?

VS Codes inbyggda Chromium har H.264-avkodaren för bilden men ingen AAC-avkodare, och de flesta MP4- och MOV-filer har AAC-ljud. Det här tillägget avkodar ljudet själv och spelar det i takt med bilden.

Behöver jag ffmpeg?

Inte för MP4, MOV och M4V med ljud i AAC, ALAC, MP3 eller PCM. Du behöver ffmpeg för MKV, WebM, AVI, WMV, FLV, MPG, OGV och M2TS, för ProRes och annan video som VS Code inte kan avkoda, och för MP4-klipp från Clip export. Ljud i AC-3, E-AC-3 och DTS kräver ffmpeg, eller afconvert på macOS.

Är det gratis?

Ja. Uppspelning, ljud, undertexter, stegning bildruta för bildruta, att spara aktuell bildruta som PNG och konvertering är gratis. Clip export, Frame export och kontaktarket är Zovo Pro-verktyg med 3 gratis försök vardera, därefter 19 USD en gång för alla Zovo-tillägg.

Fungerar det i Cursor?

Ja. Tillägget finns på Open VSX som zovo/video-preview-with-sound, så Cursor, Windsurf och VSCodium kan installera det.
