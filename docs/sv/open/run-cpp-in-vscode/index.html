Kör en C++-fil i VS Code med ett klick

Installera det kostnadsfria tillägget Run C++ and C Code, öppna en .cpp- eller .c-fil och klicka på Run i editorns titelrad, eller tryck Ctrl+Alt+Enter (Cmd+Alt+Enter på Mac). Det kompilerar filen med den gcc, g++, clang eller clang++ som redan finns på datorn och kör den i terminalen, där cin och scanf fungerar. Kompileringsfel hamnar i panelen Problems på rätt rad, och panelen Input & Tests, stresstestet och benchmarken är gratis. Zovo Pro (19 USD, betalas en gång) lägger till en sanitizer-kontroll, en jämförelse av -O0, -O2 och -O3 och en testrapport, med 3 gratis försök vardera.

Steg i VS Code

  1. Installera Run C++ and C Code från Marketplace, eller tryck Ctrl+P (Cmd+P på macOS) och kör ext install zovo.zovo-run-cpp.
  2. Kontrollera att en kompilator är installerad. ”Run C++: Pick Compiler (gcc, g++, clang, clang++)” listar vad tillägget hittar. Finns ingen visar en installationssida de officiella stegen för ditt system (Xcode Command Line Tools, MSYS2 eller WinLibs, eller pakethanteraren i Linux).
  3. Öppna en .cpp-, .cc-, .cxx- eller .c-fil och klicka på knappen Run i editorns titelrad, eller tryck Ctrl+Alt+Enter (Cmd+Alt+Enter på Mac).
  4. Programmet körs i en terminal som heter ”Run: file.cpp”. Skriv indata där. På slutet ser du returkoden, körtiden och toppminnet. Medan programmet körs blir knappen Run en Stop-knapp.
  5. För flaggor eller argument skriver du // run: -O2 -lm och // args: "Hello World" 3 bland de första 40 raderna i filen. Standardflaggorna för C++ är -std=c++20 -Wall -Wextra -g -O0.
  6. Kör ”Run C++: Run with Input & Test Cases” för att testa med sparad indata. Klistra in indata, tryck på Run with input och sedan på Save as test case. Run all tests visar godkänt eller underkänt med en radvis diff.

Vad som är gratis och vad Zovo Pro lägger till

Run, Build Only, Run Last Build, Debug, byggen av hela mappar, panelen Input & Tests, stresstestet och benchmarken är gratis. Det kräver ingen inloggning, gör inga nätverksanrop och har ingen telemetri.

Ett program som klarar dina tester kan ändå läsa förbi slutet av en array eller få overflow i en int. Sanitizer check bygger en andra kopia med AddressSanitizer och UndefinedBehaviorSanitizer (-fsanitize=address,undefined), kör den på indatan i panelen och på varje sparat testfall, och lägger varje heap- eller stack-overflow, use after free, signed overflow eller annat odefinierat beteende i panelen Problems på rätt rad. Du hittar felet på dess rad utan att ställa in sanitizer-flaggor för hand.

Använd Sanitizer check (Zovo Pro)

  1. Lägg indata i panelen Input & Tests och spara testfall om du har några. Kontrollen körs på indatan i panelen och på varje sparat testfall.
  2. Klicka på ”Sanitizer check (Pro)” i panelen under ”Stress test, benchmark and more”, eller kör ”Run C++: Sanitizer Check: AddressSanitizer and UBSan on the Input and Test Cases (Zovo Pro)” från Command Palette.
  3. Klicka på ett fynd i panelen Problems för att hoppa till dess rad. Ett byggfel, Stop eller Cancel använder inget gratis försök.

Sanitizer check fungerar 3 gånger gratis på din dator innan en licens behövs. Det finns ingen popup och ingen nedräkning.

Steg i Cursor, Windsurf eller VSCodium

  1. Öppna vyn Extensions med Ctrl+Shift+X (Cmd+Shift+X på macOS).
  2. Sök efter zovo.zovo-run-cpp och klicka på Install. Cursor, Windsurf och VSCodium installerar tillägg från Open VSX, där det här tillägget heter zovo/zovo-run-cpp.
  3. Om din editor inte har något tilläggsgalleri laddar du ner .vsix-filen från sidan på Open VSX och kör ”Extensions: Install from VSIX...”.
  4. Sedan fungerar allt som i VS Code.

Vad Run C++ and C Code gör

  • C- och C++-filer (.c, .cpp, .cc, .cxx) med gcc, g++, clang och clang++.
  • MSYS2, WinLibs, MinGW, TDM-GCC och LLVM i sina vanliga mappar i Windows, och Homebrew-namn som g++-14.
  • Sökvägar med mellanslag, & eller bokstäver utanför ASCII, eftersom inget skal tolkar dem.
  • Program som skriver ut en miljon rader. Panelen visar de första 2 000 och räknar resten.

Vad det inte gör

  • Det kräver en kompilator på datorn och laddar aldrig ner någon.
  • Körningar i panelen Input och testfall stoppas efter 10 sekunder (inställningen zovoRun.timeLimitSeconds).
  • Utdata efter 32 MB räknas men sparas inte (inställningen zovoRun.maxCapturedOutputMB).
  • Sanitizer-kontrollen kräver en kompilator med sanitizer-runtime. MinGW gcc på Windows saknar den, så använd clang från LLVM där. Kontrollen säger det utan att använda ett försök.
  • Debug kräver att CodeLLDB eller tillägget C/C++ är installerat.

Vanliga frågor

Är det gratis?

Run, Build Only, Debug, byggen av hela mappar, panelen Input & Tests, stresstestet och benchmarken är gratis. De tre Pro-verktygen, Sanitizer check, Compare -O0, -O2 and -O3 och Test report, har 3 gratis försök vardera. Därefter behöver de Zovo Pro, 19 USD en gång för alla Zovo-tillägg.

Kan mitt program läsa indata med cin?

Ja. Det körs i en riktig terminal, så cin och scanf väntar på det du skriver, och frågor utan radbrytning visas först.

Ändrar det min settings.json eller tasks.json?

Nej. Det skriver aldrig till dina inställningsfiler. Debug lägger till en post i .vscode/launch.json, och bara när du trycker på Debug.

Fungerar det i Cursor?

Ja. Tillägget finns på Open VSX, så Cursor, Windsurf och VSCodium kan installera det.
