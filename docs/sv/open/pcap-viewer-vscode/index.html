Öppna en PCAP-fil i VS Code

Installera det kostnadsfria tillägget PCAP Viewer och klicka på .pcap- eller .pcapng-filen. Du får en paketlista, ett protokollträd, en hexpanel kopplad till trädet, display filters i Wireshark-stil, follow stream och statistik. Tillägget läser filen själv i JavaScript, så du behöver inte Wireshark, tshark eller sharkd. Visaren är gratis, och Zovo Pro (19 USD, betalas en gång) lägger till export av paketlistan till CSV eller JSON, en rapport om fångsten i Markdown och en sammanfattning av en mapp, med 3 gratis försök för varje verktyg.

Steg i VS Code

  1. Installera PCAP Viewer från Marketplace, eller tryck Ctrl+P (Cmd+P på macOS) och kör ext install zovo.zovo-pcap-viewer.
  2. Klicka på en .pcap-, .pcapng-, .pcap.gz-, .pcapng.gz- eller .ntar-fil. För .cap, .dmp eller andra namn högerklickar du på filen i Explorer och väljer ”Open in PCAP Viewer”.
  3. Skriv ett display filter som tcp.port == 443 && ip.addr == 10.0.0.1 och tryck Enter. Rutan blir grön när filtret är giltigt och säger vad som är fel när det inte är det.
  4. Klicka på ett fält i protokollträdet för att markera dess bytes i hexpanelen, eller klicka på en byte för att hitta dess fält.
  5. Dubbelklicka på ett paket för att följa dess TCP- eller UDP-ström, som ASCII, UTF-8 eller hexdump. Kopiera strömmen eller spara den till en fil.
  6. Klicka på Statistics för protokollhierarki, conversations, endpoints och de namn som finns i fångsten. Klicka på en rad för att filtrera på den.
  7. Öppna menyn Export för att spara de markerade paketen, eller alla paket som filtret visar, som en ny pcap-fil.

Vad som är gratis och vad Zovo Pro lägger till

Paketlistan, protokollträdet, den kopplade hexpanelen, display filters, sparade filter, follow stream, statistik och export av paket som en ny pcap-fil är gratis. Det kräver ingen inloggning och fungerar offline.

Verktyget skriver de paket som filtret visar till en CSV- eller JSON-fil, en rad per paket, med nummer, UTC-tid, sekunder sedan start, källa, mål, portar, protokoll, längd, filter för strömmen, värdnamn från fångsten och Info-texten. CSV-filen öppnas i Excel, där text som liknar formler görs ofarlig, och JSON-filen fungerar med jq och pandas. Du får en tabell till ett ärende eller ett skript utan att kopiera rader för hand.

Använd Export packet list to CSV or JSON (Zovo Pro)

  1. Öppna fångsten och skriv ett display filter om du bara vill ha vissa paket.
  2. Öppna menyn Export i verktygsfältet och välj ”Packet list as CSV” eller ”Packet list as JSON”, eller kör ”PCAP Viewer: Export Packet List to CSV or JSON (Pro)...” från Command Palette. Du kan också högerklicka på fångsten i Explorer och välja ”Zovo Pro: Export packet list to CSV or JSON”.
  3. Välj var filen ska sparas. Ett försök räknas bara när filen har skrivits, så Escape eller ett fel förbrukar inget.

Export packet list to CSV or JSON fungerar 3 gånger gratis på din dator innan en licens behövs. Det finns ingen popup och ingen nedräkning.

Steg i Cursor, Windsurf eller VSCodium

  1. Öppna vyn Extensions med Ctrl+Shift+X (Cmd+Shift+X på macOS).
  2. Sök efter zovo.zovo-pcap-viewer och klicka på Install. Cursor, Windsurf och VSCodium installerar tillägg från Open VSX, där det här tillägget heter zovo/zovo-pcap-viewer.
  3. Om din editor inte har något tilläggsgalleri laddar du ner .vsix-filen från sidan på Open VSX och kör ”Extensions: Install from VSIX...”.
  4. Sedan fungerar allt som i VS Code.

Vad PCAP Viewer gör

  • pcap (mikrosekunder och nanosekunder, little- och big-endian) och pcapng, även som .gz.
  • Ethernet, 802.1Q VLAN, Linux cooked capture (SLL och SLL2), rå IPv4 och IPv6, BSD loopback, 802.11-headers och radiotap.
  • ARP, IPv4, IPv6, ICMP, ICMPv6, TCP, UDP, DNS och mDNS, DHCP, HTTP/1.x, TLS-poster med servernamn (SNI) och ALPN, och QUIC long headers.
  • Stora fångster. I releasetesterna listades en fångst på 1 GB med 1 438 965 paket på ungefär 2 s.
  • Skadade filer. Alla paket före skadan visas, med ett meddelande om vad som är fel och var.

Vad det inte gör

  • Bara protokollen i listan avkodas till fält. HTTP är HTTP/1.x, för 802.11 avkodas headern och för QUIC long header.
  • TLS-trafik dekrypteras inte. Du ser TLS-posterna med servernamn (SNI) och ALPN.
  • Filterrutan tar den vanliga delen av Wiresharks syntax för display filters, inte hela.
  • En .gz-fångst slutar packas upp vid 512 MB (inställningen pcapViewer.maxGzipMB), och visaren säger det.
  • Filer på fjärr- eller virtuella filsystem öppnas upp till 256 MB (inställningen pcapViewer.maxRemoteMB).

Vanliga frågor

Behöver jag ha Wireshark installerat?

Nej. PCAP Viewer läser pcap och pcapng i JavaScript inne i VS Code, på Windows, macOS och Linux. Det använder inte Wireshark, tshark eller sharkd.

Skickar det DNS-frågor när jag öppnar en fångst?

Nej. Värdnamn kommer bara från DNS-svar i paketen och från namnblocken i pcapng-filer. Tillägget har ingen telemetri och gör inga nätverksanrop.

Är det gratis?

Ja. Visaren, filtren, follow stream, statistiken och pcap-exporten är gratis. Export packet list to CSV or JSON, Capture report och Folder summary är Zovo Pro-verktyg med 3 gratis försök vardera, därefter 19 USD en gång för alla Zovo-tillägg.

Fungerar det i Cursor?

Ja. Det fungerar i VS Code 1.90 och senare och i editorer som installerar från Open VSX, till exempel Cursor, Windsurf och VSCodium.
