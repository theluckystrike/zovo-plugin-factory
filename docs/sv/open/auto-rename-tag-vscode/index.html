Byt namn på HTML-, JSX- och Vue-taggar automatiskt i VS Code

Installera det kostnadsfria tillägget Auto Rename Tag & Close Tag Sync och ändra namnet i en start- eller sluttagg. Den matchande taggen ändras medan du skriver. Namnbytet är VS Codes egen linked editing (editor.linkedEditing). Tillägget slår på den inställningen för sina språk och hittar den matchande taggen i HTML, JSX, TSX, Vue, Svelte, Astro, PHP, Blade, Twig, XML, Markdown med flera, så ett enda ångra-steg återställer båda taggarna. Namnbyte, auto close och ramen runt den matchande taggen är gratis, och Zovo Pro (19 USD, betalas en gång) lägger till Rename Tag in All Files och Check Unclosed Tags in All Files, med 3 gratis försök för varje verktyg.

Steg i VS Code

  1. Installera Tag Auto Rename & Close Tag Sync från Marketplace, eller tryck Ctrl+P (Cmd+P på macOS) och kör ext install zovo.zovo-auto-rename-tag.
  2. Öppna en HTML-, JSX-, TSX-, Vue-, Svelte-, PHP- eller annan mallfil och ändra namnet i en starttagg. Sluttaggen ändras medan du skriver, och tvärtom.
  3. Skriv > efter en starttagg så visas sluttaggen efter markören. Skriv </ så fylls namnet på det öppna elementet i.
  4. Ställ markören på en tagg så får båda taggarna en ram i temats färger för hakparenteser.
  5. Högerklicka i editorn för ”Go to Matching Tag” och ”Select Tag Content”. Om du vill skriva ett nytt namn i en ruta kör du ”Tag Sync: Rename Tag Pair…” från Command Palette.
  6. Klicka på Tags i statusfältet för att se vad som är påslaget för filen, eller för att stänga av tillägget för ett språk. Om det står ”Tags: rename off” klickar du på det för att slå på namnbyte för det språket.

Vad som är gratis och vad Zovo Pro lägger till

Namnbyte medan du skriver, auto close på > och </, ramen runt den matchande taggen, Go to Matching Tag, Select Tag Content, Rename Tag Pair… och menyn i statusfältet är gratis. Tillägget har ingen reklam, kräver ingen inloggning och fungerar offline.

Verktyget byter namn på en komponent eller ett element i alla taggfiler i arbetsytan på en gång, till exempel <Button> till <UiButton> i alla .tsx-, .vue-, .html- och mallfiler. Bara taggnamn ändras, aldrig text, attribut, strängar eller kommentarer. Du ser först hur många ändringar det blir, ”Preview first” öppnar VS Codes refactor preview, och ett enda Undo återställer alla filer.

Använd Rename Tag in All Files (Zovo Pro)

  1. Öppna projektmappen i VS Code. Verktyget kräver en öppen mapp.
  2. Kör ”Tag Sync: Rename Tag in All Files… (Pro)” från Command Palette, eller högerklicka på en .html-, .htm-, .vue-, .jsx-, .tsx- eller .svelte-fil i Explorer och välj ”Zovo Pro: Rename Tag in All Files”.
  3. Skriv taggen som ska byta namn så som den står i filerna (till exempel Button), och sedan det nya namnet.
  4. Välj ”Rename”, eller ”Preview first” för att granska ändringarna i refactor preview. Filer som inte var öppna ändras men sparas inte. File > Save All sparar dem, och Undo återställer dem.

Rename Tag in All Files fungerar 3 gånger gratis på din dator innan en licens behövs. Det finns ingen popup och ingen nedräkning.

Steg i Cursor, Windsurf eller VSCodium

  1. Öppna vyn Extensions med Ctrl+Shift+X (Cmd+Shift+X på macOS).
  2. Sök efter zovo.zovo-auto-rename-tag och klicka på Install. Cursor, Windsurf och VSCodium installerar tillägg från Open VSX, där det här tillägget heter zovo/zovo-auto-rename-tag.
  3. Om din editor inte har något tilläggsgalleri laddar du ner .vsix-filen från sidan på Open VSX och kör ”Extensions: Install from VSIX...”.
  4. Sedan fungerar allt som i VS Code.

Vad Tag Auto Rename & Close Tag Sync gör

  • Namnbyte i HTML, JSX och TSX, Vue, Svelte, Astro, PHP, Blade, Twig, Jinja, Nunjucks, Liquid, ERB, EJS, Handlebars, XML, SVG och Markdown.
  • Void-taggar som br, img, input, meta och hr paras aldrig ihop och stängs aldrig.
  • I .tsx räknas bara riktig JSX som taggar. Jämförelser som a < b && c > d och generics som useState<string>() lämnas orörda, och .ts-filer berörs inte.
  • Kommentarer, strängar, innehållet i <script> och <style> och block som {{ }}, {% %}, <?php ?> och <% %> hoppas över.
  • Nya filer som inte har sparats fungerar så snart de har ett språk.

Vad det inte gör

  • I JSX och TSX stänger TypeScript taggar själv, så där lämnar tillägget stängningen åt TypeScript. Sluttaggen från TypeScript är ett eget ångra-steg.
  • När tillägget för Vue, Svelte, Astro eller Red Hat XML är installerat stänger det tillägget taggar i sitt språk, och det här håller sig undan.
  • Filer över 1 MB eller 50 000 rader får inget live-namnbyte, ingen auto close och ingen markering (inställningarna zovoTags.maxFileSizeKB och zovoTags.maxFileLines). Statusfältet säger det, och kommandona fungerar fortfarande.
  • Taggar som skrivs inuti uttryck med {...} i Svelte eller Astro byter inte namn.
  • Om det äldre tillägget Auto Rename Tag eller Auto Close Tag också är på kan båda ändra samma tagg. Behåll bara ett av dem.

Vanliga frågor

Vad är skillnaden mot inställningen editor.linkedEditing?

Tillägget använder editor.linkedEditing för namnbytet. Det slår på inställningen för varje språk det stöder och hittar den matchande taggen i vart och ett av dem, från HTML och Vue till PHP, Twig, XML och JSX. Det stänger också taggar, ritar en ram runt den matchande taggen och lägger till Go to Matching Tag och Select Tag Content. Om du själv har stängt av editor.linkedEditing visar statusfältet ”Tags: rename off”, och ett klick slår på det för det språket.

Fungerar ångra fortfarande?

Ja. Din ändring och ändringen av den matchande taggen är ett enda ångra-steg, eftersom namnbytet använder VS Codes linked editing. En sluttagg från auto close ingår i samma ångra-steg som det > du skrev, utom i JSX och TSX, där TypeScript stänger taggarna.

Är det gratis?

Ja. Namnbyte, auto close, ramen runt den matchande taggen och kommandona i editorn är gratis. Rename Tag in All Files och Check Unclosed Tags in All Files är Zovo Pro-verktyg med 3 gratis försök vardera, därefter 19 USD en gång för alla Zovo-tillägg.

Fungerar det i Cursor?

Ja. Cursor, Windsurf och VSCodium installerar det från Open VSX som zovo/zovo-auto-rename-tag.
