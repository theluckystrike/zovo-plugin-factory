Spela ljudfiler i VS Code

Installera det kostnadsfria tillägget Audio Player & WAV Player och klicka på en .wav-, .mp3-, .flac-, .ogg- eller .opus-fil. Det spelar filen med en vågform för varje kanal, ett spektrogram, en A-B-loop, hastigheter från 0,25x till 2x med bevarad tonhöjd och loudness-värden i LUFS. Opus spelas med den medföljande avkodaren, och M4A- och AAC-filer spelas efter ett klick om du har ffmpeg. Att spela och kontrollera filer är gratis, och Zovo Pro (19 USD, betalas en gång) lägger till två verktyg, Folder Loudness Report och Normalize Loudness, med 3 gratis försök vardera.

Steg i VS Code

  1. Installera Audio Player & WAV Player från Marketplace, eller tryck Ctrl+P (Cmd+P på macOS) och kör ext install zovo.audio-preview-vscode.
  2. Klicka på en .wav-, .mp3-, .flac-, .ogg-, .opus- eller .m4a-fil i Explorer. Om en annan spelare öppnas högerklickar du på filen och väljer ”Open in Audio Preview”.
  3. Tryck på mellanslag för att spela eller pausa. Vänster- och högerpil hoppar 5 sekunder (1 sekund med Shift). Klicka i vågformen för att hoppa dit.
  4. Dra över vågformen för att loopa den delen, eller tryck [ och ] för att sätta loopens start och slut vid spelhuvudet. L slår på eller av loopen.
  5. Välj en hastighet från 0,25x till 2x. Tonhöjden förblir densamma.
  6. Läs headern för codec, samplingsfrekvens, kanaler, bitdjup, längd och bithastighet, panelen Loudness för LUFS, peak och RMS, och panelen Tags för titel, artist, album och övriga taggar.

Vad som är gratis och vad Zovo Pro lägger till

Uppspelning av alla format som stöds, vågformen, spektrogrammet, A-B-loopen, hastigheten, panelerna Loudness, File och Tags och Copy stats är gratis. Ingenting skrivs tillbaka till ljudfilen, och tillägget gör inga nätverksanrop.

Folder Loudness Report skriver en CSV-rad för varje ljudfil i en mapp, med format, längd, samplingsfrekvens, bitdjup, titel och artist, integrated LUFS, högsta short-term och momentary, sample peak, RMS, klippta samplingar och den förstärkning varje fil behöver för att nå -14, -16 och -23 LUFS. Du sorterar och kontrollerar en mapp med inspelningar i ett kalkylark i stället för att öppna varje fil. WAV-filer läses av tillägget självt, medan rader för MP3, FLAC, Ogg, Opus och M4A kräver din egen ffmpeg.

Använd Folder Loudness Report (Zovo Pro)

  1. Högerklicka på en mapp i Explorer och välj ”Folder Loudness Report (CSV, Pro)”, eller kör ”Audio Preview: Folder Loudness Report (CSV, Pro)” från Command Palette och välj mappen. I spelaren finns verktyget också i menyn ”...” i editorns titelrad.
  2. Välj ”This folder and its subfolders” eller ”This folder only” och sedan var loudness-report.csv ska sparas.
  3. En avisering visar förloppet och kan avbrytas. Öppna CSV-filen i ett kalkylark. Ett försök räknas bara när filen har skrivits.

Folder Loudness Report fungerar 3 gånger gratis på din dator innan en licens behövs. Det finns ingen popup och ingen nedräkning.

Steg i Cursor, Windsurf eller VSCodium

  1. Öppna vyn Extensions med Ctrl+Shift+X (Cmd+Shift+X på macOS).
  2. Sök efter zovo.audio-preview-vscode och klicka på Install. Cursor, Windsurf och VSCodium installerar tillägg från Open VSX, där det här tillägget heter zovo/audio-preview-vscode.
  3. Om din editor inte har något tilläggsgalleri laddar du ner .vsix-filen från sidan på Open VSX och kör ”Extensions: Install from VSIX...”.
  4. Sedan fungerar allt som i VS Code.

Vad Audio Player & WAV Player gör

  • WAV (PCM 8 till 32 bitar, float, A-law, mu-law, RF64), som läses i delar om 2 MB så att en stor fil inte låser editorn.
  • MP3, FLAC och Ogg Vorbis med den avkodare som VS Code redan har.
  • Opus i .opus eller .ogg, med den medföljande libopus-avkodaren (WebAssembly).
  • Upp till 8 kanaler, var och en i sitt eget vågformsfält.
  • Taggar från ID3v1, ID3v2.2 till 2.4, RIFF INFO, Vorbis comments och iTunes-atomer.

Vad det inte gör

  • M4A och AAC kräver din egen ffmpeg. Utan den ser du codec, längd, bithastighet och taggar, och ett meddelande.
  • ALAC, AC-3 och andra codecs som VS Code inte kan avkoda kräver också ffmpeg-knappen.
  • Komprimerade filer avkodas i sin helhet. Över 600 MB avkodade samplingar (ungefär 28 minuter stereo i 44,1 kHz) spelas de bara upp (inställningen audioPreview.maxDecodedMB).
  • Peak är sample peak, inte en översamplad true peak, och det finns inget loudness range (LRA).
  • Det spelar och kontrollerar filer. Det klipper eller redigerar dem inte.

Vanliga frågor

Är det gratis?

Uppspelning, vågformen, spektrogrammet, loopen och loudness-värdena är gratis. De två Pro-verktygen, Folder Loudness Report och Normalize Loudness, har 3 gratis försök vardera. Därefter behöver de Zovo Pro, 19 USD en gång för alla Zovo-tillägg.

Varför spelas inte min .opus-fil i VS Code?

VS Code levereras med Chromium utan Opus-avkodare. Det här tillägget har libopus kompilerat till WebAssembly, så Opus spelas utan att du installerar något mer.

Varför visar min M4A ett meddelande i stället för att spelas?

VS Code har inte heller någon AAC-avkodare. Med ffmpeg installerat gör knappen Decode with ffmpeg en WAV-kopia i tilläggets lagringsmapp, och sedan spelas filen. Ingenting följer med tillägget eller laddas ner.

Fungerar det i Cursor?

Ja. Tillägget finns på Open VSX som zovo/audio-preview-vscode, så Cursor, Windsurf och VSCodium kan installera det.
