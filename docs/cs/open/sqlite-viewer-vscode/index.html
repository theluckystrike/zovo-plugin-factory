Otevření databáze SQLite ve VS Code

Nainstalujte bezplatné rozšíření SQLite Viewer & Editor a klikněte na soubor .db, .sqlite nebo .sqlite3. Každá tabulka se otevře jako mřížka jen pro čtení a karty Schema a SQL jsou o jedno kliknutí dál. Rozšíření čte i potvrzené řádky, které jsou ještě v souboru -wal. Prohlížení, úpravy po kliknutí na Enable editing, Save se zálohou a import CSV jsou zdarma. Zovo Pro (19 USD jednorázově) přidává porovnání databází, ER diagramy a export všech tabulek najednou, každý nástroj se 3 pokusy zdarma.

Postup ve VS Code

  1. Nainstalujte SQLite DB Viewer z Marketplace, nebo stiskněte Ctrl+P (na macOS Cmd+P) a spusťte ext install zovo.sqlite-table-viewer.
  2. Klikněte v Exploreru na soubor .db, .sqlite, .sqlite3, .db3, .s3db, .sl3, .vscdb nebo .gpkg. Otevře se jako tabulka, jen pro čtení.
  3. Vlevo vyberte tabulku nebo pohled (view). Kliknutím na záhlaví sloupce řadíte, psaním pod záhlaví filtrujete (například 5..9 nebo =word), nebo hledáte ve všech sloupcích najednou.
  4. Karta Schema ukáže sloupce, klíče, cizí klíče a příkazy CREATE. Karta SQL spouští vždy jeden příkaz. Posledních 20 příkazů se uchová.
  5. Data změníte po kliknutí na Enable editing. Dvakrát klikněte na buňku, napište novou hodnotu a stiskněte Enter. Každá změna čeká v seznamu čekajících změn se svým SQL a tlačítkem Undo.
  6. Stiskněte Save (Ctrl+S, na macOS Cmd+S). Save zkontroluje omezení (constraints), vytvoří záložní kopii, například name.db.20261109-143000.bak, a nahradí soubor v jednom kroku.

Co je zdarma a co přidává Zovo Pro

Otevírání a čtení, karta SQL, úpravy buněk a řádků, Save se zálohou, import CSV a TSV, nástroje tabulky a export zobrazených řádků jsou zdarma. Nepotřebujete účet a neběží žádný zkušební odpočet.

Tento nástroj zapíše všechny tabulky databáze v jednom běhu, buď jako jeden sešit Excel (.xlsx) s listem pro každou tabulku a tučným ukotveným řádkem záhlaví, nebo jako složku s jedním souborem CSV na tabulku. Bezplatný Export uloží jen zobrazené řádky jedné tabulky, takže tabulky nemusíte exportovat jednu po druhé. Databázi jen čte a nikdy do ní nezapisuje.

Jak použít Export All SQLite Tables to Excel or CSV (Zovo Pro)

  1. S otevřenou databází klikněte na tlačítko DB tools (má malý odznak PRO) na panelu nástrojů editoru, nebo klikněte na nástroj v řádku „Pro tools“ pod panelem nástrojů.
  2. Nebo klikněte pravým tlačítkem na soubor databáze v Exploreru a zvolte „Zovo Pro: Export All Tables to Excel or CSV“, případně spusťte z Command Palette „Export All SQLite Tables to Excel or CSV (Pro)…“.
  3. Zvolte „Excel workbook (.xlsx)“ nebo „CSV files in a folder“ a vyberte místo uložení. Pokus se započítá, až když se soubory zapíšou. Escape nic nestojí.

Export All SQLite Tables to Excel or CSV můžete na svém počítači 3krát použít zdarma, teprve potom si řekne o licenci. Neobjeví se žádné vyskakovací okno ani odpočet.

Postup v Cursoru, Windsurfu nebo VSCodiu

  1. Otevřete pohled Extensions zkratkou Ctrl+Shift+X (na macOS Cmd+Shift+X).
  2. Vyhledejte zovo.sqlite-table-viewer a klikněte na Install. Cursor, Windsurf a VSCodium instalují rozšíření z Open VSX, kde má toto rozšíření název zovo/sqlite-table-viewer.
  3. Pokud váš editor nemá galerii rozšíření, stáhněte soubor .vsix ze stránky Open VSX a spusťte „Extensions: Install from VSIX...“.
  4. Dál vše funguje stejně jako ve VS Code.

Co umí SQLite DB Viewer

  • Potvrzené řádky, které jsou ještě v souboru -wal, s živým obnovováním, zatímco vaše aplikace zapisuje (tlačítko Live ho vypne).
  • Buňky JSON jako strom, obrázky jako obrázky a BLOBy float32 jako vektory v panelu buňky.
  • Kopírování jako CSV, TSV, JSON nebo příkazy INSERT a export zobrazených řádků jako CSV, JSON nebo příkazy SQL INSERT.
  • Import CSV a TSV do nové nebo existující tabulky, s náhledem, mapováním sloupců, ukazatelem průběhu a tlačítkem Cancel.
  • Databáze do 512 MB, řádky se načítají po stránkách.

Co neumí

  • Celá databáze se načte do paměti. Soubory nad 512 MB ukážou zprávu (nastavení sqliteTableViewer.maxFileSizeMB).
  • Úpravy jsou možné jen u souborů do 256 MB (nastavení sqliteTableViewer.editMaxFileSizeMB). Větší soubory zůstanou jen pro čtení.
  • Šifrované databáze (SQLCipher, SEE) nejde otevřít.
  • Úpravy fungují jen u souborů v tomto počítači. Soubory ve vzdálených nebo virtuálních souborových systémech se otevřou jen pro čtení.
  • Neuložené změny se při zavření karty zahodí a soubor zůstane, jak byl.

Časté otázky

Je to zdarma?

Otevírání, prohlížení, karta SQL, úpravy, Save a import CSV jsou zdarma, bez účtu. Tři nástroje Pro (Compare SQLite Databases, ER Diagram a Export All Tables) mají každý 3 pokusy zdarma. Pak potřebují Zovo Pro, 19 USD jednorázově za všechna rozšíření Zovo.

Můžu ve VS Code upravovat řádky?

Ano. Soubor se otevře jen pro čtení. Po kliknutí na Enable editing můžete měnit buňky a řádky nebo spouštět INSERT a UPDATE. Nic se nezapíše, dokud nestisknete Save, který nejdřív vytvoří záložní kopii.

Proč jiný prohlížeč ukazuje staré řádky?

V režimu WAL zůstávají nové commity v souboru -wal, dokud je checkpoint nepřekopíruje do hlavního souboru. Prohlížeč, který čte jen hlavní soubor, je nevidí. Toto rozšíření čte potvrzenou část souboru -wal.

Funguje to v Cursoru?

Ano. Rozšíření je na Open VSX jako zovo/sqlite-table-viewer, takže ho Cursor, Windsurf a VSCodium mohou nainstalovat.
