Automatické přejmenování tagů HTML, JSX a Vue ve VS Code

Nainstalujte bezplatné rozšíření Auto Rename Tag & Close Tag Sync a změňte název v otevíracím nebo uzavíracím tagu. Párový tag se mění, jak píšete. Přejmenování je vlastní linked editing VS Code (editor.linkedEditing). Rozšíření toto nastavení zapne pro své jazyky a najde párový tag v HTML, JSX, TSX, Vue, Svelte, Astro, PHP, Blade, Twig, XML, Markdownu a dalších, takže jedno vrácení zpět (undo) obnoví oba tagy. Přejmenování, automatické uzavírání a rámeček kolem párového tagu jsou zdarma. Zovo Pro (19 USD jednorázově) přidává Rename Tag in All Files a Check Unclosed Tags in All Files, každý nástroj se 3 pokusy zdarma.

Postup ve VS Code

  1. Nainstalujte Tag Auto Rename & Close Tag Sync z Marketplace, nebo stiskněte Ctrl+P (na macOS Cmd+P) a spusťte ext install zovo.zovo-auto-rename-tag.
  2. Otevřete soubor HTML, JSX, TSX, Vue, Svelte, PHP nebo jinou šablonu a změňte název v otevíracím tagu. Uzavírací tag se mění, jak píšete, a funguje to i obráceně.
  3. Napište > za otevírací tag a za kurzorem se objeví uzavírací tag. Napište </ a doplní se název otevřeného prvku.
  4. Postavte kurzor na tag a oba tagy dostanou rámeček v barvách závorek vašeho motivu.
  5. Po kliknutí pravým tlačítkem v editoru najdete „Go to Matching Tag“ a „Select Tag Content“. Chcete-li nový název napsat do okna, spusťte z Command Palette „Tag Sync: Rename Tag Pair…“.
  6. Klikněte na položku Tags ve stavovém řádku a uvidíte, co je pro tento soubor zapnuté, nebo rozšíření vypnete pro jeden jazyk. Pokud ukazuje „Tags: rename off“, kliknutím přejmenování pro tento jazyk zapnete.

Co je zdarma a co přidává Zovo Pro

Přejmenování při psaní, automatické uzavírání po > a </, rámeček kolem párového tagu, Go to Matching Tag, Select Tag Content, Rename Tag Pair… a nabídka ve stavovém řádku jsou zdarma. Rozšíření nemá reklamy, nepotřebuje přihlášení a funguje offline.

Přejmenuje komponentu nebo prvek ve všech souborech s tagy v pracovním prostoru najednou, například <Button> na <UiButton> ve všech souborech .tsx, .vue, .html a v šablonách. Mění se jen názvy tagů, nikdy text, atributy, řetězce ani komentáře. Nejdřív uvidíte počet změn, „Preview first“ otevře náhled refaktoringu ve VS Code a jedno Undo vrátí všechny soubory.

Jak použít Rename Tag in All Files (Zovo Pro)

  1. Otevřete složku projektu ve VS Code. Nástroj potřebuje otevřenou složku.
  2. Spusťte z Command Palette „Tag Sync: Rename Tag in All Files… (Pro)“, nebo klikněte v Exploreru pravým tlačítkem na soubor .html, .htm, .vue, .jsx, .tsx nebo .svelte a zvolte „Zovo Pro: Rename Tag in All Files“.
  3. Napište tag, který chcete přejmenovat, tak, jak je zapsaný v souborech (například Button), a pak nový název.
  4. Zvolte „Rename“, nebo „Preview first“ a změny zkontrolujte v náhledu refaktoringu. Soubory, které nebyly otevřené, se změní, ale neuloží. File > Save All je uloží a Undo je vrátí.

Postup v Cursoru, Windsurfu nebo VSCodiu

  1. Otevřete pohled Extensions zkratkou Ctrl+Shift+X (na macOS Cmd+Shift+X).
  2. Vyhledejte zovo.zovo-auto-rename-tag a klikněte na Install. Cursor, Windsurf a VSCodium instalují rozšíření z Open VSX, kde má toto rozšíření název zovo/zovo-auto-rename-tag.
  3. Pokud váš editor nemá galerii rozšíření, stáhněte soubor .vsix ze stránky Open VSX a spusťte „Extensions: Install from VSIX...“.
  4. Dál vše funguje stejně jako ve VS Code.

Co umí Tag Auto Rename & Close Tag Sync

  • Přejmenování v HTML, JSX a TSX, Vue, Svelte, Astro, PHP, Blade, Twig, Jinja, Nunjucks, Liquid, ERB, EJS, Handlebars, XML, SVG a Markdownu.
  • Prázdné (void) tagy jako br, img, input, meta a hr se nikdy nepárují ani neuzavírají.
  • V .tsx je tagem jen skutečné JSX. Porovnání jako a < b && c > d a generika jako useState<string>() zůstanou beze změny a soubory .ts rozšíření nechává být.
  • Komentáře, řetězce, obsah <script> a <style> a bloky {{ }}, {% %}, <?php ?> a <% %> se přeskakují.
  • Nové neuložené soubory fungují, jakmile mají nastavený jazyk.

Co neumí

  • V JSX a TSX uzavírá tagy sám TypeScript, takže tam to rozšíření nechává na něm. Uzavírací tag od TypeScriptu je samostatný krok undo.
  • Když je nainstalované rozšíření Vue, Svelte, Astro nebo Red Hat XML, uzavírá tagy ve svém jazyce ono a toto rozšíření se do toho nevměšuje.
  • Soubory nad 1 MB nebo 50 000 řádků nemají živé přejmenování, uzavírání ani zvýraznění (nastavení zovoTags.maxFileSizeKB a zovoTags.maxFileLines). Stavový řádek to oznámí a příkazy dál fungují.
  • Tagy zapsané uvnitř výrazů {...} ve Svelte nebo Astro se nepřejmenují.
  • Pokud je zapnuté i starší rozšíření Auto Rename Tag nebo Auto Close Tag, mohou obě upravovat tentýž tag. Nechte zapnuté jen jedno z nich.

Časté otázky

Čím se liší od nastavení editor.linkedEditing?

Rozšíření používá editor.linkedEditing pro přejmenování. Toto nastavení zapne pro každý podporovaný jazyk a v každém z nich najde párový tag, od HTML a Vue po PHP, Twig, XML a JSX. Navíc uzavírá tagy, kreslí rámeček kolem párového tagu a přidává Go to Matching Tag a Select Tag Content. Pokud jste editor.linkedEditing sami vypnuli, stavový řádek ukáže „Tags: rename off“ a kliknutím ho pro daný jazyk zapnete.

Funguje dál undo?

Ano. Vaše úprava a změna párového tagu jsou jeden krok undo, protože přejmenování používá linked editing ve VS Code. Uzavírací tag z automatického uzavírání patří do kroku undo napsaného >, kromě JSX a TSX, kde tagy uzavírá TypeScript.

Je to zdarma?

Ano. Přejmenování, automatické uzavírání, rámeček kolem párového tagu a příkazy v editoru jsou zdarma. Rename Tag in All Files a Check Unclosed Tags in All Files jsou nástroje Zovo Pro, každý se 3 pokusy zdarma, pak 19 USD jednorázově za všechna rozšíření Zovo.

Funguje to v Cursoru?

Ano. Cursor, Windsurf a VSCodium ho instalují z Open VSX jako zovo/zovo-auto-rename-tag.
