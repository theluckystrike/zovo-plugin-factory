Zobrazení souborů STL ve VS Code

Nainstalujte bezplatný 3D Model Viewer a klikněte v Exploreru na soubor .stl. Tažením model otáčíte, tažením pravým tlačítkem nebo se Shiftem posouváte, kolečkem zoomujete a klávesou M změříte vzdálenost mezi dvěma body. Stejné rozšíření otevře OBJ, PLY, 3MF, GLB a glTF. Otevírání, měření a strom scény jsou zdarma. Zovo Pro (19 USD jednorázově) přidává Print check, Section view a Turntable export, každý nástroj se 3 pokusy zdarma.

Postup ve VS Code

  1. Nainstalujte 3D Model Viewer z Marketplace, nebo stiskněte Ctrl+P (na macOS Cmd+P) a spusťte ext install zovo.3d-model-viewer.
  2. Klikněte v Exploreru na soubor .stl, .obj, .ply, .3mf, .glb nebo .gltf. Pokud se otevře jiný prohlížeč, klikněte na soubor pravým tlačítkem a zvolte „Open in 3D Model Viewer“.
  3. Tažením otáčíte, tažením pravým tlačítkem nebo se Shiftem posouváte a kolečkem zoomujete. Klávesa F vejde celý model do pohledu.
  4. V panelu si přečtěte počet vrcholů, trojúhelníků, materiálů a textur a velikost v jednotkách modelu. Klávesa P panel a strom scény ukáže nebo skryje.
  5. W zapne drátový model, N normály vrcholů a B ohraničující kvádr. Nastavte Shading na Smooth a plošky typické pro soubory STL zmizí.
  6. Stiskněte M (Measure) a klikněte na dva body povrchu. Čára ukáže vzdálenost a stavový řádek přidá složky X, Y a Z. Esc měření ukončí.
  7. Kliknutím na Screenshot uložíte pohled jako soubor PNG.

Co je zdarma a co přidává Zovo Pro

Otevírání všech šesti formátů, otáčení, posun a zoom, panel statistik, strom scény, Measure, drátový model, normály, ohraničující kvádr, mřížka, osy, animace glTF a snímky obrazovky PNG jsou zdarma. Funguje offline a nedělá žádná síťová volání.

Print check uvede rozměry, objem a plochu povrchu modelu a zkontroluje, zda je síť vodotěsná, tedy otevřené hrany, nemanifoldní hrany, plochy otočené špatným směrem, trojúhelníky s nulovou plochou a počet samostatných dílů. Mark problems vykreslí vadné hrany přímo na modelu. S materiálem, výplní, tloušťkou stěny, průměrem filamentu a cenou za kg odhadne hmotnost, délku filamentu a cenu materiálu dřív, než otevřete slicer.

Jak použít Print check (Zovo Pro)

  1. Otevřete soubor STL v 3D Model Viewer.
  2. Stiskněte „Run print check“ v bočním panelu, nebo spusťte z Command Palette „3D Model Viewer: Print Check (Zovo Pro)“. Můžete také kliknout pravým tlačítkem na soubor v Exploreru a zvolit „Zovo Pro: Print check“.
  3. Pokud má síť problémy, stiskněte „Mark problems“ a otevřené hrany uvidíte červeně a ostatní vadné hrany purpurově. Zvolte materiál (PLA, PETG, ABS, ASA, TPU, nylon, PC nebo pryskyřice), výplň a svou cenu za kg.
  4. Zprávu zkopírujte, nebo ji uložte jako Markdown či JSON. Jeden pokus zdarma platí pro jednu otevřenou kartu souboru, takže v ní můžete měnit nastavení a kontrolu spustit znovu.

Print check můžete na svém počítači 3krát použít zdarma, teprve potom si řekne o licenci. Neobjeví se žádné vyskakovací okno ani odpočet.

Postup v Cursoru, Windsurfu nebo VSCodiu

  1. Otevřete pohled Extensions zkratkou Ctrl+Shift+X (na macOS Cmd+Shift+X).
  2. Vyhledejte zovo.3d-model-viewer a klikněte na Install. Cursor, Windsurf a VSCodium instalují rozšíření z Open VSX, kde má toto rozšíření název zovo/3d-model-viewer.
  3. Pokud váš editor nemá galerii rozšíření, stáhněte soubor .vsix ze stránky Open VSX a spusťte „Extensions: Install from VSIX...“.
  4. Dál vše funguje stejně jako ve VS Code.

Co umí 3D Model Viewer

  • STL, binární i ASCII, s barvami ploch, když je soubor obsahuje.
  • OBJ se souborem .mtl uvedeným v mtllib, když leží vedle modelu.
  • Sítě a mračna bodů PLY, ASCII i binární, s barvami vrcholů.
  • Objekty 3MF, položky sestavení (build items) a barvy základních materiálů.
  • GLB a glTF 2.0 s vloženými nebo externími buffery .bin a texturami, materiály PBR, stromem uzlů, skiny, morph targety a animacemi.

Co neumí

  • Soubory FBX, DAE, USD, STEP, IGES a glTF 1.0 se neotevřou.
  • glTF komprimované přes Draco a meshopt a textury KTX2 se zatím nedekódují. Zpráva uvede chybějící rozšíření formátu.
  • Celý soubor se načte do paměti. Soubory nad 1024 MB (nastavení modelViewer.maxFileMB) ukážou zprávu a nenačtou se.
  • STL, OBJ a PLY nemají jednotku, takže rozměry a vzdálenosti jsou surové souřadnice. glTF je v metrech a 3MF v milimetrech, pokud soubor neuvádí jinak.
  • Print check a Section view čtou viditelné sítě, nejvýš 3 miliony trojúhelníků, a potřebují síť, ne mračno bodů. Hmotnost je odhad. Podpěry, lem (brim) a horní a spodní vrstvy se nepočítají.

Časté otázky

V jakých jednotkách jsou měření STL?

Soubory STL nenesou jednotku, takže prohlížeč ukazuje surové souřadnice. Print check čte STL, OBJ a PLY jako milimetry a jednotku můžete v jeho panelu změnit, pokud soubor používá jinou.

Otevře soubory OBJ s materiály?

Ano, když soubor .mtl uvedený v mtllib leží vedle modelu. Textury a soubory .bin se načítají jen ze složky modelu a z otevřených složek pracovního prostoru.

Je to zdarma?

Ano. Otevírání modelů, měření, statistiky, strom scény a snímky obrazovky jsou zdarma. Print check, Section view a Turntable export jsou nástroje Zovo Pro, každý se 3 pokusy zdarma, pak 19 USD jednorázově za všechna rozšíření Zovo.

Funguje offline?

Ano. Kreslí pomocí three.js uvnitř VS Code, nemá telemetrii a nedělá síťová volání. Jedinou výjimkou je volání na GitHub, když Zovo Pro aktivujete přes GitHub Sponsors.
