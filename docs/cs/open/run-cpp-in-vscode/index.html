Spuštění souboru C++ ve VS Code jedním kliknutím

Nainstalujte bezplatné rozšíření Run C++ and C Code, otevřete soubor .cpp nebo .c a klikněte na Run v záhlaví editoru, nebo stiskněte Ctrl+Alt+Enter (na Macu Cmd+Alt+Enter). Soubor zkompiluje gcc, g++, clang nebo clang++, který už máte v počítači, a spustí ho v terminálu, kde fungují cin a scanf. Chyby kompilátoru jdou do panelu Problems na správný řádek. Panel Input & Tests, stress test a benchmark jsou zdarma. Zovo Pro (19 USD jednorázově) přidává kontrolu sanitizery, porovnání -O0, -O2 a -O3 a zprávu o testech, každý nástroj se 3 pokusy zdarma.

Postup ve VS Code

  1. Nainstalujte Run C++ and C Code z Marketplace, nebo stiskněte Ctrl+P (na macOS Cmd+P) a spusťte ext install zovo.zovo-run-cpp.
  2. Ověřte, že máte nainstalovaný kompilátor. „Run C++: Pick Compiler (gcc, g++, clang, clang++)“ vypíše, co najde. Pokud žádný není, stránka nastavení ukáže oficiální postup pro váš systém (Xcode Command Line Tools, MSYS2 nebo WinLibs, nebo správce balíčků vašeho Linuxu).
  3. Otevřete soubor .cpp, .cc, .cxx nebo .c a klikněte na tlačítko Run v záhlaví editoru, nebo stiskněte Ctrl+Alt+Enter (na Macu Cmd+Alt+Enter).
  4. Program běží v terminálu s názvem „Run: file.cpp“. Vstup pište tam. Na konci uvidíte návratový kód, dobu běhu a nejvyšší využití paměti. Během běhu se tlačítko Run změní na Stop.
  5. Přepínače nebo argumenty zadáte řádky // run: -O2 -lm a // args: "Hello World" 3 v prvních 40 řádcích souboru. Výchozí přepínače pro C++ jsou -std=c++20 -Wall -Wextra -g -O0.
  6. Pro test s uloženým vstupem spusťte „Run C++: Run with Input & Test Cases“. Vložte vstup, stiskněte Run with input a pak Save as test case. Run all tests ukáže úspěch nebo selhání s rozdílem po řádcích.

Co je zdarma a co přidává Zovo Pro

Run, Build Only, Run Last Build, Debug, sestavení celé složky, panel Input & Tests, stress test a benchmark jsou zdarma. Nepotřebuje přihlášení, nedělá síťová volání a nemá telemetrii.

Program, který projde vašimi testy, může přesto číst za koncem pole nebo přetéct int. Sanitizer check sestaví druhou kopii s AddressSanitizer a UndefinedBehaviorSanitizer (-fsanitize=address,undefined), spustí ji na vstupu z panelu a na každém uloženém testovacím případu a každé přetečení haldy nebo zásobníku, use after free, přetečení čísla se znaménkem nebo jiné nedefinované chování zapíše do panelu Problems na jeho řádek. Chybu najdete na jejím řádku, aniž byste ručně nastavovali přepínače sanitizerů.

Jak použít Sanitizer check (Zovo Pro)

  1. Dejte vstup do panelu Input & Tests a uložte testovací případy, pokud je máte. Kontrola běží na vstupu z panelu a na každém uloženém testovacím případu.
  2. Klikněte na „Sanitizer check (Pro)“ v panelu pod „Stress test, benchmark and more“, nebo spusťte z Command Palette „Run C++: Sanitizer Check: AddressSanitizer and UBSan on the Input and Test Cases (Zovo Pro)“.
  3. Kliknutím na nález v panelu Problems skočíte na jeho řádek. Chyba sestavení, Stop ani Cancel pokus zdarma nespotřebují.

Sanitizer check můžete na svém počítači 3krát použít zdarma, teprve potom si řekne o licenci. Neobjeví se žádné vyskakovací okno ani odpočet.

Postup v Cursoru, Windsurfu nebo VSCodiu

  1. Otevřete pohled Extensions zkratkou Ctrl+Shift+X (na macOS Cmd+Shift+X).
  2. Vyhledejte zovo.zovo-run-cpp a klikněte na Install. Cursor, Windsurf a VSCodium instalují rozšíření z Open VSX, kde má toto rozšíření název zovo/zovo-run-cpp.
  3. Pokud váš editor nemá galerii rozšíření, stáhněte soubor .vsix ze stránky Open VSX a spusťte „Extensions: Install from VSIX...“.
  4. Dál vše funguje stejně jako ve VS Code.

Co umí Run C++ and C Code

  • Soubory C a C++ (.c, .cpp, .cc, .cxx) s gcc, g++, clang a clang++.
  • MSYS2, WinLibs, MinGW, TDM-GCC a LLVM v jejich obvyklých složkách ve Windows a názvy z Homebrew jako g++-14.
  • Cesty s mezerami, & nebo znaky mimo ASCII, protože je neparsuje žádný shell.
  • Programy, které vypíšou milion řádků. Panel ukáže prvních 2 000 a zbytek spočítá.

Co neumí

  • Potřebuje kompilátor ve vašem počítači a nikdy žádný nestahuje.
  • Běhy v panelu Input a testovací případy se zastaví po 10 sekundách (nastavení zovoRun.timeLimitSeconds).
  • Výstup nad 32 MB se jen počítá, neuchovává se (nastavení zovoRun.maxCapturedOutputMB).
  • Kontrola sanitizery potřebuje kompilátor s runtime sanitizerů. MinGW gcc ve Windows ho nemá, proto tam použijte clang z LLVM. Kontrola to oznámí, aniž by spotřebovala pokus.
  • Debug potřebuje nainstalované CodeLLDB nebo rozšíření C/C++.

Časté otázky

Je to zdarma?

Run, Build Only, Debug, sestavení celé složky, panel Input & Tests, stress test a benchmark jsou zdarma. Tři nástroje Pro, Sanitizer check, Compare -O0, -O2 and -O3 a Test report, mají každý 3 pokusy zdarma. Pak potřebují Zovo Pro, 19 USD jednorázově za všechna rozšíření Zovo.

Může můj program číst vstup přes cin?

Ano. Běží ve skutečném terminálu, takže cin a scanf čekají na to, co napíšete, a výzvy bez konce řádku se zobrazí předem.

Mění můj settings.json nebo tasks.json?

Ne. Nikdy nezapisuje do vašich souborů nastavení. Debug přidá jednu položku do .vscode/launch.json, a to jen když stisknete Debug.

Funguje to v Cursoru?

Ano. Rozšíření je na Open VSX, takže ho Cursor, Windsurf a VSCodium mohou nainstalovat.
