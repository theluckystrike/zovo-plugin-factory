Náhled diagramů Mermaid ve VS Code

VS Code nemá vlastní náhled Mermaid. Nainstalujte bezplatný Mermaid Viewer, otevřete soubor .mmd nebo .mermaid a klikněte na ikonu náhledu vpravo nahoře v editoru. Diagram se mění, jak píšete. U souboru Markdown náhled vypíše každý blok mermaid. Mermaid 12.3.0 je přímo v rozšíření, takže náhled a export do PNG nebo SVG jsou zdarma a fungují offline bez přihlášení. Zovo Pro (19 USD jednorázově) přidává export do PDF, export všech diagramů v pracovním prostoru a export při uložení, každý nástroj se 3 pokusy zdarma.

Postup ve VS Code

  1. Nainstalujte Mermaid Viewer z Marketplace, nebo stiskněte Ctrl+P (na macOS Cmd+P) a spusťte ext install zovo.mermaid-viewer.
  2. Otevřete soubor .mmd nebo .mermaid a klikněte na ikonu náhledu v záhlaví editoru, nebo stiskněte Ctrl+K V (na macOS Cmd+K V). Můžete také spustit z Command Palette „Mermaid Viewer: Open Diagram Editor (Text + Live Preview)“.
  3. U souboru Markdown s bloky ```mermaid klikněte na stejnou ikonu náhledu. Náhled vypíše každý diagram, každý s vlastním řádkem chyby a vlastními tlačítky exportu.
  4. Kliknutím na „Edit diagram“ nad blokem v souboru Markdown blok upravíte vedle živého náhledu. Po uložení se text vrátí do svého bloku.
  5. Kolečkem zoomujete u ukazatele a tažením posouváte. Fit a 100% jsou na panelu nástrojů.
  6. Klikněte na Export a zvolte Save PNG (1x, 2x nebo 4x, nebo přesnou šířku či výšku), Save SVG, Copy PNG nebo Copy SVG code.

Co je zdarma a co přidává Zovo Pro

Živý náhled, editor diagramů, Edit diagram pro bloky v Markdownu, doplňování, podtržení chyb, 15 šablon, osnova Mermaid Diagrams a export a kopírování PNG a SVG jsou zdarma. Nepotřebujete účet ani přihlášení a rozšíření nepoužívá žádnou AI.

Export All Diagrams in Workspace zapíše každý diagram ze všech souborů .mmd, .mermaid a Markdown ve složce do SVG, PNG nebo obojího, do složky mermaid-export/ se stejnou strukturou složek jako zdroje. Diagramy, které nejde vykreslit, se vypíšou na konci. Když se dokumentace změní, nemusíte každý diagram otevírat a exportovat ručně.

Jak použít Export All Diagrams in Workspace (Zovo Pro)

  1. Otevřete složku ve VS Code. Spusťte z Command Palette „Mermaid Viewer: Export All Diagrams in Workspace (SVG/PNG) (Pro)“, nebo klikněte na „Export All Diagrams in Workspace“ v řádku „Pro tools“ pod panelem nástrojů náhledu.
  2. Zvolte SVG, PNG nebo SVG a PNG.
  3. Ponechte výchozí složku mermaid-export (nastavení mermaidViewer.exportFolder), nebo zvolte „Choose a folder…“. Pokus se započítá, až když se soubory zapíšou. Escape ho nespotřebuje.

Export All Diagrams in Workspace můžete na svém počítači 3krát použít zdarma, teprve potom si řekne o licenci. Neobjeví se žádné vyskakovací okno ani odpočet.

Postup v Cursoru, Windsurfu nebo VSCodiu

  1. Otevřete pohled Extensions zkratkou Ctrl+Shift+X (na macOS Cmd+Shift+X).
  2. Vyhledejte zovo.mermaid-viewer a klikněte na Install. Cursor, Windsurf a VSCodium instalují rozšíření z Open VSX, kde má toto rozšíření název zovo/mermaid-viewer.
  3. Pokud váš editor nemá galerii rozšíření, stáhněte soubor .vsix ze stránky Open VSX a spusťte „Extensions: Install from VSIX...“.
  4. Dál vše funguje stejně jako ve VS Code.

Co umí Mermaid Viewer

  • Flowchart, sequence, class, state, ER, Gantt, pie, gitGraph, mindmap, timeline, sankey, XY chart, block, C4, architecture a další typy, které zná Mermaid 12.3.0.
  • Chyby podtržené na svém řádku a vypsané v panelu Problems. Poslední dobrý diagram zůstane na obrazovce a jeden rozbitý blok v Markdownu neskryje ostatní.
  • Zoom od 1 % do 3 200 % u ukazatele, s posunem a zoomem gestem na trackpadu.
  • Export SVG s prostými textovými popisky pro Azure DevOps a wiki na GitHubu.
  • Pozadí v barvě editoru, bílé, průhledné nebo ve vlastní barvě, použité i pro exporty.

Co neumí

  • Nepřidává diagramy do vestavěného náhledu Markdownu ve VS Code. Otevírá vlastní panel náhledu.
  • Matematika v popiscích ($$...$$) nemusí vypadat správně, protože písma KaTeX nejsou přibalená.
  • Sady ikon, které Mermaid načítá z internetu, se nenačtou. Vestavěné ikony fungují.
  • Diagramy nad 500 000 znaků nebo 2 000 spojení se nevykreslí, dokud limit nezvýšíte (nastavení mermaidViewer.maxTextSize a mermaidViewer.maxEdges).
  • Kreslení, které trvá déle než 10 sekund, se zastaví (nastavení mermaidViewer.renderTimeoutSeconds).

Časté otázky

Je to zdarma?

Náhled, editor, úpravy bloků v Markdownu a export PNG a SVG jsou zdarma. Nástroje Pro (export do PDF, Export All Diagrams in Workspace a Export on Save) mají každý 3 pokusy zdarma. Pak potřebují Zovo Pro, 19 USD jednorázově za všechna rozšíření Zovo.

Proč VS Code neukáže můj blok mermaid v náhledu Markdownu?

Vestavěný náhled Markdownu ve VS Code Mermaid nekreslí. Mermaid Viewer pro soubor Markdown otevře vlastní panel náhledu, se zoomem a exportem pro každý diagram.

Potřebuje účet nebo internet?

Ne. Mermaid 12.3.0 je přibalený, nepotřebujete přihlášení, rozšíření nepoužívá AI a náhled blokuje každý síťový požadavek.

Funguje to v Cursoru?

Ano. Rozšíření je na Open VSX jako zovo/mermaid-viewer, takže ho Cursor, Windsurf a VSCodium mohou nainstalovat.
