Čtení a obnovení historie Claude Code ve VS Code

Nainstalujte Claude Code History & Codex History Viewer (Agent Session Viewer). Vypíše vaše sezení Claude Code z ~/.claude/projects a sezení Codex z ~/.codex/sessions v jednom bočním pohledu, každé otevře jako čitelný přepis a jedním kliknutím ho obnoví v terminálu. Čtení, hledání, obnovení a export jednoho sezení do Markdownu jsou zdarma, bez účtu. Zovo Pro (19 USD jednorázově) přidává zprávu o využití a nákladech, export bezpečný pro sdílení se skrytými tajnými údaji a hromadný export do Markdownu. Každý nástroj Pro má 3 pokusy zdarma.

Postup ve VS Code

  1. Nainstalujte Agent Session Viewer z Marketplace, nebo stiskněte Ctrl+P (na macOS Cmd+P) a spusťte ext install zovo.agent-session-viewer.
  2. Klikněte na ikonu Agent Sessions na liště aktivit. Pohled Sessions vypíše sezení Claude Code a Codex seskupená podle složky projektu, s podagenty pod sezením, které je spustilo.
  3. Kliknutím sezení otevřete ke čtení. Volání nástrojů jsou sbalená, neúspěšná volání mají červenou značku a úpravy souborů se ukážou jako diffy. Záhlaví ukazuje model, větev git, počet kol a součty tokenů.
  4. Staré sezení najdete ikonou hledání v horní části pohledu, nebo spusťte z Command Palette „Agent Sessions: Search Sessions“. Po výběru výsledku se sezení otevře na místě shody.
  5. Klikněte na ikonu terminálu vedle sezení (Resume in Terminal). Ve složce projektu se otevře terminál a spustí claude --resume <id> nebo codex resume <id>.
  6. Soubor sezení .jsonl v jiné složce otevřete tak, že na něj kliknete pravým tlačítkem, zvolíte Open With a vyberete Agent Session Viewer.

Co je zdarma a co přidává Zovo Pro

Zdarma je strom Sessions, čtení sezení, hledání napříč sezeními, Resume in Terminal, Copy Resume Command, export jednoho sezení do Markdownu, surový pohled (raw) a Reveal in File Manager. Historie není nijak omezená a nepotřebujete přihlášení.

Share-safe export uloží jedno sezení, nebo všechna sezení projektu, jako jednu samostatnou stránku HTML nebo jeden soubor Markdown. Klíče API, tokeny, hesla v URL, hodnoty z .env, soukromé klíče, e-maily a vaše domovská složka se nahradí za [REDACTED ...] a zpráva vypíše, co bylo skryto. Sezení tak můžete poslat k pull requestu, auditu nebo při předání práce, aniž byste ho ručně čistili.

Jak použít Share-safe export (Zovo Pro)

  1. Otevřete sezení a klikněte na tlačítko Share-safe export na panelu nástrojů sezení. Nebo klikněte pravým tlačítkem na sezení či složku projektu ve stromu Sessions a zvolte „Share-Safe Export, Secrets Redacted (Pro)…“.
  2. S otevřeným sezením můžete také spustit z Command Palette „Agent Sessions: Share-Safe Export, Secrets Redacted (Pro)…“.
  3. Zvolte formát, stránku HTML nebo Markdown, s výstupy nástrojů nebo bez nich. Pak vyberte, kam soubor uložit.
  4. Export si před sdílením přečtěte. Pokus se započítá, až když se soubor uloží. Escape ani Cancel nic nestojí.

Share-safe export můžete na svém počítači 3krát použít zdarma, teprve potom si řekne o licenci. Neobjeví se žádné vyskakovací okno ani odpočet.

Postup v Cursoru, Windsurfu nebo VSCodiu

  1. Otevřete pohled Extensions zkratkou Ctrl+Shift+X (na macOS Cmd+Shift+X).
  2. Vyhledejte zovo.agent-session-viewer a klikněte na Install. Cursor, Windsurf a VSCodium instalují rozšíření z Open VSX, kde má toto rozšíření název zovo/agent-session-viewer.
  3. Pokud váš editor nemá galerii rozšíření, stáhněte soubor .vsix ze stránky Open VSX a spusťte „Extensions: Install from VSIX...“.
  4. Dál vše funguje stejně jako ve VS Code.

Co umí Agent Session Viewer

  • Sezení Claude Code v ~/.claude/projects (nebo ve složce projects pod CLAUDE_CONFIG_DIR) a sezení Codex v ~/.codex/sessions (nebo ve složce sessions pod CODEX_HOME).
  • Podagenti obou nástrojů, vnoření pod sezením, které je spustilo.
  • Záhlaví s nástrojem, modelem, složkou projektu, větví git, dobou trvání, počtem kol, součty tokenů a cenou, když ji soubor zaznamenává (Claude Code ji zapisuje, Codex ne).
  • Úpravy souborů jako diffy (Edit, Write a apply_patch), sbalené bloky thinking a souhrny reasoning z Codexu.
  • Názvy vláken Codexu ze session_index.jsonl, takže přejmenovaná vlákna si názvy ponechají.

Co neumí

  • Čte jen Claude Code a Codex. Sezení z Cursoru, Copilotu a Gemini CLI zatím podporovaná nejsou.
  • Je jen pro čtení. Soubory sezení nikdy nemění, nepřesouvá ani nemaže a nemá příkaz pro mazání.
  • Hledání porovnává prostý text, ne regulární výrazy, a končí u 300 výsledků.
  • Resume in Terminal potřebuje nainstalovaný Claude Code nebo Codex dostupný v PATH terminálu.
  • Soubory se ve výchozím stavu čtou do 256 MB (agentSessionViewer.maxFileSizeMB). Větší soubory se otevřou jen se svou první částí. Reasoning z Codexu uložený šifrovaně nejde zobrazit.

Časté otázky

Kde Claude Code ukládá historii chatu?

V ~/.claude/projects, jedna složka na projekt a jeden soubor .jsonl na sezení. Pokud je nastavená proměnná CLAUDE_CONFIG_DIR, je historie pod touto složkou.

Je to zdarma?

Ano. Čtení, hledání, obnovení a export jednoho sezení do Markdownu jsou zdarma a historie není omezená. Tři nástroje Pro (zpráva o využití a nákladech, share-safe export, hromadný export) mají každý 3 pokusy zdarma, pak stojí Zovo Pro 19 USD jednorázově za všechna rozšíření Zovo.

Můžu v prohlížeči mazat stará sezení?

Ne. Soubory sezení jen čte a nikdy je nemění, nepřesouvá ani nemaže.

Vytváří ho Anthropic?

Ne. Nevytváří ho Anthropic ani OpenAI a není s nimi nijak spojený. Nedělá žádná síťová volání a nemá telemetrii.
