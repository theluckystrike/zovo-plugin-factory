Přehrávání zvukových souborů ve VS Code

Nainstalujte bezplatný Audio Player & WAV Player a klikněte na soubor .wav, .mp3, .flac, .ogg nebo .opus. Přehraje ho s vlnovým průběhem pro každý kanál, spektrogramem, smyčkou A-B, rychlostí od 0,25x do 2x se zachovanou výškou tónu a hodnotami hlasitosti v LUFS. Opus hraje přes přibalený dekodér a soubory M4A a AAC se po jednom kliknutí přehrají, pokud máte ffmpeg. Přehrávání a kontrola souborů jsou zdarma. Zovo Pro (19 USD jednorázově) přidává dva nástroje, Folder Loudness Report a Normalize Loudness, každý se 3 pokusy zdarma.

Postup ve VS Code

  1. Nainstalujte Audio Player & WAV Player z Marketplace, nebo stiskněte Ctrl+P (na macOS Cmd+P) a spusťte ext install zovo.audio-preview-vscode.
  2. Klikněte v Exploreru na soubor .wav, .mp3, .flac, .ogg, .opus nebo .m4a. Pokud se otevře jiný přehrávač, klikněte na soubor pravým tlačítkem a zvolte „Open in Audio Preview“.
  3. Mezerník spustí nebo pozastaví přehrávání. Šipky vlevo a vpravo skáčou o 5 sekund (se Shiftem o 1 sekundu). Kliknutím do vlnového průběhu přeskočíte na dané místo.
  4. Tažením přes vlnový průběh nastavíte smyčku na tuto část, nebo klávesami [ a ] nastavíte začátek a konec smyčky na aktuální pozici. L smyčku zapne nebo vypne.
  5. Zvolte rychlost od 0,25x do 2x. Výška tónu zůstane stejná.
  6. V záhlaví si přečtěte kodek, vzorkovací frekvenci, kanály, bitovou hloubku, délku a datový tok, v panelu Loudness hodnoty LUFS, špičku a RMS a v panelu Tags název, interpreta, album a další tagy.

Co je zdarma a co přidává Zovo Pro

Přehrávání všech podporovaných formátů, vlnový průběh, spektrogram, smyčka A-B, rychlost, panely Loudness, File a Tags a Copy stats jsou zdarma. Do zvukového souboru se nic nezapisuje a rozšíření nedělá žádná síťová volání.

Folder Loudness Report zapíše jeden řádek CSV za každý zvukový soubor ve složce, s formátem, délkou, vzorkovací frekvencí, bitovou hloubkou, názvem a interpretem, integrovanou hlasitostí v LUFS, maximem krátkodobé a momentální hlasitosti, vzorkovou špičkou, RMS, oříznutými vzorky a ziskem, který soubor potřebuje k dosažení -14, -16 a -23 LUFS. Složku nahrávek tak seřadíte a zkontrolujete v tabulce, místo abyste otevírali každý soubor. Soubory WAV čte rozšíření samo. Řádky pro MP3, FLAC, Ogg, Opus a M4A potřebují váš vlastní ffmpeg.

Jak použít Folder Loudness Report (Zovo Pro)

  1. Klikněte pravým tlačítkem na složku v Exploreru a zvolte „Folder Loudness Report (CSV, Pro)“, nebo spusťte z Command Palette „Audio Preview: Folder Loudness Report (CSV, Pro)“ a vyberte složku. V přehrávači je nástroj také v nabídce „...“ v záhlaví editoru.
  2. Zvolte „This folder and its subfolders“ nebo „This folder only“ a pak, kam uložit loudness-report.csv.
  3. Průběh ukazuje oznámení, které jde zrušit. CSV otevřete v tabulkovém procesoru. Pokus se započítá, až když se soubor zapíše.

Folder Loudness Report můžete na svém počítači 3krát použít zdarma, teprve potom si řekne o licenci. Neobjeví se žádné vyskakovací okno ani odpočet.

Postup v Cursoru, Windsurfu nebo VSCodiu

  1. Otevřete pohled Extensions zkratkou Ctrl+Shift+X (na macOS Cmd+Shift+X).
  2. Vyhledejte zovo.audio-preview-vscode a klikněte na Install. Cursor, Windsurf a VSCodium instalují rozšíření z Open VSX, kde má toto rozšíření název zovo/audio-preview-vscode.
  3. Pokud váš editor nemá galerii rozšíření, stáhněte soubor .vsix ze stránky Open VSX a spusťte „Extensions: Install from VSIX...“.
  4. Dál vše funguje stejně jako ve VS Code.

Co umí Audio Player & WAV Player

  • WAV (PCM 8 až 32 bitů, float, A-law, mu-law, RF64), čtený po blocích 2 MB, aby velký soubor nezasekl editor.
  • MP3, FLAC a Ogg Vorbis přes dekodér, který VS Code už má.
  • Opus v .opus nebo .ogg, s přibaleným dekodérem libopus (WebAssembly).
  • Až 8 kanálů, každý ve vlastní stopě vlnového průběhu.
  • Tagy z ID3v1, ID3v2.2 až 2.4, RIFF INFO, Vorbis comments a iTunes atoms.

Co neumí

  • M4A a AAC potřebují váš vlastní ffmpeg. Bez něj uvidíte kodek, délku, datový tok, tagy a zprávu.
  • ALAC, AC-3 a další kodeky, které VS Code neumí dekódovat, také potřebují tlačítko ffmpeg.
  • Komprimované soubory se dekódují celé. Nad 600 MB dekódovaných vzorků (asi 28 minut sterea při 44,1 kHz) se jen přehrávají (nastavení audioPreview.maxDecodedMB).
  • Špička je vzorková (sample peak), ne převzorkovaná true peak, a rozsah hlasitosti (LRA) chybí.
  • Soubory přehrává a kontroluje. Nestříhá je ani neupravuje.

Časté otázky

Je to zdarma?

Přehrávání, vlnový průběh, spektrogram, smyčka a hodnoty hlasitosti jsou zdarma. Dva nástroje Pro, Folder Loudness Report a Normalize Loudness, mají každý 3 pokusy zdarma. Pak potřebují Zovo Pro, 19 USD jednorázově za všechna rozšíření Zovo.

Proč se můj soubor .opus ve VS Code nepřehraje?

VS Code obsahuje Chromium bez dekodéru Opus. Toto rozšíření nese libopus zkompilovaný do WebAssembly, takže Opus hraje bez další instalace.

Proč moje M4A místo přehrání ukáže zprávu?

VS Code nemá ani dekodér AAC. S nainstalovaným ffmpeg vytvoří tlačítko Decode with ffmpeg kopii WAV ve složce úložiště rozšíření a soubor se přehraje. Nic se nepřibaluje ani nestahuje.

Funguje to v Cursoru?

Ano. Rozšíření je na Open VSX jako zovo/audio-preview-vscode, takže ho Cursor, Windsurf a VSCodium mohou nainstalovat.
