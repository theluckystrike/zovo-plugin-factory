Návody v češtině

VS Code a editory na něm založené (Cursor, Windsurf, VSCodium) otevírají text, obrázky a některá média. Pro mnoho dalších formátů potřebujete rozšíření. Každý návod uvádí postup a říká, co je zdarma.

  • Otevření souborů .npy a .npz z NumPy ve VS Code. Otevřete pole NumPy .npy a .npz ve VS Code v bezplatném Tensor Viewer: dtype, tvar, statistiky, teplotní mapy, obrázky a hodnoty, bez Pythonu.
  • Bezplatný prohlížeč NetCDF přímo ve VS Code. Otevřete soubory NetCDF .nc ve VS Code na Windows, macOS i Linuxu: hlavička, proměnné, mapy s pobřežím a časové řady. Také HDF5 .h5 a MATLAB 7.3 .mat.
  • Otevření databáze SQLite ve VS Code. Otevřete soubor .db nebo .sqlite ve VS Code v bezplatném SQLite Viewer & Editor: tabulky, schéma a SQL, pak upravte buňky a řádky a uložte se zálohou.
  • Náhled diagramů Mermaid ve VS Code. Náhled diagramů Mermaid ve VS Code ze souborů .mmd a z bloků v Markdownu v bezplatném Mermaid Viewer. Živý náhled, export PNG a SVG, offline, bez přihlášení.
  • Přehrávání videí MOV, MKV, WebM a MP4 se zvukem ve VS Code. Přehrávejte MP4, MOV a M4V se zvukem AAC ve VS Code bez další instalace. MKV, WebM a AVI hrají také, s vaším ffmpeg. Bezplatný přehrávač s titulky.
  • Zobrazení souborů STL ve VS Code. Otevřete soubory STL ve VS Code v bezplatném 3D Model Viewer: otáčení, měření mezi dvěma body, drátový model a statistiky. Umí i OBJ, PLY, 3MF, GLB a glTF.
  • Otevření souboru PCAP ve VS Code. Čtěte záznamy .pcap, .pcapng a .pcap.gz ve VS Code v bezplatném PCAP Viewer: seznam paketů, strom protokolů, hex panel a filtry. Wireshark není potřeba.
  • Automatické přejmenování tagů HTML, JSX a Vue ve VS Code. Přejmenujte tag HTML, JSX nebo Vue a párový tag se změní při psaní. Bezplatné rozšíření nad linked editing ve VS Code, s uzavíráním tagů a jedním undo.
  • Čtení a obnovení historie Claude Code ve VS Code. Čtěte, prohledávejte a obnovujte stará sezení Claude Code a Codex ve VS Code. Podagenti pod sezením, úpravy jako diffy, součty tokenů. Jen čtení, offline.
  • Přehrávání zvukových souborů ve VS Code. Přehrávejte WAV, MP3, FLAC, Ogg a Opus ve VS Code v bezplatném Audio Player: vlnový průběh, spektrogram, smyčka A-B, rychlost a hlasitost v LUFS.
  • Otevření výkresu DXF ve VS Code. Prohlížejte výkresy .dxf ve VS Code v bezplatném DXF Viewer: ASCII i binární DXF, vrstvy, listy, hledání textu, měření a export PNG nebo SVG.
  • Zobrazení sekcí a importů souboru ELF, EXE nebo DLL ve VS Code. Otevřete soubory .so, .exe, .dll a .dylib ve VS Code v bezplatném ELF Viewer & PE Viewer: hlavičky, sekce, importy, exporty, symboly a hex, jen pro čtení.
  • Náhled souboru písma ve VS Code. Otevřete písma .ttf, .otf, .woff, .woff2 a .ttc ve VS Code v bezplatném Font Viewer: zkušební text, všechny glyfy a licence, bez instalace písma.
  • Náhled grafu Graphviz DOT bez instalace Graphvizu. Náhled souborů .dot a .gv vedle editoru ve VS Code při psaní, s vestavěným Graphvizem. Šest rozvrhovacích enginů, skok na řádek, export SVG a PNG.
  • Spuštění souboru C++ ve VS Code jedním kliknutím. Zkompilujte a spusťte otevřený soubor .cpp nebo .c ve VS Code jedním kliknutím, s vaším gcc, g++ nebo clang. Vstup v terminálu, chyby v Problems, testy.
  • Převod TIFF do PNG bez ztráty kvality. Otevřete soubory TIFF, BigTIFF a GeoTIFF ve VS Code zdarma a uložte jednu nebo všechny stránky jako PNG s přesnými 8 a 16bitovými hodnotami. Offline.
  • XMind do PDF bez XMindu: všechny listy v jednom PDF. Otevřete myšlenkovou mapu .xmind ve VS Code bez XMindu a uložte všechny listy do jednoho PDF, stránku na list. Prohlížení je zdarma, PDF je nástroj Zovo Pro.
  • Otevření souboru uvnitř ZIPu bez rozbalení. Procházejte ZIP, JAR, TAR nebo TAR.GZ ve VS Code a otevřete z něj jeden soubor v kartě jen pro čtení, aniž by se cokoli rozbalilo na disk. Zdarma a offline.
  • Jak otevřít JAR a číst dekompilovaný zdrojový kód Java ve VS Code. Otevřete soubory .jar, .war, .ear, .aar a .class ve VS Code: balíčky, MANIFEST.MF, bytecode a kód Java dekompilovaný pomocí CFR. Zdarma, jen pro čtení.
