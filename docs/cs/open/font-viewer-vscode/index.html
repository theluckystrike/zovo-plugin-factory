Náhled souboru písma ve VS Code

Nainstalujte bezplatný Font Viewer a klikněte na soubor .ttf, .otf, .woff, .woff2 nebo .ttc. Ukáže váš vlastní ukázkový text v daném písmu, vodopád velikostí, mřížku glyfů s hledáním a licenci a práva pro vkládání, aniž byste písmo instalovali do systému. Postup ve VS Code

  1. Nainstalujte Font Viewer z Marketplace, nebo stiskněte Ctrl+P (na macOS Cmd+P) a spusťte ext install zovo.font-viewer-vscode.
  2. Klikněte v Exploreru na soubor .ttf, .otf, .woff, .woff2, .ttc nebo .otc. Font Viewer je pro tyto soubory výchozí editor a písmo nikdy nemění.
  3. Na kartě Type tester napište vlastní text, posuvníkem nastavte velikost od 8 do 200 px a prohlédněte si vodopád od 12 do 96 px. U variabilního písma posouvejte posuvníky os a zapínejte a vypínejte rysy OpenType, například liga nebo ss01.
  4. Na kartě Glyphs hledejte podle názvu, znaku, U+20AC nebo ID glyfu. Kliknutím na glyf ho uvidíte zvětšený s účařím, výškou x a výškou verzálek a můžete zkopírovat znak, jeho kódový bod nebo obrys jako SVG.
  5. Na kartě Characters si přečtěte pokrytí každého bloku Unicode, například „Basic Latin 95/128“. Vypnutím „Only characters in the font“ uvidíte, co chybí.
  6. Na kartě Info si přečtěte licenci, autora, copyright a práva pro vkládání a zkopírujte hotové pravidlo @font-face.

Co je zdarma a co přidává Zovo Pro

Otevírání všech podporovaných písem, type tester, mřížka glyfů, mapa znaků, karta Info a Copy CSS @font-face jsou zdarma. Font Viewer funguje offline, bez síťových volání a bez telemetrie.

Font Folder Report vypíše každé písmo ve složce s rodinou, řezem, váhou, osami, verzí, počtem glyfů, licencí, URL licence a právy pro vkládání. Seznam zapíše jako soubor CSV, tabulku Markdown nebo jeden fonts.css s pravidlem @font-face pro každé písmo (WOFF2 jako první). Než složku písem použijete v aplikaci nebo na webu, uvidíte v jednom souboru, k čemu smíte které písmo použít, a nemusíte otevírat jedno písmo po druhém.

Jak použít Font Folder Report (Zovo Pro)

  1. Klikněte pravým tlačítkem na složku s písmy v Exploreru a zvolte „Font Folder Report: CSV, Markdown or @font-face CSS… (Pro)“, nebo spusťte z Command Palette „Font Viewer: Font Folder Report: CSV, Markdown or @font-face CSS… (Pro)“ a vyberte složku.
  2. Zvolte formát, tedy CSV, tabulku Markdown nebo pravidla CSS @font-face.
  3. Uložte soubor. Výchozí názvy jsou fonts-report.csv, fonts-report.md a fonts.css a pokus se započítá, až když se soubor zapíše.

Font Folder Report můžete na svém počítači 3krát použít zdarma, teprve potom si řekne o licenci. Neobjeví se žádné vyskakovací okno ani odpočet.

Postup v Cursoru, Windsurfu nebo VSCodiu

  1. Otevřete pohled Extensions zkratkou Ctrl+Shift+X (na macOS Cmd+Shift+X).
  2. Vyhledejte zovo.font-viewer-vscode a klikněte na Install. Cursor, Windsurf a VSCodium instalují rozšíření z Open VSX, kde má toto rozšíření název zovo/font-viewer-vscode.
  3. Pokud váš editor nemá galerii rozšíření, stáhněte soubor .vsix ze stránky Open VSX a spusťte „Extensions: Install from VSIX...“.
  4. Dál vše funguje stejně jako ve VS Code.

Co umí Font Viewer

  • Písma TrueType .ttf a OpenType .otf, včetně variabilních.
  • Webová písma .woff a .woff2. WOFF2 rozbalí vlastní dekodér rozšíření.
  • Kolekce .ttc a .otc, se seznamem v záhlaví pro výběr řezu.
  • Velká písma CJK s 20 000 glyfy, načítaná po stránkách při posouvání.
  • Po kliknutí pravým tlačítkem na písmo v Exploreru zvolíte Copy CSS @font-face, aniž byste ho otevírali.

Co neumí

  • Kolekce WOFF2, písma SVG, .dfont a písma Type 1 nejsou podporované.
  • Obrysy glyfů ukazují výchozí instanci variabilního písma. Type tester, vodopád a mapa znaků se řídí posuvníky os.
  • Barevná písma se v type testeru a mapě znaků kreslí barevně, ale mřížka glyfů ukazuje jejich prosté obrysy.
  • Soubory nad 64 MB místo otevření ukážou zprávu (nastavení fontViewer.maxFileMB).
  • Je jen pro čtení. Písma neupravuje ani je neinstaluje do systému.

Časté otázky

Je to zdarma?

Prohlížení písem, type tester, mřížka glyfů, mapa znaků, karta Info a Copy CSS @font-face jsou zdarma. Dva nástroje Pro, Convert Font a Font Folder Report, mají každý 3 pokusy zdarma. Pak potřebují Zovo Pro, 19 USD jednorázově za všechna rozšíření Zovo.

Musím písmo nainstalovat?

Ne. Písmo se čte ze souboru a zobrazuje se jen na kartě Font Viewer. Seznam písem v systému se nemění.

Otevře WOFF2 z mé složky sestavení?

Ano. WOFF2 rozbalí vlastní dekodér rozšíření a otevřený pohled se obnoví, když uložíte nové sestavení písma.

Funguje to v Cursoru?

Ano. Font Viewer je na Open VSX jako zovo/font-viewer-vscode, takže ho Cursor, Windsurf a VSCodium mohou nainstalovat.
