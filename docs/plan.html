What we do, in order

1. Ship the queue

Agents · Now to 2026-11-08

  1. A script uploads one new extension each time a Marketplace slot opens. The order is by expected installs.
  2. A script uploads updates in batches of 4 and checks each version on the public API.
  3. Each new extension passes unit tests and a test in a real VS Code window before upload.

Result to measure. 19 VS Code extensions live by 2026-11-08.

2. Make money from every product

Agents · 2026-11-06 to 2026-11-07

  1. Add a Sponsor button, a support section and a small support line to every extension. No popup and no limit on free features.
  2. Add cross-selling of our own products in each product, each README, each Actor page and each site page.
  3. Add PayPal and Buy Me a Coffee links when the owner creates the accounts. One config file holds all links.
  4. Switch on Table Viewer Pro when a payment link exists.

Result to measure. Sponsor clicks and new sponsors each week. Baseline 11 sponsors.

3. Get more users from the stores

Agents · Each week

  1. Update the live extensions first. Intel lane I1 found this gives the most installs for each hour. DOCX Viewer got 11 installs after its new name reached rank 3 for "word viewer".
  2. Rename listings so the search words start the display name. This rule decides the search rank.
  3. Add screenshots and a short animation to each listing.
  4. Ask for a rating one time after 5 good uses.
  5. Publish all extensions on Open VSX for Cursor and Windsurf users after the owner signs the agreement.

Result to measure. Installs, page views and search rank for each extension, on the Traffic and Users pages.

4. Build the next products

Agents · Each day

  1. Intel lane I1 ranks the next 10 products across all stores by expected installs or money for each build hour.
  2. Each day, 2 to 4 builder lanes build the top picks. A separate lane tests each one in the real app.
  3. Build only as many new VS Code extensions as the upload slots allow. Put spare build time into the live products.

Result to measure. Installs in the first 14 days for each new product.

5. Stop what does not work

Agents · Each Monday

  1. A product with 0 outside users after 14 days gets no more work.
  2. A store channel with no users after 30 days gets no new products.
  3. Move the effort to the products and stores that grow.

Result to measure. Weekly review on the Insights page.

6. Owner steps

Owner · About 70 minutes in total

  1. Open VSX. One click on the email check in the agent browser (port 9277). A script does the rest.
  2. Apify. Identity check at verify-company.apify.com (5 minutes).
  3. Atlassian. Agreement and payment details are done. Answer one GDPR question on the Gists app.
  4. Shopify. Partner account and development store (15 minutes).
  5. Roblox. ID check and one publish in Studio (35 minutes).
  6. Optional. PayPal.me and Buy Me a Coffee links in funding.json.

Result to measure. Each step unblocks one store.
