Как читать и возобновлять сессии из истории Claude Code в VS Code

Установите Claude Code History & Codex History Viewer (Agent Session Viewer). Расширение показывает в одной боковой панели ваши сессии Claude Code из ~/.claude/projects и сессии Codex из ~/.codex/sessions, открывает каждую как читаемую переписку и одним кликом возобновляет её в терминале. Чтение, поиск, возобновление сессии и экспорт одной сессии в Markdown бесплатны и без аккаунта. Zovo Pro (19 USD один раз) добавляет отчёт об использовании и стоимости, безопасный для передачи экспорт со скрытыми секретами и пакетный экспорт в Markdown, у каждого Pro-инструмента 3 бесплатных запуска.

Как это сделать в VS Code

  1. Установите Agent Session Viewer из Marketplace или нажмите Ctrl+P (Cmd+P на macOS) и выполните ext install zovo.agent-session-viewer.
  2. Кликните по значку Agent Sessions на панели активности. Панель Sessions показывает сессии Claude Code и Codex, сгруппированные по папке проекта, а субагенты вложены в сессию, которая их запустила.
  3. Кликните по сессии, чтобы прочитать её. Вызовы инструментов свёрнуты, неудачные вызовы отмечены красным, а правки файлов показаны как diff. В заголовке видны модель, ветка git, число ходов и итоги по токенам.
  4. Чтобы найти старую сессию, кликните по значку поиска вверху панели или выполните "Agent Sessions: Search Sessions" из Command Palette. Выберите результат, и сессия откроется на найденном месте.
  5. Кликните по значку терминала рядом с сессией (Resume in Terminal). В папке проекта откроется терминал и выполнит claude --resume <id> или codex resume <id>.
  6. Если файл сессии .jsonl лежит в другой папке, кликните по нему правой кнопкой, выберите Open With и затем Agent Session Viewer.

Что бесплатно и что добавляет Zovo Pro

Бесплатно доступны дерево Sessions, чтение сессий, поиск по всем сессиям, Resume in Terminal, Copy Resume Command, экспорт одной сессии в Markdown, сырой вид и Reveal in File Manager. Ограничения на глубину истории нет, вход в аккаунт не нужен.

Share-safe export сохраняет одну сессию или все сессии проекта в одну самодостаточную HTML-страницу или один Markdown-файл. API-ключи, токены, пароли в URL, значения из .env, приватные ключи, адреса электронной почты и путь к вашей домашней папке заменяются на [REDACTED ...], а сообщение перечисляет, что скрыто. Сессию можно отправить для pull request, аудита или передачи дел, не вычищая её вручную.

Как запустить Share-safe export (Zovo Pro)

  1. Откройте сессию и нажмите кнопку Share-safe export на панели инструментов сессии. Или кликните правой кнопкой по сессии или папке проекта в дереве Sessions и выберите "Share-Safe Export, Secrets Redacted (Pro)…".
  2. Когда сессия открыта, можно также выполнить "Agent Sessions: Share-Safe Export, Secrets Redacted (Pro)…" из Command Palette.
  3. Выберите формат: HTML-страница или Markdown, с выводом инструментов или без него. Затем выберите, куда сохранить файл.
  4. Прочитайте экспорт, прежде чем им делиться. Запуск засчитывается, только когда файл сохранён. Escape или Cancel запуск не тратят.

Share-safe export можно запустить на вашем компьютере 3 раза бесплатно, потом расширение попросит лицензию. Никаких всплывающих окон и никакого обратного отсчёта.

Как установить в Cursor, Windsurf или VSCodium

  1. Откройте панель Extensions сочетанием Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Найдите zovo.agent-session-viewer и нажмите Install. Cursor, Windsurf и VSCodium ставят расширения из Open VSX, где это расширение опубликовано как zovo/agent-session-viewer.
  3. Если в вашем редакторе нет каталога расширений, скачайте файл .vsix со страницы на Open VSX и выполните "Extensions: Install from VSIX...".
  4. Дальше всё работает так же, как в VS Code.

Что умеет Agent Session Viewer

  • Сессии Claude Code в ~/.claude/projects (или $CLAUDE_CONFIG_DIR/projects) и сессии Codex в ~/.codex/sessions (или $CODEX_HOME/sessions).
  • Субагенты обоих инструментов, вложенные в сессию, которая их запустила.
  • Заголовок с инструментом, моделью, папкой проекта, веткой git, длительностью, числом ходов, итогами по токенам и стоимостью, если она записана в файле (Claude Code её пишет, Codex нет).
  • Правки файлов в виде diff (Edit, Write и apply_patch), а также thinking и сводки рассуждений Codex, в свёрнутом виде.
  • Имена тредов Codex из session_index.jsonl, поэтому переименованные треды сохраняют свои имена.

Чего расширение не делает

  • Расширение читает только Claude Code и Codex. Сессии Cursor, Copilot и Gemini CLI пока не поддерживаются.
  • Это только чтение. Расширение никогда не меняет, не перемещает и не удаляет файлы сессий, команды удаления в нём нет.
  • Поиск находит обычный текст, а не регулярные выражения, и останавливается на 300 результатах.
  • Для Resume in Terminal нужен установленный Claude Code или Codex, доступный в PATH терминала.
  • По умолчанию файлы читаются до 256 МБ (agentSessionViewer.maxFileSizeMB), у файлов больше открывается только первая часть. Рассуждения Codex, сохранённые в зашифрованном виде, показать нельзя.

Частые вопросы

Где Claude Code хранит историю чатов?

В ~/.claude/projects, по папке на проект и по файлу .jsonl на сессию. Если задана переменная CLAUDE_CONFIG_DIR, история лежит в этой папке.

Это бесплатно?

Да. Чтение, поиск, возобновление сессии и экспорт одной сессии в Markdown бесплатны, ограничения на историю нет. У трёх Pro-инструментов (отчёт об использовании и стоимости, безопасный экспорт, пакетный экспорт) по 3 бесплатных запуска, дальше Zovo Pro стоит 19 USD один раз для всех расширений Zovo.

Можно ли удалить старые сессии из просмотрщика?

Нет. Расширение только читает файлы сессий и никогда их не меняет, не перемещает и не удаляет.

Это расширение от Anthropic?

Нет. Оно не создано Anthropic или OpenAI и не связано с ними. Оно не делает сетевых запросов и не собирает телеметрию.
