Просмотр файлов NumPy .npy и .npz в VS Code

Установите бесплатное расширение Tensor Viewer (NPZ Viewer & NPY Viewer) и кликните по файлу .npy или .npz. Каждый массив показан с именем, dtype и формой. По клику вы видите min, max, mean, std, число NaN, график, гистограмму и сами значения, и Python для этого не нужен. Просмотр, изображения, таблица Values и сохранение в .npy или CSV бесплатны. Zovo Pro (19 USD один раз) добавляет два инструмента, Compare two checkpoints и Scan all tensors, у каждого 3 бесплатных запуска.

Как это сделать в VS Code

  1. Установите Tensor Viewer из Marketplace или нажмите Ctrl+P (Cmd+P на macOS) и выполните ext install zovo.tensor-viewer.
  2. Кликните по файлу .npy или .npz в Explorer. В таблице перечислены все массивы с именем, типом, формой, числом параметров и размером.
  3. Кликните по массиву. Правая панель показывает min, max, mean, std и число NaN, Inf и нулей, затем тепловую карту для двумерного массива или линейный график для одномерного, и гистограмму.
  4. Смотрите числа в таблице Values, по 32 строки за раз. Для массивов с 3 и более измерениями введите срез, например [5, :, :], в поле Slice.
  5. Если массив по форме похож на изображение, например (H, W, 3) или (N, 3, H, W), раздел Image рисует его. Там же выберите Layout, Frame и Range. Для матриц с плавающей точкой вместо этого есть кнопка "Show as image".
  6. Нажмите "Save as .npy..." или "Save as CSV...", чтобы записать массив или срез в новый файл.

Что бесплатно и что добавляет Zovo Pro

Все форматы, статистика, тепловые карты, линейные графики, гистограммы, изображения, таблица Values, срезы, сырые массивы (raw arrays) и сохранение в .npy или CSV бесплатны. Python не нужен, и просмотрщик не обращается к сети.

Scan all tensors читает каждое значение каждого массива в файле, а не выборку. Он отмечает NaN, Inf, массивы из одних нулей, постоянные массивы и числа с плавающей точкой от 10 000 и больше. Для каждого массива он даёт точные min, max, mean, std и L2-норму в одном отчёте, который можно отфильтровать и сохранить в CSV, Markdown или JSON. Вы находите испорченный массив в большом .npz, не открывая каждый по очереди.

Как установить в Cursor, Windsurf или VSCodium

  1. Откройте панель Extensions сочетанием Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Найдите zovo.tensor-viewer и нажмите Install. Cursor, Windsurf и VSCodium ставят расширения из Open VSX, где это расширение опубликовано как zovo/tensor-viewer.
  3. Если в вашем редакторе нет каталога расширений, скачайте файл .vsix со страницы на Open VSX и выполните "Extensions: Install from VSIX...".
  4. Дальше всё работает так же, как в VS Code.

Что умеет Tensor Viewer

  • Файлы .npy с заголовком версий v1, v2 и v3, в порядке C и Fortran, с любым порядком байтов.
  • Архивы .npz с несжатыми и сжатыми (deflate) записями, включая zip64.
  • bool, int8–int64, uint8–uint64, float16, float32, float64 и комплексные числа (статистика по модулю).
  • Массивы в форме изображений, стеки и батчи рисуются как картинки, по одному кадру.
  • То же расширение открывает файлы .safetensors, .gguf и PyTorch .pt, .pth и .ckpt.

Чего расширение не делает

  • Массивы объектов, сохранённые через pickle, видны в списке, но не открываются и никогда не выполняются. Текстовые и структурированные массивы показаны без статистики.
  • Для массивов больше 2 000 000 значений статистика и графики считаются по выборке (настройка tensorViewer.sampleValues). Панель сообщает, когда статистика взята по выборке.
  • Сжатые записи в .npz читаются только с начала. Значения после первых 64 МБ записи не показываются, а записи больше 512 МБ нельзя сохранить.
  • Изображения рисуются не больше 512 пикселей по длинной стороне. У двухканальных массивов и массивов в порядке Fortran нет вида изображения.
  • Экспорт в CSV останавливается на 20 миллионах значений. Значения int64 больше 2^53 теряют последние цифры в таблице и в CSV.

Частые вопросы

Это бесплатно?

Открытие файлов .npy и .npz, статистика, графики, изображения, таблица Values и сохранение в .npy или CSV бесплатны. У двух Pro-инструментов, Compare two checkpoints и Scan all tensors, по 3 бесплатных запуска. После этого нужен Zovo Pro, 19 USD один раз для всех расширений Zovo.

Нужен ли Python?

Нет. Tensor Viewer сам читает файлы, поэтому Python и NumPy устанавливать не нужно.

Безопасно ли открывать файл .npy из интернета?

Ничто из файла никогда не выполняется. Массивы объектов, которые NumPy хранит как pickle, видны в списке, но не открываются, а просмотрщик никогда не меняет показанный файл.

Работает ли это в Cursor?

Да. Tensor Viewer есть на Open VSX как zovo/tensor-viewer, поэтому его можно установить в Cursor, Windsurf и VSCodium.
