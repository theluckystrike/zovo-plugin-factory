Как отформатировать скрипт bash или zsh в VS Code

Установите бесплатное расширение Shell Formatter for Bash & Zsh, откройте shell-скрипт и нажмите Shift+Alt+F (Shift+Option+F на Mac). Движок shfmt 3.14.1 входит в расширение как WebAssembly, поэтому ничего скачивать не нужно, а результат побайтно совпадает с выводом shfmt в командной строке. Format Document, Format Selection, форматирование при сохранении, ключи .editorconfig и синтаксические ошибки в Problems бесплатны и работают офлайн. Zovo Pro (19 USD один раз) добавляет три инструмента, Format All Shell Scripts in a Folder, Formatting Check with a Patch File и Minify a Script to a Copy, и у каждого есть 3 бесплатные попытки.

Как это сделать в VS Code

  1. Установите Shell Formatter for Bash & Zsh из Marketplace или нажмите Ctrl+P (Cmd+P на macOS) и выполните ext install zovo.zovo-shell-formatter.
  2. Откройте shell-скрипт и нажмите Shift+Alt+F (Shift+Option+F на Mac). Если VS Code спросит, какой форматтер использовать, выберите Shell Formatter или выполните "Shell Formatter: Use as Default Formatter for Shell Scripts".
  3. Чтобы форматировать при каждом сохранении, выполните "Shell Formatter: Turn On Format on Save for Shell Scripts".
  4. Диалект определяется по первой строке (#!/bin/bash, #!/bin/sh, #!/usr/bin/env zsh), затем по имени файла (.bash, .zsh, .zshrc, .bats, .ksh), а иначе используется bash. Чтобы выбрать его самостоятельно, задайте shellFormatter.dialect или shell_variant в .editorconfig.
  5. Щёлкните по shfmt 3.14.1 в строке состояния, чтобы открыть меню. В нём есть форматирование, выбор форматтером по умолчанию, форматирование при сохранении, "Copy the matching shfmt command (for CI)" и настройки.
  6. Если скрипт не является корректным shell-кодом, он остаётся без изменений, а панель Problems показывает строку и столбец.

Что бесплатно и что добавляет Zovo Pro

Format Document, Format Selection, форматирование при сохранении, определение диалекта, ключи .editorconfig, меню в строке состояния, Copy the Matching shfmt Command (for CI) и синтаксические ошибки в Problems бесплатны. Нет входа в аккаунт, сетевых запросов и телеметрии.

Format All Shell Scripts in a Folder проверяет все скрипты в папке и её подпапках, найденные по имени или по строке #! с названием shell, и сообщает, сколько из них изменится. Затем он форматирует их все или выдаёт отчёт Markdown, с тем же движком, настройками и .editorconfig, что и Format Document. Репозиторий с десятками скриптов в разных стилях получает один стиль за один запуск, а скрипты, которые после форматирования выполняли бы другие команды, остаются как есть.

Как запустить Format All Shell Scripts in a Folder (Zovo Pro)

  1. Щёлкните правой кнопкой по папке в Explorer и выберите "Zovo Pro: Format All Shell Scripts in a Folder" или выполните "Shell Formatter: Format All Shell Scripts in a Folder (Pro)" из Command Palette или меню в строке состояния и выберите папку.
  2. В заголовке следующего списка видно, сколько скриптов изменится, например "N of M scripts would change".
  3. Выберите "Format N scripts", чтобы отформатировать и сохранить каждый файл (отмена работает для каждого файла отдельно), или "Show the report only", чтобы получить список всех скриптов в Markdown без изменений.
  4. Попытка засчитывается, только когда вы получили результат. Папка без shell-скриптов или папка, где все скрипты уже отформатированы, попытку не тратит.

Как установить в Cursor, Windsurf или VSCodium

  1. Откройте панель Extensions сочетанием Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Найдите zovo.zovo-shell-formatter и нажмите Install. Cursor, Windsurf и VSCodium ставят расширения из Open VSX, где это расширение опубликовано как zovo/zovo-shell-formatter.
  3. Если в вашем редакторе нет каталога расширений, скачайте файл .vsix со страницы на Open VSX и выполните "Extensions: Install from VSIX...".
  4. Дальше всё работает так же, как в VS Code.

Что умеет Shell Formatter for Bash & Zsh

  • Скрипты Bash, POSIX sh (а также dash и ash), mksh (а также ksh), bats и zsh.
  • Тот же результат, что у shfmt 3.14.1 в командной строке. 354 из 354 запусков на 178 реальных скриптах из проектов GitHub и Homebrew совпали побайтно.
  • Перед применением изменений отформатированный скрипт разбирается заново и должен выполнять те же команды, что и исходный (для файлов до 256 КБ).
  • Параметры shfmt задаются настройками или ключами .editorconfig. Это отступ, бинарные операторы на следующей строке, отступ case в switch, пробелы в перенаправлениях, сохранение выравнивания, фигурные скобки функций на следующей строке, упрощение и минификация.
  • Окончания строк Windows (CRLF) остаются CRLF, а скрипт размером 2 МБ форматируется примерно за 0,2 секунды.

Чего расширение не делает

  • Расширение никогда не трогает Dockerfile, файлы .env, скрипты fish и csh.
  • Поддержка zsh в shfmt появилась недавно. Скрипт zsh, который shfmt не может разобрать, остаётся без изменений.
  • Файлы больше 10 МБ (настройка shellFormatter.maxFileMB) и файлы с двоичными байтами, например самораспаковывающиеся установщики, не форматируются.
  • shfmt работает с ограничением по времени (по умолчанию 10 секунд, настройка shellFormatter.timeoutSeconds). Если лимит достигнут, файл остаётся без изменений.

Частые вопросы

Это бесплатно?

Format Document, Format Selection, форматирование при сохранении и поддержка .editorconfig бесплатны. У трёх Pro-инструментов, Format All Shell Scripts in a Folder, Formatting Check with a Patch File и Minify a Script to a Copy, есть по 3 бесплатные попытки. Потом для них нужен Zovo Pro, 19 USD один раз за все расширения Zovo.

Нужно ли устанавливать shfmt?

Нет. shfmt 3.14.1 входит в расширение как WebAssembly, поэтому оно работает офлайн и ничего не нужно скачивать.

Не сломает ли оно мой скрипт?

Скрипт с синтаксической ошибкой остаётся без изменений. Перед применением изменений отформатированный скрипт разбирается заново и должен выполнять те же команды, что и исходный.

Работает ли расширение в Cursor?

Да. Cursor, Windsurf и VSCodium устанавливают его из Open VSX, где оно опубликовано как zovo/zovo-shell-formatter.
