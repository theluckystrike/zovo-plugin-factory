Как отформатировать XML в VS Code и выполнить XPath-запрос

Установите бесплатное расширение XML Formatter & XPath Tools, откройте XML-файл и нажмите Shift+Alt+F (Shift+Option+F на Mac). Меняются только пробельные символы между тегами. Текст, CDATA, комментарии, xml:space="preserve" и значения атрибутов остаются байт в байт, а файл, который не является правильно построенным (well-formed) XML, никогда не изменяется. Форматирование, Minify XML, XPath 1.0 с префиксами пространств имён из самого файла, Copy XPath и представление XML Tree бесплатны и работают офлайн. Zovo Pro (19 USD один раз) добавляет три инструмента, Run XPath on Every XML File in a Folder, Format All XML Files in a Folder и Compare Two XML Files Ignoring Formatting, и у каждого есть 3 бесплатные попытки.

Как это сделать в VS Code

  1. Установите XML Formatter & XPath Tools из Marketplace или нажмите Ctrl+P (Cmd+P на macOS) и выполните ext install zovo.zovo-xml-xpath-tools.
  2. Откройте файл .xml и нажмите Shift+Alt+F (Shift+Option+F на Mac) или выполните Format Document. Если у вас несколько форматировщиков XML, VS Code спросит, какой использовать. Format Selection тоже работает.
  3. Форматировщик использует ваш размер табуляции и выбор между табуляцией и пробелами и сохраняет окончания строк, метку порядка байтов (BOM) и перевод строки в конце файла. Если XML построен неправильно, ничего не меняется, а ошибка показывается с номером строки и столбца.
  4. Чтобы, наоборот, уменьшить файл, выполните "XML: Minify XML" для всего файла или выделенного фрагмента. Комментарии остаются, если не включить xmlXpathTools.minify.removeComments.
  5. Чтобы выполнить XPath, нажмите кнопку поиска в заголовке редактора или выполните "XML: Evaluate XPath…". Результаты появляются в XPath Results с номерами строк. Щелчок по результату выделяет его в редакторе.
  6. Щёлкните по XPath в строке состояния, чтобы скопировать путь элемента под курсором: с позициями, с атрибутами id или name или в переносимой форме с local-name().
  7. Если файл больше 50 МБ, щёлкните по нему правой кнопкой в Explorer и выберите "Format Large XML File on Disk…". Команда запишет рядом name.formatted.xml или, после подтверждения, заменит исходный файл.

Что бесплатно и что добавляет Zovo Pro

Format Document, Format Selection, Minify XML, XPath 1.0, Copy XPath, представление XML Tree, ошибки правильности XML в Problems и Format Large XML File on Disk бесплатны. Входить в аккаунт не нужно, а в расширении нет сетевого кода.

Run XPath on Every XML File in a Folder выполняет один XPath для каждого файла .xml, .xsd, .csproj, .svg, .kml и похожих в папке, каждый раз с префиксами пространств имён этого файла. Результаты открываются как CSV (file, line, kind, name, value) для таблицы, как JSON для скрипта или как отчёт Markdown для ревью. Так вы получаете одно и то же значение из многих файлов, например каждый artifactId из набора файлов pom.xml, не открывая их по одному.

Как запустить Run XPath on Every XML File in a Folder (Zovo Pro)

  1. Щёлкните правой кнопкой по папке в Explorer и выберите "Zovo Pro: Run XPath on Every XML File in a Folder" или выполните "XML: Run XPath on Every XML File in a Folder (Pro)" из Command Palette и выберите папку.
  2. Или, после того как вы выполнили XPath в одном файле, щёлкните по последней строке XPath Results, "Run this XPath on every XML file in a folder", чтобы выполнить то же выражение для папки.
  3. Введите XPath. Уведомление показывает прогресс с кнопкой Cancel.
  4. Выберите "Open as CSV", "Open as JSON" или "Open a Markdown report". Результаты открываются в новой вкладке редактора. Попытка засчитывается, только если вы получили результат. Escape, опечатка в XPath или папка без XML-файлов попытку не расходуют.

Run XPath on Every XML File in a Folder можно запустить на вашем компьютере 3 раза бесплатно, потом расширение попросит лицензию. Никаких всплывающих окон и никакого обратного отсчёта.

Как установить в Cursor, Windsurf или VSCodium

  1. Откройте панель Extensions сочетанием Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Найдите zovo.zovo-xml-xpath-tools и нажмите Install. Cursor, Windsurf и VSCodium ставят расширения из Open VSX, где это расширение опубликовано как zovo/zovo-xml-xpath-tools.
  3. Если в вашем редакторе нет каталога расширений, скачайте файл .vsix со страницы на Open VSX и выполните "Extensions: Install from VSIX...".
  4. Дальше всё работает так же, как в VS Code.

Что умеет XML Formatter & XPath Tools

  • Файлы, которые VS Code открывает как XML. Расширение также открывает как XML файлы .kml, .gpx, .rss, .atom, .wsdl, .dbk, .xlf, .xliff, .resx, .nuspec, .props, .targets и .xaml.
  • Большие файлы. Форматирование, дерево и XPath работают в фоновом потоке. В тестах расширения файл 49 МБ примерно с 1 миллионом элементов отформатировался за 1,6 секунды.
  • Простые имена совпадают и с пространством имён по умолчанию, поэтому //dependency/artifactId работает в pom.xml. Для строгого XPath 1.0 включите xmlXpathTools.xpath.strictNamespaces.
  • Атрибуты можно оставить как написаны, поставить в одну строку или по одному на строку (настройка xmlXpathTools.format.attributes).
  • Представление XML Tree в Explorer следует за курсором, а Problems показывает ошибки правильности XML с номером строки и столбца.

Чего расширение не делает

  • Только XPath 1.0. XPath 2.0 и 3.1, XQuery и XSLT не поддерживаются.
  • Расширение проверяет, что XML построен правильно. Проверки по XSD или DTD нет.
  • Файлы больше 50 МБ можно отформатировать на диске, но VS Code не передаёт их расширениям, поэтому дерево и XPath для них не работают.
  • Команда форматирования на диске читает UTF-8, UTF-16 с меткой порядка байтов и ISO-8859-1.
  • Элемент с текстом внутри, например <p>Some <b>bold</b> text</p>, остаётся на своей строке в том виде, в каком написан. Новые переводы строк получают только элементы, в которых есть теги и нет текста.

Частые вопросы

Это бесплатно?

Форматирование, Minify XML, XPath, Copy XPath, представление XML Tree и проверка правильности XML бесплатны. У трёх Pro-инструментов, Run XPath on Every XML File in a Folder, Format All XML Files in a Folder и Compare Two XML Files Ignoring Formatting, есть по 3 бесплатные попытки. Потом для них нужен Zovo Pro, 19 USD один раз за все расширения Zovo.

Изменит ли форматирование мой текст или CDATA?

Нет. Меняются только пробельные символы между тегами в элементах, где есть теги и нет текста. Текст, CDATA, комментарии и содержимое внутри xml:space="preserve" копируются как есть, а повторное форматирование ничего не меняет.

Почему XPath ничего не находит в pom.xml?

В файле есть пространство имён по умолчанию. В этом расширении простые имена совпадают и с ним, поэтому //dependency работает. Для строгого XPath 1.0 включите xmlXpathTools.xpath.strictNamespaces.

Работает ли расширение в Cursor?

Да. Cursor, Windsurf и VSCodium устанавливают его из Open VSX, где оно опубликовано как zovo/zovo-xml-xpath-tools.
