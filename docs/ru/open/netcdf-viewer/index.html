Бесплатный просмотрщик NetCDF в VS Code

Установите в VS Code бесплатное расширение NetCDF Viewer & HDF5 Viewer и кликните по файлу .nc. Вы получите заголовок, дерево переменных, карту с береговыми линиями, ползунок времени и временной ряд любой точки, по которой кликнете. Python, NCL и другая настройка не нужны. Тот же просмотрщик открывает файлы HDF5 .h5 и MATLAB 7.3 .mat, и всё это бесплатно. Zovo Pro (19 USD один раз) добавляет два инструмента, Compare two files и Export a subset, у каждого 3 бесплатных запуска.

Как это сделать в VS Code

  1. Установите NetCDF Viewer & HDF5 Viewer из Marketplace или нажмите Ctrl+P (Cmd+P на macOS) и выполните ext install zovo.hdf5-netcdf-explorer.
  2. Кликните по файлу .nc, .nc4, .netcdf или .cdf в Explorer. Обзор показывает формат, размерности, глобальные атрибуты и таблицу всех переменных, примерно как ncdump -h.
  3. Выберите переменную в дереве слева. Двумерный срез рисуется как тепловая карта, с береговыми линиями, если строки и столбцы задают географические координаты.
  4. Двигайте ползунок времени или нажмите ▶ рядом с ним, чтобы проиграть ряд по времени. Кликните по точке на карте, чтобы построить её временной ряд.
  5. Откройте вкладку Table, чтобы листать значения страницами по 100 строк и 30 столбцов, со значениями координат в заголовках.
  6. Нажмите "Save PNG", чтобы сохранить график, или "Export slice…", чтобы сохранить показанный срез в CSV или JSON. "Copy xarray code" даёт строку Python для того же среза.
  7. Файл HDF5 .h5 открывается обычным кликом. Файл MATLAB 7.3 .mat откройте правой кнопкой мыши через "Open in HDF5 NetCDF Explorer".

Что бесплатно и что добавляет Zovo Pro

Все форматы, дерево, атрибуты, таблица, графики и карты с береговыми линиями, Play, временные ряды точек, Save PNG и Export slice бесплатны. Для этих функций не нужен Python, и расширение не обращается к сети.

Export a subset работает как ncks -d или .sel в xarray. Вы выбираете переменную и диапазон для каждой размерности, по индексу (0:99) или по значению (30..60, 2023-08-01..2023-08-31). Результат сохраняется как файл NetCDF с координатами, атрибутами и строкой history или как аккуратный CSV, по строке на точку. Так вы получаете небольшой файл для одного региона и периода без скрипта.

Как запустить Export a subset (Zovo Pro)

  1. Откройте файл и нажмите кнопку "Export subset…" рядом с "Export slice…" или кликните по файлу правой кнопкой в Explorer и выберите "Zovo Pro: Export a Subset of a Variable".
  2. Или выполните "NetCDF Viewer Pro: Export Subset of a Variable (NetCDF or CSV)..." из Command Palette.
  3. Введите диапазон для каждой размерности. Поле сразу показывает, что вы выбрали.
  4. Выберите NetCDF или CSV и место для сохранения. Ход работы виден в уведомлении, а Cancel останавливает экспорт и не оставляет недописанный файл.

Как установить в Cursor, Windsurf или VSCodium

  1. Откройте панель Extensions сочетанием Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Найдите zovo.hdf5-netcdf-explorer и нажмите Install. Cursor, Windsurf и VSCodium ставят расширения из Open VSX, где это расширение опубликовано как zovo/hdf5-netcdf-explorer.
  3. Если в вашем редакторе нет каталога расширений, скачайте файл .vsix со страницы на Open VSX и выполните "Extensions: Install from VSIX...".
  4. Дальше всё работает так же, как в VS Code.

Что умеет NetCDF Viewer & HDF5 Viewer

  • NetCDF-4 и NetCDF-4 classic, NetCDF-3 classic и 64-bit offset, а также CDF-5 (64-битные данные).
  • Файлы HDF5 (.h5, .hdf5, .he5, .hdf) со сжатием deflate, shuffle, szip, LZF, Blosc, bitshuffle, LZ4, Zstd, bzip2 и ZFP.
  • MATLAB 7.3 .mat и другие файлы на основе HDF5, например .jld2, .loom и .h5ad.
  • Декодирование CF: scale_factor, add_offset, _FillValue и единицы времени, включая календари noleap, 360_day и all_leap.
  • Файлы на удалённой машине через Remote SSH, WSL или dev container.

Чего расширение не делает

  • Zarr и HDF4 не поддерживаются. Файлы MATLAB .mat в формате v5 не являются HDF5 и не открываются. Пересохраните их командой save(filename, '-v7.3').
  • Береговые линии рисуются только на регулярных сетках в географических координатах. Криволинейные сетки, где координаты заданы двумерными массивами, и проекционные сетки в метрах остаются без береговых линий.
  • Массивы больше 512 x 512 для графика прореживаются. Экспорт записывает не больше 1 000 000 значений в файл (настройка hdf5NetcdfExplorer.maxReadValues).
  • Виртуальные файловые системы, например репозитории GitHub, открытые в vscode.dev, не поддерживаются.
  • Наборы данных с другими фильтрами HDF5, например SZ или JPEG, показывают сообщение вместо значений.

Частые вопросы

Это бесплатно?

Просмотр бесплатный: все форматы, карты, Play, временные ряды, Save PNG и Export slice. У двух Pro-инструментов, Compare two files и Export a subset, по 3 бесплатных запуска. После этого нужен Zovo Pro, 19 USD один раз для всех расширений Zovo.

Есть ли просмотрщик NetCDF для Windows?

Да. Расширение работает везде, где работает VS Code, в том числе на Windows, macOS и Linux, и Python ему не нужен.

Открывает ли он файлы HDF5 и MAT?

Да, файлы HDF5 .h5 и MATLAB 7.3 .mat. Старые файлы MATLAB v5 .mat не являются HDF5, для них показывается сообщение.

Работает ли это в Cursor?

Да. Расширение есть на Open VSX как zovo/hdf5-netcdf-explorer, поэтому его можно установить в Cursor, Windsurf и VSCodium.
