Автоматическое переименование тегов HTML, JSX и Vue в VS Code

Установите бесплатное расширение Auto Rename Tag & Close Tag Sync и измените имя в открывающем или закрывающем теге. Парный тег меняется по мере набора. Переименование выполняет встроенный в VS Code механизм linked editing (editor.linkedEditing). Расширение включает эту настройку для своих языков и находит парный тег в HTML, JSX, TSX, Vue, Svelte, Astro, PHP, Blade, Twig, XML, Markdown и других, поэтому одна отмена возвращает оба тега. Переименование, автозакрытие и рамка вокруг парного тега бесплатны, а Zovo Pro (19 USD один раз) добавляет Rename Tag in All Files и Check Unclosed Tags in All Files, у каждого инструмента 3 бесплатных запуска.

Как это сделать в VS Code

  1. Установите Tag Auto Rename & Close Tag Sync из Marketplace или нажмите Ctrl+P (Cmd+P на macOS) и выполните ext install zovo.zovo-auto-rename-tag.
  2. Откройте файл HTML, JSX, TSX, Vue, Svelte, PHP или другой шаблон и измените имя в открывающем теге. Закрывающий тег меняется по мере набора, и наоборот.
  3. Введите > после открывающего тега, и закрывающий тег появится после курсора. Введите </, и имя открытого элемента подставится само.
  4. Поставьте курсор на тег, и оба тега получат рамку в цветах скобок вашей темы.
  5. Кликните правой кнопкой в редакторе, чтобы выбрать "Go to Matching Tag" или "Select Tag Content". Чтобы ввести новое имя в поле ввода, выполните "Tag Sync: Rename Tag Pair…" из Command Palette.
  6. Кликните по элементу Tags в строке состояния, чтобы увидеть, что включено для этого файла, или выключить расширение для одного языка. Если там написано "Tags: rename off", кликните, чтобы включить переименование для этого языка.

Инструмент переименовывает компонент или элемент сразу во всех файлах с тегами в рабочей области, например <Button> в <UiButton> во всех файлах .tsx, .vue, .html и шаблонах. Сначала вы видите число изменений, "Preview first" открывает предпросмотр рефакторинга VS Code, а одна отмена возвращает все файлы.

Как запустить Rename Tag in All Files (Zovo Pro)

  1. Откройте папку проекта в VS Code. Инструменту нужна открытая папка.
  2. Выполните "Tag Sync: Rename Tag in All Files… (Pro)" из Command Palette или кликните правой кнопкой по файлу .html, .htm, .vue, .jsx, .tsx или .svelte в Explorer и выберите "Zovo Pro: Rename Tag in All Files".
  3. Введите тег так, как он написан в файлах (например Button), а затем новое имя.
  4. Выберите "Rename" или "Preview first", чтобы проверить изменения в предпросмотре рефакторинга. Файлы, которые не были открыты, изменяются, но не сохраняются. File > Save All сохраняет их, а Undo возвращает обратно.

Как установить в Cursor, Windsurf или VSCodium

  1. Откройте панель Extensions сочетанием Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Найдите zovo.zovo-auto-rename-tag и нажмите Install. Cursor, Windsurf и VSCodium ставят расширения из Open VSX, где это расширение опубликовано как zovo/zovo-auto-rename-tag.
  3. Если в вашем редакторе нет каталога расширений, скачайте файл .vsix со страницы на Open VSX и выполните "Extensions: Install from VSIX...".
  4. Дальше всё работает так же, как в VS Code.

Что умеет Tag Auto Rename & Close Tag Sync

  • Переименование в HTML, JSX и TSX, Vue, Svelte, Astro, PHP, Blade, Twig, Jinja, Nunjucks, Liquid, ERB, EJS, Handlebars, XML, SVG и Markdown.
  • Пустые теги вроде br, img, input, meta и hr никогда не получают пару и не закрываются.
  • В .tsx тегом считается только настоящий JSX. Сравнения вроде a < b && c > d и дженерики вроде useState<string>() не трогаются, файлы .ts тоже.
  • Комментарии, строки, содержимое <script> и <style>, а также блоки {{ }}, {% %}, <?php ?> и <% %> пропускаются.
  • Новые несохранённые файлы работают, как только у них есть язык.

Чего расширение не делает

  • В JSX и TSX теги закрывает сам TypeScript, поэтому там расширение закрытие ему и оставляет. Закрывающий тег от TypeScript отменяется отдельным шагом.
  • Если установлено расширение Vue, Svelte, Astro или Red Hat XML, теги в своём языке закрывает оно, а это расширение не вмешивается.
  • В файлах больше 1 МБ или 50 000 строк нет переименования на лету, автозакрытия и подсветки (настройки zovoTags.maxFileSizeKB и zovoTags.maxFileLines). Строка состояния сообщает об этом, а команды по-прежнему работают.
  • Теги внутри выражений {...} в Svelte и Astro не переименовываются.
  • Если одновременно включено старое расширение Auto Rename Tag или Auto Close Tag, оба могут править один и тот же тег. Оставьте одно из них.

Частые вопросы

Чем это отличается от настройки editor.linkedEditing?

Расширение использует editor.linkedEditing для переименования. Оно включает эту настройку для каждого поддерживаемого языка и находит в каждом из них парный тег, от HTML и Vue до PHP, Twig, XML и JSX. Кроме того, оно закрывает теги, рисует рамку вокруг парного тега и добавляет Go to Matching Tag и Select Tag Content. Если вы сами выключили editor.linkedEditing, строка состояния показывает "Tags: rename off", и клик включает его для этого языка.

Работает ли отмена?

Да. Ваша правка и изменение парного тега отменяются одним шагом, потому что переименование идёт через linked editing VS Code. Закрывающий тег от автозакрытия входит в тот же шаг отмены, что и набранный >, кроме JSX и TSX, где теги закрывает TypeScript.

Это бесплатно?

Да. Переименование, автозакрытие, рамка вокруг парного тега и команды редактора бесплатны. Rename Tag in All Files и Check Unclosed Tags in All Files относятся к Zovo Pro, у каждого 3 бесплатных запуска, дальше 19 USD один раз для всех расширений Zovo.

Работает ли это в Cursor?

Да. Cursor, Windsurf и VSCodium ставят его из Open VSX как zovo/zovo-auto-rename-tag.
