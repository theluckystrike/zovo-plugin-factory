Как открыть файл внутри ZIP без распаковки

Установите бесплатное расширение ZIP Viewer & Archive Explorer и кликните по файлу .zip, .jar, .vsix, .tar, .tar.gz или .gz. Оно показывает папки и файлы внутри, а двойной клик открывает файл в обычной вкладке только для чтения прямо из архива, так что ничего не распаковывается. Просмотр, открытие записей, поиск по имени и извлечение бесплатны. Zovo Pro (19 USD один раз) добавляет три инструмента: сравнение двух архивов, экспорт списка записей и поиск файла во всех архивах папки, у каждого 3 бесплатных запуска.

Как это сделать в VS Code

  1. Установите ZIP Viewer & Archive Explorer из Marketplace или нажмите Ctrl+P (Cmd+P на macOS) и выполните ext install zovo.zip-archive-explorer.
  2. Кликните по файлу .zip, .jar, .vsix, .tar, .tar.gz, .tgz или .gz в Explorer. Он откроется как список папок и файлов с размером, сжатым размером, степенью сжатия и датой. Для .war, .whl, .nupkg, .apk или .epub кликните правой кнопкой и выберите Open in Archive Explorer.
  3. Найдите файл. Дважды кликните по папке, используйте строку пути сверху или нажмите Backspace, чтобы подняться выше. Или введите имя в поле поиска. * и ? работают как шаблоны, например *.json.
  4. Дважды кликните по файлу или нажмите Enter. Он откроется только для чтения в обычной вкладке. Код получает подсветку синтаксиса, изображения открываются в просмотре изображений, а ZIP внутри ZIP открывается как ещё один архив.
  5. Раздел Archive Explorer на боковой панели Explorer показывает все открытые вами архивы. Кликните там по записи правой кнопкой, чтобы выбрать Open to the Side, Extract... или Copy Path.
  6. Чтобы изменить файл, выделите его и нажмите Extract.... Один файл сохраняется через окно сохранения. Имена с .. или абсолютным путём никогда не записываются, а сам архив никогда не меняется.

Что бесплатно и что добавляет Zovo Pro

Просмотр архивов, открытие записей во вкладках, поиск по имени, дерево на боковой панели, Copy Path и извлечение бесплатны. Расширение работает офлайн, без сетевых запросов и без телеметрии.

Когда вы знаете имя файла, но не знаете, в каком архиве сборки, резервной копии или релиза он лежит, открывать каждый архив по очереди слишком медленно. Find a file in all archives of a folder ищет по именам записей во всех файлах ZIP, JAR, WAR, VSIX, TAR и GZ внутри папки, показывает каждое совпадение с архивом и путём и открывает выбранное во вкладке только для чтения. Инструмент не записывает файлов.

Как запустить Find a file in all archives of a folder (Zovo Pro)

  1. Выполните "Archive Explorer: Find a File in All Archives of a Folder... (Pro)" из Command Palette и выберите папку для поиска или кликните по папке правой кнопкой в Explorer и выберите "Zovo Pro: Find a file in all archives of a folder".
  2. Введите имя файла. * и ? работают как шаблоны, например log4j*.jar или *.properties.
  3. Выберите совпадение из списка. Оно откроется только для чтения во вкладке, как любая запись. Запуск засчитывается, только если найдено хотя бы одно совпадение.

Find a file in all archives of a folder можно запустить на вашем компьютере 3 раза бесплатно, потом расширение попросит лицензию. Никаких всплывающих окон и никакого обратного отсчёта.

Как установить в Cursor, Windsurf или VSCodium

  1. Откройте панель Extensions сочетанием Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Найдите zovo.zip-archive-explorer и нажмите Install. Cursor, Windsurf и VSCodium ставят расширения из Open VSX, где это расширение опубликовано как zovo/zip-archive-explorer.
  3. Если в вашем редакторе нет каталога расширений, скачайте файл .vsix со страницы на Open VSX и выполните "Extensions: Install from VSIX...".
  4. Дальше всё работает так же, как в VS Code.

Что умеет ZIP Viewer & Archive Explorer

  • ZIP, JAR и VSIX с записями Stored и Deflate, ZIP64 и самораспаковывающиеся архивы.
  • TAR (ustar, длинные имена GNU и заголовки pax), TAR.GZ, TGZ и одиночные файлы GZ.
  • WAR, EAR, WHL, NUPKG, APK, AAR, XPI и EPUB через Open in Archive Explorer.
  • Архивы до 200 000 записей. Они читаются с диска по частям, поэтому большой ZIP не загружается целиком.

Чего расширение не делает

  • Записи, сжатые BZIP2, LZMA, Zstandard или Deflate64, и зашифрованные записи видны в списке, но не открываются.
  • Файлы 7z, RAR, XZ и BZ2 не поддерживаются.
  • Записи открываются только для чтения. Чтобы изменить файл, извлеките его.
  • Записи больше 512 МБ не открываются во вкладке, но их можно извлечь. Файл .tar.gz распаковывается в памяти, по умолчанию до 2 ГБ.

Частые вопросы

Это бесплатно?

Просмотр архивов, открытие записей, поиск по имени, дерево на боковой панели и извлечение бесплатны. У трёх Pro-инструментов, Compare two archives, Export the entry list и Find a file in all archives of a folder, по 3 бесплатных запуска. После этого нужен Zovo Pro, 19 USD один раз для всех расширений Zovo.

Копируется ли файл во временную папку, когда я его открываю?

Нет. Запись читается из архива во вкладку только для чтения. Файлы на диск записывает только Extract.

Можно ли изменить файл внутри ZIP?

Нет. Записи доступны только для чтения, и архив никогда не меняется. Извлеките файл, измените его и снова упакуйте архив другим инструментом.

Работает ли это в Cursor?

Да. ZIP Viewer & Archive Explorer есть на Open VSX, поэтому его можно установить в Cursor, Windsurf и VSCodium.
