Hex-редактор для бинарных файлов в VS Code

Установите Hex Viewer, щёлкните файл в Explorer правой кнопкой и выберите «Open in Hex Viewer»: байты откроются в hex-виде, и их можно сразу править. Просмотр, поиск, переход к смещению, инспектор данных, редактирование со вставкой и удалением, отмена и сравнение двух файлов бесплатны. Zovo Pro (USD 19 один раз) добавляет контрольные суммы, закладки, вложенные поля шаблонов, карту энтропии, извлечение строк, поиск по многим файлам и отчёт сравнения, у каждого инструмента 3 бесплатные попытки.

Установить в VS CodeСтраница в MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

Бесплатно, лицензия MIT. Extension ID zovo.zovo-hex-viewer.

Как это сделать в VS Code

  1. Установите Hex Viewer из Marketplace или нажмите Ctrl+P (Cmd+P на macOS) и выполните ext install zovo.zovo-hex-viewer.
  2. Щёлкните любой файл в Explorer правой кнопкой и выберите «Open in Hex Viewer». Файлы .bin, .dat, .img, .rom, .dmp и .dump открываются в Hex Viewer обычным щелчком.
  3. Нажмите Ctrl+G (Cmd+G на macOS), чтобы перейти к смещению в hex или десятичном виде, или сдвиньтесь на +0x100 или -16. Ctrl+F ищет hex-байты с подстановочными знаками ??, обычный текст или текст UTF-16.
  4. Введите две hex-цифры, чтобы перезаписать байт, или нажмите Insert, чтобы перейти в режим вставки и добавлять байты. Удаление, вырезание и вставка работают на любом выделении, Ctrl+Z отменяет шаг, Ctrl+S сохраняет файл.
  5. Выделите два файла в Explorer и выберите «Compare in Hex Viewer»: файлы встанут рядом, а F7 и Shift+F7 переходят к следующему и предыдущему различию.
  6. Инспектор данных справа читает байты под курсором как целые числа, числа с плавающей точкой, время Unix, GUID и другие типы, с переключателем порядка байтов. Кнопка «Copy as...» копирует выделение как hex, массив C, Python bytes или base64.

В Cursor, Windsurf и VSCodium

Эти редакторы ставят расширения из Open VSX. Откройте Extensions (Ctrl+Shift+X), найдите zovo.zovo-hex-viewer и нажмите Install. На Open VSX оно опубликовано как zovo/zovo-hex-viewer. Дальше всё так же, как в VS Code.

Что бесплатно

Бесплатно всё, что нужно для работы с байтами: просмотр, переход к смещению, поиск, «Copy as...», инспектор данных, редактирование со вставкой и удалением, безопасное сохранение с проверкой свободного места, отмена и повтор, сравнение двух файлов и верхний уровень вкладки Structure для 26 встроенных шаблонов. Локальные файлы открываются любого размера, потому что читаются только строки на экране; в проверке перед выпуском файл на 4 ГБ открылся за 0,6 секунды. Расширение работает офлайн, без аккаунта и без телеметрии.

Что добавляет Zovo Pro

«Checksums of File» за один проход по байтам считает CRC-32, Adler-32, MD5, SHA-1, SHA-256 и SHA-512 для файла, даже размером 4 ГБ, а «Checksums of Selection or File» делает то же для выделенного фрагмента. Не нужно запускать отдельные утилиты в терминале, чтобы сверить образ прошивки или дамп с опубликованной суммой: достаточно выбрать значение и скопировать его. Другие Pro-инструменты Hex Viewer: вложенные поля шаблонов во вкладке Structure с экспортом в JSON или структуру C, закладки с названием, цветом и заметкой, экспорт отчёта сравнения в текст, CSV или JSON, «Find Bytes in Files» для поиска по многим файлам, «Entropy and Byte Histogram» и «Extract Strings».

Как работает Checksums of File

  1. Щёлкните файл (или несколько файлов) в Explorer правой кнопкой и выберите «Zovo Pro: Checksums of File».
  2. Для открытого файла нажмите кнопку «Checksums...» под инспектором данных или выполните команду «Hex Viewer Pro: Checksums of Selection or File»: она считает выделение, а без выделения весь файл.
  3. Выберите нужное значение в списке, чтобы скопировать его. Попытка засчитывается, когда значения появились на экране.

Checksums of File можно запустить 3 раза бесплатно, потом нужна лицензия. Никаких всплывающих окон при открытии файла и никакого обратного отсчёта.

Чего расширение не делает

  • Файлы на удалённых и виртуальных файловых системах открываются до 256 МБ по умолчанию (hexViewer.maxRemoteMB) и читаются целиком.
  • «Copy as...» работает до 32 МБ, вставка из буфера обмена до 16 МБ.
  • Без щелчка правой кнопкой в Hex Viewer открываются только шесть расширений; файлы Intel .hex по-прежнему открываются в текстовом редакторе.
  • Сравнение читает файлы в том виде, в каком они сохранены на диске.

Вопросы

Hex Viewer бесплатный?

Да. Просмотр, поиск, редактирование и сравнение бесплатны и останутся бесплатными. Семь Pro-инструментов входят в Zovo Pro (USD 19 один раз), и каждый можно попробовать 3 раза без ключа.

Работает ли Hex Viewer в Cursor?

Да. Cursor устанавливает расширения из Open VSX; найдите Hex Viewer по названию в панели расширений.

Откроет ли он очень большой файл?

Да. Локальный файл любого размера открывается сразу, потому что расширение читает только видимые строки кусками по 64 КБ. Вставка и удаление в файле на 4 ГБ тоже происходят мгновенно, а если размер файла не изменился, при сохранении записываются только изменённые байты.

Можно ли открыть файл только для просмотра?

Да. Включите настройку hexViewer.readOnly, и редактирование будет выключено. Файлы, доступные только для чтения, и так открываются без возможности правки.

Все функции и настройки описаны на странице Hex Viewer (на английском).
