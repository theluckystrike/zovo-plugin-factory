Как открыть базу SQLite в VS Code

Установите бесплатное расширение SQLite Viewer & Editor и кликните по файлу .db, .sqlite или .sqlite3. Каждая таблица открывается как сетка только для чтения, вкладки Schema и SQL в одном клике. Расширение читает и зафиксированные строки, которые ещё лежат в файле -wal. Просмотр, правка после нажатия Enable editing, сохранение с резервной копией и импорт CSV бесплатны. Zovo Pro (19 USD один раз) добавляет сравнение баз, ER-диаграммы и экспорт всех таблиц сразу, у каждого инструмента 3 бесплатных запуска.

Как это сделать в VS Code

  1. Установите SQLite DB Viewer из Marketplace или нажмите Ctrl+P (Cmd+P на macOS) и выполните ext install zovo.sqlite-table-viewer.
  2. Кликните по файлу .db, .sqlite, .sqlite3, .db3, .s3db, .sl3, .vscdb или .gpkg в Explorer. Он открывается как таблица только для чтения.
  3. Выберите таблицу или представление слева. Кликните по заголовку столбца, чтобы отсортировать, введите условие под заголовком, чтобы отфильтровать (например 5..9 или =word), или ищите сразу по всем столбцам.
  4. Вкладка Schema показывает столбцы, ключи, внешние ключи и команды CREATE. На вкладке SQL можно выполнять по одному запросу за раз. Последние 20 запросов сохраняются.
  5. Чтобы менять данные, нажмите Enable editing. Дважды кликните по ячейке, введите новое значение и нажмите Enter. Каждое изменение ждёт в списке отложенных правок со своим SQL и кнопкой Undo.
  6. Нажмите Save (Ctrl+S, на macOS Cmd+S). Save проверяет ограничения, делает резервную копию вроде name.db.20261109-143000.bak и заменяет файл за один шаг.

Как установить в Cursor, Windsurf или VSCodium

  1. Откройте панель Extensions сочетанием Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Найдите zovo.sqlite-table-viewer и нажмите Install. Cursor, Windsurf и VSCodium ставят расширения из Open VSX, где это расширение опубликовано как zovo/sqlite-table-viewer.
  3. Если в вашем редакторе нет каталога расширений, скачайте файл .vsix со страницы на Open VSX и выполните "Extensions: Install from VSIX...".
  4. Дальше всё работает так же, как в VS Code.

Что умеет SQLite DB Viewer

  • Зафиксированные строки, которые ещё лежат в файле -wal, с живым обновлением, пока ваше приложение пишет в базу (кнопка Live выключает его).
  • JSON в ячейках в виде дерева, изображения как картинки и BLOB с float32 как векторы в панели ячейки.
  • Копирование в CSV, TSV, JSON или командами INSERT и экспорт видимых строк в CSV, JSON или команды SQL INSERT.
  • Импорт CSV и TSV в новую или существующую таблицу, с предпросмотром, сопоставлением столбцов, индикатором хода и кнопкой Cancel.
  • Базы до 512 МБ, строки подгружаются по одной странице.

Чего расширение не делает

  • Вся база загружается в память. Для файлов больше 512 МБ показывается сообщение (настройка sqliteTableViewer.maxFileSizeMB).
  • Править можно файлы до 256 МБ (настройка sqliteTableViewer.editMaxFileSizeMB). Файлы больше остаются только для чтения.
  • Зашифрованные базы (SQLCipher, SEE) не открываются.
  • Правка работает только для файлов на этом компьютере. Файлы на удалённых или виртуальных файловых системах открываются только для чтения.
  • Несохранённые изменения пропадают при закрытии вкладки, файл остаётся прежним.

Частые вопросы

Это бесплатно?

Открытие, просмотр, вкладка SQL, правка, Save и импорт CSV бесплатны и без аккаунта. У трёх Pro-инструментов (Compare SQLite Databases, ER Diagram и Export All Tables) по 3 бесплатных запуска. После этого нужен Zovo Pro, 19 USD один раз для всех расширений Zovo.

Можно ли править строки прямо в VS Code?

Да. Файл открывается только для чтения, а кнопка Enable editing позволяет менять ячейки и строки или выполнять INSERT и UPDATE. Ничего не записывается, пока вы не нажмёте Save, а Save сначала делает резервную копию.

Почему другой просмотрщик показывает старые строки?

В режиме WAL новые коммиты лежат в файле -wal, пока checkpoint не перенесёт их в основной файл. Просмотрщик, который читает только основной файл, их не видит. Это расширение читает зафиксированную часть файла -wal.

Работает ли это в Cursor?

Да. Расширение есть на Open VSX как zovo/sqlite-table-viewer, поэтому его можно установить в Cursor, Windsurf и VSCodium.
