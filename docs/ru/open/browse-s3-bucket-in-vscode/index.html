Как просматривать бакеты AWS S3, Cloudflare R2 или MinIO в VS Code

Установите бесплатное расширение S3 Explorer и откройте его представление S3 Buckets на панели действий (Activity Bar). Оно работает с AWS S3 (профили из ~/.aws, в том числе SSO), Cloudflare R2, MinIO, Backblaze B2, Wasabi и DigitalOcean Spaces. Просмотр, открытие объектов только для чтения, загрузка, скачивание, копирование, перемещение, переименование, удаление, версии, теги, предварительно подписанные URL и синхронизация папок бесплатны, без входа в аккаунт и без телеметрии. Zovo Pro (19 USD один раз) добавляет три инструмента, Copy to Another Connection, Size and Cost Report и Scheduled Sync, и у каждого есть 3 бесплатные попытки.

Как это сделать в VS Code

  1. Установите S3 Explorer из Marketplace или нажмите Ctrl+P (Cmd+P на macOS) и выполните ext install zovo.zovo-s3-explorer.
  2. Откройте представление S3 Explorer на панели действий и нажмите Add Connection. Выберите профиль AWS из ~/.aws или введите ключ доступа, ID аккаунта R2 и токен либо URL эндпоинта MinIO или другого S3-совместимого сервиса. Введённые ключи сохраняются в хранилище ключей ОС.
  3. Разверните подключение, чтобы увидеть его бакеты. Ключи загружаются по 1000 за раз, со строкой "Load 1,000 more". Если вашему ключу нельзя получать список бакетов, щёлкните правой кнопкой по подключению и выберите Add Bucket by Name.
  4. Щёлкните по объекту, чтобы открыть его только для чтения во вкладке или в подходящем просмотрщике. Чтобы увидеть метаданные, теги, версии и предварительно подписанный URL, щёлкните по объекту правой кнопкой и выберите Show Details, Versions and Presigned URL.
  5. Чтобы изменить объект, щёлкните по нему правой кнопкой и выберите Edit and Upload. Вы редактируете копию, и перед заменой объекта диалог показывает бакет, ключ и оба размера.
  6. Перетащите файлы или папки из Explorer на бакет, чтобы загрузить их, или щёлкните правой кнопкой и выберите Download. Файлы от 16 МБ загружаются частями с прогрессом и кнопкой Cancel, а прерванная загрузка продолжается, передавая только недостающие части.
  7. Чтобы локальная папка и префикс совпадали, щёлкните правой кнопкой по бакету или папке и выберите Sync Folder. Прежде чем что-то изменится, вы увидите план dry-run (новые, изменённые, к удалению).

Что бесплатно и что добавляет Zovo Pro

Просмотр, открытие, Edit and Upload, загрузка, скачивание, копирование, перемещение, переименование, удаление, версии, теги, предварительно подписанные URL и синхронизация папок бесплатны, без входа, без аккаунта и без телеметрии. Расширение подключается только к тем хранилищам, которые вы добавили.

Copy to Another Connection копирует объекты или целые папки из одного подключения в другое, например из AWS S3 в Cloudflare R2 или MinIO. Подтверждение такое же, как при любом копировании: ключи перечисляются, а ключи, которые будут заменены, названы. Большие объекты передаются через multipart-загрузку. Вы переносите данные между провайдерами или аккаунтами прямо из дерева, без скрипта и без второго инструмента.

Как запустить Copy to Another Connection (Zovo Pro)

  1. Сначала добавьте второе подключение. Затем щёлкните правой кнопкой по объекту или папке в представлении S3 Buckets и выберите "Copy to Another Connection... (Pro)" или нажмите Copy to Another Connection в строке "Zovo Pro tools" в конце представления.
  2. Выберите целевое подключение, бакет и папку назначения (пустое значение означает верхний уровень).
  3. Прочитайте список объектов в подтверждении и нажмите Copy или Copy and Replace, если некоторые ключи уже существуют. Уведомление показывает прогресс.
  4. Попытка засчитывается, только если объекты были скопированы. Escape при выборе или отсутствие второго подключения попытку не тратят.

Copy to Another Connection можно запустить на вашем компьютере 3 раза бесплатно, потом расширение попросит лицензию. Никаких всплывающих окон и никакого обратного отсчёта.

Как установить в Cursor, Windsurf или VSCodium

  1. Откройте панель Extensions сочетанием Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Найдите zovo.zovo-s3-explorer и нажмите Install. Cursor, Windsurf и VSCodium ставят расширения из Open VSX, где это расширение опубликовано как zovo/zovo-s3-explorer.
  3. Если в вашем редакторе нет каталога расширений, скачайте файл .vsix со страницы на Open VSX и выполните "Extensions: Install from VSIX...".
  4. Дальше всё работает так же, как в VS Code.

Что умеет S3 Explorer

  • Профили AWS с ключами доступа, credential_process, роли с source_profile и профили SSO после aws sso login. endpoint_url в профиле учитывается.
  • MinIO и другие S3-совместимые сервисы с URL эндпоинта, регионом, адресами в стиле path-style или virtual-hosted и параметром, разрешающим самоподписанный сертификат.
  • Метаданные, тип содержимого, класс хранения, ETag, теги (с правкой и сохранением), версии (открыть, скачать, восстановить) и предварительно подписанные URL для GET или PUT сроком от 15 минут до 7 дней.
  • Бакеты с миллионами ключей, по 1000 за раз, с поиском и фильтром по префиксу.
  • Скачивание сохраняет структуру папок и никогда не пишет за пределы выбранной папки. Ключи с сегментами .., буквами дисков или байтами NUL пропускаются и перечисляются.

Чего расширение не делает

  • Расширение никогда само не использует профиль AWS default или AWS_PROFILE. Профиль для подключения выбираете вы.
  • Для текстовых объектов больше 10 МБ сначала задаётся вопрос, затем показывается первый 1 МБ. Двоичные объекты больше 200 МБ скачиваются только после вопроса.
  • Открытые объекты доступны только для чтения. В бакет пишет только Edit and Upload, после подтверждения.
  • Scheduled Sync работает, только пока открыт VS Code, с интервалом от 5 до 60 минут, и никогда ничего не удаляет.
  • Запросы без ответа прерываются через 30 секунд (настройка s3Explorer.requestTimeoutSeconds).

Частые вопросы

Это бесплатно?

Просмотр, открытие, загрузка, скачивание, копирование, перемещение, переименование, удаление, версии, теги, предварительно подписанные URL и синхронизация папок бесплатны. У трёх Pro-инструментов, Copy to Another Connection, Size and Cost Report и Scheduled Sync, есть по 3 бесплатные попытки. Потом для них нужен Zovo Pro, 19 USD один раз за все расширения Zovo.

Где хранятся мои ключи?

Введённые ключи хранятся в хранилище ключей ОС через VS Code SecretStorage и никогда не попадают в файлы настроек. Профили AWS читаются из ~/.aws, только когда вы выбираете профиль.

Работает ли расширение с Cloudflare R2 и MinIO?

Да. Для R2 нужны ID аккаунта и ключ доступа API-токена R2. Для MinIO и других S3-совместимых сервисов нужны URL эндпоинта, регион и адреса в стиле path-style или virtual-hosted.

Работает ли расширение в Cursor?

Да. Cursor, Windsurf и VSCodium устанавливают его из Open VSX, где оно опубликовано как zovo/zovo-s3-explorer.
