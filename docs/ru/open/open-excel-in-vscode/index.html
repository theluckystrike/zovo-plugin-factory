Excel и CSV в VS Code, с SQL-запросами

Установите XLSX Viewer & Excel Viewer: файлы .xlsx, .xls, .ods и .parquet открываются по щелчку как сортируемая таблица, а CSV открывается командой «Open in Table Viewer». Сортировка, фильтры, статистика по колонкам, SQL-запросы по строкам в таблице и экспорт бесплатны. Zovo Pro (USD 19 один раз) добавляет объединение файлов и листов, разделение таблицы по значению колонки, запросы ко всему большому файлу, JOIN с другими файлами и сохранение в Parquet, у каждого инструмента 3 бесплатные попытки.

Установить в VS CodeСтраница в MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

Бесплатно, лицензия MIT. Extension ID zovo.table-viewer-vscode.

Как это сделать в VS Code

  1. Установите Table Viewer из Marketplace или нажмите Ctrl+P (Cmd+P на macOS) и выполните ext install zovo.table-viewer-vscode.
  2. Щёлкните файл .xlsx, .xlsm, .xls, .ods или .parquet: он откроется как таблица. Файлы .csv и .tsv по-прежнему открываются в текстовом редакторе; нажмите значок таблицы справа вверху редактора или щёлкните файл правой кнопкой и выберите «Open in Table Viewer».
  3. Щелчок по заголовку колонки сортирует таблицу, а фильтры под заголовками сужают выборку: >10, 5..9, =слово, !слово, empty. Поле поиска ищет по всем колонкам. Таблица показывает до 1 000 000 строк.
  4. Для SQL нажмите Query на панели инструментов, напишите SELECT и нажмите Ctrl+Enter (Cmd+Enter на Mac). FROM this означает открытый файл, а другой лист той же книги Excel подключается через JOIN по имени.
  5. Работают WHERE, GROUP BY, HAVING, CASE, подзапросы во FROM и около 70 функций для текста, чисел и дат. Во время запроса видны прогресс и кнопка Cancel.
  6. Результат открывается в той же таблице: его можно сортировать, фильтровать и сохранить как CSV, TSV, JSON или JSON Lines. История запросов хранится для каждого файла.

В Cursor, Windsurf и VSCodium

Эти редакторы ставят расширения из Open VSX. Откройте Extensions (Ctrl+Shift+X), найдите zovo.table-viewer-vscode и нажмите Install. На Open VSX оно опубликовано как zovo/table-viewer-vscode. Дальше всё так же, как в VS Code.

Что бесплатно

Бесплатно и останется бесплатным: открытие CSV, TSV, Excel и Parquet, листы, формулы, сортировка, фильтры, поиск, статистика по колонкам, SQL-фильтр, SQL-запросы по строкам в таблице, JOIN листов одной книги, сравнение с Git HEAD или другим файлом, копирование как CSV, JSON или Markdown и экспорт в CSV, TSV, JSON и JSON Lines. Не нужны ни Python, ни база данных, ни аккаунт. Расширение работает офлайн и без рекламы.

Что добавляет Zovo Pro

«Combine Files and Sheets» собирает много файлов CSV, TSV, Excel, ODS и Parquet, целую папку или все листы одной книги в один файл CSV, XLSX или Parquet. Колонки сопоставляются по названию заголовка (регистр и пробелы не важны), а колонки source_file и source_sheet показывают, откуда пришла каждая строка. Ежемесячные выгрузки или листы по регионам больше не нужно копировать вручную в одну таблицу. Другие Pro-инструменты: «Split Table by Column Value» (отдельный CSV или лист на каждое значение колонки), запросы ко всему файлу, когда таблица держит только первые строки (например, GROUP BY по CSV на несколько гигабайт), JOIN с другими файлами CSV, Excel и Parquet рабочего пространства и сохранение результата в Parquet. С Zovo Pro также растут лимиты по умолчанию: 5 000 000 строк, CSV до 2 ГБ и Excel до 200 МБ.

Как работает Combine Files and Sheets

  1. Щёлкните правой кнопкой папку, несколько выделенных табличных файлов или книгу Excel в Explorer и выберите «Zovo Pro: Combine Files and Sheets». Можно также выполнить из Command Palette команду «Excel Viewer Pro: Combine Files and Sheets (Pro)...» или нажать Combine на панели таблицы.
  2. Выберите формат результата (CSV, XLSX или Parquet) и место, куда сохранить объединённую таблицу. Файлы, которые не удалось прочитать, пропускаются и перечисляются в итоговом сообщении.

Combine Files and Sheets можно запустить 3 раза бесплатно, потом нужна лицензия. Никаких всплывающих окон при открытии файла и никакого обратного отсчёта.

Чего расширение не делает

  • Расширение только читает: ячейки не редактируются, исходный файл не сохраняется. «Save result» и экспорт записывают только новый файл, который вы выберете.
  • По умолчанию таблица показывает до 1 000 000 строк и читает первые 512 МБ CSV; файлы .xls, .xlsb и .ods больше 50 МБ показывают сообщение вместо таблицы.
  • Запросы: один SELECT за раз, без RIGHT и FULL JOIN, без WITH и без подзапросов внутри выражений; один запрос использует не больше 512 МБ памяти.
  • Файлы CSV и TSV не открываются как таблица по щелчку: нужен значок таблицы или «Open in Table Viewer».

Вопросы

SQL-запросы бесплатные?

Да. Запросы по строкам, загруженным в таблицу, и JOIN листов одной книги бесплатны. Запросы ко всему большому файлу, JOIN с другими файлами и сохранение в Parquet входят в Zovo Pro (USD 19 один раз), у каждого инструмента 3 бесплатные попытки.

Работает ли расширение в Cursor?

Да. Cursor устанавливает расширения из Open VSX; найдите XLSX Viewer & Excel Viewer по названию в панели расширений.

Нужны ли Python или база данных?

Нет. Файлы читаются в фоновом потоке на вашем компьютере, ничего не уходит в сеть.

Можно ли редактировать ячейки?

Нет. Расширение показывает таблицу и выполняет запросы, но не меняет исходный файл.

Все функции и настройки описаны на странице Table Viewer (на английском).
