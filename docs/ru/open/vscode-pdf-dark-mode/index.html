PDF в тёмном режиме в VS Code

Установите PDF Viewer & PDF Reader (Dark) и щёлкните файл .pdf: в тёмной теме VS Code страницы сразу становятся тёмными, а кнопка с луной включает и выключает этот режим. Тёмные и сепия-страницы, поиск, структура, миниатюры, выделения и «Copy as Markdown» бесплатны. Zovo Pro (USD 19 один раз) добавляет сравнение двух PDF, инструменты для страниц, объединение PDF и экспорт выделений из всех PDF, у каждого инструмента 3 бесплатные попытки.

Установить в VS CodeСтраница в MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

Бесплатно, лицензия MIT. Extension ID zovo.pdf-viewer-dark.

Как это сделать в VS Code

  1. Установите PDF Reader из Marketplace или нажмите Ctrl+P (Cmd+P на macOS) и выполните ext install zovo.pdf-viewer-dark.
  2. Щёлкните любой .pdf в Explorer. В тёмной теме VS Code страницы будут тёмными; кнопка с луной на панели инструментов включает и выключает тёмные страницы, а кнопка с бумагой рядом с ней включает тёплые сепия-страницы для долгого чтения.
  3. Фотографии и другие растровые картинки сохраняют свои настоящие цвета: меняются только текст, линии и фон.
  4. Нажмите Ctrl+F (Cmd+F на macOS), чтобы искать по документу. Боковая панель («Toggle Outline and Pages») показывает структуру документа и миниатюры страниц.
  5. Выделите текст и выберите один из 4 цветов или нажмите H. Вкладка Highlights перечисляет все выделения, щелчок по выделению возвращает к нужному месту.
  6. Кнопка «Copy as Markdown» во вкладке Highlights копирует список ваших выделений со ссылкой на каждую страницу, удобно для заметок.

В Cursor, Windsurf и VSCodium

Эти редакторы ставят расширения из Open VSX. Откройте Extensions (Ctrl+Shift+X), найдите zovo.pdf-viewer-dark и нажмите Install. На Open VSX оно опубликовано как zovo/pdf-viewer-dark. Дальше всё так же, как в VS Code.

Что бесплатно

Чтение остаётся бесплатным: тёмные и сепия-страницы, поиск, структура документа и миниатюры, выделения в 4 цветах, «Copy as Markdown», переход к странице и ссылки на страницы. Расширение перезагружает PDF, когда файл меняется на диске, например после сборки LaTeX или Typst, и остаётся на той же странице и в том же масштабе. Каждый PDF открывается там, где вы остановились. Выделения хранятся в VS Code, в сам PDF ничего не записывается. Всё работает офлайн и без телеметрии.

Что добавляет Zovo Pro

«Export Highlights of All PDFs to Markdown» собирает в один Markdown-файл выделения из всех PDF, которые вы размечали (или только из PDF этого рабочего пространства), сгруппированные по файлам, с цветом и ссылкой на каждую страницу. Вместо того чтобы открывать каждую статью или спецификацию и копировать выделения по одной, вы получаете все заметки сразу. Другие Pro-инструменты PDF Reader: инструменты страниц («Extract Pages to a New PDF», «Delete Pages», «Split PDF into Several Files»), которые сохраняют результат в новый PDF, «Merge PDFs» для объединения нескольких PDF и «Compare Two PDFs» для сравнения текста двух PDF или PDF с последним коммитом Git.

Как работает Export Highlights of All PDFs to Markdown

  1. Выделите нужные места в одном или нескольких PDF (клавиша H или выбор цвета).
  2. Выполните из Command Palette команду «PDF: Export Highlights of All PDFs to Markdown (Pro)...» или нажмите ссылку «All PDFs» во вкладке Highlights. Если часть размеченных PDF лежит вне рабочего пространства, выберите «PDFs in this workspace» или «Every PDF I highlighted».
  3. Укажите, куда сохранить Markdown-файл (по умолчанию pdf-highlights.md).

Export Highlights of All PDFs to Markdown можно запустить 3 раза бесплатно, потом нужна лицензия. Никаких всплывающих окон при открытии файла и никакого обратного отсчёта.

Чего расширение не делает

  • Выделения хранятся в VS Code на этом компьютере, а не в PDF: другие программы их не видят, и между компьютерами они не синхронизируются.
  • Расширение не заполняет формы, не редактирует текст и картинки на странице и не печатает. Pro-инструменты страниц сохраняют целые страницы в новый PDF и пока не поворачивают страницы.
  • Векторные диаграммы в тёмном режиме инвертируются вместе с текстом; исходные цвета сохраняют только растровые картинки.
  • Большие файлы целиком загружаются в память; для PDF больше 200 МБ расширение сначала спрашивает (pdfViewer.maxFileSizeMB).

Вопросы

Тёмный режим бесплатный?

Да. Тёмные и сепия-страницы, поиск, структура, выделения и «Copy as Markdown» бесплатны и останутся бесплатными. Четыре Pro-инструмента входят в Zovo Pro (USD 19 один раз), у каждого 3 бесплатные попытки.

Работает ли PDF Reader в Cursor?

Да. Cursor устанавливает расширения из Open VSX; найдите PDF Viewer & PDF Reader (Dark) по названию в панели расширений.

Меняет ли расширение мой PDF-файл?

Нет. Выделения хранятся в VS Code, а не в файле. Pro-инструменты страниц и объединение записывают новый PDF; исходные файлы меняются, только если вы сами выберете их в диалоге сохранения.

Можно ли включить тёмные страницы при светлой теме?

Да. Нажмите кнопку с луной для открытого файла или задайте pdfViewer.darkMode = on, чтобы страницы всегда были тёмными.

Все функции и настройки описаны на странице PDF Reader (на английском).
