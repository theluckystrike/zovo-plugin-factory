Как запустить файл C++ в VS Code одной кнопкой

Установите бесплатное расширение Run C++ and C Code, откройте файл .cpp или .c и нажмите Run в заголовке редактора или Ctrl+Alt+Enter (Cmd+Alt+Enter на Mac). Расширение компилирует файл компилятором gcc, g++, clang или clang++, который уже есть на вашем компьютере, и запускает программу в терминале, где работают cin и scanf. Ошибки компилятора попадают в панель Problems на нужную строку, а панель Input & Tests, стресс-тест и бенчмарк бесплатны. Zovo Pro (19 USD один раз) добавляет проверку санитайзерами, сравнение -O0, -O2 и -O3 и отчёт по тестам, у каждого инструмента 3 бесплатных запуска.

Как это сделать в VS Code

  1. Установите Run C++ and C Code из Marketplace или нажмите Ctrl+P (Cmd+P на macOS) и выполните ext install zovo.zovo-run-cpp.
  2. Убедитесь, что компилятор установлен. "Run C++: Pick Compiler (gcc, g++, clang, clang++)" показывает найденные компиляторы. Если их нет, страница настройки покажет официальные шаги для вашей системы (Xcode Command Line Tools, MSYS2 или WinLibs, либо менеджер пакетов Linux).
  3. Откройте файл .cpp, .cc, .cxx или .c и нажмите кнопку Run в заголовке редактора или Ctrl+Alt+Enter (Cmd+Alt+Enter на Mac).
  4. Программа запускается в терминале с именем "Run: file.cpp". Вводите данные там. В конце видны код выхода, время работы и пиковая память. Пока программа работает, кнопка Run превращается в Stop.
  5. Для флагов или аргументов напишите // run: -O2 -lm и // args: "Hello World" 3 в первых 40 строках файла. Флаги C++ по умолчанию: -std=c++20 -Wall -Wextra -g -O0.
  6. Чтобы проверять на сохранённом вводе, выполните "Run C++: Run with Input & Test Cases". Вставьте ввод, нажмите Run with input, затем Save as test case. Run all tests показывает, пройден тест или нет, с построчным diff.

Что бесплатно и что добавляет Zovo Pro

Run, Build Only, Run Last Build, Debug, сборка папки, панель Input & Tests, стресс-тест и бенчмарк бесплатны. Вход в аккаунт не нужен, сетевых запросов и телеметрии нет.

Программа, которая проходит ваши тесты, всё равно может читать за концом массива или переполнять int. Sanitizer check собирает вторую копию с AddressSanitizer и UndefinedBehaviorSanitizer (-fsanitize=address,undefined), запускает её на вводе из панели и на каждом сохранённом тесте и выводит каждое переполнение кучи или стека, использование после освобождения, знаковое переполнение и другое неопределённое поведение в панель Problems на нужной строке. Вы находите ошибку на её строке, не настраивая флаги санитайзеров вручную.

Как запустить Sanitizer check (Zovo Pro)

  1. Введите данные в панели Input & Tests и сохраните тестовые примеры, если они есть. Проверка запускается на вводе из панели и на каждом сохранённом тесте.
  2. Нажмите "Sanitizer check (Pro)" в панели под "Stress test, benchmark and more" или выполните "Run C++: Sanitizer Check: AddressSanitizer and UBSan on the Input and Test Cases (Zovo Pro)" из Command Palette.
  3. Кликните по находке в панели Problems, чтобы перейти к её строке. Ошибка сборки, Stop или Cancel не тратят бесплатный запуск.

Sanitizer check можно запустить на вашем компьютере 3 раза бесплатно, потом расширение попросит лицензию. Никаких всплывающих окон и никакого обратного отсчёта.

Как установить в Cursor, Windsurf или VSCodium

  1. Откройте панель Extensions сочетанием Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Найдите zovo.zovo-run-cpp и нажмите Install. Cursor, Windsurf и VSCodium ставят расширения из Open VSX, где это расширение опубликовано как zovo/zovo-run-cpp.
  3. Если в вашем редакторе нет каталога расширений, скачайте файл .vsix со страницы на Open VSX и выполните "Extensions: Install from VSIX...".
  4. Дальше всё работает так же, как в VS Code.

Что умеет Run C++ and C Code

  • Файлы C и C++ (.c, .cpp, .cc, .cxx) с gcc, g++, clang и clang++.
  • MSYS2, WinLibs, MinGW, TDM-GCC и LLVM в их обычных папках Windows, а также имена из Homebrew вроде g++-14.
  • Пути с пробелами, & или не-ASCII буквами, потому что их не разбирает оболочка.
  • Программы, которые печатают миллион строк. Панель показывает первые 2 000 и считает остальные.

Чего расширение не делает

  • Нужен компилятор на вашем компьютере, расширение никогда его не скачивает.
  • Запуски в панели Input и тестовые примеры останавливаются через 10 секунд (настройка zovoRun.timeLimitSeconds).
  • Вывод сверх 32 МБ только подсчитывается, но не сохраняется (настройка zovoRun.maxCapturedOutputMB).
  • Для проверки санитайзерами нужен компилятор с runtime санитайзеров. У MinGW gcc в Windows его нет, поэтому там используйте clang из LLVM. Проверка сообщит об этом и не потратит запуск.
  • Для Debug нужно установленное расширение CodeLLDB или C/C++.

Частые вопросы

Это бесплатно?

Run, Build Only, Debug, сборка папки, панель Input & Tests, стресс-тест и бенчмарк бесплатны. У трёх Pro-инструментов, Sanitizer check, Compare -O0, -O2 and -O3 и Test report, по 3 бесплатных запуска. После этого нужен Zovo Pro, 19 USD один раз для всех расширений Zovo.

Может ли моя программа читать ввод через cin?

Да. Она работает в настоящем терминале, поэтому cin и scanf ждут, что вы введёте, а приглашения без перевода строки показываются сразу.

Меняет ли оно мои settings.json или tasks.json?

Нет. Расширение никогда не пишет в файлы настроек. Debug добавляет одну запись в .vscode/launch.json, и только когда вы нажимаете Debug.

Работает ли это в Cursor?

Да. Расширение есть на Open VSX, поэтому его можно установить в Cursor, Windsurf и VSCodium.
