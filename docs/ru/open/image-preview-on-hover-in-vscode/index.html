Руководства на русском

Как увидеть изображение по пути в коде на поле редактора и при наведении в VS Code

Установите бесплатное расширение Image Preview & Image Hover и откройте файл, в котором указано изображение. На поле редактора рядом со строкой появится миниатюра, а при наведении на путь подсказка покажет изображение, его тип, размер в пикселях и размер файла. Расширение работает с импортами JavaScript и TypeScript, JSX, CSS url(), Markdown, HTML src и srcset, YAML и data URI и не делает сетевых запросов. Zovo Pro (19 USD один раз) добавляет три инструмента, Find Unused Images, Find Broken Image References и Image Weight Report, и у каждого есть 3 бесплатные попытки.

Как это сделать в VS Code

  1. Установите Image Preview & Image Hover из Marketplace или нажмите Ctrl+P (Cmd+P на macOS) и выполните ext install zovo.zovo-image-preview.
  2. Откройте файл, в котором указано изображение, например import logo from './logo.png', CSS url() или HTML <img src>. Миниатюры появятся на поле редактора, по одной на строку.
  3. Наведите курсор на путь. Подсказка покажет изображение (уменьшенное по размеру, но никогда не увеличенное), его тип, ширину × высоту в пикселях, размер файла и прозрачность, а также ссылки, чтобы открыть файл или показать его в Explorer.
  4. Если путь не удаётся найти, подсказка сообщит об этом и перечислит пути, которые были проверены. Добавьте свои префиксы в imgPreview.aliases, например { "@images": "src/assets/images" }, или папки для путей, начинающихся с /, в imgPreview.publicFolders.
  5. Чтобы скрыть миниатюры на поле редактора, выполните "Image Preview: Show or Hide Gutter Thumbnails" из Command Palette.
  6. Нет проекта под рукой? Выполните "Image Preview: Open the Sample Files", чтобы открыть небольшой демо-проект со всеми видами путей.

Что бесплатно и что добавляет Zovo Pro

Миниатюры на поле редактора, подсказка при наведении, поиск путей с алиасами, paths из tsconfig.json и jsconfig.json, пакеты монорепозитория и data URI бесплатны. Нет аккаунта, сетевых запросов и телеметрии, расширение работает офлайн.

Find Unused Images находит в рабочей области (или в одной папке) изображения, которые не упоминаются ни в одном файле кода, стилей, Markdown, HTML, JSON или YAML, и показывает их в отчёте Markdown с размерами, начиная с самых больших. После подтверждения они переносятся в папку _unused-images с сохранением структуры папок, а Edit > Undo возвращает их на место. Так вы убираете старые изображения из проекта, не проверяя каждое имя вручную.

Как запустить Find Unused Images (Zovo Pro)

  1. Щёлкните правой кнопкой по папке в Explorer и выберите "Zovo Pro: Find unused images" или выполните "Image Preview: Find Unused Images (Pro)" из Command Palette. Если в рабочей области несколько папок, выберите нужную.
  2. Уведомление показывает прогресс с кнопкой Cancel. Затем открывается отчёт Markdown со всеми неиспользуемыми изображениями и их размерами, начиная с самых больших.
  3. Нажмите "Move N to _unused-images", чтобы перенести их, или закройте сообщение, чтобы оставить их на месте. Edit > Undo возвращает их обратно.
  4. Попытка засчитывается, только когда открылся отчёт. Escape никогда не тратит попытку.

Find Unused Images можно запустить на вашем компьютере 3 раза бесплатно, потом расширение попросит лицензию. Никаких всплывающих окон и никакого обратного отсчёта.

Как установить в Cursor, Windsurf или VSCodium

  1. Откройте панель Extensions сочетанием Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Найдите zovo.zovo-image-preview и нажмите Install. Cursor, Windsurf и VSCodium ставят расширения из Open VSX, где это расширение опубликовано как zovo/zovo-image-preview.
  3. Если в вашем редакторе нет каталога расширений, скачайте файл .vsix со страницы на Open VSX и выполните "Extensions: Install from VSIX...".
  4. Дальше всё работает так же, как в VS Code.

Что умеет Image Preview & Image Hover

  • Миниатюры для файлов PNG, JPEG, GIF, WebP, AVIF, SVG, BMP и ICO и для URI data:image/.... Для файлов TIFF и HEIC размер и тип читаются из заголовка.
  • Пути относительно файла, /logo.png из public/, static/ и других корневых веб-папок, @/ для src/, ~ для node_modules или домашней папки и paths из tsconfig.json или jsconfig.json с extends.
  • Имена файлов с пробелами, %20, ?v=2 или #id. Одно имя файла вроде beans.jpg в JSON сопоставляется с ближайшим изображением с таким именем.
  • В монорепозиториях для каждого пакета используются его собственная папка public/ и tsconfig.json.
  • Удалённый URL показывается как ссылка и никогда не скачивается.

Чего расширение не делает

  • Пути, которые собираются во время выполнения, например `icons/${name}.svg` или конкатенация строк, показать нельзя, и из-за них изображение может выглядеть неиспользуемым. Проверьте список неиспользуемых изображений, прежде чем переносить файлы.
  • Одна миниатюра на строку, для первого изображения в этой строке. Подсказка при наведении работает для каждого пути в строке.
  • Удалённые и виртуальные рабочие области (SSH, WSL, Codespaces, vscode.dev) в этой версии не поддерживаются.
  • Алиасы Webpack, Vite или Next.js, которые заданы только в конфигурационном файле JavaScript, не читаются. Добавьте их в imgPreview.aliases или в paths в tsconfig.json.
  • Изображения больше 20 МБ измеряются, но не отрисовываются (настройка imgPreview.maxFileSizeMB). Image Weight Report отмечает тяжёлые файлы, но не сжимает их.

Частые вопросы

Это бесплатно?

Миниатюры на поле редактора, подсказка при наведении и поиск путей бесплатны. У трёх Pro-инструментов, Find Unused Images, Find Broken Image References и Image Weight Report, есть по 3 бесплатные попытки. Потом для них нужен Zovo Pro, 19 USD один раз за все расширения Zovo.

Почему для пути с @/ или алиасом нет изображения?

Возможно, алиас задан только в конфигурационном файле Webpack, Vite или Next.js, а такие файлы не читаются. Добавьте его в imgPreview.aliases или в paths в tsconfig.json.

Работает ли расширение через Remote SSH или WSL?

Не в этой версии. Изображение для подсказки читается с локального диска.

Работает ли расширение в Cursor?

Да. Cursor, Windsurf и VSCodium устанавливают его из Open VSX, где оно опубликовано как zovo/zovo-image-preview.
