Руководства на русском

VS Code и редакторы на его основе (Cursor, Windsurf, VSCodium) открывают текст, изображения и часть медиафайлов. Для многих других форматов нужно расширение. В каждом руководстве есть шаги и сказано, что бесплатно.

  • Как конвертировать файл PDF, Word, PowerPoint или Excel в Markdown в VS Code. Щёлкните правой кнопкой по PDF, DOCX, PPTX, XLSX, CSV, HTML или EPUB в VS Code, и рядом откроется Markdown. Бесплатно, офлайн, без Python и без загрузки.
  • Как отформатировать XML в VS Code и выполнить XPath-запрос. Форматируйте и сжимайте XML в VS Code, меняя только пробелы между тегами, выполняйте XPath 1.0 с пространствами имён файла и копируйте XPath под курсором.
  • Как увидеть изображение по пути в коде на поле редактора и при наведении в VS Code. Миниатюра на поле редактора и подсказка с картинкой, размером в пикселях и весом файла для путей к изображениям в JS, CSS, HTML и Markdown в VS Code. Бесплатно.
  • Как редактировать файл .env в VS Code, не показывая секреты на экране. Подсветка .env в VS Code, секретные значения скрыты точками, пока курсор не на их строке, исправление повторных ключей и кавычек. Бесплатно и офлайн.
  • Как отформатировать скрипт bash или zsh в VS Code. Форматируйте скрипты bash, sh, zsh, bats и mksh в VS Code по Shift+Alt+F или при сохранении. shfmt 3.14.1 встроен, читает .editorconfig и работает офлайн.
  • Как просматривать бакеты AWS S3, Cloudflare R2 или MinIO в VS Code. Бакеты S3, R2, MinIO, B2 и Wasabi в VS Code: объекты открываются только для чтения, загрузка и скачивание с докачкой, синхронизация папки после плана dry-run.
  • Редактирование файлов .proto в VS Code: подсветка, форматирование и переход к определению. Подсветка, форматирование и проверка файлов .proto в VS Code: комментарии сохраняются, ошибки в формулировках protoc. Бесплатно, офлайн, без protoc.
  • Форматирование и проверка конфига nginx в VS Code. Форматирование nginx.conf в VS Code без поломки рабочего файла: пропущенная ; и директивы не в том блоке видны при вводе, подсказки для примерно 300 директив.
  • Предпросмотр диаграммы PlantUML в VS Code прямо во время набора. Живой предпросмотр PlantUML в VS Code для файлов .puml и блоков plantuml в Markdown, рисуется на вашем компьютере. Нужна Java 11, Graphviz не нужен.
  • Просмотр файлов NumPy .npy и .npz в VS Code. Откройте массивы NumPy .npy и .npz в VS Code с бесплатным Tensor Viewer: dtype, форма, статистика, тепловые карты, изображения и значения, без Python.
  • Бесплатный просмотрщик NetCDF в VS Code. Открывайте NetCDF-файлы .nc в VS Code на Windows, macOS и Linux: заголовок, переменные, карты с береговыми линиями, временные ряды. Также HDF5 и MATLAB 7.3.
  • Как открыть базу SQLite в VS Code. Откройте файл .db или .sqlite в VS Code с бесплатным SQLite Viewer & Editor: таблицы, схема и SQL, правка ячеек и строк и сохранение с резервной копией.
  • Предпросмотр диаграмм Mermaid в VS Code. Предпросмотр диаграмм Mermaid в VS Code из файлов .mmd и блоков Markdown с бесплатным Mermaid Viewer. Живой просмотр, экспорт в PNG и SVG, офлайн, без входа.
  • Как открыть STL-файл в VS Code. Откройте STL в VS Code с бесплатным 3D Model Viewer: вращение, измерение по двум точкам, каркас и статистика модели. Также OBJ, PLY, 3MF, GLB и glTF.
  • Как открыть PCAP-файл в VS Code. Читайте дампы .pcap, .pcapng и .pcap.gz в VS Code с бесплатным PCAP Viewer: список пакетов, дерево протоколов, hex-панель и фильтры. Wireshark не нужен.
  • Автоматическое переименование тегов HTML, JSX и Vue в VS Code. Измените имя тега HTML, JSX или Vue, и парный тег изменится сразу. Бесплатное расширение на основе linked editing в VS Code, с автозакрытием и одной отменой.
  • Как читать и возобновлять сессии из истории Claude Code в VS Code. Читайте, ищите и возобновляйте старые сессии Claude Code и Codex в VS Code. Субагенты вложены, правки в виде diff, итоги по токенам. Только чтение, офлайн.
  • Как конвертировать TIFF в PNG без потери качества. Открывайте TIFF, BigTIFF и GeoTIFF в VS Code бесплатно и сохраняйте одну или все страницы в PNG с точными 8- и 16-битными значениями. Офлайн.
  • XMind в PDF без XMind: все листы в одном файле. Откройте майндмэп .xmind в VS Code без XMind и сохраните все листы в один PDF, по странице на лист. Просмотр бесплатный, PDF это инструмент Zovo Pro.
  • Как посмотреть файл шрифта в VS Code. Открывайте шрифты .ttf, .otf, .woff, .woff2 и .ttc в VS Code с бесплатным Font Viewer: свой текст, все глифы и лицензия, без установки шрифта.
  • Воспроизведение аудиофайлов в VS Code. Слушайте WAV, MP3, FLAC, Ogg и Opus в VS Code с бесплатным Audio Player: волновая форма, спектрограмма, A-B петля, скорость и громкость в LUFS.
  • Как открыть чертёж DXF в VS Code. Смотрите чертежи .dxf в VS Code с бесплатным DXF Viewer: ASCII и бинарный DXF, слои, листы пространства листа, поиск текста, измерения и экспорт в PNG или SVG.
  • Как открыть файл внутри ZIP без распаковки. Просматривайте ZIP, JAR, TAR или TAR.GZ в VS Code и открывайте файл из архива во вкладке только для чтения, ничего не распаковывая на диск. Бесплатно и офлайн.
  • Как посмотреть секции и импорты файла ELF, EXE или DLL в VS Code. Открывайте файлы .so, .exe, .dll и .dylib в VS Code с бесплатным ELF Viewer & PE Viewer: заголовки, секции, импорты, экспорты, символы и hex, только чтение.
  • Предпросмотр графа Graphviz DOT без установки Graphviz. Предпросмотр файлов .dot и .gv рядом с редактором VS Code по мере набора, Graphviz уже внутри. Шесть движков раскладки, переход к строке, экспорт в SVG и PNG.
  • Как запустить файл C++ в VS Code одной кнопкой. Компилируйте и запускайте открытый файл .cpp или .c в VS Code одной кнопкой вашим gcc, g++ или clang. Ввод в терминале, ошибки в Problems, тестовые примеры.
  • Просмотр файлов Parquet в VS Code. Откройте .parquet, .parq и .pq в VS Code как сортируемую сетку со схемой, вложенными столбцами и точными DECIMAL. Бесплатно, без Python.
  • Как открыть JAR и прочитать декомпилированный исходник Java в VS Code. Открывайте файлы .jar, .war, .ear, .aar и .class в VS Code: пакеты, MANIFEST.MF, байткод и исходник Java, декомпилированный CFR. Бесплатно, только чтение.
  • Сравнение двух файлов Excel или CSV в VS Code. Сравните два файла .xlsx, .xls, .ods или CSV в VS Code по ячейкам: изменённые ячейки, добавленные и удалённые строки, столбцы, листы и Git HEAD. Бесплатно.
  • Как отформатировать HTML и CSS в VS Code, не ломая блоки pre и inline-теги. Форматирование HTML, CSS, SCSS и LESS в VS Code с блоками style и script и .editorconfig. Pre, textarea, inline-теги и порядок атрибутов не меняются. Бесплатно.
  • Как загружать файлы на сервер по SFTP или FTP из VS Code. Настройте .vscode/sftp.json, и VS Code будет выгружать каждый файл при сохранении по SFTP, FTP или FTPS. Выгрузка, скачивание и сравнение. Бесплатно.
  • Hex-редактор для бинарных файлов в VS Code. Hex Viewer открывает любой файл в VS Code в hex-виде: переход к смещению, поиск байтов, вставка и удаление, сравнение двух файлов. Бесплатно и офлайн.
  • Как открыть .docx в VS Code. Откройте .docx, .odt и старые .doc прямо в VS Code: тёмная тема, поиск, структура, правки, комментарии и сравнение версий. Без Office.
  • Excel и CSV в VS Code, с SQL-запросами. Откройте .xlsx, .xls, CSV и Parquet в VS Code как таблицу до 1 000 000 строк: сортировка, фильтры и SQL-запросы. Без Python и базы данных.
  • Word и PowerPoint в VS Code без Office. DOCX Viewer открывает .docx, .odt и .doc в VS Code, а PPTX Viewer показывает слайды .pptx. Office и LibreOffice не нужны, просмотр бесплатный.
  • PDF в тёмном режиме в VS Code. PDF Reader открывает PDF во вкладке VS Code на тёмных или сепия-страницах, фотографии сохраняют цвета. Поиск, структура и выделения бесплатны.
