Предпросмотр диаграммы PlantUML в VS Code прямо во время набора

Установите бесплатное расширение PlantUML Viewer & Preview, откройте файл .puml или файл Markdown с блоком plantuml и нажмите кнопку предпросмотра. Диаграмма рисуется рядом с кодом прямо во время набора. Её строит jar PlantUML, который входит в расширение, с помощью вашей Java 11 или новее, поэтому ничего не отправляется на сервер и Graphviz не нужен. Предпросмотр, масштабирование, ссылки на ошибки и сохранение одной диаграммы в SVG или PNG бесплатны. Zovo Pro (19 USD один раз) добавляет три инструмента, Export All Diagrams in a Folder, Markdown Diagrams to Images и Compare with a Git Version, и у каждого есть 3 бесплатные попытки.

Как это сделать в VS Code

  1. Установите PlantUML Viewer & Preview из Marketplace или нажмите Ctrl+P (Cmd+P на macOS) и выполните ext install zovo.zovo-plantuml-viewer.
  2. Убедитесь, что установлена Java 11 или новее. Расширение ищет её в настройке plantumlViewer.javaPath, затем в JAVA_HOME, затем java в PATH и затем в обычных папках JDK. Если ничего не найдено, предпросмотр сообщает об этом и предлагает кнопку "Set the Java path". Команда "PlantUML: Show Java and Layout Status" показывает, что найдено.
  3. Откройте файл .puml, .plantuml, .iuml, .pu или .wsd либо файл Markdown с блоком ```plantuml и нажмите кнопку предпросмотра в правом верхнем углу редактора. Можно также нажать Alt+D в файле PlantUML или запустить "PlantUML: Open Preview to the Side".
  4. Печатайте. Предпросмотр перерисовывается через мгновение после того, как вы перестали печатать (по умолчанию через 400 мс, настройка plantumlViewer.renderDelay). Все диаграммы файла показываются в одном предпросмотре, а диаграмма под курсором обведена рамкой.
  5. Масштабируйте кнопками, колёсиком мыши с зажатым Ctrl или Cmd или клавишами + и -. Кнопка Fit подгоняет диаграмму под ширину панели, а перетаскиванием можно перемещаться по диаграмме. Диаграмма с ошибкой показывает сообщение PlantUML и ссылку "Go to line".
  6. Нажмите SVG или PNG над диаграммой, чтобы сохранить только её, или Copy SVG, чтобы её скопировать.

Что бесплатно и что добавляет Zovo Pro

Живой предпросмотр файлов .puml, .plantuml, .iuml, .pu и .wsd и блоков plantuml в Markdown, масштабирование и перемещение, ошибки со ссылкой на строку, сохранение одной диаграммы в SVG или PNG, Copy SVG, подсветка синтаксиса, сниппеты (seq, classd, activity, mindmap, gantt и другие), сворачивание и комментарии бесплатны. Диаграммы рисуются на вашем компьютере и никогда не отправляются на сервер.

Когда диаграммы проекта нужно вставить в документацию или слайды, Export All Diagrams in a Folder за один запуск записывает каждую диаграмму каждого файла PlantUML в папке и её подпапках в SVG, PNG или PDF, рядом с каждым файлом или все в одну папку. Диаграммы с ошибками пропускаются и перечисляются с файлом, строкой и сообщением, остальные записываются. Не нужно открывать каждый файл и сохранять каждую диаграмму вручную.

Как установить в Cursor, Windsurf или VSCodium

  1. Откройте панель Extensions сочетанием Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Найдите zovo.zovo-plantuml-viewer и нажмите Install. Cursor, Windsurf и VSCodium ставят расширения из Open VSX, где это расширение опубликовано как zovo/zovo-plantuml-viewer.
  3. Если в вашем редакторе нет каталога расширений, скачайте файл .vsix со страницы на Open VSX и выполните "Extensions: Install from VSIX...".
  4. Дальше всё работает так же, как в VS Code.

Что умеет PlantUML Viewer & Preview

  • Диаграммы последовательности, классов, активности, компонентов, состояний и вариантов использования, mind map, диаграммы Ганта и другие блоки @start... встроенного PlantUML (сборка MIT 1.2026.10).
  • Блоки ```plantuml, ```puml и ```uml в Markdown, с @startuml внутри или без него. Кнопка предпросмотра появляется в файле Markdown, где есть хотя бы один такой блок.
  • !include файлов из папки диаграммы, папок рабочей области и plantumlViewer.includePaths, а также стандартная библиотека, например !include <C4/C4_Container>, без интернета. Include для C4, иконок AWS и иконочных шрифтов, записанные как адреса https://raw.githubusercontent.com/..., читаются из копии внутри jar.
  • Диаграммам последовательности, mind map и диаграммам Ганта движок раскладки не нужен. Диаграммы классов, компонентов, состояний и вариантов использования используют Graphviz, если установлен dot (plantumlViewer.layout со значением auto), а иначе встроенный в PlantUML движок Smetana.
  • Диаграммы показываются как изображения, поэтому ссылки или текст внутри диаграммы не могут запустить код в редакторе.

Чего расширение не делает

  • Должна быть установлена Java 11 или новее. Расширение не скачивает Java.
  • Include с веб-адресов отклоняются, кроме адресов C4, иконок AWS и иконочных шрифтов, копия которых есть в jar. Иконки AWS берутся из набора иконок AWS внутри PlantUML (версия 20), поэтому более новая иконка показывает ошибку со своим именем.
  • В сборке MIT нет Ditaa и рендерера LaTeX для @startmath. Блок Ditaa показывает страницу PlantUML "not supported".
  • Без Graphviz движок Smetana раскладывает диаграммы классов и компонентов немного иначе, а очень большие диаграммы классов могут выглядеть плотнее.
  • Диаграмма, которая рисуется дольше 30 секунд (настройка plantumlViewer.renderTimeoutSeconds), останавливается, а изображения обрезаются до 8192 пикселей по стороне (настройка plantumlViewer.maxImageSize).

Частые вопросы

Это бесплатно?

Живой предпросмотр, масштабирование и перемещение, ссылки на ошибки, сохранение одной диаграммы в SVG или PNG, подсветка синтаксиса и сниппеты бесплатны. У трёх Pro-инструментов, Export All Diagrams in a Folder, Markdown Diagrams to Images и Compare with a Git Version, есть по 3 бесплатные попытки. После этого нужен Zovo Pro, 19 USD один раз для всех расширений Zovo.

Нужны ли Java или Graphviz?

Java 11 или новее нужна, потому что PlantUML написан на Java. Graphviz не нужен. Без него диаграммы классов и компонентов раскладывает встроенный в PlantUML движок Smetana. Если dot установлен, используется он.

Отправляется ли моя диаграмма на сервер?

Нет. Встроенный jar PlantUML работает на вашем компьютере с профилем безопасности ALLOWLIST, а include с веб-адресов отклоняются. Сервер PlantUML не используется.

Работает ли расширение в Cursor?

Да. Cursor, Windsurf и VSCodium устанавливают его из Open VSX, где оно опубликовано как zovo/zovo-plantuml-viewer.
