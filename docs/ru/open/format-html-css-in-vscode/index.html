Как отформатировать HTML и CSS в VS Code, не ломая блоки pre и inline-теги

Установите бесплатное расширение HTML Formatter & CSS Formatter и нажмите Shift+Alt+F в файле HTML, CSS, SCSS или LESS. Оно форматирует и блоки <style> и <script> внутри страницы, следует вашему .editorconfig, оставляет <pre>, <textarea> и inline-теги в том виде, в каком вы их написали, и никогда не меняет порядок атрибутов. Расширение работает офлайн со встроенным js-beautify, поэтому Node, npm и файл конфигурации не нужны. Zovo Pro (19 USD один раз) добавляет три инструмента: Format Folder with Diff Preview, Minify HTML and CSS и HTML Lint Report. У каждого есть 3 бесплатные попытки.

Как это сделать в VS Code

  1. Установите HTML Formatter & CSS Formatter из Marketplace или нажмите Ctrl+P (Cmd+P на macOS) и выполните ext install zovo.zovo-html-formatter.
  2. Откройте файл HTML, CSS, SCSS или LESS и нажмите Shift+Alt+F (Shift+Option+F в macOS). Если VS Code спросит, какой форматировщик использовать, выберите HTML Formatter & CSS Formatter.
  3. Чтобы за один шаг сделать его форматировщиком по умолчанию для всех четырёх языков, выполните «HTML Formatter: Use as Default Formatter for HTML, CSS, SCSS and LESS» в Command Palette.
  4. Выделите несколько строк и выполните Format Selection, чтобы отформатировать только их.
  5. Чтобы форматировать при каждом сохранении, включите zovoHtmlFormat.formatOnSave или используйте штатный editor.formatOnSave VS Code, когда расширение уже стало форматировщиком по умолчанию.
  6. Отступы берутся из настроек редактора, затем из .editorconfig (стиль и размер отступа, конец строки, перевод строки в конце файла, максимальная длина строки), поэтому у всей команды получается одинаковый результат.

Что бесплатно и что добавляет Zovo Pro

Когда весь сайт нужно привести к одному стилю, Format Folder with Diff Preview форматирует в памяти каждый файл HTML, CSS, SCSS и LESS в папке, показывает изменённые файлы с diff бок о бок для каждого и записывает только те файлы, на которых вы оставили отметку. Вы видите каждое изменение до того, как файл будет записан.

Как установить в Cursor, Windsurf или VSCodium

  1. Откройте панель Extensions сочетанием Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Найдите zovo.zovo-html-formatter и нажмите Install. Cursor, Windsurf и VSCodium ставят расширения из Open VSX, где это расширение опубликовано как zovo/zovo-html-formatter.
  3. Если в вашем редакторе нет каталога расширений, скачайте файл .vsix со страницы на Open VSX и выполните "Extensions: Install from VSIX...".
  4. Дальше всё работает так же, как в VS Code.

Что умеет HTML Formatter & CSS Formatter

  • CSS в <style> и JavaScript в <script> внутри HTML.
  • Остаются как написаны: содержимое <pre> и <textarea>, inline-теги на своей строке, порядок атрибутов, пустые строки между блоками (не больше одной подряд), стиль отступов head и body страницы и шаблонные теги вроде {{ }} и {% %}.
  • В SCSS и LESS многострочные map и вызовы функций сохраняют свою раскладку, а комментарии в конце строки остаются на своей строке.
  • Ещё два инструмента Pro. Minify HTML and CSS записывает копии .min.html и .min.css с отчётом о сэкономленных байтах и байтах после gzip. HTML Lint Report находит изображения без alt, поля форм без label, повторяющиеся id, пропущенные уровни заголовков и другие проблемы и выводит их в отчёт Markdown и в панель Problems.

Чего расширение не делает

  • Отдельные файлы .js, .jsx, .ts, Vue и Svelte это расширение не форматирует. Форматируется только JavaScript внутри <script>.
  • Строки не переносятся, пока вы не зададите длину переноса, поэтому очень длинная строка так и остаётся длинной.
  • SCSS и LESS обрабатываются форматировщиком CSS. Необычный синтаксис, например detached rulesets в LESS, может сохранить исходные пробелы.
  • Минификация не сокращает JavaScript, не переименовывает и не объединяет правила CSS.

Частые вопросы

Это бесплатно?

Format Document, Format Selection и форматирование при сохранении для HTML, CSS, SCSS и LESS бесплатны. У трёх инструментов Pro, Format Folder with Diff Preview, Minify HTML and CSS и HTML Lint Report, есть по 3 бесплатные попытки. Дальше нужен Zovo Pro: 19 USD один раз за все расширения Zovo.

Форматирует ли VS Code HTML без расширения?

Да. В VS Code есть встроенный форматировщик HTML и CSS. Это расширение читает .editorconfig, сохраняет собственные отступы head и body страницы, сохраняет раскладку map в SCSS и LESS и добавляет инструменты Pro для папок, минификации и проверки.

Изменит ли оно мои блоки pre или порядок атрибутов?

Нет. Содержимое pre и textarea, inline-теги и порядок атрибутов остаются такими, как вы их написали.

Нужны ли Node или npm?

Нет. js-beautify 1.15.4 встроен в расширение и работает офлайн.
