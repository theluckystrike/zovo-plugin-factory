Как конвертировать файл PDF, Word, PowerPoint или Excel в Markdown в VS Code

Установите бесплатное расширение Convert to Markdown, в Explorer щёлкните правой кнопкой по файлу PDF, Word, PowerPoint, Excel, CSV, HTML, EPUB, ODT или RTF и выберите Convert to Markdown. Markdown откроется рядом с файлом, с заголовками, списками, таблицами, ссылками и заметками докладчика к слайдам, и никакие данные не покидают ваш компьютер. Convert to Markdown и Copy as Markdown бесплатны для всех форматов. Zovo Pro (19 USD один раз) добавляет три инструмента, Convert a Folder to Markdown, Convert to Markdown with Images и LLM-ready Markdown Chunks, и у каждого есть 3 бесплатные попытки.

Как это сделать в VS Code

  1. Установите Convert to Markdown из Marketplace или нажмите Ctrl+P (Cmd+P на macOS) и выполните ext install zovo.zovo-convert-to-markdown.
  2. В Explorer щёлкните правой кнопкой по файлу .pdf, .docx, .pptx, .xlsx, .xls, .ods, .csv, .tsv, .html, .epub, .odt или .rtf и выберите Convert to Markdown. Можно также щёлкнуть правой кнопкой по вкладке открытого файла.
  3. Или выполните "Convert to Markdown: Convert to Markdown" из Command Palette. Команда конвертирует файл в активной вкладке или просит выбрать файл.
  4. Markdown открывается рядом с файлом как несохранённый документ. Для больших файлов показывается прогресс с кнопкой Cancel.
  5. Сохраните документ. Имя name.md рядом с исходным файлом уже подставлено. Чтобы каждый раз сразу сохранять файл туда, задайте для toMarkdown.output значение file.
  6. Чтобы вставить Markdown в другое место, щёлкните по файлу правой кнопкой и выберите Copy as Markdown. Если выделить в Explorer несколько файлов, они конвертируются по очереди.
  7. Нет файла под рукой? Выполните "Convert to Markdown: Convert a sample file" из Command Palette, чтобы конвертировать встроенный пример Word, PDF или PowerPoint.

Файлы с одинаковым именем сохраняют свой тип в новом имени (report.pdf.md, report.docx.md), поэтому ни один не теряется.

Как установить в Cursor, Windsurf или VSCodium

  1. Откройте панель Extensions сочетанием Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Найдите zovo.zovo-convert-to-markdown и нажмите Install. Cursor, Windsurf и VSCodium ставят расширения из Open VSX, где это расширение опубликовано как zovo/zovo-convert-to-markdown.
  3. Если в вашем редакторе нет каталога расширений, скачайте файл .vsix со страницы на Open VSX и выполните "Extensions: Install from VSIX...".
  4. Дальше всё работает так же, как в VS Code.

Что умеет Convert to Markdown

  • PDF с заголовками по размеру шрифта, абзацами, в которых склеены разорванные строки и слова с переносами, списками, простыми таблицами и двухколоночными страницами, которые читаются по колонкам. Повторяющиеся колонтитулы и номера страниц убираются.
  • Word (.docx, .docm, .dotx) с заголовками, жирным шрифтом, курсивом, зачёркнутым текстом, ссылками, вложенными списками, таблицами, цитатами и сносками.
  • PowerPoint (.pptx, .pptm, .ppsx, .potx) с разделом ## Slide n: title для каждого слайда, пунктами списков с их уровнями, таблицами и заметками докладчика.
  • Excel и другие таблицы (.xlsx, .xlsm, .xlsb, .xls, .ods) с разделом ## Sheet: name и pipe-таблицей для каждого листа. CSV и TSV превращаются в одну таблицу.
  • HTML (.html, .htm, .xhtml), где блоки кода сохраняют язык, а скрипты и стили убираются, и EPUB, где главы идут в порядке чтения.

Чего расширение не делает

  • В отсканированных PDF (изображениях страниц) нет текста для конвертации. Распознавания текста (OCR) нет.
  • Таблицы в PDF определяются по промежуткам между колонками. Таблицы без чётких промежутков выводятся как абзацы.
  • При бесплатной конвертации изображения превращаются в заглушки вроде *[Image: Map of the site]*. Диаграммы, SmartArt и видео на слайдах только называются, но не конвертируются.
  • Старые файлы Word 97-2003 и RTF дают текст и таблицы без форматирования. Для файлов, защищённых паролем, и старых файлов PowerPoint 97-2003 вместо конвертации показывается сообщение.
  • Файлы больше 200 МБ не конвертируются (настройка toMarkdown.maxFileSizeMB), а конвертация PDF останавливается после 1000 страниц (настройка toMarkdown.pdfMaxPages).

Частые вопросы

Это бесплатно?

Convert to Markdown и Copy as Markdown бесплатны для всех форматов. У трёх Pro-инструментов, Convert a Folder to Markdown, Convert to Markdown with Images и LLM-ready Markdown Chunks, есть по 3 бесплатные попытки. Потом для них нужен Zovo Pro, 19 USD один раз за все расширения Zovo.

Расширение куда-то загружает мои файлы?

Нет. Конвертеры работают на вашем компьютере, внутри VS Code, без сетевых запросов и без телеметрии.

Конвертирует ли расширение отсканированные PDF?

Нет. В отсканированном PDF лежат изображения страниц, а не текст, а в Convert to Markdown нет OCR.

Работает ли расширение в Cursor?

Да. Cursor, Windsurf и VSCodium устанавливают его из Open VSX, где оно опубликовано как zovo/zovo-convert-to-markdown.
