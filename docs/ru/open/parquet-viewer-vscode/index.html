Просмотр файлов Parquet в VS Code

Установите бесплатное расширение Parquet Grid Viewer от Zovo и кликните по файлу .parquet, .parq или .pq. Он открывается как сетка с типами столбцов, фильтром под каждым заголовком и вкладкой Schema, и для этого не нужны Python, Java или parquet-tools. При открытии читается только footer, а строки подгружаются по мере прокрутки, поэтому большие файлы открываются сразу. Сетка, схема, фильтры, сортировка, поиск, копирование и экспорт в CSV и JSON Lines бесплатны. Zovo Pro (19 USD один раз) добавляет три инструмента, Column profile, Compare two Parquet files и Folder report, у каждого 3 бесплатных запуска.

Как это сделать в VS Code

  1. Установите Parquet Grid Viewer из Marketplace или нажмите Ctrl+P (Cmd+P на macOS) и выполните ext install zovo.zovo-parquet-viewer.
  2. Кликните по файлу .parquet, .parq или .pq в Explorer. Он открывается в сетке. Если файл открывает другой редактор, кликните по нему правой кнопкой и выберите "Open in Parquet Grid Viewer".
  3. Кликните по заголовку столбца, чтобы отсортировать. Второй клик сортирует по убыванию, третий снимает сортировку.
  4. Введите условие в поле под заголовком, чтобы отфильтровать столбец, например >100, =cash, !night, 5..9, null или регулярное выражение вроде /^JFK|LGA/. Поле "Search all columns" вверху ищет по всем столбцам, в том числе вложенным. Фильтр, сортировка и поиск работают по всему файлу, а не только по строкам на экране.
  5. Кликните по ячейке и нажмите Enter или кнопку Details, чтобы увидеть значение целиком. Ячейки LIST, MAP и STRUCT открываются в виде дерева.
  6. Вкладка Schema показывает типы столбцов, row groups, сжатие, page index и метаданные key-value. Кнопка "Copy schema as JSON" копирует схему.
  7. Кнопка Copy кладёт выбранные ячейки или строки в буфер обмена как CSV, JSON или таблицу Markdown. Кнопка Export сохраняет все строки текущего вида, с фильтрами и сортировкой, в CSV или JSON Lines.

Что бесплатно и что добавляет Zovo Pro

Сетка, вкладка Schema, фильтры, сортировка, поиск, просмотр ячеек, копирование и экспорт в CSV и JSON Lines бесплатны. Входить в аккаунт не нужно, и просмотрщик не делает сетевых запросов.

Column profile один раз читает все строки файла и для каждого столбца выводит null, различные значения, min и max, среднее, стандартное отклонение и 5 самых частых значений. Отчёт открывается в Markdown, его можно сохранить в CSV. Так видно, что лежит в каждом столбце нового файла, без запроса в pandas или DuckDB.

Как запустить Column profile (Zovo Pro)

  1. Откройте файл и нажмите "Column profile" в небольшой строке Zovo Pro на панели инструментов просмотрщика или кликните по файлу правой кнопкой в Explorer и выберите "Zovo Pro: Column profile".
  2. Или выполните "Parquet Grid Viewer: Column profile: nulls, distinct, min, max, mean (Zovo Pro)" из Command Palette. Команда берёт открытый файл Parquet или просит выбрать файл.
  3. Ход работы виден в уведомлении, кнопка Cancel останавливает запуск. Запуск засчитывается, только когда отчёт появился на экране, поэтому Cancel или Escape ничего не стоят.
  4. Отчёт открывается как документ Markdown. Нажмите "Save as CSV" в сообщении, чтобы сохранить профиль в CSV-файл.

Column profile можно запустить на вашем компьютере 3 раза бесплатно, потом расширение попросит лицензию. Никаких всплывающих окон и никакого обратного отсчёта.

Как установить в Cursor, Windsurf или VSCodium

  1. Откройте панель Extensions сочетанием Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Найдите zovo.zovo-parquet-viewer и нажмите Install. Cursor, Windsurf и VSCodium ставят расширения из Open VSX, где это расширение опубликовано как zovo/zovo-parquet-viewer.
  3. Если в вашем редакторе нет каталога расширений, скачайте файл .vsix со страницы на Open VSX и выполните "Extensions: Install from VSIX...".
  4. Дальше всё работает так же, как в VS Code.

Что умеет Parquet Grid Viewer

  • Файлы .parquet, .parq и .pq.
  • Snappy, Gzip, Zstd, Brotli, LZ4 и LZ4_RAW, страницы данных v1 и v2, кодировки dictionary, delta и byte-stream-split.
  • Точные значения DECIMAL до 38 цифр, INT64 и UINT64 больше 2^53, метки времени в наносекундах и метки времени INT96 из Spark и Hive.
  • Столбцы LIST, MAP и STRUCT, в сетке как компактный JSON, в панели подробностей как дерево.
  • Понятные сообщения для обрезанных, повреждённых и зашифрованных файлов, а также для файлов, которые вовсе не Parquet.

Чего расширение не делает

  • Расширение только читает файлы. Чтобы менять данные, используйте pandas, Polars, DuckDB или Spark.
  • Для зашифрованных файлов Parquet (Parquet Modular Encryption) показывается сообщение. Ключи просмотрщик не запрашивает.
  • Файлы, у которых фрагменты столбцов лежат в других файлах (file_path в метаданных), не поддерживаются.
  • Сортировка останавливается на 2 000 000 строк (настройка parquetViewer.maxSortRows). Чтобы отсортировать часть большего файла, сначала отфильтруйте его. Copy берёт не больше 100 000 строк за раз (настройка parquetViewer.maxCopyRows).
  • Файлы на удалённых и виртуальных файловых системах читаются целиком, до 512 МБ (настройка parquetViewer.maxVirtualFileMB).

Частые вопросы

Это бесплатно?

Сетка, схема, фильтры, сортировка, поиск, просмотр ячеек, копирование и экспорт в CSV и JSON Lines бесплатны. У трёх Pro-инструментов, Column profile, Compare two Parquet files и Folder report, по 3 бесплатных запуска. После этого нужен Zovo Pro, 19 USD один раз для всех расширений Zovo.

Нужны ли Python или parquet-tools?

Нет. Просмотрщик написан на чистом JavaScript без нативных модулей, поэтому одинаково работает в Windows, macOS (и на Apple silicon), Linux, Remote SSH, WSL и Codespaces.

Как открываются большие файлы?

При открытии читается только footer. Потом строки читаются блоками в фоновом потоке, когда они появляются при прокрутке, а старые блоки освобождаются. Фильтр, сортировка, поиск и экспорт читают нужные им столбцы, row group за row group, с индикатором хода и кнопкой Cancel.

Работает ли это в Cursor?

Да. Parquet Grid Viewer есть на Open VSX как zovo/zovo-parquet-viewer, поэтому его можно установить в Cursor, Windsurf и VSCodium.
