Как посмотреть файл шрифта в VS Code

Установите бесплатное расширение Font Viewer и кликните по файлу .ttf, .otf, .woff, .woff2 или .ttc. Оно показывает ваш текст этим шрифтом, каскад размеров, сетку глифов с поиском, а также лицензию и права на встраивание, и шрифт не нужно устанавливать в систему. Проверка текста (Type tester), сетка глифов, карта символов, вкладка Info и Copy CSS @font-face бесплатны. Zovo Pro (19 USD один раз) добавляет два инструмента, Convert Font и Font Folder Report, у каждого 3 бесплатных запуска.

Как это сделать в VS Code

  1. Установите Font Viewer из Marketplace или нажмите Ctrl+P (Cmd+P на macOS) и выполните ext install zovo.font-viewer-vscode.
  2. Кликните по файлу .ttf, .otf, .woff, .woff2, .ttc или .otc в Explorer. Font Viewer открывает эти файлы по умолчанию и никогда не меняет шрифт.
  3. На вкладке Type tester введите свой текст, двигайте ползунок размера от 8 до 200 px и смотрите каскад от 12 до 96 px. У вариативного шрифта двигайте ползунки осей и включайте или выключайте функции OpenType, например liga или ss01.
  4. На вкладке Glyphs ищите по имени, символу, U+20AC или номеру глифа. Кликните по глифу, чтобы увидеть его крупно с базовой линией, высотой строчных (x-height) и высотой прописных, и скопируйте символ, его код или контур в SVG.
  5. На вкладке Characters смотрите покрытие каждого блока Unicode, например "Basic Latin 95/128". Выключите "Only characters in the font", чтобы увидеть, каких символов нет.
  6. На вкладке Info читайте лицензию, дизайнера, копирайт и права на встраивание и копируйте готовое правило @font-face.

Что бесплатно и что добавляет Zovo Pro

Открытие всех поддерживаемых шрифтов, Type tester, сетка глифов, карта символов, вкладка Info и Copy CSS @font-face бесплатны. Font Viewer работает офлайн, без сетевых запросов и без телеметрии.

Font Folder Report перечисляет все шрифты в папке: семейство, начертание, насыщенность, оси, версия, число глифов, лицензия, ссылка на лицензию и права на встраивание. Список сохраняется как CSV-файл, таблица Markdown или один fonts.css с правилом @font-face для каждого шрифта (сначала WOFF2). Прежде чем включить папку шрифтов в приложение или сайт, вы видите в одном файле, как можно использовать каждый шрифт, и не открываете их по одному.

Как запустить Font Folder Report (Zovo Pro)

  1. Кликните правой кнопкой по папке со шрифтами в Explorer и выберите "Font Folder Report: CSV, Markdown or @font-face CSS… (Pro)" или выполните "Font Viewer: Font Folder Report: CSV, Markdown or @font-face CSS… (Pro)" из Command Palette и выберите папку.
  2. Выберите формат: CSV, таблица Markdown или правила CSS @font-face.
  3. Сохраните файл. Имена по умолчанию fonts-report.csv, fonts-report.md и fonts.css. Запуск засчитывается, только когда файл записан.

Font Folder Report можно запустить на вашем компьютере 3 раза бесплатно, потом расширение попросит лицензию. Никаких всплывающих окон и никакого обратного отсчёта.

Как установить в Cursor, Windsurf или VSCodium

  1. Откройте панель Extensions сочетанием Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Найдите zovo.font-viewer-vscode и нажмите Install. Cursor, Windsurf и VSCodium ставят расширения из Open VSX, где это расширение опубликовано как zovo/font-viewer-vscode.
  3. Если в вашем редакторе нет каталога расширений, скачайте файл .vsix со страницы на Open VSX и выполните "Extensions: Install from VSIX...".
  4. Дальше всё работает так же, как в VS Code.

Что умеет Font Viewer

  • Шрифты TrueType .ttf и OpenType .otf, в том числе вариативные.
  • Веб-шрифты .woff и .woff2. WOFF2 распаковывает собственный декодер расширения.
  • Коллекции .ttc и .otc, начертание выбирается из списка в заголовке.
  • Большие CJK-шрифты на 20 000 глифов, которые подгружаются страницами при прокрутке.
  • Кликните правой кнопкой по шрифту в Explorer и выберите Copy CSS @font-face, не открывая файл.

Чего расширение не делает

  • Коллекции WOFF2, SVG-шрифты, .dfont и шрифты Type 1 не поддерживаются.
  • Контуры глифов показаны для начального экземпляра вариативного шрифта. Type tester, каскад размеров и карта символов следуют ползункам осей.
  • Цветные шрифты рисуются в цвете в Type tester и в карте символов, а сетка глифов показывает их простые контуры.
  • Для файлов больше 64 МБ вместо шрифта показывается сообщение (настройка fontViewer.maxFileMB).
  • Расширение только читает файлы. Оно не редактирует шрифты и не устанавливает их в систему.

Частые вопросы

Это бесплатно?

Просмотр шрифтов, Type tester, сетка глифов, карта символов, вкладка Info и Copy CSS @font-face бесплатны. У двух Pro-инструментов, Convert Font и Font Folder Report, по 3 бесплатных запуска. После этого нужен Zovo Pro, 19 USD один раз для всех расширений Zovo.

Нужно ли устанавливать шрифт?

Нет. Шрифт читается из файла и показывается только во вкладке Font Viewer. Список шрифтов в системе не меняется.

Можно ли открыть WOFF2 из папки сборки?

Да. WOFF2 распаковывает собственный декодер расширения, а открытый вид перезагружается, когда вы сохраняете новую сборку шрифта.

Работает ли это в Cursor?

Да. Font Viewer есть на Open VSX как zovo/font-viewer-vscode, поэтому его можно установить в Cursor, Windsurf и VSCodium.
