Как загружать файлы на сервер по SFTP или FTP из VS Code

Установите бесплатное расширение SFTP & FTP Sync and Upload и создайте .vscode/sftp.json с адресом сервера, именем пользователя и папкой на сервере. После этого каждый файл выгружается на сервер при сохранении по SFTP, FTP или FTPS. Щёлкните правой кнопкой по файлу или папке, чтобы выгрузить или скачать их, а файл можно ещё и сравнить с копией на сервере. В панели Remote Files файлы сервера открываются в обычной вкладке. Папка .vscode, файлы .env и приватные ключи никогда не выгружаются. Всё это бесплатно и без учётной записи. Zovo Pro (19 USD один раз) добавляет три инструмента: Sync Folder with Remote, Roll Back a Remote File и Server Profiles and Jump Host. У каждого есть 3 бесплатные попытки.

Как это сделать в VS Code

  1. Установите SFTP & FTP Sync and Upload из Marketplace или нажмите Ctrl+P (Cmd+P на macOS) и выполните ext install zovo.zovo-sftp.
  2. Выполните «SFTP: Create sftp.json Config» из Command Palette или нажмите Create sftp.json в панели SFTP Remote.
  3. Заполните protocol (sftp, ftp или ftps), host, username, privateKeyPath (не указывайте его, если входите по паролю) и remotePath, то есть папку на сервере, которая соответствует вашей локальной папке. Наведите указатель на любой ключ, чтобы увидеть подсказку.
  4. Задайте "uploadOnSave": true. Теперь каждый сохранённый файл выгружается на сервер. Введённый пароль запрашивается один раз и хранится в защищённом хранилище редактора (secret storage), а не в sftp.json.
  5. Щёлкните правой кнопкой по файлу или папке в Explorer либо по вкладке и выберите Upload, Download или Compare with Server Copy (сравнение работает только для файлов).
  6. Откройте панель Remote Files, чтобы просматривать сервер. Файл можно открыть в обычной вкладке редактора и сохранить обратно, скачать, скопировать его путь или удалить. Команда «SFTP: Show Transfer Log» показывает все подключения и передачи.

Что бесплатно и что добавляет Zovo Pro

Выгрузка при сохранении, Upload, Download и Compare with Server Copy, панель Remote Files, SFTP, FTP и FTPS, проверка ключа хоста и журнал передач бесплатны. Учётная запись не нужна, входить приходится только на ваш собственный сервер. Телеметрии нет.

Когда содержимое сервера и локальной папки разошлось, Sync Folder with Remote сравнивает их и показывает все различия до того, как что-либо будет передано: файлы, которые есть только локально, только на сервере или новее с одной из сторон. Для каждого файла вы выбираете выгрузку, скачивание, удаление или пропуск, открываете сравнение двух версий рядом, сохраняете пробный прогон как текст и затем применяете план. Вы точно видите, что изменится на сервере, ещё до изменения.

Как запустить Sync Folder with Remote (Zovo Pro)

  1. Щёлкните правой кнопкой по папке в Explorer и выберите «Zovo Pro: Sync folder with remote (diff preview)» или выполните «SFTP: Sync Folder with Remote, Diff Preview (Pro)...» из Command Palette. Такая же кнопка есть в заголовке панели Remote Files.
  2. Прочитайте план. Для каждого файла выберите выгрузку, скачивание, удаление или пропуск и откройте сравнение для файлов, в которых не уверены.
  3. Примените план. Попытка засчитывается, только если план синхронизации был показан. Escape или Cancel попытку не расходуют.

Как установить в Cursor, Windsurf или VSCodium

  1. Откройте панель Extensions сочетанием Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Найдите zovo.zovo-sftp и нажмите Install. Cursor, Windsurf и VSCodium ставят расширения из Open VSX, где это расширение опубликовано как zovo/zovo-sftp.
  3. Если в вашем редакторе нет каталога расширений, скачайте файл .vsix со страницы на Open VSX и выполните "Extensions: Install from VSIX...".
  4. Дальше всё работает так же, как в VS Code.

Что умеет SFTP & FTP Sync and Upload

  • SFTP с SSH-ключами, зашифрованными ключами, SSH-агентом или паролем; FTP; FTPS с явным или неявным TLS.
  • .vscode, .git, файлы .env, приватные ключи, .npmrc и другие секретные файлы никогда не выгружаются. Свои шаблоны можно добавить в ignore в стиле .gitignore.
  • Ключ хоста сервера проверяется: закрепите его в hostFingerprint или подтвердите при первом подключении. Если ключ изменился, подключение прерывается.
  • В папке, которой вы не доверяете (Restricted Mode), расширение отключено, поэтому скачанный проект не может никуда отправить ваши файлы.
  • Есть ещё два инструмента Pro. Roll Back a Remote File хранит на вашем компьютере 10 последних серверных копий файла, прежде чем выгрузка его перезапишет. Server Profiles and Jump Host позволяет описать несколько серверов (staging, production) в одном sftp.json и подключаться через промежуточный SSH-хост (jump host).

Чего расширение не делает

  • К одному серверу открывается одно подключение за раз, а передачи по FTP идут по очереди.
  • Символические ссылки на сервере для файлов работают, но связанные папки не обходятся при выгрузке, скачивании и синхронизации папок.
  • Ключи в формате PuTTY .ppk сначала нужно преобразовать в формат OpenSSH (puttygen key.ppk -O private-openssh -o key).
  • Синхронизация сравнивает размер и время изменения, затем побайтно сравнивает файлы одинакового размера, не больше 300 файлов или 64 МБ за один запуск.
  • Копии для отката по умолчанию сохраняются для файлов до 5 МБ и только на этом компьютере.

Частые вопросы

Это бесплатно?

Выгрузка при сохранении, Upload, Download, Compare with Server Copy, панель Remote Files и журнал передач бесплатны для SFTP, FTP и FTPS. У трёх инструментов Pro (Sync Folder with Remote, Roll Back a Remote File и Server Profiles and Jump Host) есть по 3 бесплатные попытки. После этого нужен Zovo Pro, он стоит 19 USD один раз и действует для всех расширений Zovo.

Хранится ли пароль в sftp.json?

Нет. Введённый пароль или парольная фраза хранится в защищённом хранилище редактора. Не указывайте password в sftp.json, и пароль будет запрошен один раз.

Выгрузит ли расширение мой файл .env?

Нет. .vscode, .git, файлы .env, приватные ключи и .npmrc входят в список исключений по умолчанию и никогда не выгружаются.

Может ли VS Code выгружать файлы по SFTP без расширения?

Нет. В VS Code нет выгрузки по SFTP или FTP. Remote SSH редактирует файлы прямо на сервере, а чтобы выгрузить локальный проект, нужно расширение или scp и rsync в терминале.
