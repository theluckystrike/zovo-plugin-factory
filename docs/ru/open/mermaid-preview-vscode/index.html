Предпросмотр диаграмм Mermaid в VS Code

В VS Code нет своего предпросмотра Mermaid. Установите бесплатное расширение Mermaid Viewer, откройте файл .mmd или .mermaid и нажмите значок предпросмотра справа вверху редактора. Диаграмма меняется по мере набора, а для Markdown-файла предпросмотр показывает все блоки mermaid. Mermaid 12.3.0 входит в расширение, поэтому предпросмотр и экспорт в PNG или SVG бесплатны и работают офлайн, без входа в аккаунт. Zovo Pro (19 USD один раз) добавляет экспорт в PDF, экспорт всех диаграмм в рабочей папке и экспорт при сохранении, у каждого инструмента 3 бесплатных запуска.

Как это сделать в VS Code

  1. Установите Mermaid Viewer из Marketplace или нажмите Ctrl+P (Cmd+P на macOS) и выполните ext install zovo.mermaid-viewer.
  2. Откройте файл .mmd или .mermaid и нажмите значок предпросмотра в заголовке редактора или Ctrl+K V (Cmd+K V на macOS). Можно также выполнить "Mermaid Viewer: Open Diagram Editor (Text + Live Preview)" из Command Palette.
  3. Для Markdown-файла с блоками ```mermaid нажмите тот же значок предпросмотра. Предпросмотр показывает все диаграммы, у каждой своя строка ошибки и свои кнопки экспорта.
  4. Нажмите "Edit diagram" над блоком в Markdown-файле, чтобы править его рядом с живым предпросмотром. После сохранения текст возвращается в свой блок.
  5. Прокрутка колёсиком масштабирует под указателем, перетаскивание сдвигает диаграмму. Fit и 100% есть на панели инструментов.
  6. Нажмите Export и выберите Save PNG (1x, 2x или 4x либо точная ширина или высота), Save SVG, Copy PNG или Copy SVG code.

Как запустить Export All Diagrams in Workspace (Zovo Pro)

  1. Откройте папку в VS Code. Выполните "Mermaid Viewer: Export All Diagrams in Workspace (SVG/PNG) (Pro)" из Command Palette или нажмите "Export All Diagrams in Workspace" в строке "Pro tools" под панелью предпросмотра.
  2. Выберите SVG, PNG или SVG и PNG.
  3. Оставьте папку по умолчанию mermaid-export (настройка mermaidViewer.exportFolder) или выберите "Choose a folder…". Запуск засчитывается, только когда файлы записаны. Если нажать Escape, запуск не тратится.

Как установить в Cursor, Windsurf или VSCodium

  1. Откройте панель Extensions сочетанием Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Найдите zovo.mermaid-viewer и нажмите Install. Cursor, Windsurf и VSCodium ставят расширения из Open VSX, где это расширение опубликовано как zovo/mermaid-viewer.
  3. Если в вашем редакторе нет каталога расширений, скачайте файл .vsix со страницы на Open VSX и выполните "Extensions: Install from VSIX...".
  4. Дальше всё работает так же, как в VS Code.

Что умеет Mermaid Viewer

  • Flowchart, sequence, class, state, ER, Gantt, pie, gitGraph, mindmap, timeline, sankey, XY chart, block, C4, architecture и другие типы, которые знает Mermaid 12.3.0.
  • Ошибки подчёркиваются на своей строке и попадают в панель Problems. Последняя удачная диаграмма остаётся на экране, а один сломанный блок в Markdown-файле не скрывает остальные.
  • Масштаб от 1 % до 3 200 % под указателем, сдвиг и щипок на тачпаде.
  • Экспорт SVG с простыми текстовыми подписями для вики Azure DevOps и GitHub.
  • Фон в цвет редактора, белый, прозрачный или свой цвет, он же используется при экспорте.

Чего расширение не делает

  • Расширение не добавляет диаграммы во встроенный предпросмотр Markdown в VS Code. Оно открывает свою панель предпросмотра.
  • Формулы в подписях ($$...$$) могут выглядеть неправильно, потому что шрифты KaTeX не входят в расширение.
  • Наборы иконок, которые Mermaid загружает из интернета, не загружаются. Встроенные иконки работают.
  • Диаграммы больше 500 000 символов или 2 000 связей не рисуются, пока вы не поднимете лимит (настройки mermaidViewer.maxTextSize и mermaidViewer.maxEdges).
  • Отрисовка, которая идёт больше 10 секунд, останавливается (настройка mermaidViewer.renderTimeoutSeconds).

Частые вопросы

Это бесплатно?

Предпросмотр, редактор, правка блоков в Markdown и экспорт в PNG и SVG бесплатны. У Pro-инструментов (экспорт в PDF, Export All Diagrams in Workspace и Export on Save) по 3 бесплатных запуска. После этого нужен Zovo Pro, 19 USD один раз для всех расширений Zovo.

Почему VS Code не показывает мой блок mermaid в предпросмотре Markdown?

Встроенный предпросмотр Markdown в VS Code не рисует Mermaid. Mermaid Viewer открывает для Markdown-файла свою панель предпросмотра, с масштабом и экспортом для каждой диаграммы.

Нужен ли аккаунт или интернет?

Нет. Mermaid 12.3.0 входит в расширение, нет ни входа, ни AI, а предпросмотр блокирует все сетевые запросы.

Работает ли это в Cursor?

Да. Расширение есть на Open VSX как zovo/mermaid-viewer, поэтому его можно установить в Cursor, Windsurf и VSCodium.
