Сравнение двух файлов Excel или CSV в VS Code

Установите бесплатное расширение Excel Compare & XLSX Diff и выберите две книги или два CSV-файла. Изменённые ячейки выделяются жёлтым, а старое значение зачёркнуто, добавленные строки показаны зелёным, удалённые красным. Строки выравниваются, а столбцы сопоставляются по заголовку, поэтому одна вставленная строка или один столбец видны как одно изменение. Перед коммитом книгу можно сравнить с её версией в Git HEAD. Всё это бесплатно и без сетевых запросов. Zovo Pro (19 USD один раз) добавляет три инструмента: Export a diff report, Match rows by key columns и Compare two folders of workbooks. У каждого есть 3 бесплатные попытки.

Как это сделать в VS Code

  1. Установите Excel Compare & XLSX Diff из Marketplace или нажмите Ctrl+P (Cmd+P на macOS) и выполните ext install zovo.zovo-excel-compare.
  2. Выделите два файла в Explorer, щёлкните правой кнопкой и выберите Compare Selected Excel Files. Или щёлкните правой кнопкой один файл, выберите Compare with... и укажите второй. Из Command Palette можно выполнить «Excel Compare: Compare Two Excel or CSV Files...».
  3. Подходит любое сочетание .xlsx, .xlsm, .xls, .ods, .csv и .tsv, так что можно сравнить .xlsx с .csv.
  4. Прочитайте строку сводки, затем вкладки листов с числом отличий на каждой. Щёлкните ячейку, чтобы увидеть полное старое и новое значение и скопировать их.
  5. Нажимайте N и P (или Next и Previous), чтобы переходить по всем изменениям на всех листах. Переключайтесь между Values и Formulas, чтобы сравнивать то, что показывают ячейки, или сами формулы.
  6. Чтобы увидеть свои изменения до коммита, щёлкните правой кнопкой книгу в Git-репозитории и выберите Compare with Git HEAD.

Что бесплатно и что добавляет Zovo Pro

Сравнение любых двух файлов, сетка, Values и Formulas, переход к следующему и предыдущему изменению, сравнение CSV с определением кодировки и разделителя и Compare with Git HEAD бесплатны. Входить в учётную запись не нужно, сетевых запросов и телеметрии нет.

Когда изменения нужно показать другому человеку, Export a diff report создаёт книгу XLSX, где изменённые, добавленные и удалённые ячейки залиты цветом, с листом Summary и списком Changes со всеми старыми и новыми значениями. Также можно получить одну HTML-страницу или CSV-список изменений. Вы отправляете один файл вместо скриншотов.

Как запустить Export a diff report (Zovo Pro)

  1. Сравните два файла, как описано выше, затем нажмите Export report на панели сравнения или выполните «Excel Compare: Export a diff report (XLSX, HTML or CSV) (Pro)» из Command Palette.
  2. Выберите XLSX, HTML или CSV.
  3. Укажите, куда сохранить отчёт. Попытка расходуется, только если отчёт записан.

Как установить в Cursor, Windsurf или VSCodium

  1. Откройте панель Extensions сочетанием Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Найдите zovo.zovo-excel-compare и нажмите Install. Cursor, Windsurf и VSCodium ставят расширения из Open VSX, где это расширение опубликовано как zovo/zovo-excel-compare.
  3. Если в вашем редакторе нет каталога расширений, скачайте файл .vsix со страницы на Open VSX и выполните "Extensions: Install from VSIX...".
  4. Дальше всё работает так же, как в VS Code.

Что умеет Excel Compare & XLSX Diff

  • Листы сопоставляются по имени, затем по позиции. Листы, которые есть только в одном файле, отмечаются как добавленные или удалённые.
  • CSV и TSV с автоматическим определением кодировки (UTF-8 с BOM и без, UTF-16, кодовые страницы Windows) и разделителя (запятая, точка с запятой, табуляция или вертикальная черта), включая поля в кавычках с переносами строк.
  • Большие листы. Сетка отрисовывает только видимые строки, поэтому лист на 300 000 строк прокручивается так же, как короткий.
  • Примечания, если объединённые ячейки различаются или лист обрезан из-за лимита.
  • Два других инструмента Pro. Match rows by key columns сопоставляет строки по столбцу ID, поэтому отсортированные или переставленные листы сравниваются чисто, а перемещённые строки помечаются. Compare two folders of workbooks составляет пары файлов по имени и показывает, какие одинаковы, какие различаются и какие есть только в одной папке.

Чего расширение не делает

  • Файлы до 200 МБ (настройка excelCompare.maxFileSizeMB), 300 000 строк на лист (excelCompare.maxRows), 1000 столбцов и 200 листов. Если сработал лимит, в окне сравнения появляется примечание.
  • Книга, которая после распаковки заняла бы больше 600 МБ или сжата как zip-бомба, отклоняется до распаковки.
  • Без инструмента Pro Match rows by key columns строки выравниваются по содержимому и позиции, а не по столбцу ID.
  • Расширение только сравнивает файлы, оно не редактирует и не объединяет их.

Частые вопросы

Это бесплатно?

Сравнение двух книг или CSV-файлов, Values и Formulas, переход к следующему и предыдущему изменению и Compare with Git HEAD бесплатны. У трёх инструментов Pro, Export a diff report, Match rows by key columns и Compare two folders of workbooks, есть по 3 бесплатные попытки. Дальше нужен Zovo Pro за 19 USD один раз, он открывает все расширения Zovo.

Может ли VS Code сравнить два файла Excel без расширения?

Нет. Файл .xlsx представляет собой zip-архив с XML-частями, поэтому встроенный diff показывает его как двоичный. Нужно расширение, которое читает книгу.

Если вставить строку в начало, все строки ниже будут отмечены как изменённые?

Нет. Строки выравниваются перед сравнением, поэтому вставленная строка видна как одна добавленная строка.

Можно ли увидеть, что изменилось в книге после последнего коммита?

Да. Щёлкните файл правой кнопкой в Git-репозитории и выберите Compare with Git HEAD. Используется ваш локальный git.
