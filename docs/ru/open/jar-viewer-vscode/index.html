Как открыть JAR и прочитать декомпилированный исходник Java в VS Code

Установите бесплатное расширение JAR Viewer & Java Decompiler и кликните по файлу .jar, .war, .ear, .aar или .class. Вы увидите пакеты, ресурсы, MANIFEST.MF и версию Java каждого класса, листинг байткода в стиле javap -c -p, которому не нужна Java, и исходник Java, декомпилированный встроенным CFR 0.152 с помощью Java 8 или новее на вашем компьютере. Все виды и декомпиляция классов по одному бесплатны. Zovo Pro (19 USD один раз) добавляет три инструмента: Export decompiled sources of a JAR, Compare two JARs и Find in every JAR of a folder, у каждого 3 бесплатных запуска.

Как это сделать в VS Code

  1. Установите JAR Viewer из Marketplace или нажмите Ctrl+P (Cmd+P на macOS) и выполните ext install zovo.zovo-jar-viewer.
  2. Кликните по файлу .jar, .war, .ear, .aar или .class в Explorer. Он откроется в JAR Viewer. Overview показывает формат, число записей, классов и пакетов, Main-Class, Created by, MANIFEST.MF и диаграмму версий Java, под которые скомпилированы классы.
  3. Введите часть имени в поле фильтра над деревом пакетов. Классы и файлы находятся по мере набора. Внутренние классы показаны приглушённо под своим внешним классом.
  4. Кликните по классу. Вкладка Java source показывает его код, декомпилированный CFR 0.152, вместе с внутренними классами. Copy кладёт исходник в буфер обмена, а Open in editor открывает его в обычной вкладке редактора.
  5. Если вкладка Java source сообщает, что для декомпилированного исходника нужна среда Java, укажите в jarViewer.javaPath путь к файлу java или к папке JDK либо задайте JAVA_HOME. Команда "JAR Viewer: Check the Java runtime used for decompiling" показывает, какая Java используется.
  6. Откройте вкладку Bytecode, чтобы увидеть листинг в стиле javap -c -p со всеми опкодами, таблицами исключений и номерами строк. Вкладки Members, Constant pool и Class info показывают объявления, записи пула констант и атрибуты класса.
  7. В JAR Spring Boot, WAR или AAR кликните по JAR внутри BOOT-INF/lib или WEB-INF/lib либо по classes.jar внутри AAR, затем нажмите "Open nested archive". Архив откроется на один уровень вглубь, а кнопка с именем внешнего файла вверху вернёт вас назад.

Что бесплатно и что добавляет Zovo Pro

Дерево пакетов, Overview, манифест, ресурсы, декомпилированный исходник Java, байткод, члены класса, пул констант, сведения о классе и вложенные JAR бесплатны и без входа в аккаунт. CFR поставляется с расширением и работает на Java, которая уже есть на вашем компьютере. Расширение никогда не изменяет архив и не обращается к сети.

Export decompiled sources of a JAR декомпилирует с помощью CFR каждый класс JAR, WAR, EAR или AAR и записывает файлы .java в папку, показывая ход работы и кнопку Cancel. Без среды Java инструмент записывает вместо них листинги байткода. Вы получаете всю библиотеку в виде исходных файлов, по которым можно искать и которые можно читать в редакторе, и не открываете классы по одному.

Как установить в Cursor, Windsurf или VSCodium

  1. Откройте панель Extensions сочетанием Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Найдите zovo.zovo-jar-viewer и нажмите Install. Cursor, Windsurf и VSCodium ставят расширения из Open VSX, где это расширение опубликовано как zovo/zovo-jar-viewer.
  3. Если в вашем редакторе нет каталога расширений, скачайте файл .vsix со страницы на Open VSX и выполните "Extensions: Install from VSIX...".
  4. Дальше всё работает так же, как в VS Code.

Что умеет JAR Viewer

  • Архивы JAR, WAR, EAR и AAR, а также отдельные файлы .class с их внутренними классами из той же папки.
  • Архивы до 200 000 записей и фильтр, который находит класс или файл среди 50 000 записей по мере набора.
  • Generic-сигнатуры, records, permitted subclasses, nest hosts и аннотации в данных класса.
  • Текстовые ресурсы, например properties, XML, JSON, SQL и файлы services, показываются как текст, бинарные файлы в виде hex.
  • Архивы Spring Boot BOOT-INF/lib, WAR WEB-INF/lib и AAR classes.jar, на один уровень вглубь.

Чего расширение не делает

  • Для декомпилированного исходника нужна Java 8 или новее на компьютере. Без неё байткод и все остальные виды продолжают работать.
  • Вывод CFR может отличаться от исходного кода, например в именах локальных переменных, некоторых дженериках и лямбдах.
  • Записи распаковываются до 64 МБ каждая, файлы классов до 16 МБ, вложенные архивы до 128 МБ. Файлы на удалённых или виртуальных файловых системах читаются до 256 МБ.
  • Расширение только читает файлы, поэтому класс нельзя изменить или перекомпилировать. Вложенные архивы открываются только на один уровень вглубь.
  • Файлы APK и DEX не читаются.

Частые вопросы

Это бесплатно?

Да. Все виды и декомпиляция классов по одному бесплатны. У трёх Pro-инструментов, Export decompiled sources of a JAR, Compare two JARs и Find in every JAR of a folder, по 3 бесплатных запуска, и запуск засчитывается, только если инструмент дал результат. После этого нужен Zovo Pro, 19 USD один раз для всех расширений Zovo.

Почему вкладка Java source просит Java?

CFR написан на Java. Просмотрщик ищет Java в jarViewer.javaPath, затем в JAVA_HOME, затем java в вашем PATH. Подойдёт любая среда Java 8 или новее.

Можно ли читать байткод без Java?

Да. Вкладки Bytecode, Members, Constant pool и Class info разбираются на JavaScript, и Java им не нужна.

Работает ли это в Cursor?

Да. Расширение есть на Open VSX как zovo/zovo-jar-viewer, поэтому Cursor, Windsurf и VSCodium могут его установить.
