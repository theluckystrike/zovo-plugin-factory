Воспроизведение аудиофайлов в VS Code

Установите бесплатное расширение Audio Player & WAV Player и кликните по файлу .wav, .mp3, .flac, .ogg или .opus. Файл играет с волновой формой для каждого канала, спектрограммой, A-B петлёй, скоростью от 0.25x до 2x без изменения высоты тона и значениями громкости в LUFS. Opus воспроизводится встроенным декодером, а M4A и AAC играют после одного клика, если у вас установлен ffmpeg. Прослушивание и проверка файлов бесплатны, а Zovo Pro (19 USD один раз) добавляет два инструмента, Folder Loudness Report и Normalize Loudness, у каждого 3 бесплатных запуска.

Как это сделать в VS Code

  1. Установите Audio Player & WAV Player из Marketplace или нажмите Ctrl+P (Cmd+P на macOS) и выполните ext install zovo.audio-preview-vscode.
  2. Кликните по файлу .wav, .mp3, .flac, .ogg, .opus или .m4a в Explorer. Если открывается другой плеер, кликните по файлу правой кнопкой и выберите "Open in Audio Preview".
  3. Пробел запускает и ставит на паузу. Стрелки влево и вправо перематывают на 5 секунд (на 1 секунду с Shift). Клик по волновой форме переходит к этому месту.
  4. Протяните мышью по волновой форме, чтобы зациклить этот участок, или нажмите [ и ], чтобы поставить начало и конец петли в текущей позиции. L включает и выключает петлю.
  5. Выберите скорость от 0.25x до 2x. Высота тона не меняется.
  6. В заголовке видны кодек, частота дискретизации, каналы, разрядность, длительность и битрейт, на панели Loudness значения LUFS, пик и RMS, на панели Tags название, исполнитель, альбом и другие теги.

Что бесплатно и что добавляет Zovo Pro

Воспроизведение всех поддерживаемых форматов, волновая форма, спектрограмма, A-B петля, скорость, панели Loudness, File и Tags и Copy stats бесплатны. В аудиофайл ничего не записывается, и расширение не обращается к сети.

Folder Loudness Report записывает в CSV по строке на каждый аудиофайл в папке: формат, длительность, частота дискретизации, разрядность, название и исполнитель, интегральная громкость в LUFS, максимумы short-term и momentary, пиковое значение отсчёта, RMS, число клиппированных отсчётов и усиление, которое нужно файлу, чтобы выйти на -14, -16 и -23 LUFS. Вы сортируете и проверяете папку записей в таблице, а не открываете каждый файл. WAV расширение читает само, а для строк MP3, FLAC, Ogg, Opus и M4A нужен ваш ffmpeg.

Как запустить Folder Loudness Report (Zovo Pro)

  1. Кликните правой кнопкой по папке в Explorer и выберите "Folder Loudness Report (CSV, Pro)" или выполните "Audio Preview: Folder Loudness Report (CSV, Pro)" из Command Palette и выберите папку. В плеере команда есть и в меню "..." заголовка редактора.
  2. Выберите "This folder and its subfolders" или "This folder only", затем место для loudness-report.csv.
  3. Ход работы виден в уведомлении, его можно отменить. Откройте CSV в табличном редакторе. Запуск засчитывается, только когда файл записан.

Folder Loudness Report можно запустить на вашем компьютере 3 раза бесплатно, потом расширение попросит лицензию. Никаких всплывающих окон и никакого обратного отсчёта.

Как установить в Cursor, Windsurf или VSCodium

  1. Откройте панель Extensions сочетанием Ctrl+Shift+X (Cmd+Shift+X на macOS).
  2. Найдите zovo.audio-preview-vscode и нажмите Install. Cursor, Windsurf и VSCodium ставят расширения из Open VSX, где это расширение опубликовано как zovo/audio-preview-vscode.
  3. Если в вашем редакторе нет каталога расширений, скачайте файл .vsix со страницы на Open VSX и выполните "Extensions: Install from VSIX...".
  4. Дальше всё работает так же, как в VS Code.

Что умеет Audio Player & WAV Player

  • WAV (PCM от 8 до 32 бит, float, A-law, mu-law, RF64), читается блоками по 2 МБ, поэтому большой файл не подвешивает редактор.
  • MP3, FLAC и Ogg Vorbis через декодер, который уже есть в VS Code.
  • Opus в .opus или .ogg через встроенный декодер libopus (WebAssembly).
  • До 8 каналов, у каждого своя дорожка волновой формы.
  • Теги ID3v1, ID3v2.2–2.4, RIFF INFO, комментарии Vorbis и атомы iTunes.

Чего расширение не делает

  • Для M4A и AAC нужен ваш собственный ffmpeg. Без него вы видите кодек, длительность, битрейт, теги и сообщение.
  • ALAC, AC-3 и другие кодеки, которые VS Code не декодирует, тоже требуют кнопки ffmpeg.
  • Сжатые файлы декодируются целиком. Если декодированные отсчёты больше 600 МБ (примерно 28 минут стерео 44.1 кГц), файл только воспроизводится (настройка audioPreview.maxDecodedMB).
  • Пик считается по отсчётам, это не true peak с передискретизацией, и диапазона громкости (LRA) нет.
  • Расширение воспроизводит и проверяет файлы. Оно не режет и не редактирует их.

Частые вопросы

Это бесплатно?

Воспроизведение, волновая форма, спектрограмма, петля и значения громкости бесплатны. У двух Pro-инструментов, Folder Loudness Report и Normalize Loudness, по 3 бесплатных запуска. После этого нужен Zovo Pro, 19 USD один раз для всех расширений Zovo.

Почему мой файл .opus не играет в VS Code?

VS Code поставляется с Chromium без декодера Opus. Это расширение содержит libopus, скомпилированный в WebAssembly, поэтому Opus играет без установки чего-либо ещё.

Почему для M4A показывается сообщение вместо воспроизведения?

Декодера AAC в VS Code тоже нет. Если ffmpeg установлен, кнопка Decode with ffmpeg делает копию в WAV в папке хранения расширения, и файл играет. Ничего не входит в расширение и не скачивается.

Работает ли это в Cursor?

Да. Расширение есть на Open VSX как zovo/audio-preview-vscode, поэтому его можно установить в Cursor, Windsurf и VSCodium.
