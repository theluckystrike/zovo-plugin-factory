Look inside a .vsix extension file without installing it

A .vsix file is a ZIP archive, with the extension in an extension/ folder next to extension.vsixmanifest. ZIP Viewer & Archive Explorer opens it in VS Code as a list of folders and files with sizes, and opens any file, such as extension/package.json or the bundled JavaScript, in a read-only tab. Nothing is unpacked and nothing is installed. Browsing and extraction are free. Zovo Pro (USD 19 once) adds a compare of two archives, so you see what changed between two versions, with 3 free tries.

Steps in VS Code

  1. Install ZIP Viewer & Archive Explorer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zip-archive-explorer.
  2. Click the .vsix file in the Explorer. It opens as a list with size, packed size, ratio and date for each entry.
  3. Double-click the extension folder, then package.json. It opens read-only with JSON colours. Look at main, activationEvents, contributes and extensionDependencies.
  4. Open extension.vsixmanifest at the top level for the publisher and version, and the target platform of a platform-specific build.
  5. Type *.node or *.js in the search box to list the code files. A .node file is a native binary.
  6. To keep a file, select it and use Extract... to save a copy. The .vsix itself is never changed.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zip-archive-explorer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zip-archive-explorer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What ZIP Viewer & Archive Explorer handles

  • .vsix, .zip and .jar files open with a click. .whl, .nupkg, .xpi and .apk open with Open in Archive Explorer.
  • ZIP64 and archives with up to 200,000 entries.
  • A ZIP inside the archive, which opens as another archive.
  • TAR, TAR.GZ and GZ files.

What it does not do

  • Entries are read-only. Extract a file to change it.
  • Entries over 512 MB do not open in a tab (setting archiveExplorer.maxEntryMB), but can be extracted.
  • Encrypted entries and methods other than Stored and Deflate are listed but not opened.
  • The viewer shows the files. It does not scan the code for malware or check a signature.

Other options

  • unzip. unzip -l extension.vsix lists the files, and unzip -p extension.vsix extension/package.json prints the manifest.
  • vsce. vsce ls lists the files that would go into a .vsix, run from the source folder of an extension. It does not read a built .vsix.

Questions

Does opening the .vsix run any of its code?

No. The archive is read as data. Nothing is installed, unpacked or run.

How do I install it after I checked it?

Run "Extensions: Install from VSIX..." from the Command Palette and pick the file.

Can I compare two versions of an extension?

Yes, with the Compare two archives Pro tool. It lists the files added, removed or changed.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
