Normalize audio loudness to a LUFS target

Audacity's Loudness Normalization and ffmpeg's loudnorm filter are free and do this well. If you work in VS Code, Audio Player shows integrated, short-term and momentary loudness for free (ITU-R BS.1770-4, within 0.1 LU of ffmpeg's ebur128 on its test files). Its Pro tool Normalize Loudness writes a new WAV at -14, -16, -23 LUFS or your own target, and Folder Loudness Report gives one CSV row per file. Each has 3 free tries, then Zovo Pro is USD 19 once.

Install in VS CodeMarketplace pageOpen VSX (Cursor, Windsurf, VSCodium)

Free, MIT license. Extension ID zovo.audio-preview-vscode, version 0.2.1. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install Audio Player & WAV Player from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.audio-preview-vscode.
  2. Click a WAV, MP3, FLAC, Ogg or Opus file in the Explorer. It plays with a waveform and a spectrogram.
  3. Read the loudness panel: integrated, short-term and momentary LUFS, sample peak and clipped samples. That is free.

Where Zovo Pro saves time

Playing, the waveform, the spectrogram and the loudness meter are free.

Pick -14 LUFS (Spotify, YouTube), -16 (Apple Music, podcasts), -23 (EBU R128) or your own target. If the gain would push the sample peak over -1 dBFS, the gain is lowered and the message says so. Folder Loudness Report lists every file with its LUFS, peak, RMS and the gain it needs to reach -14, -16 and -23 LUFS.

With Normalize Loudness (Zovo Pro)

  1. Run Normalize Loudness on the open file and pick a target.
  2. A new WAV such as mix-14LUFS.wav is written next to the original, which is never changed.
  3. For a folder, right-click it and run "Audio Preview: Folder Loudness Report" to get a CSV.

Normalize Loudness works 3 times on your computer before it asks for a license, and a try counts only when you get a result. Nothing about Pro shows when you open a file.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.audio-preview-vscode and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/audio-preview-vscode.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Audio Player & WAV Player handles

  • -14, -16, -23 LUFS or your own target.
  • Peak guard at -1 dBFS.
  • Same bit depth (8-bit and A-law or mu-law become 16-bit).
  • A CSV for a whole folder.

What it does not do

  • The output is WAV.
  • MP3, FLAC, Ogg, Opus and M4A are measured in the folder report only with your own ffmpeg; WAV is read by the extension.

Other options

  • Audacity. Effect, Loudness Normalization, with a LUFS target. Free.
  • ffmpeg loudnorm. ffmpeg -i in.wav -af loudnorm=I=-16:TP=-1.5 out.wav. Free and scriptable.

Questions

Which LUFS target should I use?

About -14 LUFS for Spotify and YouTube, -16 for Apple Music and podcasts, -23 for EBU R128 broadcast.

Is the original file changed?

No. A new WAV is written next to it.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
