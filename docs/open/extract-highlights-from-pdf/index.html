Extract highlights from a PDF

In PDF Viewer for VS Code, select text and press H (or pick one of 4 colors). The Highlights tab lists every highlight with its page, and "Copy as Markdown" gives you a list with a link to each page. That part is free and the PDF file is not changed. If you read many PDFs, the Pro tool Export highlights of all PDFs writes one Markdown file grouped by file. It has 3 free tries, then Zovo Pro is USD 19 once.

Install in VS CodeMarketplace pageOpen VSX (Cursor, Windsurf, VSCodium)

Free, MIT license. Extension ID zovo.pdf-viewer-dark, version 0.3.7. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install PDF Reader from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.pdf-viewer-dark.
  2. Click the .pdf in the Explorer to open it in PDF Viewer.
  3. Select text and pick one of 4 colors, or press H.
  4. Open the Highlights tab. It lists every highlight with its page; a click jumps back to it.
  5. Click "Copy as Markdown" and paste the list into your notes. Each item links to its page.

Where Zovo Pro saves time

Highlighting, the Highlights tab and Copy as Markdown for one PDF are free, with no limit. Highlights are saved in VS Code for each file and are not written into the PDF.

For a literature review or a reading list, Export highlights of all PDFs saves one Markdown file with the highlights of every PDF you highlighted (or only those in this workspace), grouped by file, with the color and a link to each page.

With Export highlights of all PDFs (Zovo Pro)

  1. Click the page tools button in the toolbar, or run "PDF: Page Tools (Pro)...".
  2. Pick "Export highlights of all PDFs". The "All PDFs" link in the Highlights tab does the same.
  3. Choose all PDFs or only those in this workspace, and save the Markdown file.

Export highlights of all PDFs works 3 times on your computer before it asks for a license, and a try counts only when you get a result. Opening a file shows no popup and no countdown.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.pdf-viewer-dark and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/pdf-viewer-dark.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What PDF Reader handles

  • 4 highlight colors, saved per file.
  • Markdown with a link to each page.
  • All PDFs in one file (Pro).

What it does not do

  • It exports highlights made in PDF Viewer. Highlights stored inside the PDF by another app are not read.
  • A scanned page needs a text layer before you can select and highlight text.

Other options

  • PyMuPDF. A few lines of Python read highlight annotations stored in a PDF. Good for highlights made in Acrobat or Preview.
  • Zotero. Free reference manager that turns PDF annotations into notes.
  • Desktop PDF editors. UPDF, PDFgear and Acrobat export comments and highlights from their comment list.

Questions

Is my PDF changed?

No. Highlights are saved in VS Code on this computer, for each file, and come back when you open the PDF again.

Is exporting highlights free?

For one PDF, yes: Copy as Markdown in the Highlights tab. One file for all PDFs is the Pro tool, with 3 free tries.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
