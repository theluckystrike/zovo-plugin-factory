Preview a PlantUML diagram in VS Code as you type

PlantUML Viewer & Preview draws PlantUML diagrams beside your code in VS Code as you type, for .puml, .plantuml, .iuml, .pu and .wsd files and plantuml blocks in Markdown. It runs the bundled PlantUML jar with your Java, so nothing is sent to a server and no Graphviz is needed. You need Java 11 or newer. The preview and single-diagram saves as SVG or PNG are free. Steps in VS Code

  1. Install PlantUML Viewer & Preview from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-plantuml-viewer.
  2. Make sure Java 11 or newer is installed. The extension finds it through plantumlViewer.javaPath, JAVA_HOME, PATH or the usual JDK folders, and the preview says so when it is missing.
  3. Open a .puml file, or a Markdown file with a plantuml block, and click the preview button in the editor title (or run "PlantUML: Open Preview to the Side").
  4. Type. The diagram redraws a moment after you stop. Every diagram of the file shows in one preview, and the one under the cursor is outlined.
  5. Zoom with the buttons, Ctrl or Cmd + wheel, or the + and - keys, fit to width, and drag to pan. An error shows the PlantUML message with a link to the line.
  6. Click SVG or PNG above a diagram to save it, or Copy SVG.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-plantuml-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-plantuml-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What PlantUML Viewer & Preview handles

  • !include of files from the diagram's folder, your workspace folders and plantumlViewer.includePaths, and the standard library such as !include <C4/C4_Container>, offline.
  • Sequence diagrams, mind maps and Gantt charts need no layout engine. Class, component, state and use case diagrams use Graphviz when dot is installed, and the Smetana engine built into PlantUML when it is not.
  • One PlantUML process per folder stays running while a preview is open, so a small diagram redraws in a few milliseconds.
  • Diagrams are shown as images, so links or text inside a diagram cannot run code in the editor.

What it does not do

  • Java 11 or newer must be installed. The extension does not download Java.
  • Includes from web addresses are refused, except C4, AWS icon and icon-font addresses that the jar has its own copy of.
  • The MIT build of PlantUML has no Ditaa and no LaTeX renderer for @startmath.
  • Without Graphviz, Smetana lays out class and component diagrams a little differently, and very large class diagrams can look tighter.

Other options

Questions

Can VS Code preview PlantUML without an extension?

No. VS Code shows a .puml file as plain text. You need an extension that runs PlantUML.

Do I need Graphviz?

No. Without Graphviz, class and component diagrams use the Smetana layout engine built into PlantUML. If dot is installed, it is used.

Is my diagram sent to a server?

No. The bundled PlantUML jar runs on your computer with its ALLOWLIST security profile, and includes from web addresses are refused.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
