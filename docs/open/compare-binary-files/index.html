Compare binary files in VS Code

VS Code's own diff only compares text. To compare two binary files, install the free Hex Viewer by Zovo, select both files in the Explorer, right-click and pick "Compare in Hex Viewer". The files show side by side in hex with one offset column, differing bytes are colored, and F7 jumps to the next difference. Two 4 GB files were compared in 2.1 s. Writing the list of differences to a CSV or JSON file is Zovo Pro.

Install in VS CodeMarketplace pageOpen VSX (Cursor, Windsurf, VSCodium)JetBrains IDEs

Free, MIT license. Extension ID zovo.zovo-hex-viewer, version 0.3.7. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install Hex Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-hex-viewer.
  2. Select the two files in the Explorer (Ctrl+click or Cmd+click), right-click and pick "Compare in Hex Viewer".
  3. Or open one file in Hex Viewer and click "Compare..." in the toolbar to pick the other one.
  4. Press F7 for the next difference and Shift+F7 for the previous one. A run of differing bytes counts as one area.
  5. Read the counts in the toolbar: every differing byte and every area. The scroll bar marks where they are.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-hex-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-hex-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Hex Viewer handles

  • Files of any size. The compare reads both files from disk, 1 MB at a time.
  • Files of different length: bytes past the end of the shorter file count as different.
  • The data inspector and Copy as work in the compare view, so you can read a changed value directly.
  • Measured: two 4 GB files with one differing byte 64 bytes from the end were counted in 2.1 s on an Apple silicon Mac, with the extension host at 96 MB.

What it does not do

  • It compares byte by byte at the same offsets. It does not align inserted or removed blocks the way a text diff does, so one inserted byte makes the rest of the file differ.
  • It compares the files as saved on disk, not unsaved edits.
  • The compare report (every differing range with offset, length and the first 16 bytes of both files, as text, CSV or JSON) is part of Zovo Pro, with 3 free tries.

In JetBrains IDEs (IntelliJ IDEA, PyCharm, WebStorm, CLion and others)

  • Built in: Compare Files. JetBrains IDEs compare two selected files with Ctrl+D (Cmd+D on macOS). For binary files they show only whether the files are equal.
  • BinEd - Binary/Hex Editor. A binary and hex editor plugin with 500,280 downloads. Use "Open In / Binary Editor" in the project files menu.

Other options

  • HexDiff (sj0000e.hexdiff, 21,918 installs, not on Open VSX). Its own description: "Compare two binary files in hexadecimal mode". Not on Open VSX.
  • Hex Editor (Microsoft) (ms-vscode.hexeditor, 7.5 million installs, on Open VSX). Views and edits bytes. Its description does not list a two-file compare.
  • cmp, fc /b or vbindiff. cmp -l a.bin b.bin on macOS and Linux lists every differing byte with its offset. On Windows, fc /b a.bin b.bin does the same. vbindiff shows two files side by side in a terminal.

Questions

Can VS Code compare binary files without an extension?

No. The built-in diff opens text. For a binary file it says the file is binary and shows no differences.

How do I get a list of every difference?

In the free version, the toolbar counts them and F7 walks through them. The compare report that writes them all to a text, CSV or JSON file is part of Zovo Pro, USD 19 once, with 3 free tries.

Does it work in Cursor?

Yes. Cursor, Windsurf and VSCodium install it from Open VSX as zovo/zovo-hex-viewer.
