Compare two folders of Excel and CSV files, workbook by workbook

VS Code compares two files, not two folders, and a plain folder diff only tells you that a workbook changed, not which cells. Excel Compare & XLSX Diff has a tool that pairs the .xlsx, .xlsm, .xls, .ods, .csv and .tsv files of two folders by name, compares every pair and shows a table of the files that are the same, the files that differ and the files that exist in only one folder. Any pair opens in the full cell by cell view. Compare two folders of workbooks is part of Zovo Pro (USD 19 once), with 3 free tries on your computer.

Steps in VS Code

  1. Install Excel Compare & XLSX Diff from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-excel-compare.
  2. Put the two versions in two folders, for example q3 and q4. Files are paired by their path inside the folder, then by the file name alone when that name occurs once on each side. Upper and lower case do not matter.
  3. Select both folders in the Explorer (Ctrl+click, or Cmd+click on macOS), right-click and pick "Zovo Pro: Compare Two Folders of Workbooks". The folder you selected first is the older side. With one folder selected, the same entry asks for the second folder.
  4. Watch the table fill. Each row is one file with its status (same, different, only in the first folder, only in the second folder or could not be compared) and the number of rows changed, added and removed and of cells changed. Cancel in the progress message stops the run.
  5. Click Open on a row to see that pair in the full comparison, with changed cells in yellow, added rows in green and removed rows in red. Press N and P to step through the changes.
  6. You can also start from an open comparison. Click Compare folders in its toolbar, or run "Excel Compare: Compare two folders of workbooks (Pro)" from the Command Palette, and pick the two folders.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-excel-compare and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-excel-compare.

What Excel Compare & XLSX Diff handles

  • .xlsx, .xlsm, .xls, .ods, .csv and .tsv files, in any mix.
  • Subfolders up to 8 levels deep, paired by their path inside each folder.
  • A file that moved to another subfolder, paired by its name when that name occurs once on each side.
  • A status per file with the rows changed, added and removed, the cells changed and the sheets added or removed.

What it does not do

  • Up to 2,000 workbook and CSV files per folder, and 20,000 folder entries looked at.
  • The folders node_modules, .git, .svn, .hg, __pycache__, .venv and .cache, and Excel lock files that start with ~$, are skipped.
  • The table compares values, with rows in their order. Formulas and Match rows by key columns apply after you open a pair.
  • The folder table has no export. Export a diff report saves one open pair.
  • A pair that makes no progress for 60 seconds is marked "could not be compared".

Other options

  • Folder Compare & Directory Diff. A free Zovo extension that compares two folders of any files. It shows Excel files as text side by side, not cell by cell.
  • Beyond Compare. A paid desktop app. Its folder compare lists the files that differ, and its table compare opens a pair of spreadsheets.
  • pandas. A Python script can loop over both folders, read each pair with pandas.read_excel and compare frames of the same shape with DataFrame.compare. Free, needs code.

Questions

Are the files paired by name or by content?

By name. First by the path inside the folder, then by the file name alone when it occurs once on each side. Upper and lower case do not matter. A renamed file shows as only in the first folder and only in the second folder.

Can I compare a folder of CSV exports with a folder of Excel files?

Only when the names match, extension included, so report.csv and report.xlsx are not paired. Select those two files and pick Compare Selected Excel Files to compare them.

Does a run use a try when nothing changed?

No. When every pair is the same and no file is on one side only, a message says so and no free try is used.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
