Find out why an OBJ model shows no textures

An OBJ file names its material file on an mtllib line, and the .mtl names the texture images. If a file is not where the path says, the model shows plain or dark faces. Open the .obj in 3D Model Viewer. The status line says "Materials from model.mtl." or that the material file was not found next to the model, and the panel counts materials and textures. These checks are free. Zovo Pro (USD 19 once) adds Turntable export, a GIF of the fixed model turning, with 3 free tries.

Steps in VS Code

  1. Install 3D Model Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.3d-model-viewer.
  2. Keep the .obj, its .mtl and the texture images in the model folder or a folder below it. Then click the .obj in the Explorer.
  3. Read the status line at the bottom. "Materials from model.mtl." means the MTL was read. "The material file model.mtl was not found next to the model, so a default material is used." means the name on the mtllib line does not match a file in that folder.
  4. Open the .obj as text and check the mtllib line. The viewer reads only the first one, and it skips paths that start with a drive or /, go up with .., or are URLs. A plain name such as mtllib model.mtl works.
  5. Open the .mtl and check the map_Kd lines. Texture paths are read from the model folder, so a path from another computer such as C:\Users\ana\wood.png does not load. Change it to wood.png or textures/wood.png.
  6. Check Materials and Textures in the side panel. Textures counts the maps the materials name, so 0 means no MTL was read or it names no image. Press W for wireframe to see the mesh without materials.
  7. For a split .gltf, a missing .bin stops with "A buffer or texture that this glTF file points to was not found next to it.", and a missing image adds "Could not load" and its name to the status line. The scene tree lists every node with its triangle count, so you can see which part is missing.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.3d-model-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/3d-model-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What 3D Model Viewer handles

  • OBJ with the .mtl named by mtllib, when it sits next to the model.
  • GLB with embedded textures, and glTF 2.0 with external .bin buffers and textures.
  • PBR materials, skins, morph targets and animations in glTF.
  • A scene tree of up to 3,000 nodes, each with a checkbox to hide it and its children.

What it does not do

  • Only the first mtllib line of an OBJ is read.
  • A texture that the MTL names but that is missing gets no message of its own. The faces show without it.
  • Sibling files load only from the model folder and the open workspace folders.
  • Draco or meshopt compressed glTF and KTX2 textures are not decoded yet. A message names the missing extension.
  • FBX, DAE, USD and glTF 1.0 files do not open.

Other options

  • Blender. Free 3D software. It imports OBJ with MTL, and File > External Data > Report Missing Files lists images it could not find.
  • A text editor. The .obj and .mtl are plain text, so you can read the mtllib and map_Kd paths in any editor. You do not see the result.

Questions

Why is my OBJ grey in the viewer?

The MTL file was not read, so a default material is used. The status line says so and names the file it looked for.

Why does the model show colours but no texture?

The MTL was read, but an image it names on a map_Kd line is not at that path relative to the model folder.

Does the viewer fix the paths for me?

No. It never writes the model, the MTL or the images. Fix the paths in a text editor and open the model again.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
