TTF to WOFF2 in VS Code

Open the font in Font Viewer and run Convert Font. It writes a WOFF2 (or WOFF) next to the TTF or OTF, offline, and it can also turn a WOFF2 back into an installable TTF/OTF. Viewing the font is free: type tester, glyphs, character map and the Info tab. Convert Font is a Zovo Pro tool with 3 free tries on your computer, then USD 19 once.

Steps in VS Code

  1. Install Font Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.font-viewer-vscode.
  2. Click the .ttf or .otf file in the Explorer. It opens in Font Viewer, which is read-only and never changes the font.
  3. Open the Info tab and check the license and embedding rights before you put the font on a website.
  4. Run Convert Font from the font tab's title bar, the Explorer right-click menu or the Command Palette (type Font Viewer).
  5. Choose WOFF2 as the output. The new .woff2 file goes next to the source, and a TTC gives one file per face.
  6. The first 3 runs are free. A try counts only when the files are written.
  7. Right-click the font and pick Copy CSS @font-face to get a ready @font-face rule for your stylesheet.

What Font Viewer handles

  • TTF or OTF to WOFF2 or WOFF, for a website.
  • WOFF2 back to an installable TTF/OTF, for the "woff2 to ttf" case.
  • One font or a whole folder. A TTC gives one file per face.
  • Table data is copied as it is, so outlines, hinting, variable axes and features do not change.
  • A WOFF2 here is about 45 percent of the TTF size (JetBrains Mono variable: 96,940 to 43,632 bytes).
  • Works offline with no network calls and no telemetry. Font files are read and written on your computer only.

What it does not do

  • It does not subset fonts or rewrite glyph data. Tools that also rewrite the glyph data get a few percent smaller.
  • WOFF2 collections, SVG fonts, .dfont and Type 1 fonts aren't supported.
  • Fonts above fontViewer.maxFileMB (64 MB by default) show a message instead of opening.
  • It runs inside VS Code, not in a build script. For CI, use woff2_compress or fontTools.

Other options

  • Google woff2 (woff2_compress). The reference encoder from Google. woff2_compress font.ttf writes font.woff2, and woff2_decompress goes back to TTF. The better choice for a build script or CI.
  • fontTools (pyftsubset). Python library and command-line tools. pyftsubset with its WOFF2 flavor option subsets and compresses a font in one step, which gives smaller files when you need only part of the character set. WOFF2 output needs the brotli module.
  • ttf2woff2 (npm). A Node.js package and command for TTF to WOFF2. Useful when your build already runs on npm scripts.
  • In-browser converters. Some web pages convert the font in your browser with WebAssembly, so the file stays on your machine. Check that the page says so before you drop a licensed font on it.
  • Online upload converters. Many converter sites upload the font to their server and send back the result. Some say they delete files after 24 hours. Avoid them for licensed or unreleased fonts.

Questions

Can it convert WOFF2 back to TTF?

Yes. Convert Font turns a WOFF2 back into an installable TTF/OTF. Font Viewer reads WOFF2 with its own decoder, which rebuilds the glyf, loca and hmtx tables.

Does the WOFF2 look different from the TTF?

No. Table data is copied as it is, so outlines, hinting, variable axes and OpenType features stay the same. Only the packing changes.

How much smaller is the WOFF2?

About 45 percent of the TTF size. JetBrains Mono variable went from 96,940 to 43,632 bytes. Tools that also rewrite the glyph data, or subset the font, get smaller files.

Is my font uploaded anywhere?

No. Font Viewer works offline, makes no network calls and sends no telemetry. The Pro tools read and write font files on your computer only.

Does it work in Cursor or Windsurf?

Cursor and Windsurf install extensions from Open VSX. Search for Font Viewer in their Extensions view and install it there.
