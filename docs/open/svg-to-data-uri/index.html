Copy an SVG as a data URI for CSS

To put an SVG inline in CSS you need it as a data URI, and building one by hand means encoding the file and adding the right prefix. SVG Preview & SVG Viewer has a Data URI button in its preview toolbar. One click copies the SVG as data:image/svg+xml;base64,..., with any unsaved edits, ready to paste into url(). The copy is free. To make the URI shorter first, the Optimize SVG tool in Zovo Pro (USD 19 once) removes editor data and rounds coordinates, with 3 free tries.

Steps in VS Code

  1. Install SVG Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-svg-viewer.
  2. Open the .svg file and click the preview button in the editor title, or press Ctrl+K V (Cmd+K V on a Mac). The preview opens beside the code.
  3. Click Data URI in the preview toolbar. The SVG is copied to the clipboard as data:image/svg+xml;base64,..., and a short message gives its length.
  4. Paste it into your stylesheet, for example background-image: url("data:image/svg+xml;base64,..."), or into an <img src>.
  5. If you need a bitmap instead, pick 1x to 8x or type a width, then click Save PNG or Copy PNG.
  6. The copy uses the text in the editor, with edits you have not saved yet. A .svgz file is unpacked first.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-svg-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-svg-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What SVG Viewer handles

  • .svg files, and .svgz files, which are unpacked before the copy.
  • Unsaved edits in the open editor.
  • Files up to 50 MB at once. Bigger files ask before they draw (setting svgViewer.maxFileMB).

What it does not do

  • Data URI writes base64 only. There is no URL-encoded option, which is often shorter for small icons.
  • It copies the SVG as it is and does not minify it. Use Optimize SVG or another tool first if size matters.
  • An SVG used as a CSS background cannot be styled by the CSS of your page. Set its colors inside the SVG.

Other options

  • URL-encoder for SVG. A free web page that turns SVG code into a URL-encoded data URI for CSS, often shorter than base64.
  • mini-svg-data-uri. A small npm package that makes short, URL-encoded SVG data URIs in a build step.

Questions

Base64 or URL-encoded?

Both work in CSS. URL-encoded text is often smaller for simple icons and stays readable. SVG Viewer copies base64, which needs no escaping.

Does it change my SVG file?

No. It reads the file or the editor text and writes only to the clipboard.

Can I get a PNG instead?

Yes. Save PNG and Copy PNG export at 1x to 8x or a width you type, up to 16,384 px on a side.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
