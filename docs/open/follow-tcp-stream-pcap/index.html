Follow a TCP stream in a pcap or pcapng file

PCAP Viewer reads .pcap and .pcapng captures in VS Code with no Wireshark, tshark or sharkd. Double-click a packet and Follow stream puts the data of its TCP or UDP connection in order, client to server in red and server to client in blue, with retransmitted bytes shown once. You can show it as ASCII, UTF-8 or a hex dump, pick one direction, and copy it or save it as a text file, all for free. Zovo Pro (USD 19 once) adds a Markdown capture report, packet list export to CSV or JSON and a folder summary, with 3 free tries each.

Steps in VS Code

  1. Install PCAP Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-pcap-viewer.
  2. Click a .pcap, .pcapng, .pcap.gz or .pcapng.gz file. For a .cap file or another name, right-click it and pick Open in PCAP Viewer.
  3. Narrow the list with a display filter such as tcp.port == 443 && ip.addr == 10.0.0.1 and press Enter. The box turns green when the filter is valid.
  4. Double-click a packet of the connection, or select it and click Follow stream. The title shows the stream number and its filter, such as tcp.stream == 0.
  5. Pick ASCII, UTF-8 or Hex dump, and pick both directions or one side. Hover a block to see which packets it came from.
  6. Click Copy, or Save as... to write a .txt file in the format and direction you picked. Filter on this stream closes the window and lists only the packets of that connection.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-pcap-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-pcap-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What PCAP Viewer handles

  • TCP and UDP connections over IPv4 and IPv6.
  • Retransmitted bytes, which are shown once.
  • Large captures. In the release check, a 1 GB capture with 1,438,965 packets listed in about 2 seconds.
  • pcap with micro or nanosecond time stamps, pcapng, and both as .gz.

What it does not do

  • It does not decrypt TLS. A stream on port 443 shows the encrypted records.
  • It collects the first 16 MB of a stream. The window shows up to 4 MB, and Save as writes all that was collected.
  • Save as writes text in the format you picked, not the raw bytes. Pick Hex dump to keep every byte.
  • HTTP bodies that were sent compressed or chunked are shown as sent, not unpacked.

Other options

  • Wireshark. Free. Right-click a packet and pick Follow, then TCP Stream. It can also decrypt TLS when you give it a key log file.
  • tshark. Comes with Wireshark. tshark -r file.pcap -q -z follow,tcp,ascii,0 prints stream 0 in a terminal.
  • tcpflow. A free command-line tool that writes each TCP connection of a capture to its own file.

Questions

Can I follow a UDP stream?

Yes. Follow stream works on TCP and UDP packets. The title then shows a udp.stream filter.

Can it read HTTPS traffic?

It shows the TLS records and the server name from the Client Hello, but it does not decrypt the data.

Is Follow stream free?

Yes. Follow stream, filters, statistics and pcap export are free. The capture report, the CSV or JSON export of the packet list and the folder summary are Zovo Pro tools with 3 free tries each.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
