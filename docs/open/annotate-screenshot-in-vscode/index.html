Annotate a screenshot in VS Code

VS Code's own image preview only shows a picture. The free Image Editor adds an Edit Image button to that preview, with arrows, lines, boxes, ellipses, text, a pen, a highlighter and numbered step badges, plus Blur and Pixelate for emails, passwords and faces. Saving replaces the hidden pixels in the file, so they cannot be recovered. All editing is free. Zovo Pro (USD 19 once) adds a compare of two screenshots with a pixel diff, a batch resize of a folder and a compress to a target size, with 3 free tries each.

Steps in VS Code

  1. Install Image Editor from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-image-editor.
  2. Click the .png, .jpg, .webp, .gif or .bmp file. It opens in VS Code's own preview first. Click Edit Image at the top right, or right-click the file in the Explorer and pick Edit Image.
  3. To start from a screenshot you just took, run "Image Editor: Paste an image from the clipboard as a new file", or press Ctrl+V (Cmd+V on macOS) in the editor.
  4. Pick Arrow (A), Line (L), Box (R), Ellipse (E), Text (T), Pen (P), Highlighter (H) or Step (N), choose a colour and a width, and drag on the image. For Text and Step, click where it goes. Shift keeps lines at 45 degree steps and boxes square, and step badges count up 1, 2, 3 by themselves.
  5. Pick Blur (B) or Pixelate (X), choose a strength, and drag a box over what must not be seen.
  6. Use Crop with a free or fixed ratio, then press Ctrl+S (Cmd+S) to save in the same format. "Image Editor: Save a copy as PNG, JPEG, WebP or BMP" writes a new file instead. Undo, Redo and Revert work as in any VS Code editor.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-image-editor and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-image-editor.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Image Editor handles

  • PNG, JPEG, WebP, GIF (first frame) and BMP files.
  • Arrows, lines, boxes, ellipses, text, pen, highlighter and numbered steps in any colour.
  • Blur and pixelate that replace the pixels when you save.
  • Phone photos, turned the right way up from their EXIF orientation.

What it does not do

  • TIFF, HEIC, AVIF and SVG files do not open in this editor.
  • A GIF opens at its first frame and is saved as a PNG next to it.
  • Save writes pixels only. EXIF data such as the camera or GPS location is not copied.
  • Images up to 100 megapixels and 32,767 pixels a side open. The editor has no layers.

Other options

  • Flameshot. A free, open source screenshot tool with arrows, boxes, numbers and blur, for Windows, macOS and Linux.
  • The markup tool of your system. Preview on macOS and Snipping Tool on Windows add arrows and shapes for free, outside VS Code.
  • GIMP. A free image editor with layers, for work that needs more than markup.

Questions

Can someone undo the blur in the saved file?

No. Saving replaces those pixels in the file. Keep a copy if you need the original.

Does the original preview change?

No. Images still open in VS Code's own preview. The editor opens only when you click Edit Image or pick it with Open With.

Is it free?

Yes. All editing and saving is free. Only Compare two images, Batch resize and convert a folder and Compress to a target size are Pro, with 3 free tries each.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
