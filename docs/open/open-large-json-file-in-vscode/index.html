Open a large JSON file in VS Code

The text editor holds the whole file as text, VS Code turns off features on large files, and it does not pass files over 50 MB to extensions, so a big JSON file is slow or does not show at all. Large JSON Viewer parses the file in a background thread and draws only the rows on screen. A 30 MB array with 350,000 objects shows its first rows in about 0.6 s. It opens files up to 200 MB, or up to 1 GB with a setting, and the tree, search and copy are free. Zovo Pro (USD 19 once) adds export of an array to CSV or JSON Lines and a compare of two JSON files, with 3 free tries each.

Steps in VS Code

  1. Install Large JSON Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-json-tree-viewer.
  2. Right-click the file in the Explorer and pick "Open in JSON Viewer". This does not use the text editor, so it also works when VS Code will not show the file as text. For a file already open as text, click the tree icon in the editor title.
  3. The top bar shows the size, the number of items and how long the parse took. Rows are drawn only as you scroll.
  4. Use the 1, 2, 3 and All buttons to open the tree to the level you need, or click nodes. Arrow keys move, Right opens and Left closes.
  5. Type in Search and press Enter. It covers every key and value in the file, not only the open rows.
  6. Click a node to see its JSONPath, such as $.items[3].id, and copy the path, the JS path or the value. For an array of objects, click its Table chip to get a table you can sort.
  7. For a file over 200 MB, raise the setting jsonTreeViewer.maxFileMB (up to 1024). Parsing takes several times the file size in memory.

Where Zovo Pro saves time

A large JSON file is often one big array of records that you need in a spreadsheet or another tool. Export Array to CSV or JSON Lines writes one row per item, with nested objects as dotted columns such as customer.address.city. Big numbers stay exact, and text that Excel would run as a formula is written as plain text. It reads the file in a separate worker thread, so VS Code stays responsive. The other Pro tool, Compare Two JSON Files, lists every changed, added and removed value by path and matches arrays of objects by their id.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-json-tree-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-json-tree-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Large JSON Viewer handles

  • .json, .jsonc, .json5, .geojson, .har, .ipynb and .webmanifest files.
  • Minified JSON on one line, with no formatting pass first.
  • Strings that hold escaped JSON, such as log payloads, opened as a nested tree.
  • Comments, trailing commas, and UTF-8 or UTF-16 files with a byte order mark.

What it does not do

  • Files over 200 MB are not read unless you raise jsonTreeViewer.maxFileMB. The highest value is 1024 MB.
  • Expand all stops at 1,000,000 visible rows, and search stops at 10,000 matches. A note says when that happens.
  • The table shows the first 200 keys as columns.
  • It is a viewer. To change a value, Go to line (G) opens the text editor beside the tree at that node.

Other options

  • jq. A free command-line tool to filter and slice JSON. Its streaming mode reads files too big to hold in memory.
  • Dadroit JSON Viewer. A desktop viewer made for very large JSON files, outside VS Code. Its JSON to CSV converter is part of a paid plan.

Questions

Why does VS Code freeze on a big JSON file?

The text editor holds and colors the whole text, and a minified file is one very long line. A tree viewer parses the file once in a background thread and draws only what is on screen.

My JSON is all on one line. Do I have to format it first?

No. The viewer reads minified JSON as it is and shows it as a tree, with a type badge and a child count on each row.

Can it open a 2 GB JSON file?

No. The limit is 1 GB with the setting raised. For bigger files, use a streaming tool such as jq in its streaming mode.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
