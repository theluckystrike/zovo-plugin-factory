Search a binary file for a hex byte pattern

Text editors cannot search bytes, and many hex editors stop at 2 GB. Hex Viewer opens any file in VS Code and its Find reads the file in 1 MB pieces, so it searches a 4 GB disk image the same way as a small file. Type hex bytes such as 50 4B 03 04, use ?? for any byte, or search for text or UTF-16 text. Find is free. Zovo Pro (USD 19 once) adds a search for the same pattern in many files at once, with 3 free tries.

Steps in VS Code

  1. Install Hex Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-hex-viewer.
  2. Right-click the file in the Explorer and pick "Open in Hex Viewer". Files ending in .bin, .dat, .img, .rom, .dmp or .dump open in it when you click them.
  3. Press Ctrl+F (Cmd+F on macOS) and pick Hex in the mode menu next to the search box.
  4. Type the pattern, such as 50 4B 03 04. Type ?? for a byte that can be anything, so 50 4B ?? 04 matches any third byte.
  5. Press Enter or F3 for the next match and Shift+Enter or Shift+F3 for the previous one. The toolbar shows the offset of the match. The search goes on from the start after the end, and Esc stops a long search.
  6. For text, pick Text (with Aa to ignore case) or UTF-16. Ctrl+G with +0x100 or -16 moves from a match by an offset.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-hex-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-hex-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Hex Viewer handles

  • Files of any size. Find reads 1 MB at a time, also across 64 KB edges.
  • Hex bytes with ?? wildcards, ASCII or UTF-8 text with or without case, and UTF-16 text.
  • Unsaved edits, which are searched as you see them.
  • Go to offset in hex or decimal, such as 0x1F40, 1F40h, end or end-15.

What it does not do

  • A wildcard stands for one whole byte. Half-byte wildcards and regular expressions do not work.
  • A pattern can be up to 4,096 bytes and needs at least one byte that is not ??.
  • Find shows one match at a time. To list every match with its offset, use the Find Bytes in Files Pro tool.
  • Files on remote and virtual file systems open up to 256 MB.

Other options

  • GNU grep. On Linux, grep -obUaP "\x50\x4B\x03\x04" file.bin prints the byte offset of each match. The macOS grep lacks the -P option.
  • ImHex. A free hex editor for Windows, macOS and Linux with find by hex pattern and a pattern language.

Questions

Does it load the whole file?

No. It reads the rows on screen, and Find reads the file in 1 MB pieces. In the release check a 4 GB file opened in 0.6 s.

Can I search for a string in UTF-16, as in Windows files?

Yes. Pick UTF-16 in the mode menu and type the text. It is searched as little-endian UTF-16.

Can I search many files at once?

Yes, with the Find Bytes in Files Pro tool. It lists every match with its file and offset.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
