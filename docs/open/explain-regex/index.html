Find out what a regex in your code does

A regex in old code is hard to read, and pasting it into a website loses the context. Regex Preview & Regex Tester adds a Test regex link above each regex in JavaScript, TypeScript, Python, Go, Rust, Java, Kotlin, C#, PHP and Ruby files. The panel explains the pattern with one plain line per part, draws a railroad diagram and shows the matches and groups on your own text. That is free, and Zovo Pro (USD 19 once) checks every regex in the workspace for catastrophic backtracking, with 3 free tries.

Steps in VS Code

  1. Install Regex Preview from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-regex-preview.
  2. Click Test regex above the pattern. In any other file, select the pattern and press Ctrl+Alt+M (Cmd+Alt+M on a Mac), or run "Regex Preview: Test Selected Text as Regex".
  3. Open the Explain tab. It gives one plain line for each part of the pattern.
  4. Open the Diagram tab to see the structure with groups, lookarounds and repeat counts. Click Fit width for a long pattern, or export it as SVG or PNG.
  5. Paste a real line in Sample text, or click Load file. The Matches tab lists each match with one column per group. Click a row to select the match in the text.
  6. If the regex comes from Python, Java or another language, the flavor is set from the file, and a list names any syntax that works differently there.

What Regex Preview handles

  • Regex literals and calls such as re.compile(r"..."), regexp.MustCompile(...), Pattern.compile("..."), new Regex(@"...") and preg_match('/.../').
  • String escapes, which are undone first, so "\\d+" in Java is read as \d+.
  • Numbered and named groups, lookarounds and repeat counts.
  • Sample text up to 10 MB from a file (regexPreview.maxSampleMB).

What it does not do

  • A regex built at run time from variables gets no Test regex link. Select the pattern text and use Test Selected Text as Regex.
  • Files over 1,024 KB get no Test regex link (regexPreview.codeLensMaxFileKB).
  • Patterns run in the JavaScript engine of VS Code. For other flavors the panel rewrites what it can and warns about the rest.

Other options

  • regex101. A free website with an explanation panel and several flavors. You paste the pattern and text into the browser.
  • Regexper. A free website that draws a railroad diagram of a JavaScript regex.

Questions

Does it change my code?

No. The Test regex link is a CodeLens only. The panel never edits the file.

Is my text or pattern sent anywhere?

No. The panel blocks every network request, and the sample text stays in VS Code's workspace storage on your machine.

What happens with a pattern that hangs?

Each match run stops after 1 second, and the panel says so. VS Code keeps working.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
