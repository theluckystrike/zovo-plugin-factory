Find the images that no file in your project uses

Old logos and screenshots stay in a repo long after the code stops using them, and VS Code has no command that checks the images on disk against the paths in your files. Image Preview & Image Hover has a Find Unused Images tool. It lists every image in the workspace, or in one folder, that no code, style, Markdown, HTML, JSON or YAML file names, largest first. Then it can move them to an _unused-images folder that Edit > Undo puts back. Find Unused Images is part of Zovo Pro (USD 19 once), with 3 free tries on your computer.

Steps in VS Code

  1. Install Image Preview & Image Hover from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-image-preview.
  2. Open the project folder in VS Code. The tool reads the images and the text files of a workspace folder.
  3. Right-click the folder to check, such as public or src/assets, and pick "Zovo Pro: Find unused images". Or run "Image Preview: Find Unused Images (Pro)" from the Command Palette to check the whole workspace folder.
  4. Read the Markdown report that opens. It says how many images are not named in any of the text files it read and their total size, then lists each image with its size, largest first. Click a name to open the image.
  5. Check the list before you move anything. An image whose path the code builds while it runs, such as icons/${name}.svg in a template string, looks unused here.
  6. In the message that follows, click "Move N to _unused-images" to move the listed images with their folders kept, or close it to leave them where they are. Edit > Undo moves them back.

Where Zovo Pro saves time

The gutter thumbnails and the hover are free, with no limits. Hover any image path to see the picture, its type, pixel size and file size, or a note that the file is missing. To check one image by hand, search its file name with Ctrl+Shift+F (Cmd+Shift+F on a Mac) and see where it is used.

A text search for each image takes a long time in a project with hundreds of assets. Find Unused Images reads the code, style, Markdown, HTML, JSON and YAML files of the workspace folder in one run. An image counts as used when a path resolves to it or when its file name appears in one of those files. The ones you confirm move in one step that Undo reverses. The other two Pro tools are Find Broken Image References, which lists paths to images that do not exist, and Image Weight Report, which lists the heaviest images and flags the ones worth shrinking.

  2. Search for zovo.zovo-image-preview and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-image-preview.

What Image Preview & Image Hover handles

  • PNG, APNG, JPEG, GIF, WebP, AVIF, SVG, BMP, ICO, HEIC and TIFF files.
  • Image names in JavaScript, TypeScript, JSX, Vue, Svelte, CSS, SCSS, LESS, HTML, Markdown, JSON, YAML and many other text files.
  • Paths through tsconfig.json paths, @/, ~, public folders and your own imgPreview.aliases.
  • File names in any case or URL-encoded, and icon names written in quotes without the extension.

What it does not do

  • An image counts as used when its file name appears anywhere in a text file, even in a comment. So the list can miss some unused images.
  • Paths built while the code runs, and images a server loads by name, can make an image look unused. Check the list before you move files.
  • Text files over 2 MB are not read. Folders that match imgPreview.exclude, such as node_modules, dist and build, are skipped.
  • The _unused-images folder is made at the top of the workspace folder. Set another name in imgPreview.archiveFolder.
  • Remote and virtual workspaces (SSH, WSL, Codespaces, vscode.dev) are not supported in this version.

Other options

  • ripgrep. A fast command line search. A short shell loop that runs rg for each image name shows which names never appear. Free, needs a script.
  • VS Code search. Search for one file name with Ctrl+Shift+F. Free and built in, but one image at a time.

Questions

Does it delete images?

No. It moves the images you confirm to the _unused-images folder, with their folders kept. Edit > Undo moves them back, and you can delete that folder yourself later.

Can it check one folder only?

Yes. Right-click that folder. The images in it are checked against the text files of the whole workspace folder, so an image used from another folder is not listed.

Why is an image I use in the list?

Its path is probably built while the code runs, such as a template string with a variable, or a server loads it by name. Close the message instead of moving, and move the files you are sure about by hand.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
