Steps in VS Code

  1. Install DBML Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-dbml-viewer.
  2. Open a .dbml file, a .prisma schema or a .sql file with CREATE TABLE statements. Click the diagram button in the editor title bar, or run "DBML Viewer: Open ER Diagram" from the Command Palette. The diagram opens beside the editor.
  3. Drag tables to where you want them. The positions are kept for each file, and Reset layout starts over. Fit shows the whole schema, and Ctrl or Cmd + scroll zooms.
  4. For a free copy, click Copy SVG in the diagram toolbar. The diagram goes to the clipboard as an SVG image in the colors of your VS Code theme, for docs and pull requests.
  5. For a PNG, SVG or PDF file, click Export image in the same toolbar. It is a Zovo Pro tool with 3 free tries (see below).

Where Zovo Pro saves time

The live ER diagram for DBML, SQL and Prisma, the layout, search, Copy SVG and the DBML language support (syntax colors, problems, outline and go to definition) are free, with no limit.

When the diagram has to go into a design doc, a wiki page or a slide as a file, Export the diagram saves it as a PNG at twice the screen size, an SVG file or a one-page vector PDF, on a white background and with the table positions you dragged. It can also write a Markdown data dictionary with the column, type, keys, nullable, default and note of every table. The other two Pro tools are Export SQL (DBML to CREATE TABLE scripts for PostgreSQL, MySQL, SQL Server or SQLite, and SQL DDL to DBML) and Schema diff, which compares two schema files and writes the migration SQL.

With Export the diagram (Zovo Pro)

  1. With the diagram open, click Export image in the toolbar, or run "DBML Viewer: Export the diagram as PNG, SVG, PDF or data dictionary (Pro)" from the Command Palette.
  2. Pick PNG image, SVG image, PDF document or Markdown data dictionary.
  3. Pick where to save. The name starts as <schema>.erd.png (or .svg, .pdf) next to the schema file. Escape or Cancel uses no free try.

Export the diagram works 3 times on your computer before it asks for a license, and a try counts only when you get a result. Opening a file shows no popup and no countdown.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-dbml-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-dbml-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What DBML Viewer handles

  • DBML with tables, enums, TableGroup colors, sticky notes and references with ON DELETE actions.
  • SQL DDL for PostgreSQL, MySQL, SQL Server and SQLite: CREATE TABLE, keys, ALTER TABLE ... ADD FOREIGN KEY, CREATE INDEX and enums.
  • Prisma schemas.
  • Big schemas. With 200 tables or more, the tables are laid out in a grid ordered by relation.

What it does not do

  • PNG, SVG and PDF files come from a Zovo Pro tool with 3 free tries. Copy SVG to the clipboard is free with no limit.
  • The SQL reader is made for schema files. INSERT statements, views and functions are skipped and listed under the toolbar. It does not run or check SQL.
  • Files up to 8 million characters are read.
  • It draws from a schema file. It does not connect to a database.

Other options

  • dbdiagram.io. A web app by Holistics, the makers of DBML, that draws DBML as a diagram and exports it. The schema goes into a website.
  • Copy SVG and a browser. Free. Paste the copied SVG into a .svg file, open it in a browser and print it to PDF. You get the colors of your editor theme.

Questions

Is Copy SVG free?

Yes. Copy SVG, the diagram and the DBML language support are free with no limit. Only the file exports, Export SQL and Schema diff are Pro tools, with 3 free tries each.

Does the export keep my layout?

Yes. The export uses the positions you dragged. A table you added after that gets its automatic place.

Do table names in Chinese or Cyrillic show in the PDF?

No. The PDF uses a built-in Courier font and writes letters outside Western European scripts as a question mark. Use the PNG or SVG export for those names.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
