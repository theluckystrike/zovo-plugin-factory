Compare two .hex or .s19 firmware images by address

A text diff of two .hex files shows changed lines, not changed memory, and one moved record makes every line after it look different. Intel HEX Viewer compares the two images by address. It lists each range of changed bytes, and the data only in one of them, with the old and new bytes. One file can be Intel HEX and the other an S-record file. Compare is a Zovo Pro tool (USD 19 once) with 3 free tries. The memory map and hex view of each file are free.

Steps in VS Code

  1. Install Intel HEX Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-intel-hex-viewer.
  2. Open the first image in Intel HEX Viewer. For a .hex file, click the board icon in the editor title. S-record files open in the viewer when you click them.
  3. Click Compare… at the top, or run "Intel HEX Viewer: Compare two firmware images (Pro)" from the Command Palette.
  4. Pick the second image. It can be Intel HEX or S-record.
  5. The Compare tab lists each range as Changed, Only in A or Only in B, with the first and last address, the size and the bytes. Click hex on a row to see those bytes.
  6. Click Open as Markdown to get the report as a document you can save or paste into a review.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-intel-hex-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-intel-hex-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Intel HEX Viewer handles

  • Intel HEX against Intel HEX, S-record against S-record, or one of each.
  • Images with gaps and blocks at different addresses.
  • Changed bytes, bytes only in the first file and bytes only in the second file.
  • A summary of changed bytes, bytes only in A, bytes only in B and bytes that are the same.

What it does not do

  • The list stops at 20,000 ranges.
  • It compares bytes. It does not tell you which function or variable changed, since it has no disassembly and reads no map file.
  • Plain .bin files are not read.

Other options

  • srec_cmp from SRecord. A free command-line tool that compares two HEX or S-record files by address.
  • The intelhex Python package. Free. Its hexdiff.py script prints a diff of two Intel HEX files.
  • objcopy and cmp. Convert both to binary and compare them with cmp. Gaps are filled, so the offsets are not addresses.

Questions

Why not use a text diff?

Two images with the same bytes can have different line lengths or record order. A text diff then shows changes where memory is the same. This compare reads the bytes by address.

Can I compare a .hex file with a .s19 file?

Yes. Each file is read as memory by address, so the two can be in different formats.
