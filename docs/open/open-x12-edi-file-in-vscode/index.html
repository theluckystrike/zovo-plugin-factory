Read an X12 or EDIFACT file in VS Code

EDI Viewer shows an X12 or EDIFACT file in VS Code as a tree of interchanges, groups, transaction sets, loops and segments. Click a segment to see each element with its ID, name, value and the meaning of its code. It also checks control numbers, counts and empty mandatory elements. All of that is free. Zovo Pro (USD 19 once) adds export to JSON or CSV, a compare of two files and a check of a whole folder, with 3 free tries each.

Steps in VS Code

  1. Install EDI Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-edi-viewer.
  2. Click the .edi, .x12, .edifact or .850-style file. It opens as EDI text with colors. Files that start with ISA, UNA or UNB are found by their first line, whatever their name.
  3. Click the Open in EDI Viewer button in the editor title bar, or right-click the file in the Explorer and pick Open in EDI Viewer.
  4. In the Tree tab, click a segment. The panel on the right lists each element with its ID (such as BEG03), name, value and code meaning. Double-click a row to select that segment in the text.
  5. Open the Problems tab to see wrong control numbers, wrong counts, ISA fields with the wrong width and empty mandatory elements, each with its line.
  6. Back in the text editor, rest the mouse on a value to see its name. Right-click and pick Format EDI (one segment per line) to read it line by line, or Minify EDI to put it back on one line.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-edi-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-edi-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What EDI Viewer handles

  • X12 850, 855, 810, 856, 997, 999, 820, 837P, 837I, 835, 270, 271, 276, 277, 204, 214, 940 and 945, with names and common code lists.
  • EDIFACT ORDERS, ORDRSP, DESADV, INVOIC, IFTMIN, PRICAT, APERAK and CONTRL, with names from the UN/CEFACT directories.
  • Separators read from the ISA header or UNA, with or without line breaks.
  • HL hierarchies and loops such as NM1, N1, PO1, LIN and CLM.

What it does not do

  • It is a viewer. It does not translate EDI into your ERP, send files to partners or write 997 acknowledgments.
  • Files up to 64 MB open, and up to 500,000 segments are shown.
  • Names are short descriptions written for the extension, not the full X12 implementation guides.
  • Transaction sets outside the lists above still open as segments, with fewer names.

Other options

  • A plain text editor. Free. Replace the segment terminator with a line break to read one segment per line, with no names or checks.
  • pyx12. A free Python library that parses and validates X12 files from a script.
  • Online EDI viewers. Free websites that show a file as a tree. The file is uploaded to someone else's server.

Questions

Why does my .edi file open as text?

The viewer is not the default editor for EDI files. Click Open in EDI Viewer in the editor title bar, or right-click the file and pick Open in EDI Viewer.

Can it change my file?

The viewer never writes to the file. Only Format EDI and Minify EDI in the text editor change it, and they change only the line breaks between segments.

Is my file sent anywhere?

No. It is read on your computer, and the extension makes no network calls.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
