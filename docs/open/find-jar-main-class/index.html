Find the Main-Class of a JAR file

The class that java -jar app.jar runs is named by the Main-Class line of META-INF/MANIFEST.MF inside the JAR. JAR Viewer opens the .jar in VS Code and shows Main-Class, Start-Class for Spring Boot, Created by and the other manifest attributes on its Overview, with nothing unpacked. Click the class to read its decompiled source or bytecode. Zovo Pro (USD 19 once) adds a search for a class in every JAR of a folder, with 3 free tries.

Steps in VS Code

  1. Install JAR Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-jar-viewer.
  2. Click the .jar file in the Explorer. It opens in JAR Viewer on the Overview.
  3. Read the Main-Class row. For a Spring Boot JAR, Main-Class is the Spring Boot launcher and Start-Class is your own main class.
  4. Scroll down to the META-INF/MANIFEST.MF section for every main attribute, such as Class-Path, Implementation-Version and Automatic-Module-Name.
  5. Type part of the class name in the filter box above the package tree and click the class.
  6. Read the Java source tab, decompiled with CFR on the Java on your computer, or the Bytecode tab, which needs no Java. Look for public static void main.

What JAR Viewer handles

  • Main-Class, Start-Class, Created-By, Build-Jdk-Spec and Automatic-Module-Name from the manifest.
  • Spring Boot JARs, WAR files and AAR files, with nested JARs one level deep.
  • Up to 60 main attributes of the manifest on the Overview.
  • Archives with up to 200,000 entries.

What it does not do

  • Decompiled source needs Java 8 or newer on your computer. The bytecode view works without it.
  • CFR output can differ from the original source, such as local variable names and some lambdas.
  • If the manifest has no Main-Class, the JAR is a library and java -jar cannot run it.

Other options

  • unzip. unzip -p app.jar META-INF/MANIFEST.MF prints the manifest in a terminal without unpacking the rest.
  • 7-Zip. A free archiver for Windows. Open the JAR, go to META-INF and view MANIFEST.MF.

Questions

Why does Main-Class say JarLauncher?

In a Spring Boot JAR, Main-Class is the Spring Boot launcher, which sets up the nested JARs. Your own main class is in the Start-Class row.

What if there is no Main-Class row?

The manifest has no Main-Class, so java -jar says "no main manifest attribute". Run a class by name with java -cp app.jar com.example.Main instead.

Can I read the source of the main class?

Yes. Click it in the package tree. The Java source tab shows it decompiled with CFR, using the Java on your computer.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
