Copy a request from a HAR file as cURL

HAR Viewer opens a .har file from browser DevTools in VS Code as a table with one row per request. Click the request, then click Copy as cURL in the details pane, and you get a curl command with the method, URL, headers, cookies and body, ready for bash or zsh. That is free and works offline. Zovo Pro (USD 19 once) adds export of many requests at once to a Postman collection, with 3 free tries.

Steps in VS Code

  1. Install HAR Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-har-viewer.
  2. Click the .har file in the VS Code Explorer. It opens in HAR Viewer with one row per request. No capture yet? In Chrome, Edge or Firefox DevTools, open the Network tab and pick "Save all as HAR".
  3. Find the request. Type part of the URL in the filter box, click a type such as Fetch/XHR, or pick Failed in the status list to see only 4xx, 5xx and requests with no response.
  4. Click the row. The details pane opens with the Headers, Payload, Response, Cookies and Timing tabs.
  5. Click Copy as cURL at the top of the pane and paste the command into a terminal. Copy as fetch gives the same request as JavaScript for a browser console.
  6. To share the command, click "Save redacted copy..." first, open the copy and copy the request from there. Tokens and cookie values then read [REDACTED].

What HAR Viewer handles

  • GET, POST, PUT, PATCH and DELETE requests. The request body is sent as raw data, and form fields are joined as name=value pairs.
  • An Accept-Encoding header turns on the compressed option of curl, so curl asks for a compressed response and unpacks it.
  • Headers that curl sets itself (Host, Content-Length and Connection) and HTTP/2 headers such as :authority are left out.
  • Big captures. In the release test, a 47 MB capture with 30,000 requests showed all rows in under 1 second.

What it does not do

  • The command is written for bash and zsh, with single quotes and a backslash at the end of each line. It does not run as is in Windows cmd or PowerShell. Use Git Bash or WSL there.
  • The command holds the cookies and tokens of the capture. Copy from a redacted copy before you paste it into a ticket or a chat.
  • Redaction works by field name. A secret under an unusual name or in a binary body is not found, so read the copy before you send it.
  • WebSocket frames are not listed, and files over 300 MB (setting harViewer.maxFileMB) show a message instead of loading.

Other options

  • Chrome or Edge DevTools. Free. Drag the .har file into the Network panel, then right-click a request and pick Copy, then Copy as cURL. It needs the browser open.
  • Firefox DevTools. Free. The Network panel can import a HAR file from its settings menu, and Copy as cURL is in the right-click menu of a request.
  • jq. A free command-line JSON tool. It can print the method, URL and headers of each entry, but you write the curl command yourself.

Questions

Does the cURL command include cookies?

Yes. The Cookie header is copied like any other header, so the command runs with the same session. Copy from a redacted copy if someone else will see it.

Can I copy it for Windows cmd?

No. The copy uses one cURL format, for bash and zsh. Copy as fetch is the other choice, for JavaScript in a browser console.

Is the HAR file sent anywhere?

No. HAR Viewer works offline, with no network calls and no telemetry.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
