Use a Parquet viewer in VS Code

VS Code cannot show a .parquet file by itself. Install the free Parquet Grid Viewer by Zovo and click the file: it opens as a grid with column types, a filter under each header and a Schema tab. Opening reads only the footer and rows load as you scroll, so large files open at once. It needs no Python, Java or parquet-tools.

Free, MIT license. Extension ID zovo.zovo-parquet-viewer, version 0.2.0. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install Parquet Grid Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-parquet-viewer.
  2. Click a .parquet, .parq or .pq file in the Explorer. If another editor opens it, right-click the file and pick "Open in Parquet Grid Viewer".
  3. Click a header to sort. Type in the box under a header to filter, for example >100, =cash, 5..9, null or a /regex/.
  4. Click a cell and press Enter to see the whole value. LIST, MAP and STRUCT cells open as a tree.
  5. Open the Schema tab for column types, row groups, compression and key-value metadata. Export saves the filtered rows as CSV or JSON Lines.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-parquet-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-parquet-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Parquet Grid Viewer handles

  • Snappy, Gzip, Zstd, Brotli, LZ4 and LZ4_RAW, data pages v1 and v2, dictionary, delta and byte-stream-split encodings.
  • Exact values: DECIMAL up to 38 digits, INT64 and UINT64 above 2^53, nanosecond timestamps, and INT96 timestamps from Spark and Hive.
  • Filter, sort and search on the whole file, not only the rows on screen, in a background thread with a Cancel button.
  • Copy cells or rows as CSV, JSON or a Markdown table.
  • Clear messages for files that are cut off, damaged, encrypted or not Parquet at all.

What it does not do

  • It is read-only. To change data, use pandas, Polars, DuckDB or Spark.
  • Encrypted Parquet files show a message. The viewer does not ask for keys.
  • Sorting stops at 2,000,000 rows (a setting). Filter first to sort part of a bigger file.
  • Files on remote and virtual file systems are read whole, up to 512 MB.
  • No SQL. For SQL on a Parquet file, see XLSX Viewer & CSV Preview below.

Questions

Do I need Python or parquet-tools?

No. The viewer is plain JavaScript, so it runs the same on Windows, macOS (Apple silicon too), Linux, Remote SSH, WSL and Codespaces.

How does it open large files?

Opening reads only the footer. Rows are then read in blocks as they scroll into view, and older blocks are dropped, so memory stays flat. Filter, sort and export read the columns they need, row group by row group.

Can it show nested columns?

Yes. LIST, MAP and STRUCT columns show as compact JSON in the grid and as a tree in the detail pane, at any depth.
