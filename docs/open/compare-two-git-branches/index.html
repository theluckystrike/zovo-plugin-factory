Compare two git branches in VS Code

VS Code has no built-in report of what one branch has and the other lacks, and in a terminal it takes git log with a range, git merge-base and git diff. Git Commit Graph & History Log writes one Markdown report for two branches, with the commits on each side, the merge base, the files changed since the merge base and the authors. The Branch comparison report is a Zovo Pro tool (USD 19 once) with 3 free tries, and comparing two commits with Ctrl+click in the graph is free.

Steps in VS Code

  1. Install Commit Graph from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-git-commit-graph.
  2. Open the repository and click Graph in the status bar, or run "Commit Graph: Show Commit Graph".
  3. Click Compare Branches in the graph toolbar, or run "Commit Graph: Compare Branches (Report)...". Pick the base, for example main, then the branch to compare with it. Local branches, remote branches and tags are in the list.
  4. Or right-click a branch label in the graph and pick "Compare with main (report)", where main is the branch you have checked out.
  5. Read the report. A table gives the commits that only each branch has, the merge base and the number of changed files. Below are the authors, both commit lists with hash, subject, author and date, and the changed files.
  6. Fetch first when you compare with a remote branch. The report reads your local repository only.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-git-commit-graph and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-git-commit-graph.

  4. Then use it the same way as in VS Code.

What Commit Graph handles

  • Local branches, remote branches and tags.
  • Branches with no common history, shown with no merge base.
  • Renamed files, shown with their old path.
  • Nested repositories and submodules, each picked from the repository list.

What it does not do

  • Each commit list shows at most 500 commits, and the file list at most 2,000 files. The counts above them stay exact.
  • The changed files are those changed on the second branch since the merge base. Changes made only on the base branch are not in that list.
  • The report lists files, not line changes. Ctrl+click two commits in the graph to open the diff of a file.
  • Only local refs are read, and nothing is fetched for you.

Other options

  • git in a terminal. git log main..feature lists the commits that feature has and main lacks, and git diff main...feature shows the changes. Free, but plain text.
  • GitLens. A VS Code extension whose Search and Compare view compares branches and lists commits and files. Some features need a paid plan.

Questions

Which branch is the base?

The first one you pick. The report lists what the second branch has since it left the base, and the commits the base has that the second branch lacks.

Does it change my repository?

No. It runs read-only git commands on your local repository and opens the report in a new tab.

Can I compare a branch with a tag?

Yes. Tags are in the same list as branches.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
