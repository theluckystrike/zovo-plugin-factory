Open a Feather or Arrow file without pandas

A Feather V2 file is an Arrow IPC file, and Avro File Viewer, Apache Arrow & Feather Viewer reads it with no Python. Click a .feather, .arrow, .arrows or .ipc file and it opens as a paged table with typed column headers, a Schema tab, column stats, search and export to CSV or JSON. Only the record batch you scroll to is decoded, so big files open fast. All of that is free. Zovo Pro (USD 19 once) adds a profile of all columns, a compare of two files and a CREATE TABLE statement from the schema, with 3 free tries each.

Steps in VS Code

  1. Install Avro and Arrow Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.arrow-avro-viewer.
  2. Click a .feather, .arrow, .arrows or .ipc file. It opens as a table. The reader is picked from the first bytes, so a stream saved as .arrow still opens.
  3. Scroll, or use the pager at the top right (1,000 rows a page). Type a number in Row # to jump to that row. Click a cell to see its full value below the table, with JSON formatting for nested values.
  4. Open the Schema tab for every column with its type and nullability, the compression, the number of record batches and the file metadata, such as the pandas metadata that pyarrow writes.
  5. Click a column header for its nulls, distinct count, min, max, mean and most common values. Find searches every row, in all columns or the one you pick.
  6. Click Export to save this page or all rows as CSV or JSON. Export always asks for a new file and never changes the one you are viewing.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.arrow-avro-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/arrow-avro-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Avro and Arrow Viewer handles

  • Feather V2 from pandas and pyarrow, uncompressed, LZ4 or ZSTD.
  • Arrow IPC file and stream format (.arrow, .arrows, .ipc).
  • Avro container files with the null, deflate, snappy and zstandard codecs.
  • 64-bit integers above 2^53 kept exact, and decimals, dates, timestamps, structs, lists and maps shown as real values.

What it does not do

  • Feather V1 is not supported. Files written before 2020 get a message that explains how to save them as V2.
  • Files up to 4 GB. One record batch or Avro block can be up to 1 GB, since it is decoded whole.
  • Remote files in virtual workspaces are read whole, up to 256 MB.
  • ORC and Parquet are not read here. Parquet opens in Table Viewer by Zovo.

Other options

  • pyarrow. Free. pyarrow.feather.read_table("file.feather") reads the file as an Arrow table with no pandas. It needs Python.
  • Polars. Free. polars.read_ipc("file.feather") reads Feather V2 and Arrow IPC files into a DataFrame. It needs Python.

Questions

Do I need Python, pandas or pyarrow?

No. The extension reads the file itself with Apache Arrow for JavaScript, inside VS Code.

Why does my old .feather file not open?

It is probably Feather V1, written before 2020. The extension shows a message that explains how to save it again as Feather V2.

Is my file changed or uploaded?

No. The extension makes no network calls and never writes to the file you view. Export always asks for a new file.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
