Open a PDF file in VS Code

VS Code has no built-in PDF viewer, so clicking a .pdf gives a message that the file is binary. Install a PDF viewer extension, such as the free PDF Reader by Zovo, and click the PDF again. It opens in a normal editor tab with search, an outline, page thumbnails, zoom and Ctrl+G to go to a page. It reloads when a LaTeX or Typst build writes the file, and it keeps your page.

Install in VS CodeMarketplace pageOpen VSX (Cursor, Windsurf, VSCodium)JetBrains IDEs

Free, MIT license. Extension ID zovo.pdf-viewer-dark, version 0.3.7. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install PDF Reader from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.pdf-viewer-dark.
  2. Click any .pdf file in the Explorer. It opens in a tab like any other file.
  3. Press Ctrl+F (Cmd+F on macOS) to search. Enter and Shift+Enter move between matches.
  4. Press Ctrl+G to go to a page. Open the sidebar for the outline and page thumbnails.
  5. Zoom with Fit width, Fit page or 50% to 400%, or Ctrl plus the mouse wheel.
  6. If another PDF extension is installed, right-click the PDF and pick "Open With..." to choose.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.pdf-viewer-dark and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/pdf-viewer-dark.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What PDF Reader handles

  • Reload when the PDF changes on disk, at the same page, zoom and scroll position. A half-written file keeps the last version on screen.
  • Dark and sepia pages that keep photos in their real colors. By default the pages follow your VS Code theme.
  • Highlights in 4 colors, listed in a sidebar tab and copied as Markdown with a link to each page.
  • Links like docs/paper.pdf#page=12 in Markdown open the PDF at that page. "Copy Link to This Page" writes one for you.

What it does not do

  • It doesn't fill forms, edit the PDF or print.
  • Highlights are saved in VS Code on this computer, not in the PDF file.
  • The whole file is loaded into memory. Above 200 MB it asks first.
  • Search reads every page, so it takes longer on very long PDFs.

In JetBrains IDEs (IntelliJ IDEA, PyCharm, WebStorm, CLion and others)

  • No Zovo plugin for JetBrains IDEs yet. PDF Reader is for VS Code and the editors built on it. In IntelliJ IDEA, PyCharm and the other JetBrains IDEs, the PDF Viewer plugin (413,752 downloads) "adds support for viewing PDF files in IntelliJ-based IDEs", in its own words.

Other options

  • vscode-pdf (tomoki1207.pdf, 14.4 million installs, on Open VSX). Its own description: "Display pdf file in VSCode." The most installed PDF extension, with a 4.47 rating.
  • PDF Viewer (mathematic.vscode-pdf, 2.9 million installs, on Open VSX). Its own description: "Portable document format (PDF) viewer for Visual Studio Code." It has a 4.83 rating.
  • Office Viewer (cweijan.vscode-office, 1.6 million installs, on Open VSX). Its own description: "View word, excel, powerpoint files and using WYSIWYG editor for markdown." Pick it if you want one extension for several Office formats.
  • Your browser. Right-click the PDF, pick "Reveal in File Explorer" (Finder on macOS) and open it in a browser or PDF app when you need forms or printing.

Questions

Can VS Code open PDF files without an extension?

No. VS Code shows a message that the file is binary or uses an unsupported text encoding. A PDF viewer extension adds a viewer that opens in a normal tab.

Will the PDF reload after I rebuild my LaTeX document?

Yes. PDF Reader watches the file and reloads it at the same page, zoom and scroll position. While the build is still writing, the last version stays on screen.

Does it upload my PDF?

No. It reads the file with the VS Code file system API, makes no network calls and has no telemetry. PDF JavaScript is not run.
