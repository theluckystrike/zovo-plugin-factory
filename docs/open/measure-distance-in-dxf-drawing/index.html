Measure a distance in a DXF drawing in VS Code

DXF Viewer & File Preview for 2D CAD Drawings opens .dxf files in VS Code with no CAD program. Press M (or click Measure) and click two points. The bar under the drawing shows the distance in the drawing units, ΔX, ΔY and the angle, and points snap to ends, centres and vertices. Copy puts that line on the clipboard. Measuring is free, like the rest of the viewer. Zovo Pro (USD 19 once) adds three tools for many drawings or revisions, such as Compare drawings, with 3 free tries each.

Steps in VS Code

  1. Install DXF Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.dxf-viewer.
  2. Click a .dxf file in the Explorer. ASCII and binary DXF from R12 to AutoCAD 2018 open. The Drawing panel on the left shows the units stored in the file, such as mm, or "not set".
  3. If the drawing has sheets, pick Model in the Sheet list first. On a sheet the viewports are scaled, so you would measure the sheet and not the real size.
  4. Press M or click Measure in the top bar. Zoom in with the scroll wheel, then move the mouse near a line end, a centre or a vertex. A small square shows the point it snaps to. Click the first point, then the second.
  5. Read the bar under the drawing. It shows Distance, ΔX, ΔY and Angle, in the units of the file. Click Copy to put that line on the clipboard for a ticket or a chat.
  6. A third click starts a new measurement. Press Esc, or M again, to stop measuring.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.dxf-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/dxf-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What DXF Viewer handles

  • ASCII and binary DXF, from R12 to AutoCAD 2018, with blocks, nested inserts, text and dimensions.
  • Snapping to ends, centres and vertices while you measure.
  • The units stored in the file (mm, cm, m, in, ft and others), shown in the Drawing panel and after the distance.
  • Paper space sheets with their viewports, layers you can hide, and find text.

What it does not do

  • 3D entities are drawn flat, as a top view, and a measurement has only ΔX and ΔY. 3DSOLID, REGION and BODY are not drawn.
  • Viewports are drawn as rectangles. A viewport clipped to a polygon shows its rectangular frame.
  • DWG files are not supported. Save a DXF copy from your CAD program, or convert a folder with the free ODA File Converter.
  • Files over 500 MB are not read (setting dxfViewer.maxFileMB, up to 2048).

Other options

  • LibreCAD. A free, open source 2D CAD program for Windows, macOS and Linux that opens DXF files and measures distances. A separate desktop install.
  • QCAD. A 2D CAD program for Windows, macOS and Linux with a free community edition. It opens DXF files and has measuring tools.

Questions

What units is the distance in?

In the drawing units stored in the file, such as mm or in. The Drawing panel shows them. When the file sets no units, the bar says units, and you need to know the scale the drawing was made in.

Can I measure an area?

No. Measure gives the distance between two points, with ΔX, ΔY and the angle. It has no area or perimeter tool.

Does measuring change the file?

No. DXF Viewer never changes the drawing. The only files it writes are exports you pick in the save dialog, and it refuses to write over a drawing.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
