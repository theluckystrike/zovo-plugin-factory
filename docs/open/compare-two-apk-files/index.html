Compare two APK files in VS Code

APK Analyzer opens an .apk, .aab, .apks or .xapk file in VS Code and shows the manifest, permissions, components, DEX method counts, sizes and the signing certificate. That is free and offline, with no Android SDK and no Java. To see what changed between two builds, its Compare two APKs tool lists size changes by folder and file, added and removed permissions and components, SDK level and signing changes, and method references per package. It is part of Zovo Pro (USD 19 once), with 3 free tries.

Steps in VS Code

  1. Install APK Analyzer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-apk-analyzer.

  4. Open Folders, Types or Files to see where the bytes go, largest first, and Packages for method counts as a tree.

  4. Then use it the same way as in VS Code.

What APK Analyzer handles

  • .apk files, with the manifest decoded from Android binary XML.
  • .aab bundles: files, sizes, DEX counts, native ABIs and signing.
  • .apks sets and .xapk files, where the base APK is read.
  • v1 signature files and the APK Signing Block with v2, v3 and v3.1, with the signer certificate.

What it does not do

  • It shows the signature data but does not verify signatures.
  • It does not read resources.arsc, so an app label stored as a string resource shows as its resource id.
  • In an .aab the manifest is a protocol buffer, which this version does not decode.
  • It is read-only. It does not edit, re-sign or rebuild an APK.

Other options

  • APK Analyzer in Android Studio. Free, and it can compare two APKs too. It needs the full Android Studio install.
  • apkanalyzer. The command-line tool in the Android SDK. apkanalyzer apk compare old.apk new.apk prints the size differences.
  • diffuse. A free, open source command-line tool that diffs two APKs, AABs or AARs.

Questions

Do I need Android Studio or the Android SDK?

No. APK Analyzer reads the files itself, with no Android SDK, no Java and no network calls.

Does it open app bundles (.aab)?

Yes, for files, sizes, DEX counts, native ABIs and signing. The manifest inside a bundle is a protocol buffer, which this version does not decode.

Is comparing free?

Reading one APK is free. Compare two APKs is a Zovo Pro tool with 3 free tries on your computer, and a try is used only when the comparison is shown.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
