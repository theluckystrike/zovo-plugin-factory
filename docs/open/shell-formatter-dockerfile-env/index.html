Format shell scripts but leave Dockerfiles and .env files alone

A shell formatter that also runs on Dockerfiles or .env files can break them, because they only look like shell. Shell Formatter for Bash & Zsh formats only files that VS Code opens as Shell Script or Bats. Even then it skips .env names, fish and csh scripts, and any file you list. Formatting is free, and Zovo Pro (USD 19 once) formats every shell script in a folder, found by name or by its shebang line, with 3 free tries.

Steps in VS Code

  1. Install Shell Formatter for Bash & Zsh from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-shell-formatter.
  2. Open a shell script and press Shift+Alt+F (Shift+Option+F on a Mac). If VS Code asks which formatter to use, pick Shell Formatter, or run "Shell Formatter: Use as Default Formatter for Shell Scripts".
  3. Dockerfiles open as Dockerfile, not as Shell Script, so this formatter never runs on them.
  4. Files named .env, .env.* or *.env are skipped even when they open as Shell Script. Add more names to shellFormatter.skipFiles, where * and ? are wildcards.
  5. To keep a path out for the whole team, set ignore = true for it in .editorconfig.
  6. Fish and csh scripts are never formatted, because shfmt cannot read them. The status bar tooltip says why.

What Shell Formatter for Bash & Zsh handles

  • Scripts with no .sh ending, when VS Code opens them as Shell Script, with the dialect taken from the shebang line.
  • A skip list with wildcards (shellFormatter.skipFiles).
  • The .editorconfig key ignore = true.
  • Files with binary bytes, such as self-extracting installers, which are not formatted.

What it does not do

  • It formats only files that VS Code opens as Shell Script or Bats. A file opened in another language is not formatted.
  • Files over 10 MB are not formatted, and a message says why.
  • Zsh support in shfmt is new. A zsh script that shfmt cannot parse is left unchanged.

Other options

  • shell-format by foxundermoon. A widely used shfmt extension that runs a separate shfmt program. Check which languages it is set to format if other files change.
  • shfmt. The command line tool. When you pass it a folder, it finds scripts by their ending and their shebang line.

Questions

Will it reformat my Dockerfile?

No. VS Code opens a Dockerfile as Dockerfile, and this formatter runs only on Shell Script and Bats files.

My .env file opens as Shell Script. Is it safe?

Yes. .env, .env.* and *.env names are in shellFormatter.skipFiles by default, so they are skipped.

How do I skip one more file?

Add its name to shellFormatter.skipFiles, or set ignore = true for it in .editorconfig.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
