Read GeoTIFF coordinates in VS Code

TIFF Viewer opens a GeoTIFF in VS Code and adds a GeoTIFF section to its side panel with the CRS as an EPSG code, the pixel size and units, the west, east, south and north bounds, the nodata value and every GeoKey by name. Move the pointer over the image and the line under it shows the pixel, its stored value, and the easting and northing, or the longitude and latitude for a geographic raster. All of it is free and works with no network. Zovo Pro (USD 19 once) adds statistics of a region you drag, with its map corners and a CSV, with 3 free tries.

Steps in VS Code

  1. Install TIFF Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.tiff-viewer.
  2. Click the .tif or .tiff file in the Explorer. If another viewer opens, right-click the file and pick "Open in TIFF Viewer".
  3. Press Tags (or T) to open the side panel. When the page has ModelPixelScale, ModelTiepoint, ModelTransformation or GeoKeyDirectory tags, a GeoTIFF section lists the CRS, pixel size, bounds, nodata value and each GeoKey.
  4. Move the pointer over the image. The line under it shows x and y, the stored value, and the map coordinate of that pixel.
  5. Read the Values section for min, max and mean. Nodata and NaN pixels stay transparent and are left out of these numbers.
  6. Click Copy next to the Tags heading to put every tag on the clipboard as tab-separated text, for an issue or a note.

Where Zovo Pro saves time

Every page, the contrast stretches, pixel values, all tags, the GeoTIFF section, the coordinate readout and Export PNG of the page as shown are free, offline and without sign-in.

To check the values of one field, lake or tile, Region Statistics measures a rectangle you drag: pixel count, min, max, mean, standard deviation, percentiles and a histogram of the stored values, with nodata and NaN left out and counted. For a GeoTIFF it adds the map corners of the rectangle, and Save CSV writes one row per channel with the map bounds. The other Pro tools are Export pages, which saves PNG files with a .pgw world file and a GeoJSON footprint, and Batch convert for a folder.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.tiff-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/tiff-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What TIFF Viewer handles

  • Projected rasters with easting and northing, and geographic rasters with longitude and latitude.
  • Float32 and float64 elevation models, and 8, 16 and 32-bit integer data.
  • The GDAL_NODATA tag, with nodata pixels shown as transparent.
  • BigTIFF, tiled and striped files, and multi-page files.

What it does not do

  • It shows no map tiles and does no reprojection. Coordinates are in the CRS of the file.
  • A user-defined CRS with no EPSG code shows its GeoKeys, but no EPSG number.
  • Pages compressed with ZSTD, LERC, WebP or JPEG 2000 list their tags but are not decoded.
  • Files over 1 GB show the tags of every page but no pixels (setting tiffViewer.maxFileMB).

Other options

  • gdalinfo. Free. gdalinfo file.tif prints the CRS, origin, pixel size, corner coordinates and nodata value as text.
  • QGIS. A free desktop GIS. It shows the raster on a map, with reprojection and the Identify tool for pixel values.

Questions

Does it need a network connection?

No. It reads the tags from the file and loads no map tiles, so nothing is downloaded.

Is the value in the readout the colour on screen?

No. It is the stored value of the pixel, such as 1125.17 metres in an elevation model.

Is it free?

Yes. Viewing, the GeoTIFF section and the coordinate readout are free. Only Export pages, Region Statistics and Batch convert are Pro, with 3 free tries each.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
