CSV to Parquet in VS Code

Open the CSV in Table Viewer, run a query such as SELECT * FROM this and pick Save result, then Parquet. Viewing, filters, SQL on the rows in the table and export as CSV, TSV, JSON or JSON Lines are free. Save as Parquet is a Zovo Pro tool (USD 19 once) with 3 free tries.

Free, MIT license. Extension ID zovo.table-viewer-vscode, version 0.5.2. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install Table Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.table-viewer-vscode.
  2. Right-click the .csv file in the Explorer and pick "Open in Table Viewer", or click the table icon at the top right of the editor.
  3. Check the column types in the headers. If the delimiter or the header row is wrong, fix it in the toolbar.
  4. Click Query, write SELECT * FROM this (or pick the columns and a WHERE) and press Ctrl+Enter (Cmd+Enter on a Mac).
  5. Click Save result and pick Parquet, then choose a file name.
  6. The first 3 runs of Save as Parquet are free on your computer. A try counts only when the tool did its work.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.table-viewer-vscode and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/table-viewer-vscode.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Table Viewer handles

  • Column types for CSV come from the values (int, float, bool, date, timestamp or string). Integers too large to hold exactly stay as text.
  • Detects the delimiter and the encoding, including UTF-16, Windows-1252, Shift_JIS, GB18030, Big5 and EUC-KR.
  • SQL with WHERE, GROUP BY, JOIN of sheets, CASE and CAST before you save.
  • Opens the Parquet file you wrote, with the full schema tree, row groups and compression in the Schema panel.
  • Runs offline in plain JavaScript and sends nothing anywhere.

What it does not do

  • The table loads up to 1,000,000 rows by default (setting tableViewer.maxRows). A query that reads past them, the whole file, is a separate Pro tool.
  • One query may keep up to 512 MB of memory (setting tableViewer.queryMemoryMB), and the result counts. A query past that stops with a message, with no spill to disk.
  • It is read-only. It does not edit the CSV; Save result and Export write only the new file you pick.
  • For CSV files of many GB, or a daily pipeline, DuckDB or Spark is the better tool.

Other options

  • DuckDB. Free command-line database. COPY (SELECT * FROM 'a.csv') TO 'a.parquet' converts a CSV of many GB with typed columns. For large files it is the better choice.
  • pandas and pyarrow. In Python, pd.read_csv('a.csv').to_parquet('a.parquet') needs pyarrow installed. Good inside a script or notebook you already have.
  • csv2parquet CLI. A small Rust command-line tool, documented on docs.rs, that writes a Parquet file from a CSV file. Handy when you want one binary and no Python.
  • Apache Spark. For data spread over many files or too large for one machine. spark.read.csv(...).write.parquet(...) runs on a cluster.

Questions

Can I convert Parquet back to CSV for free?

Yes. Open the Parquet file, then Export the rows in view as CSV, TSV, JSON or JSON Lines. That export is free.

Does it need Python or a database?

No. It is plain JavaScript that runs offline. There is no Python, no kernel and no account.

Is my data sent anywhere?

No. Files are read on your machine in a worker thread, with no telemetry and no network requests. The one exception is "Unlock with GitHub Sponsors", which you start yourself.

Does it work in Cursor or Windsurf?

Yes. Cursor and Windsurf install extensions from Open VSX, where Table Viewer is listed.
