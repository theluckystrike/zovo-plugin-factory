Merge CSV files into one

If the files have the same columns and no header problems, cat *.csv > all.csv (or copy on Windows) is free and fast, but it repeats the header line. Excel's Power Query handles headers well. In VS Code, Table Viewer opens each CSV for free, and its Pro tool Combine Files and Sheets merges many CSV, TSV, Excel, ODS and Parquet files, a folder, or all sheets of a workbook into one CSV, XLSX or Parquet file. It has 3 free tries, then Zovo Pro is USD 19 once.

Steps in VS Code

  1. Install Table Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.table-viewer-vscode.
  2. Click a .csv file in the Explorer. It opens in Table Viewer as a grid you can sort and filter.
  3. Open two or three of the files you want to merge and check that the columns match.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.table-viewer-vscode and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/table-viewer-vscode.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Table Viewer handles

  • CSV, TSV, Excel, ODS and Parquet as input.
  • A folder, or all sheets of one workbook.
  • CSV, XLSX or Parquet as output.

What it does not do

  • It runs in VS Code, not in a scheduled job. For a nightly merge, a script with pandas or DuckDB is the better choice.

Other options

  • cat or copy. cat *.csv > all.csv on macOS and Linux, copy *.csv all.csv on Windows. Free and fast; it keeps every header line.
  • Excel Power Query. Data, Get Data, From Folder, then Combine. Free with Excel and good with headers.
  • pandas or DuckDB. A few lines of Python, or SELECT * FROM read_csv('*.csv') in DuckDB. Best for repeated jobs.

Questions

Are my files uploaded?

No. Table Viewer reads and writes files on your computer.

Can it merge Excel sheets into one?

Yes. Pick a workbook and Combine Files and Sheets puts all its sheets into one CSV, XLSX or Parquet file.

Is viewing CSV free?

Yes. Opening, sorting, filtering and queries on the loaded rows are free. Only the merge is a Pro tool, with 3 free tries.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
