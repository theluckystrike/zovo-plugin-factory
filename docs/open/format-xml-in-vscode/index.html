Format XML in VS Code and run XPath on it

XML Formatter & XPath Tools formats XML in VS Code with Shift+Alt+F and changes only the whitespace between tags: text, CDATA, comments, xml:space="preserve" and attribute values stay byte for byte, and a second format changes nothing. It also runs XPath 1.0 on the file's own namespace prefixes and shows the XPath at the cursor in the status bar. All of that is free and offline. Steps in VS Code

  1. Install XML Formatter & XPath Tools from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-xml-xpath-tools.
  2. Open an XML file and press Shift+Alt+F (Shift+Option+F on macOS). If you have more than one XML formatter, VS Code asks which one to use. Format Selection works too.
  3. The formatter uses your tab size and tabs or spaces, and keeps the line endings, the byte order mark and the final newline. A file that is not well formed is never changed: you get the error with its line and column.
  4. To make the file small instead, run "XML: Minify XML". Comments stay unless you turn on xmlXpathTools.minify.removeComments.
  5. To run an XPath, click the search button in the editor title or run "XML: Evaluate XPath...". Results list with their line; click one to select it in the editor.
  6. Click the XPath in the status bar to copy the path of the element under the cursor, with positions, with id or name attributes, or in a portable local-name() form.

What XML Formatter & XPath Tools handles

  • Big files: formatting, the tree and XPath run in a worker thread. In its tests a 49 MB file with about 1 million elements formatted in 1.6 seconds, and the editor never paused for more than 0.1 seconds.
  • Files over 50 MB, which VS Code does not pass to extensions: right-click and pick "Format Large XML File on Disk" to write name.formatted.xml next to it.
  • Plain names also match a default namespace, so //dependency/artifactId works in a pom.xml, SVG, XAML or .csproj file.
  • Attribute layout: keep as written, one line, or one attribute per line (setting xmlXpathTools.format.attributes).
  • Entities are never expanded and DTDs are never loaded, so an entity bomb or an external entity does no harm.

What it does not do

  • XPath 1.0 only: no XPath 2.0 or 3.1, XQuery or XSLT.
  • It checks that a file is well formed. It does not validate against an XSD or a DTD.
  • Files over 50 MB can be formatted on disk, but the tree and XPath do not run on them.

Other options

Questions

Can VS Code format XML without an extension?

No. VS Code has no built-in XML formatter, so Shift+Alt+F does nothing on an .xml file until you install one.

Will formatting change my text or CDATA?

No. Only the whitespace between tags in elements that hold tags and no text changes. Text, CDATA, comments and preserved content are copied as they are.

Why does my XPath select nothing in a pom.xml?

The file has a default namespace. In this extension plain names also match a default namespace, so //dependency works. Turn on xmlXpathTools.xpath.strictNamespaces for strict XPath 1.0.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
