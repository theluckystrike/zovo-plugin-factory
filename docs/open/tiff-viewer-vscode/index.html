View a 16-bit, 32-bit or multi-page TIFF in VS Code

A 16-bit or float TIFF often looks black or white in a plain viewer, because its values use a small part of the range the viewer maps to the screen. TIFF Viewer opens .tif and .tiff files in VS Code with a contrast stretch, shows the stored value under the pointer, and pages through multi-page files. Viewing is free. Zovo Pro (USD 19 once) adds Region statistics for a rectangle you drag, plus page export and folder conversion, with 3 free tries each.

Steps in VS Code

  1. Install TIFF Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.tiff-viewer.
  2. Click a .tif or .tiff file in the Explorer. If another viewer opens, right-click the file and pick "Open in TIFF Viewer", or use "Reopen Editor With...".
  3. 8-bit images open as stored. 16-bit, 32-bit and float pages open with Auto contrast, a stretch between the 0.5 and 99.5 percentiles. Pick Percentile 2 to 98, Min to max or Full type range in the contrast menu. Full type range shows what a plain viewer does.
  4. Move the pointer over the image. The status bar shows the stored value, not the screen colour. The Values section lists min, max, mean, the shown range, nodata and NaN counts and a histogram.
  5. In a multi-page file, pick a page in the page strip, or press PageDown and PageUp (or J and K). The View menu switches between the RGB image and each channel.
  6. Press T for the tags, such as BitsPerSample, SampleFormat and PhotometricInterpretation. Copy puts them on the clipboard as tab-separated text. Export PNG saves the page as shown.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.tiff-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/tiff-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What TIFF Viewer handles

  • Classic TIFF and BigTIFF, little and big-endian, strips and tiles.
  • 1 to 64-bit integers, signed and unsigned, and 16, 32 and 64-bit float samples.
  • Gray, RGB, RGBA, palette, CMYK and YCbCr in JPEG, with no compression, LZW, Deflate, PackBits, JPEG or CCITT.
  • Multi-page files, with thumbnails for the first 300 pages.
  • GeoTIFF tags with the EPSG code, pixel size, bounds and the map coordinate under the pointer.

What it does not do

  • Pages with ZSTD, LERC, WebP or JPEG 2000 compression are listed with their tags but not decoded.
  • Pages over 6000 pixels on a side or 24 million pixels are drawn with every Nth pixel. The pointer still reads full-resolution values.
  • Files over 1 GB (setting tiffViewer.maxFileMB) are not decoded. The tags of every page are still listed.
  • Sub-images in SubIFDs, such as some DNG and OME-TIFF pyramids, are listed in the tags but not shown as pages.

Other options

  • Fiji (ImageJ). Free desktop app for scientific images. It opens 16 and 32-bit TIFF stacks and sets the display range with Brightness and Contrast.
  • gdalinfo. Free command-line tool. gdalinfo -stats file.tif prints the size, data type and min, max and mean, with no picture.

Questions

Why does my 16-bit TIFF look black in other viewers?

Its values often sit low in the 0 to 65535 range, for example 189 to 4830. A viewer that maps the full range to the screen shows them as almost black. A stretch maps the real range instead.

Does the contrast stretch change the file?

No. The stretch is only for display. The viewer never writes the TIFF, and Export PNG writes a new file.

Can it show one page of a multi-page TIFF?

Yes. Pick the page in the page strip. Export PNG saves the page on screen, as shown.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
