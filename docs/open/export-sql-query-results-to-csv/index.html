Export query results to CSV from PostgreSQL or MySQL

COPY ... TO 'file' in PostgreSQL and SELECT ... INTO OUTFILE in MySQL write the file on the database server, not on your computer, and they need extra rights. Postgres & MySQL Query Client runs the query from VS Code and writes the CSV on your own machine. In the result tab, click Export and pick CSV. Every row goes to the file, not only the rows on screen, and export is free. Zovo Pro (USD 19 once) adds Import CSV into Table for the way back, plus five more tools, with 3 free tries each.

Steps in VS Code

  1. Install Postgres & MySQL Query Client from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-sql-client.
  2. Open the SQL Client view in the activity bar, click Add Connection and paste a postgres:// or mysql:// URL. Click Test connection, then Save.
  3. Click New Query on the connection, type your SELECT and press Ctrl+Enter (Cmd+Enter on macOS). The first 1,000 rows show in a result tab.
  4. In the result tab, click Export and pick CSV. Choose where to save the file. The suggested name is the table name or query_result.csv, in your workspace folder.
  5. The query runs again on its own connection, and the rows stream to the file in batches of 5,000. A progress message counts the rows and has a Cancel button. When it ends, click Open file or Show in folder.
  6. To save a whole table without writing SQL, right-click it in the Database Explorer and pick "Export Table (CSV, JSON, SQL)…".

What Postgres & MySQL Query Client handles

  • PostgreSQL, MySQL, MariaDB and SQLite connections.
  • Results of any size. In the release test, 5,000,000 rows were exported in 5.3 seconds.
  • NULL as an empty field, and values with quotes, commas or line breaks quoted the CSV way.
  • The sort and filter you set in the grid, when they ran on the server.

What it does not do

  • Export runs the query a second time, on a separate connection, so the file shows the data at that moment.
  • The file must be in a folder on this computer. Other locations get the message "Exports are written to a local file."
  • The CSV is UTF-8 with no byte order mark.
  • PostgreSQL, MySQL, MariaDB and SQLite only. No SQL Server or Oracle.

Other options

  • psql \copy. \copy (SELECT ...) TO 'out.csv' CSV HEADER in psql writes the file on your computer, not on the server. Free, in the terminal.
  • mysql command line. The mysql client in batch mode prints tab-separated rows that you can redirect to a file. Free, but the output is TSV, not quoted CSV.
  • MySQL Workbench or pgAdmin. The free desktop tools for MySQL and PostgreSQL can also save a result grid to CSV.

Questions

Does export save only the rows I see?

No. The grid loads 1,000 rows at a time, but Export runs the query again and writes every row to the file.

Do I need the FILE privilege or superuser rights?

No. The extension reads the rows like any client and writes the file itself, so a user who can run the SELECT can export it.

Can I export to JSON or SQL INSERT too?

Yes. The same Export menu has JSON (an array of objects) and SQL INSERT (one statement per row).

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
