Calculate the checksum of a file

For a whole file the built-in commands are free and enough: certutil -hashfile file SHA256 on Windows, shasum -a 256 file on macOS and sha256sum file on Linux. When you need the checksum of part of a file, such as a firmware section, or six algorithms at once, Hex Viewer in VS Code has a Checksums tool: CRC-32, Adler-32, MD5, SHA-1, SHA-256 and SHA-512 of the selection or the file in one pass, so a 4 GB file works. It has 3 free tries, then Zovo Pro is USD 19 once.

Steps in VS Code

  1. Install Hex Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-hex-viewer.
  2. On Windows, run certutil -hashfile file.bin SHA256. On macOS, shasum -a 256 file.bin. On Linux, sha256sum file.bin. All free.
  3. To look at the bytes, click the file in VS Code and pick Hex Viewer. Viewing, editing, find and the data inspector are free.

Where Zovo Pro saves time

Viewing, find, go to offset, copy as, the data inspector, editing bytes and the side-by-side compare are free in Hex Viewer.

Select the bytes of a header or a section and get all six checksums of just that range, or right-click several files in the Explorer. Pick a value to copy it. Other Hex Viewer Pro tools: nested structure view, bookmarks with notes, a compare report, find bytes in many files and an entropy map.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-hex-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-hex-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Hex Viewer handles

  • CRC-32, Adler-32, MD5, SHA-1, SHA-256 and SHA-512.
  • A selection or the whole file.
  • Files of 4 GB in one pass.

What it does not do

  • For a whole file in a script, the built-in commands are simpler.

Other options

  • certutil, shasum, sha256sum. Built into Windows, macOS and Linux. Free.
  • Get-FileHash. PowerShell: Get-FileHash file.bin -Algorithm SHA256.

Questions

Which checksum should I use?

SHA-256 to check a download. CRC-32 is common in file formats and firmware. MD5 and SHA-1 are fine for matching files, not for security.

Is the file uploaded?

No. Hex Viewer reads it on your computer.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
