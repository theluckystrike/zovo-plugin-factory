Preview and play a Lottie animation in VS Code

Lottie Viewer & Lottie Player plays Lottie JSON (Bodymovin) and .lottie files right in VS Code, with a bundled player that works offline. You can play, pause, loop, change the speed and scrub frame by frame, and an Info panel shows the size, frame rate, duration, markers and every layer. A Lottie JSON preview opens next to the text and follows your edits as you type. All of that is free, with no account and no network calls. Steps in VS Code

  1. Install Lottie Viewer & Lottie Player from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-lottie-viewer.
  2. Click a .lottie file in the Explorer. It opens in the player.
  3. For a Lottie .json file, which opens as text, press the play button in the editor title (Open Lottie Preview to the Side). The preview follows your edits as you type. The button shows only for JSON files that look like a Lottie animation.
  4. Play and pause, turn Loop on or off, pick a speed from 0.25x to 3x, or drag the frame scrubber. Space, Left, Right, Home and End work too.
  5. Pick Fit, 50%, 100% or 200%, and a checkerboard, dark, light or editor background, so transparent parts are easy to see. Switch between the SVG and canvas player in the toolbar.
  6. Open Info for the size, frame rate, frames, duration, fonts and format version. Click a marker or a layer to jump to its frame.

What Lottie Viewer & Lottie Player handles

  • Lottie JSON (Bodymovin) files, and .lottie packages in the version 1 and version 2 layouts.
  • Several animations in one .lottie file, with a picker, and images from the package.
  • Notes for missing images next to the file, expressions, web fonts, audio and video layers and damaged files inside a package.
  • Any .json file through Open With... > Lottie Viewer, or every Lottie JSON in a folder with a workbench.editorAssociations pattern.

What it does not do

  • Expressions are not run, because the bundled player is the build without expressions. Properties driven by an expression show their keyframe values.
  • Text uses fonts installed on your computer. A font the animation loads from the web is not downloaded.
  • 3D layers are drawn flat, as in the web player, and audio and video layers are not played.
  • Themes and state machines inside a .lottie file are listed but not applied.
  • Files over 50 MB open with a message instead of the player by default (the lottieViewer.maxFileSizeMB setting).

Questions

Can VS Code play a Lottie animation without an extension?

No. VS Code opens a Lottie JSON file as text and a .lottie file as a binary file. You need an extension with a player.

Why does part of my animation not show?

Check the notes in the player: images missing next to the file, web fonts, expressions and audio or video layers are not shown. The notes list what the preview cannot show for that file.

Does it send my animation anywhere?

No. The player page may not load anything from the web, so image URLs and web fonts in a file are never fetched. Files are written only by the Pro tools, to the place you pick.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
