Make a video contact sheet

A contact sheet is one image with frames of a video in a grid. vcsi and the VCS script make them from the command line with ffmpeg. Video Preview with Sound plays MP4, MOV, MKV and WebM in VS Code for free, and its Pro tool Contact sheet saves one PNG with 16, 30 or 48 frames, each with its time and frame number, under a header with the file name, length, frame size, codecs and file size. It has 3 free tries, then Zovo Pro is USD 19 once.

Install in VS CodeMarketplace pageOpen VSX (Cursor, Windsurf, VSCodium)

Free, MIT license. Extension ID zovo.video-preview-with-sound, version 0.3.3. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install Video Preview with Sound from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.video-preview-with-sound.
  2. Click the video file in the Explorer. It plays in Video Preview with sound.
  3. Scrub through it and check that it is the right file. Playing is free.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.video-preview-with-sound and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/video-preview-with-sound.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Video Preview with Sound handles

  • 16, 30 or 48 frames.
  • Time and frame number on each frame.
  • Header with name, length, frame size, codecs and file size.

What it does not do

  • One video at a time. For a folder of videos, vcsi in a loop is quicker.

Other options

  • vcsi. A free Python command-line tool with grid, width and timestamp options.
  • VCS. A shell script that needs only ffmpeg.

Questions

Is my video uploaded?

No. Everything runs in VS Code on your computer.

Is a try used if I cancel?

No. A try is used only when a file is saved.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
