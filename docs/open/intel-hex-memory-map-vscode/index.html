See what an Intel HEX or S19 file puts in memory

Intel HEX Viewer shows what a .hex, .s19 or .srec image puts in memory. The Memory map tab lists each block with its first and last address, size and the gap before it, on a bar placed by address. Overlapping records are marked. The Hex tab shows the bytes by address with a data inspector, and every line with a bad checksum or count is listed. All of that is free. Steps in VS Code

  1. Install Intel HEX Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-intel-hex-viewer.
  2. Click a .s19, .srec, .s28, .s37, .mot, .ihex or .ihx file. It opens in the viewer.
  3. A .hex file opens as text first, because many .hex files hold other things. Click the board icon in the editor title, or right-click the file and pick Open in Intel HEX Viewer.
  4. The Overview tab shows the format, address range, data size, segments and gaps, start address, record counts and the checksum result.
  5. Open the Memory map tab to see each block by address. Click hex on a row to see its bytes.
  6. In the Hex tab, go to an address or step from segment to segment. Click a byte to read it in the data inspector as u8 to u64, i8 to i64, float or double, little or big endian.

What Intel HEX Viewer handles

  • Intel HEX record types 00 to 05, with 16, 20 and 32-bit addresses.
  • Motorola S-records S0 to S9, with the S0 header text, S5 and S6 counts and the start address.
  • Lowercase digits, CRLF or LF line ends, blank lines and a missing end record.
  • Images with gaps of gigabytes between blocks, since gaps are never filled in memory.

What it does not do

  • Plain .bin files are not read. A hex viewer opens those.
  • Text files up to 256 MB, about 6 million lines. The Problems tab keeps the first 10,000 problems.
  • No disassembly and no editing in place.

Other options

  • srec_info from SRecord. A free command-line tool that prints the address ranges of a HEX or S-record file.
  • The intelhex Python package. Free. Its hexinfo.py script prints the start, end and size of each data block.
  • objcopy and a hex viewer. Convert to a binary with objcopy, then read the bytes. You lose the addresses of the gaps.

Questions

Why does my .hex file open as text?

Many .hex files are not Intel HEX, so .hex files open as text. Click the board icon in the editor title to open the file in the viewer.

Does it check the checksums?

Yes. Every line is checked. Wrong checksums, wrong byte counts, bad hex digits and unknown record types are listed with their line numbers.

Can it read an ELF file?

No. It reads Intel HEX and Motorola S-record text files only.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
