See the image behind a base64 data URI in VS Code

VS Code shows a data:image/png;base64,... string as a long line of text. Image Preview & Image Hover decodes it and draws the picture as a thumbnail in the gutter. The hover shows it larger, with its type, pixel size and decoded size. It also works for plain SVG text in a data URI, and in an untitled tab where you paste a string. All of that is free. Zovo Pro (USD 19 once) adds a finder for unused images, a finder for broken image references and an image weight report, with 3 free tries each.

Steps in VS Code

  1. Install Image Preview & Image Hover from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-image-preview.
  2. Open the file that holds the data URI. A JavaScript string, a CSS url(), an HTML src, JSON and YAML all work.
  3. Look at the gutter. A thumbnail of the decoded image shows next to the line.
  4. Hover the data URI. The hover shows the picture, the type, the width and height in pixels and the decoded size, with a note such as "data URI, base64" and the length of the text.
  5. To check a string from a log or an API response, press Ctrl+N (Cmd+N on a Mac) for an untitled tab and paste it there with its data:image/png;base64, prefix.
  6. To turn the gutter thumbnails off or on, run "Image Preview: Show or Hide Gutter Thumbnails".

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-image-preview and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-image-preview.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Image Preview & Image Hover handles

  • Base64 data URIs, and SVG text data URIs, plain or URL-encoded.
  • PNG, JPEG, GIF, WebP, AVIF, SVG, BMP and ICO pictures inside the URI.
  • Data URIs in quotes, in CSS url() and on very long lines.
  • Saved files and untitled tabs.

What it does not do

  • Data URIs that decode to more than 1 MB are not drawn. The hover says so.
  • One thumbnail per line, for the first image on it. The hover works for each data URI on the line.
  • A base64 string without the data:image/...;base64, prefix is not recognized.
  • Remote and virtual workspaces (SSH, WSL, Codespaces, vscode.dev) are not supported in this version.

Other options

  • A web browser. Paste the whole data URI into the address bar of Firefox or Chrome to see the image. Free, outside VS Code.
  • The base64 command. On macOS and Linux, the base64 command decodes the part after the comma into an image file you can open. Free.

Questions

Does it work for SVG data URIs that are not base64?

Yes. Plain and URL-encoded SVG text after data:image/svg+xml, is drawn too.

Is the image sent anywhere?

No. It is decoded on your computer, with no network requests.

Why is there no thumbnail?

The data URI may decode to more than 1 MB, the data may not be a valid image, or another image comes first on the same line. Hover it to see which.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
