Compare two ZIP files in VS Code

Run Archive Explorer: Compare Two Archives... (Pro) in ZIP Viewer, or right-click an archive. It lists the files added, removed or changed between two ZIP, JAR, VSIX or TAR builds as a Markdown report. Browsing, opening entries, name search and extraction are free. The compare is a Zovo Pro tool with 3 free tries.

Steps in VS Code

  1. Install ZIP Viewer & Archive Explorer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zip-archive-explorer.
  2. Open the Command Palette and run Archive Explorer: Compare Two Archives... (Pro), or right-click one of the archives in the Explorer.
  3. Choose the two archives you want to compare.
  4. Read the Markdown report. It lists the files added, removed or changed, by size and CRC-32, or by the bytes when there is no CRC.
  5. The first 3 runs are free. A try counts only after the tool shows its result, so Escape or Cancel costs nothing.
  6. To look at a changed file, open each archive and double-click the entry. It opens in a normal read-only tab.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zip-archive-explorer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zip-archive-explorer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What ZIP Viewer & Archive Explorer handles

  • Compares ZIP, JAR, VSIX and TAR builds.
  • Marks each file as added, removed or changed, using size and CRC-32, or the bytes when there is no CRC.
  • Archives with up to 200,000 entries (setting archiveExplorer.maxEntries).
  • Large archives are read from disk with range reads, so a large ZIP or TAR is not loaded whole.
  • The archives themselves are never changed.

What it does not do

  • The report lists which files changed. It does not show a line-by-line diff of their content.
  • Compression methods other than Stored and Deflate (for example BZIP2, LZMA, Zstandard and Deflate64) and encrypted entries are listed but not opened.
  • 7z, RAR, XZ and BZ2 files are not supported.

Other options

  • zipcmp (libzip). Free command-line tool that compares the contents of two ZIP files. The better choice in a shell script or on a server.
  • unzip -l and diff. Free on most systems: diff <(unzip -l a.zip) <(unzip -l b.zip). It compares the file lists with sizes and dates, not the content.
  • diff -r on extracted folders. Free. Unpack both archives and run diff -r on the two folders. Use this when you need the line changes inside the files.
  • Beyond Compare. Paid desktop app that compares folders and archives side by side, with content diffs.
  • zipdiff. Free Java tool that compares two ZIP or JAR files. Often used for Java builds.

Questions

Does it work in Cursor or Windsurf?

Cursor and Windsurf install extensions from Open VSX. Search for ZIP Viewer in their Extensions view and install it there.

Are my archives uploaded?

No. The extension works offline, makes no network calls and has no telemetry.

Can I compare two JAR or VSIX files?

Yes. The compare takes ZIP, JAR, VSIX or TAR builds.

Does it show what changed inside a file?

No. The report says which files were added, removed or changed. Open the entry in each archive to read it, or extract both and use a diff tool.

Can I check a build in CI?

Yes, with the Pro tool Export the entry list. It saves every entry with size, CRC-32 and date as JSON, which a script or CI check can compare between builds.
