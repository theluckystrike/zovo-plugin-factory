Find the heaviest images in your project

Large images slow a site down, but each one looks fine on its own and VS Code shows no list of image sizes. Image Preview & Image Hover shows the file size and pixel size of one image on hover, for free. Its Image Weight Report lists every image in a folder, largest first, with totals per type. It flags files over 200 KB, images wider or taller than 2560 px, photos saved as PNG, BMP and TIFF files, and heavy SVGs. The report is part of Zovo Pro (USD 19 once), with 3 free tries on your computer.

Steps in VS Code

  1. Install Image Preview & Image Hover from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-image-preview.
  2. Open the project folder in VS Code.
  3. Right-click a folder such as public and pick "Zovo Pro: Image weight report". Or run "Image Preview: Image Weight Report (Pro)" from the Command Palette for the whole workspace folder.
  4. Read the report. A table gives the count and size per type, then the 100 largest images with size, pixels and notes.
  5. Read the notes column. It flags files over the size limit, images over the pixel limit, photo-like PNG, BMP or TIFF files with no transparency, BMP and TIFF files, SVGs over 100 KB and JPEGs saved at a very high quality.
  6. To use your own budget, change imgPreview.weightMaxKB (default 200) and imgPreview.weightMaxSide (default 2560) and run the report again.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-image-preview and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-image-preview.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Image Preview & Image Hover handles

  • PNG, JPEG, GIF, WebP, AVIF, SVG, BMP, ICO, HEIC and TIFF files, measured from their headers.
  • Totals per type, and the 100 largest images in a table. Other flagged images are listed under it.
  • Size and pixel limits that you set in the settings.
  • Folders in imgPreview.exclude, such as node_modules and dist, are skipped.

What it does not do

  • The report does not compress, resize or convert any file.
  • The photo saved as PNG flag is a guess from file size, pixel count and transparency. A large screenshot without transparency can get it too.
  • Only image files in the folder are measured. Images a page loads from a CDN are not part of the report.
  • Remote and virtual workspaces (SSH, WSL, Codespaces, vscode.dev) are not supported in this version.

Other options

  • Lighthouse. Built into Chrome DevTools. It flags images that are larger than their display size or could use a smaller format, for the page you test.
  • Squoosh. A free web app that compresses and resizes one image at a time and shows the size before and after.

Questions

Does it make my images smaller?

No. It measures and flags only. Resize or convert the flagged files in an image tool.

Can I change the 200 KB limit?

Yes. Set imgPreview.weightMaxKB for the file size and imgPreview.weightMaxSide for the longest side in pixels.

Which images count as photos saved as PNG?

PNG, BMP and TIFF files over 300 KB with more than 250,000 pixels and no transparency. JPEG or WebP is usually much smaller for those.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
