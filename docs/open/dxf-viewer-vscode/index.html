Open a DXF drawing in VS Code

DXF Viewer opens a .dxf file in VS Code as a drawing, not as text. It reads ASCII and binary DXF from R12 to AutoCAD 2018, with blocks, text, dimensions, hatches and paper space sheets, and you can hide layers, find text and measure. DWG files are not read. A .dwg opens a short page with its version and the ways to save a DXF copy. Viewing is free. Zovo Pro (USD 19 once) adds a CSV inventory of a folder of drawings, CSV export of block attributes and text, and a compare of two revisions, with 3 free tries each.

Steps in VS Code

  1. Install DXF Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.dxf-viewer.
  2. Click a .dxf file in the Explorer. It opens in DXF Viewer. The side panel lists the layers, the entity types and the drawing facts such as version, units and size.
  3. Drag to pan, scroll to zoom at the pointer, and press F or double-click to fit the drawing. B switches between a dark and a white background.
  4. If the drawing has paper space, pick a layout in the Sheet list. It shows the way it prints, with the title block and the viewports at their scale.
  5. Untick a layer in the Layers panel to hide it. Press Ctrl+F (Cmd+F on a Mac) to find text, MTEXT or block attributes, and M to measure between two points.
  6. Click Export PNG or Export SVG to save the view. When you save the DXF again from your CAD program, the open view reloads with the same zoom, sheet and layers.
  7. If you click a .dwg file, a page shows its DWG version and how to save it as DXF in AutoCAD, BricsCAD, LibreCAD, QCAD or the free ODA File Converter. Then open the .dxf.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.dxf-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/dxf-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What DXF Viewer handles

  • ASCII and binary DXF, from R12 to AutoCAD 2018.
  • Lines, arcs, circles, ellipses, polylines with bulges, splines, pattern hatches, TEXT, MTEXT, block attributes, nested blocks and dimensions.
  • Paper space layouts, with each viewport at its own scale and twist and the layers it freezes left out.
  • Big files, read in a worker thread. A 24 MB drawing with 600,000 lines loads in about one second.

What it does not do

  • DWG files are not read. Save them as DXF first.
  • 3D entities are drawn flat, as a top view, and 3DSOLID, REGION and BODY are not drawn.
  • Text uses a sans-serif font, not the SHX or TrueType font of the file, and line weights are not used.
  • Files over 500 MB are not read (setting dxfViewer.maxFileMB, up to 2048).

Other options

  • Autodesk DWG TrueView. A free Windows viewer from Autodesk that opens DWG and DXF files, outside VS Code.
  • LibreCAD. A free, open source 2D CAD program for Windows, macOS and Linux that opens and edits DXF files.
  • ODA File Converter. A free tool that converts a folder of DWG files to DXF in one go.

Questions

Can it open DWG files?

No. DWG is a closed format. A .dwg file opens a short page with its version and the steps to save a DXF copy in AutoCAD, BricsCAD, LibreCAD, QCAD or the ODA File Converter.

Can I edit the drawing?

No. The viewer is read-only. The only files it writes are the PNG, SVG or CSV exports you pick, and it refuses to write over a drawing.

Do I need AutoCAD?

No. The extension reads the DXF file itself, with no CAD program installed.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
