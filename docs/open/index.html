Open files in VS Code and Cursor

VS Code and the editors built on it (Cursor, Windsurf, VSCodium) open text files, images and some media. For Word, Excel, Parquet, SQLite, NetCDF, PDF and many other formats you need an extension. Each guide below gives the steps for VS Code and for Cursor, says what the extension can and cannot do, and names the other options.

Office files

  • Open a .docx Word file in VS Code. VS Code shows a .docx as binary. Install a free viewer and the Word file opens as a read-only preview with search, outline and dark mode. Works in Cursor too.
  • View a PowerPoint .pptx file in VS Code. Open .pptx and .ppt decks in VS Code with slide thumbnails, speaker notes, search and full-screen present. No LibreOffice, no upload. Free and offline.
  • Read PDFs in dark mode in VS Code. Turn on dark pages for PDFs in VS Code without turning photos into negatives. Toggle per file or set it in settings. Works with LaTeX and Typst rebuilds.
  • Open a PDF in Cursor. Cursor ships no PDF viewer. Install a free one from Open VSX to read PDFs with search, dark pages and highlights, then copy highlights as Markdown into chat.
  • Open a PDF file in VS Code. VS Code cannot display a PDF by itself. Install a free PDF viewer and the file opens in a tab with search, an outline, page thumbnails, zoom and go to page. Offline.
  • Compare two Word documents. Compare two versions of a Word document, or a .docx with its last Git commit, as a redline in VS Code. Free, offline, nothing uploaded.
  • Make a redline of two DOCX files. Make a redline of two .docx versions in VS Code and export it as a Word document with real tracked changes that can be accepted or rejected.
  • Extract pages from a PDF without uploading it. Extract, delete, split and merge PDF pages inside VS Code, on your computer, with the PDF viewer you already read papers and specs in.
  • Turn PPTX slides into PNG images. Save one slide or every slide of a .pptx as PNG, or the whole deck as one PDF, inside VS Code. No PowerPoint, no LibreOffice, no upload.
  • MBOX to EML in VS Code, one file per message. Split an .mbox file into one .eml file per message in VS Code, offline. Read the mailbox for free, then run the split as a Zovo Pro tool.
  • Merge PDF files in VS Code, offline. Merge PDF files inside VS Code on your own computer. Open a PDF, pick the other files and save one new PDF. Reading stays free; merge is a Zovo Pro tool.
  • DOCX to Markdown in VS Code. Turn a Word .docx into Markdown in VS Code for free with Copy as Markdown, or convert a whole folder of Word, PowerPoint and Excel files offline.
  • Export Word track changes to Excel. Get every change between two versions of a Word document as an Excel list: section, paragraph, old text and new text. Offline, in VS Code, no VBA macro.
  • Compress a PPTX file without uploading it. Reduce a PowerPoint file size on your computer: shrink oversized photos to Screen, Email or Print size and drop unused media. The original deck is never changed.
  • Compare two PDF files for differences. See every text change between two PDFs: deleted words in red, new words in green, moved text in blue, page by page. Offline in VS Code, with a CSV change list.
  • Extract highlights from a PDF. Highlight a PDF in VS Code and copy every highlight as Markdown with a link to its page, free. Zovo Pro puts the highlights of all your PDFs in one file.
  • Open Word and PowerPoint files without Office. Read .docx, .odt and old .doc files and view .pptx decks in VS Code or Cursor, with no Office, no LibreOffice and no upload. Two free extensions.
  • Check SPF, DKIM and DMARC of a suspicious email. Open a saved .eml or .mbox in VS Code and see the SPF, DKIM and DMARC results the receiving server recorded, and the Received hops. Free, offline.
  • Convert a PDF, Word, PowerPoint or Excel file to Markdown in VS Code. Right-click a PDF, DOCX, PPTX, XLSX, CSV, HTML or EPUB file in VS Code and get clean Markdown beside it. Free, offline, no Python and no upload.
  • Edit a Word document in VS Code. VS Code shows a .docx as binary. DOCX Editor lets you type into it and saves only the changed paragraphs, so pictures and tracked changes stay. Free.
  • Convert a PDF or Word file to Markdown and keep the images. Most PDF and Word to Markdown converters drop the pictures. Save them to an assets folder next to the .md, linked with relative paths, in VS Code.
  • Show PPTX slides in a web page with JavaScript. Show PowerPoint PPTX slides in your web page with one script tag from jsDelivr. The browser reads the file, so it is never uploaded. Free under GPL-3.0.
