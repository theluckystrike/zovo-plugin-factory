Open files in VS Code and Cursor

VS Code and the editors built on it (Cursor, Windsurf, VSCodium) open text files, images and some media. For Word, Excel, Parquet, SQLite, NetCDF, PDF and many other formats you need an extension. Each guide below gives the steps for VS Code and for Cursor, says what the extension can and cannot do, and names the other options.

Office files

  • Open a .docx Word file in VS Code. VS Code shows a .docx as binary. Install a free viewer and the Word file opens as a read-only preview with search, outline and dark mode. Works in Cursor too.
  • View a PowerPoint .pptx file in VS Code. Open .pptx and .ppt decks in VS Code with slide thumbnails, speaker notes, search and full-screen present. No LibreOffice, no upload. Free and offline.
  • Read PDFs in dark mode in VS Code. Turn on dark pages for PDFs in VS Code without turning photos into negatives. Toggle per file or set it in settings. Works with LaTeX and Typst rebuilds.
  • Open a PDF in Cursor. Cursor ships no PDF viewer. Install a free one from Open VSX to read PDFs with search, dark pages and highlights, then copy highlights as Markdown into chat.
  • Open a PDF file in VS Code. VS Code cannot display a PDF by itself. Install a free PDF viewer and the file opens in a tab with search, an outline, page thumbnails, zoom and go to page. Offline.
  • Compare two Word documents. Compare two versions of a Word document, or a .docx with its last Git commit, as a redline in VS Code. Free, offline, nothing uploaded.
  • Make a redline of two DOCX files. Make a redline of two .docx versions in VS Code and export it as a Word document with real tracked changes that can be accepted or rejected.

Tables and data

  • Open an Excel .xlsx file in VS Code. VS Code cannot show .xlsx files by itself. A free extension opens xlsx, xls and ods workbooks as a sortable, filterable table with the sheet picker and number formats.
  • Open an Excel file in Cursor. Cursor gets extensions from Open VSX, not the VS Code Marketplace, so some Excel tools are missing. Table Viewer is there and opens xlsx, xls, ods, CSV and Parquet.
  • See a CSV file as a table in VS Code. Three free ways to read CSV in VS Code: color the columns, edit in a grid, or open a read-only sortable table that handles 1,000,000 rows. Steps and honest limits.
  • Open a Parquet file in VS Code. Open .parquet files in VS Code as a sortable table with column types and the full schema. No Python, pandas or kernel. Free, offline, also in Cursor via Open VSX.
  • Open a SQLite database in VS Code. Open .db, .sqlite and .sqlite3 files in VS Code as tables, with the rows still in the WAL file, a schema tab and read-only SQL. Free, no paywall, also on Open VSX.
  • Use a PostgreSQL client in VS Code. Connect VS Code to PostgreSQL, run SQL with Ctrl+Enter, browse tables and edit rows with a free extension. Unlimited connections and no subscription.
  • Use a MySQL client in VS Code. Connect VS Code to MySQL or MariaDB, run queries, edit rows after you see the exact SQL, and export millions of rows, with a free extension.
  • Use a Parquet viewer in VS Code. Open .parquet files in VS Code as a sortable grid with the schema, nested columns and exact decimals. It reads only the footer to open. Free, no Python.
  • See an ER diagram of your database in VS Code. Draw an ER diagram of a live PostgreSQL, MySQL, MariaDB or SQLite schema in VS Code, with tables, keys and foreign-key links, and save it as SVG.
  • Compare two Postgres schemas. Compare the schema of two PostgreSQL or MySQL databases side by side in VS Code's diff view: tables, columns, types, keys and foreign keys.
  • Query Excel with SQL. Run SQL with GROUP BY and JOIN on Excel, CSV and Parquet files in VS Code, with no database, no Python and no upload. Free.
  • Query a Parquet file in VS Code. Run SQL with GROUP BY and JOIN on Parquet files in VS Code. Row groups are skipped by their statistics. No Python, no DuckDB install. Free.
  • View a large CSV file. Open a large CSV file in VS Code as a table, up to 1,000,000 rows and 512 MB, then sort, filter and export it with a free extension. No Excel row limit.

Science data

  • A free NetCDF viewer that runs in VS Code. View .nc files on Windows, macOS or Linux: variable tree, header like ncdump -h, maps with coastlines, a time slider and point time series. No Python or NCL.
  • Open an HDF5 (.h5) file in VS Code. Browse .h5 and .hdf5 groups and datasets in VS Code, with tables, heatmaps, stats and compressed filters, without h5py or Python. Free, also on Open VSX for Cursor.

Machine learning files

  • View .npy and .npz NumPy files in VS Code. Open .npy and .npz arrays in VS Code: shape, dtype, stats, heatmaps, plots and images, without Python. Pickled object arrays are refused, not run.
  • A safetensors viewer for VS Code. List every tensor in a .safetensors file with dtype and shape, then click one for stats and a heatmap. Reads only the header first. Also GGUF and PyTorch files.
  • Open a .pkl pickle file in VS Code without running it. View .pkl and .pickle files in VS Code as a tree, NumPy arrays and pandas tables, without Python and without running the pickle. A Safety tab flags risky calls.
  • View a JSONL file as a table in VS Code. Open .jsonl, .ndjson and .jsonl.gz files in VS Code as a table, a record tree or chat bubbles for fine-tuning data. Filter, sort and export. Files up to 4 GB.
  • Open a .npz file in VS Code. See every array in a NumPy .npz archive in VS Code, with name, dtype, shape, stats, plots and values. Compressed npz files from np.savez_compressed work too. No Python.

3D and imaging

  • View STL files in VS Code. Open STL, OBJ, PLY, 3MF, GLB and glTF models in VS Code. Orbit, measure distances, see wireframe and normals, and save a PNG. Free, offline, 344 KB.
  • Open DICOM and NIfTI files in VS Code. View .dcm, DICOMDIR and NIfTI (.nii, .nii.gz) files in VS Code with CT window presets, axial, coronal and sagittal views, HU values and a tag table. Offline.

Binary, network and hardware

  • Use a hex editor in VS Code. VS Code has no hex editor built in. A free extension opens 4 GB files in under a second, edits, inserts and deletes bytes with undo, and compares two files.
  • Open a binary file in VS Code. VS Code will not show a binary file in the text editor. Open it as hex instead, to read the bytes, find values and check headers, with a free extension.
  • Open a PCAP file in VS Code. Read .pcap and .pcapng captures in VS Code with a packet list, protocol tree, hex pane, display filters and follow TCP stream. No Wireshark or tshark needed.
  • View VCD waveforms in VS Code. Open .vcd files from Icarus Verilog, Verilator, Vivado, ModelSim or GHDL as waveforms in VS Code, with markers, buses, radix and no limit on signals. Free, offline.
  • Analyze a linker map file in VS Code. Open a GNU ld, LLVM lld, IAR or Keil .map file in VS Code: memory region bars, the biggest object files and symbols, a treemap and a compare of two builds.
  • Read binary files with templates in a VS Code hex editor. A hex editor template turns raw bytes into named fields. Hex Viewer for VS Code has 20 built-in binary templates and reads your own JSON templates.
  • A 010 Editor alternative inside VS Code. What a VS Code hex editor can replace from 010 Editor, and what it cannot: large files, insert and delete, compare, binary templates, checksums.
  • Compare binary files in VS Code. Compare two binary files side by side in hex, jump to each difference with F7, and count every differing byte, with a free VS Code extension.

Code and APIs

  • Open a SARIF file in VS Code. Read .sarif logs from CodeQL, Semgrep, ESLint, Trivy and other scanners in VS Code. Paths from CI open the right file, with baseline filters and code flows.
  • Preview a Swagger or OpenAPI file in VS Code. See a live Swagger UI preview of an OpenAPI 3.1, 3.0 or Swagger 2.0 file in VS Code, in YAML or JSON. External $ref files work, and problems show with line numbers.
  • Preview an HTML file with its CSS and images in VS Code. See an HTML page beside its code in VS Code, with linked CSS, scripts and images. It updates as you type, needs no local server and loads nothing from the web.
  • Test a regex in VS Code. Click Test regex above a regex in your code and test it on your own text beside the editor, with groups, a replace preview, a railroad diagram and flavor warnings.
  • Take a screenshot of code in VS Code. Select code, press one key, and a PNG of it is on your clipboard, drawn with your own theme, font and bracket colors. Save PNG or SVG. Works offline with no website.
  • Auto rename HTML tags in VS Code. Change an opening tag and the closing tag follows. The built-in linked editing setting, and a free extension for JSX, Vue, PHP and Blade that also closes tags.
  • Get CSS class name completion in VS Code. Complete class names and ids from your own CSS, SCSS and Less files in HTML, JSX, Vue, Svelte, PHP and Blade, with hover and Go to Definition. Free.
  • Format SQL in VS Code. VS Code has no SQL formatter built in. A free extension formats SQL in 20 dialects, keeps $$ bodies and comments, and leaves the file alone if it cannot.

Docs and diagrams

  • Preview a reStructuredText (.rst) file in VS Code. See a .rst file rendered beside the editor as you type, with no Python, docutils or Sphinx. Tables, admonitions, math and code colors work, and errors show in Problems.
  • Read an RTF file in VS Code. VS Code shows an .rtf file as raw control words. A free viewer opens it as a read-only page with tables, pictures, search, an outline and dark mode. Offline.
  • Preview Mermaid diagrams in VS Code. Preview .mmd files and mermaid blocks in Markdown in VS Code, with zoom, pan and SVG or PNG export. Mermaid 12 is bundled, so it works offline with no sign-in.
  • Preview an SVG file in VS Code. Preview an SVG beside its code in VS Code with zoom at the pointer, a background you pick, a viewBox outline and PNG export at 1x to 8x. Scripts in the SVG never run.

Developer files

  • Read a HAR file offline in VS Code. HAR captures hold cookies and tokens. Open them offline in VS Code with a request table, timing waterfall and filters, and save a redacted copy before you share.
  • Read your Claude Code history in VS Code. Claude Code keeps every session as a JSONL file. Browse them by project in VS Code, read each as a transcript with diffs and tokens, search all of them, and resume.
