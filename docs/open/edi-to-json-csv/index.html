Convert an EDI file to JSON or CSV

EDI Viewer saves an X12 or EDIFACT file as JSON or CSV in VS Code. The JSON is a tree per transaction, with the name, value and code meaning of every element. The CSV has one row per line item for 850, 855, 810, 856, ORDERS, ORDRSP, INVOIC and DESADV, and one row per segment for other types. Export is a Zovo Pro tool (USD 19 once) with 3 free tries. Reading the file as a tree is free.

Steps in VS Code

  1. Install EDI Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-edi-viewer.
  2. Open the file in EDI Viewer. Click Open in EDI Viewer in the editor title bar, or right-click the file in the Explorer.
  3. Look at the Problems tab first. The export uses the same reader, and the JSON lists the first 1,000 problems.
  4. Click Export at the top and pick As JSON or As CSV. From the Command Palette, run "EDI Viewer: Export EDI to JSON (Pro)" or "EDI Viewer: Export EDI to CSV (Pro)".
  5. Pick where to save. The new file opens beside the viewer.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-edi-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-edi-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What EDI Viewer handles

  • X12 and EDIFACT, with the separators read from the file.
  • CSV line items for 850, 855, 810, 856, ORDERS, ORDRSP, INVOIC and DESADV.
  • One CSV row per segment for every other transaction set or message.
  • Values that start with = + - or @ get a leading apostrophe in the CSV, so a spreadsheet does not run them as formulas.

What it does not do

  • The CSV has line items only when every transaction in the file is one of the line item types. A mixed file gets one row per segment.
  • It exports one file at a time, not a whole folder.
  • Files up to 64 MB are read.
  • It exports to JSON and CSV only. It does not write EDI from JSON.

Other options

  • node-x12. A free JavaScript library that parses X12 into objects you can save as JSON from your own code.
  • pydifact. A free Python library that reads EDIFACT messages into segments.
  • EDI translation services. Paid services and APIs turn EDI into JSON and back, with mapping. The file goes to their servers.

Questions

Is the export free?

It is a Zovo Pro tool with 3 free tries on your computer. A try counts only when the file is written. Reading the file is free.

What is in the JSON?

The standard, version, separators and a summary, the problems, and a tree of interchanges, groups, transactions, loops and segments. Each element has its value, and its name and code meaning when the viewer knows them.

Can it turn JSON or CSV back into EDI?

No. It exports from EDI only.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
