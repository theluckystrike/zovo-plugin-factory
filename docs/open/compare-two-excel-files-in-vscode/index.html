Compare two Excel or CSV files in VS Code

Excel Compare & XLSX Diff compares two workbooks or CSV files in VS Code cell by cell. Changed cells show in yellow with the old value struck through, added rows in green and removed rows in red. Rows are lined up and columns are matched by their header, so one inserted row or column shows as one change, and you can compare a workbook with its Git HEAD version before you commit. All of that is free, with no network requests. Zovo Pro (USD 19 once) adds a diff report as XLSX, HTML or CSV, row matching by key columns, and folder comparison, with 3 free tries each.

Steps in VS Code

  1. Install Excel Compare & XLSX Diff from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-excel-compare.
  2. Select two files in the Explorer, right-click and pick Compare Selected Excel Files. Or right-click one file, pick Compare with... and choose the other.
  3. Any mix of .xlsx, .xlsm, .xls, .ods, .csv and .tsv works, so you can compare an .xlsx with a .csv.
  4. Read the summary line, then the tab of each sheet with its number of differences. Click a cell to see its full old and new value and copy them.
  5. Press N and P (or Next and Previous) to jump through every change across sheets. Switch between Values and Formulas to compare what the cells show or the formulas themselves.
  6. To see what you changed before a commit, right-click a workbook in a Git repository and pick Compare with Git HEAD.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-excel-compare and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-excel-compare.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Excel Compare & XLSX Diff handles

  • Sheets matched by name, then by position. Sheets that exist in only one file are listed as added or removed.
  • CSV and TSV with the encoding detected (UTF-8 with or without BOM, UTF-16, Windows code pages) and the delimiter detected (comma, semicolon, tab or pipe), including quoted fields with line breaks.
  • Big sheets: the grid draws only the rows on screen, so a sheet with 300,000 rows scrolls like a short one.
  • Notes when merged cells differ or when a limit cut a sheet.

What it does not do

  • Files up to 200 MB (setting excelCompare.maxFileSizeMB), 300,000 rows per sheet (excelCompare.maxRows), 1,000 columns and 200 sheets. A note in the view says when a limit applied.
  • A workbook that would inflate to more than 600 MB, or is compressed like a zip bomb, is refused before it is unpacked.
  • Rows are compared by position after alignment. Matching rows by an ID column is the Pro tool Match rows by key columns.

Questions

Can VS Code compare two Excel files without an extension?

No. An .xlsx file is a zip of XML parts, so the built-in diff shows it as binary. You need an extension that reads the workbook.

Does a row inserted at the top mark every row below as changed?

No. Rows are lined up before they are compared, so an inserted row shows as one added row.

Can I see what changed in a workbook since my last commit?

Yes. Right-click the file in a Git repository and pick Compare with Git HEAD. It runs your local git.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
