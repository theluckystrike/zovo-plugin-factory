Open files in VS Code and Cursor / 3D and imaging

Crop an image in VS Code

The image preview in VS Code only shows images. Image Editor adds an Edit Image button to that preview. Click Crop, drag a box or type X, Y, W and H in pixels, pick a ratio if you want one, press Enter, then save with Ctrl+S (Cmd+S) or save a copy. Cropping and saving are free for PNG, JPEG, WebP, GIF and BMP. Zovo Pro (USD 19 once) adds Compress to a target size, which makes an image fit a size such as 200 KB, with 3 free tries.

Steps in VS Code

  1. Install Image Editor from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-image-editor.
  2. Open the image and click Edit Image at the top right of the preview. You can also right-click a .png, .jpg, .webp, .gif or .bmp file in the Explorer and pick Edit Image.
  3. Click Crop in the toolbar, or press C. In the crop bar, pick Free, 1:1, 4:3, 3:2, 16:9, 9:16 or a custom ratio such as 5:4.
  4. Drag a box on the image, or type X, Y, W and H in pixels. Press Enter or click Apply crop. Cancel leaves the image as it was.
  5. If you need to, turn the image with the 90° and 180° buttons, mirror it with Flip, or use Straighten for a small angle.
  6. Press Ctrl+S (Cmd+S) to save over the file in the same format. To keep the original, run "Image Editor: Save a copy as PNG, JPEG, WebP or BMP" instead.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-image-editor and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-image-editor.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Image Editor handles

  • PNG, JPEG, WebP and BMP, and the first frame of a GIF.
  • Phone photos the right way up, because the EXIF orientation is applied before you edit.
  • Images up to 100 megapixels and 32,767 pixels on a side.
  • Undo, Redo, Save and Revert, as in any VS Code editor.

What it does not do

  • TIFF, HEIC, AVIF and SVG files do not open in this editor.
  • A GIF opens at its first frame and is saved as a PNG next to it. The GIF itself is not changed.
  • Save writes pixels only. EXIF data such as the camera or the GPS location is not copied into the saved file.
  • Saving a JPEG or WebP encodes it again at the quality in the settings (92 for JPEG and 90 for WebP by default).

Other options

  • Your system photo app. Preview on macOS and Photos on Windows can crop an image, outside VS Code.
  • ImageMagick. Free command line. magick in.png -crop 800x600+100+50 +repage out.png crops by pixel values, good for scripts.

Questions

Can I crop to an exact size in pixels?

Yes. Type W and H in the crop bar, and X and Y for the top left corner, then press Enter.

Does saving keep the EXIF data?

No. Save writes only the pixels, so the camera data and GPS location are not in the saved file.

Does it upload my image?

No. The extension makes no network calls and has no telemetry. Everything runs inside VS Code.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
