See where Codex stops reading a long AGENTS.md

Codex reads at most 32 KiB of AGENTS.md text by default (the project_doc_max_bytes setting) and stops adding instructions at that size, so rules near the end of a long file never reach the model. Context Drift flags an AGENTS.md or AGENTS.override.md over 32 KiB in VS Code with one warning on the line where Codex stops. The message gives the file size and how much is cut. Zovo Pro (USD 19 once) adds a Drift Report with a size table of every instruction file, plus two more tools, with 3 free tries each.

Steps in VS Code

  1. Install Context Drift from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.context-drift.
  2. Open the repo in VS Code. Context Drift checks every AGENTS.md when the folder opens and when you edit or save one.
  3. Look for the warning with the rule id CD008 in the Problems panel and click it. The cursor goes to the line where Codex stops reading.
  4. Move the rules that matter most above that line, and cut or merge the rest.
  5. Or move parts into AGENTS.md files in subfolders, which Codex reads only when it works there. You can also raise project_doc_max_bytes in ~/.codex/config.toml.
  6. Save the file. The warning goes away once the file is 32 KiB or smaller.

What Context Drift handles

  • AGENTS.md and AGENTS.override.md files at any level of the repo.
  • Files with Windows (CRLF) line endings, where each line ending counts as 2 bytes.
  • Stale commands, paths, package managers and versions in the same files.

What it does not do

  • It checks one file at a time. Codex also counts the AGENTS.md files above the current folder toward the same 32 KiB, so a smaller file can still be cut.
  • It assumes the default limit. If you raised project_doc_max_bytes, the warning still uses 32 KiB. Turn the rule off with contextDrift.ignoreRules.
  • Files over 1 MB are not checked.

Other options

  • Codex config. Raise project_doc_max_bytes in ~/.codex/config.toml so Codex reads more of the file. Every session then carries the longer text.
  • A size check by hand. Look at the file size in your file manager or with wc -c AGENTS.md. It tells you that the file is too long, not where Codex stops.

Questions

Does Codex warn me when it cuts AGENTS.md?

No. It stops adding instructions at the limit and goes on without a message.

Do parent AGENTS.md files count?

Yes. Codex counts the AGENTS.md files above the current folder toward the same 32 KiB. Context Drift checks each file on its own, so keep some room.

Is 32 KiB the same as 32,000 characters?

No. It is 32,768 bytes. Letters outside English and emoji take more than one byte each.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
