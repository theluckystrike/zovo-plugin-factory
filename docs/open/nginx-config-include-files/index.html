See every nginx server and location across include files

An nginx config is often split into nginx.conf, conf.d and sites-enabled, so no single file shows which servers and locations exist. On the server, nginx -T prints all of it as text. In VS Code, the free config overview of Nginx Config Formatter & Lint reads a file with its includes and lists every server with its ports and names, every location with what it does, and every upstream, with a link to each line. Steps in VS Code

  1. Install Nginx Config Formatter & Lint from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-nginx-config.
  2. Open the main nginx.conf. Files named nginx.conf or *.nginx, and files in a folder whose name contains nginx, open as nginx. For any other file, pick "nginx" as the language mode.
  3. Click the overview button in the editor title, or run "Nginx: Show Config Overview". You can also right-click a .conf file in the Explorer.
  4. Read the Servers list. Each server shows its names and listen ports, with ssl and default_server marked, and its locations with modifier, path and what they do.
  5. Click a file and line link to open that spot. The Files list shows every file that was read and how many syntax problems each has.
  6. Check the note at the top. It names includes that matched no file and include loops. If your config is a copy outside /etc/nginx, set nginxConfig.prefix to its folder.

What Nginx Config Formatter & Lint handles

  • include with absolute paths, relative paths and patterns such as conf.d/*.conf, expanded in sorted order like nginx does.
  • Servers, nested locations, upstreams and stream servers.
  • Includes that match no file and include loops, which are reported.

What it does not do

  • Up to 500 files, 20 levels of include and 16 MB per file are read.
  • Relative includes are looked up in nginxConfig.prefix, the file's folder, its parent and then the usual nginx folders such as /etc/nginx. A config in another place needs the prefix setting.
  • The overview lists servers and locations. It does not show the merged config text that nginx -T prints.

Other options

  • nginx -T. On the server, nginx -T tests the config and prints every file it read. Needs nginx and access to the machine.
  • crossplane. A free Python tool by NGINX that parses a config with its includes into JSON.

Questions

Do I need nginx installed?

No. The extension reads the files itself. It never runs nginx.

Why does it say an include matched no file?

The path was not found from the folders it tries. Set nginxConfig.prefix to the folder where your nginx.conf is.

Can I open a site file on its own?

Yes. The overview then shows the servers and locations of that file and its own includes.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
