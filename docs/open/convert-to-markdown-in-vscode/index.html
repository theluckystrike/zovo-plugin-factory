Convert a PDF, Word, PowerPoint or Excel file to Markdown in VS Code

Convert to Markdown turns a PDF, Word, PowerPoint, Excel, CSV, HTML, EPUB, ODT or RTF file into Markdown inside VS Code. Right-click the file in the Explorer and pick Convert to Markdown: the Markdown opens beside it, with headings, lists, tables, links and slide notes. It needs no Python, no server and no command-line tool, and nothing leaves your computer. Converting single files is free with no limit. Zovo Pro (USD 19 once) adds whole-folder conversion, image extraction and LLM-ready chunks, with 3 free tries each.

Steps in VS Code

  1. Install Convert to Markdown from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-convert-to-markdown.
  2. In the Explorer, right-click a .pdf, .docx, .pptx, .xlsx, .xls, .ods, .csv, .html, .epub, .odt or .rtf file and pick Convert to Markdown. You can also right-click the tab of an open file.
  3. The Markdown opens beside the file as an unsaved document. Big files show progress with a Cancel button.
  4. Press Save. The file name name.md next to the source is filled in for you. To skip this step every time, set toMarkdown.output to file and the Markdown is saved next to the source at once.
  5. To paste the result somewhere else instead, right-click the file and pick Copy as Markdown. Select several files in the Explorer to convert them one after the other.
  6. No file at hand? Run "Convert to Markdown: Convert a sample file" from the Command Palette to convert a bundled Word, PDF or PowerPoint sample.

What Convert to Markdown handles

  • PDF: headings from the font sizes, paragraphs with broken lines and hyphenated words joined, lists, simple tables, two-column pages read column by column. Running headers, footers and page numbers are dropped.
  • Word (.docx, .docm, .dotx): headings, bold, italic, strikethrough, links, nested lists, tables, block quotes and footnotes.
  • PowerPoint (.pptx, .pptm, .ppsx, .potx): one ## Slide n: title section per slide, bullets with their levels, tables and the speaker notes.
  • Excel and other sheets (.xlsx, .xlsm, .xlsb, .xls, .ods): one ## Sheet: name section with a pipe table per sheet. CSV and TSV become one table.
  • HTML (code blocks keep their language, scripts and styles are dropped) and EPUB (each chapter in reading order).
  • Each file is converted in a worker thread with a memory cap and Cancel, so a damaged or huge file cannot freeze VS Code.

What it does not do

  • Scanned PDFs (pictures of pages) have no text to convert. Text recognition (OCR) is not included.
  • PDF tables are found from the gaps between columns. Tables without clear gaps come out as paragraphs.
  • Images become placeholders such as *[Image: Map of the site]* in the free conversion. Charts, SmartArt and video in slides are named, not converted.
  • Old Word 97-2003 files and RTF give text and tables without formatting. Password-protected files and old PowerPoint 97-2003 files get a message instead.
  • Files over 200 MB are not converted (setting toMarkdown.maxFileSizeMB), and a PDF stops after 1,000 pages (setting toMarkdown.pdfMaxPages).

Questions

Can VS Code convert a PDF or Word file to Markdown without an extension?

No. VS Code opens a PDF or a .docx as a binary file. You need an extension such as Convert to Markdown, or a separate command-line tool.

Does it upload my files?

No. The converters run on your computer, inside VS Code, with no network calls and no telemetry.

Does it convert scanned PDFs?

No. A scanned PDF holds pictures of pages, not text, and Convert to Markdown has no OCR.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
