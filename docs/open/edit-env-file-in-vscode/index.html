Steps in VS Code

  1. Install Dotenv & .env File Editor from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-dotenv.
  2. Open a .env file (also .env.local, .env.production, *.env or .flaskenv). Keys, values, export, multi-line values and ${NAME} references get colors.
  3. Secret-looking values show as dots until the cursor is on their line. Click the eye button in the editor title, or run "Dotenv: Show or Hide Secret Values", to show them all. Templates such as .env.example are never hidden.
  4. Problems show in the Problems panel: a key set twice, spaces around =, a quote that never closes, a line with no =, an invalid name, or a ${NAME} that no line sets. Press Ctrl+. (Cmd+. on macOS) on one for its fix.
  5. Run Format Document to remove spaces around = and trailing spaces. Comments, order and quotes stay as they are.
  6. In your code, hover process.env.DB_HOST, os.getenv("X"), System.getenv("X") and similar to see which .env file sets it, and press F12 to open that line.

What Dotenv & .env File Editor handles

  • Code hovers in JavaScript and TypeScript (process.env, import.meta.env), Python (os.environ, os.getenv), Go, Ruby, Java, PHP (env("X")) and more.
  • Completion of the keys after process.env..
  • Which names count as secrets: PASSWORD, TOKEN, SECRET, API_KEY, DSN, DATABASE_URL and similar, or every value or none (setting envFile.maskValues).
  • Hidden values stay hidden in the outline, hovers and completions unless you turn that off.

What it does not do

  • Hiding is for the screen only. The text is still in the file, in search results and in the minimap shape, and copy and paste copy the real value.
  • .envrc (direnv) is a shell script and is left to shell extensions.
  • The code report sees literal names such as process.env.API_KEY. Names built at run time are not found.
  • Problems follow the rules of the dotenv package. A few tools (Docker Compose v1, systemd) are stricter, which is what the warnings point out.

Other options

  • DotENV (mikestead.dotenv, 8.5 million installs, on Open VSX). Its own description: "Support for dotenv file syntax".
  • A .gitignore line. Add .env to .gitignore so the file never reaches the repository. It does not hide the values on your screen.

Questions

Can VS Code hide the values in a .env file?

Not on its own. VS Code shows .env files as plain text. This extension hides secret-looking values on screen until the cursor is on their line, and leaves the file unchanged.

Does it send my .env file anywhere?

No. It makes no network requests and has no telemetry. The files are read on your computer only.

Why is my key marked as set twice?

The same key appears on two lines, so only one of the two values is used. The quick fix removes the second line.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
