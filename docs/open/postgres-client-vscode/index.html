Use a PostgreSQL client in VS Code

VS Code cannot connect to a database on its own. Install the free Postgres & MySQL Query Client by Zovo, click Add Connection in its view and paste a URL such as postgres://me@localhost:5432/shop. Then press Ctrl+Enter (Cmd+Enter on macOS) in a .sql file to run a query. Connections are unlimited, editing rows is free, and there is no subscription.

Steps in VS Code

  1. Install Postgres & MySQL Query Client from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-sql-client.
  2. Open the SQL Client view in the activity bar and click Add Connection.
  3. Paste a postgres:// URL, or fill in host, port, user, database and SSL mode. Click Test connection, then Save. The password goes to VS Code's secret storage.
  4. Click New Query on the connection, type SQL and press Ctrl+Enter to run the statement at the cursor. Ctrl+Alt+Enter runs the whole file.
  5. Click a table to browse it. Double-click a cell to edit it. Review shows the exact UPDATE, and it runs in one transaction.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-sql-client and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-sql-client.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Postgres & MySQL Query Client handles

  • PostgreSQL with every SSL mode from disable to verify-full, and an optional CA file. MySQL, MariaDB and SQLite files too.
  • A Database Explorer with schemas, tables, views, columns with types and keys, indexes and estimated row counts. Each level loads when you open it.
  • A results grid that loads 1,000 rows at a time. When not every row is loaded, sort and filter run on the server, so a 5,000,000-row table sorts correctly.
  • Cancel stops the running statement on the server with pg_cancel_backend.
  • Export a result or a whole table to CSV, JSON or SQL INSERT, streamed to the file. 5,000,000 rows took 5.3 seconds in the release test.
  • A read-only switch per connection that the server enforces, and a question before an UPDATE or DELETE without WHERE.

What it does not do

  • PostgreSQL, MySQL, MariaDB and SQLite only. No SQL Server, Oracle, MongoDB or Redis.
  • A table without a primary key is read-only in the grid, and the grid says why.
  • SQLite files are read into memory, up to 512 MB by default.
  • The ER diagram, schema compare, CSV import and query library are Zovo Pro tools, with 3 free tries each. Everything else on this page is free.

Questions

Is there a free PostgreSQL client for VS Code?

Yes. Postgres & MySQL Query Client is free, with unlimited connections, row editing and export. The PostgreSQL extension from Microsoft and SQLTools are free too.

Does it keep a connection busy while I am idle?

No. It runs no keep-alive or polling query. In the release test the PostgreSQL log showed 0 statements in 60 idle seconds while connections were open.

Where is my password stored?

In VS Code's secret storage, which uses the system keychain. Never in settings or logs.
