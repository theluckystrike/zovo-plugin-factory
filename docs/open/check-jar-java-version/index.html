Check which Java version a JAR was compiled for

An UnsupportedClassVersionError means a class was compiled for a newer Java than the one that runs it. Class file version 52 is Java 8, 55 is Java 11, 61 is Java 17 and 65 is Java 21. JAR Viewer opens the .jar in VS Code and shows the highest Java version and a chart of how many classes target each one, and the version of every class. No JDK is needed for this. Zovo Pro (USD 19 once) adds a compare of two JARs that shows Java version changes, with 3 free tries.

Steps in VS Code

  1. Install JAR Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-jar-viewer.
  2. Click the .jar file in the Explorer. It opens in JAR Viewer. .war, .ear, .aar and .class files open too.
  3. Read the title line, such as 224 classes · up to Java 9, and the Overview. It shows Highest Java version, a Java versions chart with the number of classes for each version, Created by and Multi-release.
  4. Look at the package tree. Each class has a badge such as J8 or J17, so you can find the classes that need the newer Java.
  5. Click a class and open Class info. The Java version row shows the exact class file version, such as Java 17 (class file 61.0).
  6. For a Spring Boot JAR or a WAR, open a JAR in BOOT-INF/lib or WEB-INF/lib to check your dependencies the same way.

What JAR Viewer handles

  • Class file versions from Java 1.0 to the newest releases, and classes compiled with preview features.
  • Multi-release JARs, with the classes under META-INF/versions.
  • .jar, .war, .ear, .aar and single .class files.
  • Nested JARs in BOOT-INF/lib, WEB-INF/lib and the classes.jar of an AAR, one level deep.

What it does not do

  • The Overview reads the Java version of up to 50,000 classes.
  • A multi-release JAR keeps classes for newer Java under META-INF/versions, so its highest version can be newer than the Java it needs at least.
  • Nested archives open one level deep.
  • Archives can have up to 200,000 entries.

Other options

  • javap. Comes with the JDK. javap -v -cp app.jar com.example.Main prints the major version of one class.
  • file. On macOS and Linux, file Main.class prints "compiled Java class data, version 61.0" for a class you unzipped.

Questions

What does "class file version 61.0" in an error mean?

The class was compiled for Java 17. Subtract 44 from the major version to get the Java release, so 52 is Java 8, 55 is Java 11 and 65 is Java 21.

Does the Created-By line tell me the target Java?

Not always. Created-By names the JDK that built the JAR, which can target an older release. The Java versions chart reads the class files themselves.

Do I need Java installed?

No, not for the versions or the bytecode. Only the decompiled Java source needs Java 8 or newer.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
