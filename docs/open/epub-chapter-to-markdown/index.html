Save an EPUB chapter as Markdown

EPUB Reader opens an .epub book in a VS Code tab. Go to the chapter you want, click Markdown in the toolbar and pick where to save. The chapter is written as a .md file with its headings, lists, quotes, code blocks and tables, and its images go into a folder next to it. Reading and the chapter export are free, with no sign-in. Zovo Pro (USD 19 once) adds Export Book, which writes every chapter at once, and Check EPUB, with 3 free tries each.

Steps in VS Code

  1. Install EPUB Reader from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-epub-reader.
  2. Click a .epub file in the Explorer. It opens in EPUB Reader, at the page where you stopped last time.
  3. Open the contents with the button at the left end of the toolbar and click the chapter you want. EPUB 3 and EPUB 2 contents lists both work.
  4. Click Markdown at the right end of the toolbar, or run "EPUB Reader: Export Chapter to Markdown" from the Command Palette. The save dialog suggests <book> - <chapter>.md next to the book.
  5. Pick where to save. The images of the chapter go into a <name>-images folder next to the Markdown file, and the file opens beside the book.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-epub-reader and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-epub-reader.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What EPUB Reader handles

  • EPUB 2 and EPUB 3 books, with the contents from the EPUB 3 nav or the EPUB 2 NCX.
  • Headings, lists, block quotes, code blocks and tables, written as Markdown.
  • The images of the chapter, saved as files and linked from the Markdown.
  • Books up to 200 MB by default (setting epubReader.maxFileMB). Only the parts you open are read from disk.

What it does not do

  • Books protected with DRM cannot be opened. They get a clear message instead.
  • Fixed-layout books (comics, picture books) are shown as flowing pages, so their page design is lost.
  • Audio, video and inline SVG drawings are not shown. An SVG cover or picture shown as an image works.
  • The book's own style sheet and embedded fonts are not used.

Other options

  • Pandoc. Free. pandoc book.epub -o book.md converts the whole book on the command line, and --extract-media saves the images.
  • Calibre. A free ebook manager. Its converter writes an EPUB as a TXT file, with a Markdown formatting option. A desktop app, outside VS Code.

Questions

Can I save the whole book at once?

Yes, with Export Book to Markdown or Text, a Zovo Pro tool with 3 free tries. Chapter by chapter, the free Markdown button does it too.

Is the book uploaded anywhere?

No. The extension makes no network calls. It reads the book on your computer and writes only the files you ask for.

Do scripts in the book run?

No. Scripts, forms, frames and remote images are removed before a chapter is shown, and a strict Content Security Policy blocks them too.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
