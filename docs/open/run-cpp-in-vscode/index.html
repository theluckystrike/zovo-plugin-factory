Run a C++ file in VS Code with one click

Run C++ and C Code compiles the open .cpp or .c file with the gcc, g++, clang or clang++ already on your computer and runs it in the terminal, where cin and scanf work. Click Run in the editor title or press Ctrl+Alt+Enter (Cmd+Alt+Enter on Mac). Compiler errors land in the Problems panel at the right line, and an Input & Tests panel keeps test cases with pass or fail. Zovo Pro (USD 19 once) adds a sanitizer check, a compare of -O0, -O2 and -O3 and a test report, with 3 free tries each.

Steps in VS Code

  1. Install Run C++ and C Code from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-run-cpp.
  2. Make sure a compiler is installed. "Run C++: Pick Compiler" lists what it finds. If there is none, a setup page shows the official steps for your system (Xcode Command Line Tools, MSYS2 or WinLibs, or your Linux package manager).
  3. Open a .cpp, .cc, .cxx or .c file and click the Run button in the editor title, or press Ctrl+Alt+Enter (Cmd+Alt+Enter on Mac).
  4. The program runs in a terminal named "Run: file.cpp". Type its input there. At the end you see the exit code, the run time and the peak memory. Stop ends an endless loop.
  5. For flags or arguments, put // run: -O2 -lm and // args: "Hello World" 3 in the first 40 lines of the file. The C++ defaults are -std=c++20 -Wall -Wextra -g -O0.
  6. To test with saved input, run "Run C++: Run with Input & Test Cases". Paste input, press Run with input, then Save as test case. Run all tests shows pass or fail with a line diff.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-run-cpp and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-run-cpp.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Run C++ and C Code handles

  • C and C++ files (.c, .cpp, .cc, .cxx) with gcc, g++, clang and clang++.
  • MSYS2, WinLibs, MinGW, TDM-GCC and LLVM in their usual Windows folders, and Homebrew names such as g++-14.
  • Paths with spaces, & or non-ASCII letters, because no shell parses them.
  • Programs that print a million lines. The panel shows the first 2,000 and counts the rest.

What it does not do

  • It needs a compiler on your computer and never downloads one.
  • Runs in the Input panel and test cases stop after 10 seconds (setting zovoRun.timeLimitSeconds). Programs in the terminal have no limit.
  • Output past 32 MB per run is counted, not kept (setting zovoRun.maxCapturedOutputMB).
  • The sanitizer check needs a compiler with the sanitizer runtime. MinGW gcc on Windows has none, so use clang from LLVM there.

Other options

  • C/C++ Runner. A popular free runner extension. Its open issues ask for flags per file and for program arguments with spaces.
  • C/C++ Compile Run. Another free runner. Its issues report garbled non-ASCII folder names in the Problems panel.
  • A terminal. g++ -std=c++20 main.cpp -o main, then ./main, works anywhere. Free, with no test cases and no Problems panel.

Questions

Can my program read input with cin?

Yes. It runs in a real terminal, so cin and scanf wait for what you type, and prompts without a newline show first.

Does it change my settings.json or tasks.json?

No. It never writes your settings files. Debug adds one entry to .vscode/launch.json, and only when you press Debug.

Where do the built programs go?

To .zovo-run/bin in the workspace, with a .gitignore inside, or to the system temp folder (setting zovoRun.outputFolder).

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
