Compare two Word documents

Word has Review, Compare built in. Without Word, or when the files live in a Git repo, install the free DOCX Viewer by Zovo in VS Code, select both .docx files, right-click and pick "Compare Documents (Redline)...". You get one document with inserted words underlined, deleted words struck through, moved paragraphs, changed table cells and formatting changes marked, plus a change list. Nothing is uploaded. Exporting the result as a Word file with tracked changes is Zovo Pro.

Free, MIT license. Extension ID zovo.docx-viewer-vscode, version 0.4.10. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install DOCX Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.docx-viewer-vscode.
  2. Select the two files in the Explorer, right-click and pick "Compare Documents (Redline)...". The file changed longest ago goes on the left as the older version; "Swap" changes that.
  3. For a file in Git, right-click it in the Explorer or in Source Control and pick "Compare with Git HEAD", then Redline.
  4. Use the change list, the filters and F7 to go from change to change. "Side by side" shows both versions in one scrolling view.
  5. To send the result to someone with Word, click "Export DOCX" (Zovo Pro). Your two documents are never changed.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.docx-viewer-vscode and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/docx-viewer-vscode.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What DOCX Viewer handles

  • .docx, .odt and old .doc files.
  • Word-level insertions and deletions, moved paragraphs, added and removed table rows, changed cells and formatting-only changes.
  • Tracked changes already in a file are accepted first, so the compare uses the final text of both versions.
  • Two 500-page documents with 200 tables compared in 0.44 s in a background worker, with progress and Cancel.
  • A Markdown diff in VS Code's own diff editor, if you prefer plain text.

What it does not do

  • Changes in headers, footers, footnote text, text boxes and comments are not marked.
  • Pictures, charts and equations count as one object each, so a changed picture shows only when one is added or removed.
  • The redline view needs desktop VS Code. In VS Code for the Web the compare opens the Markdown diff.

Questions

Can I compare two Word documents for free?

Yes. The redline in DOCX Viewer is free, offline and has no page limit. Only the exports (DOCX with tracked changes, HTML) and the folder compare are Zovo Pro.

Can it compare a .docx with an older Git version?

Yes. Right-click the file and pick "Compare with Git HEAD". Plain git diff shows nothing useful for Word files.

Is my document uploaded anywhere?

No. DOCX Viewer makes no network calls with your files. The only network call is the optional GitHub check when you unlock Zovo Pro.
