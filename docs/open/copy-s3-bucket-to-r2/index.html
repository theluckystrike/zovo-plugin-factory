Copy objects from AWS S3 to Cloudflare R2 or MinIO

Moving files between two storage providers usually means rclone, or a download and an upload by hand. S3 Explorer connects to AWS S3, Cloudflare R2, MinIO, Backblaze B2, Wasabi and DigitalOcean Spaces in one view, and its Copy to Another Connection tool copies objects or whole folders from one connection to another. Before anything is written, a confirmation lists the objects and every object on the target that would be replaced. The tool is part of Zovo Pro (USD 19 once) with 3 free tries, and copy and move inside one connection are free.

Steps in VS Code

  1. Install S3 Explorer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-s3-explorer.
  2. In the S3 Buckets view, click Add Connection twice. Add the source, for example an AWS profile from ~/.aws, and the target, for example Cloudflare R2 with its account ID and an R2 API token.
  3. Expand the source bucket and select the objects or folders to copy. Ctrl+click or Shift+click selects several.
  4. Right-click and pick "Copy to Another Connection... (Pro)". Pick the target connection, the bucket and the destination folder. Leave the folder empty for the top level.
  5. Read the confirmation. It lists the objects to copy and every object on the target that would be replaced. Click Copy, or Copy and Replace.
  6. Watch the progress. At the end, a message says how many objects were copied and names any that failed.

What S3 Explorer handles

  • AWS S3 with profiles from ~/.aws (SSO and role profiles too) or access keys.
  • Cloudflare R2, MinIO and other S3-compatible services, Backblaze B2, Wasabi and DigitalOcean Spaces.
  • Single objects, many selected objects and whole folders.
  • Objects of 64 MB or more, which go through a temporary file and upload in parts.

What it does not do

  • Objects travel through your computer. Each one is downloaded from the source and uploaded to the target, so your connection sets the speed, and the source provider may bill the download.
  • Content type and user metadata are kept for objects under 64 MB. Larger objects get a content type from their name. Tags and older versions are not copied.
  • Nothing is deleted on either side. To move data, delete the source objects yourself after you check the copy.
  • A failed object does not stop the rest. Run the copy again for the ones the message names.

Other options

  • rclone. A free command-line tool that copies and syncs between S3, R2, MinIO and many other storage services.
  • Cloudflare Super Slurper. Cloudflare's migration tool copies a whole S3 bucket into R2 from the Cloudflare dashboard, without going through your computer.

Questions

Does the data go through my computer?

Yes. VS Code downloads each object from the source and uploads it to the target. For a very large bucket, a server-side tool such as Cloudflare Super Slurper may be faster.

Can I copy a whole bucket?

Yes. Click Copy to Another Connection in the Zovo Pro tools row, pick the source connection and bucket, and leave the prefix empty.

Where are my R2 keys stored?

Keys you type go to the OS keychain through VS Code SecretStorage, never into settings files.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
