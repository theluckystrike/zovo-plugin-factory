Read PDFs in dark mode in VS Code

VS Code has no PDF viewer of its own. With the free PDF Reader extension, PDF pages follow your theme, so a dark theme gives dark pages. Click the moon button, or run "PDF: Toggle Dark Pages", to switch the open file. Photos keep their real colors, because the page is inverted and each raster image is then painted back in its original pixels.

Install in VS CodeMarketplace pageOpen VSX (Cursor, Windsurf, VSCodium)

Free, MIT license. Extension ID zovo.pdf-viewer-dark, version 0.3.5. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install PDF Reader from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.pdf-viewer-dark.
  2. Click any .pdf file. With a dark theme, the pages are dark.
  3. Click the moon button, or run "PDF: Toggle Dark Pages", to switch for this file.
  4. To set it for every PDF, set pdfViewer.darkMode to on or off in Settings.
  5. Prefer softer contrast? Run "PDF: Toggle Sepia Pages".

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.pdf-viewer-dark and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/pdf-viewer-dark.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What PDF Reader handles

  • Search with highlights and a match counter, an outline and page thumbnails.
  • Highlights in four colors, and "Copy Highlights as Markdown" with page links.
  • Reloads when LaTeX or Typst rebuilds the PDF, and stays on the same page.

What it does not do

  • Charts drawn as vector lines are inverted like text, because to the PDF they are lines.
  • It doesn't fill forms, edit the PDF or print. Highlights are stored in VS Code, not in the PDF.
  • Files over 200 MB ask before they load.

Other options

  • vscode-pdf (tomoki1207.pdf, 14.4 million installs, on Open VSX). The most installed PDF viewer. Its own description: "Display pdf file in VSCode."
  • PDF Viewer (mathematic.vscode-pdf, 2.9 million installs, on Open VSX). Another pdf.js based viewer, also on Open VSX.
  • LaTeX Workshop (James-Yu.latex-workshop, 5.9 million installs, on Open VSX). If you only read PDFs that LaTeX Workshop builds, its own viewer has the latex-workshop.view.pdf.invert setting.

Questions

How do I turn dark pages off for one PDF?

Click the moon button in the toolbar. Set pdfViewer.darkMode to off to turn it off everywhere.

Why are my charts inverted but photos are not?

Photos are raster images, so the viewer repaints them in their original pixels. Vector charts are drawn as lines and text, so they are inverted with the page.

Does it work offline?

Yes. pdf.js is bundled. It makes no network calls and has no telemetry.
