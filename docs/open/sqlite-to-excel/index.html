SQLite to Excel in VS Code

Open the .db file in SQLite Editor & Viewer, pick a table and click Export to save the rows in view as CSV, which Excel opens. That part is free. To get one Excel workbook with a sheet per table, run "Export All SQLite Tables to Excel or CSV", a Zovo Pro tool with 3 free tries.

Install in VS CodeMarketplace pageOpen VSX (Cursor, Windsurf, VSCodium)

Free, MIT license. Extension ID zovo.sqlite-table-viewer, version 0.4.3. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install SQLite DB Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.sqlite-table-viewer.
  2. Click the .db or .sqlite file in the Explorer. It opens as a table, read-only.
  3. Pick the table or view on the left. Sort, filter under a header or search to narrow the rows if you need to.
  4. Click Export and save the rows in view as CSV.
  5. Open the CSV file in Excel. For another query, run it in the SQL tab first and export the result the same way.

Where Zovo Pro saves time

Free: opening, the SQL tab, editing, Save with a backup, CSV import, Copy as CSV, TSV, JSON or INSERT statements, and Export of every row in view as CSV, JSON or SQL INSERT statements. A real .xlsx workbook with all tables is the Pro tool.

One run writes the whole database: one Excel workbook with a sheet per table, with a bold, frozen header row, or a folder with one CSV file per table. You do not export table by table, and the database file is only read.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.sqlite-table-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/sqlite-table-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What SQLite DB Viewer handles

  • Opens .db, .sqlite, .sqlite3, .db3, .s3db, .sl3, .vscdb and .gpkg files, read-only until you click Enable editing.
  • Export saves every row in view as CSV, JSON or SQL INSERT statements, up to 1,000,000 rows per export (setting sqliteTableViewer.exportMaxRows).
  • The SQL tab runs one statement at a time, so you can export the result of a query.
  • Reads committed transactions from the -wal file, so the export matches what your app wrote.
  • Pro: one Excel workbook with a sheet per table, or one CSV file per table.

What it does not do

  • The free Export writes CSV, JSON or SQL, not .xlsx. Excel opens the CSV.
  • Encrypted databases (SQLCipher, SEE) cannot be opened.
  • The whole database is loaded into memory. Files up to 512 MB open (setting sqliteTableViewer.maxFileSizeMB).
  • Large tables can be past what one Excel sheet holds. Check the row counts on the left first.

Other options

  • sqlite3 shell. Free. .once -x followed by a query opens that result in your spreadsheet app. .mode csv with .output file.csv writes a CSV. One query at a time, not all tables.
  • DB Browser for SQLite. Free, open source desktop app. File, Export, Table(s) as CSV file writes tables to CSV. A good choice when you want a full desktop database app.
  • pandas. In Python, pd.read_sql on each table and to_excel with an ExcelWriter gives a sheet per table. Needs Python and openpyxl, and suits a repeated job.
  • Paid converters. Several desktop converters and Excel add-ins sell SQLite to Excel export. They cost more than the free options above and do the same core job.

Questions

Can I export a SQL query result to Excel?

Yes. Run the SELECT in the SQL tab, then Export the rows in view as CSV and open it in Excel. The export is free.

Does the export change my database?

No. Export and the Pro tools only read the file. The database is written only when you click Enable editing and then Save.

Is anything sent over the network?

No. It has no network requests and no telemetry. The only exception is a click on a Zovo Pro button.

Does it work in Cursor or Windsurf?

Yes. Cursor and Windsurf install extensions from Open VSX. Search for SQLite Editor & Viewer by Zovo there.
