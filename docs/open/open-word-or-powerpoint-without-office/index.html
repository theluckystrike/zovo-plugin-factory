Open files in VS Code and Cursor / Office files

Open Word and PowerPoint files without Office

Two free extensions open Office files in VS Code and Cursor with no Office or LibreOffice installed. DOCX Viewer shows .docx, .odt and old .doc files with an outline, search, tracked changes and comments. PPTX Viewer shows .pptx decks with thumbnails, speaker notes, search and full screen Present. Nothing is uploaded. Zovo Pro (USD 19 once) adds exports, such as the redline of two versions as one HTML file, with 3 free tries each.

Steps in VS Code

  1. Install DOCX Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.docx-viewer-vscode.
  2. Click a .docx, .odt or .doc file in the Explorer. Word and OpenDocument files show with styles, tables, images, charts and equations. Old Word 97-2003 .doc files open as text.
  3. Use the outline to jump to a heading, and search to find a word. Tracked changes and comments show with the author, and Copy as Markdown copies the whole document.
  4. For slides, install PPTX Viewer (zovo.pptx-slide-viewer) the same way, then click a .pptx, .ppsx or .potx file. You get slide thumbnails, speaker notes and search across the whole deck. Old .ppt files open as text with titles, slide text and notes.
  5. Press Present to show one slide at a time full screen. Esc brings the editor back.
  6. Both viewers reload when another program saves the file, so a document or deck written by a script or an AI agent shows its latest version.

Where Zovo Pro saves time

Reading and Page view, search, the outline, tracked changes and comments, Copy as Markdown and the on-screen redline of two versions are free in DOCX Viewer. Thumbnails, speaker notes, search, Present, Copy as Markdown and copying one slide as PNG are free in PPTX Viewer.

Without Word, it is hard to show someone what changed between two versions of a document. The on-screen redline is free. Export Redline as HTML saves it as one self-contained HTML file with the change list and the marked text, for people without Word. Open it in a browser and print it to PDF. The same Pro tool can save a new .docx with real tracked changes that Word and LibreOffice can accept or reject one by one. DOCX Viewer also has the change list as Excel and a compare of two folders as Pro tools. PPTX Viewer Pro exports all slides as PNG, saves the deck as one PDF, converts a folder of decks to Markdown and compresses a deck.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.docx-viewer-vscode and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/docx-viewer-vscode.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What DOCX Viewer handles

  • .docx, .docm, .dotx, .odt and old .doc (as text).
  • .pptx, .ppsx, .potx, .pptm and old .ppt (as text) in PPTX Viewer.
  • Tracked changes and comments, with Final and Original views.
  • Remote SSH, WSL, Dev Containers and Codespaces for decks, because files are read through VS Code.

What it does not do

  • Both are viewers. You cannot type into the document or edit a slide.
  • .rtf files are not opened. Only RTF saved with a .doc name opens, as text.
  • Old .doc and .ppt files show text only, without pictures or layout.

Other options

  • LibreOffice. A free office suite that opens and edits Word and PowerPoint files. A large desktop install.
  • Word and PowerPoint for the web. Free with a Microsoft account. The file goes to OneDrive first.
  • Google Docs and Google Slides. Free with a Google account. The file is uploaded to Google Drive.

Questions

Do I need Microsoft Office or LibreOffice?

No. Both extensions read the files themselves, inside VS Code or Cursor.

Is my file uploaded?

No. Both read the file on your computer and do not upload it.

Can I edit the document?

No. These are viewers. For editing, use LibreOffice, Word or Word for the web.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
