Steps in VS Code

  1. Install HTML Formatter & CSS Formatter from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-html-formatter.
  2. Open an HTML, CSS, SCSS or LESS file and press Shift+Alt+F (Shift+Option+F on macOS). If VS Code asks which formatter to use, pick HTML Formatter & CSS Formatter.
  3. To make it the default for all four languages in one step, run "HTML Formatter: Use as Default Formatter for HTML, CSS, SCSS and LESS".
  4. Select some lines and run Format Selection to format only those.
  5. To format on every save, turn on zovoHtmlFormat.formatOnSave, or use VS Code's own editor.formatOnSave once it is the default formatter.
  6. Indentation comes from the editor, then from .editorconfig (indent style and size, end of line, final newline, max line length), so the whole team gets the same result.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-html-formatter and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-html-formatter.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What HTML Formatter & CSS Formatter handles

  • The CSS in <style> and the JavaScript in <script> inside HTML.
  • Kept as written: the contents of <pre> and <textarea>, inline tags on their line, attribute order, blank lines between blocks (at most one in a row), the page's head and body indentation style, and template tags such as {{ }} and {% %}.
  • In SCSS and LESS, multi-line maps and function calls keep their layout, and trailing comments stay on their line.
  • Settings for wrap length, attribute wrapping, a blank line between CSS rules and one selector per line.

What it does not do

  • Standalone .js, .jsx, .ts, Vue and Svelte files are not formatted by this extension. Only the JavaScript inside <script> is.
  • Lines are not wrapped unless you set a wrap length, so a very long line stays long.
  • SCSS and LESS go through the CSS formatter. Unusual syntax such as LESS detached rulesets can keep its original spacing.
  • Minify does not shorten JavaScript and does not rename or merge CSS rules.

Questions

Does VS Code format HTML without an extension?

Yes. VS Code has a built-in HTML and CSS formatter. This extension reads .editorconfig, keeps the page's own head and body indentation, keeps SCSS and LESS maps in their layout, and adds the folder, minify and lint Pro tools.

Will it change my pre blocks or reorder attributes?

No. The contents of pre and textarea, inline tags and attribute order stay as you wrote them.

Does it need Node or npm?

No. js-beautify 1.15.4 is bundled in the extension and runs offline.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
