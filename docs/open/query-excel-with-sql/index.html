Open files in VS Code and Cursor / Tables and data

Query Excel with SQL

You do not need to import a workbook into a database to filter it with SQL. Install the free XLSX Viewer by Zovo (Table Viewer) in VS Code, click an .xlsx file and click "SQL" in the toolbar. Type a condition such as amount > 100 AND region = 'EU' and only the matching rows stay. Sort, column stats and export to CSV or JSON work on the result. Nothing is uploaded and nothing is locked.

Install in VS CodeMarketplace pageOpen VSX (Cursor, Windsurf, VSCodium)JetBrains IDEs

Free, MIT license. Extension ID zovo.table-viewer-vscode, version 0.4.2. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install Table Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.table-viewer-vscode.
  2. Click an .xlsx, .xls or .ods file in the Explorer. It opens as a table. Pick the sheet in the toolbar.
  3. Click "SQL" and type a WHERE condition, for example total > 20 AND (city = 'Paris' OR city LIKE 'Lon%').
  4. Click "Stats" for count, nulls, distinct values, min, max, mean and top values of each column in the rows you see.
  5. Click "Export" to save the filtered and sorted rows as CSV, TSV, JSON or JSON Lines.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.table-viewer-vscode and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/table-viewer-vscode.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Table Viewer handles

  • .xlsx, .xlsm, .xls, .xlsb and .ods, and also CSV, TSV and Parquet.
  • Big workbooks: a 48 MB workbook with 660,000 rows showed its first rows in 0.5 s and finished loading in 3.4 s.
  • Cells look the way Excel shows them (25.0%, $1,234.50, dates), while the filter and sort use the stored values.
  • Compare a workbook with its last Git commit, sheet by sheet.

What it does not do

  • In this version SQL is a WHERE filter on one sheet: no GROUP BY, no JOIN with another file.
  • It reads workbooks. It does not write cells back to the .xlsx.
  • Up to 1,000,000 rows per file (setting tableViewer.maxRows).

Questions

Can I run SQL on an Excel file without importing it?

Yes. Table Viewer reads the workbook directly. Click SQL in the toolbar and type a WHERE condition.

Is it free?

Yes. The SQL filter, stats and export are free, with no trial and no license banner.

Does it change my workbook?

No. It only reads the file. Export writes a new file.
