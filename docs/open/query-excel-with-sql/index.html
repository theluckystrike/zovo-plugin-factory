Open files in VS Code and Cursor / Tables and data

Query Excel with SQL

You do not need to import a workbook into a database to query it. Install the free XLSX Viewer by Zovo (Table Viewer) in VS Code, click an .xlsx file, click "Query" in the toolbar, write a SELECT and press Ctrl+Enter (Cmd+Enter on macOS). FROM this is the open sheet. GROUP BY, HAVING, ORDER BY and JOIN with another sheet or another CSV, Excel or Parquet file in the workspace all work. Nothing is uploaded and nothing is locked.

Free, MIT license. Extension ID zovo.table-viewer-vscode, version 0.5.7. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install Table Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.table-viewer-vscode.
  2. Click an .xlsx, .xls or .ods file in the Explorer. It opens as a table.
  3. Click "Query" in the toolbar and write a SELECT, for example SELECT region, SUM(amount) FROM this GROUP BY region ORDER BY 2 DESC. Press Ctrl+Enter.
  4. Join another sheet by name, JOIN "Customer List" c ON ..., or another file by path in single quotes, JOIN 'customers.csv' c ON ....
  5. Sort, filter or get stats on the result, then "Save result" as CSV, TSV, JSON, JSON Lines or Parquet.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.table-viewer-vscode and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/table-viewer-vscode.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Table Viewer handles

  • Real SQL: WHERE, GROUP BY with COUNT, SUM, AVG, MIN, MAX, MEDIAN, HAVING, ORDER BY, LIMIT, DISTINCT, CASE, CAST, subqueries in FROM and about 70 functions.
  • INNER, LEFT and CROSS JOIN with another sheet of the same workbook or another CSV, TSV, Excel or Parquet file.
  • Progress and a Cancel button. A query that would need too much memory stops with a message instead of freezing VS Code.
  • Only SELECT runs: the viewer never writes to the file you query.

What it does not do

  • It reads workbooks. It does not write cells back to the .xlsx.
  • One SELECT at a time. No RIGHT or FULL JOIN, no WITH, and no subqueries inside expressions.
  • A query may keep up to 512 MB in memory (setting tableViewer.queryMemoryMB). A bigger one stops with a message.

Questions

Can I run SQL on an Excel file without importing it?

Yes. Table Viewer reads the workbook directly. Click Query, write a SELECT and press Ctrl+Enter.

Can I join two sheets or two files?

Yes. Join another sheet by name in double quotes, or another CSV, Excel or Parquet file of the workspace by its path in single quotes.

Is it free?

Yes. SQL queries, JOIN, the SQL filter, stats and export are free, with no trial and no license banner.
