Steps in VS Code

  1. Install DBML Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-dbml-viewer.
  2. Open the newer schema file, a .dbml file or a .sql file with CREATE TABLE statements, and click the diagram button in the editor title bar.
  3. Click Compare schemas in the diagram toolbar. Or right-click the file in the Explorer and pick "Zovo Pro: Compare schemas and write migration SQL".
  4. Pick the older schema file to compare with. It can be the other format, DBML against SQL.
  5. Pick the database the migration SQL is for: PostgreSQL, MySQL, SQL Server or SQLite.
  6. A Markdown report opens with the counts, the tables added, removed and changed (column, old value, new value), the relations and a Migration SQL block. Copy the SQL into your migration file and read it before you run it.

What DBML Viewer handles

  • DBML files and SQL DDL for PostgreSQL, MySQL, SQL Server and SQLite, in any mix.
  • Tables, columns (type, NOT NULL, default, unique, primary key), indexes, relations and enums.
  • Migration SQL for PostgreSQL, MySQL, SQL Server or SQLite.
  • Type aliases such as int4 and integer, or bool and boolean, seen as the same type.

What it does not do

  • A renamed table or column shows up as a drop plus an add, and a dropped column loses its data. The SQL says so at the top.
  • SQLite cannot change a column or add a foreign key in place. The SQL has a comment that says to rebuild the table.
  • A changed primary key, a changed SQL Server default and a removed index with no name are left as comments to do by hand.
  • PostgreSQL cannot drop an enum value. The SQL notes it.
  • The SQL reader is made for schema files. It skips INSERT statements, views and functions.

Questions

Which file is old and which is new?

The file you have open is the new schema. The file you pick is the old one. The SQL goes from the old schema to the new one.

Does it run the SQL?

No. The report opens in an editor tab. You copy the SQL and run it yourself.

Can I compare a DBML file with a SQL dump?

Yes. Both are read into the same model, so DBML against SQL DDL works. INSERT lines in a dump are skipped, and a file is read up to 8 million characters.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
