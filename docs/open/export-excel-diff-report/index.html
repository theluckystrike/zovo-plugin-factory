Export the differences between two Excel files as a report

A screenshot of a diff shows one screen, and the person who reviews the change often has no VS Code. Excel Compare & XLSX Diff compares two workbooks or CSV files cell by cell, and its Export a diff report tool saves the result as a file. You get an XLSX workbook with the changed, added and removed cells filled in colour, a Summary sheet and a Changes sheet with every old and new value, or one HTML page, or a CSV list of the changes. Export a diff report is part of Zovo Pro (USD 19 once), with 3 free tries on your computer.

Steps in VS Code

  1. Install Excel Compare & XLSX Diff from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-excel-compare.
  2. Compare the two files. Select both in the Explorer, right-click and pick Compare Selected Excel Files, or right-click a workbook in a Git repository and pick Compare with Git HEAD.
  3. Set the comparison the way the report should show it. Pick Values or Formulas, and match rows by key if the row order differs (Match by key is a Pro tool too).
  4. Click Export report in the toolbar, or run "Excel Compare: Export a diff report (XLSX, HTML or CSV) (Pro)" from the Command Palette.
  5. Pick XLSX workbook, HTML page or CSV list, then choose where to save. The suggested name comes from the second file, such as budget-april-diff.xlsx in its folder.
  6. Open the report. The XLSX has a Summary sheet, a Changes sheet and one sheet per compared sheet with the rows coloured. A CSV report opens beside the comparison.

Where Zovo Pro saves time

Comparing the files is free, with the grid of changed cells in yellow, added rows in green and removed rows in red, the summary line, Next and Previous change and Compare with Git HEAD. To pass on one value, click the cell and use Copy, which copies the old and the new value.

In the XLSX, changed cells are yellow, added rows green, removed rows red and moved rows blue, and the Changes sheet lists the sheet, cell, row in each file, column, change, before and after, with a filter on the header. The HTML page shows the old value struck through above the new one. The other Pro tools are Match rows by key columns and Compare two folders of workbooks.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-excel-compare and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-excel-compare.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Excel Compare & XLSX Diff handles

  • An XLSX report with a Summary sheet, a Changes sheet and one sheet per compared sheet.
  • One HTML page that opens in any browser and runs no scripts.
  • A CSV list in UTF-8 with a byte order mark, so Excel reads the text correctly. Text that starts with =, + or @ gets a leading quote, so Excel does not run it as a formula.
  • Values or Formulas and key matched rows, as set in the comparison.

What it does not do

  • The Changes list stops at 1,000,000 changes.
  • The HTML page shows at most 20,000 changed rows per sheet. The XLSX report has all of them.
  • In the sheets of the XLSX, a changed cell holds the new value. The old value is in the Changes sheet.
  • Cell formats, fonts and charts of the compared workbooks are not copied into the report.

Other options

  • Spreadsheet Compare. A Windows desktop tool from Microsoft that comes with some Office editions. It compares two workbooks and can export the results to Excel.
  • daff. A free table diff tool. It can render the diff of two CSV files as an HTML page. It runs in a terminal.

Questions

Can people without VS Code read the report?

Yes. The XLSX opens in Excel, LibreOffice or Google Sheets, and the HTML page opens in any browser.

Does the report include the old values?

Yes. The Changes sheet of the XLSX and the CSV list have a Before and an After column, and the HTML page shows the old value struck through.

Is my data uploaded anywhere?

No. The report is written on your computer, and the extension makes no network requests.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
