Create a presigned URL for an S3, R2 or MinIO object

A presigned URL lets someone download or upload one object without credentials, until the link expires. S3 Explorer creates one in VS Code when you right-click an object, pick "Copy Presigned URL..." and choose 15 minutes, 1 hour, 1 day or 7 days, and the details page of the object also makes PUT links for uploads. Presigned URLs are free, and Zovo Pro (USD 19 once) adds a size and cost report, copy between two connections and scheduled sync, with 3 free tries each.

Free, MIT license. Extension ID zovo.zovo-s3-explorer, version 0.1.1. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install S3 Explorer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-s3-explorer.
  2. Add a connection in the S3 Buckets view, for example an AWS profile, Cloudflare R2 or MinIO, and expand the bucket down to the object.
  3. Right-click the object and pick "Copy Presigned URL...". Choose 15 minutes, 1 hour, 1 day or 7 days.
  4. The GET link is now in your clipboard, and a message says until when it is valid. If the object does not exist, the message says the link answers 404 until it is uploaded.
  5. For an upload link, click the info icon next to the object to open its details. Under Presigned URL, pick PUT (upload) and an expiry, click Create URL, then Copy URL.
  6. Send the link. Anyone who has it can download the object, or upload to that key with a PUT link, until it expires.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-s3-explorer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-s3-explorer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What S3 Explorer handles

  • GET links for downloads and PUT links for uploads.
  • Expiry of 15 minutes, 1 hour, 1 day or 7 days, and 12 hours on the details page.
  • AWS S3, Cloudflare R2, MinIO, Backblaze B2, Wasabi and DigitalOcean Spaces.
  • Links signed on your computer with AWS Signature Version 4.

What it does not do

  • The longest expiry is 7 days, the most S3 allows.
  • A link signed with temporary credentials, such as an SSO or role profile, stops working when those credentials expire, even if you chose 7 days.
  • A single link cannot be cancelled. Deleting or renaming the object, or turning off the access key that signed it, stops it.
  • The right-click command makes GET links only. PUT links come from the details page.

Other options

  • AWS CLI. aws s3 presign prints a GET link for an object, with an expiry in seconds. Free, needs the AWS CLI and credentials.
  • AWS S3 console. Select an object, open Object actions and pick Share with a presigned URL. AWS only, GET links only.

Questions

Can I make a link for an upload?

Yes. On the details page, pick PUT (upload). The person with the link can upload a file to that exact key until the link expires.

Does it work with Cloudflare R2 and MinIO?

Yes. The link is signed for the endpoint of the connection, so it works with R2, MinIO and the other S3-compatible services you add.

Why did my 7-day link stop working after a few hours?

It was signed with temporary credentials, for example from an SSO profile, and the link stops when they expire. Use a connection with a long-term access key for links that must last for days.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
