Use .editorconfig so shell scripts format the same everywhere

shfmt reads its style from .editorconfig, so the file is the one place a team needs. Shell Formatter for Bash & Zsh has shfmt 3.14.1 built in and reads the same keys, such as indent_style, indent_size and switch_case_indent. A key in .editorconfig wins over the VS Code setting, so everyone who opens the project gets the same output as the shfmt command line. That is free, and Zovo Pro (USD 19 once) adds a formatting check of a whole folder as one patch file, with 3 free tries.

Steps in VS Code

  1. Install Shell Formatter for Bash & Zsh from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-shell-formatter.
  2. Add a .editorconfig at the root of the repository, with a section such as [*.sh] and keys such as indent_style = space, indent_size = 2 and switch_case_indent = true.
  3. Open a script and press Shift+Alt+F (Shift+Option+F on a Mac). The keys in .editorconfig win over the shellFormatter.* settings.
  4. Hover the shfmt 3.14.1 item in the status bar. The tooltip shows the dialect and where the indent came from.
  5. In CI, run shfmt 3.14.1 with no style flags, for example shfmt -d ., so it reads the same .editorconfig.
  6. Or run "Shell Formatter: Copy the Matching shfmt Command (for CI)". It copies a command for the open script with the matching flags, such as -ln=bash -i=2 -ci, ending in -w and the file name.

What Shell Formatter for Bash & Zsh handles

  • The shfmt keys indent_style, indent_size, shell_variant, binary_next_line, switch_case_indent, space_redirects, keep_padding, function_next_line, simplify, minify and ignore.
  • The [[shell]] and [[bash]] sections that shfmt understands.
  • Several .editorconfig files in nested folders, read from the script upward.

What it does not do

  • The output matches shfmt 3.14.1. Another shfmt version in CI can format some scripts differently.
  • The copied command is for the open script. Its flags fix the dialect and style of that file.
  • The same-commands check is skipped for files over 256 KB, and it is off when simplify is on.

Other options

  • shfmt. The command line formatter itself. shfmt -d in CI fails when a script is not formatted.
  • EditorConfig. The file format and its plugins. Many editors read the indent keys, but only shfmt-based tools read the shell keys.

Questions

Which wins, .editorconfig or my VS Code settings?

The .editorconfig key. The setting is used only when the file has no such key.

Can I keep some files out?

Yes. Set ignore = true for them in .editorconfig, or add their names to shellFormatter.skipFiles.

Is the output the same as the shfmt command line?

Yes, for shfmt 3.14.1. The extension was checked on 178 real scripts with two option sets, and all 354 runs gave the same bytes.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
