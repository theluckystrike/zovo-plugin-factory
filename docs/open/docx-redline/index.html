Make a redline of two DOCX files

A redline shows what changed between two versions of a document. DOCX Viewer by Zovo makes one in VS Code: right-click two .docx files and pick "Compare Documents (Redline)...". To send it back as Word, click "Export DOCX": you get a new .docx built on the newer version where every difference is a real tracked change (author "Compare") that Word and LibreOffice can accept or reject one by one. The redline view is free; the DOCX and HTML exports are Zovo Pro, USD 19 once, with 3 free tries.

Free, MIT license. Extension ID zovo.docx-viewer-vscode, version 0.4.5. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install DOCX Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.docx-viewer-vscode.
  2. Right-click the two .docx files in the Explorer and pick "Compare Documents (Redline)...", or run "Redline against Git HEAD" on one file.
  3. Check the changes in the change list. The Theme button shows the redline on white paper.
  4. Click "Export DOCX" for a Word file with tracked changes, or "Export HTML" for one file that prints to PDF.
  5. Open the exported file in Word or LibreOffice and accept or reject the changes one by one.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.docx-viewer-vscode and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/docx-viewer-vscode.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What DOCX Viewer handles

  • The export keeps the newer document's styles, numbering, headers, footers, pictures and comments.
  • Inserted and deleted words become w:ins and w:del, moved paragraphs w:moveFrom and w:moveTo, and added or removed table rows become row revisions. Formatting changes are written as formatting revisions.
  • Two 500-page documents: compare in 0.44 s and DOCX export in 0.64 s, including a check that the result opens and its changes can be accepted and rejected.
  • Compare two folders of documents (Zovo Pro): one HTML redline per changed pair of same-named files and an index.html with the counts.

What it does not do

  • The redline compares the main text and tables, not headers, footers, footnote text, text boxes or comments. The export keeps those parts of the newer document as they are.
  • A changed picture, chart or equation is marked only when one is added or removed.
  • It needs desktop VS Code.

Questions

What is a redline?

A copy of a document where every change from the earlier version is marked: inserted text underlined, deleted text struck through. In a Word file the marks are tracked changes that can be accepted or rejected.

Is the exported file a real Word redline?

Yes. The changes are real tracked changes by the author "Compare". Word and LibreOffice list them and can accept or reject each one.

How much is it?

The on-screen redline is free. The DOCX and HTML exports and the folder compare are Zovo Pro: USD 19 once for every Zovo VS Code extension, with 3 free tries of each.
