Compress a PPTX file without uploading it

Most PPTX files are big because of photos that are larger than the place they fill on the slide. PowerPoint's own Compress Pictures is free and fine for one deck. If you do not have PowerPoint, or do not want to upload a deck to a compressor site, PPTX Viewer in VS Code has Compress Deck: it writes a smaller copy next to the deck and never changes the original. Viewing slides is free; Compress Deck is a Zovo Pro tool with 3 free tries, then USD 19 once.

Install in VS CodeMarketplace pageOpen VSX (Cursor, Windsurf, VSCodium)

Free, MIT license. Extension ID zovo.pptx-slide-viewer, version 0.5.5. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install PPTX Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.pptx-slide-viewer.
  2. Click the .pptx file in the Explorer. It opens in PPTX Viewer with thumbnails, the outline and speaker notes.
  3. Check the deck before you shrink it. Present mode, search and Copy as Markdown are free.

Where Zovo Pro saves time

Viewing, Present, speaker notes, search, thumbnails, the outline, copying or saving one slide as PNG and Copy as Markdown are free. Compress Deck is the Pro tool.

Compress Deck does in one step what you would do picture by picture: photos larger than their place on the slide are made smaller and saved as JPEG at quality 82, pictures with transparency stay PNG, media files that no slide uses are removed, and a file stored twice is kept once. Nothing is uploaded.

With Compress Deck (Zovo Pro)

  1. Run "PPTX Viewer Pro: Compress Deck: Shrink Pictures (Pro)...", pick it in the Export menu, or right-click the .pptx in the Explorer.
  2. Pick a size: Screen (150 ppi, the default), Email (96 ppi) or Print (220 ppi).
  3. A new file, deck (compressed).pptx, is written next to the deck. The message says how much smaller it is.
  4. Click "Show Details" to see every picture with its size before and after.

Compress Deck works 3 times on your computer before it asks for a license, and a try counts only when you get a result. Opening a file shows no popup and no countdown.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.pptx-slide-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/pptx-slide-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What PPTX Viewer handles

  • Oversized photos, re-saved as JPEG at quality 82.
  • Pictures with transparency stay PNG.
  • Unused media removed, duplicates kept once.
  • Three sizes: Screen, Email and Print.

What it does not do

  • EMF, WMF, SVG, GIF, video and audio are kept as they are, so a deck that is big because of a video does not get much smaller.
  • It does not convert the deck to PDF.

Other options

  • PowerPoint Compress Pictures. Free if you have PowerPoint: select a picture, then Picture Format, Compress Pictures, and apply it to all pictures. The first thing to try.
  • compress-pptx (open source). A command-line tool that turns large PNG and TIFF pictures in a deck into JPEG. Good for scripts.
  • Online compressors. Sites such as Zamzar or NXPowerLite (desktop, paid) shrink decks too. Upload sites send your deck to their server.

Questions

Will my slides look different?

Photos are resized to the size they fill on the slide at the ppi you pick, so they look the same on screen. Pick Print (220 ppi) for printing.

Is the original deck changed?

No. Compress Deck writes a new file, deck (compressed).pptx, next to it.

Is my deck uploaded?

No. It runs in VS Code on your computer.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
