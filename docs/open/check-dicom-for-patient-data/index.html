Check a DICOM series for patient data in VS Code

DICOM Viewer reads Patient's Name (0010,0010) and Patient ID (0010,0020) in every file of a series. When either is filled, a yellow "Not anonymized" bar names the values and counts the files. It also lists other identifying tags it finds, such as the birth date, address, accession number or institution. It is a check, not a de-identification tool. Text burned into the pixels and private tags are not checked. The viewer and the check are free and work offline. Steps in VS Code

  1. Install DICOM Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.dicom-nifti-viewer.
  2. For a folder of slices, right-click the folder in the Explorer and pick "Open Folder as DICOM Series". For one file, click the .dcm file or the DICOMDIR. If the folder holds several series, pick one from the list.
  3. Look at the bar above the image. A yellow bar that starts with "Not anonymized" names the Patient's Name and Patient ID values and says in how many files of the series they are filled. When both are empty, a short grey line says so.
  4. Read the rest of that bar. It also names other identifying tags that are filled, such as Patient's Birth Date, Patient's Address, Accession Number, Institution Name or Referring Physician's Name.
  5. Press T (or click Tags) and type patient in the search box. The Patient's Name and Patient ID rows are marked. Double-click a row to copy it.
  6. Scroll through the slices. Text burned into the image, such as a name in a corner, is not checked, so look for it yourself.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.dicom-nifti-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/dicom-nifti-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What DICOM Viewer handles

  • Single .dcm, .dicom and .ima files, files without an extension, and DICOMDIR.
  • Folders of slices up to 4 folders deep, with a list to pick from when a folder holds several series.
  • Patient's Name and Patient ID in every file of the series, plus birth date, address, telephone numbers, other patient IDs and names, accession number, institution and referring physician.
  • Compressed files (JPEG, JPEG 2000 and others), which still open with their full tag table even when the image cannot be shown.

What it does not do

  • It is a check, not a de-identification tool. It does not remove or change any tag, and the scan is never changed.
  • Text burned into the pixels and private tags are not checked.
  • Overlays, presentation states, segmentation objects, RT structures and DICOM SR content are not drawn. Their tags show in the table.
  • Scans over 1024 MB are not read. The setting dicomViewer.maxFileMB raises the limit up to 4096.

Other options

  • pydicom. A free Python library. pydicom.dcmread("file.dcm").PatientName reads one tag. You write the loop over a folder yourself.
  • DCMTK dcmdump. Free command-line tools. dcmdump file.dcm prints every tag of one file, and you search the output for the patient tags.

Questions

Does the check look at every file?

It reads Patient's Name and Patient ID in every file of the series you open, and the bar says in how many files they are filled. When a folder holds several series, open each one from the list to check it.

Does it remove the patient data?

No. It never changes the file. Remove the tags with a de-identification tool, then open the result again to check it.

Is my scan sent anywhere?

No. DICOM Viewer makes no network calls and has no telemetry.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
