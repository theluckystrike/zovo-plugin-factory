See the tracked changes and comments of a Word file without Word

To review the tracked changes of a .docx, you usually need Word. DOCX Viewer opens the file in VS Code and marks every insertion and deletion in one color per author, with the name and the date when you hover. Comments get numbered markers and a list at the end, and the Final and Original buttons show the text with all changes accepted or all rejected. Reading them is free, and the file is never changed. Zovo Pro (USD 19 once) adds tools such as Export Redline as Word, which turns two versions into one document with tracked changes, with 3 free tries each.

Steps in VS Code

  1. Install DOCX Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.docx-viewer-vscode.
  2. Click the .docx file in the Explorer. It opens in DOCX Viewer in Reading view.
  3. Read the bar above the text. It counts the changes, the people who made them and the comments, and it lists each author in a color.
  4. With Markup on, insertions are underlined and deletions are struck through. Hover a change to see who made it and when.
  5. Comments have small numbered markers in the text. Their text, author and date are in the Comments section at the end of the document, which the outline also lists.
  6. Click Final to read the text with every change accepted, or Original to read it with every change rejected. Copy as Markdown always copies the Final text.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.docx-viewer-vscode and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/docx-viewer-vscode.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What DOCX Viewer handles

  • Insertions and deletions in .docx, .docm and .dotx files, with the author and the date of each one.
  • Moved text, which says "Moved away" or "Moved here" when you hover it.
  • Changes by several people, each person in a color of their own.
  • Comments with their number, author and date, listed at the end of the document.
  • Markup, Final and Original views of the same file.

What it does not do

  • It is a viewer. You cannot accept or reject a change, or add a comment.
  • Page view does not show tracked changes or comments. It says so and offers Reading view.
  • Tracked changes to paragraph marks, formatting and table rows are not marked. They show as in Final.
  • Tracked changes and comments in .odt files are not shown.
  • A password-protected file shows a message instead of the text.

Other options

  • LibreOffice Writer. A free office suite. Edit > Track Changes > Manage lists every change with its author and date, and you can accept or reject each one.
  • Word for the web. Free with a Microsoft account. It shows tracked changes and comments in the browser, but the file has to be uploaded to OneDrive or SharePoint first.

Questions

Can I accept or reject the changes here?

No. DOCX Viewer only reads the file. Use Word, LibreOffice or Word for the web to accept or reject changes.

Why do I not see any changes?

Switch to Reading view, because Page view does not show tracked changes or comments. Tracked changes in .odt files are not shown either.

Does it upload the document?

No. It works offline, with no sign-in, and nothing about your documents is sent anywhere.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
