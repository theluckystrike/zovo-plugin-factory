Steps in VS Code

  1. Install Nginx Config Formatter & Lint from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-nginx-config.
  2. Open the main nginx.conf, so the audit follows every include. If your config is a copy outside /etc/nginx, set nginxConfig.prefix to the folder where nginx.conf is.
  3. Fix the problems the editor already marks, such as a missing ;, ssl on or two servers with the same name on one port. Press Ctrl+. (Cmd+. on a Mac) for a quick fix.
  4. Run the Security audit from the overview toolbar, the Explorer right-click menu ("Zovo Pro: Security audit") or "Nginx: Security Audit (Pro)" in the Command Palette.
  5. Read the findings, sorted high, medium and low. Each one gives the file, the line, why it matters and the fix.
  6. Fix them, run the audit again, and click Save report to keep the result as Markdown.

What Nginx Config Formatter & Lint handles

  • The main config with its include files, also patterns such as sites-enabled/*.
  • Old SSL and TLS versions, weak cipher lists and HTTPS servers without a certificate.
  • Missing Strict-Transport-Security, X-Content-Type-Options and X-Frame-Options headers.
  • server_tokens, autoindex, client_max_body_size 0, and HTTP servers that serve pages next to an HTTPS server with the same name.

What it does not do

  • It reads your files. It does not run nginx -t, so a missing certificate file or a module that is not loaded is not found.
  • It does not connect to your server or test it from outside.
  • An include that matches no file is named and not checked. Up to 500 files and 20 levels of include are read.

Other options

  • gixy. A free command line analyzer for nginx configs, by Yandex. It needs Python.
  • Mozilla SSL Configuration Generator. Gives a current TLS block for nginx to copy. It does not read your config.

Questions

Does it replace nginx -t?

No. Run nginx -t on the server to check that the config loads. The audit looks for risky settings in a config that loads.

Does it follow include files?

Yes. Open the main nginx.conf. Includes with patterns are expanded the way nginx does it.

Is anything sent to a server?

No. The audit reads the files on your computer and makes no network calls.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
