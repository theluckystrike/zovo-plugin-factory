Export the speaker notes of a PowerPoint deck as text

PowerPoint keeps the speaker notes of each slide on a page of their own, so they are hard to get out in one piece. Convert to Markdown turns a .pptx deck into one Markdown file in VS Code. Each slide gets a heading with its number and title, then its bullets and tables, then its speaker notes as a quote. The conversion is free for any number of decks and needs no PowerPoint. Zovo Pro (USD 19 once) adds Convert a Folder to Markdown for a whole folder of decks, with 3 free tries.

Steps in VS Code

  1. Install Convert to Markdown from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-convert-to-markdown.
  2. In the Explorer, right-click the .pptx file and pick Convert to Markdown. .pptm, .ppsx, .ppsm and .potx files work the same way.
  3. The Markdown opens beside the deck. Each slide starts with a level 2 heading that holds the slide number and its title, and its speaker notes follow as a quote that starts with the word Notes.
  4. Press Save. The name of the deck with .md is filled in, next to the deck. To skip this step every time, set toMarkdown.output to file.
  5. To paste the text somewhere else instead, right-click the deck and pick Copy as Markdown.

Where Zovo Pro saves time

Convert to Markdown and Copy as Markdown are free for every deck, with no limit and no sign-in. Slide titles, subtitles, bullets with their levels, tables, links and the speaker notes are all in the free result. The deck is read on your computer, and nothing is uploaded.

For a course or a conference with many decks, one right-click per deck adds up. Convert a Folder to Markdown converts every deck in a folder and its subfolders, together with any PDF, Word or Excel files there, and writes one .md file for each, with the notes under each slide. A file named _conversion-report.md lists what was converted. The other Pro tools save the pictures inside the slides to an assets folder and split a deck into LLM-ready chunks with token estimates.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-convert-to-markdown and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-convert-to-markdown.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Convert to Markdown handles

  • .pptx, .pptm, .ppsx, .ppsm and .potx decks.
  • Speaker notes with several paragraphs, bold and italic words and links.
  • Bullets with their indent levels, numbered lists, and tables as Markdown tables.
  • Hidden slides, which get "(hidden)" in their heading.
  • Charts, SmartArt, video and audio, which are named in the text, for example *[Chart]*.

What it does not do

  • Old PowerPoint 97-2003 .ppt files are not converted. Save them as .pptx in PowerPoint, Keynote or LibreOffice first.
  • Pictures become placeholders, with their alt text when the deck has one. Charts and SmartArt are named, not converted.
  • You get the slide text and the notes together. There is no mode for the notes alone.
  • A deck can be up to 200 MB (setting toMarkdown.maxFileSizeMB), and only the first 5,000 slides are converted.

Other options

  • PowerPoint for Windows. File > Export > Create Handouts sends the slides and the notes to Word, with the notes next to each slide. Needs PowerPoint and Word.
  • python-pptx. A free Python library. A short script reads slide.notes_slide.notes_text_frame.text for each slide that has notes. Needs Python.
  • PPTX Viewer & PowerPoint Preview. A free Zovo viewer for VS Code. It shows the notes under each slide, and the All button in its Copy group puts every slide with its notes on the clipboard as Markdown. It also reads old .ppt files as text.

Questions

Can I get the notes of an old .ppt file?

Not with this extension. Save the file as .pptx in PowerPoint, Keynote or LibreOffice first. The free PPTX Viewer extension opens .ppt files as text, with the notes, and copies them as Markdown.

Can I convert many decks at once?

Yes. Select up to 20 decks in the Explorer and pick Convert to Markdown, and they are converted one after the other, for free. For a whole folder with subfolders, Convert a Folder to Markdown is a Zovo Pro tool with 3 free tries.

Does it change the deck?

No. It only reads the deck and writes a new Markdown file.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
