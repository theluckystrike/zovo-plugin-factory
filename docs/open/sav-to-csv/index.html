Convert an SPSS .sav file to CSV or Excel

An SPSS .sav file is binary, so you need a program that reads it before you can save it as CSV. SPSS Viewer & Stata Viewer opens .sav, .zsav, .dta and .xpt files in VS Code without SPSS, Stata or Python. Its Export tool saves the rows in the current view as CSV, an Excel workbook or JSON, with value labels such as "Strongly agree" or with the codes behind them. Viewing, filtering and copying are free, and Export is part of Zovo Pro (USD 19 once), with 3 free tries on your computer.

Steps in VS Code

  1. Install SPSS Viewer & Stata Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-spss-stata-viewer.
  2. Click the .sav file in the Explorer. It opens in the data grid. .zsav, Stata .dta and SAS .xpt files open the same way.
  3. To export only part of the data, pick a column in the filter bar above the grid, type a value, a comparison such as > 30 or a range such as 18..65, and click Filter. Click a column header to sort.
  4. Use the Value labels button to choose what the cells hold. With it on, you get the label, such as "Female". With it off, you get the code, such as 2.
  5. Click Export and pick CSV, Excel (.xlsx) or JSON, then choose where to save the new file. The export takes the rows in the current view, with the filter and the sort applied.
  6. Open the new file. A CSV or JSON file under 20 MB opens beside the grid. The Excel workbook has a Data sheet and a Variables sheet with the label, type, format, measure, missing values and value labels of each variable.

What SPSS Viewer & Stata Viewer handles

  • SPSS .sav files (uncompressed and bytecode compressed) and .zsav files, with long names, very long strings and the encoding record.
  • Stata .dta releases 113 to 119 (Stata 8 to 18), with strL strings and the extended missing values .a to .z.
  • SAS transport .xpt files, version 5 and version 8.
  • SPSS, Stata and SAS date and time formats.

What it does not do

  • Excel export stops at the Excel limit of 1,048,575 rows, and a message says how many rows were left out. CSV has no such limit.
  • JSON export stops at 2,000,000 rows. Filter the rows or use CSV for more.
  • System missing values become empty cells. SPSS user-defined missing codes, such as 99, are written as their values, so filter them out first if you do not want them.
  • The viewer reads up to 40 million cells, for example 2 million rows of 20 variables. A larger file shows its first rows and says so on the Info tab.
  • SAS .sas7bdat, SPSS portable .por and Stata 7 or older files are not read.

Other options

  • pyreadstat. A free Python library that reads SPSS, Stata and SAS files into pandas. Then df.to_csv() writes the CSV. Needs Python.
  • PSPP. A free program that works much like SPSS. It opens .sav files and can save the data as CSV.
  • haven for R. A free R package that reads .sav and .dta files with their labels. write.csv then saves a CSV.

Questions

Can I keep the value labels instead of numbers?

Yes. Turn on Value labels before you export, and the cells hold labels such as "Strongly agree". Turn it off to write the codes. In Excel, the Variables sheet lists every code with its label either way.

Does it work for Stata .dta files too?

Yes. Export works the same way for .dta, .zsav and .xpt files.

Do I need SPSS or Python?

No. The extension reads the file itself, offline, and never changes it.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
