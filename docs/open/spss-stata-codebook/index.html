Make a codebook from a .sav or .dta file

A codebook lists every variable with its label, type, value labels, missing value definitions and summary statistics, and writing one by hand from a .sav or .dta file is slow. SPSS Viewer & Stata Viewer shows most of this for free on its Variables tab. Its Codebook tool writes the full codebook as Markdown, HTML or CSV, with counts and percentages for each value label. Codebook is part of Zovo Pro (USD 19 once), with 3 free tries on your computer.

Install in VS CodeMarketplace pageOpen VSX (Cursor, Windsurf, VSCodium)

Free, MIT license. Extension ID zovo.zovo-spss-stata-viewer, version 0.1.1. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install SPSS Viewer & Stata Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-spss-stata-viewer.
  2. Click the .sav or .dta file in the Explorer to open it.
  3. Open the Variables tab. It lists the name, label, type, format, measure, user-defined missing values and value labels of every variable, with a filter box. Copy list puts the table on the clipboard as tab-separated text.
  4. Click Codebook in the toolbar and pick Markdown, HTML or CSV.
  5. Choose where to save. The codebook opens beside the viewer. It covers every row of the file, whatever filter is on in the grid.

Where Zovo Pro saves time

The Variables tab, the Info tab and the summary of each column are free. The Info tab shows the rows, the file label, the encoding, the program that wrote the file, the weight variable and the documents stored in the file. Missing values show in grey. The system missing value is a dot, and SPSS user-defined missing values and Stata .a to .z are in italics. All of them are left out of the statistics.

A data appendix, a data management plan or a handover needs the codebook as a file. Write a codebook goes through every variable and writes its label, type, format, measure and missing value definitions, the valid, missing and distinct counts, and the mean, standard deviation, minimum, median and maximum of a numeric variable. A labelled variable gets a table of its values with count, percent and valid percent. The CSV version has one row per value label, for a spreadsheet. The other Pro tools export the data to CSV, Excel or JSON and run a crosstab with a chi-square test.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-spss-stata-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-spss-stata-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What SPSS Viewer & Stata Viewer handles

  • SPSS .sav and .zsav, Stata .dta releases 113 to 119 and SAS .xpt files.
  • SPSS user-defined missing values, as single values or ranges, and the Stata extended missing values .a to .z.
  • Value labels, also for long strings in SPSS files.
  • Variable labels, display formats and SPSS measure levels (nominal, ordinal, scale).

What it does not do

  • Stata 7 and older files, SPSS portable .por files and SAS .sas7bdat files are not read.
  • The viewer reads up to 40 million cells and 200 million characters of text. A larger file is read in part, the Info tab says so, and the statistics then cover the rows that were read.
  • The layout of the codebook is fixed. To change it, edit the Markdown, HTML or CSV file it writes.

Other options

  • Stata codebook command. In Stata, codebook prints much the same for each variable. Needs a Stata license.
  • codebook for R. A free R package that builds a codebook from labelled data. Needs R, with haven to read the file.
  • pyreadstat. A free Python library that reads variable labels, value labels and missing value definitions, so you can write your own codebook script.

Questions

What do the Stata values .a to .z mean?

They are Stata extended missing values. The viewer treats them as missing, shows them in grey italics and leaves them out of the statistics, the same as SPSS user-defined missing values.

Does a filter change the codebook?

No. The codebook always covers every row of the file. Export and the crosstab use the filtered rows.

Can I get the variable list for free?

Yes. The Variables tab shows it, and Copy list puts it on the clipboard as tab-separated text.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
