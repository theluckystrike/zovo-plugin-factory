Open files in VS Code and Cursor / Machine learning files

Compare two PyTorch checkpoints

To see what changed between two checkpoints without writing a script, install NumPy Viewer by Zovo (Tensor Viewer) in VS Code, open one checkpoint and run "Compare two checkpoints". Every value of every tensor is read. Per tensor you get the max and mean absolute difference, RMSE, relative L2 error, cosine similarity and the number of values that differ, plus tensors that exist in only one file and shape or type changes. It works across formats, such as .safetensors against .pt. Viewing is free; the compare is Zovo Pro (USD 19 once) with 3 free tries.

Free, MIT license. Extension ID zovo.tensor-viewer, version 0.6.1. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install Tensor Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.tensor-viewer.
  2. Click a .pt, .pth, .ckpt, .safetensors, .gguf, .npy or .npz file. It opens with every tensor's name, shape and dtype.
  3. Run "Compare two checkpoints" from the viewer or the Command Palette and pick the second file.
  4. Tick "Only tensors that differ" to hide the identical ones. Sort by any column.
  5. Save the report as CSV, Markdown or JSON.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.tensor-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/tensor-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Tensor Viewer handles

  • Cross-format compares: .safetensors against .pt, .gguf against .npz. Quantized GGUF tensors too.
  • Per tensor: max and mean absolute difference, RMSE, relative L2 error, cosine similarity, values that differ, the index of the largest difference and NaN mismatches.
  • "Scan all tensors" (also Zovo Pro) reads every value of one file and flags NaN, Inf, all-zero, constant and very large tensors.
  • Progress and Cancel. A 7B fp16 model is about 14 GB, so a compare reads 28 GB; expect about a minute on a fast SSD.

What it does not do

  • It compares tensors with the same name. A renamed layer shows up as one tensor only in A and one only in B.
  • It reads weights. It does not load or run the model code.

Questions

Do I need Python or PyTorch installed?

No. The viewer reads .pt, .safetensors, GGUF and NumPy files itself.

Is opening a .pt file safe?

Yes. The pickle inside is decoded as data and never run, and a file that would run code when loaded gets a red warning.

What is free?
