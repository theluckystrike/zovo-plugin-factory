Run a crosstab with a chi-square test on a .sav or .dta file

Without SPSS, a crosstab of a .sav file usually means a script in Python or R. SPSS Viewer & Stata Viewer opens .sav, .zsav, .dta and .xpt files in VS Code, and its Crosstab tool cross-tabulates two variables, with an optional third as a layer. You get counts, row, column and total percentages, and a Pearson chi-square test with degrees of freedom, the p-value and a note when expected counts are below 5. Crosstab is part of Zovo Pro (USD 19 once), with 3 free tries on your computer.

Steps in VS Code

  1. Install SPSS Viewer & Stata Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-spss-stata-viewer.
  2. Click the .sav or .dta file in the Explorer to open it in the data grid.
  3. To test a subgroup only, filter the grid first. The crosstab uses the rows in the current view.
  4. Click Crosstab... in the toolbar. Pick the row variable, then the column variable, then a layer variable or No layer. Type a name or a label to find a variable.
  5. Read the table on the Crosstab tab. Tick Count, Row %, Column % and Total % to choose what each cell shows. Under the table you get N, the Pearson chi-square, df and p.
  6. Click Save as CSV or Save as Markdown to keep the table, or New crosstab... for another pair.

Where Zovo Pro saves time

Opening the file, the grid, filters, sort, value labels, the Variables tab and the column summary are free. For a variable with value labels, the summary is a frequency table with percent, valid percent and cumulative percent. That answers a one-variable question without a crosstab.

A crosstab with a test is the quick check before a report, such as whether satisfaction differs by region. Crosstab with chi-square builds the table from the whole file or the filtered rows. It leaves out rows with a missing value in one of the variables, says how many it left out, and runs the Pearson chi-square test. A third variable splits the result into one table and one test per layer. The other Pro tools export the data to CSV, Excel or JSON and write a codebook of all variables.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-spss-stata-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-spss-stata-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What SPSS Viewer & Stata Viewer handles

  • SPSS .sav and .zsav, Stata .dta (Stata 8 to 18) and SAS .xpt files.
  • Variables with value labels, shown as labels or codes in the table.
  • Missing values, which are left out of the table and counted apart.
  • An optional layer variable, with one table and one test per layer.

What it does not do

  • A row or column variable can have at most 200 categories, and a layer variable at most 50.
  • The test is the Pearson chi-square. This version has no Fisher exact test and no Cramer's V.
  • The test needs at least 2 rows and 2 columns with data. Otherwise the table shows N only.
  • Cells with an expected count below 5 are counted in a note. The test itself is not corrected for them.

Other options

  • PSPP. A free program that works much like SPSS. Its CROSSTABS command gives the table and the chi-square test.
  • R. The haven package reads the file, and chisq.test(table(x, y)) runs the test. Free, needs a script.
  • Python with SciPy. pyreadstat reads the file, and scipy.stats.chi2_contingency runs the test on a pandas.crosstab table.

Questions

Does it use the filtered rows or the whole file?

The rows in the current view. Clear the filter to use the whole file.

How are missing values handled?

A row with a missing value in the row, column or layer variable is left out. The tab says how many rows were used and how many were left out.

What does the note about expected counts mean?

The chi-square test is less reliable when expected cell counts are small. The note says how many cells have an expected count below 5, so you can merge categories or use another test.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
