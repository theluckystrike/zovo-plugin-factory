Browse AWS S3, Cloudflare R2 or MinIO buckets in VS Code

S3 Explorer adds an S3 Buckets view to VS Code for AWS S3 (profiles from ~/.aws, SSO profiles too), Cloudflare R2, MinIO, Backblaze B2, Wasabi and DigitalOcean Spaces. Browse buckets with millions of keys, open objects read-only in a tab or the matching viewer, upload and download with multipart uploads that resume, and sync a folder with a dry-run plan first. All of that is free, with no sign-in and no telemetry. Zovo Pro (USD 19 once) adds copy between connections, a size and cost report and scheduled sync, with 3 free tries each.

Steps in VS Code

  1. Install S3 Explorer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-s3-explorer.
  2. Open the S3 Explorer view in the Activity Bar and click Add Connection. Pick an AWS profile from ~/.aws, or type an access key, an R2 account ID and token, or the endpoint of MinIO or another S3-compatible service. Typed keys go to the OS keychain.
  3. Expand a connection to see its buckets. Keys load 1,000 at a time with a "Load 1,000 more" row. If your key may not list buckets, right-click the connection and pick Add Bucket by Name.
  4. Click an object to see its details, and click Open to read it in a tab or the matching viewer. Opened objects are read-only. To change one, use Edit and Upload: you edit a copy, and a dialog shows the bucket, key and both sizes before the object is replaced.
  5. Drag files or folders from the Explorer onto a bucket to upload them, or use Download. Files of 16 MB or more upload in parts with progress and Cancel, and a stopped upload resumes with only the missing parts.
  6. To keep a local folder and a prefix the same, right-click the bucket or prefix and pick Sync Folder. You see a dry-run plan (new, changed, to delete) before anything changes.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-s3-explorer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-s3-explorer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What S3 Explorer handles

  • AWS profiles with access keys, credential_process, roles with source_profile, and SSO profiles after aws sso login. endpoint_url in a profile is honored.
  • Path-style or virtual-hosted URLs and an option to accept a self-signed certificate, for MinIO and other S3-compatible services.
  • Metadata, content type, storage class, ETag, tags (edit and save), versions (open, download, restore) and presigned GET or PUT URLs from 15 minutes to 7 days.
  • Downloads never write outside the folder you chose: keys with .. segments, drive letters or NUL bytes are skipped and listed.

What it does not do

  • It never uses the AWS default profile or AWS_PROFILE on its own: you pick the profile to connect with.
  • Large text objects (over 10 MB by default) ask first, then show the first 1 MB. Binary objects over 200 MB ask before they download.
  • Scheduled Sync runs only while VS Code is open.
  • Requests that get no answer stop after 30 seconds (setting s3Explorer.requestTimeoutSeconds).

Questions

Can VS Code browse S3 without an extension?

No. VS Code has no S3 view. You need an extension or the AWS CLI in the terminal.

Where are my keys stored?

Keys you type go to the OS keychain through VS Code SecretStorage, never into settings files. AWS profiles are read from ~/.aws only when you pick one.

Does it work with Cloudflare R2 and MinIO?

Yes. R2 takes your account ID and an R2 API token's access key. MinIO and other S3-compatible services take an endpoint URL, a region and path-style or virtual-hosted URLs.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
