Format a bash or zsh script in VS Code

Shell Formatter for Bash & Zsh formats bash, sh, zsh, bats and mksh scripts in VS Code with Shift+Alt+F, Format Selection or format on save. The shfmt 3.14.1 engine ships inside the extension as WebAssembly, so there is nothing to download, and the output is the same as the shfmt command line, byte for byte. It reads the shfmt keys from .editorconfig, and a script with a syntax error is left unchanged. All of that is free and offline. Zovo Pro (USD 19 once) adds formatting of a whole folder, a formatting check as a patch file, and minify to a copy, with 3 free tries each.

Steps in VS Code

  1. Install Shell Formatter for Bash & Zsh from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-shell-formatter.
  2. Open a shell script and press Shift+Alt+F (Shift+Option+F on macOS). If VS Code asks which formatter to use, pick Shell Formatter, or run "Shell Formatter: Use as Default Formatter for Shell Scripts".
  3. To format each time you save, run "Shell Formatter: Turn On Format on Save for Shell Scripts".
  4. The dialect comes from the first line (#!/bin/bash, #!/bin/sh, #!/usr/bin/env zsh), then from the file name (.bash, .zsh, .zshrc, .bats, .ksh), else bash. Set shellFormatter.dialect or shell_variant in .editorconfig to choose it yourself.
  5. Click shfmt 3.14.1 in the status bar for the menu: format, set as default, format on save, settings, and "Copy the Matching shfmt Command (for CI)" so your pipeline formats the same way.
  6. If the script is not valid shell, it stays unchanged and the Problems panel shows the line and column.

What Shell Formatter for Bash & Zsh handles

  • The same output as shfmt 3.14.1 on the command line: 354 of 354 runs on 178 real scripts from GitHub projects and Homebrew matched byte for byte.
  • Before a change is applied, the formatted script is parsed again and must run the same commands as the original.
  • shfmt options as settings or .editorconfig keys: indent, binary operators on the next line, switch case indent, space redirects, keep padding, function braces on the next line, simplify.
  • Windows line ends (CRLF) stay CRLF, and a 2 MB script formats in about 0.2 seconds.

What it does not do

  • It never touches Dockerfiles, .env files, fish or csh scripts.
  • Zsh support in shfmt is new. A zsh script that shfmt cannot parse is left unchanged.
  • Files over 10 MB (setting shellFormatter.maxFileMB) and files with binary bytes, such as self-extracting installers, are not formatted.
  • shfmt runs with a time limit (10 seconds by default). If it is reached, the file stays unchanged.

Questions

Can VS Code format a shell script without an extension?

No. VS Code has no built-in formatter for shell scripts, so Shift+Alt+F does nothing on a .sh file until you install one.

Do I need to install shfmt?

No. shfmt 3.14.1 ships inside the extension as WebAssembly, so it works offline with nothing to download.

Will it break my script?

A script with a syntax error is left unchanged. Before any change is applied, the formatted script is parsed again and must run the same commands as the original.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
