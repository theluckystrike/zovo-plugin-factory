Compare two SQLite databases

sqldiff, the official SQLite tool, prints the SQL that turns one database into the other, and it is free. If you want a readable report next to the script, SQLite Viewer in VS Code has Compare SQLite Databases: tables, columns, indexes, views, triggers and rows, with rows matched by primary key (or rowid). You get a Markdown report and a-vs-b-sync.sql. Opening and editing databases is free; the compare has 3 free tries, then Zovo Pro is USD 19 once.

Install in VS CodeMarketplace pageOpen VSX (Cursor, Windsurf, VSCodium)

Free, MIT license. Extension ID zovo.sqlite-table-viewer, version 0.4.6. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install SQLite DB Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.sqlite-table-viewer.
  2. Click the .sqlite or .db file in the Explorer. It opens in SQLite Viewer.
  3. Browse both databases. Opening, the SQL tab, editing and CSV import are free, with no banner.

Where Zovo Pro saves time

Opening, reading, the SQL tab, editing cells and rows, Save with a backup, CSV and TSV import and export of the rows in view are free.

sqldiff gives SQL only. Compare SQLite Databases also writes a Markdown report with counts and the first differences of each table, which you can paste into a review. The sync script is opened in an editor and never run for you.

With Compare SQLite Databases (Zovo Pro)

  1. Run Compare SQLite Databases (Pro) from the Command Palette (type SQLite).

  3. Read the Markdown report: counts per table and the first differences.
  4. Check a-vs-b-sync.sql. It makes the second database match the first. Run it yourself when you are sure.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.sqlite-table-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/sqlite-table-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What SQLite DB Viewer handles

  • Tables, columns, indexes, views and triggers.
  • Rows matched by primary key or rowid.
  • Markdown report and a SQL sync script.

What it does not do

  • The sync script is never run for you.
  • It works on SQLite files only, not on a server database.

Other options

  • sqldiff. The official command-line tool. It prints a SQL script; --summary gives counts per table and --schema compares only the schema. Free and the best choice for scripts.
  • diffdb-sqlite. A Perl script that shows the result as a colored unified diff.

Questions

Does it change my database?

No. The compare only reads both files. The sync script opens in an editor and you decide whether to run it.

Is the SQLite viewer free?

Yes. Opening, editing and import are free with no paywall. The compare, ER diagrams and export of all tables are Pro tools.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
