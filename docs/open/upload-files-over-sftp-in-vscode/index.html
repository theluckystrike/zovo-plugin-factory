Upload files to a server over SFTP or FTP from VS Code

SFTP & FTP Sync and Upload sends your project to a server from VS Code over SFTP, FTP or FTPS. Write a .vscode/sftp.json with the host, user and server folder, and each file uploads when you save it. Right-click a file or folder to upload, download or compare it with the server copy, and open server files in a normal tab from the Remote Files view. Your .vscode folder, .env files and private keys are never uploaded. All of that is free, with no account. Steps in VS Code

  1. Install SFTP & FTP Sync and Upload from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-sftp.
  2. Run "SFTP: Create sftp.json Config" from the Command Palette, or click Create sftp.json in the SFTP Remote view.
  3. Fill in protocol (sftp, ftp or ftps), host, username, privateKeyPath or nothing for a password, and remotePath, the server folder that matches your local folder. Hover any key for its help.
  4. Set "uploadOnSave": true. From now on, each file you save is uploaded. A password you type is asked once and kept in the editor's secret storage, never in sftp.json.
  5. Right-click any file or folder in the Explorer (or a tab) and pick Upload, Download or Compare with Server Copy.
  6. Open the Remote Files view to browse the server, open a file in a normal editor tab and save it back, download it, copy its path or delete it. "SFTP: Show Transfer Log" shows every connection and transfer.

What SFTP & FTP Sync and Upload handles

  • SFTP with SSH keys, encrypted keys, the SSH agent or a password, FTP, and FTPS with explicit or implicit TLS.
  • .vscode, .git, .env files, private keys, .npmrc and other secret files are never uploaded. Add your own patterns in ignore, .gitignore style.
  • The server's host key is checked: pin it with hostFingerprint or confirm it on the first connection. A changed key stops the connection.
  • In a folder you have not trusted (Restricted Mode) the extension stays off, so a downloaded project cannot send your files anywhere.

What it does not do

  • One connection per server at a time, and FTP transfers run one after another.
  • Symbolic links on the server are followed for files, but linked folders are not walked by folder uploads, downloads or sync.
  • Keys in PuTTY .ppk format must be converted to OpenSSH first (puttygen key.ppk -O private-openssh -o key).
  • Sync compares size and modified time, then the bytes of same-size files, up to 300 files or 64 MB per run.

Questions

Can VS Code upload to a server over SFTP without an extension?

No. VS Code has no SFTP or FTP upload. Remote SSH edits files on the server itself; to upload a local project you need an extension or scp and rsync.

Is my password stored in sftp.json?

No. A password or passphrase you type is kept in the editor's secret storage. Leave password out of sftp.json and you are asked once.

Will it upload my .env file?

No. .vscode, .git, .env files, private keys and .npmrc are on the default ignore list and are never uploaded.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
