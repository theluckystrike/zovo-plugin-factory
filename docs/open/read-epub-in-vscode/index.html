Read an EPUB book in VS Code

EPUB Reader opens an .epub book in a VS Code tab. You read it page by page or scrolled, jump from the table of contents, search the whole book and open footnotes in a popup, in the VS Code, light, sepia or dark theme. Each book opens where you stopped. Reading is free. Zovo Pro (USD 19 once) adds export of the whole book to Markdown or text and a check of the EPUB file, with 3 free tries each.

Steps in VS Code

  1. Install EPUB Reader from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-epub-reader.
  2. Click an .epub file in the Explorer. The book opens in a tab, at the page where you stopped last time.
  3. Turn pages with the Left and Right arrow keys, Page Up and Page Down, Space, the mouse wheel or a click on the edge of the page. In a wide editor the page shows two columns.
  4. Click the Contents button at the left end of the toolbar and pick a chapter. EPUB 3 and EPUB 2 contents are both read, with their parts and sections.
  5. Type in Search in book (or press Ctrl+F, Cmd+F on a Mac) and press Enter. Each match is listed with its chapter, and Enter and Shift+Enter move between them.
  6. Click a note number to read the footnote in a popup. Escape closes it.
  7. In the toolbar, switch between Paged and Scrolled, pick the VS Code, Light, Sepia or Dark theme, and use A− and A+ for the text size. Your choice is kept for every book.

Where Zovo Pro saves time

Reading, the contents, search, footnote popups, themes, text size, book info and export of one chapter to Markdown are free, with no sign-in. The extension makes no network calls, and scripts in a book never run.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-epub-reader and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-epub-reader.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What EPUB Reader handles

  • EPUB 2 and EPUB 3 books, with the EPUB 3 nav or the EPUB 2 NCX contents.
  • Footnotes and endnotes, also when they sit in a separate notes file.
  • Big books. Only the parts you open are read, and a 400-chapter test book opened in about a second.
  • Book details with the cover, title, author, language, ISBN, publisher, dates and EPUB version.

What it does not do

  • Books with DRM cannot be opened.
  • The book's own style sheet and fonts are not used, and fixed-layout books such as comics show as flowing pages.
  • Audio, video and inline SVG drawings are not shown.
  • Search works one chapter at a time, so a phrase split across two chapters is not found. Books over 200 MB are not read.

Other options

Questions

Can it open Kindle or DRM books?

No. Books protected with DRM get a clear message instead of garbled text. Only .epub files open, so Kindle formats such as AZW or MOBI are not read.

Does it remember where I stopped?

Yes. Each book opens at your last page. The positions stay on this computer, in VS Code local storage.

Is reading free?

Yes. Reading, search, footnotes, themes and the export of one chapter to Markdown are free. Only Export Book and Check EPUB are Zovo Pro tools, with 3 free tries each.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
