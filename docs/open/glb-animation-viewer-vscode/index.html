Play GLB and glTF animations in VS Code

3D Model Viewer plays the animations stored in a .glb or .gltf file inside VS Code. An Animation bar lists every clip with its length, plays the first one when the file opens, and has Play and Pause (Space) and a time slider you can drag to any pose. The panel counts the animations, and the scene tree lets you hide a node and its children. All of that is free. Zovo Pro (USD 19 once) adds a turntable GIF export, a print check and a section view, with 3 free tries each.

Steps in VS Code

  1. Install 3D Model Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.3d-model-viewer.
  2. Click the .glb or .gltf file in the Explorer. If another viewer opens, right-click it and pick "Open in 3D Model Viewer".
  3. If the file has animations, the Animation bar shows above the model and the first clip starts. The panel on the right gives the number of animations.
  4. Pick another clip from the list. Each one shows its name and length, or Clip 1, Clip 2 when it has no name.
  5. Press Pause (or Space) and drag the time slider to step through the clip and stop at any pose.
  6. Uncheck a node in the scene tree to hide it and its children, and press F to frame the model again if a clip moves it out of view.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.3d-model-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/3d-model-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What 3D Model Viewer handles

  • glTF 2.0 animations, skins and morph targets.
  • Embedded or external .bin buffers and textures, and PBR materials.
  • A scene tree of up to 3,000 nodes with a visibility check box each.
  • STL, OBJ, PLY and 3MF in the same viewer.

What it does not do

  • One clip plays at a time, and there is no speed control.
  • Draco or meshopt compressed glTF and KTX2 textures are not decoded yet. A message names the missing extension.
  • FBX, DAE, USD and glTF 1.0 files do not open.
  • Fit uses the pose on screen, so an animated model can move out of the frame during a clip. Press F again.

Other options

  • glTF Viewer by Don McCurdy. A free web viewer where you drop a GLB and pick its animation clips.
  • Blender. Free. It imports glTF with its actions, for when you need to change the animation, not just check it.

Questions

My GLB plays in another tool but shows no Animation bar here. Why?

The bar shows only when the file holds glTF animations. Check that the exporter wrote them, and that the file is not Draco or meshopt compressed.

Can I export the animation as a video?

No. Turntable Export turns the model in one pose. It does not record the clip.

Is it free?

Yes. Playing animations and the scene tree are free. Only Print check, Section view and Turntable Export are Pro, with 3 free tries each.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
