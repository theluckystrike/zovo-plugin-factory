Open files in VS Code and Cursor / Developer files

See and fix every agent skill in one tree

Skill Shelf shows every SKILL.md your agents can load in one tree, from known folders such as .claude/skills, .agents/skills and .cursor/skills in the project and your home folder, plus the skills inside installed Claude Code plugins. A skill with a red icon has a problem that can make an agent skip it, and the Problems panel shows the line. Right-click a skill to disable, enable or copy it to another agent. Zovo Pro (USD 19 once) adds Sync Skills Between Folders and a Skills Report, with 3 free tries each.

Steps in VS Code

  1. Install Skill Shelf from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.skill-shelf.
  2. Open a folder and click the shelf icon in the Activity Bar. Skills are grouped under Project and User, and each folder shows which agents read it. Cursor, for example, reads .agents/skills and .cursor/skills, plus .claude/skills as a compatibility folder.
  3. Expand a skill with a red icon and click a problem to open SKILL.md at that line. Common ones are an uppercase name, a name that does not match the folder, an unquoted Use when: in the YAML description and a missing scripts/ file.
  4. Right-click a skill and pick Disable Skill to hide it from every agent. The folder moves to a hidden sibling such as .claude/.disabled-skills, and Enable Skill moves it back. Nothing is deleted.
  5. Pick Copy Skill To… to give a skill to another agent, for example from ~/.claude/skills to this repo's .agents/skills, so Codex and Cursor load it too. The copy never overwrites.
  6. Use Create Skill… for a new skill that passes the checks, Find Skill… to search all of them, and Export Skill as .skill File… to share one.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.skill-shelf and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/skill-shelf.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Skill Shelf handles

  • Project and user skills folders of Claude Code, Codex, Cursor, GitHub Copilot, Windsurf, Gemini CLI, OpenCode, Devin, Amp, Junie, Roo Code and Kiro.
  • Skills inside installed Claude Code plugins, read-only, with their /plugin-name:skill-name names.
  • .skill and .zip bundles, for export and install.
  • Extra folders, such as a monorepo package's .claude/skills, with agentSkills.extraLocations.

What it does not do

  • It lists skills directly inside a skills folder. Skills folders deeper in a monorepo need agentSkills.extraLocations.
  • Codex admin skills, Claude Code managed (enterprise) skills and plugin skills of other agents are not listed.
  • Plugin skills are read-only. Turn a plugin off with /plugin in Claude Code.
  • In Restricted Mode it only lists, finds and checks skills.
  • Tested on macOS. The Windows path logic has unit tests only.

Other options

  • The skills CLI. Free. npx skills add owner/repo installs skills for several agents from the terminal. Skill Shelf can build that command for you.
  • Your file manager or terminal. Free. Open each dot-folder by hand. Nothing tells you why an agent skips a skill.
  • The skills screen in VS Code. Newer VS Code versions have their own screen for agent skills. If you only use VS Code, look there first.

Questions

Why does Claude Code or Cursor not load my skill?

Most often the frontmatter is the cause. A name with capitals or spaces, a name that does not match the folder, or YAML that a strict parser rejects. Skill Shelf lists each problem with its line.

Does Disable delete the skill?

No. It moves the folder to a hidden sibling folder that no agent scans. Enable moves it back.

Does it send anything?

No. It makes no network calls on its own and starts no processes.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
