Open files in VS Code and Cursor / Office files

DOCX to Markdown in VS Code

Open the .docx in DOCX Viewer and run "DOCX Viewer: Copy as Markdown" to copy the whole document as Markdown, with tables and footnotes. That is free. To convert a whole folder of Word and PowerPoint files to Markdown, and Excel sheets to CSV, the Office Viewer Pack has "Export Office files to Markdown and CSV", a Zovo Pro tool with 3 free tries.

Install in VS CodeMarketplace pageOpen VSX (Cursor, Windsurf, VSCodium)

Free, MIT license. Extension ID zovo.zovo-file-viewers, version 0.3.0. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install Office Viewer Pack from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-file-viewers.
  2. Click the .docx file in the Explorer. It opens as a read-only preview in DOCX Viewer.
  3. Run "DOCX Viewer: Copy as Markdown" from the Command Palette, or right-click the file in the Explorer and pick Copy as Markdown without opening it.
  4. Paste into a .md file. Or run "DOCX Viewer: Open as Markdown" to get the Markdown in a new untitled editor and save it.
  5. Check the images: in Markdown they become placeholder links such as ![](#image-1).

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-file-viewers and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-file-viewers.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Office Viewer Pack handles

  • Copy as Markdown writes headings, lists, tables and footnotes, and the data table of each chart.
  • Equations become one line of text, such as x=(-b±√(b^2-4ac))/(2a).
  • Tracked changes: Copy as Markdown uses Final, the text with every change accepted.
  • Reads .docx, .dotx, .docm, .odt and old .doc files. Macros in .docm files never run.
  • Pro folder export: Word and PowerPoint to Markdown with speaker notes, Excel sheets to CSV.

What it does not do

  • Copy as Markdown does not save images: they become placeholder links. Use pandoc with --extract-media when you need the pictures.
  • Old .doc files give text only: paragraphs, simple tables, headers, footers, footnotes, comments and text boxes.
  • These are viewers. To edit a document, use the app that made it.

Other options

  • pandoc. Free command-line converter. pandoc -t gfm --extract-media=media in.docx -o out.md writes GitHub Markdown and saves the images. For images and scripts it is the better choice.
  • mammoth. Free library for JavaScript and Python that turns .docx into HTML or Markdown. DOCX Viewer itself uses mammoth for its .docx conversion.
  • markitdown and docx2md. Python tools. markitdown converts Word, PowerPoint, Excel and PDF files to Markdown from the command line; docx2md is a smaller Word-only package on PyPI.
  • Online converters. Work in the browser with no install, but the file is uploaded and many sites cap the size at 10 to 20 MB.

Questions

What does the Office Viewer Pack install?

Four free, read-only viewers: DOCX Viewer for Word, XLSX Viewer for Excel, CSV and Parquet, PPTX Viewer for PowerPoint and PDF Viewer. You can uninstall any of them and the others keep working.

Do I need the pack for one document?

No. DOCX Viewer alone has Copy as Markdown. The pack adds the other viewers and the folder tools.

Are my documents sent anywhere?

No. DOCX Viewer makes no network calls and sends no telemetry, and the pack's folder tools read files on your computer only.

Does it work in Cursor or Windsurf?

Yes. Cursor and Windsurf install extensions from Open VSX, where DOCX Viewer is listed. Install it, or the pack, from there.
