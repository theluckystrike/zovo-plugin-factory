Run a JavaScript or TypeScript snippet in VS Code

JavaScript Playground & TypeScript Scratchpad runs a snippet as you type and shows the value of each line, console.log output and errors at the end of their lines. Run "New JavaScript Scratchpad" or "New TypeScript Scratchpad" and start typing. There is no package.json, tsconfig or install, and each run is a fresh Node.js process with a 5 second time limit. Steps in VS Code

  1. Install JavaScript Playground & TypeScript Scratchpad from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-js-ts-scratchpad.
  2. Open the Command Palette and run "JavaScript Playground: New JavaScript Scratchpad" or "JavaScript Playground: New TypeScript Scratchpad". A new tab opens with values already showing.
  3. Type code. About 300 ms after you stop typing, each expression and new variable shows its value at the end of its line, for example total = 42.
  4. For a file you already have, open any .js, .mjs, .cjs, .ts, .mts or .cts file and click Inline Values in the status bar. Imports and require resolve from the file's folder and your node_modules.
  5. Hover a value to see more of it. Click the status bar item for the full console output and the stack of each error.
  6. Run "Show All Values of This Line" for every value a loop line took, or "Copy Code with Values as Markdown" to paste the result into an issue.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-js-ts-scratchpad and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-js-ts-scratchpad.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What JavaScript Playground & TypeScript Scratchpad handles

  • JavaScript and TypeScript, ES modules and CommonJS, with top-level await.
  • Types, interfaces, generics, enums and satisfies, with no tsconfig.
  • Promises, shown with their value once they settle.
  • Loops that log a million times, cut to the first 100 values per line and a count.

What it does not do

  • Values show for expression statements and new variables, not inside every sub-expression.
  • .jsx and .tsx files are not run.
  • A .ts file that imports another .ts file needs Node 22.6 or newer as your node (setting jsScratchpad.runtime).
  • It is Node.js, so browser APIs such as document do not exist.
  • Each run stops after 5 seconds (setting jsScratchpad.timeoutSeconds). Your code runs on your computer, so only run code you trust.

Other options

  • Quokka.js. A popular scratchpad extension with inline values. Some Marketplace reviews complain about notifications and a what's new page that advertise.
  • The Node.js REPL. Run node in a terminal and type lines one at a time. Free, with no inline values.
  • Browser DevTools console. Free, and it has browser APIs such as document. The code is gone when you close the tab.

Questions

Do I need a package.json or tsconfig?

No. New scratchpads are untitled tabs, and TypeScript types are removed on the fly.

Which Node.js runs my code?

By default the Node.js inside VS Code, so nothing needs installing. Set jsScratchpad.runtime to node to use the node on your PATH.

What if my code has an endless loop?

Each run is a separate process with a 5 second time limit and a memory limit. The run is stopped and VS Code stays responsive.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
