Open files in VS Code and Cursor / Media

Read the tags of an MP3, FLAC or M4A file in VS Code

The preview built into VS Code plays an MP3 but does not show its tags. Audio Player & WAV Player opens MP3, FLAC, Ogg, Opus, WAV and M4A files in VS Code. Its Tags panel lists title, artist, album, date, genre, track, comment, encoder and custom fields, from ID3v1, ID3v2.2 to 2.4, RIFF INFO, Vorbis comments and iTunes atoms, and the File panel gives the format details. Both panels are free. Zovo Pro (USD 19 once) adds Folder Loudness Report and Normalize Loudness, with 3 free tries each.

Steps in VS Code

  1. Install Audio Player & WAV Player from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.audio-preview-vscode.
  2. Click the .mp3, .flac, .ogg, .opus, .wav or .m4a file in the Explorer. If another player opens, right-click the file and pick "Open in Audio Preview".
  3. Read the header line under the file name. It gives the codec, sample rate, channels, duration, bitrate and file size.
  4. Read the Tags panel at the bottom. It lists title, artist, album, album artist, date, genre, track, disc, composer, comment, encoder and any custom fields the file has.
  5. Read the File panel for the ID3 version, whether the file has cover art and how many bytes it takes, and details such as the LAME header of an MP3 or the MD5 stored in a FLAC file.
  6. M4A and AAC files show their tags and details even without ffmpeg. To play them, install ffmpeg and click Decode with ffmpeg.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.audio-preview-vscode and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/audio-preview-vscode.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Audio Player & WAV Player handles

  • ID3v1 and ID3v2.2 to 2.4 tags in MP3 files.
  • Vorbis comments in FLAC, Ogg and Opus files.
  • iTunes atoms in M4A files, and RIFF INFO in WAV files.
  • Custom fields, such as ID3 TXXX frames.

What it does not do

  • Tags are read-only. To edit them, use a tag editor.
  • Cover art is not shown. The File panel only says that the file has it and how big it is.
  • M4A and AAC files need your own ffmpeg to play. Their tags show without it.

Other options

  • Mp3tag. A tag editor that reads and changes ID3, Vorbis and MP4 tags, for many files at once. Free on Windows.
  • ffprobe. ffprobe song.mp3 prints the tags and the stream details in a terminal. Free, comes with ffmpeg.
  • ExifTool. A free command line tool that prints the tags of audio, image and video files.

Questions

Can I edit the tags here?

No. The extension is read-only and never writes to the file. Use a tag editor to change them.

Does it show the album cover?

No. The File panel says whether the file has cover art and how big it is.

Does it read FLAC and M4A tags too?

Yes. FLAC, Ogg and Opus use Vorbis comments, and M4A uses iTunes atoms. M4A tags show even without ffmpeg.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
