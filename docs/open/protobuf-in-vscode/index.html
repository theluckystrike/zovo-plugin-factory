It runs offline with its own parser, so there is no protoc, no language server and no setup. All of that is free. Steps in VS Code

  1. Install Protobuf & Proto3 Formatter from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-protobuf.
  2. Open a folder with .proto files. Highlighting, the outline and breadcrumbs start at once.
  3. Press Shift+Alt+F (Shift+Option+F on macOS) to format, or turn on editor.formatOnSave. You get one statement per line, your editor's indentation and single spaces around =; comments, blank-line groups and your line breaks in long statements stay where they were.
  4. Press F12 on a type or an import to go to its definition, and Shift+F12 to list its uses. Hover a type to see its fields and its comment.
  5. Errors show in the Problems panel with the protoc wording: duplicate field numbers (with the next free number), unknown types, types used without their import, reserved numbers and names, and the proto3 and editions rules.
  6. If your imports start from a folder such as proto/ or third_party/, they are found by walking up from each file. For other roots, add them to zovoProto.importPaths, as you would with protoc -I.

What Protobuf & Proto3 Formatter handles

  • proto2, proto3 and editions (2023, 2024), and proto code blocks in Markdown.
  • The protobuf scoping rules: nested types, packages and a leading .. Ctrl or Cmd click an import to open the file.
  • Built-in names for the well-known types such as google/protobuf/timestamp.proto.
  • No false red marks: when an import is not in your workspace, the import line says so and the types it would bring are not guessed at.

What it does not do

  • Custom option names are checked for their import but not against the extension's field type.
  • The editions feature checks cover enum_type, labels, packed and groups. Other feature rules are left to protoc.
  • The formatter keeps your line breaks inside long statements. It does not wrap long lines and does not align = in columns.
  • Formatting needs a file that parses. Fix the error in the Problems panel first.

Questions

Can VS Code highlight .proto files without an extension?

No. VS Code opens a .proto file as plain text, with no colors, no formatting and no go to definition.

Do I need protoc installed?

No. The extension has its own parser and runs offline. The errors use the same wording as protoc.

Why does an import show a note instead of red marks?

The imported file is not in your workspace. Add its root folder to zovoProto.importPaths, like protoc -I.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
