Open files in VS Code and Cursor / Tables and data

View a large CSV file

Excel stops at 1,048,576 rows, and VS Code's text editor turns off features for big files. Install the free XLSX Viewer by Zovo (Table Viewer), right-click the CSV and pick "Open in Table Viewer". The first rows show while the rest load in a background thread, so VS Code does not freeze. A 1,000,000-row CSV of about 30 MB loads in 0.5 s, and sorting it by a number column takes about 0.2 s.

Free, MIT license. Extension ID zovo.table-viewer-vscode, version 0.4.2. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install Table Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.table-viewer-vscode.
  2. Right-click the .csv or .tsv file in the Explorer and pick "Open in Table Viewer". (CSV files keep opening as text by default, since people often edit them as text.)
  3. Check the delimiter and the header row in the toolbar. The delimiter is detected; the Delimiter list fixes a wrong guess.
  4. Type in the box under a header to filter, click a header to sort, or use the search box for every column.
  5. Click "Export" to save the rows in view, or select cells and copy them as CSV, JSON or Markdown.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.table-viewer-vscode and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/table-viewer-vscode.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Table Viewer handles

  • Up to 1,000,000 rows and 512 MB of a CSV file by default (settings tableViewer.maxRows and tableViewer.maxFileSizeMB). A banner says when a file has more.
  • Only the rows and columns on screen are drawn, also with 5,000 columns.
  • Auto-reload when a script appends rows, keeping your filter and sort.
  • Encodings such as Shift_JIS, GB18030, Big5, EUC-KR, Windows-1251 and UTF-16 are detected.

What it does not do

  • It is a viewer. To edit cells, open the file as text or use a CSV editor.
  • Past 1,000,000 rows or 512 MB, the table shows the first part of the file.

Questions

Why does VS Code struggle with a large CSV file?

VS Code turns off some editor features for large files, and it does not give extensions a text document over 50 MB, so text-based CSV tools stop working there. A table viewer reads the file from disk in a background thread instead.

How large a CSV can it open?

1,000,000 rows and 512 MB by default. Both are settings. Past that the table shows the first part of the file and a banner says so.

Is it free?

Yes. Sort, filters, the SQL filter, stats and export are free, with no license banner.
