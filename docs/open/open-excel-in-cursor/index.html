Open files in VS Code and Cursor / Tables and data

Open an Excel file in Cursor

Cursor doesn't open .xlsx files by itself, and it installs extensions from Open VSX rather than the Microsoft Marketplace. Microsoft's Data Wrangler is not there. Table Viewer is: search for it in Cursor's Extensions view, install it, and click the workbook. It opens as a read-only table with a sheet picker.

Install in VS CodeMarketplace pageOpen VSX (Cursor, Windsurf, VSCodium)

Free, MIT license. Extension ID zovo.table-viewer-vscode, version 0.5.1. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install Table Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.table-viewer-vscode.
  2. Click the .xlsx, .xls or .ods file in the Explorer.
  3. Pick the sheet. Sort by clicking a header, and filter with the row under the headers.
  4. To use the table in Cursor chat, select the rows and copy them as CSV or JSON, then paste them into the chat.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.table-viewer-vscode and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/table-viewer-vscode.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Table Viewer handles

  • Workbooks with several sheets, with the number formats of the workbook.
  • CSV, TSV and Parquet files in the same table view.
  • Up to 1,000,000 rows, drawn only where you look, so the editor stays fast.

What it does not do

  • Read-only. Excel files over 50 MB show a message unless you raise the limit.
  • It needs VS Code engine 1.90 or newer. Cursor 3.29 reports VS Code 1.128, so current Cursor builds qualify.

Other options

  • Spreadsheet Viewer (GrapeCity.gc-excelviewer, 6.8 million installs, on Open VSX). Also on Open VSX, so it installs in Cursor. Its description says it edits XLSX and CSV files.
  • Office Viewer (cweijan.vscode-office, 1.6 million installs, on Open VSX). Also on Open VSX. Views Word, Excel and PowerPoint files.
  • Data Wrangler (ms-toolsai.datawrangler, 2.4 million installs, not on Open VSX). Not on Open VSX and not in Cursor's gallery when we checked.

Install counts and Open VSX status were checked on 8 November 2026. Descriptions in quotes are the extensions' own.

Questions

Why can't I find some VS Code extensions in Cursor?

Cursor, Windsurf and VSCodium use the Open VSX registry. Each publisher decides whether to publish there. Microsoft does not publish Data Wrangler there.

Can I install a .vsix file in Cursor instead?

Yes. Download the .vsix from the Open VSX page and run "Extensions: Install from VSIX..." from the Command Palette.

Is it free?

Yes. It is MIT licensed, with no account and no paywall. It makes no network requests and has no telemetry.
