DXF to CSV in VS Code

Open the drawing in DXF Viewer and run Extract drawing data. It saves a CSV with block attributes (one row per insert, one column per tag), block counts, all text with layer and position, or the layer list. Steps in VS Code

  1. Install DXF Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.dxf-viewer.
  2. Click the .dxf file in the Explorer. The side panel lists the layers, the entity types and the block count.
  3. Press Ctrl+F (Cmd+F on a Mac) to find a tag number or block attribute and check that the data is there.
  4. Run "DXF Viewer: Extract Block Attributes, Text or Layers to CSV" from the Command Palette, the ... menu of the open drawing, or right-click the .dxf file.
  5. Pick what to export: block attributes, block counts, all text with layer and position, or the layer list.
  6. Save the CSV and open it in Excel. The first 3 runs are free; a try counts only when the CSV file was saved.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.dxf-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/dxf-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What DXF Viewer handles

  • Block attributes: one row per insert, one column per tag, such as a door or equipment schedule.
  • Block counts, as a bill of materials.
  • All text with layer and position, and the layer list.
  • One drawing or every drawing in a folder.
  • Reads ASCII and binary DXF, from R12 to AutoCAD 2018 files, with blocks and nested inserts.
  • Reads the files on your computer only, with no network calls and no telemetry. It refuses to write over a drawing.

What it does not do

  • DWG isn't supported. Save a DXF copy first; the free ODA File Converter converts a whole folder of DWG files at once.
  • The CSV types are block attributes, block counts, text and layers. It is not a dump of every line and polyline coordinate; ezdxf can do that.
  • Files over 500 MB are not read (setting dxfViewer.maxFileMB, up to 2048).

Other options

  • AutoCAD Data Extraction. In AutoCAD, the DATAEXTRACTION command builds a table of block attributes and properties and exports it to Excel or CSV. It needs a paid AutoCAD license.
  • ezdxf (Python). Free Python library. A short script reads every INSERT and its ATTRIB tags, or every TEXT and MTEXT, and writes them with the csv module. The better choice for custom columns and automation.
  • QGIS. Free desktop GIS. It opens a DXF as point, line and polygon layers with fields such as Layer and Text, and Export, Save Features As writes CSV. Good for survey and site drawings; it does not lay block attributes out as one column per tag.
  • Online upload converters. Several sites convert DXF to CSV after you upload the drawing to their server. Most give geometry or text only, not block attributes as columns. Avoid them for client drawings.

Questions

How do I export DXF block attributes to Excel?

Run Extract drawing data and pick block attributes. You get one row per insert and one column per tag, such as a door or equipment schedule. Open the CSV in Excel.

Can I get a CSV from a DWG file?

Not directly. DWG isn't supported. Save the DWG as DXF first: Save As or DXFOUT in AutoCAD, Save As in BricsCAD, or the free ODA File Converter for a whole folder.

Is the drawing uploaded anywhere?

No. DXF Viewer makes no network calls and sends no telemetry, and the Pro tools read the files on your computer only.

Does it work in Cursor or Windsurf?

Cursor and Windsurf install extensions from Open VSX. Search for DXF Viewer in their Extensions view and install it there.
