Read binary files with templates in a VS Code hex editor

A binary template describes a file format, so the hex editor can show bytes as named fields with values instead of a wall of hex. In VS Code, install Hex Viewer by Zovo, open a file and click the Structure tab: it picks one of 20 built-in templates (PNG, ZIP, ELF, PE, Mach-O, PDF, SQLite and more) from the first bytes and shows a tree of fields. Click a field to select its bytes. The hex editor itself is free; the Structure view is part of Zovo Pro (USD 19 once) and works 3 times without a key.

Steps in VS Code

  1. Install Hex Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-hex-viewer.
  2. Right-click a file in the Explorer and pick "Open in Hex Viewer".
  3. Open the Structure tab in the side panel. Hex Viewer picks the template from the first bytes of the file and shows each field with its name, value, offset and size.
  4. Click a field to select its bytes in the grid. Edit a byte and the tree reads the new value.
  5. Click "Template..." to read the file with another template, or "JSON" or "C struct" to open the selected struct as JSON or as a packed C struct with its values.
  6. For your own format, put a JSON template in .vscode/hex-templates in your workspace. The built-in templates in the extension's templates folder are examples.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-hex-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-hex-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Hex Viewer handles

  • 20 built-in templates: PNG, JPEG, GIF, BMP, ICO and CUR, TIFF (also DNG and many camera raw files), WebP, WAV, FLAC, MP4 and MOV boxes, ZIP (also JAR, APK, DOCX, XLSX, EPUB), GZIP, TAR, PDF, the SQLite header, ELF, PE, Mach-O, Java class and PCAP.
  • Your own templates as JSON: fields, types from u8 to u64 and f32 to f64, strings, LEB128, counts, conditions, switches, enums, flags, and offsets written as expressions such as header.offset + 16.
  • A template is data, never code, so a template from someone else cannot run anything on your computer.
  • Limits keep a broken file or template from hanging VS Code: 50,000 fields, 15 seconds and 100,000 items in one list. The tree says where it stopped.
  • The free part of the editor works on files of any size: a 4 GB file opened in 0.6 s in the release check.

What it does not do

  • It does not run 010 Editor .bt templates. Templates are JSON, and C-like scripting is not supported.
  • The PDF template reads classic xref tables. An xref stream (PDF 1.5 and later) is named but not unpacked.
  • Templates read up to 16 MB from the end of a file when they look for a marker, as the ZIP and PDF templates do.

Questions

What is a binary template in a hex editor?

A description of a file format: which fields come in which order, their types and sizes, and when a part repeats or depends on a flag. The hex editor applies it to a file and shows named fields with their values.

Is the template feature free?

The hex editor is free. The Structure view with templates is part of Zovo Pro, USD 19 once. It works 3 times on your computer first, so you can try it on your own files.

Can I write a template for my own format?

Yes. Save a JSON template in .vscode/hex-templates in your workspace or in a folder from the hexViewer.templateFolders setting. TEMPLATES.md in the GitHub repo explains the format.
