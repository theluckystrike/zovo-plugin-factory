Compare two Postgres schemas

To see how two databases differ, for example dev against prod, install Postgres & MySQL Query Client by Zovo, add both connections and run "Compare Two Schemas (Pro)". It writes each schema as a sorted text description, one table per block with columns, types, keys and foreign keys, and opens both in VS Code's diff view, so every added, removed or changed column is marked. It is part of Zovo Pro (USD 19 once) and works 3 times without a key.

Free, MIT license. Extension ID zovo.zovo-sql-client, version 0.1.0. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install Postgres & MySQL Query Client from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-sql-client.
  2. Add both databases in the SQL Client view: Add Connection, paste the URL, Test connection, Save.
  3. Right-click a connection or schema in the SQL Client view and pick "Compare Two Schemas (Pro)", or run it from the Command Palette.
  4. Pick the first connection and schema, then the second one.
  5. Read the result in VS Code's diff view. F7 jumps to the next change.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-sql-client and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-sql-client.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Postgres & MySQL Query Client handles

  • Two schemas from any two connections, also two schemas in the same database.
  • PostgreSQL, MySQL, MariaDB and SQLite.
  • Tables and views with their columns, types, NOT NULL, defaults and primary keys, and every foreign key, sorted by name so the order of creation does not show up as a change.
  • A short summary of added, removed and changed tables.

What it does not do

  • It shows the differences. It does not write a migration script and does not change either database.
  • Indexes, functions, triggers and permissions are not compared. For a view only its columns are compared, not its query.
  • PostgreSQL and MySQL compare with each other only as text, so expect type names to differ.

Questions

Can it generate the ALTER statements?

No. It shows the differences in the diff view. Write the migration yourself, or use a tool such as migra or Liquibase for that step.

Is it safe to run against production?

Yes. It only reads the catalog. You can also set the production connection to read-only, which the server enforces.

What does it cost?

Schema compare is part of Zovo Pro: USD 19 once for every Zovo VS Code extension, with 3 free tries. The database client itself is free.
