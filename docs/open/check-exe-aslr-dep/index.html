Check if an .exe or .dll has ASLR and DEP enabled

A Windows PE file asks for ASLR and DEP with the DYNAMIC_BASE and NX_COMPAT bits of its DLL characteristics. ELF Viewer & PE Viewer opens an .exe, .dll or .sys file in VS Code and shows a Security flags row such as ASLR on, DEP on, Control Flow Guard, high-entropy ASLR, plus whether the file carries an Authenticode signature. It needs no Visual Studio and no dumpbin. Zovo Pro (USD 19 once) adds a compare of two builds that shows a changed flag, with 3 free tries.

Steps in VS Code

  1. Install ELF Viewer & PE Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-elf-pe-viewer.
  2. Click the .exe, .dll, .sys or .efi file in the Explorer. It opens in the viewer.
  3. Read the Overview. The Security flags row says ASLR on or off and DEP on or off, and adds Control Flow Guard and high-entropy ASLR when they are set.
  4. Read the Signature row. It shows the size and offset of the Authenticode data, or says not signed.
  5. Open the Headers tab to see the DLL characteristics field with every bit by name, such as DYNAMIC_BASE (ASLR) and NX_COMPAT (DEP). Click the offset next to a field to see its bytes in the Hex tab.
  6. Open the Data directories tab to check the Base relocation and Load config entries.

What ELF Viewer & PE Viewer handles

  • PE32 and PE32+ files such as .exe, .dll, .sys, .efi, .ocx, .pyd and .scr.
  • DYNAMIC_BASE, NX_COMPAT, GUARD_CF and HIGH_ENTROPY_VA, and every other DLL characteristics bit by name.
  • The Authenticode entry, the PDB path from the debug directory and the .NET runtime header.
  • Linux ELF and Apple Mach-O files in the same viewer.

What it does not do

  • The flags are what the PE header asks for. The viewer does not check system policy, such as mandatory ASLR set in Windows Security.
  • The Signature row shows that Authenticode data is there. It does not verify the signature or the certificate.
  • For ELF files there is no security summary. The GNU_STACK and GNU_RELRO segments are listed on the Segments tab.
  • No disassembly.

Other options

  • dumpbin. Comes with Visual Studio. dumpbin /headers app.exe lists the DLL characteristics, such as Dynamic base and NX compatible.
  • PE-bear. A free PE viewer for Windows, macOS and Linux. It shows the optional header with the DLL characteristics flags.

Questions

Which flag means ASLR?

DYNAMIC_BASE (0x40) in the DLL characteristics. HIGH_ENTROPY_VA (0x20) asks for 64-bit ASLR on top of it.

Which flag means DEP?

NX_COMPAT (0x100). The viewer shows it as DEP on.

Does it work for DLLs and drivers?

Yes. .dll, .sys, .efi and other PE files show the same row.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
