Run an XPath on many XML files at once

Most XPath tools in an editor work on one open file, so collecting a value from fifty files means fifty queries. XML Formatter & XPath Tools runs XPath 1.0 on the open file for free, and lists every result with its line. Its Pro tool Run XPath on Every XML File in a Folder runs the same expression on every XML file under a folder, each with its own namespace prefixes, and writes the results as CSV, JSON or a Markdown report. It is part of Zovo Pro (USD 19 once), with 3 free tries on your computer.

Steps in VS Code

  1. Install XML Formatter & XPath Tools from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-xml-xpath-tools.
  2. Open one of the files and click the search button in the editor title, or run "XML: Evaluate XPath...". Type the XPath, such as //dependency/artifactId. Plain names also match a default namespace.
  3. Check the results in XPath Results. Click one to select it in the editor, or right-click it to copy its value or its XPath.
  4. For one file, the copy button of XPath Results copies all results as tab-separated lines with the line, the name and the value.
  5. For a folder, click the Zovo Pro line at the end of XPath Results, or right-click the folder in the Explorer and pick "Zovo Pro: Run XPath on Every XML File in a Folder".
  6. Pick CSV (file, line, kind, name, value), JSON or a Markdown report. The results open in an editor.

XPath on the open file, with clickable results, Copy Value, Copy XPath and Copy All Results, is free. So are Format Document, Minify XML, Copy XPath at Cursor, the XML Tree view and the well-formedness errors. The last 20 expressions are kept per workspace.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-xml-xpath-tools and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-xml-xpath-tools.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What XML Formatter & XPath Tools handles

  • Default namespaces, as in pom.xml, SVG, XAML and .csproj files. Plain names match them.
  • Prefixes declared in each file, such as //soap:Body/m:GetStockPrice.
  • Node results with file and line, and number, string or boolean results.

What it does not do

  • XPath 1.0 only. XPath 2.0 and 3.1, XQuery and XSLT are not supported.
  • Binary files and files larger than xmlXpathTools.maxFileMB (60 MB by default) are skipped.
  • XPath Results for one file lists up to 5,000 results (xmlXpathTools.xpath.maxResults). The count shows the full number.

Other options

  • xmlstarlet. A free command line tool. Its sel command runs an XPath on many files, but you declare the namespaces yourself.
  • Python with lxml. A short script with lxml.etree and a loop over the files. Free, needs Python and a namespace map.

Questions

Do I have to declare the namespaces?

No. Each file uses the prefixes it declares, and names without a prefix also match a default namespace.

Which files does the folder tool read?

XML files under the folder and its subfolders, such as .xml, .xsd, .csproj, .svg and .kml files.

Can I export the results of one file for free?

Yes. The copy button of XPath Results copies every result as tab-separated lines, ready to paste into a spreadsheet.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
