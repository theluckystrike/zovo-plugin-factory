Compare the formulas of two Excel workbooks

Two workbooks can show the same numbers while a formula behind them changed, and a diff of the values misses that. Excel Compare & XLSX Diff compares two workbooks cell by cell in VS Code, and its Formulas button compares the formulas themselves, such as =D2+E2 against =E2+F2. Values compares the results that are saved in the file. Both are free. Zovo Pro (USD 19 once) adds a diff report you can save and send, with 3 free tries on your computer.

Steps in VS Code

  1. Install Excel Compare & XLSX Diff from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-excel-compare.
  2. Select the two workbooks in the Explorer, right-click and pick Compare Selected Excel Files. To check your own edits before a commit, right-click one workbook and pick Compare with Git HEAD instead.
  3. Click Formulas in the toolbar. Each formula cell is now compared by its formula. A cell without a formula is compared by its value.
  4. Press N and P to step through the changed formulas, across sheets. Click a cell to see the old and the new formula in full, and click Copy to copy both.
  5. Click Values to compare the results again. A cell that changed in Values but not in Formulas changed because of its inputs. A cell that changed in Formulas but not in Values has a new formula with the same result.

What Excel Compare & XLSX Diff handles

  • Formulas in .xlsx, .xlsm, .xls and .ods workbooks.
  • Formulas as the file stores them, with a leading = and English function names such as SUM and IF.
  • Rows lined up and columns matched by their header, with a tab per sheet and its number of differences.
  • A note when merged cells differ.

What it does not do

  • The extension does not calculate formulas. Values compares the results that were saved in the file.
  • When a row or a column is inserted, Excel shifts the references of the formulas below it, for example =D5+E5 becomes =D6+E6. Formulas compares the text, so those cells show as changed.
  • CSV and TSV files have no formulas, so Formulas shows the same result as Values for them.
  • Cell formats, comments, charts and VBA macros are not compared.

Other options

  • Spreadsheet Compare. A Windows desktop tool from Microsoft that comes with some Office editions. It marks changed formulas and changed values in two workbooks.
  • openpyxl. A free Python library. It reads the formulas by default and the saved results with data_only=True, so a short script can compare either.

Questions

Why do the values match when a formula changed?

The new formula can give the same result for the data you have now, for example a SUM over a longer range that ends in empty cells. Formulas shows that change, and Values does not.

Does it recalculate the workbook?

No. It reads the formulas and the results that Excel saved in the file. Save the workbook in Excel first if the results are out of date.

Can I compare the formulas with the last commit?

Yes. Right-click the workbook in a Git repository, pick Compare with Git HEAD and click Formulas.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
