Check the dimensions of an STL file

An STL file stores bare coordinates with no unit. Slicers read them as millimetres, so a model saved in metres comes out 1000 times too small and one saved in inches 25.4 times too small. Click the .stl in 3D Model Viewer and read Size in the side panel, press B for the bounding box, or press M and click two points to measure. Size, bounds and Measure are free. Zovo Pro (USD 19 once) adds Print check, which reads the file in the unit you pick and gives the size in mm with the volume, weight and a watertight check, with 3 free tries.

Steps in VS Code

  1. Install 3D Model Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.3d-model-viewer.
  2. Click the .stl file in the Explorer. It opens in 3D Model Viewer with Z up. If another viewer opens, right-click the file and pick "Open in 3D Model Viewer".
  3. Read Size in the side panel (press P if the panel is hidden), for example 81.53 × 81.53 × 22.8 units. STL has no unit, so these are the raw numbers in the file.
  4. Compare them with the size the part should have. A part that should be about 80 mm wide but reads about 0.08 was saved in metres. One that reads about 3.2 was saved in inches.
  5. Press B for the bounding box. The status bar gives its size. Press M and click two points on the surface to get the distance with its X, Y and Z parts. A third click starts over, and Esc stops.
  6. If the scale is wrong, export the model again in millimetres from your CAD program, or scale it in the slicer: 2540 percent for inches, 100000 percent for metres.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.3d-model-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/3d-model-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What 3D Model Viewer handles

  • Binary and ASCII STL, with per-face colours when the file has them.
  • OBJ, PLY and 3MF files, and GLB and glTF in metres. 3MF sizes are in millimetres.
  • Point clouds from PLY files. Measure snaps to the nearest point.
  • Models up to 1 GB by default (setting modelViewer.maxFileMB).

What it does not do

  • STL, OBJ and PLY have no unit. Size, the bounding box and Measure show raw file numbers, labelled units.
  • Measure picks the nearest visible surface, so hide parts in the scene tree to reach a hidden face.
  • FBX, DAE, USD, STEP and IGES files do not open. Export an STL from your CAD program first.
  • The print check reads up to 3 million triangles, and its weight is an estimate. Your slicer gives the exact figure.

Other options

  • Your slicer. PrusaSlicer, Cura and other slicers show the size of an imported model and can scale it before you print.
  • Blender. Free 3D software. The sidebar shows the dimensions of the selected object, with a full scene to scale and edit it.

Questions

What unit does an STL file use?

None. The file holds plain numbers. Most CAD programs write millimetres for 3D printing, and slicers assume millimetres when they read it.

Why is my model tiny in the slicer?

The file was most likely saved in metres or inches. If Size reads about 0.08 for an 80 mm part, it is metres. If it reads about 3.2, it is inches.

Does the viewer change my file?

No. The model file is never written. Screenshot and the Pro reports go to new files you pick in a save dialog.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
