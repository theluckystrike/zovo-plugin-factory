Compare two images and see which pixels changed

To check what a UI change did, two images side by side are not enough. Image Editor & Image Resizer has a Compare two images tool with a slider, an onion skin and a Difference view. It counts the changed pixels, draws boxes around the changed areas, lists them largest first and saves the diff as a PNG. A threshold from 0 to 255 ignores small color noise. Compare two images is part of Zovo Pro (USD 19 once), with 3 free tries on your computer.

Steps in VS Code

  1. Install Image Editor from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-image-editor.
  2. Right-click the first image, such as the before screenshot, in the Explorer and pick "Zovo Pro: Compare two images". Or open it in the Image Editor and click Compare in its toolbar.
  3. Pick the second image in the file dialog that opens.
  4. Read the line at the top, such as "6,661 of 928,884 pixels changed (0.72%) in 2 areas, threshold 16". The Difference view marks the changed pixels and draws a box around each area.
  5. Switch to Slider or Onion skin to see the two images over each other. Move the Threshold to ignore small color changes, such as anti-aliasing.
  6. Open "Changed areas (largest first)" for the list of areas, and click Save diff PNG to keep the result.

Where Zovo Pro saves time

Opening, cropping, resizing, annotating, blurring and converting images are free. You can also open both images in VS Code tabs side by side, but VS Code itself has no pixel diff.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-image-editor and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-image-editor.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Image Editor handles

  • PNG, JPEG, WebP, GIF (first frame) and BMP images, also two different formats.
  • Images of different sizes. The shared area at the top left is compared, and a note says so.
  • Images over 40 megapixels, compared at a smaller scale with a note.
  • Up to 20 changed areas listed, largest first, with the total count.

What it does not do

  • Images of different sizes are compared from the top left corner, so a shifted screenshot shows changes everywhere.
  • It compares two images at a time. It is not a test runner for a folder of screenshots.
  • TIFF, HEIC, AVIF and SVG files are not opened.

Other options

  • ImageMagick. The free magick compare before.png after.png diff.png command writes a diff image from the command line.
  • pixelmatch. A small free JavaScript library for pixel diffs, used by many visual test tools. Needs a script.
  • Playwright. Its toHaveScreenshot check compares screenshots in automated tests. Free, made for test suites rather than one quick check.

Questions

Do the images need the same size?

No, but only the shared area at the top left is compared. Crop or resize first if one image is shifted.

What does the threshold do?

It is the largest color difference, from 0 to 255, that still counts as the same pixel. The default is 16. Raise it to ignore anti-aliasing and compression noise.

Can I save the diff?

Yes. Save diff PNG writes the diff as a PNG file, and the save dialog starts in the folder of the first image.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
