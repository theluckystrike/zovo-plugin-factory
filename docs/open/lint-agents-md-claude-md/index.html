Lint AGENTS.md and CLAUDE.md against your repo

Context Drift reads AGENTS.md, CLAUDE.md, GEMINI.md, .cursorrules, .cursor/rules and other agent instruction files and checks what they say against the repo. A renamed npm script, a moved file, the wrong package manager, an old Node version or a CLAUDE.md @import of a missing file shows as a squiggle and in the Problems panel, and many have a one-click fix. It runs locally with no network, and the same check runs in CI. Steps in VS Code

  1. Install Context Drift from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.context-drift.
  2. Open a folder that has an AGENTS.md, CLAUDE.md or other agent instruction file. Findings show up as squiggles and in the Problems panel, and the status bar shows Drift: N.
  3. Read each finding. CD001 is a script or make target that does not exist, CD002 a path that does not exist, CD003 the wrong package manager, CD004 a version that does not match files such as .nvmrc, CD007 an import of a missing file in CLAUDE.md or GEMINI.md, and CD008 an AGENTS.md over the Codex 32 KiB limit.
  4. Put the cursor on a finding and press Ctrl+. (Cmd+. on macOS). Pick the suggested fix, or "Apply all N Context Drift fixes in this file" when there are two or more.
  5. To keep a line on purpose, pick the fix that disables the check for this line, or add <!-- context-drift-disable-next-line CD002 --> above it.
  6. Run "Context Drift: Check Workspace" to check every instruction file. In CI, npx -y github:theluckystrike/context-drift --format github gives the same findings as pull request annotations.

What Context Drift handles

  • AGENTS.md, AGENTS.override.md, CLAUDE.md, CLAUDE.local.md, .claude/rules and GEMINI.md.
  • .cursorrules, .cursor/rules/*.mdc, Copilot, Windsurf, Cline, Devin and Kiro rule files, and SKILL.md.
  • npm, pnpm, yarn and bun scripts, and make, just, task, cargo, uv and poetry commands.
  • Node, Python and Go version claims against .nvmrc, engines, .python-version, go.mod and .tool-versions.

What it does not do

  • It checks facts against the repo, not the format of the files. For frontmatter and rule schemas, use agnix.
  • It skips negated, historical and example text, so it misses some real drift. On the repos measured, about 9 in 10 findings were true.
  • Files over 1 MB and lines over 4,000 characters are not checked.
  • The stale file check (CD006) is off by default and needs git.

Other options

  • agnix. Lints the format of agent files (frontmatter, rule schemas, hook and MCP config). It does not check them against the repo, so the two tools fit together.
  • A check by hand. Free. Run each command in AGENTS.md once after a big refactor. Slow, and easy to skip.

Questions

Why does Claude Code ignore part of my CLAUDE.md?

An @path import of a file that does not exist is skipped without a warning, so those instructions never load. Context Drift flags it as CD007 and offers the file with the same name when the repo has one.

Does it send my files anywhere?

No. It makes no network requests. In trusted workspaces it may run read-only git commands to skip ignored files.

Does it check the Codex size limit?

Yes. An AGENTS.md over 32 KiB gets one finding on the line where Codex stops reading.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
