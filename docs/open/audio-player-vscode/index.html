Play audio files in VS Code

VS Code's built-in Chromium has no Opus decoder, so a .opus file does not play in VS Code alone. The free Audio Player & WAV Player plays WAV, MP3, FLAC, Ogg and Opus files with a waveform for each channel, a spectrogram, an A-B loop and speeds from 0.25x to 2x with the pitch kept. It ships its own Opus decoder, and M4A and AAC files play after one click if you have ffmpeg. Zovo Pro (USD 19 once) adds a CSV report of every audio file in a folder, with 3 free tries.

Steps in VS Code

  1. Install Audio Player & WAV Player from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.audio-preview-vscode.
  2. Click a .wav, .mp3, .flac, .ogg, .opus or .m4a file in the Explorer. If another player opens, right-click the file and pick "Open in Audio Preview".
  3. Press Space to play or pause. Left and Right jump 5 seconds (1 second with Shift). Click the waveform to seek.
  4. Drag across the waveform to loop that part, or press [ and ] to set the loop start and end at the playhead. L turns the loop on or off.
  5. Pick a speed from 0.25x to 2x. The pitch stays the same, so slow speech is still clear.
  6. Read the header for the codec, sample rate, channels, bit depth, duration and bitrate, and the Tags panel for title, artist, album and the other tags.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.audio-preview-vscode and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/audio-preview-vscode.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Audio Player & WAV Player handles

  • WAV (PCM, float, A-law, mu-law, RF64), read in chunks so a 173 MB file does not freeze the editor.
  • MP3, FLAC and Ogg Vorbis with the decoder VS Code already has.
  • Opus in .opus or .ogg, with the bundled libopus decoder.
  • Up to 8 channels, each in its own waveform lane.

What it does not do

  • M4A and AAC need ffmpeg. Without it you see the codec, duration, bitrate and tags, and a message.
  • ALAC, AC-3 and other codecs VS Code cannot decode also need the ffmpeg button.
  • Compressed files are decoded whole. Above about 28 minutes of 44.1 kHz stereo they only play (setting audioPreview.maxDecodedMB).
  • It plays and checks files. It does not cut or edit them.

Other options

  • VLC. A free desktop player that plays Opus, MP3, FLAC, M4A and almost any other audio file, outside VS Code.
  • ffplay. ffplay file.opus plays a file from the terminal. Free, comes with ffmpeg.
  • VS Code's own preview. Plays common formats such as MP3 and WAV in a plain player, with no waveform, and does not play Opus.

Questions

Why does my .opus file not play in VS Code?

VS Code ships Chromium without an Opus decoder. This extension carries libopus compiled to WebAssembly, so Opus plays with nothing else to install.

Why does my M4A show a message instead of playing?

VS Code has no AAC decoder either. With ffmpeg installed, a Decode with ffmpeg button makes a WAV copy in the extension's storage and the file plays.

Is it free?

Yes. Playing, the waveform, the spectrogram and the loop are free. Only Folder Loudness Report and Normalize Loudness are Pro, with 3 free tries each.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
