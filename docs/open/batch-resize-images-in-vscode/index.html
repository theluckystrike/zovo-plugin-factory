Batch resize a folder of images in VS Code

Image Editor & Image Resizer is a free VS Code extension. It resizes, crops and converts one image at a time, with Undo and Save As, for free and with no limit. To do a whole folder at once, its Batch resize and convert tool fits every image in 1920, 1280 or 800 pixels, a percent or your own size, writes PNG, JPEG or WebP, and never overwrites the originals. Steps in VS Code

  1. Install Image Editor from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-image-editor.
  2. Click a .png, .jpg, .webp, .gif or .bmp file. It opens in VS Code's own preview. Click Edit Image at the top right, or right-click the file in the Explorer and pick Edit Image.
  3. Click Resize in the toolbar. Type the width or the height, in pixels or percent. With the ratio kept, the other side follows. Press Enter or click Apply resize. Downscaling goes in steps for a sharp result.
  4. Press Ctrl+S (Cmd+S on macOS) to save in the same format. JPEG and WebP use the quality from the settings (92 and 90). To keep the original, run "Image Editor: Save a copy as PNG, JPEG, WebP or BMP" instead. The extension of the new name picks the format.
  5. Undo and Revert work as in any VS Code editor, so you can try another size before you save. For a few images, repeat these steps. For a whole folder, use the batch tool below.

Where Zovo Pro saves time

Opening, crop, resize, rotate, flip, straighten, arrows, boxes, text, blur and pixelate, brightness, contrast and saturation, Save, and Save As to PNG, JPEG, WebP or BMP are free. There is no account and no network.

When a folder holds dozens of photos or screenshots, opening each one takes too long. Batch resize and convert a folder does every image in the folder in one run. It writes new files into a subfolder named resized, or next to the originals with -resized in the name. If a name is taken, a number is added, so no file is overwritten. A panel lists each file with its new size, and the summary shows how many bytes were saved. The other two Pro tools are Compress to a target size (the highest JPEG or WebP quality that fits a size such as 200 KB) and Compare two images (slider, onion skin and pixel diff).

With Batch resize and convert a folder (Zovo Pro)

  1. Click Batch resize in the editor toolbar (it uses the folder of the open image), or run "Image Editor: Batch resize and convert a folder (Pro)" from the Command Palette and pick a folder.
  2. Pick a size (Fit in 1920 x 1920, 1280 x 1280 or 800 x 800, 50 %, 25 %, Keep the size, your own largest width x height, or a percent). Then pick Keep each format, PNG, JPEG or WebP, and the JPEG and WebP quality (85 by default).
  3. Pick the subfolder "resized" or "-resized" next to the originals. The panel shows each file as it is written, with Cancel, and ends with the summary.

Batch resize and convert a folder works 3 times on your computer before it asks for a license, and a try counts only when you get a result. Opening a file shows no popup and no countdown.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-image-editor and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-image-editor.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Image Editor handles

  • PNG, JPEG, WebP, BMP and GIF (the first frame, written as PNG).
  • Output as PNG, JPEG or WebP in the batch tool, and also BMP with Save As in the editor.
  • Phone photos the right way up, because the EXIF orientation is applied first.
  • Images up to 100 megapixels and 32,767 pixels a side.

What it does not do

  • TIFF, HEIC, AVIF and SVG files are not opened.
  • GIF animations keep only the first frame.
  • The batch tool takes the images directly in the folder you pick, not those in subfolders, up to 2,000 at a time.
  • Save writes pixels only. EXIF data such as the camera or the GPS location is not copied into the new file.

Other options

  • ImageMagick. Free command-line tool. magick mogrify -path resized -resize 1920x1920> *.jpg shrinks every JPEG into a resized folder. Good for scripts.
  • sips on macOS. Built into macOS. sips -Z 1920 *.jpg fits each image in 1920 pixels, but it changes the files in place, so work on a copy.
  • PowerToys Image Resizer. Free from Microsoft for Windows. Select images in File Explorer, right-click and resize them to a preset size.

Questions

Does batch resize overwrite my photos?

No. New files go into a subfolder named resized, or next to the originals with -resized in the name. If a name is taken, a number is added.

Can I resize images without Zovo Pro?

Yes. Resizing, cropping and converting one image at a time in the editor is free, with no limit. Only the folder tool is Pro, and it has 3 free tries.

Does it make small images bigger?

Not with Fit in or your own largest width and height. Images that are already smaller keep their size. A percent above 100 does make them bigger.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
