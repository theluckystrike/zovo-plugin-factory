Merge PDF files in VS Code, offline

Open a PDF in PDF Viewer, click the page tools button and pick "Merge with other PDFs". You choose the other files and whether this PDF goes first or last, and a new PDF is saved on your computer. Reading, dark mode, search and highlights are free. Merge is a Zovo Pro tool (USD 19 once) with 3 free tries.

Steps in VS Code

  1. Install PDF Reader from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.pdf-viewer-dark.
  2. Click the first PDF in the Explorer. It opens in PDF Viewer.
  3. Click the page tools button in the toolbar (the stacked pages icon), or run "PDF: Page Tools (Pro)..." from the Command Palette or the ... menu of the PDF tab.
  4. Pick "Merge with other PDFs" and select the other PDF files.
  5. Choose whether the open PDF goes first or last, then pick a name for the new PDF in the save dialog.
  6. The first 3 runs are free on your computer. A try counts only when the tool gives a result.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.pdf-viewer-dark and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/pdf-viewer-dark.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What PDF Reader handles

  • Merge with other PDFs: pick the files, then choose whether the open PDF goes first or last.
  • The new PDF is written by the same pdf.js that shows the page, on your computer. Nothing is uploaded.
  • Links, the outline and form fields come along. A PDF with a password keeps the same password.
  • The source files are not changed unless you pick one of them in the save dialog.
  • Split into several PDFs every N pages, one file per page, or at the ranges you type.

What it does not do

  • It saves whole pages. It does not rotate pages yet, and it does not edit text or images on a page.
  • It does not fill forms or print.
  • Big files load fully into memory. Above 200 MB it asks first (setting pdfViewer.maxFileSizeMB).
  • If you only merge PDFs now and then and do not use VS Code, a desktop tool such as PDFsam Basic or macOS Preview is simpler.

Other options

  • PDFsam Basic. Free and open source desktop app for Windows, macOS and Linux that merges, splits and rotates PDFs offline. For people who do not work in VS Code it is the simpler choice.
  • qpdf. Free command-line tool. qpdf --empty --pages a.pdf b.pdf -- out.pdf merges two files. Good for scripts and builds.
  • macOS Preview. Built into macOS. Open a PDF, show the thumbnails and drag pages of another PDF into the sidebar, then export. No install needed on a Mac.
  • iLovePDF and other online sites. Merge in the browser with no install. Your files are uploaded to their servers, so avoid them for contracts and other private PDFs.

Questions

Does merging upload my PDFs anywhere?

No. The new PDF is written on your computer by the bundled pdf.js. The extension has no telemetry, and the only network call is the one you start with "Unlock with GitHub Sponsors".

Can I set the page order of the merged file?

Merge puts the open PDF first or last. To move pages after that, open the new PDF and use "Extract pages to a new PDF" with an order such as 5, 1-4.

Does it work in Cursor or Windsurf?

Yes. Cursor and Windsurf install extensions from Open VSX, where PDF Viewer is listed. The Pro tools work the same way there.
