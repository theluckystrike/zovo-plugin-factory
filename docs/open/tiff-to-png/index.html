Convert TIFF to PNG without losing quality

PNG is lossless, so a TIFF to PNG conversion keeps every pixel when the tool keeps the bit depth. Many converters save 8-bit only, which drops detail from 16-bit microscopy or scans. TIFF Viewer in VS Code views TIFF for free, and its Pro tool Export pages saves a page or every page as PNG with "stored values": 8 and 16-bit data keep their exact values. Batch convert does a whole folder. Each has 3 free tries, then Zovo Pro is USD 19 once.

Steps in VS Code

  1. Install TIFF Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.tiff-viewer.
  2. Click the .tif or .tiff file in the Explorer. It opens in TIFF Viewer, with a page strip for multi-page files.
  3. Check the pages, channels and bit depth. Viewing is free, offline and without sign-in.

Where Zovo Pro saves time

Viewing TIFF and BigTIFF files, every page, channels, 16-bit and float data and GeoTIFF tags is free.

Export pages lets you pick "as shown" (8-bit, the view you see) or "stored values" (8 and 16-bit data keep their exact values). Signed, 32-bit and float data are mapped to 16 bits over the shown range, and the PNG text says how to get the values back. GeoTIFF pages also get a .pgw world file and a .geojson footprint for QGIS or ArcGIS. Batch convert does every TIFF in a folder and writes convert-report.csv.

With Export pages (Zovo Pro)

  1. Press Export pages in the toolbar and pick this page or every page.
  2. Pick "stored values" to keep 16-bit data, or "as shown" for an 8-bit PNG of what you see.
  3. For a folder, right-click it and run "TIFF Viewer: Batch Convert TIFF Folder to PNG". Choose the first page or every page.
  4. The PNG files go to a png folder next to the TIFFs, with convert-report.csv listing each page, its size and bit depth.

Export pages works 3 times on your computer before it asks for a license, and a try counts only when you get a result. Opening a file shows no popup and no countdown.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.tiff-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/tiff-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What TIFF Viewer handles

  • Every page of a multi-page TIFF.
  • 8 and 16-bit values kept exactly.
  • GeoTIFF world file and footprint.
  • A folder with subfolders.

What it does not do

  • Float and 32-bit data become 16-bit PNG over the shown range.
  • It writes PNG only.

Other options

  • ImageMagick. magick in.tif out.png, or mogrify -format png *.tif for a folder. Free; check the bit depth flags for 16-bit files.
  • GIMP or Photoshop. Open and export as PNG, one file at a time.
  • Online converters. Many sites convert TIFF to PNG after an upload. Avoid them for private images.

Questions

Does TIFF to PNG lose quality?

No, PNG is lossless. Quality is lost only if the tool reduces 16-bit data to 8-bit. Pick "stored values" to keep it.

Are my images uploaded?

No. TIFF Viewer works offline.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
