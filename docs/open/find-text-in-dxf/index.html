Find text in a DXF drawing

A text search on the raw .dxf finds the string but not where it sits on the drawing. DXF Viewer opens the drawing in VS Code. Press Ctrl+F (Cmd+F on a Mac) and type part of the text, and it frames each match of TEXT, MTEXT and block attributes such as tag numbers, with a count like "1 of 3". Searching is free. Zovo Pro (USD 19 once) adds Extract drawing data, which saves all the text of one drawing or a folder of drawings to CSV with layer and position, with 3 free tries.

Steps in VS Code

  1. Install DXF Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.dxf-viewer.
  2. Click the .dxf file in the Explorer. DXF Viewer reads ASCII and binary DXF from R12 to AutoCAD 2018.
  3. Press Ctrl+F (Cmd+F on a Mac), or click the Find text box in the top bar, and type part of the text. Upper and lower case do not matter.
  4. The view zooms to the first match and the count shows "1 of 3". Enter goes to the next match and Shift+Enter to the one before. The count reads "No match" when nothing is found.
  5. No match, but you know the text is there? Find searches only the sheet on screen and skips hidden layers. Pick Model or another layout in the Sheet list, or click All in the Layers panel, and search again.
  6. Press M to measure from the match, or click Export PNG or Export SVG to save the framed view for a ticket.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.dxf-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/dxf-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What DXF Viewer handles

  • TEXT, MTEXT and block attributes such as tag numbers, matched as part of a word.
  • Paper space sheets and model space, each searched on its own.
  • Live reload. When you export the DXF again, the view keeps its zoom, sheet, layers and search.
  • Files up to 500 MB by default (setting dxfViewer.maxFileMB, up to 2048).

What it does not do

  • Find covers only the sheet on screen and the visible layers.
  • Text is drawn in a sans-serif font, not the SHX or TrueType font named in the file, so text widths differ a little from CAD.
  • DWG files are not read. A .dwg opens a page with its version and the ways to save a DXF copy.
  • The free viewer searches one drawing at a time. A folder search needs the Pro extract.

Other options

  • A text search on the .dxf. VS Code search or grep finds the string in the raw file, among coordinates and group codes, and shows no place on the drawing.
  • LibreCAD or QCAD. Free desktop CAD programs that open DXF drawings, outside VS Code.

Questions

Does find search hidden layers?

No. It skips layers you turned off and layers that are off or frozen in the file. Click All in the Layers panel to search them too.

Can I search every drawing in a folder?

With the Pro tool Extract drawing data. Pick All text on a folder and filter the CSV, which has a File column.

Is the drawing changed?

No. The only file DXF Viewer writes is an export you pick in a save dialog, and it refuses to write over a drawing.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
