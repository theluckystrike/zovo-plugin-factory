Minify an XML file in VS Code

To make an XML file smaller, you remove the whitespace between tags, but a careless minifier can also change text or break CDATA. XML Formatter & XPath Tools has "XML: Minify XML", which removes only the whitespace between tags in the file or the selection. Text, CDATA and attribute values stay as they are, and comments stay unless you turn on a setting. Minify is free, and Zovo Pro (USD 19 once) compares two XML files while ignoring formatting, with 3 free tries.

Free, MIT license. Extension ID zovo.zovo-xml-xpath-tools, version 0.1.1. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install XML Formatter & XPath Tools from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-xml-xpath-tools.
  2. Open the XML file. To minify only a part, select it.
  3. Run "XML: Minify XML" from the Command Palette. With a selection, it is also on the right-click menu.
  4. Comments stay. To remove them too, turn on xmlXpathTools.minify.removeComments in Settings.
  5. If the file is not well formed, nothing changes and a message names the line of the error.
  6. To make the file readable again, press Shift+Alt+F (Shift+Option+F on a Mac).

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-xml-xpath-tools and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-xml-xpath-tools.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What XML Formatter & XPath Tools handles

  • A whole file or only the selected part.
  • Text, CDATA and attribute values, which stay as they are.
  • Comments, which stay by default.

What it does not do

  • Minify works in the open editor. No command minifies a file on disk or a whole folder.
  • A file that is not well formed is not minified.
  • Files over 50 MB are not passed to extensions by VS Code, so they cannot be minified here.

Other options

  • xmllint (libxml2). A free command line tool that can drop whitespace-only text between tags. Good in a build step.
  • XML Tools by Josh Johnson. Another VS Code extension with a minify command.

Questions

Does Minify remove comments?

Not by default. Turn on xmlXpathTools.minify.removeComments to remove them too.

Can I minify only part of a file?

Yes. Select the part and run XML: Minify XML.

How do I get the readable layout back?

Press Shift+Alt+F to format the file. Format also changes only the whitespace between tags.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
