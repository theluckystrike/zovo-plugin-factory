Compare two large Excel or CSV files without freezing VS Code

Excel Compare & XLSX Diff reads and compares the two files in a separate worker thread with a memory cap, and its grid draws only the rows on screen, so a sheet with 300,000 rows scrolls like a short one. By default it compares files up to 200 MB and 300,000 rows per sheet, and in Settings you can raise the row limit to 1,000,000 and the size limit to 2,000 MB. When a limit cuts a sheet, a note in the view says so. Comparing is free, and Zovo Pro (USD 19 once) adds a diff report you can save, with 3 free tries on your computer.

Steps in VS Code

  1. Install Excel Compare & XLSX Diff from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-excel-compare.
  2. Select the two files in the Explorer, right-click and pick Compare Selected Excel Files. While it works, the view says Reading the first file, Reading the second file and then Comparing.
  3. Read the notes above the grid. A note such as "Only the first 300,000 of 450,000 rows were read (row limit)." tells you that a limit cut the sheet.
  4. To compare more rows, open Settings, search for excelCompare.maxRows and set up to 1,000,000. For a file over 200 MB, raise excelCompare.maxFileSizeMB, up to 2,000.
  5. Run the comparison again. The new limits apply to the next comparison.
  6. Press N and P to jump from change to change instead of scrolling. The tab of each sheet shows its number of differences.

What Excel Compare & XLSX Diff handles

  • 300,000 rows per sheet by default, up to 1,000,000 with excelCompare.maxRows.
  • Files up to 200 MB by default, up to 2,000 MB with excelCompare.maxFileSizeMB.
  • CSV and TSV files read as a stream, with the encoding and the delimiter detected.
  • A worker thread with a 2,048 MB memory cap, so a file that needs more stops with a message and VS Code keeps running.

What it does not do

  • 1,000 columns and 200 sheets per file, and 12 million cells per workbook. Sheets after the cell limit are not read, with a note.
  • A workbook larger than the size limit is refused. A CSV file larger than the limit is read up to the limit, with a note.
  • A workbook that would inflate to more than 600 MB, or is compressed like a zip bomb, is not opened.
  • Reading one file, or comparing, stops with a message when it takes longer than 90 seconds.
  • Files on a remote or virtual file system are read up to 256 MB.

Other options

  • csv-diff. A free Python tool that compares two CSV files by a key column and lists the added, removed and changed rows. It runs in a terminal.
  • pandas. Read both files with read_excel or read_csv and compare them in a script. Free, needs Python and enough memory for both files.
  • diff or git diff. A text diff of two CSV files is fast at any size, but it compares lines, so a changed column order shows every line as changed.

Questions

How many rows can it compare?

300,000 rows per sheet by default, and up to 1,000,000 when you raise excelCompare.maxRows. A longer sheet is compared up to that row, with a note.

Will a huge file crash VS Code?

No. Reading runs in a separate worker with a memory cap and a time limit. When a file needs more, the comparison stops with a message and VS Code keeps running.

Are the files uploaded?

No. The files are read on your computer, and the extension makes no network requests.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
