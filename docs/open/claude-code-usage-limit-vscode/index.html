Check your Claude Code 5-hour and weekly limit in VS Code

Claude Code saves its own last reading of your plan usage, the numbers on claude.ai/settings/usage, in its config file. AI Usage Meter reads that reading and shows the 5-hour and weekly limit in percent in the VS Code status bar, such as Claude 5h 34% wk 61%, next to today's tokens and estimated cost. Hover it for the reset times, click it for a dashboard. There is no login, no API call and no token. Zovo Pro (USD 19 once) adds a CSV export and a usage report for a month or period, with 3 free tries each.

Steps in VS Code

  1. Install AI Usage Meter from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.ai-usage-meter.
  2. Use Claude Code as usual. The status bar item appears at the bottom right once the meter has read your session folders.
  3. Read the limit in the status bar. The item turns yellow when any limit reaches 90%.
  4. Hover the item to see each limit with its reset clock time and how long ago Claude Code saved the reading. A window that has already reset shows "reset" instead of an old percent.
  5. Click the item, or run "AI Usage: Open Usage Dashboard", for tiles with each limit, a chart per day and tables by project, model and day.
  6. If you run several accounts with CLAUDE_CONFIG_DIR, such as ~/.claude and ~/.claude-work, each folder shows as its own account with its own limits.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.ai-usage-meter and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/ai-usage-meter.

What AI Usage Meter handles

  • The Claude Code 5-hour and weekly limit, and the weekly limit for one model when your plan has it.
  • Several Claude Code accounts in ~/.claude-* folders or CLAUDE_CONFIG_DIR.
  • Codex 5-hour and weekly limits from the newest Codex session file.
  • Today's tokens and estimated cost for Claude Code, Codex and Gemini CLI.

What it does not do

  • The percent is only as fresh as Claude Code's last saved reading, which it updates while you use it.
  • Older Claude Code versions do not save a reading. Then the meter shows a clock for the current 5-hour block instead.
  • Use on another computer or in the claude.ai app is not in your local files and is not counted.
  • Cost is an estimate from a price table. On a Pro or Max plan you are not billed per token.

Other options

  • claude.ai usage page. Shows your plan usage in the browser. You have to leave the editor to check it.
  • ccusage. A free command line tool that reads the Claude Code log files and prints tokens and cost per day or per session in the terminal.

Questions

Does it need my Claude login or an API key?

No. It reads the limit numbers Claude Code already saved in ~/.claude.json, and only those numbers and their reset times.

Why does the percent not change right away?

Claude Code saves a new reading while you use it. The tooltip says how long ago that was.

Can I hide the cost?

Yes. Set aiUsageMeter.statusBarCost to false to show only tokens and limits.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
