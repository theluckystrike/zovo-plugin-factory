Fix a CSV that opens in one column or with broken characters

A CSV opens in one column when the program expects commas and the file uses semicolons, tabs or pipes, and letters break when the encoding is guessed wrong. Spreadsheet Editor finds the delimiter and the encoding on its own, and the Delimiter and Encoding lists in its toolbar fix a wrong guess. A save keeps the delimiter, quotes, encoding and byte order mark. Zovo Pro (USD 19 once) adds Save Filtered Rows as a New File, which writes a comma-separated UTF-8 copy, with 3 free tries.

Steps in VS Code

  1. Install Spreadsheet Editor from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-spreadsheet-editor.
  2. Right-click the .csv file in the Explorer and pick "Open in Spreadsheet Editor", or click the table icon at the top right of the text editor.
  3. If the columns are still wrong, pick the separator in the Delimiter list (Comma, Semicolon, Tab, Pipe, Colon, Space), or pick Other... and type any one character.
  4. If letters look broken, pick the encoding in the Encoding list, such as Windows-1252, UTF-16 LE or Shift_JIS.
  5. Set Quote, Comments (#, // or ;) and Header row if the file needs them. The choices are kept for this file.
  6. Edit and press Ctrl+S. The file is saved with its own delimiter, quotes, encoding, byte order mark and line endings.

Where Zovo Pro saves time

Opening, the Delimiter, Quote, Encoding and Comments lists, editing and saving are free, with no limit on rows or edits. Semicolon, tab, pipe, UTF-16 and Windows-1252 files usually open with the right settings on their own. If you type a character that the file's encoding cannot hold, the save stops and offers a UTF-8 copy.

Another program may need a plain comma-separated UTF-8 file. Save Filtered Rows as a New File writes the rows shown, in their sorted order, to a new CSV with commas in UTF-8, a TSV file or an XLSX workbook. With no filter, that is every row. The open file is not changed. The other Pro tools in Spreadsheet Editor are Find and Replace in CSV Files and editing files past the free size limits.

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-spreadsheet-editor and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-spreadsheet-editor.

  4. Then use it the same way as in VS Code.

What Spreadsheet Editor handles

  • Comma, semicolon, tab, pipe, colon and space delimiters, or any other single character.
  • Auto plus 13 encodings, from UTF-8, UTF-16 LE and BE and Windows-1252 to KOI8-R, EUC-JP, GB18030, Big5 and EUC-KR.
  • Double quote, single quote or no quote character, and comment lines that start with #, // or ;.
  • Files with and without a header row.

What it does not do

  • A delimiter is one character. Two-character separators are not supported.
  • Changing the Delimiter list changes how the file is read. It does not turn a semicolon file into a comma file on save.
  • The encoding list holds 13 encodings. Other code pages are not read.
  • Free editing stops at 512 MB per file.

Other options

Questions

Why does Excel put my CSV in one column?

Excel splits a double-clicked CSV with the list separator of your region. A file written with semicolons opens in one column where the separator is a comma, and the other way round.

Will saving change my delimiter or encoding?

No. Rows you did not touch are saved byte for byte, and the file keeps its delimiter, quotes, encoding, byte order mark and line endings.

Can I convert a semicolon CSV to a comma CSV?

Yes, with Save Filtered Rows as a New File, a Zovo Pro tool with 3 free tries. It writes a new comma-separated UTF-8 file and leaves the original as it is.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
