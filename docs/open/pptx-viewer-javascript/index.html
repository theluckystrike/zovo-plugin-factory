Show PPTX slides in a web page with JavaScript

Load the Zovo Doc Viewer web component with one script tag from jsDelivr, then put <zovo-doc-viewer src="deck.pptx"> in your page. The browser reads the file, so it is never uploaded to Microsoft, Google or anyone else. PPTX support is in beta: most decks draw well, and some shapes, SmartArt and charts may look different from PowerPoint.

The code

<script type="module" src="https://cdn.jsdelivr.net/gh/theluckystrike/zovo-doc-viewer@v0.1.0/dist/zovo-doc-viewer.js"></script>

<zovo-doc-viewer src="/files/deck.pptx" theme="auto"></zovo-doc-viewer>

From JavaScript, with a file the user picked or dropped:

const viewer = document.querySelector('zovo-doc-viewer');
await viewer.load(file);   // a File, Blob, ArrayBuffer, typed array or URL
viewer.addEventListener('error', (e) => console.log(e.detail.code));   // 'pptx-beta' when a deck cannot be drawn

Steps

  1. Add the script tag from jsDelivr (shown above) to your page. It loads the element, about 10 KB gzipped.
  2. Put a <zovo-doc-viewer> element where the slides should show, with src pointing to the .pptx file.
  3. Or call viewer.load(file) with a File from an input or a drop, a Blob, an ArrayBuffer or a URL.
  4. Listen for the error event. A deck that cannot be drawn sends code: "pptx-beta", and the viewer shows a clear message.
  5. To host it yourself, copy the dist/ folder to your site and load dist/zovo-doc-viewer.js from there.

What it handles

  • PPTX, PPSX and POTX slides, drawn by pptx-preview 1.0.7.
  • The same element opens DOCX, ODT, XLSX, XLS, ODS, CSV, TSV, Parquet and PDF files. The format is found from the file content first and its name second.
  • A toolbar with zoom, find, page navigation, print, download and full screen, and light, dark and auto themes.
  • Each format has its own file that loads only when a file of that type opens. The PPTX code is 393 KB gzipped and loads only for a PPTX.
  • Examples for plain HTML, React and Vue are in the examples/ folder of the repository.

What it does not do

  • PPTX is beta. Some shapes, SmartArt and charts may look different from PowerPoint.
  • The source code of pptx-preview is not public, so the viewer ships its published build unchanged, in dist/formats/pptx.js. Delete that file from a self-hosted copy to leave PPTX out; the other formats keep working.
  • Zovo Doc Viewer is free under GPL-3.0-or-later. On public pages without a licence key, a small "Zovo Doc Viewer" link shows in the corner of the viewer. Closed-source sites need a commercial licence; see COMMERCIAL.md in the repository.

Other options

  • pptx-preview. The npm package that draws the slides inside this viewer. 824,412 downloads from 10 October to 8 November 2026. Use it directly when you only need PPTX and want to build your own toolbar.
  • docx-preview. Renders Word files, not slides. 11,629,421 downloads in the same 30 days. Zovo Doc Viewer uses it for DOCX.
  • Office viewer embeds. Online Office viewers take a public URL of the file, so the file has to be on the internet and is read by their servers. Private and intranet files do not work that way.

Questions

Can I show a PPTX file in the browser without uploading it?

Yes. Zovo Doc Viewer reads the file in the browser with JavaScript. Nothing is sent to a server, so private and intranet files work.

Do I need a build step or a framework?

No. One <script type="module"> tag from jsDelivr is enough. It is a standard web component, so it also works inside React and Vue; the repository has examples for both.

Which version should I load from jsDelivr?

Pin the tag, for example @v0.1.0, as in the snippet on this page. A pinned tag does not change under you.

Is it free for commercial sites?

It is free under GPL-3.0-or-later. A closed-source site or app needs the commercial licence described in COMMERCIAL.md in the repository.
