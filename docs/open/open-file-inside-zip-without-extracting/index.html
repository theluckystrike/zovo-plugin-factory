Open a file inside a ZIP without extracting it

ZIP Viewer & Archive Explorer is a free VS Code extension. Click a .zip, .jar, .vsix, .tar, .tar.gz or .gz file and it lists the folders and files inside. Double-click a file and it opens in a normal read-only tab, read straight from the archive, so nothing is unpacked. Code gets syntax colors and images open in the image preview. Browsing, opening entries, name search and extraction are free. Zovo Pro (USD 19 once) adds compare two archives, export the entry list and find a file in all archives of a folder, with 3 free tries each.

Steps in VS Code

  1. Install ZIP Viewer & Archive Explorer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zip-archive-explorer.
  2. Click a .zip, .jar, .vsix, .tar, .tar.gz, .tgz or .gz file in the Explorer. It opens as a list of folders and files with size, packed size, ratio and date. For .war, .whl, .nupkg, .apk or .epub, right-click and pick Open in Archive Explorer.
  3. Find the file. Double-click a folder, use the path bar at the top, or press Backspace to go up. Or type in the search box. * and ? work as wildcards, for example *.json.
  4. Double-click the file or press Enter. It opens read-only in a normal tab. Open to the side puts it next to the archive. A ZIP inside the ZIP opens as another archive.
  5. The Archive Explorer section of the Explorer lists every archive you opened. Right-click an entry there for Open to the Side, Extract... or Copy Path.
  6. To change the file, select it and click Extract.... One file goes through a save dialog. Names with .. or an absolute path are never written, and the archive itself is never changed.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zip-archive-explorer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zip-archive-explorer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What ZIP Viewer & Archive Explorer handles

  • ZIP, JAR and VSIX, with Stored and Deflate entries, ZIP64 and self-extracting archives.
  • TAR (ustar, GNU long names and pax headers), TAR.GZ, TGZ and single GZ files.
  • WAR, EAR, WHL, NUPKG, APK, AAR, XPI and EPUB through Open in Archive Explorer.
  • Archives with up to 200,000 entries, read from disk with range reads, so a large ZIP is not loaded whole.

What it does not do

  • Entries compressed with BZIP2, LZMA, Zstandard or Deflate64, and encrypted entries, are listed but not opened.
  • 7z, RAR, XZ and BZ2 files are not supported.
  • Entries are read-only. Extract a file to change it.
  • Entries over 512 MB do not open in a tab but can still be extracted. A .tar.gz is unpacked in memory, up to 2 GB by default.

Other options

  • 7-Zip. Free archive manager for Windows. Its file manager lists a ZIP, 7z or RAR file and opens a file from it with a double-click.
  • unzip -p. Free on most systems. unzip -p archive.zip path/in/zip.txt prints one file from the ZIP without writing anything to disk.
  • tar -xOf. Free on most systems. tar -xOf archive.tar.gz path/in/tar.txt prints one file from a TAR or TAR.GZ to the terminal.

Questions

Is the file copied to a temp folder when I open it?

No. The entry is read from the archive into a read-only tab. Only Extract writes files to disk.

Can I edit a file inside the ZIP?

No. Entries are read-only and the archive is never changed. Extract the file, edit it, and pack the archive again with another tool.

Are my archives uploaded?

No. The extension works offline, makes no network calls and has no telemetry.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
