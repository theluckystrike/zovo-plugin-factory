Claude Code token usage report

/cost shows the current session, and the free ccusage command line tool reports daily usage. Free, MIT license. Extension ID zovo.agent-session-viewer, version 0.3.2. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install Agent Session Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.agent-session-viewer.
  2. Open the Sessions view in VS Code. Reading and searching sessions is free.
  3. Pick the project you want to report on.

Where Zovo Pro saves time

Reading, searching, resuming and exporting one session to Markdown are free. The usage and cost report is the Pro tool.

The CSV has one row per day, project and model, ready for client billing or a spreadsheet. A message copied into a resumed session counts once, and subagents count with the session that started them.

With Usage and cost report (Zovo Pro)

  1. Run Usage and cost report from the Command Palette (type Agent Session).
  2. Choose all sessions, one project or one tool, and a date range.
  3. Save the Markdown report and the CSV file.

Usage and cost report works 3 times on your computer before it asks for a license, and a try counts only when you get a result. Opening a file shows no popup and no countdown.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.agent-session-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/agent-session-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Agent Session Viewer handles

  • Per project, model and day.
  • Subagents counted with their parent session.
  • Resumed sessions counted once.

What it does not do

  • The cost is an estimate at API list prices, not your plan's bill.
  • It reads sessions on this computer only. For an organization, use the Admin API usage report.

Other options

  • ccusage. npx ccusage@latest prints daily, monthly and session reports in the terminal. Free and widely used.
  • /cost. Built into Claude Code, for the current session.
  • Claude Code usage report API. For organizations, through the Admin API.

Questions

Is the cost exact?

No. It is an estimate at API list prices. A subscription plan bills differently.

Is anything uploaded?

No. The report is built from the session files on your computer.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
