Open a .pkl pickle file in VS Code without running it

Loading a pickle with Python can run code that is inside the file. The free Pickle Viewer & PKL Viewer by Zovo reads .pkl and .pickle files without Python and without running anything. It shows the data as a tree, NumPy arrays with stats, pandas DataFrames as tables, the opcodes, and a Safety tab that lists every call the pickle would make.

Install in VS CodeMarketplace pageOpen VSX (Cursor, Windsurf, VSCodium)

Free, MIT license. Extension ID zovo.zovo-pickle-viewer, version 0.2.0. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install Pickle Viewer & PKL Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-pickle-viewer.
  2. Click a .pkl or .pickle file. For .p files, right-click and pick "Open in PKL Viewer".
  3. Read the Tree tab. Classes that need their package show as module.Class placeholders.
  4. Open Arrays for NumPy data and Tables for pandas DataFrames.
  5. Check the Safety tab. A red banner opens it for you when a file calls something risky such as os.system.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-pickle-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-pickle-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Pickle Viewer & PKL Viewer handles

  • Pickle protocols 0 to 5, NumPy 1.x and 2.x, pandas 2.x and older layouts.
  • Ratings for every call: Risky, Check, Needs package and Data type.

What it does not do

  • A clean Safety list is not a promise that a file is safe. Only load pickles you trust in Python.
  • Files over 512 MB show a message. Containers show their first 1,000 items and tables their first 1,000 rows.
  • PyTorch .pt archives and joblib files with compressed arrays do not open here. Use Tensor Viewer for .pt files.

Other options

Questions

Is it dangerous to open a pickle file?

Loading it with pickle.load or pandas.read_pickle can run code from the file. Reading it with this viewer does not, because the reader never imports or calls anything.

Do I need Python installed?

No.

Can it open PyTorch .pt files?

No. Tensor Viewer opens those, also without running the pickle.
