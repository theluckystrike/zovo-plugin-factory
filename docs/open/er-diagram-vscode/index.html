See an ER diagram of your database in VS Code

VS Code has no ER diagram view of its own. To draw one from a live database, install Postgres & MySQL Query Client by Zovo, add a connection, right-click a schema and pick "ER Diagram (Pro)". It reads the tables, columns, keys and foreign keys and draws them with the links. Drag tables to arrange them and save the diagram as SVG. The client is free; the ER diagram is part of Zovo Pro (USD 19 once) and works 3 times without a key.

Install in VS CodeMarketplace pageOpen VSX (Cursor, Windsurf, VSCodium)JetBrains IDEs

Free, MIT license. Extension ID zovo.zovo-sql-client, version 0.2.3. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install Postgres & MySQL Query Client from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-sql-client.
  2. Open the SQL Client view in the activity bar and click Add Connection. Paste a postgres:// or mysql:// URL or fill in the form, then Save.
  3. Expand the connection to the schema you want.
  4. Right-click the schema and pick "ER Diagram (Pro)", or run it from the Command Palette.
  5. Drag tables to arrange them, then save the diagram as an SVG file for docs or a pull request.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-sql-client and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-sql-client.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Postgres & MySQL Query Client handles

  • PostgreSQL, MySQL, MariaDB and SQLite.
  • Tables with their columns, types and primary keys, and a line for each foreign key.
  • It reads the schema from the database, so the diagram matches what is deployed, not what a migration file says.
  • The free client next to it: unlimited connections, SQL with Ctrl+Enter, row edits and streamed export.

What it does not do

  • It draws an existing schema. It does not design a new one or write DDL from a drawing.
  • No SQL Server, Oracle or MongoDB.
  • The diagram is saved as SVG. There is no PNG or PDF export.

Questions

Can VS Code draw an ER diagram from a database?

Not by itself. You need an extension that connects to the database, such as Postgres & MySQL Query Client, or one that reads your ORM or migration files.

Is the ER diagram free?

It is part of Zovo Pro, USD 19 once, and works 3 times on your computer before it asks. Connecting, querying, editing rows and exporting stay free.

Does it change my database?

No. It only reads the schema. Saving the SVG writes a file on your computer.
