Convert a PDF or Word file to Markdown and keep the images

Markdown is plain text, so the pictures of a converted document must be saved as separate files and linked. A plain conversion skips that and leaves a placeholder. In Convert to Markdown, the Pro tool Convert to Markdown with Images saves the pictures of a PDF, Word, PowerPoint, OpenDocument, EPUB or HTML file to a name_assets folder next to the .md file and links them with relative paths, so the Markdown preview shows them. It is part of Zovo Pro (USD 19 once), with 3 free tries on your computer, and the plain conversion stays free.

Steps in VS Code

  1. Install Convert to Markdown from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-convert-to-markdown.
  2. Right-click a .pdf, .docx, .pptx, .odt, .epub or .html file in the Explorer and pick "Zovo Pro: Convert to Markdown with Images". You can also run "Convert to Markdown: Convert to Markdown with Images (Pro)" from the Command Palette.
  3. Pick where to save the .md file. The name next to the source is filled in for you.
  4. The pictures go to a folder named after the Markdown file, such as report_assets, as image-001.png, image-002.jpg and so on. The Markdown opens beside the source and links to them with relative paths.
  5. Open the Markdown preview to check the pictures. In a PDF, pictures smaller than 24 points are skipped, and a logo repeated on every page is saved once.
  6. If the file has no pictures, the Markdown is still saved and no free try is used.

Where Zovo Pro saves time

Convert to Markdown and Copy as Markdown are free for PDF, DOCX, PPTX, XLSX, XLS, ODS, CSV, HTML, EPUB, ODT and RTF files, with no network calls. In the free conversion each picture becomes a placeholder, with its alt text when the file has one.

Saving each picture by hand from Word or a PDF reader, and then linking it in the Markdown, takes long in a document with many figures. Convert to Markdown with Images does both in one run. What Convert to Markdown handles

  • Word (.docx, .docm, .dotx): each picture in its place in the text.
  • PowerPoint (.pptx, .pptm, .ppsx, .potx): the pictures of each slide, under the heading of that slide.
  • PDF: each picture decoded and saved as PNG, placed by its position among the lines of the page, with alt text such as "Image 3 on page 2".
  • OpenDocument text, EPUB chapters, and HTML files with pictures embedded as data URIs.
  • Up to 2,000 pictures or 512 MB of pictures per file.

What it does not do

  • A scanned PDF has no text to convert. Text recognition (OCR) is not included.
  • Word pictures in EMF or WMF format are saved as they are, and the Markdown preview cannot show them.
  • Charts, SmartArt and video in slides are named in the text, not saved as pictures.
  • Past 2,000 pictures or 512 MB, the rest stay placeholders and a note says how many.
  • Files over 200 MB are not converted (setting toMarkdown.maxFileSizeMB), and a PDF stops after 1,000 pages (setting toMarkdown.pdfMaxPages).

Other options

  • pandoc. Free command-line converter. Its extract-media option saves the pictures of Word, EPUB and ODT files to a folder and links them in the Markdown. It does not read PDF files.
  • pdfimages (Poppler). Free command-line tool. pdfimages -png file.pdf img saves every picture of a PDF, but writes no Markdown and no links.

Questions

Why does my converted Markdown have no pictures?

Markdown is plain text. Pictures must be separate files that the Markdown links to, and a converter that does not save them can only leave a placeholder.

Where are the pictures saved?

In a folder next to the .md file, named after it with _assets at the end, such as report_assets. The links are relative, so move the .md file and the folder together.

Is anything uploaded?

No. The conversion runs on your computer in a worker thread, with no network calls and no telemetry.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
