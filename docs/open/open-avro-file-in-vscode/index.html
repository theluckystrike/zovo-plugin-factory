Open an Avro file in VS Code

An Avro file is a binary container with a schema and blocks of records, often compressed, so the text editor shows it as gibberish. Avro and Arrow Viewer opens .avro files as a table with the schema, search and column stats, with no Python, Java or avro-tools. It reads the null, deflate, snappy and zstandard codecs, and viewing and export are free. Zovo Pro (USD 19 once) adds a CREATE TABLE statement from the Avro schema, a profile of all columns and a compare of two files, with 3 free tries each.

Steps in VS Code

  1. Install Avro and Arrow Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.arrow-avro-viewer.
  2. Click the .avro file in the Explorer. It opens as a table, 1,000 rows a page. Only the block you scroll to is decoded.
  3. Open the Schema tab. Each field shows its type in short form, such as string? for a union with null, array<string>, enum Plan or decimal(10,2), and whether it can be null. The codec, the block count and the raw schema JSON are there too.
  4. Click a cell to read its full value below the table. Nested records show as formatted JSON with a Copy button.
  5. Type in Find to search every row, in all columns or in one. Cancel keeps the matches found so far. Click a header for nulls, distinct count, min, max, mean and the most common values.
  6. Pick Export to save this page or all rows as CSV or JSON. Nested values go into CSV cells as JSON text.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.arrow-avro-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/arrow-avro-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Avro and Arrow Viewer handles

  • Avro object container files with the null, deflate, snappy or zstandard codec.
  • Unions, enums, records, arrays, maps, decimals, dates and timestamps.
  • Longs above 2^53, kept exact.
  • Files up to 4 GB, read block by block.

What it does not do

  • Avro files with the bzip2 or xz codec are not read. The message names the codec.
  • One Avro block can be at most 1 GB, since it is decoded whole.
  • Files bigger than 4 GB show a message instead of loading.
  • Search keeps the first 5,000,000 matches.

Other options

  • avro-tools. The Java tool from Apache Avro. java -jar avro-tools.jar tojson file.avro prints the records as JSON. Free, needs Java.
  • fastavro. A free Python library that reads and writes Avro files. Good for scripts, with no table view.

Questions

Why does my Avro file look like gibberish in VS Code?

VS Code opens it as text. Avro stores the records as binary, often compressed, after a JSON schema at the start of the file, so it needs a reader that decodes the blocks.

Do I need Java, Python or avro-tools?

No. The extension reads Avro itself, offline.

Can I edit the Avro file?

No. It is a viewer and never writes to the file. Export always writes a new file.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
