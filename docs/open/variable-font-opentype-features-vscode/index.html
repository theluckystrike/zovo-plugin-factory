Test a variable font and its OpenType features

Font Viewer shows a slider for every variable axis of a font, a list of its named instances, and a check box for each OpenType feature the font has, such as liga, frac or ss01. Your sample text and the size waterfall change as you move them, drawn by the same engine as Chromium, so the result matches a browser. Copy CSS gives the @font-face rule with the matching font-variation-settings and font-feature-settings, for free. Zovo Pro (USD 19 once) adds a folder report that lists the axes, version and license of every font, with 3 free tries.

Steps in VS Code

  1. Install Font Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.font-viewer-vscode.
  2. Click the .ttf, .otf, .woff or .woff2 file. A variable font shows a VARIABLE badge in the header.
  3. On the Type tester tab, type text that uses the features you care about, such as 1/2 for frac or fi for liga.
  4. Under Variable axes, move the slider of each axis, or pick a named instance from the list. Reset axes goes back to the default.
  5. Under OpenType features, turn each feature on or off and watch the sample and the waterfall change.
  6. Click Copy CSS to get the @font-face rule with the font-variation-settings and font-feature-settings you picked. The Info tab lists the axes with their minimum, default and maximum, the named instances and every GSUB and GPOS feature tag.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.font-viewer-vscode and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/font-viewer-vscode.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Font Viewer handles

  • Weight, width, slant and any custom axis of a variable font.
  • Named instances from the font.
  • Every OpenType feature tag in the GSUB and GPOS tables.
  • TTF, OTF, WOFF, WOFF2 and TTC files.

What it does not do

  • The glyph grid draws outlines at the default instance. The type tester, waterfall and character map follow the sliders.
  • CFF2 variable fonts show their text and metadata, but the glyph grid draws them with the font instead of from outlines.
  • Shaping comes from VS Code's Chromium engine, so other apps can shape some text differently.

Other options

  • Wakamai Fondue. A free web page that lists the features and axes of a font you drop in, with CSS to copy.
  • Firefox DevTools. The Fonts panel of the Inspector has sliders for the axes of a variable font used on a page. Free.
  • fontTools. ttx -t fvar font.ttf dumps the axes and named instances as XML. Free, with no preview.

Questions

Why is a feature I expect missing from the list?

The list shows only the features the font itself has. If ss01 is not there, the font has no ss01 stylistic set.

Does the glyph grid show the weight I picked?

No. Glyph outlines show the default instance. The sample text, the waterfall and the character map follow the sliders.

Is it free?

Yes. Testing axes and features and Copy CSS are free. Only Convert Font and Font Folder Report are Pro, with 3 free tries each.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
