View .npy and .npz NumPy files in VS Code

Install the free Tensor Viewer and click the .npy or .npz file. Each array is listed with its name, dtype and shape. Click one to see min, max, mean, std and NaN counts, a heatmap, a line plot or a histogram, and image-shaped arrays drawn as pictures. Python is not needed.

Install in VS CodeMarketplace pageOpen VSX (Cursor, Windsurf, VSCodium)

Free, MIT license. Extension ID zovo.tensor-viewer, version 0.6.3. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install Tensor Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.tensor-viewer.
  2. Click a .npy or .npz file. The table lists every array.
  3. Click an array. Read the stats, then switch between heatmap, line plot and histogram.
  4. Type a slice such as [5,:,:] to look at one part.
  5. Save the array, or a slice, as .npy or CSV.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.tensor-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/tensor-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Tensor Viewer handles

  • (H,W), (H,W,3) and (3,H,W) arrays and stacks drawn as pictures.
  • The same extension opens .safetensors, .gguf and PyTorch .pt files.

What it does not do

  • Pickled object arrays inside .npy or .npz files are listed and refused, never run.
  • Fortran-order and 2-channel arrays have no picture view. Images are drawn up to 512 px on the long side.
  • int64 values above 2^53 lose digits in the table and CSV.

Other options

  • vscode-numpy-viewer (Percy.vscode-numpy-viewer, 511,774 installs, not on Open VSX). Its own description: "Display (binary) .npy or .npz files in VSCode." Not on Open VSX, so not in Cursor.
  • vscode-pydata-viewer (Percy.vscode-pydata-viewer, 126,784 installs, not on Open VSX). Its own description: "Display PyData files (.npz .npy .pkl .pth) in VSCode."
  • NumPy in a terminal. python -c "import numpy as np; a = np.load('x.npy'); print(a.shape, a.dtype)" prints the shape and type.

Install counts and Open VSX status were checked on 8 November 2026. Descriptions in quotes are the extensions' own.

Questions

Is it safe to open an .npy file from the internet?

Tensor Viewer never runs code from a file. Object arrays, which NumPy stores as pickles, are refused.

Can I open it in Cursor?

Yes. Tensor Viewer is on Open VSX as zovo/tensor-viewer. The most installed NumPy viewer is not on Open VSX.

Does it need Python?

No. It reads the files itself and makes no network calls.
