Compress a JPG or PNG to a target file size, such as 200 KB

Upload forms and page budgets often ask for an image under a set size, such as 200 KB, and finding the right quality by hand takes several tries. Image Editor & Image Resizer has a Compress to a target size tool. You type the size and pick WebP or JPEG, and it finds the highest quality that fits. It scales the image down only when even the lowest quality is too big, and the new file goes next to the original. Compress to a target size is part of Zovo Pro (USD 19 once), with 3 free tries on your computer.

Steps in VS Code

  1. Install Image Editor from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-image-editor.
  2. Right-click a .png, .jpg, .webp, .gif or .bmp file, or a folder of them, in the Explorer and pick "Zovo Pro: Compress to a target size". Or open the image in the Image Editor and click Compress in its toolbar.
  3. Type the largest size you want, such as 200 KB or 1.5 MB.
  4. Pick WebP or JPEG for the new file.
  5. Read the result. For one image you see the before and after side by side. A table gives the new file, its size before and after, and the quality used, with the scale if the image had to be made smaller.
  6. Open the new file next to the original. Its name ends with the target, such as photo-200kb.webp. The original is never changed.

Opening, cropping, resizing, rotating, annotating, blurring and saving images are free. For one image you can also lower the size by hand. Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-image-editor and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-image-editor.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Image Editor handles

  • PNG, JPEG, WebP, GIF (first frame) and BMP images.
  • Any target from 1 KB to 512 MB, typed in KB or MB.
  • A whole folder in one run, with a row per image and a summary of the bytes saved.
  • Phone photos, with the EXIF orientation applied.

What it does not do

  • The new file is always WebP or JPEG. A JPEG has no transparency, so pick WebP for a PNG with transparent areas.
  • If an image still does not fit after it was scaled down, the file is saved anyway and its row says "still over the target".
  • A folder run takes the images in that folder only, not in its subfolders.
  • TIFF, HEIC, AVIF and SVG files are not opened.

Other options

  • ImageMagick. A free command line tool. magick photo.jpg -define jpeg:extent=200kb out.jpg searches the JPEG quality for a size.
  • Squoosh. A free web app with a quality slider and a live size readout, one image at a time.

Questions

Can the result stay a PNG?

No. PNG has no quality setting to search, so the tool writes WebP or JPEG. For a PNG with transparency, pick WebP.

Is my original changed?

No. The new file goes next to it with the target in its name, and an existing file is never overwritten.

What if the target is too small?

The tool lowers the quality first, then scales the pixels down, up to four times. If the image still does not fit, its row says so and you can try a larger target.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
