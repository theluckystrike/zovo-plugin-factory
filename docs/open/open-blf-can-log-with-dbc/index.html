Open a BLF CAN log and decode it with a DBC file

DBC Viewer & CAN Log Viewer opens Vector .blf and .asc logs, PCAN .trc files and candump logs in VS Code, with no CANoe or CANalyzer. Put the .dbc file next to the log, or pick it with the DBC button, and every frame decodes into signal values with units and value-table labels. The frame table, filters, per-id statistics and the DBC viewer are free. Zovo Pro (USD 19 once) adds CSV export of the decoded signals, a signal plot and a compare of two DBC files, with 3 free tries each.

Steps in VS Code

  1. Install DBC Viewer & CAN Log Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-can-dbc-viewer.
  2. Click a .blf, .asc or .trc file in the Explorer. It opens in the CAN Log Viewer. For a candump .log file, right-click it and pick Open in CAN Log Viewer.
  3. If a .dbc file sits in the same folder, the log is decoded with it. If not, click Pick a DBC… at the top and choose one. The choice is kept for this workspace.
  4. Click a frame to see each signal with its value, unit, label and raw value. Copy values puts them on the clipboard.
  5. Type in the filter box to narrow the frames. 1F0 finds an id, part of a name finds a message, and ch:2, tx, rx and fd filter by channel, direction and CAN FD. Terms combine.
  6. Open the Statistics tab for the count, mean cycle time, jitter and shortest and longest gap of each id, next to the cycle time in the DBC.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-can-dbc-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-can-dbc-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What DBC Viewer & CAN Log Viewer handles

  • Vector BLF with CAN, CAN FD (64 bytes) and zlib-compressed containers. Error frames are counted.
  • Vector ASC with absolute or relative time stamps, hex or decimal, Rx and Tx and channels.
  • PCAN .trc versions 1.0 to 2.1, and candump -l and -L logs.
  • DBC files with Intel and Motorola byte order, multiplexed signals, float signals and value tables.

What it does not do

  • It is read-only. You cannot edit frames or write a log.
  • Logs stop at 10 million frames, and BLF containers inflate to 64 MB at most.
  • The DBC next to the log is found only for local files. On a remote file system, pick it with the DBC button. Logs there are read up to 256 MB.
  • Only DBC files are read for decoding. ARXML, LDF and SYM files are not.

Other options

  • Vector CANoe or CANalyzer. The Vector tools that record BLF and ASC logs. They need a paid licence.
  • python-can and cantools. Free Python libraries. python-can reads BLF and ASC logs and cantools decodes them with a DBC, in your own script.
  • SavvyCAN. A free, open source desktop app for CAN logs and DBC files, outside VS Code.

Questions

Do I need CANoe or a Vector licence?

No. The extension reads BLF and ASC files itself. Nothing from Vector is installed or needed.

Why are my frames not decoded?

The log needs a DBC. Put the .dbc file in the same folder as the log, or click the DBC button at the top of the viewer and pick it.

Is my log uploaded?

No. The log is read on your computer in a worker thread, and the extension makes no network calls.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
