Compare your working folder with a git branch or tag

The Source Control view compares your files with HEAD only. Folder Compare & Directory Diff compares a folder on disk with the same folder on any branch, tag or commit, as two trees side by side. Files that exist only in your folder, such as new files git does not track yet, show as only right, and a double-click opens the diff of any file, Word and Excel files too. The Git compare is free, and Zovo Pro (USD 19 once) adds folder sync, a report of document changes and a three-way merge, with 3 free tries each.

Steps in VS Code

  1. Install Folder Compare & Directory Diff from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-folder-diff.
  2. Right-click a folder of your repository in the Explorer and pick "Compare Folder with Git Branch or Tag...". The workspace must be trusted, because this runs git.
  3. Pick HEAD, a branch or a tag from the list, or pick "Type a ref or commit..." and enter something like HEAD~3 or a commit id.
  4. Read the compare. The git version is on the left and your folder, the working tree, on the right. Click a count, such as Changed or Only right, to see only those rows.
  5. Double-click a row for its diff. Text opens in the VS Code diff editor, Word files as Markdown, Excel and CSV as rows, and PDF as text.
  6. To get the branch version of some files back, select them and click Copy to right. Export saves the result as Markdown, CSV or HTML.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-folder-diff and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-folder-diff.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Folder Compare & Directory Diff handles

  • HEAD, local and remote branches, tags, HEAD~n and commit ids.
  • Files only in your folder, such as untracked files, and files only on the branch.
  • Word, Excel, CSV, Parquet and PDF files, compared by their text.
  • Any other file, compared byte by byte.

What it does not do

  • It compares the folder you right-clicked with the same path on the branch. Pick the repository root to compare everything.
  • Files that .gitignore ignores are left out by default (setting folderDiff.useGitignore), and so are node_modules, .git and dist.
  • The git side cannot be written. Copy to left, Delete on the left and Mirror Right to Left do not work on it.
  • It needs a trusted workspace and git on your computer.

Other options

  • git diff. git diff with a branch name shows the text changes of tracked files. Free, but new untracked files are not included.
  • GitLens. A VS Code extension whose Search and Compare view compares the working tree with a branch or tag. Some features need a paid plan.

Questions

Are untracked files included?

Yes. A new file that git does not track yet shows as only right. Files that .gitignore ignores are left out unless you turn off folderDiff.useGitignore.

Does it run git hooks?

No. Git runs locally with repository hooks turned off, and only in a trusted workspace.

Can I compare with a remote branch?

Yes. Remote branches are in the list. Fetch first, because the compare reads your local repository.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
