XMind to PDF without XMind Pro

Open the .xmind file in XMind Viewer and pick the PDF export from the Export menu. You get one PDF, one page per sheet, in print colors, with a bookmark per sheet. The viewer and its PNG, SVG and Markdown exports are free, and PDF of every sheet is a Zovo Pro tool with 3 free tries. Steps in VS Code

  1. Install XMind Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.xmind-mind-map-viewer.
  2. Click the .xmind file in the Explorer. Every sheet opens as its own tab.
  3. Look through the sheets. Each one opens in the layout saved in the file.
  4. Open the Export menu above the map and pick the PDF export, or run XMind Viewer: Export every sheet as PDF from the Command Palette.
  5. The first 3 runs are free. A try counts only when a file is saved.
  6. Open the PDF: one page per sheet, in print colors, with a bookmark per sheet. Your map file is never changed.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.xmind-mind-map-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/xmind-mind-map-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What XMind Viewer handles

  • .xmind files from XMind 2020 to 2026 and XMind Zen (content.json), and XMind 8, XMind 7 and older 3.x files (content.xml).
  • Every sheet, with relationships, boundaries, summaries, markers, labels, notes, pictures from inside the file and LaTeX equations drawn with KaTeX.
  • Chinese, Japanese, Korean and emoji titles, with long titles wrapped.
  • Large maps: a 30 MB .xmind with 10,111 topics and 60 pictures opened in 0.65 seconds in the README test.
  • FreeMind and Freeplane .mm files and .opml outlines open too.

What it does not do

  • Maps with a password cannot be opened, because XMind encrypts their content.
  • Fishbone, timeline, matrix and brace sheets are drawn as logic or org charts, and topic positions you dragged by hand in XMind are not kept.
  • Styles from XMind themes (fonts, line shapes, topic shapes) are not copied. Topic fill and text colors are.
  • Convert a folder writes Markdown, CSV or OPML, not PDF. The PDF is made one map at a time.

Other options

  • XMind (File &gt; Export &gt; PDF). The PDF looks exactly like the map in XMind, theme styles included. PDF export needs XMind Pro (USD 4.92 a month on xmind.com/pricing, 10 Nov 2026). The better choice if you already pay for it or need the exact XMind look.
  • Print to PDF from a PNG or SVG export. Free. Export a sheet as SVG or PNG in XMind Viewer, open it in a browser and save it as PDF from the print dialog. One sheet per file and no bookmarks.
  • Pandoc on the Markdown export. Free. Export all sheets as one Markdown file in XMind Viewer and convert it with Pandoc. You get an outline as text, not the drawn map. Pandoc needs a LaTeX engine for PDF output.

Questions

Does it work in Cursor or Windsurf?

Yes. The README says the extension is also on Open VSX, so it works in Cursor, Windsurf, VSCodium and other editors based on VS Code.

Do I need XMind installed?

No. XMind Viewer opens .xmind files in VS Code without XMind.

Is the map sent anywhere?

No. There is no telemetry, no account and no network use. Nothing goes over the network until you click a buy button.

Can I turn a whole folder of XMind files into PDF?

Not in one run. Convert a folder writes Markdown, CSV or OPML. The PDF export works on the map you have open.

Does the PDF include every sheet?

Yes. It has one page per sheet and a bookmark per sheet.
