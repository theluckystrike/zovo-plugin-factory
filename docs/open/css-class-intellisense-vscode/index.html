Get CSS class name completion in VS Code

VS Code's built-in HTML support does not read the style sheets in your workspace, so it does not suggest your class names in class="...". Install the free Class Names IntelliSense by Zovo. It reads every .css, .scss and .less file in the workspace, plus <style> blocks and linked sheets, and lists each name with the file it comes from. Hover a name to see its rule, or press F12 to jump to it.

Free, MIT license. Extension ID zovo.zovo-html-css-class-intellisense, version 0.1.0. Needs VS Code 1.90.0 or newer.

Steps in VS Code

  1. Install Class Names IntelliSense from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-html-css-class-intellisense.
  2. Open any HTML, JSX, Vue, Svelte, Angular, PHP or Blade file. The style sheets are read once in the background, and the status bar shows the number of classes.
  3. Type inside class="...", className, :class or clsx() and pick a name from the list.
  4. Hover a class name to see its CSS rule and file. Press F12 to open the rule.
  5. If a page loads Bootstrap 5 or Bulma from a CDN, turn on the bundled class list with the htmlCssClass.frameworks setting.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-html-css-class-intellisense and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-html-css-class-intellisense.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Class Names IntelliSense handles

  • CSS, SCSS, Less and PostCSS files in the workspace, with nesting resolved: .card { &__title {} } gives card__title.
  • Completion for ids as well as class names.
  • CSS modules: styles. completes the classes of the imported .module.css or .module.scss file.
  • node_modules, files.exclude and .gitignore are skipped. In the release test, 7,408 classes from 16 sheets were indexed in 262 ms, with 0% CPU when idle.
  • Completion only. Nothing is inserted or rewritten while you type.

What it does not do

  • Remote style sheets are never downloaded. Classes from a CDN sheet other than Bootstrap 5 or Bulma are unknown. If the package is in node_modules, add it to htmlCssClass.includePackages.
  • It does not generate Tailwind utility classes from a Tailwind config. For Tailwind, use Tailwind CSS IntelliSense.
  • Sheets over 2 MB are skipped, and indexing stops at 5,000 sheets. Both are settings.
  • Vue and Svelte files need their usual language extension so VS Code knows the file type.

In JetBrains IDEs (IntelliJ IDEA, PyCharm, WebStorm, CLion and others)

  • Built in (WebStorm, IntelliJ IDEA Ultimate). JetBrains web IDEs complete CSS class names from your project in HTML class attributes, with no plugin. Zovo has no JetBrains plugin for this.
  • React CSS Modules. 163,469 downloads. Its listing says it adds "Completion and error highlighting for CSS classes" used through CSS modules in React components.

Other options

  • HTML CSS Support (ecmel.vscode-html-css, 30.1 million installs, on Open VSX). Its own description: "CSS Intellisense for HTML". The most installed choice.
  • IntelliSense for CSS class names in HTML (Zignd.html-css-class-completion, 10 million installs, on Open VSX). Its own description: "CSS class name completion for the HTML class attribute based on the definitions found in your workspace."

Questions

Why does VS Code not suggest my CSS classes?

Its HTML support suggests tags and attributes, but it does not read the style sheets in your workspace. An extension has to read them first.

Will it slow down VS Code in a big project?

It reads the sheets once in the background and then only the files you change. node_modules and ignored folders are skipped, and it uses no CPU while you type in other files.

Does it work with React and CSS modules?

Yes. It completes className, clsx(), cn() and cva(), and styles. for an imported CSS module.
