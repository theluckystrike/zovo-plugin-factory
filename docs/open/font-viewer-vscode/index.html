Preview a font file in VS Code

VS Code shows a font file as binary. The free Font Viewer opens .ttf, .otf, .woff, .woff2 and .ttc files with your own sample text, a waterfall of sizes, a glyph grid you can search and the license and embedding rights, without installing the font on your system. WOFF2 files are unpacked by its own decoder, so a web font from your build shows too. Zovo Pro (USD 19 once) adds a report of every font in a folder with its license, with 3 free tries.

Steps in VS Code

  1. Install Font Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.font-viewer-vscode.
  2. Click a .ttf, .otf, .woff, .woff2, .ttc or .otc file in the Explorer. Font Viewer is the default editor for these files, and it never changes the font.
  3. On the Type tester tab, type your own text, drag the size from 8 to 200 px and read the waterfall from 12 to 96 px.
  4. On the Glyphs tab, search by name, character, U+20AC or glyph id. Click a glyph to see it large with the baseline, x-height and cap height, and copy the character, its code point or its outline as SVG.
  5. On the Characters tab, see the coverage of each Unicode block, such as "Basic Latin 95/128". Turn off "Only characters in the font" to see what is missing.
  6. On the Info tab, read the license, designer, copyright and embedding rights, and copy a ready @font-face rule.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.font-viewer-vscode and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/font-viewer-vscode.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Font Viewer handles

  • TTF and OTF, also variable fonts.
  • WOFF and WOFF2 web fonts.
  • TTC and OTC collections, with a list to pick the face.
  • CJK fonts with 20,000 glyphs, loaded in pages as you scroll.

What it does not do

  • WOFF2 collections, SVG fonts, .dfont and Type 1 fonts are not supported.
  • Color fonts are drawn in color in the type tester, but the glyph grid shows their plain outlines.
  • Files over 64 MB show a message instead of opening (setting fontViewer.maxFileMB).
  • It is a viewer. It does not edit or install fonts.

Other options

  • Font Book on macOS, the font preview on Windows. Free and built in for TTF and OTF files, but they do not open WOFF or WOFF2.
  • FontDrop!. A free web page that shows the glyphs and the name table of a font you drop into the browser.

Questions

Do I have to install the font?

No. The font is read from the file and shown only inside the Font Viewer tab. Your system font list does not change.

Can it open a WOFF2 from my build folder?

Yes. WOFF2 is unpacked by the extension's own decoder, and the view reloads when you save a new build of the font.

Is viewing free?

Yes. Viewing, the glyph grid, the character map and the license info are free. Only Convert Font and Font Folder Report are Pro, with 3 free tries each.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
