Open files in VS Code and Cursor / Tables and data

See a Postgres EXPLAIN plan as a tree in VS Code

Install Postgres & MySQL Query Client by Zovo in VS Code, connect, put the cursor in a query and press Ctrl+Alt+E (Cmd+Alt+E on macOS). The plan opens as a tree of steps with cost bars, the slowest step is marked, and plain hints point at the usual problems: a full scan of a filtered table with the rows it threw away, a sort that spilled to disk, a step with no index, a row estimate 10 times off. "Explain Analyze" shows real time and rows per step. The client is free; Explain Plan is Zovo Pro (USD 19 once) with 3 free tries.

Steps in VS Code

  1. Install Postgres & MySQL Query Client from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-sql-client.
  2. Add a connection in the SQL Client view and open a .sql file on it.
  3. Put the cursor in a SELECT and press Ctrl+Alt+E (Cmd+Alt+E on macOS) for the plan.
  4. Run "Explain Analyze" to execute a read-only query and see the real time and rows of each step.
  5. Read the hints under the tree, change the query or add an index, and run it again.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.zovo-sql-client and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/zovo-sql-client.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What Postgres & MySQL Query Client handles

  • PostgreSQL EXPLAIN and EXPLAIN ANALYZE, MySQL 8 EXPLAIN ANALYZE, MariaDB ANALYZE FORMAT=JSON, and SQLite EXPLAIN QUERY PLAN.
  • Explain Analyze runs only read-only statements.
  • The plan page runs no scripts and makes no network calls.
  • Table data compare (also Zovo Pro): two tables on any two connections matched by primary key, with a report and a sync script that is opened, never run for you.

What it does not do

  • No SQL Server or Oracle.
  • Hints cover common plan problems. They do not rewrite your query.

Questions

Does Explain Analyze change data?

No. It runs only read-only statements.

Is my plan sent anywhere?

No. The plan is read from your database and drawn in VS Code. The extension connects only to the servers you add.

What is free?

Connections, queries, the results grid, row edits and export. Explain Plan, table data compare, the ER diagram, schema compare, CSV import and the query library are Zovo Pro, USD 19 once, with 3 free tries each.
