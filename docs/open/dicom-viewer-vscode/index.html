Open DICOM and NIfTI files in VS Code

Install the free DICOM Viewer and click a .dcm, .nii or .nii.gz file, or a DICOMDIR. For a folder of slices, right-click the folder and pick "Open Folder as DICOM Series". You get window presets for CT, axial, coronal and sagittal views with real slice spacing, the value under the cursor (HU for CT) and a searchable tag table.

Install in VS CodeMarketplace pageOpen VSX (Cursor, Windsurf, VSCodium)

This guide is also in Türkçe.

Steps in VS Code

  1. Install DICOM Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.dicom-nifti-viewer.
  2. Click a .dcm, .dicom, .nii or .nii.gz file, or a DICOMDIR.
  3. Press 1 to 4 for the brain, soft tissue, lung and bone windows, or drag to set window and level.
  4. Press A, C or S for axial, coronal or sagittal. Press T for the tag table.
  5. Export the view as PNG.

Steps in Cursor, Windsurf or VSCodium

  1. Open the Extensions view with Ctrl+Shift+X (Cmd+Shift+X on macOS).
  2. Search for zovo.dicom-nifti-viewer and click Install. Cursor, Windsurf and VSCodium install from Open VSX, where it is published as zovo/dicom-nifti-viewer.
  3. If your editor has no gallery, download the .vsix from the Open VSX page and run "Extensions: Install from VSIX...".
  4. Then use it the same way as in VS Code.

What DICOM Viewer handles

  • Uncompressed and RLE Lossless transfer syntaxes, 8 to 32 bit pixels, multi-frame and RGB.
  • NIfTI-1 and NIfTI-2, with a volume picker for 4D files.
  • A warning bar when a file still holds the patient's name or ID.

What it does not do

  • JPEG, JPEG-LS, JPEG 2000 and HTJ2K compressed images are not decoded yet. The tag table still opens, with a message naming the syntax.
  • Not for diagnosis. It is a developer and research viewer.
  • Overlays, presentation states, segmentations, RT structures and SR are not drawn.

Questions

Can it open compressed DICOM?

RLE Lossless and Deflated files open. JPEG family and JPEG 2000 files show their tags and a message for now.

Does it de-identify files?

No. It warns when common patient fields are present, but it is a check, not a de-identification tool.

Does any data leave my computer?

No. It makes no network calls and has no telemetry.
