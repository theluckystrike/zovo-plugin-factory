Every view is free and read-only, and you need no readelf, objdump or dumpbin. Steps in VS Code

  1. Install ELF Viewer & PE Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-elf-pe-viewer.
  2. Click a .exe, .dll, .sys, .so, .dylib, .elf or .ko file in the Explorer. It opens in the viewer. For a .o object file or a Linux or macOS executable with no extension, right-click it and pick Open in ELF & PE Viewer.
  3. The Overview tab comes first. It shows the architecture, file type, entry point, linked libraries, security flags such as ASLR and DEP, the build ID and the PDB path.
  4. Open the Sections or Imports tab. ELF imports show the library and the symbol version of each function. PE files also get data directories, delay-load imports and resources, and Mach-O files get load commands.
  5. Type in the filter box above a table to narrow the rows, and click a column header to sort. Copy rows puts the rows you see on the clipboard as tab-separated text.
  6. Click the bytes link of a section or segment to see its bytes marked in the Hex tab. In the Headers tab, Show every header field with its offset opens the field tree.

Where Zovo Pro saves time

Every view of a file is free, with no limit and no sign-in. That covers the overview, all tables, filter, sort and copy, the hex view and the field tree. The file is read in a separate worker thread with a time and memory limit. The extension never writes to the binary and makes no network calls.

To learn which binaries in a build folder import a function or link a library, this tool reads every ELF, PE and Mach-O file in the folder and lists each match with its file. Plain text matches any part of a name, and a /regex/ works too. The other two Pro tools compare two builds (header fields, sections, libraries, imports and exports that changed) and export the structure as JSON or as a C header.

With Find a symbol or import in a folder (Zovo Pro)

  1. Open a binary and click Find in folder… at the top, or run "ELF & PE Viewer: Find a symbol or import in a folder (Pro)" from the Command Palette.
  2. Type a name such as CreateFileW or SSL_read, or a regex such as /^_?pthread_/. It searches the workspace folder, or asks you for a folder.
  3. From the viewer, the matches open in a Find tab with a Copy button. Escape, or a search with no match, uses no free try.

What ELF Viewer & PE Viewer handles

  • ELF files in 32 and 64-bit, little and big endian, such as .so, .o, .ko, .elf, .axf and Linux executables.
  • PE32 and PE32+ files such as .exe, .dll, .sys, .efi and .pyd, with imports by name and ordinal, exports with forwarders and the .NET runtime header.
  • Mach-O in 32 and 64-bit, and universal binaries. Pick the architecture, such as arm64 or x86_64, at the top.
  • Tables with up to 100,000 rows that still scroll and filter fast.

What it does not do

  • It is read-only and has no disassembly.
  • Static libraries (.a), Java class files, WebAssembly and DEX files are not read.
  • Tables stop at 100,000 rows each, and reading stops after 10 seconds. The viewer says so when it happens.
  • Files on remote or virtual file systems are read up to 256 MB. Find in folder searches local folders only.

Other options

  • readelf and objdump. Free command-line tools from GNU binutils that print ELF headers, sections and symbols, and disassemble code.
  • dumpbin. Comes with Visual Studio on Windows. dumpbin /imports and /exports list the imports and exports of a PE file.
  • otool and nm. Command-line tools on macOS. otool -L lists the libraries a Mach-O file links.

Questions

Do I need readelf, objdump or dumpbin?

No. The extension reads ELF, PE and Mach-O files itself, with no other program installed.

Can it change the binary?

No. It only reads the file and never writes to it. The Pro export saves a new JSON or header file where you pick.

Is it free?

Yes. Every view of a file is free, with no sign-in. Find in a folder, compare and export are Zovo Pro tools with 3 free tries each, and a try counts only when the tool gives a result.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
