Read a JSON log file as a table and follow it

A structured log writes one JSON object per line, which is hard to read as text and often has a .log name. JSONL Viewer opens it in VS Code as a table with one column per key, and "Open as JSON Lines (any file)" works for .log, .txt and other names. A filter such as level == error and ctx.ms > 500 searches the whole file, and Follow keeps the newest record in view while the log grows. Viewing, filters and Follow are free, and Zovo Pro (USD 19 once) adds a JSONL split and a fine-tuning data check, with 3 free tries each.

Steps in VS Code

  1. Install JSONL Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-jsonl-viewer.
  2. For a .jsonl or .ndjson log, click it in the Explorer. For a .log, .txt, .out, .data or .json file, right-click it and pick "Open as JSON Lines (any file)". The same command is in the Command Palette and the menu of an editor tab.
  3. Type a filter such as level == error in the Filter box and press Enter. Join conditions with and, as in level == error and ctx.ms > 500. The search runs in the background with a progress count and a Cancel button.
  4. Click a cell to see its value as a tree below the table. Double-click a row to open the whole record.
  5. Click Follow to keep the newest record in view. New records show up within about two seconds, and an open filter picks up new matches too.
  6. Use Export to save the matching records as CSV, a JSON array or JSON Lines.

What JSONL Viewer handles

  • Logs with one JSON object per line, under any file name.
  • Nested keys in filters, such as ctx.user.id, and regular expressions with =~.
  • Logs that grow while you read them, and logs that are replaced by a shorter file, which reload.
  • Gzipped .jsonl.gz logs, read without unpacking them on disk.

What it does not do

  • Follow works for files on disk. It is off for gzipped files and for files in virtual workspaces.
  • A file whose first lines are not JSON shows a note and an Open as Text button. Plain text logs need a text log viewer.
  • Files must be under 4 GB, and lines over 5 MB show as truncated.
  • Find matches the raw text of each line, so it does not match a character stored as a \u escape. Use a filter with contains for that.

Other options

  • lnav. A terminal log viewer that reads JSON logs, with SQL queries and live tail.
  • jq. tail -f app.log | jq 'select(.level == "error")' follows and filters a log in a terminal.

Questions

Does Follow work when the log is rotated?

If the file is replaced by a shorter one, the viewer reloads it. A log that moves to a new file name has to be opened again.

Can I turn off live updates?

Yes. Set jsonlViewer.liveTail to false.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
