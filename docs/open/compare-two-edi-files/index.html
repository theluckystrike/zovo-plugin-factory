Compare two X12 or EDIFACT files

A plain diff of two EDI files is hard to read, because the segments often sit on one line and the control numbers differ in every file. For free, run Format EDI (one segment per line) on both files and compare them with the VS Code diff. Zovo Pro (USD 19 once) adds Compare two EDI files to EDI Viewer. Steps in VS Code

  1. Install EDI Viewer from the Marketplace, or press Ctrl+P (Cmd+P on macOS) and run ext install zovo.zovo-edi-viewer.
  2. Click the first file. It opens as EDI text with colors.
  3. Right-click in the text and pick "Format EDI (one segment per line)". Do the same in the second file. Only the line breaks between segments change.
  4. With the first file active, run "File: Compare Active File With..." from the Command Palette and pick the second file. VS Code shows both side by side with the changed lines marked.
  5. Control numbers and dates in the envelope show as changes in that diff. To skip them and see element names, use Compare two EDI files in EDI Viewer, described below.

What EDI Viewer handles

  • X12 and EDIFACT. The separators of each file are read from its ISA header or UNA, so a file on one line and a file with one segment per line compare fine.
  • Element IDs and names for 850, 855, 810, 856, 837, 835 and the other transaction sets and EDIFACT messages EDI Viewer knows.
  • A segment that was replaced by one of the same type shows as one changed segment, with only the elements that differ.
  • The ignore option skips control numbers and envelope dates and times in ISA, IEA, GS, GE, ST, SE and BHT, or in UNB, UNZ, UNG, UNE, UNH and UNT.

What it does not do

  • Both files must use the same standard. An X12 file cannot be compared with an EDIFACT file.
  • Only envelope values are ignored. Dates inside the transaction, such as in BEG or DTM, are still compared.
  • Segments are matched in order. A segment that moved to another place shows as removed in one place and added in the other.
  • Up to 5,000 differences are listed, and the report counts the rest.

Other options

  • The VS Code diff. Free and built in. After Format EDI on both files it compares line by line, with no element names, and control numbers show as changes.
  • diff in a terminal. Free. In bash, diff <(tr '~' '\n' < a.edi) <(tr '~' '\n' < b.edi) puts each X12 segment on its own line first. It assumes ~ ends a segment.

Questions

Why does a plain diff mark the whole file?

Many EDI files keep all segments on one line, so one change marks that whole line. Even with one segment per line, the control numbers in ISA, GS and ST and the envelope dates differ in every file.

Does it change my files?

No. Compare only reads both files. Format EDI changes the line breaks between segments in the text editor, and only when you run it.

Is my file sent anywhere?

No. Both files are read on your computer, and the extension makes no network calls.

Does it work in Cursor or Windsurf?

Yes. Cursor, Windsurf and VSCodium install extensions from Open VSX. Search for the extension in their Extensions view and install it there.
