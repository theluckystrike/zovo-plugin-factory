VS Code में PDF, Word, PowerPoint या Excel फ़ाइल को Markdown में कैसे बदलें

मुफ़्त Convert to Markdown एक्सटेंशन इंस्टॉल करें, Explorer में किसी PDF, Word, PowerPoint, Excel, CSV, HTML, EPUB, ODT या RTF फ़ाइल पर राइट-क्लिक करें और Convert to Markdown चुनें। Markdown फ़ाइल के बगल में खुलता है, जिसमें headings, lists, tables, links और slides के speaker notes होते हैं, और कुछ भी आपके कंप्यूटर से बाहर नहीं जाता। Convert to Markdown और Copy as Markdown हर फ़ॉर्मैट के लिए मुफ़्त हैं। Zovo Pro (19 USD, एक बार) तीन टूल जोड़ता है, Convert a Folder to Markdown, Convert to Markdown with Images और LLM-ready Markdown Chunks, और हर टूल 3 बार मुफ़्त चलता है।

VS Code में स्टेप्स

  1. Marketplace से Convert to Markdown इंस्टॉल करें, या Ctrl+P (macOS पर Cmd+P) दबाकर ext install zovo.zovo-convert-to-markdown चलाएँ।
  2. Explorer में किसी .pdf, .docx, .pptx, .xlsx, .xls, .ods, .csv, .tsv, .html, .epub, .odt या .rtf फ़ाइल पर राइट-क्लिक करें और Convert to Markdown चुनें। खुली फ़ाइल के टैब पर राइट-क्लिक करके भी यह मिलता है।
  3. या Command Palette से "Convert to Markdown: Convert to Markdown" चलाएँ। यह active टैब की फ़ाइल को बदलता है, या फ़ाइल चुनने को कहता है।
  4. Markdown फ़ाइल के बगल में एक unsaved document के रूप में खुलता है। बड़ी फ़ाइलों पर progress और Cancel बटन दिखता है।
  5. Save दबाएँ। Source के बगल में name.md नाम पहले से भरा होता है। हर बार सीधे वहीं सेव करने के लिए toMarkdown.output को file पर सेट करें।
  6. Markdown को कहीं और पेस्ट करने के लिए फ़ाइल पर राइट-क्लिक करके Copy as Markdown चुनें। Explorer में कई फ़ाइलें चुनें, तो वे एक के बाद एक बदली जाती हैं।
  7. कोई फ़ाइल पास नहीं है? Command Palette से "Convert to Markdown: Convert a sample file" चलाएँ। यह साथ आई Word, PDF या PowerPoint sample फ़ाइल को बदलता है।

क्या मुफ़्त है और Zovo Pro क्या जोड़ता है

Convert to Markdown और Copy as Markdown हर फ़ॉर्मैट के लिए मुफ़्त हैं: PDF, Word, PowerPoint, Excel, ODS, CSV, TSV, HTML, EPUB, ODT और RTF। आपको कुछ और इंस्टॉल नहीं करना पड़ता, न Python, न server, न कोई command-line tool। कुछ भी आपके कंप्यूटर से बाहर नहीं जाता।

Convert a Folder to Markdown एक फ़ोल्डर और उसके subfolders की हर समर्थित फ़ाइल को एक ही run में .md फ़ाइलों में बदलता है, एक नए mirrored फ़ोल्डर में या हर फ़ाइल के बगल में, progress और Cancel के साथ। पहले से मौजूद .md फ़ाइलों को skip या overwrite करना आप चुनते हैं, और _conversion-report.md हर फ़ाइल को converted, skipped या failed के रूप में दिखाता है। एक ही नाम वाली फ़ाइलों के नए नाम में उनका type रहता है (report.pdf.md, report.docx.md), इसलिए कोई फ़ाइल खोती नहीं।

Convert a Folder to Markdown का इस्तेमाल (Zovo Pro)

  1. Explorer में किसी फ़ोल्डर पर राइट-क्लिक करके "Zovo Pro: Convert a Folder to Markdown" चुनें, या Command Palette से "Convert to Markdown: Convert a Folder to Markdown (Pro)" चलाएँ और फ़ोल्डर चुनें।
  2. चुनें कि .md फ़ाइलें कहाँ जाएँ: "Into a new folder" (फ़ोल्डर का नाम और -markdown, उन्हीं subfolders के साथ), "Next to each file" या "Pick another folder..."।
  3. अगर कुछ .md फ़ाइलें पहले से हैं, तो Skip या Overwrite चुनें। एक notification में progress और Cancel बटन दिखता है।
  4. आख़िर में _conversion-report.md खुलता है। इसमें हर फ़ाइल converted, skipped या failed के रूप में लिखी होती है, और हर नई Markdown फ़ाइल का link होता है।

Convert a Folder to Markdown आपके कंप्यूटर पर 3 बार मुफ़्त चलता है, उसके बाद लाइसेंस माँगता है। न कोई पॉप-अप आता है, न कोई काउंटडाउन चलता है।

Convert to Markdown क्या करता है

  • PDF: font size से headings, टूटी लाइनें और hyphen से बँटे शब्द जोड़कर paragraphs, lists, सरल tables, और दो कॉलम वाले पेज कॉलम-दर-कॉलम पढ़े जाते हैं। बार-बार आने वाले headers, footers और page numbers हटा दिए जाते हैं।
  • Word (.docx, .docm, .dotx): headings, bold, italic, strikethrough, links, nested lists, tables, block quotes और footnotes।
  • PowerPoint (.pptx, .pptm, .ppsx, .potx): हर slide के लिए एक ## Slide n: title section, bullets और उनके levels, tables और speaker notes के साथ।
  • Excel और दूसरी sheets (.xlsx, .xlsm, .xlsb, .xls, .ods): हर sheet के लिए pipe table वाला एक ## Sheet: name section। CSV और TSV एक table बनते हैं।
  • HTML (.html, .htm, .xhtml), जिसमें code blocks अपनी language रखते हैं और scripts व styles हटा दिए जाते हैं, और EPUB, जिसमें हर chapter पढ़ने के क्रम में आता है।

यह क्या नहीं करता

  • Scanned PDF (पेजों की तस्वीरें) में बदलने के लिए text नहीं होता। Text recognition (OCR) शामिल नहीं है।
  • PDF tables कॉलमों के बीच की खाली जगह से पहचानी जाती हैं। साफ़ खाली जगह के बिना tables paragraphs बनकर आती हैं।
  • मुफ़्त conversion में images *[Image: Map of the site]* जैसे placeholders बनती हैं। Slides के charts, SmartArt और video का सिर्फ़ नाम आता है, वे बदले नहीं जाते।
  • पुरानी Word 97-2003 फ़ाइलें और RTF बिना formatting के text और tables देती हैं। Password से सुरक्षित फ़ाइलों और पुरानी PowerPoint 97-2003 फ़ाइलों पर conversion की जगह एक message आता है।
  • 200 MB से बड़ी फ़ाइलें नहीं बदली जातीं (सेटिंग toMarkdown.maxFileSizeMB), और PDF 1,000 पेजों के बाद रुक जाता है (सेटिंग toMarkdown.pdfMaxPages)।

क्या यह मुफ़्त है?

Convert to Markdown और Copy as Markdown हर फ़ॉर्मैट के लिए मुफ़्त हैं। तीनों Pro टूल, Convert a Folder to Markdown, Convert to Markdown with Images और LLM-ready Markdown Chunks, 3-3 बार मुफ़्त चलते हैं। उसके बाद इनके लिए Zovo Pro चाहिए, जो सभी Zovo एक्सटेंशन के लिए एक बार 19 USD का है।

क्या यह मेरी फ़ाइलें upload करता है?

नहीं। Converters आपके कंप्यूटर पर, VS Code के अंदर चलते हैं। कोई network call और कोई telemetry नहीं है।

क्या यह scanned PDF बदलता है?

नहीं। Scanned PDF में text नहीं, पेजों की तस्वीरें होती हैं, और Convert to Markdown में OCR नहीं है।

क्या यह Cursor में चलता है?

हाँ। Cursor, Windsurf और VSCodium इसे Open VSX से इंस्टॉल करते हैं, जहाँ यह zovo/zovo-convert-to-markdown नाम से है।
