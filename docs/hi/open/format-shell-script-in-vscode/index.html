VS Code में स्टेप्स

  1. Marketplace से Shell Formatter for Bash & Zsh इंस्टॉल करें, या Ctrl+P (macOS पर Cmd+P) दबाकर ext install zovo.zovo-shell-formatter चलाएँ।
  2. कोई shell script खोलें और Shift+Alt+F (Mac पर Shift+Option+F) दबाएँ। अगर VS Code पूछे कि कौन-सा formatter इस्तेमाल करें, तो Shell Formatter चुनें, या "Shell Formatter: Use as Default Formatter for Shell Scripts" चलाएँ।
  3. हर save पर फ़ॉर्मैट करने के लिए "Shell Formatter: Turn On Format on Save for Shell Scripts" चलाएँ।
  4. Dialect पहली लाइन से तय होता है (#!/bin/bash, #!/bin/sh, #!/usr/bin/env zsh), फिर फ़ाइल के नाम से (.bash, .zsh, .zshrc, .bats, .ksh), वरना bash। इसे ख़ुद चुनने के लिए shellFormatter.dialect या .editorconfig में shell_variant सेट करें।
  5. Menu के लिए status bar में shfmt 3.14.1 पर क्लिक करें: format, set as default, format on save, "Copy the matching shfmt command (for CI)" और settings।
  6. अगर script valid shell नहीं है, तो वह बिना बदले रहती है और Problems panel line और column दिखाता है।

क्या मुफ़्त है और Zovo Pro क्या जोड़ता है

Format Document, Format Selection, format on save, dialect detection, .editorconfig keys, status bar menu, Copy the Matching shfmt Command (for CI) और Problems में syntax errors मुफ़्त हैं। कोई sign-in, कोई network request और कोई telemetry नहीं है।

Format All Shell Scripts in a Folder एक फ़ोल्डर और उसके subfolders की हर script जाँचता है, जो नाम से या shell का नाम लेने वाली #! लाइन से पहचानी जाती है, और बताता है कि कितनी बदलेंगी। फिर यह उन सबको फ़ॉर्मैट करता है या एक Markdown report देता है, उसी engine, settings और .editorconfig के साथ जो Format Document इस्तेमाल करता है। अलग-अलग style वाली दर्जनों scripts की repository एक ही run में एक style पा लेती है, और जिन scripts का फ़ॉर्मैट किया हुआ रूप वही commands नहीं चलाता, वे वैसी ही छोड़ दी जाती हैं।

Format All Shell Scripts in a Folder का इस्तेमाल (Zovo Pro)

  1. Explorer में किसी फ़ोल्डर पर राइट-क्लिक करके "Zovo Pro: Format All Shell Scripts in a Folder" चुनें, या Command Palette या status bar menu से "Shell Formatter: Format All Shell Scripts in a Folder (Pro)" चलाएँ और फ़ोल्डर चुनें।
  2. अगली list के title में दिखता है कि कितनी scripts बदलेंगी, जैसे "N of M scripts would change"।
  3. हर फ़ाइल को फ़ॉर्मैट और save करने के लिए "Format N scripts" चुनें (Undo हर फ़ाइल पर अलग से काम करता है), या बिना कुछ बदले हर script की Markdown list के लिए "Show the report only" चुनें।
  4. Try तभी गिना जाता है जब आपको result मिले। बिना shell scripts वाला फ़ोल्डर, या ऐसा फ़ोल्डर जिसकी हर script पहले से फ़ॉर्मैट है, कोई try नहीं लेता।

Format All Shell Scripts in a Folder आपके कंप्यूटर पर 3 बार मुफ़्त चलता है, उसके बाद लाइसेंस माँगता है। न कोई पॉप-अप आता है, न कोई काउंटडाउन चलता है।

Shell Formatter for Bash & Zsh क्या करता है

  • Bash, POSIX sh (dash और ash भी), mksh (ksh भी), bats और zsh scripts।
  • Command line वाले shfmt 3.14.1 जैसा ही output: GitHub projects और Homebrew की 178 असली scripts पर 354 में से 354 runs byte-दर-byte मेल खाए।
  • कोई बदलाव लागू होने से पहले फ़ॉर्मैट की हुई script फिर से parse की जाती है, और उसे original जैसे ही commands चलाने होते हैं (256 KB तक की फ़ाइलें)।
  • shfmt options settings या .editorconfig keys के रूप में: indent, binary operators अगली लाइन पर, switch case indent, space redirects, keep padding, function braces अगली लाइन पर, simplify और minify।
  • Windows line endings (CRLF) CRLF ही रहते हैं, और 2 MB की script लगभग 0.2 सेकंड में फ़ॉर्मैट होती है।

यह क्या नहीं करता

  • यह Dockerfiles, .env फ़ाइलें, fish या csh scripts कभी नहीं छूता।
  • shfmt में zsh support नया है। जिस zsh script को shfmt parse नहीं कर पाता, वह बिना बदले रहती है।
  • 10 MB से बड़ी फ़ाइलें (सेटिंग shellFormatter.maxFileMB) और binary bytes वाली फ़ाइलें, जैसे self-extracting installers, फ़ॉर्मैट नहीं होतीं।
  • shfmt एक time limit के साथ चलता है (default 10 सेकंड, सेटिंग shellFormatter.timeoutSeconds)। Limit पूरी होने पर फ़ाइल बिना बदले रहती है।

अक्सर पूछे जाने वाले सवाल

क्या यह मुफ़्त है?

Format Document, Format Selection, format on save और .editorconfig support मुफ़्त हैं। तीनों Pro टूल, Format All Shell Scripts in a Folder, Formatting Check with a Patch File और Minify a Script to a Copy, 3-3 बार मुफ़्त चलते हैं। उसके बाद इनके लिए Zovo Pro चाहिए, जो सभी Zovo एक्सटेंशन के लिए एक बार 19 USD का है।

क्या मुझे shfmt इंस्टॉल करना होगा?

नहीं। shfmt 3.14.1 एक्सटेंशन के अंदर WebAssembly के रूप में आता है, इसलिए यह offline चलता है और कुछ download नहीं करना पड़ता।

क्या यह मेरी script तोड़ देगा?

Syntax error वाली script बिना बदले रहती है। कोई बदलाव लागू होने से पहले फ़ॉर्मैट की हुई script फिर से parse होती है, और उसे original जैसे ही commands चलाने होते हैं।

क्या यह Cursor में चलता है?

हाँ। Cursor, Windsurf और VSCodium इसे Open VSX से इंस्टॉल करते हैं, जहाँ यह zovo/zovo-shell-formatter नाम से है।
