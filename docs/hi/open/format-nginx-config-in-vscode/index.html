VS Code में स्टेप्स

  1. Marketplace से Nginx Config Formatter & Lint इंस्टॉल करें, या Ctrl+P (macOS पर Cmd+P) दबाकर ext install zovo.zovo-nginx-config चलाएँ।
  2. Config खोलें। यह nginx के रूप में तब खुलता है जब उसका नाम nginx.conf हो या वह .nginx या .nginxconf पर ख़त्म हो, या जब वह nginx नाम के फ़ोल्डर में कोई .conf फ़ाइल हो (जैसे /etc/nginx/conf.d/default.conf), या nginx/sites-available, nginx/sites-enabled या nginx/snippets में कोई फ़ाइल हो। किसी और फ़ाइल के लिए language mode में "nginx" चुनें।
  3. Shift+Alt+F (Mac पर Shift+Option+F) दबाएँ। आपके editor के indentation के साथ हर लाइन में एक statement आता है, लंबी log_format values अपने line breaks रखती हैं, और लगातार ज़्यादा से ज़्यादा एक खाली लाइन रहती है (सेटिंग nginxConfig.format.maxBlankLines)।
  4. टाइप करते समय problems दिखते हैं: छूटा हुआ ;, बंद न हुए या फ़ालतू braces, बंद न हुई strings, गलत block में directive, duplicate root या listen, एक port पर एक ही नाम वाले दो servers। Quick fix के लिए Ctrl+. (Mac पर Cmd+.) दबाएँ, जैसे "Add the missing ";"" या proxy_set_heder को proxy_set_header में बदलना।
  5. किसी directive पर hover करने से उसका syntax, default value, allowed blocks और nginx documentation का link दिखता है। Completion मौजूदा block में allowed directives, और $ के बाद variables सुझाता है।
  6. हर server को उसके ports और names के साथ, और हर location को उसके काम के साथ, include फ़ाइलों के पार देखने के लिए editor title bar में list icon पर क्लिक करें, या "Nginx: Show Config Overview" चलाएँ। किसी फ़ाइल और लाइन पर क्लिक करके वहाँ पहुँचें।

क्या मुफ़्त है और Zovo Pro क्या जोड़ता है

Syntax colours (Lua blocks Lua की तरह रंगे जाते हैं), Format Document, quick fixes वाले problems, hover मदद, completion, outline और config overview मुफ़्त हैं। सब कुछ आपके कंप्यूटर पर चलता है, बिना किसी network request के।

Security Audit config को उसकी सभी include फ़ाइलों के साथ जाँचता है और हर finding को उसकी फ़ाइल, लाइन, उसके मायने और fix के साथ, high, medium और low में बाँटकर दिखाता है। यह TLS 1.0 और 1.1, कमज़ोर ciphers, बिना HSTS और दूसरे security headers वाले HTTPS servers, वे locations जिनका अपना add_header चुपचाप उन headers को हटा देता है, alias का off-by-slash path traversal, request से लिए गए host पर proxy_pass, serve हो रही .git और .env फ़ाइलें, फ़ोल्डर listings और बिना limit का request body ढूँढता है। Config के production में जाने से पहले आपको ये गलतियाँ मिल जाती हैं, हर include फ़ाइल हाथ से पढ़े बिना।

Security Audit का इस्तेमाल (Zovo Pro)

  1. Config overview toolbar की Pro tools row में "Security audit" पर क्लिक करें, Explorer में किसी .conf या .nginx फ़ाइल पर राइट-क्लिक करके "Zovo Pro: Security audit" चुनें, या Command Palette से "Nginx: Security Audit (Pro)" चलाएँ।
  2. Audit editor के बगल में खुलता है। हर finding अपनी फ़ाइल और लाइन, कारण और fix दिखाती है। वहाँ पहुँचने के लिए फ़ाइल और लाइन पर क्लिक करें।
  3. Findings को Markdown फ़ाइल के रूप में रखने के लिए "Save report" पर क्लिक करें।
  4. Try तभी गिना जाता है जब audit ने अपना result दिखाया हो। Escape, या बिना http या server block वाली फ़ाइल, कोई try नहीं लेती।

Security Audit आपके कंप्यूटर पर 3 बार मुफ़्त चलता है, उसके बाद लाइसेंस माँगता है। न कोई पॉप-अप आता है, न कोई काउंटडाउन चलता है।

Nginx Config Formatter & Lint क्या करता है

  • OpenResty/Lua, headers-more, Brotli, Passenger और दूसरे आम modules के directives पहचाने जाते हैं और कभी गलत नहीं बताए जाते।
  • content_by_lua_block जैसे Lua blocks Lua की तरह रंगे जाते हैं।
  • Outline view servers को उनके names और ports के साथ, और locations, upstreams और maps को list करता है।
  • Relative includes nginxConfig.prefix, फ़ाइल के फ़ोल्डर, उसके parent फ़ोल्डर या /etc/nginx से, इसी क्रम में पढ़े जाते हैं।
  • Overview और Pro tools खुले editors के unsaved changes इस्तेमाल करते हैं।

यह क्या नहीं करता

  • Formatter directive और उसकी values के बीच एक space रखता है, इसलिए listen 80; जैसा column alignment नहीं रहता।
  • बंद न हुए brace या string वाली फ़ाइल फ़ॉर्मैट नहीं होती। वह बिना बदले रहती है और status bar कारण बताता है।
  • Checks आपकी फ़ाइलें पढ़ते हैं और nginx -t नहीं चलाते। गायब certificate फ़ाइल या load न हुआ module सिर्फ़ nginx ख़ुद पकड़ता है।
  • Location regexes JavaScript regular expressions से test होते हैं। कुछ PCRE-only features (possessive quantifiers, recursion) test नहीं हो सकते और skipped के रूप में report होते हैं।

अक्सर पूछे जाने वाले सवाल

क्या यह मुफ़्त है?

Formatting, quick fixes वाले problems, hover मदद, completion, outline और config overview मुफ़्त हैं। तीनों Pro टूल, Security Audit, Location Tester और Convert .htaccess to nginx, 3-3 बार मुफ़्त चलते हैं। उसके बाद इनके लिए Zovo Pro चाहिए, जो सभी Zovo एक्सटेंशन के लिए एक बार 19 USD का है।

क्या formatting मेरा config तोड़ सकती है?

नहीं। Formatter अपने result को फिर से parse करता है और अगर फ़ाइल पहले जैसी नहीं पढ़ी जाएगी तो कुछ नहीं बदलता, इसलिए valid config valid ही रहता है।

क्या यह nginx -t की जगह ले लेता है?

नहीं। यह आपकी फ़ाइलें पढ़ता है और syntax व हर directive की जगह जाँचता है। Certificates और modules के लिए server पर nginx -t चलाएँ।

क्या यह Cursor में चलता है?

हाँ। Cursor, Windsurf और VSCodium इसे Open VSX से इंस्टॉल करते हैं, जहाँ यह zovo/zovo-nginx-config नाम से है।
