VS Code में JAR खोलें और डिकंपाइल किया गया Java source पढ़ें

मुफ़्त JAR Viewer & Java Decompiler इंस्टॉल करें और किसी .jar, .war, .ear, .aar या .class फ़ाइल पर क्लिक करें। इसमें packages, resources, MANIFEST.MF और हर class का Java version दिखता है, साथ में javap -c -p जैसी bytecode listing जिसके लिए Java नहीं चाहिए, और Java source, जिसे bundled CFR 0.152 आपके कंप्यूटर पर मौजूद Java 8 या नए runtime से डिकंपाइल करता है। सभी व्यू और एक बार में एक class डिकंपाइल करना मुफ़्त है। Zovo Pro (19 USD, एक बार का भुगतान) तीन टूल जोड़ता है, Export decompiled sources of a JAR, Compare two JARs और Find in every JAR of a folder, और हर टूल को आप 3 बार मुफ़्त चला सकते हैं।

VS Code में स्टेप्स

  1. Marketplace से JAR Viewer इंस्टॉल करें, या Ctrl+P (macOS पर Cmd+P) दबाकर ext install zovo.zovo-jar-viewer चलाएँ।
  2. Explorer में किसी .jar, .war, .ear, .aar या .class फ़ाइल पर क्लिक करें। वह JAR Viewer में खुलती है। Overview में format, entries, classes और packages की गिनती, Main-Class, Created by, MANIFEST.MF और एक चार्ट दिखता है कि classes किन Java versions के लिए compile हुई थीं।
  3. Package tree के ऊपर filter box में नाम का कोई हिस्सा टाइप करें। टाइप करते ही classes और फ़ाइलें मिल जाती हैं। Inner classes अपनी outer class के नीचे हल्के रंग में दिखती हैं।
  4. किसी class पर क्लिक करें। Java source टैब उसे CFR 0.152 से डिकंपाइल करके उसकी inner classes के साथ दिखाता है। Copy से source clipboard पर आ जाता है, और Open in editor उसे एक सामान्य editor टैब में खोलता है।
  5. अगर Java source टैब बताए कि decompiled Java source के लिए Java runtime चाहिए, तो jarViewer.javaPath में किसी java binary या JDK फ़ोल्डर का path डालें, या JAVA_HOME सेट करें। "JAR Viewer: Check the Java runtime used for decompiling" बताता है कि डिकंपाइल करने के लिए कौन-सा Java इस्तेमाल हो रहा है।
  6. Bytecode टैब खोलें। इसमें javap -c -p जैसी listing है, जिसमें हर opcode, exception tables और line numbers हैं। Members, Constant pool और Class info टैब declarations, constant pool की entries और class attributes दिखाते हैं।
  7. Spring Boot JAR, WAR या AAR में BOOT-INF/lib या WEB-INF/lib के अंदर किसी JAR पर, या AAR की classes.jar पर क्लिक करें, फिर "Open nested archive" पर क्लिक करें। यह एक level अंदर तक खुलता है, और ऊपर बाहरी फ़ाइल के नाम वाला बटन आपको वापस ले जाता है।

क्या मुफ़्त है और Zovo Pro क्या जोड़ता है

Package tree, Overview, manifest, resources, डिकंपाइल किया गया Java source, bytecode, members, constant pool, class info और nested JARs मुफ़्त हैं, और sign-in की ज़रूरत नहीं है। CFR एक्सटेंशन के साथ आता है और आपके कंप्यूटर पर पहले से मौजूद Java पर चलता है। एक्सटेंशन archive को कभी नहीं बदलता और कोई नेटवर्क कॉल नहीं करता।

Export decompiled sources of a JAR किसी JAR, WAR, EAR या AAR की हर class को CFR से डिकंपाइल करता है और .java फ़ाइलें एक फ़ोल्डर में लिखता है, progress और Cancel बटन के साथ। Java runtime न हो, तो यह उनकी जगह bytecode listings लिखता है। एक-एक class खोलने के बजाय पूरी library आपको source फ़ाइलों के रूप में मिलती है, जिन्हें आप editor में खोज या पढ़ सकते हैं।

Export decompiled sources of a JAR का इस्तेमाल (Zovo Pro)

  1. Archive खोलें और viewer के ऊपर "Export sources…" पर, या छोटी Pro tools row में "Export decompiled sources" पर क्लिक करें। Explorer में फ़ाइल पर राइट-क्लिक करके "Zovo Pro: Export decompiled sources" भी चुन सकते हैं।
  2. या Command Palette से "JAR Viewer: Export decompiled sources of a JAR (Pro)" चलाएँ। कोई archive खुला न हो, तो यह आपसे कोई JAR, WAR, EAR या AAR फ़ाइल चुनने को कहता है।
  3. कोई फ़ोल्डर चुनें और "Export here" पर क्लिक करें। Sources एक नए फ़ोल्डर में जाते हैं, जिसका नाम archive का नाम है और आख़िर में -src जुड़ा होता है।
  4. एक notification progress दिखाता है। Cancel export रोक देता है और कोई मुफ़्त ट्रायल ख़र्च नहीं होता। पूरा होने पर viewer बताता है कि उसने कितनी फ़ाइलें लिखीं और कहाँ।

Export decompiled sources of a JAR आपके कंप्यूटर पर 3 बार मुफ़्त चलता है, उसके बाद लाइसेंस माँगता है। न कोई पॉप-अप आता है, न कोई काउंटडाउन चलता है।

Cursor, Windsurf या VSCodium में स्टेप्स

  1. Ctrl+Shift+X (macOS पर Cmd+Shift+X) से Extensions व्यू खोलें।
  2. zovo.zovo-jar-viewer खोजें और Install पर क्लिक करें। Cursor, Windsurf और VSCodium एक्सटेंशन Open VSX से इंस्टॉल करते हैं, जहाँ इस एक्सटेंशन का नाम zovo/zovo-jar-viewer है।
  3. अगर आपके एडिटर में एक्सटेंशन गैलरी नहीं है, तो Open VSX पेज से .vsix फ़ाइल डाउनलोड करें और "Extensions: Install from VSIX..." चलाएँ।
  4. इसके बाद सब कुछ VS Code की तरह ही काम करता है।

JAR Viewer क्या करता है

  • JAR, WAR, EAR और AAR archives, और अकेली .class फ़ाइलें, उसी फ़ोल्डर की inner classes के साथ।
  • 200,000 entries तक के archives, और एक filter जो 50,000 entries में से कोई class या फ़ाइल टाइप करते ही ढूँढ लेता है।
  • Class data में generic signatures, records, permitted subclasses, nest hosts और annotations।
  • Properties, XML, JSON, SQL और services फ़ाइलों जैसे text resources टेक्स्ट के रूप में, और binary फ़ाइलों का hex preview।
  • Spring Boot BOOT-INF/lib, WAR WEB-INF/lib और AAR classes.jar archives, एक level अंदर तक।

यह क्या नहीं करता

  • Decompiled source के लिए कंप्यूटर पर Java 8 या नया चाहिए। इसके बिना भी bytecode और बाकी सभी व्यू काम करते हैं।
  • CFR का output मूल source से अलग हो सकता है, जैसे local variables के नाम, कुछ generics और lambdas में।
  • हर entry 64 MB तक, class फ़ाइलें 16 MB तक और nested archives 128 MB तक unpack होते हैं। Remote या virtual file systems पर फ़ाइलें 256 MB तक पढ़ी जाती हैं।
  • यह read-only है, इसलिए आप किसी class को edit या दोबारा compile नहीं कर सकते। Nested archives सिर्फ़ एक level अंदर तक खुलते हैं।
  • APK और DEX फ़ाइलें नहीं पढ़ी जातीं।

अक्सर पूछे जाने वाले सवाल

क्या यह मुफ़्त है?

हाँ। सभी व्यू और एक बार में एक class डिकंपाइल करना मुफ़्त है। तीन Pro टूल, Export decompiled sources of a JAR, Compare two JARs और Find in every JAR of a folder, हर एक 3 बार मुफ़्त चलते हैं, और ट्रायल तभी गिना जाता है जब टूल कोई नतीजा देता है। उसके बाद इनके लिए Zovo Pro चाहिए, जो सभी Zovo एक्सटेंशन के लिए एक बार 19 USD का है।

Java source टैब Java क्यों माँगता है?

CFR एक Java प्रोग्राम है। Viewer पहले jarViewer.javaPath, फिर JAVA_HOME, फिर आपके PATH पर java में Java ढूँढता है। Java 8 या उससे नया कोई भी runtime चलेगा।

क्या Java के बिना bytecode पढ़ सकते हैं?

हाँ। Bytecode, Members, Constant pool और Class info टैब JavaScript में पढ़े जाते हैं और इनके लिए Java नहीं चाहिए।

क्या यह Cursor में चलता है?

हाँ। यह Open VSX पर zovo/zovo-jar-viewer नाम से है, इसलिए Cursor, Windsurf और VSCodium इसे इंस्टॉल कर सकते हैं।
