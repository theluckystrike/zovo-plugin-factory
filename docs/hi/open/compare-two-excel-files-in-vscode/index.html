VS Code में दो Excel या CSV फ़ाइलें compare करें

मुफ़्त extension Excel Compare & XLSX Diff install करें और दो workbooks या CSV फ़ाइलें चुनें। बदले हुए cells पीले रंग में दिखते हैं और पुरानी value कटी हुई दिखती है, जोड़ी गई rows हरी और हटाई गई rows लाल दिखती हैं। Rows पहले आपस में मिलाई जाती हैं और columns header से match होते हैं, इसलिए बीच में डाली गई एक row या एक column एक ही बदलाव के रूप में दिखता है। Commit से पहले आप किसी workbook को उसके Git HEAD version से भी compare कर सकते हैं। यह सब मुफ़्त है और कोई network request नहीं जाती। Zovo Pro (एक बार USD 19) तीन tools जोड़ता है, Export a diff report, Match rows by key columns और Compare two folders of workbooks, और हर tool को 3 बार मुफ़्त आज़माया जा सकता है।

VS Code में स्टेप्स

  1. Marketplace से Excel Compare & XLSX Diff इंस्टॉल करें, या Ctrl+P (macOS पर Cmd+P) दबाकर ext install zovo.zovo-excel-compare चलाएँ।
  2. Explorer में दो फ़ाइलें चुनें, right-click करें और Compare Selected Excel Files चुनें। या एक फ़ाइल पर right-click करके Compare with... चुनें और दूसरी फ़ाइल चुनें। Command Palette से "Excel Compare: Compare Two Excel or CSV Files..." भी चला सकते हैं।
  3. .xlsx, .xlsm, .xls, .ods, .csv और .tsv का कोई भी मेल चलता है, इसलिए आप एक .xlsx फ़ाइल को एक .csv फ़ाइल से compare कर सकते हैं।
  4. पहले summary line पढ़ें, फिर हर sheet का tab देखें, जिस पर उस sheet के differences की गिनती होती है। किसी cell पर click करने से पूरी पुरानी और नई value दिखती है और आप उन्हें copy कर सकते हैं।
  5. सभी sheets के हर बदलाव पर जाने के लिए N और P दबाएँ (या Next और Previous)। Cells में दिखने वाली values या खुद formulas compare करने के लिए Values और Formulas के बीच switch करें।
  6. Commit से पहले अपने बदलाव देखने के लिए Git repository में workbook पर right-click करें और Compare with Git HEAD चुनें।

क्या मुफ़्त है और Zovo Pro क्या जोड़ता है

कोई भी दो फ़ाइलें compare करना, grid, Values और Formulas, अगले और पिछले बदलाव पर जाना, encoding और delimiter अपने आप पहचानने वाला CSV diff और Compare with Git HEAD मुफ़्त हैं। Sign-in की ज़रूरत नहीं, कोई network request नहीं और कोई telemetry नहीं।

जब बदलाव किसी और को दिखाने हों, तब Export a diff report एक XLSX workbook लिखता है जिसमें बदले, जोड़े और हटाए गए cells रंग से भरे होते हैं, साथ में एक Summary sheet और हर पुरानी और नई value वाली Changes list होती है। यह एक HTML page या बदलावों की CSV list भी लिख सकता है। Screenshots की जगह आप एक ही फ़ाइल भेजते हैं।

Export a diff report का इस्तेमाल (Zovo Pro)

  1. ऊपर बताए तरीके से दो फ़ाइलें compare करें, फिर comparison toolbar में Export report पर click करें, या Command Palette से "Excel Compare: Export a diff report (XLSX, HTML or CSV) (Pro)" चलाएँ।
  2. XLSX, HTML या CSV चुनें।
  3. Report कहाँ save करनी है, वह जगह चुनें। Try तभी गिनी जाती है जब report लिख दी गई हो।

Export a diff report आपके कंप्यूटर पर 3 बार मुफ़्त चलता है, उसके बाद लाइसेंस माँगता है। न कोई पॉप-अप आता है, न कोई काउंटडाउन चलता है।

Excel Compare & XLSX Diff क्या करता है

  • Sheets पहले नाम से, फिर position से match होती हैं। जो sheets सिर्फ़ एक फ़ाइल में हैं, वे added या removed के रूप में दिखती हैं।
  • CSV और TSV, जिनकी encoding (BOM के साथ या बिना UTF-8, UTF-16, Windows code pages) और delimiter (comma, semicolon, tab या pipe) अपने आप पहचाने जाते हैं, line breaks वाले quoted fields के साथ भी।
  • बड़ी sheets। Grid सिर्फ़ screen पर दिख रही rows बनाती है, इसलिए 300,000 rows वाली sheet भी छोटी sheet जैसी scroll होती है।
  • Merged cells अलग हों या किसी limit ने sheet को काट दिया हो, तो note दिखता है।
  • बाकी दो Pro tools। Match rows by key columns rows को एक ID column से match करता है, इसलिए sort या reorder की गई sheets साफ़ compare होती हैं और जगह बदलने वाली rows mark होती हैं। Compare two folders of workbooks फ़ाइलों को नाम से जोड़ता है और दिखाता है कि कौन-सी फ़ाइलें एक जैसी हैं, कौन-सी अलग हैं और कौन-सी सिर्फ़ एक folder में हैं।

यह क्या नहीं करता

  • हर फ़ाइल 200 MB तक (setting excelCompare.maxFileSizeMB), हर sheet में 300,000 rows तक (excelCompare.maxRows), 1,000 columns और 200 sheets। कोई limit लागू होने पर view में note दिखता है।
  • जो workbook unpack होने पर 600 MB से बड़ा हो जाए, या zip bomb की तरह compressed हो, उसे unpack करने से पहले ही reject कर दिया जाता है।
  • Pro tool Match rows by key columns के बिना rows अपने content और position से मिलाई जाती हैं, ID column से नहीं।
  • यह सिर्फ़ compare करता है, फ़ाइलें edit या merge नहीं करता।

अक्सर पूछे जाने वाले सवाल

क्या यह मुफ़्त है?

दो workbooks या CSV फ़ाइलें compare करना, Values और Formulas, अगला और पिछला बदलाव और Compare with Git HEAD मुफ़्त हैं। तीनों Pro tools, Export a diff report, Match rows by key columns और Compare two folders of workbooks, में से हर एक के 3 मुफ़्त tries हैं। उसके बाद Zovo Pro चाहिए, जो एक बार USD 19 में सभी Zovo extensions के लिए है।

क्या VS Code बिना extension के दो Excel फ़ाइलें compare कर सकता है?

नहीं। .xlsx फ़ाइल XML parts की एक zip होती है, इसलिए built-in diff उसे binary दिखाता है। आपको ऐसा extension चाहिए जो workbook पढ़ सके।

ऊपर एक row डालने से क्या नीचे की हर row बदली हुई दिखेगी?

नहीं। Compare करने से पहले rows मिलाई जाती हैं, इसलिए डाली गई row एक जोड़ी गई row के रूप में दिखती है।

क्या मैं देख सकता हूँ कि पिछले commit के बाद workbook में क्या बदला?

हाँ। Git repository में फ़ाइल पर right-click करें और Compare with Git HEAD चुनें। यह आपका local git चलाता है।
