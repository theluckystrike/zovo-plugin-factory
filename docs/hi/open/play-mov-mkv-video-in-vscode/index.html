VS Code में स्टेप्स

  1. Marketplace से Video Preview with Sound इंस्टॉल करें, या Ctrl+P (macOS पर Cmd+P) दबाकर ext install zovo.video-preview-with-sound चलाएँ।
  2. अगर वीडियो MKV, WebM, AVI, WMV, FLV, MPG, OGV या M2TS फ़ाइल है, या उसमें AC-3, E-AC-3 या DTS आवाज़ है, तो पहले ffmpeg इंस्टॉल करें। Windows पर winget install ffmpeg, Linux पर sudo apt install ffmpeg या macOS पर brew install ffmpeg चलाएँ। AAC आवाज़ वाली MP4, MOV और M4V के लिए और कुछ नहीं चाहिए।
  3. Explorer में .mp4, .m4v, .mov, .webm, .mkv, .avi, .wmv, .flv, .mpg, .mpeg, .ogv या .m2ts फ़ाइल पर क्लिक करें और चलाने के लिए Space दबाएँ। अगर VS Code पूछे कि कौन-सा editor इस्तेमाल करना है, तो "Video Preview with Sound" चुनें।
  4. जब तक chip पर "Sound: on" न दिखे, वीडियो बिना आवाज़ के चलता है। MKV या WebM को re-encode किए बिना MP4 में कॉपी किया जाता है। ProRes, AVI, WMV और दूसरे वीडियो जिन्हें VS Code decode नहीं कर पाता, एक बार H.264 में बदले जाते हैं और cache में रखे जाते हैं।
  5. वीडियो के बगल में उसी नाम की .srt या .vtt फ़ाइल रखें, subtitles अपने आप लोड हो जाते हैं। tracks बदलने या उन्हें बंद करने के लिए C दबाएँ या CC मेन्यू इस्तेमाल करें।
  6. एक frame आगे या पीछे जाने के लिए , और . दबाएँ, speed 0.1x से 4x तक बदलने के लिए [ और ], loop सेट करने के लिए A और B, मौजूदा frame को पूरे साइज़ के PNG में सेव करने के लिए S और picture-in-picture के लिए P।

क्या मुफ़्त है और Zovo Pro क्या जोड़ता है

आवाज़ के साथ playback, built-in AAC decoder, ffmpeg के साथ MKV और WebM playback, जिन वीडियो को VS Code decode नहीं कर पाता उनका conversion, subtitles, picture-in-picture, frame steps, speed, A-B loop, मौजूदा frame को PNG में सेव करना (S), metadata पैनल और resume मुफ़्त हैं।

Clip export वीडियो के A-B हिस्से को, या पूरे वीडियो को, pull request, issue या docs के लिए GIF या MP4 के रूप में सेव करता है। GIF player के अंदर ही बनता है, किसी दूसरे टूल के बिना, 480 px पर 10 fps, 640 px पर 15 fps, या 960 px तक 15 fps पर, और ज़्यादा से ज़्यादा 60 सेकंड का। MP4 आपके अपने ffmpeg से कटता है, या तो exact cut के रूप में, जो H.264 और AAC में re-encode करता है और A वाले frame से शुरू होता है, या fast copy के रूप में, जो original streams रखता है और A से पहले वाले keyframe से शुरू होता है।

Clip export का इस्तेमाल (Zovo Pro)

  1. वीडियो को player में खोलें। जो हिस्सा चाहिए उसकी शुरुआत पर A और आख़िर में B दबाएँ, या पूरे वीडियो के लिए कुछ भी सेट न करें।
  2. player में Clip (उस पर PRO badge है) दबाएँ, या controls के नीचे छोटी Pro tools row में "Export a Clip as GIF or MP4"। Explorer में वीडियो पर राइट-क्लिक करके "Zovo Pro: Export a Clip as GIF or MP4" भी चुन सकते हैं।
  3. "GIF, 480 px wide, 10 fps", "GIF, 640 px wide, 15 fps", "GIF, up to 960 px wide, 15 fps", "MP4, exact cut" या "MP4, fast copy" चुनें, फिर सेव करने की जगह चुनें।
  4. Esc दबाने से export रुक जाता है। try तभी गिना जाता है जब फ़ाइल सेव होती है, इसलिए cancel किया गया dialog या रोका गया export कोई मुफ़्त try खर्च नहीं करता।

Clip export आपके कंप्यूटर पर 3 बार मुफ़्त चलता है, उसके बाद लाइसेंस माँगता है। न कोई पॉप-अप आता है, न कोई काउंटडाउन चलता है।

Video Preview with Sound क्या करता है

  • AAC (mono या stereo), ALAC, MP3 या PCM आवाज़ वाली MP4, M4V और MOV, बिना कुछ और इंस्टॉल किए, Windows, Linux और macOS पर।
  • MKV और WebM, जिन्हें ffmpeg MP4 में कॉपी करता है और फिर वे आवाज़ के साथ चलते हैं।
  • MP4, M4V या MOV में AC-3, E-AC-3, DTS, Opus या 5.1 AAC आवाज़, जिसे ffmpeg या macOS के साथ आने वाला afconvert decode करता है।
  • Apple ProRes, MPEG-4 Part 2 और DNxHD वीडियो, और AVI, WMV, FLV, MPG, MPEG, OGV और M2TS फ़ाइलें, जिन्हें ffmpeg से H.264 में बदला जाता है।
  • वीडियो के बगल में रखी .srt और .vtt फ़ाइलों से subtitles।

यह क्या नहीं करता

  • ffmpeg के बिना MKV और WebM किसी भी सिस्टम पर नहीं खुलते। player में "Install ffmpeg to open this file" लिखा आता है। ffmpeg एक्सटेंशन के साथ नहीं आता।
  • macOS का afconvert वीडियो नहीं बदल सकता और MKV या WebM नहीं खोल सकता। conversion के लिए हमेशा आपका अपना ffmpeg चाहिए, और लंबी ProRes फ़ाइल में कई मिनट लग सकते हैं।
  • built-in decoder HE-AAC को उसके AAC-LC core से आधे sample rate पर चलाता है। पूरे HE-AAC, 5.1 AAC, AC-3 और DTS के लिए ffmpeg इंस्टॉल करें।
  • 4096 MB से बड़ी फ़ाइलें चलती तो हैं, पर बिना आवाज़ के (सेटिंग videoPreview.maxDecodeSizeMB)।
  • subtitles सिर्फ़ .srt और .vtt फ़ाइलों से आते हैं, हर फ़ाइल ज़्यादा से ज़्यादा 5 MB की। वीडियो फ़ाइल के अंदर के subtitles नहीं पढ़े जाते। .ts और .mts फ़ाइलें नहीं खुलतीं, क्योंकि इन नामों वाली फ़ाइलें TypeScript फ़ाइलें होती हैं।

अक्सर पूछे जाने वाले सवाल

VS Code मेरा MP4 बिना आवाज़ के क्यों चलाता है?

VS Code के built-in Chromium में H.264 वीडियो decoder है, पर AAC decoder नहीं है, और ज़्यादातर MP4 और MOV फ़ाइलों में AAC आवाज़ होती है। यह एक्सटेंशन आवाज़ खुद decode करता है और उसे तस्वीर के साथ sync में चलाता है।

क्या ffmpeg चाहिए?

AAC, ALAC, MP3 या PCM आवाज़ वाली MP4, MOV और M4V के लिए नहीं। MKV, WebM, AVI, WMV, FLV, MPG, OGV और M2TS के लिए, ProRes और उन दूसरे वीडियो के लिए जिन्हें VS Code decode नहीं कर पाता, और Clip export से MP4 clips के लिए ffmpeg चाहिए। AC-3, E-AC-3 और DTS आवाज़ के लिए ffmpeg चाहिए, या macOS पर afconvert।

क्या यह मुफ़्त है?

हाँ। Playback, आवाज़, subtitles, frame steps, मौजूदा frame को PNG में सेव करना और conversion मुफ़्त हैं। Clip export, Frame export और contact sheet Zovo Pro टूल हैं, हर एक 3 बार मुफ़्त, फिर सभी Zovo एक्सटेंशन के लिए एक बार 19 USD।

क्या यह Cursor में चलता है?

हाँ। यह Open VSX पर zovo/video-preview-with-sound नाम से है, इसलिए Cursor, Windsurf और VSCodium इसे इंस्टॉल कर सकते हैं।
