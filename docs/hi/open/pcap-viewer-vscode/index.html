VS Code में PCAP फ़ाइल खोलें

मुफ़्त PCAP Viewer इंस्टॉल करें और .pcap या .pcapng फ़ाइल पर क्लिक करें। यह पैकेट लिस्ट, प्रोटोकॉल ट्री, ट्री से जुड़ा hex पैनल, Wireshark जैसे display filter, follow stream और statistics दिखाता है। यह फ़ाइल को खुद JavaScript में पढ़ता है, इसलिए Wireshark, tshark या sharkd की ज़रूरत नहीं होती। व्यूअर मुफ़्त है, और Zovo Pro (19 USD, एक बार का भुगतान) पैकेट लिस्ट का CSV या JSON एक्सपोर्ट, Markdown कैप्चर रिपोर्ट और फ़ोल्डर का सारांश जोड़ता है। हर टूल 3 बार मुफ़्त चलता है।

VS Code में स्टेप्स

  1. Marketplace से PCAP Viewer इंस्टॉल करें, या Ctrl+P (macOS पर Cmd+P) दबाकर ext install zovo.zovo-pcap-viewer चलाएँ।
  2. .pcap, .pcapng, .pcap.gz, .pcapng.gz या .ntar फ़ाइल पर क्लिक करें। .cap, .dmp या दूसरे नाम वाली फ़ाइल के लिए Explorer में उस पर राइट-क्लिक करें और "Open in PCAP Viewer" चुनें।
  3. tcp.port == 443 && ip.addr == 10.0.0.1 जैसा display filter टाइप करें और Enter दबाएँ। फ़िल्टर सही हो तो बॉक्स हरा हो जाता है, और गलत हो तो बताता है कि उसमें क्या गलत है।
  4. प्रोटोकॉल ट्री में किसी फ़ील्ड पर क्लिक करें, तो hex पैनल में उसके बाइट हाइलाइट हो जाते हैं। किसी बाइट पर क्लिक करें, तो उसका फ़ील्ड मिल जाता है।
  5. किसी पैकेट पर डबल-क्लिक करके उसकी TCP या UDP stream को ASCII, UTF-8 या hex dump के रूप में follow करें। इसे कॉपी करें या किसी फ़ाइल में सेव करें।
  6. प्रोटोकॉल hierarchy, conversations, endpoints और कैप्चर में मिले नामों के लिए Statistics पर क्लिक करें। किसी row पर क्लिक करके उसी पर फ़िल्टर लगाएँ।
  7. चुने हुए पैकेट, या फ़िल्टर में दिख रहे सभी पैकेट, नई pcap फ़ाइल के रूप में सेव करने के लिए Export मेन्यू खोलें।

क्या मुफ़्त है और Zovo Pro क्या जोड़ता है

पैकेट लिस्ट, प्रोटोकॉल ट्री, जुड़ा हुआ hex पैनल, display filter, सेव किए गए फ़िल्टर, follow stream, statistics और पैकेट को नई pcap फ़ाइल में एक्सपोर्ट करना मुफ़्त है। साइन-इन की ज़रूरत नहीं होती, और यह ऑफ़लाइन काम करता है।

यह फ़िल्टर में दिख रहे पैकेट CSV या JSON फ़ाइल में लिखता है, हर पैकेट की एक row: नंबर, UTC समय, शुरुआत से सेकंड, source, destination, पोर्ट, प्रोटोकॉल, लंबाई, stream फ़िल्टर, कैप्चर से मिले होस्ट नाम और Info टेक्स्ट। CSV Excel में खुलती है और उसमें फ़ॉर्मूला जैसा टेक्स्ट सुरक्षित कर दिया जाता है। JSON jq और pandas के साथ काम करती है। टिकट या स्क्रिप्ट के लिए टेबल आपको हाथ से row कॉपी किए बिना मिल जाती है।

Export packet list to CSV or JSON का इस्तेमाल (Zovo Pro)

  1. कैप्चर खोलें, और अगर सिर्फ़ कुछ पैकेट चाहिए तो display filter टाइप करें।
  2. टूलबार में Export मेन्यू खोलें और "Packet list as CSV" या "Packet list as JSON" चुनें, या Command Palette से "PCAP Viewer: Export Packet List to CSV or JSON (Pro)..." चलाएँ। आप Explorer में कैप्चर पर राइट-क्लिक करके "Zovo Pro: Export packet list to CSV or JSON" भी चुन सकते हैं।
  3. फ़ाइल सेव करने की जगह चुनें। ट्राई तभी गिना जाता है जब फ़ाइल लिख दी गई हो, इसलिए Escape दबाने या error आने पर कुछ खर्च नहीं होता।

Export packet list to CSV or JSON आपके कंप्यूटर पर 3 बार मुफ़्त चलता है, उसके बाद लाइसेंस माँगता है। न कोई पॉप-अप आता है, न कोई काउंटडाउन चलता है।

Cursor, Windsurf या VSCodium में स्टेप्स

  1. Ctrl+Shift+X (macOS पर Cmd+Shift+X) से Extensions व्यू खोलें।
  2. zovo.zovo-pcap-viewer खोजें और Install पर क्लिक करें। Cursor, Windsurf और VSCodium एक्सटेंशन Open VSX से इंस्टॉल करते हैं, जहाँ इस एक्सटेंशन का नाम zovo/zovo-pcap-viewer है।
  3. अगर आपके एडिटर में एक्सटेंशन गैलरी नहीं है, तो Open VSX पेज से .vsix फ़ाइल डाउनलोड करें और "Extensions: Install from VSIX..." चलाएँ।
  4. इसके बाद सब कुछ VS Code की तरह ही काम करता है।

PCAP Viewer क्या करता है

  • pcap (माइक्रोसेकंड और नैनोसेकंड, little और big-endian) और pcapng, .gz के रूप में भी।
  • Ethernet, 802.1Q VLAN, Linux cooked capture (SLL और SLL2), raw IPv4 और IPv6, BSD loopback, 802.11 हेडर और radiotap।
  • ARP, IPv4, IPv6, ICMP, ICMPv6, TCP, UDP, DNS और mDNS, DHCP, HTTP/1.x, server name (SNI) और ALPN के साथ TLS records, और QUIC long headers।
  • बड़े कैप्चर। रिलीज़ जाँच में 1,438,965 पैकेट वाला 1 GB का कैप्चर लगभग 2 सेकंड में लिस्ट हुआ।
  • खराब फ़ाइलें। खराबी से पहले के सारे पैकेट दिखते हैं, साथ में एक मैसेज जो बताता है कि क्या गलत है और कहाँ।

यह क्या नहीं करता

  • सिर्फ़ लिस्ट में दिए प्रोटोकॉल ही फ़ील्ड में डिकोड होते हैं। HTTP का मतलब HTTP/1.x है, 802.11 में सिर्फ़ हेडर, और QUIC में सिर्फ़ long header।
  • TLS ट्रैफ़िक decrypt नहीं होता। यह server name (SNI) और ALPN के साथ TLS records दिखाता है।
  • फ़िल्टर बॉक्स Wireshark display filter syntax का आम हिस्सा समझता है, पूरा नहीं।
  • .gz कैप्चर 512 MB पर unpack होना बंद कर देता है (सेटिंग pcapViewer.maxGzipMB) और यह बात बताता है।
  • रिमोट या वर्चुअल फ़ाइल सिस्टम पर फ़ाइलें 256 MB तक खुलती हैं (सेटिंग pcapViewer.maxRemoteMB)।

अक्सर पूछे जाने वाले सवाल

क्या Wireshark इंस्टॉल होना ज़रूरी है?

नहीं। PCAP Viewer Windows, macOS और Linux पर VS Code के अंदर JavaScript में pcap और pcapng पढ़ता है। यह Wireshark, tshark या sharkd का इस्तेमाल नहीं करता।

क्या कैप्चर खोलने पर DNS queries भेजी जाती हैं?

नहीं। होस्ट नाम सिर्फ़ पैकेट के अंदर के DNS जवाबों और pcapng फ़ाइलों के name blocks से आते हैं। एक्सटेंशन में कोई telemetry नहीं है और यह कोई नेटवर्क request नहीं भेजता।

क्या यह मुफ़्त है?

हाँ। व्यूअर, फ़िल्टर, follow stream, statistics और pcap एक्सपोर्ट मुफ़्त हैं। Export packet list to CSV or JSON, Capture report और Folder summary Zovo Pro टूल हैं, और हर एक 3 बार मुफ़्त चलता है। उसके बाद Zovo Pro सभी Zovo एक्सटेंशन के लिए एक बार 19 USD का है।

क्या यह Cursor में काम करता है?

हाँ। यह VS Code 1.90 और उसके बाद के वर्शन में, और Open VSX से एक्सटेंशन इंस्टॉल करने वाले एडिटर, जैसे Cursor, Windsurf और VSCodium, में काम करता है।
