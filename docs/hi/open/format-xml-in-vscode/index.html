VS Code में स्टेप्स

  1. Marketplace से XML Formatter & XPath Tools इंस्टॉल करें, या Ctrl+P (macOS पर Cmd+P) दबाकर ext install zovo.zovo-xml-xpath-tools चलाएँ।
  2. कोई .xml फ़ाइल खोलें और Shift+Alt+F (Mac पर Shift+Option+F) दबाएँ, या Format Document चलाएँ। अगर आपके पास एक से ज़्यादा XML formatter हैं, तो VS Code पूछता है कि कौन-सा इस्तेमाल करें। Format Selection भी काम करता है।
  3. Formatter आपका tab size और tabs या spaces इस्तेमाल करता है, और line endings, byte order mark और आख़िरी newline को वैसा ही रखता है। अगर फ़ाइल well formed नहीं है, तो कुछ नहीं बदलता और आपको line और column के साथ error दिखता है।
  4. फ़ाइल को छोटा करने के लिए पूरी फ़ाइल या selection पर "XML: Minify XML" चलाएँ। Comments बने रहते हैं, जब तक आप xmlXpathTools.minify.removeComments चालू न करें।
  5. XPath चलाने के लिए editor title में search बटन पर क्लिक करें या "XML: Evaluate XPath…" चलाएँ। Results अपनी line के साथ XPath Results में आते हैं। किसी result पर क्लिक करने से वह editor में select हो जाता है।
  6. Cursor के नीचे वाले element का path कॉपी करने के लिए status bar में XPath पर क्लिक करें: positions के साथ, id या name attributes के साथ, या portable local-name() रूप में।
  7. 50 MB से बड़ी फ़ाइल के लिए Explorer में उस पर राइट-क्लिक करके "Format Large XML File on Disk…" चुनें। यह बगल में name.formatted.xml लिखता है, या आपकी पुष्टि के बाद फ़ाइल को ही बदल देता है।

क्या मुफ़्त है और Zovo Pro क्या जोड़ता है

Format Document, Format Selection, Minify XML, XPath 1.0, Copy XPath, XML Tree view, Problems में well-formedness errors और Format Large XML File on Disk मुफ़्त हैं। कोई sign-in नहीं है, और एक्सटेंशन में कोई network code नहीं है।

Run XPath on Every XML File in a Folder एक फ़ोल्डर के अंदर हर .xml, .xsd, .csproj, .svg, .kml और ऐसी ही फ़ाइलों पर एक XPath चलाता है, हर फ़ाइल के अपने namespace prefixes के साथ। Results spreadsheet के लिए CSV (file, line, kind, name, value), script के लिए JSON, या review के लिए Markdown report के रूप में खुलते हैं। आपको कई फ़ाइलों से एक ही value मिलती है, जैसे pom.xml फ़ाइलों के सेट में हर artifactId, उन्हें एक-एक करके खोले बिना।

Run XPath on Every XML File in a Folder का इस्तेमाल (Zovo Pro)

  1. Explorer में किसी फ़ोल्डर पर राइट-क्लिक करके "Zovo Pro: Run XPath on Every XML File in a Folder" चुनें, या Command Palette से "XML: Run XPath on Every XML File in a Folder (Pro)" चलाएँ और फ़ोल्डर चुनें।
  2. या एक फ़ाइल में XPath चलाने के बाद XPath Results की आख़िरी line, "Run this XPath on every XML file in a folder", पर क्लिक करें, ताकि वही expression पूरे फ़ोल्डर पर चले।
  3. XPath टाइप करें। एक notification में progress और Cancel बटन दिखता है।
  4. "Open as CSV", "Open as JSON" या "Open a Markdown report" चुनें। Results एक नए editor टैब में खुलते हैं। Try तभी गिना जाता है जब आपको result मिले: Escape, XPath में typo या बिना XML फ़ाइलों वाला फ़ोल्डर कोई try नहीं लेता।

Run XPath on Every XML File in a Folder आपके कंप्यूटर पर 3 बार मुफ़्त चलता है, उसके बाद लाइसेंस माँगता है। न कोई पॉप-अप आता है, न कोई काउंटडाउन चलता है।

XML Formatter & XPath Tools क्या करता है

  • वे फ़ाइलें जिन्हें VS Code XML के रूप में खोलता है। एक्सटेंशन .kml, .gpx, .rss, .atom, .wsdl, .dbk, .xlf, .xliff, .resx, .nuspec, .props, .targets और .xaml फ़ाइलों को भी XML के रूप में खोलता है।
  • बड़ी फ़ाइलें: formatting, tree और XPath एक background thread में चलते हैं। एक्सटेंशन के tests में लगभग 1 million elements वाली 49 MB की फ़ाइल 1.6 सेकंड में फ़ॉर्मैट हुई।
  • Plain names default namespace से भी मिलते हैं, इसलिए pom.xml में //dependency/artifactId चलता है। Strict XPath 1.0 के लिए xmlXpathTools.xpath.strictNamespaces चालू करें।
  • Attribute layout: जैसा लिखा है वैसा, एक line में, या हर attribute अलग line में (सेटिंग xmlXpathTools.format.attributes)।
  • Explorer में XML Tree view cursor के साथ चलता है, और Problems well-formedness errors को उनकी line और column के साथ दिखाता है।

यह क्या नहीं करता

  • सिर्फ़ XPath 1.0। XPath 2.0 या 3.1, XQuery और XSLT नहीं हैं।
  • यह जाँचता है कि फ़ाइल well formed है। यह XSD या DTD के हिसाब से validate नहीं करता।
  • 50 MB से बड़ी फ़ाइलें disk पर फ़ॉर्मैट हो सकती हैं, पर VS Code उन्हें extensions को नहीं देता, इसलिए उन पर tree और XPath नहीं चलते।
  • On-disk command UTF-8, byte order mark वाला UTF-16 और ISO-8859-1 पढ़ता है।
  • जिस element के अंदर text है, जैसे <p>Some <b>bold</b> text</p>, वह जैसा लिखा है वैसे ही अपनी line पर रहता है। सिर्फ़ उन elements में नए line breaks आते हैं जिनमें tags हैं और text नहीं।

अक्सर पूछे जाने वाले सवाल

क्या यह मुफ़्त है?

Formatting, Minify XML, XPath, Copy XPath, XML Tree view और well-formedness checks मुफ़्त हैं। तीनों Pro टूल, Run XPath on Every XML File in a Folder, Format All XML Files in a Folder और Compare Two XML Files Ignoring Formatting, 3-3 बार मुफ़्त चलते हैं। उसके बाद इनके लिए Zovo Pro चाहिए, जो सभी Zovo एक्सटेंशन के लिए एक बार 19 USD का है।

क्या formatting मेरा text या CDATA बदलेगी?

नहीं। सिर्फ़ tags के बीच का whitespace बदलता है, उन elements में जिनमें tags हैं और text नहीं। Text, CDATA, comments और xml:space="preserve" के अंदर का content जैसा है वैसा कॉपी होता है, और दूसरी बार फ़ॉर्मैट करने पर कुछ नहीं बदलता।

pom.xml में मेरा XPath कुछ भी select क्यों नहीं करता?

फ़ाइल में default namespace है। इस एक्सटेंशन में plain names default namespace से भी मिलते हैं, इसलिए //dependency चलता है। Strict XPath 1.0 के लिए xmlXpathTools.xpath.strictNamespaces चालू करें।

क्या यह Cursor में चलता है?

हाँ। Cursor, Windsurf और VSCodium इसे Open VSX से इंस्टॉल करते हैं, जहाँ यह zovo/zovo-xml-xpath-tools नाम से है।
