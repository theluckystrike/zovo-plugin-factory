ELF, PE और Mach-O बाइनरी फ़ाइलें VS Code में खोलें

मुफ़्त ELF Viewer & PE Viewer इंस्टॉल करें और किसी .so, .exe, .dll या .dylib फ़ाइल पर क्लिक करें। Linux ELF, Windows PE और Apple Mach-O फ़ाइलों के headers, sections, segments, imports, exports और symbols के लिए अलग टैब मिलते हैं, साथ में एक hex व्यू, और readelf, objdump या dumpbin की ज़रूरत नहीं पड़ती। फ़ाइल के सभी व्यू मुफ़्त और read-only हैं। Zovo Pro (19 USD, एक बार का भुगतान) तीन टूल जोड़ता है, JSON या C header के रूप में एक्सपोर्ट, दो बाइनरी की तुलना और बाइनरी वाले फ़ोल्डर में कोई नाम खोजना, और हर टूल को आप 3 बार मुफ़्त चला सकते हैं।

VS Code में स्टेप्स

  1. Marketplace से ELF Viewer & PE Viewer इंस्टॉल करें, या Ctrl+P (macOS पर Cmd+P) दबाकर ext install zovo.zovo-elf-pe-viewer चलाएँ।
  2. Explorer में किसी .exe, .dll, .sys, .so, .dylib, .elf या .ko फ़ाइल पर क्लिक करें। वह viewer में खुलती है। .o object फ़ाइल या बिना extension वाली Linux या macOS executable के लिए उस पर राइट-क्लिक करके Open in ELF & PE Viewer चुनें।
  3. सबसे पहले Overview टैब आता है। इसमें architecture, फ़ाइल का type, entry point, linked libraries, ASLR और DEP जैसे security flags, build ID और PDB path दिखते हैं।
  4. Sections या Imports टैब खोलें। ELF imports में हर function की library और symbol version दिखता है। PE फ़ाइलों में data directories, delay-load imports और resources भी मिलते हैं, और Mach-O फ़ाइलों में load commands।
  5. Rows कम करने के लिए टेबल के ऊपर filter box में टाइप करें, और sort करने के लिए कॉलम header पर क्लिक करें। Copy rows से rows tab-separated टेक्स्ट के रूप में clipboard पर आ जाती हैं।
  6. किसी section या segment का bytes लिंक क्लिक करें, तो Hex टैब में उसके bytes मार्क होकर दिखते हैं। Headers टैब में Show every header field with its offset से field tree खुलता है।

क्या मुफ़्त है और Zovo Pro क्या जोड़ता है

फ़ाइल के सभी व्यू मुफ़्त हैं और sign-in की ज़रूरत नहीं है, यानी overview, सभी टेबल, filter, sort और copy, hex व्यू और field tree। एक्सटेंशन बाइनरी में कभी कुछ नहीं लिखता और कोई नेटवर्क कॉल नहीं करता।

Build फ़ोल्डर की कौन-सी बाइनरी किसी function को import करती हैं या किसी library से link होती हैं, यह जानने के लिए यह टूल फ़ोल्डर की हर ELF, PE और Mach-O फ़ाइल पढ़ता है और हर मैच को उसकी फ़ाइल के साथ दिखाता है। सादा टेक्स्ट नाम के किसी भी हिस्से से मैच करता है, और /regex/ भी काम करता है। हर बाइनरी खोलने या फ़ाइल-दर-फ़ाइल readelf या dumpbin चलाने के बजाय आपको एक ही खोज में जवाब मिल जाता है।

Find a symbol or import in a folder का इस्तेमाल (Zovo Pro)

  1. कोई बाइनरी खोलें और viewer के ऊपर Find in folder… पर क्लिक करें, या Command Palette से "ELF & PE Viewer: Find a symbol or import in a folder (Pro)" चलाएँ।
  2. CreateFileW या SSL_read जैसा कोई नाम टाइप करें, या /^_?pthread_/ जैसा regex। यह workspace फ़ोल्डर में खोजता है, या आपसे फ़ोल्डर पूछता है।
  3. Viewer से चलाने पर मैच एक Find टैब में Copy बटन के साथ खुलते हैं। Command Palette से चलाने पर वे एक लिस्ट में दिखते हैं, और किसी पर क्लिक करने से वह बाइनरी खुलती है।
  4. Escape दबाने पर, या ऐसी खोज में जिसका कोई मैच न मिले, कोई मुफ़्त ट्रायल ख़र्च नहीं होता।

Find a symbol or import in a folder आपके कंप्यूटर पर 3 बार मुफ़्त चलता है, उसके बाद लाइसेंस माँगता है। न कोई पॉप-अप आता है, न कोई काउंटडाउन चलता है।

Cursor, Windsurf या VSCodium में स्टेप्स

  1. Ctrl+Shift+X (macOS पर Cmd+Shift+X) से Extensions व्यू खोलें।
  2. zovo.zovo-elf-pe-viewer खोजें और Install पर क्लिक करें। Cursor, Windsurf और VSCodium एक्सटेंशन Open VSX से इंस्टॉल करते हैं, जहाँ इस एक्सटेंशन का नाम zovo/zovo-elf-pe-viewer है।
  3. अगर आपके एडिटर में एक्सटेंशन गैलरी नहीं है, तो Open VSX पेज से .vsix फ़ाइल डाउनलोड करें और "Extensions: Install from VSIX..." चलाएँ।
  4. इसके बाद सब कुछ VS Code की तरह ही काम करता है।

ELF Viewer & PE Viewer क्या करता है

  • 32 और 64-bit, little और big endian ELF फ़ाइलें, जैसे .so, .o, .ko, .elf, .axf और Linux executables।
  • PE32 और PE32+ फ़ाइलें, जैसे .exe, .dll, .sys, .efi और .pyd, नाम और ordinal से imports, forwarders वाले exports और .NET runtime header के साथ।
  • 32 और 64-bit Mach-O, और universal binaries। ऊपर से architecture चुनें, जैसे arm64 या x86_64।
  • 100,000 rows तक की टेबल, जिन्हें filter, sort और copy किया जा सकता है।

यह क्या नहीं करता

  • यह read-only है और इसमें disassembly नहीं है।
  • Static libraries (.a), Java class फ़ाइलें, WebAssembly और DEX फ़ाइलें नहीं पढ़ी जातीं।
  • हर टेबल 100,000 rows पर रुक जाती है, और फ़ाइल पढ़ना 10 सेकंड बाद रुक जाता है। ऐसा होने पर viewer यह बताता है।
  • Remote या virtual file systems पर फ़ाइलें 256 MB तक पढ़ी जाती हैं। Find in folder सिर्फ़ लोकल फ़ोल्डरों में खोजता है।
  • .o फ़ाइलें और बिना extension वाली फ़ाइलें डिफ़ॉल्ट रूप से नहीं खुलतीं। राइट-क्लिक मेन्यू से Open in ELF & PE Viewer इस्तेमाल करें।

अक्सर पूछे जाने वाले सवाल

क्या यह मुफ़्त है?

फ़ाइल के सभी व्यू मुफ़्त हैं, sign-in की ज़रूरत नहीं। तीन Pro टूल, JSON या C header के रूप में एक्सपोर्ट, दो बाइनरी की तुलना और फ़ोल्डर में नाम खोजना, हर एक 3 बार मुफ़्त चलते हैं। उसके बाद इनके लिए Zovo Pro चाहिए, जो सभी Zovo एक्सटेंशन के लिए एक बार 19 USD का है।

क्या readelf, objdump या dumpbin चाहिए?

नहीं। एक्सटेंशन ELF, PE और Mach-O फ़ाइलें खुद पढ़ता है, कोई दूसरा प्रोग्राम इंस्टॉल करने की ज़रूरत नहीं।

क्या यह बाइनरी को बदल सकता है?

नहीं। यह फ़ाइल सिर्फ़ पढ़ता है और उसमें कभी नहीं लिखता। Pro एक्सपोर्ट एक नई JSON या header फ़ाइल वहाँ सेव करता है जहाँ आप चुनें।

क्या यह Cursor में चलता है?

हाँ। README के मुताबिक यह Cursor, Windsurf और VSCodium में काम करता है, और यह Open VSX पर है, इसलिए ये एडिटर इसे इंस्टॉल कर सकते हैं।
