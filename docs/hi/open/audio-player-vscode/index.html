हिन्दी में गाइड

VS Code में WAV, MP3, FLAC, Ogg और Opus फ़ाइलें waveform के साथ सुनें

मुफ़्त Audio Player & WAV Player इंस्टॉल करें और किसी .wav, .mp3, .flac, .ogg या .opus फ़ाइल पर क्लिक करें। फ़ाइल हर चैनल के waveform, spectrogram, A-B loop, 0.25x से 2x तक की स्पीड (pitch वही रहती है) और LUFS loudness के आँकड़ों के साथ चलती है। Opus फ़ाइलें एक्सटेंशन के साथ आए decoder से चलती हैं, और अगर आपके पास ffmpeg है तो M4A और AAC फ़ाइलें एक क्लिक के बाद चलती हैं। फ़ाइलें चलाना और जाँचना मुफ़्त है। Zovo Pro (19 USD, एक बार का भुगतान) दो टूल जोड़ता है, Folder Loudness Report और Normalize Loudness, और हर टूल को आप 3 बार मुफ़्त चला सकते हैं।

VS Code में स्टेप्स

  1. Marketplace से Audio Player & WAV Player इंस्टॉल करें, या Ctrl+P (macOS पर Cmd+P) दबाकर ext install zovo.audio-preview-vscode चलाएँ।
  2. Explorer में किसी .wav, .mp3, .flac, .ogg, .opus या .m4a फ़ाइल पर क्लिक करें। अगर कोई दूसरा player खुले, तो फ़ाइल पर राइट-क्लिक करके "Open in Audio Preview" चुनें।
  3. चलाने या रोकने के लिए Space दबाएँ। Left और Right से 5 सेकंड आगे या पीछे जाएँ (Shift के साथ 1 सेकंड)। किसी जगह पर पहुँचने के लिए waveform पर क्लिक करें।
  4. किसी हिस्से को loop में चलाने के लिए waveform पर उस हिस्से में drag करें, या playhead की जगह पर loop की शुरुआत और अंत तय करने के लिए [ और ] दबाएँ। L से loop चालू या बंद होता है।
  5. 0.25x से 2x तक कोई स्पीड चुनें। Pitch नहीं बदलती।
  6. Header में codec, sample rate, चैनल, bit depth, अवधि और bitrate देखें। Loudness पैनल में LUFS, peak और RMS हैं, और Tags पैनल में title, artist, album और बाकी tags।

क्या मुफ़्त है और Zovo Pro क्या जोड़ता है

सभी सपोर्टेड फ़ॉर्मैट चलाना, waveform, spectrogram, A-B loop, स्पीड, Loudness, File और Tags पैनल और Copy stats मुफ़्त हैं। ऑडियो फ़ाइल में कुछ भी वापस नहीं लिखा जाता, और एक्सटेंशन कोई नेटवर्क कॉल नहीं करता।

Folder Loudness Report किसी फ़ोल्डर की हर ऑडियो फ़ाइल के लिए CSV में एक row लिखता है। इसमें फ़ॉर्मैट, अवधि, sample rate, bit depth, title और artist, integrated LUFS, short-term और momentary max, sample peak, RMS, clipped samples और वह gain होता है जिससे फ़ाइल -14, -16 और -23 LUFS तक पहुँचे। हर फ़ाइल अलग से खोलने के बजाय आप रिकॉर्डिंग का पूरा फ़ोल्डर spreadsheet में sort करके जाँच लेते हैं। WAV फ़ाइलें एक्सटेंशन खुद पढ़ता है। MP3, FLAC, Ogg, Opus और M4A की rows के लिए आपका अपना ffmpeg चाहिए।

Folder Loudness Report का इस्तेमाल (Zovo Pro)

  1. Explorer में किसी फ़ोल्डर पर राइट-क्लिक करके "Folder Loudness Report (CSV, Pro)" चुनें, या Command Palette से "Audio Preview: Folder Loudness Report (CSV, Pro)" चलाकर फ़ोल्डर चुनें। Player में यह editor title के "..." मेन्यू में भी है।
  2. "This folder and its subfolders" या "This folder only" चुनें, फिर तय करें कि loudness-report.csv कहाँ सेव हो।
  3. एक notification प्रोग्रेस दिखाता है, और वहीं से काम रद्द किया जा सकता है। CSV को spreadsheet में खोलें। मुफ़्त ट्रायल तभी गिना जाता है जब फ़ाइल सच में लिखी जाए।

Folder Loudness Report आपके कंप्यूटर पर 3 बार मुफ़्त चलता है, उसके बाद लाइसेंस माँगता है। न कोई पॉप-अप आता है, न कोई काउंटडाउन चलता है।

Cursor, Windsurf या VSCodium में स्टेप्स

  1. Ctrl+Shift+X (macOS पर Cmd+Shift+X) से Extensions व्यू खोलें।
  2. zovo.audio-preview-vscode खोजें और Install पर क्लिक करें। Cursor, Windsurf और VSCodium एक्सटेंशन Open VSX से इंस्टॉल करते हैं, जहाँ इस एक्सटेंशन का नाम zovo/audio-preview-vscode है।
  3. अगर आपके एडिटर में एक्सटेंशन गैलरी नहीं है, तो Open VSX पेज से .vsix फ़ाइल डाउनलोड करें और "Extensions: Install from VSIX..." चलाएँ।
  4. इसके बाद सब कुछ VS Code की तरह ही काम करता है।

Audio Player & WAV Player क्या करता है

  • WAV (PCM 8 से 32-bit, float, A-law, mu-law, RF64), जो 2 MB के टुकड़ों में पढ़ी जाती है, ताकि बड़ी फ़ाइल से एडिटर न अटके।
  • MP3, FLAC और Ogg Vorbis, उस decoder से जो VS Code में पहले से है।
  • .opus या .ogg में Opus, एक्सटेंशन के साथ आए libopus decoder (WebAssembly) से।
  • 8 चैनल तक, हर चैनल का अपना waveform lane।
  • ID3v1, ID3v2.2 से 2.4, RIFF INFO, Vorbis comments और iTunes atoms के tags।

यह क्या नहीं करता

  • M4A और AAC के लिए आपका अपना ffmpeg चाहिए। उसके बिना आपको codec, अवधि, bitrate और tags दिखते हैं, साथ में एक मैसेज।
  • ALAC, AC-3 और दूसरे codecs, जिन्हें VS Code decode नहीं कर सकता, उनके लिए भी ffmpeg बटन चाहिए।
  • Compressed फ़ाइलें पूरी decode होती हैं। 600 MB से ज़्यादा decoded samples (44.1 kHz stereo के लगभग 28 मिनट) होने पर वे सिर्फ़ चलती हैं (सेटिंग audioPreview.maxDecodedMB)।
  • Peak एक sample peak है, oversampled true peak नहीं, और loudness range (LRA) नहीं दिखती।
  • यह फ़ाइलें चलाता और जाँचता है। उन्हें काटता या एडिट नहीं करता।

अक्सर पूछे जाने वाले सवाल

क्या यह मुफ़्त है?

फ़ाइलें चलाना, waveform, spectrogram, loop और loudness के आँकड़े मुफ़्त हैं। दो Pro टूल, Folder Loudness Report और Normalize Loudness, हर एक 3 बार मुफ़्त चलते हैं। उसके बाद इनके लिए Zovo Pro चाहिए, जो सभी Zovo एक्सटेंशन के लिए एक बार 19 USD का है।

VS Code में मेरी .opus फ़ाइल क्यों नहीं चलती?

VS Code जिस Chromium के साथ आता है, उसमें Opus decoder नहीं है। यह एक्सटेंशन WebAssembly में compile किया गया libopus साथ लाता है, इसलिए Opus बिना कुछ और इंस्टॉल किए चलता है।

मेरी M4A फ़ाइल चलने के बजाय मैसेज क्यों दिखाती है?

VS Code में AAC decoder भी नहीं है। ffmpeg इंस्टॉल हो तो Decode with ffmpeg बटन एक्सटेंशन के storage फ़ोल्डर में एक WAV कॉपी बनाता है और फ़ाइल चलने लगती है। एक्सटेंशन ffmpeg न साथ लाता है, न डाउनलोड करता है।

क्या यह Cursor में चलता है?

हाँ। एक्सटेंशन Open VSX पर zovo/audio-preview-vscode नाम से है, इसलिए Cursor, Windsurf और VSCodium इसे इंस्टॉल कर सकते हैं।
