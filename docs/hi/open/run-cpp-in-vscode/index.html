VS Code में C और C++ कोड एक क्लिक में चलाएँ

मुफ़्त Run C++ and C Code एक्सटेंशन इंस्टॉल करें, कोई .cpp या .c फ़ाइल खोलें और editor title में Run पर क्लिक करें, या Ctrl+Alt+Enter (Mac पर Cmd+Alt+Enter) दबाएँ। यह आपके कंप्यूटर पर पहले से मौजूद gcc, g++, clang या clang++ से फ़ाइल compile करता है और उसे टर्मिनल में चलाता है, जहाँ cin और scanf काम करते हैं। Compiler errors Problems पैनल में सही लाइन पर दिखते हैं, और Input & Tests पैनल, stress test और benchmark मुफ़्त हैं। Zovo Pro (19 USD, एक बार का भुगतान) sanitizer check, -O0, -O2 और -O3 की तुलना और test report जोड़ता है, और हर टूल को आप 3 बार मुफ़्त चला सकते हैं।

VS Code में स्टेप्स

  1. Marketplace से Run C++ and C Code इंस्टॉल करें, या Ctrl+P (macOS पर Cmd+P) दबाकर ext install zovo.zovo-run-cpp चलाएँ।
  2. पक्का करें कि compiler इंस्टॉल है। "Run C++: Pick Compiler (gcc, g++, clang, clang++)" दिखाता है कि उसे कौन-से compiler मिले। अगर कोई नहीं मिला, तो एक setup पेज आपके सिस्टम के आधिकारिक स्टेप्स दिखाता है (Xcode Command Line Tools, MSYS2 या WinLibs, या आपका Linux package manager)।
  3. कोई .cpp, .cc, .cxx या .c फ़ाइल खोलें और editor title में Run बटन पर क्लिक करें, या Ctrl+Alt+Enter (Mac पर Cmd+Alt+Enter) दबाएँ।
  4. प्रोग्राम "Run: file.cpp" नाम के टर्मिनल में चलता है। उसका इनपुट वहीं टाइप करें। आख़िर में exit code, run time और peak memory दिखते हैं। प्रोग्राम चलते समय Run बटन Stop बन जाता है।
  5. Flags या arguments के लिए फ़ाइल की पहली 40 लाइनों में // run: -O2 -lm और // args: "Hello World" 3 लिखें। C++ के डिफ़ॉल्ट flags -std=c++20 -Wall -Wextra -g -O0 हैं।
  6. सेव किए इनपुट से टेस्ट करने के लिए "Run C++: Run with Input & Test Cases" चलाएँ। इनपुट पेस्ट करें, Run with input दबाएँ, फिर Save as test case। Run all tests हर टेस्ट का pass या fail लाइन diff के साथ दिखाता है।

क्या मुफ़्त है और Zovo Pro क्या जोड़ता है

Run, Build Only, Run Last Build, Debug, फ़ोल्डर builds, Input & Tests पैनल, stress test और benchmark मुफ़्त हैं। इसके लिए sign-in नहीं चाहिए, यह कोई नेटवर्क कॉल नहीं करता और इसमें telemetry नहीं है।

जो प्रोग्राम आपके टेस्ट पास कर लेता है, वह भी array के आख़िर से आगे पढ़ सकता है या int को overflow कर सकता है। Sanitizer check AddressSanitizer और UndefinedBehaviorSanitizer (-fsanitize=address,undefined) के साथ प्रोग्राम की एक दूसरी कॉपी build करता है, उसे पैनल के इनपुट और हर सेव किए test case पर चलाता है, और हर heap या stack overflow, use after free, signed overflow या दूसरे undefined behavior को उसकी लाइन पर Problems पैनल में दिखाता है। Sanitizer flags हाथ से सेट किए बिना आपको bug उसकी लाइन पर मिल जाता है।

Sanitizer check का इस्तेमाल (Zovo Pro)

  1. Input & Tests पैनल में इनपुट डालें, और अगर test cases हैं तो उन्हें सेव करें। Check पैनल के इनपुट और हर सेव किए test case पर चलता है।
  2. पैनल में "Stress test, benchmark and more" के नीचे "Sanitizer check (Pro)" पर क्लिक करें, या Command Palette से "Run C++: Sanitizer Check: AddressSanitizer and UBSan on the Input and Test Cases (Zovo Pro)" चलाएँ।
  3. Problems पैनल में किसी finding पर क्लिक करके उसकी लाइन पर जाएँ। Build error, Stop या Cancel से कोई मुफ़्त ट्रायल ख़र्च नहीं होता।

Sanitizer check आपके कंप्यूटर पर 3 बार मुफ़्त चलता है, उसके बाद लाइसेंस माँगता है। न कोई पॉप-अप आता है, न कोई काउंटडाउन चलता है।

Cursor, Windsurf या VSCodium में स्टेप्स

  1. Ctrl+Shift+X (macOS पर Cmd+Shift+X) से Extensions व्यू खोलें।
  2. zovo.zovo-run-cpp खोजें और Install पर क्लिक करें। Cursor, Windsurf और VSCodium एक्सटेंशन Open VSX से इंस्टॉल करते हैं, जहाँ इस एक्सटेंशन का नाम zovo/zovo-run-cpp है।
  3. अगर आपके एडिटर में एक्सटेंशन गैलरी नहीं है, तो Open VSX पेज से .vsix फ़ाइल डाउनलोड करें और "Extensions: Install from VSIX..." चलाएँ।
  4. इसके बाद सब कुछ VS Code की तरह ही काम करता है।

Run C++ and C Code क्या करता है

  • C और C++ फ़ाइलें (.c, .cpp, .cc, .cxx), gcc, g++, clang और clang++ के साथ।
  • Windows के सामान्य फ़ोल्डरों में MSYS2, WinLibs, MinGW, TDM-GCC और LLVM, और g++-14 जैसे Homebrew नाम।
  • Spaces, & या non-ASCII अक्षरों वाले paths, क्योंकि उन्हें कोई shell parse नहीं करता।
  • एक मिलियन लाइनें प्रिंट करने वाले प्रोग्राम। पैनल पहली 2,000 लाइनें दिखाता है और बाकी गिनता है।

यह क्या नहीं करता

  • इसके लिए आपके कंप्यूटर पर compiler चाहिए, और यह कभी compiler डाउनलोड नहीं करता।
  • Input पैनल और test cases वाले रन 10 सेकंड बाद रुक जाते हैं (सेटिंग zovoRun.timeLimitSeconds)।
  • 32 MB से ज़्यादा आउटपुट गिना जाता है, रखा नहीं जाता (सेटिंग zovoRun.maxCapturedOutputMB)।
  • Sanitizer check के लिए sanitizer runtime वाला compiler चाहिए। Windows पर MinGW gcc में यह नहीं होता, इसलिए वहाँ LLVM का clang इस्तेमाल करें। Check यह बात बता देता है और कोई ट्रायल ख़र्च नहीं होता।
  • Debug के लिए CodeLLDB या C/C++ एक्सटेंशन इंस्टॉल होना चाहिए।

अक्सर पूछे जाने वाले सवाल

क्या यह मुफ़्त है?

Run, Build Only, Debug, फ़ोल्डर builds, Input & Tests पैनल, stress test और benchmark मुफ़्त हैं। तीन Pro टूल, Sanitizer check, Compare -O0, -O2 and -O3 और Test report, हर एक 3 बार मुफ़्त चलते हैं। उसके बाद इनके लिए Zovo Pro चाहिए, जो सभी Zovo एक्सटेंशन के लिए एक बार 19 USD का है।

क्या मेरा प्रोग्राम cin से इनपुट पढ़ सकता है?

हाँ। प्रोग्राम असली टर्मिनल में चलता है, इसलिए cin और scanf आपके टाइप किए इनपुट का इंतज़ार करते हैं, और newline के बिना वाले prompts पहले दिख जाते हैं।

क्या यह मेरी settings.json या tasks.json बदलता है?

नहीं। यह आपकी settings फ़ाइलों में कभी नहीं लिखता। Debug .vscode/launch.json में एक entry जोड़ता है, और वह भी सिर्फ़ तब जब आप Debug दबाएँ।

क्या यह Cursor में चलता है?

हाँ। एक्सटेंशन Open VSX पर है, इसलिए Cursor, Windsurf और VSCodium इसे इंस्टॉल कर सकते हैं।
