VS Code में AWS S3, Cloudflare R2 या MinIO buckets browse करें

मुफ़्त S3 Explorer इंस्टॉल करें और Activity Bar में उसका S3 Buckets view खोलें। यह AWS S3 (~/.aws की profiles, SSO profiles भी), Cloudflare R2, MinIO, Backblaze B2, Wasabi और DigitalOcean Spaces के साथ काम करता है। Browse करना, objects को read-only खोलना, upload, download, copy, move, rename, delete, versions, tags, presigned URLs और folder sync मुफ़्त हैं, बिना sign-in और बिना telemetry के। Zovo Pro (19 USD, एक बार) तीन टूल जोड़ता है, Copy to Another Connection, Size and Cost Report और Scheduled Sync, और हर टूल 3 बार मुफ़्त चलता है।

VS Code में स्टेप्स

  1. Marketplace से S3 Explorer इंस्टॉल करें, या Ctrl+P (macOS पर Cmd+P) दबाकर ext install zovo.zovo-s3-explorer चलाएँ।
  2. Activity Bar में S3 Explorer view खोलें और Add Connection पर क्लिक करें। ~/.aws से कोई AWS profile चुनें, या access key, R2 account ID और token, या MinIO या किसी दूसरी S3-compatible service का endpoint URL टाइप करें। आपकी टाइप की हुई keys OS keychain में जाती हैं।
  3. Buckets देखने के लिए connection को expand करें। Keys एक बार में 1,000 लोड होती हैं, और नीचे "Load 1,000 more" row आती है। अगर आपकी key buckets की list नहीं देख सकती, तो connection पर राइट-क्लिक करके Add Bucket by Name चुनें।
  4. किसी object को टैब में या उससे मेल खाते viewer में read-only खोलने के लिए उस पर क्लिक करें। उसका metadata, tags, versions और presigned URL देखने के लिए उस पर राइट-क्लिक करके Show Details, Versions and Presigned URL चुनें।
  5. किसी object को बदलने के लिए उस पर राइट-क्लिक करके Edit and Upload चुनें। आप एक copy edit करते हैं, और object replace होने से पहले एक dialog bucket, key और दोनों sizes दिखाता है।
  6. Upload करने के लिए Explorer से फ़ाइलें या फ़ोल्डर किसी bucket पर drag करें, या राइट-क्लिक करके Download चुनें। 16 MB या उससे बड़ी फ़ाइलें progress और Cancel के साथ हिस्सों में upload होती हैं, और रुका हुआ upload सिर्फ़ बचे हुए हिस्सों के साथ resume होता है।
  7. किसी local फ़ोल्डर और prefix को एक जैसा रखने के लिए bucket या फ़ोल्डर पर राइट-क्लिक करके Sync Folder चुनें। कुछ भी बदलने से पहले आपको एक dry-run plan (new, changed, to delete) दिखता है।

क्या मुफ़्त है और Zovo Pro क्या जोड़ता है

Browse करना, खोलना, Edit and Upload, upload, download, copy, move, rename, delete, versions, tags, presigned URLs और folder sync मुफ़्त हैं, बिना sign-in, बिना account और बिना telemetry के। यह सिर्फ़ उन storage endpoints से जुड़ता है जिन्हें आप जोड़ते हैं।

Copy to Another Connection objects या पूरे फ़ोल्डरों को एक connection से दूसरे में कॉपी करता है, जैसे AWS S3 से Cloudflare R2 या MinIO में, उसी पुष्टि के साथ जो हर copy में होती है: keys की list दिखती है, और जो keys replace होंगी उनके नाम बताए जाते हैं। बड़े objects multipart upload से जाते हैं। आप script या दूसरे tool के बिना, tree से ही providers या accounts के बीच data ले जाते हैं।

Copy to Another Connection का इस्तेमाल (Zovo Pro)

  1. पहले दूसरा connection जोड़ें। फिर S3 Buckets view में किसी object या फ़ोल्डर पर राइट-क्लिक करके "Copy to Another Connection... (Pro)" चुनें, या view के आख़िर में "Zovo Pro tools" row में Copy to Another Connection पर क्लिक करें।
  2. Target connection, bucket और destination फ़ोल्डर चुनें (top level के लिए खाली छोड़ें)।
  3. पुष्टि वाली list में objects पढ़ें और Copy पर क्लिक करें, या जब कुछ keys पहले से मौजूद हों तो Copy and Replace पर। एक notification में progress दिखता है।
  4. Try तभी गिना जाता है जब objects कॉपी हुए हों। किसी चुनाव पर Escape, या दूसरे connection का न होना, कोई try नहीं लेता।

Copy to Another Connection आपके कंप्यूटर पर 3 बार मुफ़्त चलता है, उसके बाद लाइसेंस माँगता है। न कोई पॉप-अप आता है, न कोई काउंटडाउन चलता है।

S3 Explorer क्या करता है

  • Access keys, credential_process, source_profile वाले roles, और aws sso login के बाद SSO profiles वाली AWS profiles। Profile में दिया endpoint_url माना जाता है।
  • Endpoint URL, region, और path-style या virtual-hosted URLs के साथ MinIO और दूसरी S3-compatible services, और self-signed certificate स्वीकार करने का option।
  • Metadata, content type, storage class, ETag, tags (edit और save), versions (open, download, restore) और 15 मिनट से 7 दिन तक के presigned GET या PUT URLs।
  • लाखों keys वाले buckets, एक बार में 1,000, prefix से find और filter के साथ।
  • Downloads फ़ोल्डर structure बनाए रखते हैं और आपके चुने फ़ोल्डर के बाहर कभी नहीं लिखते: .. segments, drive letters या NUL bytes वाली keys skip होती हैं और list की जाती हैं।

यह क्या नहीं करता

  • यह AWS default profile या AWS_PROFILE का अपने आप कभी इस्तेमाल नहीं करता। Connect करने के लिए profile आप चुनते हैं।
  • 10 MB से बड़े text objects पहले पूछते हैं, फिर पहला 1 MB दिखाते हैं। 200 MB से बड़े binary objects download से पहले पूछते हैं।
  • खोले गए objects read-only होते हैं। सिर्फ़ Edit and Upload पुष्टि के बाद bucket में लिखता है।
  • Scheduled Sync सिर्फ़ VS Code खुला रहने पर चलता है, हर 5 से 60 मिनट में, और कभी delete नहीं करता।
  • जिन requests का जवाब नहीं आता, वे 30 सेकंड बाद रुक जाती हैं (सेटिंग s3Explorer.requestTimeoutSeconds)।

अक्सर पूछे जाने वाले सवाल

क्या यह मुफ़्त है?

Browse करना, खोलना, upload, download, copy, move, rename, delete, versions, tags, presigned URLs और folder sync मुफ़्त हैं। तीनों Pro टूल, Copy to Another Connection, Size and Cost Report और Scheduled Sync, 3-3 बार मुफ़्त चलते हैं। उसके बाद इनके लिए Zovo Pro चाहिए, जो सभी Zovo एक्सटेंशन के लिए एक बार 19 USD का है।

मेरी keys कहाँ रखी जाती हैं?

आपकी टाइप की हुई keys VS Code SecretStorage के ज़रिए OS keychain में जाती हैं, settings फ़ाइलों में कभी नहीं। AWS profiles ~/.aws से सिर्फ़ तब पढ़ी जाती हैं जब आप कोई profile चुनते हैं।

क्या यह Cloudflare R2 और MinIO के साथ काम करता है?

हाँ। R2 के लिए आपका account ID और R2 API token की access key चाहिए। MinIO और दूसरी S3-compatible services के लिए endpoint URL, region और path-style या virtual-hosted URLs चाहिए।

क्या यह Cursor में चलता है?

हाँ। Cursor, Windsurf और VSCodium इसे Open VSX से इंस्टॉल करते हैं, जहाँ यह zovo/zovo-s3-explorer नाम से है।
