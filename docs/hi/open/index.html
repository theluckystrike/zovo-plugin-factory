हिन्दी में गाइड

VS Code और उस पर बने एडिटर (Cursor, Windsurf, VSCodium) टेक्स्ट, इमेज और कुछ मीडिया फ़ाइलें खोल लेते हैं। कई दूसरे फ़ॉर्मैट के लिए एक्सटेंशन चाहिए। हर गाइड में स्टेप्स दिए गए हैं और बताया गया है कि क्या मुफ़्त है।

  • NumPy की .npy और .npz फ़ाइलें VS Code में देखें. मुफ़्त Tensor Viewer से VS Code में NumPy की .npy और .npz फ़ाइलें खोलें। dtype, shape, stats, heatmap, इमेज और values, बिना Python के।
  • VS Code में चलने वाला मुफ़्त NetCDF viewer. Windows, macOS या Linux पर VS Code में .nc NetCDF फ़ाइलें खोलें। header, variables, coastlines वाले map और time series। HDF5 .h5 और MATLAB 7.3 .mat भी।
  • VS Code में SQLite database खोलें. मुफ़्त SQLite Viewer & Editor से VS Code में .db या .sqlite फ़ाइल खोलें। tables, schema और SQL देखें, फिर cells और rows बदलें और backup के साथ सेव करें।
  • VS Code में Mermaid diagrams का preview देखें. मुफ़्त Mermaid Viewer से VS Code में .mmd फ़ाइलों और Markdown blocks के Mermaid diagrams देखें। Live preview, PNG और SVG export, offline, बिना sign-in।
  • VS Code में MOV, MKV, WebM और MP4 वीडियो आवाज़ के साथ चलाएँ. AAC आवाज़ वाली MP4, MOV और M4V फ़ाइलें VS Code में बिना कुछ और इंस्टॉल किए चलाएँ। MKV, WebM और AVI आपके अपने ffmpeg से चलते हैं। subtitles वाला मुफ़्त player।
  • VS Code में STL फ़ाइलें देखें. मुफ़्त 3D Model Viewer से VS Code में STL फ़ाइलें खोलें। orbit, दो points के बीच दूरी, wireframe और model stats। यह OBJ, PLY, 3MF, GLB और glTF भी खोलता है।
  • VS Code में PCAP फ़ाइल खोलें. मुफ़्त PCAP Viewer से VS Code में .pcap, .pcapng और .pcap.gz कैप्चर पढ़ें: पैकेट लिस्ट, प्रोटोकॉल ट्री, hex पैनल और फ़िल्टर। Wireshark की ज़रूरत नहीं।
  • VS Code में HTML, JSX और Vue टैग का नाम अपने-आप बदलें. HTML, JSX या Vue टैग का नाम बदलें, मैचिंग टैग टाइप करते ही बदल जाता है। VS Code की linked editing पर बना मुफ़्त एक्सटेंशन, auto close और एक undo के साथ।
  • Claude Code हिस्ट्री VS Code में पढ़ें और वहीं से resume करें. पुराने Claude Code और Codex सेशन VS Code में पढ़ें, खोजें और resume करें। Subagents nested, एडिट diff के रूप में, token totals। Read-only और ऑफ़लाइन।
  • क्वालिटी खोए बिना TIFF को PNG में बदलें. VS Code में TIFF, BigTIFF और GeoTIFF फ़ाइलें मुफ़्त खोलें, फिर एक पेज या हर पेज PNG में सेव करें, 8 और 16-bit वैल्यू बिल्कुल वैसी ही रहती हैं। ऑफ़लाइन।
  • XMind के बिना XMind को PDF में बदलें: हर शीट एक ही PDF में. XMind के बिना VS Code में .xmind माइंड मैप खोलें और हर शीट एक PDF में सेव करें, हर शीट का एक पेज। देखना मुफ़्त है, PDF एक Zovo Pro टूल है।
  • VS Code में फ़ॉन्ट फ़ाइल का प्रीव्यू देखें. मुफ़्त Font Viewer से VS Code में .ttf, .otf, .woff, .woff2 और .ttc फ़ॉन्ट खोलें: अपना टेक्स्ट आज़माएँ, हर glyph देखें और लाइसेंस पढ़ें, इंस्टॉल किए बिना।
  • VS Code में WAV, MP3, FLAC, Ogg और Opus फ़ाइलें waveform के साथ सुनें. मुफ़्त Audio Player से VS Code में WAV, MP3, FLAC, Ogg और Opus फ़ाइलें चलाएँ। Waveform, spectrogram, A-B loop, स्पीड और LUFS loudness साथ में।
  • VS Code में DXF ड्रॉइंग देखें. मुफ़्त DXF Viewer से VS Code में .dxf ड्रॉइंग देखें। ASCII और binary DXF, लेयर, paper space शीट, टेक्स्ट खोज, माप और PNG या SVG एक्सपोर्ट।
  • ZIP के अंदर की फ़ाइल बिना extract किए VS Code में खोलें. VS Code में ZIP, JAR, TAR या TAR.GZ ब्राउज़ करें और उसकी कोई फ़ाइल read-only टैब में खोलें, डिस्क पर कुछ भी unpack किए बिना। मुफ़्त और ऑफ़लाइन।
  • ELF, PE और Mach-O बाइनरी फ़ाइलें VS Code में खोलें. मुफ़्त ELF Viewer & PE Viewer से VS Code में .so, .exe, .dll और .dylib फ़ाइलें खोलें। Headers, sections, imports, exports, symbols और hex, read-only।
  • VS Code में Graphviz DOT ग्राफ का लाइव प्रीव्यू. VS Code में .dot और .gv फ़ाइलों का प्रीव्यू टाइप करते ही एडिटर के बगल में देखें, Graphviz साथ में है। छह layout engines, क्लिक से लाइन पर, SVG और PNG एक्सपोर्ट।
  • VS Code में C और C++ कोड एक क्लिक में चलाएँ. VS Code में खुली .cpp या .c फ़ाइल एक क्लिक में compile करके चलाएँ, आपके अपने gcc, g++ या clang से। इनपुट टर्मिनल में, errors Problems में, test cases भी।
  • VS Code में JAR खोलें और डिकंपाइल किया गया Java source पढ़ें. VS Code में .jar, .war, .ear, .aar और .class फ़ाइलें खोलें: packages, MANIFEST.MF, bytecode और CFR से डिकंपाइल किया Java source। मुफ़्त और read-only।
  • VS Code में PDF, Word, PowerPoint या Excel फ़ाइल को Markdown में कैसे बदलें. VS Code में PDF, DOCX, PPTX, XLSX, CSV, HTML या EPUB फ़ाइल पर राइट-क्लिक करें और उसके बगल में Markdown पाएँ। मुफ़्त, offline, बिना Python और बिना upload।
  • VS Code में XML फ़ॉर्मैट करें और उस पर XPath चलाएँ. VS Code में XML फ़ॉर्मैट या minify करें, सिर्फ़ tags के बीच का whitespace बदलता है। फ़ाइल के namespaces के साथ XPath 1.0 चलाएँ और cursor का XPath कॉपी करें।
  • VS Code में code के image path की image gutter और hover में देखें. VS Code में JS, CSS, HTML और Markdown के image paths के लिए gutter में thumbnail, और hover पर image, उसका pixel size और file size देखें। मुफ़्त।
  • VS Code में secrets दिखाए बिना .env फ़ाइल कैसे edit करें. VS Code में .env फ़ाइलों को रंग दें, secret values को cursor के उनकी लाइन पर आने तक बिंदुओं में छिपाएँ, duplicate keys व गलत quotes ठीक करें। मुफ़्त, offline।
  • VS Code में bash या zsh script फ़ॉर्मैट करें. VS Code में bash, sh, zsh, bats और mksh scripts को Shift+Alt+F या save पर फ़ॉर्मैट करें। shfmt 3.14.1 शामिल है, .editorconfig पढ़ता है और offline चलता है।
  • VS Code में AWS S3, Cloudflare R2 या MinIO buckets browse करें. VS Code में S3, R2, MinIO, B2 और Wasabi buckets browse करें: objects read-only खोलें, resume के साथ upload-download करें, dry-run plan देखकर फ़ोल्डर sync करें।
  • VS Code में highlighting, formatting और go to definition के साथ .proto फ़ाइलें edit करें. VS Code में .proto फ़ाइलें highlight, format और check करें: comments रखने वाला formatter, go to definition, protoc-style errors। मुफ़्त, offline, बिना protoc।
  • VS Code में nginx config फ़ाइल फ़ॉर्मैट और check करें. VS Code में nginx.conf को valid फ़ाइल तोड़े बिना फ़ॉर्मैट करें, टाइप करते ही छूटा ; या गलत जगह का directive देखें, और लगभग 300 directives पर hover मदद पाएँ।
  • VS Code में टाइप करते समय PlantUML diagram का preview देखें. VS Code में .puml फ़ाइलों और Markdown के plantuml blocks का live PlantUML preview, आपके कंप्यूटर पर bundled jar से बना। Java 11 चाहिए, Graphviz नहीं।

और गाइड अंग्रेज़ी में उपलब्ध हैं।
