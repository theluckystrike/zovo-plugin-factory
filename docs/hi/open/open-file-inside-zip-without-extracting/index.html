ZIP के अंदर की फ़ाइल बिना extract किए VS Code में खोलें

मुफ़्त ZIP Viewer & Archive Explorer इंस्टॉल करें और किसी .zip, .jar, .vsix, .tar, .tar.gz या .gz फ़ाइल पर क्लिक करें। यह अंदर के फ़ोल्डर और फ़ाइलें दिखाता है, और double-click करने पर फ़ाइल एक सामान्य read-only टैब में खुलती है। फ़ाइल सीधे archive से पढ़ी जाती है, इसलिए कुछ भी unpack नहीं होता। Archive ब्राउज़ करना, entries खोलना, नाम से खोज और extraction मुफ़्त हैं। Zovo Pro (19 USD, एक बार का भुगतान) तीन टूल जोड़ता है, दो archives की तुलना, entry list का एक्सपोर्ट और किसी फ़ोल्डर के सभी archives में फ़ाइल खोजना, और हर टूल को आप 3 बार मुफ़्त चला सकते हैं।

VS Code में स्टेप्स

  1. Marketplace से ZIP Viewer & Archive Explorer इंस्टॉल करें, या Ctrl+P (macOS पर Cmd+P) दबाकर ext install zovo.zip-archive-explorer चलाएँ।
  2. Explorer में किसी .zip, .jar, .vsix, .tar, .tar.gz, .tgz या .gz फ़ाइल पर क्लिक करें। वह फ़ोल्डरों और फ़ाइलों की लिस्ट की तरह खुलती है, जिसमें साइज़, packed साइज़, ratio और तारीख होती है। .war, .whl, .nupkg, .apk या .epub के लिए राइट-क्लिक करके Open in Archive Explorer चुनें।
  3. फ़ाइल ढूँढें। किसी फ़ोल्डर पर double-click करें, ऊपर की path bar इस्तेमाल करें, या एक लेवल ऊपर जाने के लिए Backspace दबाएँ। या search box में टाइप करें। * और ? wildcard की तरह काम करते हैं, जैसे *.json।
  4. फ़ाइल पर double-click करें या Enter दबाएँ। वह एक सामान्य टैब में read-only खुलती है। कोड को syntax colors मिलते हैं, इमेज image preview में खुलती हैं, और ZIP के अंदर की ZIP एक और archive की तरह खुलती है।
  5. Explorer साइड बार का Archive Explorer सेक्शन हर वह archive दिखाता है जो आपने खोला। वहाँ किसी entry पर राइट-क्लिक करके Open to the Side, Extract... या Copy Path चुनें।
  6. फ़ाइल बदलनी हो तो उसे चुनें और Extract... पर क्लिक करें। एक फ़ाइल save dialog से सेव होती है। .. या absolute path वाले नाम कभी नहीं लिखे जाते, और archive खुद कभी नहीं बदलता।

क्या मुफ़्त है और Zovo Pro क्या जोड़ता है

Archives ब्राउज़ करना, entries को टैब में खोलना, नाम से खोज, साइड बार का ट्री, Copy Path और extraction मुफ़्त हैं। एक्सटेंशन ऑफ़लाइन काम करता है, न कोई नेटवर्क कॉल करता है, न telemetry भेजता है।

जब आपको फ़ाइल का नाम पता हो, पर यह नहीं कि वह किस build, backup या release archive में है, तो हर archive खोलने में बहुत समय लगता है। Find a file in all archives of a folder किसी फ़ोल्डर के अंदर की हर ZIP, JAR, WAR, VSIX, TAR और GZ फ़ाइल की entries के नामों में खोजता है, हर मैच को उसके archive और path के साथ दिखाता है, और जिसे आप चुनें उसे read-only टैब में खोलता है। यह कोई फ़ाइल नहीं लिखता।

Find a file in all archives of a folder का इस्तेमाल (Zovo Pro)

  1. Command Palette से "Archive Explorer: Find a File in All Archives of a Folder... (Pro)" चलाएँ और खोजने के लिए फ़ोल्डर चुनें, या Explorer में किसी फ़ोल्डर पर राइट-क्लिक करके "Zovo Pro: Find a file in all archives of a folder" चुनें।
  2. फ़ाइल का नाम टाइप करें। * और ? wildcard की तरह काम करते हैं, जैसे log4j*.jar या *.properties।
  3. लिस्ट से कोई मैच चुनें। वह किसी भी entry की तरह टैब में read-only खुलता है। मुफ़्त ट्रायल तभी गिना जाता है जब कम से कम एक मैच मिले।

Find a file in all archives of a folder आपके कंप्यूटर पर 3 बार मुफ़्त चलता है, उसके बाद लाइसेंस माँगता है। न कोई पॉप-अप आता है, न कोई काउंटडाउन चलता है।

Cursor, Windsurf या VSCodium में स्टेप्स

  1. Ctrl+Shift+X (macOS पर Cmd+Shift+X) से Extensions व्यू खोलें।
  2. zovo.zip-archive-explorer खोजें और Install पर क्लिक करें। Cursor, Windsurf और VSCodium एक्सटेंशन Open VSX से इंस्टॉल करते हैं, जहाँ इस एक्सटेंशन का नाम zovo/zip-archive-explorer है।
  3. अगर आपके एडिटर में एक्सटेंशन गैलरी नहीं है, तो Open VSX पेज से .vsix फ़ाइल डाउनलोड करें और "Extensions: Install from VSIX..." चलाएँ।
  4. इसके बाद सब कुछ VS Code की तरह ही काम करता है।

ZIP Viewer & Archive Explorer क्या करता है

  • ZIP, JAR और VSIX, Stored और Deflate entries, ZIP64 और self-extracting archives के साथ।
  • TAR (ustar, GNU long names और pax headers), TAR.GZ, TGZ और अकेली GZ फ़ाइलें।
  • WAR, EAR, WHL, NUPKG, APK, AAR, XPI और EPUB, Open in Archive Explorer के ज़रिए।
  • 200,000 entries तक के archives, जो डिस्क से range reads से पढ़े जाते हैं, इसलिए बड़ी ZIP पूरी लोड नहीं होती।

यह क्या नहीं करता

  • BZIP2, LZMA, Zstandard या Deflate64 से compressed entries और encrypted entries लिस्ट में दिखती हैं, पर खुलती नहीं।
  • 7z, RAR, XZ और BZ2 फ़ाइलें सपोर्ट नहीं होतीं।
  • Entries read-only हैं। फ़ाइल बदलने के लिए उसे extract करें।
  • 512 MB से बड़ी entries टैब में नहीं खुलतीं, पर extract हो सकती हैं। .tar.gz मेमोरी में unpack होता है, डिफ़ॉल्ट रूप से 2 GB तक।

अक्सर पूछे जाने वाले सवाल

क्या यह मुफ़्त है?

Archives ब्राउज़ करना, entries खोलना, नाम से खोज, साइड बार का ट्री और extraction मुफ़्त हैं। तीन Pro टूल, Compare two archives, Export the entry list और Find a file in all archives of a folder, हर एक 3 बार मुफ़्त चलते हैं। उसके बाद इनके लिए Zovo Pro चाहिए, जो सभी Zovo एक्सटेंशन के लिए एक बार 19 USD का है।

फ़ाइल खोलते समय क्या वह किसी temp फ़ोल्डर में कॉपी होती है?

नहीं। Entry archive से सीधे read-only टैब में पढ़ी जाती है। सिर्फ़ Extract डिस्क पर फ़ाइलें लिखता है।

क्या ZIP के अंदर की फ़ाइल एडिट की जा सकती है?

नहीं। Entries read-only हैं और archive कभी नहीं बदलता। फ़ाइल extract करें, उसे एडिट करें, और किसी दूसरे टूल से archive फिर से बनाएँ।

क्या यह Cursor में चलता है?

हाँ। ZIP Viewer & Archive Explorer Open VSX पर है, इसलिए Cursor, Windsurf और VSCodium इसे इंस्टॉल कर सकते हैं।
