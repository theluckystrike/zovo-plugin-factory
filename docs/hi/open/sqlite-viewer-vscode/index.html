VS Code में SQLite database खोलें

मुफ़्त SQLite Viewer & Editor इंस्टॉल करें और .db, .sqlite या .sqlite3 फ़ाइल पर क्लिक करें। हर table एक grid के रूप में read-only खुलती है, और Schema और SQL टैब बस एक क्लिक दूर हैं। यह -wal फ़ाइल में अभी पड़ी committed rows भी पढ़ता है। देखना, Enable editing पर क्लिक करने के बाद editing, backup के साथ Save और CSV import मुफ़्त हैं। Zovo Pro (19 USD, एक बार का भुगतान) database compare, ER diagram और सभी tables को एक साथ export करने के टूल जोड़ता है, और हर टूल 3 बार मुफ़्त चलता है।

VS Code में स्टेप्स

  1. Marketplace से SQLite DB Viewer इंस्टॉल करें, या Ctrl+P (macOS पर Cmd+P) दबाकर ext install zovo.sqlite-table-viewer चलाएँ।
  2. Explorer में किसी .db, .sqlite, .sqlite3, .db3, .s3db, .sl3, .vscdb या .gpkg फ़ाइल पर क्लिक करें। यह एक टेबल के रूप में read-only खुलती है।
  3. बाईं ओर कोई table या view चुनें। sort करने के लिए column header पर क्लिक करें, filter के लिए header के नीचे टाइप करें (जैसे 5..9 या =word), या सभी columns में एक साथ खोजें।
  4. columns, keys, foreign keys और CREATE statements देखने के लिए Schema टैब खोलें, या एक बार में एक statement चलाने के लिए SQL टैब। आख़िरी 20 statements सेव रहते हैं।
  5. डेटा बदलने के लिए Enable editing पर क्लिक करें। किसी cell पर डबल-क्लिक करें, नई value टाइप करें और Enter दबाएँ। हर बदलाव अपने SQL और Undo के साथ एक pending list में रुका रहता है।
  6. Save दबाएँ (Ctrl+S, macOS पर Cmd+S)। Save constraints जाँचता है, name.db.20261109-143000.bak जैसी backup कॉपी बनाता है और फ़ाइल को एक ही स्टेप में बदल देता है।

क्या मुफ़्त है और Zovo Pro क्या जोड़ता है

फ़ाइल खोलना और पढ़ना, SQL टैब, cells और rows बदलना, backup के साथ Save, CSV और TSV import, table टूल और दिख रही rows का export मुफ़्त हैं। न कोई अकाउंट है, न कोई trial टाइमर।

यह टूल database की हर table एक ही बार में लिखता है, या तो एक Excel workbook (.xlsx) में, जिसमें हर table की एक sheet होती है और header row bold और frozen रहती है, या एक फ़ोल्डर में, जिसमें हर table की एक CSV फ़ाइल होती है। मुफ़्त Export सिर्फ़ एक table की दिख रही rows सेव करता है, इसलिए इस टूल से आपको tables एक-एक करके export नहीं करनी पड़तीं। यह database को सिर्फ़ पढ़ता है, उसमें कभी कुछ नहीं लिखता।

  1. database खुला रहने पर editor toolbar में DB tools बटन (उस पर छोटा PRO badge है) पर क्लिक करें, या toolbar के नीचे "Pro tools" row में इस टूल पर क्लिक करें।
  2. या Explorer में database फ़ाइल पर राइट-क्लिक करके "Zovo Pro: Export All Tables to Excel or CSV" चुनें, या Command Palette से "Export All SQLite Tables to Excel or CSV (Pro)…" चलाएँ।

Export All SQLite Tables to Excel or CSV आपके कंप्यूटर पर 3 बार मुफ़्त चलता है, उसके बाद लाइसेंस माँगता है। न कोई पॉप-अप आता है, न कोई काउंटडाउन चलता है।

Cursor, Windsurf या VSCodium में स्टेप्स

  1. Ctrl+Shift+X (macOS पर Cmd+Shift+X) से Extensions व्यू खोलें।
  2. zovo.sqlite-table-viewer खोजें और Install पर क्लिक करें। Cursor, Windsurf और VSCodium एक्सटेंशन Open VSX से इंस्टॉल करते हैं, जहाँ इस एक्सटेंशन का नाम zovo/sqlite-table-viewer है।
  3. अगर आपके एडिटर में एक्सटेंशन गैलरी नहीं है, तो Open VSX पेज से .vsix फ़ाइल डाउनलोड करें और "Extensions: Install from VSIX..." चलाएँ।
  4. इसके बाद सब कुछ VS Code की तरह ही काम करता है।

SQLite DB Viewer क्या करता है

  • -wal फ़ाइल में अभी भी पड़ी committed rows, और आपका app लिखते समय live reload (Live बटन इसे बंद करता है)।
  • cell पैनल में JSON cells tree के रूप में, इमेज तस्वीर के रूप में और float32 BLOBs vectors के रूप में।
  • CSV, TSV, JSON या INSERT statements के रूप में Copy, और दिख रही rows का CSV, JSON या SQL INSERT statements में Export।
  • नई या मौजूदा table में CSV और TSV import, preview, column mapping, progress bar और Cancel के साथ।
  • 512 MB तक के databases, जिनकी rows एक बार में एक पेज लाई जाती हैं।

यह क्या नहीं करता

  • पूरा database memory में लोड होता है। 512 MB से बड़ी फ़ाइलों पर एक मैसेज दिखता है (सेटिंग sqliteTableViewer.maxFileSizeMB)।
  • editing सिर्फ़ 256 MB तक की फ़ाइलों में होती है (सेटिंग sqliteTableViewer.editMaxFileSizeMB)। इससे बड़ी फ़ाइलें read-only रहती हैं।
  • Encrypted databases (SQLCipher, SEE) नहीं खुलते।
  • editing सिर्फ़ इसी कंप्यूटर पर रखी फ़ाइलों में होती है। remote या virtual file systems की फ़ाइलें read-only खुलती हैं।
  • टैब बंद करने पर बिना सेव किए बदलाव हट जाते हैं, और फ़ाइल पहले जैसी रहती है।

अक्सर पूछे जाने वाले सवाल

क्या यह मुफ़्त है?

फ़ाइल खोलना, देखना, SQL टैब, editing, Save और CSV import मुफ़्त हैं, और कोई अकाउंट नहीं चाहिए। तीनों Pro टूल (Compare SQLite Databases, ER Diagram और Export All Tables) 3-3 बार मुफ़्त चलते हैं। उसके बाद इनके लिए Zovo Pro चाहिए, जो सभी Zovo एक्सटेंशन के लिए एक बार 19 USD का है।

क्या VS Code में rows बदली जा सकती हैं?

हाँ। फ़ाइल read-only खुलती है। cells और rows बदलने या INSERT और UPDATE चलाने के लिए Enable editing पर क्लिक करें। जब तक आप Save नहीं दबाते, कुछ भी लिखा नहीं जाता, और Save पहले एक backup कॉपी बनाता है।

दूसरा viewer पुरानी rows क्यों दिखाता है?

WAL mode में नए commits -wal फ़ाइल में रहते हैं, जब तक checkpoint उन्हें main फ़ाइल में कॉपी न कर दे। जो viewer सिर्फ़ main फ़ाइल पढ़ता है, उसे ये rows नहीं दिखतीं। यह एक्सटेंशन -wal फ़ाइल का committed हिस्सा भी पढ़ता है।

क्या यह Cursor में चलता है?

हाँ। यह Open VSX पर zovo/sqlite-table-viewer नाम से है, इसलिए Cursor, Windsurf और VSCodium इसे इंस्टॉल कर सकते हैं।
