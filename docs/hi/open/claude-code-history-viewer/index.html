Claude Code हिस्ट्री VS Code में पढ़ें और वहीं से resume करें

Claude Code History & Codex History Viewer (Agent Session Viewer) इंस्टॉल करें। यह ~/.claude/projects से आपके Claude Code सेशन और ~/.codex/sessions से Codex सेशन एक ही साइड व्यू में दिखाता है, हर सेशन को पढ़ने लायक transcript की तरह खोलता है, और एक क्लिक में उसे terminal में resume करता है। पढ़ना, सर्च, resume और एक सेशन का Markdown एक्सपोर्ट मुफ़्त है, किसी अकाउंट के बिना। Zovo Pro (19 USD, एक बार का भुगतान) usage और cost रिपोर्ट, secrets छिपाकर share-safe एक्सपोर्ट और Markdown में bulk एक्सपोर्ट जोड़ता है, और हर Pro टूल 3 बार मुफ़्त चलता है।

VS Code में स्टेप्स

  1. Marketplace से Agent Session Viewer इंस्टॉल करें, या Ctrl+P (macOS पर Cmd+P) दबाकर ext install zovo.agent-session-viewer चलाएँ।
  2. Activity bar में Agent Sessions आइकन पर क्लिक करें। Sessions व्यू Claude Code और Codex सेशन को प्रोजेक्ट फ़ोल्डर के हिसाब से ग्रुप करके दिखाता है, और subagents उस सेशन के नीचे दिखते हैं जिसने उन्हें शुरू किया।
  3. पढ़ने के लिए किसी सेशन पर क्लिक करें। Tool calls collapsed रहते हैं, फ़ेल हुए calls पर लाल निशान होता है, और फ़ाइल एडिट diff के रूप में दिखते हैं। हेडर में model, git branch, turns और token totals दिखते हैं।
  4. पुराना सेशन ढूँढने के लिए व्यू के ऊपर सर्च आइकन पर क्लिक करें, या Command Palette से "Agent Sessions: Search Sessions" चलाएँ। कोई नतीजा चुनें, तो सेशन उसी मैच पर खुलता है।
  5. सेशन के बगल में terminal आइकन (Resume in Terminal) पर क्लिक करें। प्रोजेक्ट फ़ोल्डर में एक terminal खुलता है और claude --resume <id> या codex resume <id> चलाता है।
  6. किसी दूसरे फ़ोल्डर की .jsonl सेशन फ़ाइल के लिए उस पर राइट-क्लिक करें, Open With चुनें और Agent Session Viewer चुनें।

क्या मुफ़्त है और Zovo Pro क्या जोड़ता है

Sessions ट्री, सेशन पढ़ना, सभी सेशन में सर्च, Resume in Terminal, Copy Resume Command, एक सेशन का Markdown एक्सपोर्ट, raw व्यू और Reveal in File Manager मुफ़्त हैं। हिस्ट्री की कोई सीमा नहीं है और साइन-इन नहीं चाहिए।

Share-safe export एक सेशन को, या किसी प्रोजेक्ट के सभी सेशन को, एक self-contained HTML पेज या एक Markdown फ़ाइल के रूप में सेव करता है। API keys, tokens, URL में लिखे passwords, .env values, private keys, emails और आपका home फ़ोल्डर [REDACTED ...] से बदल दिए जाते हैं, और मैसेज बताता है कि क्या छिपाया गया। आप किसी pull request, audit या handover के लिए सेशन हाथ से साफ़ किए बिना भेज सकते हैं।

Share-safe export का इस्तेमाल (Zovo Pro)

  1. सेशन खोलें, फिर सेशन टूलबार में Share-safe export बटन पर क्लिक करें। या Sessions ट्री में किसी सेशन या प्रोजेक्ट फ़ोल्डर पर राइट-क्लिक करके "Share-Safe Export, Secrets Redacted (Pro)…" चुनें।
  2. सेशन खुला हो, तो आप Command Palette से "Agent Sessions: Share-Safe Export, Secrets Redacted (Pro)…" भी चला सकते हैं।
  3. फ़ॉर्मैट चुनें: HTML पेज या Markdown, tool outputs के साथ या उनके बिना। फिर फ़ाइल सेव करने की जगह चुनें।
  4. शेयर करने से पहले एक्सपोर्ट को पढ़ लें। ट्राई तभी गिना जाता है जब फ़ाइल सेव हो जाए, Escape या Cancel पर कुछ खर्च नहीं होता।

Share-safe export आपके कंप्यूटर पर 3 बार मुफ़्त चलता है, उसके बाद लाइसेंस माँगता है। न कोई पॉप-अप आता है, न कोई काउंटडाउन चलता है।

5 लोगों की टीम एक बार 59 USD देती है (कार्ड से)। सभी नियम और सारे Pro टूल Zovo Pro पेज पर हैं (अंग्रेज़ी में)।

Cursor, Windsurf या VSCodium में स्टेप्स

  1. Ctrl+Shift+X (macOS पर Cmd+Shift+X) से Extensions व्यू खोलें।
  2. zovo.agent-session-viewer खोजें और Install पर क्लिक करें। Cursor, Windsurf और VSCodium एक्सटेंशन Open VSX से इंस्टॉल करते हैं, जहाँ इस एक्सटेंशन का नाम zovo/agent-session-viewer है।
  3. अगर आपके एडिटर में एक्सटेंशन गैलरी नहीं है, तो Open VSX पेज से .vsix फ़ाइल डाउनलोड करें और "Extensions: Install from VSIX..." चलाएँ।
  4. इसके बाद सब कुछ VS Code की तरह ही काम करता है।

Agent Session Viewer क्या करता है

  • ~/.claude/projects (या $CLAUDE_CONFIG_DIR/projects) में Claude Code सेशन और ~/.codex/sessions (या $CODEX_HOME/sessions) में Codex सेशन।
  • दोनों टूल के subagents, उस सेशन के नीचे nested जिसने उन्हें शुरू किया।
  • हेडर में tool, model, प्रोजेक्ट फ़ोल्डर, git branch, अवधि, turns की गिनती, token totals, और cost अगर फ़ाइल में दर्ज हो (Claude Code इसे लिखता है, Codex नहीं)।
  • फ़ाइल एडिट diff के रूप में (Edit, Write और apply_patch), और thinking और Codex reasoning summaries collapsed रूप में।
  • session_index.jsonl से Codex thread के नाम, ताकि rename किए गए threads के नाम बने रहें।

यह क्या नहीं करता

  • यह सिर्फ़ Claude Code और Codex पढ़ता है। Cursor, Copilot और Gemini CLI सेशन अभी सपोर्टेड नहीं हैं।
  • यह read-only है। यह सेशन फ़ाइलों को कभी नहीं बदलता, न दूसरी जगह ले जाता है, न डिलीट करता है, और इसमें कोई delete कमांड नहीं है।
  • सर्च सादा टेक्स्ट मिलाती है, regular expressions नहीं, और 300 नतीजों पर रुक जाती है।
  • Resume in Terminal के लिए Claude Code या Codex इंस्टॉल होना चाहिए और terminal के PATH में होना चाहिए।
  • डिफ़ॉल्ट रूप से फ़ाइलें 256 MB तक पढ़ी जाती हैं (agentSessionViewer.maxFileSizeMB), बड़ी फ़ाइलों का सिर्फ़ पहला हिस्सा खुलता है। Encrypted रूप में सेव की गई Codex reasoning नहीं दिखाई जा सकती।

अक्सर पूछे जाने वाले सवाल

Claude Code चैट हिस्ट्री कहाँ सेव करता है?

~/.claude/projects में, हर प्रोजेक्ट के लिए एक फ़ोल्डर और हर सेशन के लिए एक .jsonl फ़ाइल। अगर CLAUDE_CONFIG_DIR सेट है, तो हिस्ट्री उस फ़ोल्डर के अंदर होती है।

क्या यह मुफ़्त है?

हाँ। पढ़ना, सर्च, resume और एक सेशन का Markdown एक्सपोर्ट मुफ़्त है, और हिस्ट्री की कोई सीमा नहीं है। तीनों Pro टूल (usage और cost रिपोर्ट, share-safe export, bulk export) 3 बार मुफ़्त चलते हैं, उसके बाद Zovo Pro सभी Zovo एक्सटेंशन के लिए एक बार 19 USD का है।

क्या व्यूअर से पुराने सेशन डिलीट कर सकते हैं?

नहीं। यह सिर्फ़ आपकी सेशन फ़ाइलें पढ़ता है और उन्हें कभी नहीं बदलता, न दूसरी जगह ले जाता है, न डिलीट करता है।

क्या इसे Anthropic ने बनाया है?

नहीं। इसे Anthropic या OpenAI ने नहीं बनाया है और इसका उनसे कोई संबंध नहीं है। यह कोई नेटवर्क कॉल नहीं करता और इसमें telemetry नहीं है।
