मुफ़्त extension HTML Formatter & CSS Formatter install करें और किसी HTML, CSS, SCSS या LESS फ़ाइल में Shift+Alt+F दबाएँ। यह page के अंदर के <style> और <script> blocks भी format करता है, आपकी .editorconfig follow करता है, <pre>, <textarea> और inline tags को वैसे ही रखता है जैसे आपने लिखे थे, और attributes का order कभी नहीं बदलता। यह extension के अंदर bundled js-beautify से offline चलता है, इसलिए Node, npm या config file की ज़रूरत नहीं। Zovo Pro (एक बार USD 19) तीन tools जोड़ता है, Format Folder with Diff Preview, Minify HTML and CSS और HTML Lint Report, और हर tool को 3 बार मुफ़्त आज़माया जा सकता है।

VS Code में स्टेप्स

  1. Marketplace से HTML Formatter & CSS Formatter इंस्टॉल करें, या Ctrl+P (macOS पर Cmd+P) दबाकर ext install zovo.zovo-html-formatter चलाएँ।
  2. कोई HTML, CSS, SCSS या LESS फ़ाइल खोलें और Shift+Alt+F दबाएँ (macOS पर Shift+Option+F)। अगर VS Code पूछे कि कौन-सा formatter इस्तेमाल करना है, तो HTML Formatter & CSS Formatter चुनें।
  3. इसे एक ही step में चारों languages का default formatter बनाने के लिए Command Palette से "HTML Formatter: Use as Default Formatter for HTML, CSS, SCSS and LESS" चलाएँ।
  4. कुछ lines select करें और Format Selection चलाएँ, तो सिर्फ़ वही lines format होंगी।
  5. हर save पर format करने के लिए zovoHtmlFormat.formatOnSave चालू करें, या default formatter बन जाने के बाद VS Code की अपनी editor.formatOnSave setting इस्तेमाल करें।
  6. Indentation पहले editor से आती है, फिर .editorconfig से (indent style और size, end of line, final newline, max line length), इसलिए पूरी team को एक जैसा result मिलता है।

क्या मुफ़्त है और Zovo Pro क्या जोड़ता है

HTML, CSS, SCSS और LESS के लिए Format Document, Format Selection और format on save, .editorconfig support के साथ, मुफ़्त हैं। Sign-in की ज़रूरत नहीं, कोई network request नहीं और कोई telemetry नहीं।

जब पूरी site को एक ही style में लाना हो, तब Format Folder with Diff Preview किसी folder की हर HTML, CSS, SCSS और LESS फ़ाइल को memory में format करता है, बदली हुई फ़ाइलें हर फ़ाइल के side-by-side diff के साथ दिखाता है, और सिर्फ़ वही फ़ाइलें लिखता है जिन्हें आप checked रखते हैं। कोई फ़ाइल लिखे जाने से पहले आप हर बदलाव देख लेते हैं।

Format Folder with Diff Preview का इस्तेमाल (Zovo Pro)

  1. Explorer में किसी folder पर right-click करें और "Zovo Pro: Format folder with diff preview" चुनें, या Command Palette से "HTML Formatter: Format Folder with Diff Preview (Pro)" चलाएँ।
  2. बदली हुई फ़ाइलें देखें। किसी भी फ़ाइल का diff खोलें और जिन फ़ाइलों को वैसे ही छोड़ना है, उन्हें uncheck करें।
  3. Checked फ़ाइलें लिखें। Try तभी गिनी जाती है जब tool आपको result देता है।

Format Folder with Diff Preview आपके कंप्यूटर पर 3 बार मुफ़्त चलता है, उसके बाद लाइसेंस माँगता है। न कोई पॉप-अप आता है, न कोई काउंटडाउन चलता है।

Cursor, Windsurf या VSCodium में स्टेप्स

  1. Ctrl+Shift+X (macOS पर Cmd+Shift+X) से Extensions व्यू खोलें।
  2. zovo.zovo-html-formatter खोजें और Install पर क्लिक करें। Cursor, Windsurf और VSCodium एक्सटेंशन Open VSX से इंस्टॉल करते हैं, जहाँ इस एक्सटेंशन का नाम zovo/zovo-html-formatter है।
  3. अगर आपके एडिटर में एक्सटेंशन गैलरी नहीं है, तो Open VSX पेज से .vsix फ़ाइल डाउनलोड करें और "Extensions: Install from VSIX..." चलाएँ।
  4. इसके बाद सब कुछ VS Code की तरह ही काम करता है।

HTML Formatter & CSS Formatter क्या करता है

  • HTML के अंदर <style> की CSS और <script> की JavaScript।
  • जैसे लिखे गए वैसे ही रहते हैं: <pre> और <textarea> का content, अपनी line पर inline tags, attribute order, blocks के बीच blank lines (लगातार ज़्यादा से ज़्यादा एक), page की head और body indentation style, और {{ }} व {% %} जैसे template tags।
  • SCSS और LESS में multi-line maps और function calls का layout बना रहता है, और line के आख़िर वाले comments उसी line पर रहते हैं।
  • बाकी दो Pro tools। Minify HTML and CSS .min.html और .min.css copies लिखता है, बचाए गए bytes और gzip bytes की report के साथ। HTML Lint Report बिना alt text वाली images, बिना label वाले form fields, duplicate ids, छूटे हुए heading levels और दूसरी problems ढूँढता है, Markdown report में और Problems panel में।

यह क्या नहीं करता

  • अलग से रखी .js, .jsx, .ts, Vue और Svelte फ़ाइलें यह extension format नहीं करता। सिर्फ़ <script> के अंदर की JavaScript format होती है।
  • जब तक आप wrap length set नहीं करते, lines wrap नहीं होतीं, इसलिए बहुत लंबी line लंबी ही रहती है।
  • SCSS और LESS CSS formatter से होकर जाते हैं। LESS detached rulesets जैसा असामान्य syntax अपनी original spacing रख सकता है।
  • Minify JavaScript को छोटा नहीं करता और CSS rules को rename या merge नहीं करता।

अक्सर पूछे जाने वाले सवाल

क्या यह मुफ़्त है?

HTML, CSS, SCSS और LESS के लिए Format Document, Format Selection और format on save मुफ़्त हैं। तीनों Pro tools, Format Folder with Diff Preview, Minify HTML and CSS और HTML Lint Report, हर एक में 3 free tries हैं। उसके बाद Zovo Pro चाहिए, सभी Zovo extensions के लिए एक बार USD 19।

क्या VS Code बिना extension के HTML format करता है?

हाँ। VS Code में built-in HTML और CSS formatter है। यह extension .editorconfig पढ़ता है, page की अपनी head और body indentation रखता है, SCSS और LESS maps का layout बनाए रखता है, और folder, minify और lint वाले Pro tools जोड़ता है।

क्या यह मेरे pre blocks बदलेगा या attributes का order बदलेगा?

नहीं। pre और textarea का content, inline tags और attribute order वैसे ही रहते हैं जैसे आपने लिखे थे।

क्या Node या npm चाहिए?

नहीं। js-beautify 1.15.4 extension में bundled है और offline चलता है।
