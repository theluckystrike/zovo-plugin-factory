VS Code में चलने वाला मुफ़्त NetCDF viewer

VS Code में मुफ़्त NetCDF Viewer & HDF5 Viewer एक्सटेंशन इंस्टॉल करें और किसी .nc फ़ाइल पर क्लिक करें। आपको header, variables का tree, coastlines वाला map, एक time slider और map पर क्लिक किए गए किसी भी point की time series मिलती है, बिना Python, NCL या किसी और setup के। यही viewer HDF5 .h5 फ़ाइलें और MATLAB 7.3 .mat फ़ाइलें भी खोलता है, और यह सब मुफ़्त है। Zovo Pro (19 USD, एक बार का भुगतान) दो टूल जोड़ता है, Compare two files और Export a subset, और हर टूल 3 बार मुफ़्त चलता है।

VS Code में स्टेप्स

  1. Marketplace से NetCDF Viewer & HDF5 Viewer इंस्टॉल करें, या Ctrl+P (macOS पर Cmd+P) दबाकर ext install zovo.hdf5-netcdf-explorer चलाएँ।
  2. Explorer में किसी .nc, .nc4, .netcdf या .cdf फ़ाइल पर क्लिक करें। Overview में format, dimensions, global attributes और सभी variables की टेबल दिखती है, लगभग ncdump -h जैसी।
  3. बाईं ओर के tree में कोई variable चुनें। 2-D slice एक heatmap के रूप में बनता है, और अगर rows और columns latitude और longitude हैं तो coastlines भी दिखती हैं।
  4. time slider को खिसकाएँ, या समय के साथ आगे चलाने के लिए उसके बगल में ▶ दबाएँ। किसी point की time series का plot देखने के लिए map पर उस point पर क्लिक करें।
  5. values पेज-दर-पेज देखने के लिए Table टैब खोलें। एक पेज में 100 rows और 30 columns होते हैं, और headers में coordinate values होती हैं।
  6. plot सेव करने के लिए "Save PNG" पर क्लिक करें, या स्क्रीन पर दिख रहे slice को CSV या JSON में सेव करने के लिए "Export slice…" पर। "Copy xarray code" उसी slice के लिए Python की लाइन देता है।
  7. HDF5 फ़ाइल के लिए .h5 फ़ाइल पर क्लिक करें। MATLAB 7.3 .mat फ़ाइल के लिए उस पर राइट-क्लिक करें और "Open in HDF5 NetCDF Explorer" चुनें।

क्या मुफ़्त है और Zovo Pro क्या जोड़ता है

सभी फ़ॉर्मैट, tree, attributes, टेबल, plots और coastlines वाले map, Play, point की time series, Save PNG और Export slice मुफ़्त हैं। इन फ़ीचर के लिए Python नहीं चाहिए, और एक्सटेंशन इनके लिए कोई नेटवर्क कॉल नहीं करता।

Export a subset, ncks -d या xarray के .sel की तरह काम करता है। आप एक variable चुनते हैं और हर dimension के लिए एक range देते हैं, index से (0:99) या value से (30..60, 2023-08-01..2023-08-31)। यह coordinates, attributes और एक history लाइन के साथ NetCDF फ़ाइल सेव करता है, या हर point की एक row वाली साफ़ CSV। किसी एक इलाके और समय की छोटी फ़ाइल आपको script लिखे बिना मिल जाती है।

Export a subset का इस्तेमाल (Zovo Pro)

  1. फ़ाइल खोलें और "Export slice…" के बगल वाले "Export subset…" बटन पर क्लिक करें, या Explorer में फ़ाइल पर राइट-क्लिक करके "Zovo Pro: Export a Subset of a Variable" चुनें।
  2. या Command Palette से "NetCDF Viewer Pro: Export Subset of a Variable (NetCDF or CSV)..." चलाएँ।
  3. हर dimension के लिए range टाइप करें। आप जैसे-जैसे टाइप करते हैं, box में दिखता है कि आपने क्या चुना है।
  4. NetCDF या CSV चुनें और सेव करने की जगह चुनें। एक notification में प्रोग्रेस दिखती है, और Cancel दबाने पर काम रुक जाता है, कोई आधी लिखी फ़ाइल नहीं बचती।

Export a subset आपके कंप्यूटर पर 3 बार मुफ़्त चलता है, उसके बाद लाइसेंस माँगता है। न कोई पॉप-अप आता है, न कोई काउंटडाउन चलता है।

Cursor, Windsurf या VSCodium में स्टेप्स

  1. Ctrl+Shift+X (macOS पर Cmd+Shift+X) से Extensions व्यू खोलें।
  2. zovo.hdf5-netcdf-explorer खोजें और Install पर क्लिक करें। Cursor, Windsurf और VSCodium एक्सटेंशन Open VSX से इंस्टॉल करते हैं, जहाँ इस एक्सटेंशन का नाम zovo/hdf5-netcdf-explorer है।
  3. अगर आपके एडिटर में एक्सटेंशन गैलरी नहीं है, तो Open VSX पेज से .vsix फ़ाइल डाउनलोड करें और "Extensions: Install from VSIX..." चलाएँ।
  4. इसके बाद सब कुछ VS Code की तरह ही काम करता है।

NetCDF Viewer & HDF5 Viewer क्या करता है

  • NetCDF-4 और NetCDF-4 classic, NetCDF-3 classic और 64-bit offset, और CDF-5 (64-bit data)।
  • HDF5 फ़ाइलें (.h5, .hdf5, .he5, .hdf), deflate, shuffle, szip, LZF, Blosc, bitshuffle, LZ4, Zstd, bzip2 और ZFP compression के साथ।
  • MATLAB 7.3 .mat और HDF5 पर आधारित दूसरी फ़ाइलें, जैसे .jld2, .loom और .h5ad।
  • scale_factor, add_offset, _FillValue और time units की CF decoding, noleap, 360_day और all_leap calendars समेत।
  • Remote SSH, WSL या dev container के ज़रिए दूसरी मशीन पर रखी फ़ाइलें।

यह क्या नहीं करता

  • Zarr और HDF4 सपोर्ट नहीं हैं। v5 फ़ॉर्मैट में सेव की गई MATLAB .mat फ़ाइलें HDF5 नहीं होतीं और नहीं खुलतीं। उन्हें save(filename, '-v7.3') से दोबारा सेव करें।
  • Coastlines सिर्फ़ regular latitude-longitude grid पर बनती हैं। 2-D latitude और longitude वाले curvilinear grid और मीटर में projected grid पर coastlines नहीं आतीं।
  • 512 x 512 से बड़े arrays plot के लिए sample किए जाते हैं। Export एक फ़ाइल में ज़्यादा से ज़्यादा 1,000,000 values लिखता है (सेटिंग hdf5NetcdfExplorer.maxReadValues)।
  • Virtual file systems, जैसे vscode.dev में खोली गई GitHub repositories, सपोर्ट नहीं हैं।
  • SZ या JPEG जैसे दूसरे HDF5 filters वाले datasets में values की जगह एक मैसेज दिखता है।

अक्सर पूछे जाने वाले सवाल

क्या यह मुफ़्त है?

फ़ाइलें देखना मुफ़्त है, यानी सभी फ़ॉर्मैट, map, Play, time series, Save PNG और Export slice। दोनों Pro टूल, Compare two files और Export a subset, 3-3 बार मुफ़्त चलते हैं। उसके बाद इनके लिए Zovo Pro चाहिए, जो सभी Zovo एक्सटेंशन के लिए एक बार 19 USD का है।

क्या Windows के लिए कोई NetCDF viewer है?

हाँ। यह एक्सटेंशन हर उस सिस्टम पर चलता है जहाँ VS Code चलता है, जिसमें Windows, macOS और Linux शामिल हैं, और इसे Python नहीं चाहिए।

क्या यह HDF5 और MAT फ़ाइलें खोल सकता है?

HDF5 .h5 फ़ाइलें और MATLAB 7.3 .mat फ़ाइलें, हाँ। पुरानी MATLAB v5 .mat फ़ाइलें HDF5 नहीं हैं, उनके लिए एक मैसेज दिखता है।

क्या यह Cursor में चलता है?

हाँ। यह Open VSX पर zovo/hdf5-netcdf-explorer नाम से है, इसलिए Cursor, Windsurf और VSCodium इसे इंस्टॉल कर सकते हैं।
