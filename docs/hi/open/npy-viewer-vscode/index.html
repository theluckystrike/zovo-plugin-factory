NumPy की .npy और .npz फ़ाइलें VS Code में देखें

मुफ़्त Tensor Viewer (NPZ Viewer & NPY Viewer) इंस्टॉल करें और किसी .npy या .npz फ़ाइल पर क्लिक करें। हर array अपने नाम, dtype और shape के साथ लिस्ट में दिखता है। किसी array पर क्लिक करने से min, max, mean, std, NaN की गिनती, एक चार्ट, एक histogram और values दिखती हैं, Python के बिना। फ़ाइल देखना, इमेज, Values टेबल और .npy या CSV में Save मुफ़्त हैं। Zovo Pro (19 USD, एक बार का भुगतान) दो टूल जोड़ता है, Compare two checkpoints और Scan all tensors, और हर टूल 3 बार मुफ़्त चलता है।

VS Code में स्टेप्स

  1. Marketplace से Tensor Viewer इंस्टॉल करें, या Ctrl+P (macOS पर Cmd+P) दबाकर ext install zovo.tensor-viewer चलाएँ।
  2. Explorer में किसी .npy या .npz फ़ाइल पर क्लिक करें। टेबल में हर array का नाम, type, shape, parameters की गिनती और साइज़ दिखता है।
  3. किसी array पर क्लिक करें। दाईं ओर का पैनल min, max, mean, std और NaN, Inf व zero की गिनती दिखाता है। उसके नीचे 2-D array के लिए heatmap या 1-D array के लिए line plot आता है, और एक histogram भी।
  4. Values टेबल में संख्याएँ पढ़ें, एक बार में 32 rows। 3 या उससे ज़्यादा dimensions वाले array के लिए Slice फ़ील्ड में [5, :, :] जैसा slice टाइप करें।
  5. अगर array इमेज के आकार का है, जैसे (H, W, 3) या (N, 3, H, W), तो Image सेक्शन उसे इमेज की तरह दिखाता है। वहीं Layout, Frame और Range चुनें। Float matrix में इसकी जगह "Show as image" बटन आता है।
  6. array या slice को नई फ़ाइल में लिखने के लिए "Save as .npy..." या "Save as CSV..." पर क्लिक करें।

क्या मुफ़्त है और Zovo Pro क्या जोड़ता है

सभी फ़ॉर्मैट, stats, heatmap, line plot, histogram, इमेज, Values टेबल, slice, raw arrays और .npy या CSV में Save मुफ़्त हैं। Python की ज़रूरत नहीं है, और viewer कोई नेटवर्क कॉल नहीं करता।

Scan all tensors फ़ाइल के हर array की हर value पढ़ता है, सिर्फ़ एक sample नहीं। यह NaN, Inf, पूरी तरह zero वाले और constant arrays को, और 10,000 या उससे बड़ी float values को फ़्लैग करता है। हर array का सटीक min, max, mean, std और L2 norm एक ही रिपोर्ट में आता है, जिसे आप फ़िल्टर कर सकते हैं और CSV, Markdown या JSON में सेव कर सकते हैं। बड़ी .npz फ़ाइल में खराब array ढूँढने के लिए आपको हर array पर अलग से क्लिक नहीं करना पड़ता।

Scan all tensors का इस्तेमाल (Zovo Pro)

  1. फ़ाइल खोलें और viewer में ऊपर "Scan all tensors" बटन पर क्लिक करें, या Explorer में फ़ाइल पर राइट-क्लिक करके "Zovo Pro: Scan Tensors for NaN, Inf and Zeros" चुनें।
  2. या Command Palette से "NumPy Viewer Pro: Scan All Tensors for NaN, Inf and Zeros" चलाएँ और फ़ाइल चुनें।
  3. एक notification में प्रोग्रेस दिखती है, और लंबे स्कैन को Cancel से रोका जा सकता है। रिपोर्ट में "Only tensors to check" फ़िल्टर लगाएँ, फिर रिपोर्ट को CSV, Markdown या JSON में सेव करें।

Scan all tensors आपके कंप्यूटर पर 3 बार मुफ़्त चलता है, उसके बाद लाइसेंस माँगता है। न कोई पॉप-अप आता है, न कोई काउंटडाउन चलता है।

Cursor, Windsurf या VSCodium में स्टेप्स

  1. Ctrl+Shift+X (macOS पर Cmd+Shift+X) से Extensions व्यू खोलें।
  2. zovo.tensor-viewer खोजें और Install पर क्लिक करें। Cursor, Windsurf और VSCodium एक्सटेंशन Open VSX से इंस्टॉल करते हैं, जहाँ इस एक्सटेंशन का नाम zovo/tensor-viewer है।
  3. अगर आपके एडिटर में एक्सटेंशन गैलरी नहीं है, तो Open VSX पेज से .vsix फ़ाइल डाउनलोड करें और "Extensions: Install from VSIX..." चलाएँ।
  4. इसके बाद सब कुछ VS Code की तरह ही काम करता है।

Tensor Viewer क्या करता है

  • header v1, v2 और v3 वाली .npy फ़ाइलें, C और Fortran order में, दोनों byte order के साथ।
  • stored या deflate से compressed entries वाले .npz archives, zip64 भी।
  • bool, int8 से int64, uint8 से uint64, float16, float32, float64 और complex numbers (stats magnitude पर)।
  • इमेज के आकार वाले arrays, stacks और batches, इमेज की तरह, एक बार में एक frame।
  • यही एक्सटेंशन .safetensors, .gguf और PyTorch की .pt, .pth और .ckpt फ़ाइलें भी खोलता है।

यह क्या नहीं करता

  • pickle किए गए object arrays लिस्ट में दिखते हैं, पर खोले नहीं जाते और कभी चलाए नहीं जाते। Text और structured arrays बिना stats के लिस्ट होते हैं।
  • 2,000,000 से ज़्यादा values वाले array के stats और plots एक sample से बनते हैं (सेटिंग tensorViewer.sampleValues)। stats sample से आए हों तो पैनल यह बताता है।
  • .npz की compressed entries सिर्फ़ शुरू से पढ़ी जाती हैं। उनके पहले 64 MB के बाद की values नहीं दिखतीं, और 512 MB से बड़ी entries सेव नहीं की जा सकतीं।
  • इमेज की लंबी साइड ज़्यादा से ज़्यादा 512 pixels की बनती है। 2-channel और Fortran-order arrays का इमेज व्यू नहीं होता।
  • CSV export 20 मिलियन values पर रुक जाता है। 2^53 से बड़ी int64 values के आख़िरी अंक टेबल और CSV में सही नहीं रहते।

अक्सर पूछे जाने वाले सवाल

क्या यह मुफ़्त है?

.npy और .npz फ़ाइलें खोलना, stats, plots, इमेज, Values टेबल और .npy या CSV में Save मुफ़्त हैं। दोनों Pro टूल, Compare two checkpoints और Scan all tensors, 3-3 बार मुफ़्त चलते हैं। उसके बाद इनके लिए Zovo Pro चाहिए, जो सभी Zovo एक्सटेंशन के लिए एक बार 19 USD का है।

क्या Python चाहिए?

नहीं। Tensor Viewer फ़ाइलें खुद पढ़ता है, इसलिए Python और NumPy इंस्टॉल होना ज़रूरी नहीं है।

क्या इंटरनेट से आई .npy फ़ाइल खोलना सुरक्षित है?

फ़ाइल के अंदर की कोई चीज़ कभी चलाई नहीं जाती। Object arrays, जिन्हें NumPy pickle के रूप में रखता है, लिस्ट में दिखते हैं पर खोले नहीं जाते, और viewer दिखाई जा रही फ़ाइल को कभी नहीं बदलता।

क्या यह Cursor में चलता है?

हाँ। Tensor Viewer Open VSX पर zovo/tensor-viewer नाम से है, इसलिए Cursor, Windsurf और VSCodium इसे इंस्टॉल कर सकते हैं।
