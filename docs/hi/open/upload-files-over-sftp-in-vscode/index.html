VS Code से SFTP या FTP पर server पर फ़ाइलें upload करें

मुफ़्त SFTP & FTP Sync and Upload एक्सटेंशन इंस्टॉल करें और host, user और server फ़ोल्डर के साथ एक .vscode/sftp.json लिखें। इसके बाद हर फ़ाइल save करते ही SFTP, FTP या FTPS पर upload होती है। किसी फ़ाइल या फ़ोल्डर पर राइट-क्लिक करके उसे upload, download या server copy से compare करें, और Remote Files view से server की फ़ाइलें normal टैब में खोलें। आपका .vscode फ़ोल्डर, .env फ़ाइलें और private keys कभी upload नहीं होते। यह सब मुफ़्त है, बिना account के। Zovo Pro (19 USD, एक बार) तीन टूल जोड़ता है, Sync Folder with Remote, Roll Back a Remote File और Server Profiles and Jump Host, और हर टूल 3 बार मुफ़्त चलता है।

VS Code में स्टेप्स

  1. Marketplace से SFTP & FTP Sync and Upload इंस्टॉल करें, या Ctrl+P (macOS पर Cmd+P) दबाकर ext install zovo.zovo-sftp चलाएँ।
  2. Command Palette से "SFTP: Create sftp.json Config" चलाएँ, या SFTP Remote view में Create sftp.json पर क्लिक करें।
  3. protocol (sftp, ftp या ftps), host, username, privateKeyPath (password इस्तेमाल करना हो तो इसे छोड़ दें) और remotePath भरें, यानी server का वह फ़ोल्डर जो आपके local फ़ोल्डर से मेल खाता है। किसी भी key की मदद देखने के लिए उस पर hover करें।
  4. "uploadOnSave": true सेट करें। अब से आपकी save की हुई हर फ़ाइल upload होती है। आपका टाइप किया password एक बार पूछा जाता है और editor के secret storage में रखा जाता है, sftp.json में कभी नहीं।
  5. Explorer में किसी भी फ़ाइल या फ़ोल्डर पर, या किसी टैब पर, राइट-क्लिक करें और Upload, Download या Compare with Server Copy चुनें (Compare फ़ाइलों पर काम करता है)।
  6. Server browse करने के लिए Remote Files view खोलें। किसी फ़ाइल को normal editor टैब में खोलकर वापस save करें, उसे download करें, उसका path कॉपी करें या उसे delete करें। "SFTP: Show Transfer Log" हर connection और transfer दिखाता है।

क्या मुफ़्त है और Zovo Pro क्या जोड़ता है

Upload on save, Upload, Download और Compare with Server Copy, Remote Files view, SFTP, FTP और FTPS, host key checks और transfer log मुफ़्त हैं, बिना account के, और आपके अपने server के सिवा कहीं sign-in नहीं करना पड़ता। कोई telemetry नहीं है।

जब server और आपका local फ़ोल्डर अलग-अलग हो गए हों, तो Sync Folder with Remote दोनों की तुलना करता है और कुछ भी move होने से पहले हर अंतर की list देता है: सिर्फ़ यहाँ वाली फ़ाइलें, सिर्फ़ server वाली, या किसी एक तरफ़ नई। हर फ़ाइल के लिए आप upload, download, delete या skip चुनते हैं, side-by-side diff खोलते हैं, dry run को text के रूप में save करते हैं, फिर apply करते हैं। Server पर कुछ बदलने से पहले आप ठीक-ठीक देख लेते हैं कि क्या बदलेगा।

Sync Folder with Remote का इस्तेमाल (Zovo Pro)

  1. Explorer में किसी फ़ोल्डर पर राइट-क्लिक करके "Zovo Pro: Sync folder with remote (diff preview)" चुनें, या Command Palette से "SFTP: Sync Folder with Remote, Diff Preview (Pro)..." चलाएँ। Remote Files view के title bar में भी यही बटन है।
  2. Plan पढ़ें। हर फ़ाइल के लिए upload, download, delete या skip चुनें, और जिस फ़ाइल को लेकर पक्का न हों उसका diff खोलें।
  3. Plan apply करें। Try तभी गिना जाता है जब sync plan दिखाया गया हो। Escape या Cancel कभी try नहीं लेते।

Sync Folder with Remote आपके कंप्यूटर पर 3 बार मुफ़्त चलता है, उसके बाद लाइसेंस माँगता है। न कोई पॉप-अप आता है, न कोई काउंटडाउन चलता है।

SFTP & FTP Sync and Upload क्या करता है

  • SSH keys, encrypted keys, SSH agent या password के साथ SFTP; FTP; और explicit या implicit TLS के साथ FTPS।
  • .vscode, .git, .env फ़ाइलें, private keys, .npmrc और दूसरी secret फ़ाइलें कभी upload नहीं होतीं। अपने patterns ignore में, .gitignore style में जोड़ें।
  • Server की host key जाँची जाती है: उसे hostFingerprint से pin करें, या पहले connection पर उसकी पुष्टि करें। Key बदली हो तो connection रुक जाता है।
  • जिस फ़ोल्डर पर आपने trust नहीं किया है (Restricted Mode), उसमें एक्सटेंशन बंद रहता है, ताकि download किया गया कोई project आपकी फ़ाइलें कहीं न भेज सके।
  • बाकी दो Pro टूल: Roll Back a Remote File किसी upload के overwrite करने से पहले फ़ाइल की आख़िरी 10 server copies आपके कंप्यूटर पर रखता है, और Server Profiles and Jump Host कई servers (staging, production) को एक sftp.json में रखता है और SSH jump host के ज़रिए connect करता है।

यह क्या नहीं करता

  • एक समय में हर server से एक connection, और FTP transfers एक के बाद एक चलते हैं।
  • Server पर symbolic links फ़ाइलों के लिए follow होते हैं, पर folder uploads, downloads या sync linked फ़ोल्डरों के अंदर नहीं जाते।
  • PuTTY .ppk format वाली keys को पहले OpenSSH में बदलना होता है (puttygen key.ppk -O private-openssh -o key)।
  • Sync size और modified time की तुलना करता है, फिर एक जैसे size वाली फ़ाइलों के bytes की, हर run में 300 फ़ाइलों या 64 MB तक।
  • Rollback copies default रूप से 5 MB तक की फ़ाइलों के लिए रखी जाती हैं, और सिर्फ़ इसी कंप्यूटर पर।

अक्सर पूछे जाने वाले सवाल

क्या यह मुफ़्त है?

Upload on save, Upload, Download, Compare with Server Copy, Remote Files view और transfer log मुफ़्त हैं, SFTP, FTP और FTPS पर। तीनों Pro टूल, Sync Folder with Remote, Roll Back a Remote File और Server Profiles and Jump Host, 3-3 बार मुफ़्त चलते हैं। उसके बाद इनके लिए Zovo Pro चाहिए, जो सभी Zovo एक्सटेंशन के लिए एक बार 19 USD का है।

क्या मेरा password sftp.json में रखा जाता है?

नहीं। आपका टाइप किया password या passphrase editor के secret storage में रखा जाता है। sftp.json में password न लिखें, तो आपसे एक बार पूछा जाएगा।

क्या यह मेरी .env फ़ाइल upload करेगा?

नहीं। .vscode, .git, .env फ़ाइलें, private keys और .npmrc default ignore list में हैं और कभी upload नहीं होते।

क्या VS Code बिना एक्सटेंशन के SFTP पर upload कर सकता है?

नहीं। VS Code में SFTP या FTP upload नहीं है। Remote SSH सीधे server पर फ़ाइलें edit करता है। Local project upload करने के लिए आपको एक्सटेंशन चाहिए, या terminal में scp और rsync।
