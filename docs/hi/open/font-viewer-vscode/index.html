VS Code में फ़ॉन्ट फ़ाइल का प्रीव्यू देखें

मुफ़्त Font Viewer इंस्टॉल करें और किसी .ttf, .otf, .woff, .woff2 या .ttc फ़ाइल पर क्लिक करें। यह आपका अपना sample टेक्स्ट उस फ़ॉन्ट में, साइज़ का waterfall, सर्च करने लायक glyph ग्रिड, और लाइसेंस और embedding rights दिखाता है, फ़ॉन्ट को सिस्टम पर इंस्टॉल किए बिना। Type tester, glyph ग्रिड, character map, Info टैब और Copy CSS @font-face मुफ़्त हैं। Zovo Pro (19 USD, एक बार का भुगतान) दो टूल जोड़ता है, Convert Font और Font Folder Report, और हर एक 3 बार मुफ़्त चलता है।

VS Code में स्टेप्स

  1. Marketplace से Font Viewer इंस्टॉल करें, या Ctrl+P (macOS पर Cmd+P) दबाकर ext install zovo.font-viewer-vscode चलाएँ।
  2. Explorer में किसी .ttf, .otf, .woff, .woff2, .ttc या .otc फ़ाइल पर क्लिक करें। इन फ़ाइलों के लिए Font Viewer डिफ़ॉल्ट एडिटर है, और यह फ़ॉन्ट को कभी नहीं बदलता।
  3. Type tester टैब पर अपना टेक्स्ट टाइप करें, साइज़ स्लाइडर को 8 से 200 px तक खींचें और 12 से 96 px तक का waterfall देखें। Variable font के स्लाइडर हिलाएँ और liga या ss01 जैसे OpenType features चालू या बंद करें।
  4. Glyphs टैब पर नाम, character, U+20AC या glyph id से सर्च करें। किसी glyph पर क्लिक करके उसे baseline, x-height और cap height के साथ बड़ा देखें, और character, उसका code point या उसकी outline SVG के रूप में कॉपी करें।
  5. Characters टैब पर हर Unicode block की कवरेज देखें, जैसे "Basic Latin 95/128"। क्या कमी है, यह देखने के लिए "Only characters in the font" बंद करें।
  6. Info टैब पर लाइसेंस, डिज़ाइनर, copyright और embedding rights पढ़ें, और तैयार @font-face rule कॉपी करें।

क्या मुफ़्त है और Zovo Pro क्या जोड़ता है

हर सपोर्टेड फ़ॉन्ट खोलना, type tester, glyph ग्रिड, character map, Info टैब और Copy CSS @font-face मुफ़्त हैं। Font Viewer ऑफ़लाइन काम करता है, बिना नेटवर्क कॉल और बिना telemetry के।

Font Folder Report किसी फ़ोल्डर के हर फ़ॉन्ट की लिस्ट बनाता है, जिसमें family, style, weight, axes, वर्शन, glyph count, लाइसेंस, लाइसेंस URL और embedding rights होते हैं। यह लिस्ट CSV फ़ाइल, Markdown टेबल, या हर फ़ॉन्ट के लिए एक @font-face rule वाली एक fonts.css (WOFF2 पहले) के रूप में लिखता है। किसी ऐप या वेबसाइट में फ़ॉन्ट का फ़ोल्डर भेजने से पहले आप एक ही फ़ाइल में देख लेते हैं कि हर फ़ॉन्ट किस काम में इस्तेमाल हो सकता है, हर फ़ॉन्ट अलग से खोलने की ज़रूरत नहीं पड़ती।

Font Folder Report का इस्तेमाल (Zovo Pro)

  1. Explorer में फ़ॉन्ट वाले फ़ोल्डर पर राइट-क्लिक करें और "Font Folder Report: CSV, Markdown or @font-face CSS… (Pro)" चुनें, या Command Palette से "Font Viewer: Font Folder Report: CSV, Markdown or @font-face CSS… (Pro)" चलाएँ और फ़ोल्डर चुनें।
  2. फ़ॉर्मैट चुनें: CSV, Markdown टेबल या CSS @font-face rules।
  3. फ़ाइल सेव करें। डिफ़ॉल्ट नाम fonts-report.csv, fonts-report.md और fonts.css हैं, और ट्राई तभी गिना जाता है जब फ़ाइल लिख दी जाए।

Font Folder Report आपके कंप्यूटर पर 3 बार मुफ़्त चलता है, उसके बाद लाइसेंस माँगता है। न कोई पॉप-अप आता है, न कोई काउंटडाउन चलता है।

Cursor, Windsurf या VSCodium में स्टेप्स

  1. Ctrl+Shift+X (macOS पर Cmd+Shift+X) से Extensions व्यू खोलें।
  2. zovo.font-viewer-vscode खोजें और Install पर क्लिक करें। Cursor, Windsurf और VSCodium एक्सटेंशन Open VSX से इंस्टॉल करते हैं, जहाँ इस एक्सटेंशन का नाम zovo/font-viewer-vscode है।
  3. अगर आपके एडिटर में एक्सटेंशन गैलरी नहीं है, तो Open VSX पेज से .vsix फ़ाइल डाउनलोड करें और "Extensions: Install from VSIX..." चलाएँ।
  4. इसके बाद सब कुछ VS Code की तरह ही काम करता है।

Font Viewer क्या करता है

  • TrueType .ttf और OpenType .otf फ़ॉन्ट, variable fonts भी।
  • .woff और .woff2 वेब फ़ॉन्ट। WOFF2 को एक्सटेंशन का अपना decoder अनपैक करता है।
  • .ttc और .otc collections, हेडर में face चुनने के लिए एक लिस्ट के साथ।
  • 20,000 glyphs वाले बड़े CJK फ़ॉन्ट, जो स्क्रॉल करते समय हिस्सों में लोड होते हैं।
  • Explorer में किसी फ़ॉन्ट पर राइट-क्लिक करके उसे खोले बिना Copy CSS @font-face चुनें।

यह क्या नहीं करता

  • WOFF2 collections, SVG fonts, .dfont और Type 1 फ़ॉन्ट सपोर्टेड नहीं हैं।
  • Glyph outlines variable font का default instance दिखाती हैं। Type tester, waterfall और character map axis स्लाइडर के हिसाब से बदलते हैं।
  • Color fonts type tester और character map में रंग के साथ दिखते हैं, पर glyph ग्रिड उनकी सादी outlines दिखाता है।
  • 64 MB से बड़ी फ़ाइलें खुलने की जगह एक मैसेज दिखाती हैं (सेटिंग fontViewer.maxFileMB)।
  • यह read-only है। यह फ़ॉन्ट एडिट नहीं करता और उन्हें आपके सिस्टम पर इंस्टॉल नहीं करता।

अक्सर पूछे जाने वाले सवाल

क्या यह मुफ़्त है?

फ़ॉन्ट देखना, type tester, glyph ग्रिड, character map, Info टैब और Copy CSS @font-face मुफ़्त हैं। दोनों Pro टूल, Convert Font और Font Folder Report, 3 बार मुफ़्त चलते हैं। उसके बाद इनके लिए Zovo Pro चाहिए, जो सभी Zovo एक्सटेंशन के लिए एक बार 19 USD का है।

क्या फ़ॉन्ट इंस्टॉल करना पड़ता है?

नहीं। फ़ॉन्ट फ़ाइल से पढ़ा जाता है और सिर्फ़ Font Viewer टैब के अंदर दिखता है। आपके सिस्टम की फ़ॉन्ट लिस्ट नहीं बदलती।

क्या यह मेरे build फ़ोल्डर की WOFF2 फ़ाइल खोल सकता है?

हाँ। WOFF2 को एक्सटेंशन का अपना decoder अनपैक करता है, और जब आप फ़ॉन्ट का नया build सेव करते हैं तो खुला व्यू फिर से लोड हो जाता है।

क्या यह Cursor में काम करता है?

हाँ। Font Viewer Open VSX पर zovo/font-viewer-vscode नाम से है, इसलिए Cursor, Windsurf और VSCodium इसे इंस्टॉल कर सकते हैं।
