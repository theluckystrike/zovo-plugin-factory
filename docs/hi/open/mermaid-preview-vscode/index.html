VS Code में Mermaid diagrams का preview देखें

VS Code में Mermaid का अपना preview नहीं है। मुफ़्त Mermaid Viewer इंस्टॉल करें, कोई .mmd या .mermaid फ़ाइल खोलें और editor में ऊपर दाईं ओर preview आइकन पर क्लिक करें। आप जैसे-जैसे टाइप करते हैं, diagram साथ-साथ बदलता है। Markdown फ़ाइल पर preview हर mermaid block की लिस्ट दिखाता है। Mermaid 12.3.0 एक्सटेंशन के अंदर ही आता है, इसलिए preview और PNG या SVG export मुफ़्त हैं और offline, बिना sign-in के चलते हैं। Zovo Pro (19 USD, एक बार का भुगतान) PDF export, workspace के सभी diagrams का export और सेव करते समय export जोड़ता है, और हर टूल 3 बार मुफ़्त चलता है।

VS Code में स्टेप्स

  1. Marketplace से Mermaid Viewer इंस्टॉल करें, या Ctrl+P (macOS पर Cmd+P) दबाकर ext install zovo.mermaid-viewer चलाएँ।
  2. कोई .mmd या .mermaid फ़ाइल खोलें और editor title में preview आइकन पर क्लिक करें, या Ctrl+K V (macOS पर Cmd+K V) दबाएँ। Command Palette से "Mermaid Viewer: Open Diagram Editor (Text + Live Preview)" भी चला सकते हैं।
  3. ```mermaid blocks वाली Markdown फ़ाइल के लिए भी वही preview आइकन क्लिक करें। preview हर diagram की लिस्ट दिखाता है, और हर diagram की अपनी error लाइन और अपने export बटन होते हैं।
  4. Markdown फ़ाइल में किसी block के ऊपर "Edit diagram" पर क्लिक करें, block live preview के बगल में edit के लिए खुल जाता है। सेव करें, और text वापस अपने block में चला जाता है।
  5. pointer की जगह पर zoom करने के लिए scroll करें और pan करने के लिए drag करें। Fit और 100% toolbar में हैं।
  6. Export पर क्लिक करें और Save PNG (1x, 2x या 4x, या एक तय width या height), Save SVG, Copy PNG या Copy SVG code चुनें।

क्या मुफ़्त है और Zovo Pro क्या जोड़ता है

live preview, diagram editor, Markdown blocks के लिए Edit diagram, completion, error underlines, 15 templates, Mermaid Diagrams outline और PNG व SVG export और copy मुफ़्त हैं। न कोई अकाउंट, न sign-in और न कोई AI।

Export All Diagrams in Workspace फ़ोल्डर की हर .mmd, .mermaid और Markdown फ़ाइल का हर diagram SVG, PNG या दोनों में mermaid-export/ में लिखता है, और वहाँ फ़ोल्डरों का ढाँचा sources जैसा ही रहता है। जो diagrams नहीं बन पाते, उनकी लिस्ट आख़िर में दिखती है। docs बदलने पर आपको हर diagram अलग से खोलकर export नहीं करना पड़ता।

Export All Diagrams in Workspace का इस्तेमाल (Zovo Pro)

  1. VS Code में फ़ोल्डर खोलें। Command Palette से "Mermaid Viewer: Export All Diagrams in Workspace (SVG/PNG) (Pro)" चलाएँ, या preview toolbar के नीचे "Pro tools" row में "Export All Diagrams in Workspace" पर क्लिक करें।
  2. SVG, PNG, या SVG और PNG दोनों चुनें।
  3. डिफ़ॉल्ट फ़ोल्डर mermaid-export रखें (सेटिंग mermaidViewer.exportFolder) या "Choose a folder…" चुनें। try तभी गिना जाता है जब फ़ाइलें लिख दी जाती हैं। Escape दबाने पर try बचा रहता है।

Export All Diagrams in Workspace आपके कंप्यूटर पर 3 बार मुफ़्त चलता है, उसके बाद लाइसेंस माँगता है। न कोई पॉप-अप आता है, न कोई काउंटडाउन चलता है।

Cursor, Windsurf या VSCodium में स्टेप्स

  1. Ctrl+Shift+X (macOS पर Cmd+Shift+X) से Extensions व्यू खोलें।
  2. zovo.mermaid-viewer खोजें और Install पर क्लिक करें। Cursor, Windsurf और VSCodium एक्सटेंशन Open VSX से इंस्टॉल करते हैं, जहाँ इस एक्सटेंशन का नाम zovo/mermaid-viewer है।
  3. अगर आपके एडिटर में एक्सटेंशन गैलरी नहीं है, तो Open VSX पेज से .vsix फ़ाइल डाउनलोड करें और "Extensions: Install from VSIX..." चलाएँ।
  4. इसके बाद सब कुछ VS Code की तरह ही काम करता है।

Mermaid Viewer क्या करता है

  • Flowchart, sequence, class, state, ER, Gantt, pie, gitGraph, mindmap, timeline, sankey, XY chart, block, C4, architecture और वे सभी दूसरे types जिन्हें Mermaid 12.3.0 जानता है।
  • errors अपनी लाइन पर underline होते हैं और Problems पैनल में लिस्ट होते हैं। आख़िरी सही diagram स्क्रीन पर बना रहता है, और Markdown फ़ाइल का एक टूटा block बाकी blocks को नहीं छिपाता।
  • pointer की जगह पर 1 % से 3,200 % तक zoom, trackpad से pan और pinch के साथ।
  • Azure DevOps और GitHub wikis के लिए plain text labels वाला SVG export।
  • background editor के रंग में, सफ़ेद, transparent या आपके चुने रंग में, जो exports में भी लगता है।

यह क्या नहीं करता

  • यह VS Code के अपने Markdown preview में diagrams नहीं जोड़ता। यह अपना अलग preview पैनल खोलता है।
  • labels में math ($$...$$) शायद ठीक से न दिखे, क्योंकि KaTeX fonts साथ में नहीं आते।
  • जो icon packs Mermaid इंटरनेट से लोड करता है, वे लोड नहीं होते। built-in icons काम करते हैं।
  • 500,000 से ज़्यादा characters या 2,000 से ज़्यादा links वाले diagrams तब तक नहीं बनते जब तक आप limit न बढ़ाएँ (सेटिंग mermaidViewer.maxTextSize और mermaidViewer.maxEdges)।
  • जिस diagram को बनने में 10 सेकंड से ज़्यादा लगें, उसे रोक दिया जाता है (सेटिंग mermaidViewer.renderTimeoutSeconds)।

अक्सर पूछे जाने वाले सवाल

क्या यह मुफ़्त है?

preview, editor, Markdown blocks की editing और PNG व SVG export मुफ़्त हैं। Pro टूल (PDF export, Export All Diagrams in Workspace और Export on Save) 3-3 बार मुफ़्त चलते हैं। उसके बाद इनके लिए Zovo Pro चाहिए, जो सभी Zovo एक्सटेंशन के लिए एक बार 19 USD का है।

VS Code के Markdown preview में मेरा mermaid block क्यों नहीं दिखता?

VS Code का built-in Markdown preview Mermaid diagrams नहीं बनाता। Mermaid Viewer उस Markdown फ़ाइल के लिए अपना preview पैनल खोलता है, जिसमें हर diagram के लिए zoom और export है।

क्या इसके लिए अकाउंट या इंटरनेट चाहिए?

नहीं। Mermaid 12.3.0 साथ में आता है, न कोई sign-in है न कोई AI, और preview हर नेटवर्क request को रोक देता है।

क्या यह Cursor में चलता है?

हाँ। यह Open VSX पर zovo/mermaid-viewer नाम से है, इसलिए Cursor, Windsurf और VSCodium इसे इंस्टॉल कर सकते हैं।
