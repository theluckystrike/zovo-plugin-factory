VS Code में स्टेप्स

  1. Marketplace से Dotenv & .env File Editor इंस्टॉल करें, या Ctrl+P (macOS पर Cmd+P) दबाकर ext install zovo.zovo-dotenv चलाएँ।
  2. एक .env फ़ाइल खोलें (.env.local, .env.production, *.env या .flaskenv भी)। Keys, export, values, multi-line values और ${NAME} references को रंग मिलते हैं।
  3. Secret जैसी दिखने वाली values तब तक बिंदुओं में दिखती हैं जब तक cursor उनकी लाइन पर न हो। सब दिखाने के लिए editor title में eye बटन पर क्लिक करें, या "Dotenv: Show or Hide Secret Values" चलाएँ। .env.example जैसे templates कभी छिपाए नहीं जाते।
  4. Problems panel में problems दिखते हैं: दो बार सेट की गई key, = के आसपास spaces, कभी बंद न होने वाला quote, बिना = की लाइन, गलत नाम, trailing spaces, या ऐसा ${NAME} जिसे कोई लाइन सेट नहीं करती। Fix के लिए उस problem पर Ctrl+. (Mac पर Cmd+.) दबाएँ।
  5. = के आसपास के spaces और trailing spaces हटाने के लिए Format Document चलाएँ। Comments, क्रम और quotes जैसे हैं वैसे रहते हैं।
  6. किसी value को दिखाए बिना कॉपी करने के लिए "Dotenv: Copy the Value on This Line" चलाएँ। यह value को quotes और escapes हटाकर कॉपी करता है, छिपी होने पर भी।
  7. अपने code में process.env.DB_HOST, os.getenv("X"), System.getenv("X") और ऐसे ही नामों पर hover करें, ताकि दिखे कि कौन-सी .env फ़ाइल उसे सेट करती है। वह लाइन खोलने के लिए F12 दबाएँ।

क्या मुफ़्त है और Zovo Pro क्या जोड़ता है

Syntax colors, छिपी secret values, quick fixes वाले problems, Format Document, keys का outline, Copy the Value on This Line, और code में hovers, go to definition और completion मुफ़्त हैं। कोई account, कोई network request और कोई telemetry नहीं है।

Compare .env with .env.example फ़ाइल के बगल में एक report में दिखाता है कि कौन-सी keys .env में नहीं हैं, कौन-सी keys .env.example में documented नहीं हैं और कौन-सी खाली हैं। फिर buttons गायब keys को किसी भी फ़ाइल में जोड़ते हैं: .env में example values के साथ, या .env.example में खाली values के साथ। .env की values कभी दिखाई या कॉपी नहीं की जातीं, इसलिए आप फ़ाइल को लाइन-दर-लाइन पढ़े बिना किसी teammate का setup या fail हो रहा deploy ठीक कर सकते हैं।

Compare .env with .env.example का इस्तेमाल (Zovo Pro)

  1. Explorer में किसी .env फ़ाइल पर राइट-क्लिक करके "Zovo Pro: Compare .env with .env.example" चुनें, या Command Palette से "Dotenv: Compare .env with .env.example (Pro)..." चलाएँ। यह active टैब की .env फ़ाइल इस्तेमाल करता है, या पूछता है कि कौन-सी।
  2. अगर बगल में कोई .env.example, .env.sample, .env.template या .env.dist नहीं है, तो "Create .env.example next to .env" या "Pick another file..." चुनें।
  3. फ़ाइल के बगल में खुली report पढ़ें। Keys जोड़ने के लिए "Add N keys to .env.example (empty values)" या "Add N keys to .env (example values)" पर क्लिक करें।
  4. Try तभी गिना जाता है जब report खुली हो। Escape या Cancel कभी try नहीं लेते।

Compare .env with .env.example आपके कंप्यूटर पर 3 बार मुफ़्त चलता है, उसके बाद लाइसेंस माँगता है। न कोई पॉप-अप आता है, न कोई काउंटडाउन चलता है।

Dotenv & .env File Editor क्या करता है

  • .env, .env.* (जैसे .env.local और .env.production), *.env और .flaskenv फ़ाइलें।
  • कौन-सी values छिपती हैं: PASSWORD, TOKEN, SECRET, API_KEY, DSN, DATABASE_URL और ऐसे ही नामों वाली, या हर value, या कोई नहीं (सेटिंग envFile.maskValues)।
  • process.env और import.meta.env (JavaScript, TypeScript), os.environ और os.getenv (Python), os.Getenv (Go), ENV (Ruby), System.getenv (Java), env() (PHP) और दूसरों के लिए code में hovers और go to definition।
  • process.env. के बाद keys का completion।
  • छिपी values outline, hovers और completions में भी छिपी रहती हैं, जब तक आप इसे बंद न करें (सेटिंग envFile.hoverShowsSecrets)।

यह क्या नहीं करता

  • छिपाना सिर्फ़ screen के लिए है। Text फ़ाइल में, search results में और minimap की shape में फिर भी रहता है, और copy-paste असली value कॉपी करता है।
  • .envrc (direnv) एक shell script है, इसलिए उसे shell extensions के लिए छोड़ दिया जाता है।
  • Code report process.env.API_KEY जैसे literal नाम देखता है। Run time पर बनने वाले नाम नहीं मिलते।
  • Problems dotenv package के नियमों पर चलते हैं। कुछ tools (Docker Compose v1, systemd) ज़्यादा सख़्त हैं, और warnings यही बताती हैं।

क्या यह मुफ़्त है?

Colors, छिपी values, quick fixes वाले problems, formatting और code hovers मुफ़्त हैं। तीनों Pro टूल, Compare .env with .env.example, Find Keys Missing in Code or .env और Convert .env to JSON, YAML, Kubernetes, 3-3 बार मुफ़्त चलते हैं। उसके बाद इनके लिए Zovo Pro चाहिए, जो सभी Zovo एक्सटेंशन के लिए एक बार 19 USD का है।

क्या values छिपाने के लिए यह मेरी .env फ़ाइल बदलता है?

नहीं। सिर्फ़ display बदलता है, फ़ाइल कभी नहीं बदली जाती। Copy-paste अब भी असली value कॉपी करता है।

मेरी key को दो बार सेट क्यों बताया गया है?

वही key दो लाइनों पर है। dotenv package पहली value रखता है, जबकि shells और Docker Compose आख़िरी। Quick fix दूसरी लाइन हटा देता है।

हाँ। Cursor, Windsurf और VSCodium इसे Open VSX से इंस्टॉल करते हैं, जहाँ यह zovo/zovo-dotenv नाम से है।
