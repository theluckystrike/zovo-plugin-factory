VS Code में HTML, JSX और Vue टैग का नाम अपने-आप बदलें

मुफ़्त Auto Rename Tag & Close Tag Sync एक्सटेंशन इंस्टॉल करें और किसी opening या closing टैग में नाम बदलें। मैचिंग टैग टाइप करते ही बदल जाता है। यह rename VS Code की अपनी linked editing (editor.linkedEditing) है। एक्सटेंशन अपनी भाषाओं के लिए यह सेटिंग चालू करता है और HTML, JSX, TSX, Vue, Svelte, Astro, PHP, Blade, Twig, XML, Markdown और दूसरी भाषाओं में मैचिंग टैग ढूँढता है, इसलिए एक undo से दोनों टैग वापस आ जाते हैं। Rename, auto close और मैचिंग टैग का बॉक्स मुफ़्त हैं। Zovo Pro (19 USD, एक बार का भुगतान) Rename Tag in All Files और Check Unclosed Tags in All Files जोड़ता है, और हर टूल 3 बार मुफ़्त चलता है।

VS Code में स्टेप्स

  1. Marketplace से Tag Auto Rename & Close Tag Sync इंस्टॉल करें, या Ctrl+P (macOS पर Cmd+P) दबाकर ext install zovo.zovo-auto-rename-tag चलाएँ।
  2. कोई HTML, JSX, TSX, Vue, Svelte, PHP या दूसरी template फ़ाइल खोलें और opening टैग में नाम बदलें। Closing टैग टाइप करते ही बदल जाता है, और उल्टा भी होता है।
  3. Opening टैग के बाद > टाइप करें, तो closing टैग कर्सर के बाद आ जाता है। </ टाइप करें, तो खुले element का नाम अपने-आप भर जाता है।
  4. कर्सर किसी टैग पर रखें, तो दोनों टैग पर आपकी theme के bracket रंगों में एक बॉक्स दिखता है।
  5. "Go to Matching Tag" और "Select Tag Content" के लिए एडिटर में राइट-क्लिक करें। बॉक्स में नया नाम टाइप करने के लिए Command Palette से "Tag Sync: Rename Tag Pair…" चलाएँ।
  6. इस फ़ाइल के लिए क्या चालू है यह देखने के लिए, या किसी एक भाषा के लिए एक्सटेंशन बंद करने के लिए, स्टेटस बार में Tags आइटम पर क्लिक करें। अगर वहाँ "Tags: rename off" लिखा है, तो उस भाषा में rename चालू करने के लिए उस पर क्लिक करें।

क्या मुफ़्त है और Zovo Pro क्या जोड़ता है

टाइप करते समय rename, > और </ पर auto close, मैचिंग टैग का बॉक्स, Go to Matching Tag, Select Tag Content, Rename Tag Pair… और स्टेटस बार मेन्यू मुफ़्त हैं। इसमें कोई विज्ञापन नहीं है, साइन-इन नहीं चाहिए और यह ऑफ़लाइन काम करता है।

यह workspace की हर टैग फ़ाइल में किसी component या element का नाम एक साथ बदलता है, जैसे हर .tsx, .vue, .html और template फ़ाइल में <Button> को <UiButton>। सिर्फ़ टैग के नाम बदलते हैं, टेक्स्ट, attributes, strings या comments कभी नहीं। पहले आपको गिनती दिखती है, "Preview first" VS Code का refactor preview खोलता है, और एक Undo से सभी फ़ाइलें पहले जैसी हो जाती हैं।

Rename Tag in All Files का इस्तेमाल (Zovo Pro)

  1. VS Code में प्रोजेक्ट फ़ोल्डर खोलें। इस टूल के लिए खुला फ़ोल्डर ज़रूरी है।
  2. Command Palette से "Tag Sync: Rename Tag in All Files… (Pro)" चलाएँ, या Explorer में किसी .html, .htm, .vue, .jsx, .tsx या .svelte फ़ाइल पर राइट-क्लिक करके "Zovo Pro: Rename Tag in All Files" चुनें।
  3. जिस टैग का नाम बदलना है, उसे वैसे ही टाइप करें जैसे वह फ़ाइलों में लिखा है (जैसे Button), फिर नया नाम।
  4. "Rename" चुनें, या बदलाव refactor preview में जाँचने के लिए "Preview first" चुनें। जो फ़ाइलें खुली नहीं थीं, वे बदल जाती हैं पर सेव नहीं होतीं। File > Save All से वे सेव होती हैं, और Undo से पहले जैसी हो जाती हैं।

Rename Tag in All Files आपके कंप्यूटर पर 3 बार मुफ़्त चलता है, उसके बाद लाइसेंस माँगता है। न कोई पॉप-अप आता है, न कोई काउंटडाउन चलता है।

Tag Auto Rename & Close Tag Sync क्या करता है

  • HTML, JSX और TSX, Vue, Svelte, Astro, PHP, Blade, Twig, Jinja, Nunjucks, Liquid, ERB, EJS, Handlebars, XML, SVG और Markdown में rename।
  • br, img, input, meta और hr जैसे void टैग की कभी जोड़ी नहीं बनती और उन्हें बंद नहीं किया जाता।
  • .tsx में सिर्फ़ असली JSX को टैग माना जाता है। a < b && c > d जैसी तुलना और useState<string>() जैसे generics को नहीं छुआ जाता, और .ts फ़ाइलों में कुछ नहीं बदलता।
  • Comments, strings, <script> और <style> के अंदर का हिस्सा, और {{ }}, {% %}, <?php ?> और <% %> blocks छोड़ दिए जाते हैं।
  • नई, बिना सेव की फ़ाइलें भी काम करती हैं, जैसे ही उनकी भाषा तय हो जाती है।

यह क्या नहीं करता

  • JSX और TSX में TypeScript खुद टैग बंद करता है, इसलिए वहाँ यह एक्सटेंशन closing का काम उसी पर छोड़ देता है। TypeScript का closing टैग अपना अलग undo step होता है।
  • जब Vue, Svelte, Astro या Red Hat XML एक्सटेंशन इंस्टॉल हो, तो वह एक्सटेंशन अपनी भाषा में टैग बंद करता है और यह एक्सटेंशन बीच में नहीं आता।
  • 1 MB से बड़ी या 50,000 से ज़्यादा लाइनों वाली फ़ाइलों में live rename, close या highlight नहीं होता (सेटिंग zovoTags.maxFileSizeKB और zovoTags.maxFileLines)। स्टेटस बार यह बताता है, और commands फिर भी काम करती हैं।
  • Svelte या Astro के {...} expressions के अंदर लिखे टैग rename नहीं होते।
  • अगर पुराना Auto Rename Tag या Auto Close Tag एक्सटेंशन भी चालू है, तो दोनों एक ही टैग को बदल सकते हैं। इनमें से एक ही रखें।

अक्सर पूछे जाने वाले सवाल

यह editor.linkedEditing सेटिंग से कैसे अलग है?

एक्सटेंशन rename के लिए editor.linkedEditing का ही इस्तेमाल करता है। यह अपनी हर भाषा के लिए यह सेटिंग चालू करता है और हर भाषा में मैचिंग टैग ढूँढता है, HTML और Vue से लेकर PHP, Twig, XML और JSX तक। साथ ही यह टैग बंद करता है, मैचिंग टैग के चारों ओर बॉक्स बनाता है, और Go to Matching Tag और Select Tag Content जोड़ता है। अगर आपने खुद editor.linkedEditing बंद किया है, तो स्टेटस बार में "Tags: rename off" दिखता है, और एक क्लिक से यह उस भाषा के लिए चालू हो जाता है।

क्या undo अब भी काम करता है?

हाँ। आपका बदलाव और मैचिंग टैग का बदलाव एक ही undo step है, क्योंकि rename VS Code की linked editing से होता है। Auto close से आया closing टैग आपके टाइप किए > के undo step में ही जुड़ता है, सिवाय JSX और TSX के, जहाँ TypeScript टैग बंद करता है।

क्या यह मुफ़्त है?

हाँ। Rename, auto close, मैचिंग टैग का बॉक्स और एडिटर commands मुफ़्त हैं। Rename Tag in All Files और Check Unclosed Tags in All Files Zovo Pro टूल हैं, और हर एक 3 बार मुफ़्त चलता है। उसके बाद Zovo Pro सभी Zovo एक्सटेंशन के लिए एक बार 19 USD का है।

क्या यह Cursor में काम करता है?

हाँ। Cursor, Windsurf और VSCodium इसे Open VSX से zovo/zovo-auto-rename-tag नाम से इंस्टॉल करते हैं।
