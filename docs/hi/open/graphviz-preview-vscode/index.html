VS Code में Graphviz DOT ग्राफ का लाइव प्रीव्यू

मुफ़्त Graphviz Viewer & DOT Viewer इंस्टॉल करें, कोई .dot या .gv फ़ाइल खोलें और प्रीव्यू आइकन पर क्लिक करें। ग्राफ एडिटर के बगल में बनता है और टाइप करते ही फिर से बनता है। Graphviz 16.1 एक्सटेंशन के अंदर WebAssembly के रूप में मौजूद है, इसलिए कुछ और इंस्टॉल नहीं करना पड़ता। प्रीव्यू, छह layout engines, क्लिक करके लाइन पर जाना और SVG या PNG एक्सपोर्ट मुफ़्त हैं। Zovo Pro (19 USD, एक बार का भुगतान) vector PDF एक्सपोर्ट, workspace के हर ग्राफ का एक्सपोर्ट और सेव करने पर एक्सपोर्ट जोड़ता है, और हर टूल को आप 3 बार मुफ़्त चला सकते हैं।

VS Code में स्टेप्स

  1. Marketplace से Graphviz Viewer & DOT Viewer इंस्टॉल करें, या Ctrl+P (macOS पर Cmd+P) दबाकर ext install zovo.zovo-graphviz-preview चलाएँ।
  2. कोई .dot या .gv फ़ाइल खोलें। Editor title bar में प्रीव्यू आइकन पर क्लिक करें, या Ctrl+K V (Mac पर Cmd+K V) दबाएँ। ग्राफ फ़ाइल के बगल में खुलता है।
  3. फ़ाइल एडिट करें। टाइप करना रुकने के 300 ms बाद प्रीव्यू फिर से बनता है, सेव करने की ज़रूरत नहीं। Syntax error अपनी लाइन पर underline होता है और Problems में दिखता है, और प्रीव्यू आख़िरी सही ड्रॉइंग दिखाता रहता है।
  4. Toolbar में dot, neato, fdp, sfdp, circo या twopi चुनें। auto पर ग्राफ का layout= attribute इस्तेमाल होता है, और वह न हो तो dot।
  5. Find node में टाइप करें, तो जिन nodes का नाम या label मैच करता है वे हाइलाइट हो जाते हैं। किसी node, edge या cluster पर क्लिक करें, तो कर्सर सोर्स में उसकी लाइन पर पहुँच जाता है।
  6. ग्राफ सेव करने के लिए SVG या PNG पर क्लिक करें। PNG सफ़ेद बैकग्राउंड पर 2x में, Graphviz के सामान्य रंगों में सेव होता है।

क्या मुफ़्त है और Zovo Pro क्या जोड़ता है

लाइव प्रीव्यू, सभी छह layout engines, Problems में errors, Find node, क्लिक से लाइन पर जाना, pan और zoom, खुले ग्राफ का SVG और PNG एक्सपोर्ट और Markdown preview में dot blocks मुफ़्त हैं। इसके लिए sign-in नहीं चाहिए, यह कोई नेटवर्क कॉल नहीं करता और इसमें telemetry नहीं है।

PDF एक्सपोर्ट ग्राफ का vector PDF सेव करता है, जिसमें टेक्स्ट टेक्स्ट ही रहता है, इसलिए वह हर zoom पर साफ़ दिखता है और आप उसे खोज और कॉपी कर सकते हैं। dot -Tpdf की तरह ग्राफ के साइज़ वाले पेज चुनें, या title page और bookmarks के साथ A4 या Letter पेज, और Markdown फ़ाइल से हर dot block का एक पेज बनता है। Graphviz इंस्टॉल किए बिना आपको design document या प्रिंट के लिए PDF मिल जाता है।

Export to PDF (Vector, Title Page) का इस्तेमाल (Zovo Pro)

  1. प्रीव्यू खोलें और toolbar में PDF पर क्लिक करें (उस पर छोटा PRO टैग है), या Command Palette से "Graphviz: Export to PDF (Vector, Title Page) (Pro)" चलाएँ।
  2. "Graph-size pages", "Title page and A4 pages", "Title page and Letter pages" या "Graph-size pages with a title page" चुनें, फिर तय करें कि फ़ाइल कहाँ सेव हो।
  3. Escape, Cancel या ग्राफ की error से कोई मुफ़्त ट्रायल ख़र्च नहीं होता।

Export to PDF (Vector, Title Page) आपके कंप्यूटर पर 3 बार मुफ़्त चलता है, उसके बाद लाइसेंस माँगता है। न कोई पॉप-अप आता है, न कोई काउंटडाउन चलता है।

Cursor, Windsurf या VSCodium में स्टेप्स

  1. Ctrl+Shift+X (macOS पर Cmd+Shift+X) से Extensions व्यू खोलें।
  2. zovo.zovo-graphviz-preview खोजें और Install पर क्लिक करें। Cursor, Windsurf और VSCodium एक्सटेंशन Open VSX से इंस्टॉल करते हैं, जहाँ इस एक्सटेंशन का नाम zovo/zovo-graphviz-preview है।
  3. अगर आपके एडिटर में एक्सटेंशन गैलरी नहीं है, तो Open VSX पेज से .vsix फ़ाइल डाउनलोड करें और "Extensions: Install from VSIX..." चलाएँ।
  4. इसके बाद सब कुछ VS Code की तरह ही काम करता है।

Graphviz Viewer & DOT Viewer क्या करता है

  • Clusters, subgraphs और HTML labels वाले graphs और digraphs।
  • Markdown में fenced dot, graphviz और gv blocks, जो VS Code के अपने Markdown preview में बनते हैं।
  • Dark themes। डिफ़ॉल्ट काली लाइनें और टेक्स्ट आपकी theme के रंग ले लेते हैं, और ग्राफ में आपके सेट किए रंग वैसे ही रहते हैं।
  • बड़े ग्राफ, जिनका layout समय सीमा के साथ अलग thread में बनता है। हज़ारों nodes के लिए sfdp आम तौर पर dot से काफ़ी तेज़ है।

यह क्या नहीं करता

  • 4,096 KB से बड़े ग्राफ का layout नहीं बनता, और 15 सेकंड से ज़्यादा लेने वाला layout रोक दिया जाता है (graphvizPreview.maxSourceKB, graphvizPreview.renderTimeoutSeconds)।
  • image= attributes और HTML labels की तस्वीरें जानबूझकर नहीं बनाई जातीं।
  • हर फ़ाइल का एक ही प्रीव्यू होता है, और restart के बाद प्रीव्यू वापस नहीं खुलते। Problems सिर्फ़ तब दिखते हैं जब प्रीव्यू खुला हो।
  • PDF में standard PDF fonts इस्तेमाल होते हैं, इसलिए Western European टेक्स्ट के बाहर के अक्षर, जैसे Chinese या Cyrillic labels, PDF में "?" दिखते हैं। SVG और PNG में वे ठीक दिखते हैं।

अक्सर पूछे जाने वाले सवाल

क्या यह मुफ़्त है?

लाइव प्रीव्यू, छह engines, क्लिक से लाइन पर जाना और SVG और PNG एक्सपोर्ट मुफ़्त हैं। तीन Pro टूल, PDF export, Export All Graphs in Workspace और Export on Save, हर एक 3 बार मुफ़्त चलते हैं। उसके बाद इनके लिए Zovo Pro चाहिए, जो सभी Zovo एक्सटेंशन के लिए एक बार 19 USD का है।

क्या Graphviz इंस्टॉल करना पड़ेगा?

नहीं। Graphviz 16.1 एक्सटेंशन के अंदर WebAssembly के रूप में है। आपके कंप्यूटर पर कुछ और इंस्टॉल नहीं होता, और यह ऑफ़लाइन काम करता है।

क्या यह Markdown में dot blocks बनाता है?

हाँ। dot, graphviz या gv language वाले fenced blocks VS Code के Markdown preview में बनते हैं।

क्या यह Cursor में चलता है?

हाँ। एक्सटेंशन Open VSX पर है, इसलिए Cursor, Windsurf और VSCodium इसे इंस्टॉल कर सकते हैं।
