VS Code में टाइप करते समय PlantUML diagram का preview देखें

मुफ़्त PlantUML Viewer & Preview इंस्टॉल करें, कोई .puml फ़ाइल या plantuml block वाली Markdown फ़ाइल खोलें और preview बटन पर क्लिक करें। आपके टाइप करते समय diagram आपके code के बगल में बनता है। इसे एक्सटेंशन के अंदर आने वाला PlantUML jar आपकी अपनी Java 11 या नए version से बनाता है, इसलिए कुछ भी server पर नहीं भेजा जाता और Graphviz की ज़रूरत नहीं होती। Preview, zoom, error links और एक diagram को SVG या PNG में save करना मुफ़्त है। Zovo Pro (19 USD, एक बार) तीन टूल जोड़ता है, Export All Diagrams in a Folder, Markdown Diagrams to Images और Compare with a Git Version, और हर टूल 3 बार मुफ़्त चलता है।

VS Code में स्टेप्स

  1. Marketplace से PlantUML Viewer & Preview इंस्टॉल करें, या Ctrl+P (macOS पर Cmd+P) दबाकर ext install zovo.zovo-plantuml-viewer चलाएँ।
  2. पक्का करें कि Java 11 या नया version इंस्टॉल है। एक्सटेंशन उसे सेटिंग plantumlViewer.javaPath में, फिर JAVA_HOME में, फिर PATH पर java में, फिर आम JDK फ़ोल्डरों में ढूँढता है। कुछ न मिले तो preview यह बताता है और "Set the Java path" देता है। "PlantUML: Show Java and Layout Status" दिखाता है कि क्या मिला।
  3. कोई .puml, .plantuml, .iuml, .pu या .wsd फ़ाइल, या ```plantuml block वाली Markdown फ़ाइल खोलें, और editor के ऊपर दाईं ओर preview बटन पर क्लिक करें। PlantUML फ़ाइल में Alt+D भी दबा सकते हैं, या "PlantUML: Open Preview to the Side" चला सकते हैं।
  4. टाइप करें। आपके रुकने के कुछ पल बाद preview फिर से बनता है (default 400 ms, सेटिंग plantumlViewer.renderDelay)। फ़ाइल का हर diagram एक ही preview में दिखता है, और cursor वाले diagram के चारों ओर outline होती है।
  5. Buttons से, Ctrl या Cmd और mouse wheel से, या + और - keys से zoom करें। Panel की चौड़ाई के लिए Fit पर क्लिक करें, और diagram में घूमने के लिए उसे drag करें। Error वाला diagram PlantUML का message और एक "Go to line" link दिखाता है।
  6. सिर्फ़ उस एक diagram को save करने के लिए उसके ऊपर SVG या PNG पर क्लिक करें, या कॉपी करने के लिए Copy SVG पर।

क्या मुफ़्त है और Zovo Pro क्या जोड़ता है

.puml, .plantuml, .iuml, .pu और .wsd फ़ाइलों का और Markdown के plantuml blocks का live preview, zoom और pan, लाइन के link वाले errors, एक diagram को SVG या PNG में save करना, Copy SVG, syntax colours, snippets (seq, classd, activity, mindmap, gantt और दूसरे), folding और comments मुफ़्त हैं। Diagrams आपके कंप्यूटर पर बनते हैं और कभी server पर नहीं भेजे जाते।

जब किसी project के diagrams को docs या slides में डालना हो, तो Export All Diagrams in a Folder एक फ़ोल्डर और उसके subfolders की हर PlantUML फ़ाइल के हर diagram को एक ही run में SVG, PNG या PDF में लिखता है, हर फ़ाइल के बगल में या सब एक फ़ोल्डर में। Error वाले diagrams skip होते हैं और फ़ाइल, लाइन और message के साथ list होते हैं, और बाकी लिखे जाते हैं। आपको हर फ़ाइल खोलकर हर diagram हाथ से save नहीं करना पड़ता।

Export All Diagrams in a Folder का इस्तेमाल (Zovo Pro)

  1. Explorer में किसी फ़ोल्डर पर राइट-क्लिक करके "Zovo Pro: Export all diagrams in a folder" चुनें, preview toolbar की Pro tools row में "Export all diagrams in a folder" पर क्लिक करें, या Command Palette से "PlantUML: Export All Diagrams in a Folder (Pro)" चलाएँ और फ़ोल्डर चुनें।
  2. SVG, PNG या PDF चुनें, फिर "Next to each PlantUML file" या "All in one folder..."।
  3. काम पूरा होने पर एक message बताता है कि कितने diagrams export हुए। Error वाले diagrams की list के लिए "Show errors" पर क्लिक करें, या फ़ाइलें देखने के लिए "Reveal" पर।
  4. Try तभी गिना जाता है जब कम से कम एक image लिखी गई हो। Escape, Cancel या बिना PlantUML फ़ाइलों वाला फ़ोल्डर कोई try नहीं लेता।

Export All Diagrams in a Folder आपके कंप्यूटर पर 3 बार मुफ़्त चलता है, उसके बाद लाइसेंस माँगता है। न कोई पॉप-अप आता है, न कोई काउंटडाउन चलता है।

PlantUML Viewer & Preview क्या करता है

  • Sequence, class, activity, component, state, use case diagrams, mind maps, Gantt charts और bundled PlantUML (MIT build 1.2026.10) के दूसरे @start... blocks।
  • Markdown fences ```plantuml, ```puml और ```uml, अंदर @startuml के साथ या बिना। Preview बटन उस Markdown फ़ाइल पर दिखता है जिसमें कम से कम एक ऐसा block हो।
  • Diagram के फ़ोल्डर, आपके workspace फ़ोल्डरों और plantumlViewer.includePaths से फ़ाइलों का !include, और !include <C4/C4_Container> जैसी standard library, offline। https://raw.githubusercontent.com/... addresses के रूप में लिखे C4, AWS icon और icon-font includes jar के अंदर की copy से पढ़े जाते हैं।
  • Sequence diagrams, mind maps और Gantt charts को layout engine नहीं चाहिए। Class, component, state और use case diagrams dot इंस्टॉल होने पर Graphviz इस्तेमाल करते हैं (plantumlViewer.layout को auto पर रखने पर), और न होने पर PlantUML में बना Smetana engine।
  • Diagrams images के रूप में दिखते हैं, इसलिए diagram के अंदर के links या text editor में code नहीं चला सकते।

यह क्या नहीं करता

  • Java 11 या नया version इंस्टॉल होना चाहिए। एक्सटेंशन Java download नहीं करता।
  • Web addresses से includes मना कर दिए जाते हैं, सिवाय उन C4, AWS icon और icon-font addresses के जिनकी copy jar के अंदर है। AWS icons PlantUML के अंदर वाले AWS icon set (version 20) से आते हैं, इसलिए कोई नया icon अपने नाम के साथ error दिखाता है।
  • PlantUML के MIT build में Ditaa नहीं है और @startmath के लिए LaTeX renderer नहीं है। Ditaa block PlantUML का "not supported" पेज दिखाता है।
  • Graphviz के बिना Smetana class और component diagrams को थोड़ा अलग layout करता है, और बहुत बड़े class diagrams ज़्यादा सटे हुए दिख सकते हैं।
  • 30 सेकंड से ज़्यादा लेने वाला diagram रोक दिया जाता है (सेटिंग plantumlViewer.renderTimeoutSeconds), और images हर side पर 8192 pixels पर काट दी जाती हैं (सेटिंग plantumlViewer.maxImageSize)।

अक्सर पूछे जाने वाले सवाल

क्या यह मुफ़्त है?

Live preview, zoom और pan, error links, एक diagram को SVG या PNG में save करना, syntax colours और snippets मुफ़्त हैं। तीनों Pro टूल, Export All Diagrams in a Folder, Markdown Diagrams to Images और Compare with a Git Version, 3-3 बार मुफ़्त चलते हैं। उसके बाद इनके लिए Zovo Pro चाहिए, जो सभी Zovo एक्सटेंशन के लिए एक बार 19 USD का है।

क्या Java या Graphviz चाहिए?

Java 11 या नया version, हाँ, क्योंकि PlantUML एक Java program है। Graphviz, नहीं। उसके बिना class और component diagrams PlantUML में बना Smetana layout engine इस्तेमाल करते हैं। अगर dot इंस्टॉल है, तो वह इस्तेमाल होता है।

क्या मेरा diagram किसी server पर भेजा जाता है?

नहीं। Bundled PlantUML jar आपके कंप्यूटर पर अपने ALLOWLIST security profile के साथ चलता है, और web addresses से includes मना कर दिए जाते हैं। कोई PlantUML server इस्तेमाल नहीं होता।

क्या यह Cursor में चलता है?

हाँ। Cursor, Windsurf और VSCodium इसे Open VSX से इंस्टॉल करते हैं, जहाँ यह zovo/zovo-plantuml-viewer नाम से है।
