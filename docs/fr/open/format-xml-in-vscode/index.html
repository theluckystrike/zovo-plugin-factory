Formater du XML dans VS Code et y lancer des requêtes XPath

Installez l’extension gratuite XML Formatter & XPath Tools, ouvrez un fichier XML et appuyez sur Shift+Alt+F (Shift+Option+F sur Mac). Seuls les espaces entre les balises changent. Le texte, les sections CDATA, les commentaires, xml:space="preserve" et les valeurs d’attributs restent identiques octet par octet, et un fichier mal formé n’est jamais modifié. Le formatage, Minify XML, XPath 1.0 avec les préfixes d’espaces de noms du fichier, Copy XPath et la vue XML Tree sont gratuits et fonctionnent hors ligne. Étapes dans VS Code

  1. Installez XML Formatter & XPath Tools depuis le Marketplace, ou appuyez sur Ctrl+P (Cmd+P sur macOS) et lancez ext install zovo.zovo-xml-xpath-tools.
  2. Ouvrez un fichier .xml et appuyez sur Shift+Alt+F (Shift+Option+F sur Mac), ou lancez Format Document. Si plusieurs formateurs XML sont installés, VS Code vous demande lequel utiliser. Format Selection fonctionne aussi.
  3. Le formateur suit votre taille de tabulation et votre choix entre tabulations et espaces, et garde les fins de ligne, la marque d’ordre des octets (BOM) et le saut de ligne final. Si le fichier est mal formé, rien ne change et l’erreur s’affiche avec sa ligne et sa colonne.
  4. Pour réduire plutôt la taille du fichier, lancez « XML: Minify XML » sur tout le fichier ou sur une sélection. Les commentaires restent, sauf si vous activez xmlXpathTools.minify.removeComments.
  5. Pour lancer une requête XPath, cliquez sur le bouton de recherche dans la barre de titre de l’éditeur ou lancez « XML: Evaluate XPath… ». Les résultats s’affichent dans XPath Results avec leur ligne. Cliquez sur un résultat pour le sélectionner dans l’éditeur.
  6. Cliquez sur le XPath dans la barre d’état pour copier le chemin de l’élément sous le curseur, avec les positions, avec les attributs id ou name, ou sous une forme portable avec local-name().
  7. Pour un fichier de plus de 50 Mo, faites un clic droit dessus dans l’Explorer et choisissez « Format Large XML File on Disk… ». La commande écrit name.formatted.xml à côté, ou remplace le fichier après votre confirmation.

Ce qui est gratuit et ce qu’ajoute Zovo Pro

Format Document, Format Selection, Minify XML, XPath 1.0, Copy XPath, la vue XML Tree, les erreurs de bonne formation dans Problems et Format Large XML File on Disk sont gratuits. Aucune connexion à un compte n’est demandée, et l’extension ne contient aucun code réseau.

Run XPath on Every XML File in a Folder lance une même requête XPath sur chaque fichier .xml, .xsd, .csproj, .svg, .kml ou d’un type proche dans un dossier, chacun avec ses propres préfixes d’espaces de noms. Les résultats s’ouvrent en CSV (file, line, kind, name, value) pour un tableur, en JSON pour un script ou en rapport Markdown pour une relecture. Vous obtenez la même valeur dans de nombreux fichiers, par exemple chaque artifactId d’un ensemble de fichiers pom.xml, sans les ouvrir un par un.

Utiliser Run XPath on Every XML File in a Folder (Zovo Pro)

  1. Faites un clic droit sur un dossier dans l’Explorer et choisissez « Zovo Pro: Run XPath on Every XML File in a Folder », ou lancez « XML: Run XPath on Every XML File in a Folder (Pro) » depuis la Command Palette et choisissez le dossier.
  2. Ou, après avoir lancé un XPath dans un fichier, cliquez sur la dernière ligne de XPath Results, « Run this XPath on every XML file in a folder », pour lancer la même expression sur un dossier.
  3. Tapez le XPath. Une notification affiche la progression avec un bouton Cancel.
  4. Choisissez « Open as CSV », « Open as JSON » ou « Open a Markdown report ». Les résultats s’ouvrent dans un nouvel onglet de l’éditeur. Un essai ne compte que si vous obtenez un résultat. Escape, une faute de frappe dans le XPath ou un dossier sans fichier XML n’en consomment aucun.

Run XPath on Every XML File in a Folder fonctionne 3 fois sur votre ordinateur avant de demander une licence. Il n’y a ni fenêtre surgissante ni compte à rebours.

Étapes dans Cursor, Windsurf ou VSCodium

  1. Ouvrez la vue Extensions avec Ctrl+Maj+X (Cmd+Maj+X sur macOS).
  2. Cherchez zovo.zovo-xml-xpath-tools et cliquez sur Install. Cursor, Windsurf et VSCodium installent les extensions depuis Open VSX, où celle-ci s’appelle zovo/zovo-xml-xpath-tools.
  3. Si votre éditeur n’a pas de galerie, téléchargez le fichier .vsix sur la page Open VSX et lancez « Extensions: Install from VSIX... ».
  4. Ensuite, tout fonctionne comme dans VS Code.

Ce que fait XML Formatter & XPath Tools

  • Les fichiers que VS Code ouvre en XML. L’extension ouvre aussi en XML les fichiers .kml, .gpx, .rss, .atom, .wsdl, .dbk, .xlf, .xliff, .resx, .nuspec, .props, .targets et .xaml.
  • Les gros fichiers. Le formatage, l’arbre et XPath tournent dans un thread en arrière-plan. Dans les tests de l’extension, un fichier de 49 Mo avec environ 1 million d’éléments a été formaté en 1,6 seconde.
  • Les noms simples correspondent aussi à un espace de noms par défaut, donc //dependency/artifactId fonctionne dans un pom.xml. Activez xmlXpathTools.xpath.strictNamespaces pour un XPath 1.0 strict.
  • Les attributs peuvent rester tels qu’ils sont écrits, tenir sur une ligne ou passer à un attribut par ligne (réglage xmlXpathTools.format.attributes).
  • La vue XML Tree dans l’Explorer suit le curseur, et Problems liste les erreurs de bonne formation avec leur ligne et leur colonne.

Ce qu’il ne fait pas

  • XPath 1.0 uniquement. Il n’y a ni XPath 2.0 ou 3.1, ni XQuery, ni XSLT.
  • L’extension vérifie qu’un fichier est bien formé. Elle ne le valide pas par rapport à un XSD ou une DTD.
  • Les fichiers de plus de 50 Mo peuvent être formatés sur le disque, mais VS Code ne les transmet pas aux extensions, donc l’arbre et XPath ne fonctionnent pas sur eux.
  • La commande sur disque lit l’UTF-8, l’UTF-16 avec marque d’ordre des octets et l’ISO-8859-1.
  • Un élément qui contient du texte, comme <p>Some <b>bold</b> text</p>, reste sur sa ligne tel qu’il est écrit. Seuls les éléments qui contiennent des balises et pas de texte reçoivent de nouveaux sauts de ligne.

Questions fréquentes

Est-ce gratuit ?

Le formatage, Minify XML, XPath, Copy XPath, la vue XML Tree et la vérification de bonne formation sont gratuits. Les trois outils Pro, Run XPath on Every XML File in a Folder, Format All XML Files in a Folder et Compare Two XML Files Ignoring Formatting, ont 3 essais gratuits chacun. Ensuite, ils demandent Zovo Pro, 19 USD une seule fois pour toutes les extensions Zovo.

Le formatage change-t-il mon texte ou mes CDATA ?

Non. Seuls les espaces entre les balises changent, dans les éléments qui contiennent des balises et pas de texte. Le texte, les CDATA, les commentaires et le contenu dans xml:space="preserve" sont copiés tels quels, et un second formatage ne change rien.

Pourquoi mon XPath ne sélectionne rien dans un pom.xml ?

Le fichier a un espace de noms par défaut. Dans cette extension, les noms simples correspondent aussi à un espace de noms par défaut, donc //dependency fonctionne. Activez xmlXpathTools.xpath.strictNamespaces pour un XPath 1.0 strict.

L’extension fonctionne-t-elle dans Cursor ?

Oui. Cursor, Windsurf et VSCodium l’installent depuis Open VSX, où elle est publiée sous le nom zovo/zovo-xml-xpath-tools.
