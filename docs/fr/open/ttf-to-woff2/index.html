Convertir une police TTF en WOFF2 dans VS Code

Installez Font Viewer (TTF, OTF and WOFF viewer). L’extension ouvre gratuitement les polices .ttf, .otf, .woff, .woff2, .ttc et .otc, avec un testeur de texte, une grille des glyphes, une table des caractères et un onglet Info qui montre la licence. L’outil Zovo Pro Convert Font écrit un WOFF2 (ou un WOFF) à côté d’un TTF ou d’un OTF, et peut aussi retransformer un WOFF2 en TTF/OTF installable. Convert Font et Font Folder Report ont 3 essais gratuits chacun, puis Zovo Pro coûte 19 USD, payés une seule fois.

Étapes dans VS Code

  1. Installez Font Viewer depuis le Marketplace, ou appuyez sur Ctrl+P (Cmd+P sur macOS) et lancez ext install zovo.font-viewer-vscode.
  2. Cliquez sur un fichier .ttf ou .otf dans l’Explorer. Il s’ouvre dans Font Viewer, qui est en lecture seule et ne modifie jamais la police. Si un autre éditeur s’ouvre, faites un clic droit sur le fichier et choisissez « Open in Font Viewer ».
  3. Dans l’onglet Type tester, tapez un texte d’exemple, faites glisser le curseur de taille et déplacez les curseurs des axes variables. Activez ou désactivez les fonctionnalités OpenType.
  4. Ouvrez l’onglet Info pour vérifier la licence, le dessinateur et les droits d’incorporation avant de mettre la police sur un site web.
  5. Cliquez sur Copy CSS dans le Type tester pour obtenir la règle @font-face, ou faites un clic droit sur la police dans l’Explorer et choisissez « Copy CSS @font-face ».
  6. Pour créer le fichier WOFF2, lancez Convert Font (un outil Zovo Pro, voir plus bas).

Ce qui est gratuit et ce qu’ajoute Zovo Pro

L’ouverture des polices TTF, OTF, WOFF, WOFF2, TTC et OTC, le testeur avec axes variables et fonctionnalités OpenType, la grille des glyphes, la table des caractères, l’onglet Info avec la licence et Copy CSS @font-face sont gratuits.

Convert Font transforme un TTF ou un OTF en WOFF2 ou en WOFF pour un site web, ou un WOFF2 en TTF/OTF installable. Il traite une police ou un dossier entier, écrit les nouveaux fichiers à côté des sources et produit un fichier par police pour une collection TTC. Les données des tables sont copiées telles quelles, donc les contours, le hinting, les axes variables et les fonctionnalités ne changent pas.

Utiliser Convert Font (Zovo Pro)

  1. Cliquez sur le bouton Convert Font dans la barre de titre de l’onglet de la police, ou faites un clic droit sur un fichier de police ou un dossier dans l’Explorer et choisissez « Convert Font to WOFF2, WOFF or TTF… (Pro) ».
  2. Depuis la Command Palette, lancez « Font Viewer: Convert Font to WOFF2, WOFF or TTF… (Pro) » et choisissez une police ou un dossier.
  3. Choisissez WOFF2. Le nouveau fichier .woff2 est écrit à côté de la source, qui reste telle quelle.
  4. Un essai ne compte que si les fichiers sont écrits.

Convert Font fonctionne 3 fois sur votre ordinateur avant de demander une licence. Il n’y a ni fenêtre surgissante ni compte à rebours.

Étapes dans Cursor, Windsurf ou VSCodium

  1. Ouvrez la vue Extensions avec Ctrl+Maj+X (Cmd+Maj+X sur macOS).
  2. Cherchez zovo.font-viewer-vscode et cliquez sur Install. Cursor, Windsurf et VSCodium installent les extensions depuis Open VSX, où celle-ci s’appelle zovo/font-viewer-vscode.
  3. Si votre éditeur n’a pas de galerie, téléchargez le fichier .vsix sur la page Open VSX et lancez « Extensions: Install from VSIX... ».
  4. Ensuite, tout fonctionne comme dans VS Code.

Ce que fait Font Viewer

  • TrueType .ttf, y compris les polices variables, et OpenType .otf à contours CFF.
  • Polices WOFF .woff et WOFF2 .woff2.
  • Collections .ttc et .otc, avec le choix de la police dans une liste de l’en-tête.
  • Chaque glyphe avec son nom et son point de code, la recherche par nom, caractère, U+20AC ou identifiant de glyphe, et la copie du contour en SVG.
  • La couverture des blocs Unicode, la table name complète, les métriques, les axes et les balises de fonctionnalités GSUB et GPOS.

Ce qu’il ne fait pas

  • Les collections WOFF2, les polices SVG, les .dfont et les polices Type 1 ne sont pas prises en charge.
  • Les fichiers de plus de 64 Mo (réglage fontViewer.maxFileMB) affichent un message au lieu de s’ouvrir.
  • Les contours des glyphes montrent l’instance par défaut d’une police variable. Le testeur, la cascade (waterfall) et la table des caractères suivent les curseurs des axes.
  • Les polices couleur sont dessinées en couleur dans le testeur et la table des caractères, mais la grille des glyphes montre des contours simples. Les polices variables CFF2 sont dessinées avec la police elle-même dans la grille des glyphes, pas à partir des contours.
  • Convert Font copie les données des tables telles quelles. Les outils qui réécrivent aussi les données des glyphes produisent des WOFF2 plus petits de quelques pour cent.

Questions fréquentes

Est-ce gratuit ?

L’affichage des polices est gratuit : le testeur, les glyphes, la table des caractères, l’onglet Info et Copy CSS @font-face. Convert Font et Font Folder Report sont des outils Pro avec 3 essais gratuits chacun, puis Zovo Pro coûte 19 USD, payés une seule fois pour toutes les extensions Zovo.

Un WOFF2 est-il beaucoup plus petit ?

Dans le test du README, le WOFF2 faisait environ 45 % de la taille du TTF (JetBrains Mono variable, de 96 940 à 43 632 octets).

La conversion modifie-t-elle la police ?

Non. Les données des tables sont copiées telles quelles, donc les contours, le hinting, les axes variables et les fonctionnalités restent identiques. Le fichier source n’est pas modifié.

Mes polices sont-elles envoyées en ligne ?

Non. Font Viewer fonctionne hors ligne, ne fait aucun appel réseau et n’envoie aucune télémétrie.
