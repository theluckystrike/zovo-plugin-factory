Ouvrir un fichier Word .docx dans VS Code

VS Code n'a pas de lecteur Word : un .docx s'ouvre avec un message indiquant que le fichier est binaire. Installez l'extension gratuite DOCX Viewer et cliquez de nouveau sur le fichier. Il s'ouvre en aperçu, en lecture seule, aux couleurs de votre thème, avec le plan du document, la recherche, les tableaux, les graphiques et les équations. Ni Office ni LibreOffice ne sont nécessaires, et rien ne part sur Internet.

Les étapes dans VS Code

  1. Installez l'extension DOCX Viewer depuis le Marketplace, ou appuyez sur Ctrl+P (Cmd+P sur macOS) et tapez ext install zovo.docx-viewer-vscode.
  2. Cliquez sur un fichier .docx, .dotx ou .docm dans l'Explorer. Les fichiers OpenDocument (.odt) et les anciens .doc de Word 97-2003 s'ouvrent aussi, les .doc en texte seul.
  3. Appuyez sur Ctrl+F (Cmd+F sur macOS) pour chercher. Le compteur indique le nombre de correspondances, et le plan mène directement à n'importe quel titre.
  4. Le bouton de thème passe des couleurs de l'éditeur au papier blanc. « Page view » montre les pages telles que Word les met en page, avec marges, en-têtes et pieds de page, et « Reading view » revient au texte continu.
  5. Si le document contient des modifications suivies ou des commentaires, une barre en haut les compte. Markup, Final et Original affichent le texte avec les marques, accepté ou refusé, sans toucher au fichier.
  6. Pour voir ce qui a changé entre deux versions, faites un clic droit sur le fichier et choisissez « Compare with Git HEAD » ou « Compare Documents (Redline)... ». La comparaison à l'écran est gratuite.

Ce qui est gratuit, et ce que Zovo Pro ajoute

La lecture, Page view, la recherche, le plan, les modifications suivies et les commentaires, Copy as Markdown et la comparaison de deux versions à l'écran sont gratuits, sans compte.

Quand quelqu'un doit relire les changements dans Word, Export Redline as Word enregistre un nouveau .docx où chaque différence entre les deux versions devient une vraie modification suivie, signée « Compare ». Word et LibreOffice peuvent les accepter ou les refuser une par une. Zovo Pro exporte aussi la comparaison en un seul fichier HTML, enregistre la liste des changements dans un classeur Excel et compare deux dossiers de documents.

Avec Export Redline as Word (Zovo Pro)

  1. Document ouvert, lancez « Export Redline as Word (Pro)... » depuis la palette de commandes, ou faites un clic droit sur le fichier dans l'Explorer.
  2. Choisissez l'autre version du document.
  3. Choisissez où enregistrer. Les deux documents d'origine ne sont pas modifiés.

Export Redline as Word fonctionne 3 fois sur votre ordinateur avant de demander une licence, et un essai ne compte que si vous obtenez un résultat. Rien ne parle de Pro quand vous ouvrez un fichier.

Dans Cursor, Windsurf ou VSCodium

Ces éditeurs installent leurs extensions depuis Open VSX. Ouvrez la vue Extensions (Ctrl+Shift+X, ou Cmd+Shift+X sur macOS), cherchez zovo.docx-viewer-vscode et cliquez sur Install. La suite se passe comme dans VS Code.

Ce qu'elle ne fait pas

  • C'est un lecteur. Il ne modifie pas et n'enregistre pas le document.
  • Les anciens fichiers .doc s'affichent en texte seul, sans mise en forme ni images.
  • Les SmartArt ne s'affichent pas, et un fichier protégé par mot de passe affiche un message à la place du contenu.

Questions fréquentes

Faut-il Microsoft Office ?

Non. L'extension lit le fichier elle-même, dans VS Code ou Cursor, et fonctionne hors ligne.

L'extension est-elle payante ?

Non. Lire, chercher et comparer à l'écran est gratuit. Seuls les exports et la comparaison de dossiers font partie de Zovo Pro (USD 19 une fois), avec 3 essais gratuits chacun.

Ça marche dans le navigateur ?

Oui. Dans vscode.dev et github.dev, cliquez sur un .docx d'un dépôt GitHub pour le lire sans le cloner.
