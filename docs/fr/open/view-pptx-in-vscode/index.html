Voir des diapositives PowerPoint .pptx dans VS Code

L'extension gratuite PPTX Viewer ouvre les présentations PowerPoint directement dans VS Code : .pptx, .ppsx, .potx, .pptm et les anciens .ppt, avec vignettes, notes du présentateur, recherche et bouton Present. Pratique pour relire un deck qu'un script, python-pptx ou un agent IA vient de générer : la diapositive se recharge à chaque enregistrement du fichier. Sans PowerPoint, sans LibreOffice, sans envoi en ligne.

Les étapes dans VS Code

  1. Installez l'extension PPTX Viewer depuis le Marketplace, ou appuyez sur Ctrl+P (Cmd+P sur macOS) et tapez ext install zovo.pptx-slide-viewer.
  2. Cliquez sur un fichier .pptx, .ppsx, .potx, .pptm ou .ppt dans l'Explorer. Les diapositives s'affichent avec les vignettes et, en dessous, les notes du présentateur.
  3. Appuyez sur Ctrl+F (Cmd+F sur macOS) pour chercher dans les titres, les puces, les tableaux et les notes de tout le deck. L'onglet Outline liste les diapositives trouvées, et Entrée passe à la suivante.
  4. Cliquez sur Present pour afficher une diapositive à la fois en plein écran. Les flèches, la barre d'espace ou un clic font avancer, Échap rend l'éditeur.
  5. Copy: « PNG » copie la diapositive en image (environ 1920 pixels de large) pour une pull request ou un ticket. Copy: « Markdown » copie la diapositive en Markdown, et « All » tout le deck.
  6. Laissez le deck ouvert pendant qu'un script le régénère : à chaque enregistrement, la diapositive se met à jour en une seconde environ, sans changer de page.

Ce qui est gratuit, et ce que Zovo Pro ajoute

L'affichage des diapositives, Present, les notes du présentateur, la recherche, les vignettes et le plan, la copie ou l'enregistrement d'une diapositive en PNG et Copy as Markdown sont gratuits.

Pour envoyer le deck à quelqu'un qui n'a pas PowerPoint, Export Deck as PDF enregistre un PDF avec une page par diapositive, au format de la diapositive. Les pages sont des images des diapositives, donc le texte du PDF ne se sélectionne pas. Zovo Pro exporte aussi toutes les diapositives en PNG, convertit un dossier de decks en Markdown avec les notes, et enregistre une copie plus légère d'un deck chargé de photos (Compress Deck).

Avec Export Deck as PDF (Zovo Pro)

  1. Deck ouvert, cliquez sur Export dans la barre d'outils et choisissez le PDF, ou lancez « Export Deck as PDF (Pro)... » depuis la palette de commandes.
  2. Choisissez où enregistrer le PDF.
  3. Le deck d'origine n'est pas modifié, et les images sont produites sur votre ordinateur.

Export Deck as PDF fonctionne 3 fois sur votre ordinateur avant de demander une licence, et un essai ne compte que si vous obtenez un résultat. Rien ne parle de Pro quand vous ouvrez un fichier.

Dans Cursor, Windsurf ou VSCodium

Ces éditeurs installent leurs extensions depuis Open VSX. Ouvrez la vue Extensions (Ctrl+Shift+X, ou Cmd+Shift+X sur macOS), cherchez zovo.pptx-slide-viewer et cliquez sur Install. La suite se passe comme dans VS Code.

Ce qu'elle ne fait pas

  • C'est un lecteur. Il ne modifie pas les diapositives.
  • Les anciens .ppt s'ouvrent en texte seul : titres, texte des diapositives et notes, sans images ni mise en page.
  • La vidéo, l'audio et les objets incorporés ne sont pas dessinés, et la diapositive indique ce qui manque.
  • Une police absente de votre machine est remplacée par une police proche, les retours à la ligne peuvent donc varier un peu.

Questions fréquentes

L'extension est-elle payante ?

Non. Afficher, présenter, chercher et copier des diapositives est gratuit. Seuls les exports, la compression et la comparaison de decks font partie de Zovo Pro (USD 19 une fois), avec 3 essais gratuits chacun.

Ça marche avec Remote SSH, WSL ou Codespaces ?

Oui. L'extension lit le fichier via VS Code, donc elle fonctionne aussi avec Remote SSH, WSL, Dev Containers et Codespaces.

Le fichier est-il envoyé quelque part ?

Non. Tout se passe sur votre machine, sans télémétrie.
