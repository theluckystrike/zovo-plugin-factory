Formater HTML et CSS dans VS Code sans casser les blocs pre ni les balises inline

Installez l’extension gratuite HTML Formatter & CSS Formatter et appuyez sur Shift+Alt+F dans un fichier HTML, CSS, SCSS ou LESS. Elle formate aussi les blocs <style> et <script> d’une page, suit votre .editorconfig, laisse <pre>, <textarea> et les balises inline tels que vous les avez écrits, et ne change jamais l’ordre des attributs. Elle fonctionne hors ligne avec un js-beautify intégré, donc sans Node, sans npm et sans fichier de configuration. Zovo Pro (19 USD, payés une seule fois) ajoute trois outils, Format Folder with Diff Preview, Minify HTML and CSS et HTML Lint Report, avec 3 essais gratuits pour chacun.

Étapes dans VS Code

  1. Installez HTML Formatter & CSS Formatter depuis le Marketplace, ou appuyez sur Ctrl+P (Cmd+P sur macOS) et lancez ext install zovo.zovo-html-formatter.
  2. Ouvrez un fichier HTML, CSS, SCSS ou LESS et appuyez sur Shift+Alt+F (Shift+Option+F sur macOS). Si VS Code demande quel formateur utiliser, choisissez HTML Formatter & CSS Formatter.
  3. Pour en faire le formateur par défaut des quatre langages en une seule étape, lancez « HTML Formatter: Use as Default Formatter for HTML, CSS, SCSS and LESS » depuis la Command Palette.
  4. Sélectionnez quelques lignes et lancez Format Selection pour ne formater qu’elles.
  5. Pour formater à chaque enregistrement, activez zovoHtmlFormat.formatOnSave, ou utilisez le réglage editor.formatOnSave de VS Code une fois l’extension définie comme formateur par défaut.
  6. L’indentation vient de l’éditeur, puis de .editorconfig (style et taille d’indentation, fin de ligne, saut de ligne final, longueur maximale de ligne). Toute l’équipe obtient donc le même résultat.

Quand tout un site doit suivre le même style, Format Folder with Diff Preview formate en mémoire chaque fichier HTML, CSS, SCSS et LESS d’un dossier, affiche les fichiers modifiés avec un diff côte à côte pour chacun, et n’écrit que les fichiers que vous laissez cochés. Vous voyez chaque modification avant qu’un fichier soit écrit.

Étapes dans Cursor, Windsurf ou VSCodium

  1. Ouvrez la vue Extensions avec Ctrl+Maj+X (Cmd+Maj+X sur macOS).
  2. Cherchez zovo.zovo-html-formatter et cliquez sur Install. Cursor, Windsurf et VSCodium installent les extensions depuis Open VSX, où celle-ci s’appelle zovo/zovo-html-formatter.
  3. Si votre éditeur n’a pas de galerie, téléchargez le fichier .vsix sur la page Open VSX et lancez « Extensions: Install from VSIX... ».
  4. Ensuite, tout fonctionne comme dans VS Code.

Ce que fait HTML Formatter & CSS Formatter

  • Le CSS dans <style> et le JavaScript dans <script> à l’intérieur du HTML.
  • Restent tels que vous les avez écrits : le contenu de <pre> et de <textarea>, les balises inline sur leur ligne, l’ordre des attributs, les lignes vides entre les blocs (une au plus d’affilée), le style d’indentation de head et body de la page, et les balises de template comme {{ }} et {% %}.
  • En SCSS et LESS, les maps et les appels de fonction sur plusieurs lignes gardent leur mise en page, et les commentaires de fin de ligne restent sur leur ligne.
  • Les deux autres outils Pro. Minify HTML and CSS écrit des copies .min.html et .min.css avec un rapport des octets et des octets gzip économisés. HTML Lint Report trouve les images sans texte alt, les champs de formulaire sans label, les id en double, les niveaux de titre sautés et d’autres problèmes, dans un rapport Markdown et dans le panneau Problems.

Ce qu’il ne fait pas

  • Les fichiers .js, .jsx, .ts, Vue et Svelte autonomes ne sont pas formatés par cette extension. Seul le JavaScript placé dans <script> l’est.
  • Les lignes ne sont pas coupées tant que vous ne définissez pas de longueur de retour à la ligne. Une très longue ligne reste donc longue.
  • SCSS et LESS passent par le formateur CSS. Une syntaxe inhabituelle, comme les detached rulesets de LESS, peut garder son espacement d’origine.
  • La minification ne raccourcit pas le JavaScript et ne renomme ni ne fusionne les règles CSS.

Questions fréquentes

Est-ce gratuit ?

Format Document, Format Selection et le formatage à l’enregistrement pour HTML, CSS, SCSS et LESS sont gratuits. Les trois outils Pro, Format Folder with Diff Preview, Minify HTML and CSS et HTML Lint Report, ont chacun 3 essais gratuits. Ensuite, il faut Zovo Pro, 19 USD payés une seule fois pour toutes les extensions Zovo.

VS Code formate-t-il le HTML sans extension ?

Oui. VS Code a un formateur HTML et CSS intégré. Cette extension lit .editorconfig, garde l’indentation propre à head et body de la page, garde la mise en page des maps SCSS et LESS, et ajoute les outils Pro pour les dossiers, la minification et le lint.

Va-t-elle modifier mes blocs pre ou réordonner les attributs ?

Non. Le contenu de pre et de textarea, les balises inline et l’ordre des attributs restent comme vous les avez écrits.

Faut-il Node ou npm ?

Non. js-beautify 1.15.4 est intégré à l’extension et fonctionne hors ligne.
