Convertir un fichier PDF, Word, PowerPoint ou Excel en Markdown dans VS Code

Installez l’extension gratuite Convert to Markdown, faites un clic droit sur un fichier PDF, Word, PowerPoint, Excel, CSV, HTML, EPUB, ODT ou RTF dans l’Explorer et choisissez Convert to Markdown. Étapes dans VS Code

  1. Installez Convert to Markdown depuis le Marketplace, ou appuyez sur Ctrl+P (Cmd+P sur macOS) et lancez ext install zovo.zovo-convert-to-markdown.
  2. Dans l’Explorer, faites un clic droit sur un fichier .pdf, .docx, .pptx, .xlsx, .xls, .ods, .csv, .tsv, .html, .epub, .odt ou .rtf et choisissez Convert to Markdown. Vous pouvez aussi faire un clic droit sur l’onglet d’un fichier ouvert.
  3. Ou lancez « Convert to Markdown: Convert to Markdown » depuis la Command Palette. La commande convertit le fichier de l’onglet actif, ou vous en demande un.
  4. Le Markdown s’ouvre à côté du fichier, dans un document non enregistré. Pour les gros fichiers, une progression s’affiche avec un bouton Cancel.
  5. Enregistrez le document. Le nom name.md, à côté du fichier source, est déjà rempli. Pour l’enregistrer directement à cet endroit à chaque fois, réglez toMarkdown.output sur file.
  6. Pour coller le Markdown ailleurs, faites un clic droit sur le fichier et choisissez Copy as Markdown. Si vous sélectionnez plusieurs fichiers dans l’Explorer, ils sont convertis l’un après l’autre.
  7. Pas de fichier sous la main ? Lancez « Convert to Markdown: Convert a sample file » depuis la Command Palette pour convertir un exemple Word, PDF ou PowerPoint fourni avec l’extension.

Ce qui est gratuit et ce qu’ajoute Zovo Pro

Convert to Markdown et Copy as Markdown sont gratuits pour tous les formats : PDF, Word, PowerPoint, Excel, ODS, CSV, TSV, HTML, EPUB, ODT et RTF. Vous n’installez rien d’autre, ni Python, ni serveur, ni outil en ligne de commande. Rien ne quitte votre ordinateur.

Convert a Folder to Markdown convertit en une seule fois chaque fichier pris en charge d’un dossier et de ses sous-dossiers en fichiers .md, dans un nouveau dossier qui reprend la même structure ou à côté de chaque fichier, avec une progression et Cancel. Vous choisissez d’ignorer ou d’écraser les fichiers .md qui existent déjà, et _conversion-report.md indique pour chaque fichier s’il a été converti, ignoré ou s’il a échoué. Les fichiers qui portent le même nom gardent leur type dans le nouveau nom (report.pdf.md, report.docx.md), donc aucun n’est perdu.

Utiliser Convert a Folder to Markdown (Zovo Pro)

  1. Faites un clic droit sur un dossier dans l’Explorer et choisissez « Zovo Pro: Convert a Folder to Markdown », ou lancez « Convert to Markdown: Convert a Folder to Markdown (Pro) » depuis la Command Palette et choisissez le dossier.
  2. Choisissez où vont les fichiers .md : « Into a new folder » (le nom du dossier suivi de -markdown, avec les mêmes sous-dossiers), « Next to each file » ou « Pick another folder... ».

Étapes dans Cursor, Windsurf ou VSCodium

  1. Ouvrez la vue Extensions avec Ctrl+Maj+X (Cmd+Maj+X sur macOS).
  2. Cherchez zovo.zovo-convert-to-markdown et cliquez sur Install. Cursor, Windsurf et VSCodium installent les extensions depuis Open VSX, où celle-ci s’appelle zovo/zovo-convert-to-markdown.
  3. Si votre éditeur n’a pas de galerie, téléchargez le fichier .vsix sur la page Open VSX et lancez « Extensions: Install from VSIX... ».
  4. Ensuite, tout fonctionne comme dans VS Code.

Ce que fait Convert to Markdown

  • Les PDF, avec les titres déduits des tailles de police, les lignes coupées et les mots coupés en fin de ligne rassemblés en paragraphes, les listes, les tableaux simples et les pages à deux colonnes lues colonne par colonne. Les en-têtes, pieds de page et numéros de page répétés sont supprimés.
  • Word (.docx, .docm, .dotx), avec les titres, le gras, l’italique, le barré, les liens, les listes imbriquées, les tableaux, les citations et les notes de bas de page.
  • PowerPoint (.pptx, .pptm, .ppsx, .potx), avec une section ## Slide n: title par diapositive, les puces et leurs niveaux, les tableaux et les notes de l’orateur.
  • Excel et les autres tableurs (.xlsx, .xlsm, .xlsb, .xls, .ods), avec une section ## Sheet: name et un tableau à barres verticales par feuille. Un fichier CSV ou TSV donne un seul tableau.
  • HTML (.html, .htm, .xhtml), où les blocs de code gardent leur langage et où les scripts et les styles sont supprimés, et EPUB, avec chaque chapitre dans l’ordre de lecture.

Ce qu’il ne fait pas

  • Les PDF scannés (des images de pages) n’ont pas de texte à convertir. La reconnaissance de texte (OCR) n’est pas incluse.
  • Les tableaux des PDF sont repérés grâce aux espaces entre les colonnes. Un tableau sans espaces nets sort sous forme de paragraphes.
  • Dans la conversion gratuite, les images deviennent des repères comme *[Image: Map of the site]*. Les graphiques, SmartArt et vidéos des diapositives sont nommés, pas convertis.
  • Les anciens fichiers Word 97-2003 et le RTF donnent le texte et les tableaux sans mise en forme. Les fichiers protégés par mot de passe et les anciens PowerPoint 97-2003 reçoivent un message au lieu d’une conversion.
  • Les fichiers de plus de 200 Mo ne sont pas convertis (réglage toMarkdown.maxFileSizeMB), et un PDF s’arrête après 1 000 pages (réglage toMarkdown.pdfMaxPages).

Questions fréquentes

Est-ce gratuit ?

Convert to Markdown et Copy as Markdown sont gratuits pour tous les formats. Les trois outils Pro, Convert a Folder to Markdown, Convert to Markdown with Images et LLM-ready Markdown Chunks, ont 3 essais gratuits chacun. Ensuite, ils demandent Zovo Pro, 19 USD une seule fois pour toutes les extensions Zovo.

Mes fichiers sont-ils envoyés en ligne ?

Non. Les convertisseurs tournent sur votre ordinateur, dans VS Code, sans appel réseau et sans télémétrie.

L’extension convertit-elle les PDF scannés ?

Non. Un PDF scanné contient des images de pages, pas du texte, et Convert to Markdown n’a pas d’OCR.

L’extension fonctionne-t-elle dans Cursor ?

Oui. Cursor, Windsurf et VSCodium l’installent depuis Open VSX, où elle est publiée sous le nom zovo/zovo-convert-to-markdown.
