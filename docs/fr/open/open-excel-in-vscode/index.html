Ouvrir Excel et CSV dans VS Code sous forme de tableau

VS Code ouvre un .xlsx comme un fichier binaire et un CSV comme du texte brut. L'extension gratuite Table Viewer affiche les classeurs Excel, les CSV et les fichiers Parquet en tableau que l'on trie, filtre et fouille, jusqu'à 1 000 000 de lignes, avec les formats de nombre d'Excel et les formules. Le bouton Query lance du SQL avec GROUP BY sur le fichier. Sans Excel, sans Python, et rien ne passe par le réseau.

Les étapes dans VS Code

  1. Installez l'extension Table Viewer depuis le Marketplace, ou appuyez sur Ctrl+P (Cmd+P sur macOS) et tapez ext install zovo.table-viewer-vscode.
  2. Cliquez sur un fichier .xlsx, .xlsm, .xlsb, .xls, .ods ou .parquet dans l'Explorer. Il s'ouvre en tableau. Un classeur à plusieurs feuilles affiche un sélecteur de feuille.
  3. Un .csv ou un .tsv s'ouvre toujours en texte. Cliquez sur l'icône de tableau en haut à droite de l'éditeur, ou faites un clic droit sur le fichier et choisissez « Open in Table Viewer ».
  4. Cliquez sur l'en-tête d'une colonne pour trier. Tapez dans la case sous l'en-tête pour filtrer : >10, 5..9 ou un morceau de texte. La recherche en haut regarde dans toutes les colonnes.
  5. Cliquez sur Query, écrivez un SELECT et appuyez sur Ctrl+Entrée (Cmd+Entrée sur macOS). FROM this désigne le fichier ouvert, et une jointure avec une autre feuille du même classeur est gratuite.
  6. Copy CSV, Copy JSON et Copy Markdown copient la sélection. Export enregistre les lignes filtrées en CSV, TSV, JSON ou JSON Lines.

Ce qui est gratuit, et ce que Zovo Pro ajoute

L'ouverture des CSV, TSV, Excel et Parquet, les feuilles, les formules, le tri, les filtres, la recherche, les statistiques de colonnes, le filtre SQL, les requêtes SQL sur les lignes du tableau, la jointure entre feuilles du même classeur, la comparaison avec Git et l'export en CSV, TSV et JSON sont gratuits.

Quand les données arrivent en plusieurs fichiers, un par mois ou un par agence, Combine Files and Sheets réunit plusieurs CSV, TSV, Excel, ODS et Parquet, un dossier entier ou toutes les feuilles d'un classeur en un seul fichier CSV, XLSX ou Parquet. Les colonnes sont rapprochées par le nom de l'en-tête, et les colonnes source_file et source_sheet indiquent d'où vient chaque ligne. Zovo Pro lance aussi les requêtes sur le fichier entier quand le tableau n'en contient que le début (un GROUP BY sur un CSV de plusieurs Go), fait des jointures avec d'autres fichiers et enregistre en Parquet.

Avec Combine Files and Sheets (Zovo Pro)

  1. Dans l'Explorer, faites un clic droit sur un dossier, sur plusieurs fichiers de tableau sélectionnés ou sur un classeur, et choisissez Combine Files and Sheets. Le bouton Combine de la barre d'outils et « Excel Viewer Pro: Combine Files and Sheets (Pro)... » dans la palette de commandes font la même chose.
  2. Choisissez le format de sortie (CSV, XLSX ou Parquet) et l'emplacement.
  3. Les fichiers illisibles sont ignorés et listés dans le résumé. Les fichiers source ne changent pas.

Combine Files and Sheets fonctionne 3 fois sur votre ordinateur avant de demander une licence, et un essai ne compte que si vous obtenez un résultat. Rien ne parle de Pro quand vous ouvrez un fichier.

Dans Cursor, Windsurf ou VSCodium

Ces éditeurs installent leurs extensions depuis Open VSX. Ouvrez la vue Extensions (Ctrl+Shift+X, ou Cmd+Shift+X sur macOS), cherchez zovo.table-viewer-vscode et cliquez sur Install. La suite se passe comme dans VS Code.

Ce qu'elle ne fait pas

  • L'extension ne fait que lire. Elle ne modifie pas et n'enregistre pas le classeur.
  • Par défaut, elle charge jusqu'à 1 000 000 de lignes par fichier (réglage tableViewer.maxRows).
  • Les fichiers .xls, .xlsb et .ods de plus de 50 Mo ne se chargent pas.
  • Une requête sur tout un CSV plus grand que le tableau, la jointure avec d'autres fichiers et l'enregistrement en Parquet font partie de Zovo Pro, avec 3 essais gratuits chacun.

Questions fréquentes

Faut-il Excel ou Python ?

Non. L'extension est écrite en JavaScript, fonctionne hors ligne, sans noyau Python et sans compte.

Le SQL est-il payant ?

Non. Les requêtes sur les lignes du tableau, le filtre SQL et la jointure entre feuilles du même classeur sont gratuits. Lire tout un gros fichier et joindre d'autres fichiers font partie de Zovo Pro, avec 3 essais gratuits.

Le tableau se met-il à jour quand le fichier change ?

Oui. Quand un script ou un git pull réécrit le fichier, le tableau se recharge en une demi-seconde environ et garde le tri et les filtres.
