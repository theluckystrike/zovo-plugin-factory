DXF en CSV dans VS Code : extraire les attributs de blocs et les textes

Installez DXF Viewer & File Preview for 2D CAD Drawings (zovo.dxf-viewer) et cliquez sur le fichier .dxf pour voir ses feuilles, ses calques et ses textes. L’affichage, les calques, la recherche de texte, la mesure et l’export PNG ou SVG sont gratuits. Extract drawing data est un outil Zovo Pro qui enregistre un CSV avec les attributs de blocs (une ligne par insertion, une colonne par étiquette), le nombre d’insertions de chaque bloc, tous les textes avec leur calque et leur position, ou la liste des calques. Il a 3 essais gratuits sur votre ordinateur, puis Zovo Pro coûte 19 USD, payés une seule fois pour toutes les extensions Zovo.

Étapes dans VS Code

  1. Installez DXF Viewer depuis le Marketplace, ou appuyez sur Ctrl+P (Cmd+P sur macOS) et lancez ext install zovo.dxf-viewer.
  2. Cliquez sur le fichier .dxf dans l’Explorer. Le panneau latéral liste les calques avec leur couleur et leur nombre d’entités, un tableau des types d’entités (espace objet et intérieur des blocs) et les informations du dessin, dont le nombre de blocs.
  3. Appuyez sur Ctrl+F (Cmd+F sur Mac) et tapez un numéro de repère ou une valeur d’attribut pour vérifier que la donnée est bien dans le dessin. Entrée passe à l’occurrence suivante.
  4. Lancez « DXF Viewer: Extract Block Attributes, Text or Layers to CSV (Zovo Pro) » depuis la Command Palette ou depuis le menu ... du dessin ouvert. Vous pouvez aussi faire un clic droit sur le fichier .dxf dans l’Explorer et choisir « Zovo Pro: Extract drawing data to CSV ».
  5. Dans la liste « What should the CSV file hold? », choisissez Block attributes, Block counts, All text ou Layers.
  6. Choisissez un nom de fichier dans la boîte d’enregistrement. Un message indique le nombre de lignes enregistrées. Ouvrez le CSV dans Excel ou Google Sheets.

Ce qui est gratuit et ce qu’ajoute Zovo Pro

L’ouverture des fichiers DXF est gratuite et le restera, avec les feuilles de l’espace papier, les calques, la recherche de texte, la mesure, le rechargement en direct et l’export PNG ou SVG. Le panneau latéral avec les calques, les types d’entités et les informations du dessin est gratuit aussi.

Extract drawing data enregistre les données du dessin que vous copieriez sinon à la main dans un tableur : les attributs de blocs avec une ligne par insertion et une colonne par étiquette (comme une nomenclature de portes ou d’équipements), le nombre d’insertions de chaque bloc pour une liste de matériel, tous les textes avec leur calque et leur position, ou la liste des calques. Il fonctionne sur un dessin ou sur tous les fichiers .dxf d’un dossier et de ses sous-dossiers, et avec plusieurs dessins le CSV reçoit une colonne File. Il lit seulement les fichiers sur votre ordinateur et n’écrit jamais dans un dessin.

Utiliser Extract drawing data (Zovo Pro)

  1. Pour un dessin, ouvrez le fichier .dxf et lancez « DXF Viewer: Extract Block Attributes, Text or Layers to CSV (Zovo Pro) » depuis la Command Palette, ou cliquez sur « Extract drawing data to CSV » dans la petite ligne Zovo Pro en haut de la visionneuse.
  2. Pour un dossier, faites un clic droit sur le dossier dans l’Explorer et choisissez « Extract Block Attributes, Text or Layers to CSV (Zovo Pro) ». Chaque fichier .dxf du dossier et de ses sous-dossiers est lu.
  3. Choisissez le contenu du CSV et enregistrez le fichier. Un essai ne compte que si le fichier CSV a été enregistré, donc Cancel ou Échap ne coûte rien.
  4. Après les 3 essais gratuits, l’outil affiche les moyens d’obtenir Zovo Pro.

Étapes dans Cursor, Windsurf ou VSCodium

  1. Ouvrez la vue Extensions avec Ctrl+Maj+X (Cmd+Maj+X sur macOS).
  2. Cherchez zovo.dxf-viewer et cliquez sur Install. Cursor, Windsurf et VSCodium installent les extensions depuis Open VSX, où celle-ci s’appelle zovo/dxf-viewer.
  3. Si votre éditeur n’a pas de galerie, téléchargez le fichier .vsix sur la page Open VSX et lancez « Extensions: Install from VSIX... ».
  4. Ensuite, tout fonctionne comme dans VS Code.

Ce que fait DXF Viewer

  • Les attributs de blocs, avec une ligne par insertion de bloc (Block, Layer, X, Y, Rotation, Space et Handle), puis une colonne par étiquette d’attribut.
  • Le nombre d’insertions de chaque bloc, dans l’espace objet et dans l’espace papier, avec ses calques et ses étiquettes d’attribut.
  • Tous les textes, soit TEXT, MTEXT, attributs et valeurs de cotes, avec type, calque, X, Y, hauteur, bloc et étiquette.
  • Les calques, avec le nombre d’entités, la couleur (ACI), l’état activé ou désactivé et le gel.
  • Le DXF ASCII et binaire, des fichiers R12 aux fichiers AutoCAD 2018, avec blocs et insertions imbriquées.

Ce qu’il ne fait pas

  • Le DWG n’est pas pris en charge. Quand vous cliquez sur un fichier .dwg, l’extension affiche une page avec la version du DWG et la façon d’en enregistrer une copie DXF. Le convertisseur gratuit ODA File Converter convertit tout un dossier de fichiers DWG en une fois.
  • Le CSV contient les attributs de blocs, le nombre de blocs, les textes ou les calques. Ce n’est pas une liste des coordonnées de chaque ligne et de chaque polyligne.
  • Les fichiers de plus de 500 Mo ne sont pas lus (réglage dxfViewer.maxFileMB, jusqu’à 2048).
  • Un traitement de dossier lit au plus 5 000 dessins et ignore les dossiers node_modules, .git, .svn et .hg.
  • La visionneuse est en lecture seule. La boîte d’enregistrement refuse les noms de fichiers qui se terminent par .dxf ou .dwg, donc un dessin n’est jamais écrasé.

Questions fréquentes

Est-ce gratuit ?

L’affichage des fichiers DXF, les calques, les feuilles, la recherche de texte, la mesure et l’export PNG ou SVG sont gratuits. Extract drawing data, Compare drawings et Folder inventory sont des outils Zovo Pro. Chaque outil Pro a 3 essais gratuits sur votre ordinateur, puis Zovo Pro coûte 19 USD, payés une seule fois pour toutes les extensions Zovo.

Peut-on extraire les attributs d’un fichier DWG ?

Pas directement, car le DWG n’est pas pris en charge. Enregistrez une copie DXF depuis votre logiciel de CAO, ou convertissez les fichiers DWG avec le convertisseur gratuit ODA File Converter, puis ouvrez le DXF.

Excel affichera-t-il correctement les accents et les formules ?

Le CSV commence par une marque d’ordre des octets UTF-8 (BOM), donc Excel lit correctement les accents et les textes non latins. Une cellule qui commence par =, +, - ou @ reçoit une apostrophe au début, pour qu’Excel ne l’exécute pas comme une formule.

Est-ce que ça marche dans Cursor ?

Oui. L’extension est publiée sur Open VSX sous le nom zovo/dxf-viewer, elle s’installe donc dans Cursor, Windsurf et VSCodium.
