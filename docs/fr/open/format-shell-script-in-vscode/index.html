Formater un script bash ou zsh dans VS Code

Installez l’extension gratuite Shell Formatter for Bash & Zsh, ouvrez un script shell et appuyez sur Shift+Alt+F (Shift+Option+F sur Mac). Le moteur shfmt 3.14.1 est livré dans l’extension en WebAssembly, il n’y a donc rien à télécharger, et le résultat est identique, octet pour octet, à celui de shfmt en ligne de commande. Format Document, Format Selection, le formatage à l’enregistrement, les clés .editorconfig et les erreurs de syntaxe dans Problems sont gratuits et fonctionnent hors ligne. Zovo Pro (19 USD, payés une seule fois) ajoute trois outils, Format All Shell Scripts in a Folder, Formatting Check with a Patch File et Minify a Script to a Copy, avec 3 essais gratuits pour chacun.

Étapes dans VS Code

  1. Installez Shell Formatter for Bash & Zsh depuis le Marketplace, ou appuyez sur Ctrl+P (Cmd+P sur macOS) et lancez ext install zovo.zovo-shell-formatter.
  2. Ouvrez un script shell et appuyez sur Shift+Alt+F (Shift+Option+F sur Mac). Si VS Code demande quel formateur utiliser, choisissez Shell Formatter, ou lancez « Shell Formatter: Use as Default Formatter for Shell Scripts ».
  3. Pour formater à chaque enregistrement, lancez « Shell Formatter: Turn On Format on Save for Shell Scripts ».
  4. Le dialecte vient de la première ligne (#!/bin/bash, #!/bin/sh, #!/usr/bin/env zsh), puis du nom du fichier (.bash, .zsh, .zshrc, .bats, .ksh), sinon c’est bash. Pour le choisir vous-même, réglez shellFormatter.dialect ou shell_variant dans .editorconfig.
  5. Cliquez sur shfmt 3.14.1 dans la barre d’état pour ouvrir le menu : formater, définir par défaut, formater à l’enregistrement, « Copy the matching shfmt command (for CI) » et réglages.
  6. Si le script n’est pas du shell valide, il reste inchangé et le panneau Problems indique la ligne et la colonne.

Ce qui est gratuit et ce qu’ajoute Zovo Pro

Format Document, Format Selection, le formatage à l’enregistrement, la détection du dialecte, les clés .editorconfig, le menu de la barre d’état, Copy the Matching shfmt Command (for CI) et les erreurs de syntaxe dans Problems sont gratuits. Il n’y a ni connexion, ni requête réseau, ni télémétrie.

Format All Shell Scripts in a Folder examine chaque script d’un dossier et de ses sous-dossiers, repéré par son nom ou par une ligne #! qui nomme un shell, et indique combien seraient modifiés. Ensuite, il les formate tous ou produit un rapport Markdown, avec le même moteur, les mêmes réglages et le même .editorconfig que Format Document. Un dépôt avec des dizaines de scripts écrits dans des styles différents prend un seul style en une passe, et les scripts qui n’exécuteraient plus les mêmes commandes restent tels quels.

Utiliser Format All Shell Scripts in a Folder (Zovo Pro)

  1. Faites un clic droit sur un dossier dans l’Explorer et choisissez « Zovo Pro: Format All Shell Scripts in a Folder », ou lancez « Shell Formatter: Format All Shell Scripts in a Folder (Pro) » depuis la Command Palette ou le menu de la barre d’état, puis choisissez le dossier.
  2. Le titre de la liste suivante indique combien de scripts seraient modifiés, par exemple « N of M scripts would change ».
  3. Choisissez « Format N scripts » pour formater et enregistrer chaque fichier (Undo fonctionne fichier par fichier), ou « Show the report only » pour obtenir une liste Markdown de chaque script sans rien modifier.
  4. Un essai ne compte que si vous obtenez un résultat. Un dossier sans script shell, ou dont tous les scripts sont déjà formatés, n’en consomme aucun.

Format All Shell Scripts in a Folder fonctionne 3 fois sur votre ordinateur avant de demander une licence. Il n’y a ni fenêtre surgissante ni compte à rebours.

Étapes dans Cursor, Windsurf ou VSCodium

  1. Ouvrez la vue Extensions avec Ctrl+Maj+X (Cmd+Maj+X sur macOS).
  2. Cherchez zovo.zovo-shell-formatter et cliquez sur Install. Cursor, Windsurf et VSCodium installent les extensions depuis Open VSX, où celle-ci s’appelle zovo/zovo-shell-formatter.
  3. Si votre éditeur n’a pas de galerie, téléchargez le fichier .vsix sur la page Open VSX et lancez « Extensions: Install from VSIX... ».
  4. Ensuite, tout fonctionne comme dans VS Code.

Ce que fait Shell Formatter for Bash & Zsh

  • Les scripts Bash, POSIX sh (aussi dash et ash), mksh (aussi ksh), bats et zsh.
  • Le même résultat que shfmt 3.14.1 en ligne de commande : 354 exécutions sur 354, sur 178 scripts réels de projets GitHub et de Homebrew, sont identiques octet pour octet.
  • Avant qu’une modification soit appliquée, le script formaté est analysé de nouveau et doit exécuter les mêmes commandes que l’original (fichiers jusqu’à 256 Ko).
  • Les options de shfmt en réglages ou en clés .editorconfig : indentation, opérateurs binaires en début de ligne suivante, indentation des case, espaces autour des redirections, conservation de l’alignement, accolades de fonction sur la ligne suivante, simplification et minification.
  • Les fins de ligne Windows (CRLF) restent en CRLF, et un script de 2 Mo se formate en 0,2 seconde environ.

Ce qu’il ne fait pas

  • L’extension ne touche jamais aux Dockerfiles, aux fichiers .env ni aux scripts fish ou csh.
  • La prise en charge de zsh dans shfmt est récente. Un script zsh que shfmt ne sait pas analyser reste inchangé.
  • Les fichiers de plus de 10 Mo (réglage shellFormatter.maxFileMB) et les fichiers qui contiennent des octets binaires, comme les installateurs auto-extractibles, ne sont pas formatés.
  • shfmt tourne avec une limite de temps (10 secondes par défaut, réglage shellFormatter.timeoutSeconds). Si elle est atteinte, le fichier reste inchangé.

Questions fréquentes

Est-ce gratuit ?

Format Document, Format Selection, le formatage à l’enregistrement et la prise en charge de .editorconfig sont gratuits. Les trois outils Pro, Format All Shell Scripts in a Folder, Formatting Check with a Patch File et Minify a Script to a Copy, ont 3 essais gratuits chacun. Ensuite, ils demandent Zovo Pro, 19 USD une seule fois pour toutes les extensions Zovo.

Faut-il installer shfmt ?

Non. shfmt 3.14.1 est livré dans l’extension en WebAssembly, donc tout fonctionne hors ligne, sans rien télécharger.

L’extension peut-elle casser mon script ?

Un script qui contient une erreur de syntaxe reste inchangé. Avant qu’une modification soit appliquée, le script formaté est analysé de nouveau et doit exécuter les mêmes commandes que l’original.

L’extension fonctionne-t-elle dans Cursor ?

Oui. Cursor, Windsurf et VSCodium l’installent depuis Open VSX, où elle est publiée sous le nom zovo/zovo-shell-formatter.
