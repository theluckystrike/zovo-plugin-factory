Envoyer des fichiers sur un serveur en SFTP ou FTP depuis VS Code

Installez l’extension gratuite SFTP & FTP Sync and Upload et écrivez un fichier .vscode/sftp.json avec l’hôte, l’utilisateur et le dossier du serveur. Chaque fichier est alors envoyé quand vous l’enregistrez, en SFTP, FTP ou FTPS. Faites un clic droit sur un fichier ou un dossier pour l’envoyer ou le télécharger, ou sur un fichier pour le comparer avec la copie du serveur. La vue Remote Files ouvre les fichiers du serveur dans un onglet normal. Votre dossier .vscode, vos fichiers .env et vos clés privées ne sont jamais envoyés. Tout cela est gratuit, sans compte. Zovo Pro (19 USD, payés une seule fois) ajoute trois outils, Sync Folder with Remote, Roll Back a Remote File et Server Profiles and Jump Host, avec 3 essais gratuits pour chacun.

Étapes dans VS Code

  1. Installez SFTP & FTP Sync and Upload depuis le Marketplace, ou appuyez sur Ctrl+P (Cmd+P sur macOS) et lancez ext install zovo.zovo-sftp.
  2. Lancez « SFTP: Create sftp.json Config » depuis la Command Palette, ou cliquez sur Create sftp.json dans la vue SFTP Remote.
  3. Renseignez protocol (sftp, ftp ou ftps), host, username, privateKeyPath (omettez-le pour utiliser un mot de passe) et remotePath, le dossier du serveur qui correspond à votre dossier local. Survolez une clé pour afficher son aide.
  4. Indiquez "uploadOnSave": true. Dès lors, chaque fichier que vous enregistrez est envoyé. Un mot de passe saisi n’est demandé qu’une fois et reste dans le stockage sécurisé de l’éditeur, jamais dans sftp.json.
  5. Faites un clic droit sur un fichier ou un dossier dans l’Explorer, ou sur un onglet, puis choisissez Upload, Download ou Compare with Server Copy (Compare ne fonctionne que sur les fichiers).
  6. Ouvrez la vue Remote Files pour parcourir le serveur. Ouvrez un fichier dans un onglet normal et enregistrez-le pour le renvoyer, téléchargez-le, copiez son chemin ou supprimez-le. « SFTP: Show Transfer Log » affiche chaque connexion et chaque transfert.

Ce qui est gratuit et ce qu’ajoute Zovo Pro

L’envoi à l’enregistrement, Upload, Download et Compare with Server Copy, la vue Remote Files, SFTP, FTP et FTPS, la vérification de la clé d’hôte et le journal des transferts sont gratuits, sans compte et sans connexion à autre chose que votre propre serveur. Aucune télémétrie.

Quand le serveur et votre dossier local ne correspondent plus, Sync Folder with Remote les compare et liste chaque différence avant de déplacer quoi que ce soit : fichiers présents seulement en local, seulement sur le serveur, ou plus récents d’un côté. Pour chaque fichier, vous choisissez envoyer, télécharger, supprimer ou ignorer, vous ouvrez un diff côte à côte, vous enregistrez la simulation en texte, puis vous appliquez. Vous voyez exactement ce qui va changer sur le serveur avant que cela change.

Utiliser Sync Folder with Remote (Zovo Pro)

  1. Faites un clic droit sur un dossier dans l’Explorer et choisissez « Zovo Pro: Sync folder with remote (diff preview) », ou lancez « SFTP: Sync Folder with Remote, Diff Preview (Pro)... » depuis la Command Palette. La barre de titre de la vue Remote Files a le même bouton.
  2. Lisez le plan. Pour chaque fichier, choisissez envoyer, télécharger, supprimer ou ignorer, et ouvrez le diff des fichiers dont vous n’êtes pas sûr.
  3. Appliquez le plan. Un essai n’est compté que si un plan de synchronisation a été affiché. Escape ou Cancel n’en consomme jamais.

Sync Folder with Remote fonctionne 3 fois sur votre ordinateur avant de demander une licence. Il n’y a ni fenêtre surgissante ni compte à rebours.

Étapes dans Cursor, Windsurf ou VSCodium

  1. Ouvrez la vue Extensions avec Ctrl+Maj+X (Cmd+Maj+X sur macOS).
  2. Cherchez zovo.zovo-sftp et cliquez sur Install. Cursor, Windsurf et VSCodium installent les extensions depuis Open VSX, où celle-ci s’appelle zovo/zovo-sftp.
  3. Si votre éditeur n’a pas de galerie, téléchargez le fichier .vsix sur la page Open VSX et lancez « Extensions: Install from VSIX... ».
  4. Ensuite, tout fonctionne comme dans VS Code.

Ce que fait SFTP & FTP Sync and Upload

  • SFTP avec clés SSH, clés chiffrées, agent SSH ou mot de passe ; FTP ; FTPS avec TLS explicite ou implicite.
  • .vscode, .git, les fichiers .env, les clés privées, .npmrc et les autres fichiers secrets ne sont jamais envoyés. Ajoutez vos propres motifs dans ignore, au format .gitignore.
  • La clé d’hôte du serveur est vérifiée : épinglez-la avec hostFingerprint ou confirmez-la à la première connexion. Une clé modifiée interrompt la connexion.
  • Dans un dossier que vous n’avez pas approuvé (Restricted Mode), l’extension reste désactivée, donc un projet téléchargé ne peut pas envoyer vos fichiers ailleurs.
  • Deux autres outils Pro existent. Roll Back a Remote File garde sur votre ordinateur les 10 dernières copies serveur d’un fichier avant qu’un envoi ne l’écrase. Server Profiles and Jump Host réunit plusieurs serveurs (staging, production) dans un seul sftp.json et se connecte via un hôte de rebond SSH.

Ce qu’il ne fait pas

  • Une seule connexion par serveur à la fois, et les transferts FTP s’exécutent l’un après l’autre.
  • Sur le serveur, les liens symboliques vers des fichiers sont suivis, mais les dossiers liés ne sont pas parcourus par les envois, téléchargements ou synchronisations de dossiers.
  • Les clés au format PuTTY .ppk doivent d’abord être converties en OpenSSH (puttygen key.ppk -O private-openssh -o key).
  • La synchronisation compare la taille et la date de modification, puis les octets des fichiers de même taille, jusqu’à 300 fichiers ou 64 Mo par exécution.
  • Les copies de restauration sont conservées par défaut pour les fichiers de 5 Mo maximum, et seulement sur cet ordinateur.

Questions fréquentes

Est-ce gratuit ?

L’envoi à l’enregistrement, Upload, Download, Compare with Server Copy, la vue Remote Files et le journal des transferts sont gratuits, en SFTP, FTP et FTPS. Les trois outils Pro, Sync Folder with Remote, Roll Back a Remote File et Server Profiles and Jump Host, offrent chacun 3 essais gratuits. Ensuite, il faut Zovo Pro, 19 USD payés une seule fois pour toutes les extensions Zovo.

Mon mot de passe est-il enregistré dans sftp.json ?

Non. Un mot de passe ou une phrase de passe saisis sont gardés dans le stockage sécurisé de l’éditeur. Laissez password hors de sftp.json et il vous sera demandé une fois.

Mon fichier .env sera-t-il envoyé ?

Non. .vscode, .git, les fichiers .env, les clés privées et .npmrc font partie de la liste d’exclusion par défaut et ne sont jamais envoyés.

VS Code peut-il envoyer des fichiers en SFTP sans extension ?

Non. VS Code n’a pas d’envoi SFTP ou FTP. Remote SSH modifie les fichiers directement sur le serveur ; pour envoyer un projet local, il faut une extension, ou scp et rsync dans un terminal.
