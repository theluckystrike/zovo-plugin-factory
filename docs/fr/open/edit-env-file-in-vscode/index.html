Étapes dans VS Code

  1. Installez Dotenv & .env File Editor depuis le Marketplace, ou appuyez sur Ctrl+P (Cmd+P sur macOS) et lancez ext install zovo.zovo-dotenv.
  2. Ouvrez un fichier .env (ou .env.local, .env.production, *.env ou .flaskenv). Les clés, export, les valeurs, les valeurs sur plusieurs lignes et les références ${NAME} prennent des couleurs.
  3. Les valeurs qui ressemblent à des secrets s’affichent sous forme de points tant que le curseur n’est pas sur leur ligne. Pour les afficher toutes, cliquez sur le bouton en forme d’œil dans le titre de l’éditeur ou lancez « Dotenv: Show or Hide Secret Values ». Les modèles comme .env.example ne sont jamais masqués.
  4. Les problèmes apparaissent dans le panneau Problems : une clé définie deux fois, des espaces autour de =, un guillemet jamais fermé, une ligne sans =, un nom invalide, des espaces en fin de ligne ou un ${NAME} qu’aucune ligne ne définit. Appuyez sur Ctrl+. (Cmd+. sur Mac) sur un problème pour obtenir sa correction.
  5. Lancez Format Document pour retirer les espaces autour de = et les espaces en fin de ligne. Les commentaires, l’ordre et les guillemets restent tels quels.
  6. Pour copier une valeur sans l’afficher, lancez « Dotenv: Copy the Value on This Line ». La commande copie la valeur sans les guillemets ni les échappements, même quand elle est masquée.
  7. Dans votre code, survolez process.env.DB_HOST, os.getenv("X"), System.getenv("X") ou une expression semblable pour voir quel fichier .env la définit, et appuyez sur F12 pour ouvrir cette ligne.

Étapes dans Cursor, Windsurf ou VSCodium

  1. Ouvrez la vue Extensions avec Ctrl+Maj+X (Cmd+Maj+X sur macOS).
  2. Cherchez zovo.zovo-dotenv et cliquez sur Install. Cursor, Windsurf et VSCodium installent les extensions depuis Open VSX, où celle-ci s’appelle zovo/zovo-dotenv.
  3. Si votre éditeur n’a pas de galerie, téléchargez le fichier .vsix sur la page Open VSX et lancez « Extensions: Install from VSIX... ».
  4. Ensuite, tout fonctionne comme dans VS Code.

Ce que fait Dotenv & .env File Editor

  • Les fichiers .env, .env.* (comme .env.local et .env.production), *.env et .flaskenv.
  • Le choix des valeurs masquées : les noms qui contiennent PASSWORD, TOKEN, SECRET, API_KEY, DSN, DATABASE_URL et similaires, toutes les valeurs, ou aucune (réglage envFile.maskValues).
  • Le survol et l’accès à la définition dans le code pour process.env et import.meta.env (JavaScript, TypeScript), os.environ et os.getenv (Python), os.Getenv (Go), ENV (Ruby), System.getenv (Java), env() (PHP) et d’autres.
  • La complétion des clés après process.env..
  • Les valeurs masquées restent masquées dans le plan, les survols et les complétions, sauf si vous désactivez ce comportement (réglage envFile.hoverShowsSecrets).

Ce qu’il ne fait pas

  • Le masquage ne concerne que l’écran. Le texte reste dans le fichier, dans les résultats de recherche et dans la forme de la minimap, et copier-coller copie la vraie valeur.
  • .envrc (direnv) est un script shell et reste du ressort des extensions shell.
  • Le rapport sur le code voit les noms écrits en clair, comme process.env.API_KEY. Les noms construits à l’exécution ne sont pas trouvés.
  • Les problèmes suivent les règles du paquet dotenv. Quelques outils (Docker Compose v1, systemd) sont plus stricts, et c’est ce que signalent les avertissements.

Questions fréquentes

Est-ce gratuit ?

Les couleurs, les valeurs masquées, les problèmes avec leurs corrections rapides, le formatage et le survol dans le code sont gratuits. Les trois outils Pro, Compare .env with .env.example, Find Keys Missing in Code or .env et Convert .env to JSON, YAML, Kubernetes, ont 3 essais gratuits chacun. Ensuite, ils demandent Zovo Pro, 19 USD une seule fois pour toutes les extensions Zovo.

L’extension modifie-t-elle mon fichier .env pour masquer les valeurs ?

Non. Seul l’affichage change, le fichier n’est jamais modifié. Copier-coller copie toujours la vraie valeur.

Pourquoi ma clé est-elle signalée comme définie deux fois ?

La même clé apparaît sur deux lignes. Le paquet dotenv garde la première valeur, alors que les shells et Docker Compose gardent la dernière. La correction rapide supprime la deuxième ligne.

L’extension fonctionne-t-elle dans Cursor ?

Oui. Cursor, Windsurf et VSCodium l’installent depuis Open VSX, où elle est publiée sous le nom zovo/zovo-dotenv.
