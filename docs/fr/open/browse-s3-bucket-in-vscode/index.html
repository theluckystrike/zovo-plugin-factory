Parcourir des buckets AWS S3, Cloudflare R2 ou MinIO dans VS Code

Installez l’extension gratuite S3 Explorer et ouvrez sa vue S3 Buckets dans l’Activity Bar. Elle fonctionne avec AWS S3 (profils de ~/.aws, profils SSO compris), Cloudflare R2, MinIO, Backblaze B2, Wasabi et DigitalOcean Spaces. La navigation, l’ouverture des objets en lecture seule, le téléversement, le téléchargement, la copie, le déplacement, le renommage, la suppression, les versions, les tags, les URL présignées et la synchronisation de dossiers sont gratuits, sans connexion à un compte et sans télémétrie. Zovo Pro (19 USD, payés une seule fois) ajoute trois outils, Copy to Another Connection, le Size and Cost Report et Scheduled Sync, avec 3 essais gratuits pour chacun.

Étapes dans VS Code

  1. Installez S3 Explorer depuis le Marketplace, ou appuyez sur Ctrl+P (Cmd+P sur macOS) et lancez ext install zovo.zovo-s3-explorer.
  2. Ouvrez la vue S3 Explorer dans l’Activity Bar et cliquez sur Add Connection. Choisissez un profil AWS de ~/.aws, ou saisissez une clé d’accès, un account ID et un jeton R2, ou l’URL du point de terminaison de MinIO ou d’un autre service compatible S3. Les clés que vous saisissez vont dans le trousseau du système.
  3. Dépliez une connexion pour voir ses buckets. Les clés se chargent par 1 000, avec une ligne « Load 1,000 more ». Si votre clé n’a pas le droit de lister les buckets, faites un clic droit sur la connexion et choisissez Add Bucket by Name.
  4. Cliquez sur un objet pour l’ouvrir en lecture seule dans un onglet ou dans la visionneuse adaptée. Pour voir ses métadonnées, ses tags, ses versions et une URL présignée, faites un clic droit dessus et choisissez Show Details, Versions and Presigned URL.
  5. Pour modifier un objet, faites un clic droit dessus et choisissez Edit and Upload. Vous modifiez une copie, et une boîte de dialogue affiche le bucket, la clé et les deux tailles avant que l’objet soit remplacé.
  6. Faites glisser des fichiers ou des dossiers de l’Explorer sur un bucket pour les téléverser, ou faites un clic droit et choisissez Download. Les fichiers de 16 Mo ou plus sont envoyés en plusieurs parties, avec la progression et Cancel, et un envoi interrompu reprend avec les seules parties manquantes.
  7. Pour garder un dossier local et un préfixe identiques, faites un clic droit sur le bucket ou le dossier et choisissez Sync Folder. Un plan de simulation (nouveaux, modifiés, à supprimer) s’affiche avant tout changement.

Ce qui est gratuit et ce qu’ajoute Zovo Pro

La navigation, l’ouverture, Edit and Upload, le téléversement, le téléchargement, la copie, le déplacement, le renommage, la suppression, les versions, les tags, les URL présignées et la synchronisation de dossiers sont gratuits, sans connexion, sans compte et sans télémétrie. L’extension se connecte seulement aux points de terminaison de stockage que vous ajoutez.

Copy to Another Connection copie des objets ou des dossiers entiers d’une connexion à une autre, par exemple d’AWS S3 vers Cloudflare R2 ou MinIO, avec la même confirmation que pour toute copie : les clés sont listées, et celles qui seraient remplacées sont nommées. Les gros objets passent par un envoi en plusieurs parties. Vous déplacez des données entre fournisseurs ou entre comptes depuis l’arborescence, sans script ni second outil.

Utiliser Copy to Another Connection (Zovo Pro)

  1. Ajoutez d’abord la deuxième connexion. Faites ensuite un clic droit sur un objet ou un dossier dans la vue S3 Buckets et choisissez « Copy to Another Connection... (Pro) », ou cliquez sur Copy to Another Connection dans la ligne « Zovo Pro tools » en bas de la vue.
  2. Choisissez la connexion cible, le bucket et le dossier de destination (vide pour le niveau supérieur).
  3. Lisez la liste des objets dans la confirmation et cliquez sur Copy, ou sur Copy and Replace si certaines clés existent déjà. Une notification affiche la progression.
  4. Un essai ne compte que si des objets ont été copiés. Escape pendant un choix, ou l’absence de deuxième connexion, n’en consomme aucun.

Copy to Another Connection fonctionne 3 fois sur votre ordinateur avant de demander une licence. Il n’y a ni fenêtre surgissante ni compte à rebours.

Étapes dans Cursor, Windsurf ou VSCodium

  1. Ouvrez la vue Extensions avec Ctrl+Maj+X (Cmd+Maj+X sur macOS).
  2. Cherchez zovo.zovo-s3-explorer et cliquez sur Install. Cursor, Windsurf et VSCodium installent les extensions depuis Open VSX, où celle-ci s’appelle zovo/zovo-s3-explorer.
  3. Si votre éditeur n’a pas de galerie, téléchargez le fichier .vsix sur la page Open VSX et lancez « Extensions: Install from VSIX... ».
  4. Ensuite, tout fonctionne comme dans VS Code.

Ce que fait S3 Explorer

  • Les profils AWS avec clés d’accès, credential_process, rôles avec source_profile et profils SSO après aws sso login. Le endpoint_url d’un profil est respecté.
  • MinIO et les autres services compatibles S3, avec une URL de point de terminaison, une région, des URL path-style ou virtual-hosted et une option pour accepter un certificat auto-signé.
  • Les métadonnées, le type de contenu, la classe de stockage, l’ETag, les tags (modification et enregistrement), les versions (ouverture, téléchargement, restauration) et les URL présignées GET ou PUT de 15 minutes à 7 jours.
  • Les buckets de plusieurs millions de clés, chargées par 1 000, avec recherche et filtre par préfixe.
  • Les téléchargements gardent l’arborescence et n’écrivent jamais en dehors du dossier choisi. Les clés avec des segments .., des lettres de lecteur ou des octets NUL sont ignorées et listées.

Ce qu’il ne fait pas

  • L’extension n’utilise jamais d’elle-même le profil AWS default ni AWS_PROFILE. C’est vous qui choisissez le profil de connexion.
  • Les objets texte de plus de 10 Mo demandent d’abord une confirmation, puis montrent le premier Mo. Les objets binaires de plus de 200 Mo demandent une confirmation avant le téléchargement.
  • Les objets ouverts sont en lecture seule. Seul Edit and Upload écrit dans le bucket, après une confirmation.
  • Scheduled Sync ne tourne que pendant que VS Code est ouvert, toutes les 5 à 60 minutes, et ne supprime jamais rien.
  • Les requêtes sans réponse s’arrêtent après 30 secondes (réglage s3Explorer.requestTimeoutSeconds).

Questions fréquentes

Est-ce gratuit ?

La navigation, l’ouverture, le téléversement, le téléchargement, la copie, le déplacement, le renommage, la suppression, les versions, les tags, les URL présignées et la synchronisation de dossiers sont gratuits. Les trois outils Pro, Copy to Another Connection, le Size and Cost Report et Scheduled Sync, ont 3 essais gratuits chacun. Ensuite, ils demandent Zovo Pro, 19 USD une seule fois pour toutes les extensions Zovo.

Où mes clés sont-elles enregistrées ?

Les clés que vous saisissez vont dans le trousseau du système via VS Code SecretStorage, jamais dans les fichiers de réglages. Les profils AWS ne sont lus dans ~/.aws que lorsque vous en choisissez un.

L’extension fonctionne-t-elle avec Cloudflare R2 et MinIO ?

Oui. R2 demande votre account ID et la clé d’accès d’un jeton d’API R2. MinIO et les autres services compatibles S3 demandent une URL de point de terminaison, une région et des URL path-style ou virtual-hosted.

L’extension fonctionne-t-elle dans Cursor ?

Oui. Cursor, Windsurf et VSCodium l’installent depuis Open VSX, où elle est publiée sous le nom zovo/zovo-s3-explorer.
