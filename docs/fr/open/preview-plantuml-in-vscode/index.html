Prévisualiser un diagramme PlantUML dans VS Code pendant la saisie

Installez l’extension gratuite PlantUML Viewer & Preview, ouvrez un fichier .puml ou un fichier Markdown avec un bloc plantuml et cliquez sur le bouton d’aperçu. Le diagramme est dessiné à côté de votre code pendant que vous tapez, par le jar PlantUML fourni avec l’extension et votre propre Java 11 ou plus récent. Rien n’est donc envoyé à un serveur, et Graphviz n’est pas nécessaire. L’aperçu, le zoom, les liens vers les erreurs et l’enregistrement d’un diagramme en SVG ou PNG sont gratuits. Zovo Pro (19 USD, payés une seule fois) ajoute trois outils, Export All Diagrams in a Folder, Markdown Diagrams to Images et Compare with a Git Version, avec 3 essais gratuits pour chacun.

Étapes dans VS Code

  1. Installez PlantUML Viewer & Preview depuis le Marketplace, ou appuyez sur Ctrl+P (Cmd+P sur macOS) et lancez ext install zovo.zovo-plantuml-viewer.
  2. Vérifiez que Java 11 ou plus récent est installé. L’extension le cherche dans le réglage plantumlViewer.javaPath, puis dans JAVA_HOME, puis java dans le PATH, puis dans les dossiers JDK habituels. Si aucun n’est trouvé, l’aperçu le signale et propose « Set the Java path ». La commande « PlantUML: Show Java and Layout Status » montre ce qui a été trouvé.
  3. Ouvrez un fichier .puml, .plantuml, .iuml, .pu ou .wsd, ou un fichier Markdown avec un bloc ```plantuml, et cliquez sur le bouton d’aperçu en haut à droite de l’éditeur. Vous pouvez aussi appuyer sur Alt+D dans un fichier PlantUML ou lancer « PlantUML: Open Preview to the Side ».
  4. Tapez. L’aperçu se redessine un instant après la fin de la saisie (400 ms par défaut, réglage plantumlViewer.renderDelay). Tous les diagrammes du fichier s’affichent dans un seul aperçu, et celui qui se trouve sous le curseur est encadré.
  5. Zoomez avec les boutons, avec Ctrl ou Cmd et la molette de la souris, ou avec les touches + et -. Cliquez sur Fit pour adapter le diagramme à la largeur du panneau, et faites glisser un diagramme pour vous y déplacer. Un diagramme en erreur affiche le message de PlantUML et un lien « Go to line ».
  6. Cliquez sur SVG ou PNG au-dessus d’un diagramme pour enregistrer ce seul diagramme, ou sur Copy SVG pour le copier.

Ce qui est gratuit et ce qu’ajoute Zovo Pro

L’aperçu en direct des fichiers .puml, .plantuml, .iuml, .pu et .wsd et des blocs plantuml du Markdown, le zoom et le déplacement, les erreurs avec un lien vers la ligne, l’enregistrement d’un diagramme en SVG ou PNG, Copy SVG, la coloration syntaxique, les snippets (seq, classd, activity, mindmap, gantt et d’autres), le pliage et les commentaires sont gratuits. Les diagrammes sont dessinés sur votre machine et ne sont jamais envoyés à un serveur.

Quand les diagrammes d’un projet doivent aller dans une documentation ou des slides, Export All Diagrams in a Folder écrit en une seule fois chaque diagramme de chaque fichier PlantUML d’un dossier et de ses sous-dossiers en SVG, PNG ou PDF, à côté de chaque fichier ou tous dans un même dossier. Les diagrammes en erreur sont ignorés et listés avec le fichier, la ligne et le message, et les autres sont écrits. Vous n’avez plus à ouvrir chaque fichier pour enregistrer chaque diagramme à la main.

Utiliser Export All Diagrams in a Folder (Zovo Pro)

  1. Faites un clic droit sur un dossier dans l’Explorer et choisissez « Zovo Pro: Export all diagrams in a folder », cliquez sur « Export all diagrams in a folder » dans la ligne Pro tools de la barre d’outils de l’aperçu, ou lancez « PlantUML: Export All Diagrams in a Folder (Pro) » depuis la Command Palette et choisissez le dossier.
  2. Choisissez SVG, PNG ou PDF, puis « Next to each PlantUML file » ou « All in one folder... ».
  3. À la fin, un message indique combien de diagrammes ont été exportés. Cliquez sur « Show errors » pour voir la liste des diagrammes qui avaient une erreur, ou sur « Reveal » pour voir les fichiers.
  4. Un essai ne compte que si au moins une image a été écrite. Échap, Cancel ou un dossier sans fichier PlantUML n’en consomment aucun.

Export All Diagrams in a Folder fonctionne 3 fois sur votre ordinateur avant de demander une licence. Il n’y a ni fenêtre surgissante ni compte à rebours.

Étapes dans Cursor, Windsurf ou VSCodium

  1. Ouvrez la vue Extensions avec Ctrl+Maj+X (Cmd+Maj+X sur macOS).
  2. Cherchez zovo.zovo-plantuml-viewer et cliquez sur Install. Cursor, Windsurf et VSCodium installent les extensions depuis Open VSX, où celle-ci s’appelle zovo/zovo-plantuml-viewer.
  3. Si votre éditeur n’a pas de galerie, téléchargez le fichier .vsix sur la page Open VSX et lancez « Extensions: Install from VSIX... ».
  4. Ensuite, tout fonctionne comme dans VS Code.

Ce que fait PlantUML Viewer & Preview

  • Les diagrammes de séquence, de classes, d’activité, de composants, d’états et de cas d’utilisation, les mind maps, les diagrammes de Gantt et les autres blocs @start... du PlantUML fourni (build MIT 1.2026.10).
  • Les blocs Markdown ```plantuml, ```puml et ```uml, avec ou sans @startuml à l’intérieur. Le bouton d’aperçu apparaît sur un fichier Markdown qui en contient au moins un.
  • !include de fichiers du dossier du diagramme, de vos dossiers d’espace de travail et de plantumlViewer.includePaths, et la bibliothèque standard comme !include <C4/C4_Container>, hors ligne. Les includes C4, d’icônes AWS et d’icon fonts écrits sous forme d’adresses https://raw.githubusercontent.com/... sont lus depuis la copie intégrée au jar.
  • Les diagrammes de séquence, les mind maps et les diagrammes de Gantt n’ont besoin d’aucun moteur de mise en page. Les diagrammes de classes, de composants, d’états et de cas d’utilisation utilisent Graphviz quand dot est installé (plantumlViewer.layout sur auto), et sinon le moteur Smetana intégré à PlantUML.
  • Les diagrammes sont affichés comme des images, donc un lien ou un texte dans un diagramme ne peut pas exécuter de code dans l’éditeur.

Ce qu’il ne fait pas

  • Java 11 ou plus récent doit être installé. L’extension ne télécharge pas Java.
  • Les includes depuis des adresses web sont refusés, sauf les adresses C4, d’icônes AWS et d’icon fonts dont le jar a sa propre copie. Les icônes AWS viennent du jeu d’icônes AWS intégré à PlantUML (version 20), donc une icône plus récente affiche une erreur qui la nomme.
  • Le build MIT de PlantUML n’a ni Ditaa ni le rendu LaTeX de @startmath. Un bloc Ditaa affiche la page « not supported » de PlantUML.
  • Sans Graphviz, Smetana dispose les diagrammes de classes et de composants un peu différemment, et les très grands diagrammes de classes peuvent paraître plus serrés.
  • Un diagramme qui prend plus de 30 secondes (réglage plantumlViewer.renderTimeoutSeconds) est arrêté, et les images sont coupées à 8192 pixels de côté (réglage plantumlViewer.maxImageSize).

Questions fréquentes

Est-ce gratuit ?

L’aperçu en direct, le zoom et le déplacement, les liens vers les erreurs, l’enregistrement d’un diagramme en SVG ou PNG, la coloration syntaxique et les snippets sont gratuits. Les trois outils Pro, Export All Diagrams in a Folder, Markdown Diagrams to Images et Compare with a Git Version, ont 3 essais gratuits chacun. Ensuite, ils demandent Zovo Pro, 19 USD une seule fois pour toutes les extensions Zovo.

Faut-il Java ou Graphviz ?

Java 11 ou plus récent, oui, car PlantUML est un programme Java. Graphviz, non. Sans lui, les diagrammes de classes et de composants utilisent le moteur de mise en page Smetana intégré à PlantUML. Si dot est installé, il est utilisé.

Mon diagramme est-il envoyé à un serveur ?

Non. Le jar PlantUML fourni tourne sur votre machine avec son profil de sécurité ALLOWLIST, et les includes depuis des adresses web sont refusés. Aucun serveur PlantUML n’est utilisé.

L’extension fonctionne-t-elle dans Cursor ?

Oui. Cursor, Windsurf et VSCodium l’installent depuis Open VSX, où elle est publiée sous le nom zovo/zovo-plantuml-viewer.
