Ouvrir vos fichiers dans VS Code et Cursor

VS Code ouvre le texte, les images et quelques vidéos. Pour Word, PowerPoint, Excel, les PDF en mode sombre ou un fichier binaire, il faut une extension. Chaque guide donne les étapes dans VS Code et dans Cursor, dit ce qui est gratuit et ce que Zovo Pro ajoute.

  • Ouvrir un fichier Word .docx dans VS Code
    VS Code affiche un .docx comme un fichier binaire. Avec l'extension gratuite DOCX Viewer, le document Word s'ouvre en aperçu avec recherche, plan et mode sombre. Fonctionne aussi dans Cursor.
  • Voir des diapositives PowerPoint .pptx dans VS Code
    Ouvrez les .pptx, .ppsx, .potx et anciens .ppt dans VS Code ou Cursor, avec vignettes, notes du présentateur, recherche et présentation plein écran. Extension gratuite, sans envoi en ligne.
  • Ouvrir Excel et CSV dans VS Code sous forme de tableau
    Affichez .xlsx, .xls, .ods, CSV et Parquet dans VS Code en tableau triable et filtrable, jusqu'à 1 000 000 de lignes, et lancez du SQL avec GROUP BY. Extension gratuite, sans Excel ni Python.
  • Lire un PDF en mode sombre dans VS Code
    Lisez vos PDF dans VS Code sur des pages sombres ou sépia, et les photos gardent leurs vraies couleurs. Recherche, plan, vignettes et surlignages en Markdown. Extension gratuite et hors ligne.
  • Éditeur hexadécimal dans VS Code
    Voyez, modifiez et comparez les octets de n'importe quel fichier dans VS Code, jusqu'aux images disque de 4 Go. Aller à un offset, recherche avec jokers, inspecteur de données. Extension gratuite et hors ligne.
  • Renommer automatiquement les balises HTML, JSX et Vue dans VS Code
    Renommez une balise HTML, JSX ou Vue et la balise correspondante change pendant la saisie. Extension gratuite basée sur le linked editing de VS Code.
  • Parcourir des buckets AWS S3, Cloudflare R2 ou MinIO dans VS Code
    Parcourez vos buckets S3, R2, MinIO, B2 et Wasabi dans VS Code, ouvrez les objets en lecture seule, téléversez avec reprise et synchronisez un dossier.
  • Relire et reprendre votre historique Claude Code dans VS Code
    Relisez, cherchez et reprenez vos sessions Claude Code et Codex dans VS Code. Sous-agents imbriqués, modifications en diff, tokens. Lecture seule, hors ligne.
  • Comparer deux fichiers ZIP dans VS Code
    Ouvrez gratuitement les ZIP, JAR, TAR et GZ dans VS Code, puis listez les fichiers ajoutés, supprimés ou modifiés entre deux archives dans un rapport Zovo Pro.
  • Convertir un fichier PDF, Word, PowerPoint ou Excel en Markdown dans VS Code
    Clic droit sur un fichier PDF, DOCX, PPTX, XLSX, CSV, HTML ou EPUB dans VS Code, et le Markdown s’ouvre à côté. Gratuit, hors ligne, sans Python ni envoi.
  • DXF en CSV dans VS Code : extraire les attributs de blocs et les textes
    Ouvrez un DXF dans VS Code et enregistrez ses attributs de blocs, ses blocs, ses textes ou ses calques en CSV pour Excel. Affichage gratuit, CSV en Zovo Pro.
  • Modifier un fichier .env dans VS Code sans afficher vos secrets
    Colorez les fichiers .env dans VS Code, masquez les valeurs secrètes par des points hors de leur ligne et corrigez les clés en double. Gratuit et hors ligne.
  • Formater un script bash ou zsh dans VS Code
    Formatez vos scripts bash, sh, zsh, bats et mksh dans VS Code avec Shift+Alt+F ou à l’enregistrement. shfmt 3.14.1 est intégré, lit .editorconfig, hors ligne.
  • Formater du XML dans VS Code et y lancer des requêtes XPath
    Formatez ou minifiez du XML dans VS Code en ne changeant que les espaces entre balises, lancez XPath 1.0 avec les espaces de noms du fichier et copiez le XPath.
  • Voir l’image derrière un chemin dans votre code, dans la gouttière et au survol
    Une miniature dans la gouttière et un survol avec l’image, ses dimensions et son poids pour vos chemins d’images en JS, CSS, HTML et Markdown. Gratuit.
  • Afficher les diagrammes Mermaid dans VS Code
    Affichez les diagrammes Mermaid des fichiers .mmd et des blocs Markdown dans VS Code avec Mermaid Viewer, gratuit. Aperçu en direct, PNG et SVG, hors ligne.
  • Une visionneuse NetCDF gratuite dans VS Code
    Ouvrez les fichiers NetCDF .nc dans VS Code sous Windows, macOS ou Linux : en-tête, variables, cartes avec côtes, séries temporelles. Aussi HDF5 et MATLAB 7.3.
  • Normaliser le volume d’un fichier audio à une cible LUFS
    Écoutez WAV, MP3, FLAC, Ogg et Opus dans VS Code avec un mesureur LUFS gratuit, puis écrivez un nouveau WAV à -14, -16 ou -23 LUFS. Hors ligne, sans envoi.
  • Ouvrir les fichiers .npy et .npz de NumPy dans VS Code
    Ouvrez les tableaux NumPy .npy et .npz dans VS Code avec Tensor Viewer, gratuit : dtype, forme, statistiques, cartes de chaleur, images et valeurs, sans Python.
  • Ouvrir un fichier PCAP dans VS Code
    Lisez les captures .pcap, .pcapng et .pcap.gz dans VS Code avec PCAP Viewer, gratuit : paquets, arbre des protocoles, vue hexa et filtres. Sans Wireshark.
  • Lire des vidéos MOV, MKV, WebM et MP4 avec le son dans VS Code
    Lisez les MP4, MOV et M4V avec le son AAC dans VS Code sans rien installer d’autre. MKV, WebM et AVI aussi, avec votre ffmpeg. Lecteur gratuit avec sous-titres.
  • Modifier des fichiers .proto dans VS Code avec coloration, formatage et accès à la définition
    Colorez, formatez et vérifiez les fichiers .proto dans VS Code : formateur qui garde les commentaires, erreurs façon protoc. Gratuit, hors ligne, sans protoc.
  • Ouvrir une base de données SQLite dans VS Code
    Ouvrez un fichier .db ou .sqlite dans VS Code avec SQLite Viewer & Editor, gratuit : tables, schéma et SQL, puis modifiez et enregistrez avec une sauvegarde.
  • Ouvrir des fichiers STL dans VS Code
    Ouvrez un fichier STL dans VS Code avec 3D Model Viewer, gratuit : rotation, mesure de distances, filaire et statistiques. Aussi OBJ, PLY, 3MF, GLB et glTF.
  • Convertir un TIFF en PNG sans perte de qualité
    Ouvrez gratuitement les TIFF, BigTIFF et GeoTIFF dans VS Code, puis enregistrez une page ou toutes en PNG avec les valeurs 8 et 16 bits exactes. Hors ligne.
  • Convertir une police TTF en WOFF2 dans VS Code
    Prévisualisez gratuitement les polices TTF, OTF, WOFF et WOFF2 dans VS Code, puis convertissez un TTF ou un OTF en WOFF2 à côté du fichier source. Hors ligne.
  • XMind en PDF sans XMind : toutes les feuilles dans un seul PDF
    Ouvrez une carte .xmind dans VS Code sans XMind et enregistrez toutes les feuilles dans un PDF, une page par feuille. Affichage gratuit, PDF en Zovo Pro.
