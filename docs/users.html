How to get more Apify users

  • 1. Our 5 public Actors cannot be found in Apify Store search. The API counts them (`username=zovo-one` gives total 5) but returns 0 items, even for their exact titles. 825 Actors from other publishers, created after ours, are listed. Until this is fixed, Store traffic and Store users are 0.
  • 2. The fix is an owner message to Apify support (15 minutes). Another publisher (`changeable_peddler`) had the same symptom in 2026 and is listed now. The cause for us is UNVERIFIED.
  • 3. Pricing is fine. Each of our prices is equal to or below the top 3 rivals. Do not cut prices. The gaps are the titles (TubeText, TikTok, Medium/Substack, Screenshot do not start with the phrase people search), placeholder `{"helloWorld":123}` API example input on all 10 Actors, and missing README sections (use cases, AI agents/MCP, free credit math).
  • 4. Money in the next 30 days is small even when listed. The net is $0.22 low, $4.26 mid and $53.53 high for all 10 Actors together (ESTIMATE, model below). Leaders earn from a few heavy users (thewolves has 38,583 runs from 680 users in 30 days), so the goal is repeat API and agent users, not more trial runs.
  • 5. `google-jobs-scraper` (a 10th Actor, private) has no pay-per-event price. It would earn $0 if it went public as it is.

How to get more VS Code and Open VSX users

  • 1. Context Drift is not on Open VSX. AI agent tools there get a median 7.9x more downloads than on VS Code (5 comparables), so publishing there is the best action per hour, at about 400 extra users per 30 days per hour of work.
  • 2. The AGENTS.md / CLAUDE.md niche is small. New extensions there get a median 0.1 installs a day, and the 90th percentile gets 0.5 to 1.0 a day. We rank #1 for "claude.md" but are not in the top 200 for "cursor rules", "ai rules" or "claude code".
  • 3. The live 0.1.4 README has 0 images. The fast-growing rivals have 4 to 14. Ship 0.1.5 with the screenshot (another lane added images/demo.png at 06:26) and grow the keywords from 11 to 30.
  • 4. Money from Context Drift is small in every model, at $0 to $600 a year (ESTIMATE). Sponsors pay almost nothing. Bookmarks has 5.2M installs and 2 public GitHub sponsors. If we sell, use Paddle (5% + 50¢). Lemon Squeezy is moving its users to Stripe Managed Payments.
  • 5. The next 3 extensions are a PDF viewer, a DOCX viewer and a Parquet/XLSX table viewer. File viewers get 7 to 18 installs a day at the 90th percentile, 10 to 100 times our niche. SQLite Viewer PRO proves people pay for viewers ($99 one-time).
