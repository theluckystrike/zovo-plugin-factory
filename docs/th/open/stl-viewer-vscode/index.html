ดูไฟล์ STL และโมเดล 3D ใน VS Code

ติดตั้ง 3D Model Viewer ซึ่งใช้ได้ฟรี แล้วคลิกไฟล์ .stl ใน Explorer ลากเพื่อหมุนรอบโมเดล ลากด้วยปุ่มขวาหรือ Shift-ลากเพื่อเลื่อน เลื่อนล้อเมาส์เพื่อซูม และกด M เพื่อวัดระยะระหว่างสองจุด ส่วนขยายเดียวกันนี้เปิด OBJ, PLY, 3MF, GLB และ glTF ได้ และการเปิดไฟล์ การวัด และ scene tree ใช้ได้ฟรี Zovo Pro (19 ดอลลาร์สหรัฐ จ่ายครั้งเดียว) เพิ่ม Print check, Section view และ Turntable export โดยแต่ละเครื่องมือลองใช้ฟรีได้ 3 ครั้ง

ขั้นตอนใน VS Code

  1. ติดตั้ง 3D Model Viewer จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.3d-model-viewer
  2. คลิกไฟล์ .stl, .obj, .ply, .3mf, .glb หรือ .gltf ใน Explorer ถ้าโปรแกรมดูตัวอื่นเปิดขึ้นมาแทน ให้คลิกขวาที่ไฟล์แล้วเลือก "Open in 3D Model Viewer"
  3. ลากเพื่อหมุนรอบโมเดล ลากด้วยปุ่มขวาหรือ Shift-ลากเพื่อเลื่อน และเลื่อนล้อเมาส์เพื่อซูม กด F เพื่อให้เห็นโมเดลทั้งหมดในมุมมอง
  4. ดูจำนวน vertices, triangles, materials, textures และขนาดในหน่วยของโมเดลได้ในแผงข้อมูล กด P เพื่อแสดงหรือซ่อนแผงข้อมูลและ scene tree
  5. กด W สำหรับ wireframe, N สำหรับ vertex normals และ B สำหรับ bounding box ตั้ง Shading เป็น Smooth เพื่อลบผิวเหลี่ยม ๆ ที่เห็นในไฟล์ STL
  6. กด M (Measure) แล้วคลิกสองจุดบนพื้นผิว เส้นที่ลากจะแสดงระยะห่าง และแถบสถานะจะแสดงค่า X, Y และ Z แยกกัน กด Esc เพื่อหยุด
  7. คลิก Screenshot เพื่อบันทึกมุมมองเป็นไฟล์ PNG

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

การเปิดทั้งหกฟอร์แมต การหมุน เลื่อน และซูม แผงสถิติ scene tree, Measure, wireframe, normals, bounding box, grid, axes แอนิเมชันของ glTF และการบันทึกภาพหน้าจอเป็น PNG ใช้ได้ฟรี ทำงานออฟไลน์และไม่เรียกเครือข่าย

Print check แสดงขนาด ปริมาตร และพื้นที่ผิวของโมเดล และตรวจว่า mesh ปิดสนิท (watertight) หรือไม่ ทั้ง open edges, non-manifold edges, หน้าที่หันผิดทิศ, สามเหลี่ยมที่มีพื้นที่เป็นศูนย์ และจำนวนชิ้นส่วนที่แยกกัน ปุ่ม Mark problems จะวาดขอบที่มีปัญหาบนโมเดล เมื่อใส่วัสดุ ค่า infill ความหนาผนัง เส้นผ่านศูนย์กลางของ filament และราคาต่อกิโลกรัม มันจะประมาณน้ำหนัก ความยาว filament และค่าวัสดุให้ก่อนที่คุณจะเปิด slicer

วิธีใช้ Print check (Zovo Pro)

  1. เปิดไฟล์ STL ใน 3D Model Viewer
  2. กด "Run print check" ในแผงด้านข้าง หรือรัน "3D Model Viewer: Print Check (Zovo Pro)" จาก Command Palette หรือคลิกขวาที่ไฟล์ใน Explorer แล้วเลือก "Zovo Pro: Print check"
  3. ถ้า mesh มีปัญหา ให้กด "Mark problems" เพื่อดู open edges เป็นสีแดงและขอบที่มีปัญหาอื่นเป็นสีม่วงแดง (magenta) แล้วเลือกวัสดุ (PLA, PETG, ABS, ASA, TPU, nylon, PC หรือ resin) ค่า infill และราคาต่อกิโลกรัมของคุณ
  4. คัดลอกรายงาน หรือบันทึกเป็น Markdown หรือ JSON การลองใช้ฟรีหนึ่งครั้งครอบคลุมแท็บไฟล์ที่เปิดอยู่หนึ่งแท็บ คุณจึงเปลี่ยนการตั้งค่าแล้วรันซ้ำในแท็บนั้นได้

Print check ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.3d-model-viewer แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/3d-model-viewer
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

3D Model Viewer ทำอะไรได้บ้าง

  • STL ทั้งแบบ binary และ ASCII พร้อมสีรายหน้าเมื่อไฟล์มีข้อมูลสี
  • OBJ พร้อมไฟล์ .mtl ที่ระบุใน mtllib เมื่อวางอยู่ข้างโมเดล
  • PLY ทั้ง mesh และ point cloud แบบ ASCII และ binary พร้อม vertex colours
  • 3MF ทั้ง objects, build items และสีวัสดุพื้นฐาน
  • GLB และ glTF 2.0 ที่มี buffer .bin แบบฝังในไฟล์หรือแยกไฟล์ พร้อม textures, PBR materials, node tree, skins, morph targets และแอนิเมชัน

สิ่งที่ยังทำไม่ได้

  • เปิดไฟล์ FBX, DAE, USD, STEP, IGES และ glTF 1.0 ไม่ได้
  • ยังไม่ถอดรหัส glTF ที่บีบอัดแบบ Draco และ meshopt และ textures แบบ KTX2 ระบบจะแสดงข้อความบอกชื่อ extension ที่ขาด
  • ไฟล์ทั้งไฟล์ถูกอ่านเข้าหน่วยความจำ ไฟล์ที่ใหญ่กว่า 1024 MB (การตั้งค่า modelViewer.maxFileMB) จะแสดงข้อความและไม่ถูกอ่าน
  • STL, OBJ และ PLY ไม่มีหน่วย ขนาดและระยะจึงเป็นค่าพิกัดดิบ glTF ใช้หน่วยเมตร และ 3MF ใช้หน่วยมิลลิเมตร เว้นแต่ไฟล์จะระบุเป็นอย่างอื่น
  • Print check และ Section view อ่านเฉพาะ mesh ที่มองเห็น สูงสุด 3 ล้าน triangles และต้องเป็น mesh ไม่ใช่ point cloud น้ำหนักเป็นค่าประมาณ และไม่นับ support, brim และชั้นบนสุดกับชั้นล่างสุด

คำถามที่พบบ่อย

ระยะที่วัดในไฟล์ STL เป็นหน่วยอะไร

ไฟล์ STL ไม่มีหน่วย ตัวแสดงผลจึงแสดงค่าพิกัดดิบ ส่วน Print check อ่าน STL, OBJ และ PLY เป็นมิลลิเมตร และเปลี่ยนหน่วยได้ในแผงของมันถ้าไฟล์ใช้หน่วยอื่น

เปิดไฟล์ OBJ พร้อม material ได้ไหม

ได้ เมื่อไฟล์ .mtl ที่ระบุใน mtllib วางอยู่ข้างโมเดล ส่วน textures และไฟล์ .bin จะโหลดได้เฉพาะจากโฟลเดอร์ของโมเดลและโฟลเดอร์ใน workspace ที่เปิดอยู่

ใช้ฟรีไหม

ใช้ได้ฟรี การเปิดโมเดล การวัดระยะ สถิติ scene tree และภาพหน้าจอไม่มีค่าใช้จ่าย Print check, Section view และ Turntable export เป็นเครื่องมือ Zovo Pro ที่ลองใช้ฟรีได้ตัวละ 3 ครั้ง หลังจากนั้นราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว
