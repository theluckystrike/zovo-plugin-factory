ดูตัวอย่างไฟล์ฟอนต์ใน VS Code

ติดตั้ง Font Viewer ซึ่งใช้ฟรี แล้วคลิกไฟล์ .ttf, .otf, .woff, .woff2 หรือ .ttc จะเห็นข้อความตัวอย่างของคุณเองในฟอนต์นั้น, waterfall หลายขนาด, glyph grid ที่ค้นหาได้ และ license กับสิทธิ์การฝังฟอนต์ (embedding rights) โดยไม่ต้องติดตั้งฟอนต์ลงเครื่อง Type tester, glyph grid, character map, แท็บ Info และ Copy CSS @font-face ใช้ฟรี Zovo Pro (19 ดอลลาร์สหรัฐ จ่ายครั้งเดียว) เพิ่มเครื่องมือ 2 ตัว คือ Convert Font และ Font Folder Report แต่ละตัวลองใช้ฟรีได้ 3 ครั้ง

ติดตั้งใน VS Codeหน้า MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

ใช้ฟรี ไลเซนส์ MIT รหัสส่วนขยาย zovo.font-viewer-vscode เวอร์ชัน 0.2.3

ขั้นตอนใน VS Code

  1. ติดตั้ง Font Viewer จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.font-viewer-vscode
  2. คลิกไฟล์ .ttf, .otf, .woff, .woff2, .ttc หรือ .otc ใน Explorer Font Viewer เป็น editor เริ่มต้นของไฟล์เหล่านี้ และไม่เปลี่ยนแปลงไฟล์ฟอนต์เลย
  3. ในแท็บ Type tester พิมพ์ข้อความของคุณเอง ลาก slider ขนาดตั้งแต่ 8 ถึง 200 px และดู waterfall ตั้งแต่ 12 ถึง 96 px ถ้าเป็น variable font ให้เลื่อน slider ของแต่ละ axis และเปิดปิด OpenType features เช่น liga หรือ ss01
  4. ในแท็บ Glyphs ค้นหาจากชื่อ ตัวอักษร U+20AC หรือ glyph id คลิก glyph เพื่อดูภาพใหญ่พร้อม baseline, x-height และ cap height แล้วคัดลอกตัวอักษร code point หรือ outline เป็น SVG ได้
  5. ในแท็บ Characters ดู coverage ของแต่ละ Unicode block เช่น "Basic Latin 95/128" ปิดตัวเลือก "Only characters in the font" เพื่อดูว่าขาดตัวอักษรอะไรบ้าง
  6. ในแท็บ Info อ่าน license, designer, copyright และ embedding rights แล้วคัดลอกกฎ @font-face ที่พร้อมใช้

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

การเปิดฟอนต์ทุกชนิดที่รองรับ, type tester, glyph grid, character map, แท็บ Info และ Copy CSS @font-face ใช้ฟรี Font Viewer ทำงานออฟไลน์ ไม่เรียกเครือข่ายและไม่มี telemetry

Font Folder Report แสดงรายการฟอนต์ทุกไฟล์ในโฟลเดอร์ พร้อม family, style, weight, axes, เวอร์ชัน, จำนวน glyph, license, URL ของ license และ embedding rights แล้วเขียนรายการเป็นไฟล์ CSV, ตาราง Markdown หรือไฟล์ fonts.css ไฟล์เดียวที่มีกฎ @font-face ของทุกฟอนต์ (WOFF2 มาก่อน) ก่อนนำฟอนต์ทั้งโฟลเดอร์ไปใช้ในแอปหรือเว็บไซต์ คุณจะเห็นว่าฟอนต์แต่ละตัวใช้ทำอะไรได้บ้างในไฟล์เดียว แทนที่จะเปิดทีละฟอนต์

วิธีใช้ Font Folder Report (Zovo Pro)

  1. คลิกขวาที่โฟลเดอร์ฟอนต์ใน Explorer แล้วเลือก "Font Folder Report: CSV, Markdown or @font-face CSS… (Pro)" หรือรัน "Font Viewer: Font Folder Report: CSV, Markdown or @font-face CSS… (Pro)" จาก Command Palette แล้วเลือกโฟลเดอร์
  2. เลือกรูปแบบ CSV, ตาราง Markdown หรือกฎ CSS @font-face
  3. บันทึกไฟล์ ชื่อเริ่มต้นคือ fonts-report.csv, fonts-report.md และ fonts.css ระบบนับการลองใช้เมื่อเขียนไฟล์เสร็จแล้วเท่านั้น

Font Folder Report ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.font-viewer-vscode แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/font-viewer-vscode
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

Font Viewer ทำอะไรได้บ้าง

  • ฟอนต์ TrueType .ttf และ OpenType .otf รวมถึง variable font
  • เว็บฟอนต์ .woff และ .woff2 โดย WOFF2 ถูกคลายด้วย decoder ของส่วนขยายเอง
  • ไฟล์ collection .ttc และ .otc มีรายการใน header ให้เลือก face
  • ฟอนต์ CJK ขนาดใหญ่ที่มี 20,000 glyph โดยโหลดเป็นหน้า ๆ ตามการเลื่อน
  • คลิกขวาที่ฟอนต์ใน Explorer แล้วเลือก Copy CSS @font-face ได้โดยไม่ต้องเปิดไฟล์

สิ่งที่ยังทำไม่ได้

  • ไม่รองรับ WOFF2 collections, SVG fonts, .dfont และ Type 1
  • outline ของ glyph แสดง default instance ของ variable font ส่วน type tester, waterfall และ character map เปลี่ยนตาม slider ของ axis
  • color font แสดงเป็นสีใน type tester และ character map แต่ glyph grid แสดงเป็น outline ธรรมดา
  • ไฟล์ที่ใหญ่กว่า 64 MB จะแสดงข้อความแทนการเปิด (การตั้งค่า fontViewer.maxFileMB)
  • เป็นแบบอ่านอย่างเดียว ไม่แก้ไขฟอนต์และไม่ติดตั้งฟอนต์ลงเครื่อง

คำถามที่พบบ่อย

ใช้ฟรีไหม

การดูฟอนต์, type tester, glyph grid, character map, แท็บ Info และ Copy CSS @font-face ใช้ฟรี เครื่องมือ Pro 2 ตัว คือ Convert Font และ Font Folder Report ลองใช้ฟรีได้อย่างละ 3 ครั้ง หลังจากนั้นต้องใช้ Zovo Pro ราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว

ต้องติดตั้งฟอนต์ก่อนไหม

ไม่ต้อง ฟอนต์ถูกอ่านจากไฟล์และแสดงเฉพาะในแท็บของ Font Viewer รายชื่อฟอนต์ในระบบของคุณไม่เปลี่ยน

เปิด WOFF2 จากโฟลเดอร์ build ได้ไหม

ได้ WOFF2 ถูกคลายด้วย decoder ของส่วนขยายเอง และหน้าที่เปิดอยู่จะโหลดใหม่เมื่อคุณบันทึก build ใหม่ของฟอนต์

ใช้ใน Cursor ได้ไหม

ได้ Font Viewer อยู่บน Open VSX ในชื่อ zovo/font-viewer-vscode Cursor, Windsurf และ VSCodium จึงติดตั้งได้
