คู่มือภาษาไทย

พรีวิวไดอะแกรม PlantUML ใน VS Code ขณะพิมพ์

ติดตั้ง PlantUML Viewer & Preview ซึ่งใช้ได้ฟรี เปิดไฟล์ .puml หรือไฟล์ Markdown ที่มีบล็อก plantuml แล้วคลิกปุ่มพรีวิว ไดอะแกรมจะถูกวาดข้างโค้ดของคุณขณะพิมพ์ โดย PlantUML jar ที่มาในส่วนขยายกับ Java 11 ขึ้นไปของคุณเอง จึงไม่มีอะไรถูกส่งไปเซิร์ฟเวอร์และไม่ต้องมี Graphviz พรีวิว การซูม ลิงก์ไปยัง error และการบันทึกไดอะแกรมทีละรูปเป็น SVG หรือ PNG ใช้ได้ฟรี Zovo Pro (19 ดอลลาร์สหรัฐ จ่ายครั้งเดียว) เพิ่มเครื่องมือ 3 ตัว คือ Export All Diagrams in a Folder, Markdown Diagrams to Images และ Compare with a Git Version และแต่ละตัวลองใช้ฟรีได้ 3 ครั้ง

ติดตั้งใน VS Codeหน้า MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

ใช้ฟรี ไลเซนส์ MIT รหัสส่วนขยาย zovo.zovo-plantuml-viewer เวอร์ชัน 0.1.0

คู่มือนี้มีภาษาอื่นด้วย English · Français · 한국어 · Polski · Português (Brasil) · Русский · 简体中文 · Türkçe · Bahasa Indonesia · Tiếng Việt · हिन्दी · Українська

ขั้นตอนใน VS Code

  1. ติดตั้ง PlantUML Viewer & Preview จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.zovo-plantuml-viewer
  2. ตรวจว่าติดตั้ง Java 11 หรือใหม่กว่าไว้แล้ว ส่วนขยายจะหาจากการตั้งค่า plantumlViewer.javaPath แล้วจาก JAVA_HOME แล้วจาก java ใน PATH แล้วจากโฟลเดอร์ JDK ที่ใช้กันทั่วไป ถ้าไม่พบเลย พรีวิวจะแจ้งและเสนอ "Set the Java path" คำสั่ง "PlantUML: Show Java and Layout Status" แสดงสิ่งที่หาเจอ
  3. เปิดไฟล์ .puml, .plantuml, .iuml, .pu หรือ .wsd หรือไฟล์ Markdown ที่มีบล็อก ```plantuml แล้วคลิกปุ่มพรีวิวที่มุมขวาบนของ editor หรือกด Alt+D ในไฟล์ PlantUML หรือรัน "PlantUML: Open Preview to the Side" ก็ได้
  4. พิมพ์ได้เลย พรีวิวจะวาดใหม่ไม่นานหลังจากคุณหยุดพิมพ์ (ค่าเริ่มต้น 400 ms การตั้งค่า plantumlViewer.renderDelay) ทุกไดอะแกรมในไฟล์แสดงในพรีวิวเดียวกัน และไดอะแกรมที่เคอร์เซอร์อยู่จะมีกรอบ
  5. ซูมด้วยปุ่ม ด้วย Ctrl หรือ Cmd กับล้อเมาส์ หรือด้วยปุ่ม + และ - คลิก Fit เพื่อให้พอดีกับความกว้างของแผง และลากไดอะแกรมเพื่อเลื่อนดู ไดอะแกรมที่มี error จะแสดงข้อความของ PlantUML พร้อมลิงก์ "Go to line"
  6. คลิก SVG หรือ PNG เหนือไดอะแกรมเพื่อบันทึกไดอะแกรมนั้น หรือคลิก Copy SVG เพื่อคัดลอก

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

พรีวิวแบบสดของไฟล์ .puml, .plantuml, .iuml, .pu และ .wsd และบล็อก plantuml ใน Markdown การซูมและเลื่อน error พร้อมลิงก์ไปยังบรรทัด การบันทึกไดอะแกรมทีละรูปเป็น SVG หรือ PNG, Copy SVG สีไวยากรณ์ snippet (seq, classd, activity, mindmap, gantt และอื่น ๆ) การพับโค้ด และ comment ใช้ได้ฟรี ไดอะแกรมถูกวาดบนเครื่องของคุณและไม่ถูกส่งไปเซิร์ฟเวอร์

เมื่อต้องนำไดอะแกรมของโปรเจกต์ไปใส่ในเอกสารหรือสไลด์ Export All Diagrams in a Folder จะเขียนทุกไดอะแกรมจากทุกไฟล์ PlantUML ในโฟลเดอร์และโฟลเดอร์ย่อยเป็น SVG, PNG หรือ PDF ในการรันครั้งเดียว โดยวางข้างแต่ละไฟล์หรือรวมไว้ในโฟลเดอร์เดียว ไดอะแกรมที่มี error จะถูกข้ามและแสดงในรายการพร้อมไฟล์ บรรทัด และข้อความ ส่วนที่เหลือจะถูกเขียนออกมา คุณจึงไม่ต้องเปิดทีละไฟล์และบันทึกทีละไดอะแกรมเอง

วิธีใช้ Export All Diagrams in a Folder (Zovo Pro)

  1. คลิกขวาที่โฟลเดอร์ใน Explorer แล้วเลือก "Zovo Pro: Export all diagrams in a folder" หรือคลิก "Export all diagrams in a folder" ในแถว Pro tools ของแถบเครื่องมือพรีวิว หรือรัน "PlantUML: Export All Diagrams in a Folder (Pro)" จาก Command Palette แล้วเลือกโฟลเดอร์
  2. เลือก SVG, PNG หรือ PDF แล้วเลือก "Next to each PlantUML file" หรือ "All in one folder..."
  3. เมื่อเสร็จ ข้อความจะบอกว่า export ไดอะแกรมไปกี่รูป คลิก "Show errors" เพื่อดูรายการไดอะแกรมที่มี error หรือ "Reveal" เพื่อดูไฟล์
  4. ระบบนับการลองใช้เฉพาะเมื่อเขียนรูปได้อย่างน้อยหนึ่งรูป การกด Escape หรือ Cancel หรือโฟลเดอร์ที่ไม่มีไฟล์ PlantUML จะไม่เสียสิทธิ์

Export All Diagrams in a Folder ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.zovo-plantuml-viewer แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/zovo-plantuml-viewer
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

PlantUML Viewer & Preview ทำอะไรได้บ้าง

  • ไดอะแกรม sequence, class, activity, component, state, use case, mind map, Gantt chart และบล็อก @start... อื่น ๆ ของ PlantUML ที่มาในตัว (MIT build 1.2026.10)
  • Markdown fence แบบ ```plantuml, ```puml และ ```uml จะมี @startuml อยู่ข้างในหรือไม่ก็ได้ ปุ่มพรีวิวจะแสดงในไฟล์ Markdown ที่มีบล็อกเหล่านี้อย่างน้อยหนึ่งบล็อก
  • !include ไฟล์จากโฟลเดอร์ของไดอะแกรม โฟลเดอร์ใน workspace และ plantumlViewer.includePaths รวมถึงไลบรารีมาตรฐาน เช่น !include <C4/C4_Container> แบบออฟไลน์ include ของ C4, ไอคอน AWS และ icon font ที่เขียนเป็นที่อยู่ https://raw.githubusercontent.com/... จะอ่านจากสำเนาใน jar
  • ไดอะแกรม sequence, mind map และ Gantt chart ไม่ต้องใช้ layout engine ส่วนไดอะแกรม class, component, state และ use case จะใช้ Graphviz เมื่อติดตั้ง dot ไว้ (plantumlViewer.layout ตั้งเป็น auto) และใช้เอนจิน Smetana ที่มีใน PlantUML เมื่อไม่ได้ติดตั้ง
  • ไดอะแกรมแสดงเป็นรูปภาพ ลิงก์หรือข้อความในไดอะแกรมจึงรันโค้ดใน editor ไม่ได้

สิ่งที่ยังทำไม่ได้

  • ต้องติดตั้ง Java 11 หรือใหม่กว่า ส่วนขยายไม่ดาวน์โหลด Java ให้
  • include จากที่อยู่เว็บจะถูกปฏิเสธ ยกเว้นที่อยู่ของ C4, ไอคอน AWS และ icon font ที่ jar มีสำเนาของตัวเอง ไอคอน AWS มาจากชุดไอคอน AWS ใน PlantUML (เวอร์ชัน 20) ไอคอนที่ใหม่กว่าจึงแสดง error พร้อมชื่อไอคอนนั้น
  • PlantUML รุ่น MIT ไม่มี Ditaa และไม่มีตัววาด LaTeX สำหรับ @startmath บล็อก Ditaa จะแสดงหน้า "not supported" ของ PlantUML
  • เมื่อไม่มี Graphviz เอนจิน Smetana จะจัดวางไดอะแกรม class และ component ต่างไปเล็กน้อย และไดอะแกรม class ที่ใหญ่มากอาจดูแน่นกว่า
  • ไดอะแกรมที่ใช้เวลานานกว่า 30 วินาที (การตั้งค่า plantumlViewer.renderTimeoutSeconds) จะถูกหยุด และรูปจะถูกตัดที่ 8192 พิกเซลต่อด้าน (การตั้งค่า plantumlViewer.maxImageSize)

คำถามที่พบบ่อย

ใช้ฟรีไหม

พรีวิวแบบสด การซูมและเลื่อน ลิงก์ไปยัง error การบันทึกไดอะแกรมทีละรูปเป็น SVG หรือ PNG สีไวยากรณ์ และ snippet ใช้ได้ฟรี เครื่องมือ Pro 3 ตัว คือ Export All Diagrams in a Folder, Markdown Diagrams to Images และ Compare with a Git Version ลองใช้ฟรีได้ตัวละ 3 ครั้ง หลังจากนั้นต้องใช้ Zovo Pro ราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว

ต้องมี Java หรือ Graphviz ไหม

ต้องมี Java 11 หรือใหม่กว่า เพราะ PlantUML เป็นโปรแกรม Java ส่วน Graphviz ไม่ต้องมี เมื่อไม่มี Graphviz ไดอะแกรม class และ component จะใช้ layout engine Smetana ที่มีใน PlantUML และถ้าติดตั้ง dot ไว้ ส่วนขยายจะใช้ dot

ไดอะแกรมของฉันถูกส่งไปเซิร์ฟเวอร์ไหม

ไม่ PlantUML jar ที่มาในตัวทำงานบนเครื่องของคุณด้วยโปรไฟล์ความปลอดภัย ALLOWLIST และ include จากที่อยู่เว็บจะถูกปฏิเสธ ไม่มีการใช้เซิร์ฟเวอร์ PlantUML

ใช้ใน Cursor ได้ไหม

ได้ Cursor, Windsurf และ VSCodium ติดตั้งได้จาก Open VSX ซึ่งเผยแพร่ในชื่อ zovo/zovo-plantuml-viewer
