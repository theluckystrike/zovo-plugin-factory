เปิดไฟล์ข้างใน ZIP โดยไม่ต้องแตกไฟล์

ติดตั้ง ZIP Viewer & Archive Explorer ซึ่งใช้ฟรี แล้วคลิกไฟล์ .zip, .jar, .vsix, .tar, .tar.gz หรือ .gz ส่วนขยายจะแสดงโฟลเดอร์และไฟล์ข้างใน และดับเบิลคลิกจะเปิดไฟล์ในแท็บปกติแบบอ่านอย่างเดียว โดยอ่านตรงจาก archive จึงไม่มีอะไรถูกแตกออกมา การเรียกดู การเปิดไฟล์ข้างใน การค้นหาชื่อ และการแตกไฟล์ใช้ฟรี Zovo Pro (19 ดอลลาร์สหรัฐ จ่ายครั้งเดียว) เพิ่มเครื่องมือสามตัว คือการเปรียบเทียบสอง archive การ export รายการไฟล์ และการค้นหาไฟล์ในทุก archive ของโฟลเดอร์ โดยลองใช้ฟรีได้ตัวละ 3 ครั้ง

ติดตั้งใน VS Codeหน้า MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

ใช้ฟรี ไลเซนส์ MIT รหัสส่วนขยาย zovo.zip-archive-explorer เวอร์ชัน 0.2.2

ขั้นตอนใน VS Code

  1. ติดตั้ง ZIP Viewer & Archive Explorer จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.zip-archive-explorer
  2. คลิกไฟล์ .zip, .jar, .vsix, .tar, .tar.gz, .tgz หรือ .gz ใน Explorer ไฟล์จะเปิดเป็นรายการโฟลเดอร์และไฟล์ พร้อมขนาด ขนาดหลังบีบอัด อัตราส่วน และวันที่ ส่วน .war, .whl, .nupkg, .apk หรือ .epub ให้คลิกขวาแล้วเลือก Open in Archive Explorer
  3. หาไฟล์ที่ต้องการ โดยดับเบิลคลิกโฟลเดอร์ ใช้แถบ path ด้านบน หรือกด Backspace เพื่อขึ้นไปหนึ่งระดับ หรือพิมพ์ในช่องค้นหา ซึ่งใช้ * และ ? เป็น wildcard ได้ เช่น *.json
  4. ดับเบิลคลิกไฟล์หรือกด Enter ไฟล์จะเปิดแบบอ่านอย่างเดียวในแท็บปกติ โค้ดจะมีสี syntax รูปภาพเปิดในพรีวิวรูปภาพ และ ZIP ที่อยู่ใน ZIP จะเปิดเป็นอีก archive หนึ่ง
  5. ส่วน Archive Explorer ในแถบด้านข้างของ Explorer จะแสดงทุก archive ที่คุณเปิด คลิกขวาที่รายการตรงนั้นเพื่อใช้ Open to the Side, Extract... หรือ Copy Path
  6. ถ้าจะแก้ไฟล์ ให้เลือกไฟล์แล้วคลิก Extract... ไฟล์เดียวจะผ่านหน้าต่างบันทึก ชื่อที่มี .. หรือ path แบบ absolute จะไม่ถูกเขียนลงดิสก์ และตัว archive จะไม่ถูกแก้ไขเลย

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

การเรียกดู archive การเปิดไฟล์ข้างในเป็นแท็บ การค้นหาชื่อ tree ในแถบด้านข้าง Copy Path และการแตกไฟล์ใช้ฟรี ส่วนขยายทำงานออฟไลน์ ไม่เชื่อมต่อเครือข่าย และไม่มี telemetry

เมื่อคุณรู้ชื่อไฟล์แต่ไม่รู้ว่าอยู่ใน archive ของ build, backup หรือ release ตัวไหน การเปิดทีละ archive ใช้เวลานานเกินไป Find a file in all archives of a folder จะค้นชื่อไฟล์ข้างในของทุกไฟล์ ZIP, JAR, WAR, VSIX, TAR และ GZ ใต้โฟลเดอร์ แสดงทุกรายการที่ตรงพร้อม archive และ path ของมัน และเปิดรายการที่คุณเลือกในแท็บแบบอ่านอย่างเดียว เครื่องมือนี้ไม่เขียนไฟล์ใด ๆ

วิธีใช้ Find a file in all archives of a folder (Zovo Pro)

  1. รัน "Archive Explorer: Find a File in All Archives of a Folder... (Pro)" จาก Command Palette แล้วเลือกโฟลเดอร์ที่จะค้น หรือคลิกขวาที่โฟลเดอร์ใน Explorer แล้วเลือก "Zovo Pro: Find a file in all archives of a folder"
  2. พิมพ์ชื่อไฟล์ ซึ่งใช้ * และ ? เป็น wildcard ได้ เช่น log4j*.jar หรือ *.properties
  3. เลือกรายการที่ตรงจากลิสต์ ไฟล์จะเปิดแบบอ่านอย่างเดียวในแท็บเหมือนไฟล์อื่นใน archive สิทธิ์ลองใช้จะถูกนับเฉพาะเมื่อมีผลลัพธ์อย่างน้อยหนึ่งรายการ

Find a file in all archives of a folder ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.zip-archive-explorer แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/zip-archive-explorer
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

ZIP Viewer & Archive Explorer ทำอะไรได้บ้าง

  • ZIP, JAR และ VSIX ที่มี entry แบบ Stored และ Deflate รวมถึง ZIP64 และ archive แบบ self-extracting
  • TAR (ustar, ชื่อยาวแบบ GNU และ pax header), TAR.GZ, TGZ และไฟล์ GZ เดี่ยว
  • WAR, EAR, WHL, NUPKG, APK, AAR, XPI และ EPUB ผ่าน Open in Archive Explorer
  • archive ที่มีได้ถึง 200,000 entry ซึ่งอ่านจากดิสก์ด้วย range read ไฟล์ ZIP ใหญ่จึงไม่ถูกโหลดทั้งไฟล์

สิ่งที่ยังทำไม่ได้

  • entry ที่บีบอัดด้วย BZIP2, LZMA, Zstandard หรือ Deflate64 และ entry ที่เข้ารหัส จะแสดงในรายการแต่เปิดไม่ได้
  • ไม่รองรับไฟล์ 7z, RAR, XZ และ BZ2
  • entry เป็นแบบอ่านอย่างเดียว ถ้าจะแก้ต้องแตกไฟล์ออกมาก่อน
  • entry ที่ใหญ่กว่า 512 MB จะไม่เปิดในแท็บ แต่ยังแตกไฟล์ออกมาได้ ส่วน .tar.gz จะถูกคลายในหน่วยความจำ โดยค่าเริ่มต้นได้ถึง 2 GB

คำถามที่พบบ่อย

ใช้ฟรีไหม

การเรียกดู archive การเปิดไฟล์ข้างใน การค้นหาชื่อ tree ในแถบด้านข้าง และการแตกไฟล์ใช้ฟรี เครื่องมือ Pro ทั้งสามตัว คือ Compare two archives, Export the entry list และ Find a file in all archives of a folder ลองใช้ฟรีได้ตัวละ 3 ครั้ง หลังจากนั้นต้องใช้ Zovo Pro ราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว

ตอนเปิด ไฟล์ถูกคัดลอกไปไว้ในโฟลเดอร์ temp หรือไม่

ไม่ entry ถูกอ่านจาก archive เข้าแท็บแบบอ่านอย่างเดียวโดยตรง มีแค่ Extract ที่เขียนไฟล์ลงดิสก์

แก้ไฟล์ที่อยู่ใน ZIP ได้ไหม

ไม่ได้ entry เป็นแบบอ่านอย่างเดียว และ archive จะไม่ถูกแก้ไข ให้แตกไฟล์ออกมา แก้ไข แล้วแพ็ก archive ใหม่ด้วยเครื่องมืออื่น

ใช้ใน Cursor ได้ไหม

ได้ ZIP Viewer & Archive Explorer อยู่บน Open VSX ทั้ง Cursor, Windsurf และ VSCodium จึงติดตั้งได้
