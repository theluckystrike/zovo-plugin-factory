เปิด JAR และอ่านซอร์ส Java ที่ decompile แล้วใน VS Code

ติดตั้ง JAR Viewer & Java Decompiler ซึ่งใช้ฟรี แล้วคลิกไฟล์ .jar, .war, .ear, .aar หรือ .class ส่วนขยายจะแสดงแพ็กเกจ รีซอร์ส MANIFEST.MF และเวอร์ชัน Java ของแต่ละคลาส รายการ bytecode แบบ javap -c -p ที่ไม่ต้องใช้ Java และซอร์ส Java ที่ decompile ด้วย CFR 0.152 ซึ่งมาพร้อมส่วนขยาย โดยใช้ Java runtime เวอร์ชัน 8 ขึ้นไปที่มีอยู่บนเครื่องของคุณ ทุกมุมมองและการ decompile ทีละคลาสใช้ฟรี Zovo Pro (19 ดอลลาร์สหรัฐ จ่ายครั้งเดียว) เพิ่มเครื่องมือสามตัว คือการ export ซอร์สที่ decompile แล้วของทั้ง JAR การเปรียบเทียบ JAR สองตัว และการค้นหาในทุก JAR ของโฟลเดอร์ โดยลองใช้ฟรีได้ตัวละ 3 ครั้ง

ขั้นตอนใน VS Code

  1. ติดตั้ง JAR Viewer จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.zovo-jar-viewer
  2. คลิกไฟล์ .jar, .war, .ear, .aar หรือ .class ใน Explorer ไฟล์จะเปิดใน JAR Viewer หน้า Overview แสดงรูปแบบไฟล์ จำนวน entry คลาสและแพ็กเกจ, Main-Class, Created by, MANIFEST.MF และแผนภูมิเวอร์ชัน Java ที่ใช้คอมไพล์คลาส
  3. พิมพ์ชื่อบางส่วนในช่องกรองเหนือ tree ของแพ็กเกจ ช่องนี้จะหาคลาสและไฟล์ไปพร้อมกับที่คุณพิมพ์ ส่วน inner class จะแสดงเป็นสีจางอยู่ใต้คลาสภายนอกของมัน
  4. คลิกคลาส แท็บ Java source จะแสดงคลาสนั้นที่ decompile ด้วย CFR 0.152 พร้อม inner class ของมัน ปุ่ม Copy คัดลอกซอร์สไปที่คลิปบอร์ด และ Open in editor เปิดซอร์สในแท็บ editor ปกติ
  5. ถ้าแท็บ Java source บอกว่าซอร์ส Java ที่ decompile ต้องใช้ Java runtime ให้ตั้ง jarViewer.javaPath เป็นไฟล์ java หรือโฟลเดอร์ JDK หรือตั้ง JAVA_HOME คำสั่ง "JAR Viewer: Check the Java runtime used for decompiling" จะบอกว่ากำลังใช้ Java ตัวไหน
  6. เปิดแท็บ Bytecode เพื่อดูรายการแบบ javap -c -p ที่มีทุก opcode ตาราง exception และเลขบรรทัด ส่วนแท็บ Members, Constant pool และ Class info แสดง declaration, entry ใน constant pool และ attribute ของคลาส
  7. ใน JAR ของ Spring Boot, WAR หรือ AAR ให้คลิก JAR ที่อยู่ใน BOOT-INF/lib หรือ WEB-INF/lib หรือ classes.jar ของ AAR แล้วคลิก "Open nested archive" ไฟล์จะเปิดลึกลงไปหนึ่งชั้น และปุ่มที่มีชื่อไฟล์ภายนอกอยู่ด้านบนจะพาคุณกลับไป

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

tree ของแพ็กเกจ, Overview, manifest, รีซอร์ส, ซอร์ส Java ที่ decompile แล้ว, bytecode, Members, Constant pool, Class info และ nested JAR ใช้ฟรีโดยไม่ต้องล็อกอิน CFR มาพร้อมส่วนขยายและทำงานด้วย Java ที่มีอยู่แล้วบนเครื่องของคุณ ส่วนขยายไม่แก้ไข archive และไม่เชื่อมต่อเครือข่าย

Export decompiled sources of a JAR จะ decompile ทุกคลาสใน JAR, WAR, EAR หรือ AAR ด้วย CFR แล้วเขียนไฟล์ .java ลงโฟลเดอร์ พร้อมแสดงความคืบหน้าและมีปุ่ม Cancel ถ้าไม่มี Java runtime จะเขียนรายการ bytecode แทน คุณจะได้ไลบรารีทั้งชุดเป็นไฟล์ซอร์สไว้ค้นหาหรืออ่านใน editor แทนที่จะเปิดทีละคลาส

วิธีใช้ Export decompiled sources of a JAR (Zovo Pro)

  1. เปิด archive แล้วคลิก "Export sources…" ที่ด้านบนของ viewer หรือ "Export decompiled sources" ในแถบ Pro tools เล็ก ๆ หรือคลิกขวาที่ไฟล์ใน Explorer แล้วเลือก "Zovo Pro: Export decompiled sources"
  2. หรือรัน "JAR Viewer: Export decompiled sources of a JAR (Pro)" จาก Command Palette ถ้ายังไม่ได้เปิด archive ไว้ คำสั่งจะให้คุณเลือกไฟล์ JAR, WAR, EAR หรือ AAR
  3. เลือกโฟลเดอร์แล้วคลิก "Export here" ซอร์สจะถูกเขียนลงโฟลเดอร์ใหม่ที่ตั้งชื่อตาม archive และต่อท้ายด้วย -src
  4. การแจ้งเตือนจะแสดงความคืบหน้า Cancel จะหยุดการ export และไม่นับสิทธิ์ลองใช้ เมื่อเสร็จแล้ว viewer จะบอกว่าเขียนไฟล์ไปกี่ไฟล์และเขียนไว้ที่ไหน

Export decompiled sources of a JAR ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.zovo-jar-viewer แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/zovo-jar-viewer
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

JAR Viewer ทำอะไรได้บ้าง

  • archive แบบ JAR, WAR, EAR และ AAR และไฟล์ .class เดี่ยวพร้อม inner class ที่อยู่ในโฟลเดอร์เดียวกัน
  • archive ที่มีได้ถึง 200,000 entry และช่องกรองที่หาคลาสหรือไฟล์จาก 50,000 entry ได้ขณะพิมพ์
  • generic signature, record, permitted subclass, nest host และ annotation ในข้อมูลคลาส
  • รีซอร์สแบบข้อความ เช่น properties, XML, JSON, SQL และไฟล์ services แสดงเป็นข้อความ ส่วนไฟล์ไบนารีแสดงพรีวิวแบบ hex
  • archive ใน BOOT-INF/lib ของ Spring Boot, WEB-INF/lib ของ WAR และ classes.jar ของ AAR ลึกหนึ่งชั้น

สิ่งที่ยังทำไม่ได้

  • ซอร์สที่ decompile ต้องใช้ Java 8 ขึ้นไปบนเครื่องของคุณ ถ้าไม่มี Java แท็บ bytecode และมุมมองอื่นทั้งหมดยังใช้งานได้
  • ผลลัพธ์ของ CFR อาจต่างจากซอร์สต้นฉบับ เช่น ชื่อตัวแปรโลคัล generics บางส่วน และ lambda
  • entry แตกได้ถึง 64 MB ต่อรายการ class file ถึง 16 MB และ nested archive ถึง 128 MB ไฟล์บนระบบไฟล์ระยะไกลหรือระบบไฟล์เสมือนอ่านได้ถึง 256 MB
  • ส่วนขยายเป็นแบบอ่านอย่างเดียว จึงแก้ไขหรือคอมไพล์คลาสใหม่ไม่ได้ และ nested archive เปิดได้ลึกแค่หนึ่งชั้น
  • ไม่อ่านไฟล์ APK และ DEX

คำถามที่พบบ่อย

ใช้ฟรีไหม

ใช้ฟรี ทุกมุมมองและการ decompile ทีละคลาสใช้ฟรี เครื่องมือ Pro ทั้งสามตัว คือ Export decompiled sources of a JAR, Compare two JARs และ Find in every JAR of a folder ลองใช้ฟรีได้ตัวละ 3 ครั้ง และจะนับสิทธิ์ก็ต่อเมื่อเครื่องมือให้ผลลัพธ์ หลังจากนั้นต้องใช้ Zovo Pro ราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว

ทำไมแท็บ Java source ถึงขอ Java

CFR เป็นโปรแกรม Java ตัว viewer จะหา Java จาก jarViewer.javaPath ก่อน ต่อด้วย JAVA_HOME แล้วจึงเป็น java บน PATH ของคุณ Java runtime เวอร์ชัน 8 ขึ้นไปใช้ได้ทั้งหมด

อ่าน bytecode โดยไม่มี Java ได้ไหม

ได้ แท็บ Bytecode, Members, Constant pool และ Class info อ่านด้วย JavaScript และไม่ต้องใช้ Java

ใช้ใน Cursor ได้ไหม

ได้ ส่วนขยายนี้อยู่บน Open VSX ในชื่อ zovo/zovo-jar-viewer ทั้ง Cursor, Windsurf และ VSCodium จึงติดตั้งได้
