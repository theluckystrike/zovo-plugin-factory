คู่มือภาษาไทย

แก้ไฟล์ .env ใน VS Code โดยไม่ให้ค่าลับโชว์บนหน้าจอ

ติดตั้ง Dotenv & .env File Editor ซึ่งใช้ได้ฟรี แล้วเปิดไฟล์ .env key และค่าจะมีสี และค่าของ key อย่าง DB_PASSWORD หรือ STRIPE_SECRET_KEY จะแสดงเป็นจุดจนกว่าเคอร์เซอร์จะอยู่บรรทัดนั้น คุณจึงแชร์หน้าจอได้ การแจ้งปัญหาพร้อม quick fix, Format Document, outline ของ key และ hover ที่ process.env.X ในโค้ดใช้ได้ฟรีและทำงานออฟไลน์ Zovo Pro (19 ดอลลาร์สหรัฐ จ่ายครั้งเดียว) เพิ่มเครื่องมือ 3 ตัว คือ Compare .env with .env.example, Find Keys Missing in Code or .env และ Convert .env to JSON, YAML, Kubernetes และแต่ละตัวลองใช้ฟรีได้ 3 ครั้ง

ติดตั้งใน VS Codeหน้า MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

ใช้ฟรี ไลเซนส์ MIT รหัสส่วนขยาย zovo.zovo-dotenv เวอร์ชัน 0.1.0

ขั้นตอนใน VS Code

  1. ติดตั้ง Dotenv & .env File Editor จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.zovo-dotenv
  2. เปิดไฟล์ .env (รวมถึง .env.local, .env.production, *.env หรือ .flaskenv) key, export, ค่า, ค่าหลายบรรทัด และการอ้างอิง ${NAME} จะมีสี
  3. ค่าที่ดูเหมือนค่าลับจะแสดงเป็นจุดจนกว่าเคอร์เซอร์จะอยู่บรรทัดนั้น คลิกปุ่มรูปตาในแถบชื่อ editor หรือรัน "Dotenv: Show or Hide Secret Values" เพื่อแสดงทั้งหมด ไฟล์ template อย่าง .env.example จะไม่ถูกซ่อนเลย
  4. ปัญหาจะแสดงในแผง Problems ได้แก่ key ที่ตั้งค่าสองครั้ง ช่องว่างรอบ = เครื่องหมายคำพูดที่ไม่ปิด บรรทัดที่ไม่มี = ชื่อที่ไม่ถูกต้อง ช่องว่างท้ายบรรทัด หรือ ${NAME} ที่ไม่มีบรรทัดไหนตั้งค่า กด Ctrl+. (บน Mac กด Cmd+.) ที่ปัญหาเพื่อดูวิธีแก้
  5. รัน Format Document เพื่อลบช่องว่างรอบ = และช่องว่างท้ายบรรทัด comment ลำดับ และเครื่องหมายคำพูดยังคงเดิม
  6. ถ้าจะคัดลอกค่าโดยไม่ให้แสดงบนจอ ให้รัน "Dotenv: Copy the Value on This Line" คำสั่งนี้คัดลอกค่าโดยตัดเครื่องหมายคำพูดและ escape ออก แม้ค่านั้นจะซ่อนอยู่
  7. ในโค้ดของคุณ ให้ hover ที่ process.env.DB_HOST, os.getenv("X"), System.getenv("X") หรือรูปแบบคล้ายกัน เพื่อดูว่าไฟล์ .env ไหนตั้งค่านั้น และกด F12 เพื่อเปิดบรรทัดนั้น

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

การไฮไลต์ไวยากรณ์ การซ่อนค่าลับ การแจ้งปัญหาพร้อม quick fix, Format Document, outline ของ key, Copy the Value on This Line รวมทั้ง hover, go to definition และ completion ในโค้ดใช้ได้ฟรี ไม่ต้องมีบัญชี ไม่มีการเรียกเครือข่าย และไม่มี telemetry

Compare .env with .env.example แสดงรายการ key ที่ .env ขาดไป key ที่ .env.example ไม่ได้ระบุไว้ และ key ที่ว่างอยู่ ในรายงานข้างไฟล์ จากนั้นปุ่มต่าง ๆ จะเพิ่ม key ที่ขาดลงในไฟล์ใดไฟล์หนึ่ง คือเพิ่มลง .env พร้อมค่าจากไฟล์ตัวอย่าง หรือเพิ่มลง .env.example โดยเว้นค่าว่าง ค่าจาก .env จะไม่ถูกแสดงหรือคัดลอกเลย คุณจึงปรับการตั้งค่าของเพื่อนร่วมทีมหรือ deploy ที่ล้มเหลวให้ตรงกันได้โดยไม่ต้องอ่านไฟล์ทีละบรรทัด

วิธีใช้ Compare .env with .env.example (Zovo Pro)

  1. คลิกขวาที่ไฟล์ .env ใน Explorer แล้วเลือก "Zovo Pro: Compare .env with .env.example" หรือรัน "Dotenv: Compare .env with .env.example (Pro)..." จาก Command Palette คำสั่งจะใช้ไฟล์ .env ในแท็บที่ใช้งานอยู่ หรือถามว่าจะใช้ไฟล์ไหน
  2. ถ้าไม่มี .env.example, .env.sample, .env.template หรือ .env.dist อยู่ข้างไฟล์ ให้เลือก "Create .env.example next to .env" หรือ "Pick another file..."
  3. อ่านรายงานที่เปิดข้างไฟล์ แล้วคลิก "Add N keys to .env.example (empty values)" หรือ "Add N keys to .env (example values)" เพื่อเพิ่ม key
  4. ระบบนับการลองใช้เฉพาะเมื่อรายงานเปิดขึ้นแล้ว การกด Escape หรือ Cancel ไม่เสียสิทธิ์

Compare .env with .env.example ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.zovo-dotenv แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/zovo-dotenv
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

Dotenv & .env File Editor ทำอะไรได้บ้าง

  • ไฟล์ .env, .env.* (เช่น .env.local และ .env.production), *.env และ .flaskenv
  • ค่าที่ถูกซ่อน คือชื่อที่มี PASSWORD, TOKEN, SECRET, API_KEY, DSN, DATABASE_URL และคำคล้ายกัน หรือซ่อนทุกค่า หรือไม่ซ่อนเลย (การตั้งค่า envFile.maskValues)
  • hover และ go to definition ในโค้ดสำหรับ process.env และ import.meta.env (JavaScript, TypeScript), os.environ และ os.getenv (Python), os.Getenv (Go), ENV (Ruby), System.getenv (Java), env() (PHP) และอื่น ๆ
  • completion ของ key หลัง process.env.
  • ค่าที่ซ่อนไว้ยังซ่อนอยู่ใน outline, hover และ completion เว้นแต่คุณปิดไว้ (การตั้งค่า envFile.hoverShowsSecrets)

สิ่งที่ยังทำไม่ได้

  • การซ่อนมีผลแค่บนหน้าจอ ข้อความจริงยังอยู่ในไฟล์ ในผลการค้นหา และในรูปทรงของ minimap และการคัดลอกและวางจะได้ค่าจริง
  • .envrc (direnv) เป็น shell script จึงปล่อยให้ส่วนขยายสำหรับ shell จัดการ
  • รายงานจากโค้ดเห็นเฉพาะชื่อที่เขียนตรง ๆ เช่น process.env.API_KEY ชื่อที่สร้างตอนโปรแกรมทำงานจะหาไม่เจอ
  • การแจ้งปัญหาใช้กฎของแพ็กเกจ dotenv เครื่องมือบางตัว (Docker Compose v1, systemd) เข้มงวดกว่า ซึ่งคำเตือนจะชี้ให้เห็น

คำถามที่พบบ่อย

ใช้ฟรีไหม

สี การซ่อนค่า การแจ้งปัญหาพร้อม quick fix การจัดรูปแบบ และ hover ในโค้ดใช้ได้ฟรี เครื่องมือ Pro 3 ตัว คือ Compare .env with .env.example, Find Keys Missing in Code or .env และ Convert .env to JSON, YAML, Kubernetes ลองใช้ฟรีได้ตัวละ 3 ครั้ง หลังจากนั้นต้องใช้ Zovo Pro ราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว

ส่วนขยายแก้ไฟล์ .env เพื่อซ่อนค่าไหม

ไม่ เปลี่ยนเฉพาะการแสดงผล ไฟล์ไม่ถูกแก้ไขเลย และการคัดลอกและวางยังได้ค่าจริง

ทำไม key ของฉันถูกแจ้งว่าตั้งค่าสองครั้ง

key เดียวกันอยู่ในสองบรรทัด แพ็กเกจ dotenv ใช้ค่าแรก ส่วน shell และ Docker Compose ใช้ค่าสุดท้าย quick fix จะลบบรรทัดที่สองออก

ใช้ใน Cursor ได้ไหม

ได้ Cursor, Windsurf และ VSCodium ติดตั้งได้จาก Open VSX ซึ่งเผยแพร่ในชื่อ zovo/zovo-dotenv
