ดูไฟล์ NumPy .npy และ .npz ใน VS Code

ติดตั้ง Tensor Viewer (NPZ Viewer & NPY Viewer) ซึ่งใช้ได้ฟรี แล้วคลิกไฟล์ .npy หรือ .npz ทุกอาร์เรย์จะแสดงพร้อมชื่อ dtype และ shape และเมื่อคลิกอาร์เรย์จะเห็น min, max, mean, std, จำนวน NaN, กราฟ, ฮิสโตแกรม และค่าข้างใน โดยไม่ต้องมี Python การดูข้อมูล รูปภาพ ตาราง Values และการบันทึกเป็น .npy หรือ CSV ใช้ได้ฟรี Zovo Pro (19 ดอลลาร์สหรัฐ จ่ายครั้งเดียว) เพิ่มเครื่องมือ 2 ตัวคือ Compare two checkpoints และ Scan all tensors และแต่ละตัวลองใช้ฟรีได้ 3 ครั้ง

ติดตั้งใน VS Codeหน้า MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

ใช้ฟรี ไลเซนส์ MIT รหัสส่วนขยาย zovo.tensor-viewer เวอร์ชัน 0.6.5

ขั้นตอนใน VS Code

  1. ติดตั้ง Tensor Viewer จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.tensor-viewer
  2. คลิกไฟล์ .npy หรือ .npz ใน Explorer ตารางจะแสดงทุกอาร์เรย์พร้อมชื่อ ชนิดข้อมูล shape จำนวนพารามิเตอร์ และขนาด
  3. คลิกอาร์เรย์ที่ต้องการ แผงด้านขวาจะแสดง min, max, mean, std และจำนวน NaN, Inf และค่าศูนย์ ตามด้วยฮีตแมปสำหรับอาร์เรย์ 2 มิติหรือกราฟเส้นสำหรับอาร์เรย์ 1 มิติ และฮิสโตแกรม
  4. อ่านตัวเลขในตาราง Values ทีละ 32 แถว สำหรับอาร์เรย์ที่มี 3 มิติขึ้นไป ให้พิมพ์ slice เช่น [5, :, :] ในช่อง Slice
  5. ถ้าอาร์เรย์มี shape แบบรูปภาพ เช่น (H, W, 3) หรือ (N, 3, H, W) ส่วน Image จะวาดเป็นภาพให้ และเลือก Layout, Frame และ Range ได้ในส่วนนั้น ส่วนเมทริกซ์ float จะมีปุ่ม "Show as image" แทน
  6. คลิก "Save as .npy..." หรือ "Save as CSV..." เพื่อบันทึกอาร์เรย์หรือ slice ลงไฟล์ใหม่

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

ทุกฟอร์แมต สถิติ ฮีตแมป กราฟเส้น ฮิสโตแกรม รูปภาพ ตาราง Values การดู slice อาร์เรย์แบบ raw และการบันทึกเป็น .npy หรือ CSV ใช้ได้ฟรีทั้งหมด ไม่ต้องมี Python และตัวแสดงผลไม่เรียกเครือข่ายเลย

Scan all tensors อ่านทุกค่าของทุกอาร์เรย์ในไฟล์ ไม่ใช่แค่ตัวอย่าง และแจ้งอาร์เรย์ที่มี NaN หรือ Inf อาร์เรย์ที่เป็นศูนย์ทั้งหมดหรือเป็นค่าคงที่ และค่า float ตั้งแต่ 10,000 ขึ้นไป รายงานเดียวจะแสดง min, max, mean, std และ L2 norm ที่แม่นยำของแต่ละอาร์เรย์ กรองได้ และบันทึกเป็น CSV, Markdown หรือ JSON ได้ คุณจึงหาอาร์เรย์ที่เสียในไฟล์ .npz ขนาดใหญ่ได้โดยไม่ต้องคลิกดูทีละตัว

วิธีใช้ Scan all tensors (Zovo Pro)

  1. เปิดไฟล์แล้วคลิกปุ่ม "Scan all tensors" ที่ด้านบนของตัวแสดงผล หรือคลิกขวาที่ไฟล์ใน Explorer แล้วเลือก "Zovo Pro: Scan Tensors for NaN, Inf and Zeros"
  2. หรือรัน "NumPy Viewer Pro: Scan All Tensors for NaN, Inf and Zeros" จาก Command Palette แล้วเลือกไฟล์
  3. การแจ้งเตือนจะแสดงความคืบหน้า และ Cancel ใช้หยุดการสแกนที่ใช้เวลานาน ในรายงาน ให้ใช้ตัวกรอง "Only tensors to check" แล้วบันทึกรายงานเป็น CSV, Markdown หรือ JSON

Scan all tensors ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.tensor-viewer แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/tensor-viewer
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

Tensor Viewer ทำอะไรได้บ้าง

  • ไฟล์ .npy ที่มี header v1, v2 และ v3 ทั้ง C order และ Fortran order และ byte order ได้ทั้งสองแบบ
  • ไฟล์ .npz ที่เก็บ entry แบบไม่บีบอัดหรือบีบอัดด้วย deflate รวมถึง zip64
  • bool, int8 ถึง int64, uint8 ถึง uint64, float16, float32, float64 และจำนวนเชิงซ้อน (คำนวณสถิติจาก magnitude)
  • อาร์เรย์ที่มี shape แบบรูปภาพ สแต็ก และแบตช์ วาดเป็นภาพทีละเฟรม
  • ส่วนขยายเดียวกันนี้เปิดไฟล์ .safetensors, .gguf และไฟล์ PyTorch .pt, .pth และ .ckpt ได้ด้วย

สิ่งที่ยังทำไม่ได้

  • อาร์เรย์ object ที่เก็บแบบ pickle จะแสดงในรายการแต่ถูกปฏิเสธ และไม่ถูกรันเด็ดขาด อาร์เรย์ข้อความและอาร์เรย์แบบ structured แสดงในรายการแต่ไม่มีสถิติ
  • อาร์เรย์ที่มีมากกว่า 2,000,000 ค่าจะใช้การสุ่มตัวอย่างเพื่อคำนวณสถิติและวาดกราฟ (การตั้งค่า tensorViewer.sampleValues) และแผงจะบอกเมื่อสถิติมาจากตัวอย่าง
  • entry ที่บีบอัดใน .npz อ่านได้จากช่วงต้นเท่านั้น ค่าที่อยู่หลัง 64 MB แรกจะไม่แสดง และ entry ที่ใหญ่กว่า 512 MB บันทึกไม่ได้
  • ภาพที่วาดมีขนาดไม่เกิน 512 พิกเซลด้านยาว อาร์เรย์ 2 channel และอาร์เรย์ Fortran order ไม่มีมุมมองภาพ
  • การ export เป็น CSV หยุดที่ 20 ล้านค่า ค่า int64 ที่เกิน 2^53 จะเสียหลักท้าย ๆ ในตารางและใน CSV

คำถามที่พบบ่อย

ใช้ฟรีไหม

การเปิดไฟล์ .npy และ .npz สถิติ กราฟ รูปภาพ ตาราง Values และการบันทึกเป็น .npy หรือ CSV ใช้ได้ฟรี เครื่องมือ Pro 2 ตัวคือ Compare two checkpoints และ Scan all tensors ลองใช้ฟรีได้ตัวละ 3 ครั้ง หลังจากนั้นต้องใช้ Zovo Pro ราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว

ต้องมี Python ไหม

ไม่ต้อง Tensor Viewer อ่านไฟล์เองได้ จึงไม่ต้องติดตั้ง Python หรือ NumPy

เปิดไฟล์ .npy ที่ได้มาจากอินเทอร์เน็ตปลอดภัยไหม

ไม่มีส่วนใดในไฟล์ถูกรัน อาร์เรย์ object ซึ่ง NumPy เก็บเป็น pickle จะแสดงในรายการแต่ถูกปฏิเสธ และตัวแสดงผลไม่แก้ไขไฟล์ที่เปิดอยู่เลย

ใช้ใน Cursor ได้ไหม

ได้ Tensor Viewer อยู่บน Open VSX ในชื่อ zovo/tensor-viewer จึงติดตั้งใน Cursor, Windsurf และ VSCodium ได้
