พรีวิวไดอะแกรม Mermaid ใน VS Code

VS Code ไม่มีพรีวิว Mermaid ในตัว ให้ติดตั้ง Mermaid Viewer ซึ่งใช้ได้ฟรี เปิดไฟล์ .mmd หรือ .mermaid แล้วคลิกไอคอนพรีวิวที่มุมขวาบนของ editor ไดอะแกรมจะเปลี่ยนตามที่คุณพิมพ์ ส่วนในไฟล์ Markdown พรีวิวจะแสดงบล็อก mermaid ทุกบล็อก Mermaid 12.3.0 มาพร้อมกับส่วนขยาย พรีวิวและการ export เป็น PNG หรือ SVG จึงใช้ได้ฟรีแบบออฟไลน์โดยไม่ต้องล็อกอิน Zovo Pro (19 ดอลลาร์สหรัฐ จ่ายครั้งเดียว) เพิ่มการ export เป็น PDF การ export ทุกไดอะแกรมใน workspace และการ export เมื่อบันทึก และแต่ละอย่างลองใช้ฟรีได้ 3 ครั้ง

ติดตั้งใน VS Codeหน้า MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

ใช้ฟรี ไลเซนส์ MIT รหัสส่วนขยาย zovo.mermaid-viewer เวอร์ชัน 0.3.4

ขั้นตอนใน VS Code

  1. ติดตั้ง Mermaid Viewer จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.mermaid-viewer
  2. เปิดไฟล์ .mmd หรือ .mermaid แล้วคลิกไอคอนพรีวิวในแถบชื่อของ editor หรือกด Ctrl+K V (Cmd+K V บน macOS) จะรัน "Mermaid Viewer: Open Diagram Editor (Text + Live Preview)" จาก Command Palette ก็ได้
  3. สำหรับไฟล์ Markdown ที่มีบล็อก ```mermaid ให้คลิกไอคอนพรีวิวเดียวกัน พรีวิวจะแสดงทุกไดอะแกรม และแต่ละอันมีบรรทัดแสดงข้อผิดพลาดและปุ่ม export ของตัวเอง
  4. คลิก "Edit diagram" เหนือบล็อกในไฟล์ Markdown เพื่อแก้บล็อกนั้นข้างพรีวิวสด เมื่อบันทึก ข้อความจะกลับเข้าไปในบล็อกเดิม
  5. เลื่อนล้อเมาส์เพื่อซูมตรงตำแหน่งเมาส์ และลากเพื่อเลื่อนภาพ ปุ่ม Fit และ 100% อยู่ในแถบเครื่องมือ
  6. คลิก Export แล้วเลือก Save PNG (1x, 2x หรือ 4x หรือกำหนดความกว้างหรือความสูงที่แน่นอน), Save SVG, Copy PNG หรือ Copy SVG code

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

พรีวิวสด ตัวแก้ไขไดอะแกรม Edit diagram สำหรับบล็อกใน Markdown การเติมโค้ดอัตโนมัติ (completion) การขีดเส้นใต้ข้อผิดพลาด เทมเพลต 15 แบบ outline ของ Mermaid Diagrams และการ export และคัดลอกเป็น PNG และ SVG ใช้ได้ฟรี ไม่ต้องมีบัญชี ไม่ต้องล็อกอิน และไม่มี AI

Export All Diagrams in Workspace เขียนทุกไดอะแกรมจากทุกไฟล์ .mmd, .mermaid และ Markdown ในโฟลเดอร์ออกเป็น SVG, PNG หรือทั้งสองแบบ ลงใน mermaid-export/ โดยใช้โครงสร้างโฟลเดอร์เดียวกับไฟล์ต้นฉบับ ไดอะแกรมที่วาดไม่ได้จะแสดงเป็นรายการตอนท้าย เมื่อเอกสารเปลี่ยน คุณจึงไม่ต้องเปิดและ export ทีละไดอะแกรมเอง

วิธีใช้ Export All Diagrams in Workspace (Zovo Pro)

  1. เปิดโฟลเดอร์ใน VS Code แล้วรัน "Mermaid Viewer: Export All Diagrams in Workspace (SVG/PNG) (Pro)" จาก Command Palette หรือคลิก "Export All Diagrams in Workspace" ในแถว "Pro tools" ใต้แถบเครื่องมือของพรีวิว
  2. เลือก SVG, PNG หรือ SVG และ PNG
  3. ใช้โฟลเดอร์เริ่มต้น mermaid-export (การตั้งค่า mermaidViewer.exportFolder) หรือเลือก "Choose a folder…" ระบบนับการลองใช้เฉพาะเมื่อเขียนไฟล์เสร็จ ถ้ากด Escape สิทธิ์ยังอยู่ครบ

Export All Diagrams in Workspace ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.mermaid-viewer แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/mermaid-viewer
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

Mermaid Viewer ทำอะไรได้บ้าง

  • Flowchart, sequence, class, state, ER, Gantt, pie, gitGraph, mindmap, timeline, sankey, XY chart, block, C4, architecture และไดอะแกรมประเภทอื่นที่ Mermaid 12.3.0 รองรับ
  • ข้อผิดพลาดถูกขีดเส้นใต้ในบรรทัดที่ผิดและแสดงใน Problems panel ไดอะแกรมล่าสุดที่วาดได้ยังค้างอยู่บนจอ และบล็อกที่เสียหนึ่งบล็อกในไฟล์ Markdown ไม่ทำให้บล็อกอื่นหายไป
  • ซูมได้ตั้งแต่ 1 % ถึง 3,200 % ตรงตำแหน่งเมาส์ ใช้ trackpad เลื่อนและบีบเพื่อซูมได้
  • export เป็น SVG ที่ใช้ป้ายข้อความธรรมดา สำหรับ wiki ของ Azure DevOps และ GitHub
  • พื้นหลังเป็นสีของ editor สีขาว โปร่งใส หรือสีที่กำหนดเอง และใช้กับไฟล์ที่ export ด้วย

สิ่งที่ยังทำไม่ได้

  • ไม่ได้เพิ่มไดอะแกรมลงในพรีวิว Markdown ของ VS Code เอง แต่เปิดแผงพรีวิวของตัวเอง
  • สูตรคณิตศาสตร์ในป้าย ($$...$$) อาจแสดงผลไม่ถูกต้อง เพราะไม่ได้รวมฟอนต์ KaTeX มาด้วย
  • icon pack ที่ Mermaid โหลดจากอินเทอร์เน็ตจะไม่ถูกโหลด ส่วนไอคอนในตัวใช้ได้
  • ไดอะแกรมที่ยาวเกิน 500,000 ตัวอักษรหรือมีเส้นเชื่อมเกิน 2,000 เส้นจะไม่ถูกวาดจนกว่าคุณจะเพิ่มขีดจำกัด (การตั้งค่า mermaidViewer.maxTextSize และ mermaidViewer.maxEdges)
  • การวาดที่ใช้เวลานานกว่า 10 วินาทีจะถูกหยุด (การตั้งค่า mermaidViewer.renderTimeoutSeconds)

คำถามที่พบบ่อย

ใช้ฟรีไหม

พรีวิว ตัวแก้ไข การแก้บล็อกใน Markdown และการ export เป็น PNG และ SVG ใช้ได้ฟรี เครื่องมือ Pro (PDF export, Export All Diagrams in Workspace และ Export on Save) ลองใช้ฟรีได้ตัวละ 3 ครั้ง หลังจากนั้นต้องใช้ Zovo Pro ราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว

ทำไมบล็อก mermaid ไม่แสดงในพรีวิว Markdown ของ VS Code

พรีวิว Markdown ที่มากับ VS Code ไม่วาด Mermaid ส่วน Mermaid Viewer จะเปิดแผงพรีวิวของตัวเองสำหรับไฟล์ Markdown พร้อมการซูมและการ export ของแต่ละไดอะแกรม

ต้องมีบัญชีหรือต่ออินเทอร์เน็ตไหม

ไม่ต้อง Mermaid 12.3.0 มาพร้อมกับส่วนขยาย ไม่ต้องล็อกอิน ไม่มี AI และพรีวิวจะบล็อกการเรียกเครือข่ายทั้งหมด

ใช้ใน Cursor ได้ไหม

ได้ ส่วนขยายนี้อยู่บน Open VSX ในชื่อ zovo/mermaid-viewer จึงติดตั้งใน Cursor, Windsurf และ VSCodium ได้
