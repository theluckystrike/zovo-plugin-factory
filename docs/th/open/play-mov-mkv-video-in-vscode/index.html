คู่มือภาษาไทย

เปิดวิดีโอ MP4, MOV และ MKV ใน VS Code ให้มีเสียง

ติดตั้งส่วนขยาย Video Preview with Sound ซึ่งใช้ได้ฟรี แล้วคลิกวิดีโอใน Explorer ไฟล์ MP4, MOV และ M4V ที่มีเสียง AAC จะเล่นพร้อมเสียงโดยไม่ต้องติดตั้งอะไรเพิ่ม เพราะส่วนขยายมีตัวถอดรหัสเสียงของตัวเอง ส่วน MKV, WebM, AVI และวิดีโอที่ VS Code ถอดรหัสไม่ได้ เช่น Apple ProRes ต้องมี ffmpeg บนเครื่องของคุณ การเล่น เสียง ซับไตเติล และการแปลงไฟล์ใช้ได้ฟรี และ Zovo Pro (19 ดอลลาร์สหรัฐ จ่ายครั้งเดียว) เพิ่ม Clip export, Frame export และ contact sheet โดยแต่ละเครื่องมือลองใช้ฟรีได้ 3 ครั้ง

ขั้นตอนใน VS Code

  1. ติดตั้ง Video Preview with Sound จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.video-preview-with-sound
  2. ถ้าวิดีโอเป็นไฟล์ MKV, WebM, AVI, WMV, FLV, MPG, OGV หรือ M2TS หรือมีเสียง AC-3, E-AC-3 หรือ DTS ให้ติดตั้ง ffmpeg ก่อน โดยรัน winget install ffmpeg บน Windows, sudo apt install ffmpeg บน Linux หรือ brew install ffmpeg บน macOS ส่วน MP4, MOV และ M4V ที่มีเสียง AAC ไม่ต้องติดตั้งอะไรเพิ่ม
  3. คลิกไฟล์ .mp4, .m4v, .mov, .webm, .mkv, .avi, .wmv, .flv, .mpg, .mpeg, .ogv หรือ .m2ts ใน Explorer แล้วกด Space เพื่อเล่น ถ้า VS Code ถามว่าจะใช้ editor ตัวไหน ให้เลือก "Video Preview with Sound"
  4. วิดีโอจะเล่นแบบไม่มีเสียงจนกว่าป้ายจะขึ้นว่า "Sound: on" ไฟล์ MKV หรือ WebM จะถูกคัดลอกเข้า MP4 โดยไม่ re-encode ส่วน ProRes, AVI, WMV และวิดีโออื่นที่ VS Code ถอดรหัสไม่ได้จะถูกแปลงเป็น H.264 ครั้งเดียวแล้วเก็บไว้ในแคช
  5. วางไฟล์ .srt หรือ .vtt ที่ชื่อเดียวกับวิดีโอไว้ข้างกัน ซับไตเติลจะโหลดเอง กด C หรือใช้เมนู CC เพื่อสลับแทร็กหรือปิดซับไตเติล
  6. กด , และ . เพื่อเลื่อนทีละเฟรม กด [ และ ] เพื่อปรับความเร็วตั้งแต่ 0.1x ถึง 4x กด A และ B เพื่อตั้งช่วงวนซ้ำ กด S เพื่อบันทึกเฟรมปัจจุบันเป็น PNG ขนาดเต็ม และกด P สำหรับ picture-in-picture

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

การเล่นพร้อมเสียง ตัวถอดรหัส AAC ในตัว การเล่น MKV และ WebM ด้วย ffmpeg การแปลงวิดีโอที่ VS Code ถอดรหัสไม่ได้ ซับไตเติล picture-in-picture การเลื่อนทีละเฟรม การปรับความเร็ว การวนซ้ำ A-B การบันทึกเฟรมปัจจุบันเป็น PNG (S) แผง metadata และการเล่นต่อจากจุดเดิม ใช้ได้ฟรี

Clip export บันทึกช่วง A-B ของวิดีโอ หรือทั้งวิดีโอ เป็น GIF หรือ MP4 สำหรับ pull request, issue หรือเอกสาร GIF ถูกสร้างในตัวเล่นเองโดยไม่ต้องใช้เครื่องมืออื่น เลือกได้ 480 px ที่ 10 fps, 640 px ที่ 15 fps หรือสูงสุด 960 px ที่ 15 fps และยาวได้ไม่เกิน 60 วินาที ส่วน MP4 จะตัดด้วย ffmpeg ของคุณเอง แบบ exact cut ที่ re-encode เป็น H.264 และ AAC และเริ่มที่เฟรม A พอดี หรือแบบ fast copy ที่เก็บสตรีมเดิมไว้และเริ่มที่ keyframe ก่อนจุด A

วิธีใช้ Clip export (Zovo Pro)

  1. เปิดวิดีโอในตัวเล่น กด A ที่จุดเริ่มต้นและ B ที่จุดสิ้นสุดของช่วงที่ต้องการ หรือไม่ตั้งอะไรเลยเพื่อใช้ทั้งวิดีโอ
  2. กด Clip (มีป้าย PRO) ในตัวเล่น หรือ "Export a Clip as GIF or MP4" ในแถว Pro tools เล็ก ๆ ใต้ปุ่มควบคุม หรือคลิกขวาที่วิดีโอใน Explorer แล้วเลือก "Zovo Pro: Export a Clip as GIF or MP4"
  3. เลือก "GIF, 480 px wide, 10 fps", "GIF, 640 px wide, 15 fps", "GIF, up to 960 px wide, 15 fps", "MP4, exact cut" หรือ "MP4, fast copy" แล้วเลือกที่บันทึก
  4. กด Esc เพื่อหยุดการ export ระบบนับการลองใช้เฉพาะเมื่อบันทึกไฟล์สำเร็จ การยกเลิกกล่องโต้ตอบหรือหยุด export กลางทางจึงไม่เสียสิทธิ์ลองใช้ฟรี

Clip export ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.video-preview-with-sound แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/video-preview-with-sound
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

Video Preview with Sound ทำอะไรได้บ้าง

  • MP4, M4V และ MOV ที่มีเสียง AAC (mono หรือ stereo), ALAC, MP3 หรือ PCM โดยไม่ต้องติดตั้งอะไรเพิ่ม บน Windows, Linux และ macOS
  • MKV และ WebM ที่ ffmpeg คัดลอกเข้า MP4 แล้วเล่นพร้อมเสียง
  • เสียง AC-3, E-AC-3, DTS, Opus หรือ AAC 5.1 ใน MP4, M4V หรือ MOV ซึ่งถอดรหัสด้วย ffmpeg หรือ afconvert ที่มากับ macOS
  • วิดีโอ Apple ProRes, MPEG-4 Part 2 และ DNxHD รวมถึงไฟล์ AVI, WMV, FLV, MPG, MPEG, OGV และ M2TS ที่แปลงเป็น H.264 ด้วย ffmpeg
  • ซับไตเติลจากไฟล์ .srt และ .vtt ที่วางข้างวิดีโอ

สิ่งที่ยังทำไม่ได้

  • ถ้าไม่มี ffmpeg จะเปิด MKV และ WebM ไม่ได้ในทุกระบบ ตัวเล่นจะแจ้งว่า "Install ffmpeg to open this file" และส่วนขยายไม่ได้รวม ffmpeg มาให้
  • afconvert ของ macOS แปลงวิดีโอไม่ได้และเปิด MKV หรือ WebM ไม่ได้ การแปลงต้องใช้ ffmpeg ของคุณเองเสมอ และไฟล์ ProRes ที่ยาวอาจใช้เวลาหลายนาที
  • ตัวถอดรหัสในตัวเล่น HE-AAC จากแกน AAC-LC ที่ sample rate ครึ่งหนึ่ง ให้ติดตั้ง ffmpeg ถ้าต้องการ HE-AAC แบบเต็ม, AAC 5.1, AC-3 และ DTS
  • ไฟล์ที่ใหญ่กว่า 4096 MB ยังเล่นได้แต่ไม่มีเสียง (การตั้งค่า videoPreview.maxDecodeSizeMB)
  • ซับไตเติลมาจากไฟล์ .srt และ .vtt เท่านั้น ไฟล์ละไม่เกิน 5 MB ซับไตเติลที่ฝังอยู่ในไฟล์วิดีโอจะไม่ถูกอ่าน และไฟล์ .ts และ .mts จะไม่ถูกเปิด เพราะนามสกุลเหล่านี้เป็นไฟล์ TypeScript

คำถามที่พบบ่อย

ทำไม VS Code เล่น MP4 แล้วไม่มีเสียง

Chromium ที่อยู่ใน VS Code มีตัวถอดรหัสวิดีโอ H.264 แต่ไม่มีตัวถอดรหัส AAC และไฟล์ MP4 และ MOV ส่วนใหญ่ใช้เสียง AAC ส่วนขยายนี้ถอดรหัสเสียงเองและเล่นให้ตรงกับภาพ

ต้องมี ffmpeg ไหม

ไม่ต้องสำหรับ MP4, MOV และ M4V ที่มีเสียง AAC, ALAC, MP3 หรือ PCM แต่ต้องมี ffmpeg สำหรับ MKV, WebM, AVI, WMV, FLV, MPG, OGV และ M2TS สำหรับ ProRes และวิดีโออื่นที่ VS Code ถอดรหัสไม่ได้ และสำหรับคลิป MP4 จาก Clip export ส่วนเสียง AC-3, E-AC-3 และ DTS ต้องใช้ ffmpeg หรือ afconvert บน macOS

ใช้ฟรีไหม

ใช้ได้ฟรี การเล่น เสียง ซับไตเติล การเลื่อนทีละเฟรม การบันทึกเฟรมปัจจุบันเป็น PNG และการแปลงไฟล์ไม่มีค่าใช้จ่าย Clip export, Frame export และ contact sheet เป็นเครื่องมือ Zovo Pro ที่ลองใช้ฟรีได้ตัวละ 3 ครั้ง หลังจากนั้นราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว

ใช้ใน Cursor ได้ไหม

ได้ ส่วนขยายนี้อยู่บน Open VSX ในชื่อ zovo/video-preview-with-sound จึงติดตั้งใน Cursor, Windsurf และ VSCodium ได้
