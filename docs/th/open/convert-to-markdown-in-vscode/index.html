คู่มือภาษาไทย

แปลงไฟล์ PDF, Word, PowerPoint หรือ Excel เป็น Markdown ใน VS Code

ติดตั้งส่วนขยาย Convert to Markdown ซึ่งใช้ได้ฟรี แล้วคลิกขวาที่ไฟล์ PDF, Word, PowerPoint, Excel, CSV, HTML, EPUB, ODT หรือ RTF ใน Explorer และเลือก Convert to Markdown ไฟล์ Markdown จะเปิดข้างไฟล์เดิมพร้อมหัวข้อ รายการ ตาราง ลิงก์ และ speaker notes ของสไลด์ โดยไม่มีข้อมูลใดออกจากเครื่องของคุณ Convert to Markdown และ Copy as Markdown ใช้ได้ฟรีกับทุกฟอร์แมต Zovo Pro (19 ดอลลาร์สหรัฐ จ่ายครั้งเดียว) เพิ่มเครื่องมือ 3 ตัว คือ Convert a Folder to Markdown, Convert to Markdown with Images และ LLM-ready Markdown Chunks และแต่ละตัวลองใช้ฟรีได้ 3 ครั้ง

ขั้นตอนใน VS Code

  1. ติดตั้ง Convert to Markdown จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.zovo-convert-to-markdown
  2. ใน Explorer ให้คลิกขวาที่ไฟล์ .pdf, .docx, .pptx, .xlsx, .xls, .ods, .csv, .tsv, .html, .epub, .odt หรือ .rtf แล้วเลือก Convert to Markdown หรือคลิกขวาที่แท็บของไฟล์ที่เปิดอยู่ก็ได้
  3. หรือรัน "Convert to Markdown: Convert to Markdown" จาก Command Palette คำสั่งนี้แปลงไฟล์ในแท็บที่ใช้งานอยู่ หรือถามว่าจะแปลงไฟล์ไหน
  4. Markdown จะเปิดข้างไฟล์เดิมเป็นเอกสารที่ยังไม่ได้บันทึก ไฟล์ขนาดใหญ่จะแสดงความคืบหน้าพร้อมปุ่ม Cancel
  5. กด Save แล้วชื่อ name.md ข้างไฟล์ต้นฉบับจะกรอกไว้ให้แล้ว ถ้าต้องการให้บันทึกไว้ที่นั่นทันทีทุกครั้ง ให้ตั้ง toMarkdown.output เป็น file
  6. ถ้าจะนำ Markdown ไปวางที่อื่น ให้คลิกขวาที่ไฟล์แล้วเลือก Copy as Markdown ถ้าเลือกหลายไฟล์ใน Explorer ไฟล์เหล่านั้นจะถูกแปลงทีละไฟล์ต่อกันไป
  7. ถ้ายังไม่มีไฟล์ให้ลอง ให้รัน "Convert to Markdown: Convert a sample file" จาก Command Palette เพื่อแปลงไฟล์ตัวอย่าง Word, PDF หรือ PowerPoint ที่มากับส่วนขยาย

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

Convert to Markdown และ Copy as Markdown ใช้ได้ฟรีกับทุกฟอร์แมต ได้แก่ PDF, Word, PowerPoint, Excel, ODS, CSV, TSV, HTML, EPUB, ODT และ RTF ไม่ต้องติดตั้งอะไรเพิ่ม ไม่ต้องมี Python ไม่ต้องมีเซิร์ฟเวอร์ และไม่ต้องมี command-line tool ไม่มีข้อมูลใดออกจากเครื่องของคุณ

Convert a Folder to Markdown แปลงทุกไฟล์ที่รองรับในโฟลเดอร์และโฟลเดอร์ย่อยเป็นไฟล์ .md ในการรันครั้งเดียว โดยเขียนลงโฟลเดอร์ใหม่ที่มีโครงสร้างเหมือนเดิมหรือวางข้างแต่ละไฟล์ พร้อมแสดงความคืบหน้าและปุ่ม Cancel คุณเลือกได้ว่าจะข้ามหรือเขียนทับไฟล์ .md ที่มีอยู่แล้ว และ _conversion-report.md จะระบุว่าแต่ละไฟล์แปลงสำเร็จ ถูกข้าม หรือแปลงไม่สำเร็จ ไฟล์ที่ชื่อซ้ำกันจะมีชนิดไฟล์อยู่ในชื่อใหม่ (report.pdf.md, report.docx.md) จึงไม่มีไฟล์ไหนหายไป

วิธีใช้ Convert a Folder to Markdown (Zovo Pro)

  1. คลิกขวาที่โฟลเดอร์ใน Explorer แล้วเลือก "Zovo Pro: Convert a Folder to Markdown" หรือรัน "Convert to Markdown: Convert a Folder to Markdown (Pro)" จาก Command Palette แล้วเลือกโฟลเดอร์
  2. เลือกว่าจะเก็บไฟล์ .md ไว้ที่ไหน ได้แก่ "Into a new folder" (ชื่อโฟลเดอร์ต่อท้ายด้วย -markdown และมีโฟลเดอร์ย่อยเหมือนเดิม), "Next to each file" หรือ "Pick another folder..."
  3. ถ้ามีไฟล์ .md บางไฟล์อยู่แล้ว ให้เลือก Skip หรือ Overwrite การแจ้งเตือนจะแสดงความคืบหน้าพร้อมปุ่ม Cancel
  4. เมื่อเสร็จแล้ว _conversion-report.md จะเปิดขึ้นมา รายงานนี้ระบุว่าแต่ละไฟล์แปลงสำเร็จ ถูกข้าม หรือแปลงไม่สำเร็จ พร้อมลิงก์ไปยังไฟล์ Markdown ใหม่แต่ละไฟล์

Convert a Folder to Markdown ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.zovo-convert-to-markdown แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/zovo-convert-to-markdown
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

Convert to Markdown ทำอะไรได้บ้าง

  • PDF ได้หัวข้อจากขนาดฟอนต์ ย่อหน้าที่ต่อบรรทัดที่ขาดและคำที่ตัดด้วยยัติภังค์ให้แล้ว รายการ ตารางแบบง่าย และหน้าสองคอลัมน์ที่อ่านทีละคอลัมน์ ส่วนหัวกระดาษ ท้ายกระดาษ และเลขหน้าที่ซ้ำทุกหน้าจะถูกตัดออก
  • Word (.docx, .docm, .dotx) ได้หัวข้อ ตัวหนา ตัวเอียง ขีดฆ่า ลิงก์ รายการซ้อน ตาราง block quote และเชิงอรรถ
  • PowerPoint (.pptx, .pptm, .ppsx, .potx) ได้ส่วน ## Slide n: title หนึ่งส่วนต่อสไลด์ พร้อม bullet ตามระดับ ตาราง และ speaker notes
  • Excel และสเปรดชีตอื่น (.xlsx, .xlsm, .xlsb, .xls, .ods) ได้ส่วน ## Sheet: name พร้อมตาราง pipe หนึ่งตารางต่อชีต ส่วน CSV และ TSV กลายเป็นตารางเดียว
  • HTML (.html, .htm, .xhtml) ซึ่ง code block ยังระบุภาษาไว้ และ script กับ style ถูกตัดออก และ EPUB ซึ่งแต่ละบทเรียงตามลำดับการอ่าน

สิ่งที่ยังทำไม่ได้

  • PDF ที่สแกนมา (ภาพของหน้ากระดาษ) ไม่มีข้อความให้แปลง และส่วนขยายนี้ไม่มีการรู้จำข้อความ (OCR)
  • ตารางใน PDF หาได้จากช่องว่างระหว่างคอลัมน์ ตารางที่ไม่มีช่องว่างชัดเจนจะออกมาเป็นย่อหน้า
  • ในการแปลงแบบฟรี รูปภาพจะกลายเป็นตัวแทน เช่น *[Image: Map of the site]* ส่วนกราฟ SmartArt และวิดีโอในสไลด์จะถูกระบุชื่อไว้เท่านั้น ไม่ได้แปลง
  • ไฟล์ Word 97-2003 แบบเก่าและ RTF ได้ข้อความและตารางโดยไม่มีการจัดรูปแบบ ไฟล์ที่มีรหัสผ่านและไฟล์ PowerPoint 97-2003 แบบเก่าจะได้ข้อความแจ้งแทนการแปลง
  • ไฟล์ที่ใหญ่กว่า 200 MB จะไม่ถูกแปลง (การตั้งค่า toMarkdown.maxFileSizeMB) และ PDF จะหยุดหลัง 1,000 หน้า (การตั้งค่า toMarkdown.pdfMaxPages)

ใช้ฟรีไหม

Convert to Markdown และ Copy as Markdown ใช้ได้ฟรีกับทุกฟอร์แมต เครื่องมือ Pro 3 ตัว คือ Convert a Folder to Markdown, Convert to Markdown with Images และ LLM-ready Markdown Chunks ลองใช้ฟรีได้ตัวละ 3 ครั้ง หลังจากนั้นต้องใช้ Zovo Pro ราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว

ส่วนขยายอัปโหลดไฟล์ของฉันไหม

ไม่ ตัวแปลงทำงานบนเครื่องของคุณภายใน VS Code ไม่มีการเรียกเครือข่ายและไม่มี telemetry

แปลง PDF ที่สแกนมาได้ไหม

ไม่ได้ PDF ที่สแกนมาเก็บภาพของหน้ากระดาษ ไม่ใช่ข้อความ และ Convert to Markdown ไม่มี OCR

ใช้ใน Cursor ได้ไหม

ได้ Cursor, Windsurf และ VSCodium ติดตั้งได้จาก Open VSX ซึ่งเผยแพร่ในชื่อ zovo/zovo-convert-to-markdown
