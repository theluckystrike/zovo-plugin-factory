เปิดไฟล์ NetCDF ใน VS Code ได้ฟรี

ติดตั้งส่วนขยาย NetCDF Viewer & HDF5 Viewer ซึ่งใช้ได้ฟรีใน VS Code แล้วคลิกไฟล์ .nc คุณจะเห็น header ต้นไม้ตัวแปร แผนที่พร้อมเส้นชายฝั่ง แถบเลื่อนเวลา และอนุกรมเวลาของจุดที่คลิก โดยไม่ต้องมี Python, NCL หรือติดตั้งอะไรเพิ่ม ตัวแสดงผลเดียวกันนี้เปิดไฟล์ HDF5 .h5 และไฟล์ MATLAB 7.3 .mat ได้ด้วย และทั้งหมดนี้ใช้ได้ฟรี Zovo Pro (19 ดอลลาร์สหรัฐ จ่ายครั้งเดียว) เพิ่มเครื่องมือ 2 ตัวคือ Compare two files และ Export a subset และแต่ละตัวลองใช้ฟรีได้ 3 ครั้ง

ติดตั้งใน VS Codeหน้า MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

ใช้ฟรี ไลเซนส์ MIT รหัสส่วนขยาย zovo.hdf5-netcdf-explorer เวอร์ชัน 0.6.5

ขั้นตอนใน VS Code

  1. ติดตั้ง NetCDF Viewer & HDF5 Viewer จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.hdf5-netcdf-explorer
  2. คลิกไฟล์ .nc, .nc4, .netcdf หรือ .cdf ใน Explorer หน้าภาพรวมจะแสดงฟอร์แมต มิติ global attributes และตารางของตัวแปรทั้งหมด คล้ายกับ ncdump -h
  3. เลือกตัวแปรจากต้นไม้ทางซ้าย สไลซ์ 2 มิติจะถูกวาดเป็นฮีตแมป และมีเส้นชายฝั่งเมื่อแถวและคอลัมน์เป็นละติจูดและลองจิจูด
  4. เลื่อนแถบเวลา หรือกด ▶ ข้างแถบเพื่อเล่นไล่ตามเวลา คลิกจุดบนแผนที่เพื่อพล็อตอนุกรมเวลาของจุดนั้น
  5. เปิดแท็บ Table เพื่อดูค่าทีละหน้า หน้าละ 100 แถว 30 คอลัมน์ โดยใช้ค่าพิกัดเป็นหัวตาราง
  6. คลิก "Save PNG" เพื่อบันทึกกราฟ หรือ "Export slice…" เพื่อบันทึกสไลซ์ที่แสดงอยู่เป็น CSV หรือ JSON ส่วน "Copy xarray code" ให้โค้ด Python หนึ่งบรรทัดสำหรับสไลซ์เดียวกัน
  7. สำหรับไฟล์ HDF5 ให้คลิกไฟล์ .h5 ส่วนไฟล์ MATLAB 7.3 .mat ให้คลิกขวาแล้วเลือก "Open in HDF5 NetCDF Explorer"

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

ทุกฟอร์แมต ต้นไม้ตัวแปร แอตทริบิวต์ ตาราง กราฟ แผนที่พร้อมเส้นชายฝั่ง Play อนุกรมเวลาของจุด Save PNG และ Export slice ใช้ได้ฟรี ไม่ต้องมี Python และฟีเจอร์เหล่านี้ไม่เรียกเครือข่าย

Export a subset ทำงานแบบเดียวกับ ncks -d หรือ .sel ของ xarray โดยเลือกตัวแปรและช่วงของแต่ละมิติ จะระบุด้วย index (0:99) หรือด้วยค่า (30..60, 2023-08-01..2023-08-31) ก็ได้ ผลลัพธ์เป็นไฟล์ NetCDF ที่มีพิกัด แอตทริบิวต์ และบรรทัด history หรือเป็น CSV แบบ tidy หนึ่งแถวต่อหนึ่งจุด คุณจะได้ไฟล์เล็ก ๆ ของพื้นที่และช่วงเวลาที่ต้องการโดยไม่ต้องเขียนสคริปต์

วิธีใช้ Export a subset (Zovo Pro)

  1. เปิดไฟล์แล้วคลิกปุ่ม "Export subset…" ข้าง "Export slice…" หรือคลิกขวาที่ไฟล์ใน Explorer แล้วเลือก "Zovo Pro: Export a Subset of a Variable"
  2. หรือรัน "NetCDF Viewer Pro: Export Subset of a Variable (NetCDF or CSV)..." จาก Command Palette
  3. พิมพ์ช่วงของแต่ละมิติ กล่องจะแสดงสิ่งที่เลือกไว้ระหว่างที่พิมพ์
  4. เลือก NetCDF หรือ CSV แล้วเลือกที่บันทึก การแจ้งเตือนจะแสดงความคืบหน้า และ Cancel จะหยุดโดยไม่ทิ้งไฟล์ที่เขียนไม่เสร็จไว้

Export a subset ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.hdf5-netcdf-explorer แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/hdf5-netcdf-explorer
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

NetCDF Viewer & HDF5 Viewer ทำอะไรได้บ้าง

  • NetCDF-4 และ NetCDF-4 classic, NetCDF-3 แบบ classic และ 64-bit offset และ CDF-5 (ข้อมูล 64-bit)
  • ไฟล์ HDF5 (.h5, .hdf5, .he5, .hdf) ที่บีบอัดด้วย deflate, shuffle, szip, LZF, Blosc, bitshuffle, LZ4, Zstd, bzip2 และ ZFP
  • MATLAB 7.3 .mat และไฟล์อื่นที่ใช้ HDF5 เป็นฐาน เช่น .jld2, .loom และ .h5ad
  • ถอดรหัสแบบ CF ให้กับ scale_factor, add_offset, _FillValue และหน่วยเวลา รวมถึงปฏิทิน noleap, 360_day และ all_leap
  • ไฟล์บนเครื่องอื่นผ่าน Remote SSH, WSL หรือ dev container

สิ่งที่ยังทำไม่ได้

  • ไม่รองรับ Zarr และ HDF4 ไฟล์ MATLAB .mat ที่บันทึกในฟอร์แมต v5 ไม่ใช่ HDF5 จึงเปิดไม่ได้ ให้บันทึกใหม่ด้วย save(filename, '-v7.3')
  • เส้นชายฝั่งวาดได้เฉพาะกริดละติจูด-ลองจิจูดแบบ regular กริดแบบ curvilinear ที่มีละติจูดและลองจิจูดเป็น 2 มิติ และกริดแบบ projected ที่มีหน่วยเป็นเมตร จะไม่มีเส้นชายฝั่ง
  • อาร์เรย์ที่ใหญ่กว่า 512 x 512 จะถูกสุ่มตัวอย่างเพื่อวาดกราฟ การ export เขียนได้ไม่เกิน 1,000,000 ค่าต่อไฟล์ (การตั้งค่า hdf5NetcdfExplorer.maxReadValues)
  • ไม่รองรับ virtual file system เช่น repository บน GitHub ที่เปิดใน vscode.dev
  • ชุดข้อมูลที่ใช้ HDF5 filter อื่น เช่น SZ หรือ JPEG จะแสดงข้อความแทนค่า

คำถามที่พบบ่อย

ใช้ฟรีไหม

การดูข้อมูลใช้ได้ฟรี ทั้งทุกฟอร์แมต แผนที่ Play อนุกรมเวลา Save PNG และ Export slice เครื่องมือ Pro 2 ตัวคือ Compare two files และ Export a subset ลองใช้ฟรีได้ตัวละ 3 ครั้ง หลังจากนั้นต้องใช้ Zovo Pro ราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว

มีโปรแกรมเปิดไฟล์ NetCDF บน Windows ไหม

มี ส่วนขยายนี้ทำงานได้ทุกที่ที่ VS Code ทำงาน ทั้ง Windows, macOS และ Linux และไม่ต้องมี Python

เปิดไฟล์ HDF5 และ MAT ได้ไหม

ได้สำหรับไฟล์ HDF5 .h5 และไฟล์ MATLAB 7.3 .mat ส่วนไฟล์ .mat แบบ MATLAB v5 ที่เก่ากว่าไม่ใช่ HDF5 และจะแสดงข้อความแทน

ใช้ใน Cursor ได้ไหม

ได้ ส่วนขยายนี้อยู่บน Open VSX ในชื่อ zovo/hdf5-netcdf-explorer จึงติดตั้งใน Cursor, Windsurf และ VSCodium ได้
