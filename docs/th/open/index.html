คู่มือภาษาไทย

VS Code และ editor ที่สร้างต่อจาก VS Code (Cursor, Windsurf, VSCodium) เปิดไฟล์ข้อความ รูปภาพ และสื่อบางชนิดได้ แต่ไฟล์อีกหลายรูปแบบต้องใช้ส่วนขยาย แต่ละคู่มือบอกขั้นตอนและบอกว่าอะไรใช้ฟรี

  • ดูไฟล์ NumPy .npy และ .npz ใน VS Code. เปิดอาร์เรย์ NumPy .npy และ .npz ใน VS Code ด้วย Tensor Viewer ฟรี ดู dtype, shape, สถิติ, ฮีตแมป, รูปภาพ และค่าในอาร์เรย์ได้โดยไม่ต้องมี Python
  • เปิดไฟล์ NetCDF ใน VS Code ได้ฟรี. เปิดไฟล์ NetCDF .nc ใน VS Code บน Windows, macOS หรือ Linux ดู header ตัวแปร แผนที่พร้อมเส้นชายฝั่ง และอนุกรมเวลา เปิด HDF5 .h5 และ MATLAB 7.3 .mat ได้ด้วย
  • ดูและแก้ไขฐานข้อมูล SQLite ใน VS Code. เปิดไฟล์ .db หรือ .sqlite ใน VS Code ด้วย SQLite Viewer & Editor ฟรี ดูตาราง schema และรัน SQL แก้เซลล์และแถว แล้วบันทึกพร้อมไฟล์สำรอง
  • พรีวิวไดอะแกรม Mermaid ใน VS Code. ดูพรีวิวไดอะแกรม Mermaid ใน VS Code จากไฟล์ .mmd และบล็อกใน Markdown ด้วย Mermaid Viewer ฟรี พรีวิวสด export เป็น PNG และ SVG ใช้ออฟไลน์ ไม่ต้องล็อกอิน
  • เปิดวิดีโอ MP4, MOV และ MKV ใน VS Code ให้มีเสียง. เล่น MP4, MOV และ M4V ที่มีเสียง AAC ใน VS Code โดยไม่ต้องติดตั้งอะไรเพิ่ม MKV, WebM และ AVI เล่นได้เมื่อมี ffmpeg ของคุณเอง ตัวเล่นฟรีพร้อมซับไตเติล
  • ดูไฟล์ STL และโมเดล 3D ใน VS Code. เปิดไฟล์ STL ใน VS Code ด้วย 3D Model Viewer ฟรี หมุนดูโมเดล วัดระยะสองจุด ดู wireframe และสถิติของโมเดล เปิด OBJ, PLY, 3MF, GLB และ glTF ได้ด้วย
  • แปลงไฟล์ TIFF เป็น PNG โดยไม่เสียคุณภาพ. เปิดไฟล์ TIFF, BigTIFF และ GeoTIFF ใน VS Code ได้ฟรี แล้วบันทึกหน้าเดียวหรือทุกหน้าเป็น PNG โดยค่า 8 และ 16-bit ไม่เปลี่ยน ทำงานออฟไลน์
  • เปิดไฟล์ PCAP ใน VS Code. อ่านไฟล์ .pcap, .pcapng และ .pcap.gz ใน VS Code ด้วย PCAP Viewer ฟรี มีรายการแพ็กเก็ต protocol tree แผง hex และ display filter ไม่ต้องติดตั้ง Wireshark
  • ดู sections และ imports ของไฟล์ ELF, EXE หรือ DLL ใน VS Code. เปิดไฟล์ .so, .exe, .dll และ .dylib ใน VS Code ด้วย ELF Viewer & PE Viewer ฟรี ดู header, section, import, export, symbol และ hex แบบอ่านอย่างเดียว
  • ดูตัวอย่างไฟล์ฟอนต์ใน VS Code. เปิดฟอนต์ .ttf, .otf, .woff, .woff2 และ .ttc ใน VS Code ด้วย Font Viewer ฟรี ทดสอบข้อความ ดู glyph ทุกตัว และอ่าน license โดยไม่ต้องติดตั้งฟอนต์
  • เล่นไฟล์เสียงใน VS Code. เล่นไฟล์ WAV, MP3, FLAC, Ogg และ Opus ใน VS Code ด้วย Audio Player ฟรี มี waveform, spectrogram, A-B loop, ปรับความเร็ว และวัดความดัง LUFS
  • แปลง XMind เป็น PDF โดยไม่ต้องใช้ XMind ทุก sheet ใน PDF ไฟล์เดียว. เปิด mind map .xmind ใน VS Code โดยไม่ต้องมี XMind แล้วบันทึกทุก sheet เป็น PDF ไฟล์เดียว หน้าละหนึ่ง sheet การดูใช้ฟรี ส่วน PDF เป็นเครื่องมือ Zovo Pro
  • รันไฟล์ C++ ใน VS Code ด้วยคลิกเดียว. คอมไพล์และรันไฟล์ .cpp หรือ .c ใน VS Code ด้วยคลิกเดียว ใช้ gcc, g++ หรือ clang ในเครื่องของคุณ พิมพ์ input ในเทอร์มินัล ดู error ใน Problems และมี test case
  • เปลี่ยนชื่อแท็ก HTML, JSX และ Vue อัตโนมัติใน VS Code. แก้ชื่อแท็ก HTML, JSX หรือ Vue แล้วแท็กคู่เปลี่ยนตามขณะพิมพ์ ส่วนขยายฟรีที่ใช้ linked editing ของ VS Code ปิดแท็กอัตโนมัติ และ Undo ได้ในครั้งเดียว
  • อ่านและ resume ประวัติ Claude Code ใน VS Code. อ่าน ค้นหา และ resume เซสชันเก่าของ Claude Code และ Codex ใน VS Code แสดง subagent แบบซ้อน การแก้ไฟล์เป็น diff และยอด token แบบอ่านอย่างเดียวและออฟไลน์
  • เปิดแบบ DXF ใน VS Code. ดูแบบ .dxf ใน VS Code ด้วย DXF Viewer ฟรี รองรับ DXF แบบ ASCII และ binary มี layer ชีต paper space ค้นหาข้อความ วัดระยะ และ export เป็น PNG หรือ SVG
  • พรีวิวกราฟ Graphviz DOT โดยไม่ต้องติดตั้ง Graphviz. พรีวิวไฟล์ .dot และ .gv ข้าง editor ใน VS Code ขณะพิมพ์ มี Graphviz ในตัว layout engine หกแบบ คลิกเพื่อไปยังบรรทัด และ export เป็น SVG และ PNG
  • เปิดไฟล์ข้างใน ZIP โดยไม่ต้องแตกไฟล์. ดูข้างใน ZIP, JAR, TAR หรือ TAR.GZ ใน VS Code และเปิดไฟล์เดียวจาก archive ในแท็บแบบอ่านอย่างเดียว โดยไม่แตกไฟล์ลงดิสก์ ใช้ฟรีและทำงานออฟไลน์
  • เปิด JAR และอ่านซอร์ส Java ที่ decompile แล้วใน VS Code. เปิดไฟล์ .jar, .war, .ear, .aar และ .class ใน VS Code ดูแพ็กเกจ, MANIFEST.MF, bytecode และซอร์ส Java ที่ decompile ด้วย CFR ใช้ฟรีและอ่านอย่างเดียว
  • เปรียบเทียบไฟล์ Excel หรือ CSV สองไฟล์ใน VS Code. เปรียบเทียบไฟล์ .xlsx, .xls, .ods หรือ CSV สองไฟล์ใน VS Code ทีละเซลล์ ดูเซลล์ที่เปลี่ยน แถวที่เพิ่มและลบ คอลัมน์ ชีต และเทียบกับ Git HEAD ได้ฟรี
  • แปลงไฟล์ PDF, Word, PowerPoint หรือ Excel เป็น Markdown ใน VS Code. คลิกขวาที่ไฟล์ PDF, DOCX, PPTX, XLSX, CSV, HTML หรือ EPUB ใน VS Code แล้ว Markdown จะเปิดข้างไฟล์ ฟรี ออฟไลน์ ไม่ต้องมี Python และไม่อัปโหลดไฟล์
  • จัดรูปแบบ XML ใน VS Code และรัน XPath กับไฟล์. จัดรูปแบบหรือย่อ XML ใน VS Code โดยเปลี่ยนแค่ช่องว่างระหว่างแท็ก รัน XPath 1.0 ด้วย namespace ของไฟล์เอง และคัดลอก XPath ที่ตำแหน่งเคอร์เซอร์
  • ดูรูปภาพจาก path ในโค้ด ทั้งใน gutter และเมื่อ hover. ดูรูปย่อใน gutter และ hover ที่แสดงรูป ขนาดพิกเซล และขนาดไฟล์ ของ path รูปในไฟล์ JS, CSS, HTML และ Markdown ใน VS Code ใช้ได้ฟรี
  • แก้ไฟล์ .env ใน VS Code โดยไม่ให้ค่าลับโชว์บนหน้าจอ. ไฮไลต์ไฟล์ .env ใน VS Code ซ่อนค่าลับเป็นจุดจนกว่าเคอร์เซอร์จะอยู่บรรทัดนั้น และแก้ key ซ้ำหรือเครื่องหมายคำพูดผิด ฟรีและออฟไลน์
  • จัดรูปแบบสคริปต์ bash หรือ zsh ใน VS Code. จัดรูปแบบสคริปต์ bash, sh, zsh, bats และ mksh ใน VS Code ด้วย Shift+Alt+F หรือตอนบันทึก มี shfmt 3.14.1 ในตัว อ่าน .editorconfig และใช้ออฟไลน์ได้
  • เปิดดู bucket ของ AWS S3, Cloudflare R2 หรือ MinIO ใน VS Code. เปิดดู bucket ของ S3, R2, MinIO, B2 และ Wasabi ใน VS Code เปิด object แบบอ่านอย่างเดียว อัปโหลดและดาวน์โหลดต่อจากที่หยุดได้ และซิงก์โฟลเดอร์หลังดู dry-run
  • แก้ไฟล์ .proto ใน VS Code พร้อมไฮไลต์ จัดรูปแบบ และ go to definition. ไฮไลต์ จัดรูปแบบ และตรวจไฟล์ .proto ใน VS Code ด้วย formatter ที่เก็บ comment ไว้ go to definition และ error แบบ protoc ฟรี ออฟไลน์ ไม่ต้องมี protoc
  • จัดรูปแบบและตรวจไฟล์ config ของ nginx ใน VS Code. จัดรูปแบบ nginx.conf ใน VS Code โดยไม่ทำให้ไฟล์ที่ถูกต้องเสีย เห็น ; ที่หายหรือ directive ผิดที่ขณะพิมพ์ และดู hover help ของ directive ราว 300 ตัว
  • พรีวิวไดอะแกรม PlantUML ใน VS Code ขณะพิมพ์. พรีวิว PlantUML แบบสดใน VS Code สำหรับไฟล์ .puml และบล็อก plantuml ใน Markdown วาดบนเครื่องคุณด้วย jar ที่มาในตัว ต้องมี Java 11 ไม่ต้องมี Graphviz
  • อัปโหลดไฟล์ขึ้นเซิร์ฟเวอร์ผ่าน SFTP หรือ FTP จาก VS Code. ตั้งค่า .vscode/sftp.json แล้ว VS Code จะอัปโหลดไฟล์ทุกครั้งที่บันทึกผ่าน SFTP, FTP หรือ FTPS อัปโหลด ดาวน์โหลด เทียบ และแก้ไฟล์บนเซิร์ฟเวอร์ได้ฟรี
  • จัดรูปแบบ HTML และ CSS ใน VS Code โดยไม่ทำให้บล็อก pre หรือแท็ก inline เสีย. จัดรูปแบบ HTML, CSS, SCSS และ LESS ใน VS Code รวมบล็อก style, script และ .editorconfig โดย pre, textarea, แท็ก inline และลำดับ attribute คงเดิม ใช้ได้ฟรี

คู่มืออื่น ๆ มีให้อ่านเป็นภาษาอังกฤษ
