คู่มือภาษาไทย

อัปโหลดไฟล์ขึ้นเซิร์ฟเวอร์ผ่าน SFTP หรือ FTP จาก VS Code

ติดตั้งส่วนขยาย SFTP & FTP Sync and Upload ซึ่งใช้ได้ฟรี แล้วเขียน .vscode/sftp.json ที่มี host, user และโฟลเดอร์บนเซิร์ฟเวอร์ จากนั้นทุกไฟล์จะอัปโหลดเมื่อคุณบันทึก ผ่าน SFTP, FTP หรือ FTPS คลิกขวาที่ไฟล์หรือโฟลเดอร์เพื่ออัปโหลด ดาวน์โหลด หรือเทียบกับสำเนาบนเซิร์ฟเวอร์ และเปิดไฟล์บนเซิร์ฟเวอร์ในแท็บปกติจากมุมมอง Remote Files โฟลเดอร์ .vscode, ไฟล์ .env และ private key ของคุณจะไม่ถูกอัปโหลด ทั้งหมดนี้ใช้ได้ฟรีโดยไม่ต้องมีบัญชี Zovo Pro (19 ดอลลาร์สหรัฐ จ่ายครั้งเดียว) เพิ่มเครื่องมือ 3 ตัว คือ Sync Folder with Remote, Roll Back a Remote File และ Server Profiles and Jump Host และแต่ละตัวลองใช้ฟรีได้ 3 ครั้ง

ติดตั้งใน VS Codeหน้า MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

ใช้ฟรี ไลเซนส์ MIT รหัสส่วนขยาย zovo.zovo-sftp เวอร์ชัน 0.1.0

ขั้นตอนใน VS Code

  1. ติดตั้ง SFTP & FTP Sync and Upload จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.zovo-sftp
  2. รัน "SFTP: Create sftp.json Config" จาก Command Palette หรือคลิก Create sftp.json ในมุมมอง SFTP Remote
  3. กรอก protocol (sftp, ftp หรือ ftps), host, username, privateKeyPath (ไม่ต้องใส่ถ้าใช้รหัสผ่าน) และ remotePath ซึ่งเป็นโฟลเดอร์บนเซิร์ฟเวอร์ที่ตรงกับโฟลเดอร์ในเครื่อง hover ที่ key ใดก็ได้เพื่อดูคำอธิบาย
  4. ตั้ง "uploadOnSave": true ตั้งแต่นี้ไปทุกไฟล์ที่คุณบันทึกจะถูกอัปโหลด รหัสผ่านที่คุณพิมพ์จะถูกถามครั้งเดียวและเก็บไว้ใน secret storage ของ editor ไม่เคยเก็บใน sftp.json
  5. คลิกขวาที่ไฟล์หรือโฟลเดอร์ใดก็ได้ใน Explorer หรือที่แท็บ แล้วเลือก Upload, Download หรือ Compare with Server Copy (Compare ใช้กับไฟล์)
  6. เปิดมุมมอง Remote Files เพื่อดูไฟล์บนเซิร์ฟเวอร์ เปิดไฟล์ในแท็บ editor ปกติแล้วบันทึกกลับ ดาวน์โหลด คัดลอก path หรือลบไฟล์ได้ "SFTP: Show Transfer Log" แสดงทุกการเชื่อมต่อและการโอนไฟล์

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

การอัปโหลดตอนบันทึก, Upload, Download และ Compare with Server Copy, มุมมอง Remote Files, SFTP, FTP และ FTPS การตรวจ host key และ transfer log ใช้ได้ฟรี ไม่ต้องมีบัญชีและไม่ต้องลงชื่อเข้าใช้ที่ไหนนอกจากเซิร์ฟเวอร์ของคุณเอง ไม่มี telemetry

เมื่อไฟล์บนเซิร์ฟเวอร์กับโฟลเดอร์ในเครื่องไม่ตรงกันแล้ว Sync Folder with Remote จะเทียบทั้งสองฝั่งและแสดงทุกความแตกต่างก่อนที่จะมีไฟล์ใดถูกย้าย ได้แก่ ไฟล์ที่มีแค่ในเครื่อง ไฟล์ที่มีแค่บนเซิร์ฟเวอร์ หรือไฟล์ที่ใหม่กว่าในฝั่งใดฝั่งหนึ่ง คุณเลือก upload, download, delete หรือ skip ได้ทีละไฟล์ เปิด diff แบบเทียบข้างกัน บันทึก dry run เป็นข้อความ แล้วจึงนำไปใช้ คุณจึงเห็นชัดว่าอะไรจะเปลี่ยนบนเซิร์ฟเวอร์ก่อนที่มันจะเปลี่ยน

วิธีใช้ Sync Folder with Remote (Zovo Pro)

  1. คลิกขวาที่โฟลเดอร์ใน Explorer แล้วเลือก "Zovo Pro: Sync folder with remote (diff preview)" หรือรัน "SFTP: Sync Folder with Remote, Diff Preview (Pro)..." จาก Command Palette มุมมอง Remote Files มีปุ่มเดียวกันในแถบชื่อ
  2. อ่านแผน แล้วเลือก upload, download, delete หรือ skip สำหรับแต่ละไฟล์ และเปิด diff ของไฟล์ที่คุณไม่แน่ใจ
  3. นำแผนไปใช้ ระบบนับการลองใช้เฉพาะเมื่อแผนการซิงก์แสดงขึ้นแล้ว การกด Escape หรือ Cancel ไม่เสียสิทธิ์

Sync Folder with Remote ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.zovo-sftp แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/zovo-sftp
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

SFTP & FTP Sync and Upload ทำอะไรได้บ้าง

  • SFTP ที่ใช้ SSH key, key ที่เข้ารหัส, SSH agent หรือรหัสผ่าน, FTP และ FTPS แบบ TLS ทั้ง explicit และ implicit
  • .vscode, .git, ไฟล์ .env, private key, .npmrc และไฟล์ลับอื่น ๆ จะไม่ถูกอัปโหลด เพิ่ม pattern ของคุณเองได้ใน ignore ในรูปแบบเดียวกับ .gitignore
  • host key ของเซิร์ฟเวอร์จะถูกตรวจ โดยปักไว้ด้วย hostFingerprint หรือยืนยันตอนเชื่อมต่อครั้งแรก ถ้า key เปลี่ยน การเชื่อมต่อจะหยุด
  • ในโฟลเดอร์ที่คุณยังไม่ได้ trust (Restricted Mode) ส่วนขยายจะปิดอยู่ โปรเจกต์ที่ดาวน์โหลดมาจึงส่งไฟล์ของคุณไปที่ไหนไม่ได้
  • เครื่องมือ Pro อีกสองตัว คือ Roll Back a Remote File ซึ่งเก็บสำเนาจากเซิร์ฟเวอร์ 10 ฉบับล่าสุดของไฟล์ไว้ในเครื่องก่อนที่การอัปโหลดจะเขียนทับ และ Server Profiles and Jump Host ซึ่งรวมหลายเซิร์ฟเวอร์ (staging, production) ไว้ใน sftp.json เดียวและเชื่อมต่อผ่าน SSH jump host

สิ่งที่ยังทำไม่ได้

  • เชื่อมต่อได้ครั้งละหนึ่ง connection ต่อเซิร์ฟเวอร์ และการโอนไฟล์ทาง FTP ทำทีละไฟล์ต่อกัน
  • symbolic link บนเซิร์ฟเวอร์จะถูกตามไปสำหรับไฟล์ แต่โฟลเดอร์ที่เป็น link จะไม่ถูกไล่ดูในการอัปโหลด ดาวน์โหลด หรือซิงก์ทั้งโฟลเดอร์
  • key แบบ PuTTY .ppk ต้องแปลงเป็น OpenSSH ก่อน (puttygen key.ppk -O private-openssh -o key)
  • การซิงก์เทียบขนาดและเวลาที่แก้ไข แล้วจึงเทียบไบต์ของไฟล์ที่ขนาดเท่ากัน ได้สูงสุด 300 ไฟล์หรือ 64 MB ต่อการรัน
  • สำเนาสำหรับ rollback เก็บไว้สำหรับไฟล์ขนาดไม่เกิน 5 MB เป็นค่าเริ่มต้น และเก็บไว้ในเครื่องนี้เท่านั้น

คำถามที่พบบ่อย

ใช้ฟรีไหม

การอัปโหลดตอนบันทึก, Upload, Download, Compare with Server Copy, มุมมอง Remote Files และ transfer log ใช้ได้ฟรีทั้งผ่าน SFTP, FTP และ FTPS เครื่องมือ Pro 3 ตัว คือ Sync Folder with Remote, Roll Back a Remote File และ Server Profiles and Jump Host ลองใช้ฟรีได้ตัวละ 3 ครั้ง หลังจากนั้นต้องใช้ Zovo Pro ราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว

รหัสผ่านถูกเก็บไว้ใน sftp.json ไหม

ไม่ รหัสผ่านหรือ passphrase ที่คุณพิมพ์จะเก็บไว้ใน secret storage ของ editor ถ้าไม่ใส่ password ใน sftp.json ระบบจะถามคุณครั้งเดียว

ส่วนขยายจะอัปโหลดไฟล์ .env ของฉันไหม

ไม่ .vscode, .git, ไฟล์ .env, private key และ .npmrc อยู่ในรายการ ignore เริ่มต้นและจะไม่ถูกอัปโหลด

VS Code อัปโหลดผ่าน SFTP ได้โดยไม่มีส่วนขยายไหม

ไม่ได้ VS Code ไม่มีการอัปโหลดผ่าน SFTP หรือ FTP ในตัว Remote SSH แก้ไฟล์บนเซิร์ฟเวอร์โดยตรง ถ้าจะอัปโหลดโปรเจกต์จากเครื่อง ต้องใช้ส่วนขยาย หรือใช้ scp และ rsync ใน terminal
