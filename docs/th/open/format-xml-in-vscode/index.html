คู่มือภาษาไทย

จัดรูปแบบ XML ใน VS Code และรัน XPath กับไฟล์

ติดตั้ง XML Formatter & XPath Tools ซึ่งใช้ได้ฟรี เปิดไฟล์ XML แล้วกด Shift+Alt+F (บน Mac กด Shift+Option+F) ระบบจะเปลี่ยนเฉพาะช่องว่างระหว่างแท็ก ส่วนข้อความ, CDATA, comment, xml:space="preserve" และค่า attribute ยังเหมือนเดิมทุกไบต์ และไฟล์ที่ไม่ well-formed จะไม่ถูกแก้เลย การจัดรูปแบบ, Minify XML, XPath 1.0 ที่ใช้ prefix ของ namespace ในไฟล์, Copy XPath และมุมมอง XML Tree ใช้ได้ฟรีและทำงานออฟไลน์ Zovo Pro (19 ดอลลาร์สหรัฐ จ่ายครั้งเดียว) เพิ่มเครื่องมือ 3 ตัว คือ Run XPath on Every XML File in a Folder, Format All XML Files in a Folder และ Compare Two XML Files Ignoring Formatting และแต่ละตัวลองใช้ฟรีได้ 3 ครั้ง

ขั้นตอนใน VS Code

  1. ติดตั้ง XML Formatter & XPath Tools จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.zovo-xml-xpath-tools
  2. เปิดไฟล์ .xml แล้วกด Shift+Alt+F (บน Mac กด Shift+Option+F) หรือรัน Format Document ถ้าคุณมี XML formatter มากกว่าหนึ่งตัว VS Code จะถามว่าจะใช้ตัวไหน Format Selection ก็ใช้ได้เช่นกัน
  3. formatter ใช้ขนาด tab และการเลือกใช้ tab หรือช่องว่างตามที่คุณตั้งไว้ และคงรูปแบบท้ายบรรทัด byte order mark และบรรทัดว่างท้ายไฟล์ไว้ ถ้าไฟล์ไม่ well-formed จะไม่มีอะไรเปลี่ยน และคุณจะเห็น error พร้อมบรรทัดและคอลัมน์
  4. ถ้าต้องการให้ไฟล์เล็กลงแทน ให้รัน "XML: Minify XML" กับทั้งไฟล์หรือส่วนที่เลือก comment ยังคงอยู่ เว้นแต่คุณเปิด xmlXpathTools.minify.removeComments
  5. ถ้าจะรัน XPath ให้คลิกปุ่มค้นหาในแถบชื่อ editor หรือรัน "XML: Evaluate XPath…" ผลลัพธ์จะแสดงใน XPath Results พร้อมเลขบรรทัด คลิกรายการใดก็ได้เพื่อเลือกตำแหน่งนั้นใน editor
  6. คลิก XPath ในแถบสถานะเพื่อคัดลอก path ของ element ที่เคอร์เซอร์อยู่ แบบมีตำแหน่ง แบบใช้ attribute id หรือ name หรือแบบ local-name() ที่ใช้ได้ทั่วไป
  7. สำหรับไฟล์ที่ใหญ่กว่า 50 MB ให้คลิกขวาที่ไฟล์ใน Explorer แล้วเลือก "Format Large XML File on Disk…" คำสั่งนี้เขียน name.formatted.xml ไว้ข้างไฟล์ หรือแทนที่ไฟล์เดิมหลังจากคุณยืนยัน

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

Format Document, Format Selection, Minify XML, XPath 1.0, Copy XPath, มุมมอง XML Tree, error เรื่อง well-formedness ในแผง Problems และ Format Large XML File on Disk ใช้ได้ฟรี ไม่ต้องลงชื่อเข้าใช้ และส่วนขยายไม่มีโค้ดเครือข่ายเลย

Run XPath on Every XML File in a Folder รัน XPath หนึ่งนิพจน์กับทุกไฟล์ .xml, .xsd, .csproj, .svg, .kml และไฟล์ทำนองเดียวกันในโฟลเดอร์ โดยแต่ละไฟล์ใช้ prefix ของ namespace ของตัวเอง ผลลัพธ์เปิดได้เป็น CSV (file, line, kind, name, value) สำหรับสเปรดชีต เป็น JSON สำหรับสคริปต์ หรือเป็นรายงาน Markdown สำหรับการรีวิว คุณจึงดึงค่าเดียวกันจากหลายไฟล์ได้ เช่น artifactId ทุกตัวในชุดไฟล์ pom.xml โดยไม่ต้องเปิดทีละไฟล์

วิธีใช้ Run XPath on Every XML File in a Folder (Zovo Pro)

  1. คลิกขวาที่โฟลเดอร์ใน Explorer แล้วเลือก "Zovo Pro: Run XPath on Every XML File in a Folder" หรือรัน "XML: Run XPath on Every XML File in a Folder (Pro)" จาก Command Palette แล้วเลือกโฟลเดอร์
  2. หรือหลังจากรัน XPath ในไฟล์หนึ่งแล้ว ให้คลิกบรรทัดสุดท้ายของ XPath Results คือ "Run this XPath on every XML file in a folder" เพื่อรันนิพจน์เดิมกับทั้งโฟลเดอร์
  3. พิมพ์ XPath การแจ้งเตือนจะแสดงความคืบหน้าพร้อมปุ่ม Cancel
  4. เลือก "Open as CSV", "Open as JSON" หรือ "Open a Markdown report" ผลลัพธ์จะเปิดในแท็บ editor ใหม่ ระบบนับการลองใช้เฉพาะเมื่อได้ผลลัพธ์ การกด Escape, XPath ที่พิมพ์ผิด หรือโฟลเดอร์ที่ไม่มีไฟล์ XML จะไม่เสียสิทธิ์

Run XPath on Every XML File in a Folder ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.zovo-xml-xpath-tools แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/zovo-xml-xpath-tools
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

XML Formatter & XPath Tools ทำอะไรได้บ้าง

  • ไฟล์ที่ VS Code เปิดเป็น XML และส่วนขยายยังเปิดไฟล์ .kml, .gpx, .rss, .atom, .wsdl, .dbk, .xlf, .xliff, .resx, .nuspec, .props, .targets และ .xaml เป็น XML ด้วย
  • ไฟล์ใหญ่ การจัดรูปแบบ tree และ XPath ทำงานใน background thread ในการทดสอบของส่วนขยาย ไฟล์ 49 MB ที่มีประมาณ 1 ล้าน element จัดรูปแบบเสร็จใน 1.6 วินาที
  • ชื่อธรรมดาจับคู่กับ default namespace ได้ด้วย //dependency/artifactId จึงใช้ได้ใน pom.xml ถ้าต้องการ XPath 1.0 แบบเคร่งครัด ให้เปิด xmlXpathTools.xpath.strictNamespaces
  • การจัดวาง attribute เลือกได้ว่าจะคงไว้ตามที่เขียน ให้อยู่บรรทัดเดียว หรือหนึ่ง attribute ต่อบรรทัด (การตั้งค่า xmlXpathTools.format.attributes)
  • มุมมอง XML Tree ใน Explorer ตามตำแหน่งเคอร์เซอร์ และแผง Problems แสดง error เรื่อง well-formedness พร้อมบรรทัดและคอลัมน์

สิ่งที่ยังทำไม่ได้

  • รองรับ XPath 1.0 เท่านั้น ไม่มี XPath 2.0 หรือ 3.1, XQuery หรือ XSLT
  • ส่วนขยายตรวจว่าไฟล์ well-formed แต่ไม่ได้ validate กับ XSD หรือ DTD
  • ไฟล์ที่ใหญ่กว่า 50 MB จัดรูปแบบบนดิสก์ได้ แต่ VS Code ไม่ส่งไฟล์ขนาดนี้ให้ส่วนขยาย tree และ XPath จึงไม่ทำงานกับไฟล์เหล่านี้
  • คำสั่งจัดรูปแบบบนดิสก์อ่านไฟล์ UTF-8, UTF-16 ที่มี byte order mark และ ISO-8859-1
  • element ที่มีข้อความอยู่ข้างใน เช่น <p>Some <b>bold</b> text</p> จะคงอยู่ในบรรทัดเดิมตามที่เขียนไว้ มีเพียง element ที่มีแต่แท็กและไม่มีข้อความเท่านั้นที่ได้การขึ้นบรรทัดใหม่

คำถามที่พบบ่อย

ใช้ฟรีไหม

การจัดรูปแบบ, Minify XML, XPath, Copy XPath, มุมมอง XML Tree และการตรวจ well-formedness ใช้ได้ฟรี เครื่องมือ Pro 3 ตัว คือ Run XPath on Every XML File in a Folder, Format All XML Files in a Folder และ Compare Two XML Files Ignoring Formatting ลองใช้ฟรีได้ตัวละ 3 ครั้ง หลังจากนั้นต้องใช้ Zovo Pro ราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว

การจัดรูปแบบจะเปลี่ยนข้อความหรือ CDATA ไหม

ไม่ เปลี่ยนเฉพาะช่องว่างระหว่างแท็กใน element ที่มีแต่แท็กและไม่มีข้อความ ข้อความ, CDATA, comment และเนื้อหาใน xml:space="preserve" ถูกคัดลอกไว้ตามเดิม และการจัดรูปแบบรอบที่สองไม่เปลี่ยนอะไรเลย

ทำไม XPath ไม่เลือกอะไรเลยใน pom.xml

ไฟล์นี้มี default namespace ในส่วนขยายนี้ชื่อธรรมดาจับคู่กับ default namespace ได้ด้วย //dependency จึงใช้ได้ ถ้าต้องการ XPath 1.0 แบบเคร่งครัด ให้เปิด xmlXpathTools.xpath.strictNamespaces

ใช้ใน Cursor ได้ไหม

ได้ Cursor, Windsurf และ VSCodium ติดตั้งได้จาก Open VSX ซึ่งเผยแพร่ในชื่อ zovo/zovo-xml-xpath-tools
