ดูและแก้ไขฐานข้อมูล SQLite ใน VS Code

ติดตั้ง SQLite Viewer & Editor ซึ่งใช้ได้ฟรี แล้วคลิกไฟล์ .db, .sqlite หรือ .sqlite3 แต่ละตารางจะเปิดเป็นกริดแบบอ่านอย่างเดียว มีแท็บ Schema และ SQL ให้คลิกได้ทันที และยังอ่านแถวที่ commit แล้วแต่ยังอยู่ในไฟล์ -wal ด้วย การดูข้อมูล การแก้ไขหลังคลิก Enable editing การ Save พร้อมไฟล์สำรอง และการนำเข้า CSV ใช้ได้ฟรี Zovo Pro (19 ดอลลาร์สหรัฐ จ่ายครั้งเดียว) เพิ่มการเปรียบเทียบฐานข้อมูล ER diagram และการ export ทุกตารางในครั้งเดียว และแต่ละอย่างลองใช้ฟรีได้ 3 ครั้ง

ติดตั้งใน VS Codeหน้า MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

ใช้ฟรี ไลเซนส์ MIT รหัสส่วนขยาย zovo.sqlite-table-viewer เวอร์ชัน 0.4.6

ขั้นตอนใน VS Code

  1. ติดตั้ง SQLite DB Viewer จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.sqlite-table-viewer
  2. คลิกไฟล์ .db, .sqlite, .sqlite3, .db3, .s3db, .sl3, .vscdb หรือ .gpkg ใน Explorer ไฟล์จะเปิดเป็นตารางแบบอ่านอย่างเดียว
  3. เลือกตารางหรือ view ทางซ้าย คลิกหัวคอลัมน์เพื่อเรียงลำดับ พิมพ์ใต้หัวคอลัมน์เพื่อกรอง (เช่น 5..9 หรือ =word) หรือค้นหาทุกคอลัมน์พร้อมกัน
  4. เปิดแท็บ Schema เพื่อดูคอลัมน์ คีย์ foreign key และคำสั่ง CREATE หรือแท็บ SQL เพื่อรันทีละหนึ่งคำสั่ง ระบบเก็บ 20 คำสั่งล่าสุดไว้ให้
  5. ถ้าต้องการแก้ข้อมูล ให้คลิก Enable editing ดับเบิลคลิกเซลล์ พิมพ์ค่าใหม่แล้วกด Enter ทุกการเปลี่ยนแปลงจะรออยู่ในรายการ pending พร้อมคำสั่ง SQL และ Undo
  6. กด Save (Ctrl+S หรือ Cmd+S บน macOS) Save จะตรวจ constraint สร้างไฟล์สำรอง เช่น name.db.20261109-143000.bak แล้วแทนที่ไฟล์เดิมในขั้นตอนเดียว

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

การเปิดและอ่านข้อมูล แท็บ SQL การแก้เซลล์และแถว Save พร้อมไฟล์สำรอง การนำเข้า CSV และ TSV เครื่องมือจัดการตาราง และการ export แถวที่แสดงอยู่ ใช้ได้ฟรี ไม่ต้องมีบัญชีและไม่มีตัวจับเวลาทดลองใช้

เครื่องมือนี้เขียนทุกตารางของฐานข้อมูลในครั้งเดียว เป็นไฟล์ Excel (.xlsx) ไฟล์เดียวที่มีหนึ่ง sheet ต่อหนึ่งตาราง พร้อมแถวหัวตารางตัวหนาที่ตรึงไว้ หรือเป็นโฟลเดอร์ที่มีไฟล์ CSV หนึ่งไฟล์ต่อหนึ่งตาราง Export แบบฟรีบันทึกได้เฉพาะแถวที่แสดงอยู่ของตารางเดียว เครื่องมือนี้จึงช่วยให้ไม่ต้อง export ทีละตาราง และมันอ่านฐานข้อมูลอย่างเดียว ไม่เขียนอะไรลงไป

วิธีใช้ Export All SQLite Tables to Excel or CSV (Zovo Pro)

  1. เมื่อเปิดฐานข้อมูลอยู่ ให้คลิกปุ่ม DB tools (มีป้าย PRO เล็ก ๆ) ในแถบเครื่องมือของ editor หรือคลิกเครื่องมือนี้ในแถว "Pro tools" ใต้แถบเครื่องมือ
  2. หรือคลิกขวาที่ไฟล์ฐานข้อมูลใน Explorer แล้วเลือก "Zovo Pro: Export All Tables to Excel or CSV" หรือรัน "Export All SQLite Tables to Excel or CSV (Pro)…" จาก Command Palette
  3. เลือก "Excel workbook (.xlsx)" หรือ "CSV files in a folder" แล้วเลือกที่บันทึก ระบบนับการลองใช้เฉพาะเมื่อเขียนไฟล์เสร็จ และการกด Escape ไม่เสียสิทธิ์

Export All SQLite Tables to Excel or CSV ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.sqlite-table-viewer แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/sqlite-table-viewer
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

SQLite DB Viewer ทำอะไรได้บ้าง

  • แถวที่ commit แล้วแต่ยังอยู่ในไฟล์ -wal พร้อมรีโหลดสดขณะที่แอปของคุณกำลังเขียน (ปุ่ม Live ใช้ปิดฟีเจอร์นี้)
  • เซลล์ JSON แสดงเป็นต้นไม้ รูปภาพแสดงเป็นภาพ และ BLOB แบบ float32 แสดงเป็นเวกเตอร์ในแผงเซลล์
  • คัดลอกเป็น CSV, TSV, JSON หรือคำสั่ง INSERT และ export แถวที่แสดงอยู่เป็น CSV, JSON หรือคำสั่ง SQL INSERT
  • นำเข้า CSV และ TSV ลงตารางใหม่หรือตารางที่มีอยู่ พร้อมพรีวิว การจับคู่คอลัมน์ แถบความคืบหน้า และ Cancel
  • ฐานข้อมูลขนาดไม่เกิน 512 MB โดยดึงแถวมาทีละหน้า

สิ่งที่ยังทำไม่ได้

  • ฐานข้อมูลทั้งไฟล์ถูกโหลดเข้าหน่วยความจำ ไฟล์ที่ใหญ่กว่า 512 MB จะแสดงข้อความ (การตั้งค่า sqliteTableViewer.maxFileSizeMB)
  • แก้ไขได้เฉพาะไฟล์ขนาดไม่เกิน 256 MB (การตั้งค่า sqliteTableViewer.editMaxFileSizeMB) ไฟล์ที่ใหญ่กว่านั้นเปิดได้แบบอ่านอย่างเดียว
  • เปิดฐานข้อมูลที่เข้ารหัส (SQLCipher, SEE) ไม่ได้
  • แก้ไขได้เฉพาะไฟล์ที่อยู่บนเครื่องนี้ ไฟล์บน remote หรือ virtual file system เปิดได้แบบอ่านอย่างเดียว
  • การเปลี่ยนแปลงที่ยังไม่ได้ Save จะหายไปเมื่อปิดแท็บ และไฟล์จะยังเหมือนเดิม

คำถามที่พบบ่อย

ใช้ฟรีไหม

การเปิด การดูข้อมูล แท็บ SQL การแก้ไข Save และการนำเข้า CSV ใช้ได้ฟรีโดยไม่ต้องมีบัญชี เครื่องมือ Pro 3 ตัว (Compare SQLite Databases, ER Diagram และ Export All Tables) ลองใช้ฟรีได้ตัวละ 3 ครั้ง หลังจากนั้นต้องใช้ Zovo Pro ราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว

แก้ไขแถวใน VS Code ได้ไหม

ได้ ไฟล์จะเปิดแบบอ่านอย่างเดียวก่อน ให้คลิก Enable editing เพื่อแก้เซลล์และแถว หรือรัน INSERT และ UPDATE ไม่มีอะไรถูกเขียนลงไฟล์จนกว่าคุณจะกด Save ซึ่งจะสร้างไฟล์สำรองก่อน

ทำไมโปรแกรมดูอื่นแสดงข้อมูลเก่า

ในโหมด WAL การ commit ใหม่จะอยู่ในไฟล์ -wal จนกว่า checkpoint จะคัดลอกเข้าไฟล์หลัก โปรแกรมที่อ่านเฉพาะไฟล์หลักจึงไม่เห็นแถวเหล่านั้น ส่วนขยายนี้อ่านส่วนที่ commit แล้วในไฟล์ -wal ด้วย

ใช้ใน Cursor ได้ไหม

ได้ ส่วนขยายนี้อยู่บน Open VSX ในชื่อ zovo/sqlite-table-viewer จึงติดตั้งใน Cursor, Windsurf และ VSCodium ได้
