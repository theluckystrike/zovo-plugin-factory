เปิดดู bucket ของ AWS S3, Cloudflare R2 หรือ MinIO ใน VS Code

ติดตั้ง S3 Explorer ซึ่งใช้ได้ฟรี แล้วเปิดมุมมอง S3 Buckets ใน Activity Bar ใช้ได้กับ AWS S3 (โปรไฟล์จาก ~/.aws รวมถึงโปรไฟล์ SSO), Cloudflare R2, MinIO, Backblaze B2, Wasabi และ DigitalOcean Spaces การเปิดดู การเปิด object แบบอ่านอย่างเดียว อัปโหลด ดาวน์โหลด คัดลอก ย้าย เปลี่ยนชื่อ ลบ versions, tags, presigned URL และการซิงก์โฟลเดอร์ใช้ได้ฟรี ไม่ต้องลงชื่อเข้าใช้และไม่มี telemetry Zovo Pro (19 ดอลลาร์สหรัฐ จ่ายครั้งเดียว) เพิ่มเครื่องมือ 3 ตัว คือ Copy to Another Connection, Size and Cost Report และ Scheduled Sync และแต่ละตัวลองใช้ฟรีได้ 3 ครั้ง

ขั้นตอนใน VS Code

  1. ติดตั้ง S3 Explorer จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.zovo-s3-explorer
  2. เปิดมุมมอง S3 Explorer ใน Activity Bar แล้วคลิก Add Connection เลือกโปรไฟล์ AWS จาก ~/.aws หรือพิมพ์ access key, account ID และ token ของ R2 หรือ endpoint URL ของ MinIO หรือบริการอื่นที่เข้ากันได้กับ S3 key ที่คุณพิมพ์จะเก็บไว้ใน keychain ของระบบปฏิบัติการ
  3. ขยาย connection เพื่อดู bucket key จะโหลดครั้งละ 1,000 รายการพร้อมแถว "Load 1,000 more" ถ้า key ของคุณไม่มีสิทธิ์แสดงรายการ bucket ให้คลิกขวาที่ connection แล้วเลือก Add Bucket by Name
  4. คลิก object เพื่อเปิดแบบอ่านอย่างเดียวในแท็บหรือใน viewer ที่เหมาะกับไฟล์ ถ้าต้องการดู metadata, tags, versions และ presigned URL ให้คลิกขวาแล้วเลือก Show Details, Versions and Presigned URL
  5. ถ้าจะแก้ object ให้คลิกขวาแล้วเลือก Edit and Upload คุณแก้สำเนา และกล่องโต้ตอบจะแสดง bucket, key และขนาดทั้งสองก่อนแทนที่ object
  6. ลากไฟล์หรือโฟลเดอร์จาก Explorer มาวางบน bucket เพื่ออัปโหลด หรือคลิกขวาแล้วเลือก Download ไฟล์ตั้งแต่ 16 MB ขึ้นไปจะอัปโหลดเป็นส่วน ๆ พร้อมความคืบหน้าและปุ่ม Cancel และการอัปโหลดที่หยุดไปจะทำต่อโดยส่งเฉพาะส่วนที่ขาด
  7. ถ้าต้องการให้โฟลเดอร์ในเครื่องกับ prefix ตรงกัน ให้คลิกขวาที่ bucket หรือโฟลเดอร์แล้วเลือก Sync Folder คุณจะเห็นแผน dry-run (ใหม่ เปลี่ยนแปลง จะลบ) ก่อนที่จะมีอะไรเปลี่ยน

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

การเปิดดู การเปิด object, Edit and Upload, อัปโหลด ดาวน์โหลด คัดลอก ย้าย เปลี่ยนชื่อ ลบ versions, tags, presigned URL และการซิงก์โฟลเดอร์ใช้ได้ฟรี ไม่ต้องลงชื่อเข้าใช้ ไม่ต้องมีบัญชี และไม่มี telemetry ส่วนขยายเชื่อมต่อเฉพาะ storage endpoint ที่คุณเพิ่มเท่านั้น

Copy to Another Connection คัดลอก object หรือทั้งโฟลเดอร์จาก connection หนึ่งไปอีก connection หนึ่ง เช่น จาก AWS S3 ไป Cloudflare R2 หรือ MinIO โดยมีการยืนยันแบบเดียวกับการคัดลอกทุกครั้ง คือแสดงรายการ key และระบุ key ที่จะถูกแทนที่ object ขนาดใหญ่ใช้ multipart upload คุณจึงย้ายข้อมูลข้ามผู้ให้บริการหรือข้ามบัญชีได้จาก tree โดยไม่ต้องเขียนสคริปต์หรือใช้เครื่องมืออื่น

วิธีใช้ Copy to Another Connection (Zovo Pro)

  1. เพิ่ม connection ที่สองก่อน จากนั้นคลิกขวาที่ object หรือโฟลเดอร์ในมุมมอง S3 Buckets แล้วเลือก "Copy to Another Connection... (Pro)" หรือคลิก Copy to Another Connection ในแถว "Zovo Pro tools" ท้ายมุมมอง
  2. เลือก connection ปลายทาง bucket และโฟลเดอร์ปลายทาง (เว้นว่างไว้สำหรับระดับบนสุด)
  3. อ่านรายการ object ในหน้ายืนยันแล้วคลิก Copy หรือ Copy and Replace เมื่อมีบาง key อยู่แล้ว การแจ้งเตือนจะแสดงความคืบหน้า
  4. ระบบนับการลองใช้เฉพาะเมื่อคัดลอก object แล้ว การกด Escape ระหว่างเลือก หรือการที่ยังไม่มี connection ที่สอง จะไม่เสียสิทธิ์

Copy to Another Connection ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.zovo-s3-explorer แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/zovo-s3-explorer
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

S3 Explorer ทำอะไรได้บ้าง

  • โปรไฟล์ AWS ที่ใช้ access key, credential_process, role ที่มี source_profile และโปรไฟล์ SSO หลัง aws sso login ส่วนขยายใช้ endpoint_url ในโปรไฟล์ด้วย
  • MinIO และบริการอื่นที่เข้ากันได้กับ S3 ผ่าน endpoint URL, region, URL แบบ path-style หรือ virtual-hosted และตัวเลือกให้ยอมรับ certificate แบบ self-signed
  • Metadata, content type, storage class, ETag, tags (แก้และบันทึก), versions (เปิด ดาวน์โหลด กู้คืน) และ presigned URL แบบ GET หรือ PUT ตั้งแต่ 15 นาทีถึง 7 วัน
  • bucket ที่มี key นับล้าน โหลดครั้งละ 1,000 รายการ พร้อมการค้นหาและกรองด้วย prefix
  • การดาวน์โหลดคงโครงสร้างโฟลเดอร์ไว้และไม่เขียนไฟล์นอกโฟลเดอร์ที่คุณเลือก key ที่มีส่วน .., drive letter หรือไบต์ NUL จะถูกข้ามและแสดงในรายการ

สิ่งที่ยังทำไม่ได้

  • ส่วนขยายไม่ใช้โปรไฟล์ default ของ AWS หรือ AWS_PROFILE เอง คุณต้องเลือกโปรไฟล์ที่จะใช้เชื่อมต่อ
  • object ที่เป็นข้อความและใหญ่กว่า 10 MB จะถามก่อน แล้วแสดง 1 MB แรก object แบบ binary ที่ใหญ่กว่า 200 MB จะถามก่อนดาวน์โหลด
  • object ที่เปิดเป็นแบบอ่านอย่างเดียว มีเพียง Edit and Upload ที่เขียนลง bucket หลังการยืนยัน
  • Scheduled Sync ทำงานเฉพาะตอนที่ VS Code เปิดอยู่ ทุก 5 ถึง 60 นาที และไม่ลบไฟล์
  • request ที่ไม่ได้รับคำตอบจะหยุดหลัง 30 วินาที (การตั้งค่า s3Explorer.requestTimeoutSeconds)

คำถามที่พบบ่อย

ใช้ฟรีไหม

การเปิดดู การเปิด object อัปโหลด ดาวน์โหลด คัดลอก ย้าย เปลี่ยนชื่อ ลบ versions, tags, presigned URL และการซิงก์โฟลเดอร์ใช้ได้ฟรี เครื่องมือ Pro 3 ตัว คือ Copy to Another Connection, Size and Cost Report และ Scheduled Sync ลองใช้ฟรีได้ตัวละ 3 ครั้ง หลังจากนั้นต้องใช้ Zovo Pro ราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว

key ของฉันถูกเก็บไว้ที่ไหน

key ที่คุณพิมพ์จะเก็บใน keychain ของระบบปฏิบัติการผ่าน SecretStorage ของ VS Code ไม่เคยเก็บในไฟล์ settings ส่วนโปรไฟล์ AWS จะอ่านจาก ~/.aws เฉพาะเมื่อคุณเลือกโปรไฟล์

ใช้กับ Cloudflare R2 และ MinIO ได้ไหม

ได้ R2 ใช้ account ID ของคุณและ access key ของ R2 API token ส่วน MinIO และบริการอื่นที่เข้ากันได้กับ S3 ใช้ endpoint URL, region และ URL แบบ path-style หรือ virtual-hosted

ใช้ใน Cursor ได้ไหม

ได้ Cursor, Windsurf และ VSCodium ติดตั้งได้จาก Open VSX ซึ่งเผยแพร่ในชื่อ zovo/zovo-s3-explorer
