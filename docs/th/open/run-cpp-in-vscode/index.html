รันไฟล์ C++ ใน VS Code ด้วยคลิกเดียว

ติดตั้งส่วนขยายฟรี Run C++ and C Code เปิดไฟล์ .cpp หรือ .c แล้วคลิก Run ที่แถบชื่อของ editor หรือกด Ctrl+Alt+Enter (Cmd+Alt+Enter บน Mac) ส่วนขยายจะคอมไพล์ไฟล์ด้วย gcc, g++, clang หรือ clang++ ที่มีอยู่แล้วในเครื่อง แล้วรันในเทอร์มินัลที่ cin และ scanf ใช้งานได้ปกติ error จาก compiler จะไปอยู่ในแผง Problems ตรงบรรทัดที่ผิด ส่วนแผง Input & Tests, stress test และ benchmark ใช้ฟรี Zovo Pro (19 ดอลลาร์สหรัฐ จ่ายครั้งเดียว) เพิ่ม sanitizer check การเทียบ -O0, -O2 และ -O3 และ test report โดยลองใช้ฟรีได้ตัวละ 3 ครั้ง

ติดตั้งใน VS Codeหน้า MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

ใช้ฟรี ไลเซนส์ MIT รหัสส่วนขยาย zovo.zovo-run-cpp เวอร์ชัน 0.2.3

ขั้นตอนใน VS Code

  1. ติดตั้ง Run C++ and C Code จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.zovo-run-cpp
  2. ตรวจว่ามี compiler ติดตั้งอยู่ คำสั่ง "Run C++: Pick Compiler (gcc, g++, clang, clang++)" จะแสดงรายการที่หาเจอ ถ้าไม่เจอเลย จะมีหน้า setup ที่บอกขั้นตอนทางการสำหรับระบบของคุณ (Xcode Command Line Tools, MSYS2 หรือ WinLibs หรือ package manager ของ Linux)
  3. เปิดไฟล์ .cpp, .cc, .cxx หรือ .c แล้วคลิกปุ่ม Run ที่แถบชื่อของ editor หรือกด Ctrl+Alt+Enter (Cmd+Alt+Enter บน Mac)
  4. โปรแกรมจะรันในเทอร์มินัลชื่อ "Run: file.cpp" ให้พิมพ์ input ที่นั่น เมื่อจบจะเห็น exit code เวลาที่ใช้รัน และหน่วยความจำสูงสุด (peak memory) ระหว่างที่โปรแกรมรัน ปุ่ม Run จะเปลี่ยนเป็น Stop
  5. ถ้าต้องการแฟล็กหรืออาร์กิวเมนต์ ให้ใส่ // run: -O2 -lm และ // args: "Hello World" 3 ไว้ใน 40 บรรทัดแรกของไฟล์ ค่าเริ่มต้นของ C++ คือ -std=c++20 -Wall -Wextra -g -O0
  6. ถ้าจะทดสอบด้วย input ที่บันทึกไว้ ให้รัน "Run C++: Run with Input & Test Cases" วาง input แล้วกด Run with input จากนั้นกด Save as test case ส่วน Run all tests จะแสดงว่าผ่านหรือไม่ผ่าน พร้อม diff ทีละบรรทัด

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

Run, Build Only, Run Last Build, Debug การ build ทั้งโฟลเดอร์ แผง Input & Tests, stress test และ benchmark ใช้ฟรี ไม่ต้องลงชื่อเข้าใช้ ไม่มีการเชื่อมต่อเครือข่าย และไม่มี telemetry

โปรแกรมที่ผ่านเทสต์ทุกเคสก็ยังอาจอ่านเลยท้าย array หรือทำให้ int overflow ได้ Sanitizer check จะ build อีกชุดหนึ่งด้วย AddressSanitizer และ UndefinedBehaviorSanitizer (-fsanitize=address,undefined) รันกับ input ในแผงและกับ test case ที่บันทึกไว้ทุกเคส แล้วแสดง heap หรือ stack overflow, use after free, signed overflow และ undefined behavior แบบอื่นในแผง Problems ตรงบรรทัดที่เกิด คุณจึงเจอบั๊กที่บรรทัดของมันโดยไม่ต้องตั้งแฟล็ก sanitizer เอง

วิธีใช้ Sanitizer check (Zovo Pro)

  1. ใส่ input ในแผง Input & Tests และบันทึก test case ไว้ถ้ามี การตรวจจะรันกับ input ในแผงและกับ test case ที่บันทึกไว้ทุกเคส
  2. คลิก "Sanitizer check (Pro)" ในแผงใต้หัวข้อ "Stress test, benchmark and more" หรือรัน "Run C++: Sanitizer Check: AddressSanitizer and UBSan on the Input and Test Cases (Zovo Pro)" จาก Command Palette
  3. คลิกรายการที่พบในแผง Problems เพื่อไปยังบรรทัดนั้น ถ้า build error หรือกด Stop หรือ Cancel จะไม่เสียสิทธิ์ลองใช้ฟรี

Sanitizer check ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.zovo-run-cpp แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/zovo-run-cpp
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

Run C++ and C Code ทำอะไรได้บ้าง

  • ไฟล์ C และ C++ (.c, .cpp, .cc, .cxx) กับ gcc, g++, clang และ clang++
  • MSYS2, WinLibs, MinGW, TDM-GCC และ LLVM ในโฟลเดอร์ปกติบน Windows และชื่อแบบ Homebrew เช่น g++-14
  • path ที่มีช่องว่าง & หรือตัวอักษรที่ไม่ใช่ ASCII เพราะไม่มี shell มาแปลความ path
  • โปรแกรมที่พิมพ์ออกมาเป็นล้านบรรทัด แผงจะแสดง 2,000 บรรทัดแรกและนับส่วนที่เหลือ

สิ่งที่ยังทำไม่ได้

  • ต้องมี compiler ในเครื่องของคุณ ส่วนขยายไม่ดาวน์โหลด compiler ให้
  • การรันในแผง Input และ test case จะหยุดหลัง 10 วินาที (การตั้งค่า zovoRun.timeLimitSeconds)
  • output ที่เกิน 32 MB จะถูกนับ แต่ไม่เก็บไว้ (การตั้งค่า zovoRun.maxCapturedOutputMB)
  • sanitizer check ต้องใช้ compiler ที่มี sanitizer runtime ซึ่ง MinGW gcc บน Windows ไม่มี ให้ใช้ clang จาก LLVM แทน และการตรวจจะแจ้งเรื่องนี้โดยไม่เสียสิทธิ์ลองใช้
  • Debug ต้องติดตั้ง CodeLLDB หรือส่วนขยาย C/C++ ไว้ก่อน

คำถามที่พบบ่อย

ใช้ฟรีไหม

Run, Build Only, Debug การ build ทั้งโฟลเดอร์ แผง Input & Tests, stress test และ benchmark ใช้ฟรี เครื่องมือ Pro ทั้งสามตัว คือ Sanitizer check, Compare -O0, -O2 และ -O3 และ Test report ลองใช้ฟรีได้ตัวละ 3 ครั้ง หลังจากนั้นต้องใช้ Zovo Pro ราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว

โปรแกรมรับ input ด้วย cin ได้ไหม

ได้ โปรแกรมรันในเทอร์มินัลจริง cin และ scanf จึงรอสิ่งที่คุณพิมพ์ และข้อความถามที่ไม่มีการขึ้นบรรทัดใหม่จะแสดงขึ้นก่อน

ส่วนขยายแก้ settings.json หรือ tasks.json ไหม

ไม่แก้ ส่วนขยายไม่เขียนไฟล์การตั้งค่าของคุณเลย Debug จะเพิ่มหนึ่งรายการใน .vscode/launch.json และเพิ่มเฉพาะตอนที่คุณกด Debug เท่านั้น

ใช้ใน Cursor ได้ไหม

ได้ ส่วนขยายนี้อยู่บน Open VSX ทั้ง Cursor, Windsurf และ VSCodium จึงติดตั้งได้
