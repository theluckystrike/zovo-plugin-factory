เล่นไฟล์เสียงใน VS Code

ติดตั้ง Audio Player & WAV Player ซึ่งใช้ฟรี แล้วคลิกไฟล์ .wav, .mp3, .flac, .ogg หรือ .opus ส่วนขยายจะเล่นไฟล์พร้อม waveform แยกตามช่องเสียง, spectrogram, A-B loop, ความเร็ว 0.25x ถึง 2x โดย pitch ไม่เปลี่ยน และค่าความดัง LUFS ไฟล์ Opus เล่นด้วย decoder ที่มากับส่วนขยาย ส่วนไฟล์ M4A และ AAC เล่นได้หลังคลิกหนึ่งครั้งถ้าเครื่องคุณมี ffmpeg การเล่นและตรวจไฟล์ใช้ฟรี และ Zovo Pro (19 ดอลลาร์สหรัฐ จ่ายครั้งเดียว) เพิ่มเครื่องมือ 2 ตัว คือ Folder Loudness Report และ Normalize Loudness แต่ละตัวลองใช้ฟรีได้ 3 ครั้ง

ขั้นตอนใน VS Code

  1. ติดตั้ง Audio Player & WAV Player จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.audio-preview-vscode
  2. คลิกไฟล์ .wav, .mp3, .flac, .ogg, .opus หรือ .m4a ใน Explorer ถ้า player ตัวอื่นเปิดขึ้นมาแทน ให้คลิกขวาที่ไฟล์แล้วเลือก "Open in Audio Preview"
  3. กด Space เพื่อเล่นหรือหยุด ลูกศรซ้ายและขวากระโดด 5 วินาที (1 วินาทีเมื่อกด Shift ด้วย) คลิกที่ waveform เพื่อ seek
  4. ลากบน waveform เพื่อวนเล่นช่วงนั้น หรือกด [ และ ] เพื่อตั้งจุดเริ่มและจุดจบของ loop ที่ตำแหน่ง playhead กด L เพื่อเปิดหรือปิด loop
  5. เลือกความเร็วตั้งแต่ 0.25x ถึง 2x โดย pitch ยังเท่าเดิม
  6. ดูส่วนหัวสำหรับ codec, sample rate, จำนวนช่องเสียง, bit depth, ความยาว และ bitrate ดูแผง Loudness สำหรับ LUFS, peak และ RMS และดูแผง Tags สำหรับ title, artist, album และ tag อื่น ๆ

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

การเล่นทุกฟอร์แมตที่รองรับ, waveform, spectrogram, A-B loop, ความเร็ว, แผง Loudness, File และ Tags และ Copy stats ใช้ฟรี ส่วนขยายไม่เขียนอะไรกลับลงไฟล์เสียงและไม่เรียกเครือข่าย

Folder Loudness Report เขียนไฟล์ CSV ที่มีหนึ่งแถวต่อไฟล์เสียงหนึ่งไฟล์ในโฟลเดอร์ ประกอบด้วยฟอร์แมต, ความยาว, sample rate, bit depth, title และ artist, integrated LUFS, ค่าสูงสุดของ short-term และ momentary, sample peak, RMS, จำนวน clipped samples และ gain ที่แต่ละไฟล์ต้องปรับเพื่อให้ได้ -14, -16 และ -23 LUFS คุณเรียงและตรวจไฟล์บันทึกเสียงทั้งโฟลเดอร์ใน spreadsheet ได้แทนการเปิดทีละไฟล์ ส่วนขยายอ่านไฟล์ WAV เอง ส่วนแถวของ MP3, FLAC, Ogg, Opus และ M4A ต้องใช้ ffmpeg ของคุณเอง

วิธีใช้ Folder Loudness Report (Zovo Pro)

  1. คลิกขวาที่โฟลเดอร์ใน Explorer แล้วเลือก "Folder Loudness Report (CSV, Pro)" หรือรัน "Audio Preview: Folder Loudness Report (CSV, Pro)" จาก Command Palette แล้วเลือกโฟลเดอร์ ใน player ยังมีคำสั่งนี้ในเมนู "..." บนแถบชื่อของ editor ด้วย
  2. เลือก "This folder and its subfolders" หรือ "This folder only" แล้วเลือกตำแหน่งบันทึก loudness-report.csv
  3. การแจ้งเตือนจะแสดงความคืบหน้าและกดยกเลิกได้ เปิดไฟล์ CSV ใน spreadsheet ระบบนับการลองใช้เมื่อเขียนไฟล์เสร็จแล้วเท่านั้น

Folder Loudness Report ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.audio-preview-vscode แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/audio-preview-vscode
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

Audio Player & WAV Player ทำอะไรได้บ้าง

  • WAV (PCM 8 ถึง 32-bit, float, A-law, mu-law, RF64) อ่านทีละ chunk ขนาด 2 MB ไฟล์ใหญ่จึงไม่ทำให้ editor ค้าง
  • MP3, FLAC และ Ogg Vorbis ด้วย decoder ที่ VS Code มีอยู่แล้ว
  • Opus ในไฟล์ .opus หรือ .ogg ด้วย decoder libopus (WebAssembly) ที่มากับส่วนขยาย
  • สูงสุด 8 ช่องเสียง แต่ละช่องมี waveform ของตัวเอง
  • Tags จาก ID3v1, ID3v2.2 ถึง 2.4, RIFF INFO, Vorbis comments และ iTunes atoms

สิ่งที่ยังทำไม่ได้

  • M4A และ AAC ต้องใช้ ffmpeg ของคุณเอง ถ้าไม่มีจะเห็น codec, ความยาว, bitrate, tags และข้อความแจ้ง
  • ALAC, AC-3 และ codec อื่นที่ VS Code ถอดรหัสไม่ได้ ก็ต้องใช้ปุ่ม ffmpeg เช่นกัน
  • ไฟล์ที่บีบอัดจะถูกถอดรหัสทั้งไฟล์ ถ้า sample ที่ถอดรหัสแล้วเกิน 600 MB (ประมาณ 28 นาทีของ stereo 44.1 kHz) จะเล่นได้อย่างเดียว (การตั้งค่า audioPreview.maxDecodedMB)
  • ค่า peak เป็น sample peak ไม่ใช่ true peak แบบ oversampled และไม่มี loudness range (LRA)
  • ส่วนขยายนี้เล่นและตรวจไฟล์เท่านั้น ไม่ได้ตัดหรือแก้ไขไฟล์

คำถามที่พบบ่อย

ใช้ฟรีไหม

การเล่น, waveform, spectrogram, loop และค่าความดังใช้ฟรี เครื่องมือ Pro 2 ตัว คือ Folder Loudness Report และ Normalize Loudness ลองใช้ฟรีได้อย่างละ 3 ครั้ง หลังจากนั้นต้องใช้ Zovo Pro ราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว

ทำไมไฟล์ .opus เล่นใน VS Code ไม่ได้

VS Code มาพร้อม Chromium ที่ไม่มี Opus decoder ส่วนขยายนี้จึงใส่ libopus ที่คอมไพล์เป็น WebAssembly มาด้วย Opus จึงเล่นได้โดยไม่ต้องติดตั้งอะไรเพิ่ม

ทำไมไฟล์ M4A แสดงข้อความแทนที่จะเล่น

VS Code ไม่มี AAC decoder เช่นกัน ถ้าติดตั้ง ffmpeg ไว้ ปุ่ม Decode with ffmpeg จะสร้างสำเนา WAV ไว้ในโฟลเดอร์ storage ของส่วนขยาย แล้วไฟล์จะเล่นได้ ส่วนขยายไม่ได้ใส่ ffmpeg มาให้และไม่ดาวน์โหลดเอง

ใช้ใน Cursor ได้ไหม

ได้ ส่วนขยายอยู่บน Open VSX ในชื่อ zovo/audio-preview-vscode Cursor, Windsurf และ VSCodium จึงติดตั้งได้
