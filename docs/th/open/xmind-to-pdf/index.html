คู่มือภาษาไทย

แปลง XMind เป็น PDF โดยไม่ต้องใช้ XMind ทุก sheet ใน PDF ไฟล์เดียว

ติดตั้ง XMind Viewer & Mind Map Viewer (zovo.xmind-mind-map-viewer) แล้วคลิกไฟล์ .xmind ทุก sheet จะเปิดเป็นแท็บโดยไม่ต้องมี XMind การดู การค้นหา และการ export เป็น PNG, SVG และ Markdown ใช้ฟรี PDF of every sheet เป็นเครื่องมือ Zovo Pro ที่บันทึก PDF ไฟล์เดียว หน้าละหนึ่ง sheet ในสีสำหรับพิมพ์ และมี bookmark ของแต่ละ sheet ลองใช้ฟรีได้ 3 ครั้งบนเครื่องของคุณ หลังจากนั้น Zovo Pro ราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว

ติดตั้งใน VS Codeหน้า MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

ใช้ฟรี ไลเซนส์ MIT รหัสส่วนขยาย zovo.xmind-mind-map-viewer เวอร์ชัน 0.2.3

ขั้นตอนใน VS Code

  1. ติดตั้ง XMind Viewer จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.xmind-mind-map-viewer
  2. คลิกไฟล์ .xmind ใน Explorer เปิดได้ทั้งไฟล์จาก XMind 2020 ขึ้นไป, XMind Zen และ XMind 8 ทุก sheet ของแผนผังจะเป็นแท็บอยู่ด้านบน
  3. ดูทีละ sheet แต่ละ sheet เปิดด้วยเลย์เอาต์ที่บันทึกไว้ในไฟล์ ลากเพื่อเลื่อน ใช้ Ctrl หรือ Cmd กับล้อเมาส์เพื่อซูม และกด F เพื่อให้ sheet พอดีกับหน้าจอ
  4. เปิดเมนู "Export…" ในแถบเครื่องมือเหนือแผนผัง แล้วเลือก "PDF, every sheet (Zovo Pro)" หรือรัน "XMind Viewer: Export every sheet as PDF (Zovo Pro)" จาก Command Palette ขณะที่แผนผังเปิดอยู่
  5. ตั้งชื่อไฟล์ในหน้าต่างบันทึกแล้วคลิก "Export PDF" จะมีข้อความบอกจำนวนหน้าที่บันทึก พร้อมปุ่ม "Show in folder" ไฟล์แผนผังของคุณไม่ถูกแก้ไขเลย
  6. ถ้าต้องการภาพของ sheet เดียวแบบฟรี ให้เลือก "PNG picture" หรือ "SVG picture" ในเมนู Export เดียวกัน

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

การเปิดไฟล์ .xmind, .mm และ .opml ใช้ฟรี ทั้งทุก sheet, ทุกเลย์เอาต์, การย่อกิ่ง, ระดับ, การค้นหา และแผงรายละเอียด การ export เป็น PNG (สูงสุด 2x), SVG, sheet เป็น Markdown outline ลง clipboard และทุก sheet เป็นไฟล์ Markdown ไฟล์เดียวก็ใช้ฟรีเช่นกัน

PDF of every sheet บันทึกทุก sheet ของแผนผังเป็นไฟล์ PDF ไฟล์เดียว หน้าละหนึ่ง sheet ในสีสำหรับพิมพ์ และมี bookmark ของแต่ละ sheet คุณได้แผนผังทั้งหมดในการรันครั้งเดียว แทนที่จะ export ทีละ sheet เป็นภาพแล้วนำภาพมาต่อกันเอง ใน XMind เอง การ export เป็น PDF ต้องใช้ XMind Pro ซึ่งเป็นแผนแบบเสียเงินของ XMind

วิธีใช้ PDF of every sheet (Zovo Pro)

  1. ขณะที่แผนผังเปิดอยู่ ให้เลือก "PDF, every sheet (Zovo Pro)" ในเมนู "Export…" หรือคลิก "PDF of every sheet" ในแถว Zovo Pro เล็ก ๆ บนแถบเครื่องมือ หรือรัน "XMind Viewer: Export every sheet as PDF (Zovo Pro)" จาก Command Palette
  2. จาก Explorer ให้คลิกขวาที่ไฟล์ .xmind, .mm หรือ .opml แล้วเลือก "Zovo Pro: PDF of every sheet"
  3. เลือกตำแหน่งบันทึก PDF แล้วคลิก "Export PDF" ระบบนับการลองใช้เมื่อบันทึกไฟล์แล้วเท่านั้น การกด Cancel จึงไม่เสียสิทธิ์
  4. เมื่อใช้ครบ 3 ครั้งที่ลองฟรีแล้ว เครื่องมือจะแสดงช่องทางรับ Zovo Pro

PDF of every sheet ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

Zovo Pro ราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียว ไม่ใช่แบบ subscription และไลเซนส์จะเปิดเครื่องมือ Pro ในส่วนขยาย Zovo ทุกตัว ไม่ใช่แค่ใน XMind Viewer หลังจ่ายด้วยบัตร (Stripe) คีย์ไลเซนส์จะแสดงในหน้าถัดไป ใน VS Code ให้รัน "Zovo Pro: Enter Zovo Pro license key" จาก Command Palette แล้ววางคีย์ คีย์จะถูกตรวจบนเครื่องของคุณโดยไม่ต้องเชื่อมต่อเครือข่าย ถ้าจ่ายผ่าน GitHub Sponsors ให้เลือกระดับ "$19 one time" แล้วรัน "Zovo Pro: I already paid: unlock with GitHub Sponsors"

ทีม 5 คนจ่าย 59 ดอลลาร์สหรัฐ ครั้งเดียวเช่นกัน (จ่ายด้วยบัตร) กติกาทั้งหมดและเครื่องมือ Pro ทุกตัวอยู่ในหน้า Zovo Pro (ภาษาอังกฤษ)

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.xmind-mind-map-viewer แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/xmind-mind-map-viewer
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

XMind Viewer ทำอะไรได้บ้าง

  • ไฟล์ .xmind จาก XMind 2020 ถึง 2026 และ XMind Zen (content.json) และจาก XMind 8, XMind 7 และเวอร์ชัน 3.x ที่เก่ากว่า (content.xml)
  • ทุก sheet เป็นแท็บ พร้อม relationships, boundaries, summaries, markers, labels, notes, รูปภาพที่อยู่ในไฟล์ และสมการ LaTeX ที่วาดด้วย KaTeX
  • ไฟล์ .mm ของ FreeMind และ Freeplane และ outline แบบ .opml โดย PDF of every sheet ใช้กับไฟล์เหล่านี้ได้ด้วย
  • หัวข้อภาษาจีน ญี่ปุ่น เกาหลี และอีโมจิ พร้อมตัดบรรทัดหัวข้อที่ยาว
  • แผนผังขนาดใหญ่ ในการทดสอบของ README ไฟล์ .xmind ขนาด 30 MB ที่มี 10,111 หัวข้อและรูป 60 รูปเปิดได้ใน 0.65 วินาที

สิ่งที่ยังทำไม่ได้

  • เป็นแบบอ่านอย่างเดียว ถ้าต้องการแก้แผนผัง ให้เปิดใน XMind, Freeplane หรือโปรแกรม mind map อื่น
  • แผนผังที่ตั้งรหัสผ่านไว้เปิดไม่ได้ เพราะ XMind เข้ารหัสเนื้อหาไว้ จะมีข้อความแจ้งให้ทราบ
  • sheet แบบ fishbone, timeline, matrix และ brace จะวาดเป็น logic chart หรือ org chart ตำแหน่งหัวข้อที่ลากเองใน XMind จะไม่ถูกเก็บ และสไตล์จากธีมของ XMind (ฟอนต์ รูปทรงเส้น และรูปทรงหัวข้อ) จะไม่ถูกคัดลอกมา แต่สีพื้นและสีข้อความของหัวข้อถูกคัดลอกมา
  • แต่ละหน้าใน PDF เป็นภาพของ sheet จึงเลือกหรือค้นหาข้อความใน PDF ไม่ได้
  • ไฟล์ที่ใหญ่กว่า 1 GB (การตั้งค่า xmindViewer.maxFileMB) จะแสดงข้อความแทนการเปิด

คำถามที่พบบ่อย

ใช้ฟรีไหม

การดูแผนผังและการ export เป็น PNG, SVG และ Markdown ใช้ฟรี ส่วน PDF of every sheet, การ export เป็น CSV (Excel) และ OPML และ Convert a folder เป็นเครื่องมือ Zovo Pro แต่ละตัวลองใช้ฟรีได้ 3 ครั้งบนเครื่องของคุณ หลังจากนั้น Zovo Pro ราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว

ต้องติดตั้ง XMind ไหม

ไม่ต้อง ส่วนขยายอ่านไฟล์ .xmind เอง ทำงานออฟไลน์ และไม่ส่ง request ออกเครือข่าย

แปลงแผนผังทั้งโฟลเดอร์เป็น PDF ได้ไหม

ไม่ได้ Convert a folder เขียนเป็นไฟล์ Markdown, CSV หรือ OPML ส่วน PDF ต้องทำทีละแผนผัง

ใช้ใน Cursor ได้ไหม

ได้ ส่วนขยายอยู่บน Open VSX ด้วย จึงติดตั้งได้ใน Cursor, Windsurf, VSCodium และ editor อื่นที่สร้างจาก VS Code
