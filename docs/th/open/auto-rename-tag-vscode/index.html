คู่มือภาษาไทย

เปลี่ยนชื่อแท็ก HTML, JSX และ Vue อัตโนมัติใน VS Code

ติดตั้งส่วนขยายฟรี Auto Rename Tag & Close Tag Sync แล้วแก้ชื่อในแท็กเปิดหรือแท็กปิด แท็กคู่จะเปลี่ยนตามขณะที่พิมพ์ การเปลี่ยนชื่อนี้คือ linked editing ของ VS Code เอง (editor.linkedEditing) ส่วนขยายจะเปิดการตั้งค่านี้ให้ในภาษาที่รองรับ และหาแท็กคู่ใน HTML, JSX, TSX, Vue, Svelte, Astro, PHP, Blade, Twig, XML, Markdown และภาษาอื่น ๆ Undo ครั้งเดียวจึงคืนค่าทั้งสองแท็ก การเปลี่ยนชื่อ การปิดแท็กอัตโนมัติ และกรอบแท็กคู่ใช้ฟรี ส่วน Zovo Pro (19 ดอลลาร์สหรัฐ จ่ายครั้งเดียว) เพิ่ม Rename Tag in All Files และ Check Unclosed Tags in All Files โดยลองใช้ฟรีได้ตัวละ 3 ครั้ง

ขั้นตอนใน VS Code

  1. ติดตั้ง Tag Auto Rename & Close Tag Sync จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.zovo-auto-rename-tag
  2. เปิดไฟล์ HTML, JSX, TSX, Vue, Svelte, PHP หรือไฟล์ template อื่น แล้วแก้ชื่อในแท็กเปิด แท็กปิดจะเปลี่ยนตามขณะพิมพ์ และแก้จากแท็กปิดก็ได้เช่นกัน
  3. พิมพ์ > หลังแท็กเปิด แท็กปิดจะขึ้นหลังเคอร์เซอร์ พิมพ์ </ แล้วชื่อของ element ที่ยังเปิดอยู่จะถูกเติมให้
  4. วางเคอร์เซอร์บนแท็ก ทั้งสองแท็กจะมีกรอบตามสี bracket ของธีม
  5. คลิกขวาใน editor เพื่อใช้ "Go to Matching Tag" และ "Select Tag Content" ถ้าต้องการพิมพ์ชื่อใหม่ในกล่อง ให้รัน "Tag Sync: Rename Tag Pair…" จาก Command Palette
  6. คลิกรายการ Tags ใน status bar เพื่อดูว่าอะไรเปิดอยู่สำหรับไฟล์นี้ หรือเพื่อปิดส่วนขยายสำหรับภาษาเดียว ถ้าแสดง "Tags: rename off" ให้คลิกเพื่อเปิดการเปลี่ยนชื่อสำหรับภาษานั้น

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

การเปลี่ยนชื่อขณะพิมพ์ การปิดแท็กอัตโนมัติเมื่อพิมพ์ > และ </ กรอบแท็กคู่ Go to Matching Tag, Select Tag Content, Rename Tag Pair… และเมนูใน status bar ใช้ฟรี ไม่มีโฆษณา ไม่ต้องลงชื่อเข้าใช้ และทำงานแบบออฟไลน์

เครื่องมือนี้เปลี่ยนชื่อ component หรือ element ในทุกไฟล์ที่มีแท็กของ workspace พร้อมกัน เช่นเปลี่ยน <Button> เป็น <UiButton> ในทุกไฟล์ .tsx, .vue, .html และไฟล์ template เปลี่ยนเฉพาะชื่อแท็ก ไม่แตะข้อความ attribute สตริง หรือคอมเมนต์ คุณจะเห็นจำนวนที่จะเปลี่ยนก่อน "Preview first" จะเปิด refactor preview ของ VS Code และ Undo ครั้งเดียวคืนค่าทุกไฟล์

วิธีใช้ Rename Tag in All Files (Zovo Pro)

  1. เปิดโฟลเดอร์โปรเจกต์ใน VS Code เครื่องมือนี้ต้องมีโฟลเดอร์ที่เปิดอยู่
  2. รัน "Tag Sync: Rename Tag in All Files… (Pro)" จาก Command Palette หรือคลิกขวาที่ไฟล์ .html, .htm, .vue, .jsx, .tsx หรือ .svelte ใน Explorer แล้วเลือก "Zovo Pro: Rename Tag in All Files"
  3. พิมพ์ชื่อแท็กที่จะเปลี่ยนตามที่เขียนในไฟล์ (เช่น Button) แล้วพิมพ์ชื่อใหม่
  4. เลือก "Rename" หรือ "Preview first" เพื่อตรวจการเปลี่ยนแปลงใน refactor preview ไฟล์ที่ไม่ได้เปิดอยู่จะถูกแก้แต่ยังไม่บันทึก ใช้ File > Save All เพื่อบันทึก หรือใช้ Undo เพื่อคืนค่า

Rename Tag in All Files ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.zovo-auto-rename-tag แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/zovo-auto-rename-tag
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

Tag Auto Rename & Close Tag Sync ทำอะไรได้บ้าง

  • เปลี่ยนชื่อแท็กใน HTML, JSX และ TSX, Vue, Svelte, Astro, PHP, Blade, Twig, Jinja, Nunjucks, Liquid, ERB, EJS, Handlebars, XML, SVG และ Markdown
  • แท็ก void เช่น br, img, input, meta และ hr จะไม่ถูกจับคู่หรือปิดให้
  • ใน .tsx เฉพาะ JSX จริงเท่านั้นที่นับเป็นแท็ก การเปรียบเทียบอย่าง a < b && c > d และ generic อย่าง useState<string>() จะไม่ถูกแตะ และไฟล์ .ts จะไม่ถูกแตะเลย
  • ข้ามคอมเมนต์ สตริง เนื้อหาใน <script> และ <style> และบล็อก {{ }}, {% %}, <?php ?> และ <% %>
  • ไฟล์ใหม่ที่ยังไม่ได้บันทึกใช้ได้ทันทีที่กำหนดภาษาแล้ว

สิ่งที่ยังทำไม่ได้

  • ใน JSX และ TSX ตัว TypeScript ปิดแท็กเอง ส่วนขยายนี้จึงปล่อยการปิดแท็กให้ TypeScript และแท็กปิดจาก TypeScript นับเป็น Undo แยกอีกขั้น
  • ถ้าติดตั้งส่วนขยาย Vue, Svelte, Astro หรือ Red Hat XML ไว้ ส่วนขยายนั้นจะปิดแท็กในภาษาของตัวเอง และส่วนขยายนี้จะไม่เข้าไปยุ่ง
  • ไฟล์ที่ใหญ่กว่า 1 MB หรือเกิน 50,000 บรรทัดจะไม่มีการเปลี่ยนชื่อ ปิดแท็ก หรือไฮไลต์แบบสด (การตั้งค่า zovoTags.maxFileSizeKB และ zovoTags.maxFileLines) status bar จะแจ้งไว้ และคำสั่งต่าง ๆ ยังใช้ได้
  • แท็กที่เขียนในนิพจน์ {...} ของ Svelte หรือ Astro จะไม่ถูกเปลี่ยนชื่อ
  • ถ้าเปิดส่วนขยาย Auto Rename Tag หรือ Auto Close Tag ตัวเก่าไว้ด้วย ทั้งสองตัวอาจแก้แท็กเดียวกัน ให้เก็บไว้ตัวเดียว

คำถามที่พบบ่อย

ต่างจากการตั้งค่า editor.linkedEditing อย่างไร

ส่วนขยายใช้ editor.linkedEditing ในการเปลี่ยนชื่อ โดยเปิดการตั้งค่านี้ให้ในแต่ละภาษาที่รองรับ และหาแท็กคู่ในทุกภาษาเหล่านั้น ตั้งแต่ HTML และ Vue ไปจนถึง PHP, Twig, XML และ JSX นอกจากนี้ยังปิดแท็ก วาดกรอบรอบแท็กคู่ และเพิ่ม Go to Matching Tag กับ Select Tag Content ถ้าคุณปิด editor.linkedEditing ไว้เอง status bar จะแสดง "Tags: rename off" และคลิกเดียวก็เปิดกลับสำหรับภาษานั้น

Undo ยังใช้ได้ไหม

ได้ การแก้ของคุณและการเปลี่ยนแท็กคู่นับเป็น Undo ขั้นเดียว เพราะการเปลี่ยนชื่อใช้ linked editing ของ VS Code แท็กปิดจากการปิดอัตโนมัติจะรวมอยู่ใน Undo ขั้นเดียวกับ > ที่คุณพิมพ์ ยกเว้นใน JSX และ TSX ที่ TypeScript เป็นผู้ปิดแท็ก

ใช้ฟรีไหม

ใช้ฟรี การเปลี่ยนชื่อ การปิดแท็กอัตโนมัติ กรอบแท็กคู่ และคำสั่งใน editor ใช้ฟรี ส่วน Rename Tag in All Files และ Check Unclosed Tags in All Files เป็นเครื่องมือ Zovo Pro ที่ลองใช้ฟรีได้ตัวละ 3 ครั้ง หลังจากนั้นราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว

ใช้ใน Cursor ได้ไหม

ได้ Cursor, Windsurf และ VSCodium ติดตั้งได้จาก Open VSX ในชื่อ zovo/zovo-auto-rename-tag
