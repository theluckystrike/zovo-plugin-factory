คู่มือภาษาไทย

แปลงไฟล์ TIFF เป็น PNG โดยไม่เสียคุณภาพ

ติดตั้ง TIFF Viewer & TIF Viewer (16-bit, GeoTIFF) ซึ่งเปิดไฟล์ .tif และ .tiff ใน VS Code ได้ รวมถึงไฟล์ 16-bit, float และไฟล์หลายหน้า ส่วนปุ่ม Export PNG บันทึกหน้าตามที่เห็นได้ฟรี เครื่องมือ Zovo Pro ชื่อ Export pages บันทึกหน้านี้หรือทุกหน้าเป็น PNG ความละเอียดเต็มพร้อมค่าที่เก็บไว้จริง (stored values) ข้อมูล 8 และ 16-bit จึงได้ค่าเดิมทุกค่า Export pages, Batch convert และ Region stats ลองใช้ฟรีได้อย่างละ 3 ครั้ง หลังจากนั้นต้องใช้ Zovo Pro ราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียว

ติดตั้งใน VS Codeหน้า MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

ใช้ฟรี ไลเซนส์ MIT รหัสส่วนขยาย zovo.tiff-viewer เวอร์ชัน 0.2.4

ขั้นตอนใน VS Code

  1. ติดตั้ง TIFF Viewer จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.tiff-viewer
  2. คลิกไฟล์ .tif หรือ .tiff ใน Explorer ไฟล์จะเปิดใน TIFF Viewer ถ้า viewer ตัวอื่นเปิดขึ้นมาแทน ให้คลิกขวาที่ไฟล์แล้วเลือก "Open in TIFF Viewer" หรือใช้ "Reopen Editor With..." จากเมนูบนแถบชื่อของ editor
  3. เลื่อนล้อเมาส์เพื่อซูมและลากเพื่อเลื่อนภาพ แถบสถานะจะแสดงค่าที่เก็บไว้จริงของพิกเซลใต้ตัวชี้เมาส์
  4. ถ้าเป็นไฟล์หลายหน้า ให้เลือกหน้าจากแถบหน้า (page strip) หรือกด PageDown และ PageUp (หรือ J และ K)
  5. สำหรับข้อมูล 16-bit หรือ float ให้ใช้ตัวควบคุม Channel และ Contrast stretch (min ถึง max, 2 ถึง 98 เปอร์เซ็นต์ หรือช่วงเต็มของชนิดข้อมูล) กด T เพื่อเปิดแผง tags ซึ่งจะมีส่วน GeoTIFF เมื่อไฟล์มี GeoTIFF tags
  6. คลิก Export PNG เพื่อบันทึกหน้าปัจจุบันตามที่เห็นบนจอ ด้วย channel และ stretch ที่เลือกไว้ ขั้นตอนนี้ใช้ฟรี

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

ฟีเจอร์ที่ใช้ฟรีได้แก่ ทุกหน้า, channel และ contrast stretch, ค่าพิกเซลใต้ตัวชี้เมาส์, TIFF tags, พิกัด GeoTIFF และ Export PNG ของหน้าตามที่เห็น การดูไฟล์ทำงานออฟไลน์และไม่ต้องลงชื่อเข้าใช้

Export pages บันทึกหน้านี้หรือทุกหน้าของไฟล์หลายหน้าเป็น PNG ความละเอียดเต็ม ถ้าเลือก "stored values" ข้อมูล 8 และ 16-bit จะได้ค่าเดิมทุกค่าใน PNG แบบ 8 หรือ 16-bit ส่วนข้อมูลแบบมีเครื่องหมาย (signed), 32-bit และ float จะถูกแปลงเป็น 16 บิตตามช่วงที่แสดงอยู่ และข้อความใน PNG จะบอกวิธีคำนวณค่ากลับ หน้า GeoTIFF จะได้ world file .pgw และ footprint .geojson เพิ่ม PNG จึงวางลงตำแหน่งที่ถูกต้องใน QGIS หรือ ArcGIS

วิธีใช้ Export pages (Zovo Pro)

  1. เปิดไฟล์ TIFF แล้วคลิก Export pages ในแถบเครื่องมือของ viewer หรือรัน "TIFF Viewer: Export Pages to PNG (Pro)..." จาก Command Palette ขณะที่ไฟล์เปิดอยู่
  2. เลือก "Page N with the stored values" (PNG 16-bit สำหรับข้อมูล 16-bit) หรือ "Page N as shown" (8-bit) ในไฟล์หลายหน้ายังเลือก "All N pages with the stored values" หรือ "All N pages as shown" ได้ด้วย
  3. ตั้งชื่อไฟล์ หรือเลือกโฟลเดอร์ถ้าบันทึกทุกหน้า แล้วกดบันทึก ระบบนับการลองใช้เมื่อเขียน PNG เสร็จแล้วเท่านั้น การกด Escape จึงไม่เสียสิทธิ์
  4. ถ้าต้องการแปลงไฟล์ TIFF ทั้งโฟลเดอร์ ให้คลิกขวาที่โฟลเดอร์แล้วรัน "TIFF Viewer: Batch Convert TIFF Folder to PNG (Pro)..." (เป็นเครื่องมือ Pro เช่นกัน)

Export pages ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.tiff-viewer แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/tiff-viewer
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

TIFF Viewer ทำอะไรได้บ้าง

  • TIFF แบบ Classic และ BigTIFF ทั้ง little-endian และ big-endian แบบ strips และ tiles ทั้ง chunky และ planar
  • sample แบบจำนวนเต็มไม่มีเครื่องหมายและมีเครื่องหมายตั้งแต่ 1 ถึง 64-bit และ float 16, 32 และ 64-bit พร้อม contrast stretch ตามเปอร์เซ็นไทล์
  • Gray, RGB และ RGBA, palette, CMYK และ YCbCr ใน JPEG ทั้งไฟล์ที่ไม่บีบอัดและที่บีบอัดแบบ LZW, Deflate, PackBits, JPEG และ CCITT Group 3 และ 4
  • ไฟล์หลายหน้า มีแถบหน้าและภาพย่อของ 300 หน้าแรก
  • GeoTIFF tags ได้แก่ รหัส EPSG, ขนาดพิกเซล, ขอบเขต, ค่า nodata และพิกัดแผนที่ใต้ตัวชี้เมาส์

สิ่งที่ยังทำไม่ได้

  • หน้าที่บีบอัดแบบ ZSTD, LERC, WebP และ JPEG 2000 จะแสดงในรายการพร้อม tags แต่ไม่ถูกถอดรหัส
  • ไฟล์ที่ใหญ่กว่า 1 GB (การตั้งค่า tiffViewer.maxFileMB ค่าเริ่มต้น 1024) จะไม่ถูกถอดรหัส แต่จะแสดงข้อความและ tags ของทุกหน้า
  • หน้าที่ด้านใดด้านหนึ่งยาวเกิน 6000 พิกเซล หรือมีเกิน 24 ล้านพิกเซล จะแสดงโดยใช้พิกเซลทุก ๆ N พิกเซล แต่ค่าที่อ่านใต้ตัวชี้เมาส์และสถิติยังใช้ความละเอียดเต็ม
  • หน้าแบบ tiles ที่มีน้อยกว่า 8 บิตต่อพิกเซล และ YCbCr ที่ไม่บีบอัด จะไม่ถูกถอดรหัส ภาพย่อยใน SubIFD (pyramid ของ DNG และ OME-TIFF บางไฟล์) จะแสดงใน tags แต่ไม่แสดงเป็นหน้า
  • viewer เป็นแบบอ่านอย่างเดียว (read-only) และไม่เขียนลงไฟล์ TIFF เลย ไม่มี map tiles และไม่มีการ reproject

คำถามที่พบบ่อย

แปลง TIFF เป็น PNG แล้วเสียคุณภาพไหม

PNG เป็นรูปแบบ lossless คุณภาพจะลดลงก็ต่อเมื่อข้อมูล 16-bit ถูกลดเหลือ 8-bit ใน Export pages ให้เลือกตัวเลือก stored values เพื่อให้ค่า 8 และ 16-bit ไม่เปลี่ยน

ใช้ฟรีไหม

การดูไฟล์ TIFF และ Export PNG ของหน้าตามที่เห็นใช้ฟรี ส่วน Export pages, Batch convert และ Region stats เป็นเครื่องมือ Pro ที่ลองใช้ฟรีได้อย่างละ 3 ครั้ง หลังจากนั้นต้องใช้ Zovo Pro ราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว

ภาพของฉันถูกอัปโหลดไหม
