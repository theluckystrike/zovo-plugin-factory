คู่มือภาษาไทย

ดู sections และ imports ของไฟล์ ELF, EXE หรือ DLL ใน VS Code

ติดตั้ง ELF Viewer & PE Viewer ซึ่งใช้ฟรี แล้วคลิกไฟล์ .so, .exe, .dll หรือ .dylib จะได้แท็บสำหรับ header, section, segment, import, export และ symbol ของไฟล์ ELF บน Linux, PE บน Windows และ Mach-O ของ Apple พร้อมมุมมอง hex โดยไม่ต้องใช้ readelf, objdump หรือ dumpbin ทุกมุมมองของไฟล์ใช้ฟรีและเป็นแบบอ่านอย่างเดียว Zovo Pro (19 ดอลลาร์สหรัฐ จ่ายครั้งเดียว) เพิ่มเครื่องมือ 3 ตัว คือ export เป็น JSON หรือ C header, เปรียบเทียบไบนารีสองไฟล์ และค้นหาชื่อในโฟลเดอร์ที่มีไบนารีหลายไฟล์ แต่ละตัวลองใช้ฟรีได้ 3 ครั้ง

ขั้นตอนใน VS Code

  1. ติดตั้ง ELF Viewer & PE Viewer จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.zovo-elf-pe-viewer
  2. คลิกไฟล์ .exe, .dll, .sys, .so, .dylib, .elf หรือ .ko ใน Explorer ไฟล์จะเปิดใน viewer ส่วนไฟล์ object .o หรือไฟล์ executable ของ Linux หรือ macOS ที่ไม่มีนามสกุล ให้คลิกขวาแล้วเลือก Open in ELF & PE Viewer
  3. แท็บ Overview จะแสดงเป็นแท็บแรก บอกสถาปัตยกรรม, ชนิดไฟล์, entry point, ไลบรารีที่ link, security flags เช่น ASLR และ DEP, build ID และ path ของ PDB
  4. เปิดแท็บ Sections หรือ Imports สำหรับ ELF แท็บ imports จะบอกไลบรารีและ symbol version ของแต่ละฟังก์ชัน ไฟล์ PE จะมี data directories, delay-load imports และ resources เพิ่ม ส่วนไฟล์ Mach-O จะมี load commands
  5. พิมพ์ในช่องกรองเหนือตารางเพื่อกรองแถว และคลิกหัวคอลัมน์เพื่อเรียงลำดับ Copy rows คัดลอกแถวไปยัง clipboard เป็นข้อความแบบ tab-separated
  6. คลิกลิงก์ bytes ของ section หรือ segment เพื่อดูไบต์ที่ถูกทำเครื่องหมายในแท็บ Hex ในแท็บ Headers ตัวเลือก Show every header field with its offset จะเปิด field tree

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

ทุกมุมมองของไฟล์ใช้ฟรีโดยไม่ต้องลงชื่อเข้าใช้ ได้แก่ overview, ตารางทั้งหมด, การกรอง การเรียงลำดับ และการคัดลอก, มุมมอง hex และ field tree ส่วนขยายไม่เขียนลงไฟล์ไบนารีเลยและไม่เรียกเครือข่าย

ถ้าอยากรู้ว่าไบนารีตัวไหนในโฟลเดอร์ build ที่ import ฟังก์ชันหนึ่งหรือ link ไลบรารีหนึ่ง เครื่องมือนี้จะอ่านไฟล์ ELF, PE และ Mach-O ทุกไฟล์ในโฟลเดอร์ แล้วแสดงทุกรายการที่ตรงพร้อมชื่อไฟล์ ข้อความธรรมดาจะตรงกับส่วนใดก็ได้ของชื่อ และใช้ /regex/ ได้ด้วย คุณได้คำตอบจากการค้นหาครั้งเดียว แทนที่จะเปิดไบนารีทีละไฟล์หรือรัน readelf หรือ dumpbin ทีละไฟล์

วิธีใช้ Find a symbol or import in a folder (Zovo Pro)

  1. เปิดไบนารีแล้วคลิก Find in folder… ด้านบนของ viewer หรือรัน "ELF & PE Viewer: Find a symbol or import in a folder (Pro)" จาก Command Palette
  2. พิมพ์ชื่อ เช่น CreateFileW หรือ SSL_read หรือ regex เช่น /^_?pthread_/ เครื่องมือจะค้นในโฟลเดอร์ของ workspace หรือถามให้คุณเลือกโฟลเดอร์
  3. ถ้าเริ่มจาก viewer ผลลัพธ์จะเปิดในแท็บ Find ที่มีปุ่ม Copy ถ้าเริ่มจาก Command Palette ผลลัพธ์จะแสดงเป็นรายการ และคลิกเพื่อเปิดไบนารีนั้นได้
  4. การกด Escape หรือการค้นหาที่ไม่พบผลลัพธ์ จะไม่นับเป็นการลองใช้ฟรี

Find a symbol or import in a folder ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.zovo-elf-pe-viewer แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/zovo-elf-pe-viewer
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

ELF Viewer & PE Viewer ทำอะไรได้บ้าง

  • ไฟล์ ELF แบบ 32 และ 64-bit ทั้ง little และ big endian เช่น .so, .o, .ko, .elf, .axf และไฟล์ executable ของ Linux
  • ไฟล์ PE32 และ PE32+ เช่น .exe, .dll, .sys, .efi และ .pyd พร้อม imports แบบชื่อและ ordinal, exports ที่มี forwarder และ .NET runtime header
  • Mach-O แบบ 32 และ 64-bit และ universal binaries เลือกสถาปัตยกรรม เช่น arm64 หรือ x86_64 ได้ที่ด้านบน
  • ตารางที่มีได้ถึง 100,000 แถว กรอง เรียงลำดับ และคัดลอกได้

สิ่งที่ยังทำไม่ได้

  • เป็นแบบอ่านอย่างเดียวและไม่มี disassembly
  • ไม่อ่าน static library (.a), ไฟล์ Java class, WebAssembly และไฟล์ DEX
  • แต่ละตารางหยุดที่ 100,000 แถว และการอ่านไฟล์หยุดหลัง 10 วินาที viewer จะแจ้งเมื่อเกิดกรณีนี้
  • ไฟล์บน remote หรือ virtual file system อ่านได้ไม่เกิน 256 MB และ Find in folder ค้นได้เฉพาะโฟลเดอร์ในเครื่อง
  • ไฟล์ .o และไฟล์ที่ไม่มีนามสกุลจะไม่เปิดเองเมื่อคลิก ให้ใช้ Open in ELF & PE Viewer จากเมนูคลิกขวา

คำถามที่พบบ่อย

ใช้ฟรีไหม

ทุกมุมมองของไฟล์ใช้ฟรีโดยไม่ต้องลงชื่อเข้าใช้ เครื่องมือ Pro 3 ตัว ได้แก่ export เป็น JSON หรือ C header, เปรียบเทียบไบนารีสองไฟล์ และค้นหาชื่อในโฟลเดอร์ ลองใช้ฟรีได้อย่างละ 3 ครั้ง หลังจากนั้นต้องใช้ Zovo Pro ราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว

ต้องมี readelf, objdump หรือ dumpbin ไหม

ไม่ต้อง ส่วนขยายอ่านไฟล์ ELF, PE และ Mach-O เองโดยไม่ต้องติดตั้งโปรแกรมอื่น

แก้ไขไบนารีได้ไหม

ไม่ได้ ส่วนขยายอ่านไฟล์อย่างเดียวและไม่เขียนลงไฟล์ ส่วนการ export ของ Pro จะบันทึกไฟล์ JSON หรือ header ใหม่ในตำแหน่งที่คุณเลือก

ใช้ใน Cursor ได้ไหม

ได้ README ระบุว่าใช้ได้ใน Cursor, Windsurf และ VSCodium และส่วนขยายอยู่บน Open VSX editor เหล่านี้จึงติดตั้งได้
