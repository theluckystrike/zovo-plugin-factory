คู่มือภาษาไทย

พรีวิวกราฟ Graphviz DOT โดยไม่ต้องติดตั้ง Graphviz

ติดตั้ง Graphviz Viewer & DOT Viewer ซึ่งใช้ฟรี เปิดไฟล์ .dot หรือ .gv แล้วคลิกไอคอนพรีวิว กราฟจะถูกวาดข้าง editor และวาดใหม่ขณะที่คุณพิมพ์ โดยมี Graphviz 16.1 อยู่ในส่วนขยายในรูปแบบ WebAssembly จึงไม่ต้องติดตั้งอะไรเพิ่ม พรีวิว layout engine ทั้งหกแบบ การคลิกเพื่อไปยังบรรทัด และการ export เป็น SVG หรือ PNG ใช้ฟรี Zovo Pro (19 ดอลลาร์สหรัฐ จ่ายครั้งเดียว) เพิ่มการ export เป็น PDF แบบ vector การ export ทุกกราฟใน workspace และการ export เมื่อบันทึกไฟล์ โดยลองใช้ฟรีได้ตัวละ 3 ครั้ง

ติดตั้งใน VS Codeหน้า MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

ใช้ฟรี ไลเซนส์ MIT รหัสส่วนขยาย zovo.zovo-graphviz-preview เวอร์ชัน 0.2.3

ขั้นตอนใน VS Code

  1. ติดตั้ง Graphviz Viewer & DOT Viewer จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.zovo-graphviz-preview
  2. เปิดไฟล์ .dot หรือ .gv คลิกไอคอนพรีวิวในแถบชื่อของ editor หรือกด Ctrl+K V (Cmd+K V บน Mac) กราฟจะเปิดข้างไฟล์
  3. แก้ไฟล์ได้เลย พรีวิวจะวาดใหม่ 300 ms หลังจากคุณหยุดพิมพ์ โดยไม่ต้องบันทึก syntax error จะถูกขีดเส้นใต้ที่บรรทัดนั้นและแสดงใน Problems และพรีวิวจะคงภาพล่าสุดที่วาดได้ถูกต้องไว้
  4. เลือก dot, neato, fdp, sfdp, circo หรือ twopi ในแถบเครื่องมือ ถ้าเลือก auto จะใช้ attribute layout= ของกราฟ หรือใช้ dot ถ้าไม่มี
  5. พิมพ์ในช่อง Find node เพื่อไฮไลต์ node ที่ชื่อหรือ label ตรงกัน คลิก node, edge หรือ cluster เพื่อวางเคอร์เซอร์ที่บรรทัดของมันในซอร์ส
  6. คลิก SVG หรือ PNG เพื่อบันทึกกราฟ PNG จะถูกบันทึกที่ 2x บนพื้นหลังสีขาว ด้วยสีปกติของ Graphviz

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

พรีวิวแบบสด layout engine ทั้งหกแบบ error ใน Problems, Find node การคลิกเพื่อไปยังบรรทัด การเลื่อนและซูม การ export กราฟที่เปิดอยู่เป็น SVG และ PNG และบล็อก dot ในพรีวิว Markdown ใช้ฟรี ไม่ต้องลงชื่อเข้าใช้ ไม่เชื่อมต่อเครือข่าย และไม่มี telemetry

การ export เป็น PDF จะบันทึกกราฟเป็น PDF แบบ vector ที่ข้อความยังเป็นข้อความ จึงคมชัดทุกระดับซูม และค้นหาหรือคัดลอกข้อความได้ เลือกหน้าขนาดเท่ากราฟแบบ dot -Tpdf หรือหน้า A4 หรือ Letter ที่มีหน้าปกและ bookmark ก็ได้ ส่วนไฟล์ Markdown จะได้หนึ่งหน้าต่อหนึ่งบล็อก dot คุณจึงได้ PDF สำหรับเอกสารออกแบบหรือสำหรับพิมพ์โดยไม่ต้องติดตั้ง Graphviz

วิธีใช้ Export to PDF (Vector, Title Page) (Zovo Pro)

  1. เปิดพรีวิวแล้วคลิก PDF ในแถบเครื่องมือ (มีป้าย PRO เล็ก ๆ) หรือรัน "Graphviz: Export to PDF (Vector, Title Page) (Pro)" จาก Command Palette
  2. เลือก "Graph-size pages", "Title page and A4 pages", "Title page and Letter pages" หรือ "Graph-size pages with a title page" แล้วเลือกที่บันทึก
  3. การกด Escape หรือ Cancel หรือกราฟที่มี error จะไม่เสียสิทธิ์ลองใช้ฟรี

Export to PDF (Vector, Title Page) ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.zovo-graphviz-preview แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/zovo-graphviz-preview
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

Graphviz Viewer & DOT Viewer ทำอะไรได้บ้าง

  • graph และ digraph ที่มี cluster, subgraph และ HTML label
  • บล็อก dot, graphviz และ gv แบบ fenced ใน Markdown ซึ่งวาดในพรีวิว Markdown ของ VS Code
  • ธีมสีเข้ม เส้นและข้อความสีดำตามค่าเริ่มต้นจะใช้สีของธีม ส่วนสีที่คุณกำหนดในกราฟจะคงไว้ตามเดิม
  • กราฟใหญ่ซึ่งจัด layout ใน thread แยกโดยมีเวลาจำกัด สำหรับกราฟหลายพัน node ปกติ sfdp จะเร็วกว่า dot มาก

สิ่งที่ยังทำไม่ได้

  • กราฟที่ใหญ่กว่า 4,096 KB จะไม่ถูกจัด layout และ layout ที่ใช้เวลาเกิน 15 วินาทีจะถูกหยุด (graphvizPreview.maxSourceKB, graphvizPreview.renderTimeoutSeconds)
  • attribute image= และรูปภาพใน HTML label จะไม่ถูกวาด ซึ่งตั้งใจออกแบบไว้แบบนั้น
  • มีพรีวิวได้หนึ่งอันต่อไฟล์ และพรีวิวจะไม่กลับมาหลังรีสตาร์ต Problems จะแสดงเฉพาะตอนที่พรีวิวเปิดอยู่
  • PDF ใช้ฟอนต์มาตรฐานของ PDF ตัวอักษรที่อยู่นอกชุดภาษายุโรปตะวันตก เช่น label ภาษาจีนหรือ Cyrillic จะแสดงเป็น "?" ใน PDF ส่วน SVG และ PNG แสดงได้ปกติ

คำถามที่พบบ่อย

ใช้ฟรีไหม

พรีวิวแบบสด engine ทั้งหกแบบ การคลิกเพื่อไปยังบรรทัด และการ export เป็น SVG และ PNG ใช้ฟรี เครื่องมือ Pro ทั้งสามตัว คือ PDF export, Export All Graphs in Workspace และ Export on Save ลองใช้ฟรีได้ตัวละ 3 ครั้ง หลังจากนั้นต้องใช้ Zovo Pro ราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว

ต้องติดตั้ง Graphviz ไหม

ไม่ต้อง Graphviz 16.1 อยู่ในส่วนขยายในรูปแบบ WebAssembly ไม่มีอะไรติดตั้งเพิ่มในเครื่องของคุณ และทำงานแบบออฟไลน์ได้

วาดบล็อก dot ใน Markdown ได้ไหม

ได้ บล็อกแบบ fenced ที่ระบุภาษา dot, graphviz หรือ gv จะถูกวาดในพรีวิว Markdown ของ VS Code

ใช้ใน Cursor ได้ไหม

ได้ ส่วนขยายนี้อยู่บน Open VSX ทั้ง Cursor, Windsurf และ VSCodium จึงติดตั้งได้
