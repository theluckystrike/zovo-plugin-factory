คู่มือภาษาไทย

ดูรูปภาพจาก path ในโค้ด ทั้งใน gutter และเมื่อ hover

ติดตั้งส่วนขยาย Image Preview & Image Hover ซึ่งใช้ได้ฟรี แล้วเปิดไฟล์ที่อ้างถึงรูปภาพ รูปย่อจะแสดงใน gutter ข้างบรรทัดนั้น และเมื่อ hover ที่ path จะเห็นรูป ชนิดไฟล์ ขนาดเป็นพิกเซล และขนาดไฟล์ ใช้ได้กับ import ใน JavaScript และ TypeScript, JSX, CSS url(), Markdown, HTML src และ srcset, YAML และ data URI โดยไม่มีการเรียกเครือข่าย Zovo Pro (19 ดอลลาร์สหรัฐ จ่ายครั้งเดียว) เพิ่มเครื่องมือ 3 ตัว คือ Find Unused Images, Find Broken Image References และ Image Weight Report และแต่ละตัวลองใช้ฟรีได้ 3 ครั้ง

ติดตั้งใน VS Codeหน้า MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

ใช้ฟรี ไลเซนส์ MIT รหัสส่วนขยาย zovo.zovo-image-preview เวอร์ชัน 0.1.0

ขั้นตอนใน VS Code

  1. ติดตั้ง Image Preview & Image Hover จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.zovo-image-preview
  2. เปิดไฟล์ที่อ้างถึงรูปภาพ เช่น import logo from './logo.png', CSS url() หรือ HTML <img src> รูปย่อจะแสดงใน gutter บรรทัดละหนึ่งรูป
  3. hover ที่ path จะเห็นรูป (ย่อให้พอดี ไม่ขยายให้ใหญ่ขึ้น) ชนิดไฟล์ กว้าง × สูงเป็นพิกเซล ขนาดไฟล์ และความโปร่งใส พร้อมลิงก์สำหรับเปิดไฟล์หรือแสดงไฟล์ใน Explorer
  4. ถ้าหา path ไม่เจอ hover จะบอกไว้และแสดงรายการ path ที่ค้นหาแล้ว เพิ่ม prefix ของคุณเองใน imgPreview.aliases เช่น { "@images": "src/assets/images" } หรือเพิ่มโฟลเดอร์สำหรับ path ที่ขึ้นต้นด้วย / ใน imgPreview.publicFolders
  5. ถ้าต้องการซ่อนรูปย่อใน gutter ให้รัน "Image Preview: Show or Hide Gutter Thumbnails" จาก Command Palette
  6. ถ้ายังไม่มีโปรเจกต์ให้ลอง ให้รัน "Image Preview: Open the Sample Files" เพื่อเปิดโปรเจกต์ตัวอย่างขนาดเล็กที่มี path ทุกแบบ

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

รูปย่อใน gutter, hover, การหา path ด้วย alias, paths ใน tsconfig.json และ jsconfig.json และ package ใน monorepo รวมทั้ง data URI ใช้ได้ฟรี ไม่ต้องมีบัญชี ไม่มีการเรียกเครือข่าย ไม่มี telemetry และทำงานออฟไลน์

Find Unused Images แสดงรายการรูปภาพใน workspace (หรือในโฟลเดอร์หนึ่ง) ที่ไม่มีไฟล์โค้ด สไตล์ Markdown, HTML, JSON หรือ YAML ไหนอ้างถึง เรียงจากไฟล์ใหญ่ที่สุด ในรายงาน Markdown พร้อมขนาดไฟล์ เมื่อคุณยืนยัน รูปเหล่านั้นจะถูกย้ายไปที่โฟลเดอร์ _unused-images โดยคงโครงสร้างโฟลเดอร์ไว้ และ Edit > Undo ย้ายกลับได้ คุณจึงล้างรูปเก่าออกจากโปรเจกต์ได้โดยไม่ต้องตรวจชื่อไฟล์ทีละชื่อเอง

วิธีใช้ Find Unused Images (Zovo Pro)

  1. คลิกขวาที่โฟลเดอร์ใน Explorer แล้วเลือก "Zovo Pro: Find unused images" หรือรัน "Image Preview: Find Unused Images (Pro)" จาก Command Palette ถ้ามี workspace folder มากกว่าหนึ่งโฟลเดอร์ ให้เลือกโฟลเดอร์
  2. การแจ้งเตือนจะแสดงความคืบหน้าพร้อมปุ่ม Cancel จากนั้นรายงาน Markdown จะเปิดขึ้นพร้อมรูปที่ไม่ได้ใช้แต่ละรูปและขนาดไฟล์ เรียงจากใหญ่ที่สุด
  3. คลิก "Move N to _unused-images" เพื่อย้ายรูป หรือปิดข้อความเพื่อเก็บไว้ที่เดิม Edit > Undo ย้ายกลับได้
  4. ระบบนับการลองใช้เฉพาะเมื่อรายงานเปิดขึ้นแล้ว การกด Escape ไม่เสียสิทธิ์

Find Unused Images ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.zovo-image-preview แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/zovo-image-preview
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

Image Preview & Image Hover ทำอะไรได้บ้าง

  • รูปย่อใน gutter สำหรับไฟล์ PNG, JPEG, GIF, WebP, AVIF, SVG, BMP และ ICO และสำหรับ URI แบบ data:image/... ส่วนไฟล์ TIFF และ HEIC จะอ่านขนาดและชนิดจาก header
  • path ที่สัมพันธ์กับไฟล์, /logo.png จาก public/, static/ และโฟลเดอร์ web root อื่น, @/ สำหรับ src/, ~ สำหรับ node_modules หรือโฟลเดอร์ home และ paths ใน tsconfig.json หรือ jsconfig.json ที่ใช้ extends
  • ชื่อไฟล์ที่มีช่องว่าง, %20, ?v=2 หรือ #id ชื่อธรรมดาอย่าง beans.jpg ใน JSON จะจับคู่กับรูปชื่อนั้นที่อยู่ใกล้ที่สุด
  • ใน monorepo จะใช้โฟลเดอร์ public/ และ tsconfig.json ของแต่ละ package
  • URL ระยะไกลแสดงเป็นลิงก์เท่านั้นและไม่ถูกดาวน์โหลด

สิ่งที่ยังทำไม่ได้

  • path ที่สร้างตอนโค้ดทำงาน เช่น `icons/${name}.svg` หรือการต่อสตริง จะแสดงพรีวิวไม่ได้ และอาจทำให้รูปดูเหมือนไม่ได้ใช้ ควรตรวจรายการรูปที่ไม่ได้ใช้ก่อนย้ายไฟล์
  • รูปย่อหนึ่งรูปต่อบรรทัด คือรูปแรกในบรรทัดนั้น ส่วน hover ใช้ได้กับทุก path ในบรรทัด
  • เวอร์ชันนี้ยังไม่รองรับ remote และ virtual workspace (SSH, WSL, Codespaces, vscode.dev)
  • alias ของ Webpack, Vite หรือ Next.js ที่มีอยู่แค่ในไฟล์ config ของ JavaScript จะไม่ถูกอ่าน ให้เพิ่มไว้ใน imgPreview.aliases หรือ paths ของ tsconfig.json
  • รูปที่ใหญ่กว่า 20 MB จะถูกวัดขนาดแต่ไม่ถูกวาด (การตั้งค่า imgPreview.maxFileSizeMB) Image Weight Report ระบุไฟล์ที่หนักแต่ไม่ได้บีบอัดให้

คำถามที่พบบ่อย

ใช้ฟรีไหม

รูปย่อใน gutter, hover และการหา path ใช้ได้ฟรี เครื่องมือ Pro 3 ตัว คือ Find Unused Images, Find Broken Image References และ Image Weight Report ลองใช้ฟรีได้ตัวละ 3 ครั้ง หลังจากนั้นต้องใช้ Zovo Pro ราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว

ทำไม path แบบ @/ หรือ alias ไม่แสดงรูป

alias นั้นอาจมีอยู่แค่ในไฟล์ config ของ Webpack, Vite หรือ Next.js ซึ่งส่วนขยายไม่ได้อ่าน ให้เพิ่มไว้ใน imgPreview.aliases หรือใน paths ของ tsconfig.json

ใช้ผ่าน Remote SSH หรือ WSL ได้ไหม

เวอร์ชันนี้ยังไม่ได้ รูปใน hover อ่านจากดิสก์ในเครื่อง

ใช้ใน Cursor ได้ไหม

ได้ Cursor, Windsurf และ VSCodium ติดตั้งได้จาก Open VSX ซึ่งเผยแพร่ในชื่อ zovo/zovo-image-preview
