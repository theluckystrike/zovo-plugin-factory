คู่มือภาษาไทย

เปรียบเทียบไฟล์ Excel หรือ CSV สองไฟล์ใน VS Code

ติดตั้งส่วนขยายฟรี Excel Compare & XLSX Diff แล้วเลือก workbook หรือไฟล์ CSV สองไฟล์ เซลล์ที่เปลี่ยนจะแสดงเป็นสีเหลืองและค่าเดิมมีเส้นขีดฆ่า แถวที่เพิ่มเป็นสีเขียว และแถวที่ลบเป็นสีแดง ระบบจะจัดแถวให้ตรงกันก่อนและจับคู่คอลัมน์ตามหัวคอลัมน์ การแทรกแถวหรือคอลัมน์หนึ่งรายการจึงแสดงเป็นการเปลี่ยนแปลงเดียว และยังเทียบ workbook กับเวอร์ชันใน Git HEAD ก่อน commit ได้ด้วย ทั้งหมดนี้ใช้ได้ฟรีและไม่มีการส่งคำขอผ่านเครือข่าย Zovo Pro (19 USD จ่ายครั้งเดียว) เพิ่มเครื่องมือสามตัว ได้แก่ Export a diff report, Match rows by key columns และ Compare two folders of workbooks แต่ละตัวทดลองใช้ฟรีได้ 3 ครั้ง

ขั้นตอนใน VS Code

  1. ติดตั้ง Excel Compare & XLSX Diff จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.zovo-excel-compare
  2. เลือกสองไฟล์ใน Explorer คลิกขวาแล้วเลือก Compare Selected Excel Files หรือคลิกขวาที่ไฟล์หนึ่ง เลือก Compare with... แล้วเลือกอีกไฟล์ หรือรัน "Excel Compare: Compare Two Excel or CSV Files..." จาก Command Palette
  3. ใช้ .xlsx, .xlsm, .xls, .ods, .csv และ .tsv ผสมกันแบบใดก็ได้ จึงเทียบไฟล์ .xlsx กับไฟล์ .csv ได้
  4. อ่านบรรทัดสรุปก่อน แล้วดูแท็บของแต่ละชีตที่แสดงจำนวนจุดที่ต่างกัน คลิกเซลล์เพื่อดูค่าเดิมและค่าใหม่แบบเต็มและคัดลอกได้
  5. กด N และ P (หรือ Next และ Previous) เพื่อไล่ดูทุกการเปลี่ยนแปลงในทุกชีต สลับระหว่าง Values และ Formulas เพื่อเทียบค่าที่เซลล์แสดงหรือเทียบตัวสูตรเอง
  6. หากต้องการดูว่าแก้อะไรไปก่อน commit ให้คลิกขวาที่ workbook ใน Git repository แล้วเลือก Compare with Git HEAD

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

การเทียบไฟล์สองไฟล์ใดก็ได้ ตาราง Values และ Formulas การไปยังการเปลี่ยนแปลงถัดไปและก่อนหน้า การเทียบ CSV ที่ตรวจหา encoding และตัวคั่นเอง และ Compare with Git HEAD ใช้ได้ฟรี ไม่ต้องลงชื่อเข้าใช้ ไม่มีคำขอผ่านเครือข่าย และไม่มี telemetry

เมื่อต้องส่งการเปลี่ยนแปลงให้คนอื่นดู Export a diff report จะเขียน workbook XLSX ที่ระบายสีเซลล์ที่เปลี่ยน เพิ่ม และลบ พร้อมชีต Summary และรายการ Changes ที่มีค่าเดิมและค่าใหม่ทุกค่า หรือจะเขียนเป็นหน้า HTML หน้าเดียวหรือรายการการเปลี่ยนแปลงแบบ CSV ก็ได้ คุณส่งไฟล์เดียวแทนภาพหน้าจอหลายภาพ

วิธีใช้ Export a diff report (Zovo Pro)

  1. เทียบสองไฟล์ตามขั้นตอนด้านบน แล้วคลิก Export report ในแถบเครื่องมือของหน้าเปรียบเทียบ หรือรัน "Excel Compare: Export a diff report (XLSX, HTML or CSV) (Pro)" จาก Command Palette
  2. เลือก XLSX, HTML หรือ CSV
  3. เลือกตำแหน่งที่จะบันทึกรายงาน ระบบจะนับการทดลองใช้เฉพาะเมื่อเขียนรายงานสำเร็จ

Export a diff report ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.zovo-excel-compare แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/zovo-excel-compare
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

Excel Compare & XLSX Diff ทำอะไรได้บ้าง

  • จับคู่ชีตตามชื่อก่อน แล้วตามตำแหน่ง ชีตที่มีอยู่ในไฟล์เดียวจะแสดงเป็นชีตที่เพิ่มหรือถูกลบ
  • CSV และ TSV ที่ตรวจหา encoding เอง (UTF-8 แบบมีหรือไม่มี BOM, UTF-16, Windows code page) และตรวจหาตัวคั่นเอง (comma, semicolon, tab หรือ pipe) รวมถึงฟิลด์ในเครื่องหมายคำพูดที่มีการขึ้นบรรทัดใหม่
  • ชีตขนาดใหญ่ ตารางวาดเฉพาะแถวที่อยู่บนหน้าจอ ชีต 300,000 แถวจึงเลื่อนได้เหมือนชีตสั้น ๆ
  • มีหมายเหตุเมื่อ merged cell ต่างกัน หรือเมื่อชีตถูกตัดเพราะถึงขีดจำกัด
  • เครื่องมือ Pro อีกสองตัว Match rows by key columns จับคู่แถวด้วยคอลัมน์ ID ชีตที่เรียงลำดับใหม่จึงเทียบได้ตรง และแถวที่ย้ายตำแหน่งจะถูกทำเครื่องหมาย ส่วน Compare two folders of workbooks จับคู่ไฟล์ตามชื่อ แล้วแสดงว่าไฟล์ใดเหมือนกัน ไฟล์ใดต่างกัน และไฟล์ใดมีอยู่ในโฟลเดอร์เดียว

สิ่งที่ยังทำไม่ได้

  • ไฟล์ขนาดไม่เกิน 200 MB (การตั้งค่า excelCompare.maxFileSizeMB) ไม่เกิน 300,000 แถวต่อชีต (excelCompare.maxRows) 1,000 คอลัมน์ และ 200 ชีต เมื่อถึงขีดจำกัดจะมีหมายเหตุแสดงในหน้าเปรียบเทียบ
  • workbook ที่จะขยายเกิน 600 MB เมื่อแตกไฟล์ หรือถูกบีบอัดแบบ zip bomb จะถูกปฏิเสธก่อนแตกไฟล์
  • หากไม่มีเครื่องมือ Pro Match rows by key columns แถวจะถูกจัดให้ตรงกันตามเนื้อหาและตำแหน่ง ไม่ใช่ตามคอลัมน์ ID
  • ส่วนขยายนี้เปรียบเทียบเท่านั้น ไม่แก้ไขหรือรวมไฟล์

คำถามที่พบบ่อย

ใช้ฟรีไหม

การเทียบ workbook หรือไฟล์ CSV สองไฟล์ Values และ Formulas การไปยังการเปลี่ยนแปลงถัดไปและก่อนหน้า และ Compare with Git HEAD ใช้ได้ฟรี เครื่องมือ Pro สามตัว คือ Export a diff report, Match rows by key columns และ Compare two folders of workbooks ทดลองใช้ฟรีได้ตัวละ 3 ครั้ง หลังจากนั้นต้องใช้ Zovo Pro ราคา 19 USD จ่ายครั้งเดียว ใช้ได้กับส่วนขยาย Zovo ทุกตัว

VS Code เทียบไฟล์ Excel สองไฟล์โดยไม่ใช้ส่วนขยายได้ไหม

ไม่ได้ ไฟล์ .xlsx คือไฟล์ zip ที่รวมส่วนต่าง ๆ ที่เป็น XML ไว้ diff ที่มีมากับ VS Code จึงแสดงเป็นไฟล์ไบนารี ต้องใช้ส่วนขยายที่อ่าน workbook ได้

ถ้าแทรกแถวที่ด้านบน แถวด้านล่างทั้งหมดจะถูกมาร์กว่าเปลี่ยนไหม

ไม่ แถวจะถูกจัดให้ตรงกันก่อนเปรียบเทียบ แถวที่แทรกจึงแสดงเป็นแถวที่เพิ่มหนึ่งแถว

ดูได้ไหมว่า workbook เปลี่ยนอะไรไปตั้งแต่ commit ล่าสุด

ได้ คลิกขวาที่ไฟล์ใน Git repository แล้วเลือก Compare with Git HEAD ส่วนขยายจะเรียกใช้ git ในเครื่องของคุณ
