จัดรูปแบบสคริปต์ bash หรือ zsh ใน VS Code

ติดตั้ง Shell Formatter for Bash & Zsh ซึ่งใช้ได้ฟรี เปิดสคริปต์ shell แล้วกด Shift+Alt+F (บน Mac กด Shift+Option+F) เอนจิน shfmt 3.14.1 มาในส่วนขยายในรูป WebAssembly จึงไม่ต้องดาวน์โหลดอะไร และผลลัพธ์ตรงกับ shfmt แบบ command line ทุกไบต์ Format Document, Format Selection, การจัดรูปแบบตอนบันทึก, key ใน .editorconfig และ syntax error ในแผง Problems ใช้ได้ฟรีและทำงานออฟไลน์ Zovo Pro (19 ดอลลาร์สหรัฐ จ่ายครั้งเดียว) เพิ่มเครื่องมือ 3 ตัว คือ Format All Shell Scripts in a Folder, Formatting Check with a Patch File และ Minify a Script to a Copy และแต่ละตัวลองใช้ฟรีได้ 3 ครั้ง

ติดตั้งใน VS Codeหน้า MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

ใช้ฟรี ไลเซนส์ MIT รหัสส่วนขยาย zovo.zovo-shell-formatter เวอร์ชัน 0.1.1

ขั้นตอนใน VS Code

  1. ติดตั้ง Shell Formatter for Bash & Zsh จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.zovo-shell-formatter
  2. เปิดสคริปต์ shell แล้วกด Shift+Alt+F (บน Mac กด Shift+Option+F) ถ้า VS Code ถามว่าจะใช้ formatter ตัวไหน ให้เลือก Shell Formatter หรือรัน "Shell Formatter: Use as Default Formatter for Shell Scripts"
  3. ถ้าต้องการจัดรูปแบบทุกครั้งที่บันทึก ให้รัน "Shell Formatter: Turn On Format on Save for Shell Scripts"
  4. dialect ดูจากบรรทัดแรก (#!/bin/bash, #!/bin/sh, #!/usr/bin/env zsh) แล้วดูจากชื่อไฟล์ (.bash, .zsh, .zshrc, .bats, .ksh) ถ้าไม่พบจะใช้ bash ถ้าต้องการเลือกเอง ให้ตั้ง shellFormatter.dialect หรือ shell_variant ใน .editorconfig
  5. คลิก shfmt 3.14.1 ในแถบสถานะเพื่อเปิดเมนู ซึ่งมี format, set as default, format on save, "Copy the matching shfmt command (for CI)" และการตั้งค่า
  6. ถ้าสคริปต์ไม่ใช่ shell ที่ถูกต้อง ไฟล์จะไม่ถูกเปลี่ยน และแผง Problems จะแสดงบรรทัดและคอลัมน์

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

Format Document, Format Selection, การจัดรูปแบบตอนบันทึก, การตรวจหา dialect, key ใน .editorconfig, เมนูในแถบสถานะ, Copy the Matching shfmt Command (for CI) และ syntax error ในแผง Problems ใช้ได้ฟรี ไม่ต้องลงชื่อเข้าใช้ ไม่มีการเรียกเครือข่าย และไม่มี telemetry

Format All Shell Scripts in a Folder ตรวจทุกสคริปต์ในโฟลเดอร์และโฟลเดอร์ย่อย ซึ่งหาจากชื่อไฟล์หรือจากบรรทัด #! ที่ระบุ shell แล้วบอกว่าจะมีกี่ไฟล์ที่เปลี่ยน จากนั้นจะจัดรูปแบบทั้งหมดหรือให้รายงาน Markdown โดยใช้เอนจิน การตั้งค่า และ .editorconfig เดียวกับ Format Document repository ที่มีสคริปต์หลายสิบไฟล์ในสไตล์ต่างกันจะได้สไตล์เดียวในการรันครั้งเดียว และสคริปต์ที่จะรันคำสั่งไม่เหมือนเดิมจะถูกปล่อยไว้ตามเดิม

วิธีใช้ Format All Shell Scripts in a Folder (Zovo Pro)

  1. คลิกขวาที่โฟลเดอร์ใน Explorer แล้วเลือก "Zovo Pro: Format All Shell Scripts in a Folder" หรือรัน "Shell Formatter: Format All Shell Scripts in a Folder (Pro)" จาก Command Palette หรือจากเมนูในแถบสถานะ แล้วเลือกโฟลเดอร์
  2. ชื่อของรายการถัดไปจะบอกว่ามีกี่สคริปต์ที่จะเปลี่ยน เช่น "N of M scripts would change"
  3. เลือก "Format N scripts" เพื่อจัดรูปแบบและบันทึกแต่ละไฟล์ (Undo ได้ทีละไฟล์) หรือ "Show the report only" เพื่อดูรายการ Markdown ของทุกสคริปต์โดยไม่เปลี่ยนอะไร
  4. ระบบนับการลองใช้เฉพาะเมื่อได้ผลลัพธ์ โฟลเดอร์ที่ไม่มีสคริปต์ shell หรือที่ทุกสคริปต์จัดรูปแบบไว้แล้ว จะไม่เสียสิทธิ์

Format All Shell Scripts in a Folder ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.zovo-shell-formatter แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/zovo-shell-formatter
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

Shell Formatter for Bash & Zsh ทำอะไรได้บ้าง

  • สคริปต์ Bash, POSIX sh (รวมถึง dash และ ash), mksh (รวมถึง ksh), bats และ zsh
  • ผลลัพธ์เหมือน shfmt 3.14.1 แบบ command line โดยรัน 354 จาก 354 ครั้งกับสคริปต์จริง 178 ไฟล์จากโปรเจกต์บน GitHub และ Homebrew ได้ผลตรงกันทุกไบต์
  • ก่อนนำการเปลี่ยนแปลงไปใช้ สคริปต์ที่จัดรูปแบบแล้วจะถูก parse อีกครั้งและต้องรันคำสั่งเดียวกับต้นฉบับ (ไฟล์ไม่เกิน 256 KB)
  • ตัวเลือกของ shfmt ตั้งได้ทั้งในการตั้งค่าและเป็น key ใน .editorconfig ได้แก่ indent, binary operator ขึ้นบรรทัดถัดไป, switch case indent, space redirect, keep padding, ปีกกาของ function ขึ้นบรรทัดถัดไป, simplify และ minify
  • ท้ายบรรทัดแบบ Windows (CRLF) ยังเป็น CRLF และสคริปต์ 2 MB จัดรูปแบบเสร็จในราว 0.2 วินาที

สิ่งที่ยังทำไม่ได้

  • ไม่แตะ Dockerfile, ไฟล์ .env หรือสคริปต์ fish และ csh
  • การรองรับ zsh ใน shfmt ยังใหม่ สคริปต์ zsh ที่ shfmt parse ไม่ได้จะไม่ถูกเปลี่ยน
  • ไฟล์ที่ใหญ่กว่า 10 MB (การตั้งค่า shellFormatter.maxFileMB) และไฟล์ที่มีไบต์แบบ binary เช่น installer ที่แตกไฟล์ตัวเองได้ จะไม่ถูกจัดรูปแบบ
  • shfmt ทำงานภายใต้เวลาจำกัด (ค่าเริ่มต้น 10 วินาที การตั้งค่า shellFormatter.timeoutSeconds) ถ้าครบเวลา ไฟล์จะไม่ถูกเปลี่ยน

คำถามที่พบบ่อย

ใช้ฟรีไหม

Format Document, Format Selection, การจัดรูปแบบตอนบันทึก และการรองรับ .editorconfig ใช้ได้ฟรี เครื่องมือ Pro 3 ตัว คือ Format All Shell Scripts in a Folder, Formatting Check with a Patch File และ Minify a Script to a Copy ลองใช้ฟรีได้ตัวละ 3 ครั้ง หลังจากนั้นต้องใช้ Zovo Pro ราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว

ต้องติดตั้ง shfmt ไหม

ไม่ต้อง shfmt 3.14.1 มาในส่วนขยายในรูป WebAssembly จึงทำงานออฟไลน์ได้โดยไม่ต้องดาวน์โหลดอะไร

จะทำให้สคริปต์ของฉันเสียไหม

สคริปต์ที่มี syntax error จะไม่ถูกเปลี่ยน และก่อนนำการเปลี่ยนแปลงไปใช้ สคริปต์ที่จัดรูปแบบแล้วจะถูก parse อีกครั้งและต้องรันคำสั่งเดียวกับต้นฉบับ

ใช้ใน Cursor ได้ไหม

ได้ Cursor, Windsurf และ VSCodium ติดตั้งได้จาก Open VSX ซึ่งเผยแพร่ในชื่อ zovo/zovo-shell-formatter
