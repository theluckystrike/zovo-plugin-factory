คู่มือภาษาไทย

จัดรูปแบบ HTML และ CSS ใน VS Code โดยไม่ทำให้บล็อก pre หรือแท็ก inline เสีย

ติดตั้งส่วนขยายฟรี HTML Formatter & CSS Formatter แล้วกด Shift+Alt+F ในไฟล์ HTML, CSS, SCSS หรือ LESS ส่วนขยายนี้จัดรูปแบบบล็อก <style> และ <script> ในหน้าเว็บด้วย ทำตาม .editorconfig ของคุณ คง <pre>, <textarea> และแท็ก inline ไว้ตามที่เขียน และไม่เปลี่ยนลำดับ attribute เลย ทำงานแบบออฟไลน์ด้วย js-beautify ที่รวมมาในส่วนขยาย จึงไม่ต้องใช้ Node, npm หรือไฟล์ config Zovo Pro (19 USD จ่ายครั้งเดียว) เพิ่มเครื่องมือสามตัว ได้แก่ Format Folder with Diff Preview, Minify HTML and CSS และ HTML Lint Report แต่ละตัวทดลองใช้ฟรีได้ 3 ครั้ง

ติดตั้งใน VS Codeหน้า MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

ใช้ฟรี ไลเซนส์ MIT รหัสส่วนขยาย zovo.zovo-html-formatter เวอร์ชัน 0.1.0

ขั้นตอนใน VS Code

  1. ติดตั้ง HTML Formatter & CSS Formatter จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.zovo-html-formatter
  2. เปิดไฟล์ HTML, CSS, SCSS หรือ LESS แล้วกด Shift+Alt+F (บน macOS กด Shift+Option+F) ถ้า VS Code ถามว่าจะใช้ formatter ตัวไหน ให้เลือก HTML Formatter & CSS Formatter
  3. หากต้องการตั้งให้เป็น formatter เริ่มต้นของทั้งสี่ภาษาในขั้นตอนเดียว ให้รัน "HTML Formatter: Use as Default Formatter for HTML, CSS, SCSS and LESS" จาก Command Palette
  4. เลือกบางบรรทัดแล้วรัน Format Selection เพื่อจัดรูปแบบเฉพาะบรรทัดเหล่านั้น
  5. หากต้องการจัดรูปแบบทุกครั้งที่บันทึก ให้เปิด zovoHtmlFormat.formatOnSave หรือใช้ editor.formatOnSave ของ VS Code เองหลังจากตั้งส่วนขยายนี้เป็น formatter เริ่มต้นแล้ว
  6. การย่อหน้ามาจาก editor ก่อน แล้วจึงมาจาก .editorconfig (รูปแบบและขนาดการย่อหน้า, end of line, ขึ้นบรรทัดใหม่ท้ายไฟล์, ความยาวบรรทัดสูงสุด) ทั้งทีมจึงได้ผลลัพธ์เหมือนกัน

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

Format Document, Format Selection และการจัดรูปแบบเมื่อบันทึกสำหรับ HTML, CSS, SCSS และ LESS พร้อมการรองรับ .editorconfig ใช้ได้ฟรี ไม่ต้องลงชื่อเข้าใช้ ไม่มีคำขอผ่านเครือข่าย และไม่มี telemetry

เมื่อทั้งเว็บไซต์ต้องใช้รูปแบบเดียวกัน Format Folder with Diff Preview จะจัดรูปแบบไฟล์ HTML, CSS, SCSS และ LESS ทุกไฟล์ในโฟลเดอร์ในหน่วยความจำ แสดงไฟล์ที่เปลี่ยนพร้อม diff แบบเทียบข้างกันของแต่ละไฟล์ และเขียนเฉพาะไฟล์ที่คุณยังเลือกไว้ คุณเห็นทุกการเปลี่ยนแปลงก่อนที่ไฟล์จะถูกเขียน

วิธีใช้ Format Folder with Diff Preview (Zovo Pro)

  1. คลิกขวาที่โฟลเดอร์ใน Explorer แล้วเลือก "Zovo Pro: Format folder with diff preview" หรือรัน "HTML Formatter: Format Folder with Diff Preview (Pro)" จาก Command Palette
  2. ดูรายการไฟล์ที่เปลี่ยน เปิด diff ของไฟล์ใดก็ได้ และเอาเครื่องหมายเลือกออกจากไฟล์ที่ต้องการคงไว้ตามเดิม
  3. เขียนไฟล์ที่เลือกไว้ ระบบจะนับการทดลองใช้เฉพาะเมื่อเครื่องมือให้ผลลัพธ์

Format Folder with Diff Preview ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.zovo-html-formatter แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/zovo-html-formatter
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

HTML Formatter & CSS Formatter ทำอะไรได้บ้าง

  • CSS ใน <style> และ JavaScript ใน <script> ภายใน HTML
  • สิ่งที่คงไว้ตามที่เขียน ได้แก่ เนื้อหาใน <pre> และ <textarea> แท็ก inline บนบรรทัดของตัวเอง ลำดับ attribute บรรทัดว่างระหว่างบล็อก (ติดกันได้ไม่เกินหนึ่งบรรทัด) รูปแบบการย่อหน้า head และ body ของหน้า และแท็ก template อย่าง {{ }} และ {% %}
  • ใน SCSS และ LESS map และการเรียกฟังก์ชันที่เขียนหลายบรรทัดจะคงเลย์เอาต์เดิม และคอมเมนต์ท้ายบรรทัดยังอยู่บนบรรทัดเดิม
  • เครื่องมือ Pro อีกสองตัว Minify HTML and CSS เขียนสำเนา .min.html และ .min.css พร้อมรายงานจำนวนไบต์และไบต์ gzip ที่ลดได้ ส่วน HTML Lint Report หารูปที่ไม่มี alt text ฟิลด์ฟอร์มที่ไม่มี label id ที่ซ้ำกัน ระดับหัวข้อที่ข้ามไป และปัญหาอื่น ๆ แล้วแสดงในรายงาน Markdown และในแผง Problems

สิ่งที่ยังทำไม่ได้

  • ส่วนขยายนี้ไม่จัดรูปแบบไฟล์ .js, .jsx, .ts, Vue และ Svelte ที่แยกเป็นไฟล์เดี่ยว จัดรูปแบบเฉพาะ JavaScript ที่อยู่ใน <script>
  • บรรทัดจะไม่ถูกตัดขึ้นบรรทัดใหม่จนกว่าคุณจะตั้งค่า wrap length บรรทัดที่ยาวมากจึงยังยาวเหมือนเดิม
  • SCSS และ LESS ผ่าน formatter ของ CSS ไวยากรณ์ที่ไม่ค่อยพบ เช่น detached ruleset ของ LESS อาจคงระยะห่างเดิมไว้
  • Minify ไม่ย่อ JavaScript และไม่เปลี่ยนชื่อหรือรวมกฎ CSS

ใช้ฟรีไหม

Format Document, Format Selection และการจัดรูปแบบเมื่อบันทึกสำหรับ HTML, CSS, SCSS และ LESS ใช้ได้ฟรี เครื่องมือ Pro สามตัว ได้แก่ Format Folder with Diff Preview, Minify HTML and CSS และ HTML Lint Report ทดลองใช้ฟรีได้ตัวละ 3 ครั้ง หลังจากนั้นต้องใช้ Zovo Pro ซึ่งจ่าย 19 USD ครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว

VS Code จัดรูปแบบ HTML ได้โดยไม่ต้องมีส่วนขยายไหม

ได้ VS Code มี formatter สำหรับ HTML และ CSS ในตัว ส่วนขยายนี้อ่าน .editorconfig คงการย่อหน้า head และ body แบบที่หน้านั้นใช้ คงเลย์เอาต์ของ map ใน SCSS และ LESS และเพิ่มเครื่องมือ Pro สำหรับโฟลเดอร์ minify และ lint

ส่วนขยายจะเปลี่ยนบล็อก pre หรือเรียงลำดับ attribute ใหม่ไหม

ไม่ เนื้อหาใน pre และ textarea แท็ก inline และลำดับ attribute คงไว้ตามที่คุณเขียน

ต้องมี Node หรือ npm ไหม

ไม่ต้อง js-beautify 1.15.4 รวมมาในส่วนขยายและทำงานแบบออฟไลน์
