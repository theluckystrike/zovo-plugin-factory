เปิดแบบ DXF ใน VS Code

ติดตั้ง DXF Viewer ซึ่งใช้ฟรี แล้วคลิกไฟล์ .dxf ส่วนขยายอ่าน DXF แบบ ASCII และ binary ตั้งแต่ R12 ถึง AutoCAD 2018 พร้อม block ข้อความ dimension, hatch และชีต paper space และคุณซ่อน layer ค้นหาข้อความ และวัดระยะได้ ไฟล์ DWG อ่านไม่ได้ เมื่อเปิด .dwg จะเห็นหน้าสั้น ๆ ที่บอกเวอร์ชันของไฟล์และวิธีบันทึกสำเนาเป็น DXF การดูแบบใช้ฟรี และ Zovo Pro (19 ดอลลาร์สหรัฐ จ่ายครั้งเดียว) เพิ่มเครื่องมือสามตัว คือ Extract drawing data, Compare drawings และ Folder inventory โดยลองใช้ฟรีได้ตัวละ 3 ครั้ง

ติดตั้งใน VS Codeหน้า MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

ใช้ฟรี ไลเซนส์ MIT รหัสส่วนขยาย zovo.dxf-viewer เวอร์ชัน 0.3.2

ขั้นตอนใน VS Code

  1. ติดตั้ง DXF Viewer จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.dxf-viewer
  2. คลิกไฟล์ .dxf ใน Explorer ไฟล์จะเปิดใน DXF Viewer แผงด้านข้างแสดงรายการ layer ประเภท entity และข้อมูลของแบบ เช่น เวอร์ชัน หน่วย และขนาด
  3. ลากเพื่อเลื่อนมุมมอง เลื่อนล้อเมาส์เพื่อซูมตรงตำแหน่งตัวชี้ และกด F หรือดับเบิลคลิกเพื่อให้แบบพอดีจอ กด B เพื่อสลับพื้นหลังระหว่างสีเข้มกับสีขาว
  4. ถ้าแบบมี paper space ให้เลือก layout ในรายการ Sheet แบบจะแสดงแบบเดียวกับตอนพิมพ์ พร้อม title block และ viewport ตามสเกลของแต่ละอัน
  5. เอาเครื่องหมายถูกหน้า layer ออกในแผง Layers เพื่อซ่อน layer นั้น กด Ctrl+F (Cmd+F บน Mac) เพื่อค้นหาข้อความ MTEXT หรือ block attribute และกด M เพื่อวัดระยะระหว่างสองจุด
  6. คลิก Export PNG หรือ Export SVG เพื่อบันทึกมุมมอง เมื่อคุณบันทึก DXF อีกครั้งจากโปรแกรม CAD มุมมองที่เปิดอยู่จะโหลดใหม่โดยคงระดับซูม ชีต และ layer เดิมไว้

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

การเปิดไฟล์ DXF ชีต layer การค้นหาข้อความ การวัดระยะ live reload และการ export เป็น PNG หรือ SVG ใช้ฟรี ตัวดูไม่เชื่อมต่อเครือข่าย และไม่แก้ไขแบบเลย

Inventory อ่านไฟล์ .dxf ทุกไฟล์ในโฟลเดอร์และโฟลเดอร์ย่อย แล้วบันทึกเป็น CSV หนึ่งแถวต่อหนึ่งแบบ แต่ละแถวมีเวอร์ชัน DXF หน่วย ความกว้างและความสูง layer, entity, block ข้อความ และฟิลด์ใน title block เช่น TITLE, DWG_NO, REV และ DATE เมื่อได้รับแบบมาทั้งโฟลเดอร์ คุณจะเห็นว่ามีอะไรบ้างใน spreadsheet เดียวโดยไม่ต้องเปิดทีละไฟล์

วิธีใช้ Inventory of a Folder of Drawings to CSV (Zovo Pro)

  1. คลิกขวาที่โฟลเดอร์ใน Explorer แล้วเลือก "Inventory of a Folder of Drawings to CSV (Zovo Pro)" หรือรัน "DXF Viewer: Inventory of a Folder of Drawings to CSV (Zovo Pro)" จาก Command Palette แล้วเลือกโฟลเดอร์
  2. การแจ้งเตือนจะแสดงความคืบหน้าและกดยกเลิกได้ จากนั้นเลือกที่บันทึก CSV ชื่อไฟล์เริ่มต้นจะลงท้ายด้วย -dxf-inventory.csv
  3. สิทธิ์ลองใช้จะถูกนับเฉพาะเมื่อบันทึกไฟล์ CSV แล้ว การกด Cancel หรือ Escape จึงไม่เสียสิทธิ์ ไฟล์ที่อ่านไม่ได้จะถูกระบุไว้ในคอลัมน์ Error

Inventory of a Folder of Drawings to CSV ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.dxf-viewer แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/dxf-viewer
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

DXF Viewer ทำอะไรได้บ้าง

  • DXF แบบ ASCII และ binary ตั้งแต่ R12 ถึง AutoCAD 2018
  • เส้นตรง arc วงกลม วงรี polyline ที่มี bulge, spline, hatch แบบ pattern, TEXT, MTEXT, block attribute, block ซ้อน และ dimension
  • layout ของ paper space โดยแต่ละ viewport ใช้สเกลและการหมุนของตัวเอง และไม่แสดง layer ที่ viewport นั้น freeze ไว้
  • ไฟล์ใหญ่ซึ่งอ่านใน worker thread แบบขนาด 24 MB ที่มี 600,000 เส้นโหลดเสร็จในประมาณหนึ่งวินาที

สิ่งที่ยังทำไม่ได้

  • อ่านไฟล์ DWG ไม่ได้ ต้องบันทึกเป็น DXF ก่อน
  • entity แบบ 3D จะถูกวาดแบนเป็นมุมมองด้านบน และไม่วาด 3DSOLID, REGION และ BODY
  • ข้อความใช้ฟอนต์ sans-serif ไม่ใช่ฟอนต์ SHX หรือ TrueType ของไฟล์ และไม่ใช้ line weight
  • viewport ถูกวาดเป็นสี่เหลี่ยม และ hatch แบบไล่สีจะแสดงเป็นสีทึบ
  • ไฟล์ที่ใหญ่กว่า 500 MB จะไม่ถูกอ่าน (การตั้งค่า dxfViewer.maxFileMB ปรับได้สูงสุด 2048)

คำถามที่พบบ่อย

ใช้ฟรีไหม

การเปิดไฟล์ DXF ชีต layer การค้นหาข้อความ การวัดระยะ live reload และการ export เป็น PNG หรือ SVG ใช้ฟรี เครื่องมือ Pro ทั้งสามตัว คือ Extract drawing data, Compare drawings และ Folder inventory ลองใช้ฟรีได้ตัวละ 3 ครั้ง หลังจากนั้นต้องใช้ Zovo Pro ราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว

เปิดไฟล์ DWG ได้ไหม

ไม่ได้ DWG เป็นฟอร์แมตปิด ไฟล์ .dwg จะเปิดเป็นหน้าสั้น ๆ ที่บอกเวอร์ชันและขั้นตอนบันทึกสำเนาเป็น DXF ใน AutoCAD, BricsCAD, LibreCAD, QCAD หรือ ODA File Converter ซึ่งใช้ฟรี

แก้ไขแบบได้ไหม

ไม่ได้ ตัวดูเป็นแบบอ่านอย่างเดียว ไฟล์ที่มันเขียนมีแค่ไฟล์ export ที่คุณเลือกในหน้าต่างบันทึก และจะไม่ยอมเขียนทับไฟล์แบบ

ใช้ใน Cursor ได้ไหม

ได้ DXF Viewer อยู่บน Open VSX ทั้ง Cursor, Windsurf และ VSCodium จึงติดตั้งได้
