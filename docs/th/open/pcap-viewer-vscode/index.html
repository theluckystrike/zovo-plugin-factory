เปิดไฟล์ PCAP ใน VS Code

ติดตั้ง PCAP Viewer ซึ่งใช้ฟรี แล้วคลิกไฟล์ .pcap หรือ .pcapng จะเห็นรายการแพ็กเก็ต, protocol tree, แผง hex ที่เชื่อมกับ tree, display filter แบบ Wireshark, follow stream และสถิติ ส่วนขยายอ่านไฟล์เองด้วย JavaScript จึงไม่ต้องมี Wireshark, tshark หรือ sharkd ตัว viewer ใช้ฟรี ส่วน Zovo Pro (19 ดอลลาร์สหรัฐ จ่ายครั้งเดียว) เพิ่มการ export รายการแพ็กเก็ตเป็น CSV หรือ JSON, รายงาน capture แบบ Markdown และสรุปทั้งโฟลเดอร์ โดยแต่ละเครื่องมือลองใช้ฟรีได้ 3 ครั้ง

ติดตั้งใน VS Codeหน้า MarketplaceOpen VSX (Cursor, Windsurf, VSCodium)

ใช้ฟรี ไลเซนส์ MIT รหัสส่วนขยาย zovo.zovo-pcap-viewer เวอร์ชัน 0.2.2

ขั้นตอนใน VS Code

  1. ติดตั้ง PCAP Viewer จาก Marketplace หรือกด Ctrl+P (Cmd+P บน macOS) แล้วรัน ext install zovo.zovo-pcap-viewer
  2. คลิกไฟล์ .pcap, .pcapng, .pcap.gz, .pcapng.gz หรือ .ntar ส่วนไฟล์ .cap, .dmp หรือชื่ออื่น ให้คลิกขวาที่ไฟล์ใน Explorer แล้วเลือก "Open in PCAP Viewer"
  3. พิมพ์ display filter เช่น tcp.port == 443 && ip.addr == 10.0.0.1 แล้วกด Enter ช่องกรองจะเป็นสีเขียวเมื่อ filter ถูกต้อง และบอกว่าผิดตรงไหนเมื่อไม่ถูกต้อง
  4. คลิก field ใน protocol tree เพื่อไฮไลต์ไบต์ของ field นั้นในแผง hex หรือคลิกไบต์เพื่อหาว่าอยู่ใน field ไหน
  5. ดับเบิลคลิกแพ็กเก็ตเพื่อ follow stream ของ TCP หรือ UDP แบบ ASCII, UTF-8 หรือ hex dump แล้วคัดลอกหรือบันทึกเป็นไฟล์ได้
  6. คลิก Statistics เพื่อดู protocol hierarchy, conversations, endpoints และชื่อที่พบใน capture คลิกแถวใดแถวหนึ่งเพื่อกรองตามแถวนั้น
  7. เปิดเมนู Export เพื่อบันทึกแพ็กเก็ตที่เลือก หรือทุกแพ็กเก็ตที่ filter แสดงอยู่ เป็นไฟล์ pcap ใหม่

อะไรใช้ฟรี และ Zovo Pro เพิ่มอะไร

รายการแพ็กเก็ต, protocol tree, แผง hex ที่เชื่อมกัน, display filter, filter ที่บันทึกไว้, follow stream, สถิติ และการ export แพ็กเก็ตเป็นไฟล์ pcap ใหม่ ใช้ฟรีทั้งหมด ไม่ต้องลงชื่อเข้าใช้และทำงานออฟไลน์ได้

เครื่องมือนี้เขียนแพ็กเก็ตที่ filter แสดงอยู่ลงไฟล์ CSV หรือ JSON แพ็กเก็ตละหนึ่งแถว ได้แก่ หมายเลข, เวลา UTC, วินาทีนับจากจุดเริ่ม, ต้นทาง, ปลายทาง, พอร์ต, โปรโตคอล, ความยาว, stream filter, ชื่อโฮสต์จาก capture และข้อความ Info ไฟล์ CSV เปิดใน Excel ได้โดยข้อความที่หน้าตาเหมือนสูตรถูกทำให้ปลอดภัย ส่วน JSON ใช้กับ jq และ pandas ได้ คุณจึงได้ตารางสำหรับแนบ ticket หรือใช้ในสคริปต์โดยไม่ต้องคัดลอกทีละแถว

วิธีใช้ Export packet list to CSV or JSON (Zovo Pro)

  1. เปิดไฟล์ capture และพิมพ์ display filter ถ้าต้องการเฉพาะบางแพ็กเก็ต
  2. เปิดเมนู Export ในแถบเครื่องมือแล้วเลือก "Packet list as CSV" หรือ "Packet list as JSON" หรือรัน "PCAP Viewer: Export Packet List to CSV or JSON (Pro)..." จาก Command Palette จะคลิกขวาที่ไฟล์ capture ใน Explorer แล้วเลือก "Zovo Pro: Export packet list to CSV or JSON" ก็ได้
  3. เลือกตำแหน่งบันทึกไฟล์ ระบบนับการลองใช้เมื่อเขียนไฟล์เสร็จแล้วเท่านั้น การกด Escape หรือเกิด error จึงไม่เสียสิทธิ์

Export packet list to CSV or JSON ใช้ได้ฟรี 3 ครั้งบนเครื่องของคุณก่อนจะขอไลเซนส์ ไม่มีป๊อปอัปและไม่มีการนับถอยหลัง

ขั้นตอนใน Cursor, Windsurf หรือ VSCodium

  1. เปิดมุมมอง Extensions ด้วย Ctrl+Shift+X (Cmd+Shift+X บน macOS)
  2. ค้นหา zovo.zovo-pcap-viewer แล้วคลิก Install ทั้ง Cursor, Windsurf และ VSCodium ติดตั้งส่วนขยายจาก Open VSX ซึ่งส่วนขยายนี้ใช้ชื่อ zovo/zovo-pcap-viewer
  3. ถ้า editor ของคุณไม่มีหน้าค้นหาส่วนขยาย ให้ดาวน์โหลดไฟล์ .vsix จากหน้า Open VSX แล้วรัน "Extensions: Install from VSIX..."
  4. จากนั้นทุกอย่างใช้งานได้เหมือนใน VS Code

PCAP Viewer ทำอะไรได้บ้าง

  • pcap (microsecond และ nanosecond, little-endian และ big-endian) และ pcapng รวมถึงไฟล์ที่บีบอัดเป็น .gz
  • Ethernet, 802.1Q VLAN, Linux cooked capture (SLL และ SLL2), raw IPv4 และ IPv6, BSD loopback, header ของ 802.11 และ radiotap
  • ARP, IPv4, IPv6, ICMP, ICMPv6, TCP, UDP, DNS และ mDNS, DHCP, HTTP/1.x, TLS records พร้อมชื่อเซิร์ฟเวอร์ (SNI) และ ALPN และ QUIC long header
  • ไฟล์ capture ขนาดใหญ่ ในการทดสอบก่อนออกเวอร์ชัน ไฟล์ 1 GB ที่มี 1,438,965 แพ็กเก็ตแสดงรายการเสร็จในประมาณ 2 วินาที
  • ไฟล์ที่เสียหาย ทุกแพ็กเก็ตก่อนจุดที่เสียจะแสดงครบ พร้อมข้อความบอกว่าเสียอะไรและตรงไหน

สิ่งที่ยังทำไม่ได้

  • ถอดรหัสเป็น field เฉพาะโปรโตคอลในรายการเท่านั้น HTTP คือ HTTP/1.x, 802.11 คือส่วน header และ QUIC คือ long header
  • ไม่ถอดรหัสลับ (decrypt) ทราฟฟิก TLS แต่แสดง TLS records พร้อมชื่อเซิร์ฟเวอร์ (SNI) และ ALPN
  • ช่องกรองรองรับส่วนที่ใช้บ่อยของไวยากรณ์ display filter ของ Wireshark ไม่ใช่ทั้งหมด
  • ไฟล์ capture แบบ .gz จะหยุดคลายที่ 512 MB (การตั้งค่า pcapViewer.maxGzipMB) และแจ้งให้ทราบ
  • ไฟล์บน remote หรือ virtual file system เปิดได้ไม่เกิน 256 MB (การตั้งค่า pcapViewer.maxRemoteMB)

คำถามที่พบบ่อย

ต้องติดตั้ง Wireshark ไหม

ไม่ต้อง PCAP Viewer อ่าน pcap และ pcapng ด้วย JavaScript ภายใน VS Code บน Windows, macOS และ Linux โดยไม่ใช้ Wireshark, tshark หรือ sharkd

เปิดไฟล์ capture แล้วจะส่ง DNS query ออกไปไหม

ไม่ส่ง ชื่อโฮสต์มาจากคำตอบ DNS ในแพ็กเก็ตและ name block ของไฟล์ pcapng เท่านั้น ส่วนขยายไม่มี telemetry และไม่ส่ง request ใด ๆ ออกเครือข่าย

ใช้ฟรีไหม

ใช้ฟรี ทั้ง viewer, filter, follow stream, สถิติ และการ export เป็น pcap ส่วน Export packet list to CSV or JSON, Capture report และ Folder summary เป็นเครื่องมือ Zovo Pro ที่ลองใช้ฟรีได้อย่างละ 3 ครั้ง หลังจากนั้นราคา 19 ดอลลาร์สหรัฐ จ่ายครั้งเดียวสำหรับส่วนขยาย Zovo ทุกตัว

ใช้ใน Cursor ได้ไหม
