Markdown Editor & Rich Text

Markdown Editor & Rich Text, a VS Code extension by Zovo

Edit Markdown files as rich text, the way you write in a document, and keep them plain Markdown. Only the paragraph, list or table you change is rewritten. Everything you do not touch stays byte-identical, so diffs stay small and hand-written formatting is safe.

Free, with no limits

  • Headings, bold, italic, strikethrough, inline code and links, with toolbar buttons and the usual keys (Ctrl+B, Ctrl+I, Ctrl+K; Cmd on macOS).
  • Bulleted, numbered and task lists: Enter adds an item, Tab indents, a click ticks a task.

How it keeps your file intact

The editor splits the file into blocks (a paragraph, a list, a table, a code block) and remembers where each one is in the text. When you change a block, only that block's text is replaced. A block opens as rich text only when the editor can write it back exactly as it was. Otherwise it opens as Markdown source in place. Emphasis keeps the marker you used (* or _, ** or __), and links keep their original target text.

Privacy

No account, no telemetry and no network requests. Images from the web are not loaded unless you turn on zovoMd.remoteImages. Pasted images are saved only next to your file.

Limits in this version

  • Lists with multi-line items or nested blocks, and quotes that contain lists or headings, open as Markdown source.
  • Setext headings (underlined with === or ---) stay setext; a level change writes an ATX heading.
  • Editing a table rewrites that table with aligned columns.
  • A link's address is edited in source mode, or by selecting the text and pressing Ctrl+K again.
  • Files over 8 MB are best edited with Reopen as text.
