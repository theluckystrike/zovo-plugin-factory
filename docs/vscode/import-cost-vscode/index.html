Import Cost & Bundle Size

Import Cost & Bundle Size, a VS Code extension by Zovo

Import Cost shows a minified and gzip footprint beside JavaScript and TypeScript imports. It runs on your computer with installed dependencies.

Questions people ask

Is Import Cost & Bundle Size free?

Yes. Import Cost & Bundle Size is free and MIT licensed.

How do I install Import Cost & Bundle Size?

Click "Install in VS Code" above, or search for zovo.zovo-import-cost in the Extensions view.

Free

  • Inline sizes for JavaScript, JSX, TypeScript and TSX imports, shown after the import line
  • Node built-ins such as fs, net and node:tls get no size; Node packages that use them are still measured
  • No account, telemetry or extension network calls
  • Skips packages over the 5 MB source limit by default
  • The same source files stay untouched

Zovo Pro tools

Zovo Pro: USD 19 once covers these project workflows.

  • Project report with each installed package's minified and gzip size
  • A project gzip budget saved as JSON for CI

Each Pro tool has 3 free tries. Run them from the Command Palette, or right-click package.json or a script file in the Explorer and pick a Zovo Pro entry. The importCost.showProTools setting hides those entries. The report is based on your current dependency tree. A branch comparison uses the dependencies installed in this workspace for both versions.

Use it

Open a JavaScript or TypeScript file after installing its dependencies. Inline sizes appear at the end of each package import line. A package that isn't installed shows install to measure. Run Import Cost: Project Report to see a full list. Run Import Cost: Set Size Budget to set a gzip threshold and save a JSON result for CI.

Limits

The budget JSON includes passed, complete, and per-package sizes. It checks the dependencies installed in this workspace. Sizes keep a package's exported API in the estimate, so a production bundler may remove more code. The scanner reads static import and direct require() calls, not dynamic imports, custom aliases or bundler plugins. The branch diff compares committed file changes between main and HEAD; uncommitted edits aren’t included. It doesn’t run your production bundler or reproduce a separate lockfile from main.
