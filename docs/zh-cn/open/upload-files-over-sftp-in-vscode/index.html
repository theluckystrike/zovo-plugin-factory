在 VS Code 中通过 SFTP 或 FTP 把文件上传到服务器

安装免费扩展 SFTP & FTP Sync and Upload，写一个 .vscode/sftp.json，填好主机、用户名和服务器目录。之后每次保存文件，都会通过 SFTP、FTP 或 FTPS 上传。右键文件或文件夹可以上传或下载，右键文件还可以与服务器副本比较。在 Remote Files 视图里，服务器文件会在普通标签页中打开。.vscode 文件夹、.env 文件和私钥永远不会上传。以上功能全部免费，无需账号。Zovo Pro（一次性 19 美元）增加三个工具：Sync Folder with Remote、Roll Back a Remote File 和 Server Profiles and Jump Host，每个工具可以免费试用 3 次。

在 VS Code 中的步骤

  1. 从 Marketplace 安装 SFTP & FTP Sync and Upload，或者按 Ctrl+P（macOS 上按 Cmd+P）后运行 ext install zovo.zovo-sftp。
  2. 在 Command Palette 中运行“SFTP: Create sftp.json Config”，或在 SFTP Remote 视图中点击 Create sftp.json。
  3. 填写 protocol（sftp、ftp 或 ftps）、host、username、privateKeyPath（用密码登录则不填）和 remotePath，即与本地文件夹对应的服务器目录。鼠标悬停在任意键上可以查看说明。
  4. 设置 "uploadOnSave": true。此后每保存一个文件就会上传。你输入的密码只询问一次，保存在编辑器的密钥存储（secret storage）中，不会写进 sftp.json。
  5. 在 Explorer 中右键任意文件、文件夹或标签页，选择 Upload、Download 或 Compare with Server Copy（Compare 只适用于文件）。
  6. 打开 Remote Files 视图浏览服务器。可以在普通编辑器标签页中打开文件并保存回服务器，也可以下载、复制路径或删除。“SFTP: Show Transfer Log”会显示每一次连接和传输。

哪些免费，Zovo Pro 增加什么

当服务器和本地文件夹的内容出现偏差时，Sync Folder with Remote 会比较两边，在传输任何文件之前列出所有差异：只在本地的文件、只在服务器上的文件，以及某一边更新的文件。你可以为每个文件选择上传、下载、删除或跳过，打开并排 diff，把试运行结果保存为文本，然后再执行。服务器上会改动什么，改动之前就能看得清清楚楚。

使用 Sync Folder with Remote（Zovo Pro）

  1. 在 Explorer 中右键文件夹，选择“Zovo Pro: Sync folder with remote (diff preview)”，或在 Command Palette 中运行“SFTP: Sync Folder with Remote, Diff Preview (Pro)...”。Remote Files 视图的标题栏里也有同样的按钮。

SFTP & FTP Sync and Upload 能做什么

  • SFTP 支持 SSH 密钥、加密私钥、SSH agent 或密码；也支持 FTP，以及使用显式或隐式 TLS 的 FTPS。
  • .vscode、.git、.env 文件、私钥、.npmrc 等敏感文件永远不会上传。可以在 ignore 中按 .gitignore 的写法添加自己的规则。
  • 会校验服务器的主机密钥：用 hostFingerprint 固定，或在首次连接时确认。密钥变化时连接会中止。
  • 在未信任的文件夹（Restricted Mode）中扩展保持关闭，下载来的项目无法把你的文件发往任何地方。
  • 另外两个 Pro 工具是 Roll Back a Remote File 和 Server Profiles and Jump Host。前者会在上传覆盖服务器文件之前，把该文件最近 10 个服务器副本保存在你的电脑上；后者可以在一个 sftp.json 中配置多台服务器（staging、production），并通过 SSH 跳板机连接。

它做不到的事

  • 每台服务器同时只有一个连接，FTP 传输逐个依次进行。
  • 服务器上指向文件的符号链接会被跟随，但文件夹上传、下载和同步不会进入链接的文件夹。
  • PuTTY .ppk 格式的密钥需要先转换为 OpenSSH 格式（puttygen key.ppk -O private-openssh -o key）。
  • 同步先比较大小和修改时间，再逐字节比较大小相同的文件，每次最多 300 个文件或 64 MB。
  • 回滚副本默认只为不超过 5 MB 的文件保留，并且只保存在本机。

常见问题

免费吗？

保存时上传、Upload、Download、Compare with Server Copy、Remote Files 视图和传输日志都免费，支持 SFTP、FTP 和 FTPS。三个 Pro 工具 Sync Folder with Remote、Roll Back a Remote File 和 Server Profiles and Jump Host 各有 3 次免费试用。之后需要 Zovo Pro，一次性 19 美元，适用于所有 Zovo 扩展。

密码会保存在 sftp.json 里吗？

不会。你输入的密码或私钥口令保存在编辑器的密钥存储中。sftp.json 里不写 password，就只会询问一次。

会上传我的 .env 文件吗？

不会。.vscode、.git、.env 文件、私钥和 .npmrc 都在默认忽略列表中，永远不会上传。

不装扩展，VS Code 能通过 SFTP 上传吗？

不能。VS Code 本身没有 SFTP 或 FTP 上传功能。Remote SSH 是直接在服务器上编辑文件；要上传本地项目，需要安装扩展，或在终端里用 scp 和 rsync。
