在 VS Code 中的步骤

  1. 从 Marketplace 安装 Shell Formatter for Bash & Zsh，或者按 Ctrl+P（macOS 上按 Cmd+P）后运行 ext install zovo.zovo-shell-formatter。
  2. 打开 shell 脚本，按 Shift+Alt+F（Mac 上按 Shift+Option+F）。如果 VS Code 问你用哪个格式化程序，选择 Shell Formatter，或运行 “Shell Formatter: Use as Default Formatter for Shell Scripts”。
  3. 如果想每次保存时都格式化，运行 “Shell Formatter: Turn On Format on Save for Shell Scripts”。
  4. 方言先根据第一行判断（#!/bin/bash、#!/bin/sh、#!/usr/bin/env zsh），再根据文件名判断（.bash、.zsh、.zshrc、.bats、.ksh），都无法判断时按 bash 处理。如果想自己指定，设置 shellFormatter.dialect，或在 .editorconfig 中设置 shell_variant。
  5. 点击状态栏中的 shfmt 3.14.1 打开菜单，其中有格式化、设为默认、保存时格式化、“Copy the matching shfmt command (for CI)” 和设置。
  6. 如果脚本不是有效的 shell，它会保持不变，Problems 面板会显示出错的行和列。

Shell Formatter for Bash & Zsh 能做什么

  • Bash、POSIX sh（也包括 dash 和 ash）、mksh（也包括 ksh）、bats 和 zsh 脚本。
  • 输出与命令行上的 shfmt 3.14.1 相同：在来自 GitHub 项目和 Homebrew 的 178 个真实脚本上运行 354 次，354 次全部逐字节一致。
  • 应用改动之前，会重新解析格式化后的脚本，它必须执行与原脚本相同的命令（适用于 256 KB 以内的文件）。
  • shfmt 选项可以作为设置项或 .editorconfig 键使用，包括缩进、二元运算符放到下一行、switch 中 case 的缩进、重定向符号后加空格、保留对齐用的空格、函数大括号放到下一行、简化和压缩。
  • Windows 换行符（CRLF）保持为 CRLF，2 MB 的脚本格式化约需 0.2 秒。

它做不到的事

  • 它从不处理 Dockerfile、.env 文件、fish 或 csh 脚本。
  • shfmt 对 zsh 的支持是新加入的。shfmt 无法解析的 zsh 脚本会保持不变。
  • 超过 10 MB 的文件（设置项 shellFormatter.maxFileMB）以及含有二进制字节的文件（例如自解压安装程序）不会被格式化。
  • shfmt 运行有时间限制（默认 10 秒，设置项 shellFormatter.timeoutSeconds）。达到限制时，文件保持不变。

常见问题

免费吗？

Format Document、Format Selection、保存时格式化和 .editorconfig 支持都免费。三个 Pro 工具 Format All Shell Scripts in a Folder、Formatting Check with a Patch File 和 Minify a Script to a Copy 各可免费试用 3 次。之后需要 Zovo Pro，一次性 19 美元，适用于所有 Zovo 扩展。

需要安装 shfmt 吗？

不需要。shfmt 3.14.1 以 WebAssembly 形式内置在扩展中，可以离线使用，不需要下载任何东西。

会把我的脚本改坏吗？

有语法错误的脚本会保持不变。应用改动之前，会重新解析格式化后的脚本，它必须执行与原脚本相同的命令。

能在 Cursor 中使用吗？

能。Cursor、Windsurf 和 VSCodium 从 Open VSX 安装它，这个扩展在那里的名称是 zovo/zovo-shell-formatter。
