在 VS Code 中的步骤

  1. 从 Marketplace 安装 Dotenv & .env File Editor，或者按 Ctrl+P（macOS 上按 Cmd+P）后运行 ext install zovo.zovo-dotenv。
  2. 打开 .env 文件（也包括 .env.local、.env.production、*.env 或 .flaskenv）。键、export、值、多行值和 ${NAME} 引用都会着色。
  3. 看起来像密钥的值会显示为圆点，直到光标移到该行。点击编辑器标题栏中的眼睛按钮，或运行 “Dotenv: Show or Hide Secret Values”，可以显示全部值。.env.example 这类模板中的值从不隐藏。
  4. Problems 面板会列出问题：同一个键设置了两次、= 两侧有空格、引号没有闭合、某行没有 =、名称无效、行尾有空格，或者 ${NAME} 引用的变量没有在任何一行中设置。在问题上按 Ctrl+.（Mac 上按 Cmd+.）即可看到修复方法。
  5. 运行 Format Document，去掉 = 两侧的空格和行尾空格。注释、顺序和引号保持不变。
  6. 如果想复制某个值又不显示它，运行 “Dotenv: Copy the Value on This Line”。即使值处于隐藏状态，它也会复制去掉引号和转义后的值。
  7. 在代码中悬停 process.env.DB_HOST、os.getenv("X")、System.getenv("X") 等，可以看到是哪个 .env 文件设置了它，按 F12 打开那一行。

Dotenv & .env File Editor 能做什么

  • .env、.env.*（例如 .env.local 和 .env.production）、*.env 和 .flaskenv 文件。
  • 可以选择隐藏名称中含有 PASSWORD、TOKEN、SECRET、API_KEY、DSN、DATABASE_URL 等字样的键的值，或者隐藏全部值，或者都不隐藏（设置项 envFile.maskValues）。
  • 代码中的悬停提示和转到定义支持 process.env 和 import.meta.env（JavaScript、TypeScript）、os.environ 和 os.getenv（Python）、os.Getenv（Go）、ENV（Ruby）、System.getenv（Java）、env()（PHP）等。
  • 在 process.env. 后面自动补全键名。
  • 隐藏的值在大纲、悬停提示和自动补全中也保持隐藏，除非你关闭这一选项（设置项 envFile.hoverShowsSecrets）。

它做不到的事

  • 隐藏只作用于屏幕显示。文本仍然在文件中、搜索结果中以及缩略图（minimap）的轮廓里，复制粘贴得到的是真实的值。
  • .envrc（direnv）是 shell 脚本，交给 shell 扩展处理。
  • 代码报告只能识别字面名称，例如 process.env.API_KEY。运行时拼出的名称找不到。
  • 问题检查遵循 dotenv 包的规则。少数工具（Docker Compose v1、systemd）更严格，警告指出的正是这些情况。

常见问题

着色、隐藏值、带快速修复的问题提示、格式化和代码中的悬停提示都免费。三个 Pro 工具 Compare .env with .env.example、Find Keys Missing in Code or .env 和 Convert .env to JSON, YAML, Kubernetes 各可免费试用 3 次。之后需要 Zovo Pro，一次性 19 美元，适用于所有 Zovo 扩展。

为了隐藏值，它会修改我的 .env 文件吗？

不会。改变的只是显示方式，文件从不被修改。复制粘贴得到的仍是真实的值。

为什么我的键被标记为设置了两次？

同一个键出现在两行中。dotenv 包保留第一个值，而 shell 和 Docker Compose 保留最后一个。快速修复会删除第二行。

能在 Cursor 中使用吗？

能。Cursor、Windsurf 和 VSCodium 从 Open VSX 安装它，这个扩展在那里的名称是 zovo/zovo-dotenv。
