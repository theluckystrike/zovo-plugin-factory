在 VS Code 中的步骤

  1. 从 Marketplace 安装 Video Preview with Sound，或者按 Ctrl+P（macOS 上按 Cmd+P）后运行 ext install zovo.video-preview-with-sound。
  2. 如果视频是 MKV、WebM、AVI、WMV、FLV、MPG、OGV 或 M2TS 文件，或者带 AC-3、E-AC-3 或 DTS 音轨，先安装 ffmpeg。Windows 上运行 winget install ffmpeg，Linux 上运行 sudo apt install ffmpeg，macOS 上运行 brew install ffmpeg。带 AAC 声音的 MP4、MOV 和 M4V 不需要另装任何东西。
  3. 在 Explorer 中点击 .mp4、.m4v、.mov、.webm、.mkv、.avi、.wmv、.flv、.mpg、.mpeg、.ogv 或 .m2ts 文件，按空格键播放。如果 VS Code 询问用哪个编辑器打开，选择 “Video Preview with Sound”。
  4. 在提示标签显示 “Sound: on” 之前，视频是静音播放的。MKV 或 WebM 会被复制封装成 MP4，不重新编码。ProRes、AVI、WMV 和其他 VS Code 解不了的视频会转成 H.264，只转一次，结果保存在缓存里。
  5. 把同名的 .srt 或 .vtt 文件放在视频旁边，字幕会自动加载。按 C 或使用 CC 菜单切换字幕轨道或关闭字幕。
  6. 按 , 和 . 逐帧后退和前进，按 [ 和 ] 在 0.1x 到 4x 之间调整速度，按 A 和 B 设置循环区间，按 S 把当前帧保存为原尺寸 PNG，按 P 进入画中画。

使用 Clip export（Zovo Pro）

  1. 在播放器中打开视频。在想要的片段开头按 A，结尾按 B；什么都不设就使用整个视频。
  2. 在播放器中按 Clip（带 PRO 标记），或者点击控制栏下方 Pro tools 小栏里的 “Export a Clip as GIF or MP4”。也可以在 Explorer 中右键点击视频，选择 “Zovo Pro: Export a Clip as GIF or MP4”。

在 Cursor、Windsurf 或 VSCodium 中的步骤

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）打开 Extensions 视图。
  2. 搜索 zovo.video-preview-with-sound，点击 Install。Cursor、Windsurf 和 VSCodium 从 Open VSX 安装扩展，这个扩展在那里的名称是 zovo/video-preview-with-sound。
  3. 如果编辑器没有扩展商店，就在 Open VSX 页面下载 .vsix 文件，然后运行 “Extensions: Install from VSIX...”。
  4. 之后的用法和 VS Code 里一样。

Video Preview with Sound 能做什么

  • MP4、M4V 和 MOV，声音为 AAC（单声道或立体声）、ALAC、MP3 或 PCM，在 Windows、Linux 和 macOS 上都不用另装任何东西。
  • MKV 和 WebM，由 ffmpeg 复制封装成 MP4 后带声音播放。
  • MP4、M4V 或 MOV 中的 AC-3、E-AC-3、DTS、Opus 或 5.1 AAC 声音，由 ffmpeg 或 macOS 自带的 afconvert 解码。
  • Apple ProRes、MPEG-4 Part 2 和 DNxHD 视频，以及 AVI、WMV、FLV、MPG、MPEG、OGV 和 M2TS 文件，用 ffmpeg 转成 H.264。
  • 视频旁边的 .srt 和 .vtt 字幕文件。

它做不到的事

  • 没有 ffmpeg 时，MKV 和 WebM 在任何系统上都打不开，播放器会提示 “Install ffmpeg to open this file”。扩展不内置 ffmpeg。
  • macOS 的 afconvert 不能转换视频，也打不开 MKV 或 WebM。转换总是需要你自己安装的 ffmpeg，较长的 ProRes 文件可能要几分钟。
  • 内置解码器播放 HE-AAC 时只解码其 AAC-LC 核心，采样率减半。要完整播放 HE-AAC、5.1 AAC、AC-3 和 DTS，请安装 ffmpeg。
  • 大于 4096 MB 的文件仍能播放，但没有声音（设置项 videoPreview.maxDecodeSizeMB）。
  • 字幕只来自 .srt 和 .vtt 文件，每个最大 5 MB，不读取视频文件内嵌的字幕。.ts 和 .mts 文件不会打开，因为这些扩展名属于 TypeScript 文件。

常见问题

为什么 VS Code 播放 MP4 没有声音？

VS Code 内置的 Chromium 有 H.264 视频解码器，但没有 AAC 解码器，而大多数 MP4 和 MOV 文件用的是 AAC 声音。这个扩展自己解码声音，并与画面同步播放。

需要 ffmpeg 吗？

带 AAC、ALAC、MP3 或 PCM 声音的 MP4、MOV 和 M4V 不需要。MKV、WebM、AVI、WMV、FLV、MPG、OGV 和 M2TS，ProRes 和其他 VS Code 解不了的视频，以及用 Clip export 导出 MP4 片段，都需要 ffmpeg。AC-3、E-AC-3 和 DTS 声音需要 ffmpeg，在 macOS 上也可以用 afconvert。

它免费吗？

免费。播放、声音、字幕、逐帧、把当前帧保存为 PNG 和格式转换都免费。Clip export、Frame export 和 Contact sheet 是 Zovo Pro 工具，各可免费试用 3 次，之后需要 Zovo Pro，一次性付费，适用于所有 Zovo 扩展。

能在 Cursor 中使用吗？

可以。它在 Open VSX 上的名称是 zovo/video-preview-with-sound，Cursor、Windsurf 和 VSCodium 都能安装。
