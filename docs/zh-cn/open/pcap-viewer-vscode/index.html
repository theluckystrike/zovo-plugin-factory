在 VS Code 中的步骤

  1. 从 Marketplace 安装 PCAP Viewer，或者按 Ctrl+P（macOS 上按 Cmd+P）后运行 ext install zovo.zovo-pcap-viewer。
  2. 点击 .pcap、.pcapng、.pcap.gz、.pcapng.gz 或 .ntar 文件。对于 .cap、.dmp 或其他文件名，在 Explorer 中右键点击文件，选择 “Open in PCAP Viewer”。
  3. 输入显示过滤器，例如 tcp.port == 443 && ip.addr == 10.0.0.1，然后按 Enter。过滤器有效时输入框变绿，无效时会说明哪里有错。
  4. 点击协议树中的字段，十六进制窗格里对应的字节会高亮；点击某个字节，也能找到它所属的字段。
  5. 双击数据包，可以跟踪它所在的 TCP 或 UDP 流，以 ASCII、UTF-8 或十六进制转储显示。可以复制，也可以保存到文件。
  6. 点击 Statistics，查看协议层级、会话、端点和抓包中出现的主机名。点击某一行即可按它过滤。
  7. 打开 Export 菜单，把选中的数据包，或当前过滤器显示的所有数据包，保存为新的 pcap 文件。

在 Cursor、Windsurf 或 VSCodium 中的步骤

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）打开 Extensions 视图。
  2. 搜索 zovo.zovo-pcap-viewer，点击 Install。Cursor、Windsurf 和 VSCodium 从 Open VSX 安装扩展，这个扩展在那里的名称是 zovo/zovo-pcap-viewer。
  3. 如果编辑器没有扩展商店，就在 Open VSX 页面下载 .vsix 文件，然后运行 “Extensions: Install from VSIX...”。
  4. 之后的用法和 VS Code 里一样。

PCAP Viewer 能做什么

  • pcap（微秒和纳秒精度，大端和小端）和 pcapng，也支持 .gz 压缩的文件。
  • Ethernet、802.1Q VLAN、Linux cooked capture（SLL 和 SLL2）、原始 IPv4 和 IPv6、BSD loopback、802.11 头部和 radiotap。
  • ARP、IPv4、IPv6、ICMP、ICMPv6、TCP、UDP、DNS 和 mDNS、DHCP、HTTP/1.x、带服务器名称（SNI）和 ALPN 的 TLS 记录，以及 QUIC 长头部。
  • 大型抓包文件。在发布前的测试中，一个包含 1,438,965 个数据包的 1 GB 文件约 2 秒完成列表显示。
  • 损坏的文件。损坏位置之前的每个数据包都会显示，并提示出了什么问题、在什么位置。

它做不到的事

  • 只有列表中的协议会被解析成字段。HTTP 仅限 HTTP/1.x，802.11 只解析头部，QUIC 只解析长头部。
  • 不解密 TLS 流量，只显示带服务器名称（SNI）和 ALPN 的 TLS 记录。
  • 过滤框只支持 Wireshark 显示过滤器语法中常用的部分，不是全部。
  • .gz 抓包文件解压到 512 MB 时会停止（设置项 pcapViewer.maxGzipMB），并给出提示。
  • 远程或虚拟文件系统上的文件最大可打开 256 MB（设置项 pcapViewer.maxRemoteMB）。

常见问题

需要安装 Wireshark 吗？

不需要。PCAP Viewer 在 VS Code 内用 JavaScript 读取 pcap 和 pcapng，支持 Windows、macOS 和 Linux，不使用 Wireshark、tshark 或 sharkd。

打开抓包文件会发出 DNS 查询吗？

不会。主机名只来自数据包里的 DNS 应答和 pcapng 文件中的名称块。扩展没有遥测，也不发网络请求。

它免费吗？

免费。查看器、过滤器、跟踪流、统计和 pcap 导出都免费。Export packet list to CSV or JSON、Capture report 和 Folder summary 是 Zovo Pro 工具，各可免费试用 3 次，之后需要 Zovo Pro，一次性付费，适用于所有 Zovo 扩展。

能在 Cursor 中使用吗？

可以。它支持 VS Code 1.90 及以上版本，以及从 Open VSX 安装扩展的编辑器，例如 Cursor、Windsurf 和 VSCodium。
