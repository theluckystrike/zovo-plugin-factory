在 VS Code 中的步骤

  1. 从 Marketplace 安装 DXF Viewer，或者按 Ctrl+P（macOS 上按 Cmd+P）后运行 ext install zovo.dxf-viewer。
  2. 在 Explorer 中点击 .dxf 文件。侧边面板列出各图层及其颜色和实体数量、实体类型表（模型空间和块内），以及图纸信息，其中包括块的数量。
  3. 按 Ctrl+F（Mac 上按 Cmd+F），输入位号或属性值，确认图纸里有这些数据。按 Enter 跳到下一个匹配。
  4. 从 Command Palette 或打开的图纸的 ... 菜单运行 “DXF Viewer: Extract Block Attributes, Text or Layers to CSV (Zovo Pro)”。也可以在 Explorer 中右键点击 .dxf 文件，选择 “Zovo Pro: Extract drawing data to CSV”。
  5. 在 “What should the CSV file hold?” 列表中选择 Block attributes、Block counts、All text 或 Layers。
  6. 在保存对话框中输入文件名。提示信息会显示保存了多少行。用 Excel 或 Google Sheets 打开 CSV。

在 Cursor、Windsurf 或 VSCodium 中的步骤

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）打开 Extensions 视图。
  2. 搜索 zovo.dxf-viewer，点击 Install。Cursor、Windsurf 和 VSCodium 从 Open VSX 安装扩展，这个扩展在那里的名称是 zovo/dxf-viewer。

  4. 之后的用法和 VS Code 里一样。

DXF Viewer 能做什么

  • 块属性，每个块插入一行，包含 Block、Layer、X、Y、Rotation、Space 和 Handle，后面每个属性标记占一列。
  • 块数量，即每个块在模型空间和图纸空间中插入了多少次，以及它所在的图层和属性标记。
  • 全部文字，包括 TEXT、MTEXT、属性和标注值，带类型、图层、X、Y、高度、块和标记。
  • 图层，包括实体数量、颜色（ACI）、开关状态和冻结状态。
  • ASCII 和二进制 DXF，从 R12 到 AutoCAD 2018 的文件，支持块和嵌套插入。

它做不到的事

  • 不支持 DWG。点击 .dwg 文件时，扩展会显示一个页面，写明 DWG 版本以及如何另存一份 DXF。免费的 ODA File Converter 可以一次转换整个文件夹的 DWG 文件。
  • CSV 里是块属性、块数量、文字或图层，不是每条直线和多段线的坐标列表。
  • 超过 500 MB 的文件不会读取（设置项 dxfViewer.maxFileMB，最大可设为 2048）。
  • 按文件夹运行时最多读取 5,000 张图纸，并跳过 node_modules、.git、.svn 和 .hg 文件夹。
  • 查看器是只读的。保存对话框不接受以 .dxf 或 .dwg 结尾的文件名，所以图纸永远不会被覆盖。

常见问题

它免费吗？

查看 DXF 文件、图层、布局、查找文字、测量以及导出 PNG 或 SVG 都免费。Extract drawing data、Compare drawings 和 Folder inventory 是 Zovo Pro 工具，每个可以在你的电脑上免费试用 3 次，之后需要 Zovo Pro，一次性付费，适用于所有 Zovo 扩展。

能从 DWG 文件中提取属性吗？

不能直接提取，因为不支持 DWG。先在 CAD 软件中另存一份 DXF，或者用免费的 ODA File Converter 转换 DWG 文件，再打开 DXF。

用 Excel 打开会乱码吗？公式会被执行吗？

CSV 文件以 UTF-8 BOM 开头，所以 Excel 能正确读取中文等非拉丁文字和带重音的字符。以 =、+、- 或 @ 开头的单元格会加一个前导撇号，Excel 不会把它当作公式执行。

能在 Cursor 中使用吗？

可以。它发布在 Open VSX 上，名称是 zovo/dxf-viewer，所以能在 Cursor、Windsurf 和 VSCodium 中安装。
