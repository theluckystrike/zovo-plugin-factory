在 VS Code 中以深色模式阅读 PDF

大多数 PDF 深色模式会把整页反色，照片里的蓝天会变成橙色。免费的 PDF Reader 扩展先把页面反色，再把每张图片的原始像素画回去，所以文字和背景变深，照片保持原色。页面跟随 VS Code 主题，也可以用月亮按钮随时切换。全部离线运行，没有遥测。

在 VS Code 中安装Marketplace 页面Open VSX (Cursor, Windsurf, VSCodium)

免费，MIT 许可证。扩展 ID zovo.pdf-viewer-dark，版本 0.3.7。需要 VS Code 1.90.0 或更高版本。

在 VS Code 中的步骤

  1. 从 Marketplace 安装 PDF Reader 扩展，或按 Ctrl+P（macOS 上为 Cmd+P）并运行 ext install zovo.pdf-viewer-dark。
  2. 在资源管理器中点击 .pdf 文件。使用深色 VS Code 主题时，页面直接以深色打开。
  3. 工具栏上的月亮按钮（或 Command Palette 中的 "PDF: Toggle Dark Pages"）为当前文件打开或关闭深色页面。把设置项 pdfViewer.darkMode 设为 on 或 off，就不再跟随主题。
  4. 月亮旁边的纸张按钮显示米黄色页面，适合长时间阅读。把 pdfViewer.lightPages 设为 sepia，所有 PDF 都会使用。
  5. 按 Ctrl+F（macOS 上为 Cmd+F）搜索。侧边栏有 PDF 大纲和页面缩略图。
  6. 选中文字，选择 4 种颜色之一，或按 H 高亮。Highlights 标签页列出所有高亮，"Copy as Markdown" 复制带有每页链接的列表。

免费功能与 Zovo Pro

阅读、深色和米黄色页面、搜索、大纲、缩略图、高亮、Copy as Markdown 以及页面链接，全部免费。

读很多论文或规格文档的人，希望把高亮集中在一个地方。Export Highlights of All PDFs 会写出一个 Markdown 文件，包含你高亮过的所有 PDF（或只包含当前工作区的 PDF）中的高亮，按文件分组，带颜色和每页的链接。Zovo Pro 还可以把页面提取、删除或拆分成新的 PDF，合并 PDF，以及对比两个 PDF。

使用 Export Highlights of All PDFs（Zovo Pro）

  1. 在 Command Palette 中运行 "PDF: Export Highlights of All PDFs to Markdown (Pro)..."，或点击 Highlights 标签页中的 "All PDFs" 链接。
  2. 选择所有 PDF，或只选当前工作区的 PDF。
  3. 选择 .md 文件的保存位置。PDF 本身不会被修改。

Export Highlights of All PDFs 可以在你的电脑上使用 3 次，之后才会要求许可证，而且只有得到结果时才算一次。打开文件时不会出现任何 Pro 提示。

在 Cursor、Windsurf 或 VSCodium 中

这些编辑器从 Open VSX 安装扩展。按 Ctrl+Shift+X（macOS 上为 Cmd+Shift+X）打开 Extensions 视图，搜索 zovo.pdf-viewer-dark 并点击 Install。之后的用法与 VS Code 相同。

它不能做什么

  • 以矢量线条绘制的图表会像文字一样被反色；以图片形式保存的图表保持原色。
  • 高亮保存在这台电脑的 VS Code 中，不写入 PDF。
  • 不能填写表单、编辑 PDF 或打印。
  • 超过 200 MB 的文件会先询问再打开。

常见问题

PDF 文件会被修改吗？

不会。深色模式和高亮只存在于显示和 VS Code 中，文件本身不变。

LaTeX 编译后会自动刷新吗？

会。文件在磁盘上变化后，查看器重新加载，并停在同一页、同一缩放比例。

Ctrl+P 还能用吗？

能。扩展不占用 Ctrl+P（macOS 上为 Cmd+P），打开 PDF 时 Quick Open 照常可用。
