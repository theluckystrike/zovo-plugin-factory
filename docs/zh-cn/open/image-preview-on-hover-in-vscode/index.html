在 VS Code 的装订线和悬停提示中查看代码里图片路径对应的图片

安装免费的 Image Preview & Image Hover 扩展，打开一个引用了图片的文件。该行旁边的装订线会显示缩略图，悬停在路径上会显示图片、类型、像素尺寸和文件大小。它支持 JavaScript 和 TypeScript 的 import、JSX、CSS url()、Markdown、HTML src 和 srcset、YAML 以及 data URI，不发出任何网络请求。Zovo Pro（一次性 19 美元）增加三个工具：Find Unused Images、Find Broken Image References 和 Image Weight Report，每个工具可以免费试用 3 次。

在 VS Code 中的步骤

  1. 从 Marketplace 安装 Image Preview & Image Hover，或者按 Ctrl+P（macOS 上按 Cmd+P）后运行 ext install zovo.zovo-image-preview。
  2. 打开一个引用了图片的文件，例如 import logo from './logo.png'、CSS url() 或 HTML <img src>。缩略图显示在装订线中，每行一个。
  3. 把鼠标悬停在路径上。悬停提示会显示图片（缩小到合适大小，从不放大）、类型、宽 × 高像素、文件大小以及是否透明，并提供打开文件和在 Explorer 中显示的链接。
  4. 如果路径无法解析，悬停提示会说明这一点，并列出它查找过的路径。可以在 imgPreview.aliases 中添加自己的前缀，例如 { "@images": "src/assets/images" }；以 / 开头的路径所在的文件夹，可以添加到 imgPreview.publicFolders 中。
  5. 要隐藏装订线缩略图，在 Command Palette 中运行 “Image Preview: Show or Hide Gutter Thumbnails”。
  6. 手边没有项目？运行 “Image Preview: Open the Sample Files”，打开一个包含各种路径写法的小型示例项目。

哪些免费，Zovo Pro 增加什么

装订线缩略图、悬停提示、支持别名的路径解析、tsconfig.json 和 jsconfig.json 中的 paths、monorepo 包以及 data URI 都免费。不需要账号，没有网络请求，没有遥测，可以离线使用。

Find Unused Images 会列出工作区（或某个文件夹）中没有被任何代码、样式、Markdown、HTML、JSON 或 YAML 文件引用的图片，按大小从大到小排列，生成带文件大小的 Markdown 报告。确认后，这些图片会移动到 _unused-images 文件夹并保留原来的文件夹结构，用 Edit > Undo 可以移回去。这样清理项目中的旧图片时，不用再逐个手动核对文件名。

使用 Find Unused Images（Zovo Pro）

  1. 在 Explorer 中右键一个文件夹，选择 “Zovo Pro: Find unused images”；或者在 Command Palette 中运行 “Image Preview: Find Unused Images (Pro)”。如果工作区有多个文件夹，选择其中一个。
  2. 通知中会显示进度和 Cancel 按钮。完成后会打开 Markdown 报告，按从大到小列出每张未使用的图片及其大小。
  3. 点击 “Move N to _unused-images” 移动这些图片，或关闭提示让它们留在原处。Edit > Undo 可以把它们移回去。
  4. 只有报告打开后才算用掉一次试用。按 Escape 不会消耗次数。

在 Cursor、Windsurf 或 VSCodium 中的步骤

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）打开 Extensions 视图。
  2. 搜索 zovo.zovo-image-preview，点击 Install。Cursor、Windsurf 和 VSCodium 从 Open VSX 安装扩展，这个扩展在那里的名称是 zovo/zovo-image-preview。

Image Preview & Image Hover 能做什么

  • 装订线缩略图支持 PNG、JPEG、GIF、WebP、AVIF、SVG、BMP 和 ICO 文件，以及 data:image/... URI。TIFF 和 HEIC 文件会从文件头读取尺寸和类型。
  • 相对于当前文件的路径；public/、static/ 等网站根目录下的 /logo.png；指向 src/ 的 @/；指向 node_modules 或主目录的 ~；以及带 extends 的 tsconfig.json 或 jsconfig.json 中的 paths。
  • 包含空格、%20、?v=2 或 #id 的文件名。JSON 中像 beans.jpg 这样只有文件名的值，会匹配到最近的同名图片。
  • Monorepo 中每个包都使用它自己的 public/ 文件夹和 tsconfig.json。
  • 远程 URL 只显示为链接，从不下载。

它做不到的事

  • 运行时拼出的路径，例如 `icons/${name}.svg` 或字符串拼接，无法预览，还可能让图片看起来像未使用。移动文件前请先检查未使用列表。
  • 每行只显示一个缩略图，即该行的第一张图片。悬停提示对该行的每个路径都有效。
  • 此版本不支持远程和虚拟工作区（SSH、WSL、Codespaces、vscode.dev）。
  • 只写在 JavaScript 配置文件中的 Webpack、Vite 或 Next.js 别名不会被读取。请把它们添加到 imgPreview.aliases 或 tsconfig.json 的 paths 中。
  • 超过 20 MB 的图片只测量不绘制（设置项 imgPreview.maxFileSizeMB）。Image Weight Report 会标出过大的文件，但不会压缩它们。

常见问题

免费吗？

装订线缩略图、悬停提示和路径解析都免费。三个 Pro 工具 Find Unused Images、Find Broken Image References 和 Image Weight Report 各可免费试用 3 次。之后需要 Zovo Pro，一次性 19 美元，适用于所有 Zovo 扩展。

为什么我的 @/ 或别名路径不显示图片？

这个别名可能只写在 Webpack、Vite 或 Next.js 的配置文件中，而这些文件不会被读取。把它添加到 imgPreview.aliases 或 tsconfig.json 的 paths 中即可。

能通过 Remote SSH 或 WSL 使用吗？

此版本不能。悬停提示中的图片是从本地磁盘读取的。

能在 Cursor 中使用吗？

能。Cursor、Windsurf 和 VSCodium 从 Open VSX 安装它，这个扩展在那里的名称是 zovo/zovo-image-preview。
