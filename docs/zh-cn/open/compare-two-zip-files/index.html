在 VS Code 中的步骤

  1. 从 Marketplace 安装 ZIP Viewer & Archive Explorer，或者按 Ctrl+P（macOS 上按 Cmd+P）后运行 ext install zovo.zip-archive-explorer。
  2. 在 Explorer 中点击 .zip、.jar、.vsix、.tar、.tar.gz、.tgz 或 .gz 文件。不用解压，就能看到其中的文件夹和文件，以及大小、压缩后大小、压缩率和修改日期。
  3. 从 Command Palette 运行 “Archive Explorer: Compare Two Archives... (Pro)”，或者在 Explorer 中右键点击一个压缩包，选择 “Zovo Pro: Compare two archives”。
  4. 选择较旧的压缩包，点击 “Choose”，再选择较新的压缩包，点击 “Compare”。如果是从右键菜单开始的，你点击的那个压缩包就是较旧的一个。
  5. 在新打开的 Markdown 标签页中查看报告。顶部的表格统计新增、删除、修改和相同的文件数量，下面是每一组的文件列表。想保留报告就保存这个标签页。
  6. 要查看某个修改过的文件的内容，分别打开两个压缩包，双击该条目。它会在普通的只读标签页中打开。

哪些免费，Zovo Pro 增加什么

浏览 ZIP、JAR、VSIX、TAR、TAR.GZ 和 GZ 文件免费，在编辑器标签页中打开条目、用 * 和 ? 通配符按名称搜索、侧边栏里的 Archive Explorer 树，以及安全解压单个文件、文件夹或整个压缩包也都免费。

Compare two archives 按路径匹配两个压缩包里的每个文件，并根据大小和 CRC-32 把每个文件标为新增、删除或修改；压缩包没有 CRC 时（例如 TAR）就逐字节比较。不用把两个包都解压再对比两个文件夹，就能看到两次构建之间的变化。报告以 Markdown 标签页打开，可以保存。

在 Cursor、Windsurf 或 VSCodium 中的步骤

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）打开 Extensions 视图。
  2. 搜索 zovo.zip-archive-explorer，点击 Install。Cursor、Windsurf 和 VSCodium 从 Open VSX 安装扩展，这个扩展在那里的名称是 zovo/zip-archive-explorer。

ZIP Viewer & Archive Explorer 能做什么

  • 对比 ZIP、JAR、VSIX 和 TAR 构建包。文件选择对话框也接受 WAR、EAR、WHL、NUPKG、TGZ 和 GZ 文件。
  • 按大小和 CRC-32 把每个文件标为新增、删除或修改，没有 CRC 时逐字节比较。
  • 最多 200,000 个条目的压缩包（设置项 archiveExplorer.maxEntries）。大的 ZIP 和 TAR 文件按范围从磁盘读取，不会整个载入。
  • 报告每组最多列出 2,000 个文件，并注明还有多少个。
  • 压缩包本身不会被修改。

它做不到的事

  • 报告列出哪些文件变了，但不显示文件内容的逐行差异。
  • 不比较修改日期。日期变了但内容没变的文件算作相同。
  • 如果某个条目在两个压缩包中大小相同、没有 CRC-32，并且是加密的、使用了不支持的压缩方法或大于 16 MB，报告会把它放在 “Same size, content not checked” 下面。
  • Stored 和 Deflate 以外的压缩方法（例如 BZIP2、LZMA、Zstandard 和 Deflate64）以及加密的条目只会列出，不能打开。不支持 7z、RAR、XZ 和 BZ2 文件。
  • .tar.gz 在内存中解压，默认最多 2 GB（设置项 archiveExplorer.maxUnpackedMB）。

常见问题

它免费吗？

浏览压缩包、打开条目、按名称搜索和解压都免费。Compare two archives、Export the entry list（CSV 或 JSON）和 Find a file in all archives of a folder 是 Zovo Pro 工具，每个可以在你的电脑上免费试用 3 次，之后需要 Zovo Pro，一次性付费，适用于所有 Zovo 扩展。

能看到文件内部改了什么吗？

不能。报告只说明哪些文件新增、删除或修改，以及它们的大小。要看具体改动的行，先把两个版本都解压出来再比较，例如用 VS Code 的 diff。

能对比两个 JAR 或 TAR 文件吗？

可以。Compare two archives 支持 ZIP、JAR、VSIX 和 TAR 构建包。TAR 文件没有 CRC-32，所以大小相同的文件会逐字节比较，每个文件最多 16 MB。

能在 Cursor 中使用吗？

可以。它发布在 Open VSX 上，名称是 zovo/zip-archive-explorer，所以能在 Cursor、Windsurf 和 VSCodium 中安装。
