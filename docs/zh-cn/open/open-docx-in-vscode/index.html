在 VS Code 中打开 .docx Word 文件

VS Code 没有 Word 查看器，打开 .docx 只会提示这是二进制文件。安装免费的 DOCX Viewer 扩展，再点一次文件，它就会以只读预览打开，颜色跟随编辑器主题，并带有文档大纲、搜索、表格、图表和公式。不需要 Office 或 LibreOffice，文件也不会上传。

在 VS Code 中安装Marketplace 页面Open VSX (Cursor, Windsurf, VSCodium)

免费，MIT 许可证。扩展 ID zovo.docx-viewer-vscode，版本 0.4.6。需要 VS Code 1.90.0 或更高版本。

在 VS Code 中的步骤

  1. 从 Marketplace 安装 DOCX Viewer 扩展，或按 Ctrl+P（macOS 上为 Cmd+P）并运行 ext install zovo.docx-viewer-vscode。
  2. 在资源管理器中点击 .docx、.dotx 或 .docm 文件。OpenDocument（.odt）和旧版 Word 97-2003 的 .doc 也能打开，.doc 只显示文字。
  3. 按 Ctrl+F（macOS 上为 Cmd+F）搜索，计数器会显示匹配数量，大纲可以直接跳到任意标题。
  4. 主题按钮可以在编辑器配色和白纸之间切换。"Page view" 按 Word 的排版显示页面，包括页边距、页眉和页脚；"Reading view" 切回连续的文字视图。
  5. 如果文档里有修订或批注，顶部会有一条栏显示数量。Markup、Final 和 Original 分别显示带标记、全部接受和全部拒绝后的文字，不会改动文件。
  6. 想看两个版本之间改了什么，右键点击文件，选择 "Compare with Git HEAD" 或 "Compare Documents (Redline)..."。屏幕上的对比是免费的。

免费功能与 Zovo Pro

阅读、Page view、搜索、大纲、修订和批注、Copy as Markdown，以及在屏幕上对比两个版本，全部免费，不需要账号。

当别人需要在 Word 里审阅改动时，Export Redline as Word 会保存一个新的 .docx，两个版本之间的每处差异都成为真正的修订记录，作者为 "Compare"，Word 和 LibreOffice 可以逐条接受或拒绝。Zovo Pro 还可以把对比结果导出为一个 HTML 文件、把改动清单保存为 Excel 工作簿，以及对比两个文件夹中的文档。

使用 Export Redline as Word（Zovo Pro）

  1. 打开文档后，在 Command Palette 中运行 "Export Redline as Word (Pro)..."，或在资源管理器中右键点击该文件。
  2. 选择这个文档的另一个版本。
  3. 选择保存位置。两个原始文档都不会被修改。

Export Redline as Word 可以在你的电脑上使用 3 次，之后才会要求许可证，而且只有得到结果时才算一次。打开文件时不会出现任何 Pro 提示。

在 Cursor、Windsurf 或 VSCodium 中

这些编辑器从 Open VSX 安装扩展。按 Ctrl+Shift+X（macOS 上为 Cmd+Shift+X）打开 Extensions 视图，搜索 zovo.docx-viewer-vscode 并点击 Install。之后的用法与 VS Code 相同。

它不能做什么

  • 它是查看器，不能编辑或保存文档。
  • 旧版 .doc 文件只显示文字，没有格式和图片。
  • SmartArt 不会显示；有密码保护的文件会显示一条提示，而不是内容。

常见问题

需要安装 Microsoft Office 吗？

不需要。扩展自己读取文件，在 VS Code 或 Cursor 中离线工作。

这个扩展收费吗？

不收费。阅读、搜索和屏幕对比都是免费的。只有导出功能和文件夹对比属于 Zovo Pro（一次性 USD 19），每项可以免费使用 3 次。

能在浏览器里用吗？

可以。在 vscode.dev 和 github.dev 中，点击 GitHub 仓库里的 .docx 文件即可阅读，无需克隆。
