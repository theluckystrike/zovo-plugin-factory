在 VS Code 中的步骤

  1. 从 Marketplace 安装 Agent Session Viewer，或者按 Ctrl+P（macOS 上按 Cmd+P）后运行 ext install zovo.agent-session-viewer。
  2. 点击活动栏里的 Agent Sessions 图标。Sessions 视图按项目文件夹分组列出 Claude Code 和 Codex 会话，子代理显示在启动它的会话下面。
  3. 点击一个会话即可查看。工具调用默认折叠，失败的调用带红色标记，文件修改显示为 diff。顶部显示模型、git 分支、轮数和 token 总数。
  4. 要找旧会话，点击视图顶部的搜索图标，或者从 Command Palette 运行 “Agent Sessions: Search Sessions”。选一条结果，会话会在匹配的位置打开。
  5. 点击会话旁边的终端图标（Resume in Terminal）。终端会在项目文件夹中打开，并运行 claude --resume <id> 或 codex resume <id>。
  6. 如果 .jsonl 会话文件在其他文件夹，右键点击它，选择 Open With，再选 Agent Session Viewer。

使用 Share-safe export（Zovo Pro）

  1. 打开会话，点击会话工具栏里的 Share-safe export 按钮。也可以在 Sessions 树中右键点击一个会话或项目文件夹，选择 “Share-Safe Export, Secrets Redacted (Pro)…”。
  2. 打开会话后，也可以从 Command Palette 运行 “Agent Sessions: Share-Safe Export, Secrets Redacted (Pro)…”。
  3. 选择 HTML 页面或 Markdown 格式，以及是否包含工具输出，然后选择保存位置。
  4. 分享之前先通读导出的文件。只有文件保存成功才算一次试用，按 Escape 或 Cancel 不消耗次数。

在 Cursor、Windsurf 或 VSCodium 中的步骤

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）打开 Extensions 视图。
  2. 搜索 zovo.agent-session-viewer，点击 Install。Cursor、Windsurf 和 VSCodium 从 Open VSX 安装扩展，这个扩展在那里的名称是 zovo/agent-session-viewer。
  3. 如果编辑器没有扩展商店，就在 Open VSX 页面下载 .vsix 文件，然后运行 “Extensions: Install from VSIX...”。
  4. 之后的用法和 VS Code 里一样。

Agent Session Viewer 能做什么

  • Claude Code 会话，位于 ~/.claude/projects（或 $CLAUDE_CONFIG_DIR/projects）；Codex 会话，位于 ~/.codex/sessions（或 $CODEX_HOME/sessions）。
  • 两种工具的子代理，都嵌套在启动它的会话下面。
  • 会话头部显示工具、模型、项目文件夹、git 分支、时长、轮数、token 总数，文件里记录了费用时还显示费用（Claude Code 会记录，Codex 不会）。
  • 文件修改显示为 diff（Edit、Write 和 apply_patch），思考过程和 Codex 的推理摘要默认折叠。
  • 从 session_index.jsonl 读取 Codex 线程名，重命名过的线程保留新名字。

它做不到的事

  • 只支持 Claude Code 和 Codex，暂不支持 Cursor、Copilot 和 Gemini CLI 的会话。
  • 它是只读的，不会修改、移动或删除会话文件，也没有删除命令。
  • 搜索匹配纯文本，不支持正则表达式，最多返回 300 条结果。
  • Resume in Terminal 需要已安装 Claude Code 或 Codex，并且能在终端的 PATH 中找到。
  • 默认最多读取 256 MB 的文件（agentSessionViewer.maxFileSizeMB），更大的文件只打开前面一部分。以加密形式存储的 Codex 推理内容无法显示。

常见问题

Claude Code 的聊天记录存在哪里？

在 ~/.claude/projects 下，每个项目一个文件夹，每个会话一个 .jsonl 文件。如果设置了 CLAUDE_CONFIG_DIR，就在那个文件夹下面。

它免费吗？

免费。查看、搜索、恢复会话和把单个会话导出为 Markdown 都免费，不限制历史记录的条数。三个 Pro 工具（用量和费用报告、安全分享导出、批量导出）各可免费试用 3 次，之后需要 Zovo Pro，一次性付费，适用于所有 Zovo 扩展。

能在查看器里删除旧会话吗？

不能。它只读取会话文件，不会修改、移动或删除它们。

它是 Anthropic 官方出品的吗？

不是。它不是 Anthropic 或 OpenAI 开发的，和它们也没有关联。它不发网络请求，也没有遥测。
