在 VS Code 中浏览 AWS S3、Cloudflare R2 或 MinIO 存储桶

安装免费的 S3 Explorer，在活动栏中打开它的 S3 Buckets 视图。它支持 AWS S3（使用 ~/.aws 中的配置文件，也支持 SSO 配置文件）、Cloudflare R2、MinIO、Backblaze B2、Wasabi 和 DigitalOcean Spaces。浏览、以只读方式打开对象、上传、下载、复制、移动、重命名、删除、版本、标签、预签名 URL 和文件夹同步都免费，不需要登录，没有遥测。Zovo Pro（一次性 19 美元）增加三个工具：Copy to Another Connection、Size and Cost Report 和 Scheduled Sync，每个工具可以免费试用 3 次。

在 VS Code 中的步骤

  1. 从 Marketplace 安装 S3 Explorer，或者按 Ctrl+P（macOS 上按 Cmd+P）后运行 ext install zovo.zovo-s3-explorer。
  2. 在活动栏中打开 S3 Explorer 视图，点击 Add Connection。选择 ~/.aws 中的 AWS 配置文件，或者输入访问密钥、R2 账户 ID 和令牌，或者 MinIO 等 S3 兼容服务的端点 URL。你输入的密钥保存在操作系统的钥匙串中。
  3. 展开一个连接，查看它的存储桶。键每次加载 1,000 个，末尾有一行 “Load 1,000 more”。如果你的密钥没有列出存储桶的权限，右键该连接并选择 Add Bucket by Name。
  4. 点击一个对象，会以只读方式在标签页或对应的查看器中打开它。要查看元数据、标签、版本和预签名 URL，右键对象并选择 Show Details, Versions and Presigned URL。
  5. 要修改对象，右键它并选择 Edit and Upload。你编辑的是一个副本，替换对象之前会弹出对话框，显示存储桶、键以及新旧两个大小。
  6. 把文件或文件夹从 Explorer 拖到存储桶上即可上传，或者右键并选择 Download 下载。16 MB 及以上的文件分段上传，显示进度和 Cancel 按钮；中断的上传在继续时只传缺少的部分。
  7. 要让本地文件夹和某个前缀保持一致，右键存储桶或文件夹，选择 Sync Folder。在任何改动之前，你会先看到一份试运行计划（新增、已更改、要删除）。

哪些免费，Zovo Pro 增加什么

浏览、打开、Edit and Upload、上传、下载、复制、移动、重命名、删除、版本、标签、预签名 URL 和文件夹同步都免费，不需要登录，不需要账号，没有遥测。它只连接你添加的存储端点。

Copy to Another Connection 把对象或整个文件夹从一个连接复制到另一个连接，例如从 AWS S3 复制到 Cloudflare R2 或 MinIO。确认方式与其他复制操作相同，会列出所有键，并指出哪些键会被替换。大对象通过分段上传传输。这样不用写脚本，也不用第二个工具，就能在树视图中把数据从一个服务商或账户搬到另一个。

使用 Copy to Another Connection（Zovo Pro）

  1. 先添加第二个连接。然后在 S3 Buckets 视图中右键一个对象或文件夹，选择 “Copy to Another Connection... (Pro)”，或者点击视图末尾 “Zovo Pro tools” 行中的 Copy to Another Connection。
  2. 选择目标连接、存储桶和目标文件夹（留空表示顶层）。
  3. 在确认框中查看对象列表，点击 Copy；如果有些键已经存在，点击 Copy and Replace。通知中会显示进度。
  4. 只有复制了对象才算用掉一次试用。在选择时按 Escape，或者还没有第二个连接，都不会消耗次数。

Copy to Another Connection 在你的电脑上可以免费用 3 次，之后才需要许可证。没有弹窗，也没有倒计时。

在 Cursor、Windsurf 或 VSCodium 中的步骤

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）打开 Extensions 视图。
  2. 搜索 zovo.zovo-s3-explorer，点击 Install。Cursor、Windsurf 和 VSCodium 从 Open VSX 安装扩展，这个扩展在那里的名称是 zovo/zovo-s3-explorer。
  3. 如果编辑器没有扩展商店，就在 Open VSX 页面下载 .vsix 文件，然后运行 “Extensions: Install from VSIX...”。
  4. 之后的用法和 VS Code 里一样。

S3 Explorer 能做什么

  • 带访问密钥的 AWS 配置文件、credential_process、使用 source_profile 的角色，以及运行 aws sso login 之后的 SSO 配置文件。配置文件中的 endpoint_url 会被采用。
  • MinIO 等使用端点 URL 的 S3 兼容服务，可以设置区域、路径样式或虚拟主机样式 URL，并可选择接受自签名证书。
  • 元数据、内容类型、存储类别、ETag、标签（可编辑并保存）、版本（打开、下载、恢复），以及有效期从 15 分钟到 7 天的预签名 GET 或 PUT URL。
  • 含有数百万个键的存储桶，每次加载 1,000 个，可以按前缀查找和筛选。
  • 下载会保留文件夹结构，从不写到你选择的文件夹之外。含有 .. 段、盘符或 NUL 字节的键会被跳过并列出。

它做不到的事

  • 它从不自行使用 AWS default 配置文件或 AWS_PROFILE。连接时使用哪个配置文件由你选择。
  • 超过 10 MB 的文本对象会先询问，然后只显示前 1 MB。超过 200 MB 的二进制对象下载前会先询问。
  • 打开的对象是只读的。只有 Edit and Upload 会在确认后写入存储桶。
  • Scheduled Sync 只在 VS Code 打开时运行，间隔为 5 到 60 分钟，并且从不删除。
  • 没有响应的请求会在 30 秒后停止（设置项 s3Explorer.requestTimeoutSeconds）。

常见问题

免费吗？

浏览、打开、上传、下载、复制、移动、重命名、删除、版本、标签、预签名 URL 和文件夹同步都免费。三个 Pro 工具 Copy to Another Connection、Size and Cost Report 和 Scheduled Sync 各可免费试用 3 次。之后需要 Zovo Pro，一次性 19 美元，适用于所有 Zovo 扩展。

我的密钥保存在哪里？

你输入的密钥通过 VS Code SecretStorage 保存在操作系统的钥匙串中，从不写入设置文件。只有在你选择某个 AWS 配置文件时，才会读取 ~/.aws。

支持 Cloudflare R2 和 MinIO 吗？

支持。R2 需要你的账户 ID 和 R2 API 令牌的访问密钥。MinIO 等 S3 兼容服务需要端点 URL、区域，以及路径样式或虚拟主机样式 URL。

能在 Cursor 中使用吗？

能。Cursor、Windsurf 和 VSCodium 从 Open VSX 安装它，这个扩展在那里的名称是 zovo/zovo-s3-explorer。
