在 VS Code 中的步骤

  1. 从 Marketplace 安装 NetCDF Viewer & HDF5 Viewer，或者按 Ctrl+P（macOS 上按 Cmd+P）后运行 ext install zovo.hdf5-netcdf-explorer。
  2. 在 Explorer 中点击 .nc、.nc4、.netcdf 或 .cdf 文件。概览页显示格式、维度、全局属性和所有变量的表格，和 ncdump -h 的输出差不多。
  3. 在左侧的树中选择一个变量。二维切片会画成热力图，行列是纬度和经度时还会叠加海岸线。
  4. 拖动时间滑块，或者按旁边的 ▶ 按时间连续播放。点击地图上的一点，可以画出该点的时间序列。
  5. 打开 Table 标签页，按每页 100 行、30 列翻看数值，表头显示坐标值。
  6. 点击 “Save PNG” 保存图片，或者点击 “Export slice…” 把屏幕上的切片保存为 CSV 或 JSON。“Copy xarray code” 会给出读取同一切片的 Python 代码。
  7. HDF5 文件直接点击 .h5 文件即可。MATLAB 7.3 .mat 文件需要右键点击，选择 “Open in HDF5 NetCDF Explorer”。

哪些免费，Zovo Pro 增加什么

所有格式、变量树、属性、表格、图和带海岸线的地图、播放、单点时间序列、Save PNG 和 Export slice 都免费。这些功能不需要 Python，也不发网络请求。

Export a subset 的作用类似 ncks -d 或 xarray 的 .sel。选择一个变量，再给每个维度指定范围，可以按下标（0:99）或按数值（30..60、2023-08-01..2023-08-31）。结果保存为 NetCDF 文件，带坐标、属性和一行 history，也可以保存为每个点一行的整齐 CSV。不用写脚本，就能得到某个区域和时段的小文件。

使用 Export a subset（Zovo Pro）

  1. 打开文件，点击 “Export slice…” 旁边的 “Export subset…” 按钮，或者在 Explorer 中右键点击文件，选择 “Zovo Pro: Export a Subset of a Variable”。
  2. 也可以从 Command Palette 运行 “NetCDF Viewer Pro: Export Subset of a Variable (NetCDF or CSV)...”。
  3. 为每个维度输入范围。输入时，输入框会显示当前选中的内容。
  4. 选择 NetCDF 或 CSV，再选择保存位置。通知会显示进度，按 Cancel 停止时不会留下写了一半的文件。

在 Cursor、Windsurf 或 VSCodium 中的步骤

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）打开 Extensions 视图。
  2. 搜索 zovo.hdf5-netcdf-explorer，点击 Install。Cursor、Windsurf 和 VSCodium 从 Open VSX 安装扩展，这个扩展在那里的名称是 zovo/hdf5-netcdf-explorer。
  3. 如果编辑器没有扩展商店，就在 Open VSX 页面下载 .vsix 文件，然后运行 “Extensions: Install from VSIX...”。
  4. 之后的用法和 VS Code 里一样。

NetCDF Viewer & HDF5 Viewer 能做什么

  • NetCDF-4 和 NetCDF-4 classic、NetCDF-3 classic 和 64-bit offset，以及 CDF-5（64 位数据）。
  • HDF5 文件（.h5、.hdf5、.he5、.hdf），支持 deflate、shuffle、szip、LZF、Blosc、bitshuffle、LZ4、Zstd、bzip2 和 ZFP 压缩。
  • MATLAB 7.3 .mat，以及其他基于 HDF5 的文件，例如 .jld2、.loom 和 .h5ad。
  • 按 CF 约定解码 scale_factor、add_offset、_FillValue 和时间单位，支持 noleap、360_day 和 all_leap 日历。
  • 通过 Remote SSH、WSL 或 dev container 打开远程机器上的文件。

它做不到的事

  • 不支持 Zarr 和 HDF4。以 v5 格式保存的 MATLAB .mat 文件不是 HDF5，无法打开，需要用 save(filename, '-v7.3') 重新保存。
  • 只有规则的经纬度网格才会画海岸线。使用二维经纬度的曲线网格，以及以米为单位的投影网格，都不画海岸线。
  • 大于 512 x 512 的数组在绘图时会抽样。导出时每个文件最多写入 1,000,000 个值（设置项 hdf5NetcdfExplorer.maxReadValues）。
  • 不支持虚拟文件系统，例如在 vscode.dev 中打开的 GitHub 仓库。
  • 使用其他 HDF5 过滤器（例如 SZ 或 JPEG）的数据集会显示提示信息，而不是数值。

常见问题

它免费吗？

查看功能免费，包括所有格式、地图、播放、时间序列、Save PNG 和 Export slice。两个 Pro 工具 Compare two files 和 Export a subset 各可免费试用 3 次，之后需要 Zovo Pro，一次性付费，适用于所有 Zovo 扩展。

有 Windows 上能用的 NetCDF 查看器吗？

有。这个扩展在 VS Code 能运行的地方都能用，包括 Windows、macOS 和 Linux，不需要 Python。

能打开 HDF5 和 MAT 文件吗？

HDF5 .h5 文件和 MATLAB 7.3 .mat 文件可以。旧的 MATLAB v5 .mat 文件不是 HDF5，会显示一条提示。

能在 Cursor 中使用吗？

可以。它在 Open VSX 上的名称是 zovo/hdf5-netcdf-explorer，Cursor、Windsurf 和 VSCodium 都能安装。
