在 VS Code 中自动重命名 HTML、JSX 和 Vue 标签

安装免费的 Auto Rename Tag & Close Tag Sync 扩展，然后修改开始标签或结束标签的名字，配对的标签会随着输入同步改变。重命名用的是 VS Code 自带的 linked editing（editor.linkedEditing）。扩展为它支持的语言打开这个设置，并在 HTML、JSX、TSX、Vue、Svelte、Astro、PHP、Blade、Twig、XML、Markdown 等语言里找到配对标签，所以撤销一次就能把两个标签一起还原。重命名、自动闭合和配对标签框都免费。Zovo Pro（一次性 19 美元）增加 Rename Tag in All Files 和 Check Unclosed Tags in All Files，每个工具可以免费试用 3 次。

在 VS Code 中的步骤

  1. 从 Marketplace 安装 Tag Auto Rename & Close Tag Sync，或者按 Ctrl+P（macOS 上按 Cmd+P）后运行 ext install zovo.zovo-auto-rename-tag。
  2. 打开 HTML、JSX、TSX、Vue、Svelte、PHP 或其他模板文件，修改开始标签的名字，闭合标签会随输入同步改变，反过来也一样。
  3. 在开始标签后输入 >，闭合标签会出现在光标后面。输入 </，当前未闭合元素的名字会自动填上。
  4. 把光标放在标签上，两个标签都会出现一个边框，颜色用的是当前主题的括号颜色。
  5. 在编辑器里右键点击，可以找到 “Go to Matching Tag” 和 “Select Tag Content”。如果想在输入框里输入新名字，从 Command Palette 运行 “Tag Sync: Rename Tag Pair…”。
  6. 点击状态栏里的 Tags 项，可以查看当前文件开启了哪些功能，或者对某种语言关闭这个扩展。如果显示 “Tags: rename off”，点击它即可为该语言打开重命名。

使用 Rename Tag in All Files（Zovo Pro）

  1. 在 VS Code 中打开项目文件夹。这个工具需要打开一个文件夹。
  2. 从 Command Palette 运行 “Tag Sync: Rename Tag in All Files… (Pro)”，或者在 Explorer 中右键点击 .html、.htm、.vue、.jsx、.tsx 或 .svelte 文件，选择 “Zovo Pro: Rename Tag in All Files”。
  3. 输入要重命名的标签，写法和文件里一致（例如 Button），再输入新名字。
  4. 选择 “Rename”，或者选择 “Preview first” 在重构预览里检查改动。原本没打开的文件会被修改但不会保存，用 File > Save All 保存，或者用撤销还原。

在 Cursor、Windsurf 或 VSCodium 中的步骤

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）打开 Extensions 视图。
  2. 搜索 zovo.zovo-auto-rename-tag，点击 Install。Cursor、Windsurf 和 VSCodium 从 Open VSX 安装扩展，这个扩展在那里的名称是 zovo/zovo-auto-rename-tag。

Tag Auto Rename & Close Tag Sync 能做什么

  • 支持在 HTML、JSX 和 TSX、Vue、Svelte、Astro、PHP、Blade、Twig、Jinja、Nunjucks、Liquid、ERB、EJS、Handlebars、XML、SVG 和 Markdown 中重命名。
  • br、img、input、meta 和 hr 这类空元素不会被配对，也不会被自动闭合。
  • 在 .tsx 中只有真正的 JSX 才算标签。a < b && c > d 这样的比较和 useState<string>() 这样的泛型不会被改动，.ts 文件也不会被处理。
  • 注释、字符串、<script> 和 <style> 的内容，以及 {{ }}、{% %}、<?php ?> 和 <% %> 块都会被跳过。
  • 新建的未保存文件只要设置了语言就能用。

它做不到的事

  • 在 JSX 和 TSX 中，TypeScript 会自己闭合标签，所以这个扩展把闭合交给它。TypeScript 插入的闭合标签是单独的一步撤销。
  • 如果装了 Vue、Svelte、Astro 或 Red Hat XML 扩展，在对应语言里由那个扩展负责闭合标签，这个扩展不介入。
  • 超过 1 MB 或 50,000 行的文件不会实时重命名、闭合或高亮（设置项 zovoTags.maxFileSizeKB 和 zovoTags.maxFileLines）。状态栏会提示这一点，命令仍然可用。
  • 写在 Svelte 或 Astro {...} 表达式里的标签不会被重命名。
  • 如果同时开着旧的 Auto Rename Tag 或 Auto Close Tag 扩展，两者可能同时修改同一个标签，只保留其中一个即可。

常见问题

它和 editor.linkedEditing 设置有什么区别？

扩展用 editor.linkedEditing 来完成重命名。它为支持的每种语言打开这个设置，并在这些语言中找到配对标签，从 HTML、Vue 到 PHP、Twig、XML 和 JSX。它还会自动闭合标签，给配对标签加边框，并提供 Go to Matching Tag 和 Select Tag Content。如果你自己关掉了 editor.linkedEditing，状态栏会显示 “Tags: rename off”，点一下就能为该语言重新打开。

撤销还正常吗？

正常。你的修改和配对标签的改动是同一步撤销，因为重命名用的是 VS Code 的 linked editing。自动闭合插入的闭合标签和你输入的 > 算同一步撤销，JSX 和 TSX 除外，那里由 TypeScript 闭合标签。

它免费吗？

免费。重命名、自动闭合、配对标签框和编辑器命令都免费。Rename Tag in All Files 和 Check Unclosed Tags in All Files 是 Zovo Pro 工具，各可免费试用 3 次，之后需要 Zovo Pro，一次性付费，适用于所有 Zovo 扩展。

能在 Cursor 中使用吗？

可以。Cursor、Windsurf 和 VSCodium 从 Open VSX 安装它，名称是 zovo/zovo-auto-rename-tag。
