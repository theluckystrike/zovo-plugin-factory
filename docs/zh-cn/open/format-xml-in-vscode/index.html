在 VS Code 中的步骤

  1. 从 Marketplace 安装 XML Formatter & XPath Tools，或者按 Ctrl+P（macOS 上按 Cmd+P）后运行 ext install zovo.zovo-xml-xpath-tools。
  2. 打开 .xml 文件，按 Shift+Alt+F（Mac 上按 Shift+Option+F），或运行 Format Document。如果装了多个 XML 格式化程序，VS Code 会问你用哪一个。Format Selection 也可以用。
  3. 格式化程序使用你设置的制表符宽度以及制表符或空格，并保留换行符、字节顺序标记（BOM）和文件末尾的换行。如果文件不是格式良好的，内容不会有任何改动，并会显示错误所在的行和列。
  4. 如果想让文件变小，对整个文件或选中部分运行 “XML: Minify XML”。注释会保留，除非打开 xmlXpathTools.minify.removeComments。
  5. 要运行 XPath，点击编辑器标题栏中的搜索按钮，或运行 “XML: Evaluate XPath…”。结果会连同行号列在 XPath Results 中。点击某个结果即可在编辑器中选中它。
  6. 点击状态栏中的 XPath，可以复制光标所在元素的路径，可选带位置、带 id 或 name 属性，或者使用可移植的 local-name() 形式。
  7. 对于超过 50 MB 的文件，在 Explorer 中右键它，选择 “Format Large XML File on Disk…”。它会在旁边写入 name.formatted.xml，或在你确认后替换原文件。

XML Formatter & XPath Tools 能做什么

  • VS Code 以 XML 打开的文件。扩展还会把 .kml、.gpx、.rss、.atom、.wsdl、.dbk、.xlf、.xliff、.resx、.nuspec、.props、.targets 和 .xaml 文件作为 XML 打开。
  • 大文件。格式化、树视图和 XPath 都在后台线程中运行。在扩展的测试中，一个 49 MB、约一百万个元素的文件用 1.6 秒完成了格式化。
  • 普通名称也能匹配默认命名空间，所以 //dependency/artifactId 在 pom.xml 中可以直接用。如需严格的 XPath 1.0，打开 xmlXpathTools.xpath.strictNamespaces。
  • 属性可以保持原样、放在一行，或每行一个（设置项 xmlXpathTools.format.attributes）。
  • Explorer 中的 XML Tree 视图会跟随光标，Problems 会列出格式良好性错误及其行和列。

它做不到的事

  • 只支持 XPath 1.0。不支持 XPath 2.0 或 3.1、XQuery 和 XSLT。
  • 它只检查文件是否格式良好，不会根据 XSD 或 DTD 做验证。
  • 超过 50 MB 的文件可以在磁盘上格式化，但 VS Code 不会把这些文件交给扩展，所以树视图和 XPath 无法处理它们。
  • 磁盘格式化命令可以读取 UTF-8、带字节顺序标记的 UTF-16 和 ISO-8859-1。
  • 包含文本的元素，例如 <p>Some <b>bold</b> text</p>，会按原样留在自己那一行。只有只包含标签、不含文本的元素才会加入新的换行。

常见问题

免费吗？

格式化、Minify XML、XPath、Copy XPath、XML Tree 视图和格式良好性检查都免费。三个 Pro 工具 Run XPath on Every XML File in a Folder、Format All XML Files in a Folder 和 Compare Two XML Files Ignoring Formatting 各可免费试用 3 次。之后需要 Zovo Pro，一次性 19 美元，适用于所有 Zovo 扩展。

格式化会改动我的文本或 CDATA 吗？

不会。只有在只包含标签、不含文本的元素中，标签之间的空白才会改变。文本、CDATA、注释和 xml:space="preserve" 内的内容都原样复制，再格式化一次也不会有任何变化。

为什么我的 XPath 在 pom.xml 中什么都选不到？

这个文件有默认命名空间。在这个扩展中，普通名称也能匹配默认命名空间，所以 //dependency 可以用。如需严格的 XPath 1.0，打开 xmlXpathTools.xpath.strictNamespaces。

能在 Cursor 中使用吗？

能。Cursor、Windsurf 和 VSCodium 从 Open VSX 安装它，这个扩展在那里的名称是 zovo/zovo-xml-xpath-tools。
