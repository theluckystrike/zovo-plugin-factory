在 VS Code 中的步骤

  1. 从 Marketplace 安装 TIFF Viewer，或者按 Ctrl+P（macOS 上按 Cmd+P）后运行 ext install zovo.tiff-viewer。
  2. 在 Explorer 中点击 .tif 或 .tiff 文件，它会在 TIFF Viewer 中打开。如果打开的是别的查看器，右键点击文件，选择 “Open in TIFF Viewer”，或者在编辑器标题菜单中使用 “Reopen Editor With...”。
  3. 滚动滚轮缩放，拖动平移。状态栏显示指针下像素的存储值。
  4. 多页文件可以在页面条中选择页面，或者按 PageDown 和 PageUp（或 J 和 K）翻页。
  5. 16 位或浮点数据可以用 Channel 和 Contrast stretch 控件调整（min 到 max、2% 到 98%，或该类型的完整范围）。按 T 打开标签面板，文件带 GeoTIFF 标签时会有 GeoTIFF 一节。
  6. 点击 Export PNG，按当前显示效果保存当前页，包括你选的通道和拉伸。这个功能免费。

哪些免费，Zovo Pro 增加什么

查看每一页、通道和对比度拉伸、指针下的像素值、TIFF 标签、GeoTIFF 坐标，以及按显示效果 Export PNG 都免费。查看功能离线可用，不需要登录。

Export pages 把当前页，或多页文件的每一页，保存为全分辨率 PNG。选择 “stored values” 时，8 位和 16 位数据会以 8 位或 16 位 PNG 保存，数值完全不变；有符号、32 位和浮点数据会按显示范围映射到 16 位，PNG 的文本信息里写明了如何还原数值。GeoTIFF 页面还会生成 .pgw 世界文件和 .geojson 范围框，PNG 在 QGIS 或 ArcGIS 中能放到正确的位置。

使用 Export pages（Zovo Pro）

  1. 打开 TIFF，点击查看器工具栏中的 Export pages。文件打开时，也可以从 Command Palette 运行 “TIFF Viewer: Export Pages to PNG (Pro)...”。
  2. 选择 “Page N with the stored values”（16 位数据得到 16 位 PNG）或 “Page N as shown”（8 位）。多页文件还可以选 “All N pages with the stored values” 或 “All N pages as shown”。
  3. 输入文件名（导出所有页时选择文件夹），然后保存。只有 PNG 写出后才算一次试用，按 Escape 不消耗次数。
  4. 要转换整个文件夹的 TIFF，右键点击文件夹，运行 “TIFF Viewer: Batch Convert TIFF Folder to PNG (Pro)...”（这也是 Pro 工具）。

Export pages 在你的电脑上可以免费用 3 次，之后才需要许可证。没有弹窗，也没有倒计时。

在 Cursor、Windsurf 或 VSCodium 中的步骤

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）打开 Extensions 视图。
  2. 搜索 zovo.tiff-viewer，点击 Install。Cursor、Windsurf 和 VSCodium 从 Open VSX 安装扩展，这个扩展在那里的名称是 zovo/tiff-viewer。
  3. 如果编辑器没有扩展商店，就在 Open VSX 页面下载 .vsix 文件，然后运行 “Extensions: Install from VSIX...”。
  4. 之后的用法和 VS Code 里一样。

TIFF Viewer 能做什么

  • 经典 TIFF 和 BigTIFF，大端和小端，条带（strip）和瓦片（tile），chunky 和 planar 存储。
  • 1 到 64 位无符号和有符号整数，以及 16、32 和 64 位浮点采样，支持按百分位拉伸对比度。
  • 灰度、RGB 和 RGBA、调色板、CMYK，以及 JPEG 中的 YCbCr；支持无压缩、LZW、Deflate、PackBits、JPEG 以及 CCITT Group 3 和 Group 4。
  • 多页文件带页面条，前 300 页有缩略图。
  • GeoTIFF 标签，包括 EPSG 代码、像素大小、范围、nodata 值和指针所在位置的地图坐标。

它做不到的事

  • 使用 ZSTD、LERC、WebP 和 JPEG 2000 压缩的页面会列出标签，但不会解码。
  • 超过 1 GB 的文件（设置项 tiffViewer.maxFileMB，默认 1024）不会解码，只显示提示和每一页的标签。
  • 单边超过 6000 像素或总像素超过 2,400 万的页面，显示时每隔 N 个像素取一个；指针读数和统计值仍按全分辨率计算。
  • 每像素少于 8 位的瓦片页面和未压缩的 YCbCr 不会解码。SubIFD 中的子图像（某些 DNG 和 OME-TIFF 金字塔）会在标签中列出，但不作为页面显示。
  • 查看器是只读的，从不写入 TIFF 文件。它不提供地图瓦片，也不做重投影。

常见问题

TIFF 转 PNG 会损失画质吗？

PNG 是无损格式。只有把 16 位数据降成 8 位时才会损失。在 Export pages 中选择保存存储值（stored values），8 位和 16 位的数值都能保持不变。

它免费吗？

查看 TIFF 文件和按显示效果 Export PNG 都免费。Export pages、Batch convert 和 Region stats 是 Pro 工具，各可免费试用 3 次，之后需要 Zovo Pro，一次性付费，适用于所有 Zovo 扩展。

图片会被上传吗？

不会。扩展自身不发网络请求，也没有遥测。文件都在你的电脑上读取和写入。

能在 Cursor 或 Windsurf 中使用吗？

可以。Cursor、Windsurf 和 VSCodium 从 Open VSX 安装扩展，TIFF Viewer 已发布在 Open VSX 上。
