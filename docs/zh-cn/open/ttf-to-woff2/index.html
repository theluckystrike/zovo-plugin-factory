在 VS Code 中的步骤

  1. 从 Marketplace 安装 Font Viewer，或者按 Ctrl+P（macOS 上按 Cmd+P）后运行 ext install zovo.font-viewer-vscode。
  2. 在 Explorer 中点击 .ttf 或 .otf 文件，它会在 Font Viewer 中打开。Font Viewer 是只读的，不会修改字体。如果打开的是别的编辑器，右键点击文件，选择 “Open in Font Viewer”。
  3. 在 Type tester 标签页输入示例文字，拖动字号滑块，调整可变字体的轴滑块，并打开或关闭 OpenType 特性。
  4. 在网站上使用字体之前，打开 Info 标签页查看许可证、设计者和嵌入权限。
  5. 在 Type tester 中点击 Copy CSS 获取 @font-face 规则，或者在 Explorer 中右键点击字体文件，选择 “Copy CSS @font-face”。
  6. 要生成 WOFF2 文件，运行 Convert Font（Zovo Pro 工具，见下文）。

Font Viewer 能做什么

  • TrueType .ttf（包括可变字体）和使用 CFF 轮廓的 OpenType .otf。
  • WOFF .woff 和 WOFF2 .woff2 字体。
  • 字体集合 .ttc 和 .otc，可在顶部的列表中选择其中的字体。
  • 每个字形及其名称和码位，可以按名称、字符、U+20AC 或字形 ID 搜索，并把轮廓复制为 SVG。
  • Unicode 区块覆盖情况、完整的 name 表、度量值、可变轴，以及 GSUB 和 GPOS 特性标签。

它做不到的事

  • 不支持 WOFF2 字体集合、SVG 字体、.dfont 和 Type 1 字体。
  • 超过 64 MB 的文件（设置项 fontViewer.maxFileMB）只显示提示，不会打开。
  • 字形轮廓显示的是可变字体的默认实例；Type tester、waterfall 和字符表会跟随轴滑块变化。
  • 彩色字体在 Type tester 和字符表中以彩色显示，但字形网格只显示普通轮廓。CFF2 可变字体在字形网格中直接用字体渲染，而不是根据轮廓绘制。
  • Convert Font 原样复制表数据。会重写字形数据的工具生成的 WOFF2 文件会再小几个百分点。

常见问题

它免费吗？

查看字体免费，包括 Type tester、字形、字符表、Info 标签页和 Copy CSS @font-face。Convert Font 和 Font Folder Report 是 Pro 工具，各可免费试用 3 次，之后需要 Zovo Pro，一次性付费，适用于所有 Zovo 扩展。

WOFF2 能小多少？

在 README 的测试中，WOFF2 大约是 TTF 大小的 45%（JetBrains Mono 可变字体从 96,940 字节降到 43,632 字节）。

转换会改变字体吗？

不会。表数据原样复制，轮廓、hinting、可变轴和特性都保持不变，源文件也不会被修改。

字体会被上传吗？

不会。Font Viewer 离线工作，不发网络请求，也不发送遥测数据。
