在 VS Code 中查看 PowerPoint .pptx 幻灯片

免费的 PPTX Viewer 扩展可以直接在 VS Code 中打开 PowerPoint 演示文稿：.pptx、.ppsx、.potx、.pptm 和旧版 .ppt，带缩略图、演讲者备注、搜索和 Present 按钮。用脚本、python-pptx 或 AI 智能体生成幻灯片时尤其方便：文件每次保存，幻灯片都会自动刷新。不需要 PowerPoint 或 LibreOffice，也不上传文件。

免费，MIT 许可证。扩展 ID zovo.pptx-slide-viewer，版本 0.5.7。需要 VS Code 1.90.0 或更高版本。

在 VS Code 中的步骤

  1. 从 Marketplace 安装 PPTX Viewer 扩展，或按 Ctrl+P（macOS 上为 Cmd+P）并运行 ext install zovo.pptx-slide-viewer。
  2. 在资源管理器中点击 .pptx、.ppsx、.potx、.pptm 或 .ppt 文件。幻灯片和缩略图会显示出来，下方是演讲者备注。
  3. 按 Ctrl+F（macOS 上为 Cmd+F）在整个演示文稿的标题、要点、表格和备注中搜索。Outline 标签页会列出含有该词的幻灯片，按 Enter 跳到下一张。
  4. 点击 Present，一次全屏显示一张幻灯片，用方向键、空格键或鼠标点击翻页，按 Esc 回到编辑器。
  5. Copy: "PNG" 把当前幻灯片复制为图片（约 1920 像素宽），可以贴到 pull request 或 issue 里。Copy: "Markdown" 把幻灯片复制为 Markdown，"All" 复制整个演示文稿。
  6. 脚本重新生成演示文稿时保持文件打开：每次保存后，大约一秒内幻灯片就会更新，并停留在当前页。

免费功能与 Zovo Pro

查看幻灯片、Present、演讲者备注、搜索、缩略图和大纲、把单张幻灯片复制或保存为 PNG，以及 Copy as Markdown，全部免费。

要把演示文稿发给没有 PowerPoint 的人，Export Deck as PDF 会保存一个 PDF，每张幻灯片一页，页面大小与幻灯片相同。页面是幻灯片的图片，所以 PDF 中的文字不能选中。Zovo Pro 还可以把所有幻灯片导出为 PNG、把一个文件夹里的演示文稿连同备注转换为 Markdown，以及为照片很多的演示文稿保存一个更小的副本（Compress Deck）。

使用 Export Deck as PDF（Zovo Pro）

  1. 打开演示文稿后，点击工具栏上的 Export 并选择 PDF，或在 Command Palette 中运行 "Export Deck as PDF (Pro)..."。
  2. 选择 PDF 的保存位置。
  3. 原始演示文稿不会被修改，图片在你的电脑上生成。

Export Deck as PDF 可以在你的电脑上使用 3 次，之后才会要求许可证，而且只有得到结果时才算一次。打开文件时不会出现任何 Pro 提示。

在 Cursor、Windsurf 或 VSCodium 中

这些编辑器从 Open VSX 安装扩展。按 Ctrl+Shift+X（macOS 上为 Cmd+Shift+X）打开 Extensions 视图，搜索 zovo.pptx-slide-viewer 并点击 Install。之后的用法与 VS Code 相同。

它不能做什么

  • 它是查看器，不能编辑幻灯片。
  • 旧版 .ppt 只以文字打开：标题、幻灯片文字和备注，没有图片和版式。
  • 视频、音频和嵌入对象不会绘制，幻灯片上会提示缺少了什么。
  • 电脑上没有安装的字体会用相近的字体代替，所以换行位置可能和 PowerPoint 略有不同。

常见问题

这个扩展收费吗？

不收费。查看、放映、搜索和复制幻灯片都是免费的。只有导出、压缩和对比演示文稿属于 Zovo Pro（一次性 USD 19），每项可以免费使用 3 次。

支持 Remote SSH、WSL 或 Codespaces 吗？

支持。扩展通过 VS Code 读取文件，所以在 Remote SSH、WSL、Dev Containers 和 Codespaces 中都能用。

文件会被上传吗？

不会。一切都在你的电脑上运行，没有遥测。
