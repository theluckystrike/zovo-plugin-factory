在 VS Code 中比较两个 Excel 或 CSV 文件

安装免费的 Excel Compare & XLSX Diff，选择两个工作簿或 CSV 文件。修改的单元格显示为黄色，旧值带删除线；新增的行为绿色，删除的行为红色。比较前会先对齐行，列按表头匹配，所以插入一行或一列只显示为一处变化。提交前还可以把工作簿与它的 Git HEAD 版本比较。以上功能全部免费，不发送任何网络请求。Zovo Pro（一次性 19 美元）增加三个工具，即 Export a diff report、Match rows by key columns 和 Compare two folders of workbooks，每个工具可免费试用 3 次。

在 VS Code 中的步骤

  1. 从 Marketplace 安装 Excel Compare & XLSX Diff，或者按 Ctrl+P（macOS 上按 Cmd+P）后运行 ext install zovo.zovo-excel-compare。
  2. 在 Explorer 中选中两个文件，右键选择 Compare Selected Excel Files。也可以右键一个文件，选择 Compare with...，再选另一个文件。或者在 Command Palette 中运行 "Excel Compare: Compare Two Excel or CSV Files..."。
  3. .xlsx、.xlsm、.xls、.ods、.csv 和 .tsv 可以任意搭配，因此可以把 .xlsx 和 .csv 放在一起比较。
  4. 先看摘要行，再看各工作表的标签，每个标签上显示该表的差异数。点击单元格可查看完整的旧值和新值，并可复制。
  5. 按 N 和 P（或点击 Next 和 Previous）可在所有工作表中逐个跳转到每处变化。在 Values 和 Formulas 之间切换，可以比较单元格显示的值，也可以比较公式本身。
  6. 要在提交前查看自己改了什么，在 Git 仓库中右键工作簿，选择 Compare with Git HEAD。

在 Cursor、Windsurf 或 VSCodium 中的步骤

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）打开 Extensions 视图。
  2. 搜索 zovo.zovo-excel-compare，点击 Install。Cursor、Windsurf 和 VSCodium 从 Open VSX 安装扩展，这个扩展在那里的名称是 zovo/zovo-excel-compare。

Excel Compare & XLSX Diff 能做什么

  • 工作表先按名称匹配，再按位置匹配。只在一个文件中存在的工作表会列为新增或删除。
  • CSV 和 TSV 会自动检测编码（带或不带 BOM 的 UTF-8、UTF-16、Windows 代码页）和分隔符（逗号、分号、制表符或竖线），也能处理带换行的引号字段。
  • 表格只绘制屏幕上可见的行，因此 300,000 行的大工作表滚动起来和短表一样。
  • 合并单元格不一致，或因限制截断了工作表时，会显示提示。
  • 另外两个 Pro 工具。Match rows by key columns 按 ID 列匹配行，排序或重排过的工作表也能干净地比较，移动过的行会被标出。Compare two folders of workbooks 按文件名配对，显示哪些文件相同、哪些不同、哪些只在一个文件夹中。

它做不到的事

  • 文件最大 200 MB（设置 excelCompare.maxFileSizeMB），每个工作表最多 300,000 行（excelCompare.maxRows），最多 1,000 列和 200 个工作表。触发限制时，视图中会显示提示。
  • 解压后会超过 600 MB 或像 zip 炸弹一样压缩的工作簿，会在解压前被拒绝。
  • 没有 Pro 工具 Match rows by key columns 时，行按内容和位置对齐，而不是按 ID 列。
  • 它只做比较，不编辑也不合并文件。

常见问题

免费吗？

比较两个工作簿或 CSV 文件、Values 和 Formulas、上一处和下一处变化以及 Compare with Git HEAD 都免费。三个 Pro 工具 Export a diff report、Match rows by key columns 和 Compare two folders of workbooks 各有 3 次免费试用。之后需要 Zovo Pro，一次性 19 美元，适用于所有 Zovo 扩展。

不装扩展，VS Code 能比较两个 Excel 文件吗？

不能。.xlsx 文件是由 XML 部件组成的 zip 包，内置的 diff 会把它当作二进制文件。需要一个能读取工作簿的扩展。

在顶部插入一行，下面的行会全部标为已修改吗？

不会。比较前会先对齐行，所以插入的行只显示为一行新增。

能看到工作簿自上次提交以来改了什么吗？

能。在 Git 仓库中右键该文件，选择 Compare with Git HEAD。它调用你本地的 git。
