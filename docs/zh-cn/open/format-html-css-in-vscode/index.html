在 VS Code 中的步骤

  1. 从 Marketplace 安装 HTML Formatter & CSS Formatter，或者按 Ctrl+P（macOS 上按 Cmd+P）后运行 ext install zovo.zovo-html-formatter。
  2. 打开 HTML、CSS、SCSS 或 LESS 文件，按 Shift+Alt+F（macOS 上按 Shift+Option+F）。如果 VS Code 询问使用哪个格式化程序，选择 HTML Formatter & CSS Formatter。
  3. 要一步把它设为这四种语言的默认格式化程序，在 Command Palette 中运行 "HTML Formatter: Use as Default Formatter for HTML, CSS, SCSS and LESS"。
  4. 选中几行后运行 Format Selection，只格式化这几行。
  5. 要在每次保存时格式化，打开 zovoHtmlFormat.formatOnSave；或者在它成为默认格式化程序后，使用 VS Code 自带的 editor.formatOnSave。
  6. 缩进先取编辑器设置，再取 .editorconfig（缩进风格和大小、行尾、文件末尾换行、最大行长），所以整个团队得到相同的结果。

在 Cursor、Windsurf 或 VSCodium 中的步骤

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）打开 Extensions 视图。
  2. 搜索 zovo.zovo-html-formatter，点击 Install。Cursor、Windsurf 和 VSCodium 从 Open VSX 安装扩展，这个扩展在那里的名称是 zovo/zovo-html-formatter。

HTML Formatter & CSS Formatter 能做什么

  • HTML 中 <style> 里的 CSS 和 <script> 里的 JavaScript。
  • 保持原样的内容：<pre> 和 <textarea> 的内容、所在行的行内标签、属性顺序、块之间的空行（连续最多保留一行）、页面 head 和 body 的缩进风格，以及 {{ }} 和 {% %} 这样的模板标签。
  • 在 SCSS 和 LESS 中，多行的 map 和函数调用保持原有布局，行尾注释留在原来的行上。
  • 另外两个 Pro 工具：Minify HTML and CSS 生成 .min.html 和 .min.css 副本，并报告节省的字节数和 gzip 字节数；HTML Lint Report 找出没有 alt 文本的图片、没有 label 的表单字段、重复的 id、跳级的标题等问题，输出到 Markdown 报告和 Problems 面板。

它做不到的事

  • 单独的 .js、.jsx、.ts、Vue 和 Svelte 文件不由此扩展格式化，只格式化 <script> 里的 JavaScript。
  • 除非设置了换行长度，否则不会自动折行，很长的行会保持原样。
  • SCSS 和 LESS 通过 CSS 格式化程序处理。LESS detached rulesets 这类不常见的语法可能保留原来的空格。
  • Minify 不压缩 JavaScript，也不重命名或合并 CSS 规则。

常见问题

免费吗？

HTML、CSS、SCSS 和 LESS 的 Format Document、Format Selection 和保存时格式化是免费的。三个 Pro 工具 Format Folder with Diff Preview、Minify HTML and CSS 和 HTML Lint Report 各有 3 次免费试用。之后需要 Zovo Pro，一次性 19 美元，适用于所有 Zovo 扩展。

不装扩展，VS Code 能格式化 HTML 吗？

能。VS Code 自带 HTML 和 CSS 格式化程序。此扩展会读取 .editorconfig，保留页面自身的 head 和 body 缩进，保持 SCSS 和 LESS map 的布局，并增加文件夹格式化、压缩和 lint 三个 Pro 工具。

它会改动我的 pre 块或调整属性顺序吗？

不会。pre 和 textarea 的内容、行内标签和属性顺序都保持你写的样子。

需要 Node 或 npm 吗？

不需要。js-beautify 1.15.4 已内置在扩展中，离线运行。
