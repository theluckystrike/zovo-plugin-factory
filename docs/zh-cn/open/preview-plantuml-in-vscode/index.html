在 VS Code 中的步骤

  1. 从 Marketplace 安装 PlantUML Viewer & Preview，或者按 Ctrl+P（macOS 上按 Cmd+P）后运行 ext install zovo.zovo-plantuml-viewer。
  2. 确认已安装 Java 11 或更高版本。扩展会依次在设置 plantumlViewer.javaPath、JAVA_HOME、PATH 中的 java 以及常见的 JDK 文件夹中查找。如果都找不到，预览中会提示，并提供 “Set the Java path” 按钮。运行 “PlantUML: Show Java and Layout Status” 可以查看找到了什么。
  3. 打开 .puml、.plantuml、.iuml、.pu 或 .wsd 文件，或包含 ```plantuml 代码块的 Markdown 文件，然后点击编辑器右上角的预览按钮。也可以在 PlantUML 文件中按 Alt+D，或运行 “PlantUML: Open Preview to the Side”。
  4. 直接输入。停止输入片刻后，预览会重新绘制（默认 400 ms，设置项 plantumlViewer.renderDelay）。文件中的所有图表都显示在同一个预览中，光标所在的图表会加上边框。
  5. 用按钮、按住 Ctrl 或 Cmd 滚动鼠标滚轮，或用 + 和 - 键缩放。点击 Fit 让图表适应面板宽度，拖动图表可以平移查看。出错的图表会显示 PlantUML 的错误信息和 “Go to line” 链接。
  6. 点击图表上方的 SVG 或 PNG 保存这一个图表，或点击 Copy SVG 复制它。

PlantUML Viewer & Preview 能做什么

  • 内置 PlantUML（MIT 版 1.2026.10）支持的时序图、类图、活动图、组件图、状态图、用例图、思维导图、甘特图以及其他 @start... 代码块。
  • Markdown 中的 ```plantuml、```puml 和 ```uml 代码块，里面写不写 @startuml 都可以。Markdown 文件中至少有一个这样的代码块时，才会显示预览按钮。
  • 离线处理 !include：可以引用图表所在文件夹、工作区文件夹和 plantumlViewer.includePaths 中的文件，以及标准库，例如 !include <C4/C4_Container>。写成 https://raw.githubusercontent.com/... 地址的 C4、AWS 图标和图标字体 include 会从 jar 内的副本读取。
  • 时序图、思维导图和甘特图不需要布局引擎。类图、组件图、状态图和用例图在安装了 dot 时使用 Graphviz（plantumlViewer.layout 设为 auto），没有安装时使用 PlantUML 内置的 Smetana 引擎。
  • 图表以图片形式显示，因此图表中的链接或文字无法在编辑器中运行代码。

它做不到的事

  • 必须安装 Java 11 或更高版本。扩展不会下载 Java。
  • 来自网络地址的 include 会被拒绝，但 jar 自带副本的 C4、AWS 图标和图标字体地址除外。AWS 图标来自 PlantUML 内置的 AWS 图标集（版本 20），更新的图标会显示一条写出其名称的错误。
  • PlantUML 的 MIT 版不包含 Ditaa，也不包含 @startmath 所用的 LaTeX 渲染器。Ditaa 代码块会显示 PlantUML 的 “not supported” 页面。
  • 没有 Graphviz 时，Smetana 对类图和组件图的布局会略有不同，非常大的类图可能显得更紧凑。
  • 绘制时间超过 30 秒的图表会被停止（设置项 plantumlViewer.renderTimeoutSeconds），图片每边最多 8192 像素，超出部分会被裁掉（设置项 plantumlViewer.maxImageSize）。

常见问题

免费吗？

实时预览、缩放和平移、错误链接、把单个图表保存为 SVG 或 PNG、语法高亮和代码片段都免费。三个 Pro 工具 Export All Diagrams in a Folder、Markdown Diagrams to Images 和 Compare with a Git Version 各可免费试用 3 次。之后需要 Zovo Pro，一次性 19 美元，适用于所有 Zovo 扩展。

需要 Java 或 Graphviz 吗？

需要 Java 11 或更高版本，因为 PlantUML 是一个 Java 程序。不需要 Graphviz。没有它时，类图和组件图使用 PlantUML 内置的 Smetana 布局引擎；如果安装了 dot，就会使用它。

我的图表会发送到服务器吗？

不会。内置的 PlantUML jar 在你的电脑上以 ALLOWLIST 安全配置运行，来自网络地址的 include 会被拒绝。不会使用任何 PlantUML 服务器。

能在 Cursor 中使用吗？

可以。Cursor、Windsurf 和 VSCodium 从 Open VSX 安装它，发布名称为 zovo/zovo-plantuml-viewer。
