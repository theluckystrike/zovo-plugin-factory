在 VS Code 中的步骤

  1. 从 Marketplace 安装 SQLite DB Viewer，或者按 Ctrl+P（macOS 上按 Cmd+P）后运行 ext install zovo.sqlite-table-viewer。
  2. 在 Explorer 中点击 .db、.sqlite、.sqlite3、.db3、.s3db、.sl3、.vscdb 或 .gpkg 文件，它会以只读表格打开。
  3. 在左侧选择一个表或视图。点击列标题排序，在标题下方输入内容进行过滤（例如 5..9 或 =word），也可以一次搜索所有列。
  4. 打开 Schema 标签页查看列、键、外键和 CREATE 语句，或者打开 SQL 标签页，一次执行一条语句。最近的 20 条语句会被保留。
  5. 要修改数据，点击 Enable editing。双击单元格，输入新值后按 Enter。每处改动都会进入待处理列表，附带对应的 SQL 和 Undo。
  6. 按 Save（Ctrl+S，macOS 上按 Cmd+S）。Save 会检查约束，生成一个备份副本，例如 name.db.20261109-143000.bak，然后一步替换原文件。

在 Cursor、Windsurf 或 VSCodium 中的步骤

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）打开 Extensions 视图。
  2. 搜索 zovo.sqlite-table-viewer，点击 Install。Cursor、Windsurf 和 VSCodium 从 Open VSX 安装扩展，这个扩展在那里的名称是 zovo/sqlite-table-viewer。
  3. 如果编辑器没有扩展商店，就在 Open VSX 页面下载 .vsix 文件，然后运行 “Extensions: Install from VSIX...”。
  4. 之后的用法和 VS Code 里一样。

SQLite DB Viewer 能做什么

  • 仍在 -wal 文件中的已提交行，应用写入时实时重新加载（点击 Live 按钮可关闭）。
  • 在单元格面板中，JSON 单元格显示为树，图片显示为图片，float32 BLOB 显示为向量。
  • 复制为 CSV、TSV、JSON 或 INSERT 语句，并能把当前视图中的行导出为 CSV、JSON 或 SQL INSERT 语句。
  • 把 CSV 和 TSV 导入新表或已有的表，带预览、列映射、进度条和 Cancel。
  • 最大 512 MB 的数据库，行数据按页读取。

它做不到的事

  • 整个数据库会载入内存。超过 512 MB 的文件只显示提示（设置项 sqliteTableViewer.maxFileSizeMB）。
  • 编辑仅限 256 MB 以内的文件（设置项 sqliteTableViewer.editMaxFileSizeMB），更大的文件保持只读。
  • 无法打开加密的数据库（SQLCipher、SEE）。
  • 只能编辑本机上的文件，远程或虚拟文件系统上的文件以只读方式打开。
  • 关闭标签页时，未保存的改动会被丢弃，文件保持原样。

常见问题

它免费吗？

打开、查看、SQL 标签页、编辑、Save 和 CSV 导入都免费，不需要账号。三个 Pro 工具（Compare SQLite Databases、ER Diagram 和 Export All Tables）各可免费试用 3 次，之后需要 Zovo Pro，一次性付费，适用于所有 Zovo 扩展。

能在 VS Code 中编辑数据行吗？

可以。文件默认以只读方式打开，点击 Enable editing 后就能修改单元格和行，或者运行 INSERT 和 UPDATE。按 Save 之前什么都不会写入，Save 会先生成一个备份副本。

为什么别的查看器显示的是旧数据？

在 WAL 模式下，新的提交会先留在 -wal 文件里，直到检查点（checkpoint）把它们复制到主文件。只读取主文件的查看器看不到这些行。这个扩展会读取 -wal 文件中已提交的部分。

能在 Cursor 中使用吗？

可以。它在 Open VSX 上的名称是 zovo/sqlite-table-viewer，Cursor、Windsurf 和 VSCodium 都能安装。
