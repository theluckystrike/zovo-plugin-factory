在 VS Code 中的步骤

  1. 从 Marketplace 安装 3D Model Viewer，或者按 Ctrl+P（macOS 上按 Cmd+P）后运行 ext install zovo.3d-model-viewer。
  2. 在 Explorer 中点击 .stl、.obj、.ply、.3mf、.glb 或 .gltf 文件。如果打开的是别的查看器，右键点击文件，选择 “Open in 3D Model Viewer”。
  3. 拖动旋转，右键拖动或按住 Shift 拖动平移，滚轮缩放。按 F 让整个模型适配视图。
  4. 面板里显示顶点数、三角面数、材质、纹理，以及以模型单位表示的尺寸。按 P 显示或隐藏面板和场景树。
  5. 按 W 切换线框，按 N 显示顶点法线，按 B 显示包围盒。把 Shading 设为 Smooth，可以去掉 STL 文件常见的棱面感。
  6. 按 M（Measure），在模型表面点击两个点。连线上显示距离，状态栏还会给出 X、Y、Z 分量。按 Esc 结束测量。
  7. 点击 Screenshot，把当前视图保存为 PNG 文件。

在 Cursor、Windsurf 或 VSCodium 中的步骤

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）打开 Extensions 视图。
  2. 搜索 zovo.3d-model-viewer，点击 Install。Cursor、Windsurf 和 VSCodium 从 Open VSX 安装扩展，这个扩展在那里的名称是 zovo/3d-model-viewer。

3D Model Viewer 能做什么

  • STL，二进制和 ASCII 都支持，文件带逐面颜色时会显示颜色。
  • OBJ，以及 mtllib 指定的 .mtl 文件（需要放在模型旁边）。
  • PLY 网格和点云，ASCII 和二进制，支持顶点颜色。
  • 3MF 的对象、构建项和基础材质颜色。
  • GLB 和 glTF 2.0，支持内嵌或外部 .bin 缓冲和纹理、PBR 材质、节点树、蒙皮、morph target 和动画。

它做不到的事

  • FBX、DAE、USD、STEP、IGES 和 glTF 1.0 文件无法打开。
  • 暂不支持解码 Draco 和 meshopt 压缩的 glTF 以及 KTX2 纹理，提示信息会写明缺少哪个扩展。
  • 整个文件会读入内存。超过 1024 MB 的文件（设置项 modelViewer.maxFileMB）只显示提示，不会读取。
  • STL、OBJ 和 PLY 没有单位，所以尺寸和距离是原始坐标值。glTF 以米为单位，3MF 以毫米为单位，除非文件另有说明。
  • Print check 和 Section view 读取可见的网格，最多 300 万个三角面，并且需要网格，不支持点云。重量只是估算，不计算支撑、裙边（brim）以及顶层和底层。

常见问题

STL 的测量单位是什么？

STL 文件不带单位，所以查看器显示的是原始坐标值。Print check 会把 STL、OBJ 和 PLY 当作毫米处理，如果你的文件用的是别的单位，可以在它的面板里修改。

能打开带材质的 OBJ 文件吗？

可以，只要 mtllib 指定的 .mtl 文件放在模型旁边。纹理和 .bin 文件只会从模型所在文件夹和当前打开的工作区文件夹中加载。

它免费吗？

免费。打开模型、测量、统计信息、场景树和截图都免费。Print check、Section view 和 Turntable export 是 Zovo Pro 工具，各可免费试用 3 次，之后需要 Zovo Pro，一次性付费，适用于所有 Zovo 扩展。

可以离线使用吗？

可以。它在 VS Code 内用 three.js 绘制，没有遥测，也不发网络请求。唯一的例外是用 GitHub Sponsors 开通 Zovo Pro 时会访问 GitHub。
