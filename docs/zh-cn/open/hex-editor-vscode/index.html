中文指南 · Hex Viewer

VS Code 中的十六进制编辑器

免费的 Hex Viewer 扩展可以在 VS Code 中显示任意文件的字节，从空文件到 4 GB 的磁盘镜像。它只读取屏幕上显示的行，测试中一个 4 GB 的文件 0.6 秒就打开了。你可以跳转到偏移、用 ?? 通配符搜索字节、在数据检查器中读取数值、插入和删除字节并撤销，还能逐字节对比两个文件。

在 VS Code 中安装Marketplace 页面Open VSX (Cursor, Windsurf, VSCodium)

免费，MIT 许可证。扩展 ID zovo.zovo-hex-viewer，版本 0.3.7。需要 VS Code 1.90.0 或更高版本。

在 VS Code 中的步骤

  1. 从 Marketplace 安装 Hex Viewer 扩展，或按 Ctrl+P（macOS 上为 Cmd+P）并运行 ext install zovo.zovo-hex-viewer。
  2. 在资源管理器中右键点击任意文件，选择 "Open in Hex Viewer"。.bin、.dat、.img、.rom、.dmp 和 .dump 文件点击即在 Hex Viewer 中打开。
  3. Ctrl+G（macOS 上为 Cmd+G）跳转到偏移，例如 0x1F40、+0x100、-16 或 end。Ctrl+F 搜索 50 4B 03 04 这样的字节，用 ?? 代表任意字节，也可以搜索文本或 UTF-16 文本。
  4. 右侧的数据检查器把光标处的字节读作 8 到 64 位整数、浮点数、Unix 时间、GUID 等。点击 "Little-endian" 切换字节序。
  5. 输入两个十六进制数字即可覆盖一个字节。按 Insert 切换到插入模式，文件会变长。Ctrl+Z 撤销，Ctrl+S 保存。
  6. 要对比两个文件，在资源管理器中选中它们，选择 "Compare in Hex Viewer"。F7 跳到下一处差异。

免费功能与 Zovo Pro

查看任意大小的文件、跳转到偏移、搜索、Copy as（十六进制、C 数组、Python bytes、base64）、数据检查器、插入和删除字节的编辑、撤销、安全保存，以及两个文件的对比，全部免费，并且会一直免费。

要校验下载的文件或固件时，Checksums of File 一次读完就算出文件或选区的 CRC-32、Adler-32、MD5、SHA-1、SHA-256 和 SHA-512，4 GB 的文件也可以，而且不必先打开文件。Zovo Pro 还提供二进制模板的嵌套字段（ELF、PE、PNG、ZIP 等）、带备注的书签、对比报告、多文件搜索，以及熵图和字节直方图。

使用 Checksums of File（Zovo Pro）

  1. 在资源管理器中右键点击一个或多个文件，选择 Checksums of File。文件已打开时，用数据检查器下方的 "Checksums..." 按钮计算选区的校验值。
  2. 结果以列表显示。
  3. 选择一个值即可复制。

Checksums of File 可以在你的电脑上使用 3 次，之后才会要求许可证，而且只有得到结果时才算一次。打开文件时不会出现任何 Pro 提示。

在 Cursor、Windsurf 或 VSCodium 中

这些编辑器从 Open VSX 安装扩展。按 Ctrl+Shift+X（macOS 上为 Cmd+Shift+X）打开 Extensions 视图，搜索 zovo.zovo-hex-viewer 并点击 Install。之后的用法与 VS Code 相同。

它不能做什么

  • Copy as 最多 32 MB，粘贴最多 16 MB。
  • 远程或虚拟文件系统上的文件最大可打开 256 MB（设置项 hexViewer.maxRemoteMB）。
  • 文本文件和 Intel .hex 文件仍在文本编辑器中打开。

常见问题

这个扩展收费吗？

不收费。查看、编辑和对比都是免费的。校验值、模板的嵌套字段、书签和其他 Pro 工具属于 Zovo Pro（一次性 USD 19），每项可以免费使用 3 次。

保存大文件安全吗？

安全。大小不变时只写入改动的字节；大小改变时，扩展先写一个新副本再替换旧文件，所以磁盘满了也不会留下写了一半的文件。

可以离线使用吗？

可以。没有遥测，也没有网络请求。
