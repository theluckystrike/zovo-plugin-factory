在 VS Code 中的步骤

  1. 从 Marketplace 安装 Convert to Markdown，或者按 Ctrl+P（macOS 上按 Cmd+P）后运行 ext install zovo.zovo-convert-to-markdown。
  2. 在 Explorer 中右键 .pdf、.docx、.pptx、.xlsx、.xls、.ods、.csv、.tsv、.html、.epub、.odt 或 .rtf 文件，选择 Convert to Markdown。也可以右键已打开文件的标签页。
  3. 也可以在 Command Palette 中运行 “Convert to Markdown: Convert to Markdown”。它会转换当前标签页中的文件，如果没有，会让你选择一个文件。
  4. Markdown 会作为未保存的文档在文件旁边打开。转换大文件时会显示进度，并带有 Cancel 按钮。
  5. 保存文档。文件名会自动填为源文件旁边的 name.md。如果想每次都直接保存到那里，把 toMarkdown.output 设为 file。
  6. 如果要把 Markdown 粘贴到别处，右键文件并选择 Copy as Markdown。在 Explorer 中选中多个文件时，会逐个转换。
  7. 手边没有文件？在 Command Palette 中运行 “Convert to Markdown: Convert a sample file”，转换扩展自带的 Word、PDF 或 PowerPoint 示例文件。

在 Cursor、Windsurf 或 VSCodium 中的步骤

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）打开 Extensions 视图。
  2. 搜索 zovo.zovo-convert-to-markdown，点击 Install。Cursor、Windsurf 和 VSCodium 从 Open VSX 安装扩展，这个扩展在那里的名称是 zovo/zovo-convert-to-markdown。

Convert to Markdown 能做什么

  • 对于 PDF，根据字号识别标题，把断开的行和行尾用连字符拆开的单词拼回段落，识别列表和简单表格，双栏页面按栏依次读取。重复出现的页眉、页脚和页码会被去掉。
  • Word（.docx、.docm、.dotx）保留标题、粗体、斜体、删除线、链接、嵌套列表、表格、引用块和脚注。
  • PowerPoint（.pptx、.pptm、.ppsx、.potx）每张幻灯片生成一个 ## Slide n: title 小节，包含项目符号及其层级、表格和演讲者备注。
  • Excel 等电子表格（.xlsx、.xlsm、.xlsb、.xls、.ods）每个工作表生成一个 ## Sheet: name 小节和一张管道表格。CSV 和 TSV 生成一张表格。
  • HTML（.html、.htm、.xhtml）中的代码块保留语言标记，脚本和样式会被去掉；EPUB 按阅读顺序输出每一章。

它做不到的事

  • 扫描版 PDF（页面图片）没有可转换的文字。不包含文字识别（OCR）。
  • PDF 表格是根据列之间的空白识别的。没有明显空白的表格会输出为段落。
  • 免费转换中，图片会变成 *[Image: Map of the site]* 这样的占位符。幻灯片中的图表、SmartArt 和视频只写出名称，不做转换。
  • 旧版 Word 97-2003 文件和 RTF 只输出文字和表格，不带格式。受密码保护的文件和旧版 PowerPoint 97-2003 文件不会被转换，只会显示一条提示。
  • 超过 200 MB 的文件不会被转换（设置项 toMarkdown.maxFileSizeMB），PDF 转到 1000 页后停止（设置项 toMarkdown.pdfMaxPages）。

常见问题

免费吗？

Convert to Markdown 和 Copy as Markdown 对所有格式都免费。三个 Pro 工具 Convert a Folder to Markdown、Convert to Markdown with Images 和 LLM-ready Markdown Chunks 各可免费试用 3 次。之后需要 Zovo Pro，一次性 19 美元，适用于所有 Zovo 扩展。

会上传我的文件吗？

不会。转换器在你的电脑上、在 VS Code 内部运行，没有网络请求，也没有遥测。

能转换扫描版 PDF 吗？

不能。扫描版 PDF 里是页面图片，不是文字，而 Convert to Markdown 没有 OCR。

能在 Cursor 中使用吗？

能。Cursor、Windsurf 和 VSCodium 从 Open VSX 安装它，这个扩展在那里的名称是 zovo/zovo-convert-to-markdown。
