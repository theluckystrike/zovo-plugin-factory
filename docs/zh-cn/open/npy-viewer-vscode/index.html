在 VS Code 中的步骤

  1. 从 Marketplace 安装 Tensor Viewer，或者按 Ctrl+P（macOS 上按 Cmd+P）后运行 ext install zovo.tensor-viewer。
  2. 在 Explorer 中点击 .npy 或 .npz 文件。表格列出每个数组的名称、类型、shape、参数量和大小。
  3. 点击一个数组。右侧面板显示 min、max、mean、std 以及 NaN、Inf 和零值的数量，然后是二维数组的热力图或一维数组的折线图，以及直方图。
  4. 在 Values 表格中查看数值，每次 32 行。三维及以上的数组可以在 Slice 输入框中输入切片，例如 [5, :, :]。
  5. 如果数组的形状像图像，例如 (H, W, 3) 或 (N, 3, H, W)，Image 区域会把它画出来，可以在那里选择 Layout、Frame 和 Range。浮点矩阵则显示一个 “Show as image” 按钮。
  6. 点击 “Save as .npy...” 或 “Save as CSV...”，把数组或当前切片写入新文件。

在 Cursor、Windsurf 或 VSCodium 中的步骤

  1. 按 Ctrl+Shift+X（macOS 上按 Cmd+Shift+X）打开 Extensions 视图。
  2. 搜索 zovo.tensor-viewer，点击 Install。Cursor、Windsurf 和 VSCodium 从 Open VSX 安装扩展，这个扩展在那里的名称是 zovo/tensor-viewer。
  3. 如果编辑器没有扩展商店，就在 Open VSX 页面下载 .vsix 文件，然后运行 “Extensions: Install from VSIX...”。
  4. 之后的用法和 VS Code 里一样。

Tensor Viewer 能做什么

  • .npy 文件，支持 v1、v2、v3 文件头，C 和 Fortran 顺序，大端和小端字节序。
  • .npz 压缩包，支持未压缩（stored）和 deflate 压缩的条目，包括 zip64。
  • bool、int8 到 int64、uint8 到 uint64、float16、float32、float64 和复数（统计值按模计算）。
  • 形状像图像的数组、图像堆栈和批次会画成图片，一次显示一帧。
  • 同一个扩展还能打开 .safetensors、.gguf 以及 PyTorch 的 .pt、.pth 和 .ckpt 文件。

它做不到的事

  • pickle 序列化的对象数组只会列出并被拒绝加载，绝不会执行。文本和结构化数组只列出，不计算统计值。
  • 超过 2,000,000 个值的数组在计算统计值和绘图时会抽样（设置项 tensorViewer.sampleValues），面板会注明统计值来自抽样。
  • 压缩的 .npz 条目只从头读取，前 64 MB 之后的值不会显示，超过 512 MB 的条目无法保存。
  • 图片的长边最多绘制 512 像素。双通道数组和 Fortran 顺序的数组没有图片视图。
  • CSV 导出最多 2,000 万个值。大于 2^53 的 int64 值在表格和 CSV 中会丢失最后几位。

常见问题

它免费吗？

打开 .npy 和 .npz 文件、统计值、图表、图片、Values 表格以及 Save as .npy 或 CSV 都免费。两个 Pro 工具 Compare two checkpoints 和 Scan all tensors 各可免费试用 3 次，之后需要 Zovo Pro，一次性付费，适用于所有 Zovo 扩展。

需要 Python 吗？

不需要。Tensor Viewer 自己读取文件，不需要安装 Python 和 NumPy。

打开网上下载的 .npy 文件安全吗？

文件里的任何内容都不会被执行。NumPy 以 pickle 存储的对象数组只会被列出并拒绝加载，查看器也不会修改它显示的文件。

能在 Cursor 中使用吗？

可以。Tensor Viewer 在 Open VSX 上的名称是 zovo/tensor-viewer，Cursor、Windsurf 和 VSCodium 都能安装。
