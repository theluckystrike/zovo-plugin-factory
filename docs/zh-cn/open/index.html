在 VS Code 和 Cursor 中打开文件

VS Code 可以打开文本、图片和部分视频。要查看 Word、PowerPoint、Excel、深色模式的 PDF 或二进制文件，需要安装扩展。每篇指南都给出在 VS Code 和 Cursor 中的步骤，并说明哪些功能免费、Zovo Pro 增加了什么。

  • 在 VS Code 中打开 .docx Word 文件
    VS Code 会把 .docx 当成二进制文件。安装免费的 DOCX Viewer 扩展后，Word 文档以预览方式打开，带搜索、大纲和深色模式。Cursor 中同样可用。
  • 在 VS Code 中查看 PowerPoint .pptx 幻灯片
    在 VS Code 或 Cursor 中打开 .pptx、.ppsx、.potx 和旧版 .ppt，带缩略图、演讲者备注、搜索和全屏放映。免费扩展，不上传文件。
  • 在 VS Code 中以表格方式打开 Excel 和 CSV
    在 VS Code 中把 .xlsx、.xls、.ods、CSV 和 Parquet 显示为可排序、可筛选的表格，最多 1,000,000 行，还能用 SQL 做 GROUP BY。免费扩展，不需要 Excel 或 Python。
  • 在 VS Code 中以深色模式阅读 PDF
    在 VS Code 中用深色或米黄色页面阅读 PDF，照片保持原本的颜色。带搜索、大纲、缩略图和可导出为 Markdown 的高亮。免费、离线的扩展。
  • VS Code 中的十六进制编辑器
    在 VS Code 中查看、编辑和对比任意文件的字节，最大可到 4 GB 的磁盘镜像。跳转到偏移、通配符搜索、数据检查器。免费、离线的扩展。
  • 在 VS Code 中自动重命名 HTML、JSX 和 Vue 标签
    修改 HTML、JSX 或 Vue 标签名时，配对的标签随输入同步修改。免费扩展，基于 VS Code 的 linked editing，支持自动闭合标签，撤销一次即可还原。
  • 在 VS Code 中查看和恢复 Claude Code 历史会话
    在 VS Code 中查看、搜索和恢复 Claude Code 与 Codex 的旧会话。子代理嵌套显示，文件修改显示为 diff，带 token 统计。只读，离线可用。
  • 在 VS Code 中对比两个 ZIP 文件
    在 VS Code 中免费打开 ZIP、JAR、TAR 和 GZ 文件，再用 Markdown 报告列出两个压缩包之间新增、删除或修改的文件（Zovo Pro）。
  • 在 VS Code 中把 DXF 转成 CSV：提取块属性和文字
    在 VS Code 中打开 DXF 图纸，把块属性、块数量、文字或图层保存为 CSV，用 Excel 打开。查看图纸免费，CSV 导出是 Zovo Pro 工具。
  • 在 VS Code 中预览 Mermaid 图
    用免费的 Mermaid Viewer 在 VS Code 中预览 .mmd 文件和 Markdown 里的 Mermaid 代码块。实时预览，导出 PNG 和 SVG，离线可用，无需登录。
  • 在 VS Code 中运行的免费 NetCDF 查看器
    在 Windows、macOS 或 Linux 上用 VS Code 打开 .nc NetCDF 文件，查看文件头、变量、带海岸线的地图和时间序列。也支持 HDF5 .h5 和 MATLAB 7.3 .mat。
  • 把音频响度标准化到目标 LUFS
    在 VS Code 中播放 WAV、MP3、FLAC、Ogg 和 Opus，免费查看 LUFS 响度表，再生成 -14、-16 或 -23 LUFS 的新 WAV 文件。离线处理，不上传。
  • 在 VS Code 中查看 .npy 和 .npz NumPy 文件
    用免费的 Tensor Viewer 在 VS Code 中打开 .npy 和 .npz NumPy 数组，查看 dtype、shape、统计值、热力图、图像和具体数值，不需要 Python。
  • 在 VS Code 中打开 PCAP 抓包文件
    用免费的 PCAP Viewer 在 VS Code 中查看 .pcap、.pcapng 和 .pcap.gz 抓包文件，包括数据包列表、协议树、十六进制窗格和过滤器。不需要 Wireshark。
  • 在 VS Code 中带声音播放 MOV、MKV、WebM 和 MP4 视频
    在 VS Code 中播放带 AAC 声音的 MP4、MOV 和 M4V，不用另装任何东西。装上 ffmpeg 后，MKV、WebM 和 AVI 也能播放。免费播放器，支持字幕。
  • 在 VS Code 中打开 SQLite 数据库
    用免费的 SQLite Viewer & Editor 在 VS Code 中打开 .db 或 .sqlite 文件，查看表、结构和 SQL，然后编辑单元格和行，保存时自动备份。
  • 在 VS Code 中查看 STL 文件
    用免费的 3D Model Viewer 在 VS Code 中打开 STL 文件，可以旋转、两点测量、看线框和模型统计。它还能打开 OBJ、PLY、3MF、GLB 和 glTF。
  • 把 TIFF 转成 PNG，不损失画质
    在 VS Code 中免费打开 TIFF、BigTIFF 和 GeoTIFF 文件，再把一页或所有页保存为 PNG，8 位和 16 位数值保持不变。离线处理。
  • 在 VS Code 中把 TTF 转成 WOFF2
    在 VS Code 中免费预览 TTF、OTF、WOFF 和 WOFF2 字体，再把 TTF 或 OTF 转成 WOFF2，新文件保存在源文件旁边。离线处理，不上传。
  • 不用 XMind 把 XMind 转成 PDF：所有画布合成一个 PDF
    不用安装 XMind，在 VS Code 中打开 .xmind 思维导图，把所有画布保存为一个 PDF，每个画布一页。查看免费，PDF 导出是 Zovo Pro 工具。
